Rust is a programming language that is as fast as C and C++ but stops most memory and threading bugs before the program runs. For years it was the language developers loved but few companies used. In 2025 and 2026 that changed, and some of the loudest voices in tech said so in public.

Here is what was actually said, what it means, and whether you should learn Rust.

## What Elon Musk said about Rust

On 19 February 2026, replying to a developer on X, Elon Musk [wrote](https://x.com/elonmusk/status/2024565280169677297): "Rust is pretty great. xAI code is mostly Rust and 𝕏 is rapidly replacing legacy Twitter Scala code with Rust."

That is a strong statement from the company behind the Grok models. It also marks a shift in his own view. In 2022 he was more cautious, [writing](https://x.com/elonmusk/status/1496293976692899843) that he was "a fan of Rust" and that it "clearly scales well, given that Discord uses it", but that for maximum performance on Tesla's car computer "nothing beats tight C with a customized compiler", and that his teams mostly used C++ and Python.

Four years on, the claim is that a frontier AI lab writes most of its code in Rust.

## What Google found in Android

The strongest evidence comes from Google. In November 2025 the Android team [reported](https://security.googleblog.com/2025/11/rust-in-android-move-fast-fix-things.html) three results:

- Rust code showed roughly a **1000x lower density of memory-safety vulnerabilities** than Android's C and C++ code.
- Memory-safety bugs fell **below 20%** of all Android vulnerabilities, for the first time.
- Rust changes had about a **4x lower rollback rate**, meaning fewer changes had to be undone after shipping.

The last point surprises people. Rust is often described as slower to write, but Google's teams found it faster to get changes right.

## What Microsoft said

In September 2022 Mark Russinovich, then Microsoft Azure CTO, [posted](https://www.theregister.com/2022/09/20/rust_microsoft_c/) that "it's time to halt starting any new projects in C/C++ and use Rust" for cases that need a language without a garbage collector.

In December 2025 a Microsoft distinguished engineer, Galen Hunt, went further on LinkedIn. He [wrote](https://www.theregister.com/2025/12/24/microsoft_rust_codebase_migration/) that his goal was "to eliminate every line of C and C++ from Microsoft by 2030", using AI and algorithms to translate code at the scale of "1 engineer, 1 month, 1 million lines of code". After the post went viral he clarified that Windows is not being rewritten in Rust with AI, and that his team's work is a research project.

The honest reading: Microsoft is serious about Rust for new and high-risk code, and is researching AI-assisted translation, but there is no announced plan to rewrite Windows.

## What the Linux kernel decided

Rust support entered the Linux kernel in 2022 as an experiment. At the December 2025 Maintainers Summit, the developers [declared the experiment over](https://lwn.net/Articles/1050308/). As Rust-for-Linux lead Miguel Ojeda put it in his patch, the experiment is done and Rust is here to stay. Drivers, including parts of Android's Binder, are now being written in Rust.

For the most important open-source project in the world, that is a big step.

## What developers say

In the [2025 Stack Overflow Developer Survey](https://survey.stackoverflow.co/2025/technology/), Rust was again the most admired language: **72%** of developers who used it wanted to keep using it. Its build tool, Cargo, was the most admired tool in its category.

## Why this matters for AI

AI is not only models. It is also the systems around them: data pipelines, tokenizers, vector databases, inference servers, agents and developer tools. Much of that layer is moving to Rust because it needs to be fast, run many things at once and not crash.

You may already use Rust without knowing it. Hugging Face tokenizers, the Polars data-frame library, the uv package manager and the Ruff linter are all written in Rust. Our lesson on [Rust for AI](/stop/rust-for-ai-and-python) shows how Python teams speed up one slow step by moving it to Rust, without leaving Python.

## Should you learn Rust?

**Yes, as your second language,** if any of these is you:

- You are an AI, ML or MLOps engineer who wants to work on infrastructure, inference or tooling.
- You are a back-end developer in fintech, payments or any system where crashes and latency cost money.
- You enjoy understanding how computers work and want a skill few people in the job market have.

**Not yet,** if you are new to programming. Learn Python first, because it is what AI courses and most AI jobs use. Come back to Rust once you can build a small project end to end.
