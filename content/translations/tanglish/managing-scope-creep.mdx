## Idhu enna

**Scope creep**-na time, budget illa vera scope-la porundha maatram illaama, oru project deliver panna vendiya vishayam mella mella valarradhu. AI projects-la adhu aadikkadi paadhippu illaadhadhu maadhiri therium:

- "Idhu Tamil documents-aiyum handle pannumaa?"
- "Collections team-kum idhe venum-nu kekkuraanga."
- "Summary mattum illa, credit decision-aiyum edukkumaa?"
- "WhatsApp-aiyum serthudalaam."

Ovvoru request-um sariyaanadhaa irukkalaam. Serndhu, informal-aa othukkittaa, core deliverable-a adhoda date-ku appaala thalli, success-na enna-ngradha mangalaakkum.

```flow
Request varudhu | "idhoda serthu idhayum..." -> "Naan size panni Thursday-kulla varen" -> Size pannunga | velai, risk, time, cost, edhai displace pannum
Size pannunga -> Options
Options -> Swap | adha serthu, same size-la onna eduthudunga
Options -> Extend | adha serthu, date-a nagarthunga illa budget serunga
Options -> Later | adutha phase-ku, ippo irukkura gate-ku apram
Options -> No | purpose-oda illa rules-oda mothudhu
Swap -> Business owner decide pannuvaanga
Extend -> Business owner decide pannuvaanga
Later -> Business owner decide pannuvaanga
No -> Business owner decide pannuvaanga
Business owner decide pannuvaanga -> Change request log | yaar, enna, decision, date
```

Indha lesson, Chennai-la oru lender-oda credit-file pilot-oda vaaram ezhu-a follow pannum, appo oru vaaraththula moonu requests vandhana.

## Idhu eppadi work aagudhu

**Kandupidinga.** "Idhoda serthu idhayum" nu aarambikkura requests-a, agree panna users-ku velila irundhu varra requests-a, "done"-na enna-ngradha maathura changes-a paarunga. Ovvondraiyum scope of work-oda check pannunga.

**Appovae yes sollavae vendaam.** Sollunga: "Nalla idea. Naan size panni, Thursday-kulla adhukku enna aagum, edhu nagarum-nu solli varen."

**Size pannunga.** Ovvoru request-kum: involve aagura velai, risks (pudhu language-ku pudhu eval data thevai, veru model-um thevai padalam), timeline-layum cost-layum effect, adhu edhai displace pannum.

**Refusals illa, options kudunga.** Podhuvaa:

1. *Swap*: adha serthu, same size-la onna eduthudunga.
2. *Extend*: adha serthu, date-a nagarthunga illa budget serunga.
3. *Later*: adutha phase-ku, ippo irukkura gate-ku apram, list-la vainga.
4. *No*: project-oda purpose-oda illa client-oda sondha rules-oda mothumbodhu (example regulatory review illaama AI credit decisions edukka vidradhu).

**Decisions-a record pannunga.** Request, yaar kettaanga, sizing, decision, yaar approve pannaanga, eppa-nu oru change request log. Approve panravanga SOW-la peru sollapatta business owner-a irukkanum, ketta aal illa.

**Relationship-a kaappaatthunga.** Velai valuable-aa irukkarathaala makkal adhigam kekkaraanga. Nandri sollunga, adha serious-aa edukkureenga-nu kaattunga, trade-off-a theriyura maadhiri vainga; perumbaalaana clients choice kudukkaradha mathippaanga.

**Oru change request log:**

| Request | Yaarkitta irundhu | Sizing | Recommendation | Decision | Date |
| --- | --- | --- | --- | --- | --- |
| Collections correspondence summaries | Collections head | Sumaar 4 vaaram, pudhu golden set | Later: phase 2 | Head of operations accept pannaanga | Vaaram 7 |
| Tamil salary slips | Regional credit head | Sumaar 8 naal, Tamil OCR, 50 examples | PDF export-oda swap | Accept aachu | Vaaram 7 |
| Approve illa reject recommendations | Senior officer | Regulatory, fairness review thevai | Indha project-ku no | Accept aachu | Vaaram 7 |

**AI velaiya nermaiyaa size panradhu.** Entha pudhu language, document type, task-kum ivai irukkanum: golden set-ku examples collect panni label panradhu, ippo irukkura model-um parsing-um adha handle panradha check panradhu, evals run panni failures fix panradhu, guardrails-um adhoda tests-um update panradhu, users-ku training. Code change-a mattum size panra teams, vazhakkamaa paadhi alavu kuraichu estimate pannuvaanga.

**Nallaa no sollradhu.** Aal-kku nandri sollunga, project-oda purpose-oda illa client-oda rules-oda connect aana kaaranatha oru vaakkiyathula sollunga, oru vazhi kudunga: oru thaniyaana assessment, oru later phase, illa ketka vendiya sariyaana team. Makkal perumbaalum oru vazhi irukkura clear no-va othukkuvaanga; nambikkai-a paadhikkaradhu vara maattaadha oru vague yes thaan.

## Oru worked example

Chennai lender pilot-oda vaaram 7. Oru vaaraththula, moonu requests varudhu:

1. Collections head borrower correspondence-oda summaries kekkuraanga.
2. Oru regional credit head, Tamil-language salary slips-a support panna kekkuraanga.
3. Oru senior officer, system approve illa reject recommend panna mudiyuma-nu kekkuraanga.

Head of operations-ku ungaloda change request note:

- *Collections summaries*: pudhu document types, pudhu users, pudhu golden set. Sumaar naalu vaaram. **Recommend: later**, production gate-ku apram phase 2-aa; illa-na rollout oru maasam nagarum.
- *Tamil salary slips*: rendu regions-la 6% files; Tamil OCR-um 50 label panna examples-um thevai. Sumaar ettu naal. **Recommend: swap**, plan panna PDF export feature-oda, adha officers arithaa thaan use panraanga.
- *Approve illa reject recommendations*: system-a credit-ku assistance-la irundhu decision support-ku maathum, regulatory, fairness implications-oda. **Recommend: no** indha project-ku; venumna, risk-um compliance teams-oda oru thaniyaana assessment.

**Aprom enna nadandhadhu.** Head of operations moonu recommendations-aiyum oru meeting-la accept pannaanga. Collections team-ku phase 2-ku oru date kidaichudhu, adhu oru rendaavadhu contract-aa maarichu. Tamil swap pilot-oda end date-a nagarthaama vaaram 9-la ship aachu.

| Request | Recommendation | Outcome |
| --- | --- | --- |
| Collections summaries | Later, phase 2-aa | Date irukkura phase 2, apram rendaavadhu contract |
| Tamil salary slips | PDF export-oda swap | Vaaram 9-la ship aachu; end date maaralai |
| Approve illa reject recommendations | Indha project-ku no | Thaniyaana assessment offer pannaanga |

## Podhuvaa panra thappugal

- **Meeting-laye yes sollradhu.** Eppavum mudhalla size pannunga.
- **Options illaama no sollradhu.** Udhavaadhadhu maadhiri ketkum, makkal unga-a thaandi pogura maadhiri thallum.
- **Ketta aal approve panna vidradhu.** Agree panna business owner mattum thaan changes-a approve pannanum.
- **Ezhudhi vaikkaama irukkradhu.** Record illaadha changes acceptance-la sandaiyaa maarum.
- **AI-ku mattum irukkura costs-a ignore panradhu.** Pudhu languages, document types, tasks-ku pudhu eval data-um testing-um thevai, code mattum illa.

## Practice pannunga

Atlassian-oda scope creep pathi article-a padinga.

1. Ungaloda use case-ku, veru veru aalgalitta irundhu nambakkoodiya moonu change requests-a kandupidinga.
2. Ovvondraiyum size pannunga (velai, risk, timeline-um cost-um effect), swap, extend, later illa no-nu, oru-line reasoning-oda recommend pannunga.
3. Change request log entries-um, business owner-ku neenga anuppura short note-um ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** Meeting-nadula oru request vandhaa, amaidhiyaa "naan size panren"-nu sollitu, client choose panna kudiya options-oda thirumba vara mudiyum.
