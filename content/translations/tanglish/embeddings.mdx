## Idhu enna

Embedding-na oru text-oda meaning-a represent panra numbers list. Oru sentence embedding model-kulla poi, ethaavadhu 384 illa 1,536 numbers-aa varum. Andha numbers thaniyaa paartha oru aalukkum onnum puriyaadhu. Mukkiyam, rendu lists eppadi compare aagudhu-nu thaan: similar meaning-oda texts-ku kittathatta ore direction-la point panra lists kidaikkum, sammandham illaadha texts-ku vera vera direction-la irukkum.

Idhu thaan semantic search-oda trick. "How do I get my money back?"-yum "refund policy"-yum ore word-um share pannaadhu, aanaalum embeddings pakkathula irukkum, adhanaala embeddings-la build panna search oru-vatrula irundhu innonnu-a kandupidikkum. Keyword search miss pannidum.

Search, RAG, duplicate tickets kandupidikkradhu, customer feedback-a theme-vaaripaa group panradhu, similar items recommend panradhu-kku embeddings use pannuveenga.

```flow
dir: LR
"How do I get my money back?" -[embedding model]-> 0.12, -0.40, 0.88 ...
"Refund policy" -[embedding model]-> 0.10, -0.37, 0.91 ...
"Video buffers on mobile data" -[embedding model]-> -0.65, 0.22, 0.05 ...
0.12, -0.40, 0.88 ... -> Close: similar meaning
0.10, -0.37, 0.91 ... -> Close: similar meaning
-0.65, 0.22, 0.05 ... -> Far: a different meaning
```

Indha lesson-la Chennai-la oru edtech company-oda support team-a follow pannuvom. Agents-ku similar solved tickets kaattanum-nu avanga virumburanga.

## Idhu eppadi work aagudhu

1. **Embedding model text-a padikkum.** Idhu oru neural network. Match aaganum-nu irukkura neraya text pairs (oru question-um adhoda answer-um, oru title-um adhoda article-um), match aagaadha pairs-oda train aagirukku. Training match aagura pairs-a kittathula konduvarum.
2. **Oru vector output kodukkum.** Short-aa irundhaalum long-aa irundhaalum, ovvoru text-um oru model-ku ore length-la vector aagum. Different models different lengths tharum, different models-oda vectors-a ottu compare panna mudiyaadhu.
3. **Similarity score-la vectors-a compare pannuveenga.** Usual-aa cosine similarity: 1-na ore direction, 0-na sammandham illa. Neraya libraries vectors-a normalise pannum, adhanaala simple dot product-um ore ranking tharum.
4. **Pinnaadi search panna vectors-a store pannunga.** Sila aayiram texts-ku NumPy array podhum. Millions-na pgvector, Qdrant, Pinecone maadhiri vector database approximate index vechu nearest vectors-a vegamaa kandupidikkum.

Rendu practical points. Onnu, query-yaiyum documents-aiyum ore model-la embed pannunga. Rendu, embedding model-ku thani input limit irukku, perumbaalum konjam nooru tokens, adhukku mela irukkura edhaiyum amaidhiyaa cut pannidum. Idhu thaan embed panradhukku munnaadi long documents-a chunks-aa pirikkaradhukku oru kaaranam.

**Model choose panradhu:**

| Option | Size, cost | Edhukku nallaa irukkum |
| --- | --- | --- |
| Small open model (MiniLM maadhiri) | Laptop-la odum, free | Prototypes, English text, aayirakkanakkaana items |
| Periya open multilingual model | Speed-ku GPU thevai, run panna free | Indian languages, Hinglish, nalla quality |
| Hosted embedding API | Token-ku pay, servers thevai illa | Vegamaa aarambikka, periya scale, managed updates |

**Choose panradhukku munnaadi test pannunga.** Irubadhu real queries-yum, ovvonnukkum mudhalla varanum-nu irukkura ticket illa passage-yum serunga. Rendu moonu candidate models-la ellathayum embed panni, sariyaana item top moonula evvalavu thadavai varudhu-nu ennunga. Idhu oru afternoon edukkum, aana edhu public leaderboard-aiyum vida nallaa irukkum, yenna idhu ungaloda users-oda words, spellings, languages-a use pannudhu. Model maathalaam-nu yosikkum bodhellaam thirumba test pannunga, yenna maathunaa muzhu collection-aiyum thirumba embed pannanum.

**Code-la embeddings.** `sentence-transformers` library-oda:

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
docs = ["Dhoni hit the winning six in 2011", "Add the soaked rice to the biryani masala",
        "Kohli scored a century in Perth", "Fry onions until golden brown"]
vecs = model.encode(docs, normalize_embeddings=True)            # shape (4, 384)

query = model.encode(["how to cook biryani"], normalize_embeddings=True)[0]
scores = vecs @ query                                            # cosine, because vectors are normalised
for score, text in sorted(zip(scores, docs), reverse=True)[:2]:
    print(f"{score:.2f}  {text}")
```

**Multilingual models-um adhoda prefixes-um.** Hindi, Tamil, Hinglish, matha Indian-language text-ku multilingual model use pannunga. E5 family maadhiri sila models-ku inputs queries-aa illa passages-aa mark pannirukkanum:

```python
m = SentenceTransformer("intfloat/multilingual-e5-base")
passages = m.encode(["passage: बिरयानी बनाने के लिए चावल भिगो दें", "passage: Kohli scored a century"],
                    normalize_embeddings=True)
q = m.encode(["query: biryani kaise banate hain"], normalize_embeddings=True)[0]
print(passages @ q)
```

Ovvoru model-oda card-la adhoda prefixes, input limit, languages-a padinga. Prefixes illaadhaa errors varaadhu, results mattum mosamaagum, adhanaala adha miss panradhu easy.

**Size, storage.** Ovvoru vector-kum fixed dimensions irukku (384, 768, 1,024 illa adhukku mela). Storage = vectors × dimensions × bytes: oru million 768-dimension vectors 32-bit floats-la around 3 GB. 16-bit-la store panna paadhi aagum, kittathatta loss illa; 8-bit illa binary quantisation innum kammi aakkum, aana konjam quality poidum. Sila pudhu models, ovvoru vector-oda mudhal pagudhiya mattum (udhaaranam 1,024 dimensions-la 256) vechukkittaalum nallaa search aagura maadhiri train aagirukku. Edha shrink pannaalum ungaloda own golden queries-la test pannunga.

**Benchmarks oru starting point.** MTEB maadhiri public leaderboards neraya tasks, languages-la embedding models-a compare pannum, shortlist panna help aagum. Mudivu ungaloda own test-la thaan, ungaloda users-oda queries, spellings vechu.

```python
def top3_hit_rate(model, queries, corpus, correct_ids):
    """queries[i] should find corpus item correct_ids[i] in its top 3."""
    c = model.encode(corpus, normalize_embeddings=True)
    q = model.encode(queries, normalize_embeddings=True)
    top3 = (-(q @ c.T)).argsort(axis=1)[:, :3]
    return sum(correct_ids[i] in top3[i] for i in range(len(queries))) / len(queries)
```

**Model maathuradhu-na thirumba re-embed.** Different models-oda vectors different spaces-la irukkum, kalakka mudiyaadhu. Ovvoru vector-oda model name-yum version-aiyum store pannunga, ethaavadhu switch-ku full re-embed-um (test-um) plan pannunga.

## Oru worked example

Chennai-la oru edtech support team-ku 2,000 past tickets irukku, agents-ku similar solved tickets kaattanum-nu vechukkalaam.

```python
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer("all-MiniLM-L6-v2")   # small, free, runs on a laptop
tickets = [
    "Payment deducted but course not unlocked",
    "Money taken twice for one order",
    "Video keeps buffering on mobile data",
    "Certificate shows the wrong name",
]
vectors = model.encode(tickets, normalize_embeddings=True)

query = model.encode(["UPI debited, no access to the course"], normalize_embeddings=True)
scores = vectors @ query.T            # dot product = cosine similarity here
for i in np.argsort(-scores[:, 0])[:2]:
    print(round(float(scores[i, 0]), 2), tickets[i])
```

Query-la "UPI debited", "no access"-nu irukku, ticket-la "payment deducted", "not unlocked"-nu irukku, aanaalum top result mudhal ticket thaan. Rendavadhu double-charge ticket-aa irukkanum: adhuvum panam pathi thaan, adhanaala kittathula irukkum, aana kammiyaa. Buffering, certificate tickets kammi score pannanum. Run panni check pannunga: exact scores model version-a poruthu maarum.

Ippo "certificate name spelling mistake" try pannunga. Adhu certificate ticket-oda strong-aa match aagi, matha ellaathoda weak-aa match aagumnum. Illaattina, neenga encode panra illa compare panra vidhathula edho thappu.

**Team enna measure pannaanga.** 30 real agent queries-la, small English model 22 thadavai sariyaana ticket-a top moonula kondu vandhudhu. Multilingual model 27 thadavai pannudhu, perumbaalum "payment cut aachu, course open aagala" maadhiri Tamil-English mix-la ezhudhina queries-a pidichadhunaala. Team multilingual model-a choose panni, order ids-ku keyword search-a vechukkittaanga, rendu models-umae adha nallaa handle pannala.

## Podhuvaa panra thappugal

- **Models-a kalakkradhu.** Rendu different embedding models-oda vectors different spaces-la irukkum. Model maathumbodhu ellathayum re-embed pannunga.
- **Muzhu documents-a embed panradhu.** 30-page PDF-a oru vector-la ozhuchaa detail poidum, model limit-a thaandina text vittudum. Mudhalla chunk pannunga.
- **Score-a probability-nu nambradhu.** 0.62 "62% relevant" illa. Scores ranking-ku mattum useful, nalla thresholds model-ku model maarum, adhanaala cut-off-a ungaloda own data-la irundhu vainga.
- **Exact terms-a ignore panradhu.** Order numbers, product codes, rare names-la embeddings weak. Adhu mukkiyam-naa keyword search-oda serthu use pannunga.
- **Ungaloda own text-la test pannaadhadhu.** Public leaderboard-la top-la irukkura model Indian names, Hinglish, illa ungaloda domain-oda jargon-la mosamaa pannalaam. Choose panradhukku munnaadi irubadhu real queries-la check pannunga.
- **Model-oda query, passage prefixes-a marakkradhu.** Edhuvum error aagaadhu; results mattum mosamaagum.
- **Rendu models-oda vectors-a** oru index-la kalakkradhu.
- **Leaderboard-a mattum paathu choose panradhu.** Ungaloda own queries-la test pannunga.

## Embeddings sirandha tool illaadha idangal

- **Exact identifiers**: order numbers, PAN, part codes, names-a keyword search illa database lookup-la kandupidikkradhu nallaa irukkum.
- **Romba sinna collections**, 30 FAQs maadhiri: keyword matching illa ellathayum prompt-la podradhu simple.
- **Structured filters**, "last week ₹5,000-ku mela irundha orders" maadhiri: SQL query similarity-a vida nallaa.

## Demo-la irundhu production-ku

- **Ovvoru vector-odayum model name, version, dimensions-a store pannunga.**
- **Golden query set vechukkunga**, ovvoru model illa setting maatramum hit rate-a thirumba run pannunga.
- **Embedding jobs-a batch pannunga**, adhoda cost-um neram-um track pannunga.
- **Model switch-ku re-embeds plan pannunga**, pudhu index tests-la pass aagura varaikkum pazhaya index-a vechukkunga.
- **Storage-a paarunga**: precision, dimensions-a defaults-la illa, ungaloda own tests-la choose pannunga.
