## Idhu enna

**Big-O notation** input valara valara, oru algorithm pannra velai eppadi valarudhu-nu solludhu. Exact-aa evvalavu seconds-nu solladhu; curve-oda shape-a solludhu. Input-a rendu mataa aakkina velai appadiyae irukkumaa, rendu mataa aagumaa, naalu mataa aagumaa?

Idhu mukkiyam, yenna real data valarum. 100 test orders-a oru nimishathula check pannura script, Flipkart seller Big Billion Days sale-la paakkura 10 lakh orders-ku raththiri muzhuvadhum edukkalaam. Code-a odaadhukku munnaadiye idhai predict panni, scale aagura approach-a choose panna Big-O udhavum.

| Valarchi | Peyar | 1,000 items-ku velai | 10 lakh items-ku velai | Example |
|---|---|---|---|---|
| O(1) | Constant | 1 | 1 | Dict-la oru key-a lookup |
| O(log n) | Logarithmic | sumaar 10 | sumaar 20 | Sort aana list-la binary search |
| O(n) | Linear | 1,000 | 10 lakh | Ovvoru order-ayum oru thadavai check |
| O(n log n) | Linearithmic | sumaar 10,000 | sumaar 2 crore | Orders-a sort panradhu |
| O(n²) | Quadratic | 10 lakh | 10 lakh crore | Ovvoru order-ayum matha ovvonnoda compare |

```flow
title: Input rendu mataa aanaa enna aagum
Input rendu mataa -> O(1) | athey velai
Input rendu mataa -> O(log n) | oru step adhigam
Input rendu mataa -> O(n) | rendu mataa velai
Input rendu mataa -> O(n²) | naalu mataa velai
```

Nalladhula irundhu mosamaa varaikkum podhuvaana classes: O(1), O(log n), O(n), O(n log n), O(n²). O(2ⁿ) maadhiri innum mosamaanadhum irukku, adhu romba chinna inputs-ku mattum thaan work aagum.

## Idhu eppadi work aagudhu

Oru code-oda Big-O-va kandupidikka, n valara valara adhigama odura step evvalavu thadavai odudhu-nu ennunga, apram periya term-a mattum vechchukittu constants-a vittudunga.

- n items mela oru loop, adhoda body-a n thadavai odum: **O(n)**.
- Ore items mela oru loop-kulla innoru loop, n × n thadavai odum: **O(n²)**.
- Binary search maadhiri ovvoru step-layum problem-a paadhiyaakkina, sumaar log₂ n steps aagum: **O(log n)**.
- Python-oda built-in `sorted` maadhiri nalla sort, sumaar n × log n comparisons pannum: **O(n log n)**.
- List item-a position vachchu, dict value-a key vachchu padikkradhu collection evvalavu periyadhaa irundhaalum ore time edukkum: **O(1)**.

Constants-a vittudrom, yenna adhu shape-a maathaadhu. List-a rendu thadavai loop panradhu O(2n); adhaiyum O(n)-nu thaan ezhudhrom: ethuvaa irundhaalum n rendu mataanaa velai-um rendu mataagum. Chinna terms-ayum adhae kaaranathukku vittudrom: O(n² + n) O(n²) thaan, yenna n 10 lakh-naa, n² part meedhi ellathayum mulgidum.

**Space complexity** memory-ku adhae notation-a use pannum. Ovvoru order ID-yum oru set-la build panna O(n) extra space thevai; amounts-a koottaradhukku O(1) mattum podhum.

Oru step oru microsecond edukkum-nu vechchukkitta, indha classes practice-la enna artham:

| Complexity | n = 1,000 | n = 10 lakh (1,000,000) | Typical example |
|---|---|---|---|
| O(1) | 1 µs | 1 µs | dict lookup |
| O(log n) | 10 µs | 20 µs | binary search |
| O(n) | 1 ms | 1 second | list mela oru pass |
| O(n log n) | 10 ms | 20 seconds | sorting |
| O(n²) | 1 second | sumaar 11.5 naal | ella pairs mela nested loops |

Kadaisi row thaan kadikkum. Testing-la udane mudiyura O(n²) method production-la use panna mudiyaama pogalaam.

## Oru worked example

Priya Bengaluru-la oru fintech-oda payments team-la velai paakkuraanga. Ovvoru raathiriyum settle pannradhukku munnaadi, andha naal-oda file-la duplicate UPI transaction IDs-a flag pannanum. Busy naal-la file-la sumaar 20 lakh rows irukkum.

Avanga mudhal version ovvoru transaction-ayum matha ovvonnoda compare pannuchu:

```python
def has_duplicate(ids):
    for i in range(len(ids)):
        for j in range(i + 1, len(ids)):
            if ids[i] == ids[j]:
                return True
    return False
```

Idhu O(n²). 20 lakh IDs-ku sumaar 2 lakh crore comparisons. Settlement deadline-ku munnaadi adhu mudiyave illa.

Rendaavadhu version mundhi list-a sort pannum, appo duplicates pakkathula pakkathula irukkum, apram oru pass pannum:

```python
def has_duplicate(ids):
    ids = sorted(ids)
    for i in range(1, len(ids)):
        if ids[i] == ids[i - 1]:
            return True
    return False
```

Sorting O(n log n), pass O(n); adhanaala muzhusum O(n log n). Konjam seconds-la odi mudinjuchu.

Moonaavadhu version set-a use pannuchu; adhu keys-oda **hash map**:

```python
def has_duplicate(ids):
    seen = set()
    for t in ids:
        if t in seen:
            return True
        seen.add(t)
    return False
```

Ovvoru `in` check-um `add`-um average-aa O(1); adhanaala muzhu function-um O(n) time. Set-ku O(n) extra memory edukkum, server-la adhu paravaayilla. Idhu oru second-kulla odi mudinjuchu, oru duplicate kidaichadhum udane niruthidum.

Priya avanga team notes-la ezhudhina paadam: code-a line by line optimise panradhukku munnaadi, adhoda Big-O-va paarunga. O(n²)-la irundhu O(n)-ku poradhu, ethanai tuning-aiyum vida nallaa irundhuchu.

## Podhuvaa panra thappugal

**"Simple" call-kulla oru loop-a maraichu vaikkiradhu.** `if x in my_list` oru step maadhiri therium, aana list-la ovvoru item-ayum scan pannum: O(n). Adha loop-kulla pota O(n²). Membership-a neraya thadavai check panna, set illa dict use pannunga.

**Lines-a ennaama repetitions-a ennunga.** Oru thadavai odura anju lines O(1). Rendu nested loops-kulla irukkura oru line O(n²). Evvalavu adhigama odura line-a paarunga.

**Edhaiyum build panna aagura cost-a marakkiradhu.** List-a set-aa maathradhu O(n). Appuram neraya lookups pannum podhu adhu worth, oru thadavai pannum podhu illa.

**Average-a worst case-nu nenaikkiradhu.** Dict lookups average-aa O(1), aana mosamaana hash function slow aakkalaam. Quicksort average-aa O(n log n), worst case-la O(n²). Interviewers rendayum perumbaalum kekkuvaanga.

**Memory-a kandukkaama vidradhu.** O(n) extra memory thevai-ngra O(n) time solution, n crores of rows-aa irundhaa fit aagaama pogalaam. Time cost-oda serthu space cost-ayum sollunga.

**Romba munnaadiye optimise panradhu.** n eppavum 50-ku mela pogaadhu-naa, clever O(n log n) code-a vida clear-aana O(n²) code nallaa irukkalaam. n periyadhaa irukkum podhu thaan Big-O mukkiyam.
