## Idhu enna

Business-la perumbaalaana data tables-la irukkum: sales exports, customer lists, attendance sheets, survey results. **pandas** tables-oda velai seiyra Python library. Adhoda mukkiya object, **DataFrame**, rows-aiyum peyar vacha columns-aiyum vachirukkum, code-la neenga control panra spreadsheet maadhiri.

**DataFrame: df.** Columns-ku peyar irukku; rows-ku index irukku.

| index | date | store | item | amount |
|---|---|---|---|---|
| 0 | 2026-10-01 | RS Puram | Glucometer | 1250.0 |
| 1 | 2026-10-01 | Gandhipuram | Paracetamol | 40.0 |
| 2 | 2026-10-02 | RS Puram | Insulin pen | 2100.0 |

Konja lines-la oru CSV illa Excel file-a load panni, clean panni, rows filter panni, group panni summarise panni, tables-a join panni, result-a save pannalaam. Spreadsheet-a vida, steps ezhudhi vachirukkum, adhanaala adutha maadha report oru command, oru naal full-aa click panna thevai illa.

AI velaikku, training data-va ready panna, model outputs-a paakka, evaluation reports build panna pandas thaan vazhi.

Indha lesson-la Coimbatore-la aindhu pharmacies manage panra Lakshmi-a follow pannuvom; maadham 40,000-row export-a vinaadigalla answers-aa maathuraanga. Mudiyum podhu oru messy CSV-a load panni, clean panni, thirumba run panna mudiyura grouped summary produce panna mudiyum.

## Idhu eppadi work aagudhu

### Load panni paarunga

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()           # first five rows
df.info()           # columns, types, missing values
df.describe()       # quick statistics for number columns
```

Calculate panradhukku munnaadi eppavum paarunga. Neenga numbers-nu nenacha column text-aa padikkapattirukka-nu `info()` sollum.

### Columns select panni rows filter pannunga

```python
df["city"]                                        # one column
df[["city", "sales"]]                             # several columns
df[df["age"] > 30]                                # rows where age is above 30
df[(df["city"] == "Pune") & (df["sales"] > 5000)] # two conditions
```

"And"-ku `&`, "or"-ku `|` use pannunga, ovvoru condition-um brackets-kulla. Plain `and`, `or` inga work aagaadhu.

### Missing values

Kaali illa padikka mudiyaadha cells **NaN** ("not a number")-aa theriyum. `df.isna().sum()` vachu kandupidinga. Apram yosichu mudivu pannunga: `fillna` vachu fill pannunga, `dropna` vachu rows-a drop pannunga, illa yaarachum check panna flag pannunga.

### Types-a sari pannunga

| Problem | Fix |
| --- | --- |
| "1,250" maadhiri amounts text-aa padikkapattadhu | `pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")` |
| 05/11/2026 maadhiri dates | `pd.to_datetime(df["date"], dayfirst=True)` |
| Item codes-oda munnaadi irukkura zeros pogudhu | `pd.read_csv(..., dtype={"item_code": str})` |

`errors="coerce"` padikka mudiyaadha edhaiyum crash aagaama NaN-aa maathidum, adhanaala bad rows-a count panni report pannalaam.

### Pudhu columns

```python
df["gst"] = df["sales"] * 0.18
df["month"] = pd.to_datetime(df["date"], dayfirst=True).dt.month
```

### Group panni summarise pannunga

```python
df.groupby("city")["sales"].sum()                                # total per city
df.groupby(["city", "month"])["sales"].agg(["sum", "mean", "count"])
```

```flow
Ella rows -[city vachu pirikkum]-> Pune rows
Ella rows -[city vachu pirikkum]-> Nagpur rows
Ella rows -[city vachu pirikkum]-> Nashik rows
Pune rows -[sum()]-> Pune: 4.2 lakh
Nagpur rows -[sum()]-> Nagpur: 3.1 lakh
Nashik rows -[sum()]-> Nashik: 2.7 lakh
```

### Sort panni save pannunga

```python
df.sort_values("sales", ascending=False).head(10)
df.to_csv("clean_sales.csv", index=False)
```

### Pivot tables-oda reshape pannunga

Spreadsheet use panravanga pivot tables-a virumbuvaanga, pandas-layum irukku:

```python
df.pivot_table(index="store", columns="month", values="amount", aggfunc="sum")
```

Idhu ovvoru store-kum oru row, ovvoru month-kum oru column, ovvoru cell-layum totals tharum. Manager-ku oru trend-a kaattura clearest vazhi idhu thaan perumbaalum. Row, column totals-ku `margins=True` add pannunga.

### Dates-oda velai seiyunga

Oru column unmaiyaana date aanaa, pandas adhula neraya pannalaam:

```python
df["date"] = pd.to_datetime(df["date"], dayfirst=True)
df["weekday"] = df["date"].dt.day_name()             # Monday, Tuesday...
weekly = df.set_index("date").resample("W")["amount"].sum()
```

`resample("W")` sales-a vaaram vaaramaa serkkum; calendar months-ku `"MS"` use pannunga. Sunday sales eppavum kammi, illa Diwali-ku munnaadi vaaram varushathoda peak-nu ippadi thaan kandupidikkalaam.

### Tables-a join pannunga

```python
pd.merge(orders, customers, on="customer_id", how="left")
```

| `how=` | Edhai vechukkum |
| --- | --- |
| `"inner"` | Rendu tables-layum match aagura rows mattum |
| `"left"` | Left table-oda ovvoru row-um, match illaadha idathula blanks-oda |
| `"outer"` | Rendu tables-oda ovvoru row-um |

Inner joins rows-a sappunnu drop pannalaam. Merge panradhukku munnaadiyum apramum row counts-a check pannunga.

## Oru worked example

Lakshmi Coimbatore-la aindhu pharmacies-oda oru chain-a manage pannuraanga. Ovvoru maadhamum sumaar 40,000 rows-oda oru sales export varum, adha spreadsheet-la summarise panna munnaadi oru naal aagum.

```python
df = pd.read_csv("sales_oct.csv")
df["amount"] = pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")
print(df["amount"].isna().sum(), "rows with unreadable amounts")

by_store = df.groupby("store")["amount"].sum().sort_values(ascending=False)
print(by_store)

top_items = (df[df["category"] == "Diabetes care"]
             .groupby("item")["amount"].sum()
             .sort_values(ascending=False).head(5))
print(top_items)
```

**Avanga enna kathukkuraanga:**

| Kelvi | Badhil |
| --- | --- |
| Amount padikka mudiyaadha rows | 37, ellaam oru till-oda error-la irundhu "NA"; andha store-ku report pannaanga |
| Adhiga sales store | RS Puram |
| RS Puram-la diabetes-care sales matravangalodu compare panna | Sumaar 40% adhigam |
| Top diabetes-care item | Glucometer strips |

Indha 40% gap, diabetes-care products-oda stock-a stores-ku naduvula maathura-nu mudivu panna vaikkudhu, adhanaala matra branches-la stock theerndhu pogaadhu, RS Puram-la overstock aagaadhu. Avangaluku oru naal aana analysis ippo ovvoru maadhamum vinaadigalla run aagudhu, steps code-la irukkradhaala, November report ore script-a, pudhu file name-oda.

### Unga velaiya check pannunga

Yaarukkavadhu numbers anuppradhukku munnaadi, adha check pannunga. Grand total-a source system-oda total-oda compare pannunga. Ovvoru filter, merge-kum munnaadiyum apramum row-a count panni, entha maatramum irundhaa explain pannunga. Aindhu periya, aindhu sinna values-la thappugal irukka-nu paarunga, example rupees-ku badhila paise-la ezhudhina price. Oru number-a kaiyaala thirumba compute pannunga. Indha checks konja nimishangal thaan, thappaana report owner-kitta pogura avamaanatha thadukkum.

## Podhuvaa panra thappugal

- **Types-a check pannaadhadhu.** Commas-naala text-aa padikkapatta numbers-a sum panna mudiyaadhu. Convert pannunga.
- **Missing values-a ignore panradhu.** Fill, drop, illa flag edha-nu mudivu panni, sollunga.
- **Thappaana date order.** Indian dates day first; `dayfirst=True` illa explicit format use pannunga.
- **Filters-la `&`-ku badhila `and` use panradhu.** Brackets-oda `&`, `|` use pannunga.
- **Rows-a sappunnu drop panra inner joins.** Merge panradhukku munnaadiyum apramum row counts-a check pannunga.
- **Original file-a edit panradhu.** Clean panna data-va pudhu file-la save panni, raw export-a thodaama vainga.
