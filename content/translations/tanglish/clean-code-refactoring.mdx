## Idhu enna

**Clean code**-na adutha aal bayam illaama padichu, purinjukkittu, maathra mudiyura code. Andha adutha aal perumbaalum neenga thaan, moonu maadham kazhichu, yen appadi ezhudhunom-nu nyaabagam illaama.

Clean code-na clever tricks illa, kammiyaana lines-um illa. Adhu padikkiravanga pathi. Oru function enna pannudhu-nu adhoda peyar-la theriyumaa? Mela irundhu keezha, thaavaama follow panna mudiyumaa? Oru rule-a oru idathula maathha mudiyumaa?

**Refactoring**-na code enna pannudhu-nu maathaama, eppadi ezhudhirukku-nu maathradhu. Rename, split, simplify, duplication-a remove, ovvonnum chinna step-aa, behaviour appadiyae irukku-nu tests confirm panna. Risky rewrite illaama messy code clean code aagura vazhi idhu thaan.

## Idhu eppadi work aagudhu

Romba periya difference panra palakkangal:

| Palakkam | Munnaadi | Appuram |
| --- | --- | --- |
| Theliva peyargal | `def calc(d, f):` | `def invoice_total(items, include_gst):` |
| Named constants | `amount * 1.18` | `amount * (1 + GST_RATE)` |
| Chinna functions | Oru 120-line `process()` | `read_orders()`, `validate()`, `total()`, `write_report()` |
| Early returns | Naalu nested `if` blocks | Mundhi bad cases-a handle pannunga, apram main path |
| Oru source of truth | Ore rule moonu files-la copy | Ellaarum call panra oru function |
| Nermaiyaana comments | `# loop over items` | `# Refunds older than 30 days need manager approval (policy 4.2)` |

Nalla comments **yen**-nu solum, enna-nu illa. Code enna pannudhu-nu already solludhu; comment code solla mudiyaadhadhai solanum, oru business rule illa oru vichithiramaana choice-oda kaaranam maadhiri.

Refactoring oru safe loop-a follow pannum:

```flow
dir: LR
Tests pass -> Oru chinna maatram | rename, function extract, constant add
Oru chinna maatram -> Tests-a odunga
Tests-a odunga -[pass]-> Commit
Commit -> Oru chinna maatram
Tests-a odunga -[fail]-> Undo panni, innum chinna step try pannunga
Undo panni, innum chinna step try pannunga -> Oru chinna maatram
```

Chinna steps mukkiyam. Oru rename, oru tests run, oru commit. Oru extract panna function, oru run, oru commit. Oru test fail aanaa, edhu step udaichadhu-nu theriyum, andha onna mattum undo pannalaam. Periya big-bang rewrite-la idhu edhuvum kidaikkaadhu.

**Extract function** thaan romba payanulla refactor. Neenda function-kulla oru velaiya panra oru block-a eduthu, andha velaiya solra peyar-oda thani function-la vechchu, adha call pannunga. Neenda function steps-oda list maadhiri padikka aarambikkum.

**Code smells**-na code maathra kashtamaa irukkum-nu kaattura arigurigal: oru screen-la adangaadha neenda functions, pala idathula copy aana ore logic, anju files-la edit thevaippadura oru maatram, deep nesting, `data`, `temp`, `x`-nu peyar vacha variables. Avai bugs illa; bugs valara idam.

**AI projects-la clean code.** Idhey palakkangal prompts-kum pipelines-kum porundhum. Prompts-a functions-kulla pudhaicha neenda strings-aa illaama, theliva peyar-oda thani files-la vainga. Pipeline-oda ovvoru step-ukkum (load, chunk, embed, retrieve, generate) thani function kudunga; appo matha-vangala thodaama oru step-a test pannalaam, maathalaam. Chunk size, top-k, temperature maadhiri settings-a oru config file-la constants-aa peyar vainga; appo oru experiment oru line-a maathum, diff-um enna try pannom-nu theliva kaattum.

**Eppo refactor pannakoodaadhu.** Refactoring-ku cost irukku: neram, review effort, konjam risk. Odura, yaarum maathra plan pannaadha code-ku, throwaway scripts-ku, outage-oda naduvula (adhula chinna fix thaan sari) idha skip pannunga. Urgent maatram ship aagi, adhoda sutthi tests irukkum podhu, pinnaadi thani pull request-la tidy pannunga.

## Oru worked example

Kochi-la oru edtech company-la Kavya 140-line function `process_file()`-a inherit pannuraanga. Adhu course purchases-oda CSV-a padichu, refunds-a filter panni, GST-a serthu, coupons-a apply panni, oru summary ezhudhum. Pudhu rule varudhu: oru government scheme-ku GST-a skip pannanum. Function-a maathradhu risky-nu thonudhu.

**Mudhalla, tests.** Ippo irukkura behaviour-a suththi aaru tests ezhudhuraanga, chinna sample CSVs-oda: normal purchases, oru refund, oru coupon, oru zero amount, oru missing field, oru duplicate row. Pazhaiya code-la ellaam pass aagudhu. Ippo avanga kitta oru safety net irukku.

**Apram chinna steps.** `d`-a `purchases`-aa, `t`-a `total`-aa rename panraanga. Tests pass; commit. `* 1.18`-oda moonu copies-a `GST_RATE` constant-aala, `with_gst()` function-aala maathraanga. Tests pass; commit. `read_purchases()`, `apply_coupon()`, `write_summary()`-a extract panraanga. Ovvoru step-layum tests odum, thani commit-um irukkum.

Ippo main function pathinaaru lines illa, pathinonnu lines; business process maadhiri padikkudhu:

```python
def process_file(path):
    purchases = read_purchases(path)
    paid = [p for p in purchases if not p.is_refund]
    totals = [with_gst(apply_coupon(p)) for p in paid]
    write_summary(totals)
```

**Apram pudhu rule.** Scheme-ku GST-a skip panradhu ippo `with_gst()`-nra oru function-la oru maatram, plus oru pudhu test. Pull request chinnadhu, review panna easy; reviewer adhey naal approve pannuraanga.

## Podhuvaa panra thappugal

- **Tests illaama refactor panradhu.** Behaviour maaruchaa-nu theriyaadhu. Mundhi ippo adhu enna pannudhu-nu tests ezhudhunga.
- **Oru step-la refactor-um behaviour maatramum.** Tidy-up-um pudhu feature-um thani commits-la pannunga; appo ovvonnum review panna easy.
- **Periya rewrites.** Adhu vaarakkanakkaa edukkum, yaarum nyaabagam vechchirukkaadha edhaiyo udaikkum. Chinna, safe steps jeyikkum.
- **Clever one-liners.** Padikkiravanga decode panna vendi irundha, kurugiya code clean illa.
- **Code-a thirumba solra comments.** Avai pazhasaagidum. Yen-nu vilakkunga, illa comment thevai illaama aagura varaikkum rename pannunga.
- **Yaarum thodaadha code-a polish panradhu.** Maatha pora code-a refactor pannunga, ellathayum illa.

## Practice pannunga

2. Unga oru project-la romba neenda function-a kandupidichu, tests green-aa vechchukittu, adhulirundhu rendu chinna functions-a extract pannunga.

4. Oru take-home illa review-la, unga code-a yen appadi structure pannineenga-nu rendu vaakkiyathula explain pannunga.
