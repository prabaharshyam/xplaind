## Idhu enna

AI image tools words-la irundhu pictures uruvaakkum. Perumbaalum **diffusion models**: random noise-la start panni, unga prompt-oda vazhikaattuthal-la, oru image varra varaikkum step by step noise-a neekkum. Neraya tools **reference images**-um edukkum, adhanaala oru photo-va edit pannalaam, illa oru aal, product-a neraya pictures-la ore maadhiri vechukkalaam.

Rendu tools thaan perumbaalaana thevaiya cover pannum:

- **Gemini-oda image model**, nickname **Nano Banana**, Gemini app-layum Google AI Studio-layum irukku. **Plain words-la editing**-la ("make it night", "swap the shirt colour") romba nalladhu, edits naduvula mugam, objects-a consistent-aa vechirukkum.
- **Midjourney**, azhagaana, artistic, strong look irukkura images-ku peyar petradhu, adhoda website-la use panraanga. Aspect ratio, result evvalavu stylised-aa irukkanum, variations-ku settings irukku.

```flow
Prompt | subject, details, setting, camera, light, style, aspect ratio -[new image from words]-> Generate
Generate -> Pick the best of 4 -> Upscale
Prompt -[your photo + an instruction]-> Edit | "remove the bags, warmer light, keep the person unchanged"
Pick the best of 4 -[reuse as a reference]-> A consistent set of images
```

## Idhu eppadi work aagudhu

**Photographer illa illustrator maadhiri prompt pannunga.** Vague prompts podhuvaana images tharum. Oru professional mudivu pannura vishayangala solunga:

| Part | Edhukku badhil | Example |
|---|---|---|
| Subject | yaar illa enna, exact-aa | appam plate vechirukkura sirikkura Malayali paatti |
| Details | udai, materials, colours | gold border-oda white mundu, banana-leaf plate |
| Setting | enga, eppo | copper pots-oda, veyil adikkura Kerala kitchen |
| Composition | framing, angle | medium shot, eye level, subject right third-la |
| Lighting | quality, direction | window-la irundhu mellaiya kaalai velicham |
| Style illa medium | photo, illustration, 3D, watercolour | editorial food photography |
| Format | enga use aagum | Instagram-ku 4:5, YouTube-ku 16:9 |

**Regenerate pannaama edit pannunga.** Gemini-la photo upload panni, oru thadavaiku oru maatrathai describe pannunga. Edhu appadiyae irukkanum-nu sollunga ("keep the face and pose unchanged"). Neraya chinna edits, oru periya edit-a vida nallaa work aagum.

**Midjourney-la therinjikkavendiya settings.** `--ar 16:9` aspect ratio-va set pannum. Stylize setting, Midjourney thanoda artistic look-a evvalavu serkkanum-nu control pannum. Variations, remix-naala konjam pidichirukkura result-a nudge pannalaam, image, style references-um kudukkalaam. Current documentation-a paarunga, yenna version peyargal, options maarum.

**Consistency.** Oru character, product, mascot-ku oru strong reference image uruvaakki, ovvoru pudhu image-layum adha reference-aa use pannunga, written description-um ore maadhiri vechukkunga.

**Image-la irundhu video-ku.** Strong still images AI video-ku starting point-um thaan. Veo, Flow guide-la oru image-a oru shot-oda first frame-aa, illa character, product reference-aa use pannuveenga, adhanaala nalla image-ku selavu pandra neram rendu vidhathula payan tharum.

**Images-la text.** Pudhu models short text-a munnaadi vida romba nallaa ezhudhum, aana neenda text innum thappaagum. Posts, thumbnails-ku headlines-a Canva illa Figma-la serkkradhu perumbaalum vegamaanadhu.

**Resolution, upscaling.** Generators oru kurippitta size-la images-a tharum. Print, banners, periya screens-ku tool-oda upscale option illa thani upscaler use pannunga, publish panradhukku munnaadi kai, text, logos maadhiri fine details-a full size-la check pannunga; phone-la theriyaadha chinna thappugal print-la theriyum.

**Rights, labels.** Commercial use-ku ovvoru tool-oda terms-a check pannunga; paid plans perumbaalum anumadhikkum. Neraya platforms ippo AI-yaala uruvaakkina illa romba edit panna images-a label panna solludhu, Google-um than models-oda images-la kannukku theriyaadha SynthID watermark serkkudhu. AI use-a open-aa solradhu customers-oda nambikkaiya valarkkum.

## Oru example

Lakshmi Kochi-la oru home bakery nadathuraanga, pudhu Instagram page-ku images venum, aana vaaram vaaram photographer-ku selavu pannura vasadhi illa.

Avanga best-selling plum cake-a thanga kitchen table-la phone-la photo edukkuraanga. Gemini-la oru thadavaiku onnaa moonu edits pannuraanga: "replace the background with a rustic wooden table and a cup of coffee", "warmer, softer light like early morning", "add a sprig of rosemary on the plate, keep the cake exactly the same". Cake unmaiyaavae avangaloda thaan irukku, customers-kitta nermaiyaa irukka idhu mukkiyam.

Festive banner-ku Midjourney use panraanga: "Christmas window display of a small Kerala bakery at dusk, fairy lights, star lanterns, plum cakes on the shelf, warm glow, cinematic, --ar 16:9". Naalu results-la onna pick panni, upscale pannuraanga.

Oru mascot, cheerful cartoon baker-a Gemini-la design panni, adha reference-aa vechu innum moonu posts-ku use pannuraanga, adhanaala ovvoru thadavaiyum avar ore maadhiri irukkaar. Headlines-a Canva-la serkkuraanga.

Page first naalaiyae professional-aa irukku. Avanga rule: real products edit panna photos-a thaan, generate panna images illa, adhanaala customers paakkuradhaiyae vaangaranga.

## Podhuvaa panra thappugal

**Oru word prompts.** "A cake" oru stock-photo cake-a tharum. Manasula paakkura shot-a describe pannunga.

**Oru edit-la neraya maathradhu.** Gemini aindhu vishayatha vida oru, rendu clear maatrangala nalla follow pannum.

**Real products-a "photos"-aa generate panradhu.** Customers paakkuradhu thaan kidaikkanum-nu edhirpaarpaanga. Unga products-oda real photos-a edit pannunga.

**Real makkal, brands-a use panradhu.** Celebrities, sammadham illaama real customers, vera companies-oda logos-oda images uruvaakkaadheenga.

**Panam-ku uyirodu irukkura artist-oda style-a copy panradhu.** Artist peyar-a sollaama, ungalukku pidichirukkura qualities-a describe pannunga.

**Aspect ratio-va kandukkaama irukkradhu.** Square-aa senja image YouTube thumbnail-aa mosama crop aagum. Generate panradhukku munnaadi format-a set pannunga.

**Mudhal result-a ottukkaradhu.** Konjam options generate pannunga, compare pannunga, best-a chinna, specific maatrangal-oda refine pannunga.
