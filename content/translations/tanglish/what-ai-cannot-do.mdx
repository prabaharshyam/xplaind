## Idhu enna

AI assistants draft panna, summarise panna, translate panna, explain panna, brainstorm panna romba nallaa varum. Aana adhoda limits-um irukku, adhu easy-aa marandhudum, yenna adhu romba smooth-aa ezhudhudhu. Confident-aa, nallaa ezhudhina answer unmaiyaa thonum, adhu thappaa irundhaalum.

Dhinasari use-la mukkiyamaana aaru limits idhu:

| Limit | Artham | Example |
| --- | --- | --- |
| **Thappaana facts** | Thappaana info-va full confidence-oda sollum | Karpanaiyaana statistic, illaadha oru law |
| **Recent events** | Training data serthadhukku apram nadandhadhu theriyaadhu | Pona maasam announce panna pudhu scheme |
| **Exact numbers** | Tool illaama calculations, dates-la weak-aa irukkalaam | Neenda invoice-a thappaa kootradhu |
| **Judgement** | Adhukku thanoda values, goals illa; likely text-a thaan uruvaakkum | Oru employee-ku rendaavadhu chance kudukkalaama |
| **Accountability** | Oru decision-ku adhaala badhil sollaa mudiyaadhu | Loan thappaa maruthaa yaar badhil solluvaanga |
| **Unga context** | Neenga sonnadha mattum thaan theriyum | Unga company-oda leave policy |

Indha limits therinjikkradhu AI-a thavirkkanum-nu artham illa. Sariyaana vishayathukku use panna adhu thaan vazhi.

| AI romba help pannura edam | Neenga check pannanum illa mudivu edukkanum |
|---|---|
| Drafting, rewriting | Facts, figures, dates |
| Unga text-a summarise panradhu | Recent rules, prices |
| Oru topic-a explain panradhu | Makkala paadhikkura decisions |
| Options brainstorm panradhu | Thappu aanaa unga mela varra edhuvum |

Indha lesson-la Pune-la HR executive Priya oru assistant-a use panraanga: onnula adhu nallaa pannum, innonnula amaidhiyaa thappu pannum. Mudiyum podhu ovvoru limit-ayum solli, adha sutthi velai seiya theriyum.

## Idhu eppadi work aagudhu

### Confident thappugal yen varudhu

Language model training data-la irukkura patterns-la irundhu adutha words-la likely-aanadha ezhudhudhu. Product adha search tool-oda illa unga documents-oda connect panna thavira, adhu edhaiyum thedi paakaadhu. Facts illaa-na, default-aa "enakku theriyaadhu"-nu nikkaadhu. Plausible-aa theriyura answer-a ezhudhidum. Idhukku peru **hallucination**.

```flow
Question | "What is the tax-free gratuity limit?" -> Model | patterns from training text, some old, some new
Model -[knows the current rule]-> Correct answer
Model -[learned an older figure]-> Confident, but out of date
Model -[never saw it clearly]-> Confident, but invented
```

Moonu vazhiyum same confident-aa thaan ezhudhum. Tone-a vechu edhu nadandhuchu-nu solla mudiyaadhu.

### Knowledge cut-off

Model oru kurippitta date varaikkum irukkura data-la irundhu kathukkudhu, adhu **knowledge cut-off**. Search tool illaa-na pudhu government scheme, recent price change, indha varusha tax rules adhukku theriyaadhu. Sila assistants web-la search pannum, adhu help pannum, aana product unga question-ku search use pannina, nalla sources kidaichaa mattum thaan.

### Private context

Unga company policies, customer history, unga family-oda medical records model-ku theriyaadhu, neenga share pannaa thavira. Share panradhu sariyaa irukkaadhu-nu kooda irukkalaam. "Unga leave policy" pathi adhu sollradhu, podhuvaana policies-a vechu pannina guess.

### Numbers

Neraya assistants ippo maths-ku calculator illa code tool use pannudhu, adhu nambalaam. Aana eppavum illa: sila neram digits-a predict panni "manasula" kooduvaanga, neenda sums-la adhu thappaa pogum. Mukkiyamaana numbers-ku working-a kaattu-nu kelunga, neengalae check pannunga.

### Judgement-um accountability-um

Loan approve panradhu, aal hire panradhu, employee mela action edukkradhu, patient-ku enna solradhu, ivai ellaam values, laws, context sernthadhu. Decision-kku yaaraavadhu badhil solliyaaganum. AI information ready panna, options list panna, risks kaattalaam. Oru manushan thaan mudivu edukkanum. Indha role-la oru aal irukkradhukku peru **human-in-the-loop**.

### Consistency

Ore question-a rendu thadavai kettaa vera vera answers varalaam, yenna assistants words-a konjam randomness-oda choose pannum. Ideas-ku adhu ok, useful-um kooda. Facts-ku answer maarinaa adhu oru warning sign.

## Oru example

Priya Pune-la oru manufacturing company-la HR executive. 22 varusham velai paathu retire aagura oru employee, avanga gratuity-la evvalavu tax-free-nu kekkuraanga.

**Task 1: oru fact.** Priya assistant kitta kekkuraanga: "India-la tax-free-aa irukkura maximum gratuity amount evvalavu?"

Assistant confident-aa oru figure solludhu. Limit konjam varushathukku munnaadi uyarthinaanga-nu Priya-kku nyaabagam, indha figure ippo sariyaa-nu theriyala. Source kettaa, adhu oru podhuvaana description thaan tharudhu, link illa.

Income Tax Department website-ayum, avanga company tax consultant-oda recent circular-ayum check panraanga, ippo irukkura limit kidaikkudhu. Assistant sonna figure pazhaiyadhu.

**Task 2: oru draft.** Ippo adhu nallaa pannura vishayathukku use panraanga:

> "Retire aagura oru employee-ku, 22 varusha service-ku gratuity eppadi kanakkidraanga-nu, adhula oru paadhi limit varaikkum tax-free-nu explain panni, anbaana rendu paragraph email ezhudhu. Limit-a [LIMIT]-nu vittudhu, naan fill pannikkuren."

Draft clear-aa, anbaa irukku. Verify panna figure-a avangalae serkkuraanga, employee-ku vaazhthu solra oru line-um serkkuraanga.

| Task | Edhula limit | Priya enna pannaanga |
| --- | --- | --- |
| Tax-free gratuity limit | Thappaana fact, pazhaiyadhu | Official source-la check pannaanga; AI thappu |
| Explanation email | Edhuvum illa: drafting adhoda strength | Draft-a use pannaanga, verify panna figure-a serthaanga |
| Early payment approve panralaama | Judgement, accountability | Company policy-yum manager-oda mudivum follow pannaanga |

Ore tool, moonu tasks: drafting-ku nambinaanga, facts-a check pannaanga, decision-a makkal kaila vechaanga.

## Podhuvaa panra thappugal

- **Smooth-aa ezhudhuradha proof-nu nenaikkiradhu.** Nallaa ezhudhina answer-um thappaa irukkalaam.
- **Search illaama recent events kekkuradhu.** Model-ku adhu theriyaamayae irukkalaam.
- **AI-a mudivu edukka vidradhu.** Adhu information ready pannum; neenga mudivu edukkanum, badhil solla-num.
- **Adhukku unga situation theriyum-nu nenaikkiradhu.** Neenga sonnadhu mattum thaan theriyum.
- **Mental maths-a nambradhu.** Working-a kelunga, illa spreadsheet use pannunga.
- **Thappu pannudhu-nu use pannavae maattaen-nu irukkradhu.** Makkalum thappu pannuvaanga. Check panna easy-aana edathula use pannunga.

## Practice pannunga

Keezha link panni irukkura Elements of AI-la AI-na enna-ngra chapter-a padinga, apram Microsoft-oda generative AI short introduction-ayum paarunga.

1. **Recent facts-a test pannunga.** Recent Indian news illa rules pathi moonu factual questions assistant kitta kelunga, apram ovvoru answer-ayum official source-la check pannunga. Edhu thappu, edhu pazhaiyadhu-nu note pannunga.
2. **Consistency-a test pannunga.** Ore opinion question-a rendu thadavai kelunga, answers-a ottu paarunga.
3. **Unga tasks-a pirichu paarunga.** Unga velaila AI draft illa summarise panna koodiya moonu tasks-um, oru aal mudivu edukkanum-ngra moonu tasks-um ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** AI assistants-oda naalu limits-a solla mudiyum, ovvonnukkum unga test-la paartha oru example solla mudiyum.
