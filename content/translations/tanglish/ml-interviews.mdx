## Idhu enna

Typical ML engineer loops-la irukkura:

- **ML fundamentals**: bias, variance, overfitting, regularisation, metrics, cross-validation, specific models eppadi work aagudhu (trees, logistic regression, neural networks, transformers).
- **Coding**: Python, pandas-la data manipulation, oru simple algorithm-a implement panradhu, sila neram standard data-structure problems.
- **ML system design**: "UPI payments-ku fraud detection system design pannunga", "Grocery app-ku recommendations design pannunga".
- **Case illa project deep-dive**: neenga build panna oru project-a walk through panradhu, choices, results pathi follow-up questions-oda.
- **Behavioural**: ownership, collaboration, failure-a handle panradhu.

```flow
title: 40 nimishathula ML system design
1 Goal and metric -> 2 Framing and label -> 3 Data -> 4 Features | sumaar 15 nimisham
4 Features -> 5 Baseline, apram oru model -> 6 Evaluation | offline, A/B, sumaar 12 nimisham
6 Evaluation -> 7 Serving | batch illa real time, fallback-oda -> 8 Monitoring | sumaar 8 nimisham
8 Monitoring -> 9 Risks | fairness, abuse, failure; sumaar 5 nimisham
```

Numbers-a sathama sollunga: latency budget, label delay, class balance, alert capacity.

Indha lesson, Indian payments companies-la common-aa kekkura "UPI merchant transactions-ku fraud detection design pannunga" kelvikku oru model answer-a follow pannum.

## Idhu eppadi work aagudhu

**Fundamentals.** Plain words-la, oru example-oda explain panna theriyanum:

- bias-variance trade-off, learning curves-la irundhu underfitting-a overfitting-a-nu eppadi diagnose panradhu;
- imbalanced data-la accuracy yen fail aagudhu, adhukku badhila enna use panradhu;
- gradient boosting-kum random forests-kum enna difference;
- leakage-na enna, adha eppadi kandupidippeenga;
- attention eppadi work aagudhu, high level-la.

**ML system design-ku oru structure.**

1. *Goal-a clarify pannunga*, business metric-a; constraints (latency, scale, regulation).
2. *ML problem-a frame pannunga*: edha predict panradhu, yaarukku, eppo; label-um adhu eppadi kidaikkum-nu.
3. *Data*: sources, labels, volume, freshness, biases, privacy.
4. *Features*: mukkiya groups, prediction time-la compute panna.
5. *Model*: mudhalla oru simple baseline, apram reasons-oda oru strong model.
6. *Evaluation*: offline metrics, reality-ku match aagura splits, segments; online A/B test-um guardrails-um.
7. *Serving*: batch illa real-time, latency budget, fallback.
8. *Monitoring, iteration*: drift, feedback loops, retraining.
9. *Risks*: fairness, abuse, failure modes.

**Project deep-dives.** Oru illa rendu projects-a aazhama prepare pannunga: problem, data, baseline, neenga try pannadhu, numbers-oda results, enna thappa pochu, adutha enna pannuveenga. "X yen illa?" kelvigal varum-nu expect pannunga.

**Coding.** Pandas groupbys, joins, window-style calculations, time-wise train-validation split ezhudhuradhu, simple metrics illa k-means-a scratch-la implement panradhu practice pannunga.

**Behavioural.** Entha engineering role-kum maadhiri, numbers-oda STAR stories.

**Adhigam varra fundamentals:**

| Topic | Enna solla theriyanum |
| --- | --- |
| Bias, variance | Learning curves underfitting-a overfitting-a eppadi kaattum, ovvonnukkum enna fix |
| Imbalanced data | Accuracy yen misleading; PR AUC, threshold-la precision, recall |
| Trees | Random forests-kum gradient boosting-kum enna difference |
| Leakage | Adhu enna, romba nalla score-a eppadi kandupidikkradhu, splits-a features-a eppadi fix panradhu |
| Attention | Queries, keys, values, high level-la |

**Sathama practice panradhu.** System design oru pesura skill. 40 nimisha timer vainga, paarkkaadha oru kelvi edunga, oru simple diagram varanjittu onbadhu steps-aiyum pesunga. Unga-a record pannunga, apram gaps-a kekkunga: label-a define pannineengalaa, latency budget sonneengalaa, baseline peyar sonneengalaa, time-ku match aagura split choose pannineengalaa, eppadi monitor pannuveenga-nu sonneengalaa? Vaaram oru thadavai oru friend-oda idha pannunga, roles-a maathikonga, ennanna interviewer-a irukkardhu clear answer eppadi kekkum-nu kaattum.

**"X yen illa?"-a handle panradhu.** Interviewers choices-a push pannuvaanga. Trade-off-oda badhil sollunga: "Oru deep model help pannalaam, aana tabular features-um label delays-um irukkura podhu, gradient boosting ore maadhiri accuracy tharum, nimishangalla train aagum, risk team-ku explain panna easy. Baseline-ku aprom, error analysis trees miss panra patterns-a kaattina, adha try pannuven."

## Oru worked example

Question: "Oru payments company-ku fraudulent UPI merchant transactions-a detect panra system-a design pannunga."

Oru strong outline:

1. *Goal*: kuraivaana analyst capacity-oda fraud losses-a kammi panradhu; blocking-ku 100 ms-ku kulla real-time decision, oru review queue-um.
2. *Framing*: ovvoru transaction-kum binary classification; labels chargebacks-la, confirmed investigations-la irundhu, 30 la irundhu 60 naal late-aa varum.
3. *Data*: transactions, merchant profiles, device, network signals, past fraud; romba imbalance (fraud oru sathavidhathula sinna pagudhi; neenga assume panra rate-a sollunga).
4. *Features*: velocity (merchant-ku, manikku transactions), merchant history-oda amount, pudhu device, naal neram, merchant category; ellaam transaction time-la feature store-la irundhu compute panna.
5. *Model*: rules baseline; class weights-oda gradient-boosted trees; apram merchants-aiyum devices-aiyum link panra graph features.
6. *Evaluation*: time-based split; PR AUC; analysts handle panna mudiyura alert volume-la recall; merchant category-wise, region-wise; traffic-oda oru share-la A/B test.
7. *Serving*: rules-ku fallback-oda real-time scoring; rendu thresholds (romba high precision-la auto-block, keezha review queue).
8. *Monitoring*: key features-la drift, alert-rate maatrangal, block panna transactions-la irundhu feedback loop (random holdout), maadhaantheerum retraining.
9. *Risks*: nijamaana sinna merchants-a block panradhu (appeal route), adversaries adapt aagaradhu (adikkadi retraining), regions muzhukka fairness.

| Step | Fraud answer-la mukkiya point |
| --- | --- |
| Goal | Block panna 100 ms-ku kulla, analysts-ku size panna review queue-um |
| Label | Chargebacks, investigations, 30 la irundhu 60 naal late |
| Model | Rules baseline, apram class weights-oda boosted trees |
| Evaluation | Time split; analysts handle panna mudiyura alert volume-la recall |
| Monitoring | Drift, alert rates, block panna transactions-ku random holdout |

## Podhuvaa panra thappugal

- **Deep learning-ku kudhikkradhu.** Baseline-oda aarambinga, complexity-a justify pannunga.
- **Label-a ignore panradhu.** Labels enga irundhu, evvalavu late-aa varum-nu ellathaiyum shape pannum.
- **Time-based problems-ku random splits.**
- **Serving illa monitoring plan illaama irukkradhu.** Interviewers production thinking-a virumbuvaanga.
- **Aazhamillaadha project stories.** Unga numbers-um mistakes-um theriyanum.
