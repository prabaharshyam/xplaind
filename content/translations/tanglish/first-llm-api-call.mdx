## Idhu enna

Code-la irundhu oru language model-a call panradhu, edhaavadhu web API-a call panra maadhiri thaan: unga program unga prompt-oda oru request anuppum, provider model-a odum, evvalavu tokens use aachu-nu maadhiri details-oda reply thirumbi varum. Adhoda, unga sondha programs summarise pannum, classify pannum, extract pannum, ezhudhum.

Ovvoru periya provider-um oru API-yum, HTTP details-a mudi vacha oru official Python SDK-yum (software development kit) tharuvaanga.

```flow
dir: LR
Unga script | client = Anthropic(), key environment-la irundhu, messages.create(...) -[HTTPS POST: model, max_tokens, system, messages]-> Model provider | system prompt + message history-la model odum
Model provider -[reply text, usage, stop reason]-> Unga script padikkum | .content-la text blocks, tokens-la reply.usage
```

Indha lesson-la Gurugram-la oru backend developer Vikram-a follow pannuvom, avar kuzhappamaana meeting notes-a nalla summaries-a maathura oru tool build panraar.

## Idhu eppadi work aagudhu

**Key vaanganum.** Provider-oda developer console-la account create pannunga, thevai-na konjam credit serunga, oru API key create pannunga. Adha password maadhiri paarunga.

**Key-a code-la irundhu veliya vainga.** Environment variable-la store pannunga, perumbaalum `.gitignore`-la irukkura `.env` file-la. SDK bodhuvaa oru standard variable peyar-la irundhu adha thaanaagavae padikkum.

**SDK-a install pannunga**, unga project-oda virtual environment-la pip vachu.

**Oru message anuppunga.** Oru normal call model peyar-a solli, output length-ku oru limit vachu, messages list-a anuppum. Inga Anthropic-oda Python SDK-la kaattirukku; vera providers-oda SDKs-um ade pattern-a follow pannum:

```python
import anthropic

client = anthropic.Anthropic()          # reads ANTHROPIC_API_KEY from the environment

reply = client.messages.create(
    model="claude-sonnet-5-5",          # check the docs for current model names
    max_tokens=300,
    system="You are a concise assistant for a small bakery in Pune.",
    messages=[{"role": "user", "content": "Write a two-line WhatsApp message announcing fresh plum cakes for Christmas."}],
)

text = "".join(b.text for b in reply.content if b.type == "text")
print(text)
print("tokens in:", reply.usage.input_tokens, "out:", reply.usage.output_tokens)
```

Reply-oda `content` blocks-oda oru list. Pudhu models text-kku munnaadi oru thinking block-a vekkalaam, adhanaala mudhal block thaan answer-nu ninaikkaama, type `text` irukkura blocks-a eduthukkunga.

**Message list.** Oru conversation-na roles (user, assistant) irukkura messages-oda list. Chat-a thodara, munnaadi turns-a pudhu message-oda marubadiyum anuppunga; API thaanaagavae munnaadi calls-a gnaabagam vechukkaadhu. **System** prompt nirandhara instructions-a set pannum.

**Usage-um cost-um.** Ovvoru reply-yum input, output tokens-a report pannum. Model-oda per-token price-a vachu multiply panna, ovvoru call-ku evvalavu aachu-nu theriyum. Build pannum podhae usage-a print pannunga, appo cost unga-a thidukkida vaikkaadhu.

**Model select panradhu.** Providers periya, adhigam capable models-um, sinna, vegamaana, vilai kammi-aana models-um tharuvaanga. Mid-sized model-la aarambichu, maathradhukku munnaadi test pannunga.

**Oru request-oda parts-um, adhu enna control pannudhu-nu:**

| Part | Control pannuvadhu | Tip |
| --- | --- | --- |
| `model` | Capability, speed, price | Ippo irukkura peyargala docs-la paarunga |
| `max_tokens` | Maximum reply length | Eppavum set pannunga |
| `system` | Muzhu chat-kum role, tone, rules | Calls-ku idaiyila stable-aa vainga |
| `messages` | Ippo varaikkum conversation | User, assistant turns maathi maathi vaanga |
| Reply `usage` | Use aana tokens | Mudhal naalilirundhae log pannunga |
| Reply stop reason | Yen niruthichu: mudinjudhu, illa token limit-a thottadhu | Limit-a thottaa answer vettappattirukkum |

**Streaming.** Neelamaana reply mudiya paththu seconds illa adhukku mela aagum. Streaming-la API ezhudha ezhudha text-a anuppum, appo user oru second-la padikka aarambichuduvaanga. Chat interfaces kandippa stream pannum; background jobs, aayirakkanakkaana files-a raathiri summarise panradhu maadhiri, perumbaalum thevai illa.

**Errors-um retries-um.** API calls avvappo fail aagum, unga code adha edhirpaakkanum:

| Error | Artham | Enna pannanum |
| --- | --- | --- |
| 401 illa 403 | Key illa, thappu, illa anumadhi illa | Key-a sari pannunga; retry pannaadheenga |
| 400 | Unga request-la edhaavadhu invalid | Message-a padichu, request-a sari pannunga |
| 429 | Rate limit: nimisham-ku romba requests illa tokens | Kaathirundhu retry pannunga, vegatha kammi pannunga |
| 500, 529 illa timeout | Provider error illa overload | Adhigamaagura wait-oda retry pannunga; thodarndhaa backup model-ku maarunga |

Anthropic-oda SDK rate limits, overloads, connection errors-a adhigamaagura waits-oda rendu moonu thadavai already retry pannum; evvalavu thadavai-nu `max_retries`-layum, evvalavu neram kaathirukkanum-nu `timeout`-layum set pannalaam. Ella retry-um fail aanaa user enna paarpaanga-nu unga code thaan mudivu pannanum.

**Oru sinna chat program.** Idhu ellaa pieces-aiyum serkkudhu: history, streaming, anuppradhukku munnaadi token check, cut-off detection, errors.

```python
import anthropic

client = anthropic.Anthropic(max_retries=3, timeout=60)
MODEL = "claude-sonnet-5-5"            # check the docs for current model names
SYSTEM = "You help students in Kerala plan their study week. Be brief."
history = []

def ask(text):
    history.append({"role": "user", "content": text})
    size = client.messages.count_tokens(model=MODEL, system=SYSTEM, messages=history).input_tokens
    if size > 20_000:
        history.pop()
        return "This conversation is too long. Please start a new one."
    try:
        with client.messages.stream(model=MODEL, max_tokens=500, system=SYSTEM, messages=history) as stream:
            for chunk in stream.text_stream:
                print(chunk, end="", flush=True)        # words appear as they arrive
            reply = stream.get_final_message()
    except anthropic.RateLimitError:
        history.pop()
        return "Busy right now. Please try again in a minute."
    except anthropic.APIStatusError as err:
        history.pop()
        return f"The AI service returned an error ({err.status_code})."
    except anthropic.APIConnectionError:
        history.pop()
        return "Could not reach the AI service. Check the connection."
    history.append({"role": "assistant", "content": reply.content})
    if reply.stop_reason == "max_tokens":
        print("\n[reply cut off at the length limit]")
    print(f"\n(tokens in {reply.usage.input_tokens}, out {reply.usage.output_tokens})")

ask("I have maths and chemistry exams in two weeks. Make a plan for Monday.")
ask("Move chemistry to the evening.")             # the model sees the first turn too
```

Error vandhaa, user-oda message history-la irundhu remove aagum, adhanaala adutha try-la rendu user messages thodarndhu pogaadhu.

**Sampling settings.** Sila models `temperature` maadhiri settings-a edukkum, adhu words evvalavu vera vera-aa varum-nu control pannum; model eppadi words-a select pannudhu-nu lesson adha explain pannum. Pudhu models sila settings-a fix panniyirukkalaam, adhanaala nambradhukku munnaadi model-oda documentation-a check pannunga.

**Conversation history-ku panam aagum.** Ovvoru turn-layum muzhu history-a marubadiyum anuppuradhaala, neelamaana chats ovvoru message-kum adhigam selavaagum: turn 20 turns 1 mudhal 19 varaikkum input-aa marubadiyum bill pannum. Unmaiyaana apps pazhaya turns-a trim illa summarise pannum, system prompt-a stable-aa vachu provider adha cache panni, marubadiyum varra pagudhiku kammi charge panna vaikkum.

**Browser-la try pannunga.** History-a marubadiyum anuppuradhaala ovvoru turn-um evvalavu adhigama selavaagudhu-nu paarunga. Numbers-a maathi marubadiyum odunga.

```python
system_tokens, question, answer = 1200, 100, 250
history = 0
for turn in range(1, 11):
    sent = system_tokens + history + question
    print(f"turn {turn:>2}: {sent:>5} input tokens")
    history += question + answer       # this turn is resent next time
```

## Podhuvaa panra thappugal

- **API key-a code-la hard-code panradhu.** Environment variables use pannunga; edhaavadhu oru thadavai commit aana key-a rotate pannunga.
- **`max_tokens`-a marakkaradhu.** Output-a eppavum cap pannunga.
- **API munnaadi calls-a gnaabagam vechukkum-nu edhirpaakkaradhu.** Conversation history-a neengale anuppunga.
- **Pazhaya model peyargala use panradhu.** Docs-la ippo irukkura list-a paarunga.
- **Usage numbers-a gavanikkaama irukkradhu.** Mudhal call-la irundhae tokens-a track pannunga.

- **Muzhu response object-a logs-la print panradhu.** Adhula user text irukkalaam. Adhukku badhila ids, token counts, timings-a log pannunga.
- **Ovvoru call-um success aagum-nu ninaikkaradhu.** Rate limits, overloads, timeouts-a handle panni, user-ku theliva oru message kaattunga.
- **Ellathaiyum retry panradhu.** Bad key illa invalid request ovvoru thadavaiyum ade maadhiri fail aagum.
- **Stop reason-a gnaabagam vechukkaama irukkradhu.** `max_tokens`-a thotta reply paadhi thaan.

## API-a ippo thevai illaadha idangal

- **One-off tasks**: oru summary illa draft-ku chat app vegamaa irukkum.
- **Spreadsheet illa no-code velai**: n8n illa spreadsheet add-on maadhiri tools neenga solla thevai illama model-a call pannalaam.
- **Prompts kathukkradhu**: mudhalla provider-oda console illa workbench-la prompts-a try pannunga, work aagura onna apram code-ku kondu pongal.

## Demo-la irundhu production varai

- **Key-a server-la vainga.** Mobile app illa browser code-la eppovum anuppaadheenga; browser unga server-a call pannum, unga server model-a call pannum.
- **Oru user-ku limits vainga**: nimisham-ku requests-um, naalaikku tokens-um, appo oru user illa script bill-a yerra vaikkaadhu.
- **Metadata-a log pannunga**: request id, model, tokens, aana neram, stop reason, error type.
- **Provider dated names tharuna idathula, oru model version-a pin pannunga**, pudhusa maaradhukku munnaadi test pannunga.
- **Outages-ku plan pannunga**: user-ku theliva oru message-um, mukkiyamaana features-ku oru backup model-um.
