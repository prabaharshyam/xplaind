## Idhu enna

AI kathukka thodangura niraya per paadhiyilae ninnudraanga, yenna avangalukku thelivaana route illa: inga oru video, anga oru course, vaaraa vaaram oru pudhu tool, moonu maasam kazhichum oru skill-um muzhusaa mudiyala. Oru path-a thernthedukkuradhu idha sari pannum.

Xplaind-la oru **path**-naa shared lessons-la kattappatta, oru job role-kaana varisaiyaana route. Ovvoru path-um stages-aa pirikkappattirukku. Niraya stages-la oru guided project irukku; ovvoru path-layum oru employer-kitta kaattakkoodiya kurainjadhu oru guided project irukku. Neenga mudikkira lessons adha use panra **ella** paths-layum kanakkula varum; adhanaala apramaa maaththinaalum unga uzhaippu veenaagaadhu.

Xplaind-la patthu paths irukku. Length column, seeraa padikkiravangalukku Xplaind kudukkura oru thoraayamaana guide. Idhu learning neram mattum dhaan: adhukku mela sila maasam job search-kkum plan pannunga.

| **AI Engineer** | Parandha AI engineering role venum-nu ninaikkira students, developers | Aamaa, mudhal naal-la irundhae | 9 maasam | Aamaa |
| **Generative AI & LLM Engineer** | Language models mela apps build panna virumbura pudhiyavanga, engineers; RAG aazhamaa | Aamaa, level B2-la irundhu | 9 maasam | Aamaa |

Thernthedukkuradhukku munnaadi therinjukka vendiya rendu vishayangal:

- **Ungalukku path-ae thevaippadaama irukkalaam.** Unga ippodhaiya velaiyai AI vechu vegamaa seiyyanum, pudhu role venaam-naa, adhukku badhilaa Library-la irukkura B1 using-AI lessons-la thodangunga: prompting, writing, summarising, research, AI badhilgala check panradhu.
- **Oru muzhu roadmap-ku account venum.** Sign in pannaama irundhaa, ovvoru path-oda mudhal stage-a mattum paarkkalaam. Account irundhaa roadmaps-um lessons-um free; andha account unga path-aiyum progress-aiyum save-um pannum. Accounts 18 vayasum adhukku melayum irukkuravangalukku mattum; ungalukku 18 vayasukku keezhanna, quick answer-um ovvoru lesson-oda mudhal pagudhiyum Library-la open-aavae irukkum.

Indha lesson, Hyderabad-la accountant-aa irukkura Imran than path-a thernthedukkuradha follow pannudhu. Kadaisiyila neengalum unga path-a thernthedutthu, unga mani nerangala plan panni, oru mudhal milestone-a vechiruppeenga.

### Check 1: unga background-la irundhu thodangunga

Ellaathaiyum vida adhiga buzz irukkura role-la irundhu illa, ungakitta aerkanavae irukkuradhula irundhu thodangunga. Ovvoru path-um oru starting point-a edhirpaarkkudhu, adhanaala ungaloda-dha adhoda match pannunga:

| Unga starting point | Idhula thodangunga | Path neenga enna therinju vechirukkanum-nu edhirpaarkkudhu |
| --- | --- | --- |
| Endha AI-a build pannanum-nu decide panna virumbureenga, code panna virumbala | AI Product Manager | Code illa; engineers kooda nallaa velai seiyya thevaiyaana alavu kathukkuveenga |
| Risk, legal, audit, compliance illa privacy-la velai seiyyureenga | AI Governance & Compliance | Code illa; unga domain arivu dhaan unga balam |
| Business processes-a nadathureenga, konjam code kathukkuveenga | AI Automation Specialist | APIs, JSON-a padichu chinna scripts ezhudhuveenga |
| IT support, networking illa security-la velai seiyyureenga, illanna security-la aarvam irukku | AI Security Engineer | Light Python; security basics zero-la irundhu kathukkodukkappadum |
| Code-ku pudhusu, aanaa language-model apps-kaaga Python kathukka thayaar | Generative AI & LLM Engineer | AI basics-la thodangudhu; level B2-la irundhu Python |
| Code panreenga, illanna ippo Python kathukkuveenga, miga parandha role venum | AI Engineer | Mudhal stage-la irundhae Python |
| Python-la irundhu aerkanavae oru language model API-a call panreenga | Agentic AI Engineer | Tool calling-la thodangudhu, adhanaala chinnadhu |
| Oru varushamo adhukku melayo Python anubavam irukku, client meetings pidikkum | Forward Deployed Engineer | Stage 1-la irundhae production-level Python |
| Python theriyum, maths, statistics, data pidikkum | Machine Learning Engineer | Python, school maths |
| Neenga oru backend, DevOps, data illa cloud engineer | MLOps Engineer | Linux, containers, cloud ungalukku seekkiram pidipadum |

Label-a illa, path enna edhirpaarkkudhungra assumption-a check pannunga. Oru API-a kooda call pannaadha oru fresher Agentic AI Engineer-a thernthedutthaa, mudhal vaarathulayae suvaththula modhuvaanga; GenAI path adhukku badhilaa padippadiyaa agents varaikkum kondu pogudhu.

### Paarkka orae maadhiri irukkura moonu engineering paths

AI Engineer, Generative AI & LLM Engineer, Agentic AI Engineer dhaan onnoda onnu ellaathaiyum vida adhigamaa overlap aagudhu. Niraya lessons-a share pannudhu, aanaa vevvaera idathula thodangi, vevvaera vishayangalukku mukkiyathuvam kudukkudhu:

| | AI Engineer | Generative AI & LLM Engineer | Agentic AI Engineer |
| --- | --- | --- | --- |
| Mudhal stage | Python, data foundations | AI basics, code illa (B2-la irundhu Python) | Model APIs, structured output, tool calling |
| Enna cover pannudhu | Classical ML, deep learning, transformers, apram LLM apps, testing, production, system design | Pudhiyavar-la irundhu system designer varai onbadhu levels: prompts, aazhamaana RAG, agents, evals, production | Agent design, frameworks, MCP, reliability, production |
| Length | 9 maasam | 9 maasam | 4 maasam |
| Eppo idha thernthedukkanum | Parandha role venum; India-la niraya AI engineer posts ML basics-aiyum kekkudhu | Language-model apps dhaan venum-nu urudhiyaa irukkeenga, illanna zero code-la irundhu thodangureenga | Aerkanavae language models vechu build panreenga, agents-la aazham venum |

**Decision rule:** neenga code panreenga, aanaa mudivu panna mudiyalanna, ellaathaiyum vida parandhadhaana AI Engineer-a edunga. Zero code-la irundhunnaa, ellaathaiyum vida menmaiyaa thodangura GenAI path-a edunga. Oru API-a call pannath therinjadhukku apram, rendaavadhu step-aa Agentic AI Engineer-a edunga. FDE-yum idhae maadhiri engineering dhaan, kooda client velai; oru varushamo adhukku melayo Python anubavam irukkuravangalukku.

### Check 2: goal-a real jobs kooda test pannunga

Maasakkanakkaa commit panradhukku munnaadi, oru maalai nerathai patthu real job posts-ku selavu pannunga. Unga city-la andha role-ku Naukri illa LinkedIn-la search panni, naalu columns-a note pannunga:

| Title | City illa remote | Kekkura varushangal | Top moonu skills illa duties |
| --- | --- | --- | --- |
| AI Automation Engineer | Hyderabad | 1 mudhal 3 | n8n, APIs, process mapping |

Title-a illa, duties-a padinga: "AI engineer"-nu per vecha oru post unmaiyila ML velaiyaa irukkalaam-nu "India-la AI careers" lesson kaattudhu. Apram moonu rules-a apply pannunga:

- **Duties ungala urchaagappaduththudhaa?** Patthu posts-la perumbaalaanadhu ovvoru vaaramum neenga rasikkakkoodiya velaiyai vivarichaa, goal-a vechukkonga. Illanna, ippovae vera path-a paarunga, naalaavadhu maasathula illa.
- **Perumbaalaana posts moonu illa adhukku mela varusham kekkudhaa?** Appo oru bridge plan pannunga: pakkathula irukkura oru junior role, illanna mudhalla unga ippodhaiya company-kkullaeyae oru AI project. Udhaaranamaa, perumbaalaana FDE, AI product manager posts munnaadiyae engineering illa product anubavam kekkudhu.
- **Unga city-la kittatthatta posts-ae illaiyaa?** Remote posts, miga pakkathula irukkura hub, global capability centres (GCCs)-oda careers pages-a paarunga; avanga pala neram nerdiyaa hire panraanga.

### Freshers-um velai seiyyuravangalum

- **Freshers**-ku real entry-level hiring-um projects portfolio-vum irukkura paths-la dhaan ellaathaiyum vida nallaa pogum: AI Engineer, GenAI, ML Engineer, AI Automation. 0 mudhal 2 varushathukkaana typical pay-a Jobs page kaattudhu (2 November 2026 annaikku check pannadhu); udhaaranamaa AI Engineer-ku varushathukku 6 mudhal 12 lakh CTC, AI Automation Specialist-ku 4 mudhal 8 lakh. FDE, AI Product Manager-oda adhaivida adhigamaana early bands freshers-ku aridhaa dhaan kidaikkum.
- **Velai seiyyuravanga** thangalukku aerkanavae therinjadha reuse panra path-la dhaan ellaathaiyum vida vegamaa switch panraanga: DevOps-la irundhu MLOps, compliance-la irundhu governance, oru Java developer FDE-ku. Miga vegamaana route pala neram unga sondha company-kkulla oru AI pilot dhaan.

### Check 3: nerathai pathi nermaiyaa irunga

Deadline edhuvum illa. Ella path-um unga sondha vegathula pogum; adhanaala oru nalla vaarathula ungalaala mudinja adhigapatcha mani nerathai illa, maasakkanakkaa thodara mudinja vaaraandhira mani nerathai thernthedunga:

| Vaaraandhira mani nerangal | Eppadi irukkum |
| --- | --- |
| 3 mani neram | Vaarathukku oru chinna lesson, ozhungaa |
| 5 mani neram | Vaaraa vaaram oru lesson, adhoda practice |
| 8 mani neram | Rendu lessons, oru chinna project step |
| 12 mani neram | Oru stage vazhiyaa seeraana munnetram, projects-kkum neram |

Mani nerathai oru date-aa maaththa, oru chinna kanakku podunga: ovvoru lesson page-layum adhoda hours irukku, adhanaala oru stage-oda hours-a kootti, unga vaaraandhira hours-aala vaguthu, practice-ku sumaar moonula oru pangu serthukkonga. Level test irukkura anju paths-la (AI Engineer, GenAI, Agentic AI, FDE, MLOps), roadmap-la **Find my level**-a azhuthunga: aerkanavae therinjadha test skip pannum, michathukku unga hours-la sumaar etthana vaaram aagum-nu result kaattum. Maththa anju paths stage 1-la thodangum. Rendu vaaram irubadhu mani neram padichuttu apram edhuvumae illaadhadha vida, seeraana anju mani neram nalladhu.

### Oru plan podunga

Oru plan-la moonu paagangal:

1. **Unga vaarathula nilaiyaana study slots**, udhaaranamaa Tuesday, Thursday maalai, Sunday kaalai. Meetings maadhiri calendar-la podunga; exams, month-end close maadhiri aerkanavae therinja busy vaarangalaiyum note pannunga.
2. **Naalu vaarathukkulla oru mudhal milestone**, yaarkittayaavadhu kaattakkoodiyadhu: mudicha oru stage, oru mudhal workflow, velai seiyyura oru chinna app. Adhoda lesson hours unga slots-oda naalu vaarathukkulla, konjam idam micham irukkura maadhiri adangudhaa-nu check pannunga.
3. **Accountability**: per sollakkoodiya oru aal, unga update-ku oru nilaiyaana naal, andha update-um; udhaaranamaa enna mudicheenga, aduthu ennannu oru vari.

### Mudhal stage-ku apram maruparisheelanai pannunga

Stage 1-ku apram kelunga: indha velaiyai naan rasikkirenaa, job posts-la irukkura role pakkam idhu ennai nagarthudhaa? Illanna, maathunga. Mudicha lessons carry over aagum: udhaaranamaa, "AI, machine learning, language model: moonum enna-nu simple-aa" patthu paths-la aarula irukku. Oru lesson kashtamaa irundhuchunno, oru vaaram moshamaa poochunno maathaadheenga. Adhu ella path-layum saadhaaranam dhaan.

## Oru worked example

Imran, 34, Hyderabad-la oru distribution company-la accountant. Sila maasamaa velaiyila oru AI assistant-a use panraar. Bank reconciliations-a vegappaduththa adha use panradhu avarukku pidichirundhudhu, innum adhigam panna virumburaar; aanaa full-time programmer aaguradhula avarukku aarvam illa.

**Pudhu role-aa illaiyaa?** Automation dhaan than mukkiya velaiyaa irukkura oru role avarukku venum; adhanaala using-AI lessons mattum podhaadhu.

**Background.** Coding illa, finance, process arivu valuvaa irukku, Excel formulas-la comfortable. Rendu paths possible-aa theriyudhu: AI Automation Specialist (konjam code), AI Governance & Compliance (code illa), yenna avarukku financial controls theriyum.

**Goal.** Hyderabad-la patthu job posts-a padikkiraar, ovvonnukkum anju. Avaroda notes (idhu oru illustration dhaan, survey illa) kaattuvadhu: governance posts perumbaalum avarkitta illaadha risk illa compliance anubavatha kekkudhu, avarukku bore adikkira policy writing-a vivarikkudhu. "AI automation engineer" illa "finance automation analyst"-nu title irukkura automation posts n8n, Power Automate, APIs, process mapping-a kurippidudhu. Avaththoda duties "automate invoice processing", "reduce manual reconciliation"-nu irukku; avarukku pidichadhu sariyaa idhu dhaan. Perumbaalaanadhu 0 mudhal 3 varusham kekkudhu. APIs, JSON-a padikkavum chinna scripts ezhudhavum vendiyirukkum-nu avar aethukkiraar.

**Neram.** Avarukku rendu chinna kuzhandhaigal. Nadaimuraiyaa: rendu weekday maalaigal, oru weekend kaalai, vaarathukku sumaar 5 mudhal 6 mani neram. Path-oda thoraayamaana guide moonu maasam; projects-aiyum kanakkula eduthaa, avaroda vegathula konjam adhigamaa aagalaam.

Aaga 13 mani neram lessons. Vaarathukku 5.5 mani nerathula naalu vaaram-naa 22 mani neram; practice-kkum rework-kkum 9 mani neram micham. Milestone adangudhu.

## Podhuvaa panra thappugal

- **Ellaathaiyum vida adhiga hype aana, illanna ellaathaiyum vida adhiga sambalam thara path-a thernthedukkiradhu.** Unga background-kkum, ovvoru vaaramum neenga rasikkakkoodiya velaikkum porundhuradha thernthedunga.
- **Oru path enna edhirpaarkkudhu-nnu kavanikkaama viduradhu.** Agentic AI Engineer, neenga Python-la irundhu oru API-a call pannuveenga-nu edhirpaarkkudhu; FDE oru varusha Python anubavatha edhirpaarkkudhu. Adha innum ungalaala panna mudiyalanna, oru step munnaadi thodangunga.
- **Velaiyila AI use panna mattum virumbumbodhu oru career path edukkiradhu.** Using-AI lessons ungala maasakkanakkula illa, sila mani nerathula anga kondu serkkum.
- **Nadaimuraikku othuvaraadha mani nerangala plan panradhu.** Irukkanum-nu aasaippadura mani nerangala illa, maasakkanakkaa thodara mudinja mani nerangala thernthedunga.
- **Koottip paarkkaadha oru milestone-a veikkiradhu.** Mudhalla lesson hours-a koottunga; illanna milestone thallip pogum, neenga pinthangittadhaa unaruveenga.
- **Vaaraa vaaram path-a maathuradhu.** Maruparisheelanai panradhukku munnaadi oru stage-ku commit pannunga.
- **Projects-a skip panradhu.** Employers paarkka virumburadhu projects dhaan, unmaiyaana nambikkaiyum anga irundhu dhaan varum.
- **Thaniyaa kathukkiradhu.** Oru aalukku vaaraa vaaram oru nilaiyaana update kuduthaa, sathamillaama vilagip poradhu romba kashtamaagum.
- **Perfect plan-kaaga kaathirukkiradhu.** Indha vaaram thodangura oru nalla plan, aduththa maasam thodangura perfect plan-a vida nalladhu.

## Practice pannunga

Parandha paarvaikku Watch & learn panel-la irukkura video lesson-a paarunga; apram Xplaind-oda Roadmaps page-ku ponga.

Indha lesson-oda check dhaan unga plan. Oru path-a thernthedutthu, sign in panni **Make this my path**-a azhuthunga. Apram idhoda oru page plan ezhudhunga:

1. **Yen indha path**, unga background, patthu job posts pathina notes adippadaiyila.
2. **Unga vaaraandhira study slots**, unga calendar-la.
3. **Unga mudhal milestone, adhoda date**, sumaar naalu vaaram thalli.
4. **Yaarukku update kudupeenga**, endha naal-la.

Share panradhukku munnaadi, adha test pannunga:

| Test | Eppo pass aagum |
| --- | --- |
| Path-ku niyaayam irukkaa? | Unga background-aiyum patthu job posts enna kettuchunnum adhu kurippidudhu |
| Hours real-aa? | Slots koottinaa unga vaaraandhira hours varudhu, avai unga calendar-la irukku |
| Milestone-a check panna mudiyumaa? | Neenga kaattakkoodiya oru vishayam, naalu vaarathukkulla oru date irukku, adhoda lesson hours adangudhu |
| Yaaraavadhu kavanikkiraangalaa? | Per sollakkoodiya oru aal, nilaiyaana oru update naal |

Mudhal lesson-a indha vaaramae thodangunga. Ippodhaiya velaiyila mattum AI venumaa? Moonu using-AI lessons-aiyum, avaththa try panna oru real velai task-aiyum thernthedunga.

**Mudinjadhu-nnu eppo sollalaam:** neenga thernthedutha roadmap "This is your path"-nu kaattudhu, unga mudhal study slot unga calendar-la irukku.
