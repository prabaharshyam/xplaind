## Idhu enna

AI kathukkradhu romba kashtam-nu makkal vittu poradhu common kaaranam illa. Theliva route illaama aarambikkaradhu thaan: inga oru YouTube video, anga oru course, vaaram vaaram oru pudhu tool, munnaetram theriyaadhu. Oru path-a choose panninaa idhu sari aagum.

Xplaind-la onbadhu paths irukku. Ovvonnum shared lessons-oda oru ordered route, ovvoru stage-um mudiyum podhu oru project. Neenga mudicha lessons adhai use panra **ella** paths-layum count aagum, adhanaala apram maathinaalum ungaloda velai waste aagaadhu.

| Path | Yaarukku | Coding |
| --- | --- | --- |
| **AI Engineer** | Data, ML, LLM apps, production-nu broad AI engineering role venum-nu virumburavangalukku | Aam |
| **Generative AI & LLM Engineer** | Language models mela applications build panravanga, RAG aazhama, Python basics-la irundhu system design varaikkum | Aam |
| **Forward Deployed Engineer (FDE)** | Clients-oda, clients-kaaga AI systems build panra engineers | Aam |
| **AI Product Manager** | Enna AI build pannanum-nu decide panni, measure panni, poruppoda ship panravanga | Illa |
| **Agentic AI Engineer** | AI agents-a safe-aa design panni odra engineers | Aam |
| **AI Automation Specialist** | n8n maadhiri tools-la AI steps-oda business workflows-a automate panna virumburavanga | Konjam |
| **AI Governance & Compliance Specialist** | AI-a safe, fair, lawful-aa vechukkura risk, compliance, legal, policy makkal | Illa |
| **Machine Learning Engineer** | Classical, deep learning models-a train panravanga | Aam, maths-um |
| **MLOps Engineer** | ML, LLM systems-a periya scale-la nambagamaa odra engineers | Aam |

Indha lesson-la Hyderabad-la accountant Imran-a follow pannuvom, work-la sila maadham AI use panna apram avanga path-a pick panraanga. Lesson mudiyum podhu, neenga oru path-a choose panni, vaara hours-a plan panni, mudhal milestone set panniruppeenga.

## Idhu eppadi work aagudhu

Nallaa choose panna moonu checks, indha order-la: **background, goal, neram.**

```flow
dir: LR
1. Background | enakku ippo enna theriyum? Coding, maths, oru domain? -> 2. Goal | indha role-oda real job posts ennai excite pannudhaa?
2. Goal -> 3. Neram | maadha-kanakkaa vaaram evvalavu hours keep panna mudiyum?
3. Neram -> Ungaloda path
```

### Check 1: ungaloda background-la irundhu aarambinga

| Neenga code panna mudiyuma, illa Python kathukkuveengala? | Neenga... | Idhula start pannunga |
|---|---|---|
| Illa | AI-oda workflows build panna virumbureenga | AI Automation Specialist |
| Illa | Enna AI build pannanum-nu decide panna virumbureenga | AI Product Manager |
| Illa | Risk, legal, compliance-la velai seiyureenga | AI Governance & Compliance |
| Aam | Strong maths illa data background irukku | Machine Learning Engineer |
| Aam | DevOps illa cloud-la irundhu varreenga | MLOps Engineer |
| Aam | Clients-oda velai seiyya pidikkum | Forward Deployed Engineer |
| Aam | Agents-la aazham venum | Agentic AI Engineer |
| Aam | LLMs, RAG-la aazham venum | Generative AI & LLM Engineer |
| Aam | Innum theriyala | AI Engineer (romba broad) |

### Check 2: goal-a real jobs-oda test pannunga

Job site-a open panni, path ethukku kondu pogudho andha role-ku pathu real job descriptions-a padinga. Dhinasari velai ungalai excite pannina, nallaa. Boring-aa therinjaa, maadha-kanakkaa invest panra munnaadi vera path-a paarunga. Indha pathu nimisha check, ungalukku set aagaadha romba hype aana path-la irundhu neraya perai kaappathirukku.

### Check 3: neram pathi nermaiyaa irunga

Deadline illa. Ovvoru path-um ungaloda pace-la work aagum, adhanaala nalla vaaram-la neenga seiyra adhigam illa, neenga neenda kaalam keep panna mudiyura vaaram hours-a pick pannunga:

| Vaaram hours | Eppadi irukkum |
| --- | --- |
| 3 hours | Vaaram oru lesson, sariyaa |
| 5 hours | Ovvoru vaaramum oru lesson-um adhoda practice-um |
| 8 hours | Rendu lessons-um oru sirusaana project step-um |
| 12 hours | Oru stage-la steady progress, projects-ku neramum |

Rendu vaaram 20 hours seiyradhukku appuram onnum illaama irukkradhai vida, steady-aa 5 hours nallaa. Engineering paths-la, ungalukku munnaadiyae theriyradha thaandra level test edunga.

### Oru plan pannunga

Oru plan-la moonu pagudhi:

1. **Ungaloda vaaram-la fixed study slots**, example Tuesday, Thursday saayangalam, Sunday kaalai. Adha meetings maadhiri calendar-la podunga.
2. **Naalu vaarathukkulla mudhal milestone**, stage 1 mudikkradhu illa adhoda project build panradhu maadhiri.
3. **Accountability**: ungalodu kathukkura oru friend, oru study group, illa ovvoru vaaramum ungaloda progress-a share panradhu.

### Mudhal stage-ku apram thirumba paarunga

Stage 1-ku apram kelunga: enakku idhu pidikkudhaa, adhu ennai andha role pakkam kondu pogudhaa? Illa-na maathunga. Neenga mudicha lessons carry aagum, adhanaala romba kammiyaa thaan izhappeenga.

## Oru worked example

Imran, 34, Hyderabad-la oru distribution company-la accountant. Sila maadhama work-la AI assistant use panraanga. Bank reconciliations-a vegamaakka adha use panradhu pidichu, innum seiyya virumburaanga, aana programmer aagura aasai illa.

**Background.** Coding illa, finance-um process knowledge-um strong, Excel formulas nallaa theriyum.

**Goal.** Pathu job posts padikkuraanga. "AI automation specialist", "finance automation analyst" titles-la n8n, Power Automate, APIs, process mapping solluraanga, "automate invoice processing", "reduce manual reconciliation" maadhiri velai varnikkuraanga. Idhu avanga pidichathoda exact-aa match aagudhu.

**Neram.** Avanga-ku rendu sirusaana kuzhandhaigal. Realistic-aa: rendu vaaram-naal saayangalam, oru weekend kaalai, vaaram sumaar 5-la irundhu 6 hours. Indha pace-la AI Automation Specialist path sumaar moonu maadham edukkum.

Avanga plan:

| Pagudhi | Imran-oda plan |
| --- | --- |
| Path | AI Automation Specialist |
| Study slots | Tuesday, Thursday raathiri 8-la irundhu 9:30, Saturday kaalai 9-la irundhu 11 |
| Mudhal milestone | Naalu vaarathula: invoice emails-a padichu sheet-la log panra avanga mudhal n8n workflow |
| Accountability | Ovvoru Sunday-um, avangala maadhiri kathukkura oru colleague-kku sirusaana update share panraanga |
| Final project | Imran plan pathi sonna apram, avanga manager kuduthadha oru real reconciliation process |

Manager-kitta sonnadhu avanga seidha nalla vishayam-nu aachu: ippo avanga final project real velai, adhanaala practice exercise-a vida avanga portfolio romba strong-aa irukkum.

## Podhuvaa panra thappugal

- **Romba hype aana path-a pick panradhu.** Ungaloda background-kum, ungalukku pidikkura velaikkum set aagura path-a pick pannunga.
- **Realistic illaadha hours plan panradhu.** Ungalukku irukkanum-nu aasai padra hours illa, maadha-kanakkaa keep panna mudiyura hours-a choose pannunga.
- **Ovvoru vaaramum path maathradhu.** Thirumba yosikkum munnaadi oru stage-ku commit pannunga.
- **Projects-a thaandradhu.** Employers paakka virumbradhu projects thaan, unmaiyaana confidence-um adhulayae varum.
- **Accountability illaama thaniyaa kathukkradhu.** Oru aal kooda vaaram oru check-in irundhaa, thodarndhu poga vaaippu romba adhigam.
- **Perfect plan-kaaga kaathirukkradhu.** Indha vaaram aarambikkura nalla plan, adutha maadham aarambikkura perfect plan-a vida nallaa.

## Practice pannunga

Periya paarvai-ku Watch & learn panel-la irukkura video lesson-a paarunga, apram Xplaind-oda Roadmaps page-ku thirumbi vaanga.

Indha lesson-oda check ungaloda plan. Xplaind-la oru path-a choose panni, "Make this my path" press pannunga. Apram oru-page plan ezhudhunga:

1. **Yen indha path**, rendu vaakkiyathula, ungaloda background-um neenga padicha job posts-um base panni.
2. **Ungaloda vaaram study slots**, munnaadiyae calendar-la irukkanum.
3. **Ungaloda mudhal milestone-um adhoda date-um**, sumaar naalu vaaram thalli.
4. **Progress-a yaar kooda share pannuveenga**, eppo.

Indha vaaram mudhal lesson-a aarambinga.

**Mudinjadhu-nu eppo sollalaam:** Neenga choose panna path Xplaind-la "your path"-nu kaattum, ungaloda mudhal study slot calendar-la irukkum.
