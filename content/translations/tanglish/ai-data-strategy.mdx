## Idhu enna

Oru AI product adhoda data-va vida nalla irukkaadhu: badhil sollum podhu padikkura documents, adha judge panna use panra examples, adha nalla aakkura feedback. **Data strategy**-na idhu ellaathukkum plan, build aarambikkum munnaadiyae ezhudhinadhu, launch-ku apram kandupidichadhu illa.

Idhu aaru kelvigalukku badhil solludhu:

| Kelvi | Example badhil |
| --- | --- |
| Product-ku run time-layum improvement-kum **enna data** thevai? | Run time-la policy documents; evaluation-ku real customer questions-um expert answers-um |
| Adhu **engirundhu** varum, **yaarukku sondham**? | Documents policy team-ku sondham; question log support-ku sondham |
| Indha purpose-ku use panna **namakku anumadhi irukkaa**? | Chats answers-a nalla aakka help pannum-nu customers-kku sonnom, avanga opt out pannalaam |
| Adhu **evvalavu nalladhu**, eppadi current-aa vachchirukkom? | Documents ovvoru quarter-um review; duplicates remove |
| Adhu vechu product-a **eppadi evaluate** panrom? | Ovvoru release-ku munnaadiyum run aagura 150 questions-oda oru golden set |
| **Use panradhu eppadi nalla data-va uruvaakkum?** | Reason-oda thumbs down, ovvoru vaaramum review; fixes golden set-la serkkapadum |

```flow
title: AI product-la moonu vagai data
Run-time data | badhil sollum podhu padikkradhu: documents, records, history -> Nalla product
Evaluation data | adhu vechu judge panradhu: real questions-oda oru golden set -> Nalla product
Feedback data | apram users sollradhu: thumbs, edits, overrides -> Nalla product
```

Indha lesson Lakshmi-a follow pannum. Chennai-la oru agri-tech startup-la product manager-aa irukkura avanga, farmers-oda crop kelvigalukku badhil solra voice assistant-ku data plan ezhudhuraanga. Mudiyum podhu, oru privacy officer-um oru engineer-um rendu perum otthukkura oru-page data plan-a ezhudha mudiyum.

## Idhu eppadi work aagudhu

### Run-time data

Documents-la irundhu badhil solra product-ku, endha document collections-a search pannum, avai eppadi fresh-aa irukkum, yaar edha paarkkalaam-nu decide pannunga. Personalisation-ku, endha user data-va consent-oda use pannuvom-nu decide pannunga. Run-time data illa illa pazhasaa irundha, model-a vida adhaan neraya thappaana answers-ku kaaranam-aagum.

### Evaluation data

**Golden set**-na, domain experts-oda serndhu build panna, realistic inputs-um edhirpaarkkura outputs illa quality judgements-um irukkura collection. Real users-la irundhu 50-la irundhu 100 cases-la aarambinga, invent panna ones illa. Neenga kandupidikkura ovvoru mukkiyamaana failure-oda adha valarunga. Golden set thaan product-oda quality contract: adhu illa-na "ippo nalla irukkaa?"-ngradhu verum abiprayam.

### Feedback data

Modhal naal-lerndhae feedback capture panra maadhiri product-a design pannunga:

- short reason-oda thumbs up, down;
- users drafts-la panra edits, adhu enna thappu-nu exact-aa kaattum;
- human reviewers-oda overrides;
- oru aal kitta escalations.

Yaaraavadhu schedule-padi review panni, adha fixes-aavum, pudhu golden-set cases-aavum maathinaa mattum thaan feedback useful.

### Labelling

Sila improvements-ku labelled data thevai: sariyaana categories, sariyaana extractions, sariyaana answers. Yaar label panraanga (domain experts, trained staff, illa oru vendor), enna written guidelines-oda, label quality-a eppadi check panreenga-nu decide pannunga, example-ku rendu perai oru sample-a label panna sollitu compare panradhu.

### Permission, privacy

India-oda **DPDP Act**-kum adhu maadhiri laws-kum padi, personal data-va makkalukku sonna, avanga otthukkitta purposes-ukku mattum, illa vera lawful ground-la mattum use pannalaam. Customer chats-a vachchu model-a nalla aakkanum-na explicit notice-um consent-um thevai-padalaam. Business clients-oda contracts avangaludaiya data-va avangaludaiya service-ku thavira vera edhukkum use pannakoodaadhu-nu solla-lam. Idhai ellam data-va collect panradhukku **munnaadi** decide pannunga.

### Quality, coverage

| Check | Kelvi | Ignore pannaa risk |
| --- | --- | --- |
| Coverage | Ella user types, languages, regions-um irukkaa? | Illaadha groups-ku failures-um bias-um |
| Freshness | Data current-aa? | Pazhaya answers |
| Duplicates | Ore vishayam pala thadavai ennapadudhaa? | Skew aana results |
| Errors | Labels-um records-um sariyaa? | Product thappugalai kathukkum |

Data-vula irukkura bias product-la bias-aa maarum.

### Ownership, governance

Ovvoru dataset-kum oru owner-a peyar vainga, evvalavu naal vachchirukkanum, eppo delete pannanum-nu define pannunga, adhu engirundhu vandhadhu-nu record pannunga. Owner illaadha data sattham illaama pazhasaagum.

### Flywheel

```flow
dir: LR
title: Flywheel
Innum usage -> Innum feedback -> Nalla data -> Fixes-um pudhu golden cases-um -> Nalla product -> Innum usage
```

Nalla products usage-a, product-a nalla aakkura data-vaa maathum. Feedback capture aagi, permitted-aa irundhu, unmaiyaave use aanaa mattum thaan flywheel suzhalum.

## Oru example

Chennai-la oru agri-tech startup, farmers-oda crop kelvigalukku Tamil-layum English-layum badhil solra voice assistant build panraanga. Product manager Lakshmi data plan ezhudhuraanga.

| Data | Source | Owner | Permission | Evvalavu naal vachchirukkanum |
| --- | --- | --- | --- | --- |
| Run-time: crop advisories | Agricultural university advisories, state agriculture department guidance, ovvoru season-um update aagum | Content lead | Public sources | Maatra varaikkum |
| Run-time: weather, prices | Weather, market price feeds | Engineering | Licensed feeds | Rolling 30 naal |
| Evaluation: golden set | Field staff-oda collect panna 200 real farmer questions, anju crops, moonu districts, rendu agronomists answers-a check panninaanga | Lakshmi | Collect panra podhu farmers otthukkittaanga | Thodarndhu |
| Feedback | Ovvoru answer-kum apram "Idhu help pannucha?"-nu voice prompt, oru callback option, field staff-oda vaaram thorum corrections | Support lead | Modhal use-la Tamil-la notice, opt-out-oda | Recordings 90 naal, farmer vera maadhiri otthukkalana |

**Oru coverage gap.** Modhal 200 questions-a review panna podhu, perumbaalum ethuvum women farmers-kitta irundhu varala, aana target districts-la field velaiyila perumbaagam avanga thaan seiraanga. Field staff women's self-help groups-oda rendu sessions nadatthi 60 questions serkkuraanga, adhula neraya modhal sample miss panna crops, pests pathi.

**Aaru maasam apram:**

| Measure | Launch-la | Aaru maasam apram |
| --- | --- | --- |
| Golden set size | 200 questions | 650 questions |
| Accuracy reporting | Overall mattum | Crop-padi, district-padi, maasam-thorum |
| Romba common failure | Local dialect-la pest names | Feedback-la irundhu build panna glossary-yaala fix aachu |

Glossary nerlaye flywheel-la irundhu vandhadhu: farmers "help pannala" amukkinaanga, field staff recordings-a kettaanga, team local peyargala serththanga.

## Podhuvaa panra thappugal

- **Ungakitta irukkura edha data-vayum use pannalaam-nu nenaikkiradhu.** Modhalla consent, law, contracts-a check pannunga.
- **Evaluation set illaama irukkradhu.** Adhu illa-na quality abiprayam aagum, ovvoru change-um jackpot aagum.
- **Yaarum padikkaadha feedback buttons.** Button mattum illa, vaaram thorum review routine-um build pannunga.
- **Coverage-a ignore panradhu.** Illaadha groups-um languages-um failures-um bias-um aagum.
- **Owner illaama irukkradhu.** Owner illaadha data pazhasaagum, yaarukkum theriyaadhu.
- **Test questions-a invent panradhu.** Real user questions team karpanai panradhai vida messy-yaanadhu, adhanaala adhigam useful.

## Practice pannunga

Keezha link panni irukkura data collection, evaluation pathina PAIR guidebook chapter-a padinga, Hamel Husain-oda AI products-a nalla aakkura field guide-aiyum padinga.

1. **Data-va list pannunga.** Oru AI product idea-ku, run-time, evaluation, feedback data-va, ovvonnoda source-um owner-um serthu list pannunga.
2. **Permission.** Ovvonnukkum permission basis-um evvalavu naal vachchirukkuveenga-nu-um ezhudhunga.
3. **Golden set.** Domain theriñja oru aal-oda 30 evaluation cases draft pannunga, oru coverage gap-a note pannunga.

**Mudinjadhu-nu eppo sollalaam:** oru privacy officer-um oru engineer-um rendu perum otthukkura oru-page data plan-a present panna mudiyum.
