## Idhu enna

Oru **computer-use agent** software-oda screen vazhiyaa velai seiyum: screenshots-a vaangi, enga click pannanum, enna type pannanum-nu mudivu panni, thirumba thirumba seiyum. Oru **browser agent** adhe maadhiri, oru web browser-kulla, sila neram page-oda picture-oda sernthu adhoda structure-aiyum padikkum.

Idhu oru unmaiyaana idaiveliya nirappudhu. Oru system-ku API irundhaa, API-a call pannunga. Illaina, neraya government portals, insurer, bank portals, pazhaya desktop applications maadhiri, oru aal illaama automate panna screen control mattum thaan vazhiyaa irukkalaam.

```flow
title: Ladder: velai seira uyarndha rung-a use pannunga
1. API | vegam, cheap, romba nambakkoodiyadhu -[API illaya?]-> 2. Scripted browser tool | Playwright, fixed steps, oru tool-aa expose pannadhu
2. Scripted browser tool -[steps maaruma?]-> 3. Agent-driven browsing | page structure-a padikkum, actions-a mudivu pannum
3. Agent-driven browsing -[useful page structure illaya?]-> 4. Full computer use | screenshot, decide, click illa type, screenshot: romba mella, kammi nambakkai
```

Rung 3, 4-ku, oru safety box use pannunga: oru isolated VM, oru dedicated account, oru site allow-list, submit, pay, delete-ku munnaadi approval, record panna screenshots, captchas-um OTPs-um oru aal-kitta.

Indha lesson, Pune-la oru chartered accountancy firm-a follow pannum, avanga ovvoru maasamum clients-oda tax documents-a kaiyaala download panna maniththuliga selavu pannuvaanga.

## Idhu eppadi work aagudhu

**Romba nambakkoodiyadhu-la irundhu kammi varaikkum options-oda oru ladder:**

1. **Oru API**, irundhaa, illa kekkalaam-naa.
2. Playwright maadhiri oru library-oda **scripted browser automation**: neenga ezhudhina fixed steps, agent-ku oru tool-aa ("download_gst_return(gstin, period)") expose panni. Vegam, cheap, predictable.
3. **Agent-driven browsing**: agent page structure-a padichu actions-a mudivu pannum, maarura sites-ku.
4. Desktop apps-ku, romba kashtamaana cases-ku, screenshots-la irundhu **full computer use**. Romba mella, romba selavaanadhu, kammi nambakkai.

Velai seira uyarndha rung-a use pannunga, appuram serthu use pannunga: theriyura steps-ku scripted tools, pages predict panna mudiyaadha idathula mattum agent control.

**Loop.** Screenshot, oru action mudivu pannunga (oru point-la click, type, scroll, oru key amukkuradhu), seiyunga, thirumba screenshot. Ovvoru step-um oru image-oda oru model call, adhanaala neelamaana tasks-ku nimishangal aagum, real paisa selavaagum.

**Safety.**

- Thevaiyaana apps, accounts mattum irukkura oru isolated virtual machine illa container-la odunga.
- Entha websites-a reach panna mudiyum-nu restrict pannunga.
- Podhuvaana credentials-a ennaikkum kodukkaadheenga; kammiyaana permission-oda oru dedicated account use pannunga.
- Screen-la irukkura ellaathaiyum untrusted-aa paarunga: web pages-la agents-a target panra instructions irukkalaam.
- Forms submit panradhu, pay panradhu, anuppuradhu, delete panradhukku munnaadi human approval kelunga.
- Audit-ku ovvoru session-oda screenshots illa video-va record pannunga.

**Reliability.** Pages maarum, pop-ups varum, sessions expire aagum, captchas bots-a thadukkum. Failures varum-nu edhirpaarunga, adha kandupidinga (edhirpaartha confirmation varala), oru aal-kitta thirumba kodunga.

**Rungs compare pannadhu:**

| Rung | Ovvoru action-ku speed | Cost | Eppo break aagum | Edhukku best |
| --- | --- | --- | --- | --- |
| API | Milliseconds | Romba kammi | API maarum podhu, adhikam illa | API irukkura entha onnukkum |
| Scripted tool | Oru second-ku kammi | Kammi | Page layout maarum podhu; sathama fail aagum | Stable portals |
| Agent browsing | Seconds | Medium | Vichitthirama pages, pop-ups | Maarura sites |
| Computer use | Pathu pathu seconds | Romba adhigam | Pala vishayangal-la | Desktop apps, kadaisi vazhi |

**Failure-a kandupidikkuradhu.** Ovvoru automated step-kum success eppadi irukkum-nu theriyanum: oru confirmation message, edhirpaartha size-la download aana file, oru list-la pudhu row. Ovvoru mukkiya action-kum aprom adha check pannunga. Adhu illaina, guess pannaama nirutthunga, kadaisi screenshot-aiyum ippo varaikkum steps-aiyum save panni, oru theliva note-oda task-a oru aal-kitta kodunga. Tax illa banking portal-la oru silent thappaana action, nirutthina task-a vida romba adhigam selavaagum.

**Value-va measure panradhu.** Meechcham aana manineram, ovvoru step-la success rate, ovvoru action-ku average neram, hand-backs ennikkai-a track pannunga. Hand-backs project-oda failure illa; system design pannapadi velai seiyradhu. Avai oru page-la kuvindhaa, andha page scripted tool-ku oru candidate.

**Success check-oda oru scripted browser tool.** Idhu Playwright-oda Python API use pannudhu. Agent-ku oru tool mattum theriyum, `download_notice`, oru argument-oda:

```python
from pathlib import Path
from playwright.sync_api import sync_playwright, TimeoutError as PWTimeout

ALLOWED = {"www.example-gov.in"}                       # the only site this tool may reach

def download_notice(notice_id: str) -> str:
    if not notice_id.isdigit():
        return "notice_id must be digits only."
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page(accept_downloads=True)
        page.route("**/*", lambda route: route.continue_()
                   if route.request.url.split("/")[2] in ALLOWED else route.abort())
        try:
            page.goto("https://www.example-gov.in/notices", timeout=20_000)
            page.get_by_label("Notice number").fill(notice_id)
            page.get_by_role("button", name="Search").click()
            with page.expect_download(timeout=20_000) as dl:
                page.get_by_role("link", name="Download PDF").click()
            path = Path("downloads") / f"notice-{notice_id}.pdf"
            dl.value.save_as(path)
            if path.stat().st_size < 1_000:                 # success check: a real PDF, not an error page
                return "Download looked empty; a person should check this notice."
            return f"Saved {path}"
        except PWTimeout:
            page.screenshot(path=f"downloads/failed-{notice_id}.png")
            return "The site did not respond as expected; screenshot saved for a person."
        finally:
            browser.close()
```

Labels-um roles-um (`get_by_label`, `get_by_role`) CSS paths-a vida layout changes-a nallaa thaangum. Ovvoru exit-um, agent adha pass panna oru sentence-a return pannum.

**Screenshot loop, sketch.** Computer-use models unga code odikkura oru loop-la velai seiyum:

```python
for step in range(MAX_STEPS):
    shot = take_screenshot()
    action = model_decide(goal, history, shot)        # e.g. {"type": "click", "x": 412, "y": 300}
    if action["type"] == "done":
        break
    if is_risky(action, current_url()):               # submit, pay, send, delete
        if not ask_person(action, shot):
            break
    perform(action)
    history.append(action)
```

Providers thangaloda sondha action formats-oda computer-use tools tharuvaanga; mela irukkura shape appadiyae irukkum. `is_risky` check unga code, page address-aiyum click-kuzha irukkura element-aiyum use pannudhu, model-oda abhiprayam illa.

**Isolation, practice-la.** Browser-a, unga internal network-ku access illaadha container-la, oru outbound allow list-oda, ovvoru task-kum pudhu profile-oda, oru dedicated low-permission account-oda odunga. Ovvoru task-kum aprom container-a delete pannunga, appo cookies-um downloads-um runs-ukku naduvula leak aagaadhu.

**Evvalavu nallaa irukku?** Web, desktop tasks-oda public benchmarks nallaa munnaeruvadha kaattum, aana agents innum makkal easy-aa mudikkura neraya everyday tasks-la fail aagudhu, especially pop-ups, logins illa vichitthirama layouts irukkura neelamaana ones-la. Edhaiyum promise panna munnaadi, unga sondha tasks-la measure pannunga.

## Oru worked example

Pune-la oru chartered accountancy firm, ovvoru maasamum, oru government portal-layum API illaadha oru pazhaya accounting desktop app-layum irundhu clients-oda tax documents-a download panna maniththuliga selavu pannudhu.

Design:

- Portal-ku, oru scripted Playwright tool, oru vault-la irundhu client-authorised credentials-oda login panni, theriyura pages-ku poi files-a download pannum. Agent tool-a call pannum; adhu freely browse pannaadhu. Portal-oda layout maarum podhu, script sathama fail aagum, oru engineer sari pannuvaanga.
- Desktop accounting app-ku, oru computer-use agent, file share thavira internet illaadha oru Windows virtual machine-la odum. App-oda menus-a follow panni ledgers-a export pannum. Entha file-aiyum overwrite panna munnaadi, oru staff member approve panna kekkum.
- Captchas-um one-time passwords-um design-laye oru aal-kitta pogum.

Results: 120 clients-ku maadha download velai, sumaar 60 staff hours-la irundhu 12-ku kuraiyudhu, perumbaalum approvals-um exceptions-um. Computer-use steps ovvoru action-kum average 40 seconds edukkum, 91% neram succeed aagum; failures kadaisi screenshot-oda thirumba kodukkapadum.

| Measure | Munnaadi | Aprom |
| --- | --- | --- |
| Maadham staff hours, 120 clients | Sumaar 60 | Sumaar 12, perumbaalum approvals-um exceptions-um |
| Ovvoru action-ku computer-use neram | Pothu illa | Sumaar 40 seconds |
| Computer-use success rate | Pothu illa | 91%, failures screenshot-oda thirumba kodukkapadum |

## Podhuvaa panra thappugal

- **API illa script podhumaana idathula screen control.** Adhu mella, selavaanadhu, nambakkai kammi.
- **Real desktop-la real logins-oda odradhu.** Isolated machine-um dedicated account-um use pannunga.
- **Screen-la irukkura text-a nambradhu.** Pages-la injected instructions irukkalaam.
- **Thirumba maatha mudiyaadha actions-ku munnaadi human illa.** Submissions-ku, payments-ku approval thevai.
- **Captchas-a thorkadikka try panradhu.** Mariyaadhai kodunga; andha step-a oru aal-kitta kodunga.
- **Tasks-ukku naduvula browser profile-a thirumba use panradhu.** Cookies-um sessions-um oru job-la irundhu adutha job-ku leak aagum.
- **Scripted tools-la CSS-path selectors.** Chinna layout changes-ku break aagum; labels-um roles-um pannunga.

## Computer-use agent-a use pannaadha neramgal

- **Oru API illa export irukku**, illa vendor-kitta kekkalaam.
- **Steps fixed-aa irukku**: scripted Playwright tool vegam, cheap, adhigam nambakkoodiyadhu.
- **Site thanoda terms-la automation-a thadukkudhu**, illa adha block panna captchas use pannudhu.
- **Thappugal selavaanadhu, kandupidikka kashtam**, tax filings maadhiri, oru aal ovvoru submission-aiyum check panna thavira.

## Demo-la irundhu production-ku

- **Ovvoru session-aiyum** allow list-oda, dedicated account-oda oru pudhu container-la **isolate pannunga**.
- Ovvoru run-oda **screenshots illa video-va record pannunga**, audits-ku thevaippadra varaikkum vechukkunga.
- Entha submit, pay, send, delete-ku munnaadiyum **approval kelunga**.
- **Ovvoru step-la success-aiyum hand-back rate-aiyum track pannunga**, adhigam fail aagura pages-a script pannunga.
- **Site changes-a monitor pannunga**: ovvoru portal-layum oru daily scripted check, users-ku munnaadi layout changes-a pidikkum.
