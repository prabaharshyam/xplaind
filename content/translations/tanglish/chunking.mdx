## Idhu enna

RAG-ku documents-a search panra munnaadi, avatrai **chunks**-a pirippaanga: embed panni, retrieve panni, prompt-la podura alavukku chinna passages. Retrieval enna kandupidikkalaam-nu chunking decide pannum. Oru chunk romba perusaa irundhaa, adhoda embedding pala topics-a kalakki blur aagum; romba chinnadhaa irundhaa, purinjukka thevaiyaana context poidum.

```flow
title: Fixed-size chunks, ovvoru 2,000 characters-ukkum: table nadula vettapattu, topics kalandhu
HR policy -> Chunk 1 | leave policy ... earned leave table, mudhal sila rows
HR policy -> Chunk 2 | table-oda meedhi ... notice period ... probation
```

```flow
title: Structure-aware chunks: headings, apram paragraphs, sumaar 400 tokens, overlap-oda
HR policy, headings-padi -> Leave > Earned leave | muzhu table
HR policy, headings-padi -> Leave > Sick leave
HR policy, headings-padi -> Exit > Notice period
HR policy, headings-padi -> Exit > Probation
```

Ovvoru structure-aware chunk-um oru topic, adhoda title path munnaadi irukkum.

Indha lesson, Pune-la oru manufacturing company-oda HR assistant-a follow pannum; adhu 120-page employee handbook-la irundhu kelvigalukku badhil solludhu.

## Idhu eppadi work aagudhu

**Size.** Chunk size tokens illa characters-la alappaanga. Prose-ku common starting points 300-la irundhu 800 tokens. Chinna chunks (100-la irundhu 300) FAQs maadhiri precise fact lookup-ku set aagum; perusa explanation thevaippadura kelvigalukku.

- *Romba perusaana chunks*: embedding pala ideas-oda average-aa aagum, adhanaala entha oru kelvikkum nallaa match aagaadhu; ovvoru retrieve aana chunk-um prompt-a relevant illaadha text-oda nirappi, tokens selavaagi, model-a distract pannum.
- *Romba chinna chunks*: "This limit is 45 days" maadhiri oru sentence entha limit-nu sollaama retrieve aagum; answers thappaavum vague-aavum aagum.

**Overlap.** Pakkathula irukkura chunks-ku idaila konjam text-a (ex: 10-la irundhu 20%) repeat pannaa, oru boundary-la pirinja sentence illa idea, onnula muzhusaa varum.

**Structure vechu piringa.** Ovvoru N characters-ukkum vetturadhaivida idhu nallaa irukkum:

- mudhalla headings, sections-la piringa, apram paragraphs, apram sentences (recursive splitting);
- tables, lists, code blocks-a muzhusaa vechukkunga;
- FAQs-ku, oru chunk-ku oru question-and-answer pair.

**Context serunga.** Ovvoru chunk-oda document title-aiyum section heading-aiyum store pannunga, embed panra text-oda munnaadi adikkadi serunga, appo "This limit is 45 days" "Leave Policy > Earned leave: This limit is 45 days"-aa aagum.

**Metadata.** Citations-kum filters-kum document id, page, section-a vechukkunga.

**Test pannunga.** Chunking oothi paakka vendiya onnu illa, evaluate panna vendiya choice. Real kelvigal set-la rendu moonu sizes-a try panni, sariyaana passages retrieve aagudhaa-nu measure pannunga.

**Document type-padi chunking:**

| Document type | Strategy | Typical size |
| --- | --- | --- |
| Policies, manuals | Headings-la piringa, apram paragraphs; section path-a munnaadi serunga | 300-la irundhu 600 tokens |
| FAQs | Oru chunk-ku oru question-and-answer pair | Ovvoru pair-ku thevaiyaana alavu |
| Tables, price lists | Ovvoru table-aiyum muzhusaa vechukkunga; heading serunga | Oru table |
| Contracts | Clause-padi piringa; clause numbers-a vechukkunga | Oru clause illa sub-clause |
| Chat transcripts, tickets | Oru ticket illa conversation, illa sila turns | 200-la irundhu 500 tokens |
| Code | Function illa class-padi | Oru function |

**Chunk metadata.** Ovvoru chunk-lum irukkanum: document id, title, section path, page, version illa date, edhavadhu access group. Indha metadata citations-a sambhavam aakkum ("Handbook, section 4.2, page 37"), filters-a allow pannum ("current version mattum", "indha user paakkalaam-nu irukkura documents mattum"), oru document maarum podhu ellathaiyum re-index pannaama adhoda chunks-a mattum marubadiyum build panna help pannum.

**Re-chunking normal thaan.** Oru test nalla strategy-a kaattuna, re-chunk panni re-embed pannunga. Chunking code-a versioned-aa vechukkunga, settings-a index-oda record pannunga, appo ippo irukkura results entha strategy-aala vandhadhu-nu eppavum theriyum.

**PDFs, scanned documents-a chunk panradhu.** Extract aana PDF text-la ovvoru page-layum page headers, footers, page numbers irukkum. Chunking-ku munnaadi, perumbaalaana pages-la repeat aagura lines-a neekkunga, illana ovvoru chunk-um adhoda embedding-um paazhaagum. Scans-ku, mudhalla OCR run pannunga, oru sample-a check pannunga, yen-naa headings-la OCR errors structure-aware splitting-a odaikkum. Ovvoru chunk-oda aarambathula irukkura page number-a vechukkunga, appo chunk page break-a dhaandinaalum citations sariyaana page-a kaattum.

**Code-la structure-aware splitter.** Idhu Markdown illa headings irukkura text-la work aagum, section path-a vechukkum, overlap-um serkkum. Simple-ku sizes words-la; exact limits-ku embedding model-oda tokenizer-ku maathunga:

```python
import re

def split_by_headings(text, max_words=350, overlap_words=50, title=""):
    chunks, path, buf = [], [], []

    def flush():
        words = " ".join(buf).split()
        start = 0
        while start < len(words):
            piece = words[start:start + max_words]
            header = " > ".join([title] + path)
            chunks.append({"section": header, "text": f"{header}: " + " ".join(piece)})
            if start + max_words >= len(words):
                break
            start += max_words - overlap_words
        buf.clear()

    for line in text.splitlines():
        m = re.match(r"^(#{1,4})\s+(.*)", line)
        if m:
            flush()
            level = len(m.group(1))
            path[:] = path[:level - 1] + [m.group(2).strip()]
        elif line.strip():
            buf.append(line.strip())
    flush()
    return chunks
```

Ovvoru chunk-um "Leave Policy > Earned leave: ..." maadhiri adhoda section path-oda aarambikkum, appo oru chinna sentence-um adhu enna pathi-nu solludhu.

**PDFs-la repeat aagura lines-a neekkunga.** Extract aana PDF text-a chunk panra munnaadi, perumbaalaana pages-la varra lines-a drop pannunga:

```python
from collections import Counter

def strip_repeats(pages, share=0.6):
    """pages: list of page texts."""
    counts = Counter(l.strip() for p in pages for l in set(p.splitlines()) if l.strip())
    repeated = {l for l, n in counts.items() if n >= share * len(pages)}
    return ["\n".join(l for l in p.splitlines() if l.strip() not in repeated) for p in pages]
```

**Small to big.** Precise retrieval-ku chinna chunks venum; nalla answers-ku context venum. Rendaiyum pannunga: chinna chunks-a (oru illa rendu paragraphs) index pannunga, ovvoru chunk entha section-la irundhu vandhadhu-nu store pannunga, oru chinna chunk match aanaa, model-ku muzhu parent section-a (illa chunk-um adhoda neighbours-um) kodunga. Idhu adikkadi entha oru chunk size-aiyum vida nallaa irukkum.

**Model ezhudhura context.** Headings valu illaadha documents-ku, oru sutthamaana model ovvoru chunk-ku adhu enga irukku-nu solra oru sentence ezhudhalaam ("2026 leave policy-la irundhu, earned leave-a carry forward panradhu pathina section"). Embed panra munnaadi adha munnaadi serunga. Ingestion neraththula ovvoru chunk-ku oru call, oru thadavai thaan selavu, vague chunks-ku retrieval-a help pannum. Muzhu document-a prompt caching panna, idhu romba sulabam, selavum kammi.

**Measure pannunga, apram choose pannunga.** Practice-la irukkura 20-question test-a vechukkunga, ovvoru strategy-ku, size-ku recall at 5-a oru chinna table-la record pannunga. Numbers-padi choose pannunga, table-a index settings-oda vechukkunga.

## Oru worked example

Pune-la oru manufacturing company-oda HR assistant, 120-page employee handbook-la irundhu kelvigalukku badhil solludhu.

Mudhal try: overlap illaama fixed 2,000-character chunks. 40 real employee kelvigal vechu test pannaa, top five results-la sariyaana passage 55%-la mattum irukku. Failures: leave section-oda table rendu chunks-a pirinjudhu; "notice period" pathina answers-la notice period, probation, resignation kalandha chunks retrieve aachu.

Rendaavadhu try: headings-la pirichu, apram paragraphs, sumaar 400 tokens varai, 60-token overlap-oda; tables muzhusaa; title, section path munnaadi serthu. Ippo top five-la sariyaana passage 85% kelvigalukku irukku.

Moonaavadhu try, 200-token chunks: 82%, answers-la neraya context miss aachu. Avanga 400-token version-a vechukkaraanga.

| Try | Strategy | Top 5-la sariyaana passage |
| --- | --- | --- |
| 1 | Fixed 2,000 characters, overlap illa | 55% |
| 2 | Headings, apram paragraphs, ~400 tokens, 60-token overlap, tables muzhusaa, title path munnaadi | 85% |
| 3 | Adhe, aana ~200 tokens | 82%, neraya answers-la context miss |

Oru periya gain leave table-a muzhusaa vechadhunaala vandhadhu: try 1-la 18 failures-la ettu leave entitlements pathina kelvigal.

**Employees enna gavanichaanga.** Maatrathukku apram, romba common pugaar, "it gives me half the answer", kittathatta maraindhuduchu. Leave pathina kelvigal, ella kelvigal-layum moonil onnu, ippo muzhu table-a retrieve pannudhu, adhanaala assistant "moonaavadhu varushathula evvalavu earned leaves kidaikkum?"-nu kelvikku mudhal rows-a mattum quote panraadhukku badhila sariyaa answer pannudhu.

## Podhuvaa panra thappugal

- **Fixed-size cuts tables-layum sentences-layum odaikkum.**
- **Overlap illaama irukkuradhu.** Boundaries-la pirinja ideas kaanaama poidum.
- **"Context-a vechukkanum"-nu perusaana chunks.** Retrieval mosamaagum, prompts selavaagum.
- **Headings, page numbers-a izhakkuradhu.**
- **Eppavum measure pannaadhadhu.** Real kelvigal-la sizes-a test pannunga.
- **Oru thadavai chunk pannittu marubadiyum test pannaama irukkuradhu.** Documents illa kelvigal maarinaa, test set vechu retrieval-a marubadiyum check pannunga.
- **Repeat aagura page headers, footers ovvoru chunk-layum irukkuradhu.**
- **Ella document type-kum oru chunk size choose panradhu.** Policies, FAQs, tables, tickets-ku vera vera strategies thevai.
- **Retrieval test-a marubadiyum run pannaama chunking-a maathuradhu.**

## Chunking romba mukkiyam illaadha idangal

- **Chinna documents**, one-page notices maadhiri, oru chunk-la muzhusaa porundhum.
- **Already structured items**, oru record-ku oru FAQ pair, oru product, oru ticket maadhiri.
- **Context-kulla porundhura chinna collections**, retrieval-a vittudalaam.

## Demo-la irundhu production-ku

- **Chunking code-aiyum settings-aiyum version pannunga**, index-oda record pannunga.
- **Maatram varum podhu oru document-a oru thadavai re-chunk pannunga**, chunk ids-la document ids vechu.
- **Retrieval test-a vechukkunga**, ovvoru chunking maatrathukkum marubadiyum run pannunga.
- **Ovvoru ingestion-kum apram oru chunks sample-a kannaala paarunga**: odanja tables-um thevai illaadha headers-um udane theriyum.
- **Document-ku chunk counts-aiyum sizes-aiyum track pannunga**, parsing failures-a pidikka, 200-page manual moonu chunks-a kuduththaa maadhiri.
