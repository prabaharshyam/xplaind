## Idhu enna

**Experiment tracking** ovvoru training run-aiyum thaanaagavae log pannum: code version (Git commit), data version, parameters, neramvaari metrics, plots maadhiri artefacts, train aana model. **Model registry** therndhedutha model versions-a adhoda metadata-oda, alias maadhiri oru label-oda ("production" maadhiri) store pannum, appo deployment eppavum theriyadha, approve aana model-a use pannum.

Tools-la MLflow (open source), Weights & Biases, cloud ML platforms-oda built-in tracking irukku. Recent MLflow versions idhukku nagarthalaam-aana aliases use pannum; adhoda pazhaya fixed stages (Staging, Production) deprecated.

```flow
Training run 412 | params: depth=6, lr=0.05, features v3; code git a1b2c3d; data claims-2026-09; PR AUC 0.46 -[best run, approved]-> Model registry: fraud-model v14
Model registry: fraud-model v14 -[alias "production"]-> Production loads "fraud-model@production"
Production loads "fraud-model@production" -[rollback: move the alias]-> fraud-model v13, the previous one
```

Indha lesson-la Hyderabad-la oru insurer-oda ML team-a follow pannuvom, avanga maadha maadham claim-fraud model-a retrain pannuraanga.

## Idhu eppadi work aagudhu

**Oru run-a define panra ellathayum log pannunga.** Parameters (learning rate, depth, use panna features), metrics (validation, test scores, segment-vaari), Git commit, dataset version illa hash, environment (library versions), outputs (model file, confusion matrix, feature importance plot).

**Runs-a compare pannunga.** Tracking UI runs-a adhoda parameters, metrics-oda list pannum, score-padi sort pannum, runs-kku idaiyila metrics-a plot pannum. Depth 6 depth 8-a vida nalladhu-nu, illa oru pudhu feature oru segment-ku mattum help pannuchunu paakkalaam.

**Reproduce pannunga.** Code, data, parameters record aagirundha, yaarum thirumba odi, ore model-a (seeds control panra randomness-kulla) kandupidikkalaam.

**Winner-a register pannunga.** Therndhedutha run-oda model-a registry-ku pudhu version-aa, notes-oda promote pannunga: enna maarichu, evaluation results, yaar approve pannaanga. Production file path-a illa, registry-la irundhu "production version"-a load pannum.

**Promotion rules.** Promote panradhukku munnaadi: model ippo irukkura production model-a othukkitta metrics-la, key segments-um serthu, vendraanum; recent data-la checks pass aaganum; owner approval irukkanum. Pazhaya version-a rollback-ku ready-aa vainga.

**Lineage.** Audits-kum debugging-kum, chain clear-aa irukkanum: production model version → training run → code commit → data version → evaluation results.

**Edhellaam log pannanum, yen:**

| Item | Example | Yen mukkiyam |
| --- | --- | --- |
| Parameters | `depth=6`, `learning_rate=0.05` | Runs-kku idaiyila difference-a explain pannum |
| Metrics | PR AUC 0.46 overall, region-vaari | Winner-a niyaayamaa select pannum |
| Code version | Git commit `a1b2c3d` | Training logic-a reproduce pannum |
| Data version | `claims-2026-09`, hash-oda | Inputs-a reproduce pannum |
| Environment | Library versions, Python version | "En machine-la work aagudhu" problem-a thavirkkum |
| Artefacts | Model file, plots, feature importance | Reviewers results-a inspect panna vidum |
| Seed | `random_state=42` | Randomness-a control pannum |

**Script-la serkkaradhu.** MLflow-la tracking konjam lines thaan: oru run aarambinga, compute panra bodhu parameters, metrics-a log pannunga, mudivula model-a log pannunga, commit-kum data version-kum tags set pannunga. Library run-a local folder-la illa team share panra tracking server-la record pannum. scikit-learn, XGBoost maadhiri libraries-ku autologging on pannunga, extra code illaama perumbaalaana parameters, metrics-a capture aagum, aprom data version-um segment metrics-um neengalae serkkanum, yenna adha entha tool-um guess panna mudiyaadhu.

**MLflow-oda oru training run-a track panradhu.**

```python
import hashlib, subprocess
import mlflow
import mlflow.sklearn
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.metrics import average_precision_score

def data_hash(path):
    return hashlib.sha256(open(path, "rb").read()).hexdigest()[:12]

mlflow.set_experiment("claims-fraud")
params = {"max_depth": 6, "learning_rate": 0.05, "max_iter": 400}

with mlflow.start_run() as run:
    mlflow.set_tags({"git_commit": subprocess.getoutput("git rev-parse --short HEAD"),
                     "data_version": "claims-2026-09", "data_hash": data_hash("data/train.parquet")})
    mlflow.log_params(params)
    model = HistGradientBoostingClassifier(**params, random_state=42).fit(X_train, y_train)
    scores = model.predict_proba(X_val)[:, 1]
    mlflow.log_metric("pr_auc", average_precision_score(y_val, scores))
    for region in ["north", "south", "east", "west"]:
        m = val_region == region
        mlflow.log_metric(f"pr_auc_{region}", average_precision_score(y_val[m], scores[m]))
```

**Alias-oda promotion.** Production eppavum `models:/claims-fraud@champion`-a load pannum; promote panradhu oru check-ku aprom alias-a nagarthum:

```python
from mlflow import MlflowClient

client = MlflowClient()

def promote_if_better(name, candidate_version, metric="pr_auc", segments=("north", "south", "east", "west")):
    def metrics_of(version):
        run_id = client.get_model_version(name, version).run_id
        return client.get_run(run_id).data.metrics
    try:
        champ = client.get_model_version_by_alias(name, "champion").version
    except Exception:
        champ = None
    new = metrics_of(candidate_version)
    if champ:
        old = metrics_of(champ)
        if new[metric] < old[metric]:
            return f"rejected: {metric} {new[metric]:.3f} < {old[metric]:.3f}"
        worse = [s for s in segments if new[f"{metric}_{s}"] < old[f"{metric}_{s}"] - 0.02]
        if worse:
            return f"rejected: worse on {worse}"
    client.set_registered_model_alias(name, "champion", candidate_version)
    return f"version {candidate_version} is now champion (was {champ})"

model = mlflow.pyfunc.load_model("models:/claims-fraud@champion")    # in the serving code
```

Rollback-na `set_registered_model_alias`-a pazhaya version-ku thirumba kodukkuradhu.

**LLM apps-kum ore idea.** Prompt illa retrieval maatrathai oru experiment-aa nadathunga: prompt version, model name, top-k, chunk size, category-vaari eval scores-a oru run-aa log pannunga. Appo "prompt-oda v13 Hindi questions-ku help pannucha?" nnu oru sorted table, ninaivu illa.

**Tracking server-a unmaiyaa vainga.** Database backend-um artefacts-ku cloud storage-um, company-oda sign-in-ku pinnaadi irukkura shared tracking server, oru laptop-la irukkura files-a vida nallaa. Adha backup pannunga; ovvoru model mudivoda varalaarum adhu thaan.

**Browser-la try pannunga.** Oru minimal experiment log: runs-a record panni, oru metric-padi best-a select pannunga. Ungaloda own runs-a serunga.

```python
runs = []
def log_run(params, metrics, commit):
    runs.append({"params": params, "metrics": metrics, "commit": commit})

log_run({"depth": 4, "lr": 0.1}, {"pr_auc": 0.41}, "a1b2c3d")
log_run({"depth": 6, "lr": 0.05}, {"pr_auc": 0.46}, "a1b2c3d")
log_run({"depth": 8, "lr": 0.05}, {"pr_auc": 0.44}, "f9e8d7c")

best = max(runs, key=lambda r: r["metrics"]["pr_auc"])
for r in sorted(runs, key=lambda r: -r["metrics"]["pr_auc"]):
    print(r["metrics"]["pr_auc"], r["params"], r["commit"])
print("best:", best["params"])
```

## Oru worked example

Hyderabad insurer-oda ML team maadha maadham claim-fraud model-a retrain pannudhu. Tracking-kku munnaadi, models `final_v3_really_final.pkl` maadhiri peyar irukkura files-aa irundhana, auditor kettappo production edha data version use pannudhu-nu yaarum sollamudiyala.

MLflow-oda:

- Ovvoru training run-um parameters, Git commit, data snapshot id, overall-um region-vaari-yum PR AUC, model-a log pannudhu.
- Oru comparison view "claim filed within 30 days of policy start" serthadhu PR AUC-a overall 0.41-la irundhu 0.46-ku konduvandhudhu, adhula adhigam rendu regions-la nu kaattudhu.
- Best run version 14-aa notes-oda, reviewer peyaroda register aagudhu; production registry-oda production alias-a load pannudhu.
- Oru promotion check script candidate-a ippo irukkura production version-oda kadandha maadha claims-la compare pannum, entha region-oda recall rendu points-ku mela kuranjaalum promotion-a block pannum.

Aaru maadham kazhichu auditor thirumba vandhaa, oru disputed claim-a flag panna model-oda muzhu lineage-a team nimidangalula kaattudhu.

| --- | --- | --- | --- | --- |
| 398 | Kadandha maadha production model | 0.41 | 0.33 | Baseline |
| 405 | Aazhamaana trees | 0.42 | 0.31 | Reject: weakest region kuranjudhu |
| 409 | Pudhu feature: claim within 30 days of start | 0.45 | 0.38 | Nambikkai tharudhu |

## Podhuvaa panra thappugal

- **Spreadsheets-la kaiyaala track panradhu.** Adhu incomplete, pazhasaagidum.
- **Data versions-a log pannaadhadhu.** Code-um parameters-um mattum oru model-a reproduce panna mudiyaadhu.
- **Production-la models-a file paths-la irundhu load panradhu.** Registry use pannunga, appo deploy aana version clear-aa irukkum.
- **Overall score-la mattum promote panradhu.** Segments-yum recent data-vaiyum check pannunga.
- **Rollback plan illa.** Pazhaya version-a ready-aa vainga.
- **Final run-a mattum log panradhu.** Fail aana experiments enna work aagaadhu-nu team-ku kathukkudukkum; vechukkunga.
- **Seed-a marakkradhu.** Adhu illaama, ore code-um data-vum rendu thadavai odinaa vera models kidaikkalaam.
- **Registry alias-ku badhila production file path-a load panradhu.**
- **Overall metrics mattum log aagudhu,** adhanaala promotion key segments-a check panna mudiyaadhu.
- **Oru laptop-la tracking,** adhanaala history adhoda poidum.

## Tracking lightaa irukkalaam-nu idangal

- **Oru quick experiment**: results ezhudhi vecha oru notebook podhum.
- **Prompt-mattum prototypes**: prompt versions-oda scores-oda oru spreadsheet nalla aarambam.
- **Oru thadavai train panni, adikkadi maatraadha model**: adhoda lineage-a oru thadavai, kavanamaa record pannunga.

## Demo-la irundhu production-ku

- **Ovvoru run-kum commit, data version, parameters, segment metrics-a log pannunga.**

- **Prompt, retrieval experiments-a** training runs maadhiri track pannunga.
- **Access control-oda, backup panna shared tracking server** odunga.

## Practice pannunga

MLflow-oda tracking guide-a padinga, Made With ML-oda experiment tracking, versioning lessons-aiyum padinga.

1. Oru training script-ku tracking serunga: parameters, metrics, Git commit, data hash, model.
2. Rendu settings-a maathi pathu experiments odunga, tracking UI-la compare pannunga.
3. Best model-a register pannunga, "current production" model-oda oru promotion check ezhudhunga, register aana model-a thaniyaa oru prediction script-la load pannunga.
4. Ungaloda register aana rendu versions-la promote_if_better-a odunga, apram alias-a rollback panni, serving code pazhaya version-a load pannudhunu confirm pannunga.

**Mudinjadhu-nu eppo sollalaam:** Oru prediction-a, andha model-a produce panna run, code commit, data version varaikkum trace panna mudiyum.
