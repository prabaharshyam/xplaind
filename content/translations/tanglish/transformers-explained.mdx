## Idhu enna

**Transformer** oru neural network architecture, 2017-la vandhadhu, **attention**-nu oru mechanism-a suththi build aanadhu. Idhu oru sequence-a (words, image patches, audio frames) process pannum, edhu mukkiyam-nu mudivu panna ovvoru position-um matha ovvoru position-aiyum paarkka vidum.

Moonu families idha use pannudhu:

- **Decoder-only** models oru token-a oru thadavai text generate pannum: innaiku irukkura chat, coding models.
- **Encoder-only** models text-a padichu representations produce pannum: search-ku neraya embedding models, classifiers. (Sila saamibathiya embedding models decoder-only models-la irundhu adapt pannapattadhu.)
- **Encoder-decoder** models oru sequence-a innoru sequence-ku map pannum: translation, summarisation.

Vision transformers images-a patches-aa udaichu, adha tokens maadhiri treat pannum.

| Token | The | bank | approved | the | loan | because | it | trusted | the | applicant |
|---|---|---|---|---|---|---|---|---|---|---|
| "it"-la irundhu attention | 0.02 | **0.61** | 0.05 | 0.01 | 0.18 | 0.02 | 0.04 | 0.03 | 0.01 | 0.03 |

"The bank approved the loan because it trusted the applicant"-la, "it" token oru query anuppi, ovvoru key-oda compare panni, perumbaalum adhoda artham-a "bank"-la irundhu edukkum.

## Idhu eppadi work aagudhu

**Tokens-um embeddings-um.** Text tokens-aa udaiyum; ovvoru token-um oru vector (embedding) aagum. Order model-ku theriya positional information serkkapadum.

**Attention.** Ovvoru token-kum, model moonu vectors compute pannum: oru query (naan enna thedureen?), oru key (ennakkulla enna irukku?), oru value (naan enna pass panren?). Query-a ovvoru key-oda compare panni attention weights edukkum, apram values-oda weighted mix-a edukkum. "The bank approved the loan because it trusted the applicant"-la, attention "it" "the bank"-la focus panna help pannum.

**Multi-head attention.** Neraya attention heads ore neraththula odum, ovvoru head-um veraveraya relationships-a (grammar, references, topics) kathukka freedom irukku.

**Layers.** Ovvoru transformer layer-layum attention, adhukku aprom oru chinna feed-forward network irukkum, shortcuts-um normalisation-um serndhu deep stacks-a train panna mudiyura maadhiri pannum. Periya models dozens of layers-a stack pannum.

**Generation.** Decoder-only model ovvoru possible adutha token-kum oru probability predict pannum, onna pick pannum (sampling), adha serkkum, thirumba seiyum. Training-la ovvoru position-um future tokens-a paarkkaama oru mask thadukkum.

**Cost.** Attention ovvoru token-aiyum matha ovvoru token-oda compare pannum, adhanaala sequence length-oda cost vegamaa valarum. Idhanaala thaan context windows-ku limits irukku, neenda prompts mella-aagi, selavu adhigam aagum. Engineering tricks (efficient attention kernels, keys-um values-um caching) cost-a kammi pannum.

**Pre-training-um adaptation-um.** Models periya data-la missing illa adutha tokens-a predict panna pre-train aagum, apram adapt aagum: chat models-ku instruction tuning-um preference training-um, specific tasks-ku fine-tuning, illa prompts-um retrieval-um vachu appadiye use panradhu.

**Idhu yen jeyichudhu.** Attention neenda dhooram irukkura relationships-a nallaa handle pannum, GPUs-la parallel-aa efficient-aa train aagum, adhanaala romba periya models-ku, datasets-ku scale panna mudinjudhu.

**Moonu families pakkathula pakkam:**

| Family | Enna padikkum | Enna produce pannum | Typical uses |
| --- | --- | --- | --- |
| Encoder-only | Muzhu input-aiyum oru thadavai | Ovvoru token-kum illa ovvoru text-kum oru vector | Classification, embeddings, search |
| Decoder-only | Idathula irundhu valathukku, munnaadi paarkkaadhu | Adutha token, thirumba thirumba | Chat, coding, drafting, reasoning |
| Encoder-decoder | Mudhalla muzhu input, apram generate | Oru pudhu sequence | Translation, summarisation |

**Attention simple arithmetic-la.** Oru token-ku, adhoda query-yum ovvoru token-oda key-yum dot product edunga. Periya dot products-na "relevant". Scores-a vector size-oda square root-aala pirichu stable range-la vechukkunga, apram softmax vachu, serndhu 1 aagura weights-aa maathunga. Ovvoru token-oda value-yum adhoda weight-aala perukki serunga. Vara vandhadhu andha token-ku oru pudhu vector, adhu attend panna tokens-oda information-a kalandhirukkum. Ovvoru head-um idha thanoda kathukkitta queries, keys, values-oda seiyum, results serkkapadum.

**Pre-training enna kathukkudhu.** Periya alavu text-la adutha illa missing token-a predict panni, model grammar, facts, styles, reasoning patterns-a kathukkum, yen-na ellaam prediction-ku help pannum. Apram instruction tuning-um preference training-um andha raw ability-a requests-a follow panra oru helpful assistant-aa mattum.

**NumPy-oda konja lines-la attention.** Oru head, oru causal mask, weights print panni, yaaru yaar-a attend pannuraanga-nu paarkkalaam:

```python
import numpy as np

def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, causal=True):
    d = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d)                       # how relevant each token is to each other
    if causal:
        scores = np.where(np.triu(np.ones_like(scores), k=1) == 1, -np.inf, scores)
    weights = softmax(scores)                           # each row sums to 1
    return weights @ V, weights

rng = np.random.default_rng(0)
tokens = ["Priya", "paid", "the", "bill", "she"]
x = rng.normal(size=(len(tokens), 16))                  # token embeddings plus position
Wq, Wk, Wv = (rng.normal(0, 0.3, (16, 8)) for _ in range(3))
out, w = attention(x @ Wq, x @ Wk, x @ Wv)
print(np.round(w, 2))                                   # upper triangle is 0: no peeking ahead
```

Trained model-la, "she"-oda row "Priya"-ku adhigam weight podum. Inga weights random, aana shapes-um mask-um nijamaana models ovvoru layer-layum ovvoru head-kum compute pannura adhe maadhiri thaan.

**Multi-head shapes.** 768 model width-um 12 heads-um irundha, ovvoru head-um 64 dimensions-la velai seiyum; adhoda outputs thirumba 768-ku serkkapattu, innoru matrix-aala mix aagum. Adhe idea PyTorch-la:

```python
import torch
mha = torch.nn.MultiheadAttention(embed_dim=768, num_heads=12, batch_first=True)
seq = torch.randn(2, 10, 768)                           # batch of 2, 10 tokens each
mask = torch.triu(torch.ones(10, 10, dtype=torch.bool), diagonal=1)
out, weights = mha(seq, seq, seq, attn_mask=mask)
print(out.shape, weights.shape)                         # (2, 10, 768) and (2, 10, 10)
```

**Parameters enga irukku.** Ovvoru layer-layum, attention-ku width × width size-la naalu matrices irukku (queries, keys, values, output); feed-forward block perumbaalum width-oda naalu madangu viriyum, thirumba varum, adhu innum rendu madangu weights:

```python
def layer_params(width, ff_mult=4):
    attn = 4 * width * width
    ff = 2 * width * (ff_mult * width)
    return attn + ff

w, layers, vocab = 4096, 32, 128_000
total = layers * layer_params(w) + vocab * w
print(f"about {total / 1e9:.1f} billion parameters")    # about 7 billion: the 7B to 8B range
```

Nijamaana models details-la maarum (grouped key-value heads, gated feed-forward layers), aana estimate sariyaana range-la vizhundhudhu.

**Neenda inputs yen adhigam selavu.** Attention ovvoru token-aiyum munnaadi irukkura ovvoru token-oda compare pannum, adhanaala velai length-oda square-oda valarum: 8,000 tokens-ku 1,000 tokens-a vida sumaar 64 madangu attention velai. Generation ovvoru munnaadiya token-oda keys-um values-um oru cache-la vechirukkum, adhanaala neenda contexts-ku neraya GPU memory thevai.

## Oru worked example

Chennai-la oru legal-tech startup Indian court judgments-a area of law (property, family, criminal, tax, labour) padi classify pannudhu, adhu mela semantic search-um venum-nu virumbudhu.

- **Classification**: 12,000 labelled judgment summaries-la oru chinna encoder-only transformer-a fine-tune pannuraanga. Idhu 91% accuracy adaiyudhu, keyword features-la gradient-boosted model 82% thaan, yen-na attention "the appellant's claim to ancestral property" maadhiri context-a pidikkudhu.
- **Search**: paragraphs-a embed panni onnu pola irukkura passages-a retrieve panna oru embedding model (encoder) use pannuraanga.
- **Summaries**: API vazhiyaa oru decoder-only language model use pannuraanga, prompt-la retrieved passages-oda.

Judgments encoder-oda 512-token limit-a vida neenda-aa irundha, muzhu text-a classify panna maattaanga, mudhal-um romba relevant-aana sections-aiyum classify pannuvaanga, idhu length-oda attention-oda cost-oda neradi vilaivu.

| Task | Model type | Result |
| --- | --- | --- |
| Area-of-law classification | Fine-tune panna chinna encoder | 91%, keyword features-oda 82%-a vida |
| Onnu pola irukkura passage search | Encoder embedding model | Judgments-la semantic matches |
| Summaries | API vazhiyaa decoder-only model | Retrieved passages-la irundhu cited summaries |
| Neenda judgments | 512-token limit-oda encoder | Romba relevant-aana sections-a classify pannunga |

## Podhuvaa panra thappugal

- **Ella transformers-aiyum chatbots-nu ninaikkradhu.** Encoders, decoders, encoder-decoders veraveraya velaigalukku set aagum.
- **Sequence limits-a ignore panradhu.** Neenda inputs truncate aagum illa selavu aagum.
- **Chinna encoder podhum-nu irukkum podhu periya model-a fine-tune panradhu.** Model size-a task-ku match pannunga.
- **Attention weights-a explanations-nu ninaikkradhu.** Adhu decisions-oda nambaga-maana explanations illa.
- **Tokenisation-a marakkradhu.** Indian languages-ku aduthadha ovvoru word-kum adhigam tokens aagum, adhu limits-aiyum cost-aiyum affect pannum.
- **Attention thaaniyaa "purinjukkum"-nu ninaikkradhu**: adhu weighted averaging; artham training-la irundhu varum.
- **Prompts-um context-um design panra podhu neenda inputs-oda quadratic cost-a ignore panradhu.**

## Transformer internals thevai illaadha neram

- **API vazhiyaa models use panradhu**: dhinasari velaila prompts, retrieval, evals thaan mukkiyam.
- **Tabular prediction**, angae boosted trees thaan perumbaalum nalla tool.
- **Simple text tasks**, keyword rule illa chinna classifier already nallaa handle pannum.

Models choose panra podhu, hardware size panra podhu, long-context behaviour debug panra podhu, illa fine-tune panra podhu internals theriyum-nu irundha payan tharum.

## Demo-la irundhu production varaikkum

- **Hardware choose panradhukku munnaadi architecture-la irundhu memory-yum cost-aiyum estimate pannunga** (layers, width, heads, context).
- **Prompts-aiyum contexts-aiyum thevaiyai vida neendaa vaikkaadheenga**, quadratic attention cost-a manasula vechu.
- **Model-oda sondha tokenizer-aiyum chat template-aiyum** document panna maadhiriye use pannunga.
- **Long-context accuracy-a ungaloda sondha documents-la benchmark pannunga**, advertise panna window-la mattum illa.
- **Ovvoru deployment-oda model architecture-yum version-aiyum record pannunga.**
