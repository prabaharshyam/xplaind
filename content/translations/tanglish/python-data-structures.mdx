## Idhu enna

Programs perumbaalum oru nerathula oru value-oda velai seiyaadhu. Oru naal-la neraya orders, oru class-la neraya students, oru kadaila neraya products. Python-oda rendu main collections neraya values-a vechukkum:

- **Lists** position vachu edukkura ordered sequences. "Ore vagai neraya vishayam, order-la" ngradhukku nalladhu: oru naal-oda orders, marks list.
- **Dictionaries** key, value lookups. "Indha key-ku value-va vegamaa kandupidi" ngradhukku nalladhu: roll number vachu marks, field peyar vachu oru customer-oda details.

Innum rendu adikkadi varum:

- **Tuples** maatha mudiyaadha, fixed sequences, latitude, longitude jodi maadhiri.
- **Sets** unique items-oda ordered illaadha collections, duplicates-a neekka handy.

| Type | Example | Value-a eppadi edukkalaam |
|---|---|---|
| list | `["Pune", "Kochi", "Jaipur"]` | Position vachu: `[0]`, `[1]`, `[2]` |
| dict | `{"K101": 78, "K102": 64}` | Key vachu: `["K101"]` |
| tuple | `(18.52, 73.86)` | Maaraadha oru fixed jodi |
| set | `{"a@x.in", "b@y.in"}` | Unique values, order illa |

Adhai ullukkulla vechaa perumbaalaana real data-va model panna mudiyum. Dictionaries-oda list oru table; ovvoru dictionary-um oru row. APIs-um AI models-um anuppura **JSON**-oda shape-um adhae thaan, adhanaala nested lists, dictionaries-la comfortable-aa irukkradhu oru core AI skill.

Indha lesson Kota-la oru coaching centre office, test results list-a parents-ku udane badhil solra maadhiri maathradha follow pannum. Mudiyum podhu oru task-ku sariyaana structure-a choose panni, nested data-va easy-aa padikka mudiyum.

## Idhu eppadi work aagudhu

### Lists

```python
nums = [3, 1, 2]
nums.append(5)            # [3, 1, 2, 5]
print(len(nums))          # 4
print(nums[0], nums[-1])  # 3 5   (first and last)
print(sorted(nums))       # [1, 2, 3, 5]
print(nums[1:3])          # [1, 2]  (a slice: from position 1 up to, not including, 3)
```

`for n in nums:` vachu loop pannunga. **List comprehension** vachu pudhu lists-a build pannunga, oru list uruvaakkura compact loop:

```python
doubled_big = [n * 2 for n in nums if n > 1]    # [6, 4, 10]
```

### Dictionaries

```python
marks = {"asha": 80, "ravi": 72}
marks["meena"] = 91              # add a new key
print(marks["asha"])             # 80
print(marks.get("john", 0))      # 0: a default instead of an error
for name, score in marks.items():
    print(name, score)
```

Square brackets vachu illaadha key-a thedinaa `KeyError` varum; `get` adhukku badhila oru default tharum. Dictionary search pannaama nerukku key-ku thaavarathaala, millions of entries irundhaalum key vachu thedradhu vegam.

### Sariyaanadha choose panradhu

| Ungalukku venum | Use pannunga | Example |
| --- | --- | --- |
| Order, illa position vachu edukkanum | List | Customers-oda queue |
| Identifier vachu thedanum | Dictionary | Product code vachu price |
| Unique items, "ithula irukkaa?" vegamaa | Set | Unique email addresses |
| Oru chinna fixed values group | Tuple | Oru kadai-oda coordinates |
| Records-oda table | Dictionaries-oda list | Inniku sales |
| Category vachu group panna values | Lists-oda dictionary | City vachu students |

### List-la thedradhu yen slow

```flow
dir: LR
title: 10,000 records-la roll "K9000"-a kandupidinga
In a list -> Check [0], [1], [2] ... one by one -> Up to 10,000 checks
In a dictionary keyed by roll -> Jump straight to "K9000" -> About 1 step
```

Ore vagai identifier-a neraya thadavai thedinaa, oru thadavai dictionary build panni thirumba use pannunga.

### Nesting

```python
cities = {
    "Pune":   [{"name": "Asha", "marks": 80}],
    "Nagpur": [{"name": "Ravi", "marks": 72}, {"name": "Meena", "marks": 91}],
}
print(cities["Nagpur"][1]["name"])     # Meena
```

Nested access-a idamirundhu valamaa padinga: "Nagpur" list, adhoda rendaavadhu item, andha item-oda "name".

### JSON-la irundhu Python-ku, thirumbavum

Oru API illa AI model JSON thirumba tharum podhu, Python-oda `json` module adha lists, dictionaries-aa maathum, thirumbavum maathum:

```python
import json
text = '{"city": "Pune", "pins": ["411001", "411002"]}'
data = json.loads(text)          # now a dictionary
print(data["pins"][0])           # 411001
print(json.dumps(data, indent=2))  # back to neatly formatted JSON text
```

JSON objects dictionaries-aagum, JSON arrays lists-aagum, `true`, `false` `True`, `False`-aagum, `null` `None`-aagum.

### Copy panradhu

`b = a` list-a **copy pannaadhu**. Rendu peyar-um ore list-a point pannum, adhanaala onna maathinaa innonnum maarum:

```python
a = [1, 2]
b = a
b.append(3)
print(a)          # [1, 2, 3]  surprise!
c = a.copy()      # a real copy
```

## Oru example

Kota-la oru coaching centre test results-a records list-aa vechirukku, ovvoru student-kum onnu:

```python
results = [
    {"roll": "K101", "name": "Asha",  "physics": 78, "chem": 85},
    {"roll": "K102", "name": "Ravi",  "physics": 64, "chem": 70},
    {"roll": "K103", "name": "Meena", "physics": 91, "chem": 88},
]

# 1. Look up by roll number quickly: build a dictionary once
by_roll = {r["roll"]: r for r in results}
print(by_roll["K102"]["name"])            # Ravi

# 2. Average per subject with a list comprehension
physics = [r["physics"] for r in results]
print(round(sum(physics) / len(physics), 1))   # 77.7

# 3. Group students by grade band
bands = {}
for r in results:
    total = r["physics"] + r["chem"]
    band = "A" if total >= 160 else "B"
    bands.setdefault(band, []).append(r["name"])
print(bands)                               # {'A': ['Asha', 'Meena'], 'B': ['Ravi']}
```

| Office-la irundhu kelvi | Badhil solra structure | Code |
| --- | --- | --- |
| "Roll K102 eppadi pannaan?" | Roll vachu dictionary | `by_roll["K102"]` |
| "Physics average enna?" | Physics marks list | `sum(physics) / len(physics)` |
| "Band A-la yaar?" | Lists-oda dictionary | `bands["A"]` |

`setdefault(band, [])` andha band-oda list-a tharum, mudhal thadavai kaali list-a uruvaakkum. Ovvoru thadavaiyum `if` ezhudha thevai illa.

Ippo office "roll K102 eppadi pannaan?"-nu parents phone pannum podhu, 600 students sheet-la scroll pannaama udane badhil solludhu.

## Podhuvaa panra thappugal

- **Oru id-ku thirumba thirumba list-a thedradhu.** Andha id-a key-aa vechu oru thadavai dictionary build pannunga.
- **Illaadha key-ku `KeyError`.** Key illaama pogalaam-na default-oda `get` use pannunga.
- **Index out of range.** Lists 0-la start aagum; kadaisi item `[-1]`.
- **Thaanaa share aagura lists.** `b = a` copy illa; `a.copy()` use pannunga.
- **Loop pannum podhe list-a maathradhu.** Pudhu list-a build pannunga, udhaaranathukku comprehension vachu.
- **Sets order-a vechukkum-nu nenaikkiradhu.** Order mukkiyam-na result-a sort pannunga: `sorted(set(items))`.
