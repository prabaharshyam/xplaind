## Idhu enna

**Document parsing** files-a RAG system use panna mudiyura text-aavum structure-aavum maathum: sariyaana reading order-la paragraphs, sections-a kaattura headings, rows-um columns-um odaiyaadha tables, citations-ku page numbers. Moonu approaches, adikkadi serthu use aagum:

- Digital PDFs, Office files-la irundhu **text extraction**: vegam, selavu kammi, aana layout theriyaadhu.
- Scans, photos-ku **OCR** (optical character recognition): text-oda images-a text-aa maathum.
- **Layout-aware parsing**: headings, columns, tables, figures, reading order-a kandupidikkura models, apram ovvoru paguthiyaiyum sariyaa extract pannum. Docling, Unstructured maadhiri open-source tools-um cloud document services-um idha seiyum. Vision-language models-um pages-a direct-aa padikkum.

```flow
Oru file -> Entha type? | digital PDF, scan, mixed, Word, slides, image
Entha type? -[digital]-> Text extraction illa layout-aware parser
Entha type? -[scan]-> Sariyaana languages-oda OCR, illa vision-language model
Text extraction illa layout-aware parser -> Layout | columns reading order-ku, headings section path-ku, tables headers-oda rows-ku
Sariyaana languages-oda OCR, illa vision-language model -> Layout
Layout -> Clean | repeat aagura headers, footers, page numbers, watermarks-a neekkunga
Clean -> Metadata-oda chunks | document, section path, page, OCR confidence
```

Indha lesson, Kochi-la oru insurance company-a follow pannum; avanga assistant sariyaana pages-a kandupidichaalum innum thappaa badhil sonnadhu.

## Idhu eppadi work aagudhu

**Mudhalla document type-a kandupidinga.** Digital PDF, scanned PDF, mixed, Word, slides, spreadsheet, image. Extract panna mudiyura characters romba kammiyaa irukkura page scan-aa irukkalaam.

**Reading order.** Simple extraction rendu-column pages-a line line-aa thaandi padikkum, columns kalandhidum. Layout analysis columns-a kandupidichu, ovvonnaiyum orutharu padikkum.

**Tables.** Flatten aana tables arthatha izhakkum: "Premium 12,450 Sum insured 5,00,000" rows-a thaandi kuzhappamaagum. Tables-a structured data-vaa extract pannunga, apram ovvonnaiyum headers-a values-oda serthu vekkura text-aa maathunga (Markdown illa oru row-ku oru line: "Plan Gold: premium ₹12,450, sum insured ₹5,00,000"). Muzhu table-a, illa headers-oda muzhu rows-a, oru chunk-la vechukkunga.

**Headings, sections.** Ovvoru chunk-oda heading text-aiyum section path-aiyum ("Part B > Exclusions > 4.2") vechukkunga. Retrieval, filters, citations-ku help pannum.

**OCR quality.** Image quality thaan accuracy-a decide pannum: resolution, skew, nizhal, stamps, kaiyezhuthu. Indian documents adikkadi English-oda Hindi, Tamil illa matha scripts-a kalakkum; avatrai support panra OCR-a use panni, languages-a set pannunga. Images-a pre-process pannunga (nerukkunga, contrast adhigam pannunga), OCR confidence scores-a vechukkunga, weak pages-a flag panna.

**Headers, footers, noise.** Repeat aagura page headers, footers, page numbers, watermarks chunks-a paazhaakkum. Perumbaalaana pages-la repeat aagura text-a kandupidichu neekkunga.

**Output-a check pannunga.** Pages-a sample eduthu originals-oda compare pannunga, especially tables-um scanned pages-um. Ovvoru document-kum track pannunga: pages, page-ku characters, kandupidicha tables, OCR confidence.

**Ovvoru approach-um enna handle pannum:**

| Problem | Text extraction | OCR | Layout-aware parsing |
| --- | --- | --- | --- |
| Digital text | Aama | Thevai illa | Aama |
| Scanned pages | Illa: text kaaliyaa | Aama | Aama, OCR-oda serndhu |
| Rendu columns | Adikkadi kalandhidum | Adikkadi kalandhidum | Sariyaana reading order |
| Tables | Flatten aagum | Flatten aagum | Rows, columns irukkum |
| Headings | Saadharana text-aa poidum | Poidum | Kandupidikkum |
| Vegam, selavu | Romba vegam, romba kammi | Konjam mella | Romba mella, romba accurate |

Oru practical pattern: mudhalla sulabamaana text extraction run pannunga, apram checks-la fail aana pages-a mattum, ex: kammi character counts, kandupidicha tables, layout-aware parsing illa OCR-kku anuppunga. Periya document sets-la idhu selavai kuraikkum.

**Pages-a sulabamaanadhula irundhu kashtamaanadhukku route pannunga.** Plain extraction try pannunga, weak pages-a mattum OCR-ku anuppunga:

```python
import fitz                                       # PyMuPDF
import pytesseract
from PIL import Image
import io

def page_text(page, min_chars=200, langs="eng+hin+tam"):
    text = page.get_text("text")
    if len(text.strip()) >= min_chars:
        return text, "digital", None
    pix = page.get_pixmap(dpi=300)
    img = Image.open(io.BytesIO(pix.tobytes("png")))
    data = pytesseract.image_to_data(img, lang=langs, output_type=pytesseract.Output.DICT)
    words = [(w, int(c)) for w, c in zip(data["text"], data["conf"]) if w.strip() and int(c) >= 0]
    conf = sum(c for _, c in words) / len(words) if words else 0
    return " ".join(w for w, _ in words), "ocr", conf

def parse_pdf(path):
    pages = []
    for i, page in enumerate(fitz.open(path), start=1):
        text, how, conf = page_text(page)
        pages.append({"page": i, "text": text, "method": how, "ocr_conf": conf,
                      "needs_review": how == "ocr" and conf < 70})
    return pages
```

Tesseract-ku Hindi, Tamil, matravai-kku adhoda language packs install aagi irukkanum. Kuraindha average confidence irukkura pages review list-ku, illa oru strong OCR service illa vision model-ku pogum.

**Tables row-wise text-aa.** `pdfplumber` digital PDFs-la tables-a kandupidikkum; ovvoru row-aiyum adhoda headers-oda ezhudhunga, appo chunking-a thaandi irukkum:

```python
import pdfplumber

def tables_as_text(path):
    out = []
    with pdfplumber.open(path) as pdf:
        for n, page in enumerate(pdf.pages, start=1):
            for table in page.extract_tables():
                header, *rows = table
                for row in rows:
                    cells = [f"{h}: {v}" for h, v in zip(header, row) if h and v]
                    if cells:
                        out.append({"page": n, "text": "; ".join(cells)})
    return out

# "Plan: Gold; Premium: ₹12,450; Sum insured: ₹5,00,000"
```

Ippo ovvoru row-um, oru retriever match panna mudiyura, oru model quote panna mudiyura, thaniyaa nirkura sentence.

**Kashtamaana pages-ku layout-aware tools.** Docling, Unstructured maadhiri open-source parsers-um cloud document services-um columns, headings, tables-a serndhu kandupidikkum. Avai mella, sila neram paid, adhanaala sulabamaana checks-la fail aana pages-ku vechukkunga.

**Vision models parsers-aa.** Kuzhappamaana scans, forms, merged cells irukkura tables-ku, page image-a vision model-ku anuppi Markdown output kekkuradhu adikkadi classic OCR-a vida nallaa irukkum. Numbers-a kavanamaa check pannunga: vision models sila neram digits-a thappaa padikkum, mudinja idathula totals-a compare pannunga.

**Ovvoru page-um eppadi padikkapattadhu-nu record pannunga.** Page-ku method, confidence, parser version-a store pannunga. Answers thappaa pogum podhu, source text eppavaavadhu sariyaa irundhucha-nu udane paakkalaam.

**Ungaloda browser-la try pannunga.** Perumbaalaana pages-la repeat aagura lines-a (headers, footers maadhiri) kandupidinga, appo chunking-ku munnaadi neekkalaam.

```python
from collections import Counter

pages = [
    "ACME Insurance - Confidential\nPolicy terms\nPage 1",
    "ACME Insurance - Confidential\nClaims process\nPage 2",
    "ACME Insurance - Confidential\nExclusions\nPage 3",
]
counts = Counter(line for p in pages for line in set(p.splitlines()))
repeated = {l for l, n in counts.items() if n >= 0.6 * len(pages)}
clean = ["\n".join(l for l in p.splitlines() if l not in repeated and not l.startswith("Page ")) for p in pages]
print("removed:", repeated)
print(clean)
```

## Podhuvaa panra thappugal

- **Ellaathukkum oru extractor.** Scans, digital PDFs, slides-ku vera vera handling thevai.
- **Tables-a flatten panradhu.** Headers-a values-oda, rows-a serthu vechukkunga.
- **Reading order-a ignore panradhu.** Policies, circulars, reports-la multi-column pages romba common.
- **English-only OCR.** Ungaloda documents use panra languages-a, Hindi, Tamil, Malayalam maadhiri, set pannunga, ovvonnulayum oru sample page check pannunga.
- **Output-a page-oda compare pannaadhadhu.** Edhaiyum index panra munnaadi sila parsed pages-a originals pakkathula print pannunga. Paththu nimisha spot checks perumbaalaana parsing bugs-a kandupidikkum.
- **Language packs illaadhadhu**, adhanaala Hindi, Tamil pages error illaama kuppai-aa varum.
- **Tables-a running text-aa flatten panradhu.** Ovvoru row-layum headers-a vechukkunga.
- **Entha pages OCR aachu-nu record pannaadhadhu**, adhanaala weak text-a trace panna mudiyaadhu.

## Simple extraction podhum-naa

- **Single columns-um konjam tables-um irukkura sutthamaana digital PDFs.**
- **Text sources**, HTML pages, Markdown, theliva headings irukkura Word files maadhiri.
- **Structured exports** (CSV, JSON, database dumps), adhukku parsing-ae thevai illa.

## Demo-la irundhu production-ku

- **Pages-a checks vechu route pannunga**: mudhalla sulabamaana extraction, weak pages-ku mattum OCR illa layout tools.
- **Page-ku method, confidence, parser version-a store pannunga.**
- **Vaaram oru thadavai parsed pages-a originals-oda sample paarunga**, especially tables-um scans-um.
- **Document-ku page-ku characters-aiyum kandupidicha tables-aiyum track pannunga**, parser failures-a pidikka.
- **Tools improve aanaa re-parse pannunga**, neenga vechirukkura raw copies-a use panni.
