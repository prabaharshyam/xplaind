## Idhu enna

Language models web-la irukkura text-la irundhu kathukkudhu, web-la perumbaalum English. Oru romba use aagura training dataset-la, text-la sumaar 46% English. Adhoda compare panna Indian languages romba chinnadhu:

| Language | Speakers (millions) | Dataset-la share | Under-represented, sumaar |
| --- | --- | --- | --- |
| Punjabi | 113 | 0.006% | 230 madangu |
| Kannada | 64 | 0.012% | 66 madangu |
| Telugu | 95 | 0.018% | 65 madangu |
| Gujarati | 62 | 0.013% | 62 madangu |
| Marathi | 99 | 0.021% | 58 madangu |
| Bengali | 272 | 0.093% | 37 madangu |
| English (compare panna) | 1,452 | 45.9% | over-represented |

Kadaisi column ovvoru language-oda ulaga makkal thogaila share-a, dataset-la adhoda share-oda compare pannudhu. Indha figures, Chip Huyen-oda *AI Engineering*-la sollapatta, Common Crawl web dataset-pathi 2023-la nadandha oru study-la irundhu. Evvalavu perumbaalaanavanga pesuraangalo adhoda compare panna training text kammiyaa irukkura indha maadhiri languages-a **low-resource languages**-nu solluvaanga.

Idhunaala moonu practical problems:

1. **Kammi quality.** General knowledge-oda oru prasidhdha test-la, oru leading model Telugu, Marathi, Punjabi-la romba mosamaa score pannudhu; test panna languages-la romba under-represented avai thaan.
2. **Adhigam cost-um delay-yum.** **Tokenizer** text-a tokens-aa pirikkum, neraya tokenizers perumbaalum English-kaaga design aanavai. Hindi illa Tamil-la adhae vaakkiyathukku avai pala madangu adhigam tokens edukkalaam. Idhaiyae adhigam **token fertility**-nu solluvaanga. Neenga per token pay panreenga, models oru nerathula oru token ezhudhum, adhanaala adhae answer adhigam cost aagum, mella varum.
3. **Real usage kuzhappamaa irukkum.** Indians languages-a kalakkuvaanga ("mera order kab aayega?"), scripts-a maathuvaanga, Indian languages-a Roman letters-la type panuvaanga. Clean, formal text-la mattum senja test sets idhellaam miss pannum.

Nilaimai nallaa aagikittu varudhu: pudhu tokenizers Indian scripts-a romba nallaa handle pannum, Indian groups Indian languages-ku models-um data-vum build panraanga. Aana innum, unga users-kaaga language language-aa alakkanum.

```flow

Score general models -> Good enough?
Good enough? -[yes]-> Ship with monitoring per language

Try translate to English and back -> Try an Indian-language model
Try an Indian-language model -> Pick the best on quality and cost
Pick the best on quality and cost -> Ship with monitoring per language
```

## Idhu eppadi work aagudhu

**Token fertility-a neengalae alakkunga.** Neenga consider panra ovvoru model-oda tokenizer-oda, English-layum unga users-oda languages-layum adhae message-ku tokens-a ennunga. Adhae artham-a ezhudhunga, word-for-word translation illa.

```python
# pip install tiktoken
import tiktoken

texts = {
    "English": "When will my order arrive? I paid yesterday.",
    "Hindi": "मेरा ऑर्डर कब आएगा? मैंने कल भुगतान किया था।",
    "Hinglish": "Mera order kab aayega? Maine kal payment kiya tha.",
    "Tamil": "என் ஆர்டர் எப்போது வரும்? நான் நேற்று பணம் செலுத்தினேன்.",
}
for name in ["cl100k_base", "o200k_base"]:          # an older and a newer tokenizer
    enc = tiktoken.get_encoding(name)
    counts = {lang: len(enc.encode(t)) for lang, t in texts.items()}
    base = counts["English"]
    print(name, {lang: f"{n} ({n / base:.1f}x)" for lang, n in counts.items()})
```

Odi paarunga, pudhu tokenizer Hindi, Tamil counts-a vegamaa kuraikkum, Romanised Hinglish English-kitta irukkum-nu usually paapeenga. Matha providers veru tokenizers use pannuvaanga, adhanaala neenga consider panra ovvonnaiyum check pannunga.

**Oru language-a serve panna moonu vazhi.**

- **Oru general model, nerae.** Romba simple. Sameeba kaalathu strong models Hindi-la nallaa irukkum, low-resource languages-la weak. Assume panradhukku munnaadi test pannunga.
- **Translate, badhil sollunga, thirumba translate pannunga.** AI4Bharat-oda open IndicTrans2 maadhiri strong Indian-language translation model-la kelvi-a English-ku translate panni, English-la badhil sollitu, thirumba translate pannunga. Weak languages-ku quality-a ezhuppalaam, aana steps-um delay-yum errors-um serkkum, nuance-um poidum: *aap*, *tum* maadhiri mariyaadhai markers "you"-nu aagidum, local terms-um thappaa translate aagalaam.
- **Indian languages-ku build panna model.** Indian startups-um research groups-um migavum adhigam Indian-language text-la models-aiyum tokenizers-aiyum train panraanga. Government-oda Bhashini platform translation, speech services tharudhu. Idhu Indian languages-ku strong-aavum sillaravaavum irukkalaam, aana edha model-a maadhiri, unga own test set-la compare pannunga.

**Speech-um mukkiyam.** Neraya users type panradha vida pesa virumbuvaanga, especially cities-ku veliya. Speech recognition quality language, accent, background noise-padi maarum, adhanaala unga users-oda real recordings-la test pannunga.

| Approach | Weak languages-la quality | Cost, speed | Mukkiya risk |
| --- | --- | --- | --- |
| General model, nerae | Maarum; language language-aa check pannunga | Tokenizers inefficient-aa irukkura idathula adhigam aagalaam | Sathama language, thappaana local terms |
| English-ku translate panni thirumba | Weak languages-ku perumbaalum better | Extra steps, delay | Nuance poidum, names thappaa translate aagum |
| Indian-language model | Indian languages-la perumbaalum strong | Perumbaalum efficient tokenizers | Kuraivaana general knowledge; check pannunga |
| Mela irukkura edhoda serthu local facts retrieve panradhu | Schemes, prices, names-la better | Chinna extra cost | Ovvoru language-layum sources-a current-aa vechukkanum |

**Unga browser-la try pannunga.** Adhae message Indian scripts-la adhigam bytes edukkum, tokens-um perumbaalum bytes-a pinthodarum. Ungalodha sentences-a try pannunga.

```python
samples = {
    "English": "Please send the electricity bill",
    "Hindi": "कृपया बिजली का बिल भेजें",
    "Tamil": "தயவுசெய்து மின்சார கட்டணத்தை அனுப்புங்கள்",
}
for lang, text in samples.items():
    chars, utf8 = len(text), len(text.encode("utf-8"))
    print(f"{lang:<8} {chars:>3} characters, {utf8:>3} UTF-8 bytes, {utf8 / chars:.1f} bytes per character")
```

## Oru worked example

Pune-la oru agritech company Marathi-yilum Hindi-yilum farmers-kaaga chat-layum voice-layum, maadhathukku sumaar 50,000 questions-oda oru helpline build panraanga. Neraya farmers Marathi-a Roman script-la type panraanga.

300 real kelvigal-oda oru test set build panraanga: Marathi, Hindi, Devanagari, Roman script, crops, weather, schemes pathi, native-speaking agronomists check pannadhu. Apram moonu options-a compare panraanga.

| Option | Correct, natural (Marathi) | Correct, natural (Hindi) | Oru answer-ku average tokens | 1,000 answers-ku cost |
| --- | --- | --- | --- | --- |
| General model, nerae | 68% | 82% | 410 | ₹310 |
| English-ku translate, badhil, thirumba translate | 76% | 81% | 190 (English) plus translation | ₹260 |
| Retrieval-oda Indian-language model | 84% | 86% | 230 | ₹150 |

Indha numbers oru udhaaranathukku, eppadi compare pannalaam-nu kaattura. Scheme names thaan ellaa options-layum periya errors-oda source, adhanaala team Marathi, Hindi-la official scheme pages-oda retrieval-aiyum exact names-oda glossary-yum serkkudhu. Language-vaaris quality-a thodarndhu monitor pannuraanga, yenna oru model update Hindi-a nallaa aakki, Marathi-a amaidhiyaa kedukkalaam.

## Podhuvaa panra thappugal

- **English-la mattum test panni**, apram aindhu languages-la launch panradhu.
- **Formal, Devanagari text-la mattum test panradhu.** Real users languages-a kalakkuvaanga, Roman script-la type panuvaanga.
- **Token counts-a ignore panradhu.** English-la sillaravaana oru feature Tamil-la pala madangu adhigam aagalaam.
- **Ellaathaiyum word for word translate panradhu.** Names, schemes, mariyaadhai vadivangal perumbaalum udaiyum.
- **"Indian languages"-a onnaa paarkkuradhu.** Hindi-la irukkura quality, Odia illa Assamese pathi konjam thaan solludhu.
- **Evaluation-la native speakers-a vittudradhu.** Nallaa theriyura text kooda thappaa illa iyarkaiyaa illaama irukkalaam.

## English podhumaana idangal

- **English-la velai seiyra professional users**, developers illa analysts maadhiri, adhaiyae virumbalaam.
- **Romba technical content**, English terms standard-aa irukkura idathula, local-language explanations-oda English-lae irukkalaam.
- **Mudhal prototypes** oru language-la aarambikkalaam, matha-vangalukku plan-um budget-um pannina podhum.

## Demo-la irundhu production-ku

- **Ovvoru metric-aiyum language-um script-um vaariyaa report pannunga**, overall mattum illa.
- **Alandha tokens per answer-a vechu, language-vaariyaa budget pannunga.**
- **Ovvoru language-layum product names, schemes, terms-oda glossaries vechukkunga**, avaiyai retrieve pannunga.
- **Users language-a choose pannattum**, avanga ezhudhina language-lae badhil sollunga.
- **Ovvoru model maatramum aana apram thirumba test pannunga**, yenna gains-um losses-um language-padi maarum.
