## Idhu enna

Unga program ellaathayum thaane therinjukka vendiyadhu illa. Oru **web API** innoru service kitta internet vazhiyaa data illa actions-a kekka vidum: innaiku weather, oru map route, oru payment-oda status, arasaanga open data, illannaa oru AI model-oda badhil. Ovvoru AI model provider-um ippadi thaan work panraanga, adhanaala Python-la irundhu oru API-a call panradhu thaan, apram language models-a call panradhukku adippadai skill.

Oru URL-ku **HTTP request** anuppureenga. Service idhoda reply pannum:

- oru **status code**: work aachaa?
- perumbaalum **JSON**-la oru body: adhu thaan data.

```flow
dir: LR
Unga Python program | requests.get(...) -[GET /weather?city=Chennai, header X-API-Key]-> Weather service
Weather service -[200 OK, JSON body]-> r.json() | city: "Chennai", temp_c: 31.5
```

Thanga ooruku oru chinna air-quality dashboard build panra Anita-va indha lesson follow pannum. Lesson mudiyum podhu oru public API-a call panni, status-a check panni, nested JSON-a paadhukaappaa padikka mudiyum.

## Idhu eppadi work aagudhu

### requests library

```python
import requests

r = requests.get("https://api.example.com/weather",
                 params={"city": "Chennai"}, timeout=10)
print(r.status_code)
data = r.json()          # JSON text becomes Python dictionaries and lists
print(data["temp_c"])
```

`params` URL-la query parameters-a serkkum, adhanaala indha request `.../weather?city=Chennai`-ku pogum.

### Status codes

| Code | Artham | Enna pannanum |
| --- | --- | --- |
| `200` | OK: work aachu | Data-a use pannunga |
| `400` | Bad request: unga request-la edhaavadhu thappu | Parameters, body-a check pannunga |
| `401` / `403` | Sign in aagala, illa anumadhi illa | API key, permissions-a check pannunga |
| `404` | Kidaikkala | URL illa item id-a check pannunga |
| `429` | Romba adhigamaana requests | Mella poonga; kaathirundhu retry pannunga |
| `500` mudhal `504` | Server fail aachu | Perumbaalum temporary; apram retry pannunga |

Data-a use panradhukku munnaadi check pannunga. `r.raise_for_status()` 4xx, 5xx codes-ku error raise pannum, adhanaala unga code oru error reply-a data maadhiri eduthukittu thodaraadhu.

### Python-la JSON

`r.json()` reply-a dictionaries (JSON objects-ku) lists (JSON arrays-ku) aa maathum. Nested values-a step by step padinga:

```python
data["current"]["temp_c"]          # an object inside an object
data["results"][0]["location"]     # the first item of a list
```

Adha padikkura code ezhudharadhukku munnaadi, oru thadavai muzhu reply-yum print panni adhoda unmaiyaana shape-a paarunga.

### Parameters, headers, bodies

| Part | Edhukku use aagum | Example |
| --- | --- | --- |
| `params` | URL-la query parameters | `params={"city": "Pune"}` |
| `headers` | Keys, content type, matha metadata | `headers={"Authorization": "Bearer ..."}` |
| `json` | Neenga anuppura JSON body, perumbaalum POST-oda | `requests.post(url, json={"text": "..."})` |

### Timeouts

`timeout=` illaama, mellaana illa udaincha server-ku poora request **eppovum** thongi, unga program-a illa muzhu automation-a freeze pannidalaam. Eppovum oru timeout set pannunga, `requests.Timeout`-a handle pannunga.

### Keys, secrets

API keys-a neenga share panra illa commit panra code-la ezhudhaatheenga. Environment variable-la irundhu padinga:

```python
import os
key = os.environ["AQ_KEY"]
```

### Paadhukaappaa retry panradhu

Sila failures thaanaave sariyaagum. Oru `429` illa `503` konja second kazhichu perumbaalum work aagum. Simple-aana, mariyaadhaiyaana retry ippadi irukkum:

```python
import time

for attempt in range(3):
    r = requests.get(url, params=params, timeout=10)
    if r.status_code not in (429, 500, 502, 503, 504):
        break
    retry_after = r.headers.get("Retry-After", "")
    wait = int(retry_after) if retry_after.isdigit() else 2 ** attempt
    time.sleep(wait)
```

Idhu temporary-aa irukka vaaippu irukkura errors-a mattum retry pannum, ovvoru thadavaiyum adhigam neram kaathirukkum, server `Retry-After` header anuppinaa adha madhikkum. `401` illa `404`-a eppovum retry pannaadheenga: request-e thappu, thirumba pannaa onnum maaraadhu.

### API documentation-a padikkiradhu

Ovvoru API-oda documentation-um ade kelvigalukku badhil solludhu, perumbaalum ade varisaila: **base URL**, eppadi **authenticate** panradhu (edhu header-la key povanum), **endpoints** (`/latest` illa `/holidays` maadhiri paths), ovvoru endpoint-oda **parameters**, oru **example response**, adhu use panra **error codes**, adhoda **rate limits**. Code ezhudharadhukku munnaadi indha sections-a padinga, example response-a oru file-la copy pannunga, appo ovvoru thadavaiyum API-a call pannaama unga parsing-a test pannalaam. Pinnaadi oru AI model-oda API-a call panradhum idhe process thaan: endpoint-a kandupidinga, header-la key-a anuppunga, JSON body post pannunga, JSON reply-a padinga.

### Limits, cost

Perumbaalaana APIs oru nimishathukku requests-a limit pannum, sila oru call-ku kaasu vaangum. Documentation-oda limits section-a padinga, `429` vandhaa server-a adichchu odaikkaama, adhigamaagura delays-oda kaathirundhu retry pannunga.

## Oru worked example

Anita thanga ooruku air quality-oda oru chinna dashboard build panraanga. Oru location-ku ippo irukkura readings-a tharra oru public API use panraanga.

```python
import os, requests

url = "https://api.airquality.example/v1/latest"
r = requests.get(url, params={"city": "Delhi"},
                 headers={"X-API-Key": os.environ["AQ_KEY"]}, timeout=10)

if r.status_code == 200:
    for reading in r.json()["results"][:5]:
        print(reading["location"], reading["parameter"], reading.get("value", "no reading"))
elif r.status_code == 429:
    print("Rate limited; try again in a minute")
else:
    print("Request failed:", r.status_code, r.text[:200])
```

(Inga irukkura URL udhaaranathukku mattum; indha lesson-oda resource-la unmaiyaana, work aagura examples irukku.)

| Run | Enna nadandhadhu | Kaaranam | Fix |
| --- | --- | --- | --- |
| 1 | `401 Unauthorized` | Pudhu terminal-la avanga key set aagala | Run panradhukku munnaadi `export AQ_KEY=...` |
| 2 | `200`, apram oru location-ku `KeyError: 'value'` | Sila locations-ku `value` field illa | Muzhu JSON-a print pannaanga; `.get("value", "no reading")` use pannaanga |
| 3 | Nimishakkanakkaa thonginadhu | Test panna podhu `timeout=` a eduthuttaanga | `timeout=10`-a thirumba vachchaanga |
| 4 | Anju readings print aachu | Work aagudhu | Dashboard-ku ready |

Rendaavadhu run-la muzhu JSON-a oru thadavai print pannadhu, avangalukku oru mani neram guess panradhula irundhu kaapaathichu.

## Podhuvaa panra thappugal

- **Status code-a check pannaadhadhu.** Appuram error replies-la code kuzhappamaa fail aagum.
- **Timeout illaama irukkiradhu.** Mellaana server unga program-a thonga vechchidum.
- **JSON shape-a guess panradhu.** Print panni mudhalla padinga.
- **Code-la API keys.** Environment variables use pannunga.
- **Rate limits-a ignore panradhu.** Madhinga, illannaa block aaiduveenga.
- **Ovvoru field-um eppovum irukkum-nu nenaikkiradhu.** Optional fields-ku default-oda `.get()` use pannunga.
