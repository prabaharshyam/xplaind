## Idhu enna

Daily code-la mukkiyamaana velaiya moonu structures thaan pannum.

**Array** items-a order-la, memory-la pakkathula pakkathula vechchirukkum. Python-la `list` thaan array. Items pakkathula irukkradhaala, item 5-a padikkiradhum item 5 lakh-a padikkiradhum ore time thaan. Kadaisila add panradhu cheap; munnaadi insert panna, ellathayum nagarthanum.

**String** na characters-oda array. Python, Java-la string-a oru thadavai uruvaakkittaa maathha mudiyaadhu; adhanaala ovvoru edit-um pudhu string-a uruvaakkum.

**Hash map** key-um value-um serntha pairs-a store pannum, evvalavu pairs irundhaalum key vachchu value-a ore maadhiri time-la kandupidikkum. Python-oda `dict`, `set` rendumae hash maps. Counting, duplicates-a edukkradhu, matching panradhukku idhu thaan main tool.

| | Array (list) | Hash map (dict) |
|---|---|---|
| Eppadi store pannum | Values numbered slots-la: 0 Pune, 1 Goa, 2 Agra, 3 Pune | Key `hash()`-ku poi oru slot-ku varum: "Pune" slot 7-ku, value 1,240 orders |
| Read | Position vachchu: O(1) | Key vachchu: average-aa O(1) |
| Value vachchu search | O(n): ovvoru slot-ayum check pannanum | Thevai illa: key-a lookup pannunga |
| Order | Position padi irukkum | Position padi order illa |

## Idhu eppadi work aagudhu

**Arrays** items-a oru memory block-la store pannum. Item i enga irukku-nu computer simple arithmetic-la kandupidikkum; adhanaala position vachchu read panradhu O(1). Aana oru value-a search panna, array sort aagi irundha thavira, items-a onnu onnaa paakkanum, O(n).

Python lists thaane valarum. Block niraindha, Python periya block-a allocate panni ellathayum copy pannum. Andha copy O(n), aana adhu romba arithaa nadakkradhaala, append average-aa O(1)-aave irukku.

**Hash maps** oru **hash function** use pannum; adhu "Pune" maadhiri key-a oru number-aa maathum. Andha number internal array-la oru slot-a pick pannum, value andha slot-la store aagum. Thirumba padikka, map key-a marubadiyum hash panni slot-ku direct-aa pogum. Sila neram rendu keys ore slot-la vizhum, adhu **collision**; map rendayum store panni, keys-a compare panni sariyaanadha edukkum. Nalla hash function-um podhumaana slots-um irundha, lookup, insert, delete ellaam average-aa O(1).

Trade-off memory-um order-um thaan. Hash map list-a vida adhigam memory edukkum, position vachchu padikka adhu sari illa.

| Operation | List (array) | Dict / set (hash map) |
|---|---|---|
| Position vachchu read | O(1) | support illa |
| Value illa key-a kandupidikka | O(n) | average-aa O(1) |
| Kadaisila add / key insert | average-aa O(1) | average-aa O(1) |
| Munnaadi insert illa delete | O(n) | average-aa O(1) |
| Insertion order-a vechchirukkum | aama | Python 3.7+-la aama |

Arrays pathi vara interview problems perumbaalum konjam patterns-la onna use pannum: **frequency count** (items-a dict-la count panradhu), **seen set** (paartha items-a nenaivula vechchu repeats-a kandupidikkradhu), **complement lookup** ("target minus idhu" irukkaa-nu udane check panna values-a store panradhu), **grouping** (sorted letters maadhiri calculate panna key-a items list-ku map panradhu).

## Oru worked example

Rahul interview-ku prepare panraan, Jaipur-la oru chinna bakery-oda order data-la practice panraan. Oru naal-oda order amounts list avan kitta irukku; rendu orders serndhu exact-aa ₹1,000 aagudha-nu paakkanum, yenna bakery-la andha price-ku oru combo irukku.

Munnaadi theriyara answer ovvoru pair-ayum try pannum:

```python
def pair_for(amounts, target):
    for i in range(len(amounts)):
        for j in range(i + 1, len(amounts)):
            if amounts[i] + amounts[j] == target:
                return i, j
    return None
```

Idhu O(n²). 20 orders-ku paravaayilla, 2 lakh-ku slow.

Hash map version oru thadavai thaan scan pannum. Ovvoru amount-kum: ₹1,000-a mudikkura amount-a already paathirukkomaa-nu kekkum.

```python
def pair_for(amounts, target):
    seen = {}                     # amount -> position
    for i, a in enumerate(amounts):
        need = target - a
        if need in seen:          # O(1) on average
            return seen[need], i
        seen[a] = i
    return None
```

`[250, 400, 600, 120]` amounts, target 1,000: 250-la adhukku 750 thevai (paakkala); 400-la 600 thevai (paakkala); 600-la 400 thevai, adha position 1-la paathirukku, adhanaala `(1, 2)` return pannum. Oru pass, O(n) time, O(n) space.

Adutha, romba popular item-a count panraan. Sort panradhukku badhila, frequency count use panraan:

```python
from collections import Counter
items = ["bun", "cake", "bun", "puff", "bun", "cake"]
Counter(items).most_common(1)   # [('bun', 3)]
```

`Counter` ulla oru dict thaan: oru pass, O(n).

## Podhuvaa panra thappugal

**Loop-kulla list-la membership check panradhu.** `if x in some_list` ovvoru thadavaiyum O(n). n items-oda loop-kulla pota O(n²). Mundhi set-a maathunga.

**Loop-la += vachchu strings build panradhu.** Ovvoru `+=` um muzhu string-a copy pannum. Pieces-a oru list-la serthu, oru thadavai `"".join(pieces)` pannunga.

**Hashable illaadha keys use panradhu.** Python-la lists dict keys aaga mudiyaadhu, yenna adhu maaralaam. Tuple use pannunga, illa oru word-oda sorted letters maadhiri string use pannunga.

**Keys-a normalise pannaama vittudradhu.** "+91 98450 12345", "9845012345" rendum ore customer, aana vera vera keys. Count panradhukku, match panradhukku munnaadi keys-a clean pannunga.

**Dicts eppavum O(1)-nu nenaikkiradhu.** Average-aa thaan O(1). Romba mosamaana hashing irundhaalum, illa attacker keys-a choose pannaalum, slow aagalaam. Interview-la "average-aa O(1)"-nu sollunga.

**Oru list-a loop pannum podhae adha maathradhu.** Iterate panna panna items-a remove pannina sila skip aagidum. Pudhu list build pannunga.
