## Idhu enna

**Workplace AI policy** velaila AI tools-a eppadi use pannalaam-nu employees-ku solludhu. AI assistants use panna easy, thappaa use panna kooda easy; customers-oda phone numbers irukkura oru spreadsheet-a paste pannina, law-a, client contract-a, company-oda nambikkaiya ore nodiyila odaichidum.

Nalla policies short-aa, practical-aa irukkum. Perumbaalum yezhu vishayam cover aagum:

| Section | Enna solludhu | Example rule |
| --- | --- | --- |
| **Approved tools** | Edhellaam assistants, features allowed | "Company-licensed assistant use pannunga; velaikku personal accounts allowed illa" |
| **Data rules** | Edhellaam AI tools-la poda mudiyum, edhellaam mudiyaadhu | "CRM-oda built-in AI-ku veliya customer personal data vendaam" |
| **Use cases** | AI-a edhukku encourage panraanga, edhukku restrict panraanga | "Drafting, summarising-ku encourage; final hiring decisions-ku illa" |
| **Review and accuracy** | AI output-a yaar check pannuvaanga, yaar responsible | "Ovvoru figure-um neenga check pannanum; neenga anuppurathukku neenga thaan owner" |
| **Disclosure** | AI use panninga-nu eppo sollanum | "Report perumbaalum AI-a vechu draft panna, clients-kitta sollunga" |
| **Intellectual property** | AI-assisted velai yaarukku sondham, copy panradha eppadi thavirkkalaam | "Matravanga copyrighted velaiya paste panni rewrite pannaadheenga" |
| **Reporting** | Thappu illa problem-a eppadi report panradhu | "24 manineratthukkulla AI committee-ku email pannunga" |

Indha lesson Karthik-a follow pannum. Avar Chennai-la oru manufacturer-la sales-la velai paakuraar, company rules-kulla irundhu AI vachu oru proposal ready panraar. Mudiyum podhu, nalla policy enna cover pannum, data-va eppadi sort pannalaam, company-ku policy-ae illa-na enna pannanum-nu theriyum.

## Idhu eppadi work aagudhu

### Companies yen care panraanga

Consumer AI tool-la neenga type pannina text store aagalaam; settings, terms-a poruthu service-a improve panna use aagalaam. Idhula moonu risks irukku:

1. **Legal.** Approved illaadha tool-la customer personal data-va potta, India-oda DPDP Act-a meeralaam. Adhu personal data-va eppadi use panni share pannalaam-nu limit pannudhu.
2. **Contractual.** Client contracts-la avanga info-va third parties-kitta share panna koodaadhu-nu perumbaalum irukkum.
3. **Confidentiality.** Strategy, release aagaadha financial results, source code leak aagalaam.

Company-licensed enterprise versions-la perumbaalum commitments irukkum: unga data training-ku use aagaadhu, theriyura oru idathula store aagum, access control-la irukkum.

```flow
A work task with company data -> Which tool?
Which tool? -[personal free account]-> Stop | data may train models, no admin control
Which tool? -[company-licensed tool]-> Go ahead | approved work, data not used for training
```

| | Personal free account | Company-licensed tool |
|---|---|---|
| Terms | Neenga click panni accept pannadhu | Company sign panna contract |
| Unga data | Models train panna help pannalaam | Training-ku use aagaadhu |
| Control | Admin control illa | Admin controls, audit logs irukku |
| Edhaavadhu leak aanaa | Company-ala help panna mudiyaadhu | Data enga pogudhu-nu security team-ku theriyum |
| Edhukku use panradhu | Work data-ku illa | Approved velaikku |

### Unga data-va naalu categories-a pirichukkonga

Edhu enga pogalaam-nu decide panna simple vazhi:

| Category | Examples | Rule of thumb |
| --- | --- | --- |
| **Public** | Publish panna brochures, company website, public reports | Perumbaalum edha tool-layum paravaayilla |
| **Internal** | Dhinamum use panra internal documents, process notes, templates | Approved tools mattum |
| **Confidential** | Client contracts, release aagaadha results, strategy, pricing | Approved tools mattum, sila neram ange kooda vendaam |
| **Personal and sensitive** | Contact details-oda customer illa employee peyar, health, salaries, Aadhaar illa PAN numbers, bank details | Romba strict rules; perumbaalum specific approved systems-la mattum |

Sandegam irundha, document-a oru category strict-aa eduthukkonga.

### Thevaiyillaadhadha eduthudunga

Pala neram sensitive part illaamalae velaiya mudikkalaam. Peyargalai "Customer A"-nu maathunga, phone numbers, account numbers-a eduthudunga, financial figures-a round pannunga, thevaiyaana structure mattum vechukonga. Assistant "Coimbatore-la oru mid-size client"-pathi, unmaiyaana company peyar pathi ezhudhura maadhiri thaan nalla ezhudhum.

### Accountability

Unga velaila unga peyar irukku. Client report-la thappaana figure irundha, "AI ezhudhuchu" excuse illa. Policies-la idhu perumbaalum clear-aa irukkum, managers-um clients-um appadiyae nenaipaanga.

### Policy illa-na

Neraya chinna companies-ku innum AI policy illa. Adhukku rules illa-nu artham illa: laws-um contracts-um apply aagum. Policy varra varaikkum:

1. Edhu allowed-nu manager-a illa IT team-a kelunga.
2. Public material illa unga non-confidential notes mattum use pannunga.
3. Peyargal, numbers, identifiers-a eduthudunga.
4. Personal data-va eppavum paste pannaadheenga.
5. Use panradhukku munnaadi ellathayum check pannunga.
6. AI-a eppadi use panringa-nu manager-kitta sollunga.

## Oru worked example

Karthik Chennai-la oru mid-sized machine-tools manufacturer-la sales-la velai paakuraar. Oru periya automotive client-ku proposal ready panna AI assistant use panna virumburaar.

Avar company-oda oru-page policy ippadi solludhu:

- Company-licensed assistant internal, confidential info-ku approved. Velaikku personal free accounts allowed illa.
- Names, phone numbers maadhiri customer personal data-va CRM-oda built-in AI features-la thavira vera enga-um poda koodaadhu.
- Anuppurathukku munnaadi finance team pricing-a check pannanum.
- AI-assisted client documents-a account manager review pannanum.

Karthik pannadhu ippadi:

| Step | Avar enna pannaar | Edhu rule-a follow pannaar |
| --- | --- | --- |
| Material serthaar | Client publish panna requirements-um company-oda standard proposal sections-um | Internal, public data mattum |
| Notes-a clean pannaar | Paste panradhukku munnaadi client contact-oda peyar, phone number-a eduthaar | CRM-ku veliya personal data illa |
| Draft | Licensed assistant-a vachu proposal-um pricing table-um draft pannaar | Approved tool |
| Pricing check | Table-a finance-ku anuppinaar, avanga thappaana base price-la kanakku pannina discount-a sari pannaanga | Pricing-a finance review pannum |
| Review | Final proposal-a avar manager review pannaar | Account manager review |

Antha thappaana discount company-ku sumaar ₹4 lakh nashtam aakkiyirukkum. Adha pidichadhu AI illa, review step thaan.

Oru colleague "vegamaa irukkum"-nu free personal account use panna solraar. Karthik policy-a explain panni, licensed tool-a eppadi open panradhu-nu kaattaraar. Colleagues onnaiyonnu nyaabagapaduthinaa thaan policies work aagum.

## Podhuvaa panra thappugal

- **Work data-kku personal accounts use panradhu.** Paravaayilla-nu thonninaalum, data company control-ku veliya pogudhu.
- **General assistants-la customer personal data-va paste panradhu.** Specific approved system use pannunga, illa personal details-a eduthudunga.
- **"Policy illa"-na "rules illa"-nu nenaikkiradhu.** Data protection law, contracts, confidentiality ellaam apply aagum.
- **AI use-a manager-kitta maraikkiradhu.** Edhaavadhu thappaa ponaa transparency ungalai kaapaathum.
- **AI "perumbaalum sari"-nu review-a skip panradhu.** Pricing, contracts, customer data-ku perumbaalum sari pothaadhu.
- **Policy-a oru thadava padichittu vittudradhu.** Tools maaruvadhoda policies-um maarum; updates irukka-nu paarunga.

## Practice pannunga

AI Fluency course-la responsible use section-a paarunga, keezha link irukku; PRS-oda India DPDP law summary-yum padinga.

1. **Unga policy-a kandupidinga.** Unga organisation illa college-oda AI policy-a kandupidinga. Illa-na, manager-kitta kekka aindhu kelvigal ezhudhunga.
2. **Pathu documents-a classify pannunga.** Adikkadi use panra pathu documents-a list panni, ovvonnayum public, internal, confidential, personal-nu classify pannunga. Ovvonnukkum edhu tools use pannalaam-nu note pannunga.
3. **Clean panni velaiya mudinga.** Oru real task eduthu, personal, confidential details ellathayum eduthuttu, approved tool-la mudinga.

**Mudinjadhu-nu eppo sollalaam:** Unga workplace-la AI-ku edhellaam tools, edhellaam data allowed-nu, sandegam irundha enna pannanum-nu oru colleague-kitta explain panna mudiyum.
