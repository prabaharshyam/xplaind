## Idhu enna

Oru **workplace AI policy**, velaiyila AI tools-a employees eppadi use pannalaam-nu solludhu. AI assistants-a use panradhum easy, misuse panradhum easy; adhanaala thaan idhu irukku: customer phone numbers irukkura ore oru spreadsheet-a paste pannaale oru client contract-aiyum, unga company-oda confidentiality duties-aiyum meeralaam; India-voda data law muzhusaa amalukku vara vara, law-vaiyum meeralaam.

Nalla policies chinnadhaa, practical-aa irukkum. Avai podhuvaa ezhu vishayangalai cover pannum:

| Section | Enna solludhu | Example rule |
| --- | --- | --- |
| **Approved tools** | Endha assistants, features, extensions, notetakers allowed | "Company-licensed assistant-a use pannunga; velaikku personal accounts allowed illai" |
| **Data rules** | Ovvoru tool-layum edha podalaam, edha podakkoodaadhu | "CRM-oda built-in AI-kku veliya customer personal data koodaadhu" |
| **Use cases** | AI enga encourage pannappadudhu, enga restrict pannappadudhu | "Drafting, summarising-kku encourage panrom; hiring decisions-kku koodaadhu" |
| **Review, accuracy** | AI output-a yaar check panraanga, yaar poruppu | "Ovvoru figure-aiyum neenga check panreenga; neenga anuppuradhukku neenga thaan owner" |
| **Disclosure** | AI use aachu-nnu eppo makkalukku sollanum | "Oru report perumalavu AI-drafted-aa irundhaa clients-kitta sollunga" |
| **Intellectual property** | AI udhaviyoda panna velaikku yaar owner, copy panradha thavirkkiradhu | "Mathavangaloda copyrighted velaiya rewrite panna paste pannaadheenga" |
| **Reporting** | Oru thappaiyo problem-aiyo eppadi report panradhu, evvalavu vegamaa | "1 mani nerathukkulla IT security-kitta sollunga; nermaiyaana reports-kku thandanai illai" |

Oru employee-aa, policy-a neenga manappaadam panna vendiyadhilla. Ovvoru task-kkum munnaadi moonu kelvigalukku badhil sollanum, ovvoru badhilum policy-la enga irukku-nnu therinjirukkanum.

```flow
title: Oru velai task-la AI use panradhukku munnaadi moonu kelvigal
Oru velai task -> Indha tool-um indha feature-um approved-aa?
Indha tool-um indha feature-um approved-aa? -[illai]-> Niruthittu IT-kitta kelunga | illa public material mattum use pannunga
Indha tool-um indha feature-um approved-aa? -[aamaa]-> Indha data-va idhula podalaamaa?
Indha data-va idhula podalaamaa? -[illai]-> Adha eduthudunga, illa sollappatta system-a use pannunga
Indha data-va idhula podalaamaa? -[aamaa]-> Output-kku review illa disclosure venumaa?
Adha eduthudunga, illa sollappatta system-a use pannunga -> Output-kku review illa disclosure venumaa?
Output-kku review illa disclosure venumaa? -> Check panni, review vaangi, appuram anuppunga
```

Indha lesson-la, Chennai-la oru manufacturer-kitta sales-la velai panra Karthik, avaroda company rules-kkulla oru proposal thayaar panradha follow panrom. Mudivula, oru nalla policy edha cover pannum, unga data-va eppadi sort panradhu, dhinamum use panra tools-la built-in-aa irukkura AI-a eppadi handle panradhu, oru thappukku appuram enna panradhu, unga company-la policy-ye illainnaa enna panradhu-nnu therinjuppeenga.

## Idhu eppadi work aagudhu

### Companies yen kavalaippaduraanga

Oru consumer AI tool-la neenga type pannumbodhu, andha text store aagalaam, settings-aiyum vendor-oda terms-aiyum poruthu service-a improve panna use aagalaam. Adhu moonu vagaiyaana risk-a uruvaakkudhu:

1. **Legal.** India-voda Digital Personal Data Protection Act, 2023 (DPDP Act), personal data eppadi use aagudhu, share aagudhu-nnu limit pannudhu. Adhoda Rules November 2025-la notify aachu, businesses-kkaana perumbaalaana duties May 2027-la irundhu apply aagum. Adhuvaraikkum, financial details, passwords, health records maadhiri sensitive personal data pathina IT Act-oda 2011 rules innum apply aagudhu.
2. **Contractual.** Client contracts avanga information-a third parties-kitta share panradha adikkadi thadai pannum, illa kurippitta naadugalla mattum allow pannum. Idhu innaikke apply aagudhu.
3. **Confidentiality.** Strategy, release aagaadha financial results, source code leak aagalaam. 2023-la, engineers internal source code-a oru public chatbot-la paste pannadhukku appuram, Samsung than staff public chatbots use panradha restrict pannuchu.

Neenga oru bank, NBFC, insurer illa hospital-la velai pannaa, unga regulator idhukku mela rules serkkum, adhu unga compliance team-kku theriyum. Udhaaranamaa, RBI-yoda FREE-AI committee report (August 2025), regulated firms-kitta oru board-approved AI policy irukkanum-nu recommend pannudhu. Idhu binding rule illa, advice thaan, aanaa sector endha pakkam pogudhu-nnu kaattudhu.

Oru company licence, rules-a yaar set panraanga-nnu maathudhu:

| | Personal free account | Company-licensed tool |
|---|---|---|
| Terms | Neenga click panni ethukitteenga | Company sign panna oru contract |
| Unga data-la training | Unga settings-aiyum vendor-oda terms-aiyum poruthadhu | Company-oda contract set pannudhu; adhu enna solludhu-nnu IT-kitta kelunga |
| Control | Admin control illai | Single sign-on, admin settings, audit logs |
| Edhaavadhu leak aanaa | Company-aala adha paarkkavo fix pannavo mudiyaadhu | Data enga pochu-nnu security team-kku theriyum |
| Edhukku use pannalaam | Adhigabatcham public material | Approved velai, data rules-kkulla |

Oru licence blank cheque illa. Company approve panna tool, settings-kku, policy kurippidura data-kku mattum thaan adhu porundhum.

### Unga data-va naalu categories-aa sort pannunga

| Category | Examples | Rule of thumb |
| --- | --- | --- |
| **Public** | Publish aana brochures, company website, public reports | Podhuvaa endha tool-layum paravaayillai |
| **Internal** | Process notes, templates, internal announcements | Approved tools mattum |
| **Confidential** | Client contracts, release aagaadha results, strategy, draft prices | Approved tools mattum, sila neram adhuvum koodaadhu |
| **Personal, sensitive** | Phone numbers illa emails kooda peyargal, salaries, health, Aadhaar illa PAN numbers, bank details | Ellaathaiyum vida strict; adikkadi oru kurippitta system-la mattum |

Makkal adikkadi thappaa sort panra moonu items:

- **Oru client-kkaana draft price list** confidential, public illa. Adhu publish aanaa, aagumbodhu mattum thaan public aagum; oru client quote podhuvaa eppavume publish aagaadhu.
- **Unga CRM illa inbox-oda oru screenshot**, adhula peyargal, numbers illa emails therinjaa personal data thaan, andha screenshot edhai kaatta eduthadhaa irundhaalum.
- **Unga sondha meeting notes**, adhula irukkura ellaathaiyum vida adhiga sensitive-aana vishayathoda category-a eduthukkum. Oru client call-oda notes podhuvaa confidential; adhula yaaroda contact details-aavadhu irundhaa personal.

Sandhegam irundhaa, oru document-a oru category adhiga strict-kku nagarthunga.

### Neenga venumne open pannaadha AI

Niraiya leaks oru chatbot-a open panradhaala varradhilla, makkal erkanave use panra tools-la built-in-aa irukkura AI-la irundhu thaan varudhu. Idhu ovvonnukkum unga policy-a check pannunga; adhu edhuvum sollalainnaa, onna switch on panradhukku munnaadi IT-kitta kelunga.

| Feature | Adhu enna paarkka mudiyum | Sensible default |
| --- | --- | --- |
| **Office suites, email-la AI**, "summarise this thread" illa "draft a reply" maadhiri | Adha point panra documents, sheets, mail, sila neram unga muzhu drive | Unga company license panni switch on panna version-a mattum, data rules-kkulla mattum use pannunga |
| Rewrite, summarise illa translate panra **browser extensions** | Adikkadi neenga open panra ovvoru page-um, CRM, HR portal, webmail udpada | IT approve panna extensions-a mattum install pannunga; mathadha eduthudunga |
| **AI meeting notetakers** | Call-la ellaarum pesura ellaame, koodave peyargal, share panra screens | Aarambathulaye ellaarkittayum solli, yaar venumnaalum marukka vidunga; external calls-kku, mudhalla marupakkathukitta kelunga |
| **Coding assistants** | Open aana files, adikkadi muzhu repository, sila neram keys irukkura configuration files | Approved assistant mattum, unga client allow panra code-la mattum; adhu padikkira files-la passwords, keys vaikkaadheenga |

Notetakers-kku thani kavanam venum, yenna avai ungalai mattum illa, mathavangalaiyum record pannudhu. Recording rules naattukku naadu maarum. Udhaaranamaa California-la, oru confidential conversation-a record panna adhula irukkura ellaaroda consent-um venum; adhanaala oru US team kooda nadakkura client call, mariyaadhai saarndha kelvi mattum illa, oru legal kelviyaiyum ezhuppalaam. Niraiya client contracts recording-aiyum thadai pannudhu. Oru transcript-a andha meeting maadhiriye treat pannunga: adhukkum adhe category, adhe rules.

### Thevaiyillaadhadha eduthudunga

Adikkadi sensitive pagudhi illaamale task-a mudikkalaam. Peyargalukku badhilaa roles podunga ("client-oda purchase head"), phone numbers, account numbers-a eduthudunga, mukkiyam illaadha figures-a round pannunga, task-kku thevaiyaanadha mattum vainga. Unmaiyaana company pathi ezhudhura adhe alavu nallaa "oru periya automotive client" pathiyum assistant ezhudhum. Worked example-la oru muzhu before, after irukku.

### Review, disclosure, accountability

Unga velaiyila unga peyar irukku. Oru client report-la thappaana figure irundhaa, "AI thaan ezhudhuchu"-ngradhu excuse illa. Policies podhuvaa idha velippadaiyaa sollum, managers-um clients-um eppadiyum idha thaan eduthukkuvaanga. Idhula irundhu rendu pazhakkangal varudhu:

- **Ellaathaiyum vida mukkiyamaanadha mudhalla check pannunga:** prices, dates, peyargal, legal terms, neenga promise panra edhuvum.
- **Policy illa padikkiravanga edhirpaarthaa disclose pannunga.** Oru deliverable perumalavu AI-drafted-aa irundhaa sollanum-nu sila clients keppaanga. Neenga AI-a eppadi use panreenga-nnu unga manager-kitta solradhu, edhaavadhu thappaa ponaa ungalaiyum paadhukaakkum.

### Thavarudhalaa edhaavadhu paste pannitta

Ellaarum oru thadavai indha thappa pannuvaanga: thappaana file, thappaana tab, innum sign in-aa irukkura oru personal account. Mukkiyam adutha oru mani neram thaan.

1. **Niruthunga.** Innum edhuvum anuppaadheenga, adha "marandhudu"-nnu chatbot-kitta kekkaadheenga. Erkanave store aanadha adhaala undo panna mudiyaadhu.
2. **Facts-a note pannunga:** endha tool, endha account, neram, sariyaa enna ulla pochu.
3. **Udane report pannunga**, IT illa security-kitta, unga policy-la irukkura channel vazhiyaa. Sila incidents-a gavanicha 6 mani nerathukkulla, India-voda cyber security agency-yaana CERT-In-kku unga company report panna vendiyirukkalaam; adhanaala oru naal delay aanaa, oru chinna problem andha duty-a meerunadhaa maaridalaam.
4. Report pannadhukku appuram, illa security solrapadi, **chat-a delete pannunga**. Delete panradhu udhavum, aanaa service adhoda terms-padi oru kaalam varaikkum oru copy-a innum vachirukkalaam; adhanaala delete panradhum fix panradhum onnu illa.
5. Neenga paste panna **endha password, key illa access token-aiyum maathunga**, adhe naalla.

Nermaiyaana, vegamaana reports-kku thandanai illai-nnu nalla policies sollum. Oru thappa maraikkiradhu thaan adha disciplinary matter-aa maathudhu.

### Policy illaadhappo

Niraiya chinna companies-la innum AI policy illa. Adhukku rules illai-nnu artham illa: laws, contracts innum apply aagum. Oru policy varra varaikkum:

1. Endha tools allowed-nu unga manager illa IT team-kitta kelunga.
2. Public material illa unga sondha confidential illaadha notes-a mattum use pannunga.
3. Peyargal, numbers, identifiers-a eduthudunga.
4. Personal data, passwords illa keys-a eppavume paste pannaadheenga.
5. Use panradhukku munnaadi ellaathaiyum check pannunga.
6. Neenga AI-a eppadi use panreenga-nnu unga manager-kitta sollunga.

Innum nalladhu, oru one-page draft-a neengale kudunga. Ungalukku etha maadhiri maathikka oru template idho. Idhu oru aarambap pulli, legal advice illa; final rules-a IT, legal-kku poruppaanavangakitta vidunga.

```text
[Company] AI use policy (draft, version 1, [date])

1. Approved tools: [licensed assistant], with [settings]. No personal
   AI accounts for work. Ask IT before switching on any other AI
   feature, browser extension or notetaker.
2. Data: public and internal data in approved tools. Confidential
   client data only where the client contract allows it. Personal
   data only in [named systems]. Never passwords or keys.
3. Encouraged: drafting, summarising, research, formatting.
4. Needs approval: anything customer-facing, decisions about people
   (hiring, appraisal, credit), recording external calls.
5. Review: you check every fact and figure; [named role] reviews
   prices and anything sent to a client.
6. Disclosure: tell clients when a deliverable is largely AI-drafted,
   or when their contract asks.
7. Ownership: do not paste others' copyrighted work to rewrite it.
8. Mistakes: report to [contact] within 1 hour. Honest reports are
   not punished.
9. Owner: [name]. Reviewed every 6 months.
```

## Oru worked example

Idhu oru illustrative case. Method-a kaatturadhukkaaga company, peyargal, numbers ellaam karpanaiyaa uruvaakkinadhu.

Karthik, Chennai-la oru mid-sized machine-tools manufacturer-kitta sales-la velai panraaru. Oru pudhu plant-kku anju CNC machines thevaippadura oru periya automotive client-kku proposal thayaar panna avar AI-a use panna virumburaaru.

Avaroda company-oda one-page policy solludhu:

- Company-licensed assistant internal, confidential information-kku approved. Velaikku personal free accounts allowed illai.
- Peyargal, phone numbers maadhiri customer personal data, CRM-layum adhoda built-in AI features-layum mattum thaan poganum.
- Video-call tool-oda AI notetaker internal calls-kku approved. External calls-kku, mudhalla marupakkathukitta kelunga.
- Anuppuradhukku munnaadi, pricing-a finance team check pannanum, client documents-a account manager review pannanum.

**Step 1: Notes-a clean panradhu.** Mudhal call-la irundhu avaroda notes:

```text
Before: Spoke to Ramesh Natarajan (purchase head, 98765 43210) at
        Zentora Motors. Need 5 CNC machines for the new plant by March.
        Budget about Rs 2.6 crore. Unhappy with current vendor's
        service: engineers take 3 to 4 days to arrive.

After:  The client's purchase head needs 5 CNC machines for a new
        plant by March. Budget about Rs 2.6 crore. Unhappy with the
        current vendor's service: engineers take 3 to 4 days to arrive.
```

Peyarum phone number-um personal data, adhanaala avai CRM-laye irukkum. Budget-um client-oda thevaigalum confidential, adhukku licensed assistant approved. Client-oda peyar draft-kku edhaiyum serkkala, adhanaala adhuvum poyidudhu.

**Step 2: Limits kooda prompt panradhu.** Licensed assistant-la avar ezhudhuraaru:

```text
You are helping me draft a sales proposal for CNC machines. Using the
notes and our standard proposal sections below, draft three sections:
the client's needs, our proposed solution, and our service plan.
Formal Indian business English, under 600 words. Do not invent prices,
delivery dates or specifications. Write [CHECK] wherever a figure is
needed. Then build a pricing table from the price list below.
```

"Do not invent" line mukkiyam. Adhu illainnaa, yaarume kekkaadha, nambura maadhiri irukkura figures-aala assistants adikkadi gaps-a nirappidum.

**Step 3: Review thappa pidikkudhu.** Quote-la rendu pagudhi irukku: ₹2 crore madhippulla anju machines, appuram company eppavume discount kudukkaadha ₹50 lakh spares, installation. Assistant standard 8% discount-a muzhu ₹2.5 crore-kkum apply pannidichu. Finance adha kandupidichaanga: ₹2 crore-la 8% ₹16 lakh, aanaa draft ₹20 lakh-nu kaattuchu. Andha thappu ₹4 lakh-a vittukkuduthirukkum. Adha pidichadhu review step thaan, AI illa.

**Step 4: Oru notetaker kelvi.** Follow-up video call-la, meeting tool adhoda AI notetaker-a switch on pannalaamaa-nnu kekkudhu. Idhu external call, adhanaala Karthik aarambathulaye kekkuraaru. Purchase head vendaam-nu solraaru: avaroda sondha company supplier calls-a record panradha thadai pannudhu. Karthik kaiyaala notes eduthu, appuram contact details-a CRM-la serkkuraaru.

Appuram oru colleague "adhu vegamaa irukkum"-nu oru free personal account-a suggest panraaru. Licensed tool-a eppadi open panradhu-nnu Karthik avarukku kaatturaaru, adhukku oru nimishathukkum kuraivaa thaan aagudhu. Colleagues orutharukkoruthar ninaivupaduthumbodhu thaan policies work aagudhu.

## Podhuvaa panra thappugal

- **Velai data-kku personal accounts-a use panradhu.** Paadhippillaadhadhu maadhiri thoninaalum, adhu data-va unga company-oda control-kku veliya vaikkudhu.
- **Oru tool approved-naa adhoda ovvoru feature-um approved-nu ninaikkiradhu.** Connectors, extensions, notetakers, agent modes ovvonnum data-va oru pudhu idathukku anuppalaam. Ovvonnaiyum check pannunga.
- **General assistants-la customer personal data-va paste panradhu.** Sollappatta system-a use pannunga, illa mudhalla personal details-a eduthudunga.
- **Kekkaamale oru notetaker-a switch on panradhu.** Adhu call-la irukkura ellaaraiyum record pannudhu, marupakkam adha allow pannaama irukkalaam.
- **Thavaraa paste pannadha maraikkiradhu, illa chat-a delete mattum panradhu.** Udane report pannunga; delete panradhu adha undo pannaadhu, delay aanaa oru 6 mani nera reporting duty-a meeralaam.
- **"Policy illai"-naa "rules illai"-nu ninaikkiradhu.** Data protection law, contracts, confidentiality innum apply aagum.
- **AI "podhuvaa sariyaa irukkum"-nu review-a skip panradhu.** Pricing, contracts, customer data-kku "podhuvaa sari" podhaadhu.
- **Policy-a oru thadavai padichaa podhum-nu ninaikkiradhu.** Tools maara maara policies-um maarum; updates-a check pannunga.

## Practice pannunga

Keezha link panniyirukkura AI Fluency course-la responsible use pathina section-a pannunga, India-voda DPDP law pathina PRS-oda summary-a padinga. Adhu 2023-la pass aana Act-a cover pannudhu; Rules November 2025-la vandhuchu.

1. **Unga policy-a kandupidinga.** Unga organisation illa college-oda AI policy-a kandupidichu, indha vaaram neenga panna oru task-kku indha lesson-oda aarambathula irukkura moonu kelvigalukku badhil sollunga. Policy illainnaa, unga manager-kitta kekkappora anju kelvigalai ezhudhunga.
2. **Pathu documents-a classify pannunga.** Neenga adikkadi use panra pathu documents-a list panni, ovvonnaiyum public, internal, confidential illa personal-nu classify pannunga. Ovvonnukkum endha tools use pannalaam-nu note pannunga.
3. **Unga hidden AI-a audit pannunga.** Unga work laptop, phone-la irukkura ovvoru AI feature, browser extension, notetaker-aiyum list panni, ovvonnaiyum approved, unapproved illa unknown-nu mark pannunga.
4. **Clean panni seyyunga.** Oru unmaiyaana task-a eduthu, Karthik panna maadhiri ella personal, confidential details-aiyum eduthuttu, oru approved tool-la adha seyyunga.

**Mudinjadhu-nnu eppo sollalaam:** unga workplace-la AI-kku endha tools, features, data allowed-num, thavaraa paste pannadhukku appuram mudhal oru mani nerathula enna pannanum-num oru colleague-kitta explain panna mudiyum.
