## Idhu enna

**Discovery**-na oru engagement-oda mudhal phase, build panradhukku munnaadi, perumbaalum onnu-la irundhu moonu vaaram. Idhoda goal, onnaa purinjukkradhu:

- Entha problem mukkiyam, yaarukku, evvalavu?
- Ippo velai eppadi nadakkudhu, step by step?
- Neram, selavu, errors nijama enga pogudhu?
- Enna data irukku, enga, enna nilaimaila?
- Enna constraints: rules, systems, budgets, makkal?
- AI sariyaana tool-aa, illa oru form, report, process maatram podhumaa?

Output short-aa, concrete-aa irukkum: process map, numbers-oda problem statement, value, feasibility vachchu rank panna use cases shortlist, risks-um open questions-um.

```flow
title: Discovery, rendu vaarathula
Week 1: interviews, shadowing | past tense-la 5-10 interviews, paadhi naal shadowing -> Process map | trigger, steps, outcome; yaar, system, nimisham, failure points, judgement illa rote
Process map -> Week 2: rough numbers | volume, oru item-ku neram, rework -> Use cases-a score pannunga
Use cases-a score pannunga -> Play-back: "Naanga kettadhu idhu" -> Client thiruththuraanga -> Orumichchu oppukkitta mudhal use case + baseline
```

Indha lesson Chennai-la oru non-banking lender-a follow pannum; avanga customer chatbot kettaanga, aana veraa onnu thevai-nu aachu.

## Idhu eppadi work aagudhu

**Velai seiravanga kitta pesunga.** Leaders process-a design pannapadi solluvaanga; front-line staff adhu irukkapadi solluvaanga. Rendu perukittayum interview pannunga. Roles-ukku naduvula 30-la irundhu 45 nimisham, ainju-la irundhu paththu pechu-a target pannunga.

**Munnaadi nadandhadha kelunga, future pathi opinions illa.** "Neenga process panna kadaisi claim pathi sollunga" "AI assistant unga-ku help pannumaa?"-a vida nalladhu. Edhai use pannuvom-nu predict panradhula makkal mosam, seidhadha solradhula nallavanga.

**Velai-a paarunga.** Oruthar kooda oru mani neram ukkaarunga. Avanga thirakkura ovvoru system, ovvoru copy-paste, colleague-kitta kekkura ovvoru kelvi, ovvoru kaaththirukkalum note pannunga. Interviews miss panradhai shadowing kandupidikkum.

**Process-a map pannunga.** Trigger-la irundhu outcome varaikkum steps-a varainga, ovvonnayum yaar seiraanga, entha systems, evvalavu neram, failure points enga-nu. Enga judgement thevai, enga rote-nu mark pannunga.

**Rough-aa measure pannunga.** Maadhathukku volume, oru item-ku neram, error illa rework rates, backlog. Mudinja varaikkum real data kelunga; staff-oda estimates oru aarambam.

**Use cases-a score pannunga.** Ovvoru candidate-kum: value (migaththina neram, errors, revenue), feasibility (data irukka, indha maadhiri task-la AI nallaa irukka, thappukku tolerance), risk (regulatory, reputational), effort. Adikkadi nadakkura, valikkura, data adhigamaa irukkura, oru aal output-a check panna mudiyura tasks-a favour pannunga.

**Play back pannunga.** Kettadhai client-oda sollulayae avanga kitta kaattunga, avanga unga-a thiruththattum. Idhula thaan nambikkai uruvaagudhu.

**Use cases-a score panradhu:**

| Use case | Value | Feasibility | Risk | Effort | Rank |
| --- | --- | --- | --- | --- | --- |
| Document extraction, draft credit summary | High: maadhathukku sumaar 4,000 officer-hours, 7% rework | High: decisions-oda rendu varusha files | Medium: officer ovvoru figure-um review pannuvaanga | Medium | 1 |
| Collections call notes summary | Medium | High | Low | Low | 2 |
| Customer chatbot | Low: call centre queries-a already nallaa handle panudhu | Medium | Medium: customer-facing | Medium | 3 |

**Nalla interview kelvigal:**

| Idhukku badhila | Idhai kelunga |
| --- | --- |
| "AI unga-ku help pannumaa?" | "Neenga process panna kadaisi application pathi sollunga." |
| "Indha process romba slow-aa?" | "Kadaisi onnu evvalavu neram aachu, enga kaaththirundheenga?" |
| "Enna features vendum?" | "Pona vaaram oru system-la irundhu innoru system-ku enna copy pannineenga?" |
| "Errors nadakkudhaa?" | "Kadaisi eppo edhaavadhu thirumbi anuppappattadhu, yen?" |

**Play-back-a ezhudhuradhu.** Oru page: client-oda sollulayae problem, process map, mukkiyamaana moonu numbers, reasons-oda rank panna use cases, risks-um open questions-um, adhoda baseline-oda proposed first step. Meeting-ku munnaadi anuppunga, apram walk through panni, thiruththangala kelunga. Client edit panna play-back, avanga own pannura ondru.

## Oru worked example

Chennai-la oru non-banking lender "customers-ku oru AI chatbot" kekkuraanga. Neenga mudhalla rendu vaara discovery-a propose pannureenga.

Head of operations, rendu team leads, naalu credit officers, rendu collections agents kooda interviews, loan-processing team-a paadhi naal shadow pannadhula theriyavandhadhu:

- Customer queries-a ippo irukkura call centre nallaa handle panudhu.
- Nijamaana vali loan processing-la: credit officers oru application-ku sumaar 40 nimisham bank statements, salary slips, bureau reports padichu, figures-a spreadsheet-la thirumba type panni, oru summary note ezhudhuraanga. Maadhathukku 6,000 applications irundhaa, adhu sumaar 4,000 officer-hours.
- Thirumba type pannura figures-la errors-aala 7% applications-a credit committee thirumbi anuppudhu.
- Documents PDFs-aavum phone photos-aavum varudhu; lender kitta final decisions-oda rendu varusha past applications irukku.

Unga play-back, customer chatbot-la illa, document extraction-oda draft credit summary-la aarambikka recommend panudhu, officer ovvoru figure-um review pannuvaanga. Baseline 40 nimisham, 7% rework. Head of operations oppukkuraanga, chatbot idea adutha list-ku pogudhu.

| Kandupidippu | Evidence |
| --- | --- |
| Customer queries already nallaa handle aagudhu | Call-centre interviews, data |
| Officers oru application-ku sumaar 40 nimisham selavazhikkuraanga | Shadowing, team-lead estimates |
| Maadhathukku 6,000 applications, sumaar 4,000 officer-hours | Operations data |
| 7% applications retyping errors-aala thirumbi anuppappadudhu | Credit committee records |
| Recommendation | Extraction, draft summary-la aarambinga; chatbot adutha list-ku |

## Podhuvaa panra thappugal

- **Mudhal meeting-layae solutioning.** Mudhalla kelunga; evidence irukkum podhu propose pannunga.
- **Managers kitta mattum pesradhu.** Paper-la irukkura process-um nijama nadakkura process-um veraa.
- **Hypothetical kelvigal kekkradhu.** Kadaisi real case pathi kelunga.
- **Numbers illaama irukkradhu.** Volume-um oru item-ku neram-um illaama, use cases-a rank panna, apram value-va prove panna mudiyaadhu.
- **Non-AI fixes-a ignore panradhu.** Sila neram oru template illa database view-vae theerkkum. Adha sonnaa credibility valarum.

## Practice pannunga

GOV.UK-oda discovery, user research guides-a padinga.

1. Neenga observe panna mudiyra oru process-a select pannunga (college admission office, oru kadai-yoda billing, friend-oda velai). Past-tense kelvigal mattum use panni rendu perukitta interview pannunga.
2. Process map-a steps, makkal, systems, neram, failure points-oda varainga.
3. Moonu use cases list pannunga, ovvonnayum value, feasibility, risk, effort-ku score pannunga, oru page play-back ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** Oru process map-um, ovvoru use case-kum kuraindhadhu oru number-oda rank panna use-case list-um present panna mudiyum, edhu mudhalla yen-nu explain panna mudiyum.
