## Idhu enna

Oru calculator-a test panradhu easy: 2 + 2 nu 4 thaan varanum. Emails, summaries, explanations ezhudhura oru AI-a test panradhu konjam kashtam, yen-na neraya nalla answers irukkum. Indha lesson, appadi answers-ku oru number podura mukkiya vazhigala, ovvonnu eppo set aagum-nu solludhu.

Naalu kudumbangal irukku, romba exact-la irundhu kammi exact varaikkum:

1. **Functional correctness.** Output work aagudhaa? Generate panna code adhoda tests-la pass aagudhu, generate panna SQL query sariyaana rows tharudhu, extract panna invoice total ledger-oda match aagudhu.
2. **Exact match.** Answer reference-a maadhiri thaan irukkaa? Numbers, dates, labels, multiple-choice letters-ku nalladhu.
3. **Reference-oda similarity.** Oru therinja nalla answer-oda indha answer evvalavu close, **words**-la (BLEU, ROUGE maadhiri lexical similarity) illa **meaning**-la (embeddings use panra semantic similarity)?
4. **Judgement.** Oru aal illa judge model answer-a rate pannum, thaniyaa (5-la oru score) illa innoru answer-oda (**pairwise comparison**). LLM judges lesson, judge prompts-a aazhamaa cover pannum.

```flow
title: Oru answer-a eppadi score panradhunu select panradhu
Score panna vendiya answer -> Odi illa test panna mudiyumaa? | code, SQL, schema
Odi illa test panna mudiyumaa? -[aama]-> Functional check | romba nambalaam
Odi illa test panna mudiyumaa? -[illa]-> Oru sariyaana sirusaana answer irukkaa? | number, label, date
Oru sariyaana sirusaana answer irukkaa? -[aama]-> Exact match
Oru sariyaana sirusaana answer irukkaa? -[illa]-> Nalla reference answers irukkaa?
Nalla reference answers irukkaa? -[aama]-> Artham similarity illa reference-oda judge
Nalla reference answers irukkaa? -[illa]-> Rubric-oda judge
Artham similarity illa reference-oda judge -> Rendu systems-la onna select pannanumaa? -[aama]-> Pakkam pakkamaa comparison
```

## Idhu eppadi work aagudhu

**Functional correctness.** Odi illa test panna mudinja, adha thaan mudhalla pannunga. Code assistant-a unit tests ottitu score pannuvaanga. Text-to-SQL feature, generate panna query-yum reference query-yum test database-la ottitu results-a compare pannum. Extraction feature, fields-a system of record-oda check pannum. Vera edhuvum idhu maadhiri nambalaam illa. OpenAI, oru coding benchmark-la, word-overlap scores sariyaana-vum thappaana-vum solutions-ku orae maadhiri irundhadha, code-a ottina thaan rendayum pirichu kaattunadhu-nu kandupidichaanga.

**Exact match**, kavanamaa. Mudhalla normalise pannunga: lowercase, spaces trim, number formats-a standard aakkunga. Sariyaana value-va thappaana answer-kulla vechirukkura answers-a kavanamaa paarunga: "Born on 12 September 1929" la "1929" irukku, aana unmaiyaana date 12 June-naa adhu thappu. Labels-ku muzhu sentence-a illa, label field-a compare pannunga.

**Lexical similarity.** Rendu texts-a words illa word pairs-a pirichu, overlap-a ennunga. BLEU (machine translation-la irundhu) -um ROUGE (summarisation-la irundhu) -um romba theriyaadha versions. Idhoda sambandhamaana **edit distance**, oru string-a innoru string-a maatha evvalavu letter changes venum-nu ennum; names-ku, codes-ku useful.

Pudhu models-ku idhoda weaknesses serious:

- Vera words-la sonna sariyaana answer-ku score kammi. "How is it going?" na "How are you?" oda konjam thaan share pannum.
- Reference-oda words-a copy panna thappaana answer-ku score adhigam. "Let's eat, grandma" -um "Let's eat grandma" -um words-la kittathatta onnu thaan.
- References-la nalla answers miss aagalam, illa avai thappaavae irukkalam.

Appavum, sila vishayangalukku cheap-aana smoke alarms-aa use aagum, example oru template change ella replies-yum udaichadhunu kandupidikka.

**Semantic similarity.** Answer-yum reference-yum embeddings-a maathi, -1 la irundhu 1 varaikkum cosine similarity-oda compare pannunga. Paraphrases-ku score adhigam. Perumbaalaana alavula cheap, aana score embedding model-a sarndhu irukkum, "refund approved"-yum "refund rejected"-yum close-nu rate pannalaam, sariyaana threshold-a makkal judgements-oda check pannitu thaan set pannanum.

```python
import numpy as np

def cosine(a, b):
    a, b = np.asarray(a), np.asarray(b)
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b)))

def score(answer, reference, embed, must_include=()):
    """embed(text) returns a vector. must_include holds facts that need an exact check."""
    facts_ok = all(f.lower() in answer.lower() for f in must_include)
    return {"facts_ok": facts_ok, "meaning": round(cosine(embed(answer), embed(reference)), 3)}

# score(draft, agent_reply, embed, must_include=["ORD-48213", "₹2,499"])
```

Pattern-a gavanichukkunga: sariyaa irukka vendiya facts-ku exact checks, wording-ku similarity.

**Pairwise comparison.** Rendu paatula edhu pidikkum-nu solradhu, ovvonnukkum 10-la score podradha vida easy. Answers-kum adhe thaan. Adhe kelvi-ya rendu answers-oda, random order-la, labels illaama kaattunga, tie-a allow pannitu edhu nallaa-nu kelunga. Wins-a ennunga. Neraya models irundhaa Elo, Bradley–Terry maadhiri ranking methods wins-a oru league table-aa maathum; public arenas, laksha kanakkaana votes-la irundhu chatbots-a ippadi thaan rank pannum.

Rendu limits mukkiyam:

- **Preference correctness illa.** Voter-ku sariyaana answer theriyaadhu-naa, maths result, medical fact maadhiri, confident-aa irukkura thappaana answer-a virumbalaam. Style-kum helpfulness-kum vote pannunga; facts-a thaniyaa check pannunga.
- **Neraya comparisons thevai**, models serkka serkka pairs-oda ennikkai vegamaa valarum. Rendu prompts illa rendu models-la oru product decision-ku, unga sondha questions-la 100-la irundhu 300 side-by-side comparisons perumbaalum podhum.

| Method | Edhukku nallaa | Selavu | Mukkiya risk |
| --- | --- | --- | --- |
| Functional check | Code, SQL, extraction, formats | Build pannitta kammi | Cases-a miss panra tests |
| Exact match | Numbers, labels, sirusaana facts | Romba kammi | Thappaana answer-kulla sariyaana value |
| Lexical (BLEU, ROUGE) | Smoke tests, translation drift | Romba kammi | Words-a copy panradhukku reward, artham illa |
| Semantic similarity | Reference-oda paraphrased answers | Kammi | Edhirmarai facts-ukku close meaning score |
| Rubric-oda judge | Reference illaadha open text | Naduthara | Judge bias; makkal-oda check pannunga |
| Pairwise comparison | Rendu systems-la onna select panradhu | Naduthara-la irundhu adhigam | Preference-a correctness-nu ninaikradhu |

## Oru worked example

Delhi-la oru electronics retailer-ku, customer emails-ku Hindi-layum English-layum replies draft panra assistant irukku. Ovvoru reply-layum sariyaana order number-um refund amount-um sollanum, polite-aa mudikkanum. Team, prompt A (ippo irukkaradhu) -va prompt B (pudhusu) -oda, 300 past emails-yum avanga best agents-oda replies-yum vechu compare panna virumburaanga.

Mudhalla agents-oda replies-ku edhiraa ROUGE try pannuraanga. Prompt A 0.41, prompt B 0.33 score pannudhu; B mosam-nu thonudhu. Drafts-a padicha vera kadhai: B surukkamaana, therivaana Hindi ezhudhudhu, agents-oda neelamaana replies-oda kammi words-a thaan share pannudhu.

Adhanaala moonu layers-la score pannuraanga:

| Layer | Prompt A | Prompt B |
| --- | --- | --- |
| Order number-um refund amount-um sariyaa (order system-oda exact check) | 94% | 97% |
| Agent-oda reply-oda artham close (cosine 0.80-ku mela) | 88% | 90% |
| Rendu senior agents judge panna side-by-side wins, 150 emails, ties allow | 38% | 51% (11% ties) |
| Agent-oda reply-ku edhiraa ROUGE-L | 0.41 | 0.33 |

Numbers purpose-ku example-ku thaan. B facts-layum preference-layum jeikkudhu, words overlap-la mattum thorkkudhu; adhai dashboard-la irundhu eduthuduraanga. Ovvoru release-layum exact checks-a thodarndhu otturaanga.

## Podhuvaa panra thappugal

- **BLEU illa ROUGE-a** chat, summaries, explanations-ku mukkiya quality score-aa use panradhu.
- **Similarity score-a facts-a check panna vidradhu.** "Approved"-um "rejected"-um close-aa theriyalaam. Mukkiya facts-a exact-aa check pannunga.
- **Sariyaana answers irukkura questions-ku vote panradhu.** Preference makkal edha virumburaanga-nu kandupidikkum, edhu unmai-nu illa.
- **Answers-a oru fixed order-la kaattradhu.** Makkalum judges-um mudhal answer-a illa neelamaana answer-a virumbuvaanga. Order-a randomise pannunga, orae maadhiri length-a compare pannunga.
- **Yaarum check pannaadha threshold-a nambradhu.** Similarity thresholds-a, oru sample-la human judgements-oda compare pannitu pick pannunga.
- **Ellathukkum oru number.** Perumbaalaana products-ku konjam scores thevai: facts, format, meaning, preference.

## Simple-aa vechukka vendiya idangal

- **Closed tasks:** classification, extraction, routing-a exact checks-aalum precision, recall-aalum score pannuvaanga. Similarity-yum judges-um thevai illa.
- **Aarambha prototypes:** edhavadhu metric build panradhukku munnaadi, 30 answers-a neengalae padinga.
- **Arasaanga, high-stakes answers:** legal, medical outputs-ku scores enna sonnaalum expert review thevai.

## Demo-la irundhu production-ku

- **Scores-a layer pannunga:** ovvoru response-layum exact checks, oru sample-la judge illa similarity, releases-ku side-by-side comparison.
- **References-a test set-oda version pannunga**, thappaanavai kandupidicha fix pannunga.
- **Metrics-a makkal-oda ovvoru sila maadhathukkum thirumba check pannunga**, yen-na human judgement-a vittu vilagura metric, metric illaama irukkradha vida mosam.
- **Scores-a segment vaariyaa report pannunga:** language, topic, length. Overall gain, Hindi replies-la oru drop-a maraikkalam.
