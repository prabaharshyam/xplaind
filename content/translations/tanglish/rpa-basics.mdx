## Idhu enna

Neraiya Indian businesses innum vera edhoda-vum pesa mudiyaadha software-la odudhu: 15 varusha pazhaya desktop ERP, oru bank-oda back-office screens, API illaadha oru government portal. Makkal thanga naalai oru screen-la irundhu innonnukku values-a copy panradhulayae kazhikkiraanga. **Robotic process automation (RPA)** andha copy panra velaiyai edukkum.

RPA, oru aal seiyura maadhiri, applications-a avatroda **user interface** vazhiyaa iyakkura software "robots"-a use pannum: programs-a thirakkum, buttons-a click pannum, fields-la type pannum, screens-la irundhu values-a copy pannum, reports-a download pannum. Systems-kku API illaadha idaththula, illa integration build panna romba neram aagura idaththula idha use panrom.

```flow
dir: LR
title: API automation: vegam, urudhi, idhuvae viruppam
System A, API irukku -[data, nerayaa]-> System B, API irukku
```

```flow
dir: LR
title: RPA: oru aal velai seiyura engayum work aagum, aana adhiga udaiyakkoodiyadhu
Robot | UiPath, Power Automate Desktop -[screen-la clicks, typing]-> Pazhaya desktop app, API illai
```

Munnani RPA tools-la **UiPath**, **Automation Anywhere**, **Microsoft Power Automate Desktop** irukku. Steps-a record pannalaam illa design pannalaam, apparam oru schedule-la illa thevaippadumbodhu, oru desktop-layo server-layo run pannalaam.

Indha lesson-la Kolkata-la oru general insurer-oda claims team-a follow panrom; oru AI step-um oru RPA robot-um serndhu, oru pazhaya claims system-la data entry-a edukkudhu. Lesson mudiyum podhu, RPA eppo sariyaana tool-aa irukkum-num, adha oda vaikka enna selavaagum-num therinjukkuveenga.

## Idhu eppadi work aagudhu

### Attended, unattended robots

| Type | Eppo odum | Udhaaranam |
| --- | --- | --- |
| **Attended** | Oru aal start pannumbodhu, avanga computer-la | Agent "Go" click pannadhukku appuram, 40-field form-a nirappura oru robot |
| **Unattended** | Thaanaa, thani machines-la, oru queue-a velai seiyum | Raathiri muzhukka 300 claims-a ullidura oru robot |

### Robots screen-la eppadi vishayangalai kandupidikkudhu

Nalla RPA, nilaiyaana screen positions-la click pannaadhu. Adhu elements-a avatroda properties vechu adaiyaalam kaanum: oru button-oda peyar, oru field-oda label, oru web page-oda structure. Indha identifiers-kku **selectors**-nu peyar. Appo sinna layout maatrangal robot-a udaikkaadhu.

Properties kidaikkaadha pazhaya applications-kko remote desktops-kko, robots **image matching** illa **OCR**-a nambalaam; ivai adhiga udaiyakkoodiyavai: oru colour illa font maarinaalae udaiyalaam.

### RPA enga poruntthum

- Legacy desktop applications, pazhaya ERPs, banking back-office screens maadhiri; APIs illaadha portals.
- Adhiga volume, nilaiyaana, rule-based tasks: systems-kku naduvula data-va copy panradhu, dhinasari reports-a uruvaakki download panradhu, orders-a ullidurathu.
- Oru sariyaana integration build aagura varai oru paalam.

### RPA enga poruntthaadhu

| Nilaimai | Sirandha therivu |
| --- | --- |
| System-kku oru nalla API irukku | API-a use pannunga: vegam, urudhi |
| Process illa screens adikkadi maarudhu | Mudhalla process-a sari pannunga, illa kaathirunga |
| Palavidhamaana inputs-la judgement thevai | Oru AI step-um oru aalum; data entry-kku mattum RPA |

### RPA-vum AI-um serndhu

RPA screens vazhiyaa data-va nagarthum; AI documents-a padikkum, emails-a classify pannum, adutha step-a mudivu pannum. Serndhu, rendula onnaala mattum handle panna mudiyaadha processes-a cover pannum:

```flow
Claim irukkura Email -> AI step | email-aiyum attachment-aiyum padichu; policy no., vehicle no., date, idaththai edu
AI step -> Policy database-oda validate pannu
Policy database-oda validate pannu -[sari]-> RPA robot | pazhaya claims system-la type pannum
Policy database-oda validate pannu -[sariyilla]-> Oru aalodu queue | screenshots-oda
RPA robot -> Claim number tracking sheet-kku thirumba
```

**Computer-use agents**, adhaavadhu screenshots-la irundhu screens-a iyakkura AI, pudhusu, adhiga flexible, aana design panna RPA steps-a vida medhuvu, selavu adhigam, edhirpaarkka kashtam. Podhuvaana pattern: nilaiyaana steps-kku RPA, maarupaattukku judgement thevaippadura idaththula mattum AI.

### Running costs-um governance-um

Screens maarumbodhu, passwords expire aagumbodhu, edhirpaaraadha pop-ups varumbodhu robots udaiyum. Ivatrukku budget podunga:

- RPA platform-kkum robot machines-kkum **licences**;
- **monitoring**, adhanaala ninnu pona robot oru alert-a raise pannum;
- **maintenance**, selectors-a vegamaa sari pannakkoodiya oruthar.

Ovvoru robot-kkum oru register vechirunga: adhoda owner, adhu thoduradhu systems, adhu use panra credentials. Robots-kku **least-privilege** accounts kudunga, avatrukku thevaiyaana access mattum; avatroda passwords-a robot-oda script-la illaama, oru vault-la store pannunga.

## Oru udhaaranam

Kolkata-la oru general insurer, motor claim intimations-a email-la peruradhu: oru naalaikku sumaar 300. Claims team ovvoru email-la irundhum adhoda attachments-la irundhum vivarangalai, API illaadha oru pazhaya desktop claims system-kku copy panraanga. Ovvoru claim-kkum sumaar 6 nimisham, team muzhukka oru naalaikku kittathatta 30 mani neram velai.

**Theervu:**

1. Oru **AI extraction step** ovvoru intimation email-aiyum attachment-aiyum padichu, structured fields-a uruvaakkudhu: policy number, vehicle number, izhappu nadandha date, idam, vilakkam.
2. Andha fields policy database-oda **validate** aagudhu: policy irukka, active-aa irukka, vehicle poruntthudhaa?
3. Oru **unattended RPA robot** claims system-a thirandhu, "New intimation"-kku poi, validate aana fields-a nirappi, save panni, pudhu claim number-a tracking sheet-la thirumba ezhudhudhu.
4. Validation fail aanavai, robot adaiyaalam kaanaadha entha screen-um, screenshots-oda **oru aalodu queue**-kku pogudhu.

**Mudhal quarter-la results:**

| Measure | Before | After |
| --- | --- | --- |
| Data entry-kku staff neram | Oru naalaikku sumaar 30 mani neram | Oru naalaikku sumaar 6 mani neram, perumbaalum exceptions |
| Adhe naal-la ullidappatta claims | sumaar 70% | sumaar 98% |
| Robot outages | Poruntthaadhu | 2, rendumae system updates fields-a nagarthinadhukku appuram |
| Ovvoru outage-aiyum sari panna neram | Poruntthaadhu | Oru naalukkulla; monitoring RPA developer-kku alert pannuchu |

Adutha varusham claims system upgrade aagumbodhu, robot-a oru neradi API integration-aala maatha insurer thittamittirukku. Adhu varaikkum, robot thaan paalam.

## Podhuvaa panra thappugal

- **API irukkura idaththula RPA.** APIs vegam, urudhi.
- **Nilaiyaana screen positions.** Sinna maatrangal robots-a udaikkaama irukka element properties use pannunga.
- **Nilaiyillaadha processes-a automate panradhu.** Process illa screens maarumbodhellaam robots udaiyum.
- **Monitoring illa owner illaama irukkuradhu.** Udaindha robots saththamillaama fail aagum, velai yaarukkum theriyaama kuvindhudum.
- **Admin credentials irukkura robots.** Oru vault-la store panna least-privilege accounts use pannunga.
- **Veliyerum vazhigalai marakkuradhu.** Entha cases oru aal kitta pogum-nu plan panni, andha queue-a velai seiya elidhaa aakkunga.

## Practice pannunga

Keezha link pannirukkura UiPath Academy-la oru free beginner course-a edunga, illa Microsoft Learn-la irukkura Power Automate Desktop modules-a paarunga.

1. **Build.** Oru website illa desktop app-a thirandhu, oru spreadsheet row-la irundhu oru form-a nirappi, oru confirmation-a save panra oru simple robot-a seiyunga.
2. **Udainga.** Window-va resize panni, illa screen resolution-a maathi, layout-a konjam maathi, adhu innum work aagudhaa-nu paarunga. Nalla selectors vechu sari pannunga.
3. **Thernthedunga.** Unga organisation-la oru process-kku, RPA, API integration, AI agent idhula edhu sirandhadhu, yen-nu ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** Oru API illa oru AI agent-a vida RPA-a eppo thernthedupeenga-nu explain panni, oru sinna layout maatraththaiyum thaangura oru robot-a kaatta mudiyum.
