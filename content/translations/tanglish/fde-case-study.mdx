## Idhu eppadi work aagudhu

### Discovery: kettadhu thappu

Kettadhu "customers-kku oru chatbot". Onbadhu interviews-um, loan team-a arai naal kavanichadhum, customer queries-a call centre erkanave nallaa handle pannudhu-nnu kaattuchu. Vali ulle thaan irundhuchu: officers oru file-kku sumaar 40 nimisham bank statements, salary slips, bureau reports padikkiradhulaiyum, figures-a thirumba type panradhulaiyum, oru credit note ezhudhuradhulaiyum selavu pannaanga. Maasam 6,000 files-naa, adhu sumaar 4,000 officer-hours. Retype panrappo varra thappugalaala 7% files credit committee-la irundhu thirumba vandhuchu.

Head of operations-kku otthuppora numbers-oda vandhadhaala thaan indha reframe work aachu. Discovery numbers estimates thaan, adhanaala contract-kku munnaadiye team loan-system timestamps-la irundhu unmaiyaana baseline-a alandhuchu: naalu vaaram, 6,200 files-la median 41 nimisham.

### KPI, scope

- **KPI**: oru file-kku median officer time, pilot aarambichu patthu vaaratthukkulla 41-la irundhu 22 nimisham.
- **Guardrail**: rework 7%-a thaandakkoodaadhu. **Adoption**: officers avanga files-la kuranjadhu 80%-la draft-a use pannanum.
- **Scope-kkulla**: English PDFs, phone photos-la irundhu 24 fields, adhula 10 critical; oru draft credit note; oru review screen.
- **Scope-kku veliye**: credit decisions, customer features, matha mozhigal.

### Proof of concept: average maraichadhu

Golden set-naa aaru branches-la irundhu 300 masked pazhaiya files, rendu senior officers thanitthaniyaa label pannadhu. Avanga otthuppogaadha idatthula credit head mudivu pannaanga. 300 files-la patthu critical fields-naa score panna 3,000 values.

Ovvoru document-aiyum oru structured-output model call padichudhu, ovvoru value-um oru schema-va pass pannanum. Idhu oru pagudhi:

```python
from decimal import Decimal
from typing import Literal
from pydantic import BaseModel, Field, model_validator

class Source(BaseModel):
    page: int = Field(ge=1)
    text: str = Field(min_length=1)  # the exact words the value was read from

class Amount(BaseModel):
    rupees: Decimal | None  # None if the document does not show it
    source: Source | None
    confidence: Literal["high", "low"]

class SalarySlip(BaseModel):
    employer: str
    month: str = Field(pattern=r"^\d{4}-\d{2}$")  # for example 2026-06
    gross_pay: Amount
    net_pay: Amount  # critical field

    @model_validator(mode="after")
    def net_not_above_gross(self):
        g, n = self.gross_pay.rupees, self.net_pay.rupees
        if g is not None and n is not None and n > g:
            raise ValueError("net pay above gross pay: re-read or flag")
        return self
```

Moonu choices copy panna thagundhavai. Ovvoru value-um adhoda page-aiyum adhu vandha vaarthaigalaiyum koodave kondu varudhu, adhanaala oru officer sila seconds-la adha check pannalaam. Oru value illainaa adhu `None`, eppavume guess illa. "Net pay gross pay-a thaanda mudiyaadhu" maadhiri cross-checks, oru format check miss panra thappaana reads-a pidikkudhu. "Low" confidence-ngradhu model thannai patthi solra abhipraayam illa, adhu nambagamaanadhu illa. Adha rules set pannuchu: mosamaana image-quality score, fail aana oru cross-check, alladhu otthuppogaadha rendu reads.

Mudhal result 93%, 95% gate-kku keezha. Golden set-a document source vaariyaa pirichappo yen-nu therinjudhu:

| Slice | Score panna values | Mudhal run | Image clean-up-kku appuram |
| --- | --- | --- | --- |
| Net banking, HR systems-la irundhu vandha PDFs (180 files) | 1,800 | 98.0% | 98.0% |
| Phone photos (120 files) | 1,200 | 85.5% | 94.0% |
| Ellaa files | 3,000 | 93.0% | 96.4% |

Perumbaalaana misses, page muzhukka irunda nizhal vizhundha phone photos. Oru image clean-up step (neraa aakkuradhu, velicchattha samamaakkuradhu), low-confidence flag rendum adhula perumbaalaanadha sari pannuchu. Expert solra point-a kavaninga: mottha figure pass aachu, aanaa photos mattum thaniyaa innum pass aagala. Adhanaala gate note adha velippadaiyaa solluchu:

> **Gate 1, week 4.** Criteria: 300 files muzhukka 10 critical fields-la kuranjadhu 95%; ovvoru summary-um adhoda source pages-a cite pannanum. Result: mottham 96.4% (PDFs 98.0%, photos 94.0%); ovvoru summary-laiyum citations. Head of operations-oda mudivu: rendu conditions-oda pilot-kku pogalaam. Low-confidence flag eppavum on-la irukkum, photo slice ovvoru vaaramum thaniyaa report pannappadum.

### Pilot-kkaana engineering

Pilot system weeks 3, 4-la build aachu, proof of concept-oda kadaisi koodave. Lender-oda risk team erkanave oru Indian region-la avanga sondha Azure tenancy-a approve panniyirundhaanga, adhanaala pudhu vendor approval aarambikkaama, models andha tenancy vazhiyaa, oru fallback-oda oru gateway-kku pinnaadi use aachu. Service containers-la oduchu, CI-la evals, Entra ID vazhiyaa sign-on, ovvoru officer-oda branch padi documents filter, ovvoru view, edit-kkum oru audit log, traces-la personal data mask.

Risk team-oda kelvigal unga sondha velaikku oru useful list. Data enga store, process aagudhu? Provider adha models-a train panna use pannalaamaa? Endha files-a yaar paarkalaam? Edhu log aagudhu, evvalavu naal? Logs, eval set udpada ellaa idatthulaiyum oru customer-oda data eppadi azhikkappadudhu? FDE ovvonnukkum ezhutthula badhil sonnaanga, provider-oda published data-privacy terms-a oru link-oda quote panni, nyaabagatthula irundhu illa.

### Pilot: aalunga, scope, late-aana oru review

Anna Nagar, Tambaram-ngra rendu branches-la irubadhu officers patthu vaaram idha use pannaanga, oru weekly demo, oru risk log-oda.

- **Week 6.** Production security review schedule aagave illa. Adhe naal CIO office-kku escalate pannadhum, week 9-kku book aachu; production gate-a adhu block panniyirukkum nerattukku moonu vaaram munnaadi.
- **Week 7.** Adoption Anna Nagar-la 92%, Tambaram-la 41%. Endha figure thappaa irundhaalum "AI-o illaiyo" adhu officer-oda thappu-nnu branch manager solliyirundhaaru, adhanaala safe-aa irukka officers ellaatthaiyum thirumba type pannaanga. Officers edhukku poruppu-nnu head of operations ezhudhi kudutthaanga: week 8-la setha side-by-side review screen-a use panni, flag aana fields-aiyum critical fields-aiyum review panradhu. Thirumba training, oru regional summary template-oda, Tambaram rendu vaaratthula 85%-kku vandhuchu.
- **Week 7.** Ore vaaratthula moonu change requests vandhuchu. Collections summaries phase 2-kku pochu. PDF export-kku badhilaa Tamil salary slips swap pannappattu week 9-la ship aachu. Approve-or-reject recommendations decline aachu, yenna credit decisions scope-kku veliye.

Result: median 24 nimisham, 5.1% rework, 88% adoption. 22 nimisha target konjatthula miss aachu. Measures munnaadiye agree pannadhaala, client success-naa enna-nnu illaama rollout patthi pesunaanga.

### Rendu vaaratthai veenaakkuna thappaana thiruppam

Proof of concept-la kidaichadhulaye periya model ellaa page-aiyum padichudhu, yenna adhu thaan best-aa score pannuchu. POC report 300 files-la oru file-kkaana cost-a kaattuchu, adhu chinnadhaa therinjudhu. Retries-um, ovvoru page koodavum anuppura neelamaana fixed instructions-um serthu, maasam 6,000 files-kku yaarum adha perukki paarkala.

Week 10-la business case-kkaaga FDE full-volume projection-a build pannappo adha kandupidichaanga: maasam sumaar ₹14 lakh, adhaavadhu oru file-kku ₹233, aanaa oru file-kku value sumaar ₹173 thaan. Andha vilaiyila rollout nashtatthula thaan pogum.

Endha memo-vum ezhudhuradhukku munnaadi, andha vaara update-laye head of operations-kitta, oru fix plan-um oru thedhiyum kooda oru risk-aa sonnaanga. Weeks 11, 12-la team typed PDFs-a oru chinna model-kku anuppuchu, photos-kkum low-confidence pages-kkum mattum periya model-a vechudhu. Fixed instructions-a cache pannaanga, erkanave extract aana pages-a thirumba padikkiradha niruthunaanga. Golden set-a thirumba run pannappo accuracy-la endha izhappum illa. Cost maasam sumaar ₹9 lakh-kku, oru file-kku ₹150-kku kuranjudhu. Adhukku aana vilai rendu engineer-weeks, adha FDE-oda side etthukkichu, oru audit-report export mudhal rollout wave-kku thallippochu.

### Business case

CEO, CFO-kkaana memo, value-aiyum cost-aiyum ore unit-la compare pannuchu, oru file-kku 26 nimisham-ngra oru cautious planning figure-la. Officer time-kku lender-oda sondha HR figure-aana manikku sumaar ₹600, loaded, value pottaanga.

| Line | Maasatthukku |
| --- | --- |
| Michamaana neram: 6,000 files × 15 min = 1,500 hours × ₹600 | ₹9.0 lakh |
| Kuraivaa thirumba varra files: 114 × 2 hours × ₹600 | ₹1.4 lakh |
| Running cost, ellaam serthu | ₹9.0 lakh |
| Net value | Maasam ₹1.4 lakh, varushatthukku sumaar ₹16 lakh (pilot-oda 24 nimishatthula sumaar ₹31 lakh) |
| Break-even | Oru file-kku sumaar 13 nimisham micham |

Idhu oru modest case, memo-vum adha solluchu: Indian salaries-la michamaana neram running cost-a kashtappattu thaan cover pannudhu, margin quality-la irundhu thaan varudhu. Mudhal draft varushatthukku ₹50 lakh value-a maasatthukku ₹9 lakh cost kooda compare panniyirundhuchu, andha cost varushatthukku ₹1.08 crore. Meeting-kku mundhina naal CFO-oda analyst adha pidichaaru. Break-even line monthly report-la varanum-ngra condition-oda CFO moonu maadhaandhira waves-a approve pannaaru.

### Production, handover

Waves weeks 15 mudhal 18, 19 mudhal 22, 23 mudhal 26-la oduchu, kadaisi rendukkum FDE support pannaanga. Weeks 23 mudhal 26-la lender-oda engineers Karthik-um Divya-um mudhalla paartthaanga, appuram avanga paartthuttu irukkumbodhu ovvoru core task-aiyum ivangale senjaanga: oru release, oru rollback, CI vazhiyaa evals-oda oru prompt change, rendu simulated incidents. Appuram sign-off, avanga access remove, gateway keys rotate, moonu maasam escalation-only support.

Kadaisi wave mudinju moonu maasam kazhichu, 180 officers muzhukka numbers: median 25 nimisham, 5.3% rework, 84% adoption, maasam ₹8.7 lakh running cost. Adhu varushatthukku net sumaar ₹25 lakh. Photos adhigamaa irukkura rendu rural branches 29 nimishatthula irundhuchu, adhu thaan adutha velai.

## Podhuvaa panra thappugal

Ivai portfolio case studies-a moozhgadikkum, interviewers ivatha seekkirame kandupidichuduvaanga:

- **Karpanai numbers-a results-aa kaatturadhu.** Karpanai client-naa, unga discovery figures assumptions thaan. Adha label panni oru source kudunga. Unga sondha golden set-la irundhu varra numbers mattum thaan results.
- **"Efficiency-a 40% improve pannom".** Edhoda, endha baseline-la irundhu, eppadi alandhu, etthana cases-la? Number-a adhoda unit, baseline, sample-oda ezhudhunga.
- **Average mattum.** Oru accuracy figure fail aagura slice-a maraichudum. Document type alladhu source vaariyaana breakdown-a kaattunga.
- **Failure-e illaadhadhu, alladhu ore variyila solve aana failure.** Adha eppadi kandupidicheenga, nerattthulaiyo panatthulaiyo evvalavu selavaachu, client-kitta enna sonneenga-nnu sollunga.
- **Cost illaadha value.** Unga system oru case-kku ₹150 run panna selavaagudhu-nnaa, adhu michappadutthuradhukku pakkatthulaye, adhe unit-la adha sollunga.
- **Code link illa, alladhu yaaraalaiyum run panna mudiyaadha code.** Oru reviewer README-la irundhu unga evals-a thirumba run panna mudiyanum.
- **Ovvoru stage-aiyum ore neelatthula thirumba solradhu.** Process-a vivarikkiradhula illa, decisions-laiyum evidence-laiyum unga vaarthaigala selavu pannunga.

## Practice pannunga

Business context-kku FDE role patthina a16z essay-a padinga.

Indha lesson-oda check thaan capstone write-up. Oru public dataset-aiyum, ungalukku therinja oru Indian industry-la oru karpanai client-aiyum therndhedunga, udhaaranamaa oru hospital chain, oru logistics company, oru state department alladhu oru retailer. Indha lesson-oda shape-la rendu alladhu moonu pages ezhudhunga:

1. Numbers-oda discovery findings, ovvonnum adhoda source-oda assumption-nu label panni, udhaaranamaa oru published guide, oru annual report, alladhu andha velaiya seyyura oruttar kooda oru interview.
2. KPI, baseline, target, guardrail, exclusions-oda scope.
3. Unga golden set, adha eppadi label panneenga, kuranjadhu oru slice vaariyaa piricha results, adhu pass panna vendiya gate.
4. Adhoda governance choices-oda architecture: access, logging, masking, data enga pogudhu.
5. Assume panna monthly volume-la oru case-kkaana cost, oru case-kkaana value-kku edhiraa.
