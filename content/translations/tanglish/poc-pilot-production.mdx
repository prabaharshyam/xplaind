## Idhu enna

Oru AI engagement podhuvaa moonu stages-la nagarum:

- **Proof of concept (POC)**, 2-la irundhu 6 vaaram: idhu client-oda real data-la work aagumaa? Seekkiram build panni, pazhaya cases-la offline-aa run panni, evals-aala judge panradhu. Innum real users illa.
- **Pilot**, 6-la irundhu 12 vaaram: idhu real makkal-ku dinamum velaila help pannudhaa? Oru limited group safeguards-oda use pannum, neenga KPI-yum quality-yum adoption-aiyum measure pannureenga.
- **Production**: ninaichavanga ellarukkum rollout aagi, oru normal system-aa run panni support panni, client-oda team own pannum.

Ovvoru stage-kum naduvula oru **stage gate**: agree panna evidence-a review panni, client munnaadi poradhu, course maathuradhu, illa niruththuradhu-nu decide panra oru meeting.

```flow
dir: LR
POC, 2-6 vaaram | pazhaya cases offline, oru golden set-um evals-um, romba risky-aana assumption -> Gate 1: go, change illa stop?
Gate 1: go, change illa stop? -[go]-> Pilot, 6-12 vaaram | safeguards-oda real users, KPI, guardrails, adoption; sign-on, logs, security mudinjadhu
Pilot, 6-12 vaaram -> Gate 2: go, change illa stop?
Gate 2: go, change illa stop? -[go]-> Production | ellarukkum, waves-la; runbooks, on-call, dashboards; thodarndhu measure
```

Indha lesson, Chennai-la oru lender-oda credit-file assistant-a, adhoda mudhal offline test-la irundhu 180 officers-ku rollout varai follow pannum.

## Idhu eppadi work aagudhu

**POC.** Mudhalla romba risky-aana assumption-a target pannunga. Document extraction-ku, adhu perumbaalum "avanga real, messy documents-a accurate-aa padikka mudiyuma?", user interface illa. Real (thevaippadaa masked) data use pannunga, client-oda experts-oda oru golden set build pannunga, accuracy, failure types, oru case-ku cost, latency-a report pannunga. Polish-a vittudunga. Gate criteria SOW-la irundhu varum: example critical fields-la kurainjadhu 95% accuracy.

**Pilot.** Interest irukkavangala mattum illa, periya group-a represent panra users-a pick pannunga. Decisions-ku makkal-ae poruppu-aa irukkattum. Production-ku thevaiyaanadhu-a adhula irundhu kathukkura alavu early-aa serunga: sign-on, logging, monitoring, feedback buttons. KPI-a baseline-oda, guardrail measures-a, adoption-a vaaram-oru-thadava measure pannunga. Maathura-nu expect pannunga; adhu thaan point. Gate: KPI nagarndhirukkanum, guardrails nikkanum, users vechukka virumbanum, support-um security-um ready.

**Production.** Waves-la rollout pannunga (oru region, apram innum). Operations-a handover pannunga: runbooks, on-call, dashboards, training. Oru support period agree pannunga. Thodarndhu measure pannunga; production-um evaluation-oda mudivu illa.

**Stop panradhu oru valid outcome.** Documents padikka mudiyaadhu-nu kaattura oru POC, illa users tool-a ignore panra oru pilot, selavu kammiyaa nindru yen-nu explain panna, velaiya mudichuduchu. Ezhudhi vainga; kathukkiradhu valuable.

**Pilot purgatory-a thavirunga.** Podhuvaana kaaranangal: agree panna gate criteria illa, business owner illa, production requirements (security, integration) pilot-ku apram-nu vittuduradhu, rollout-ku budget plan pannaama irukkaradhu. Naalaiyum SOW-la address pannunga.

**Ovvoru stage-kum gate evidence:**

| Gate | Review panra evidence | Podhuvaana criteria |
| --- | --- | --- |
| POC-la irundhu pilot-ku | Golden-set accuracy, failure types, oru case-ku cost, latency | Critical fields-la kurainjadhu 95%; therinja failures handle aagirukkanum |
| Pilot-la irundhu production-ku | Baseline-oda KPI, guardrails, adoption, user feedback, security sign-off | KPI nagarndhadhu; guardrails nindradhu; users virumbuvaanga; support ready |
| Production-la | Maasaandhira KPI, cost, incidents | Usage valarumbodhum results nikkudhu |

**Oru gate meeting-a nadathuradhu.** Meeting-ku rendu naal munnaadi evidence pack-a anuppunga: agree panna criteria, adhukku pakkaththula measure panna results, mukkiya failures-um fixes-um, cost, oru recommendation. Meeting-la, criteria-vai oru-oruvaa paarthu, business owner-a go, change illa stop-nu decide panna sollunga. Decision-aiyum conditions-aiyum andha naalae ezhudhthula record pannunga. Munnaadiyae criteria agree aana oru gate short-aa mudiyum; illaadha gate success-na enna-ngradha pathi oru debate-aa maarum.

**Oru stop-a ezhudhuradhu.** Evidence stop-nu sonnaa, rendu pages ezhudhunga: enna test pannom, enna kandupidichom, ippo yen work aagala, enna maaranum, example nalla scans illa veru process. Nermaiyaa, selavillaama niruththuna team-a clients nyaabagam vechukkuvaanga, aadikkadi adutha project-a avangakitta kondu varuvaanga.

## Oru worked example

Chennai lender-oda credit-file assistant:

**POC, vaaram 1-la irundhu 4.** 300 pazhaya files, masked. Critical-field accuracy 93%, 95% gate-ku keezha. Error analysis: perumbaalaana misses nizhal vizhundha bank statements-oda phone photos-la. Oru image clean-up step-um oru "low confidence, please check" flag-um serkkureenga; accuracy 96.4%-ku uyarudhu. Gate pass, confidence flag pilot design-la serkkapatturukku.

**Pilot, vaaram 5-la irundhu 14.** Rendu branches-la 20 officers. Vaaram-oru-thadava numbers: oru file-ku median time 41-la irundhu 24 nimidama kuraiyudhu; rework 7% baseline-ku 5.1%; adoption 88%. Officers document-um extracted fields-um pakkaththula pakkam paarka oru view kekkuraanga, adha vaaram 8-la serkkureenga. Security review-um sign-on-um pilot-ku apram illa, pilot-oda podhae mudikkapadudhu. Gate pass.

**Production, vaaram 15-la irundhu.** 180 officers-ku, ovvondrum oru maasam-aa moonu waves-la rollout. Lender-oda IT team ungaloda runbook-um dashboards-um vechu system-a run pannum; neenga ettu vaaram support tharureenga. Maasaandhira KPI reports thodarum.

| Stage | Result | Decision |
| --- | --- | --- |
| POC, vaaram 1-la irundhu 4 | Critical fields-la 93%, apram image clean-up-um confidence flag-um serthu 96.4% | Gate pass; flag pilot-la serkkapattadhu |
| Pilot, vaaram 5-la irundhu 14 | Oru file-ku 41-la irundhu 24 nimidam; rework 5.1%; adoption 88%; security-um sign-on-um mudinjadhu | Gate pass |
| Production, vaaram 15-la irundhu | 180 officers-ku moonu maasaandhira waves; client IT ettu vaaram support-oda run panraanga | Maasaandhira KPI reports thodarum |

## Podhuvaa panra thappugal

- **Clean sample data-la polish panna POC.** Real documents pathi edhuvum prove pannaadhu.
- **Gate criteria illaadha pilots.** Mudiyavae mudiyaadhu, scale-um aagaadhu.
- **Security-yum integration-aiyum pilot-ku apram-nu vittuduradhu.** Romba mosamaana neraththula maasakkanakkula serkkum.
- **Pilot-la nalla-avanga mattum users-aa irukkradhu.** Matha ellarukkum results nikkaadhu.
- **"Stop"-a failure-nu nenaikkiradhu.** Selavu kammiyaa, nalla reasoning-oda oru stop oru nalla outcome.

## Practice pannunga

GOV.UK-oda alpha, beta, live phases guides-a padichu, AI velaiku enna porundhum-nu note pannunga.

1. Ungaloda use case-ku POC plan ezhudhunga: romba risky-aana assumption, data, golden set, measures, gate criteria.
2. Pilot plan ezhudhunga: users, safeguards, vaaram-oru-thadava measures, mudivukkulla production-ku enna ready-aa irukkanum, gate criteria.
3. Rollout plan ezhudhunga: waves, handover, support period, neenga pause panna vaikkura vishayam.

**Mudinjadhu-nu eppo sollalaam:** Moonu stages-um ovvoru gate-layum thevaiyaana evidence-um irukkura oru-page plan-a kaattamudiyum.
