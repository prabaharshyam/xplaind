## Idhu enna

**Prompt**-na AI assistant-kitta neenga type panra edhuvum. Nalla prompts ezhudha special tricks, magic phrases, technical words thevai illa. Nalla prompt, podhuvaa neraya theriyum aana unga situation pathi onnume theriyaadha oru capable pudhu colleague-kku kudukkura clear brief maadhiri irukkum.

Naalu simple pazhakkangal prompts work aagurathula perumbaalum cover pannum:

```flow
dir: LR
1. Context | who you are, who it's for, why, the facts. Always -> 2. Example | show what good looks like. When you can
2. Example -> 3. Format | length, structure, tone, language. Always
3. Format -> 4. Feedback | read it, ask for specific changes. Always
```

Indha pazhakkangal periya vithiyaasam pannum. One-line request generic answer thaan tharum, yenna assistant ellathayum guess pannanum. Nalla brief first try-laye use panra alavukku close-aa kidaikkum.

Indha lesson Ravi-ya follow pannum. Avar Coimbatore-la oru tuition centre nadathuraar, oru vague request-a parents-ku anuppura message-aa maathuraar. Mudiyum podhu, naalu pazhakkangalayum yosikkaamalae use pannuveenga.

## Idhu eppadi work aagudhu

### Pazhakkam 1: context kudunga

Neenga yaar, answer-a yaar padippaanga, unga situation facts enna-nu assistant-ku theriyaadhu. Adha sollunga.

| Weak | Strong |
| --- | --- |
| "Write a leave application." | "I'm a nurse at a hospital in Madurai. Write a short, polite leave application to my head nurse for three days next week, 12 to 14 November, for my sister's wedding. I have already arranged for a colleague to cover my shifts." |

Strong version padikkaravanga, dates, reason, oru nambikkai tharura detail-a kudukkudhu. Assistant edhaiyum karpanai pannanum-nu illa, adhanaala edhaiyaavadhu ezhudhi vaikka chance-um kammi.

### Pazhakkam 2: oru example kaattunga

Ungalukku pidicha pazhaya email, report, message irundha, private details-a eduthuttu paste panni, "indha style-la ezhudhu"-nu sollunga. Style-a words-la describe panradhai vida examples nalla work aagum, yenna model patterns-a copy panradhula romba nalla. Model pattern-a follow panna konjam input-and-output examples kudukkaradhukku **few-shot prompting**-nu peyar.

```text
  Example 1:  Product: steel water bottle  ->  "Stays cold 24 hours. Built for Chennai summers."
  Example 2:  Product: cotton kurta         ->  "Breathes in the heat. Looks sharp at work."
  Now write:  Product: jute tote bag        ->  ?
```

### Pazhakkam 3: format kelunga

Enna thirumba vennum-nu exact-aa sollunga. Format instructions ezhudha easy, neraya editing migum:

- "five bullet points"
- "under 120 words"
- "a table with columns: item, cost, notes"
- "in simple Tamil, then the same in English"
- "formal but warm"
- "start with the recommendation"

### Pazhakkam 4: specific feedback kudunga

Mudhal answer oru draft. Padichu, enna maathanum-nu exact-aa sollunga:

| Vague feedback | Specific feedback |
| --- | --- |
| "Make it better." | "Cut it to 80 words and drop the second paragraph." |
| "That's wrong." | "Our office closes at 6, not 7. Fix the timing." |
| "Too formal." | "Write it the way you'd text a colleague you like." |

Rendu moonu round specific feedback pona, perumbaalum sari aagidum.

### Vera useful moves

- **Munnaadi ungalai kelvigal kekka sollunga:** "Ezhudhradhukku munnaadi, unakku theriya vendiyadha ennai kelu." Idhu pala neram oru round feedback-a migutthum.
- **Options kelunga:** "Moonu vera vera subject lines kudu."
- **Unga yosanai-a check panna sollunga:** "Indha plan-la enna thappaa irukkalaam?"
- **Periya velaiya steps-aa piringa:** mudhal outline kelunga, adhai otthukkonga, appuram ovvoru section-a kelunga.

### Evvalavu serkkalaam

Ovvoru model-kum oru **context window** irukku: oru thadava ulla eduthukka mudiyura text alavu, unga prompt, paste panna documents, ippo varaikkum nadandha conversation serthu. Ippodhaiya assistants neraya, perumbaalum nooru pages, vachukkum, aana romba neenda conversations-la drift aagalaam. Assistant unga munnaadi instructions-a marandhudha, pudhu chat aarambichu mukkiyamaana points-a thirumba sollunga.

### Edhai share pannaakoodaadhu

Passwords, Aadhaar, PAN illa bank details, confidential work information-a prompts-la podaadheenga, unga organisation andha tool-a andha vagai data-kku approve pannina thavira.

## Oru worked example

Ravi Coimbatore-la 8-la irundhu 10 varaikkum classes-ku oru chinna tuition centre nadathuraar. Pudhu weekend batches-a arivikka oru WhatsApp message venum.

**Mudhal try:**

> "Write a message about weekend classes."

Result 180 words, generic, "all subjects", "expert faculty"-nu solludhu, aindhu emojis irukku. Use panna mudiyaadhu.

**Rendavadhu try, context-um format-um:**

> "I run a tuition centre in Coimbatore for classes 8 to 10, maths and science. Write a WhatsApp message to parents announcing new weekend batches starting 7 December, Saturday and Sunday, 9 to 11 am. Fees ₹1,500 a month. Seats limited to 15. Keep it under 80 words, friendly, with at most one emoji. Write it in English, then the same in simple Tamil."

Result close-aa irukku. Ravi **specific feedback** kudukkuraar:

> "Mention that the first class is a free trial, and put the phone number 98xxxxxx21 at the end of both versions."

Moonavadhu version ready. Anuppradhukku munnaadi, Tamil kathukudukkura thangachchi-kitta Tamil wording-a check panna sollraar. Avanga oru word-a sari pannuraanga.

| Version | Use panna pazhakkangal | Use panna mudiyuma? |
| --- | --- | --- |
| 1 | Onnum illa | Illa: generic, romba neelam |
| 2 | Context, format | Konjam: rendu details miss |
| 3 | Context, format, feedback | Aama, Tamil check-ku apram |

Mothha velai sumaar aindhu nimishathula mudinjadhu, message-la irundha ovvoru fact-um Ravi-kitta irundhu vandhudhu, assistant-oda karpanai-la irundhu illa.

## Podhuvaa panra thappugal

- **One-line requests.** Context-um format-um serkkunga; muppadhu vinaadi aagum.
- **Mudhal answer-a appadiyae edukkaradhu.** Adha draft-aa pathu feedback kudunga.
- **Vague feedback.** "Nalla pannu"-nu solradhai vida "chinnadhaa, kammi formal-aa"-nu solradhu romba help pannum.
- **Style-a kaattaama describe panradhu.** Example irundha paste pannunga.
- **Private data-va share panradhu.** Tool approve aagala-na peyargal, numbers, confidential details-a eduthudunga.
- **Nalla prompt facts-a guarantee pannum-nu nenaikkiradhu.** Nalla prompts answers-a improve pannum, ellaa neramum sari-nu aakkaadhu. Mukkiyamaana facts-a check pannunga.

## Practice pannunga

Anthropic-oda free AI Fluency course-a edunga, keezha link irukku, illa OpenAI Academy-oda beginner sessions-a paarunga.

1. **Weak-aa aarambinga.** Unga vaaraththula oru real task-a edunga, oru message, plan, illa explanation. One-line prompt ezhudhi answer-a save pannunga.
2. **Pazhakkangalai use pannunga.** Context, irundha oru example, format-oda prompt-a thirumba ezhudhunga. Pudhu answer-a save pannunga.
3. **Feedback kudunga.** Rendu round specific feedback kudutthu, moonu versions-ayum pakkathula vachu compare pannunga.

**Mudinjadhu-nu eppo sollalaam:** One-line prompt-um unga improved prompt-um pakkathula kaatti, edhu vithiyaasatha kuduthadhu-nu explain panna mudiyum.
