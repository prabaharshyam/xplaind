## Idhu enna

**Convolutional neural network (CNN)** padam mela slide aagura small learned filters vechu images-a process pannum. Mudhal layers edges-aiyum textures-aiyum kathukkum; appuram layers avatrai serthu shapes, objects-a uruvaakkum. Image-la ellaa idathulayum adhe filter use aagradhunaala, CNNs nallaa efficient-aa kathukkum, patterns enga vandhaalum recognise pannum.

**Transfer learning**, lakhs kanakkaana general images-la already train aana CNN (illa vision transformer)-la irundhu aarambichu, ungaloda task-ku adapt pannum. Scratch-la irundhu train panradhai vida romba kammi data-um neramum podhum, perumbaalum nalla results kudukkum.

```flow
dir: LR
Image, 224x224 -> Conv: edges | neraya chinna maps, 3x3 filters -> Conv: textures | pooling maps-a sirusaakkum
Conv: textures -> Conv: parts | perusaana regions -> Classifier | "slub defect" 0.91
```

```flow
dir: LR
title: Transfer learning
Pre-trained layers, frozen -> Pudhu final layer, train aagudhu -[venumna]-> Chinna learning rate-oda last blocks-a unfreeze pannunga
```

Indha lesson, Pune-la oru textile factory-la nadakkura fabric-defect project-a follow pannum.

## Idhu eppadi work aagudhu

**Convolution, pooling.** Oru filter (ex: 3 × 3 pixels) adhukku keezha irukkura pixels-a multiply panni sum pannum, adhoda pattern enga irukku-nu oru map kudukkum. Oru layer-la neraya filters irundhaa neraya patterns kandupidikkum. Pooling illa strided convolutions maps-a sirusaakkum, adhanaala aazhamaana layers perusaana regions-a paakkum.

**Classic architectures.** ResNet, EfficientNet, matravai nallaa test aanavai, pre-trained-aa kidaikkum. Vision transformers pudhu alternative; rendumae practice-la use aagum.

**Transfer learning steps.**

1. Oru pre-trained model-a load pannunga.
2. Adhoda final layer-a ungaloda classes-ku porundhura layer-aa maathunga.
3. Mudhalla munnaadi layers-a freeze panni pudhu layer-a train pannunga; apram venumna sila illa ellaa layers-aiyum unfreeze panni, chinna learning rate-la train pannunga (fine-tuning).

**Data augmentation.** Random flips, crops, rotations, brightness, colour maatrangal training images-oda vera vera versions-a uruvaakki, overfitting-a kuraikkum. Unmaiya porundhura augmentations-a choose pannunga: leaf photos-a rotate pannalaam, aana text documents-a flip pannaadheenga.

**Image data quality.** Unmaiyaana images-la velicham, angle, background, camera maarum. Production images maadhiri irukkura training images collect pannunga (oru shop-la eduththa phone photos studio photos maadhiri irukkaadhu). Labels-a check pannunga; thappaa label panna images neenga ninaikkiradhai vida adhigam hurt pannum.

**Evaluation.** Generalisation-a test panna, vera naal, vera devices, vera idangal-la irundhu images-a thaniyaa vechukkunga. Confusion matrix-aiyum thappaa classify aana images-aiyum paarunga; adhu adikkadi label errors-aiyum, illaadha conditions-aiyum (raathiri, mazhai, blur) kaattum.

**Classification-a thaandi.** Object detection (ovvonnum enga irukku), segmentation (entha pixels edhukku sondham), OCR ellaam ottra architectures-a use pannum, adhuvum perumbaalum pre-trained models-la irundhu fine-tune aagum.

**Scratch vs transfer learning:**

| Approach | Thevaiyaana data | Neram | Chinna datasets-la typical result |
| --- | --- | --- | --- |
| Scratch-la irundhu train | Pathu aayiram images illa adhukku mela | Neenda | Weak |
| Transfer learning, frozen backbone | Nooru-la irundhu sila aayiram | Kammi | Nallaa |
| Last blocks-a fine-tune panradhu | Sila aayiram | Naduthara | Adikkadi best |

**Oru filter enna compute pannudhu.** 3 × 3 filter-la onbadhu learned weights irukkum. Ovvoru position-layum adhai keezha irukkura onbadhu pixels-oda multiply panni, results-a oru number-aa serkkum. Image mela slide panna, filter-oda pattern enga irundhaalum, ex: oru vertical edge, angae bright-aa irukkura map kidaikkum. 64 filters irukkura layer 64 maps-a kudukkum, adutha layer avatrai serthu innum complex patterns-a uruvaakkum.

**Confusion matrix-a padikkradhu.** Accuracy mattum entha classes kuzhambudhu-nu maraikkum. Confusion matrix ovvoru unmaiyaana class-kum, model ovvoru class-a evvalavu thadavai predict pannichu-nu kaattum. Fabric project-la "slub", "thick place" defects adikkadi maari maari vandhadhu, "hole" kittathatta oru thadavai kooda miss aagala-nu adhu kaattuchu. Idhu team-ku engae neraya examples collect pannanum, engae oru inspector-oda second look romba mukkiyam-nu sonnadhu. Confidence-padi sort panna irubadhu thappaa classify aana images-a kannaala paakkuradhu, entha oru number-aiyum vida adhigam kathukkum.

**torchvision-oda transfer learning.** Pretrained network-a load panni, final layer-a maathi, rendu phases-la train pannunga:

```python
import torch
from torch import nn
from torchvision import models, transforms

weights = models.ResNet18_Weights.DEFAULT
model = models.resnet18(weights=weights)              # downloads pretrained weights once
for p in model.parameters():
    p.requires_grad = False                           # phase 1: freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 6)         # six defect classes

train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.7, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.3, contrast=0.3),      # shop lighting varies
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
eval_tf = weights.transforms()                        # the exact resize and normalisation used in pretraining

opt = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)
# ... train a few epochs on the head only ...

# Phase 2: unfreeze the last block and fine-tune gently
for p in model.layer4.parameters():
    p.requires_grad = True
opt = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-4},
    {"params": model.fc.parameters(), "lr": 1e-3},
], weight_decay=1e-4)
```

Unmaiya porundhura augmentations-a choose pannunga: flips leaves-ku, fabric-ku sari, aana labels-la irukkura text-ku, illa left-vs-right defects-ku thappu.

**Class-padi results-um, romba mosamaana thappugalum.**

```python
from sklearn.metrics import classification_report, confusion_matrix

def evaluate(model, loader, class_names):
    model.eval(); ys, ps, losses = [], [], []
    with torch.no_grad():
        for xb, yb in loader:
            out = model(xb)
            ys += yb.tolist(); ps += out.argmax(1).tolist()
            losses += nn.functional.cross_entropy(out, yb, reduction="none").tolist()
    print(classification_report(ys, ps, target_names=class_names, digits=3))
    print(confusion_matrix(ys, ps))
    return sorted(range(len(losses)), key=lambda i: -losses[i])[:30]   # indices of the most confident mistakes
```

Mudhalla romba adhiga loss irukkura 30 images-a paarunga: adhu adikkadi thappaa label aanavai, blurry-aanavai, illa oru vinodhamaana camera-la edutthavai-aa irukkum, adhai fix panradhu tuning-a vida adhigam help pannum.

**Random-aa mattum illa, source-padi piringa.** Photos pala shops, phones-la irundhu vandhaa, ovvoru shop-oda images-aiyum oru split-layae vechukkunga. Illana model defect-a illa, oru shop-oda backgrounds-aiyum velichathaiyum kathukkum.

**Model enna paakkudhu-nu paarunga.** Grad-CAM oru prediction-a ottina image regions-a highlight pannum. Highlight watermark-la illa table-oda edge-la irundhaa, model oru shortcut kathukkittu irukku-nu artham.

## Oru worked example

Pune fabric-defect project-a thodarndhu: rendu factory lines-la irundhu, aaru defect types-la 4,800 labelled images.

- Scratch-la train aana chinna CNN: 71% validation accuracy.
- Pre-trained ResNet-50, pudhu final layer, frozen backbone, 5 epochs: 86%.
- Kadaisi rendu blocks-a, pathil onru learning rate-oda unfreeze panni, augmentations-oda (flips, chinna rotations, brightness maatrangal): 93%.

Validation, training-la irundhu vera vaaram-la irundhu vandha images-a use pannichu. Confusion matrix perumbaalaana errors "slub", "thick place" defects-ku idaila-nu kaattuchu; 60 thappaa classify aana images-a review pannaa 14 thappaa label aanadhu kandupidichaanga. Labels-a fix panni retrain pannaa, 94.5%.

Deployment-ku munnaadi, velicham vera irukkura rendaavadhu factory line-la irundhu 300 images-la test pannaanga: 88%. Andha line-la irundhu 400 images-a training-la serthaanga, angayum 93% kidaichudhu, adhukku keezha irukkura confidence threshold-a vechaanga, adhukku keezha irukkura images oru human inspector-kitta pogum.

| Step | Validation accuracy |
| --- | --- |
| Scratch-la chinna CNN | 71% |
| Pre-trained ResNet-50, frozen, pudhu final layer | 86% |
| Kadaisi rendu blocks fine-tune, augmentation-oda | 93% |
| 14 thappaa label aana images-a fix pannadhukku apram | 94.5% |
| Rendaavadhu factory line, adhoda images serkkaama | 88% |
| Rendaavadhu line, adhoda 400 images serthadhukku apram | 93% |

Labels-um rendaavadhu line-oda velichamum architecture-a vida kammi mukkiyam illa.

## Podhuvaa panra thappugal

- **Konjam data-vodu scratch-la irundhu train panradhu.** Transfer learning use pannunga.
- **Unmaiyilla augmentations.** Unmaiyaana images maarura vazhila augment pannunga, velicham, angle, blur maadhiri; avai eppavume maaraadha vazhila illa.
- **Training images-oda near-duplicates-la validate panradhu.** Naal, device, idam-padi piringa.
- **Thappaa classify aana images-a ignore panradhu.** Avai label errors-aiyum illaadha conditions-aiyum kaattum.
- **Production-la confidence threshold illaama irukkuradhu.** Uncertain images-a force panni guess panna vaikkaama, inspector-kitta anuppunga.
- **Serving-la pretrained model-oda preprocessing-ku vera preprocessing.**
- **Label-a maathura augmentations**, left-right defects-a flip panradhu maadhiri.
- **Shops, devices muzhukka random splits**, adhu scores-a oodhidum.

## CNN answer illaadha idangal

- **Vision-language model, prompt vechae andha task-a seiyum**, receipt padikkuradhu, damage-a describe panradhu maadhiri, ungaloda volume-layum selavulayum.
- **Romba kammiyaana labelled images, innum kidaikkavum vazhi illa**: few-shot vision model illa rules-la irundhu aarambinga.
- **Signal pixels-la illa, metadata-la irukku**, sensor readings, time stamps maadhiri.

## Demo-la irundhu production-ku

- **Training-layum serving-layum adhe preprocessing**, model-oda save panni.
- **Class-padiyum source-padiyum (shop, device, naal) evaluate pannunga.**
- **Adhiga loss irukkura images-a review panni**, tuning-ku munnaadi labels-a fix pannunga.
- **Production-la image quality-a monitor pannunga:** blur, brightness, resolution.
- **Low-confidence predictions-ku oru human check** vechukkunga.
