## Idhu enna

**Synthetic data**-na unmaiyaana makkal-kitta irundhu collect pannaama, oru model illa program uruvaakkura data. Oru periya model-a 5,000 customer questions ezhudha sollalaam, English examples-a Marathi-ku translate panna sollalaam, support tickets kuvyal-a label panna sollalaam, illa oru evaluation-ku test cases ezhudha sollalaam.

**Distillation** idhoda oru mukkiyamaana use. Oru sirusaana **student** model, oru periya **teacher** model-a oru task-la copy panna train aagum, teacher-oda answers-a training data-vaa vechu. Goal: romba cheap-aanavum vegamaanavum, andha task-la teacher-ku kittathatta quality-oda irukkura oru model. Oru therinja aarambaththu example, DistilBERT, adhoda teacher-oda language-understanding thiramaila sumaar 97%-a vechitu, 40% sirusaa, 60% vegamaa irundhudhu.

Teams, aindhu mukkiya kaaranangalukku synthetic data use pannuvaanga:

- **Quantity.** Unmaiyaana labelled data collect panna mella, selavu. Oru model oru manineraththula aayirakkanakkaana examples tharum.
- **Coverage.** Arudhaana cases-ku examples-a venumnae uruvaakkalaam: vithyaasamaana complaints, romba neelamaana inputs, tricky edge cases, illa testing-ku attacks.
- **Quality.** Sila neram oru strong model, avasaramaa velai seiyra human team-a vida consistent-aana labels illa kashtamaana questions ezhudhum.
- **Privacy.** Patient files, insurance claims maadhiri unmaiyaana records-a use panna mudiyaadha podhu, unmaiyaa maadhiri irukkura made-up records, adhukku badhila use aagalaam.
- **Distillation.** Oru cheap model, oru selavaana model-la irundhu oru task-a kathukkalaam.

```flow
title: Synthetic data-va uruvaakki use panradhu
Unmaiyaana seed examples | konjam nooru, check pannadhu
Unmaiyaana seed examples -> Strong model-oda generate pannunga | paraphrase, translate, label, create
Strong model-oda generate pannunga -> Filter panni verify pannunga | duplicates, length, judges, tests
Filter panni verify pannunga -> Podhumaana sample-aa?
Podhumaana sample-aa? -[illa]-> Prompt illa seeds-a fix pannunga
Prompt illa seeds-a fix pannunga -> Strong model-oda generate pannunga
Podhumaana sample-aa? -[aama]-> Unmaiyaana data-oda kalakkunga | ellaam synthetic-aa irukka koodaadhu
Unmaiyaana data-oda kalakkunga -> Student model-a train pannunga
Student model-a train pannunga -> Unmaiyaana, paakkaadha data-la test pannunga | final judge
```

## Idhu eppadi work aagudhu

**Generate panra vazhigal.** Podhuvaana methods, simple-la irundhu adhigam ilakkanam varaikkum:

1. **Templates-um rules-um.** "I booked [service] on [date] and want a refund" maadhiri template-a values list-oda nirappunga. Cheap, predictable, aana thirumba thirumba ore maadhiri irukkum.
2. **Paraphrasing.** Oru model-kitta oru unmaiyaana example-a koduthu, pala vidhamaa maathi ezhudha sollunga. "How do I cancel my ticket?" nu irundhu "I want to cancel my booking", "Ticket cancel kaise karu?" aagum. Arudhaana classes-a valarkka idhu nalla vazhi.
3. **Translation.** Neraya data irukkura oru language-la irundhu, English maadhiri, kammiyaa data irukkura oru language-ku, Kannada maadhiri, examples-a translate pannunga. **Back-translation**-vechu quality-a check pannunga: result-a vera model-aala thirumba English-ku translate pannitu, original-oda compare pannunga. Perusa maarina, andha example-a thookki podunga.
4. **Labelling.** Label illaadha unmaiyaana data-va label panna oru strong model-a sollunga. Idhu perumbaalum romba value-aanadhu, yen-na inputs unmaiyaana-vaa irukkum, labels mattum thaan model uruvaakkum.
5. **Simulation.** Oru model customer-aa, innoru model support agent-aa nadikkattum; training illa testing-ku muzhu conversations uruvaagum.
6. **Instruction generation.** Kaiyaala ezhudhina sirusaana tasks set-la irundhu aarambichu, adhe style-la pudhu tasks-yum answers-yum kandupidikka oru model-a sollunga. Sila aarambaththu open instruction datasets ippadi thaan build aachu.

**Train panradhukku munnaadi verify pannunga.** Model uruvaakkina data-la thappugal irukkum, adhanaala filtering optional illa.

- **Mudinjaa odi paarunga.** Code-a tests-oda ottalaam, SQL-a oru sample database-la ottalaam. Otti check panna mudiyura data thaan generate panna romba safe; adhanaala thaan code romba common synthetic data vagaiyil onnu.
- **Oru judge use pannunga.** Oru LLM judge ovvoru example-yum ezhudhina quality rules-oda score pannum, illa off-topic-aa irukkura, illa made-up facts irukkura examples-a flag pannum.
- **Simple filters podunga.** Exact-aanavum near duplicates-um, romba sirusaana illa romba neelamaana examples-um, output input-a thirumba solra examples-um, adhe question-ku mothara answers irukkura examples-um remove pannunga.
- **Oru sample-a neengalae padinga.** 100 random examples-a padikka muppadhu nimisham, entha filter-aalayum pidikka mudiyaadha problems-a pidikkum.

Oru sirusaana filter script adippadai-a cover pannum:

```python
import json
from difflib import SequenceMatcher

def keep(ex, seen):
    q, a = ex["input"].strip(), ex["output"].strip()
    if not (5 <= len(q.split()) <= 120):        # too short or too long
        return False
    if a.lower() == q.lower() or q.lower() in a.lower():  # output repeats the input
        return False
    for s in seen[-500:]:                        # near-duplicate of a recent example
        if SequenceMatcher(None, q.lower(), s).ratio() > 0.9:
            return False
    seen.append(q.lower())
    return True

seen, kept = [], []
for line in open("generated.jsonl"):
    ex = json.loads(line)
    if keep(ex, seen):
        kept.append(ex)
print(f"kept {len(kept)} examples")
```

**Oru task-a distil panradhu.** Teacher-a, unga task-oda neraya unmaiyaana inputs-la ottunga, adhoda answers-a (filter pannitu) vechukkunga, andha pairs-la oru sirusaana model-a fine-tune pannunga. Student-a, adhu paakkaadha, kaiyaala label pannina unmaiyaana data-la test pannunga, adhe test-la teacher-oda compare pannunga.

| Method | Edhukku nallaa | Mukkiya risk |
| --- | --- | --- |
| Templates-um rules-um | Simple formats, sudaana test cases | Thirumba thirumba varra, unmaiyaana madhiri illaadha text |
| Paraphrasing | Arudhaana classes-a valarkka, vidha vidhamaana wording | Users unmaiyaa ezhudhura vidhathula irundhu vilagum |
| Back-translation-oda translation | English-la irundhu Indian-language data | Users pesaadha, irukkamaana, formal language |
| Unmaiyaana inputs-a model label panradhu | Classification, extraction | Teacher-oda thappugal student-oda thappugal aagum |
| Simulation | Pala-turn conversations, agent testing | Rendu pakkamum oru model maadhiri pesum |
| Distillation | Oru task-ku cheaper, vegamaana model | Skill illaama style-a copy pannum |

## Oru worked example

Gurugram-la oru travel company, maadham 50,000 support messages-a refund, date change, baggage maadhiri 20 intents-aa sort pannudhu. Oru periya model, 500 hand-labelled messages-la 94% accuracy-la pannudhu, aana maadham ₹1.2 lakh selavu.

Pazhaya 20,000 unmaiyaana messages-a eduthu, names, phone numbers, booking IDs-a mask pannitu, periya model-a label panna sollraanga. Oru support lead 300 labels-a check pannitu, 93% sariyaa irukku-nu kandupidikkiraanga; perumbaalaana thappugal, guide sariyaa describe pannaadha rendu intents-la. Guide-a fix pannitu, andha rendu intents-a thirumba label pannitu, thirumba check pannuraanga.

Visa refund-um serthu moonu intents-ku, ovvonnukkum 30-kum kammiyaa thaan unmaiyaana examples irukku. Idhukku, periya model-a ovvoru unmaiyaana example-yum English, Hindi, Hinglish-la anju vidhamaa paraphrase panna sollitu, duplicates-a filter pannitu, oru sample-a oru aal check pannuraanga. Synthetic examples final 21,500-la sumaar 10%.

Oru sirusaana open-weight model-a labelled set-la fine-tune pannitu, training-ku use pannaadha original 500 messages-la test pannuraanga.

| Option | 500 unmaiyaana messages-la accuracy | Romba weak-aana intent | Maadha selavu |
| --- | --- | --- | --- |
| Periya model, prompted | 94% | 85% (visa refund) | ₹1.2 lakh |
| Sirusaana model, unmaiyaana labels mattum | 90% | 52% (visa refund) | ₹9,000 |
| Sirusaana model, unmaiyaana labels + synthetic arudhaana intents | 93% | 81% (visa refund) | ₹9,000 |

Numbers, eppadi compare panradhu-nu kaattura example-kaaga thaan. Synthetic examples perumbaalum arudhaana intents-ku help pannuchu. Sirusaana model-ku urudhi illaadha messages-ku, team periya model-a fallback-aa vechukkuranga, ovvoru maadhamum pudhu unmaiyaana, kaiyaala check pannina messages-oda oru sample-a training set-la serkkuraanga.

## Podhuvaa panra thappugal

- **Check pannaadha output-la train panradhu.** Garbage in, garbage out. Filter pannunga, verify pannunga, oru sample-a padinga.
- **Synthetic data-la test panradhu.** Final test, training-la use pannaadha unmaiyaana data-vaa irukkanum. Illa-naa student users-ku evvalavu useful-nu illa, teacher-a evvalavu nallaa copy pannudhu-nu thaan alakkureenga.
- **Muzhumaiyum synthetic-aa pogradhu.** Models-a thirumba thirumba model uruvaakkina data-la train panna **model collapse** varalaam: arudhaana cases maraiyum, thappugal kuvindhu pogum. Unmaiyaana data-va kalandhu vechukkunga.
- **Student teacher-a thaandum-nu edhirpaakkradhu.** Distill pannina model, andha task-la teacher-a thaandradhu arudhu. Teacher weak-aa irundhaa mudhalla adha fix pannunga.
- **Terms of use-a pakkam thalluradhu.** Neraya providers, thangaloda outputs-a poti models-a train panna use panna anumadhikka maattaanga. Terms-a padinga, edhu model edhu data-va uruvaakkunadhu-nu record pannunga.
- **Data enga irundhu vandhadhu-nu marakkradhu.** Teacher oru benchmark-la train aanaa, adhula unga student-oda score contaminate aagiyirukkalaam.

## Model uruvaakkina data-oda ellaigal

- **Skill illaama style.** Valimaiyaana models-a copy panna train pannina models-a pathina research, avai style-a nallaa copy pannum, aana facts-layum pudhu tasks-layum weak-aa irukkum-nu kandupidichadhu. Thaanaa solve panna theriyaadha solutions-la train aana student, confident-aana thappaana answers tharuvadhai kathukkalaam.
- **Bias perugudhal.** Teacher sila answers-a virumbina, student andha bias-a kathukkum, sila neram innum adhigama.
- **Data enga irundhu vandhadhu-nu theriyaadhu.** Model uruvaakkina data, arivu enga irundhu vandhadhu-nu maraikkum, teacher-oda training data-la irukkalaam copyright problems-um serthu.
- **Unmaiyaa illaadha language.** Generate pannina Hindi, makkal WhatsApp-la unmaiyaa ezhudhuradha vida adhigam formal-aa irukkum. Unmaiyaana seed examples adha nelathula vechirukkum.
