## Idhu enna

**Sorting** items-a order-la podum. Data sort aanaa, neraya kelvigal easy-aagidum: duplicates pakkathula pakkathula irukkum, smallest, largest ends-la irukkum, edhaiyum vegamaa kandupidikkalaam.

**Binary search** sorted data-la middle-a paathu, andha item irukka mudiyaadha paadhiya thookki podum. Ovvoru step-layum meedhi paadhiyaagum, adhanaala sumaar log₂ n steps thaan thevai: 10 lakh items-ku 20.

**Two pointers** oru array-la rendu positions-a nagarthum, aaga paathaa rendu ends-laiyum irundhu, illa onnu pinnaadi onnu, nested loops illaama pair, range problems-a one pass-la solve panna. **Sliding window**-na best contiguous stretch kandupidikka use panra two-pointer pattern.

```flow
dir: LR
title: [3 8 15 21 27 33 42 50 61 77]-la 42-a binary search pannradhu
Middle 27 -[27, 42-a vida chinnadhu: right paadhiya search pannunga]-> [33 42 50 61 77]-oda middle 42 -> 2 steps-la kedaichidhu
```

```flow
title: Two pointers: sorted [5 12 18 25 30 38 45]-la sum 50 aagura pair
L 5-la, R 45-la -> Sum = 50?
Sum = 50? -[romba chinnadhu]-> L-a right nagathunga
Sum = 50? -[romba perusu]-> R-a left nagathunga
Sum = 50? -[aamaa: 5 + 45]-> Kedaichidhu
L-a right nagathunga -> Sum = 50?
R-a left nagathunga -> Sum = 50?
```

## Idhu eppadi work aagudhu

**Sorting algorithms** speed-layum behaviour-layum maarum:

| Algorithm | Average time | Extra space | Notes |
|---|---|---|---|
| Bubble / insertion sort | O(n²) | O(1) | simple; insertion sort kitta-thatta sorted data-la vegam |
| Merge sort | O(n log n) | O(n) | halves-a pirichu, sorted halves-a merge pannum; stable |
| Quicksort | O(n log n), worst O(n²) | O(log n) | pivot pick panni partition pannum; practice-la vegam |
| Heap sort | O(n log n) | O(1) | heap use pannum; stable illa |
| Timsort (Python-oda `sorted`) | O(n log n) | O(n) | merge sort plus insertion sort; real data-la romba vegam |

Practice-la built-in sort-a thaan call pannuvinga. Aanaalum comparison sorting average-aa O(n log n)-a vida vegamaa pogaadhu-nu theriyanum, interview-la merge sort illa quicksort-a explain panna theriyanum.

**Binary search** `lo`-vula irundhu `hi` varaikkum oru range vechchirukkum. Middle-a paakkum; target perusaa irundhaa `lo`-va middle-ku appuram nagarthum; chinnadhaa irundhaa `hi`-ya adhukku munnaadi nagarthum. Target kedaicha, illa range kaaliyaanaa niruthum. Idhae idea edhaavadhu **monotonic** yes/no kelvi-ku work aagum, udhaaranam "day d-kulla cumulative sales target-a ethiducha?"; idhu thaan **binary search on the answer**.

**Two pointers** sorted order-a use pannum. Target sum-oda pair kandupidikka, rendu ends-laiyum aarambinga: sum romba chinnadhaa irundhaa left pointer-a right nagathunga adhigamaakka; romba perusaa irundhaa right pointer-a left nagathunga. Ovvoru move-um orey neraththula neraya pairs-a vilakkidum, adhanaala O(n).

**Sliding window**-ku left edge-um right edge-um irukkum. Window valaraa right edge-a nagathunga; budget-a thaandum maadhiri oru rule udaindhaa, left edge-a nagathi kurukkunga. Povarappo best window-a track pannunga.

**Interviews-la** clues-a kavanichukkunga. "Sorted array", "first illa last position kandupidi", "work aagura minimum value" binary search-a kaattum. Sorted data-la "pair", "triplet", "sum-oda subarray" two pointers-a kaattum. "Longest illa shortest contiguous stretch" sliding window-a kaattum. Code ezhudhuradhukku munnaadi pattern-a sathathamaa sollunga; interviewer-ku neenga eppadi yosikkreenga-nu theriyum.

## Oru worked example

Sneha Hyderabad-la oru online coaching platform-ku analytics paakkraanga. Oru varushathukku daily ads spend irukku, monthly budget kelvi: total ad spend ₹1 lakh-kulla irundha, thodarchiyaa evvalavu naal longest run?

Ovvoru start, end day-yum try pannaa O(n²). Sliding window one pass-la mudikkum:

```python
def longest_within(spend, budget):
    best = total = left = 0
    for right, amount in enumerate(spend):
        total += amount                   # grow the window
        while total > budget:             # shrink until within budget
            total -= spend[left]
            left += 1
        best = max(best, right - left + 1)
    return best
```

Ovvoru naal-um window-kulla oru thadava varum, adhigamaa oru thadava veliya pogum, adhanaala O(n).

Adutha, finance kekkuradhu: cumulative sign-ups mudhal thadava 50,000-a ethiducha naal edhu? Cumulative totals melae thaan pogum, adhanaala "day d-kulla ethiducha?"-nu kelvi false, false, ..., apram ellaa pinnaadi naal-um true. Idhu monotonic, adhanaala answer-a binary search pannalaam:

```python
from itertools import accumulate

def first_day_reaching(daily, target):
    totals = list(accumulate(daily))
    lo, hi = 0, len(totals) - 1
    answer = -1
    while lo <= hi:
        mid = (lo + hi) // 2
        if totals[mid] >= target:
            answer, hi = mid, mid - 1     # works; look for an earlier day
        else:
            lo = mid + 1
    return answer
```

Oru varusha data-ku 365 varaikkum illaama sumaar 9 checks. 10 varusha hourly data-la sumaar 90,000-ku badhila sumaar 17 checks. Python-oda `bisect` module idhaiye oru call-la seiyum: `bisect.bisect_left(totals, target)`.

## Podhuvaa panra thappugal

**Unsorted data-la binary search panradhu.** Therila-mae thappaana answers kudukkum. Mudhalla sort pannunga, illa yes/no kelvi monotonic-aa irukkanum.

**Off-by-one bounds.** Inclusive, exclusive `hi`-a kalakkuradhu, `mid + 1`-ku badhila `lo = mid`-nu ezhudhuradhu infinite loops-a kudukkum. Oru convention pick pannunga, length 0, 1, 2 lists-oda test pannunga.

**Real velaikku neengalae sort ezhudhuradhu.** Built-in sorts nallaa test pannina, vegamaanavai. Kathukka mattum, illa interview-la kettaa mattum ezhudhunga.

**Loop-kulla re-sort panradhu.** Loop-ku veliya oru thadava sort pannunga. Ulla sort pannaa O(n log n) velai n thadava nadakkum.

**Unsorted data-la pair sums-ku two pointers use panradhu.** Indha method order-a nambi irukku. Sort pannaama irundhaa hash map use pannunga.

**Window-a kurukka while-ku badhila if use panradhu.** Rule-kulla varaikku oru step podhaadhu. Rule udaindhirukkara varaikkum kurukkitte irunga.
