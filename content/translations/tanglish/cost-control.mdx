## Idhu enna

Hosted model-kku pora ovvoru call-um **token** vachu bill aagudhu; token-naa oru vaarththai illa vaarththaiyoda oru thundu. **Cost control**-naa endha features, users, steps andha tokens-a selavu pannudhu-nnu therinjukittu, users-a baadhikkaama andha selavai kuraikkiradhu. Oru request-oda bill-kku naalu pagudhigal irukku:

- **Fresh input**: system prompt, tool definitions, history, retrieve panna text, user-oda message, idhellaam muzhu input price-la.
- **Cache reads and writes**: input-la provider-oda prompt cache-la irundhu varra, illa adhula save aagura pagudhi, romba kammiyaana illa konjam adhigamaana price-la.
- **Output**: theriyura reply, input price-a vida pala madangu adhigamaana price-la.
- **Thinking**: oru reasoning model-oda maranjirukkura reasoning tokens. Response-la adhula onnu kooda theriyalainnaalum avai output-aa thaan bill aagum.

```flow
title: Oru request-la panam enga pogudhu
dir: LR
System prompt, tools | ovvoru call-layum adhe thaan, adhanaala cache pannalaam -> Input bill
History, retrieve panna text | ovvoru turn-layum valarum -> Input bill
User message | podhuvaa chinnadhu -> Input bill
Input bill -> Model
Model -[maranjirukkura reasoning]-> Output bill | thinking output-aa bill aagum
Model -[theriyura reply]-> Output bill
```

Indha lesson-la perumbagudhiya rendu facts thaan nadaththudhu. Token ennikkaiyila podhuvaa input thaan perusu, yenna neelamaana fixed prefix ovvoru call-layum thirumba pogudhu. Oru token-kkaana price-la podhuvaa output (thinking serththu) thaan perusu. Adhanaala periya savings inga irundhu thaan varudhu: prefix-a muzhu price-la thirumba anuppaama irukkuradhu, task-kku thevaiyaanadha vida adhigamaa think pannaama irukkuradhu, chinna model pass aagura idaththula periya model-a use pannaama irukkuradhu.

## Idhu eppadi work aagudhu

### Mudhalla alanga

Ovvoru call-aiyum adhoda usage numbers-oda log pannunga: fresh input tokens, cache-read tokens, cache-write tokens, output tokens, API report pannaa output-la thinking-oda pangu (Anthropic-oda field `usage.output_tokens_details.thinking_tokens`; OpenAI-um reasoning tokens-a `output_tokens_details`-kkulla thaan report pannudhu). Ovvoru call-aiyum feature, user, model, effort setting, prompt version vachu tag pannunga. Appo indha kelvigalukku badhil sollalaam: endha feature adhigamaa cost aagudhu, endha users, endha agent step, evvalavu thinking. Maasaththoda moththa total mattum irundhaa idhellaam maranjudum.

Cost per request mattum illaama **cost per completed task**-a track pannunga. Fail aagura, retry aagura, illa oru aalkitta pora oru malivaana call unmaiyila malivu illai.

### Price page-a padinga, thedhiya kuringa

28 November 2026 nilavarappadi, Anthropic-oda API ippodhaiya moonu model sizes-kku ippadi vilai vaikkudhu (oru million tokens-kku US dollars):

| Model | Input | Output | Cache read | 5-minute cache write | Batch input / output |
| --- | --- | --- | --- | --- | --- |
| Claude Opus 5.5 | $4 | $20 | $0.20 | $5 | $2 / $10 |
| Claude Sonnet 5.5 | $2 | $10 | $0.10 | $2.50 | $1 / $5 |
| Claude Haiku 5.5, 100,000 tokens varaikkumaana prompts | $0.10 | $0.50 | $0.01 | $0.125 | $0.05 / $0.25 |

Idhula irundhu moonu vishayangala padikkalaam. Output-kku input-a vida anju madangu cost. Rendulayume ellaaththaiyum vida chinna model, ellaaththaiyum vida periya model-a vida 40 madangu malivu. Batch sariyaa paadhi vilai. Maththa providers-um idhe structure-a vera numbers-oda use panraanga, adhanaala avangaloda ippodhaiya pages-a padichu, neenga check panna thedhiya ezhudhi vainga.

### Model thervu: migapperiya lever

Classification, clean text-la irundhu extraction, routing, chinna replies idhukkellaam oru chinna model perumbaalum periya model-kku samamaa irukkum. Ovvoru task-aiyum unga eval set-la rendu moonu model sizes-oda test panni, pass aaguradhula malivaanadha use pannunga, kashtamaana requests-a mattum periya model-kku anuppunga. Batching, model tiering paththina lesson routers-a aazhamaa cover pannudhu. Switch pannumbodhu tokens-a thirumba ennunga: vera vera models vera vera tokenizers use pannalaam, adhanaala adhe text vera ennikkaiyila tokens-aa irukkalaam.

### Reasoning tokens-um effort-um

Ippodhaiya perumbaalaana models badhil solradhukku munnaadi think pannudhu, andha thinking muzhu output price-la output-aa bill aagudhu. Response-la oru summary mattum kaattinaalum, edhuvume kaattalainnaalum, muzhu thinking-kkum neenga panam kattureenga-nnu Anthropic-oda documentation thelivaa solludhu. Adhanaala theriyura reply-oda neelam bill-oda match aagaadhu.

Opus 5.5 prices-la oru chinna example: 10 visible tokens-um 90 thinking tokens-um irukkura oru ticket label-kku 100 × $20 per million = $0.002 output aagum, label-kku mattum aagura $0.0002-a vida paththu madangu.

Idha kattuppaduththuradhu **effort** setting (maththa providers-la "reasoning effort"). Effort kammiyaanaa thinking kammi, low effort-la simple inputs-kku model thinking-aiye skip pannalaam. Anthropic API-la default, Opus 5.5, Haiku 5.5-kku `medium`, maththa perumbaalaana models-kku `high`, adhanaala adha explicit-aa set pannunga. Moonu rules:

- **Ovvoru route-kkum tune pannunga.** Chat, tagging, extraction perumbaalum low effort-layum quality-a thakka vachukkum; multi-step maths, code, planning-kku perumbaalum high venum. Ovvoru route-kkum eval-la alanga.
- **`max_tokens`-la idam vidunga.** Thinking-um adhukkulla thaan count aagum. 200-token reply-kku size panna oru cap, model think pannumbodhu answer-a truncate pannidum, appuram retry-kku aagura cost, cap michchappaduthinadha vida adhigam.
- **Oru conversation-kkulla effort-a maathaama vainga.** Requests-kku naduvula adha maaththinaa prompt cache invalidate aagalaam.

### Prompt caching

Prompt caching, prompt-oda neelamaana, maaraadha aarambap pagudhiya (system prompt, tool definitions, illa oru periya document maadhiri) store panni vaikkudhu, adhanaala adutha calls adha malivaa read pannalaam. Idhu oru prefix match: mudhalla tools, appuram system prompt, appuram messages; endha idaththula maatram vandhaalum adhukku appuram irukkura ellaame invalidate aagum. Anthropic API-la, November 2026 nilavarappadi:

- 5-minute cache write-kku input price-oda 1.25 madangu aagum, oru read-laye laabam vandhudum. 1-hour write-kku 2 madangu aagum, rendu reads-la laabam varum.
- Oru read-kku perumbaalaana models-la input-oda 0.1 madangu, Opus 5.5, Sonnet 5.5-la 0.05 madangu.
- Oru minimum length-a vida chinna prompts (ippodhaiya models-la 512 tokens) cache aagaadhu, adha solla endha error-um varaadhu.

Caching saththamillaama fail aagum. Podhuvaana kaaranangal: system prompt-oda mel pagudhiyila oru date illa request ID, ovvoru thadavaiyum vera order-la build aagura tool definitions, maaththina effort setting, vera model-kku switch panradhu (ovvoru model-kkum thani cache), illa traffic romba kammiyaa irundhu calls-kku naduvula 5-minute lifetime mudinjudradhu. Usage-la cache-read count-a check pannunga. Adhu zero-laye irundhaa, andha maatraththai kandupidinga.

**Response caching** vera: muzhu answers-a store panni, thirumba varra kelvigalukku model-aiye skip panreenga. Ovvoru hit-layum innum adhigamaa michchamaagum, aanaa pazhaiya illa leak aana answers pora risk irukku. Caching, speed paththina lesson rendaiyum cover pannudhu.

### Batch APIs

Kaathirukkakoodiya velai (raaththiri summaries, bulk tagging, eval runs, backfills maadhiri) oru batch API vazhiyaa pogalaam. Anthropic-oda Message Batches API input-kkum output-kkum normal price-la 50% thaan vaangudhu. Perumbaalaana batches oru mani nerathukkulla mudiyum; 24 mani nerathukkulla mudiyaadha requests expire aagum, avatrukku bill varaadhu. Batch discount-um caching discount-um serndhe kidaikkum, batches 5 nimishaththukku mela edukkalaam-nguradhaala 1-hour cache avatrukku eththadhu.

### Agents: ovvoru step-layum history valarum

Oru agent ovvoru step-layum muzhu conversation-aiyum anuppudhu, adhanaala ovvoru step-layum input valarudhu. 4,000-token prefix, ovvoru step-layum 1,500 pudhu tokens-nnu vachukkonga. Ettu steps-la 4,000 × 8 + 1,500 × (0 + 1 + … + 7) = 32,000 + 42,000 = 74,000 input tokens pogudhu, ore task maadhiri thonura onnukku. Fixed prefix-aiyum mundhaiya history-aiyum cache pannunga, task-kku thevaiyaana tools-a mattum load pannunga, oru step limit vainga, neelamaana runs-la pazhaiya tool results-a summarise illa clear pannunga. Agent budgets, kill switches paththina lesson limits-a cover pannudhu.

### Indhiya mozhigalum self-hosting-um

Tokenizer-a poruththu, adhe reply-kku English-a vida Hindi, Tamil, Bengali-la pala madangu adhiga tokens thevaippadalaam, adhanaala neenga serve panra ovvoru mozhikkum tokens per request-a alanga. Indhiya mozhigalla AI paththina lesson idha cover pannudhu.

Oru open model-a self-host pannaa, per-token bill-kku badhilaa oru fixed maasa bill varum. Udhaaranamaa, oru GPU server-a run panna, aalungaloda neram serththu, maasam ₹2.5 latcham aagudhu-nnu vachukkonga. Oru batched summary-kku ₹0.47-nnaa, maasam sumaar 5.3 latcham summaries anuppumbodhu API-kkum adhe cost aagum (2,50,000 ÷ 0.47). Adhukku keezha API thaan jeyikkum; adhukku mela, open model adhe evals-a pass panni, server busy-aave irundhaa mattum thaan self-hosting jeyikkum. vLLM, total cost of ownership paththina lessons unmaiyaana numbers-a eppadi podradhu-nnu kaattudhu.

### Oru calculator

Indha calculator table-la irukkura prices-aiyum, oru dollar-kku ₹94-ngura oru illustrative rate-aiyum use pannudhu (November 2026 naduvula rupee sumaar ₹93-la irundhu ₹94 varai trade aachu). Keezha irukkura worked example-oda rows-a idhu print pannudhu.

```python
RATE = 94  # rupees per US dollar: illustrative (about 93 to 94 in mid November 2026)

# US dollars per million tokens, Anthropic API pricing page, checked 28 November 2026
PRICES = {
    "opus-5.5":  {"in": 4.00, "out": 20.00, "cache_read": 0.20, "cache_write": 5.00},
    "haiku-5.5": {"in": 0.10, "out": 0.50, "cache_read": 0.01, "cache_write": 0.125},
}

def cost_inr(model, fresh_in, out, cache_read=0, cache_write=0, batch=False):
    """Rupees for one request. `out` includes thinking tokens, which bill as output."""
    p = PRICES[model]
    usd = (fresh_in * p["in"] + out * p["out"]
           + cache_read * p["cache_read"] + cache_write * p["cache_write"]) / 1e6
    return usd * RATE * (0.5 if batch else 1)

rows = {  # (rupees per request, requests per month)
    "summary, before":  (cost_inr("opus-5.5", 1500, 200), 300_000),
    "summary, batch":   (cost_inr("opus-5.5", 1500, 200, batch=True), 300_000),
    "classify, before": (cost_inr("opus-5.5", 600, 100), 300_000),
    "classify, small":  (cost_inr("haiku-5.5", 600, 10), 300_000),
    "chat, before":     (cost_inr("opus-5.5", 6000, 750), 60_000),
    "chat, after":      (cost_inr("opus-5.5", 1000, 500, cache_read=2700, cache_write=300), 60_000),
}
for name, (per, n) in rows.items():
    print(f"{name:17} ₹{per:.4f} each, ₹{per * n / 1e5:.2f} lakh a month")
```

### Safe-aa kuraikkiradhu

Oru thadavaikku oru lever-a mattum maathunga, munnaadiyum pinnaadiyum andha feature-oda evals-a run pannunga. Cost-aiyum quality-aiyum pakkaththu pakkaththula report pannunga. Oru maatram panaththai michchappaduththi quality-a konjam kuraichaa, team andha trade-a eththukkichu-nnum yen-nnum ezhudhi vainga.

### Launch-kku munnaadi oru feature-kku vilai podradhu

Pilot-la irundhu oru user-kku maasam aagura cost-a estimate pannunga: oru user-oda requests × oru request-oda cost. Adha GST, payment fees poga user katturadhoda compare pannunga. Udhaaranamaa, keezha irukkura trim panna chat-la oru reply-kku ₹1.51-nnaa, maasam 600 messages anuppura oru student-kku ₹906 aagum, aanaa oru ₹149 plan sumaar ₹120 thaan kondu varum. Onnu, chat adhoda eval-a pass panra oru malivaana route-la run aaganum, illainnaa plan-kku oru daily limit irukkanum. Launch-kku munnaadiye caps vainga, mudhal rendu vaaraththula thirumba check pannunga, yenna unmaiyaana users pilot group maadhiri nadandhukkuradhu aridhu.

## Oru worked example

Kolkata-la irukkura oru customer-service platform model calls-kku maasam sumaar ₹6.3 latcham selavu pannudhu, ellaame Opus 5.5-la; adha paadhiyaa kuraikkanum-nu ninaikkudhu. Keezha irukkura ella volumes-um token counts-um illustrative thaan, mela irukkura table vachu, oru dollar-kku ₹94-la price pannadhu.

**Step 1: alanga.** Tag panna logs moonu features-a kaattudhu:

- **Raaththiri ticket summaries**: oru raaththirikku 10,000, maasam 3 latcham. Ovvonnukkum 1,500 input, 200 output tokens. Kaalai 10 manikku munnaadi yaarum avatrai padikkiradhillai.
- **Ticket classification**: maasam 3 latcham. Ovvonnukkum 600 input tokens, aanaa output 100 tokens: oru 10-token label, adhoda 90 tokens thinking.
- **Live chat**: maasam 60,000 replies. Ovvonnukkum 5,000-token system prompt-um tools-um, uncached, adhoda 1,000 tokens history-um kelviyum. Output 750 tokens: 450 visible, 300 thinking.

**Step 2: ovvoru feature-kkum vilai podunga.**

- Summaries: (1,500 × $4 + 200 × $20) ÷ 10 latcham = $0.0100, adhaavadhu ovvonnukkum ₹0.94, adhanaala 3 latcham × ₹0.94 = ₹2.82 latcham (45%).
- Classification: (600 × $4 + 100 × $20) ÷ 10 latcham = $0.0044, adhaavadhu ovvonnukkum ₹0.41, adhanaala ₹1.24 latcham (20%). 100 output tokens-la 90 thinking.
- Chat: (6,000 × $4 + 750 × $20) ÷ 10 latcham = $0.0390, adhaavadhu ovvonnukkum ₹3.67, adhanaala 60,000 × ₹3.67 = ₹2.20 latcham (35%).

Moththam: ₹6.26 latcham.

**Step 3: ovvoru feature-kkum oru lever-a maathunga.**

- **Summaries batch API-kku pogudhu.** Adhe tokens, paadhi vilaiyila: ovvonnukkum ₹0.47, maasam ₹1.41 latcham. Kaalai 10 manikku romba munnaadiye ready aayidum.
- **Classification low effort-la Haiku 5.5-kku pogudhu.** Opus 5.5-laye effort-a mattum kuraichaa thinking poyidum (600 × $4 + 10 × $20 = $0.0026, ovvonnukkum ₹0.24, 41% kammi). Low effort-la chinna model-kku (600 × $0.10 + 10 × $0.50) ÷ 10 latcham = $0.000065, ovvonnukkum ₹0.0061, maasam sumaar ₹1,800 aagum. Label panna 400 tickets-la accuracy 94%-la irundhu 93%-kku pogudhu, team adha eththukkudhu.
- **Chat Opus 5.5-laye irukku.** System prompt-a 5,000-la irundhu 3,000 tokens-aa trim panni cache panraanga. Pagal nera busy traffic 90% hit rate kudukkudhu, adhanaala saraasariyaa 2,700 tokens oru million-kku $0.20-la cache reads, 300 tokens oru million-kku $5-la writes. Sumaar 150 vaarththaikkulla replies venum-nu prompt kekkudhu, adhu visible output-a 450-la irundhu 200 tokens-kku kondu varudhu. Thinking 300-laye irukku. `max_tokens` 200 illa, 1,200-aa set pannirukkaanga, adhanaala thinking endha reply-aiyum truncate pannaadhu. Oru reply-kku: 1,000 × $4 + 2,700 × $0.20 + 300 × $5 + 500 × $20 = $0.01604, adhaavadhu ₹1.51, adhanaala maasam ₹0.90 latcham.
- **Limits.** Ovvoru support agent-kkum oru daily cap, chat-oda tool use-kku oru step limit, budget-la 80%-la oru spending alert, provider console-la oru hard monthly limit.

## Podhuvaa panra thappugal

- **Theriyura reply-a mattum paarkkuradhu.** Oru model upgrade-kku appuram replies adhe neelaththula therinjaalum bill double aagudhu. Kaaranam thinking tokens: price-a kurai solradhukku munnaadi usage-la thinking count-a check pannunga.
- **Ellaaththaiyum thirumba anuppura retries.** Timeout-la moonu udanadi retries oru 6,000-token prompt-a naalu thadavai varai bill pannum, overload-a innum mosamaakkum. Exponential backoff, jitter-oda adhigabatcham rendu retries mattum use pannunga.
- **Orubodhum hit aagaadha cache.** System prompt-oda mela oru timestamp irundhaa ovvoru prefix-um vera maadhiri aayidum. Arikuri: cache-read tokens zero-laye irukkum, aanaa plain input-a vida adhigamaa cost aagura cache writes vandhukkitte irukkum.
- **Ovvoru call-layum ella tools-um.** Thalaa 200 tokens irukkura muppadhu tool definitions, step-kku rendu tools thaan thevainnaalum, ovvoru step-layum 6,000 input tokens serkkum.
- **Thinking-kku idam illaadha `max_tokens` cap.** Replies oru `max_tokens` stop reason-oda vaakkiyaththoda naduvula ninnudum, users retry pannuvaanga, neenga rendu thadavai panam kattuveenga.
- **Completed task-kku illaama request-kku cost-a judge panradhu.** Oru call-kku 20 madangu malivaana, aanaa anjula oru thadavai fail aagura model, retries-um human review-um serththu kanakku pannaa adhigamaa cost aagalaam.
- **Quality-a check pannaama cost-a kuraikkiradhu.** Ovvoru maatraththukkum evals-a run pannunga, numbers-a vachukkonga.

## Selavai kuraikkuradhu thappaana ilakkaa irukkumbodhu

- **Feature innum work aagala.** Mudhalla unga evals-la quality-a sari pannunga; optimise appuram pannalaam.
- **Savings romba chinnadhu.** Maasam ₹2,000 michchappaduththuradhu vaarakkanakkaana engineering-kko, alakkakoodiya oru quality drop-kko worth illai.
- **Latency illa trust adhaivida mukkiyam.** High-stakes task-la medhuvaa irukkura illa adhiga thappu panra oru malivaana model, support-layum izhakkura users-layum adhigamaa cost aagalaam.
