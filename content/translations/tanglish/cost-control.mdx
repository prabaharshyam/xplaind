## Idhu enna

LLM apps-ku ovvoru request-kum selavu aagum, users, neenda prompts, agent loops-oda cost valarum. **Cost control**-na panam engae pogudhu-nu therinjukkittu, user experience-a paadhikkaama adha kammi panradhu. Mukkiya levers: model choice, prompt size, output size, caching, batching, limits.

| Feature (tag panna logs-la irundhu) | Maadham ₹6 lakh-la share | Fix |
|---|---|---|
| Nightly ticket summaries | 45% | Batch API-ku maathunga |
| Live chat replies | 35% | Prompt-a trim panni cache pannunga, replies-a cap pannunga |
| Ticket classification | 20% | Oru chinna model (accuracy 94%-la irundhu 93%) |

```flow
dir: LR
Ovvoru call-aiyum feature vaariyaa tag pannunga -> Periya share-a kandupidinga -> Oru fix podunga -> Caps serunga | per-agent daily cap, budget-oda 80%-la alert, provider hard limit
Caps serunga -> Adutha maadham: ₹2.7 lakh | customer satisfaction maaralai
```

Indha lesson Kolkata-la oru customer-service platform-a follow pannum, avanga thangaloda model bill-a paadhiyaa kuraikka virumbinaanga.

## Idhu eppadi work aagudhu

**Mudhalla measure pannunga.** Ovvoru call-kum tokens-aiyum cost-aiyum feature, user, model tag-oda log pannunga. Apram ungalaala badhil solla mudiyum: edhu feature adhigam selavu? Edhu users? Oru agent-oda edhu step? Maadha totals mattum idhai maraikkum; per user, per feature cost engae action edukkanum-nu, oru feature thannoda selavai thaanae kattumaa-nu kaattum.

**Model choice: periya lever.** Chinna models, periya models-a vida pala madangu kammiyaa selavu aagum. Classification, clean text-la irundhu extraction, routing, chinna replies maadhiri simple tasks-ku, oru chinna model perumbaalum periya model-oda match aagum. Ovvoru task-aiyum ungaloda eval set-la rendu, moonu model sizes-oda test panni, pass aagura romba sila-vaana model-a use pannunga. Kashtamaana requests-a mattum periya model-ku anuppunga.

**Prompt size.** Ovvoru request-um adhoda input-ku pay pannum. System prompts-a trim pannunga, kammiyaana, chinna retrieved chunks-a anuppunga, neenda conversation history-a summarise pannunga, use pannaadha tool definitions-a edunga.

**Output size.** Output tokens perumbaalum input-a vida adhigam selavu. Concise formats kelunga, `max_tokens` vainga.

**Caching.** Neenda shared prefixes-ku prompt caching; thirumba varra kelvigalukku response caching.

**Batching.** Kaathirukka mudiyura velai (nightly summaries, bulk classification, oru corpus-a embed panradhu) batch APIs vazhiyaa pogalam, providers mani neraththukkulla results kudukkuradhukku badhila periya discount tharuvaanga.

**Limits.** Per user daily caps, agents-ku step limits, spending alerts, provider console-la hard limits.

**Kanakku therinjukkunga.** Oru request-oda cost = input tokens x input price + output tokens x output price, cached input perumbaalum romba kammiyaa bill aagum. Oru chinna calculator estimates-a nermaiyaa vechukkum:

```python
def cost_per_request_inr(input_tokens, output_tokens, in_price_usd_per_m, out_price_usd_per_m,
                         cached_share=0.0, cache_discount=0.9, usd_to_inr=85):
    """Prices are US dollars per million tokens. cached_share: fraction of input served from the prompt cache."""
    fresh = input_tokens * (1 - cached_share)
    cached = input_tokens * cached_share * (1 - cache_discount)
    usd = ((fresh + cached) * in_price_usd_per_m + output_tokens * out_price_usd_per_m) / 1e6
    return usd * usd_to_inr

def monthly_cost_inr(requests_per_month, **kw):
    return requests_per_month * cost_per_request_inr(**kw)

# A chat reply: 3,000 input tokens (60% cached), 250 output, $3 / $15 per million tokens
per = cost_per_request_inr(3000, 250, 3, 15, cached_share=0.6)
print(round(per, 2), round(monthly_cost_inr(300_000, input_tokens=3000, output_tokens=250,
      in_price_usd_per_m=3, out_price_usd_per_m=15, cached_share=0.6)))
```

Prices-um exchange rate-um maarum, adhanaala provider-oda ippo irukkura page-la irundhu padinga, neengal check panna date-a record pannunga. Indha kanakku sikkiram kaattura rendu vishayam: output tokens perumbaalum input-a vida pala madangu adhigam selavu, ovvoru call-layum thirumba varra neenda prompts sikkiram serndhu periya thogaiya aagum.

**Mozhi-yum mukkiyam.** Tokenizer-a poruthu, ore reply Hindi, Tamil, Bengali-la English-a vida pala madangu adhigam tokens-a edukkalaam, adhanaala neenga serve panra ovvoru mozhikkum oru request-ku tokens-a measure pannunga. AI in Indian languages lesson idhai cover pannum.

**Kashtatha poruthu route pannunga.** Oru chinna, vegamaana classifier illa rules, easy requests-a oru sila-vaana model-ku, scope-ku veliya irukkura kelvigala model call illaama oru stock reply-ku, kashtamaana-vatrai mattum romba strong-aana model-ku anuppalaam. AI app-a layers-la valarkkuradhu lesson routers-aiyum gateways-aiyum cover pannum.

**Surprises-a kavanichukkunga.** Retry storms, loop aagura agents, oru periya document, illa oru heavy user, raathiriyilaye costs-a pala madangu aakkalaam.

**Levers-um typical savings-um:**

| Lever | Typical effect | Risk |
| --- | --- | --- |
| Simple tasks-ku chinna model | Andha task-la periya saving | Test pannaama irundhaa quality kurayum |
| Kaathirukkura velaikku batch API | Periya discount | Mani neram delay |
| Prompt caching | Thirumba varra prefixes-ku input cost kammi | Prefix maarina odaindhidum |
| Chinna prompts-um outputs-um | Vidhikkura madhiri saving | Context illa detail miss aagum |
| Response caching | Thirumba thirumba varra calls-a neekkum | Pazhaya illa share aana answers |
| Caps-um alerts-um | Surprises-a thadukkum | Users limits-a thotta |

**Action-a thoondura cost dashboard.** Feature vaariyaa oru naalaikku spend, romba heavy users-oda per user cost, oru successful task-ku cost, top feature-oda prompt-la ovvoru pagudhi-yoda tokens share-a kaattunga. Budget-ukkum alert threshold-kum oru line serunga. Vaaram oru thadavai review pannunga. Dashboard oru paarvayilaye, adutha edha optimise pannanum-nu, kadaisi vaaram panna maatram work aachaa-nu sollanum.

**Paadhugaappaa kuraikkradhu.** Oru nerathula oru lever-a mattum maathunga, munnaadi, apram andha feature-oda evals-a odunga. Cost-aiyum quality-aiyum pakkathula pakkam sollunga. Oru maatram panatha migikkum aana quality-a konjam kuraichaa, inga classifier-la maadhiri, team andha trade-a ettukitta-nu, yen-nu ezhudhi vainga.

**Launch-ku munnaadi oru feature-a price pannuradhu.** Pilot-la irundhu oru user-ku maadha cost-a estimate pannunga: oru user-ku requests, oru request-ku tokens, model-oda price. Adhai andha feature oru user-ku evvalavu sambaadhikkudhu illa migikkudhu-nu oppidunga. Oru user-oda maadha cost avanga value-va thaandalaam-na, mudhal periya bill-ku apram illa, launch-ku munnaadiyae caps vainga. Mudhal rendu vaaram real traffic-la estimate-a thirumba paarunga, yen-na real users pilot group maadhiri nadandhukka maattaanga.

## Oru worked example

Kolkata-la oru customer-service platform maadham ₹6 lakh model calls-ku selavu pannudhu, adha paadhiyaa kuraikka virumbudhu.

Feature vaariyaa logging kaattudhu:

- 45% oru nightly job-ku, adhu 10,000 support tickets-a team leads-ku summarise pannum, aana yaarum 10 am-ku munnaadi adha padikkalai;
- 35% live chat replies-ku;
- 20% ticket classification-ku.

Maatrangal:

- Nightly summaries provider-oda batch API-ku periya discount-oda poidum, kaalaikku romba munnaadiyae mudinjudum.
- Ticket classification periya model-la irundhu chinna model-ku maarudhu; 400 label panna tickets-la, accuracy 94%-la irundhu 93%-ku kurayudhu, adha team ettukkudhu.
- Live chat periya model-a vechukkum, aana system prompt 40% trim aagi cache aagudhu, replies 200 tokens-ku cap aagudhu.
- Per-agent daily cap-um budget-oda 80%-la spending alert-um serkkapadudhu.

Adutha maadha bill ₹2.7 lakh, customer satisfaction scores-la maatram illa.

| Maatram | Cost effect | Quality check |
| --- | --- | --- |
| Nightly summaries batch-ku | Spend-oda 45%-la periya discount | Munnaadi maadhiri 10 am-ku ready |
| Classification chinna model-ku | Romba sila-vu | 400 tickets-la 94%-la irundhu 93%, ettukkapattadhu |
| Chat prompt 40% trim aagi cache; replies cap | Chat cost kammi | Satisfaction maaralai |

## Podhuvaa panra thappugal

- **Feature, user vaariyaa measure pannaama optimise panradhu.**
- **Ellaathukkum periya model-a use panradhu.**
- **Kaathirukka mudiyura velaikku real-time prices kudukkuradhu.**
- **Neenda prompts-um limit illaadha outputs-um.**
- **Alerts-um caps-um illaama irukkradhu.**
- **Quality check pannaama cost kuraikkradhu.** Ovvoru maatrathukkum evals-a odunga.

## Cost kuraikkradhu thappaana goal aagura idangal

- **Feature innum work aagala.** Mudhalla ungaloda evals-la quality-a sariyaakkunga; apram optimise pannunga.
- **Saving romba chinnadhu.** Maadham ₹2,000 save panradhu, vaarakkanakka engineering-ukkum, alavidakkudiya quality drop-kkum worth illa.
- **Latency illa nambikkai mukkiyam.** High-stakes task-la slow-aana illa adhigam thappu pannura sila-vaana model, support-lum, pona users-alayum adhigam selavu aakkalaam.

## Demo-la irundhu production-ku

- **Ovvoru call-aiyum tag pannunga** feature, user, model, prompt version-oda, tokens-aiyum cost-aiyum store pannunga.
- **Ovvoru feature-kum budgets vainga** alerts-oda, provider-la hard limits-oda.
- **Cost dashboard-a vaaram review pannunga**, quality metrics-oda, ovvoru model illa prompt maatrathukkum apram thirumba check pannunga.
- **Thirumba thirumba re-price pannunga.** Providers prices-a kuraippaanga, sila-vaana models-a release pannuvaanga; aaru maadham munnaadi eduththa choice ippo adhigam pay pannalaam.
- **Sila-vaana vazhiya test pannittu vainga**, chinna fallback model maadhiri, costs yerinaa sikkiram maara.
