## Idhu enna

**Multi-agent system** oru task-a pala agents-kulla pirikkum, ovvonnukkum adhoda instructions, tools, context irukkum. Moonu patterns perumbaalaana real designs-a cover pannum:

- **Supervisor and workers**: oru lead agent plan panni, sub-tasks-a worker agents-kku (perumbaalum adhu call panra tools-aa) delegate panni, results-a serkkum.
- **Hand-offs**: oru agent conversation-a handle pannum, adhoda role-ku veliya edhavadhu vandha, control-a context-oda oru specialist agent-kku pass pannum. Customer service-la romba common: front-desk agent billing questions-a billing agent-kku hand over pannum.
- **Generator and reviewer**: oru agent work-a produce pannum; innoru agent criteria-vukku edhiraa check panni, feedback-oda thirumba anuppum.

Munnaadi sub-agents lesson-la pirikkiradhu yen help pannum-nu sonnom: clean contexts, specialised tools, parallel work. Indha lesson patterns-a select panni run panradhu pathi.

```flow
title: Supervisor + workers: parallel, summaries lead-kku thirumbum
Lead -> Worker 1
Lead -> Worker 2
Lead -> Worker 3
```

```flow
dir: LR
title: Hand-offs: summary-yum last turns-um pass pannunga; max 2 hand-offs, apram oru aal
Front desk -[billing?]-> Billing
Front desk -[cards?]-> Cards
```

```flow
dir: LR
title: Generator + reviewer: max 2 rounds
Writer -[draft]-> Reviewer
Reviewer -[problems]-> Writer
```

Indha lesson Bengaluru-la oru bank-oda customer assistant-a follow pannum; adhu oru periya agent-a irundhu specialists-oda set-aa rebuild pannapattadhu.

## Idhu eppadi work aagudhu

**Supervisor and workers.** Supervisor user-oda goal-a paakkum, tools maadhiri describe panna workers-oda list-um paakkum ("research_competitor: researches one named company, returns a 200-word summary with sources"). Edhu call pannanum-nu decide pannum, possibly parallel-aa, final answer-a ezhudhum. Strengths: parallelism, context isolation. Risks: vague delegation, duplicated work, summaries-la details poradhu, adhiga token use.

**Hand-offs.** Ovvoru agent-um adhoda tools-um permissions-um irukkura oru domain-a own pannum. Hand-off-ae oru tool call ("transfer_to_billing"), adhu conversation-a move pannum. Strengths: ovvoru agent-um chinnadhaa, focused-aa irukkum; permissions narrow-aa irukkum (billing agent mattum thaan refunds issue pannum). Risks: agents-kulla ping-pong, transfer-la context poradhu, users thirumba sollradhu.

**Generator and reviewer.** Reviewer-kitta oru checklist illa rubric irukkum, specific problems-a thirumba kudukkum. Strengths: oru pass-la miss aagura errors-a pidikkum. Risks: mudiyaadha loops (rounds-a cap pannunga), ellaathayum approve panra reviewers (reviewer-a known bad drafts-la test pannunga).

**Shared state vs messages.** Agents oru common state object-a share pannalaam (graph frameworks-la maadhiri) illa messages pass pannalaam. Shared state debugging-a easy aakkum; messages agents-a innum independent-aa vaikkum. Entha vazhiyaa irundhaalum, ovvoru agent-oda steps-aiyum oru request id-kku keezha trace pannunga.

**Eppo vendaam.** Task sequential-aa, tight-aa coupled-aa irundha, nalla tools-oda oru agent perumbaalum cost-layum reliability-yilum jeyikkum. Mudhalla oru single-agent baseline-a measure pannunga.

**Patterns-a compare pannina:**

| Pattern | Strengths | Risks | Edhukku nallaa irukkum |
| --- | --- | --- | --- |
| Supervisor and workers | Parallel work, clean contexts | Vague delegation, adhiga token use | Research, broad analysis |
| Hand-offs | Small focused agents, narrow permissions | Ping-pong, lost context | Thani domains irukkura customer service |
| Generator and reviewer | Oru pass-la miss aagura errors-a pidikkum | Loops, lenient reviewers | Regulated illa high-stakes writing |

**Hand-off design panradhu.** Hand-off tool anuppura agent ezhudhina oru short summary-a kondu pogum: customer yaaru (verification-ku apram), enna kettaanga, enna mudinjirukku, enna meedhi irukku. Last konjam turns-aiyum pass pannunga. Domains-a thaandi pogura scripted conversations-la test pannunga, example balance question-ku apram card block, customer thanga identity-yaiyo request-aiyo thirumba sollanum-nu illaama paarunga. Ovvoru hand-off-aiyum adhoda reason-oda log pannunga, appo thaanae handle pannavendiya work-a pass panra agents-a kandupidikkalaam.

**Role descriptions ezhudhuradhu.** Ovvoru agent-oda description-um adhu enna handle pannum, enna hand off pannanum, enna onnum seiyakoodaadhu-nu solla vendum. Overlaps thaan romba mosamaana failures-a kudukkum: rendu agents-um refunds thangaloda velai-nu ninaicha, onnu sandai poduvaanga illa rendu perum act pannuvaanga. Descriptions-a pakkathula pakkam vechu padichu, test pannradhukku munnaadi ovvoru overlap-aiyum remove pannunga.

**Code-la oru hand-off.** Hand-off-na adhoda arguments-la adutha agent-kku thevaiyaana summary-a kondu pogura oru tool. Conversation-a move pannuradhum transfers-a count pannuradhum model illa, unga code:

```python
AGENTS = {
    "front_desk": {"tools": ["get_profile", "transfer"], "prompt": "Greet, verify, route."},
    "cards":      {"tools": ["block_card", "card_status", "transfer"], "prompt": "Card issues only."},
    "loans":      {"tools": ["loan_balance", "transfer"], "prompt": "Loan questions only."},
}
TRANSFER_TOOL = {
    "name": "transfer",
    "description": "Hand the customer to another team. Use only for requests outside your role.",
    "input_schema": {"type": "object", "properties": {
        "to": {"type": "string", "enum": list(AGENTS)},
        "summary": {"type": "string", "description": "Who the verified customer is, what they asked, what is done, what remains"},
    }, "required": ["to", "summary"]},
}
MAX_TRANSFERS = 3

def handle_transfer(state, args):
    state["transfers"] += 1
    if state["transfers"] > MAX_TRANSFERS or args["to"] == state["agent"]:
        state["agent"] = "human_queue"
        return "Passing you to a person who can help with all of this."
    state["handoff_notes"].append({"from": state["agent"], "to": args["to"], "summary": args["summary"]})
    state["agent"] = args["to"]
    return f"Transferred to {args['to']}."
```

Receive panra agent adhoda own prompt-oda, tools-oda, hand-off summary-yoda, last konjam turns-oda start aagum, muzhu history-oda illa. `cards` agent kitta mattum thaan `block_card` irukku, adhanaala kuzhambina front-desk agent oru card-a block panna mudiyaadhu.

**Reviewer-a planted mistakes-oda test pannunga.** Generator-and-reviewer pair, reviewer evvalavu nallaa irukko avvalavu thaan nallaa irukkum:

```python
PLANTED = [
    ("Interest is 12% a year; the EMI on ₹5 lakh over 5 years is ₹4,000.", "wrong EMI"),   # real EMI is about ₹11,100
    ("You can withdraw your fixed deposit any time without penalty.", "missing penalty"),
    ("This loan is guaranteed approved.", "promise of approval"),
]

def reviewer_recall(review_fn):
    caught = sum(1 for draft, _ in PLANTED if not review_fn(draft)["pass"])
    return caught / len(PLANTED)
```

Real reviews-la irundhu 20 la irundhu 50 planted mistakes-a vechukkunga, reviewer-oda prompt-a illa model-a maathura ovvoru vaattiyum recall-a track pannunga. Nalla drafts-a romba adhigam fail panraana-nu-um paarunga, illana writers adha ignore panna kathukkuvaanga.

**Agents systems yen fail aagudhu.** Multi-agent failures pathi studies, perumbaalaana problems weak models pathi illa-nu kandupidichirukku: roles overlap aagudhu illa vague-aa irukku, agents thaan kandupidichadha pass panradhilla, yaaro romba seekirame niruthiduraanga, illa yaarum final result-a check panradhilla. Ovvoru role-oda boundaries-aiyum ezhudhunga, hand-off summaries-a require pannunga, mudinja answer-a check panra poruppa oru agent-kku (illa unga code-ku) clear-aa kudunga.

**Extra cost-a count pannunga.** Ovvoru agent-um instructions-aiyum tool definitions-aiyum repeat pannum, summaries extra calls. Oru task-ku tokens-a single-agent baseline-oda compare panni, quality illa speed-la kidaikkura gain adhukku worth-aa-nu decide pannunga.

## Oru worked example

Bengaluru bank-oda customer assistant balances, card blocks, loan queries, complaints-a handle pannudhu.

Version one, 22 tools-oda oru single agent, 9% time thappaana tools-a choose pannudhu, card-block permissions-a safe-aa kudukka mudiyala.

Version two hand-offs use pannudhu:

- Balances, FAQs-ku read-only tools-oda, ovvoru specialist-kkum hand-off tool-oda oru **front-desk agent**.
- Cards-a block panna mudiyum (identity confirm pannina apram), aana panam move panna mudiyaadha oru **cards agent**.
- Loan accounts-ku read access-um prepayment calculator-um irukkura oru **loans agent**.
- Complaints-a grievance system-la record panni, customer-ku oru complaint reference number kudukkura oru **complaints agent**.

Ovvoru hand-off-um oru short summary-yum last konjam turns-um pass pannum, adhanaala customers thirumba sollavendiyadhilla. Thodarndhu rendu hand-offs-ku mela pogakoodaadhu-nu oru rule, appadi pona oru human-kitta route aagum. Thappaana tool choices 2%-ku kurainjudhu, ovvoru agent-oda permissions-um narrow-aa irukkradhaala security team approve pannudhu. Token use 30% yerudhu, mukkiyama summaries-naala, bank adha accept pannudhu.

Generator-reviewer pair complaint responses-ku mattum serkkapattadhu, adhula oru reviewer agent tone-a-yum, reference number-um timelines-um sariyaa irukka-nu-yum check pannudhu; 6% drafts-la issues-a pidikkudhu.

| Measure | 22 tools-oda oru agent | Naalu specialists-kku hand-offs |
| --- | --- | --- |
| Thappaana tool choices | 9% | 2% |
| Card-block permissions | Safe-aa kudukka mudiyala | Cards agent-kku mattum, identity checks-ku apram |
| Token use | Baseline | Summaries-naala sumaar 30% adhigam |
| Security review | Approve aagala | Approve aachu |

## Podhuvaa panra thappugal

- **Simple task-ku neraya agents.** Onnula aarambinga; oru problem-a measure pannina apram piringa.
- **Vague roles.** Overlap aagura agents sandai podum illa work-a duplicate pannum. Sharp role descriptions ezhudhunga.
- **Lossy hand-offs.** Summary-yum recent turns-um pass pannunga, users mukkiya details-a thirumba sollavendiyadhilla-nu test pannunga.
- **Loop limits illa.** Agents work-a mari mari endless-aa pass pannalaam.
- **Agent-wise mattum traces.** Oru request-la ovvoru agent-oda steps-um serndhu theriyanum.
- **Test pannaadha reviewers.** Planted mistakes-la evvalavu catch pannudhu-nu measure pannunga.
- **Thannaiyae transfer panra agents.** Code-la adha block pannunga, transfers-a cap pannunga.

## Oru agent podhum-na eppo

- **Konjam tools-oda oru domain**: oru single agent selavu kammi, debug panna easy.
- **Sequential, tight-aa coupled steps**, pirichaa hand-off losses mattum thaan serum.
- **Kammi volume**, several agents-oda engineering cost thirumba varaadhu.

Domains-ku vera vera permissions thevai-na, work parallel-aa run aagalaam-na, illa oru context-la ellaathayum vaikka mudiyaadhu-na, pala agents-aa piringa.

## Demo-la irundhu production-ku

- **Ovvoru agent-aiyum oru request id-kku keezha trace pannunga**, hand-off summaries theriyura maadhiri.
- **Transfer rates-aiyum loops-aiyum** ovvoru agent pair-kkum track pannunga, romba mosamaana conversations-a vaaram thorum review pannunga.
- **Permissions-a ovvoru agent-kkum thaniyaa vaiyyunga**, tool code-la enforce pannunga.
- **Reviewer recall-a** planted mistakes-la ovvoru release-layum measure pannunga.
- **Single-agent baseline-a vechukkunga**, ovvoru periya change-layum cost-aiyum quality-yaiyum compare pannunga.
