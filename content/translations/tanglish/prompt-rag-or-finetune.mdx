## Idhu enna

Oru language model ungalukku vendiyadhai pannalainaa, fix unmaiyila enna thappu-nnu poruthu irukku. Rendu vagai problems irukku, anju mukkiya tools irukku.

**Model-kku knowledge illai** (unga policies, oru customer-oda account, indha vaarathu prices). Knowledge-a query nerathula, prompt-la kondu vaanga:

- **Long context**: muzhu documents-a prompt-la vainga. **Prompt caching**-la, prompt-oda maaraadha aarambap pagudhiyai provider semichu vaikkum, adhanaala thirumba varra calls adhai malivaa padikkum.
- **RAG (retrieval-augmented generation)**: unga documents-la thedi, sirandha sila passages-a mattum prompt-la vainga.
- **Tools, agentic search**: model oru database, oru API illa oru search tool-a call panni, result-a padichu, thevaippattaa thirumba thedattum.

**Model-kku podhumaana alavu theriyum, aanaa thappaa behave pannudhu** (format, tone, steps, edge cases):

- **Prompting**: thelivaana instructions, examples, API-oda **structured output**, adhula neenga oru JSON schema koduppeenga, reply adhukku porundhanum.
- **Fine-tuning**: behaviour ulleye build aagura maadhiri, unga examples-la model-a melum train panradhu. Idhu model-oda weights-a maathum, adhanaala idhu thaan romba medhuvaana, romba kammiyaa thirumba maathakkoodiya fix.

Surukkamaana rule: knowledge context-kkulla pogum; behaviour mudhalla prompt-kkulla, kadaisiyaa weights-kkulla.

```flow
title: Thernthedukkuradhukku munnaadi diagnose pannunga
Enna thappu? -[adhukku edho theriyala]-> Knowledge-a query nerathula kondu vaanga
Enna thappu? -[adhukku theriyum, aanaa thappaa pannudhu]-> Prompting, structured output
Knowledge-a query nerathula kondu vaanga -[chinnadhu, nilaiyaanadhu, adikkadi kekkappadudhu]-> Caching-oda long context
Knowledge-a query nerathula kondu vaanga -[periyadhu, maarura illa user vaariyaa]-> RAG
Knowledge-a query nerathula kondu vaanga -[live records illa pala lookups]-> Tools illa agentic search
Prompting, structured output -[adhiga volume-la innum selavaa illa thodarchi illaama]-> Fine-tune, adikkadi oru chinna model
```

Mudhirndha systems ivattrai serthu use pannum, ovvoru option-um ore test set-la alakkappadum. Indha lesson, Pune-la oru software company-la irundha moonu problems-a pinthodarudhu; ovvonnukkum vera vera fix thevaippattuchu.

## Idhu eppadi work aagudhu

### Step 1: knowledge-aa behaviour-aa-nnu diagnose pannunga

Edhaiyum thernthedukkuradhukku munnaadi 20 mudhal 30 fail aana outputs-a padinga. Ovvonnukkum kelunga: thevaiyaana fact prompt-la irundhuchaa? Illainaa, idhu oru knowledge problem, style pathina evvalavu instruction-um training-um idhai sari pannaadhu. Fact irundhum badhil thappaa, thappaana format-la illa thappaana tone-la vandhaa, idhu oru behaviour problem. Niraiya teams idhai skip pannittu, unmaiyila context illaadhadhaala vandha problem-a sari panna oru model-a fine-tune panraanga.

### Step 2: behaviour-a mudhalla prompt vachu sari pannunga

Prompting vegamaanadhu, malivaanadhu, thirumba maathalaam: oru maathathai nimishangal-la test pannalaam. Periya edhukkum munnaadi oru madhiyam selavazhinga. Task-aiyum output format-aiyum neradiyaa sollunga, oru edge case udpada rendu moonu nalla examples serunga, unga test set-a run pannunga. Pinnaadi varra ovvoru option-um jeyikka vendiya niyaayamaana baseline-aiyum idhu set pannudhu.

**Format** problems-kku API-oda structured output use pannunga: neenga oru JSON schema koduppeenga, adhukku porundhura replies-a mattum thaan provider model-a uruvaakka vidum. Appo shape urudhi, aanaa values innum thappaa irukkalaam, adhanaala avattrai code-la validate pannunga. Structured output pathina lesson idhai cover pannudhu. Sariyaana JSON kidaikkanum-ngradhukkaaga mattum fine-tune panradhu 2026-la podhuvaa oru thappu.

### Step 3: knowledge-a romba malivaana, nambagamaana vazhiyila kondu vaanga

Moonu options-um query nerathula facts-a model munnaadi vaikkum. Update panradhunnaa oru document-a illa oru database row-a maathuradhu, marupadi train panradhu illa.

**Caching-oda long context.** November 2026 nilavarappadi, Anthropic-oda sameebathiya Claude models 1 million tokens input ethukkum. Caching cost-a niraiya maathudhu. Claude Sonnet 5.5-kkaana Anthropic list prices, 28 November 2026 annaikku check pannadhu: input oru million tokens-kku $2, cache read $0.10 (input-la 5%), 5-minute cache write $2.50, output $10. Adhanaala Sonnet 5.5-la, corpus RAG context-a vida sumaar 20 madangukku keezha irukkura varaikkum, cache panna oru corpus oru kelvikku RAG prompt-a vida kammiyaa thaan aagum. Cache-la irundhu padikkura oru 60,000-token handbook, 3,000 fresh tokens-kku samamaana cost aagum. Mattra models, providers caching-a vera maadhiri price panraanga (Claude Haiku 5.5-la oru cache read input-la 10%), adhanaala ungalodhadhukku kanakkai thirumba podunga.

Sikkalgal: default-aa, use pannaama 5 nimisham aanaa cache expire aagidum, adhanaala steady traffic irundhaa thaan palan; prompt-oda aarambathula endha maathamum adhai udaichudum; romba neelamaana inputs-la accuracy kuraiyum ("lost in the middle" effect); neelamaana inputs mudhal token-a medhuvaakkum. "Long context or RAG" lesson ivattrai aazhamaa cover pannudhu.

**RAG.** Corpus periyadhaa irukkumbodhu (ovvoru call-kkum neenga panam katta virumburadhai vida romba adhigamaa), adikkadi maarumbodhu, ovvoru user-oda permissions-aiyum madhikkanum-naa, illa answers oru passage-a cite pannanum-naa idhai use pannunga. Idhukku chunking, indexing, tuning venum, search edhai thavara vidudho adhai idhuvum thavara vidum.

**Tools, agentic search.** Live, structured data-kku (oru fixed-deposit rate, oru order status, oru balance), system of record-a oru tool moolamaa query pannunga. Documents mela RAG oru pazhaiya number-a tharalaam; oru database query tharaadhu. Model thaane step by step thedura agentic search, adutha lookup mundhaiyadhai poruthu irukkura kelvigalukku porundhum. Idhu adhigamaa selavaagum: ovvoru step-um valarndhukitte pora conversation-a thirumba anuppum. Udhaaranamaa, 2,000 tokens instructions-la ovvonnum 3,000 tokens results serkkura aaru steps mothamaa 57,000 input tokens anuppum, oru RAG call-kku sumaar 4,000 thaan.

### Step 4: form-kkaaga mattum, volume-la fine-tune pannunga

Niraiya nalla examples ulla oru narrow task-la, prompting velai senjaalum adhiga volume-la romba neelamaa, romba selavaa, romba medhuvaa illa innum thodarchi illaama irundhaa fine-tuning porundhum: 30 labels ulla oru classification, millions of replies muzhukka oru house style, oru periya model-kku samamaa irukka vendiya oru chinna model.

**Facts retrieval-la irukkanum.** Rendu EMNLP 2024 papers-a peroda therinju vachukkiradhu nalladhu. Ovadia kuzhu ("Fine-Tuning or Retrieval? Comparing Knowledge Injection in LLMs"), pazhakkamaana knowledge, muzhukka pudhu knowledge rendukkume unsupervised fine-tuning-a RAG jeyichudhu-nnu kandupidichudhu. Gekhman kuzhu ("Does Fine-Tuning LLMs on New Knowledge Encourage Hallucinations?"), supervised closed-book question answering-la, pudhu facts ulla examples medhuvaa thaan kathukkappadudhu, kathukitta piragu hallucination-a koottudhu-nnu kandupidichudhu. Models perumbaalum facts-a pre-training-la irundhu thaan edukkudhu; fine-tuning, therinjadhai eppadi use pannanum-nu avattrukku kathukkodukkudhu.

"Fine-tuning"-la vera vera data thevaigal ulla pala methods adangum:

| Method | Training data | Vazhakkamaana use |
| --- | --- | --- |
| Supervised fine-tuning (SFT) | Ideal outputs-oda jodi serthu inputs | Format, style, classification, extraction |
| Preference tuning, udhaaranamaa DPO | Oru nalla answer, oru mosamaana answer jodigal | Tone, helpfulness, edhai marukkanum |
| Reinforcement fine-tuning | Prompts kooda answers-kku score podura oru grader | Check pannakkoodiya answers, kammiyaana labels ulla tasks |
| Distillation | Oru periya model-oda outputs, SFT data-vaa | Oru task-la periya model-a copy panra oru chinna, malivaana model |

Perumbaalaana teams LoRA use panraanga, adhu model-oda ella weights-aiyum train pannaama oru chinna add-on-a train pannum; fine-tuning eppadi work aagudhu, practice-la fine-tuning pathina lessons indha methods-a cover pannudhu. Endha plan-kkum munnaadi rendu practical checks varum. Mudhalla, availability: ella model-um fine-tuning tharradhilla, andha offer-um maarum. OpenAI 8 May 2026 thedhiyitta oru update-la, adhoda fine-tuning platform-a padippadiyaa niruthuradhaa solluchu, adhu inime pudhu users-kku kidaikkaadhu. Unga provider-oda documentation-a check panni thedhiyai ezhudhi vainga. Neengale train panni host panra open-weight models indha risk-a thavirkkum, aanaa GPUs-um skills-um venum. Rendaavadhu, distillation-kku terms of use-a padinga: potti models-a train panna thangaloda outputs-a use panradhai niraiya providers thadai panraanga.

### Ovvoru option-aiyum ore test set-la alanga

Ovvoru candidate-kkum adhe kelvigal, graders, cost, latency alavedugalai use pannunga. Test set-a problem type vaariyaa piringa: private illa sameebathiya facts thevaippadura kelvigal, format illa behaviour pathina kelvigal. Mudhal kuzhuvula knowledge options jeyikkanum; jeyikkalainaa, unga diagnosis thappu.

```python
def compare(approaches, test_set, grade):
    """approaches: dict name -> function(question) returning (answer, cost_inr, latency_ms)."""
    rows = []
    for name, fn in approaches.items():
        scores, costs, lat = [], [], []
        for case in test_set:
            answer, cost, ms = fn(case["question"])
            scores.append(grade(case, answer)); costs.append(cost); lat.append(ms)
        lat.sort()
        rows.append((name, sum(scores) / len(scores), sum(costs) / len(costs), lat[int(0.95 * (len(lat) - 1))]))
    print(f"{'approach':<22}{'quality':>8}{'₹/req':>8}{'p95 ms':>8}")
    for name, q, c, p95 in rows:
        print(f"{name:<22}{q:>8.0%}{c:>8.3f}{p95:>8.0f}")
    return rows
```

### Fine-tuning-a sirandha malivaana baseline-kku edhiraa price pannunga

Maasaandhira semippai, oru kurugiya payanulla kaalathukkaana build cost-oda oppidunga. Build cost-naa GPU mani nerangal mattum illa, data-vai segarichu check pannavum evals run pannavum aagura manushangaloda neramum thaan. Kurugiya kaalam yadhaarthamaanadhu, yenna oru sirandha base model adikkadi sila maasathulaye varum, velai thirumbavum seiyyanum.

```python
def finetune_break_even(requests_per_month, cost_now_inr, cost_tuned_inr,
                        build_cost_inr, upkeep_per_month_inr, life_months=6):
    saving = (cost_now_inr - cost_tuned_inr) * requests_per_month - upkeep_per_month_inr
    total = saving * life_months - build_cost_inr
    months = build_cost_inr / saving if saving > 0 else float("inf")
    return {"monthly saving ₹": round(saving), f"net over {life_months} months ₹": round(total),
            "months to break even": round(months, 1)}

print(finetune_break_even(2_000_000, 0.414, 0.01, build_cost_inr=400_000, upkeep_per_month_inr=40_000))
print(finetune_break_even(2_000_000, 0.056, 0.01, build_cost_inr=400_000, upkeep_per_month_inr=40_000))
```

Keezha irukkura worked example inputs-a vilakkudhu. Mudhal line, fine-tuning-a cache pannaadha oru periya model-kku edhiraa price pannudhu: maasam ₹7.68 latcham semippu, 0.5 maasathula break-even. Rendaavadhu, prompt cache panna adhe model-kku edhiraa price pannudhu: maasam ₹52,000 semippu, break-even-kku 7.7 maasam, aaru maasathula ₹88,000 net loss. Adhe fine-tune, edhiraana badhil. Erkanave velai seiyyura romba malivaana option-kku edhiraa thaan eppavum price pannunga.

Crossover mukkiyam. **3. Maasam 20 latcham log lines-a 30 categories-aa classify panradhu.** Innaikku avanga Sonnet 5.5-a ovvoru thadavaiyum fresh-aa anuppura oru 2,000-token prompt-oda (category definitions, examples) call panraanga, kooda sumaar 100 tokens log line, 20 tokens output. Adhu oru line-kku sumaar ₹0.41, illa maasam ₹8.3 latcham. Avangakitta 50,000 labelled lines irukku, oru vendor oru chinna open-weight model-a fine-tune pannith tharradhaa solraanga: build panna ₹4 latcham, maintain panna maasam ₹40,000, serve panna oru line-kku ₹0.01-nnu vachukkuvom.

Innaikku bill-kku edhiraa paarthaa, fine-tuning rendu vaarathula panathai thiruppum. Aanaa mudhalla avanga prompt-a cache panraanga. Nimishathukku sumaar 46 lines-la cache orubodhum cold aagaadhu, 2,000-token prompt 512-token minimum-kku mela irukku. Accuracy-la endha maathamum illaama cost oru line-kku sumaar ₹0.056-kku (maasam ₹1.13 latcham) kuraiyudhu. Andha baseline-kku edhiraa, adhe fine-tune panathai thiruppa 7.7 maasam aagum. Adhe cached prompt-oda Haiku 5.5-aiyum try panraanga: oru line-kku sumaar ₹0.004, maasam ₹7,500, aanaa accuracy 96%-la irundhu 91%-kku kuraiyudhu-nnu vachukkuvom. Lines avasaram illa, adhanaala November 2026 nilavarappadi Anthropic-la paadhi vilaiyaana batch API, endha bill-aiyum innum kuraikkum.

Volume thaan mudivu pannudhu. Aaru maasa kaalathukku, mela irukkura inputs cached baseline-kku edhiraa maasam sumaar 23 latcham lines break-even volume-a tharudhu. Rendu pudhu clients adutha quarter-la volume-a maasam 1 crore lines-kku kondu poovaanga. 10,000 labels-la oru pilot fine-tune test set-la 96% score pannudhu, Sonnet-oda samamaa, appadinnu vachukkuvom. 1 crore lines-la fine-tune maasam sumaar ₹4.2 latcham semikkum, sumaar oru maasathula panathai thiruppum. Haiku innum malivaa irukkum, aanaa adhoda 5-point idaiveli maasam sumaar 5 latcham koodudhal thappaana tags-nnu artham. Adhanaala avanga **innaikku prompt-a cache panni, periya volume-kku fine-tune panraanga**, cached prompt-a fallback-aavum baseline-aavum vachukittu.

## Podhuvaa panra thappugal

- **Facts serkka fine-tune panradhu.** Facts context-la irukkanum, long context, RAG illa oru tool moolamaa.
- **Prompt-a skip panradhu.** Adhudhaan romba malivaana fix, adikkadi podhumaanadhu, mattra ellaame jeyikka vendiya baseline.
- **JSON format-kkaaga fine-tune panradhu**, structured output-a try panradhukku munnaadiye.
- **Oru chinna, nilaiyaana document-kku RAG build panradhu**, adhai cached long context innum elimaiyaa handle pannum.
- **Rates, balances maadhiri live numbers-kku documents mela RAG use panradhu**, oru tool-kku badhilaa.
- **Cache pannaadha oru bill-kku edhiraa fine-tuning-a price panradhu.** Mudhalla prompt-a cache panni oru chinna model-a try pannunga, appuram oppidunga.
- **Build cost-la manushangaloda nerathai vittudradhu**, illa oru neelamaana payanulla kaalathai assume panradhu.
- **Vera vera test sets-la** illa vera graders-oda options-a oppidradhu.
- **Oru fine-tuning service-a nambi plan panradhu**, adhu innaikku unga model-kku irukkaa-nnu check pannaama.

## Thervu erkanave thelivaa irukkum nerangal

- **Badhil private documents-a cite pannanum**: vera enna serthaalum, retrieval.
- **Data oru database-la irukku**: oru tool, documents-oda index illa.
- **Kuraivaana volume**: fine-tuning aridhaa thaan panathai thiruppum; prompt-a membaduthunga.
- **Task ovvoru sila vaarathukkum maarudhu**: marupadi train panradhai vida prompts, retrieval vegamaa maarikkum.
- **Ungakitta labelled examples illa**: fine-tuning innum mudiyaadhu; review panna outputs-la irundhu avattrai segarikka aarambinga.

## Demo-la irundhu production-kku

- **Oru test set vachirunga**, problem type vaariyaa pirichu, ovvoru approach-kkum adhai use pannunga.
- **Ovvoru option-kkum quality, cost, p95 latency-a** thedhigaloda padhivu pannunga.
- **Caching-a nambiyirundhaa cache hit rate-a gavaninga**; sathamillaadha oru irakkam bill-a pala madangaakkalaam.
- **Prices, volumes illa models maarumbodhu break-even-a** thirumba kanakkidunga.
- **Review panna outputs-a edhirkaala training data-vaa segaringa**, innum fine-tune pannalainaalum.
- **Fine-tuned models-a ovvoru pudhu base model-kkum edhiraa** oru nalla, cached prompt-oda thirumba test pannunga.

## Practice pannunga

Keezha link panniyirukkura, production-kkaana LLM applications uruvaakkuradhu pathina Chip Huyen-oda katturaiyai padinga.

1. Ungalukku therinja moonu problems-kku, ovvonnukkum 20 fail aana outputs-a padichu, problem knowledge-aa behaviour-aa-nnu sollunga.
2. Oru knowledge problem-kku, unga provider-oda thatpodhaiya prices vachu oru kelvikku cached long context-a RAG-kku edhiraa price pannunga, check panna thedhiyai avattrukku pakkathula ezhudhunga.
3. Oru behaviour problem-kku, rendu prompt membaadugalaiyum structured output-aiyum try panni, oru chinna test set-la `compare` vachu alanga.
4. `finetune_break_even`-a rendu thadavai run pannunga: unga thatpodhaiya bill-kku edhiraa, unga romba malivaana, velai seiyyura baseline-kku edhiraa. Endha volume-la fine-tuning panathai thiruppa aarambikkudhu-nnu kandupidinga.
