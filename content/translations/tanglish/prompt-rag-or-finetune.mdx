## Idhu enna

Oru language model neenga ketkradha seiyalannaa, adha improve panna main moonu vazhigal irukku:

- **Better prompting**: thelivaana instructions, examples, structure, format.
- **RAG (retrieval-augmented generation)**: unga documents illa data-la irundhu poruththamaana information-a eduthu, prompt-la podradhu.
- **Fine-tuning**: unga own examples mela model-a innum train panni, oru behaviour-a kathukka vaikkiradhu.

Avai vera vera problems-a solve pannum, aduthadhu aduthu serthu use pannuvaanga. Nallaa choose pannaa maasakkanakkaana neram micham.

```flow
Enna thappu? -[model-ku edho onnu theriyala: facts, policies, accounts, sameebathiya nigazhvugal]-> RAG illa tools | re-index panni update; sources-a cite pannunga
Enna thappu? -[adhukku theriyum, aana thappaa panudhu: format, tone, steps, edge cases]-> Mudhalla Prompting | instructions, examples, oru template
Enna thappu? -[prompting work aagudhu, aana adhigam volume-la neelamaa, selavaa, consistent-aa illa]-> Fine-tune, adikkadi oru small model | niraiya nalla examples, evals thevai
```

Mudhirndha systems moonaiyum serkkum, ovvonnum ore test set-la check pannapadum.

Indha lesson, Pune-la oru software company-la irundha moonu problems-a follow pannum, ovvonnukkum vera fix thevai.

## Idhu eppadi work aagudhu

**Mudhalla problem-a kandaringa.**

- *Model-ku edho onnu theriyala* (unga products, policies, sameebathiya nigazhvugal, oru customer-oda account): idhu knowledge problem. **RAG** illa tools use pannunga. Facts serkka fine-tuning mosamaana vazhi: update panna selavu, model innum thappaa gnaabagam vechchukkalaam.
- *Model-ku podhumaana theriyum, aana task-a thappaana vazhila seiyudhu* (format, tone, steps, edge cases): mudhalla **prompting** try pannunga: instructions, examples, thelivaana format.
- *Prompting work aagudhu, aana oru narrow, high-volume task-ku neelamaa, selavaa, mella, illa innum consistent-aa illa*: niraiya nalla examples mela oru model-a, adikkadi oru small model-a, **fine-tune** panradha yosinga.

**Yen mudhalla prompting.** Adhu vegamaanadhu, mulaivaanadhu, thirumba maathalaam: oru maatrathai nimishangalla test pannalaam. "Model" mela kurai solra pala problems, thelivaana instructions, rendu nalla examples-oda maraindhidum.

**RAG eppo poruntum.** Adikkadi maarura (vaaraa vaaram update aagura oru handbook), periya (aayirakkanakkaana documents), private-aana, illa cite pannapada vendiya information. Update panradhunna re-index panradhu, thirumba train panradhu illa.

**Fine-tuning eppo poruntum.**

- Romba niraiya requests-la consistent style illa format;
- Niraiya labelled examples irukkura narrow classification illa extraction task;
- Oru small, mulaivaana model-a oru task-la periya model-oda match aakkuradhu;
- Niraiya examples edukkura prompts-a surukkuradhu.

Idhukku nooru-kanakkula aayirakkanakkula quality examples, evaluation, base model maarumbodhu thirumba seiyanum.

**Serthu use pannunga.** Oru podhuvaana mature setup: nallaa design panna oru prompt, knowledge-ku RAG, adhigam volume irukkura oru step-ku oruvelai fine-tune panna oru small model. Ovvoru maatrathaiyum ore test set-la evaluate pannunga.

**Approaches-a compare panradhu:**

| Factor | Prompting | RAG | Fine-tuning |
| --- | --- | --- | --- |
| Sari pannum | Behaviour, format | Illaadha illa maarura knowledge | Scale-la consistent behaviour |
| Try panna aagura neram | Nimishangal | Naatkal | Vaarangal |
| Thevaiyaana data | Konjam examples | Unga documents | Nooru-kanakkula aayirakkanakkula labelled examples |
| Update panradhu | Prompt-a edit | Re-index | Retrain |
| Oru request-ku cost | Prompt neelathoda valarum | Retrieval, context serkkum | Small model-oda kammiyaa irukkalaam |
| Citations | Illa | Aamaa | Illa |

**Fine-tuning eppo labam tharumnu madhippidradhu.** Ippo irukkura approach-oda maasaandhira cost-a, fine-tuned option-oda compare pannunga: adhoda payanulla kaalathula parava vitta training cost, unga volume-la serving cost, training data-va build panni maintain panna aagura neram. Fine-tuning podhuvaa, oru small model periyadha maathra high-volume, narrow tasks-la labam tharum; kammiyaana volume illa vegamaa maarura tasks-la aridhaa thaan. Kanakka ezhudhi vainga, break-even aagura volume-oda.

**Mudhalla prompt fixes-a test panradhu.** Periya maatrathukku munnaadi, oru madhiyam prompt-la selavazhinga: task-aiyum format-aiyum thelivaa sollunga, oru edge case ulpada rendu illa moonu nalla examples serunga, test set-a run pannunga. Ethana problems idhulaye theerudhunnu teams perumbaalum aachariyappaduvaanga, RAG illa fine-tuning-a madhippida oru niyaayamaana baseline-aiyum idhu tharudhu.

**Ella candidates-aiyum ore test set-la run pannunga.** Migavum niyaayamaana oppeedu, adhe kelvigal, adhe graders, adhe cost, latency alavugalai use pannum:

```python
def compare(approaches, test_set, grade):
    """approaches: dict name -> function(question) returning (answer, cost_inr, latency_ms)."""
    rows = []
    for name, fn in approaches.items():
        scores, costs, lat = [], [], []
        for case in test_set:
            answer, cost, ms = fn(case["question"])
            scores.append(grade(case, answer)); costs.append(cost); lat.append(ms)
        lat.sort()
        rows.append((name, sum(scores) / len(scores), sum(costs) / len(costs), lat[int(0.95 * (len(lat) - 1))]))
    print(f"{'approach':<22}{'quality':>8}{'₹/req':>8}{'p95 ms':>8}")
    for name, q, c, p95 in rows:
        print(f"{name:<22}{q:>8.0%}{c:>8.2f}{p95:>8.0f}")
    return rows

# compare({"prompt v3": prompt_only, "prompt + RAG": with_rag, "fine-tuned small": tuned}, tests, grade)
```

Test set-a problem type-aala piringa: private illa sameebathiya facts thevaippadura kelvigal, format illa behaviour pathina kelvigal. Mudhal group-la RAG jeikkanum, rendavadhula fine-tuning jeikkalaam; illannaa unga diagnosis thappu.

**Fine-tuning eppo labam tharum, numbers-la.**

```python
def finetune_break_even(requests_per_month, cost_now_inr, cost_tuned_inr,
                        build_cost_inr, upkeep_per_month_inr, life_months=6):
    saving = (cost_now_inr - cost_tuned_inr) * requests_per_month - upkeep_per_month_inr
    total = saving * life_months - build_cost_inr
    months = build_cost_inr / saving if saving > 0 else float("inf")
    return {"monthly saving ₹": round(saving), f"net over {life_months} months ₹": round(total),
            "months to break even": round(months, 1)}

print(finetune_break_even(2_000_000, 0.40, 0.06, build_cost_inr=600_000, upkeep_per_month_inr=50_000))
```

`build_cost_inr`-la data collect panni check panna, evals run panna aalgal-oda neram-aiyum serkkanum, GPU hours mattum illa. Kuraiyaana `life_months` realistic: pudhu base model adikkadi maasangalukkulla varum, velai thirumba varum.

**Facts retrieval-la irukkattum.** Pudhu knowledge-ku rendaiyum oppitta studies, retrieval podhuvaa jeikkudhunnu kandupidichchudhu; base model paarkkaadha facts-la fine-tune panradhu, nambikkaiyaana thappugalaiyum ookkuvikkalaam. Form-a (format, tone, oru narrow classification) kathukkodukka fine-tuning-aiyum, facts thara retrieval-aiyum use pannunga.

**Muyarchigalin varisai.** Prompt, apram prompt-oda retrieval illa tools, oru alandha idaiveli irundhu mela irukkura numbers poruntha mattum fine-tuning. Ovvoru padiyum mundhaiyadha baseline-aa vechchukkum.

## Oru worked example

Pune-la oru software company-la moonu problems:

1. *Support bot, vaaraa vaaram maarura oru product handbook-la irundhu badhil solanum.* Maarura knowledge: handbook mela **RAG**, ovvoru update-layum re-index. Fine-tuning oru vaaraththula out of date aagidum.
2. *Ticket summaries format-la maaruthu, customer-oda priority-a miss pannudhu.* Model-ku information theriyum; instruction thelivaa illa. **Prompting**: oru fixed template, priority pathina oru rule, rendu examples oru madhiyathula 90% cases-a sari pannidum.
3. *Maasathukku 2 million log lines-a 30 categories-la periya model-oda classify panna romba selavaagudhu.* Avangakitta pazhaya velaiyila irundhu 50,000 labelled lines irukku. Oru small model-a **fine-tune** pannunga: avanga test set-la adhu periya model-oda accuracy-kku match aagudhu, cost-um latency-yum oru siru pangu thaan.

| Problem | Diagnosis | Approach | Result |
| --- | --- | --- | --- |
| Support bot, vaaraa vaaram maarura handbook | Knowledge | RAG, ovvoru update-layum re-index | Eppavum current |
| Ticket summaries maaruthu, priority miss | Behaviour | Template, oru priority rule, rendu examples | Oru madhiyathula 90% sari |
| Maasathukku 2 million log lines, romba selavu | Narrow task-la volume | 50,000 labels mela fine-tune panna small model | Adhe accuracy, cost-um latency-yum romba kammi |

## Podhuvaa panra thappugal

- **Facts serkka fine-tune panradhu.** Retrieval use pannunga.
- **Prompting-a vittudradhu.** Adhu romba mulaivaana fix, adikkadi podhum.
- **Fashion-la choose panradhu.** Knowledge-aa behaviour-aanu diagnose pannunga.
- **Evaluation set illaama irukkradhu.** Adhu illaama approaches-a compare panna mudiyaadhu.
- **Maintenance-a marakkuradhu.** Fine-tuned models retrain aaganum; RAG-ku fresh indexes thevai.
- **Approaches-a vera vera test sets-la** illa vera graders-oda compare panradhu.
- **Aalgal-oda neram-a** fine-tuning cost-la serkkaama vidradhu.
- **Maarura facts-a add panna fine-tune panradhu**, adha retrieval nallaa paarthukkum.

## Choice munnaadiye thelivaa irukkura neram

- **Badhil private documents-a cite pannanum**: retrieval, vera enna serthaalum.
- **Kammiyaana volume**: fine-tuning aridhaa thaan payan tharum; prompt-a improve pannunga.
- **Task ovvoru sila vaaraththukkum maarum**: prompts-um retrieval-um retraining-a vida vegamaa adapt aagum.
- **Labelled examples illa**: fine-tuning ippo mudiyaadhu; reviewed outputs-la irundhu avatrai sekarikka aarambinga.

## Demo-la irundhu production-ku

- **Oru test set vechchukonga**, problem type-aala pirichchu, ovvoru approach-kum adhai use pannunga.
- **Ovvoru option-kum quality, cost, p95 latency-a** dates-oda record pannunga.
- **Prices, volumes, models maarumbodhu break-even-a** thirumba kanakku pannunga.
- **Reviewed outputs-a** future training data-vaa sekaringa, ippo fine-tune pannalannaalum.
- **Fine-tuned models-a**, pudhu base models nalla prompts-oda varumbodhu thirumba test pannunga.
