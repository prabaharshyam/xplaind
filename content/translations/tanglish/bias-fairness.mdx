## Idhu enna

Oru AI system nalla kaaranam illaama sila groups-ku mosamaa velai seiyumbodhu, alladhu avangala pathi mosamaa mudivu pannumbodhu, adhu **biased**. Andha groups gender, caste, religion, region, language, age, disability alladhu income vechu define aagalaam. **Fairness**-na andha vithiyaasangala kandupidikkuradhu, adhula evai niyaayamillaadhadhu-nnu mudivu panradhu, avatrai kuraikkuradhu.

Bias rendu vagaiyaana harm-a undaakkudhu:

- **Allocation harm:** mukkiyamaana onnai system kudukkudhu alladhu marukkudhu, udhaaranamaa oru loan, oru job interview alladhu oru welfare benefit.
- **Quality-of-service, representation harm:** system sila perukku verumane mosamaa velai seiyudhu, alladhu avangala stereotypes vazhiyaa vivarikkudhu. Udhaaranamaa, Bhojpuri accent-la fail aagura oru voice assistant, alladhu oru surname-a oru kurippitta velaiyoda inaikkura oru chatbot.

Bias aridhaa dhaan venumne nadakkudhu. "Indha district-la irundhu varra applicants-a reject pannu"-nnu yaarum rule ezhudhuradhilla. Adhu perumbaalum **system kathukkitta data**-la irundhum, **system use aagura vidhathula** irundhum varudhu.

```flow
dir: LR
title: Niyaayamillaadha history ulla ponaa, niyaayamillaadha predictions veliya varum
Kadandha kaala decisions | engineering roles-ku perumbaalum aangal dhaan hire aanaanga -> Model kathukkudhu | pattern-a, merit-a illa
Model kathukkudhu -> Model repeat pannudhu | pudhu roles-ku pengala keezha rank pannudhu
```

Loans, jobs, admissions, insurance, welfare pathina mudivugala AI evvalavukku evvalavu edukkudho, shape pannudho, avvalavukku idhu innum mukkiyamaagudhu. Oru biased spell-checker erichal dhaan tharum. Oru biased loan model vaazhkkaiyaiye maathidum, adhe thappai oru naalaikku aayirakkanakkaana thadavai repeat pannum.

Indha lesson, thannoda resume-screening tool unfair-nu kandupidichu adhai fix panra oru Bengaluru startup-a follow pannudhu. Kadaisiyila bias enga irundhu varudhu-nnu sollavum, oru simple ratio vechu adhai alakkavum, caste alladhu religion data kaiyila illaamale test pannavum, sariyaana fixes-a therndhedukkavum ungalaala mudiyum.

## Idhu eppadi work aagudhu

### Bias enga irundhu varudhu

| Source | Enna nadakkudhu | Indian udhaaranam |
| --- | --- | --- |
| **Historical labels** | Model kadandha kaala decisions-a copy pannudhu, avai fair-aa irundhaalum illainaalum | Munnaadi hiring sila colleges-aiyum perumbaalum aangalaiyum favour pannuchu, adhanaala model-um appadiye pannudhu |
| **Missing data** | Kammi examples irukkura groups-ku mosamaana results kidaikkudhu | Perumbaalum urban English speakers mela train aana oru speech model rural accents-la thadumaarudhu |
| **Proxies** | Matha features oru sensitive trait-ku badhilaa nikkudhu | Surname, PIN code alladhu college, caste, religion alladhu income-a kaatti kudukkalaam |
| **Language** | Models adhigamaa paartha languages-la dhaan best-aa velai seiyum | Oru chatbot English-la nallaa badhil solludhu, Odia alladhu Santali-la mosamaa solludhu |
| **Use** | Oru tool adhu design pannappadaadha velaikku use aagudhu | Oru shortlist-a suggest panna vandha tool oru automatic gatekeeper aagidudhu |

Makkal adhigamaa miss panradhu mudhal row-a dhaan. Oru model **labels**-la irundhu kathukkudhu, adhaavadhu adhoda training data-la irukkura "sariyaana badhilgal". Label "ivar hire aanaaraa?" alladhu "manager ivarukku high rating kudutthaaraa?"-nnu irundhaa, model andha kadandha kaala choices-a, adhula irukkura endha unfairness-aiyum serthu, imitate panna kathukkudhu. Yaar andha velaiyila nallavanga-nnu adhu kathukkala.

### Oru field-a neekkuradhu yen podhaadhu

Mudhalla podhuvaa varra idea: "Data-la irundhu gender-aiyum caste-aiyum delete pannidunga." Idhu aridhaa dhaan work aagum, yenna matha features-layum adhe information irukku. India-la oru surname caste alladhu religion-a kaattalaam. Oru PIN code income-aiyum community-yaiyum kaattalaam. Oru college, oru school board, oru hostel role alladhu oru sport, gender, region alladhu class-a kaattalaam. Model indha **proxies**-a kandupidichu, eppadiyum pazhaya pattern-a kathukkudhu.

Oru simple check: neekkuna trait-a micha features vechu predict panna muyarchi pannunga. Oru chinna model, resume-oda micha pagudhiyai vechu gender-a chance-a vida romba nallaa guess pannaa, unga scoring model-um andha signal-a use panna mudiyum. Apram endha features andha guess-a drive pannudhu-nnu paarthu, avatrai neekkunga, coarsen pannunga, alladhu marupadi yosinga.

### Bias eppadi theriyudhu

- Ore maadhiriyaana repayment records irundhaalum, rural PIN codes-la irundhu varra applicants-a oru loan model kuraivaa approve pannudhu.
- Oru resume screener engineering roles-ku pengala keezha rank pannudhu.
- Oru image generator "a doctor"-ku perumbaalum aangalaiyum, "a nurse"-ku perumbaalum pengalaiyum varaiyudhu.
- Oru chatbot English-a vida Indian languages-la chinna, mosamaana badhilgal tharudhu.
- Oru face-analysis system sila mugangalla adhiga thappu pannudhu. 2018 Gender Shades study, photo-va vechu gender-a guess panra moonu commercial systems-a test pannuchu. Avatroda error rates darker-skinned pengalukku 34.7% varai irundhuchu, lighter-skinned aangalukku 0.8%-ku mela pogala.
- Oru language model caste stereotypes-a repeat pannudhu. October 2025-la oru MIT Technology Review investigation, Indian prompts vechu test pannappo OpenAI-oda GPT-5-um adhoda video model Sora-vum adikkadi caste stereotypes-a produce pannuchu-nnu report pannuchu.

Gender Shades result-a gavaninga. Miga mosamaana gap "pengal" alladhu "darker skin" thaniyaa illa, rendum serndha **intersection** dhaan. Eppavum oru nerathula oru trait-a mattum paarkkaama, rural pengal, alladhu vayasaana Hindi-medium applicants maadhiri combined groups-aiyum check pannunga.

### Bias-a alakkuradhu: mudhalla kanakku panna vendiya numbers

Ovvoru group-kkum moonu numbers-la aarambinga.

1. **Selection rate:** group-la nalla outcome kidaikkiravangaloda share, udhaaranamaa shortlist alladhu approve aanavanga.
2. **Selection-rate ratio:** lowest group-oda rate-a highest group-oda rate-aala divide panradhu. 30% aangalum 21% pengalum shortlist aanaa, ratio 21 ÷ 30 = 0.70.
3. **Wrongful rejection rate:** unmaiyileye qualified-aa irundhavanga, alladhu repay panniyirukkakkoodiyavangalla, model reject pannavangaloda share. Idhukku outcome data venum, aanaa applicants adhigamaa kavalaippadura error idhu dhaan.

Paravalaa use aagura oru mudhal screen 1978-oda US employment guidance-la irundhu varudhu: **four-fifths rule**. Top group-oda rate-la 80%-ku keezha select aagura oru group, adverse impact irukkalaam-ngradhukku evidence-aa paarkkappadudhu. Idhai oru rule of thumb-aa use pannunga, verdict-aa illa. Idhu Indian law illa; 0.8-ku mela irukkura ratio-vum oru unmaiyaana prachanaiyai maraikkalaam; 0.8-ku keezha irukkura ratio-ku oru fair explanation irukkalaam, udhaaranamaa job-ku thevaiyaana skills-la unmaiyaana vithiyaasam. 0.8-ku keezhana "ippove investigate pannunga"-nnu artham, "kutravaali"-nnu illa.

| Metric | Adhu badhil sollra kelvi | Gavanikka vendiyadhu |
| --- | --- | --- |
| Ovvoru group-kkum selection rate | Nalla outcome yaarukku kidaikkudhu? | Groups-ku unmaiyaana qualifications-la vithiyaasam irukkalaam |
| Selection-rate ratio | Gap evvalavu perisu? | 0.8 oru screen dhaan, India-la oru legal line illa |
| Ovvoru group-kkum wrongful rejection rate | Yaar thappaa thiruppi anuppappaduraanga? | Makkal unmaiyila eppadi perform pannaanga-nnu data venum |
| Combined groups-kkum adhe numbers | Oru intersection dhaan adhigamaa baadhikkappadudhaa? | Cells seekkirame chinnadhaagidum |

**Chinna groups noisy.** Oru group-la irundhu 30 applicants mattum vandhu, adhula 3 per shortlist aanaa adhu 10%; aanaa innum oruthar shortlist aanaa adhu 13% aagidum. Ore oru aal rate-a moonu points-ku mela nagarththuraaru. Oru group-la sumaar nooru perukku kammiyaa irundhaa, oru gap-a final answer-aa paarkkaama, innum data collect pannavo cases-a kaiyaala review pannavo oru kaaranamaa paarunga.

### Group data illaadhappo test panradhu

Perumbaalaana Indian companies caste alladhu religion-a record panradhilla, adhai saadhaaranamaa collect pannavum koodaadhu. Adhanaala test pannave mudiyaadhu-nnu illa. Moonu practical methods:

- **Paired (counterfactual) tests.** Unmaiyaana cases-oda copies-a, ore oru detail-la mattum vithiyaasam irukkura maadhiri uruvaakkunga: name, surname, PIN code, pronoun alladhu college. Rendu copies-kkum score podunga. Adhe resume-la "Priya Paswan" "Priya Sharma"-va vida kammiyaa score vaangunaa, model andha signal-a use pannudhu. Idhu chatbots-kkum work aagum: vera vera communities-a serndhavangala pathi adhe kelviyai kelunga, alladhu Hindi-layum English-layum kelunga, badhilgala compare pannunga.
- **Consent vaangina oru audit sample.** Fairness testing-ngra sollappatta purpose-kkaaga, applicants alladhu users-la oru sample-a voluntary-aa sensitive traits-a share panna azhainga. Indha data-va thaniyaa store pannunga, yaar paarkkalaam-nu limit pannunga, adhai eppavume model-ku kudukkaadheenga. DPDP Act-padi (adhoda mukkiya duties May 2027-la irundhu apply aagum), personal data-ku oru thelivaana purpose venum, perumbaalaana cases-la consent-um venum.
- **Region, language vaariyaa outcome review.** Personal traits illaattiyum, state, PIN code area, interface language podhuvaa ungalukku theriyum. Idhai vechu results-a pirichaa, adikkadi adhe gaps veliya varum.

Aasai kaattura oru shortcut-la gavanamaa irunga: unga data-ku label poda, ovvorutharoda caste alladhu religion-a avanga surname vechu guess panradhu. Andha guesses adikkadi thappaa irukkum, adhoda, othukkave othukkaadha makkala pathi neenga ippo sensitive data-va uruvaakkitteenga.

### Enna seiyalaam

1. **Launch-ku munnaadi group vaariyaa test pannunga**, mela irukkura numbers vechu, combined groups-aiyum serthu.
2. **Data-va fix pannunga.** Under-represented groups-la irundhu examples serunga, rebalance pannunga, labels-a kelvi kelunga. "Hire aanaanga"-ngradhum "velaiyai nallaa seivaanga"-ngradhum onnu illa.
3. **Proxies-a neekkunga alladhu coarsen pannunga**, apram re-test pannunga, yenna andha idathukku pudhu proxies varalaam.
4. **Product-a maathunga.** Model mudivu panradhukku badhilaa suggest pannattum. Train aana oruthar rejections-a review panni, model-a overturn pannalaam.
5. **Explain pannunga, appeal panna vazhi kudunga.** Baadhikkappattavangalukku mukkiya kaaranangalum, oru decision-a challenge panna oru thelivaana vazhiyum kidaikkanum.
6. **Launch-ku apram monitor pannunga.** Group tests-a oru schedule-padiyum, endha model, data alladhu policy change-ku apramum repeat pannunga.

```flow
dir: LR
title: Fairness loop
Build -> Group vaariyaa test -> Kaaranathai kandupidi -> Data, features alladhu process-a fix pannu -> Marupadi test
Marupadi test -[launch-ku apramum ovvoru change-kkum repeat]-> Group vaariyaa test
```

### Fairness-la trade-offs irukku

Fairness-ku onnukku merpatta definitions irukku, avai onnoda onnu modhalaam:

| Definition | Artham | Trade-off |
| --- | --- | --- |
| Equal approval rates | Ovvoru group-um ore rate-la approve aagudhu | Repayment-la kashtappada vaaippirukkuravangalaiyum approve pannalaam |
| Equal error rates | Ovvoru group-layum model nalla applicants-a sama alavu adikkadi thappaa reject pannudhu | Approval rates appavum verupadalaam |
| Ore maadhiriyaanavangalukku ore treatment | Ore record irukkura rendu perukku ore result | "Ore maadhiri"-na ennanu agreement venum |

Mudhal rendum yen modhudhu-nnu paarunga. Group A-la 100 applicants-la 80 per repay pannuvaanga, Group B-la 60 per-nu vechukkonga. (Idea-va kaatta indha numbers-a uruvaakkinom.) Oru perfect model sariyaa andha 80 peraiyum 60 peraiyum approve pannum. Rendu group-layum adhu endha error-um pannala, adhanaala error rates samam, aanaa approval rates 80%, 60%. Ippo rendu groups-aiyum 70% approval rate-ku force pannunga. Group A-la repay panniyirukkakkoodiya 10 perai neenga reject pannanum. Group B-la repay pannappogaadha 10 perai approve pannanum. Equal approval rates samamillaadha errors-a uruvaakkiduchu. Researchers idhu sambandhamaana results-a prove panniyirukkaanga: base rates verupadumbodhu, oru risk score ovvoru group-layum ore repayment chance-a kurikkavum, ovvoru group-layum equal error rates irukkavum ore nerathula mudiyaadhu, adhu perfect-aa predict pannaadha varai.

Adhanaala oru definition-a therndhedukkuradhu oru value decision. Baadhikkappaduravanga, law, system-oda purpose idhaiyellaam manasula vechu andha mudivai velippadaiyaa edunga, yen-nu ezhudhi vainga. Model-a train panravangakitta adhai vittudaadheenga. Base rate verupadradhe kadandha kaala unfairness-oda vilaivaa irukkalaam; labels-a kelvi kekka adhu innoru kaaranam.

### Law enna solludhu

November 2026 nilavarappadi, algorithmic bias pathi kurippaa ezhudhappatta law India-la illa, adhukkaaga models-a test panna oru podhuvaana legal duty-yum illa. Aanaa oru model seiyura vishayangalukku, irukkura laws innum apply aagum. Udhaaranamaa, Code on Wages, 2019, ore alladhu ore maadhiriyaana velaikkaana recruitment-la gender vechu discriminate panradhai employers-ku thadai pannudhu. Rendu guidance documents fairness-a oru core principle-aa solludhu: November 2025-la vandha India's AI Governance Guidelines, financial sector-kkaaga August 2025-la vandha Reserve Bank of India-voda FREE-AI committee report. Rendume guidance dhaan, penalties irukkura binding rules illa.

EU AI Act, hiring-layum makkaloda credit scoring-layum use aagura AI-a **high-risk**-aa paarkkudhu. Adhanaala data quality, human oversight, records, transparency mela duties varudhu. May 2026-la EU lawmakers indha high-risk duties-a December 2027-ku thalli vaikka othukkittaanga, June 2026-la andha change formal-aa adopt aachu. EU-la use aagura tools vechirukkura Indian firms-kkum ivai apply aagum.

## Oru worked example

Oru Bengaluru startup oru periya IT client-kkaaga oru resume-screening tool-a build pannudhu. Client-oda anju varusha hiring decisions mela model-a train pannudhu: endha resumes shortlist aachu, edhu aagala. Label "shortlist aachaa", adhanaala model pazhaya recruiters-a copy panna kathukkudhu.

**Group vaariyaa test panradhu.** Launch-ku munnaadi, job-oda minimum requirements-a ellaarume meet panna, engineering roles-kkaana 2,400 pazhaya applicants mela team tool-a run pannudhu. Tool avangalla 480 perai (20%) shortlist pannudhu. Table **adhe 2,400 perai** rendu vidhamaa pirikkudhu, college vaariyaa, gender vaariyaa, koodave oru combined group. Indha figures illustrative, indha lesson-kkaaga uruvaakkinadhu.

| Group | Applicants | Fix-ku munnaadi shortlist | Fix-ku apram shortlist |
| --- | --- | --- | --- |
| Anju prabalamaana colleges | 400 | 180 (45%) | 92 (23%) |
| Matha colleges | 2,000 | 300 (15%) | 388 (19.4%) |
| Aangal | 1,600 | 384 (24%) | 328 (20.5%) |
| Pengal | 800 | 96 (12%) | 152 (19%) |
| Matha colleges-a serndha pengal | 680 | 56 (8.2%) | 120 (17.6%) |
| Anju colleges-a serndha aangal | 280 | 140 (50%) | 60 (21.4%) |

**Fix-ku munnaadi ratios-a kanakku panradhu.** Anju colleges-ku edhiraa matha colleges: 15 ÷ 45 = 0.33. Aangalukku edhiraa pengal: 12 ÷ 24 = 0.50. Anju colleges-a serndha aangalukku edhiraa matha colleges-a serndha pengal: 8.2 ÷ 50 = 0.16. Ellaame 0.8-ku romba keezha, combined group dhaan adhigamaa baadhikkappadudhu.

**Kaaranathai kandupidikkuradhu.** Team oru paired test run pannudhu. 200 unmaiyaana resumes-a eduthu, ovvonnukkum gender signals-la mattum vithiyaasam irukkura rendu copies pannudhu: oru aanoda per alladhu oru pennoda per, apram oru line, oru copy-la "Captain, college cricket team", innonnula "Captain, women's cricket team". Perumbaalaana pairs-la pengaloda versions kammiyaa score vaangudhu. Thaniyaa, oru chinna model resume-oda micha pagudhiyai vechu gender-a chance-a vida romba nallaa predict pannudhu. College names, gendered words, sila hobbies proxies-aa velai senjuttu irundhuchu.

**Fix.** Model score panradhula irundhu names, photos, college names, gendered terms-a team neekkudhu. Training examples-a rebalance panni, oru skills test score-a input-aa serkkudhu. Apram, comparison fair-aa irukka shortlist size-a 480-laye vechu, marupadi group vaariyaa test pannudhu.

**Fix-ku apram ratios-a kanakku panradhu.** Anju colleges-ku edhiraa matha colleges: 19.4 ÷ 23 = 0.84. Aangalukku edhiraa pengal: 19 ÷ 20.5 = 0.93. Ella combined groups-layum paarthaa, ippo highest rate anju colleges-a serndha pengalukku dhaan (120-la 32, 26.7%), adhanaala lowest-a highest-oda compare pannaa 17.6 ÷ 26.7 = 0.66. Thanithani gaps romba kuranjuduchu, aanaa combined view innum 0.8-ku keezha dhaan; adhanaala andha gap skills test scores kooda othu pogudhaa-nnu team check panni, andha judgement-a record pannudhu.

**Model-a mattum illa, product-aiyum maathuradhu.** Ippo tool makkala automatic-aa reject panradhukku badhilaa, kaaranangaloda oru shortlist-a suggest pannudhu. Recruiters ovvoru vaaramum rejections-la oru sample-a review panraanga, adhula edhai venumnaalum overturn pannalaam. Candidates oru human review kekkalaam. Team ovvoru quarter-um, ovvoru model update-ku apramum group tests-aiyum paired tests-aiyum repeat panni, results-a client-ku report pannudhu.

Model innum fair aachu, aanaa periya maatram adhu use aana vidhathula dhaan.

## Podhuvaa panra thappugal

- **Overall accuracy-a mattum paarkkuradhu.** Oru system average-aa accurate-aa irundhum oru group-ku unfair-aa irukkalaam. Eppavum results-a pirichu paarunga, combined groups-aiyum serthu.
- **Oru sensitive field-a neekkunaa bias poyidum-nu ninaikkuradhu.** Surname, PIN code, college, wording maadhiri proxies appadiye irukkum. Avai trait-a predict pannudhaa-nnu test pannunga.
- **Four-fifths rule-a oru pass mark-aa paarkkuradhu.** 0.85 ratio fairness-a prove pannaadhu, 0.75 discrimination-a prove pannaadhu. Enga paarkkanum-nu dhaan adhu sollum.
- **Romba chinna groups-a namburadhu.** 20 perai vechu varra oru rate, ovvoru aalukkum anju points aadalaam. Innum data collect pannunga, alladhu cases-a kaiyaala review pannunga.
- **Data-ku label poda surnames vechu caste alladhu religion-a guess panradhu.** Idhu adikkadi thappaa irukkum, consent illaama sensitive data-va uruvaakkum. Adhukku badhilaa paired tests alladhu consent vaangina audit sample use pannunga.
- **AI maths-ngradhaala neutral-nu ninaikkuradhu.** Adhu kathukkitta labels-aiyum decisions-aiyum dhaan pradhibalikkum.
- **English-la mattum test panradhu.** Indian users niraiya languages pesuraanga; unga users unmaiyila use panra languages-la test pannunga.
- **Verum rubber stamp-aa irukkura human review.** Model sollradhula kittathatta ellaathaiyum reviewers approve pannaa, unmaiyila manushanga control-la illa. Avangalukku neram, kaaranangal, overrule panra power kudunga.
- **Oru thadavai test pannittu marandhuduradhu.** Data, users, policies maarumbodhu launch-ku apramum bias varalaam.
