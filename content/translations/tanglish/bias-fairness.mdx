## Idhu enna

Oru AI system sila groups-ku (gender, caste, religion, region, language, age, disability, income, vera traits) mosamaa work pannina illa unfair-aa nadathina, adhu **biased**. **Fairness**-na, nyaayam illaadha andha differences-a kandupidichu kuraikkura velai.

AI-la bias perumbaalum ennam vechu varaadhu. "Indha district applicants-a reject pannu"-nu yaarum rule ezhudhaadhu. Adhu perumbaalum rendu idangalla irundhu varum: **system kathukkitta data**, **system eppadi use aagudhu**.

```flow
dir: LR
title: Unfair history ulla pona, unfair predictions veliya varum
Pazhaya decisions | engineering roles-ku perumbaalum aangal hire aanaanga -> Model kathukkudhu | "aangal = nalla engineers": oru pattern, unmai illa
Model kathukkudhu -> Model thirumba seiyudhu | pudhu engineering roles-ku pengala kuraivaa rank pannudhu
```

Loans, jobs, school admissions, insurance, welfare pathi AI mudivu edukkum podhu illa adhai shape pannum podhu idhu innum mukkiyam. Biased spell-checker thollai. Biased loan model vaazhkaiya maathum.

Indha lesson-la Bengaluru startup-a follow pannuvom, avanga resume-screening tool unfair-nu kandupidichu, adha sari panraanga. Lesson mudiyum podhu, bias enga irundhu varudhu-nu explain panna, India-la adha kandupidikka, eppadi test pannalaam-nu sollamudiyum.

## Idhu eppadi work aagudhu

### Bias enga irundhu varudhu

| Source | Enna nadakkudhu | India example |
| --- | --- | --- |
| **Historical data** | Model pazhaya unfair decisions-a copy pannudhu | Pazhaya hiring sila colleges-ayum perumbaalum aangalayum favour pannichu, adhanaala model-um appadiyae |
| **Missing data** | Konjam examples ulla groups-ku mosamaana results | City English speakers mela train panna speech system village accents-la thinarum |
| **Proxies** | Vera features oru sensitive trait-ku badhila nikkum | Surname, PIN code, college caste, religion, income-a kaattum |
| **Language** | Model adhigam paatha language-la nallaa work aagum | Chatbot English-la nallaa, Odia-la mosamaa badhil solludhu |
| **Use** | Oru tool adhukku design pannaadha velaikku use aagudhu | Suggest panna vendiya assistant automatic gatekeeper aagudhu |

### Oru field-a eduthaa podhaadhu, yen

Mudhal idea perumbaalum: "Gender-um caste-um data-la irundhu delete pannidunga." Idhu aprum work aagaadhu, yenna vera features adhe info-va kondu pogum. India-la surname caste illa religion-a kaattalaam; PIN code income-um community-yum kaattalaam; college rendayum kaattalaam. Model indha **proxies**-a kandupidichu, pazhaya pattern-a appadiyae kathukkum.

### Bias eppadi therium

- Oru loan model, oru maadhiri repayment records irundhaalum sila districts applicants-a kuraivaa approve pannudhu.
- Oru resume screener engineering roles-ku pengala kuraivaa rank pannudhu.
- Oru image generator "a doctor"-nu kettaa aangala mattum, "a nurse"-nu kettaa pengala mattum kaattudhu.
- Oru chatbot Indian languages-la English-a vida kuraivaana, mosamaana answers tharudhu.
- Oru face-recognition system karuppu skin tones-la adhigam thappu pannudhu.

### Enna seiyalaam

1. **Group-vaaraa test pannunga.** Overall mattum illa, ovvoru group-kkum accuracy-yum outcomes-aiyum measure pannunga. Bias averages-kulla olinjirukkum.
2. **Data-va sari pannunga.** Adhigam representative examples collect pannunga, rebalance pannunga, kedukkura proxies-a kuraiyungal.
3. **Makkala poruppula vainga.** Vaazhkaiya paadhikkura decisions-ku human review irukkanum, model-a override panra adhikaarathoda.
4. **Explain pannunga, appeal-a allow pannunga.** Paadhikkapatta makkalukku mukkiya reasons purinjirukkanum, decision-a challenge panna mudiyanum.
5. **Launch aana apram monitor pannunga.** Users-um data-vum maarum; group tests-a regular-aa thirumba pannunga.

```flow
dir: LR
Build -> Group-vaaraa test -> Data illa rules-a sari pannu -> Thirumba test
Thirumba test -[use-la monitor, ovvoru quarter]-> Build
```

### Fairness-la trade-offs irukku

Fairness-ku onnu-kku mela definition irukku, rendum mothalaam:

| Definition | Artham | Trade-off |
| --- | --- | --- |
| Equal approval rates | Ovvoru group-um ore rate-la approve aagum | Repayment-la kashtappada vaaippu irukkuravangala approve pannalaam |
| Equal error rates | Model ovvoru group-ku ore alavu thappu pannum | Approval rates innum vithiyaasamaa irukkalaam |
| Oru maadhiri aalgalukku ore treatment | Ore record irukkura rendu perukku ore result | "Oru maadhiri"-na enna-nu otthukkanum |

Onnu-a choose panradhu oru value decision; adha paadhikkapatta makkal, law, organisation-oda nokkam-a manasula vechu, veliyaa pannanum. Model-a train panravar mattum edukkaradhu illa.

## Oru worked example

Bengaluru startup oru periya IT client-ku resume-screening tool build panraanga. Client-oda aindhu varusha hiring decisions-la, edhu resumes shortlist aachu, edhu aagala-nu, adhula model-a train panraanga.

**Group-vaaraa testing.** Launch-ku munnaadi, oru maadhiri skills-um experience-um irukkura candidates-ku shortlist rates-a team compare panraanga:

| Group (oru maadhiri skills, experience) | Sari pannaradhuku munnaadi shortlist | Sari pannina apram |
| --- | --- | --- |
| Aindhu prasiddha colleges graduates | 48% | 31% |
| Matha colleges graduates | 14% | 27% |
| Aangal, engineering roles | 33% | 29% |
| Pengal, engineering roles | 19% | 27% |

**Kaaranam kandupidikkradhu.** Pazhaya hiring andha aindhu colleges-ayum perumbaalum aangalayum favour pannirundhudhu, model andha pattern-a kathukkittadhu. College peyargal, resumes-la "women's hostel secretary" maadhiri gendered words proxies-aa work pannichu.

**Fix.** Model score panradhula irundhu names, photos, college names, gendered words-a team eduthudhu, training examples-a rebalance panni, marubadiyum group-vaaraa test panraanga. Gaps romba kuraiyudhu, zero-ku varala.

**Model-a mattum illa, product-a maathradhu.** Tool ippo makkala automatic-aa reject pannaama, reasons-oda oru shortlist suggest pannudhu. Recruiters ovvoru rejection-aiyum review pannuvaanga. Candidates human review kekkalaam. Team ovvoru quarter-um group tests-a thirumba panni, results-a client-ku report panraanga.

Model fair aachu, aana periya maatram adhu eppadi use aagudhu-nu thaan.

## Podhuvaa panra thappugal

- **Overall accuracy mattum paakkradhu.** Oru system average-la accurate-aa irundhum oru group-ku unfair-aa irukkalaam. Eppavum results-a pirichu paarunga.
- **Sensitive field-a eduthaa bias poidum-nu nenaikkiradhu.** Surname, PIN code, college maadhiri proxies irukkum.
- **AI maths-nu neutral-nu nenaikkiradhu.** Adhu kathukkitta data-vayum decisions-aiyum prathibalikkum.
- **English-la mattum test panradhu.** Indian users pala languages pesuraanga; ungal users pesura languages-la test pannunga.
- **Human review, appeal illaama high-stakes decisions-a automate panradhu.** Oru aal-a accountable-aa vainga.
- **Oru thadava test panni marandhudradhu.** Data-vum users-um maaradhaala launch-ku apram bias varalaam.
