## Idhu enna

AI velaikku Python thaan main language: data cleaning, automation scripts, AI APIs-a call panradhu, applications build panradhu ellaam adhula thaan. Payanulla-aa irukka Python muzhusaa kathukka thevai illa. Aindhu building blocks irundhaa perumbaalaana chinna programs-a ezhudhidalaam:

| Building block | Enna pannum | Example |
| --- | --- | --- |
| **Variables** | Oru peyar-la oru value-a store pannum | `price = 250` |
| **Conditions** | Enna pannanum-nu choose pannum | `if price > 200:` |
| **Loops** | Steps-a thirumba pannum | `for item in cart:` |
| **Functions** | Reuse panna koodiya steps-a package pannum | `def total(cart):` |
| **Lists, dictionaries** | Neraya values-a vechukkum | prices list, oru student-oda details-oda dictionary |

```flow
dir: LR
Data in | orders, prices, marks -> Your program | variables hold values, loops go through each order, conditions choose a price, functions do the sum
Your program -> Result out | bills, totals, reports
```

Indha lesson Bengaluru-la oru tiffin service nadathura Divya, customers-oda bills-a kanakkida ezhudhura first useful program-a follow pannum. Mudiyum podhu neengalae 20-line program ezhudhi, adha explain panna mudiyum.

## Idhu eppadi work aagudhu

### Values, types

Python-la sila basic vagai values irukku:

| Type | Examples | Notes |
| --- | --- | --- |
| Muzhu numbers (`int`) | `250`, `-3` | Counts-ku, paise illaama rupees-ku |
| Decimal numbers (`float`) | `18.5`, `0.18` | Rates, averages-ku |
| Text (`str`) | `"Chennai"`, `'Asha'` | Eppavum quotes-kulla |
| True illa false (`bool`) | `True`, `False` | Comparisons-oda results |

Value-la irundhu Python type-a thaanaa kandupidikkum. Types naduvula `int("42")`, `float("3.5")`, `str(42)` vachu maathalaam.

### Variables

Variable-na oru value-ku oru label. Thirumba assign pannina, adhu point panradhu maarum:

```python
monthly_rent = 15000
monthly_rent = monthly_rent + 500    # now 15500
```

`x` maadhiri illaama, `monthly_rent` maadhiri clear peyargal use pannunga. Adutha maasam neengalae nandri solluveenga.

### Conditions

```python
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Pass")
```

Indentation, naalu spaces, ovvoru branch-kum endha lines-nu kaattum. Python adha romba serious-aa edukkum: thappaa indent pannina error varum, illa adhai vida mosam, program enna pannudhu-nu maarum.

Comparisons `==` (equal), `!=` (not equal), `>`, `>=`, `<`, `<=` use pannum. Oru `=` assign pannum; compare pannaadhu.

### Loops

`for` loop ovvoru item-kum oru thadavai odum:

```python
for city in ["Pune", "Kochi", "Jaipur"]:
    print("Delivering to", city)

for i in range(3):
    print(i)        # prints 0, then 1, then 2
```

`range(3)` 0, 1, 2 tharum: 0-la start aagi 3-ku **munnaadi** nikkum. `while` loop oru condition true-vaa irukkura varaikkum thirumba thirumba odum, evvalavu thadavai-nu munnaadiye theriyaadhappo useful.

### Functions

Function inputs-a edukkum, konjam velai pannum, oru result-a `return` pannum:

```python
def gst(amount, rate=0.18):
    return amount * rate

print(gst(1000))         # 180.0
print(gst(1000, 0.05))   # 50.0
```

`rate=0.18` oru default: rate-a kudukkaadhappo adhu use aagum. Ore konjam lines-a copy panra maadhiri irundhaa oru function ezhudhunga.

### Lists

Ordered collections:

```python
cities = ["Pune", "Kochi"]
cities.append("Jaipur")     # add to the end
print(cities[0])            # Pune: counting starts at 0
print(len(cities))          # 3
```

### Dictionaries

Position-ku badhila key vachu values-a thedunga:

```python
profile = {"name": "Asha", "age": 24}
profile["city"] = "Pune"     # add or change a key
print(profile["name"])       # Asha
```

**Dictionaries-oda list** thaan Python-la perumbaalaana real data-oda shape: ovvoru dictionary-um oru record, spreadsheet-oda oru row maadhiri.

### Error messages-a padikkiradhu

Edhaavadhu thappaa pona, Python oru **traceback** print pannum. Keezha irundhu mela padinga: kadaisi line error-oda peyar-a sollum, adhukku mela irukkura line enga nadandhuchu-nu kaattum.

```text
Traceback (most recent call last):
  File "bill.py", line 12, in <module>
    total = total + amount
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Idhu enna solludhu: line 12-la, oru number-oda oru text-a serkka paathingaa. Fix: value padicha edathula text-a `int()` vachu convert pannunga. Errors normal; adha amaidhiyaa padikkradhu programming-la paadhi velai.

## Oru example

Divya Bengaluru-la oru chinna tiffin service nadathuraanga, munnaadi orders-a manasulaye vechirundhaanga. Veg meals ₹90, non-veg ₹120. Avanga first useful program-a ezhudhuraanga:

```python
orders = [
    {"customer": "Ravi", "meals": 2, "veg": True},
    {"customer": "Sana", "meals": 1, "veg": False},
    {"customer": "Arun", "meals": 3, "veg": True},
]
PRICE_VEG = 90
PRICE_NONVEG = 120

def bill(order):
    price = PRICE_VEG if order["veg"] else PRICE_NONVEG
    return order["meals"] * price

total = 0
for order in orders:
    amount = bill(order)
    total = total + amount
    print(order["customer"], "owes Rs", amount)

print("Today's total: Rs", total)
```

Step by step enna nadakkudhu:

| Loop pass | Customer | Veg? | Price | Meals | Bill | Running total |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Ravi | yes | 90 | 2 | 180 | 180 |
| 2 | Sana | no | 120 | 1 | 120 | 300 |
| 3 | Arun | yes | 90 | 3 | 270 | 570 |

Program ovvoru customer-oda bill-ayum, andha naal total ₹570-ayum print pannum. Prices maarina, mela irukkura rendu lines-a edit pannaa podhum. Prices capital letters-la irukku, adhu program maathaadha settings-nu nyaabagam vechukkanum-nu.

Adutha-dhaa avanga orders-a program-kulla type panradhukku badhila CSV file-la irundhu padikka plan panraanga, adha files lesson cover pannum.

## Podhuvaa panra thappugal

- **Thappaana indentation.** `if`, `for`, `def`-kulla irukkura lines consistent-aa indent aagirukkanum, perumbaalum naalu spaces.
- **`range`-la off-by-one.** `range(3)` 0, 1, 2, 1, 2, 3 illa.
- **Text-um numbers-um kalakkaradhu.** `"5" + 3` fail aagum; mudhalla `int()` illa `str()` vachu convert pannunga.
- **Condition-la `=` use panradhu.** Compare panna `==`.
- **Function-la `return`-ku badhila `print`.** Print oru value-a kaattum; return adha use panna thirumba tharum.
- **Purinjukka mudiyaadha peyargal.** `a`, `b`, `temp` programs-a padikka kashtamaakkum; ovvonnum enna vechirukku-nu peyar vainga.
