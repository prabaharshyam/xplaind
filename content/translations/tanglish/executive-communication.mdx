## Idhu enna

Executives-ku neram kammi, neraya priorities, panam-kum risk-kum poruppu. Avangakitta nallaa communicate panradhu-na:

- **Answer first.** Conclusion-oda illa thevaiyaana decision-oda aarambinga, apram support.
- **Avanga language.** Business results (time, cost, revenue, risk, customers), model names-um architectures-um illa.
- **Proof.** Baseline-oda oru number, oru short demo, oru user-oda vaarthaigal.
- **Trade-offs, nermaiyaa.** Enna selavu, enna thappaa pogalaam, neenga enna recommend panreenga.
- **Oru clear ask.** Avangakitta enna thevai, eppa-kulla.

| Oru-page memo | |
|---|---|
| **Headline** | Recommendation: ella 180 officers-kum rollout pannunga |
| **Why** | Maasam sumaar 1,700 officer hours free aagum |
| **Evidence** | Oru file-ku 41-la irundhu 24 nimidam; rework 7%-la irundhu 5.1% |
| **Risks** | Photo edutha documents; mitigations peru sollapattirukku |
| **Ask** | Budget-a approve pannunga, oru owner-a peru sollunga, innaikku |

```flow
dir: LR
Headline -> Why -> Evidence -> Risks -> Ask
```

Appendix-la ovvoru number-um eppadi calculate aachu-nu, oru line-la kaattum.

Indha lesson, Chennai-la oru lender-oda CEO, CFO-kooda pilot mudivula nadandha meeting-a follow pannum.

## Idhu eppadi work aagudhu

**Structure.** Entha update-kum email-kum oru simple pattern:

1. *Headline*: mukkiya point oru vaakkiyathula.
2. *Why it matters*: business effect.
3. *Evidence*: rendu moonu facts.
4. *Risks illa trade-offs*: nilaimaiya maatha kudiyadhu edhu.
5. *Ask*: thevaiyaana decision illa help, date-oda.

**Avangalukku theriyura numbers.** Scope of work-la agree panna KPI-yum baseline-um use pannunga, rupees, hours, customers-la. "Maasam sumaar 1,700 officer hours micham, ippo irukkura salary costs-la varushathukku sumaar ₹50 lakh" nalla ketkum; "field extraction-la 96.4% F1" translate pannaama pona ketkaadhu.

**Executives-ku demos.** Anju nimidam, oru story: oru real case, before-after, user-oda view, oru safeguard-a kaattura oru moment. Rehearse pannunga. Network poitaa-nu oru recorded backup vechukkunga.

**Therinja questions-ku prepare aagunga.** Full scale-la enna cost? Thappaa irundha enna aagum? Namma data safe-aa? Namma aalgal enna nenaikkiraanga? Competitors panradhoda idhu eppadi compare aagudhu? Ovvondrukkum oru-line badhil ready-aa vechukkunga, kekkaradhukku detail.

**Short documents.** Decisions-ku 30-slide deck-a vida oru-page memo nalladhu. Slides kandippaa vendumna, oru slide-ku oru idea, headline thaan slide title.

**Uncertainty pathi nermaiyaa irunga.** "Full rollout-la oru file-ku 20-la irundhu 25 nimidam expect panrom; pilot branches average-a vida nalla irundhaanga, adhanaala 25-ku plan panrom" nu sonna, oru optimistic number-a vida nambikkaiyaa irukkum.

**Technical results-a translate panradhu:**

| Technical statement | Executive version |
| --- | --- |
| "Critical fields-la 96.4% accuracy" | "Muppadhu figures-la oru figure-a officers correct panraanga; ovvoru figure-kum check panna oru source irukku" |
| "p95 latency 2 seconds" | "Romba busy-aana neraththulayum answers sumaar rendu second-la varudhu" |
| "Smaller model-kum caching-kum maarinom" | "Running cost maasam ₹14 lakh-la irundhu ₹9 lakh-aa kuraichudhu, quality-la maatram illa" |
| "Recall at 5 of 0.91" | "Paththu thadavaila onbadhu thadava sariyaana document-a kandupidikkudhu" |

**60-second version.** Recommendation-aiyum adhoda evidence-aiyum oru nimidathukkulla sathamaa sollip paarunga. Neenga ketka vendiya decision, baseline-oda compare panna mukkiya result, scale-la value, cost, periya risk-um adhoda mitigation-um sollunga. Oru nimidathula solla mudiyalanaa, memo innum clear illa. Executives-oda promise panna neraththa vida kammiyaa kudupaanga, mudhal nimidam thaan meedhiya decide pannum.

**Kashtamaana questions-a handle panradhu.** Ketta kelvikku oru vaakkiyathula badhil sollitu, apram detail offer pannunga: "Aama, data India-la namma Azure region-layae irukku. Venumna architecture page kaattalaam." Theriyalanaa theriyaadhu-nu sollitu, eppa badhil solreenga-nu neram sollunga. CFO munnaadi guess panradha vida oru gap-a othukkittaa nambikkai kammiyaa pogum.

## Oru worked example

Pilot mudivula, lender-oda CEO-um CFO-vum unga-ku 15 nimidam tharaanga. Ungaloda oru-page memo:

> **Recommendation: credit-file assistant-a moonu maasaththula ella 180 officers-kum rollout pannunga.**
>
> **Result.** 20 officers-oda 10-vaara pilot-la, oru loan file-ku median time 41-la irundhu 24 nimidama kuraichudhu, credit committee thirumbi anuppura files 7%-la irundhu 5.1%-aa kuraichudhu.
>
> **Full scale-la value.** Maasam sumaar 1,700 officer hours free (6,000 files-la ovvonnukkum 17 nimidam), varushathukku sumaar ₹50 lakh; idha operations head pudhusaa aalgala edukkaama 25% adhigam applications handle panna use panna plan.
>
> **Cost.** Full scale-la run panna maasam sumaar ₹9 lakh, model costs-um support-um serthu.
>
> **Risks.** Perumbaalum photo edutha documents irukkura branches-la adoption kammiyaa irukkalaam; image clean-up step-um branch visits-um mitigation. Ella credit decisions-um officers kitta thaan.
>
> **Innaikku thevaiyaana decision:** rollout budget-a approve pannunga, operations-la oru owner-a peru sollunga.

Demo-la oru real file, officer-oda review screen, flag panna low-confidence figure correct aagurathu kaattuveenga. CFO ₹50 lakh eppadi calculate pannenga-nu kekkuraanga; appendix-la oru-line formula kaattureenga. Approval patthu nimidathula kidaikkudhu.

| Memo element | Enna sonnadhu |
| --- | --- |
| Recommendation | Moonu maasaththula ella 180 officers-kum rollout |
| Result | Oru file-ku 41-la irundhu 24 nimidam; rework 7%-la irundhu 5.1% |
| Value | Maasam sumaar 1,700 officer hours, varushathukku sumaar ₹50 lakh |
| Cost | Full scale-la maasam sumaar ₹9 lakh |
| Ask | Innaikku budget approve panni owner-a peru sollunga; patthu nimidathula approve aachu |

## Podhuvaa panra thappugal

- **Technology-yoda aarambikkiradhu.** Result-oda, decision-oda aarambinga.
- **Translate pannaadha model metrics.** Adha time, money, risk, customers-aa maathunga.
- **Simple decisions-ku neenda decks.** Oru page-ae podhum.
- **Overpromise panradhu.** Oru best-case number-a vida ranges-um downside plans-um nalladhu.
- **Ask illaama irukkradhu.** Decision ketkaama irundhaa, adhu kidaikkradhu arithu.

## Practice pannunga

Google-oda free technical writing course-la kurainjadhu mudhal unit-a eduthukkunga, idhu executive writing-ku nerukkamaa porundhum.

1. Ungaloda use case-ku anju-part structure-la oru-page recommendation memo ezhudhunga, ovvoru number-um oru source-ku trace aaganum.
2. Anju nimida demo story script pannunga: oru real case, before-after, oru safeguard.
3. Oru CFO kekkura anju questions-a list pannunga, ovvondrukkum oru-line badhil ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** Slides illaama, sathamaa, 60 nimidathukkulla ungaloda recommendation-aiyum mukkiya evidence-aiyum sollamudiyum.
