## Idhu enna

Oru language model **base model**-aa thaan aarambikkum, adhu romba periya alavu text-la adutha token-a predict panna train aagirukkum. Apram companies adha instructions follow panni, oru helpful assistant maadhiri nadandhukka innum train pannuvaanga. **Fine-tuning**-na neenga adhoda oru sinna version panradhu: irukkura oru model-a eduthu, ungaloda sondha examples-la thodarndhu train pannuveenga, appo adhoda **weights** (model-kulla irukkura numbers) ungaloda task pakkam nagarum.

Moonu vagai thodarndhu training podhuvaa irukkum:

- **Continued pre-training** oru field-oda, example legal illa medical documents-oda, innum raw text-a model-ku kudukkum. Adhu sellavaanadhu, application teams-ku arithu.
- **Supervised fine-tuning (SFT)** model-ku oru prompt-aiyum neenga virumbura exact answer-aiyum aayirakkanakkula thadavai kaattum. Idhu thaan podhuvaa edukkura choice.
- **Preference tuning** (RLHF, illa DPO-nu oru simple method) model-ku oru prompt-ku rendu answers-aiyum, makkal edhai virumbinaanga-nu-yum kaattum. Adhu tone-aiyum judgement-aiyum shape pannum.

Idhanaala thaan oru chat model, base model-a vida vidhyaasamaa nadandhukkudhu: adhu moonu-layum poitu vandhirukku. Perumbaalaana application teams SFT mattum thaan pannuvaanga, sila neram preference tuning-um.

Fine-tuning romba nallaa kathu kudukkura vishayam, oru model **eppadi respond pannanum**-ngradhu: oru format, oru tone, oru strict routine, oru narrow classification. **Facts** kathu kudukka adhu mosamaana vazhi, yenna facts maarum, model innum thappaa gnyabagam vachirukkalaam. Facts-ku retrieval use pannunga. Prompting, RAG, fine-tuning pathiya lesson rendukkum idaiyila decide panna help pannum. Indha lesson, neenga fine-tune panradhunu mudivu panna aprom enna nadakkum-nu pathi.

```flow
title: Fine-tuning loop
Task-aiyum oru test-aiyum define pannunga | nallaa-na enna?
Task-aiyum oru test-aiyum define pannunga -> Examples-a collect panni clean pannunga | quality mudhalla
Examples-a collect panni clean pannunga -> Train, validation, test-a split pannunga | test locked-aa irukkum
Train, validation, test-a split pannunga -> Konjam passes train pannunga | validation loss-a paarunga
Konjam passes train pannunga -> Prompt baseline-a vida nallaa irukkaa?
Prompt baseline-a vida nallaa irukkaa? -[illa]-> Data-va sari pannunga illa niruthunga | perumbaalum prechanai data thaan
Data-va sari pannunga illa niruthunga -> Examples-a collect panni clean pannunga
Prompt baseline-a vida nallaa irukkaa? -[aamaa]-> Pazhaya abilities-a check pannunga | forgetting
Pazhaya abilities-a check pannunga -> Deploy panni monitor pannunga | vishayam maarumbodhu retrain pannunga
```

Indha lesson-la Pune-la oru insurer, claim emails-a 12 categories-la pirikka virumburadha follow pannuvom.

## Idhu eppadi work aagudhu

1. **Training set-kku munnaadi test-a ezhudhunga.** Indha task-ku "nallaa"-na enna-nu decide pannunga, correct answers-oda unmaiyaana examples-oda oru sinna test set build pannunga. Adhu illaama, fine-tuning help pannichaa-nu theriyaadhu.
2. **Examples-a collect pannunga.** Ovvonnum oru input-um ideal output-um. Mudinja idathula, oru aal check panna pazhaya unmaiyaana velaiya use pannunga. Evvalavu thevai-nu task-a poruthu: konjam nooru arumaiyaana examples oru format-a kathu kudukkum, kashtamaana task-ku aayirakkanakkula thevai padalaam.
3. **Avatrai clean pannunga.** Duplicates-a neekkunga, thappaana labels-a sari pannunga, ellaa examples-lum format orae maadhiri irukkanum, personal data-va edunga. Model paakkura ellathaiyum, thappugal-aiyum serthu copy pannum.
4. **Data-va split pannunga.** Perumbaalaanadhu **training**-ku. Sinna paguthi **validation**, training-oda progress-a check panna. Moonaavadhu paguthi **test set**, kadaisi varaikkum adha thotta koodaadhu.
5. **Train pannunga.** Model examples-a konjam thadavai padikkum (ovvoru muzhu pass-um oru epoch), adhoda weights ideal answers-a innum possible aakkura maadhiri maarum. Neenga **loss**-a paarpeenga, model evvalavu thappa irukku-nu measure panra oru number. Training loss kuraiyanum. Training loss kuraindhukitte irukkum podhu validation loss yera aarambichaa, model examples-a memorise pannudhu, idhu **overfitting**. Angeyae niruthunga.
6. **Oru strong baseline-oda test pannunga.** Nyaayamaana comparison, base model-oda oru sumaaraana prompt illa. Nallaa ezhudhina prompt-oda, konjam nalla examples-oda base model. Fine-tuning adha theliva jeikkanum, appo thaan vachukka worth.
7. **Adhu enna marandhudhu-nu check pannunga.** Ungaloda task-ku sambandham illaadha prompts-a try pannunga. Oru narrow fine-tune oru model-a general instructions-la mosamaakkalaam, idhukku **catastrophic forgetting**-nu peyar.
8. **Deploy panni, pieces-a vachukkunga.** Data-va, labelling guide-a, settings-a, test set-a version pannunga, yenna base model illa ungaloda rules maarumbodhu retrain pannuveenga.

Oru SFT example perumbaalum oru line JSON-aa store aagum, oru short chat maadhiri ezhudhi:

```json
{"messages": [
  {"role": "user", "content": "Classify this claim email.\n\nSubject: Hospital bill for my father\nBody: He was admitted on 3 March for 4 days at a Pune hospital. Please process the cashless request."},
  {"role": "assistant", "content": "health_cashless"}
]}
```

Oru sinna script data-va split panni test set-a paadhukaakkum:

```python
import json, random

random.seed(7)                       # same split every time
rows = [json.loads(line) for line in open("claims_clean.jsonl")]
random.shuffle(rows)

n = len(rows)
test = rows[: int(n * 0.05)]         # locked away until the end
valid = rows[int(n * 0.05): int(n * 0.15)]
train = rows[int(n * 0.15):]

for name, part in [("train", train), ("valid", valid), ("test", test)]:
    with open(f"{name}.jsonl", "w") as f:
        for r in part:
            f.write(json.dumps(r) + "\n")
print(len(train), len(valid), len(test))
```

Inga duplicates mukkiyam. Orae email training-lum test-lum irundhaa, test score nallaa theriyum. Split panradhukku munnaadi exact-aanavai, kittathatta oththa duplicates-aiyum neekkunga.

**Hosted-aa illa open weights-aa?** Sila providers avangaloda models-a API vazhiyaa fine-tune panna vitturuvaanga, result-a avangale host pannuvaanga, idhu simple, aana avangala sarndhirukkanum. Open-weight models-la neengalae train panni serve pannuveenga, idhu control tharum, aana GPUs-um skills-um thevai. Availability-yum prices-um maarum, adhanaala provider-oda ippo irukkura documentation-a check pannunga. Adutha lesson periya GPU illaama open models-a eppadi train panradhu-nu solludhu.

## Oru worked example

Pune insurer maadhathukku 200,000 claim emails-a 12 categories-la pirikkudhu. Oru periya model-la aaru examples-oda oru prompt 300 labelled emails-la 78% score pannudhu, indha volume-ku oru call-ku selavu romba adhigam.

Avangakitta agents munnaadiyae label panna 40,000 emails irukku. Training-ku munnaadi, 400-oda oru sample-a check panni, 10-la sumaar 1 label thappu-nu kandupidikkuraanga, perumbaalum rendu agents "health reimbursement"-aiyum "health cashless"-aiyum vidhyaasamaa use pannadhaala. Oru-page labelling guide ezhudhi, rendu senior agents-a kuzhappamaana categories-a thirumba label pannavachchu, 3,000 duplicate emails-a neekkuraanga. Peyargal, phone numbers, policy numbers-a mask pannuraanga, adhu India-oda data protection law-padi personal data.

30,000 clean examples-la oru sinna open-weight model-a fine-tune pannuraanga, 2,000-a validation-kum, mudhal 300 test emails-a thottaama vechirukkaanga. Rendaavadhu pass-ku aprom validation loss improve aagaradhu nindhuduchu, adhanaala angeyae niruthuraanga.

| Option | 300 test emails-la accuracy | Oru email-ku relative cost | Notes |
| --- | --- | --- | --- |
| Aaru-example prompt-oda periya model | 78% | 1x (baseline) | Maatha easy, indha volume-ku sellavu adhigam |
| Adhey prompt, error review-ku aprom improve panninadhu | 84% | 1x | Oru mathiyaana velai |
| Fine-tune panna sinna model | 91% | sumaar 0.1x | Data upkeep-um retraining-um thevai |

Indha table-la numbers illustration-ku, eppadi compare pannanum-nu kaattura. Mukkiyam method: fine-tune-a *improve panna* prompt-oda (84%) judge pannraanga, mudhal prompt-oda (78%) illa.

Fine-tune panna model, indha narrow task-ku selavilum accuracy-layum theliva jeikkudhu. Aana yaaro oru podhuvaana kelvi-a adhula type pannappo badhil vichithiramaa irundhudhu, adhu forgetting. Adha classify panna mattum use panradhaala adhu pirachanai illa. Adhu eppavum customers-kitta pesaadhu-nu oru rule serkkuraanga.

## Podhuvaa panra thappugal

- **Test-ku badhila training set-oda aarambikkradhu.** Test illaama, edhaavadhu improve aachaa-nu theriyaadhu.
- **Messy labels-la train panradhu.** Model thappugal-aiyum, orumikkaama irukkura vishayangal-aiyum kathukkum.
- **Weak prompt-oda ottippaakradhu.** Mudhalla prompt-a improve pannunga, apram fine-tuning-um jeikkudhaa-nu paarunga.
- **Test examples training-kulla leak aaga vidradhu.** Splits-ku naduvula duplicates arumaiya theriyura, aana artham illaadha score tharum.
- **Facts serkka fine-tuning use panradhu.** Policies-um prices-um maarum, fine-tune update panna mella. Retrieval use pannunga.
- **Forgetting-a ignore panradhu.** Neenga train pannaadha tasks-la model-a test pannunga, illa adhu use aagura idatha restrict pannunga.
- **Training examples-la personal data-va podradhu.** Model adha thirumba solladhu, adhukku ore fix retraining thaan.

## Fine-tuning thappaana tool-aa irukkum podhu

- Prechanai missing illa maarura knowledge. Retrieval illa tools use pannunga.
- Oru nalla prompt innum try pannala. Adhukku naal illa, nimishangal thaan selavu.
- Ungakitta test set illa, illa kurainjadhu konjam nooru nalla examples illa.
- Task ovvoru maadhamum maarudhu. Neenga thodarndhu retrain pannuveenga.
- Oru answer enga irundhu vandhadhu-nu kaatta vendiyirukku. Fine-tune panna model sources-a cite panna mudiyaadhu, retrieval mudiyum.
- Volume kammi. Upkeep selavu, migaippa vida adhigam aagum.

## Demo-la irundhu production-ku

- **Ellathaiyum version pannunga.** Data, cleaning script, labelling guide, settings, test set-a version control-la vachukkunga, ovvoru result entha model-la irundhu vandhadhu-nu note pannunga.
- **Retraining-ku plan pannunga.** Base models retire aagi maathapadum, ungaloda rules-um maarum. Retraining kashtamaa irundhaa, project azhugidum.
- **Launch-ku aprom paarunga.** Ovvoru vaaramum unmaiyaana inputs-aiyum outputs-aiyum sample eduthu, ungaloda test set-oda ottippaarunga. Email vagai maarinaa, accuracy amaidhiyaa kuraiyum.
- **Oru fallback vachukkunga.** Fine-tune panna model down illa kuzhappathula irundhaa, prompt-based version-ku route pannunga.
- **Data-va document pannunga.** Enga irundhu vandhadhu, yaar label pannaanga, enna neekkappattadhu. Clients-um auditors-um kekkuvaanga.

## Practice pannunga

Oru paper exercise, apram oru sinna unmaiyaana onnu pannunga.

1. Ungaloda sondha velaila irundhu oru task-a edunga. "Nallaa"-na enna-nu ezhudhunga, correct answers-oda pathu test examples ezhudhunga.
2. Ezhudha mudinja best prompt-a, moonu examples-oda ezhudhi, andha pathula score pannunga.
3. Evvalavu clean examples unmaiyilaye collect panna mudiyum, yaar adha check pannuvaanga-nu ezhudhunga.
4. Mudivu pannunga: fine-tune, prompt-a improve, illa retrieval. Adhai justify panna moonu lines ezhudhunga.
