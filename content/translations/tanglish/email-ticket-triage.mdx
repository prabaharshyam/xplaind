## Idhu enna

**Triage**-na varra ovvoru message-um enna, evvalavu urgent, yaar handle pannanum-nu mudivu panradhu. AI triage mudhal pass-a automate pannum:

- **Classify**: edhu maadhiri message (billing, delivery, technical issue, complaint, sales enquiry, spam)?
- **Extract**: team-ku thevaiyaana details (order number, account id, product, location).
- **Prioritise**: urgent-aa illaya (service down, payment failed, legal threat, VIP customer).
- **Route**: sariyaana team-ku illa aal-ku, sariyaana tool-la.
- **Draft**: oru aal check panni anuppa, suggested reply.

```flow
Varra email illa ticket -> AI step, structured output | category, priority, fields, summary, unsure?
AI step, structured output -> Mela rules | key account? legal words? data deletion?
Mela rules -[rule match aana]-> Priority-a force pannu, senior-ku illa privacy contact-ku route pannu
Mela rules -> Unsure?
Unsure? -[aamaa]-> General queue | oru aal sort pannum
Unsure? -[illa]-> Help desk-la route pannu | team, priority, summary, draft reply
Help desk-la route pannu -> Agent draft-a check panni, edit panni, anuppuvaanga
```

Indha lesson-la Chennai-la oru broadband provider-a follow pannuvom. Avanga support inbox-ku oru naalaikku sumaar 2,500 emails varudhu.

## Idhu eppadi work aagudhu

**Categories-a team-oda serthu define pannunga.** Unga support illa operations team already use panra categories-a edunga, ovvonnukkum oru line definition-um rendu moonu example messages-um. "Other / unclear" serthukkunga.

**Structured output-oda classify pannunga.** AI step category, priority, extracted fields, oru line summary, confidence illa "unsure" flag-a oru fixed shape-la tharum.

**AI-a sutthi rules.** Sila mudivugal rules-a irukkanum, AI judgement-a illa: key accounts list-la irundhu varra messages eppavum high priority; legal action, police, consumer court-nu edhu pathi pesunaalum adhu senior aal-kitta pogum; data deletion pathi edhaavadhu irundha privacy contact-kitta pogum.

**Route pannunga.** Help desk-la ticket create illa update pannunga, team assign pannunga, priority podunga, extracted fields-um summary-yum serthukkunga. Unsure cases general queue-ku poi oru aal sort pannum.

**Replies-a draft pannunga, anuppaadheenga (mudhalla).** Customer-oda message, extracted details, unga knowledge base vachu reply draft generate panni, agent edit panni anuppa ticket-la vechidunga. Vaarakkanakkula quality-a measure panna apram thaan simple, risk kammi replies-a ("unga request vandhudhu" maadhiri) automatic-aa anuppalaam.

**Languages.** India customers English, Hindi, Tamil, Hinglish-nu pala vidhama ezhudhuvaanga. Neenga receive panra ovvoru language-layum real messages-la triage-a test pannunga.

**Measure pannunga.** Vaaram-oru sample-la classification accuracy, mudhal thadavaiye sariyaa route aanadhu evvalavu, mudhal response-ku aagura neram, agents drafts-a evvalavu edit panraanga.

**AI-yum team-um rendum purinjukkura oru category definition:**

| Category | Definition | Example messages |
| --- | --- | --- |
| Outage | Internet vae illa, oru area-vaiyum bhaadhikkalaam | "Net not working since morning", "Wi-Fi light red" |
| Slow speed | Connect aagi irukku aana plan-a vida slow | "Getting 5 Mbps on a 100 Mbps plan" |
| Billing | Charges, payments, refunds | "Charged twice this month" |
| Relocation | Connection-a pudhu address-ku maathuradhu | "Shifting to Velachery next week" |
| Other or unclear | Matha edhuvum, illa theriyala | "Hi", forwarded newsletters |

Indha definitions nera prompt-kulla pogum. Team oru category-a maathina, oru idathula definition-a maathuvaanga, test set-ku adhukku pudhu examples serum.

**Yen drafts-la aarambikkanum.** 92% classification accuracy-la kooda, kovama irukkura customer-ku thappaana automatic reply anuppina nijamaave damage aagum. Drafts-naala agents andha 8%-a sari pannalaam, 92%-la neram migalaam. Ovvoru draft-aiyum agents evvalavu edit panraanga-nu measure pannunga: oru category-oda perumbaalaana drafts vaarakkanakkula maatraama poyidhuna, andha category automatic sending-ku candidate, simple acknowledgements-la irundhu aarambikkalaam.

**Mudhalla rules, apram model, code-la.** Fixed rules edhu model call-um pannaadhadhukku munnaadi odum, adhanaala yaarum adha pesi maathida mudiyaadhu:

```python
from typing import Literal
from pydantic import BaseModel

Category = Literal["outage", "slow_speed", "billing", "relocation", "other"]

class Triage(BaseModel):
    category: Category
    priority: Literal["p1", "p2", "p3"]
    account_id: str | None = None
    summary: str
    unsure: bool

KEY_ACCOUNTS = {"ACC-1001", "ACC-2040"}
LEGAL_WORDS = ("legal notice", "consumer court", "police complaint", "lawyer")

def triage(message, sender_account, classify):
    text = message.lower()
    if any(w in text for w in LEGAL_WORDS):
        return {"queue": "senior", "priority": "p1", "reason": "legal words"}
    if "delete my data" in text or "erase my data" in text:
        return {"queue": "privacy", "priority": "p2", "reason": "data request"}
    t: Triage = classify(message)                 # structured output from the model
    if t.unsure or t.category == "other":
        return {"queue": "general", "priority": t.priority, "reason": "unsure"}
    priority = "p1" if sender_account in KEY_ACCOUNTS else t.priority
    return {"queue": t.category, "priority": priority, "summary": t.summary, "account": t.account_id}
```

**Enga thappu aagudhu-nu measure pannunga.** Overall accuracy entha categories kalandhu pogudhu-nu maraikkum. Unga labelled set-la irundhu oru confusion table build pannunga:

```python
from collections import Counter

def confusion(pairs):
    """pairs: list of (true_category, predicted_category)."""
    counts = Counter(pairs)
    cats = sorted({c for p in pairs for c in p})
    print("true \\ predicted".ljust(14) + "".join(c[:9].ljust(10) for c in cats))
    for t in cats:
        print(t[:13].ljust(14) + "".join(str(counts[(t, p)]).ljust(10) for p in cats))
    acc = sum(counts[(c, c)] for c in cats) / len(pairs)
    print(f"accuracy {acc:.0%}")
```

"slow_speed" adikkadi "outage"-nu predict aana, andha rendu definitions-a tight pannunga, rendukkum idaiyila border-la irukkura examples serunga. Language-ku oru accuracy-yum sollunga: examples serkkura varaikkum Hinglish messages English-a vida mosama pogum.

**Thappukku vera vera cost.** Outage-a billing-ku anuppina oru area-vukkae fix late aagum; billing-a general-ku anuppina konjam nimishangal thaan selavu. Entha confusions romba mukkiyam-nu team-oda decide pannunga, average-a paakkaama table-oda andha cells-a paarunga.

**Inbox maarradha paarunga.** Ovvoru category-yoda share-yum "other"-oda share-yum vaaram-oru thadavai track pannunga. Pudhu plan launch, festival sale, illa oru outage mix-a maathum. "Other" yerinaa, pudhu category thevai-nu artham.

## Podhuvaa panra thappugal

- **Team use pannaadha categories-a kandupidikkiradhu.** Avanga categories-a use pannunga.
- **Legal, safety escalations-a AI-ku mattum vittudradhu.** Idhukku rules use pannunga.
- **Replies-a romba seekiram auto-send panradhu.** Drafts-la aarambichu measure pannunga.
- **English-la mattum test panradhu.** Customers nijamaave ezhudhura languages-la test pannunga.
- **"Unsure" path illaama irukkradhu.** Ella message-kum oru category-a thinicha errors maraiyum.
- **Overall accuracy mattum paakkaradhu.** Entha categories kalandhu pogudhu-nu, language-ku language paarunga.
- **Legal, privacy routing-a model-kitta vittudradhu.** Model odradhukku munnaadi fixed rules use pannunga.

## AI triage thevai illaadha idangal

- **Help desk-oda sondha rules already work aagudhu**, customer fill panra form fields vachu route panradhu maadhiri.
