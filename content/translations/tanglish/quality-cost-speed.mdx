## Idhu enna

Ovvoru LLM app-um moonu vishayangalai onnukkonnu trade pannum:

- **Quality**: badhilgal evvalavu thadavai sariyaa, muzhumaiyaa, safe-aa irukku.
- **Cost**: oru request-ku, oru maasathukku selavu.
- **Speed**: users evvalavu neram kaathirukkanum.

Periya models, adhigam retrieve panna context, rerankers, reflection steps, agent loops perumbaalum quality-a uyarthum, cost-aiyum latency-aiyum koodave uyarthum. Nalla engineering indha trade-offs-a theriyumbadi kaattum, product-a vechchirukkura aalgaloda sernthu, venumnae mudivu pannum.

```flow
dir: LR
title: Choose pannadhu: exclusions, claims-ku router + reranker: 88%, ₹0.30, 3.1 s p95
Question -> Router
Router -[easy]-> Small model | 76%, ₹0.08, 1.6 s
Router -[hard: exclusions, claims]-> Large model + reranker | 89%, ₹0.64, 4.3 s
```

Streaming, mudhal vaarthaigalai oru vinaadikkulla kondu varum.

Indha lesson, Hyderabad-la oru health-insurance company-a follow pannum; avanga call-centre agents live calls-la oru assistant use pannuvaanga.

## Idhu eppadi work aagudhu

**Moonaiyum ore test set-la measure pannunga.** Ovvoru option-kum record pannunga:

- Unga eval-la irundhu quality (category-aala, overall mattum illa);
- Oru request-ku cost (tokens times prices);
- Median-layum 95th percentile-layum latency, time to first token-um.

**Options-a oru table-la podunga.** Udhaaranamaa: small model, large model, large model plus reranker. Appo trade-off oru business conversation aagidum: "reranker accuracy-a 85%-la irundhu 89%-ku uyarthudhu, p95-la oru request-ku 400 ms serkkudhu; worth-aa?"

**Entha quality mukkiyamnu kelunga.** Oru casual chat-ku 85% pothum; medical illa financial badhilgalukku quality-yum safety-yum thaan mukkiyam. Thappugalai avatroda vilaivugalaala weight pannunga.

**Mudhalla free wins-a thedunga.** Sila maatrangal quality-a paadhikkaama speed illa cost-a improve pannum:

- Streaming (unarum speed);
- Prompt caching (thirumba varra prefixes-ku cost, speed);
- Surukkamaana outputs, prompts;
- Suyaadheenamaana steps-a parallel-aa run panradhu;
- Thevaiyillaadha steps-a neekkuradhu.

**Difficulty-aala route pannunga.** Simple requests-a vegamaana, mulaivaana model-kum, kashtamaanadha strong model-kum anuppunga. Router evvalavu thadavai thappu pannudhunnu measure pannunga.

**Budgets set pannunga.** Oru latency budget (udhaaranamaa, p95-la first token 1.5 s-kkulla), oru cost per request ceiling-a otthukkonga, apram adhukkulla quality-a maximise pannunga.

**Thirumba paarunga.** Vilaigal kuraiyum, models improve aagum, usage valarum; best trade-off maarum. Ovvoru sila maasathukkum table-a thirumba run pannunga.

**Levers-um avatroda vilaivugalum:**

| Lever | Quality | Cost | Speed |
| --- | --- | --- | --- |
| Periya model | Mela | Mela | Mella |
| Reranker | Mela | Konjam mela | Konjam mella |
| Adhigam retrieve panna context | Adikkadi mela, apram keezha | Mela | Mella first token |
| Router | Periya model-oda kitta | Keezha | Average-la vegam |
| Streaming | Adhe | Adhe | Romba vegamaa therium |
| Prompt caching | Adhe | Keezha | Vegamaana first token |
| Surukkamaana outputs | Adhe illa nallaa | Keezha | Vegam |

**Vilaivu-aala weight panradhu.** Test set-a categories-aa pirichchu, ovvonnukkum business-la irundhu oru weight kudunga: inga oru thappaana badhil evvalavu selavaanadhu? Insurer-ku exclusions, claims-ku adhigam weight, podhuvaana kelvigalukku kammi. Oru weighted score, options-a plain accuracy-a vida vera maadhiri rank pannalaam, mudivin kaaranatthai ellaarukkum thelivaa kaattum.

**Recommendation ezhudhuradhu.** Product owner-kku oru paragraph: paarththa options, choose pannadhu, adhoda quality, cost, latency, migavum accurate-aana option-oda oppittaa adhu enna vittukkodukkudhu, eppo thirumba paarkkanum. Udhaaranamaa: "Exclusions, claims-ku reranker-oda router-a recommend panrom: 88% accuracy, oru request-ku sumaar ₹0.30, p95-la 3.1 s. Ellaa idathulayum reranker-oda large model 1 point nallaa irukkum, aana rendu madangu cost, live calls-la mella."

**Router-a measure panradhu.** Router, sariyaana requests-a sariyaana model-kku anuppinaa mattum thaan panam micham aagum. Oru sample test questions-a easy illa hard-nu label panni, router-a run panni, rendu vagai thappugal-a ennunga: hard questions small model-kku pona, adhu quality-a paadhikkum; easy-kku large model-kku pona, adhu panatthai veenaakkum. Mudhal vagai thaan mukkiyam. High-risk category-la adhu adikkadi nadandha, insurer exclusions, claims-ku pannadhu maadhiri andha muzhu category-yum strong model-kku route pannunga.

**Code-la oru weighted comparison.** Ovvoru option-aiyum business weights-oda category-aala score pannunga, apram adhukku pakkathula cost-aiyum latency-yaiyum kaattunga:

```python
WEIGHTS = {"exclusions": 3.0, "claims": 3.0, "premiums": 2.0, "general": 1.0}

def weighted_quality(results):
    """results: list of (category, correct_bool)."""
    num = sum(WEIGHTS[c] * ok for c, ok in results)
    den = sum(WEIGHTS[c] for c, _ in results)
    return num / den

def p95(values):
    v = sorted(values)
    return v[int(0.95 * (len(v) - 1))]

def summarise(option_runs):
    """option_runs: name -> list of dicts with category, correct, cost_inr, ms."""
    table = []
    for name, runs in option_runs.items():
        table.append({"option": name,
                      "quality": round(weighted_quality([(r["category"], r["correct"]) for r in runs]), 3),
                      "cost_inr": round(sum(r["cost_inr"] for r in runs) / len(runs), 3),
                      "p95_ms": p95([r["ms"] for r in runs])})
    return table
```

**Yaarum pick panna koodaadha options-a drop pannunga.** Vera oru option quality, cost, speed-la kurainjadhu samamaa irundhu, onnula nallaa irundhaa, andha option dominated:

```python
def frontier(table):
    def dominates(a, b):
        better_or_equal = a["quality"] >= b["quality"] and a["cost_inr"] <= b["cost_inr"] and a["p95_ms"] <= b["p95_ms"]
        strictly = a["quality"] > b["quality"] or a["cost_inr"] < b["cost_inr"] or a["p95_ms"] < b["p95_ms"]
        return better_or_equal and strictly
    return [o for o in table if not any(dominates(other, o) for other in table if other is not o)]
```

Meedhi irukkuradhu thaan unmaiyaana choice, adhu oru business choice: evvalavu quality, evvalavu rupees-kum milliseconds-kum worth.

**Mudhalla budgets, apram quality-a maximise pannunga.** Product owner-oda oru cost per request ceiling-aiyum oru p95 latency target-aiyum otthukkonga, frontier-a rendukkum ulla irukkura options-a filter pannunga, adhula nallaa quality irukkuradhai pick pannunga. Idhu oru mugamillaadha vivaadhatthai oru chinna meeting-aa maathum.

**Vilaigalum models-um maarum.** Comparison-a date-oda, use panna prices-oda store pannunga. Oru provider vilaiya kuraichaalum, pudhu model release pannaalum, adhe test set-a thirumba run panni table-a update pannunga; best choice adikkadi maasangalukkulla maarum.

**Rupee-ku quality mattum muzhu kadhai illa.** Safety-critical categories-ku, entha saving-aalayum keezha pogaadha oru minimum quality-a set pannunga, andha categories-a cost-a paarkkaama strong model-kku route pannunga.

## Oru worked example

Hyderabad-la oru health-insurance company-oda assistant, avanga call-centre agents-ku policy questions-ku badhil solludhu.

Team 150 test questions-la naalu options-a compare pannudhu:

| Option | Accuracy | Oru request-ku cost | p95 latency |
|---|---|---|---|
| Small model | 76% | ₹0.08 | 1.6 s |
| Large model | 85% | ₹0.60 | 3.9 s |
| Large model + reranker | 89% | ₹0.64 | 4.3 s |
| Router (small; hard ones to large) | 86% | ₹0.24 | 2.8 s |

Product owner-oda paarvai: agents live calls-la irukkaanga, so latency romba mukkiyam; thappaana coverage badhilgal complaints-aiyum refunds-aiyum uruvaakkum, so accuracy innum mukkiyam. Avanga router-oda sernthu, exclusions, claims pathina kelvigalukku (migavum risky categories) reranker-a choose pannaanga, overall 88%, oru request-ku sumaar ₹0.30, p95-la 3.1 s. Streaming, mudhal vaarthaigalai oru vinaadikkulla kondu varudhu.

| Decision factor | Choice-a eppadi shape pannadhu |
| --- | --- |
| Agents live calls-la | Latency mukkiyam, so streaming, router |
| Thappaana coverage badhilgal complaints, refunds-a uruvaakkum | Exclusions, claims-ku reranker |
| Call-centre volume-la cost | Router perumbaalaana traffic-a small model-la vaikkudhu |

## Podhuvaa panra thappugal

- **Oru dimension-a mattum amaidhiyaa optimise panradhu.** Moonaiyum kaattunga.
- **Overall accuracy mattum.** Thappugalin vilaivugal, categories-aala weight pannunga.
- **Tail latency-a kandukkaama vidradhu.** Users slow requests-a gnaabagam vechchukkuvaanga.
- **Free wins-a miss panradhu.** Mudhalla streaming, caching.
- **Mudivai thirumba paarkkaamaleye irukkradhu.**
- **Product owner illaama choose panradhu.** Trade-off oru business decision; table-a kaattunga, avanga weigh pannattum.
- **Weight illaadha accuracy**, sila thappugal mathavatrai vida romba selavaanadhaa irukkumbodhu.
- **Dominated options-a** discussion-la vechchirukkuradhu.
- **Date, prices record pannaadha comparison**, adhu amaidhiyaa pazhasaagidum.

## Muzhu trade-off study thevai illaadha neram

- **Kammiyaana volume**: oru naalaikku konjam rupees-la migavum strong model podhum; apram optimise pannalaam.
- **Oru option ellaa targets-aiyum** neraiya idaiveliyoda meetrudhu.
- **Aarambakkattu prototypes**, anga mudhalla andha task work aagudhaannu therinjukkradhu mukkiyam.

## Demo-la irundhu production-ku

- **Comparison table-a** dates, prices, test set version-oda vechchukonga.
- **Production-la quality, oru request-ku cost, p95 latency-a** feature-aala track pannunga.
- **High-risk categories-ku minimum quality** set pannunga, routing-aala keezha pogaadhu.
- **Prices maarumbodhu, pudhu models varumbodhu, traffic periya alavula maarumbodhu** comparison-a thirumba run pannunga.
- **Router-oda thappugal-a** ovvoru maasamum category-aala measure pannunga.
