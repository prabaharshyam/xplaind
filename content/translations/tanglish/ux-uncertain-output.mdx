## Idhu enna

Traditional software predictable: adhe input adhe output tharum, thappaa irundhaa adhu oru bug. AI output maarum, iyalbaagavae sila neram thappaavum irukkum. **Urudhiyillaadha output-kkaana UX**-na andha unmaikku yetha maadhiri design panradhu.

Ilakku **calibrated trust**:

```flow
dir: LR
Nambikkai kuraivu | Oru thappukku appuram useful tool-a users ignore panraanga: veenaana value -> Calibrated trust | Sariyaa irukka vaaippu irundhaa nambuvadhu, urudhi illanna check panradhu, seekkiram meendu varradhu: ilakku
Calibrated trust -> Adhiga nambikkai | Ellaa badhilaiyum yeththukkuradhu, thappugalai customers-kku kadaththuradhu: unmaiyaana baadhippu
```

Microsoft-oda Guidelines for Human-AI Interaction, Google-oda People + AI Guidebook maadhiri research adippadaiyilaana guidelines, oru core set patterns-la othuppogudhu. Indha lesson adhai, oru screen-la neenga edukkakkoodiya decisions-aa maaththudhu.

Chennai-la oru insurance company-la product manager Divya-va follow pannuveenga. Agents thappaana badhilgalai customers-kku sonna piragu, avanga oru AI coverage assistant-a marubadiyum design panraanga. Lesson mudiyumbodhu, oru thappaana AI badhilai users sila vinaadigalla kavanichchu meendu varra oru screen-a design panna mudiyum.

## Idhu eppadi work aagudhu

### Patterns

| Pattern | Eppadi irukkum | Yen work aagudhu |
| --- | --- | --- |
| **Expectations set panradhu** | "Unga policy documents pathina kelvigalukku badhil solum. Legal advice kudukkaadhu." | Edhukku idha nambalaam-nu users-kku theriyum |
| **Idhu AI-nnu kaatturadhu** | Users therinjukka virumbura idaththula thelivaana oru label | Evvalavu kavanamaa check panradhunu users adhukkethaa maadhiri maathikkuvaanga |
| **Sources kaatturadhu** | Number potta citations; onnai tap pannaa sariyaana passage varum | Users check pannalaam, thappaana badhilgal thaniyaa theriyum |
| **Uncertainty-a signal panradhu** | "Confidence kuraivu: thogaiyai check pannunga"; highlight panna fields | Kavanam thevaiyaana idaththukku pogum |
| **Correction-a elidhaakkuradhu** | Edit pannakkoodiya drafts, oru reason-oda orae click-la "idhu thappu", undo | Thappugalai sari panradhu malivu, feedback system-a improve pannum |
| **Manushangalukku control kudukkuradhu** | Anuppuradhukku munnaadi preview; panam, messages, deletions-kku munnaadi confirm | Vilaivugalukku oru manusha decision venum |
| **Gracefully fail aaguradhu** | "Enakku thelivaana badhil kidaikkala. Underwriting helpdesk-a try pannunga." | Blank screens illai, confident guesses illai |
| **Progress kaatturadhu** | Streaming text; "3 documents-a check panren..." | Feedback illaama kaathirukkuradhu udaindhu pona maadhiri irukkum |

### Confidence-a kavanamaa signal pannunga

"93.7% confident" maadhiri thulliyamaana numbers scientific-aa thonri, thavaraana nambikkaiyai undaakkum; kurippaa andha number sariyaa calibrate aagaadhappo. Nalla options:

- System-kku urudhiyillaadha kurippitta fields-a highlight pannunga;
- Eliya vaarthaigal: "Indha thogai pathi enakku urudhi illai";
- Retrieval balaveenamaa irukkumbodhu, badhil solla maruthu oru aal kitta vazhi kaatturadhu maadhiri, behaviour-a maathunga.

### Indian products-la patterns

Neraiya Indian users AI-a WhatsApp chats, voice assistants, regional-language apps-la sandhikkiraanga; anga screens sinnadhu, kavanam kuraivu. Patterns innum poruntthum, surukkamaana vadivaththula. Oru WhatsApp bot badhilai ippadi mudikkalaam: "Source: Policy section 4.2. Idhu sariyaa theriyalanna WRONG-nu reply pannunga." Oru voice assistant sollalaam: "Enakku urudhiyillai. Ungalai oru agent-kitta connect pannattumaa?" Oru regional-language app source passage-a badhil irukkura adhe mozhiyila kaattalaam. Users orae neraththula neraiya context paarkka mudiyaadhadhaala, sinna screens-la sources-um elidhaana correction-um innum mukkiyam.

### Mudhal thappukkaaga design pannunga

Oru feature-a nambanumaa-nu users seekkiramae mudivu panniduvaanga. Urudhiyaa theriyra oru tool-la irundhu mudhal thappu vandhaa nambikkai sarindhu pogum. Aarambaththula irundhae andha tool thannoda limits-aiyum sources-aiyum kaattiyirundhaa, mudhal thappu romba kuraivaa baadhikkum: user adhai kandupidichaanga, product avangalukku udhavuchu.

### Unmaiyaana errors-oda test pannunga

Usability tests perumbaalum users oru task-a mudikka mudiyudhaa-nu paarkkum. AI features-kku, AI **venumnae thappaa** irukkum cases-aiyum serthu, users kavanichchu meendu varraangalaa-nu paarunga. Adhuthaan design-oda unmaiyaana test.

```text
  Test plan for an AI answer screen
  8 questions:  6 with correct AI answers, 2 with planted errors
  Measure:      did the user spot the error?  how long did it take?
                did they know what to do next?
```

## Oru worked example

Chennai-la oru insurance company, agents customers-oda pesumbodhu policy coverage kelvigalukku badhil solla, thannoda agent app-la oru AI assistant serkkudhu.

**Mudhal version** oru confident paragraph badhilai kaattudhu; sources illai, limits illai, problems-a report panna vazhi illai. Ettu kelvigal ulla oru usability test-la rendu badhilgal venumnae thappaa irundhuchu. Agents aridhaa thaan check pannaanga, role-play-la thappaana **rendu** badhilgalum customers-kku pochu.

**Rendaavadhu version**, product manager Divya marubadiyum design pannadhu:

| Maatram | Agent ippo enna paarkkiraanga |
| --- | --- |
| Expectations | Oru header vari: "Policy wordings-la irundhu AI badhil solludhu. Customers-kku advice kudukkuradhukku munnaadi check pannunga." |
| Sources | Ovvoru badhilukkum number potta citations; onnai tap pannaa sariyaana clause varum |
| Graceful failure | Retrieval balaveenamaana matches mattum kandupidichaa, badhil "Enakku thelivaana badhil kidaikkala"-nnu aarambichu underwriting helpdesk-a suggest pannum |
| Uncertainty | Amounts-um exclusions-um agent confirm panradhukkaaga highlight aagum |
| Correction | Moonu reasons-oda oru "thappaana badhil" button, product team vaaram oru thadava review pannum |

**Adutha test:**

| Measure | Mudhal version | Rendaavadhu version |
| --- | --- | --- |
| Agents kandupidicha planted thappaana badhilgal | Oru session-kku sarasari 2-la 0 | Ellaa sessions-um serthu 8-la 7 |
| Agents-oda satisfaction score | 5-la 3.1 | 5-la 4.2 |
| Mudhal unmaiyaana thappukku appuram usage | Kuraindhudhu | Adhigarichudhu |

Agents rendaavadhu version-a **adhigamaa** nambunaanga, kuraivaa illai, yenna control thangakitta irukku-nu feel pannaanga, oru badhil yen vandhuchu-num paarkka mudinjudhu. Production-la mudhal unmaiyaana thappugal vandhadhukku appuram kooda, usage kuraiyaama thodarndhu valarndhuchu.

## Podhuvaa panra thappugal

- **Idhu AI-nnu maraikkiradhu.** Users thangalukku therinjadhai vechu thaan nambikkaiyai calibrate panraanga.
- **Sources illaadha confident badhilgal.** Users check panna mudiyaadhu, adhanaala adhigamaa nambuvaanga.
- **Poli thulliyam.** "93.7% confident" thavaraana nambikkaiyai undaakkum; eliya signals use pannunga.
- **Thiruththa kashtamaana outputs.** Final-aa edit panna mudiyaadha outputs, users thappugalai yeththukka vaikkum.
- **Vetri cases-a mattum test panradhu.** AI thappaa irukkumbodhu users enna panraanga-nu test pannunga.
- **Blank failures.** Adutha step illaadha "Edho thappaa pochu" users-a maattivittudum.

## Practice pannunga

Keezha link pannirukkura Microsoft-oda Guidelines for Human-AI Interaction-aiyum, explainability and trust pathina PAIR chapter-aiyum paadinga.

1. **Audit.** Neenga use panra oru AI feature-a eduthu, ainthu guidelines-oda check pannunga. Enga fail aagudhu-nu note pannunga.
2. **Sketch.** Expectations, sources, uncertainty signals, elidhaana correction irukkura oru maruvadivamaicha screen-a paper-la sketch pannunga.
3. **Test.** Oru sariyaana, oru thappaana AI badhilodu unga sketch-a rendu perukku kaattu, avanga thappaanadhai kandupidikkiraangalaa-nu note pannunga.

**Mudinjadhu-nu eppo sollalaam:** Oru user thappaana AI badhilai kavanichchu sila vinaadigalla meendu varra oru design-a kaatta mudiyum.
