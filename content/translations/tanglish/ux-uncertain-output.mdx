## Idhu enna

Pazhaya maadhiriyaana software predictable: adhe input-kku adhe output varum, thappaa irundhaa adhu neenga fix pannakkoodiya oru bug. AI output maarittae irukkum, edhuvum udaiyaama irundhaalum adhu iyalbaave sila neram thappaa irukkum. **Urudhiyillaadha output-kkaana UX**-na andha unmaikkaaga design panradhu.

Goal **calibrated trust**: ovvoru case-layum, AI evvalavu nambikkaikku thagudhiyo avvalavu thaan users adhai nambanum.

```flow
dir: LR
Under-trust | oru thappukku appuram users oru useful tool-a ignore panraanga: value veenaagudhu -> Calibrated trust | sariyaa irukka vaaippirundhaa nambuvadhu, urudhiyillanna check panradhu, seekkiram recover aaguradhu
Calibrated trust -> Over-trust | ella answer-aiyum yethukkittu thappugalai adutthavangalukku kadathuradhu: unmaiyaana baadhippu
```

Over-trust-kku oru peru irukku: **automation bias**, oru machine-oda output-a check pannaama yethukkura pazhakkam; makkal busy-aa irukkumbodho, machine podhuvaa sariyaa theriyumbodho idhu innum valuvaagudhu. Human in the loop-a design panradhu pathina lesson idhai aazhamaa pesudhu. Inga point simple: urudhiyaa theriyura oru screen, check panradhai niruththa makkalai pazhakkudhu; thannoda evidence-a kaattura oru screen, check panradhai vegamaakkudhu.

Indha field-a research adippadaiyilaana rendu guides vadivamaikkudhu. Microsoft-oda Guidelines for Human-AI Interaction 18 guidelines-a avai eppo apply aagudhu-nnu group pannudhu: **aarambathula**, **interaction nadakkumbodhu**, **system thappaa irukkumbodhu**, **kaalappokkula**. Google-oda People + AI Guidebook idhe maadhiri vishayangalai cover pannudhu, explainability, trust pathi oru chapter-oda. Indha lesson avatrai oru screen-la neenga edukkakkoodiya mudivugalaa maathudhu, designers adikkadi skip panra pagudhiyaiyum serkkudhu: "idhu thappaa irukkalaam"-ngra signal unmaiyila enga irundhu varudhu.

Chennai-la oru insurance company-la product manager-aa irukkura Divya-va neenga follow pannuveenga; agents customers-kku thappaana answers-a sonnadhukku appuram avanga oru AI coverage assistant-a redesign panraanga.

## Idhu eppadi work aagudhu

### Patterns, avai eppo apply aagudhu-nnu

Indha table Microsoft-oda naalu phases-a follow pannudhu, adhanaala endha AI feature-aiyum mudhal use-la irundhu aaraavadhu maasam varai audit panna idhai use pannalaam.

| Phase | Pattern | Eppadi irukkum |
| --- | --- | --- |
| Aarambathula | **Expectations set pannunga** | "Unga policy wordings pathina kelvigalukku badhil sollum. Legal advice kudukkaadhu." |
| Aarambathula | **Idhu AI-nnu kaattunga** | Answer-a nambalaamaa-nnu users mudivu panra idathula oru thelivaana label |
| Interaction nadakkumbodhu | **Check panna sources-a kaattunga** | Numbered citations; onnai tap pannaa exact passage theriyum, match aagura sentence highlight aagiyirukkum |
| Interaction nadakkumbodhu | **Uncertainty-a signal pannunga** | Kurippitta field mela "Indha amount-a check pannunga", vaarthaigallayum oru icon-layum |
| Interaction nadakkumbodhu | **Progress-a kaattunga** | Streaming text, allathu "3 documents-a check pannittirukku..." |
| Thappaa irukkumbodhu | **Correction-a easy-aakkunga** | Edit pannakkoodiya drafts, oru kaaranathoda ore tap "Wrong answer", undo |
| Thappaa irukkumbodhu | **Naasookkaa fail aagunga** | "Thelivaana badhil kidaikkala. Underwriting helpdesk-a try pannunga." |

Mudhal rendu rows selavu kurainjadhu, irundhaalum teams avatrai skip panraanga. "Interaction nadakkumbodhu" rows, system thaan eppo urudhiyillaama irukku-nnu solla mudinjaa mattum thaan work aagum; adhu thaan adutha section.

### Uncertainty signal enga irundhu varudhu

Oru designer oru nimishathula oru manjal "please check" badge-a varanjidalaam. Appuram adhai eppo kaattanum-nu oru engineer mudivu pannanum. Yaarume mudivu pannalanna, badge onnu ellaathulayum varum (users adhai ignore panna kathukkuvaanga), illanna edhulayum varaadhu. Teams unmaiyila use panra signals ivai:

| Signal | Eppadi work aagudhu | Edhai pidikkum | Edhai miss pannum |
| --- | --- | --- | --- |
| Retrieval score | Ellaathaiyum vida nallaa match aagura passage-oda score, labelled questions vechu neenga tune panra threshold-a vida keezha irukku | Documents cover pannaadha kelvigal | Ore maadhiri theriyura aanaa thappaana passages, udhaaranam vera plan-oda clause |
| Citation support check | Cited passage-la answer-oda amount, date allathu yes or no irukkaa? Numbers-kku exact match; wording-kku innoru checking step | Karpanaiyaa uruvaakkina numbers, claim-a support pannaadha citations | Match aaga mudiyaadha alavukku romba thalarvaa paraphrase panna claims |
| Rule, schema checks | Amount anumadhikkappatta range-la irukku, plan customer-oda plan kooda match aagudhu, thevaiyaana fields irukku | Saathiyamillaadha allathu match aagaadha values | Nambakkoodiyadhaa theriyura aanaa thappaana values |
| Runs-kku idaiyila agreement | Adhe kelviya rendu moonu thadavai kelunga, allathu rendu models-kitta kelunga; key fields othuppogalanna flag pannunga | Nilaiyillaadha, oogam maadhiriyaana answers | Ovvoru thadavaiyum ore maadhiri thappaa irukkura answers |
| Self-reported confidence | Model-kitta "evvalavu urudhiyaa irukka?"-nnu kekkuradhu | Thaniyaa perisaa edhuvum illa | Perumbaalum overconfident |

Kadaisi row thaan trap. Xiong-um avaroda colleagues-um 2024-la panna oru study-la, confidence-a sollach sonna language models romba adhigamaa overconfident-aa irundhuchu, values perumbaalum 80%-kkum 100%-kkum idaiyila. Pala answers-a compare panra methods idha vida nallaa pannuchu. Model-oda sondha confidence-a weak evidence-aa thaan paarunga, orubodhum ore signal-aa illa.

Signals-a serthu oru chinna set display modes-aa aakkunga; idhai code-la mudivu pannanum, model-kitta vidakkoodaadhu:

```flow
title: Signals-la irundhu user paarkkuradhu varai
Kelvi -> Passages-a retrieve pannu
Passages-a retrieve pannu -[top score threshold-a vida keezha]-> Answer illa | adhai sollittu helpdesk-a kudu
Passages-a retrieve pannu -[nalla match]-> Draft answer
Draft answer -[amount cited clause-la illa]-> Flag-oda answer | Indha amount-a check pannunga
Draft answer -[ella checks-um pass]-> Sources-oda answer
```

Amounts-kku andha mudivoda oru minimal version ippadi irukkum. 0.6 threshold oru udhaaranam thaan; sila nooru labelled questions-a score panni, weak matches enga aarambikkudhu-nnu thernthedutthu neenga ungaloda-dhai set pannuveenga.

```python
import re

def numbers(text):
    return set(re.findall(r"\d[\d,]*", text))

def display_mode(answer, cited_passage, top_score, threshold=0.6):
    if top_score < threshold:
        return "no_answer"          # say so and offer the helpdesk
    if not numbers(answer) <= numbers(cited_passage):
        return "check_amount"       # an amount is not in the cited clause
    return "answer"                 # show with sources

clause = "Room rent is covered up to Rs 5,000 per day."
print(display_mode("Room rent is covered up to Rs 5,000 per day.", clause, 0.82))  # answer
print(display_mode("Room rent is covered up to Rs 7,500 per day.", clause, 0.82))  # check_amount
print(display_mode("Dental implants are covered.", clause, 0.41))                  # no_answer
```

Unmaiyaana systems "5000", "5,000", "five thousand" ellaathaiyum normalise-um pannum, aanaa shape adhe thaan: selavu kuraincha checks, screen varaiyaradhukku munnaadiye mudivu pannadhu.

### Citations-a kaatturadhukku munnaadi check pannunga

Inga irukkuradhula citations thaan ellaathaiyum vida valuvaana pattern, aanaa adhu edhirmaraiyaavum pogalaam. Ding-um avaroda colleagues-um 2025-la panna oru study-la, citations irundhappo makkal chatbot answers-a adhigamaa nambunaanga, andha citations random-aa thernthedukkappattirundhaalum kooda. Makkal avatrai unmaiyilaye check pannappo mattum thaan trust kurainjudhu. Adhanaala answer-a support pannaadha oru citation, citation-e illaadhadhai vida mosam: adhu oru thappaana answer-a verify pannadhu maadhiri kaattudhu.

Idhula irundhu moonu rules:

- **Kaatturadhukku munnaadi verify pannunga.** Citation support check-a run pannunga. Cited passage-la mukkiyamaana claim illanna, citation-a drop pannittu claim-a flag pannunga.
- **Document-kku illa, passage-kku link pannunga.** "Policy wording, page 14"-nnaa check panradhu medhuvaagum. Match aagura sentence highlight aana nilaiyila clause-a open pannunga.
- **Anjai vida oru nalla citation mel.** Oru citation, kittathatta anju citations alavukke trust-a koottuchu-nnu Ding-um colleagues-um kandupidichaanga. Koodudhal links checking-a koottaama clutter-a mattum koottudhu.

### Percentages allathu colour mattum illaama, vaarthaigalla sollunga

"93.7% confident" maadhiri thulliyamaana numbers scientific-aa kekkudhu, thavaraana trust-a varavazhaikkudhu, adhukku pinnaadi irukkura number aridhaa thaan nallaa calibrate aagiyirukkum. Users oru percentage-a vechu act-um panna mudiyaadhu: oru customer kitta solla 81% podhumaa? Idha vida nalla options:

- flag-a kurippitta field mela vainga: "Indha amount-a check pannunga", muzhu answer mela oru thelivillaadha banner illa;
- oru action-oda serndha eliya vaarthaigalai use pannunga: "Indha limit pathi enakku urudhiyaa theriyala. Clause 4.2-la confirm pannunga";
- signals weak-aa irukkumbodhu behaviour-a maathunga: answer pannaadheenga, oru aal-kitta vazhikaattunga.

Colour-a mattum nambaadheenga. Colour-blind users-kku sivappu allathu manjal border theriyaama pogalaam, accessibility standard-aana WCAG 2.1, information-a kaattura ore vazhiyaa colour irukkak koodaadhu-nnu solludhu. Colour kooda oru icon-aiyum vaarthaigalaiyum serunga, screen reader "check pannanum"-nu announce panradhai urudhi pannunga. Voice product-la adhai vaayaala sollunga: "Indha amount pathi enakku urudhiyaa theriyala."

### Friction-a stakes-kku yetha maadhiri vainga

Neenga serkkura ovvoru check-um sila seconds selavaakkum. Ellaathulayum confirm step vechaa, makkal padikkaamaye click pannittu povaanga; adhuvum automation bias thaan. Thappugal enga ellaathaiyum vida adhigamaa selavaagudho anga friction vainga:

| Stakes | Udhaaranam | Design |
| --- | --- | --- |
| Low | Agent-oda sondha notes-kkaaga oru call-oda summary | AI label, easy-aana edit; kattaaya checks illa |
| Medium | Oru agent customer kitta thirumba solra coverage answer | Ovvoru answer-layum check panna source, highlight panna amounts, exclusions, "advise panradhukku munnaadi check pannunga" |
| High | Oru claim rejection, oru payment, oru legal allathu medical statement | Key fields-a kaattura oru confirm step, human approval, allathu AI answer-e illaama irukkuradhu |

Useful-aana oru decision rule: "Indha answer thappaa irundhu yaarume gavanikkalanna, yaar evvalavu kattuvaanga?"-nnu kelunga. Cost evvalavu perusoo, row avvalavu mela.

### Indhiya products-la patterns

Niraiya Indhiya users AI-a WhatsApp chats, voice assistants, regional-language apps-la thaan sandhikkiraanga; anga screens chinnadhu, gavanam kuraivu. Patterns innum apply aagum, surukkamaana vadivathula. Oru WhatsApp bot oru answer-a "Source: Policy section 4.2. Idhu sariyaa theriyalanna WRONG-nnu reply pannunga."-nnu mudikkalaam. Oru voice assistant "Enakku urudhiyaa theriyala. Ungalai oru agent kitta connect pannattumaa?"-nnu sollalaam.

Language innum kashtamaana oru prachanaiya kondu varudhu. Answer Tamil-layo Hindi-layo irukkalaam, aanaa policy wording perumbaalum English-la mattum thaan irukkum, adhanaala Tamil pesura oru user citation-a check panna mudiyaadhu. Rendaiyum kaattunga: match aagura sentence highlight aana original English clause, appuram "Machine translation. English text thaan official wording."-nnu label panna oru translated excerpt. Rendulayum amounts-a digits-aave vainga, support check-a English original mela run pannunga, yenna oru translation oru number-aiyo oru "not"-aiyo sathamillaama maathidalaam.

### Idhu AI-nnu makkalukku sollunga: rules

Labelling verum nalla design mattum illa, oru legal edhirpaarppaa aagittu varudhu. EU AI Act-oda Article 50, 2 August 2026-la irundhu, makkal kooda pesura AI systems, thaanga AI kooda deal panrom-nu makkalukku theriyura maadhiri design pannappadanum-nu require pannudhu, adhu velippadaiyaa therinjaa thavira. EU users-kku service kudukkura Indhiya companies-kku idhu mukkiyam. Indhiyaala, Reserve Bank-oda FREE-AI committee-oda August 2025 report, customers AI kooda deal pannumbodhu adhai avangalukku theriyappadutthanum-nu financial firms-kku recommend pannudhu. Idhu oru committee report, adhanaala adhai binding rule-aa edutthukkuradhukku munnaadi RBI-oda ippodhaiya directions-a check pannunga.

### Mudhal thappukkaaga design pannunga

Oru feature-a nambalaamaa-nnu users seekkirame mudivu pannidraanga. Urudhiyaa therinja oru tool-la irundhu mudhal thappu vandhaa, trust udainju pogum, niraiya per thirumba varave maattaanga. Aarambathula irundhe tool thannoda limits-aiyum sources-aiyum kaattiyirundhaa, mudhal thappoda vilai idha vida romba kuraivu: user adhai pidichaanga, adhai pidikka product avangalukku udhavuchu.

### Planted errors vechu test pannunga

Usability tests podhuvaa users oru task-a mudikka mudiyudhaa-nnu check pannum. AI features-kku, **venumne thappaa** irukkura answers-aiyum ulla vainga (plant pannunga), users gavanichu recover aaguraangalaa-nnu paarunga. Ella participants-kkum ore unit-la count pannunga, appo thaan versions-a compare panna mudiyum.

```text
  Test plan for an AI answer screen
  Per participant: 8 questions, 6 correct AI answers, 2 planted errors
  4 participants:  8 planted errors in total
  Measure:         planted errors caught (out of 8), seconds to catch,
                   did they know what to do next?
```

Naalu pera vechu, idhu maadhiri oru test periya design problems-a kandupidikkum. Oru chinna improvement-a adhu prove pannaadhu, adhanaala production numbers vechu confirm pannunga.

### Launch-kku appuram trust-a measure pannunga

Calibration nagarnduttae irukkum. Mudhal vaarathula gavanamaa check pannavanga aaraavadhu vaarathukkulla paarkkaamaye rubber-stamp panna aarambikkalaam. Moonu numbers-a track pannunga, stakes vaariyaa pirichu:

| Metric | Kavalai tharra pattern |
| --- | --- |
| High-stakes answers-la citation open rate | Accept rate romba adhigamaave irukkumbodhu kittathatta zero: makkal check panradhai niruthittaanga |
| Flag aana fields-la edit allathu override rate | Flag aana fields sila seconds-laye maathaama accept aagudhu: flags ignore aagudhu |
| 100 answers-kku wrong-answer reports | AI answers pathina customer complaints koodumbodhu idhu kuraiyudhu: makkal report panradhai niruthittaanga, errors nikkala |

Idhula edhuvume accuracy illa. Idhoda kooda, answers-oda oru random sample-a vaaraa vaaram oru expert audit pannunga, appo trust match aaga vendiya unmaiyaana error rate ungalukku theriyum.

## Oru worked example

Chennai-la oru insurance company thannoda agent app-la oru AI assistant-a serkkudhu, agents customers kooda pesumbodhu policy coverage kelvigalukku badhil solla. Keezha irukkura numbers vilakkathukkaaga thaan, mela sonna maadhiriyaana oru chinna usability test-la irundhu vandhadhu; production-la measure panna results illa.

**Version one** oru confident paragraph answer-a kaattudhu: sources illa, limits illa, problems-a report panna vazhiyum illa. Naalu agents ovvoruthharum 8 role-play kelvigalukku badhil sonnaanga, adhula 2-la planted thappaana answers. Agents aridhaa thaan check pannaanga: planted errors-la **8-la 0** thaan pidipattuchu, 8-um "customer"-kitta poyiduchu.

**Version two**, product manager Divya redesign pannadhu:

| Maatram | Agent ippo enna paarkkuraanga | Adhukku pinnaadi irukkura signal |
| --- | --- | --- |

## Podhuvaa panra thappugal

- **Idhu AI-nnu maraikkiradhu.** Users thangalukku therinjadhai vechu thaan trust-a calibrate panraanga, sila markets-la labelling ippo oru legal kadamai.
- **Pinnaadi endha signal-um illaadha uncertainty badges.** Flag eppo varanum-nu yaarume mudivu pannalanna, adhu eppavume varum, illanna orubodhum varaadhu.
- **Model-oda sondha confidence-a nambuvadhu.** Self-reported confidence sariyo thappo perumbaalum adhigamaa thaan irukkum; compute panna checks-a use pannunga.
- **Check pannaadha citations.** Answer-a support pannaadha oru citation oru thappaana answer-a verify pannadhu maadhiri kaattum.
- **Poliyaana thulliyam.** "93.7% confident" thavaraana trust-a varavazhaikkudhu, act panna users-kku edhuvum kudukkaadhu.
- **Colour mattume cue.** Oru sivappu border mattum colour-blind users-kkum screen readers-kkum fail aagum; oru icon-aiyum vaarthaigalaiyum serunga.
- **Ella idathulayum ore friction.** Low-stakes outputs mela confirm steps vechaa, high-stakes ones-layum makkal click pannittu poga pazhagiduvaanga.
- **Correct panna kashtamaana outputs.** Final-aana, edit panna mudiyaadha outputs thappugalai yethukka users-a thalludhu.
- **Success cases-a mattum test panradhu.** Thappaana answers-a plant panni, ethanai users pidikkiraanga-nnu count pannunga.
- **Verumaiyaana failures.** Adutha step illaadha "Edho thappaayiduchu" users-a maatti vaikkum.

## Practice pannunga

Keezha link panniyirukkura Microsoft-oda Guidelines for Human-AI Interaction-aiyum, explainability, trust pathina PAIR chapter-aiyum padinga.

1. **Audit.** Neenga use panra oru AI feature-a edunga. Naalu phases ovvonnukkum (aarambathula, interaction nadakkumbodhu, thappaa irukkumbodhu, kaalappokkula), adhu nallaa panra oru vishayathaiyum fail aagura oru idathaiyum note pannunga.
2. **Signal-a kandupidinga.** Unga redesign-la oru "please check" moment-kku, table-la irukkura endha signal adhai trigger pannudhu, adhu edhai miss pannum-nu ezhudhunga.
3. **Sketch.** Paper-la oru redesigned screen-a sketch pannunga: expectations, oru check panna source, colour-a mattum nambaadha oru field-level flag, ore tap correction. Adhoda stakes row-a mark panni, friction yen porundhudhu-nnu sollunga.
4. **Test.** Oru sariyaana answer, oru planted thappaana answer-oda unga sketch-a rendu perukku kaattunga. Avanga ethanai planted errors-a pidikkiraanga, adhukku evvalavu neram aagudhu-nnu record pannunga.

**Mudinjadhu-nnu eppo sollalaam:** oru planted thappaana answer-a oru user sila seconds-kkulla gavanichu adhula irundhu recover aagura oru design-a kaatta mudiyum, screen adhai flag panna kaaranamaana computed signal-a peru solla mudiyum.
