## Idhu enna

**Incident**-na users-a illa business-a paadhikkura, urgent-aa respond panna vendiya entha event-um. AI systems, vazhakkamaana outages-oda pudhu vagaigalaiyum serkkum:

- **Availability**: provider outage, rate limits, udainja pipeline.
- **Cost**: control illaadha agents illa traffic spikes budget-a eriyum.
- **Quality**: oru model, prompt, document maatrathukku appuram answers thidirnu thappaa irukkum.
- **Safety and security**: harmful content, prompt injection, data leakage, unauthorised actions.
- **Fairness and compliance**: unfair outputs-oda oru pattern, illa personal data thappaa use aanadhu.

**Incident response**-na idha handle panra planned vazhi: detect, assess, contain, fix, communicate, learn.

```flow
dir: LR
Detect | alerts, complaints -> Assess | severity 1, 2 illa 3; roles peyar sollappattu
Assess -> Contain | kill switch, rollback, remove, document, humans edukkuvaanga
Contain -> Investigate | traces, logs, release ids
Investigate -> Communicate | client, users, thevaippattaa regulators
Communicate -> Learn | blameless review, owners-oda actions, pudhu eval cases
Learn -[monitoring improve aachu]-> Detect
```

Indha lesson-la Chennai-la oru e-commerce company-la oru Saturday incident-a follow pannuvom, appo support assistant thappaana returns window-a promise pannuchu.

## Idhu eppadi work aagudhu

**Detect.** Errors, latency, cost, guardrail triggers, refusal rates, negative feedback, online eval scores-ku alerts. Oru theliva channel vazhiyaa user-um staff-um reports. Pala AI incidents mudhalla konjam complaints-aa thaan theriyum; avatrai serious-aa eduthukkunga.

**Severity-a assess pannunga.** Levels-a munnaadiyae define pannunga. Example: data leakage, customers-ku harmful output, unauthorised actions-ku severity 1; pala idathula thappaana answers illa full outage-ku severity 2; oru area-la kurainja quality-ku severity 3. Severity yaara eppo ezhuppanum-nu mudivu pannum.

**Roles.** Coordinate panni mudivu edukkura oru incident commander, hands-on fix panra oru aal, stakeholders-oda communicate panra oru aal. Sinna team-la oru aal pala roles-a vaikkalaam, aana commander role theliva irukkanum.

**Mudhalla contain pannunga.** Reason kandupidikkaradhukku munnaadi harm-a niruththunga: oru tool-ku illa feature-ku kill switch flip pannunga, previous release-ku rollback pannunga, index-la irundhu oru document-a disable pannunga, humans-ku route pannunga. Containment options neenga thevaippadradhukku munnaadiyae irundhu, test aagi irukkanum.

**Records-oda investigate pannunga.** Traces, audit logs, release identifiers enna nadandhadhu-nu kaattum. Avatrai paadhugaanga.

**Communicate.** Clients-ukkum users-ukkum seriyaana neraththula, nermaiyaana updates thevai. Regulated clients-ku DPDP Act-la personal data breach reporting maadhiri notification duties irukkalaam; avanga privacy, legal teams-a udane serkkunga.

**Learn.** Oru blameless post-incident review: timeline, impact, root causes (adhikka pala), enna nallaa pochu, enna maathanum, owners-um dates-um-oda. Trigger aana cases-a eval suite-layum monitoring-layum serkkunga.

**Severity levels-um responses-um:**

| Level | Examples | Response |
| --- | --- | --- |
| 1 | Data leakage, customers-ku harmful output, unauthorised actions | On-call-aiyum leads-aiyum udane page pannunga; nimishangal-la contain pannunga |
| 2 | Pala idathula thappaana answers, full outage | 15 nimishathula on-call; maninerangal-la client-ku theriyapaduthunga |
| 3 | Oru area-la kurainja quality | Adutha velai naal; mudiyara varaikkum track pannunga |

**Ovvoru incident type-kum oru runbook page.** Ovvoru vagai incident-kum oru page ezhudhunga: eppadi detect aagudhu, mudhal moonu containment actions switches-ku links-oda, yaarukku sollanum, relevant traces-um logs-um enga irukku. Pressure-la padikka mudiyura alavukku sinnadhaa vainga. Tabletop exercise-la andha page-a appadiye follow pannunga, theliva illaadha illa pazhaiya ovvoru idaththaiyum note pannunga, adha andha vaaramae sari pannunga.

**Incident-la client-ku ezhudhuradhu.** Othukkitta idaiveli-la sinna, facts irukkura updates anuppunga: enna nadakkudhu, users enna paathirukkalaam, enna pannaachu, adutha update eppo varum. Aarambaththula causes-a guess pannaadheenga. "Thappaana answers-a niruththiyaachu, evvalavu customers paadhikkapattaanga-nu confirm panrom"-nu sonnaa, nambikkaiyoda oru explanation-a vida adhigam nambikkai varum, adhu thappaa pochuna.

**Hard limits mattum illa, normal-la irundhu drift-a kandupidinga.** Pala AI incidents oru rate amaidhiyaa maarudhu. Kadaisi oru mani-a, sameeba naatkalodu adhe mani-oda compare pannunga:

```python
from statistics import mean, pstdev

def anomalous(current, history, min_sigma=3.0, min_abs=0.02):
    """current: rate this hour; history: same-hour rates from the last 14 days."""
    mu, sd = mean(history), pstdev(history) or 0.005
    return (current - mu) / sd > min_sigma and current - mu > min_abs

# e.g. refusal rate, guardrail triggers, thumbs-down rate, judge failure rate
if anomalous(0.11, [0.03, 0.04, 0.03, 0.05, 0.04, 0.03, 0.04]):
    page_on_call("Refusal rate 11% vs about 4% normal for this hour")
```

**Oru mosamaana document-a oru step-la contain pannunga.** "Assistant thappaana price-a sollidhu"-ngradhukku vegamaana fix adhikka oru source-a edukkuradhu thaan:

```python
def quarantine_document(doc_id, index, cache, audit, reason, who):
    index.set_flag(doc_id, quarantined=True)        # every search filters quarantined docs
    purged = cache.delete_where(source_doc=doc_id)  # cached answers built from it
    audit.write(actor=who, action="quarantine", target=doc_id, detail={"reason": reason, "cache_purged": purged})
```

Idha oru admin button aakkunga, launch-ku munnaadi test pannunga, runbook-la serkkunga.

**Traces-la irundhu impact-a measure pannunga.** Customers-um regulators-um "evvalavu per paathaanga?"-nu kekkuvaanga. Traces retrieved document ids-a record pannina, badhil oru query:

```sql
SELECT count(DISTINCT user_id) AS users, count(*) AS answers,
       min(created_at) AS first_seen, max(created_at) AS last_seen
FROM traces
WHERE 'pricing-2026-11' = ANY(retrieved_doc_ids)
  AND created_at BETWEEN '2026-11-06 09:00+05:30' AND '2026-11-07 14:30+05:30';
```

Trace data illaama idhu naatkal guess aagum, adhanaala nalla argument, retrieved ids-a mudhal naalilaeyae log pannuradhu.

**India-la reporting duties.** Oru personal data breach, DPDP Act-layum adhoda Rules-layum Data Protection Board-kum paadhikkappatta makkalukkum notice duties-a trigger pannalaam. Thaniyaa, CERT-In-oda 2022 directions pala vagai cyber security incidents-a 6 mani neraththukkulla report pannanum-nu solludhu. Oru incident reportable-aa-nu yaar mudivu pannuvaanga-nu (adhikka client-oda legal illa privacy lead) munnaadiyae othukkunga, avanga contact-a runbook-la vainga.

**Practice pannunga.** Ovvoru quarter-um vera scenario-oda oru tabletop exercise nadathunga: oru leak aana document, social media-la oru jailbreak screenshot, oru provider outage, formatting-a udaikkura oru model update. Detection-aiyum containment-aiyum neram paarunga, ungala mella paduthina edhaiyum sari pannunga.

## Oru worked example

Saturday, 11:40 am. Chennai e-commerce company-oda support assistant, ₹5,000-ku mela orders-ku 60 naalukku free returns kidaikkum-nu customers-kitta sollurathu aarambikkudhu. Policy 15 naal-nu solludhu.

11:55: returns kelvigalla negative feedback moonu madangu aagudhu; oru alert varudhu. On-call engineer incident commander aagi severity 2 declare pannuraanga.

12:05: Traces, marketing andha kaalai publish panna oru "Diwali returns campaign" page-a cite panra answers-a kaattudhu, adhula oru product category-ku mattum 60 naal-nu irundhudhu. Containment: andha page index-la irundhu edukkappadudhu, assistant-oda returns answers oru fixed, approve panna policy message-ku maarudhu.

12:20: Customer support leads-ku solluraanga; paadhikkappatta customers-ku 60-naal promise-a nadathikkoduppadharku thayaaraagiraanga. Audit logs 312 conversations-a identify pannudhu; andha orders-ku statement-a honour panna company mudivu pannudhu.

Thingal-kizhamai blameless review moonu causes kandupidikkudhu: indexing-ku munnaadi marketing pages review illai, campaign pages-la effective-date-um scope metadata-vum illai, returns pathi golden-set questions illai. Actions: marketing pages oru review step-oda thaniyaa index-la pogum, scope metadata serkkappadum, 20 returns questions golden set-la serkkappadum, policy sambandhamaana answers-la thidir maatrathukku oru alert.

| Neram | Event |
| --- | --- |
| 11:40 | Assistant 60-naal returns promise panna aarambikkudhu |
| 11:55 | Feedback alert; severity 2 declare |
| 12:05 | Campaign page index-la irundhu edukkapattadhu; fixed policy message on |
| 12:20 | Support leads-ku solliyaachu; 312 conversations identify panni honour pannaanga |
| Thingal | Blameless review: moonu causes, owners-oda naalu actions |

## Podhuvaa panra thappugal

- **Contain panradhukku munnaadi investigate panradhu.** Mudhalla harm-a niruththunga.
- **Test pannaadha kill switches-um rollbacks-um.** Practice pannunga.
- **Severity levels illaadhadhu.** Ovvoru incident-um illa panic, illa ignore.
- **Client-kitta silence.** Ketta seithi eppadiyum pogum; seekkiram, nermaiyaa sollunga.
- **Blame-focused reviews.** Makkal thappa maraippaanga, system improve aagaadhu.
- **Traces-la retrieved ids illaadhadhu**, adhanaala impact-a measure panna mudiyaadhu.
- **Kaagidhathula mattum irukkura containment tools.** Launch-ku munnaadi ovvoru switch-aiyum quarantine-aiyum test pannunga.
- **Root cause-kaaga kaathirundhu client-ku solradhu.** Ungalukku theriyura facts-a anuppunga.

## Lighter process podhumaana neram

- **Konjam users irukkura internal prototypes**: oru peyar sollappatta owner, oru kill switch, oru chat channel podhum.
- **Public data-la read-only tools**, mosamaana case makkal check panna mudiyura oru thappaana answer.

Customers, personal data, panam, regulated decisions irundhaa, muzhu severity levels, on-call rotas, runbooks, drills thevai.

## Demo-la irundhu production-ku

- **Rate changes-ku alert pannunga**: refusals, guardrail triggers, feedback, judge failures-ku, errors-ku mattum illa.
- **Containment-a oru click-la vainga**: kill switches, rollback, document quarantine, ellaam test aanadhu.
- **Retrieved ids, versions, users-a log pannunga**, impact-a vegamaa measure panna.
- **Runbook-la DPDP, CERT-In duties-ku reporting decision-maker-a peyar sollunga.**
- **Quarter-ku oru thadava drill pannunga**, ovvoru thadavayum mella irundha step-a sari pannunga.
