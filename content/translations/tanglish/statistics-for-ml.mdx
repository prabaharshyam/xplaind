## Idhu enna

Machine learning-na data-la irundhu kathukkiradhu; data-vo noisy-aa, skewed-aa, muzhumaiyillaama irukkum. **Statistics**-na uncertainty-kkulla ungalai neengalae yemaaththikkaama data-la irundhu kathukka udhavura toolkit. ML engineering-la dhinamum varra ainthu pagudhigal:

| Pagudhi | Entha kelvikku badhil solludhu | Entha vazhakkamaana thappai thadukkudhu |
| --- | --- | --- |
| **Data-va describe panradhu** | Typical enna, evvalavu paraviyirukku? | Misleading average-a report panradhu |
| **Sampling** | Naama kavalaippadura makkalai namma data represent pannudhaa? | Tier-3 towns-la fail aagura model |
| **Uravugal** | Idhellaam serndhu nagarudhaa, onnu innonnukku kaaranamaa? | Oru feature thaan outcome-kku kaaranam-nu claim panradhu |
| **Uncertainty** | Indha number-la evvalavu urudhi? | Noise-aa irukkura 1-point gain-a kondaadaradhu |
| **Experiments** | Namma change unmaiyilaeyae udhavuchaa? | Festival sale-oda credit-a pudhu model-kku kudukkuradhu |

```text
  Order values (skewed: most small, a few huge)

  count
   |  ####
   |  ########
   |  ##########
   |  ######
   |  ###
   |  #                                         #
   +----------------------------------------------- value
      ^ median ₹780                    ^ mean ₹1,240 pulled right by a few big orders
```

Mumbai-la oru e-commerce company-yoda data team-a indha lesson follow pannum. Pudhu recommendation model "order value-va ₹70 uyarthuchu"-ngra claim, sariyaana statistics-la paarthaa romba sinna, aana unmaiyaana gain-aa maarudhu. Lesson mudiyumbodhu oru niyaayamaana A/B test design pannavum, sinna test sets yen yemaaththum-nu explain pannavum mudiyum.

## Idhu eppadi work aagudhu

### Averages-um spread-um

**Mean** ellaaththaiyum kootti vaguum. Theeviramaana values adhai izhukkum. **Median**-na sort pannaa naduvula varra value. Adhu izhukkappadaadhu.

Indiavula income, order values, insurance claims perumbaalum **skewed**-aa irukkum: perumbaalaana values sinnadhu, sila mattum romba periyadhu. Adhanaala median thaan perumbaalum typical. Spread-kku:

| Data shape | Entha average use panradhu | Entha spread use panradhu |
| --- | --- | --- |
| Kittathatta symmetric, bell vadivam | Mean | Standard deviation |
| Skewed, neelamaana tail | Median | 90th, 99th maadhiri percentiles |

Summarise panradhukku munnaadi eppavum oru histogram plot pannunga.

### Distributions

Neraiya alavugal kittathatta **normal** (bell vadivam), udhaaranam: measurement errors. Neraiya business alavugal skewed-aavo neelamaana tails-odavo irukkum. Aboorvamaana events-oda counts vera vadivangalla irukkum. Entha summaries, models poruntthum-nu shape thaan mudivu pannum.

### Sampling

Metro customers-la train panna model tier-3 towns-la fail aagalaam. Kelunga: **Indha data-la yaaru missing?** Sila cases-kku saadhagamaa collect pannaangala, udhaaranam: complain panna customers mattum, illa approve aana loans mattum (adhanaala reject aanavanga thirumbi kattiyiruppaangalaanu neenga paarkkavae maatteenga)? Indha **selection bias** launch-kku appuram models-a saththamillaama udaikkum.

### Correlation-um causation-um

Rendu vishayangal serndhu nagarradhaala onnu innonnukku kaaranam-nu artham illai. Ice-cream sales-um neeril moozhgi irakkuradhum kodaiyila rendumae adhigamaagudhu: veyil thaan rendaiyum iyakkudhu. Model correlations-a use panni **predict** pannalaam, aana oru **cause**-a claim panna, udhaaranam: discount retention-a adhigarichudhu, oru experiment illa kavanamaana causal methods venum.

### Confidence intervals

200 test examples-la alandha 87% accuracy, vera 200 examples sample-la 82% illa 92%-aa kooda varalaam. **Confidence interval** indha range-a solludhu.

```text
  Accuracy on 200 examples, with 95% intervals:
  Model A  87%   |-------[====*====]-------|   about 82% to 92%
  Model B  88%    |-------[====*====]-------|  about 83% to 93%
                  heavily overlapping: no clear winner
```

Sinna test sets agalamaana intervals tharum. 200 examples-la 1-point gain-a kondaadaadheenga. Interval-a calculate panna oru practical vazhi **bootstrapping**: test set-a replacement-oda pala thadava resample panni, ovvoru thadavaiyum metric-a marubadiyum calculate panni, naduvula irukkura 95% results-a paarunga.

### A/B tests

Pudhu model udhavudhaa-nu therinjukka, users-a **randomly** pirainga: paadhi peru pazhaya version-a, paadhi peru pudhu version-a paarpaanga. Munnaadiyae neenga thernthedutha oru metric-a compare pannunga.

| Rule | Yen |
| --- | --- |
| Metric-aiyum sample size-aiyum munnaadiyae mudivu pannunga | Illanna nallaa theriyura number-a thernthedupeenga |
| Yaaru entha version-a paarpaanga-nu randomise pannunga | Appo groups rendukkum vithiyaasam change mattum thaan |
| Muzhu vaarangalukku run pannunga | Weekday, weekend behaviour vera vera |
| Nallaa theriyudhu-nu seekkiram niruththaadheenga | Aarambha results aadum; uchchaththula niruththunaa effect peridhaa theriyum |
| Guardrail metrics-a kavaninga | Order value gain-oda returns, complaints adhigamaagakkoodaadhu |

## Oru worked example

Mumbai e-commerce company-yoda data team solraanga, pudhu recommendation model sarasari order value-va ₹1,240-la irundhu ₹1,310-kku uyarthuchu: ₹70 gain. Leadership kondaada thayaaraa irukkaanga. Neenga check panreenga.

**Averages.** Order values skewed. Sila periya electronics orders mean-a nagarthiduchu. Median ₹780-la irundhu ₹790-kku mattum thaan uyarnthuchu.

**Sampling.** Compare pannadhu pona maasam (pazhaya model) vs indha maasam (pudhu model). Indha maasam oru festival sale irundhuchu. Adhanaala rendu maasangalaiyum compare panna mudiyaadhu.

**Sariyaana test.** Team rendu vaaram A/B test run panraanga: oru group-kku 2,00,000 users, randomly assign pannadhu, median order value-vum conversion rate-um munnaadiyae metrics-aa thernthedutthadhu, returns guardrail-aa.

| Measure | Pazhaya model | Pudhu model | Vithiyaasam (95% interval) |
| --- | --- | --- | --- |
| Median order value | ₹781 | ₹799 | +₹18 (₹6 mudhal ₹30) |
| Conversion rate | 3.42% | 3.43% | Thelivaana maatram illai |
| Return rate (guardrail) | 6.1% | 6.0% | Thelivaana maatram illai |

Model udhavudhu thaan, aana mudhal report claim pannadhula kittathatta kaal pangu thaan. Indha gain-ae roll out panradhai justify pannudhu-nu leadership mudivu panraanga, ippo nermaiyaana numbers-oda; team thannoda launch checklist-la "Impact claim panradhukku munnaadi A/B test"-a serthukkudhu.

## Podhuvaa panra thappugal

- **Skewed data-voda mean-a report panradhu.** Median-aiyum histogram-aiyum paarunga.
- **Vera vera kaalangalai compare panradhu.** Seasons, festivals ellaaththaiyum maaththum; adhukku badhila randomise pannunga.
- **Data-la yaaru missing-nu kavanikkaama irukkuradhu.** Selection bias appuram models-a udaikkum.
- **Correlation-a causation-aa eduththukkuradhu.** Prediction-ngradhu cause-kku proof illai.
- **Sinna test sets, sinna gains.** Improvement claim panradhukku munnaadi confidence interval-a check pannunga.
- **A/B tests-a ettippaarththu seekkiram niruththuradhu.** Duration-a munnaadiyae mudivu panni adhula nillunga.

## Practice pannunga

Keezha link pannirukkura StatQuest-oda histograms, mean vs median, confidence intervals, A/B testing videos-aiyum, Google-oda Machine Learning Crash Course-la data module-aiyum paarunga.

1. **Mean vs median.** Panam irukkura column ulla edhaavadhu oru public dataset-a load pannunga. Histogram plot panni, mean-aiyum median-aiyum compare pannunga.
2. **Bootstrap.** 200 test examples-la oru model-oda accuracy-kku, test set-a 1,000 thadava resample panni 95% confidence interval-a calculate pannunga.
3. **Test design pannunga.** Ungalukku mukkiyamaana oru change-kku oru A/B test design pannunga: metric, guardrails, sample size mathippeedu, duration.

**Mudinjadhu-nu eppo sollalaam:** 200 examples-la 1-point accuracy gain yen convincing illai-nu explain panna mudiyum, oru niyaayamaana A/B test-a design panna mudiyum.
