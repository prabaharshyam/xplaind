## Idhu enna

**Data curation**-na, oru model kathukkura examples-a choose panradhu, ezhudhuradhu, clean panradhu, balance panradhu. Fine-tuning-ku idhu thaan perumbaalaana velai: training run oru mani neram edukkalaam, aana data-ku vaarakkanakkaagum.

Neenga enna kathukkudukkureenga-nu adha poruthu format maarum:

- **Supervised fine-tuning (SFT):** oru instruction illa chat, adhukku ideal response.
- **Preference tuning (DPO illa RLHF):** oru prompt, oru nalla response, oru mosamaana response.
- **Continued pre-training:** legal judgements maadhiri ungaloda field-oda plain text.
- **Oru reward model illa judge:** score illa label-oda responses.

Ovvoru dataset-um moonu vishayangala judge aagum. Samaiyal oru nalla ubama:

- **Quality**-na fresh ingredients: ovvoru example-um sariyaa, consistent-aa irukku.
- **Coverage**-na sariyaana mix: examples users unmaiyilae konduvara cases-a cover pannudhu.
- **Quantity**-na mesai-ku podhumaana sappaadu: task-ku podhumaana examples irukku.

Curation-na data-va neekkuradhum thaan. Ungaloda model-ku oru ketta pazhakkam irundhaa, example kekkaama ovvoru answer-layum advice serkkuradhu maadhiri, andha pazhakkathai kaattura training examples-a thedunga, avatrai edunga, neenga virumbura behaviour-a kaattura examples-a serkkunga.

## Idhu eppadi work aagudhu

**Quality.** Oru example, ippadi irundhaa high quality:

1. Neenga train panra task-ku **relevant**.
2. Task-ku thevaiyaanadhoda **align** aagirukku. Task-ku short answers thevai-na, examples short; ovvoru score-kum oru reason thevai-na, avatrula oru reason irukku.
3. Matha examples-oda **consistent**. Adhe case-a label panra rendu per perumbaalum othukkanum.
4. **Sariyaana format**, model produce pannanum-nu virumburadhu appadiye, stray HTML illa udaintha JSON illaama.
5. **Unique.** Duplicates sila cases-a adhigam weight panni, ungaloda test set-kullayum leak aagalaam.
6. **Use panna anumadhi irukku**: use panna mudiyaadha personal data illa, train panna urimai illaadha content illa.

Quality, volume-a vida mela-nu solra evidence strong. LIMA study oru periya model-a vendum-nu therndhedutha 1,000 examples-la mattum fine-tune pannuchu, makkal adhikka oru munnani commercial model-a vida nalladhu-nu rate panna answers kidaichudhu. Yi models-oda team, kavanamaa ezhudhina 10,000 examples, noisy-aana laksha kanakkaana examples-a vella-nu kandupidichaanga.

**Labelling guide.** Yaarum periya scale-la label panradhukku munnaadi, oru perfect output eppadi irukkum-nu, kashtamaana cases-um avatrai eppadi handle panradhu-nu examples-oda ezhudhi vainga. Appuram oru pilot nadathunga: rendu per adhe 30 items-a label pannuvaanga, neenga compare pannuveenga, avanga othukkaadha idathula guide-a sari pannuveenga. Agreement high aagura varaikkum dohrunga. Idhu irukkura romba cheap-aana quality step.

**Coverage.** Unmaiyaana users varied-aa irukkaanga, adhanaala ungaloda data-vum irukkanum. Inputs eppadi maarudhu-nu list pannunga: language, length, topic, difficulty, format (typed illa scanned), single-turn illa multi-turn, ovvondrum mix-la mukkiyam-nu paarunga. Llama 3-oda munnadhiya versions-a vida adhigam gains-ku, pudhu architecture illa, nalla data quality-yum variety-yumthaan kaaranam-nu Meta sonnaanga. Aana adhigam variety thaanaa nalladhu illa: sambandhamillaadha data-va serthaa, ungaloda task-la model mosamaagalaam.

**Quantity.** Fixed number illa. Idhu poruthu irukkum:

- **Task.** Reviews-a positive, negative-aa pirikka, financial filings pathi kelvigalukku badhil solradha vida romba kammi examples podhum.
- **Base model.** Adhu ippodhae evvalavu nerungi irukko, avvalavu kammi examples thevai. Konjam data irundhaa, strong model-la irundhu aarambinga.
- **Method.** LoRA, matha light methods nooru mudhal sila aayiram examples-la work aagum; full fine-tuning adhikka pathu aayiram illa adhukku mela virumbum.

Practical vazhi: **50 mudhal 100 excellent examples**-oda aarambinga. Perumbaalum adhu theriyura improvement tharum. Avai theliva help pannina, innum data innum help pannum. Edhuvum pannaadhunaa, ungaloda prompt format-aiyum settings-aiyum check pannunga; periya set, fail aana sinna set-a adhikka kaapathaadhu.

Appuram **learning curve**-a measure pannunga: ungakitta irukkuradhoda 25%, 50%, 100%-la train pannunga, ovvondraiyum adhe test set-la score pannunga. Data serkkum podhu gains adhikka kuraiyum. Innum steep-aa yerura curve innum collect pannunga-nu solludhu; flat curve, quality-la effort podunga-nu solludhu.

Oru sinna script learning curve-ku data-va pirikkum, labeller agreement-aiyum check pannum:

```python
import json, random

def subsets(rows, fractions=(0.25, 0.5, 1.0), seed=7):
    rows = rows[:]
    random.Random(seed).shuffle(rows)       # same order every time, so subsets nest
    return {f: rows[: int(len(rows) * f)] for f in fractions}

def agreement(labels_a, labels_b):
    """Share of items two labellers marked the same way."""
    same = sum(a == b for a, b in zip(labels_a, labels_b))
    return same / len(labels_a)

train = [json.loads(line) for line in open("train.jsonl")]
for f, part in subsets(train).items():
    with open(f"train_{int(f * 100)}.jsonl", "w") as out:
        out.writelines(json.dumps(r) + "\n" for r in part)

print(agreement(["late_fee", "deposit", "lock_in"], ["late_fee", "deposit", "notice"]))  # 0.67
```

**Speed-ups.** Scratch-la irundhu ezhudharadha vida oru draft-a check panni sari panradhu vegam-nu makkal kandupidikkiraanga, adhanaala pala teams oru strong model ovvoru answer-aiyum draft pannattum, experts adha fix pannattum-nu vaikkuraanga. Bias-a gavanichukkunga: makkal oru fluent draft-a romba easy-aa othukkuvaanga, adhanaala sari panna items-la oru random sample-a neengalae check pannunga.

| Step | Nalla irundhaa eppadi irukkum | Podhuvaana failure |
| --- | --- | --- |
| Labelling guide | Ezhudhina rules, kashtamaana cases-oda | "Sariyaa label pannunga" |
| Pilot | Rendu per, adhe 30 items, high agreement | Neram migatha skip pannaanga |
| Coverage plan | Target counts-oda input types list | Mudhalla vandha files |
| Mudhal set | 50 mudhal 100 excellent, varied examples | Check pannaadha 5,000 examples |
| Cleaning | Dedupe aagi, oru format, personal data mask | Test items training-la copy aanadhu |
| Learning curve | 25%, 50%, 100%-la scores | Oru training run, compare illa |

## Oru worked example

Hyderabad-la oru legal-tech startup, residential rental agreements-a, English-layum Telugu-layum padichu, oru fixed summary kudukkura model venumnu virumbudhu: rent, deposit, lock-in period, notice period, varushaanthira increase, vazhakkamilladha clauses. Avangakitta 3,000 agreements, rendu vaaraththukku rendu lawyers, AI help-ku panam irukku.

1. **Guide-um pilot-um.** Lawyers rendu-page guide ezhudhuraanga. 30 agreements-oda pilot-la, 70% fields-la othukkuraanga, perumbaalum "vazhakkamilladha"-nu edhu count aagum-nu disagree pannuraanga. Guide-la vazhakkamilladha clauses-oda pannirendu examples serkkuraanga; adutha pilot 92% adaiyudhu.
2. **Coverage.** Users upload panradhukku match aagura agreements-a choose pannuraanga: 60% English-um 40% Telugu-vum, aindhula onnu scanned, standard-um custom formats-um.
3. **Drafts + review.** Oru strong model ovvoru summary-aiyum fixed format-la draft pannudhu, lawyers sari pannuraanga. 25-ku badhila oruththar oru naalukku sumaar 80 mudikkiraanga.
4. **Cleaning.** Duplicate templates neekkapadudhu, tenant, owner names-um Aadhaar numbers-um mask aagudhu, 120 agreements test set-aa pootti vaikkapadudhu.
5. **Learning curve.**

| Training examples | 120 test agreements-la sariyaana fields |
| --- | --- |
| 150 | 68% |
| 300 | 76% |
| 600 | 81% |

Numbers purinjukka mattum. Curve innum yerikkittu irukku, adhanaala innoru 600 collect panradhu worth-aa irukkalaam. Telugu scores English-a vida 9 points pinnaadi irukku, adhanaala adutha batch Telugu agreements pakkam saayum.

## Podhuvaa panra thappugal

- **Guide ezhudhradhukku munnaadi labelling.** Makkal disagree pannuvaanga, model andha disagreement-a kathukkum.
- **Easy-aa kidaikkura data-va edukkuradhu.** Coverage gaps production-la blind spots aagum.
- **Adhigam eppavum nalladhu-nu nambuvadhu.** Aayiram noisy examples, nooru clean examples-a thoakkalaam.
- **Test items training-ku leak aaga vidradhu.** Split panradhukku munnaadi duplicates-a edunga, test set-a thodaama vainga.
- **Expert workflows-a kannai moodikittu copy panradhu.** Experts obvious-nu nenaikkura steps-a thaandi poiduvaanga. Avanga eppadi velai seiyuraanga-nu paathu ovvoru step-aiyum ezhudhunga.
- **Multi-turn cases-a marakkuradhu.** Users conversations pannina, conversations-la train pannunga, follow-ups-um corrections-um sethu.

## Training dataset thevai illaadha neram

- **Oru nalla prompt already bar-a thotudhu.** Mudhalla adha measure pannunga.
- **Kuraivu facts illaadhadhu.** Retrieval-a, dataset-a vida seekkiram update pannalaam.
- **Test panna vazhi illa.** Mudhalla test set-a build pannunga; training help pannuchaa-nu adhu thaan solludhu.

## Demo-la irundhu production-ku

- **Data-va version pannunga**, guide-oda, cleaning script-oda, appadi irundhaa entha model-aiyum thirumba build panna mudiyum.
- **Ovvoru example-um enga irundhu vandhadhu-nu record pannunga**: oru aal ezhudhinadhu, oru model draft pannadhu, illa unmaiyaana use-la irundhu eduththadhu.
- **Production-la irundhu set-a valarthunga.** Reviewer corrections-um user feedback-um thaan ungaloda sirandha pudhu examples.
- **Product maarum podhu guide-a thirumba check pannunga**, appadi irundhaa pazhaiya labels pazhaiya rules-a kathukkudukkaadhu.
- **Deletion path vainga.** Yaaraavadhu avanga data-va neekka sonnaa, adha kandupidichu drop panni, thirumba train panna mudiyanum.
