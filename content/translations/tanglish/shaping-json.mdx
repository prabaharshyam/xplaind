## Idhu enna

Almost ovvoru automation-um AI application-um apps-kku naduvula data-va move pannum, andha data perumbaalum **JSON** (JavaScript Object Notation)-la thaan varum: structured data-va exchange panna apps use panra text format. JSON-a padichu reshape panna therinja, edhaiyum edhoda-vum connect pannalaam.

JSON-ku moonu building blocks:

| Building block | Eppadi irukkum | Example |
| --- | --- | --- |
| **Object** | Curly braces-kulla peyar vechcha fields | Name, phone, city irukkura oru customer |
| **Array** (list) | Square brackets-kulla items | Order lines-oda oru list |
| **Value** | Quotes-kulla text, number, true illa false, illa null (empty) | "Mysuru", 2, true, null |

Objects-um arrays-um onnukkulla onnu nest aagum. Oru payment webhook-la payment-ku oru object, adhukkulla customer-ku oru object, adhukkulla notes-oda oru array irukkalaam.

```flow
title: Oru order, nested JSON-aa
order (object) -> id: "ORD-88213"
order (object) -> customer (object)
customer (object) -> name: "Nisha Rao"
customer (object) -> phone: "9845012345"
customer (object) -> email: null
order (object) -> lines (array)
lines (array) -> [0] sku, qty, price
lines (array) -> [1] sku, qty, price
order (object) -> shipping (object)
shipping (object) -> city: "Mysuru"
shipping (object) -> pin: "570001"
```

Indha lesson oru online tea store-oda order webhook, dispatch sheet-la rows-aa maaridhu, customer-ku SMS-aa pogura vazhiya follow pannum. Mudiyum podhu, theriyaadha JSON payload-a eduthu, oru workflow-ku thevaiyaanadhai exact-aa edukka mudiyum.

## Idhu eppadi work aagudhu

### Path-a padikkradhu

Nested field-a reach panna, veliyila irundhu ullukku peyargala follow pannunga, dots-aala serthu. Array items square brackets-la **0**-la irundhu number aagum.

| Enna vennum | Path |
| --- | --- |
| Order id | `order.id` |
| Customer-oda phone | `order.customer.phone` |
| Modhal line-oda price | `order.lines[0].price` |
| Rendaavadhu line-oda SKU | `order.lines[1].sku` |
| Delivery PIN code | `order.shipping.pin` |

### Real samples-a paarunga

Documentation-a mattum paathu path-a guess pannaadheenga. Oru real illa test event-a trigger panni, vandha exact JSON-a paarunga. n8n-la output panel ovvoru item-aiyum table-aa, raw JSON-aa, schema-vaa kaattum; exact path-a kandupidichu copy panna adha use pannunga.

### Edu, rename pannu

Perumbaalaana workflows-ku periya payload-la sila fields mattum thaan vennum. Adhai pick panni, theliva peyar kudukka "Edit Fields" illa "Set" step use pannunga: `payment.notes.contact_no`-ku badhila `customer_phone`. Apram varra steps-a padikkavum maintain panna romba easy aagum.

### Lists-la irundhu items-ku, thirumba

Oru field-la list irundha, order lines, attachments maadhiri, adha **split** pannunga, appo ovvoru element-um adutha steps-ku thani item aagum. Appo ovvoru line-um thani sheet row aagalaam. Thirumba poganum-na, items-a oru list-aa **aggregate** pannunga.

```flow
1 item | [A, B] lines-oda oru order -[lines-a split pannu]-> Item 1 | order id, line A
1 item -[lines-a split pannu]-> Item 2 | order id, line B
Item 1 -> Ovvonnukkum oru sheet row
Item 2 -> Ovvonnukkum oru sheet row
```

Innum thevai-nu irukkura fields-a, order id, city maadhiri, ovvoru split item-layum vachchukonga.

### Types

Values perumbaalum thappaana type-la varum:

| Vandha value | Problem | Fix |
| --- | --- | --- |
| `"1,250.00"` | Comma irukkura text, number illa | Commas-a remove panni, number-aa convert pannunga |
| `"03/11/2026"` | 3 November-aa, 11 March-aa? | Provider document panna format-la parse pannunga |
| Number-aa `9845012345` | Paravaayillai, aana number-aa irukkura `0123` zero-va izhakkum | Phone numbers, PIN codes, ids-a text-aa vachchukonga |
| `"true"` | Text, true illa false illa | Text-aa compare pannunga, illa convert pannunga |

### Missing values

Sila records-la fields illaama irukkalaam illa `null`-aa irukkalaam. Munnaadiyae decide pannunga: default use pannalaam, oru step-a skip pannalaam, illa record-a oru aal kitta route pannalaam. "`customer.email` null-na, email step-a skip panni SMS anuppu" oru rule; crash aagura workflow rule illa.

### APIs-kum AI steps-kum JSON build panradhu

Oru API-kku illa AI step-ku data anuppum podhu, adhu edhirpaakkura exact shape-a neenga build pannanum. **JSON schema** andha shape-a describe pannum: endha fields, avatroda types, edhellaam kattayam. Unga output-a API-oda documentation-oda check pannunga, AI structured outputs-na model-ku neenga kudukkura schema-voda check pannunga.

### Power tools

`jq`-um JSONata-vum JSON-a query panni reshape panna chinna languages. Neraya automation tools idhu maadhiri expressions-a support pannum. Aarambikka ivai thevai illa, aana complicated payloads-ku help pannum.

## Oru example

Bengaluru-la oru online tea store-ku, order podum podhu indha webhook (surukki) varudhu:

```json
{
  "order": {
    "id": "ORD-88213",
    "created_at": "2026-11-03T10:42:00+05:30",
    "customer": { "name": "Nisha Rao", "phone": "9845012345", "email": null },
    "lines": [
      { "sku": "TEA-ASSAM-250", "qty": 2, "price": "349.00" },
      { "sku": "MUG-STEEL", "qty": 1, "price": "1,199.00" }
    ],
    "shipping": { "city": "Mysuru", "pin": "570001" }
  }
}
```

Goal: dispatch sheet-la ovvoru order line-kum oru row, customer-ku oru SMS.

1. `order.lines`-a items-aa **split** pannunga, ovvonnulayum `order.id`, `customer.name`, `shipping.city`, `shipping.pin`-a vachchukonga.
2. `price`-a commas-a remove panni text-la irundhu number-aa **convert** pannunga, apram line total = qty × price compute pannunga.
3. `pin`-a text-aa **vachchukonga**, appo "570001" ippadiyae irukkum.
4. **SMS:** `customer.phone`-oda +91 serthu use pannunga. `email` `null`-aa irukkradhaala, indha order-ku email step-a skip pannunga.

Dispatch sheet-ku rendu rows kidaikkum:

| Order | Customer | SKU | Qty | Price | Line total | City | PIN |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ORD-88213 | Nisha Rao | TEA-ASSAM-250 | 2 | 349 | 698 | Mysuru | 570001 |
| ORD-88213 | Nisha Rao | MUG-STEEL | 1 | 1,199 | 1,199 | Mysuru | 570001 |

Convert step-ku munnaadi, "1,199.00" text-aa irundhadhaala rendaavadhu line-oda total error-aa kaattuchu. Null check-ku munnaadi, email illaadha ovvoru customer-kum workflow fail aachu, sumaar anju orders-la onnu.

## Podhuvaa panra thappugal

- **Paths-a guess panradhu.** Real samples-a paathu, exact path-a copy pannunga.
- **List irukkum podhu oru item-nu nenaikkiradhu.** Lists-a items-aa split pannunga.
- **Numbers-a text-aave vittudradhu.** "1,199.00" convert pannra varaikkum serkka mudiyaadhu.
- **Mundhaiya zeros-a izhakkradhu.** PIN codes, phone numbers, ids-a text-aa vachchukonga.
- **Missing fields-ku fail aagradhu.** Null, illaadha fields-ku oru rule-oda plan pannunga.
- **Array 0-la aarambikkum-nu marandhudradhu.** Modhal item `[0]`, `[1]` illa.

## Practice pannunga

Keezha link panni irukkura MDN-oda JSON guide-aiyum, working with data pathina n8n page-aiyum padinga.

1. **Paths.** Mela irukkura sample illa oru real webhook sample-a vachchu, aindhu fields-oda path ezhudhunga, list-kulla irukkura onnu ulpada.
2. **Reshape.** n8n-la order lines-a items-aa split panni, prices-a numbers-aa convert panni, line totals compute pannunga.
3. **Missing data.** Phone number illaadha orders-a oru aal kitta route panra check-a serkkunga.

**Mudinjadhu-nu eppo sollalaam:** theriyaadha JSON payload-a eduthu, paththu nimishathukkulla, oru workflow-ku thevaiyaana fields-a extract panni reshape panna mudiyum.
