## Idhu enna

**Regression** features-la irundhu oru number-a predict pannum: oru delivery time, oru price, adutha vaara demand. **Linear regression**, prediction-a features-oda oru weighted sum kooda oru constant-nu assume pannum:

predicted delivery minutes = 6 + 2.1 × distance in km + 0.4 × items + 3 × (rain? 1 or 0)

Ovvoru weight-um oru **coefficient**. Matha features-a fixed-aa vachukittu, andha feature-la oru unit maarunaa prediction evvalavu maarum-nu adhu sollum. Inga, oru extra km 2.1 minutes serkkum, mazhai 3 serkkum. Past data-la predictions-a actual values-ku ellaathaiyum vida nerukkamaa kondu varra weights-a training kandupidikkum.

Matha regression models (decision trees, gradient boosting, neural networks) curves-aiyum interactions-aiyum follow panna mudiyum. Irundhaalum aarambikka vendiyadhu linear regression-la thaan: adhu fast, explain panna easy, endha complex model-um beat panna vendiya baseline adhu thaan.

```text
  price
   |                                  *
   |                          *   *
   |                 *    * /        <- fitted line: price = a + b x feature
   |          *    *   /  *
   |     *      /  *
   |   *    /                  residual = actual - predicted
   |    /  *                   (vertical gap from point to line)
   +-------------------------------- car age, km, ...
```

Oru real point-kkum line-kkum idaiyila irukkura gap thaan **residual**. Indha lesson-la kittathatta ellaame residuals-a nermaiyaa measure panradhaiyum adhoda patterns-a padikkiradhaiyum pathi thaan.

Sellers-ku oru suggested-price feature build panra Chennai-la irukkura oru used-car marketplace-a indha lesson follow pannudhu.

### Fitting

Vazhakkamaana loss **mean squared error** (MSE): predicted values-kkum actual values-kkum idaiyila irukkura gaps-oda squares-oda average. Square panradhaala oru ₹2 lakh miss, oru ₹1 lakh miss-a vida naalu madangu count aagum, adhanaala line periya errors pakkam valaiyum. scikit-learn maadhiri libraries idhai ore call-la fit pannum.

### Data-va split panradhu

Model train aagaadha data-la thaan eppavum evaluate pannanum. Kaalappokkula maarura edhukkum (prices, demand, delivery times), test set **latest** period-aa irukkanum: pazhaya months-la train pannunga, kadaisiyaa vandha months-la test pannunga. Random split months-a kalandhudum, adhanaala test months-oda price level-a model erkanave paarthuduchu. Appo adhoda score, market nagarndha piragu adutha maasam irukkapporadhai vida nallaa theriyum. Idhu oru vagai data leakage.

### Error-a measure panradhu

- **MAE** (mean absolute error): errors-oda average size, original units-la. "Saraasariyaa ₹59,000 thappu"-nu oru business team-ku explain panradhu easy.
- **RMSE** (root mean squared error): MSE-oda square root, idhuvum original units-la. Idhu eppavume kuranjadhu MAE alavukkaavadhu irukkum. Rendukkum idaiyila periya gap irundhaa, sila predictions romba mosamaa thappaa irukku-nnu artham.
- **MAPE** (mean absolute percentage error): "Saraasariyaa 11% thappu". Values malivula irundhu vilai adhigam varai irukkumbodhu useful, aanaa actual values zero-ku pakkathula irundhaa idhu udainjudum.
- **R²**: explain aana variation-oda share. Idhu adhigapatcham 1. Test data-la idhu **negative**-aa kooda irukkalaam, adhaavadhu average-a predict panradhai vida model mosam. Ore data-la models-a compare panna idhu useful, aanaa business users-ku idhu intuitive-aa thonuradhu aridhu.

| Measure | Eppadi padikkalaam | Eppo use pannanum |
| --- | --- | --- |
| MAE | "Saraasariyaa ₹59,000 thappu" | Business users purinjukkura oru number venumbodhu |
| RMSE | MAE maadhiri thaan, aanaa periya misses adhigamaa count aagum | Refunds, buy-back guarantees maadhiri, periya errors-ku kurippaa cost adhigamaa irukkumbodhu |
| MAPE | "Saraasariyaa 11% thappu" | Values eppavum zero-ku pakkathula varaama, percentage error thaan mukkiyamaa irukkumbodhu |
| R² | Explain aana variation-oda share | Ore test data-la models-a compare pannumbodhu |

**Oru decision rule.** Oru thappoda cost-ku match aagura metric-a therndhedunga. Error-oda ovvoru rupee-kkum ore cost-naa, MAE use pannunga. Moonu ₹1 lakh misses-a vida oru ₹3 lakh miss adhigamaa baadhikkum-naa, RMSE-a gavaninga. Ovvoru thadavaiyum model pakkathulaye median baseline-aiyum report pannunga.

### Coefficients-a padikkiradhu

Coefficients units-aiyum model-la irukkura matha features-aiyum poruthadhu. Rendu features ore information-a kondu vandhaa (distance-um travel time-um, allathu car age-um kilometres-um), model adhukku idaiyila weight-a maathi maathi kudukkalaam. Appo predictions ore maadhiri irundhaalum, coefficients oru sample-la irundhu aduthadhukku aadikitte irukkum. Idhu thaan **multicollinearity**. Idhai kandupidikka, features-ku idaiyilaana correlations-a check pannunga, allathu ovvonnukkum variance inflation factor (VIF)-a compute pannunga. Oru common rule of thumb padi VIF 4-ku mela irundhaa paarkka vendiyadhu, 10-ku mela irundhaa serious. Sari panna, overlap aagura features-la onnai drop pannunga allathu merge pannunga.

Coefficients association-a thaan sollum, cause-a illa. Adhukku confidence intervals venumnaa, vazhakkamaana formulas errors onnukkonnu independent-aavum, ellaa idathulayum kittathatta ore spread-odavum irukkum-nu assume pannum. Ore car-oda repeat sales, allathu price kooda kooda valarra errors, andha assumptions-a udaichudum.

### Residual patterns, enna pannanum

Ovvoru feature-ku edhiraavum, predicted value-ku edhiraavum residuals-a plot pannunga.

- **Oru random cloud:** model pattern-a pidichuduchu.
- **Oru curve:** oru non-linear effect. Oru transformed feature (distance squared, age bands) serunga, allathu oru tree model-a try pannunga.
- **Oru funnel** (price valara valara errors-um valarum): errors proportional. Target-oda log-a model pannunga.
- **Periya errors-oda oru cluster:** model mosamaa handle panra oru group, oru brand maadhiri, allathu oru data problem.
- **Sila extreme points:** squared error avai line-a izhukka vidum. Mudhalla avatrai investigate pannunga. Avai data errors-aa irundhaa mattum remove pannunga (oru ₹50 listing, 9,99,999 km odina oru car); illainnaa oru robust loss-a yosinga.

### Log targets, thirumbi varra vazhi

Used-car prices skewed-aa irukkum: niraiya malivaana cars, vilai adhigamaana cars-oda oru neelamaana tail. log(price)-la train pannaa model percentage errors-a fit pannum. Adhu "ovvoru varushamum price-a 11% kuraikkudhu"-ngradhai oru straight line-aa maathum, negative price-a orubodhum predict pannaadhu.

Gotcha thirumbi varra vazhiyila thaan. Predicted log price-oda exp-a eduthaa, andha features-ku kittathatta **median** price thaan kidaikkum, mean illa. Mean venumnaa, training data-la exp(residual)-oda average-aala multiply pannunga. Idhukku smearing correction-nu peru. Log errors chinnadhaa irundhaa correction chinnadhu, avai perusaa irundhaa adhu valarum.

### Regularisation, scaling

**Ridge**, **lasso** regression coefficients-oda size mela oru penalty serkkum. Niraiya features irukkumbodhu allathu overlap aagura features irukkumbodhu idhu overfitting-a kuraikkum. Lasso sila coefficients-a sariyaa zero aakkalaam, adhu andha features-a remove pannum. Penalty strength (alpha)-a cross-validation vachu therndheduppaanga, `RidgeCV` idhai ungalukkaaga pannum.

Penalty coefficient size mela velai seiyum, size units-a poruthadhu. Oru kilometre-kaana coefficient romba chinnadhu, oru varushathukkaana coefficient perusu, adhanaala scaling illainnaa avai samamillaama shrink aagum. Oru pipeline-la ridge allathu lasso-ku munnaadi eppavum oru `StandardScaler` vainga. Tree models thresholds-la split pannum, adhanaala adhukku scaling thevaiyilla.

### Linear regression-a thaandi eppo poganum

Residual plots curves allathu interactions-a (oru effect innonnai poruthu irukkuradhu) kaatti, adhai sila features vachu sari panna mudiyalainnaa, allathu niraiya mixed features irundhaa, gradient boosting maadhiri tree-based models-ku ponga. Irundhaalum linear model-a unga report-la vachirunga. Complex model konjame jeyichaa, innum simple-aanadhu better product-aa irukkalaam.

Prices-ku trees-oda oru limit mukkiyam: training-la paartha highest values-ku mela avai predict panna mudiyaadhu. Oru linear model oru trend-a extrapolate panna mudiyum, adhu nalladhukko kettadhukko.

### Code: baseline, linear, log target, boosting

24 months-kaana synthetic used-car sales. Age kooda kooda prices kuraiyum, premium 2,000 cc cars innum vegamaa value izhakkum, motha market-um medhuvaa mela drift aagum. Test set kadaisi 4 months.

```python
import numpy as np, pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.dummy import DummyRegressor
from sklearn.linear_model import RidgeCV
from sklearn.compose import TransformedTargetRegressor
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

rng = np.random.default_rng(5)
n = 8000
df = pd.DataFrame({
    "month": rng.integers(0, 24, n),      # sale month: 0 is the oldest
    "age": rng.uniform(0, 12, n),         # years
    "km": rng.uniform(5_000, 150_000, n),
    "engine_cc": rng.choice([1000, 1200, 1500, 2000], n),
    "metro": rng.integers(0, 2, n),       # 1 if sold in a metro city
})
rate = 0.10 + 0.06 * (df.engine_cc == 2000)   # premium cars lose value faster
price = (900_000 * np.exp(-rate * df.age) * (df.engine_cc / 1200)
         * (1 - df.km / 600_000) * (1 + 0.05 * df.metro) * (1 + 0.004 * df.month))
df["price"] = price * rng.lognormal(0, 0.12, n)

features = ["age", "km", "engine_cc", "metro"]
train, test = df[df.month < 20], df[df.month >= 20]   # older sales vs latest 4 months
X_tr, y_tr, X_te, y_te = train[features], train.price, test[features], test.price

alphas = np.logspace(-3, 3, 13)
models = {
    "median baseline": DummyRegressor(strategy="median"),
    "ridge": make_pipeline(StandardScaler(), RidgeCV(alphas=alphas)),
    "ridge, log target": TransformedTargetRegressor(
        make_pipeline(StandardScaler(), RidgeCV(alphas=alphas)), func=np.log, inverse_func=np.exp),
    "boosting": HistGradientBoostingRegressor(max_iter=300, random_state=5),
}
for name, m in models.items():
    pred = m.fit(X_tr, y_tr).predict(X_te)
    mae, rmse = mean_absolute_error(y_te, pred), mean_squared_error(y_te, pred) ** 0.5
    print(f"{name:<18} MAE ₹{mae:>9,.0f}  RMSE ₹{rmse:>9,.0f}  R² {r2_score(y_te, pred):6.2f}")
```

scikit-learn 1.9.1 kooda output:

```text
median baseline    MAE ₹  201,364  RMSE ₹  274,141  R²  -0.07
ridge              MAE ₹   97,976  RMSE ₹  129,071  R²   0.76
ridge, log target  MAE ₹   80,155  RMSE ₹  109,775  R²   0.83
boosting           MAE ₹   59,212  RMSE ₹   82,164  R²   0.90
```

Baseline-oda R² negative-aa irukkuradhai gavaninga: pazhaya sales-la irundhu edutha oru constant guess, test months-oda sondha average price-a vida mosamaa pannudhu.

**Group vaariyaa errors.** Oru average, model thappaa panra oru segment-a maraichidalaam. Inga percentage error thaan innum fair, yenna vilai adhigamaana cars-ku rupee errors innum perusaa irukkum:

```python
lin, best = models["ridge, log target"], models["boosting"]
pct = pd.DataFrame({
    "ridge_log": np.abs(lin.predict(X_te) - y_te) / y_te,
    "boosting": np.abs(best.predict(X_te) - y_te) / y_te,
})
print((pct.groupby(X_te.engine_cc).mean() * 100).round(1))
```


**Linear model-a padikkiradhu.** Scaled pipeline-oda coefficients oru standard deviation-ku. Adhai real units-la thirumba pera, scaler-oda spread-aala divide pannunga:

```python
ridge = lin.regressor_
coef = ridge[-1].coef_ / ridge[0].scale_
print(f"per year: {np.expm1(coef[0]):.1%}   per 10,000 km: {np.expm1(coef[1] * 10_000):.1%}   "
      f"metro: {np.expm1(coef[3]):+.1%}   alpha chosen: {ridge[-1].alpha_:.2f}")
```

```text
per year: -10.8%   per 10,000 km: -1.8%   metro: +5.6%   alpha chosen: 0.32
```

**Oru point-ku badhilaa oru price range.** Sellers-um buyers-um oru number-a vida oru band-a adhigamaa nambuvaanga:

```python
q = dict(loss="quantile", max_iter=300, random_state=5)
lo = HistGradientBoostingRegressor(quantile=0.1, **q).fit(X_tr, y_tr).predict(X_te)
hi = HistGradientBoostingRegressor(quantile=0.9, **q).fit(X_tr, y_tr).predict(X_te)
print(f"inside the 10-90% band: {((y_te >= lo) & (y_te <= hi)).mean():.0%}   "
      f"above the top: {(y_te > hi).mean():.0%}")
```

```text
inside the 10-90% band: 66%   above the top: 25%
```

Nallaa calibrate aana 10 mudhal 90% band real prices-la sumaar 80%-a ulla vachirukkum, sumaar 10% adhukku mela irukkum. Idhu 66% thaan vachirukku, real prices-la kaalvaasi top-ku mela irukku. Idhukku rendu kaaranam. Random split-laye indha band sumaar 70% thaan vachirukkum, yenna quantile models adikkadi romba narrow-aa irukkum. Time split adhai innum mosamaakkudhu, yenna training months-ku appuram prices eriduchu. Users-ku ranges-a kaatturadhukku munnaadi, oru recent validation month vachu band-a widen pannunga, adikkadi retrain pannunga.

**Edges-a paadhukaanga.** Training data-la ovvoru feature-oda range-aiyum record pannunga. Adhukku veliye varra requests-a (oru 25 varusha pazhaya car, 4,00,000 km) confident-aa oru price kudukkuradhukku badhilaa flag pannunga.

## Oru worked example

Chennai marketplace team mela irukkura code-a thangaloda mudhal experiment-aa use pannudhu. Data synthetic, adhanaala numbers method-a vilakkura illustrations thaan, oru real market-la irundhu vandha results illa. Outputs-a varisaiyaa padinga.

1. **Baseline.** Ovvoru thadavaiyum median price-a predict pannaa MAE ₹2,01,364. Endha useful model-um idhai periya margin-la beat pannanum.
2. **Linear regression** (scaled, ridge) error-a paadhiyaa kuraichu ₹97,976 aakkudhu. Cross-validation oru chinna alpha-va therndheduthuchu, adhanaala inga penalty kittathatta edhaiyum maathalai: naalu features, aayirakkanakkaana rows irukkumbodhu overfit aaga perusaa edhuvum illa.
3. **Log target.** Prices ovvoru varushamum oru percentage kuraiyum; adhu rupees-la oru curve, aanaa log price-la oru straight line. MAE ₹80,155-ku irangudhu. Model padikka easy-aana oru kadhaiyaiyum kudukkudhu: age-la ovvoru varushathukkum sumaar 10.8% kuraivu, ovvoru 10,000 km-kkum 1.8% kuraivu, metro cities-la 5.6% adhigam.
4. **Error analysis.** 1,500 cc, 2,000 cc cars-ku linear model-oda percentage error sumaar 12%-la irundhu 17 mudhal 18%-ku thaavuradhai group table kaattudhu. Idhukku rendu kaaranam. Engine size-ku log price mela straight-line effect illa, premium cars innum vegamaa depreciate aagum; idhu oru plain linear model represent panna mudiyaadha oru interaction.
5. **Gradient boosting** data-la irundhu rendu effects-aiyum kathukkudhu. MAE ₹59,212-ku kuraiyudhu, ovvoru engine group-layum sumaar 11% error, R² 0.90-ku erudhu.
6. **Honesty checks.** Training months-la boosted model-oda MAE sumaar ₹40,500, latest months-la irukkura ₹59,212-a vida romba kammi. Time split-ku badhilaa random split pannaa sumaar ₹55,000 varum, adhu reality-a vida nallaa theriyudhu. Price band real prices-la 66%-a thaan cover pannudhu, 80% illa.

| Gradient boosting | ₹59,212 | ₹82,164 | Premium-car interaction-a pidikkudhu |

**Edhu ship aagudhu.** Boosted model suggested price-a set pannudhu, adhu widen panna oru range-aa kaattappadudhu. Sellers-ku kaattura explanation-ku log-linear coefficients thaan feed pannudhu ("ovvoru extra varushamum podhuvaa price-a sumaar 11% kuraikkum"), approximate-nu thelivaa label panni. Rendu velaikku rendu models use panradhu common: number-ku ellaathaiyum vida accurate-aanadhu, nermaiyaana explanation-ku innum simple-aana onnu. Team maasaa maasam retrain pannudhu, yenna pona quarter-oda prices pazhasaagidum-nu drift kaattuchu.

## Podhuvaana thavarugal

- **Baseline illaadhadhu.** Unga model pakkathula "eppavum median-a predict panradhu" illainnaa, adhu value serkkudhaa-nnu solla mudiyaadhu.
- **Training data-laye evaluate panradhu.** ₹40,500-kkum ₹59,212-kkum idaiyila irukkura gap kaattura maadhiri, errors reality-a vida romba chinnadhaa theriyum.
- **Time order-la irukkura data-la random split.** Market prices drift aagum. Mundhaiya months-la train panni, latest months-la test pannunga.
- **Coefficients-a causes-aa edukkuradhu.** Model-oda assumptions-ku keezha avai association-a thaan sollum, features overlap aanaa avai aadum.
- **Scaling illaama ridge allathu lasso.** Appo penalty oru feature evvalavu useful-ngradhai illaama, units-a poruthu irukkum.
- **Skewed targets-a kandukkaama vidradhu.** Log price-a predict panradhu adikkadi innum nallaa work aagum, aanaa prediction-oda exp median-ku pakkathula irukkum, mean illai-nnu nyaabagam vachukkonga.
- **Extrapolations-a nambradhu.** Training range-ku veliye irukkura predictions guesses thaan.
- **R²-a mattum, allathu overall MAE-a mattum report panradhu.** Business users-ku "saraasariyaa ₹59,000 thappu" puriyum, ore oru average periya errors irukkura oru segment-a maraichidalaam.
- **Range thevaippadura decisions-ku point predictions**, price advice maadhiri, allathu yaarume coverage-a check pannaadha ranges.

## Regression model thevaiyillaadha idangal

- **Erkanave oru simple formula irukku**, oru tariff table allathu publish aana oru rate card maadhiri.
- **Kathukka romba kammi data**: domain experts-oda oru rule of thumb innum reliable-aa irukkalaam.
- **Kelvi oru category**, number illa, "indha vaaram idhu vikkumaa" maadhiri: classification use pannunga.

## Demo-la irundhu production-ku

- **Ovvoru report-layum baseline-a vachirunga.**
- **Segment vaariyaa errors-a check pannunga**, feature range vaariyaavum, ovvoru retrain-layum.
- **Out-of-range inputs-a flag pannunga**, predict panradhukku badhilaa.
- **Decisions uncertainty-a poruthu irukkura idangalla ranges kudunga**, adhoda coverage-a ovvoru maasamum check pannunga.
- **Real outcomes vara vara errors-a monitor pannunga**, market drift aanaa retrain pannunga.

## Practice pannunga

Google-oda linear regression module-aiyum Kaggle-oda Intro to Machine Learning course-aiyum mudinga.

1. Mela irukkura naalu code blocks-aiyum run pannunga. Appuram `month`-a oru feature-aa serthu thirumba run pannunga. Endha models improve aagudhu, training months-a thaandi trend-a boosting yen follow panna mudiyaadhu?
2. Date column irukkura oru public housing allathu used-car dataset-la linear regression fit pannunga. Latest period-la MAE, RMSE-a report panni, oru median baseline kooda compare pannunga.
3. Rendu features-kkum predicted value-kkum edhiraa residuals-a plot pannunga. Oru pattern-a (curve, funnel allathu cluster) solli, neenga try pannappora fix-aiyum sollunga.
4. Unga dataset-la ovvoru feature-kkum VIF-a compute panni, endha pair ellaathaiyum vida adhigamaa overlap aagudhu-nnu sollunga.
5. 10%, 90% quantile models-a fit panni, ovvoru age band-kkum band-oda coverage-a report pannunga.

**Mudinjadhu-nnu eppo sollalaam:** unga best model-oda error-a business terms-la explain panna mudiyum, latest period-la adhu baseline-a beat pannudhu-nnu kaatta mudiyum, linear model yen pinthanguchu-nnu oru kaaranam solla mudiyum.
