## Idhu enna

**Regression** features-la irundhu oru number-a predict pannum. **Linear regression** prediction-a features-oda weighted sum plus oru constant-nu assume pannum:

predict pannina delivery minutes = 6 + 2.1 × distance in km + 0.4 × items + 3 × (rain? 1 or 0)

Weights (coefficients) matha features-a maaraama vechchirukkumbodhu, ovvoru feature-oda ovvoru unit-ku prediction evvalavu maarudhu-nu solludhu. Training, pazhaya data-la predictions actual values-ku romba kitta irukkura weights-a kandupidikkum.

Matha regression models (decision trees, gradient boosting, neural networks) curves-aiyum interactions-aiyum pidikkum, aanaa linear regression thaan jeikka vendiya baseline, explain panna romba easy.

```text
  price
   |                                  *
   |                          *   *
   |                 *    * /        <- fitted line: price = a + b x feature
   |          *    *   /  *
   |     *      /  *
   |   *    /                  residual = actual - predicted
   |    /  *                   (vertical gap from point to line)
   +-------------------------------- car age, km, ...
```

Indha lesson Chennai-la oru used-car marketplace-a follow pannum; avanga sellers-ku suggested-price feature build pannraanga.

## Idhu eppadi work aagudhu

**Fitting.** Podhuvaana loss mean squared error: predict pannina values-kum actual values-kum ulla differences-oda squares-oda average. Square pannaradhaala periya errors-a romba thandikkum. Scikit-learn maadhiri libraries idha oru call-la fit pannum.

**Evaluating.** Epovum model train aagaadha data-la.

- **MAE** (mean absolute error): errors-oda average alavu, original units-la ("average-aa 3.2 minutes thappu"). Explain panna easy.
- **RMSE** (root mean squared error): MAE maadhiri thaan, aanaa periya errors-a adhigamaa thandikkum.
- **R²**: explain aagura variation-oda share, 0 (average-a predict pannradhai vida better illa)-la irundhu 1 varaikkum. Useful, aanaa business users-ku purinjikka kashtam.

Ovvoru thadavayum median-a predict pannradhu maadhiri simple baseline-oda compare pannunga. Unga model adhai konjam thaan jeichaa, adhu romba onnum serkkala.

**Coefficients-a padikkradhu.** Coefficients units-a-yum matha features-a-yum poruthu irukkum. Correlated features (distance, travel time) coefficients-a unstable-aakkum. Idhai causes-nu padikkaadheenga.

**Non-linearity.** Real relationships valaiyum: delivery time 5 km varaikkum mella ethum, apram thaavidum. Transformed features (distance squared, buckets) serunga, illa tree-based models use pannunga.

**Outliers.** Squared error konjam extreme values-a fit-a izhukka vidum. Avatrai investigate pannunga; data errors-a cap illa remove pannunga; MAE-based illa robust methods-a yosinga.

**Extrapolation.** Linear models paartha range-ku appaalum santhoshamaa predict pannum (training-la max 12 irukkumbodhu 40 km deliveries). Andha predictions nambaththagaadhavai.

**Regularisation.** Ridge, lasso regression neraya features irukkumbodhu overfitting-a kuraikka coefficients-a shrink pannum; lasso sila-vatrai zero-vaa aakkum.

**Error measure-a choose panradhu:**

| Measure | Eppadi padikkanum | Eppo use pannanum |
| --- | --- | --- |
| MAE | "Average-aa ₹29,000 thappu" | Business users-ku purira number venumna |
| RMSE | MAE maadhiri, aanaa periya misses adhigam count aagum | Periya errors-ku selavu romba adhigam-naa |
| MAPE | "Average-aa 6% thappu" | Values epovum zero-vukku kitta illa-naa |
| R² | Explain aagura variation-oda share | Orey data-la models-a compare panna |

**Residuals-a padikkradhu.** Errors-a ovvoru feature-ku ethiraa plot pannunga. Random cloud-naa model pattern-a pidichirukku. Curve, funnel, cluster-naa edho miss aayiduchu: non-linear effect, model mosamaa handle panra oru group, illa data problem.

**Linear regression-a thaandi eppo pogalaam.** Linear regression vegam, explain panna mudiyum, strong baseline. Residual plots line-aala pidikka mudiyaadha curves, interactions kaattumbodhu, mixed types-oda neraya features irukkumbodhu, illa accuracy gain extra complexity-ku worth-naa, gradient boosting maadhiri tree-based models-ku pogalaam. Aanaalum evaluation-la linear model-a odavae vechchirukkunga: complex model adha konjam thaan jeichaa, simple-aa irukkura model thaan product-ku nalla choice-aa irukkalaam.

**Baseline, linear, log target, boosting, pakkathula pakkam.** Curved age effect irukkura synthetic used-car prices:

```python
import numpy as np, pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.dummy import DummyRegressor
from sklearn.linear_model import Ridge
from sklearn.compose import TransformedTargetRegressor
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error

rng = np.random.default_rng(5)
n = 6000
df = pd.DataFrame({"age": rng.uniform(0, 12, n), "km": rng.uniform(5_000, 150_000, n),
                   "engine_cc": rng.choice([1000, 1200, 1500, 2000], n), "city_metro": rng.integers(0, 2, n)})
price = 900_000 * np.exp(-0.12 * df.age) * (df.engine_cc / 1200) * (1 - df.km / 600_000) * (1 + 0.05 * df.city_metro)
y = price * rng.lognormal(0, 0.12, n)
X_tr, X_te, y_tr, y_te = train_test_split(df, y, test_size=0.25, random_state=5)

models = {
    "median baseline": DummyRegressor(strategy="median"),
    "ridge": Ridge(alpha=1.0),
    "ridge, log target": TransformedTargetRegressor(Ridge(alpha=1.0), func=np.log, inverse_func=np.exp),
    "boosting": HistGradientBoostingRegressor(max_iter=300, random_state=5),
}
for name, m in models.items():
    pred = m.fit(X_tr, y_tr).predict(X_te)
    print(f"{name:<18} MAE ₹{mean_absolute_error(y_te, pred):>9,.0f}   RMSE ₹{mean_squared_error(y_te, pred) ** 0.5:>9,.0f}")
```

Ovvoru step-oda value-vaiyum table kaattum: "epovum median-a predict pannu"-va model evvalavu jeikkudhu, log target illa tree model curve-a nallaa pidikkudha.

**Group-padi errors.** Oru average, model thappaa panra oru segment-a maraikkalaam:

```python
best = models["boosting"]
err = pd.DataFrame({"abs_err": np.abs(best.predict(X_te) - y_te), "age_band": pd.cut(X_te.age, [0, 3, 6, 9, 12])})
print(err.groupby("age_band", observed=True)["abs_err"].mean().round(-2))
```

**Oru point-ku badhila price range.** Buyers-um sellers-um oru band-a nambuvaanga:

```python
lo = HistGradientBoostingRegressor(loss="quantile", quantile=0.1, max_iter=300).fit(X_tr, y_tr)
hi = HistGradientBoostingRegressor(loss="quantile", quantile=0.9, max_iter=300).fit(X_tr, y_tr)
inside = ((y_te >= lo.predict(X_te)) & (y_te <= hi.predict(X_te))).mean()
print(f"share of real prices inside the 10–90% band: {inside:.0%}")      # should be near 80%
```

Real prices-la 80%-a vida romba kammiyaanadhu thaan band-kulla vizhundhaa, intervals nambura alavukku romba kuraivu.

**Edges-a kaavalam paarunga.** Training data-la ovvoru feature-oda range-a record pannunga, range-ku veliya vara requests-a (25 varusha car, 400,000 km) confident-aana price-a return pannaama flag pannunga.

## Oru worked example

Chennai used-car marketplace listing prices-a suggest panna virumbudhu.

Data: 18,000 pazhaya sales, car age, kilometres driven, brand, model, fuel type, city, owners count.

1. Baseline: model, year-ku median price-a predict pannunga. MAE ₹68,000.
2. Features-la linear regression (brand-um model-um one-hot encoded, prices skewed-aa irukkaradhaala price-oda log target-aa). MAE ₹41,000.
3. Error analysis: premium cars-layum 12 varushathukku mela irukkura cars-layum errors romba adhigam. Age-ku ethiraa residuals plot-la oru curve theriyudhu.
4. Adhe features-la gradient-boosted trees. MAE ₹29,000.

Prices-ku boosted model-a ship pannraanga, aanaa sellers-ku kaattura explanation-ku ("indha model-ku ovvoru adhiga varushamum price-a sumaar 9% kuraikkum") linear model-oda coefficients-a vechchirukkaanga, approximate-nu clear-aa label panni.

| Model | MAE | Notes |
| --- | --- | --- |
| Model, year-ku median price | ₹68,000 | Baseline |
| Linear regression, log price | ₹41,000 | Explain panna mudiyura coefficients |
| Gradient-boosted trees | ₹29,000 | Pazhaya, premium cars-ku curves-a pidikkum |

Rendu velaikku rendu models ship panradhu common: number-ku romba accurate-aanadhu, nermaiyaana, approximate explanation-ku simple-aanadhu.

## Podhuvaa panra thappugal

- **Baseline illaama irukkradhu.** Adhu illaama oru model-a judge panna mudiyaadhu.
- **Training data-la evaluate panradhu.** Errors unmaiya vida romba chinnadhaa theriyum.
- **Coefficients-a causes-nu eduthukkradhu.** Avai model-oda assumptions-la oru association-a mattum solludhu.
- **Skewed targets-a ignore panradhu.** Prices-oda log-a predict pannaa perumbaalum nalla work aagum.
- **Extrapolations-a nambradhu.** Training range-ku veliya irukkura predictions guesses.

- **R² mattum report panradhu.** "R² 0.87"-a vida "average-aa ₹29,000 thappu"-nu business users-ku romba nallaa puriyum. Adhoda sera rupees illa minutes-la MAE-vum report pannunga.
- **Median baseline-oda onnum compare pannaadhadhu.** Model value serkkudha-nu theriyaadhu.
- **Overall MAE mattum report panradhu**, periya errors irukkura segment-a maraikkum.
- **Range thevaiyaana decisions-ku, price advice maadhiri, point predictions.**

## Regression model thevai illaadha idangal

- **Simple formula already irukkum**, tariff table illa published rate card maadhiri.
- **Kathukka romba kammi data**: domain experts-oda rule of thumb adhigam nambaththagaadhaa irukkalaam.
- **Kelvi oru category, number illa**, "indha vaaram vikkumaa" maadhiri: classification use pannunga.
