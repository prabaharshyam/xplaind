## Idhu enna

**Recursion**-na, oru function oru problem-a solve panna, adhoda sirusaana version-la thannaiyae call pannum, direct-aa badhil solla mudiyura alavukku sirusaana **base case**-ku varra varaikkum. Oru folder-la files-a ennuradhu iyalbaa recursive: inga irukkura files-a ennunga, apram ovvoru sub-folder-kum adhae kelvi kelunga.

**Dynamic programming** (DP)-na, oru recursion adhae sirusaana problems-a thirumba thirumba solve pannum podhu neenga seiyyaradhu. Avatrai marubadiyum compute pannaama, ovvonnaiyum oru thadavai solve panni, answer-a thirumba use pannuveenga, results-a cache panni (**memoization**) illa sirusaana case-la irundhu mela oru table-a nirappi (**tabulation**).

```flow
title: fib(5) plain recursion-la: adhe calls repeat aagudhu (15 calls; fib(35)-ku sumaar 2.7 crore)
fib(5) -> fib(4)
fib(5) -> fib(3), marubadiyum compute aagudhu
fib(4) -> fib(3)
fib(4) -> fib(2)
fib(3) -> fib(2), marubadiyum
fib(3) -> fib(1)
```

```flow
dir: LR
title: Memoization-oda: ovvoru value-um oru thadavai, apram lookups
fib(0) -> fib(1) -> fib(2) -> fib(3) -> fib(4) -> fib(5)
```

## Idhu eppadi work aagudhu

Oru problem-ku DP porundhum, adhukku rendu properties irundhaa. **Optimal substructure**: nalla answer sirusaana problems-oda nalla answers-la irundhu build aagum. **Overlapping subproblems**: adhae sirusaana problems pala thadavai varum.

Oru nambagamaana method-ku aindhu steps:

1. **State-a define pannunga**: entha oru value illa sirusaana values set oru subproblem-a identify pannum? Coin change-la, innum uruvaakka vendiya amount.
2. **Recurrence-a ezhudhunga**: oru state-oda answer sirusaana states-la irundhu eppadi varudhu.
3. **Base cases-a set pannunga**: direct-aa badhil solla mudiyura states, ex: amount 0-ku 0 coins.
4. **Order-a choose pannunga**: memoization-oda top-down, illa table-oda bottom-up.
5. **Answer-a edunga**, cost-a check pannunga: states-oda ennikkai x state-ku velai.

**Top-down memoization** iyalbaana recursive code-a vechukkittu oru cache serkkum. Python-la `@functools.lru_cache(maxsize=None)` adhai oru line-la pannidum. **Bottom-up tabulation** recursion-a, base case-la irundhu mela oru array-va nirappura loop-aa maathum. Idhu recursion-depth limits-a thavirkkum, adikkadi konjam vegamum irukkum.

| Approach | Eppadi theriyum | Edhukku nallaa | Gavanikka vendiyadhu |
|---|---|---|---|
| Plain recursion | function thannaiyae call pannum | sirusaana inputs, theliva | subproblems repeat aanaa exponential time |
| Memoization (top-down) | recursion + cache | recurrence-la irundhu vegamaa ezhudhalaam | recursion depth; cache memory |
| Tabulation (bottom-up) | table nirappura loop | periya inputs, predictable speed | fill order-a kandupidikkanum |
| Greedy | ippo nalla option-a edukkuradhu | proven greedy choice irukkura problems | local best, global best illaadhappo thappaa answer |

**Interviews-la DP-a spot panradhu.** Oru sequence illa grid-la "number of ways", "minimum cost", "maximum value", "longest", "can you reach" maadhiri vaarthaigal adikkadi DP-nu sollum. Plain recursive version-a ezhudhi, adhoda cost-a satthamaa sollunga; apram repeat aagura subproblems-a kaatti, oru cache serunga. Interviewers moolaiyil vechirukkura table-a vida, mella-la irundhu vegamaa pogura andha vazhi-ku thaan reward kudupaanga.

## Oru worked example

Arjun, Lucknow-la oru payments kiosk-ku cash-dispensing feature build panraanga. Oru amount kudutha, kiosk adhai 1, 2, 5, 10, 20, 50, 100, 200, 500-la irundhu kuraindha coins, notes-oda tharanum.

Indian denominations-ku, ellaa neramum porundhura perusaana note-a edukkuradhu work aagidum. Aana product, 1, 3, 4 tokens use panra oru canteen-layum odum. 6-ku, greedy 4 + 1 + 1 edukkum (moonu tokens), aana 3 + 3 rendu thaan. Adhanaala Arjun DP use panraanga.

**State:** innum tharanum-ngra amount `a`. **Recurrence:** best(a) = 1 + porundhura ovvoru coin c-kum, sirusaana best(a − c). **Base case:** best(0) = 0.

Avaroda mudhal version plain recursion:

```python
def fewest(a, coins):
    if a == 0:
        return 0
    return 1 + min(fewest(a - c, coins) for c in coins if c <= a)
```

Indian coins-oda ₹30-ku idhu sari; ₹300-ku adhu mudiyavae mudiyaadhu, yen-naa adhae amounts-a ennida mudiyaadha thadavai marubadiyum solve pannudhu.

Oru cache serthaa fix aagidum:

```python
from functools import lru_cache

def fewest_coins(amount, coins):
    @lru_cache(maxsize=None)
    def best(a):
        if a == 0:
            return 0
        return 1 + min(best(a - c) for c in coins if c <= a)
    return best(amount)
```

Ippo 0-la irundhu target varaikkum ovvoru amount-um oru thadavai solve aagum: sumaar amount × coins-oda ennikkai steps.

Kiosk-ku avar bottom-up version-a use pannuraar, adhu periya amounts-la recursion limits-a thavirkkum:

```python
def fewest_coins_table(amount, coins):
    INF = float("inf")
    best = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and best[a - c] + 1 < best[a]:
                best[a] = best[a - c] + 1
    return best[amount]
```

Onbadhu denominations-oda ₹3,000-ku, adhu 27,000 simple steps, entha phone-layum udane mudiyum. 1, 3, 4 tokens-oda, 6 amount-ku sariyaa 2 return pannum.

## Podhuvaa panra thappugal

**Base case illaama irukkuradhu, illa thappaa irukkuradhu.** Recursion niruththaadhu illa arthamilaadhadhai return pannum. Mudhalla base case-a ezhudhunga.

**Romba perusaana state-a choose panradhu.** Answer-a affect pannaadha values-a serthaa states-oda ennikkai peruguthu. Bhavishyam edhu-la irukku-nu mattum vechukkunga.

**Mutable arguments-a cache panradhu.** `lru_cache`-ku hashable arguments thevai. Lists-a illa, tuples-a pass pannunga, illa mela maadhiri list-a cached function-ku veliya vechukkunga.

**Recursion limit-a adikkuradhu.** Python sumaar 1,000 nested calls-la nikkum. Periya inputs-ku bottom-up-ku maathunga, illa limit-a jaakkirathaiyaa uyartha.

**Proof illaama greedy-a nambradhu.** Greedy vegam, adikkadi sari, aana adhu andha problem-ku work aagudhu-nu neenga kaattanum. 1, 3, 4 token example adhu eppadi fail aagum-nu kaattudhu.

**Udane code-ku thaavuradhu.** Perumbaalaana DP bugs theliva illaadha state illa recurrence-la irundhu varum. Code ezhudha munnaadi rendaiyum oru sentence-la ezhudhunga.
