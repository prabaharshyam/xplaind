## Idhu enna

Oru **AI policy** oru organisation AI-a eppadi use panni build pannum-nu rules vaikkum. Adhu illaadha podhu makkal guess pannuvaanga: sila per AI-a muzhusaa thavirthu pinnaadi poiduvaanga, sila per client data-va free tools-la paste pannuvaanga. Nalla policy paadhukaappaana vazhiya easy vazhiya aakkum.

Nalla mudhal policy **rendu mudhal naalu pages**, vakeel-gala illa employees-ku ezhudhina maadhiri, aaru maadhathukku oru thadavai review. Idhula perumbaalum rendu parts irukkum:

| Part | Yaarukku | Enna cover pannum |
| --- | --- | --- |
| **AI tools use panradhu** | Ellarukkum | Edhu tools, edhu data, enna review, disclosure |
| **AI features build panradhu** | Product, engineering teams | Risk assessment, testing, oversight, monitoring, launch-ku munnaadi approval |

| Policy-oda part | Enna solludhu |
|---|---|
| Principles | 3-5 chinna commitments |
| Approved tools | Peyarodu, settings-oda |
| Data classes | Public, internal, confidential, personal: edhu tools ovvondrayum paakkalaam |
| Use cases | Encouraged, restricted, prohibited |
| Review | Yaar accountable, enna review aagum |
| Disclosure | Customers-ku AI use pannadha eppo solanum |
| Building AI | Risk assessment, apram evals, apram approval |
| Incidents | Eppadi report panradhu, blame illaama |
| Training | Ellarukkum 30 nimisham, avvappo updates |

Indha lesson Pune-la oru software services company-oda delivery head Neha-va follow pannum; oru client-oda security review company-a mudhal AI policy ezhudha vekkudhu. Lesson mudiyum podhu, oru pudhu employee real tasks-ku apply panna mudiyura practical policy-a draft pannalaam.

## Idhu eppadi work aagudhu

### Principles

Mathadhellaam edhula irundhu varudho andha moonu mudhal anju chinna commitments, udhaaranathukku:

1. AI-assisted work-ku makkal accountable-aa irukkanum.
2. Personal, confidential data-va paadhukaakkanum, clients-oda data-vum serthu.
3. AI involve aanaa customers-kitta transparent-aa irukkanum.
4. Launch-ku munnaadi quality-kum fairness-kum test pannanum.
5. Prachanaigala vegamaa, blame illaama report pannanum.

India-oda AI Governance Guidelines-um NIST AI Risk Management Framework maadhiri frameworks-um principles-ku nalla sources.

### Approved tools

Approved tools-a peyar solli, adhu eppadi configure aachu-nu sollunga, udhaaranathukku "company-oda enterprise AI assistant, company data-vula train aagaadha maadhiri configure panna". Personal accounts-a work data-ku use pannakkoodaadhu-nu thelivaa sollunga.

### Data classes

| Class | Examples | Edhu tools process pannalaam |
| --- | --- | --- |
| Public | Publish aana material, public circulars | Edhu tool-um |
| Internal | Process notes, internal templates | Approved tools mattum |
| Confidential | Client code, contracts, release aagaadha results | Approved tools mattum, client contracts anumadhicha idangalla mattum |
| Personal | Customer illa employee personal data | Specifically approve aana systems mattum; DPDP Act-a follow pannum |

Personal data **DPDP Act**-a follow pannum: makkalukku sonna purposes-kku mattum, consent maadhiri lawful ground-la, thevaiyaanadhukku mela illaama use pannunga.

### Use cases

| Encouraged | Restricted (approval thevai) | Prohibited |
| --- | --- | --- |
| Drafting, summarising, research | Customer-facing AI features | Customer data-va approve aagaadha tools-la |
| Coding assistance, review-oda | Hiring illa credit maadhiri makkal pathina decisions | Unmaiyaana makkal-oda deepfakes |
| Internal documents-a translate panradhu | Medical, legal illa financial advice | Review illaama, makkal mela legal effect irukkura muzhu automated decisions |

Ovvoru prohibited use-ku, allowed alternative irundhaa adha kaattunga. Verum "pannaadheenga"-nu solra policy use-a maraivaa pogavaikkum.

### Review, accountability

AI output-a use panravar adhukku poruppu. Customer-facing, high-risk uses-ku **peyar kudutha owner**-um documented review-um thevai.

### Disclosure

AI use pannadha customers-kitta illa readers-kitta eppo sollanum-nu sollunga: chatbots thaangal AI-nu identify pannikkanum, AI-assisted reports clients illa rules ketta idangalla label pannanum.

### AI features build panradhu

Launch-ku munnaadi, risk-ku thagundha oru chinna package:

```flow
dir: LR
Idea -> Risk assessment -> Evaluation results -> Oversight plan -> Monitoring and incident plan -> Approval by a named group -> Launch
```

Low-risk internal summariser-ku oru page podhum; customer-facing credit assistant-ku romba adhigam thevai.

### Incidents

AI mistake, data leak, harmful output-a eppadi, yaarukku, evvalavu vegamaa report panradhu, udhaaranathukku "24 mani neraththukkulla security team-ku", **nermaiyaana reports-ku blame illaama**. Maraicha mistakes thaan romba selavaagum.

### Training, updates

Ella staff-ukkum oru chinna training, peyar kudutha policy owner, oru review date. Tools-um laws-um vegamaa maarum; rendu varusham pazhaya policy-la thappu irukka vaaippu adhigam.

## Oru worked example

Pune-la 300 per irukkura software services company-ku AI policy illa. Staff palavidha tools use panraanga, sila per client code-oda. Oru security review-la, oru periya client kekkuraanga: "Unga company-la AI use eppadi govern aagudhu?" Yaarukkum nalla badhil illa.

Delivery head Neha, CTO-voda, legal counsel-oda rendu vaaraththula moonu-page policy draft panraanga:

| Section | Enna ezhudhinaanga |
| --- | --- |
| Principles | Accountability, client confidentiality mudhalla, transparency, quality-um fairness-um, prachanaigala report panradhu |
| Approved tools | Enterprise AI assistant-um approved IDE-la code assistant-um, rendume company data-vula train aagaadha maadhiri configure panninadhu |
| Client code, data | Approved tools-la mattum, client contract anumadhicha idangalla mattum; opt out panna clients-oda list |
| Restricted | Client-facing AI features-ku risk assessment-um client-oda approval-um thevai |
| Prohibited | Client velaikku personal AI accounts; approve aagaadha tools-la edhaavadhu customer personal data |
| Incidents | 24 mani neraththukkulla security team-ku report; nermaiyaana mistakes-ku blame illa |
| Training | Ella staff-ukkum 30 nimisham; policy owner aaru maadhathukku oru thadavai review |

**Adhukku apram enna nadandhadhu:**

| Measure | Policy-ku munnaadi | Oru maadham kazhichu |
| --- | --- | --- |
| Approved AI tools use | Kammi; neraya per personal accounts-la | Sumaar moonu madangu adhigam |
| Client security review | Badhil illaadha kelvi | Pass aachu |
| Reported incidents | Edhuvum report aagala, sila sandhegam | Rendu report aagi vegamaa fix aachu |

Edhu allowed-nu makkalukku kadaisiyaa therinjadhunaala approved tools use moonu madangu aachu. Report aana rendu incidents, real peyargal irundha oru test file-um, oru client-oda API key irundha oru prompt-um, oru naalukkulla pidikkappattadhu, yenna report panradhula blame illa.

## Podhuvaa panra thappugal

- **AI-a muzhusaa ban panradhu.** Makkal appadiyum use pannuvaanga, paadhukaappillaama, maraivaa.
- **Yaarum padikkaadha neelamaana legal documents.** Simple-aa, examples-oda, one-page summary-oda ezhudhunga.
- **Client contracts-a ignore panradhu.** Neraya contracts client data-va eppadi process pannalaam-nu restrict pannum.
- **Owner-um review date-um illaadhadhu.** Tools-um laws-um vegamaa maarum.
- **Incident route illaadhadhu.** Appuram mistakes maraindhe irukkum.
- **"Pannaadheenga" mattum.** Task-a pannura approved vazhiya eppovum kaattunga.

## Practice pannunga

Keezha link panni irukkura NIST AI RMF-oda govern function-a, PRS-oda DPDP Act summary-a, EU AI Act summary-la prohibited-um high-risk-um uses list-a skim pannunga.

1. **Draft pannunga.** Ungalukku theriyura oru organisation-ku, mele irukkura ella sections-oda rendu-page AI policy ezhudhunga.
2. **Summarise pannunga.** Employees-ku anju dos-um anju don'ts-um irukkura one-page summary ezhudhunga.
3. **Test pannunga.** Veru veru teams-la irundhu rendu perai padikka sollunga, edhu theliva illa-nu oru vishayam sollattum; adha fix pannunga.

**Mudinjadhu-nu eppo sollalaam:** Unga policy-a oru pudhu employee-kitta kudutha, moonu example tasks-ku edhu tool-um edhu data-vum use pannalaam-nu avar sariyaa solla mudiyum.
