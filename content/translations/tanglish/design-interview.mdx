## Idhu enna

Neraya AI engineering interviews-la ippo oru **design round** irukku. "Oru bank-ku customer-support assistant design pannunga", "10 million documents mela kelvikku badhil solra system design pannunga", "Travel book panra agent-a eppadi build pannuveenga?"-nu ketkalaam. Ungalukku 30-la irundhu 45 nimisham, whiteboard illa shared document kidaikkum, interviewer "what if...?"-nu naduvula interrupt pannuvaanga.

Edhavadhu oru tool theriyumaa-nu paakkradhai vida, structured-aa yosikkradhu, sariyaana trade-offs, production awareness-a thaan test pannuvaanga.

| Nimisham | Step | Enna cover pannanum |
|---|---|---|
| 0-5 | Clarify | Users, scale, latency, cost, languages, data rules, success |
| 5-10 | High level | Boxes, arrows: channel, API, routing, tools illa RAG, model, reply |
| 10-28 | Deep dives | Indha problem-ku romba mukkiyamaana 2-3 pagudhigal |
| 28-31 | Failures | Hallucination, injection, outage, cost, privacy |
| 31-34 | Evals and ops | Test set, metrics, launch bar, monitoring, rollout |
| 34-35 | Trade-offs | Innum neram irundhaa, 10x scale-la |

## Idhu eppadi work aagudhu

**Nambikkaiyaana structure.**

1. **Clarify (3-la irundhu 5 nimisham).** Users, task, scale (users, documents, requests per second), latency, cost constraints, languages, data sensitivity, success-na enna. Kelunga, apram assumptions-a sathama sollunga.
2. **High-level design (5 nimisham).** Aazhama pogradhukku munnaadi mukkiya components-um request flow-um sketch pannunga.
3. **Deep dives (15-la irundhu 20 nimisham).** Indha problem-ku romba mukkiyamaana pagudhigal: perumbaalum retrieval (ingestion, chunking, hybrid search, reranking, permissions), generation (prompting, grounding, model choice), tools illa agents, evaluation.
4. **Failure modes and safety (5 nimisham).** Hallucination, injection, outages, cost spikes, privacy.
5. **Evaluation and operations (5 nimisham).** Test sets, metrics, launch bar, monitoring, rollout.
6. **Trade-offs and next steps (2 nimisham).** Innum neram irundhaalum, ten times scale-la irundhaalum enna pannuveenga.

**Nalla score tharra habits.**

- Sathama yosinga; trade-offs-a peru solli sollunga ("hybrid search konjam adhigam selavaagum, aana policy numbers-a pidikkum").
- Numbers use pannunga: rough token counts, costs, latency budgets.
- Simple-aa aarambinga, requirements kekkura idathula mattum complexity serunga.
- Interruptions-a attack-aa illa, pudhu requirements-aa eduthukkunga.
- Neram paarthukkunga; chunking-ku 25 nimisham selavazhikka vendaam.

**Practice panna vendiya common questions.** Company documents mela RAG; actions-oda customer-support assistant; neenda documents-a summarise panradhu; coding assistant; India-kku multilingual chatbot; tools-oda agent; model upgrade-a evaluate panradhu; cost-a paadhiyaa kuraikkuradhu.

**Sathama practice pannunga.** Unga-a record pannunga illa friend kooda practice pannunga. Design-a pesuradhu, adha theriyuradhu-kku veraa skill.

**Interviewers paakkura signals:**

| Strong signal | Weak signal |
| --- | --- |
| Mudhalla users, scale, data rules pathi kekkaraanga | Tools peru sollitta aarambikkaraanga |
| Assumptions-a numbers-oda solraanga | Numbers-a thavirkkaraanga |
| Ovvoru choice-um indha problem-ku yen set aagudhu-nu explain panraanga | Technologies-a list panraanga |
| Failure modes, evaluation cover panraanga | Happy path-oda niruthiduraanga |
| "What if"-kku amaidhiyaa adapt aaguraanga | Mudhal design-a vidaama defend panraanga |
| Ella pagudhikkum neram pirichchu kodukkuraanga | Neram perumbaalum oru box-layae selavaaguthu |

**Partner-oda practice panradhu.** Ovvoru session-layum roles maathikkunga. Interviewer, candidate paakkaadha oru prompt-a select pannuvaanga, ovvoru phase-oda neram paarthuvaanga, outage, pudhu language, ten times traffic maadhiri rendu "what if" kelvigal-oda interrupt pannuvaanga. Mudinja apram, interviewer moonu notes tharuvaanga: nalla panna onnu, oru gap, maathikka vendiya oru habit. Interviewer-aa irundhaa, clear answer eppadi kekkum-nu kathukkalaam.

**Estimates-a vegamaa podradhu.** Sila back-of-the-envelope numbers yosikkaama varra varaikkum practice pannunga. Oru page text-la evvalavu tokens, daily users-la irundhu requests per second, tokens-um prices-um vachchu cost per request, oru model size-ku evvalavu GPU memory-nu theriyanum. Interviewers-ku exact figures vendaam; orders of magnitude vachchu reason panreenga-nu paakkanum.

## Oru worked example

Prompt: "Oru state electricity board-ku, billing, outage kelvigalukku Tamil-layum English-layum badhil solra WhatsApp assistant design pannunga."

Oru nalla candidate-oda summary:

- *Clarify*: 2 million consumers; bills issue aana apram, outages-la peaks; tariffs-la answers accurate-aa irukkanum; outage data internal system-la; account kelvigalukku consumer number; data India-kulla thaan irukkanum.
- *Design*: Provider vazhiyaa WhatsApp Business Platform → API service → intent routing (billing, outage, tariff FAQ, complaint) → bill lookup, outage status-ku tools (consumer number OTP-la verify) → rendu languages-layum tariff orders, FAQs mela RAG → Indian region-la model → reply.
- *Deep dive*: Tamil, English chunks-oda bilingual retrieval; tariff tables-a kavanamaa extract panradhu; outage answers live tool-la irundhu mattum, generate panna koodaadhu; complaints reference number-oda log aagi, makkal kitta pogum.
- *Failures*: outage spikes (area-vaaripaa outage status-a cache pannunga, scale out), thappaana tariffs (citations, refusal, weekly review), injection (complaint logging thavira write tools illa), provider outage (helpline-oda fallback message).
- *Evaluation*: rendu languages-layum 300 real questions, intent-vaaripaa accuracy; mudhalla oru district-la launch.
- *Cost*: oru conversation-ku rough estimate, expected volume-la maadhaanthira total.

Interviewer, "outage system down-aa irundhaa?"-nu kekkaraanga. Candidate: last known status-a timestamp-oda, helpline-oda kaattunga, on-call-ku alert anuppunga.

| Phase | Electricity-board answer enna cover pannichu |
| --- | --- |
| Clarify | 2 million consumers, bill-day, outage peaks, Indian data residency |
| Design | WhatsApp provider, intent routing, OTP-verified tools, bilingual RAG |
| Deep dive | Outage answers live tool-la irundhu mattum; tariff tables kavanamaa extract |
| "Outage system down-aa irundhaa?" | Last known status timestamp-oda, helpline, on-call alert |

## Podhuvaa panra thappugal

- **Clarify pannaama details-la kuthikkradhu.**
- **Choices-a explain pannaama tools-a peru sollradhu.**
- **Evaluation, operations-a ignore panradhu.**
- **Numbers illaama pesradhu.**
- **Oru component-la neram mudinjuduradhu.**
