## Idhu enna

Maths-naala neraya per machine learning-a thalli podraanga. Neenga mathematician aaga thevai illa. Moonu areas-oda **intuition** thevai, oru formula varumbodhu adha follow panna mudiyanum, avlo thaan:

| Area | Core idea | ML-la enga varum |
| --- | --- | --- |
| **Linear algebra** | Data-va **vectors** (numbers list), **matrices** (numbers table) aa vachu, adhula operations | Oru customer features-oda vector; dataset oru matrix; model-oda weights matrices |
| **Calculus** | Inputs-a konjam nagarthina oru quantity eppadi maarudhu | Models **gradient**-a follow panni kathukkum, adhavadhu error romba vegamaa kuraiyura direction |
| **Probability** | Uncertainty-a describe panradhu | Models probabilities output pannum; data-kku distributions irukku; evaluation results evvalavu nikkum-nu kekkum |

```flow
dir: LR
Linear algebra | data, weights vectors, matrices-aa: model enna compute pannudhu -> Calculus | weights nagarumbodhu error eppadi maarudhu (gradients): eppadi kathukkudhu
Calculus -> Probability | evvalavu sure-aa irukkom? Outputs, base rates, Bayes: output-a eppadi padichu nambradhu
```

Indha lesson-la Hyderabad-la oru fintech simple loan-default model-a train panni, scale-um base rates-um yen mukkiyam-nu kashtappattu kathukkuradha follow pannuvom. Mudiyum podhu gradient descent-a oru sketch-oda explain panna mudiyum, rare events-la perumbaalum false alarms yen varudhu-nu sollalaam.

## Idhu eppadi work aagudhu

### Vectors-um similarity-um

**Vector**-na oru vishayatha describe panra numbers-oda list. Similar direction-la point panra rendu vectors similar vishayangala describe pannum. **Dot product** matching entries-a multiply panni add pannum:

```text
  a = (3, 1, 2)      b = (2, 0, 4)
  a . b = 3*2 + 1*0 + 2*4 = 6 + 0 + 8 = 14
```

Periya dot product-na similar direction. **Cosine similarity** vectors-oda length-a vachu divide pannum, adhanaala direction mattum count aagum, size illa. Recommendation systems-um embedding search-um "similar"-a idhu vachu thaan measure pannum.

### Matrices transformations-aa

Oru vector-a matrix-oda multiply pannaa adhu transform aagum: rotate, stretch, illa features-a mix. Neural network-oda oru layer-na matrix multiplication-um, adhukku apram oru simple non-linear function-um.

**Shapes match aagannum.** 100 rows, 20 columns irukkura matrix-a 20 weights-oda vector-oda multiply pannaa, 100 predictions kidaikkum:

```text
   data X            weights w        predictions
  (100 x 20)    x     (20 x 1)    =    (100 x 1)
       ^^                ^^
       these must be equal
```

Code-la perumbaalaana matrix bugs shape mismatches thaan. Shapes-a print pannunga.

### Derivatives-um gradients-um

**Derivative**-na oru input konjam maarumbodhu output evvalavu maarudhu-nu sollum. Neraya inputs irundhaa, **gradient** andha ella derivatives-aiyum uphill-a point panra oru vector-aa serkkum.

**Gradient descent** oru model-a **loss** (error-oda measure) mela sinna sinna steps-a downhill edukka vachu train pannum, improve aagradhu nikkura varaikkum, thirumba thirumba:

```text
   loss
    |  *
    |    *                        too-large steps bounce around:
    |      *                          *       *
    |        *  *                    *   *   *   *
    |            * * * * --           (never settles)
    +--------------------------> steps
          small, steady steps
```

**Learning rate**-na step size. Romba periya-naa training thulli veliyae pogum illa explode aagum; romba sinna-naa oorndhu pogum. Loss curve-a paathu adjust pannunga.

### Chain rule-um backpropagation-um

Neural networks neraya functions-a stack pannum. **Chain rule** naduvula irukkura ella layers vazhiyaa, final error early weights-a eppadi sarndhirukku-nu compute pannum. **Backpropagation**-na chain rule-a efficient-aa apply panradhu; idhu thaan periya networks-a train panna mudiyura kaaranam.

### Probability

- **Probability distribution** ovvoru value-um evvalavu likely-nu sollum.
- **Expected value**-na long-run average.
- **Conditional probability**, example "income ₹25,000-ku kammi-naa default aagura probability", classification-oda heart.
- **Bayes' rule** evidence vachu beliefs-a update pannum, accurate tests irundhaalum rare events yen neraya false alarms tharudhu-nu explain pannum.

### Scaling

Oru feature 400 varai pogudhu, innonnu 1-ku kezhayae irukkudhu-naa, gradient descent zigzag aagi, mella illa unstable-aa train aagum. Features-a **standardise** panninaa, ovvonnukkum similar range varum, neraya models vegamaa, nallaa train aagum.

| Feature | Raw range | Standardise pannina apram |
| --- | --- | --- |
| Income-la EMI share | 0.05 to 0.9 | about -2 to +2 |
| Last year missed payments | 0 to 12 | about -2 to +2 |
| Ippo irukkura job-la months | 1 to 400 | about -2 to +2 |

## Oru worked example

Hyderabad-la oru fintech simple model-a vachu maadha EMI default risk-a predict pannudhu:

```text
score = w1 x (EMI / income) + w2 x (missed payments last year)
      + w3 x (months at current job) + b
```

**Vectors-um weights-um.** Ovvoru applicant-um moonu features-oda oru vector. Weights w1, w2, w3, b serndhu model.

**Training.** Random weights-oda aarambikkum, 50,000 past loans-ku predict pannum, loss-a measure pannum (predictions unmaiyaana result-lendhu evvalavu dhooram), gradient-a compute pannum (ovvoru weight-kum loss eppadi maarudhu), ovvoru weight-aiyum downhill-a nagarthum. Konja nooru steps-ku apram loss kuraiyaradhu nikkum.

**Mudhal problem: scale.** Modhala training unstable-aa irundhudhu: loss thulli thulli pochu. "Months at job" 400 varai pochu, EMI ratio 1-ku kezhae, adhanaala oru weight-ku romba sinna steps, innonnuku periya steps thevai pattuchu. Moonu features-aiyum standardise pannaa sari aachu.

**Rendavadhu paadam: base rates.** 2% applicants default aagraanga, model defaulters-la 90%-a pidikkudhu, nalla applicants-la 10%-a thappa flag pannudhu-nu vechukkalaam. 1,000 applicants-la:

| | Default aavaanga | Default aagamaattaanga | Total |
| --- | --- | --- | --- |
| Count | 20 | 980 | 1,000 |
| Model flag pannadhu | 18 (20-la 90%) | 98 (980-la 10%) | 116 |
| Flag aagala | 2 | 882 | 884 |

Flag aana 116 applicants-la 18 per thaan, sumaar aarula onnu, unmaiyaave default aavaanga. Perumbaalaana flags false alarms, yenna nalla applicants romba adhigam. Adhanaala bank score-a **review-ku prioritise** panna use pannudhu, automatic-aa reject panna illa.

## Podhuvaa panra thappugal

- **Mudhalla ella maths-aiyum master panna try panradhu.** Intuition kathukkunga, apram thevaikku thagundha maadhiri deepen pannunga.
- **Shapes-a ignore panradhu.** Perumbaalaana matrix bugs shape mismatches; shapes-a print pannunga.
- **Learning rate-a guess panradhu.** Loss curve-a paathu adjust pannunga.
- **Scale pannaadha features.** Gradient-based models-ku standardise pannunga.
- **Base rates-a ignore panradhu.** Rare events-um imperfect models-um serndhaa neraya false alarms varum.
- **Probability-a certainty-nu padikkiradhu.** 0.8 score-na likely, definite illa.
