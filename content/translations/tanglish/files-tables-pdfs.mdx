## Idhu enna

Clients rarely clean database tharuvaanga. Oru shared folder anuppuvaanga: merged headers irukkura Excel sheets, pazhaya billing system-la irundhu export panna CSVs, vendor API-la irundhu JSON, nooru-kanakkaana PDFs, sila digital, sila scanned. Indha files-la irundhu nambikkaiyaana text-yum numbers-yum edukkuradhuku **document parsing**-nu per; perumbaalaana AI projects-la mudhal unmaiyaana velai idhu. Indha step thappaa irundhaa, adha vechu katta ella answers-um thappaa irukkum.

Velai file type-padi pirikkum:

| File type | Perumbaalum enna thappaagum | Main tool |
| --- | --- | --- |
| **CSV, Excel** | Encodings, leading zeros poradhu, Indian number, date formats, banner rows | pandas |
| **JSON** | Aazhamaana nesting, records-kulla lists | `json`, `pd.json_normalize` |
| **Digital PDF** | Columns kalandhudum, headers, footers repeat aagum, words udaiyum | pypdf, pdfplumber |
| **Scanned PDF** | Text-ae illa, images mattum | OCR, Tesseract illa cloud service maadhiri |
| **PDF tables** | Table oru kuzhappamaana line-aa varum | pdfplumber, Camelot, illa vision-capable model |

```flow
Client folder -[.csv or .xlsx]-> pandas with explicit options -> A clean table
Client folder -[.json]-> json + json_normalize -> A flat table
Client folder -[.pdf]-> Extract text per page
Extract text per page -[enough text]-> Keep it, with page numbers
Extract text per page -[almost none]-> OCR -> Spot-check
Extract text per page -[has tables]-> A table tool -> Check the rows
```

Indha lesson-la Madurai-la oru hospital chain-a follow pannuvom; avanga policies-um pharmacy price list-um oru assistant-kku feed aaganum. Lesson mudiyum podhu, messy tables-a sariyaa load pannalaam, edhu PDFs-ku OCR thevai-nu kandupidikkalaam.

## Idhu eppadi work aagudhu

### CSV, Excel

`pd.read_csv`, `pd.read_excel` perumbaalaana velaiya paakkum, aana adhoda defaults tidy data-nu assume pannum. Real files-ku options thevai:

| Problem | Option |
| --- | --- |
| Tamil, Hindi names garble aagudhu | `encoding="utf-8"`, illa Excel byte-order mark-ku `"utf-8-sig"`. Garble-na perumbaalum UTF-8-a `cp1252`-la padichirukkanga, adhula Indian scripts irukkaadhu |
| Item codes, branch codes, landline numbers-la leading zeros poidudhu | id maadhiri columns-ku `dtype={"item_code": str}` |
| 05/11/2026 maadhiri dates | `parse_dates` with `dayfirst=True` |
| Header-ku mela banner rows | `skiprows` |
| Udaindha rows load-a crash pannudhu | Paakka `on_bad_lines="warn"` |

"1,25,000" maadhiri Indian number formats-la numbers-aa maathuradhukku munnaadi commas-a eduthudanum.

### Excel-oda quirks

Excel files-la avanga surprises irukkum. Oru workbook-la neraya sheets irukkalaam: oru sheet-a `sheet_name="Rates"`-la padinga, ellaathaiyum `sheet_name=None`-la padinga, adhu tables-oda dictionary tharum. Merged header cells oru filled cell-aayum konjam empty cells-aayum varum, adhanaala header-a kaiyaala rebuild pannunga, illa rendu header rows-ku `header=[0, 1]` use pannunga. Hidden rows, columns-um padikkapadum, formulas, formulas-aa illa, last save panna values-aa varum. Sandhegam irundhaa, code ezhudhuradhukku munnaadi file-a thorandhu paarunga.

### JSON

`json.load` nested dictionaries, lists tharum. `pd.json_normalize` records list-a oru table-aa flatten pannum, nested fields-ku `customer.city` maadhiri dotted column names kudukkum.

### PDFs

PDF-na paragraphs irukkura document illa, drawing instructions-oda set. pypdf, pdfplumber maadhiri libraries digital PDFs-la irundhu text-a eduthudum, aana columns kalandhudalaam, headers, footers ovvoru page-layum repeat aagum, words vinodhamaa udaiyalaam.

**Text-ae varaadha** PDF perumbaalum scan: adhula images mattum irukku, adhanaala **OCR** (optical character recognition) thevai. Indian languages-ku, sariyaana OCR language pack install pannunga. Tables-ku table-aware tool, illa vision-capable model thevai.

Ovvoru text-oda **page number**-um eppavum record pannunga. Appuram citations-um debugging-um adha nambi thaan irukku.

### Checks

Ovvoru extraction-ku appuram, count pannunga, compare pannunga: rows in vs rows out, text illaadha pages, match aaganum-nu irukkura totals. Apram ayndhu random samples print panni padinga. Ayndhu nimisham padikkuradhu endha count-um kandupidikka mudiyaadha problems-a kandupidikkum.

## Oru worked example

Madurai-la oru hospital chain thangaloda policies-ku, pharmacy price list-ku oru assistant venum. Avanga oru ZIP file anuppuraanga.

**Price list CSV.** Tamil drug names garble aagi varudhu, yen-na pazhaya loading script `encoding="cp1252"`-nu set pannirundhudhu. File unmaiyilaye Excel serthudha byte-order mark-oda UTF-8, adhanaala `encoding="utf-8-sig"` fix pannum. "000412" maadhiri item codes zeros-a ilandhuduchu; `dtype={"item_code": str}` vechukkum. "1,250.00" maadhiri prices commas-a eduthadhum numbers-aagum.

**Policy PDFs.** 140 PDFs-la, pypdf 122-la text-a edukkudhu. Oru quick check kittathatta onnumae tharaadha 18-a flag pannudhu:

```python
from pathlib import Path
from pypdf import PdfReader

pdfs = sorted(Path("policies").glob("*.pdf"))
needs_ocr, records = [], []

for path in pdfs:
    reader = PdfReader(path)
    pages = [p.extract_text() or "" for p in reader.pages]
    chars = sum(len(p) for p in pages)
    if chars < 200 * len(pages):
        needs_ocr.append(path)       # probably scanned
    else:
        for n, text in enumerate(pages, 1):
            records.append({"file": path.name, "page": n, "text": text})
```

Andha 18 scanned circulars. OCR avatha padikkudhu, moonu-a images-oda spot-check panna, Tamil OCR language pack serkkura varaikkum Tamil headers thappaa irukku-nu theriyudhu.

| Item | Count | Problem | Fix |
| --- | --- | --- | --- |
| Price list rows | 4,812 | Garbled names, poona zeros, text prices | `utf-8-sig`, `dtype=str`, commas-a eduthudunga |
| Digital PDFs | 122 | Repeat aagura headers, footers | Perumbaalaana pages-la repeat aagura lines-a strip pannunga |
| Scanned PDFs | 18 | Text illa | English, Tamil packs-oda OCR |
| Innum fail aana pages | 6 | Maangiya photocopies | Client marubadiyum anuppa list pannunga |

Client-ku kudukkura notes-la edhu files-ku OCR thevaippattudhu, edhu pages fail aachu-nu exact-aa irukkum, adhanaala oru maangiya circular pathi answer konjam weak-aa irundhaa yaarum aachariyappada maattaanga.

## Podhuvaa panra thappugal

- **Defaults-a nambradhu.** pandas types-a guess pannum, 000412 maadhiri item codes-a numbers-aa maathi leading zeros-a vittudum. Id maadhiri columns-ku types set pannunga.
- **Encodings-a ignore panradhu.** Indian scripts-la garble aana names-na perumbaalum encoding thappu, file udaiyala.
- **Ella PDF-layum text irukkum-nu assume panradhu.** Scans-la empty strings silent-aa varum. Per page characters measure pannunga.
- **Page number-a ilappadhu.** Adhu illannaa source-a cite panna mudiyaadhu, thappaana answer-a debug panna mudiyaadhu.
- **Dates-a month-first-aa padikkradhu.** India-la 05/11/2026 5 November; `dayfirst=True` set pannunga.
- **Output-a padikkaadhadhu.** Ayndhu random samples kaattura problems-a counts miss pannum.
