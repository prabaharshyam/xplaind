## Idhu enna

Neenga daily use panra chat assistants oru thadavaiyila train aagala. Stages-a stages-a build aagudhu, ovvoru stage-um vera onnu serkkum.

1. **Pre-training.** Model periya alavu text-a (web pages, books, code) padichi, adutha token-a predict panna kathukkum. Idhu thaan perumbaalaana panam, compute-a edukkum. Result oru **base model**. Adhukku language pathiyum ulagam pathiyum neraya theriyum, aana adhu text-a mattum thodarum.
2. **Supervised fine-tuning (SFT).** Base model aalgal ezhudhina illa check panna prompt-um ideal answer-um irukkura examples-la train aagum. Instructions-a follow pannavum assistant maadhiri reply panna-vum kathukkum. Idhai instruction tuning-nu-m solluvaanga.
3. **Preference tuning.** Makkal ore prompt-ku rendu answers-a compare panni nalladha select pannuvaanga. Appuram virumbappatta answers adhigam varra maadhiri model tune aagum. Rendu common methods **RLHF** (reinforcement learning from human feedback), **DPO** (direct preference optimisation).

2-um 3-um serndhu perumbaalum **post-training**-nu solluvaanga. Idhu mothha compute-la sinna pagudhiya thaan use pannum, aana model-oda behaviour-a romba maathum. Oru provider oru model-oda "base" version-aiyum "instruct" illa "chat" version-aiyum release panna, difference post-training thaan.

```flow
title: Raw text-la irundhu chat model varaikkum
dir: LR
Huge text collection | web, books, code
Huge text collection -> Pre-training | predict the next token
Pre-training -> Base model | continues text
Base model -> Supervised fine-tuning | prompt and ideal answer
Supervised fine-tuning -> Instruct model | follows instructions
Instruct model -> Preference tuning | RLHF or DPO
Preference tuning -> Chat model | helpful, polite, safer
```

Oru useful picture: pre-training model-ku knowledge tharum, SFT helpful-aa irukkura format-a kathukkudukkum, preference tuning pala possible answers-la makkal unmaiyila edha virumbuvaanga-ngira judgement-a shape pannum.

## Idhu eppadi work aagudhu

**Stage 1: pre-training.** Training text tokens-aa vettappadum. Ovvoru position-kum, model adutha token-a guess pannum, adha unmaiyaana token-oda compare pannum, adhoda weights-a oru sinna alavu maathum. Trillions of tokens-la idhai thirumba thirumba pannaa, grammar, facts, reasoning patterns, code-a kathukkum. Model enna kathukkudhu-nu adhu enna padikkudhu-nu romba sarndhirukkum. Odia, Assamese maadhiri oru language training text-la arithaa irundha, andha language-la model weak-aa irukkum.

Oru base model-ku "How do I reset my UPI PIN?" nu prompt kuduthaa, adhu badhil sollalaam, illa innum kelvigala list pannalaam, yenna web-la kelvigal niraindha pages neraya. Adhu veenaa help pannaama illa. Adhu likely text-a predict pannudhu.

**Stage 2: supervised fine-tuning.** Train aana aalgal aayirakkanakkaana prompts-ku high-quality answers ezhudhuvaanga: explanations, summaries, code, polite refusals. OpenAI-oda InstructGPT velai, oru aarambakaala public example, 13,000 maadhiri demonstration examples use pannudhu. Idha ezhudhuradhu slow, selavaanadhu, yenna oru kashtamaana kelvikku nalla badhil ezhudha oru skilled person-ku neram aagum. SFT-ku aprom model kelvigala thodaraama badhil sollum.

Oru SFT example oru short chat maadhiri irukkum:

```json
{"messages": [
  {"role": "user", "content": "How do I reset my UPI PIN?"},
  {"role": "assistant", "content": "Open your UPI app, go to the bank account, choose Reset UPI PIN, and verify with your debit card details and the OTP sent to your phone."}
]}
```

**Stage 3: preference tuning.** Entha prompt-kum pala acceptable answers irukkum, sila vegam nalladha irukkum. Oru best answer-a ezhudhuradhu kashtam, aana rendu answers-a compare panradhu easy. Adhanaala makkalukku oru prompt-um model-oda rendu answers-um kaattappattu edhu nalladhu-nu kekkappadum. Ovvoru judgement-um oru **preference pair** aagum:

```json
{"prompt": "My order is late. What can I do?",
 "chosen": "Sorry about the delay. You can track it under My Orders. If it is more than 3 days late, you can ask for a refund there.",
 "rejected": "Orders are sometimes late. Please wait."}
```

Indha pairs-la irundhu kathukka rendu main vazhigal.

- **RLHF.** Mudhalla pairs-la oru thani **reward model**-a train pannunga, adhanaala entha answer-kum makkal evvalavu virumbuvaanga-nu score kudukka mudiyum. Appuram chat model-a reinforcement learning vechu adhigam score varra answers-a produce panna train pannunga, SFT model-oda kittathula irundhukkittu, score nallaa kidaikkura vichithiramaana text-ku drift aagaama.
- **DPO.** Reward model-a vittudunga. Chat model-a pairs-la neradiyaa train pannunga, aarambathula irundhadhai vida chosen answer-a adhigamaakki, rejected answer-a kammiyaakki. Idhu saadharana training code use pannum, selavu kammi, odutha stable. Pala open model families DPO illa idhu maadhiri methods-ku maaritaanga.

Moonavadhu variant **RLAIF**, edha answer nalladhu-nu judge panna makkalukku badhila oru strong model use pannum. Selavu kammi, aana judge model-oda blind spots-a inherit pannum.

| Stage | Training data | Edhu serkkum | Approx selavu |
| --- | --- | --- | --- |
| Pre-training | Trillions of tokens raw text | Language, facts, code pathiya knowledge | Perumbaalaana compute; periya labs mattum seiyum |
| Supervised fine-tuning | Aayirangal mudhal pathu aayirangal prompt-um ideal answer-um pairs | Instructions-a follow pannum, assistant maadhiri reply pannum | Sinna compute; selavaana expert writing |
| Preference tuning (RLHF illa DPO) | Pathu aayirangal chosen, rejected pairs | Nalla judgement, tone, safety | Sinna compute; selavu kammiyaana human comparisons |

Indha numbers podhuvaana patterns, exact numbers illa. Ovvoru lab-oda recipe-um vera, neram-vaari maarum.

**Browser-la try pannunga.** Oru reward model preferences-a scores-aa maathum. Oru pairwise preference eppadi oru probability-aa aagudhu-nu paarunga.

```python
import math

def prefer_probability(score_a, score_b):
    return 1 / (1 + math.exp(-(score_a - score_b)))      # the Bradley-Terry form used in reward modelling

pairs = [("helpful, cites the policy", 2.1, "vague answer", 0.4),
         ("polite refusal", 0.2, "unsafe instructions", -1.5),
         ("short and right", 1.0, "long and right", 0.9)]
for a, sa, b, sb in pairs:
    print(f"P({a!r} preferred over {b!r}) = {prefer_probability(sa, sb):.2f}")
```

## Oru worked example

Hyderabad-la oru team sinna kadai owners-ku Telugu-layum English-layum bank statements-a explain panra oru bot-a build pannuraanga. Ovvoru stage-um enna serkkudhu-nu paaka, ore open-weight model family-oda moonu versions-a, "Explain this ₹2,350 debit marked NACH" nra oru prompt-la compare pannuraanga.

| Version | Prompt-ku enna pannichu | Yen |
| --- | --- | --- |
| Base model | Oru forum post maadhiri moonu varigal ezhudhi, aprom vera oru kelvi | Adhu text-a mattum thodarum; forum posts neraya |
| SFT-ku aprom | NACH oru automatic debit, perumbaalum loan EMI illa subscription-nu, oru neenda, formal paragraph-la explain pannichu | Helpful answer-oda format-a kathukkitchu |
| Preference tuning-ku aprom | Ore explanation-a moonu short varigala kuduthu, bank app-la mandate list-a check panna suggest panni, innoru entry-a explain pannava-nu kettudhu | Makkal adutha step-oda short, practical answers-a virumbinaanga |

Team chat version-a avanga starting point-aa select pannuraanga. Appuram adhoda Telugu replies stiff-aa irukku, sila samayam English-ku maarudhu-nu gavanikkuraanga. Andha gap pre-training-la irundhu varudhu, anga Telugu text arithu. Evvalavu prompting-um pre-training gap-a muzhusaa fix pannaadhu, adhanaala 200 real questions-la rendu options-a test pannuraanga: Telugu examples-oda oru kavanamaana prompt, avanga Telugu pesura support staff ezhudhina 1,500 replies-la oru sinna SFT run. Public leaderboard-la illa, avanga own test-la edhu nalla score pannudho adha vechukkuraanga.

## Podhuvaa panra thappugal

- **Base model-a chatbot-aa use panradhu.** Adhu badhil sollaama text-a thodarum. Neenga own SFT plan pannaadha varaikkum instruct illa chat version-a download pannunga.
- **Post-training knowledge serkkum-nu ninaikkaradhu.** Adhu perumbaalum behaviour-a maathum. Facts pre-training-la irundhu illa run time-la retrieval-la irundhu varum.
- **RLHF model-a unmaiyaa aakkum-nu nambradhu.** Makkal virumbura answers-ku adhu reward tharum, makkal confident-aana, fluent-aana, aana thappaana text-a virumbalaam.
- **Refusals-a ungaloda prompt-la bug-nu ninaikkaradhu.** Romba jaakkirathaiyaana refusals perumbaalum preference tuning-la irundhu varum. Clear-aana prompt help pannum, aana sila behaviour model-kulla ye irukku.
- **Interview-la DPO-vayum RLHF-aiyum kalakkradhu.** Rendumae preference pairs-la irundhu kathukkum. RLHF mudhalla reward model-a train pannum; DPO pannaadhu.

## Chat models yen appadi nadandhukkudhu

Neraya daily quirks indha stages-la irundhu vandhavai.

- **Sycophancy.** Models ungaloda othukka maadhiri irukkum, yenna preference tuning-la othukkura answers-a aduthadi virumbinaanga.
- **Neenda, nirappina answers.** Reviewers thorough answers-ku reward kuduthaa, neendadhu nalladhaa theriyum-nu model kathukkum.
- **Samamillaadha languages.** Hindi illa Tamil quality, pre-training-layum SFT examples-layum andha language evvalavu irundhadhu-nu sarndhirukkum.
- **Knowledge cut-off.** Pre-training data collect aana aprom nadandha edhuvum model-ku theriyaadhu, neenga pudhu information kudukkaadha varaikkum.

## Demo-la irundhu production-ku

- **Model card-a padinga.** Adhu perumbaalum model entha stages-a thaandi vandhadhu, enna data use pannaanga, entha languages cover aachu-nu solludhu.
- **Sariyaana version-a select pannunga.** Applications-ku instruct illa chat versions use pannunga. Neenga own SFT pannaa illa plain text completion-ku mattum base model use pannunga.
- **Ungaloda languages-la test pannunga.** Ungaloda users ezhudhura ovvoru language-layum real questions-la model-a score pannunga, mixed Hinglish illa Tanglish-um serthu.
- **Ungaloda own pairs-a vechukkunga.** Reviewers oru reply-a fix pannaa illa rendu drafts-la onna select pannaa, adha store pannunga. Idhu pinnaadi SFT, preference data aagum.
