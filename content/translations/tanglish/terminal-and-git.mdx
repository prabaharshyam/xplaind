## Idhu enna

Ovvoru developer-um dhinamum rendu tools use panraanga:

- **Terminal**: commands run panra oru text window. Idhula folders-kku naduvula nagaralaam, programs run pannalaam, packages install pannalaam, Git maadhiri tools use pannalaam.
- **Git**: Unga project-oda snapshots-a, adhaavadhu **commits**-a record panra version control system. Enna maarichu-nu paarkkalaam, thappugalai undo pannalaam, code-a share pannalaam. **GitHub** Git repositories-a online-la host pannum; mathavanga adhai paarkkalaam, ungakooda serndhu velai seiyalaam.

```flow
dir: LR
Unga folder | hello.py, expenses.py, README.md: neenga files-a edit panreenga -[git add, git commit]-> Unga computer-la Git | commits 1, 2, 3: undo pannakkoodiya history
Unga computer-la Git -[git push]-> GitHub | Unga public repository: share pannakkoodiya link
```

Employers GitHub profiles-a paarkkuraanga. Thelivaana commits-um nalla README-um irukkura repository thaan, neenga code ezhudhi organise panna mudiyum-ngradhukku elimaiyaana proof; interview-layae interviewers adhai perumbaalum thirandhu paarppaanga.

Nagpur-la Python kathukkittirukkura Ravi, exercise scripts irukkura oru folder-a GitHub portfolio-vaa maathuradhai indha lesson follow pannum. Idhoda check oru sinna project: ungalodaya sondha repository, kuraindhadhu moonu thelivaana commits-oda, oru README-oda.

## Idhu eppadi work aagudhu

### Terminal basics

| Command | Enna pannum |
| --- | --- |
| `pwd` | Neenga irukkura folder-a kaattum (Mac, Linux; Windows-la `cd` mattum) |
| `ls` | Files-a list pannum (Windows Command Prompt-la `dir`) |
| `cd projects` | Oru folder-kkulla pogum |
| `cd ..` | Oru folder mela pogum |
| `mkdir python-practice` | Pudhu folder uruvaakkum |
| `python hello.py` | Oru program-a run pannum |

**Up arrow** mundhina commands-a thirumba konduvarum, **Tab** file, folder peyargalai complete pannum; idhanaala type panradhum typos-um romba kuraiyum.

### Git-a oru thadava set up pannunga

Git-a install pannunga, apparam neenga yaarunnu sollunga:

```bash
git config --global user.name "Priya Raman"
git config --global user.email "priya@example.com"
```

### Repository aarambichu commits pannunga

```bash
cd python-practice
git init                         # start tracking this folder
git status                       # what has changed?
git add hello.py                 # choose changes for the next commit
git commit -m "Add hello script that prints name and date"
git log --oneline                # see the history
```

`git add` changes-a **staging area**-la podum: adutha snapshot-la enna pogum-nu oru list. `git commit` andha snapshot-a oru message-oda save pannum. Indha rendu-step design-naala thodarbulla changes-a serthu commit pannavum, mathadhai apparam paarkkavum mudiyum.

### Nalla commit messages

| Balaveenam | Valimai |
| --- | --- |
| "update" | "Add expense totals by category" |
| "fixed stuff" | "Handle missing amounts in expense CSV" |
| "final" | "Add README with usage examples" |

Present tense-la ezhudhunga, enna maarichu-nu sollunga, mudhal variyai sinnadhaa vainga. Edhaavadhu udaindhaa edhirkaalaththula neengalae idha padippeenga.

### Git-la Undo

| Situation | Command |
| --- | --- |
| Kadaisi commit-kku appuram enna maarichu-nu paarkka | `git diff` |
| Oru file-la panna changes-a thookki poda | `git restore expenses.py` |
| Thappaa add panna file-a unstage panna | `git restore --staged expenses.py` |
| Pazhaya version-a paarkka | `git log --oneline`, apparam `git show <commit>` |

### GitHub-kku push pannunga

GitHub-la oru empty repository uruvaakki, apparam connect panni push pannunga:

```bash
git remote add origin https://github.com/priya-raman/python-practice.git
git branch -M main
git push -u origin main
```

GitHub ungalai sign in pannach solum; adhoda prompts-a follow pannunga, illanna oru SSH key set up pannunga. Mudhal push-kku appuram, `git push` mattum podhum, pudhu commits poidum.

### README-um .gitignore-um

`README.md` project enna, eppadi run panradhu-nu vilakkum. GitHub adhai repository-oda mudhal page-la kaattum.

`.gitignore` file Git track pannakkoodaadha vishayangalai list pannum:

```text
.venv/
__pycache__/
.env
```

`.env` vari thaan romba mukkiyam: `.env` files-la perumbaalum API keys irukkum. Unga mudhal `git add`-kku **munnaadiyae** `.gitignore` uruvaakkunga, yenna oru secret commit aayittaa, appuram file-a delete pannaalum history-la irukkum. Oru key eppavaavadhu push aayittaa, udanae adhai revoke panni pudhu key uruvaakkunga.

## Oru worked example

Nagpur-la Python kathukkittirukkura Ravi-kitta exercise scripts irukkura oru folder irukku: oru expense tracker, oru marks calculator, API key use panra oru weather fetcher. Adhai GitHub portfolio-vaa maathuraaru.

| Step | Enna panraaru | Yen |
| --- | --- | --- |
| 1 | Folder-la `git init` | History-a track panna aarambikka |
| 2 | `.venv/`, `.env` irukkura `.gitignore` uruvaakkuraaru | Environment-aiyum avaroda API key-yaiyum Git-la irundhu vilakki vaikka |
| 3 | Commit: "Add expense tracker with category totals" | Thelivaana, arthamulla oru step |
| 4 | Commit: "Handle missing amounts in expense CSV" | Thaniyaana rendaavadhu improvement |
| 5 | Commit: "Add README with usage examples" | Varravangalukku project-a vilakka |
| 6 | Pudhu public repository-kku `git push` | Share panna oru link |

Avaroda README-la oru vari summary, ovvoru script-aiyum eppadi run panradhu, output-oda oru sample irukku.

**Oru thappu, undo aachu.** Oru vaaram kazhichu oru feature serkkumbodhu expense tracker-a udaichuduraaru. `git diff` entha variyai maathunaarunnu sariyaa kaattudhu. `git restore expenses.py` kadaisiyaa commit panna version-a oru vinaadiyila thirumba konduvarudhu; avar feature-a innum kavanamaa marubadiyum try panraaru.

**Payoff.** Adutha maasam oru interview-la, panel avaroda repository-a thirandhu "Handle missing amounts in expense CSV" commit pathi kekkuraanga. Bug enna, eppadi kandupidichaar, eppadi fix pannaarunnu explain panraaru. Interview-la adhuthaan sirandha pagudhi.

## Podhuvaa panra thappugal

- **Kadaisiyila orae periya commit.** Pora vazhiyilaeyae sinna, arthamulla steps-aa commit pannunga.
- **"update" maadhiri messages.** Enna maarichu-nu sollunga.
- **Secrets-a commit panradhu.** Keys-a `.env`-la vainga, mudhal commit-kku munnaadiyae adhai `.gitignore`-la list pannunga, eppavaavadhu push aana entha key-yaiyum revoke pannunga.
- **Virtual environments, caches-a commit panradhu.** Adhai ignore pannunga.
- **README illaama irukkuradhu.** Varravangalukku project enna pannudhu, eppadi run panradhu-nu theriyaadhu.
- **`git status` illaama velai seiyradhu.** Adikkadi check pannunga; neenga enga irukkeenga-nu adhu sariyaa solum.

## Practice pannunga

Keezha link pannirukkura MIT Missing Semester-oda shell, version control lectures-a paarunga.

Indha lesson-oda check oru sinna project:

1. Unga sondha Python exercises-kku oru repository **uruvaakkunga**, mudhal commit-kku munnaadiyae `.gitignore`-oda.
2. Kuraindhadhu moonu arthamulla steps-a, ovvonnum thelivaana message-oda **commit pannunga**.
3. Ovvoru script-um enna pannum, eppadi run panradhu-nu solra oru README **ezhudhunga**.
4. Adhai GitHub-kku **push panni**, repository link-a submit pannunga.

**Mudinjadhu-nu eppo sollalaam:** Oru repository uruvaakka, thelivaana messages-oda changes-a commit panna, GitHub-kku push panna, Git-la oru thappai undo panna mudiyum.
