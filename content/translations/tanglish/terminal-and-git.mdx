## Idhu enna

Kittathatta ella software velaikkum adiyila rendu tools irukku:

- **Terminal** (shell alladhu command line-num solluvaanga) oru window, adhula click panradhukku badhilaa commands type pannuveenga. Adhula irundhe folders-kku naduvula nagaralaam, programs run pannalaam, packages install pannalaam, Git maadhiri tools use pannalaam.
- **Git** oru version control system. Adhu unga project-oda snapshots-a record pannum, adhukku **commits**-nu per, adhanaala enna maaruchu-nnu paarkkalaam, thappugala undo pannalaam, code-a share pannalaam. **GitHub** oru website, Git repositories-oda copies-a online-la store pannum, adhanaala mathavanga avatra paarkkalaam, unga kooda velai seiyalaam. GitHub illaamalum Git velai seiyum; unga history-a anuppa GitHub oru idam, avvalavu thaan.

Git kittathatta ella idathulayum irukku: Stack Overflow-oda 2022 developer survey-la 93% developers adha use panradhaa sonnaanga. Course material, take-home tasks, unga mudhal team-oda code ellaame kittathatta eppavume oru Git repository-aa thaan varum.

Git-a easy aakkura ore idea: unga changes naalu idangalla edho onnula irukkum, ovvoru command-um avatra oru idathula irundhu adutha idathukku nagarthum.

```flow
title: Unga changes enga irukku
dir: LR
Working folder | neenga edit panra files -[git add]-> Staging area | adutha commit-la enna irukkum
Staging area -[git commit]-> Local repository | unga commits-oda history
Local repository -[git push]-> GitHub | online-la irukkura shared copy
GitHub -[git clone, git pull]-> Working folder
```

Git-la varra perumbaalaana kuzhappam, oru change endha idathula irukku-nnu theriyaadhadhaala thaan. `git status` adha sollum, adhanaala matha ovvoru Git command-kkum munnaadiyum pinnaadiyum adha run pannunga.

Indha lesson, Nagpur-la Python kathukkittirukkura Ravi-a follow pannudhu; avar exercise scripts irukkura oru folder-a public repository-aa maathuraaru. Idhoda check unga sondha chinna project, kadaisila irukkura rubric vechu mark pannappadum.

## Idhu eppadi work aagudhu

### Terminal basics

**Mudhalla unga terminal-a thernthedunga.** Mac-la Terminal app-a thiranga. Linux-la endha terminal-um velai seiyum. Windows-la Git for Windows-a install pannunga, adhu kooda **Git Bash** varum; indha course-kku Git Bash (alladhu WSL, Windows-kkulla Linux) use pannunga, appo ovvoru command-um ezhudhiyirukkura maadhiriye velai seiyum. PowerShell-um `pwd`, `ls`, `cd`-a ethukkum; pazhaya Command Prompt vera commands use pannum, udhaaranamaa `ls`-kku badhilaa `dir`.

| Command | Idhu enna pannum |
| --- | --- |
| `pwd` | Neenga irukkura folder-a print pannum |
| `ls` | Indha folder-la irukkura files-a list pannum |
| `ls -a` | Hidden files-aiyum list pannum; avatroda per oru dot-la aarambikkum, udhaaranamaa `.gitignore`, `.env` |
| `cd python-practice` | Oru folder-kkulla pogum |
| `cd ..` | Oru folder mela pogum |
| `cd ~` | Unga home folder-kku pogum |
| `mkdir python-practice` | Oru pudhu folder uruvaakkum |
| `python expenses.py` | Oru program-a run pannum (sila Mac, Linux machines-la `python3`) |

**Paths.** Oru absolute path disk-oda uchchiyila irundhu aarambikkum, udhaaranamaa `/home/ravi/python-practice` (Git Bash-la C drive-na `/c`, adhanaala oru Windows home folder `/c/Users/Ravi` maadhiri irukkum). Oru relative path neenga ippo irukkura idathula irundhu aarambikkum: andha folder ippo irukkura folder-kkulla irundhaa mattum thaan `python-practice` velai seiyum. "No such file or directory"-nu vandhaa, kittathatta eppavume neenga thappaana folder-la irukkeenga: vera edhukkum munnaadi `pwd`, `ls` run pannunga. Folder pergalla spaces vendaam; edhaavadhu onnula irundhaa, `cd "My Projects"` maadhiri quotes-kkulla vainga.

**Environment variables**-na terminal thaan start panra ovvoru program-kkum anuppura, per irukkura values. `echo $HOME` onna print pannum. `export CITY=Nagpur` onna set pannum, aanaa andha terminal window-kku mattum; adha close pannaa value poyidum. Adhanaala projects API keys-a program padikkira oru `.env` file-la vechukkum, Git-kku orupodhum pogakkoodaadha file sariyaa adhu thaan.

Moonu keys manikkanakkaana nerathai michappaduthum: **up arrow** munnaadi run panna commands-a thirumba kondu varum, **Tab** file, folder pergala complete pannum (typos-aiyum thavirkkum), **Ctrl+C** run aagittirukkura alladhu stuck aana oru program-a niruthum.

### Git-a oru thadavai set up pannunga

Git install aagiyirukkaa-nnu check pannunga, appuram neenga yaaru-nnu adhukku sollunga:

```bash
git --version
git config --global user.name "Ravi Deshmukh"
git config --global user.email "12345678+ravi-d@users.noreply.github.com"
git config --global init.defaultBranch main
```

Unga perum email-um ovvoru commit-layum padhivaagum, neenga push pannadhum yaar venaalum avatra padikkalaam. Unga personal email public aagakkoodaadhu-nnaa, GitHub ungalukku oru private "noreply" address kudukkum: GitHub-oda email settings-la "Keep my email address private"-a tick panni, adhu kaattura address-a copy pannunga. Mela irukkuradhu adhoda vadivathukku oru udhaaranam mattum thaan.

Kadaisi line mudhal branch-kku `main`-nu per vaikkum, GitHub use panra per adhu thaan. Adhu illanna, sila Git versions mudhal branch-a `master`-nu koopittu adha pathi oru neelamaana hint-a print pannum.

### Dhinasari loop: status, add, commit

```bash
cd python-practice
git init                  # once per project: start tracking this folder
git status                # which files are new, changed or staged?
git add expenses.py       # stage this file for the next commit
git commit -m "Add expense tracker with category totals"
git log --oneline         # one line per commit, newest first
```

`git add` changes-a **staging area**-la vaikkum, `git commit` staged aana ellathaiyum ore snapshot-aa save pannum. Oru commit-la ore oru idea irukkanum-ngradhukkaaga thaan rendu steps irukku. Neenga oru bug-a fix pannittu oru pudhu feature-aiyum aarambichirundhaa, bug fix-a mattum stage panni commit pannunga, paadhi mudinja feature-a appuram paarthukkalaam.

`git add .` folder-la Git-kitta ignore panna sollaadha ellathaiyum stage pannum. Adhu vegamaanadhu, aanaa secrets-um kuppaiyum commit aaguradhum ippadi thaan, adhanaala mudhalla `git status` run panni list-a padinga. Neenga innum stage pannaadha changes-a `git diff` kaattum; commit aagapporadha `git diff --staged` kaattum.

### Udhavura commit messages

| Balaveenamaanadhu | Valuvaanadhu |
| --- | --- |
| "update" | "Add expense totals by category" |
| "fixed stuff" | "Handle missing amounts in expense CSV" |
| "final" | "Add README with usage examples" |

Mukkiyamaana rules:

- **Oru verb-la, oru instruction maadhiri aarambinga:** "Add", "Fix", "Handle", "Remove". Oru useful test: message, "If applied, this commit will..." ngura sentence-a mudikkanum.
- **Oru commit-kku oru change.** Adha vivarikka "and" thevaippattaa, adhu anegamaa rendu commits.
- **Mudhal line-a chinnadhaa vainga.** Oru common convention sumaar 50 characters. Yen-nu vilakkanum-naa, oru blank line vittu adhukku keezha innum ezhudhunga.
- **Code run aagumbodhu commit pannunga.** Appo unga history-la irukkura ovvoru commit-um thirumba poga oru safe point.

### Secrets-aiyum kuppaiyaiyum veliya vainga: .gitignore

Project-oda top folder-la irukkura `.gitignore`-ngura oru file, Git edha orupodhum track pannakkoodaadhu-nnu list pannum:

```text
.venv/
__pycache__/
.env
```

`.venv/` unga virtual environment (perisu, `requirements.txt`-la irundhu thirumba build pannalaam), `__pycache__/` Python-oda cache, `.env`-la keys irukku. Ellathaiyum vida mukkiyamaanadhu `.env` line thaan.

Beginners miss panra rule: **`.gitignore` Git innum track pannaadha files-a mattum thaan baadhikkum.** `.env` erkanave oru commit-la irundhaa, appuram adha `.gitignore`-la serthaa edhuvum maaraadhu, `git status` adha kaattitte irukkum. Ippadi track panradha niruthunga:

```bash
git rm --cached .env      # stop tracking; the file stays on your disk
git commit -m "Stop tracking .env"
```

Idhu future commits-la irundhu mattum thaan adha neekkum. Pazhaya commit-la innum key irukku, repository-a paarkka mudiyura yaar venaalum adha padikkalaam. Adhanaala key leak aayiduchu-nne eduthukkonga: provider-oda website-la adha revoke panni pudhu key onnu uruvaakkunga. File-a delete panradhu mattum podhaadhu.

GitHub oru safety net serkkudhu. Public repositories-la personal accounts-kku default-aa **push protection**-a on pannum; adhu thanakku therinja format-la oru secret irukkura push-a block pannum, udhaaranamaa niraiya cloud, AI provider keys. Ella secret-aiyum adhaala kandupidikka mudiyaadhu, udhaaranamaa neengale uruvaakkuna oru password, adhanaala unmaiyaana paadhugaappu unga mudhal `git add`-kku munnaadiye `.gitignore`-a uruvaakkuradhu thaan.

### Commit aaguradhukku munnaadiye undo pannunga

| Nilaimai | Command |
| --- | --- |
| Enna maariyirukku, innum stage aagalai-nnu paarkka | `git diff` |
| Adutha commit-kku enna stage aagiyirukku-nnu paarkka | `git diff --staged` |
| Oru file-la panna unga edits-a thookki poda | `git restore expenses.py` |
| Edits-a vechukkitte oru file-a unstage panna | `git restore --staged expenses.py` |
| Oru pazhaya commit-a paarkka | `git log --oneline`, appuram `git show a7d7b78` |

`git restore expenses.py`-la kavanamaa irunga: adhu kadaisiyaa commit aana version-a thirumba kondu varum, neenga thookki podura edits nirandharamaa poyidum, yenna Git avatra save pannave illa. Oru commit-a undo panradhu, erkanave push pannadhaiyum serthu, Git-la vishayangala undo panradhu pathina lesson-oda topic.

### GitHub-kku push pannunga, velai seiyura sign-in-oda

GitHub-la **New repository**-a click panni, adhukku `python-practice`-nu per vainga, README, .gitignore, licence options-a off-aave vidunga, appo repository kaaliyaa aarambikkum. Appuram unga folder-a adhoda connect panni push pannunga:

```bash
git remote add origin https://github.com/ravi-d/python-practice.git
git push -u origin main
```

`origin`-na unga GitHub copy-kku vazhakkamaa vaikkira chella per. `-u` unga `main`-a adhoda link pannum, adhanaala adhukkappuram verum `git push`, `git pull` velai seiyum.

**Perumbaalaana beginners maattikkiradhu sign in panra idathula thaan.** 13 August 2021-la irundhu, Git commands-kku unga account password-a GitHub ethukkaradhilla. Terminal username, password kettu neenga unga GitHub password-a type pannaa, push fail aagum. Adhukku badhilaa idhula onna thernthedunga:

| Unga setup | Enna pannanum |
| --- | --- |
| Git for Windows irukkura Windows | Git Credential Manager adhu koodave varum. Mudhal push-la oru sign-in window thirakkum; browser-a thernthedutthu GitHub-la sign in pannunga, adhu ungala nyaabagam vechukkum. |
| Mac alladhu Linux | GitHub CLI-a install panni `gh auth login` run pannunga. GitHub.com, HTTPS-a thernthedunga, unga GitHub credentials vechu Git-a authenticate pannavaa-nnu kettaa yes sollunga, browser-la mudinga. |
| Vera edhuvaanaalum | Indha repository-kku Contents-la read, write access irukkura oru fine-grained personal access token-a uruvaakkunga (GitHub Settings, appuram Developer settings), terminal password kekkura idathula adha paste pannunga. Adha oru password maadhiriye paadhugaappaa vainga. |

SSH keys innoru option; Linux, shell, SSH pathina lesson adha cover pannum.

**Innoru trap.** GitHub-la "Add a README"-a tick panniyirundhaa, unga mudhal push refuse aagum, yenna unga computer-la illaadha oru commit GitHub-la irukku:

```text
 ! [rejected]        main -> main (fetch first)
error: failed to push some refs to 'https://github.com/ravi-d/python-practice.git'
```

Oru pudhu repository-kku ellathaiyum vida simple-aana fix: GitHub-la adha delete pannunga (adhoda Settings page, kadaisila), thirumba kaaliyaa uruvaakki push pannunga. Mudhalla `git pull` run panradhu udhavaadhu: Git "refusing to merge unrelated histories"-nu solli ninnudum.

### Mathavanga kooda velai seiyuradhu: oru mudhal paarvai

Team work-um take-home tasks-um thalaikeezhaa aarambikkum: repository erkanave GitHub-la irukkum.

```bash
git clone https://github.com/example-team/expense-app.git
cd expense-app
git pull                          # bring in teammates' new commits
git switch -c add-monthly-report  # a new branch for your change
# edit files, then git add and git commit
git push -u origin add-monthly-report
```

Oru **branch**-na commits-oda oru thani line, adhanaala unga change ready aagura varaikkum `main`-a thodaadhu. Branch-a push pannadhukku appuram, GitHub-la oru **pull request**-a open pannuveenga: unga changes-a kaattura oru page, adhanaala avai `main`-kkulla merge aaguradhukku munnaadi oru teammate avatra review pannalaam.

Neengalum oru teammate-um adhe lines-a maathinaa, unga rendu perukkum naduvula Git-aala thernthedukka mudiyaadhu. Adhu oru **merge conflict**-oda ninnu file-a mark pannum:

```text
<<<<<<< HEAD
print(sorted(totals.items()))
=======
print("Totals:", totals)
>>>>>>> 3c1dea94b5893015fb3b508cd578f48b684bd511
```

`=======`-kku mela irukkuradhu unga version; keezha irukkuradhu varra version. Neenga virumbura version-kku file-a edit pannunga, moonu marker lines-a delete pannunga, appuram file-a `git add` panni, Git-oda message-a vechukka `git commit --no-edit` run pannunga. `git pull` "Need to specify how to reconcile divergent branches"-nu solli ninnaa, neenga rendu perume commits panniyirukkeenga; `git pull --no-rebase --no-edit` avatra merge pannum. Branches pathiyum team-oda Git use panradhu pathiyum irukkura lessons innum aazhamaa pogum.

## Oru worked example

Ravi-kitta oru expense tracker, oru marks calculator, `.env`-la irundhu API key-a padikkira oru weather fetcher irukkura oru folder irukku. Idho avaroda unmaiyaana session, output-a surukki. Unga commit hashes (`81d3fe3` maadhiri short codes) vera maadhiri irukkum.

**1. Track panna aarambinga, edhaiyum add panradhukku munnaadi paarunga.**

```text
$ cd ~/python-practice
$ git init
Initialized empty Git repository in /home/ravi/python-practice/.git/
$ git status
On branch main

No commits yet

Untracked files:
	.env
	.venv/
	__pycache__/
	expenses.py
	marks.py
	weather.py
```

Aabathu `.env` line thaan: ippo oru `git add .` pannaa avaroda key commit aayidum.

**2. `.gitignore`-a uruvaakki thirumba check pannunga.**

```text
$ printf '.venv/\n__pycache__/\n.env\n' > .gitignore
$ git status --short
?? .gitignore
?? expenses.py
?? marks.py
?? weather.py
```

`??`-na untracked. `.env`, `.venv/`, `__pycache__/` list-la irundhu kaanaama poyiduchu, ignore file velai seiyudhu-ngradhukku adhu thaan proof.

**3. Mudhal commit: oru script, kooda ignore file.**

```text
$ git add .gitignore expenses.py
$ git commit -m "Add expense tracker with category totals"
[main (root-commit) 81d3fe3] Add expense tracker with category totals
 2 files changed, 9 insertions(+)
```

**4. Oru bug fix, thani commit-aa.** Avaroda CSV-la irundha oru blank amount tracker-a crash panniduchu. Avar andha line-a fix pannittu, sariyaa enna maathinaaru-nnu check panraaru:

```text
$ git diff
-        totals[row["category"]] = totals.get(row["category"], 0) + float(row["amount"])
+        totals[row["category"]] = totals.get(row["category"], 0) + float(row["amount"] or 0)
$ git add expenses.py
$ git commit -m "Handle missing amounts in expense CSV"
```

**5. Matha scripts-um oru README-um, ovvonnukkum oru commit.** Avaroda README:

```markdown
# Python practice
```

## Podhuvaa panra thappugal

- **Thappaana folder-la Git run panradhu.** "fatal: not a git repository"-na neenga project-kku veliya irukkeenga; unga home folder-la `git init` run pannaa, `git status` ungakitta irukkura ovvoru file-aiyum list pannum. Mudhalla `pwd` run pannunga.
- **Push prompt-la unga GitHub password-a type panradhu.** Adhu reject aagum. Git Credential Manager, `gh auth login` alladhu oru personal access token use pannunga.
- **`.env` commit aanadhukku appuram `.gitignore`-a serkkuradhu.** Track aagura files mela adhukku endha effect-um illa. `git rm --cached .env` use panni, commit panni, key-a maathunga.
- **`git status`-a padikkaama `git add .`.** Keys, `.venv/`, periya data files commit aaguradhu ippadi thaan.
- **Oru pudhu GitHub repository-la "Add a README"-a tick pannittu** appuram erkanave irukkura oru folder-a push panradhu. Push refuse aagum. Pudhu repositories-a kaaliyaa uruvaakkunga.
- **Ore oru periya commit, alladhu "update" maadhiri messages.** Mudinja ovvoru step-aiyum commit pannunga, adhu enna maathudhu-nnu sollunga.
- **Vechukkanum-nu ninaicha edits mela `git restore`.** Andha edits-a thirumba edukka mudiyaadhu. Mudhalla `git diff`-a check pannunga.

## Practice pannunga

Keezha link panniyirukkura shell, version control pathina MIT Missing Semester lectures-a paarunga. Paarkkumbodhe koodave type pannunga.

Appuram indha lesson-oda check-a pannunga: unga sondha Python exercises vechu Ravi-oda steps-a follow pannunga, oru `.gitignore`-la aarambichu, repository-a GitHub-kku push pannunga. Link-a submit panradhukku munnaadi, neengale mark pannunga:

| Check | Eppo pass aagum |
| --- | --- |
| Secrets-um kuppaiyum illa | `git log --all --oneline -- .env` edhaiyum print pannaadhu, GitHub-oda file list-la `.venv/` alladhu `__pycache__/` illa |
| History | Kuranjadhu moonu commits, ovvonnum oru change, ovvoru message-um oru verb-la aarambichu enna maaruchu-nnu solludhu |
| README | Ovvoru script-um enna pannudhu-nnu solli, adha run panna command-a kudukkudhu |
| Pushed | Link thirandhu, front page-la README-a kaattudhu |

**Mudinjadhu-nnu eppo sollalaam:** terminal-la folders-kku naduvula nagara mudiyum, thelivaana messages-oda changes-a commit panna mudiyum, secrets-a history-kku veliya vaikka mudiyum, GitHub-la sign in panni push panna mudiyum, commit aagaadha oru thappai undo panna mudiyum.
