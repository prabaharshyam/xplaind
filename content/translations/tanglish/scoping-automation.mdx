## Idhu enna

"Enga WhatsApp orders-a automate panna mudiyumaa?"-nu kekkumbodhu orae kelvi maadhiri theriyum. Aana ulla dozhan kanakkaana kelvigal maraindhirukku: entha orders? Voice notes-um undaa? Theriyaadha products vandhaa? Yaaru approve pannuvaanga? Aaru maasam kazhichu yaaru fix pannuvaanga? **Automation scope** velai aarambikkiradhukku munnaadiyae idhukkellaam badhil solidum. Adhanaala enna kidaikkappogudhu-nu rendu pakkaththukkum theriyum.

Automation scope-na oru sinna agreement, perumbaalum oru pakkam:

| Section | Enna solludhu | Example |
| --- | --- | --- |
| **Process-um ellaigalum** | Enga aarambikkudhu (trigger), enga mudiyudhu (outcome) | Order message varradhula irundhu billing-kku CSV ready aagura varai |
| **Inputs** | Formats, sources, volumes | WhatsApp-la text-um photos-um, naalaikku sumaar 150 |
| **Automate aaguradhum manual-aa irukkuradhum** | Automation enna pannum, makkal innum enna pannuvaanga | AI extract pannum; staff ovvoru order-aiyum confirm pannuvaanga |
| **Exceptions** | Vazhakkaththukku maariya cases-la enna nadakkum | Theriyaadha products original message-oda staff kitta pogum |
| **Systems, access** | Apps, accounts, permissions, yaaru eppo kudupaanga | WhatsApp Business account, client December 10-kkulla set up pannanum |
| **Success measures** | Baseline-oda enna improve aaganum | Entry time 3 nimishaththula irundhu 1 nimishaththukku keezha |
| **Acceptance test** | Velai pannudhu-nu rendu pakkamum eppadi check panradhu | 200 pazhaya orders replay; 90% lines match aaganum |
| **Ownership, support** | Yaaru maintain panraanga, support kaalam, edhu change-aa kanakku | 30 naal fixes; changes othukkitta day rate-la |
| **Vilai, timeline** | Client velaikku | Fixed fee, koodavae maasaamaasam running costs |

```flow
Discovery | process map, samples -> Draft scope -[client padikkiraanga]-> Kelvigal, edits
Kelvigal, edits -> Draft scope
Draft scope -> Kaiyezhuththaana scope | in, out, acceptance, support, vilai
Kaiyezhuththaana scope -> Build -> Acceptance test -> Handover -> Support kaalam -> Change requests
```

Indha lesson-la Indore-la irukkura oru freelance automation specialist-a follow pannuvom. Oru distributor avangakitta "WhatsApp orders-a automate pannunga"-nu kekkuraanga. Lesson mudiyumbodhu, oru business owner ezhuththula othukkakkoodiya oru pakka scope-a neengalae ezhudha mudiyum.

## Idhu eppadi work aagudhu

### Process map-la irundhu aarambinga

Discovery-la uruvaakkina map-a vechu ellaigalai mudivu pannunga. Ovvoru step-aiyum **automated**, **assisted** (AI draft pannum, oru aal approve pannuvaanga) illa **manual**-nu mark pannunga. Scope-na map-um adhoda decisions-um thaan.

### Inputs-aiyum exceptions-aiyum nermaiyaa list pannunga

Edhaiyum othukkuradhukku munnaadi **20 mudhal 50 real samples** kelunga. Formats-aiyum exceptions-aiyum ennunga:

| Input vagai | Samples-la evvalavu | Decision |
| --- | --- | --- |
| Type panna text orders | 55% | Scope-la irukku |
| Kaiyaala ezhudhina lists-oda photos | 30% | Scope-la irukku, staff review-oda |
| Voice notes | 12% | Ippo scope-la illai; phase 2 |
| Vera apps-la irundhu forward panna PDFs | 3% | Exception-aa staff kitta anuppuradhu |

Ovvoru exception-kkum mudivu pannunga: handle panradhaa, oru aal kitta anuppuradhaa, vilakkuradhaa. Mudivai ezhudhi vainga.

### Human checkpoints-a othukkonga

Entha steps-kku approval venum? Payments, customers-kku pora messages, deletions-kku perumbaalum venum. Yaaru approve pannuvaanga, entha tool-la? Yaarukkum neram illaadha checkpoint-a ellaarum skip panniduvaanga.

### Access-a oru dependency-aa aakkunga

Ovvoru system-aiyum, thevaiyaana account vagaiyaiyum, access kudukka vendiya thethiyaiyum list pannunga. Technical pirachanaigalai vida access thaamadham thaan projects-a adhigam thadukkudhu. Access latta vandhaa timeline nagarum; adhai scope-layae ezhudhanum.

### Acceptance-a oru test-aa define pannunga

Thelivillaadhadhu: "system nallaa velai pannanum". Test pannakkoodiyadhu: "Pona maasaththu 100 real invoices-la kuraindhadhu 85, manusha thodudhal illaama process aagi, ellaa fields-um accountant-oda entries-oda poruntthanum; fail aana ovvonnum review queue-la varanum." Neenga illaadha vera oruthar-aalayum idha run panna mudiyanum.

### Support-um changes-um

Support kaalaththai sollunga, udhaaranam: go-live-kku appuram 30 naal fixes. **Change request**-na ennannu define pannunga: pudhu supplier format, pudhu system, pudhu feature. Changes-kku eppadi vilai poduveenga-nu sollunga. Neraththaiyum vilaiyaiyum maathaama project naduvula varra requests thaan **scope creep**; adhai quote-oda phase 2 list-la podunga.

### Pricing models

| Model | Eppo sirandhadhu | Risk |
| --- | --- | --- |
| Fixed price | Scope thelivaa irukku, samples paarthaachu | Edhirpaaraadhadhai neenga thaanganum |
| Time and materials | Scope thelivillai illa exploratory | Edhirpaaraadhadhai client thaanganum |
| Monthly retainer | Thodarndhu maintenance, sinna changes | Thelivaana maadha limit venum |

Tool, AI usage costs-a eppavum serthu sollunga, yaaru kattuvaanga-num sollunga.

## Oru worked example

Indore-la oru freelance automation specialist-kitta oru distributor "WhatsApp orders-a automate pannunga"-nu kekkuraanga.

**Discovery-la** therinjadhu: 300 retailers-la irundhu naalaikku sumaar 150 orders varudhu. WhatsApp text, voice notes, kaiyaala ezhudhina lists-oda photos, Hindi-layum English-layum. Staff adhai billing software-la type panraanga; andha software CSV files import pannum.

**Oru pakka scope:**

- **In:** business WhatsApp number-la varra text, photo orders; retailer, products, quantities-a AI extract panni product list-oda match panradhu; staff ovvoru order-aiyum confirm panra oru review screen; billing software-kku daily CSV export.
- **Out:** voice notes (phase 2), payments, stock checks, retailers-kku automatic replies.
- **Exceptions:** Theriyaadha products illa retailers original message-oda staff kitta pogum.
- **Access:** Oru provider vazhiyaa WhatsApp Business Platform account, client December 10-kkulla set up pannanum; product, retailer lists sheets-aa.
- **Success:** Oru order entry time sumaar 3 nimishaththula irundhu 1 nimishaththukku keezha; anuppura quantities-la errors innaikku irukkuradhai vida adhigam irukkakkoodaadhu.
- **Acceptance:** 200 pazhaya orders replay; staff review-kku munnaadi kuraindhadhu 90% lines sariyaa match aaganum.
- **Support:** 30 naal fixes; pudhu formats illa features othukkitta day rate-la change requests-aa.
- **Price:** fixed fee, koodavae WhatsApp provider, AI usage-kkaana maadhaandhira running costs, client kattanum.

**Rendu vaaram kazhichu**, owner retailers-kku automatic payment reminders serkka sollraanga. Nalla idea thaan, aana scope-la illai. Adhai adhukkaana thani quote-oda phase 2 list-la podraanga. Edhu out-nu scope thelivaa sollirundhadhaala, sandaiyaa maaraama rendu nimishaththula pechu mudinjuduchu.

## Podhuvaa panra thappugal

- **Samples illaama scope othukkuradhu.** Real inputs thaan exceptions-a kaattum.
- **Edhu out-nu sollaama irukkuradhu.** Ezhudhaadha vilakkugal ilavasa extra velaiyaa maarum.
- **Access-a kadaisiyila yosikkuradhu.** Thaamadhaththukku idhu romba common kaaranam.
- **Thelivillaadha acceptance.** Real data-la numbers-oda oru test define pannunga.
- **Support terms illaama irukkuradhu.** Kaasu illaadha support-aa eppavum neengalae iruppeenga.
- **Running costs-a maraikkiradhu.** Mudhal provider bill varumbodhu client yemaandha maadhiri feel pannuvaanga.

## Practice pannunga

Keezha link pannirukkura Atlassian-oda project scope guide-aiyum GOV.UK-oda user stories guide-aiyum paadinga.

1. **Samples.** Unga process map-la irundhu oru automation idea eduthu, kuraindhadhu 20 real illa realistic input samples serunga.
2. **Scope.** Mela irukkura ovvoru section-odayum oru pakka scope ezhudhunga.
3. **Acceptance.** Acceptance test-a vera oruthar run pannakkoodiya maadhiri ezhudhunga.

**Mudinjadhu-nu eppo sollalaam:** Unga scope-a business owner kitta kudutthu, edhu in, edhu out, success eppadi alakkappadum-nu ezhuththula avanga othukka vaikka mudiyum.
