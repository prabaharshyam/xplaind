## Idhu enna

Unga programs valara valara, ore sila lines-a thirumba thirumba copy panna aarambippeenga: moonu idathula GST kanakku, rendu scripts-la phone number clean panradhu. Copy panna bugs varum, yenna oru copy-a fix panni mathadha copies-a marandhuduvom. **Function** idha solve pannum.

Function-na **oru velaiya** seira peyar vechcha code block. Neenga adhukku **parameters**-nu solra inputs kudupeenga, adhu velaiya seithu, result-a **return** pannum.

```flow
dir: LR
Inputs | price = 1000, rate = 0.18 -> Function: gst_amount(price, rate=0.18) | return price * rate
Function: gst_amount(price, rate=0.18) -> Output: 180.0
```

Functions-aala neenga:

- code-a copy pannaama **reuse** pannalaam;
- periya problem-a, onnu onnaa test panna mudiyura chinna pieces-a **udaikkalaam**;
- steps-ku **peyar** vaikkalaam, adhanaala program instructions maadhiri padikkum: `clean_phone_number`, `monthly_emi`, `send_reminder`.

Indha lesson Imran-a follow pannum. Avar oru form-la irundhu customer phone numbers-a clean pannuraar, messy script-a chinna, reuse panna mudiyura functions-aa maathuraar. Lesson mudiyum podhu, result return panni, programs muzhukka reuse panna mudiyura functions ezhudha mudiyum.

## Idhu eppadi work aagudhu

### Define panradhu, call panradhu

```python
def gst_amount(price, rate=0.18):
    return price * rate

print(gst_amount(1000))         # 180.0, uses the default rate
print(gst_amount(1000, 0.05))   # 50.0
```

- `def` definition-a aarambikkudhu.
- `price`, `rate` **parameters**.
- `rate=0.18` oru **default**; caller edhuvum pass pannala-na idhu use aagum.
- `return` result-a thirumba tharum.

Call panna brackets venum: `gst_amount(1000)`. Brackets illaama `gst_amount`-nu ezhudhina adhu function-a thaane kurikkum, run pannaadhu.

### Return vs print

Beginners-ku idhu thaan romba kuzhappam:

| | `return` | `print` |
| --- | --- | --- |
| Enna pannum | Caller-kku oru value-a thirumba tharum | Screen-la text kaattum |
| Caller andha value-a use pannalaamaa? | Aamaa: `total = price + gst_amount(price)` | Illa: function `None` return pannum |
| Eppo use panradhu | Edhaavadhu compute panra functions-ku | Results-a kaattura code-la mattum |

Edhaavadhu compute panra functions adha return pannanum, print panradha adha call panra code-ku vittudunga. Appo thaan adhae function report-la, web app-la, test-la ellaathulayum work aagum.

### Position vechu, peyar vechu arguments

```python
gst_amount(1000, 0.05)               # by position
gst_amount(price=1000, rate=0.05)    # by name: clearer with several parameters
```

### Scope

Function-kulla create panna variables andha function-kullae mattum thaan irukkum:

```python
def tax(amount):
    total = amount * 1.18
    return total

result = tax(100)     # 118.0
print(total)          # NameError: total only existed inside tax
```

Function-kku enna vennumo adha pass pannunga, adhu enna uruvaakkudho adha return pannunga; veliyila irukkura variables-a nambaadheenga. Thanoda inputs-a mattum use panra functions-a test panradhum reuse panradhum easy.

### Ovvonnukkum oru velai

Nalla function oru velai mattum seiyum, adhoda peyar adha solludhu. Describe panna "and" thevai-na, "number-a clean panni SMS anuppum" maadhiri, rendaa piringa.

```flow
dir: LR
Oru periya function: process_customers() | read, clean, check, write ellaam pannum: test, reuse panna kashtam -[rendaa piringa]-> Chinna functions | digits_only(), normalise_mobile(), is_valid_email(), read_customers(), write_report(): ovvonnaiyum thaniyaa test pannalaam
```

### Docstrings, type hints

Oru line description-um type hints-um readers-kum, unga editor maadhiri tools-kum help pannum:

```python
def monthly_emi(principal: float, annual_rate: float, months: int) -> float:
    """Equated monthly instalment for a loan."""
    r = annual_rate / 12
    return principal * r * (1 + r) ** months / ((1 + r) ** months - 1)

print(round(monthly_emi(500000, 0.09, 60)))   # about 10379 rupees a month
```

### Oru trap: mutable defaults

```python
def add_order(order, orders=[]):      # bug: the same list every call
    orders.append(order)
    return orders
```

Default list oru thadavai thaan create aagum, calls-kulla share aagum, adhanaala orders serndhute pogum. `None` use panni, ullukkulla pudhu list create pannunga:

```python
def add_order(order, orders=None):
    if orders is None:
        orders = []
    orders.append(order)
    return orders
```

## Oru example

Imran Hyderabad-la oru chinna marketing agency-la velai seiraar. Oru client-oda form 3,000 customer phone numbers-a collect pannuchu, ovvoru vidhamaa ezhudhi: "98450 12345", "+91-9845012345", "09845012345", "9845012345 ". SMS tool-ku `+91`-ukku apram pathu digits vennum.

Avar first script oru neenda code block, innum rendu scripts-la konjam maathi copy pannadhu. Adha chinna functions-aa maathi ezhudhuraar, ovvonnukkum oru velai:

```python
def digits_only(text: str) -> str:
    """Keep only the digits in text."""
    return "".join(ch for ch in text if ch.isdigit())

def normalise_mobile(raw: str) -> str | None:
    """Return +91 and ten digits, or None if it is not a valid mobile number."""
    d = digits_only(raw)
    if d.startswith("91") and len(d) == 12:
        d = d[2:]
    if d.startswith("0") and len(d) == 11:
        d = d[1:]
    return "+91" + d if len(d) == 10 else None

for raw in ["98450 12345", "+91-9845012345", "09845012345", "12345"]:
    print(raw, "->", normalise_mobile(raw))
```

| Input | digits_only-ku apram | Rules-ku apram | Result |
| --- | --- | --- | --- |
| `98450 12345` | 9845012345 | 10 digits | +919845012345 |
| `+91-9845012345` | 919845012345 | mundhaiya 91-a edu | +919845012345 |
| `09845012345` | 09845012345 | mundhaiya 0-va edu | +919845012345 |
| `12345` | 12345 | romba chinnadhu | None |

Moonu numbers `+919845012345` aagudhu; kadaisi onnu `None` return pannudhu, adhanaala invalid ones-a client-ku list panna mudiyum. Logic functions-la irukkradhaala, adutha vaaram `normalise_mobile`-a innum rendu scripts-lum copy pannaama import pannuraar. Client landline numbers-um accept pannanum-nu kettaa, oru function-a oru idathula maathina podhum.

## Podhuvaa panra thappugal

- **Return pannaama print panradhu.** Caller-kku `None` thaan kidaikkum.
- **Function-a call panna marandhudradhu.** Brackets illaama `gst_amount` edhuvum pannaadhu.
- **Romba velai seira functions.** Ovvonnukkum oru velai-nu varra varaikkum piringa.
- **Veliyila irukkura variables-a nambradhu.** Inputs-a parameters-aa pass pannunga, results-a return pannunga.
- **Mutable defaults**, `def add(item, items=[])` maadhiri. `None` use panni, ullukkulla pudhu list create pannunga.
- **Theliva illaadha peyargal.** `process()`, `do_stuff()` padikkiravanga-ku edhuvum solla maattaanga.
