## Idhu enna

**PyTorch**-na neural networks build panni train panra open-source Python library. Adhoda building blocks:

- **Tensors**: NumPy arrays maadhiri multi-dimensional arrays, CPU illa GPU-la irukkalaam, gradients-a track pannum.
- **Autograd**: tensors-la nadakkura operations-a record panni, gradients-a automatic-aa compute pannum.
- **nn.Module**: models-ku base class; layers-um models-um modules thaan.
- **Dataset**-um **DataLoader**-um: data-va load panni, shuffle panna batches-la tharum.
- **Optimisers**: gradients-la irundhu weights-a update pannum (SGD, Adam).

```flow
CSV of images and labels -> Dataset | __getitem__(i) gives (tensor 3x224x224, label 4)
Dataset -> DataLoader | batches of 64, shuffled, .to(device)
DataLoader -> nn.Module | forward(x) gives scores for 6 classes
nn.Module -> loss_fn -> loss.backward() -> opt.step()
opt.step() -[next batch]-> DataLoader
opt.step() -[each epoch]-> Validate | model.eval() + no_grad(), save the best checkpoint
```

Indha lesson-la Pune-la oru textile manufacturer-la engineer, mudhal PyTorch project-aa fabric-defect classifier build panradha follow pannuvom.

## Idhu eppadi work aagudhu

**Tensors-um devices-um.** Data-la irundhu tensors create pannunga, `.shape`-um `.dtype`-um check pannunga, model-aiyum data-vayum adhe device-ku move pannunga (GPU-ku `"cuda"`, illaina `"cpu"`). Device mismatch beginners-oda top thappu.

**Data.** `Dataset` index-padi oru example-um label-um tharum; `DataLoader` adha batch panni shuffle pannum. Training-layum prediction neraththulayum adhe preprocessing apply pannunga.

**Model.** `nn.Module`-a subclass pannunga, layers-a `__init__`-la, forward computation-a `forward`-la define pannunga.

**Training loop.** PyTorch-oda idhayam:

```python
model.to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(epochs):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()              # clear old gradients
        loss = loss_fn(model(x), y)  # forward pass and loss
        loss.backward()              # backpropagation
        opt.step()                   # update weights

    model.eval()                     # switch off dropout etc.
    with torch.no_grad():            # no gradients needed for evaluation
        val_loss = evaluate(model, val_loader)
    save_if_best(model, val_loss)
```

**Evaluation mode.** `model.eval()` dropout, batch normalisation maadhiri layers-a inference behaviour-ku maathum; `torch.no_grad()` memory-yum neram-um micham pannum. `eval()` marandhaa validation numbers thappaa varum; `no_grad()` marandhaa memory waste aagum.

**Saving.** Model-oda `state_dict`-a (adhoda weights) save pannunga, adha rebuild panna thevaiyaana settings-um preprocessing-um serthu. Kadaisi-a mattum illa, validation score-padi best checkpoint-a save pannunga.

**Reproducibility.** Random seeds set pannunga, settings-um library versions-um log pannunga.

**Higher-level tools.** PyTorch Lightning, fastai maadhiri libraries loop-a logging, checkpoints, multi-GPU support-oda wrap pannum. Wrappers-a debug panna mudiyra maadhiri, mudhalla plain loop-a kathukkonga.

```python
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader

class DefectData(Dataset):
    def __init__(self, rows, label_map, transform):
        self.rows, self.label_map, self.transform = rows, label_map, transform
    def __len__(self):
        return len(self.rows)
    def __getitem__(self, i):
        path, label = self.rows[i]
        return self.transform(load_image(path)), self.label_map[label]

class SmallNet(nn.Module):
    def __init__(self, classes=6):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(32, classes)
    def forward(self, x):
        return self.head(self.body(x).flatten(1))
```

`label_map` oru thadavai build panni, training-layum validation datasets-layum rendukkum pass pannuvaanga, worked example-ku thevaipatta fix idhu thaan.

**Pogum podhae shapes-a check pannunga.** Neraya PyTorch errors shape errors. Training-ku munnaadi oru batch-a model vazhiyaa anuppi, ovvoru layer-kku aprom shape-a print pannunga. 224 pixels-la 64 colour images-oda batch-oda shape `[64, 3, 224, 224]`, model-oda output `[64, 6]` aaganum. Error-la "mat1 and mat2 shapes cannot be multiplied"-nu vandha, oru layer edhir paartha inputs-a vida vera ennikkai-ya kaiyaaldhu-nu artham.

**GPU use panradhu.** `torch.cuda.is_available()` check panni, script-oda mela `device = "cuda" if torch.cuda.is_available() else "cpu"` oru thadavai set pannunga, apram ellaa idathulayum `device` use pannunga. Google Colab illa Kaggle notebooks-la free GPUs indha path-la irukkura projects-ku podhum. GPU ovvoru layer-la irukkura periya matrix multiplications-a, pala neram paththu madangu illa adhukku mela vegamaakkum, aana mella data loading-ku onnum pannaadhu. Loop odum podhu GPU summaa irundhaa, DataLoader-la `num_workers`-a ezhuppunga, appo images parallel-aa read aagi resize aagum.

**Loop-la irundhu palakkam varaikkum.** Loop-a oru thadavai kaiyaala ezhudhi, template-aa vechukkonga: mela seeds-um device-um, datasets-um loaders-um, model, optimiser, loss, apram validation-um checkpoint saving-um irukkura epoch loop. Perumbaalum pudhu projects-la dataset-um model-um mattum thaan maarum.

**Muzhusaa, odakkoodiya oru training script.** Synthetic tabular data, adhanaala enga venumnaalum CPU-la odum; unga sondha `Dataset`-a poduingga:

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader, random_split

torch.manual_seed(0)
device = "cuda" if torch.cuda.is_available() else "cpu"

N, D, C = 6000, 20, 3
X = torch.randn(N, D)
true_w = torch.randn(D, C)
y = (X @ true_w + 0.5 * torch.randn(N, C)).argmax(1)

mean, std = X.mean(0), X.std(0)                      # save these with the model
ds = TensorDataset((X - mean) / std, y)
train_ds, val_ds = random_split(ds, [5000, 1000], generator=torch.Generator().manual_seed(0))
train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
val_dl = DataLoader(val_ds, batch_size=512)

model = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C)).to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
loss_fn = nn.CrossEntropyLoss()

def evaluate():
    model.eval(); correct = total = 0; loss_sum = 0.0
    with torch.no_grad():
        for xb, yb in val_dl:
            xb, yb = xb.to(device), yb.to(device)
            out = model(xb)
            loss_sum += loss_fn(out, yb).item() * len(yb)
            correct += (out.argmax(1) == yb).sum().item(); total += len(yb)
    return loss_sum / total, correct / total

best, patience, bad = float("inf"), 5, 0
for epoch in range(100):
    model.train()
    for xb, yb in train_dl:
        xb, yb = xb.to(device), yb.to(device)
        opt.zero_grad()
        loss_fn(model(xb), yb).backward()
        opt.step()
    val_loss, val_acc = evaluate()
    if val_loss < best - 1e-4:
        best, bad = val_loss, 0
        torch.save({"state_dict": model.state_dict(), "mean": mean, "std": std,
                    "epoch": epoch, "val_acc": val_acc, "torch": str(torch.__version__)}, "best.pt")
    else:
        bad += 1
        if bad >= patience:
            break
print(f"stopped at epoch {epoch}, best val loss {best:.3f}")
```

**Thani script-la load panni predict pannunga.** Adhe architecture-a rebuild panni, weights-a load panni, save panna preprocessing-a apply panni, eval mode-ku maathunga:

```python
ckpt = torch.load("best.pt", map_location="cpu", weights_only=True)   # never unpickle untrusted files
model2 = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C))
model2.load_state_dict(ckpt["state_dict"]); model2.eval()
new_rows = torch.randn(5, D)
with torch.no_grad():
    probs = model2((new_rows - ckpt["mean"]) / ckpt["std"]).softmax(1)
print(probs.round(decimals=2), "from epoch", ckpt["epoch"], "val acc", round(ckpt["val_acc"], 3))
```

Prediction neraththula save panna mean-um standard deviation-um marakkuradhu, amaidhiyaa nadakkura romba common bugs-la onnu.

**GPUs-la vegamaa.** Mixed precision (forward pass-a sutthi `torch.autocast(device_type="cuda", dtype=torch.bfloat16)`) kammi memory-ya use panni, modern GPUs-la vegamaa odum, `torch.compile(model)` training-a innum vegamaakkum. Plain loop work aanadhum idha serunga, validation scores maaralanu check pannunga.

**Data loading pala neram bottleneck.** GPU use kammiyaa irundhaa, `DataLoader`-la `num_workers`-a ezhuppunga, data-va vegamaana local disk-la vainga, GPU-la train panra podhu `pin_memory=True` set pannunga.

## Podhuvaa panra thappugal

- **Model-um data-vum vera vera devices-la.**
- **`zero_grad()` marakkradhu.** Batches-kku idaiyila gradients accumulate aagum.
- **Validation-la `model.eval()`-um `torch.no_grad()`-um marakkradhu.**
- **Training-layum prediction-layum vera preprocessing.**
- **Kadaisi epoch-a mattum save panradhu.** Validation-padi best checkpoint-a vechukkonga.
- **Shapes-a print pannaadhadhu.** Oru batch-a model vazhiyaa anuppi shapes-a print panna, error messages padikka aagura oru manineram micham aagum.
- **Preprocessing statistics-a weights-oda save pannaadhadhu.**
- **Validation-padi best illaama, kadaisi epoch-a vechukkradhu.**
- **Correctness-ku munnaadi speed-a optimise panradhu**: mudhalla plain loop-a sariyaa pannunga.
