## Idhu enna

**n8n** ("n-eight-n"-nu sollanum) oru visual editor irukkura workflow automation tool. Oru canvas-la **nodes**-a vachu, arrows-aala avattrai inaikkireenga. Oru **trigger** node ovvoru run-aiyum aarambikkum, adhukku appuram varra ovvoru node-um oru velai seiyum: oru sheet-a padikkum, data-va suththam pannum, oru condition-a vachu branch pannum, oru email anuppum.

Data oru node-la irundhu aduththa node-kku **items**-oda oru list-aa nagarum. Ovvoru item-um oru chinna JSON record, oru spreadsheet-oda oru row maadhiri. Perumbaalaana nodes thangalukku varra ovvoru item-kkum oru thadavai odum. Adhanaala oru trigger moonu pudhu rows-a output panna, adhukku appuram irukkura Gmail node moonu emails anuppum. Indha rule-a nyaabagam vachukkunga, yenna beginners-kku varra perumbaalaana aachariyangal idhula irundhu thaan varudhu.

```flow
title: Shalini-oda admissions workflow
Pudhu form row | Google Sheets trigger -> Tidy enquiry | Edit Fields
Tidy enquiry -> Repeats-a drop pannu | Remove Duplicates
Repeats-a drop pannu -> Course JEE-yaa?
Course JEE-yaa? -[aamaa]-> JEE welcome | Gmail
Course JEE-yaa? -[illa]-> NEET welcome | Gmail
JEE welcome -> Counsellors-kku alert | Telegram
NEET welcome -> Counsellors-kku alert
Edhaavadhu failure -> Error workflow | Shalini-kku message
```

Indha lesson mechanics pathinadhu: n8n-a oda vaikkiradhu, items, expressions, testing, publishing. "n8n-oda automation" lesson idhukku mela AI steps-oda build pannum. Jaipur-la oru coaching institute-la admissions paathukkura Shalini, mela irukkura workflow-a build panradhai neenga follow pannuveenga.

Aarambikkuradhukku munnaadi rendu facts. Mudhalla, n8n **open source illa**. Adhu thannoda sondha **Sustainable Use License**-a use pannudhu, adhu unga sondha internal business-kku, illanna personal, non-commercial use-kku adhai use pannavum maathavum anumadhikkudhu. Panam kudukkura clients-kku workflows build panradhu ok. Clients avangaloda sondha workflows-a adhula build panra maadhiri n8n-a host pannanum-naa, n8n kooda oru commercial agreement venum. Rendaavadhu, **n8n 2.0**-la irundhu, save panradhu (ippo automatic) oru draft-a mattum thaan vachirukkum. Triggers oda **Publish**-a click pannanum. Niraiya pazhaiya tutorials innum oru Active toggle-a kaattudhu.

## Idhu eppadi work aagudhu

### n8n-a oda vaikkiradhu

Ungakitta nadaimuraikku etha moonu choices irukku:

| Option | Eppadi aarambikkuradhu | Enna selavu | Google sign-in | Edhukku best |
| --- | --- | --- | --- | --- |
| n8n Cloud | Free trial-kku sign up pannunga | Trial, November 2026 nilavarappadi: 14 days, Pro features, 1,000 executions; appuram oru paid plan | Oru click, "Sign in with Google" | Unga mudhal workflow, ellaathaiyum vida vegam |
| Unga laptop-la Docker | Oru command, keezha irukku | Free software; laptop on-aa irukkumbodhu mattum thaan odum | Unga sondha Google OAuth client | Kathukka, data-va local-aa vachirukka |
| Vaadagai server-la Docker | Docker Compose | Server vaadagai, koodave unga neram | Unga sondha OAuth client-um oru domain-um | Self-hosted production |

Cloud plans-kku **executions** vachu vilai vaikkiraanga, adhaavadhu muzhu workflow runs, thanithani nodes illa. Yaarukkaavadhu quote panradhukku munnaadi ippodhaiya plans-kku n8n-oda pricing page-a check pannunga.

n8n-a local-aa otta, Docker Desktop-a install pannittu, idhai run pannunga:

```bash
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 \
  -e GENERIC_TIMEZONE="Asia/Kolkata" -e TZ="Asia/Kolkata" \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n
```

`http://localhost:5678`-a open panni owner account-a create pannunga. Container ninnaalum volume unga workflows-aiyum credentials-aiyum vachirukkum. Time zone mukkiyam: adhu illanna, oru self-hosted instance America/New_York-a use pannum, oru "9 am" schedule Indhiya nerappadi saayangaalam fire aagum. Pazhaiya tutorials n8n-a `npx n8n` vachu aarambikkum. November 2026 nilavarappadi early access-la irukkura n8n 3.0 andha vazhiya neekkittu Docker-a mattum thaan support pannudhu, adhanaala Docker vazhiya kathukkunga.

Laptop-oda oru limit: internet-la irukkura apps `localhost`-a reach panna mudiyaadhu. Google Sheets trigger maadhiri **poll** panra triggers innum work aagum, yenna n8n thaan kekkudhu. Oru Webhook maadhiri, oru call-kkaaga wait panra triggers-kku oru public address venum ("Webhooks" lesson-a paarunga).

### Triggers

Ovvoru workflow-um oru trigger-la aarambikkum. Oru workflow-la pala triggers irukkalaam, aanaa ovvoru run-um onnula irundhu thaan aarambikkum.

| Trigger | Eppo fire aagum | Adhukku eppadi theriyum |
| --- | --- | --- |
| Manual | Neenga "Execute workflow"-a click pannumbodhu | Neenga, build pannumbodhu |
| Schedule | Set panna neram varumbodhu | n8n-oda clock, workflow-oda time zone-la |
| Webhook allathu Form Trigger | Innoru app allathu oru aal oru URL-kku data submit pannumbodhu | Udane: anuppuravanga n8n-a call panraanga |
| Google Sheets, Gmail | Oru pudhu row allathu email varumbodhu | Polling: default-aa n8n ovvoru nimishamum check pannum |

Google Forms trigger node-nu onnu kidaiyaadhu. Neenga oru Google Form use panna, adhoda answers oru responses sheet-kku pogum, andha sheet-la varra pudhu rows-la neenga trigger pannuveenga.

Sheets trigger-kku therinjukka vendiya moonu pazhakkangal irukku. Adhu rows-a ennum. Publish pannadhukku appuram mudhal check ethana rows irukku-nnu mattum record pannum, adhanaala pazhaiya responses eppavume fire aagaadhu. Responses sheet-la rows-a delete allathu sort panna count kuzhambidum, adhanaala andha sheet-a thodaama, oru copy-la velai pannunga. Appuram editor-la "Execute workflow"-a click panna, adhu sheet-la irukkura **ellaa** rows-aiyum return pannum, pudhusai mattum illa.

### Nodes

Nodes moonu kudumbangalaa varum:

- **App nodes:** Google Sheets, Gmail, Telegram, Slack, HubSpot, innum noottrukkanakkaanavai.
- **Core nodes:** fields-a rename panni suththam panna **Edit Fields** (Set-num solluvaanga), branch panna **If**, **Switch**, **Remove Duplicates**, rendu inputs-a serkka **Merge**, endha API-kkum **HTTP Request**, chinna scripts-kku **Code**.
- **AI nodes:** classify panna, extract panna allathu draft panna oru language model-a call pannum. Ivai thaan "n8n-oda automation" lesson-oda subject.

### Credentials

Ovvoru app node-kkum oru **credential** venum: OAuth sign-in allathu oru API key moolamaa andha app-kku save panna access. n8n credentials-a encrypt panni store pannum, pala workflows ore credential-a reuse panna vidum. Unga personal admin account-a use panradhai vida, automation-kkunne uruvaakkina, thevaiyaana access mattum irukkura oru account-a use pannunga.

n8n Cloud-la Google credentials oru click thaan. Self-hosted n8n-la, perumbaalaana beginners maattikkira step idhu thaan, yenna neenga unga sondha **OAuth client**-a create pannanum:

1. Google Cloud Console-la oru project create panni, ungalukku thevaiyaana APIs-a enable pannunga. Google Sheets node-kku Sheets API, Drive API rendume venum; Gmail-kku Gmail API venum.
2. OAuth consent screen-a set up pannunga. Google Workspace use panna **Internal**-a therndhedunga, illanna **External**. Oru External app testing-la aarambikkum, adhanaala unga sondha Google account-a oru **test user**-aa add pannunga. Adhu illanna, Google "access denied"-nu kaattum.
3. **Web application** type-la oru OAuth client ID create pannunga. n8n credential screen kaattura **OAuth Redirect URL**-a paste pannunga. Oru laptop-la adhu `http://localhost:5678/rest/oauth2-credential/callback` maadhiri irukkum.
4. Client ID, Client Secret-a n8n-kkulla copy pannittu, Sign in with Google-a click pannunga.

Oru trap: innum testing-la irukkura oru External app-kku, consent-um tokens-um ezhu naalla expire aagum-nu n8n-oda docs echarikkudhu. Oru vaaram kazhichu workflow sheet-a padikkuradhai niruthittaa, credential-a marupadi connect pannunga, illanna app-a testing-la irundhu veliya kondu varradhu pathina Google-oda guidance-a padinga.

### Expressions: current item-um mundhaiya nodes-um

Oru node-oda settings-la, input panel-la irundhu oru field-a drag pannalaam, illanna double curly braces-kkulla oru **expression**-a type pannalaam. Expressions-na JavaScript-oda chinna thundugal.

- `{{ $json.email }}` **current item**-oda email field-a padikkum, indha node-oda direct input paarkkura maadhiri.
- `{{ $json['Phone number'] }}` perla oru space irukkura field-a padikkum. Google Form sheets kelviyoda text-aiye column names-aa use pannum, fields-a seekkirame rename panradhukku idhu oru kaaranam.
- `{{ $('Tidy enquiry').item.json.name }}` "Tidy enquiry"-ngra node-la, indha item endha item-la irundhu vandhucho adhula irundhu name-a padikkum.

Rendaavadhu vadivam paarkkuradhukku theriyuradhai vida mukkiyam. Ovvoru node-um `$json`-a thannoda sondha output-aala replace pannum. Oru Gmail node-kku appuram, `$json`-la adhu ippo anuppina email pathina details irukkum, udhaaranamaa oru message id, student-oda row illa. Adhanaala Gmail-kku appuram vaikkira oru Telegram node mundhaiya node-oda pera sollanum. Nodes-kku thelivaana per vainga, yenna per expression-oda oru pagudhi; oru node-oda pera maathinaa, adhai use panra expressions-a check pannunga.

Innum rendu defaults aalungalai thadukki vidum. **Edit Fields** neenga set panra fields-a mattum thaan output pannum, **Include Other Input Fields**-a on panna thavira, adhanaala neenga marakkura endha field-um kaanaama poyidum. Appuram oru pudhu **If** node text-a case-sensitive-aa compare pannum: **Ignore Case** option-a add panra varai "neet", "NEET"-kku equal illa.

### Pinned data vachu testing

Editor-la irundhu workflow-a otti, ovvoru node-aiyum click panni adhoda input, output-a paarunga. Output thappaa theriyura mudhal node-la irundhu aarambichu, oru thadavaikku oru node-aa problems-a fix pannunga.

Trigger-oda output-a **Pin** pannunga, appo ovvoru test run-um pudhu items-a fetch pannaama adhe sample items-a reuse pannum. Production runs pinned data-va kandukkaadhu. Mela sonna Sheets trigger pazhakkathula irundhum pinning ungalai kaappaathum: 300 pazhaiya responses irukkura oru sheet-la oru unpinned test run, 300 items-aiyum ulla anuppum, Gmail node 300 nija students-kku email anuppidum. Messages anuppura endha node-aiyum connect panradhukku munnaadi, moonu naalu rows-a pin pannunga, illanna trigger-a sheet-oda oru test copy-kku point pannunga.

### Publishing, alerts, duplicates

Ovvoru node-um adhoda tests-la pass aanadhum, **Publish**-a click pannunga. Adhula irundhu trigger thaanaa odum, **executions list** ovvoru run-aiyum adhoda data, edhaavadhu error irundhaa adhoda serthu kaattum. Workflow-a kavanikkaama vittaalum paadhugaappaa irukka innum rendu pagudhigal venum:

- **Oru error workflow.** Oru **Error Trigger** node-la aarambichu ungalukku oru message anuppura oru thani workflow-a create pannunga. Error Trigger-kku fail aana workflow-oda per `workflow.name`-layum, kadaisiyaa odina node `execution.lastNodeExecuted`-layum, error `execution.error.message`-layum, oru link `execution.url`-layum kidaikkum. Adhai publish pannittu, main workflow-oda settings-la **Error workflow**-kku keezha adhai select pannunga. Adhu automatic runs-kku mattum thaan fire aagum, neenga editor-la aarambikkura runs-kku illa, adhanaala venumne break panna oru published workflow vachu adhai test pannunga.
- **Duplicate protection.** Students forms-a rendu thadavai submit pannuvaanga, erkanave fill panna oru pillaikkaaga parents innoru thadavai fill pannuvaanga. **Remove Items Processed in Previous Executions**-kku set panna, **Value Is New**-aa irukkura items-a vachukkura oru **Remove Duplicates** node, mundhaiya runs-la irundhu values-a nyaabagam vachu repeats-a drop pannum. Adhu ore run-kkulla irukkura items-a compare pannaadhu, adhanaala ore poll-la maattina rendu copies-um pass aagum; double-clicks-kku, **Remove Items Repeated Within Current Input**-kku set panna innoru Remove Duplicates-a adhukku munnaadi vainga. Erkanave normalise panna oru value-la dedupe pannunga. "+91 98765 43210", "09876543210" rendum ore phone thaan, aanaa tidy pannadhukku appuram thaan.

```flow
dir: LR
Build -> Awkward samples-a pin pannu -> Run panni inspect pannu -> Fix
Fix -[marupadi test]-> Run panni inspect pannu
Run panni inspect pannu -[ellaam pass]-> Publish -> Executions-a kavani
```

## Oru worked example

Shalini Jaipur-la oru coaching institute-kku admissions paathukkuraanga. Enquiries "Full name", "Phone number", "Email", "Course" kelvigal irukkura oru Google Form vazhiyaa varum. Google ovvoru answer-aiyum oru responses sheet-la oru row-aa ezhudhum, mudhalla oru Timestamp column irukkum. Ippo, counsellors oru naalaikku oru thadavai sheet-a padichu aduththa naal kaalaila students-a call panraanga, sila enquiries miss aagudhu.

Avanga n8n Cloud trial-kku sign up panraanga, adhanaala Google sign-in oru click thaan, appuram idhai build panraanga:

| # | Node | Enna pannum |
| --- | --- | --- |
| 1 | Google Sheets trigger, Row Added | Ovvoru nimishamum responses sheet-la pudhu rows irukkaa-nnu check pannum |
| 2 | Edit Fields, "Tidy enquiry"-nu per | name, phone, email, course-a simple pergaloda set pannum |
| 3 | Remove Duplicates | Mundhaiya oru run-la erkanave paartha phone allathu email-a drop pannum |
| 4 | If | Course JEE-yaa, Ignore Case add panni |
| 5 | Gmail, ovvoru branch-kkum onnu | Brochure link-oda, course-kku etha welcome email |
| 6 | Telegram | Enquiry-a counsellors-oda group-la post pannum |

"Tidy enquiry"-la irukkura fields:

```text
name    {{ $json['Full name'].trim().toTitleCase() }}
phone   {{ $json['Phone number'] ? '+91' + String($json['Phone number']).replace(/\D/g, '').slice(-10) : '' }}
email   {{ $json['Email'].trim().toLowerCase() }}
course  {{ $json['Course'].trim() }}
```

Phone line digits-a mattum vachukkum, kadaisi paththai eduthu +91 serkkum, adhanaala "98765 43210", "+91 9876543210", "09876543210" ellaame "+919876543210" aagum. Trigger oru all-digit cell-a number-aa kudukkalaam-ngradhaala thaan `String()` irukku. Cell empty-aa irundhaa, result empty-aa irukkum, thaniyaa oru "+91" illa. Paththukku kuraivaana digits-oda ezhudhina oru number-a, pinnaadi phone-oda length-a check panra oru If vachaa pidikkalaam; Shalini adhai version two-kkaaga note pannikkiraanga.

Remove Duplicates-la, dedupe panna vendiya value `{{ $json.phone || $json.email }}`. Phone-a mattum vachu dedupe panna, phone-a blank-aa vitta ovvoru student-aiyum ore aalaa ninaichu, mudhal aalai thavira ellaaraiyum drop pannidum.

**Testing.** Shalini awkward-aa irukkanumne therndhedutha naalu sample rows-a pin panni, editor-la irundhu workflow-a otturaanga:

1. **Lower case-la "jee".** Ignore Case add panradhukku munnaadi, indha row NEET branch-kku pochu. Ippo JEE-kku pogudhu.
2. **Phone number illa.** Plan panna maadhiriye phone empty. Aanaa Telegram message "Phone: "-nu adhukku appuram edhuvum illaama vandhuchu. Avanga andha line-a `{{ $('Tidy enquiry').item.json.phone || 'not given, reply by email' }}`-aa maathuraanga.
3. **Telegram-la blank names.** Naalu alerts-layum name empty-aa irundhuchu. Telegram Gmail-kku appuram irukku, adhanaala `$json.name` Gmail-oda output-a padichuttu irundhuchu. Mela irukkura line-la maadhiri "Tidy enquiry"-oda pera sonnadhu ellaa field-aiyum fix pannuchu.
4. **Ore student rendu thadavai,** oru thadavai "98765 43210"-aa, oru thadavai "+91 9876543210"-aa. Remove Duplicates mundhaiya runs-la irundhu varra values-a mattum thaan nyaabagam vachukkum, adhanaala rendu rows-aiyum rendu thanithani runs-la anuppi idhai test panraanga. Rendaavadhu drop aagudhu. Editor runs-um values-a record pannum, adhanaala adhe pinned rows-a marupadi ottinaa ellaame repeats-aa drop aagum. Matha tests-kku, ovvoru rerun-kkum munnaadi node-oda **Clear Deduplication History** operation vachu adhoda memory-a kaali panraanga, endha nija student-um eppavume block aagaama irukka samples-la karpanai numbers-a use panraanga.

**Publishing.** Avanga oru error workflow build panraanga, Error Trigger appuram thanakke oru Telegram, adhai publish panni admissions workflow-oda settings-la select panraanga. Appuram admissions workflow-a publish panraanga. Sheet-la erkanave irukkura rows fire aagaadhu, avangalukku vendiyadhum adhu thaan: andha students-a erkanave call panniyaachu.

Udhaaranamaa, mudhal vaaram ippadi irukku-nnu vachukkuvom. Indha numbers edhai measure pannanum-ngradhukkaana oru illustration, measure panna result illa:

| Measure | Munnaadi | Appuram |
| --- | --- | --- |
| Enquiry-la irundhu welcome email varaikkum | Aduththa naal, kaiyaala | Onnu rendu nimishaththukkulla |
| Enquiry-la irundhu counsellor-oda call varaikkum | Aduththa naal kaalai | Adhe naal, working hours-la |
| Rendu thadavai email pona repeat enquiries | Adikkadi | Aridhu: mundhaiya runs-la irundhu varra repeats drop aagum |
| Silent failures | Kavanikkappadala | Ovvonnum oru link-oda Shalini-kku alert anuppum |

Avanga ethukkura trade-off: nijamaave rendu thadavai enquire panra oru student, udhaaranamaa mudhalla JEE-kku appuram NEET-kku, rendaavadhu thadavai drop aavaanga. Counsellors avangalai paarkkanum-naa, If node-kku munnaadi oru log sheet-a check panni, duplicates-a drop panradhukku badhilaa oru "repeat enquiry" Telegram message-aa anuppalaam.

## Podhuvaa panra thappugal

- **Pin pannaama live responses sheet-la test panradhu.** Sheets trigger-oda oru editor run ellaa row-aiyum return pannum, Gmail node ellaarukkum email anuppum. Samples-a pin pannunga, illanna oru copy use pannunga.
- **`$json`-a replace panna oru node-kku appuram adhai padikkuradhu.** Gmail allathu Telegram-kku appuram, mundhaiya node-oda pera sollunga: `$('Tidy enquiry').item.json`.
- **Neenga set pannaadhadhai Edit Fields drop pannum-ngradhai marakkuradhu.** Aduththa nodes-kku thevaiyaana ovvoru field-aiyum set pannunga, illanna Include Other Input Fields-a on pannunga.
- **Case-sensitive comparisons.** If node-oda Ignore Case option-a add pannunga, illanna tidy panna, lower-case values-a compare pannunga.
- **Tidy panradhukku munnaadi dedupe panradhu, allathu empty-aa irukkakkoodiya oru field-la dedupe panradhu.** Mudhalla normalise pannunga, oru rendaavadhu field-a fallback-aa vainga.
- **Responses sheet-a edit panradhu.** Rows-a delete allathu sort panna trigger-oda row count udainjudum, adhanaala pudhu enquiries miss aagalaam.
- **Publish panradhukku badhilaa save panradhu.** n8n 2.0-la, save panna oru workflow oru draft thaan. Production runs edhuvum theriyalanna, Publish-a click panneengalaa-nnu check pannunga.
- **Error workflow illaadhadhu.** Adhu illanna, fail aana oru run yaaraavadhu tharseyalaa paarkkura varaikkum executions list-la kaathirukkum.
- **Oru self-hosted instance-la time zone-a default-laye vidradhu.** Asia/Kolkata-a set pannunga.

## Practice pannunga

Watch & learn panel-la Kevin Stratvert-oda beginner video-a paarunga, n8n-oda "Build your first workflow" quickstart-a pannunga, appuram keezha link panniyirukkura n8n-oda free N8N101 Essentials course-a edunga.

1. **Ottunga.** Cloud trial allathu mela irukkura Docker command vachu n8n-a start pannunga, oru Google account-a connect pannunga.
2. **Build pannunga.** Oru Google Form uruvaakki Shalini-oda workflow-a build pannunga, illanna unga sondha case-kku onnu: oru trigger, oru Edit Fields node, Remove Duplicates, oru If branch, rendu app actions. Ovvoru node-kkum per vainga.
3. **Udaichu paarunga.** Naalu awkward rows-a pin pannunga: oru lower-case course, oru empty phone, spaces irukkura oru phone, oru repeat. Ovvoru node-oda output-aiyum predict panni, otti, ovvoru failure-aiyum fix pannunga; adhe rows-a marupadi otturadhukku munnaadi Remove Duplicates history-a clear pannunga.
4. **Paadhugaappaa publish pannunga.** Oru error workflow add panni, rendaiyum publish panni, appuram main workflow-a venumne break panni, velai seiyura oru link-oda alert varudhaa-nnu confirm pannunga.

**Mudinjadhu-nnu eppo sollalaam:** ovvoru node-oda input, output-aiyum explain panna mudiyum, executions list-la oru automatic run-a kaatta mudiyum, fail aana oru run-la irundhu vandha alert-a kaatta mudiyum.
