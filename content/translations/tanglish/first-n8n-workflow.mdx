## Idhu enna

**n8n** ("n-eight-n"-nu solluvaanga) oru visual editor-oda workflow automation tool. Canvas-la **nodes**-a vechu, arrows-oda connect pannuveenga. Oru **trigger** node workflow-a start pannum, adhukku apram ovvoru node-um oru vishayam pannum: sheet padikkum, app-a call pannum, data-va maathum, condition-la branch pannum, illa AI model-a call pannum.

Data node-la irundhu node-ku **items** list-aa pogum. Ovvoru item-um oru chinna JSON record, spreadsheet-oda oru row maadhiri:

```flow
Trigger: new sheet row | name "Rohan", phone "98xx", course "JEE" -> Edit Fields: tidy data | phone becomes "+9198xx"
Edit Fields: tidy data -> If: course is JEE?
If: course is JEE? -[yes]-> Gmail: JEE welcome
If: course is JEE? -[no]-> Gmail: NEET welcome
Gmail: JEE welcome -> Telegram: tell counsellors
Gmail: NEET welcome -> Telegram: tell counsellors
```

n8n-oda hosted cloud version-a use pannalaam, illa neengalae Docker maadhiri vazhiyila odikkalaam. Neraya companies data thanga own servers-la irukkanum-nu idhaiyae virumbuvaanga.

Indha lesson Jaipur-la oru coaching institute-la admissions paakkura Shalini, avanga first workflow-a build panradha follow pannum. Mudiyum podhu neengalae onna build, test, publish pannalaam.

## Idhu eppadi work aagudhu

### Triggers

Ovvoru workflow-um oru trigger-la start aagum. Oru workflow-la onnukku mela irukkalaam, aana ovvoru run-um onnula irundhu mattum start aagum. Common-aana-vai:

| Trigger | Eppo fire aagum | Example use |
| --- | --- | --- |
| Schedule | Oru kurippitta neram vandhaa | Dhinamum 9 am-ku daily report anuppradhu |
| Webhook | Vera app oru URL-a call pannaa | Payment app pudhu payment-a report pannum |
| Email (IMAP illa Gmail) | Pudhu email vandhaa | accounts@-ku varra invoices-a process panradhu |
| Form illa Sheets | Pudhu submission illa row vandhaa | Pudhu admission enquiry |
| Manual | "Execute workflow" click pannaa | Build, test panna |

### Nodes

Nodes moonu kudumbam:

- **App nodes:** Gmail, Google Sheets, Slack, Telegram, WhatsApp Business, HubSpot, innum neraya.
- **Core nodes:** edhavadhu API-ku HTTP Request, chinna scripts-ku Code, data maatha Edit Fields (Set-nu-um solluvaanga), branch panna If, Switch, serkka Merge, batches-la process panna Loop.
- **AI nodes:** language model-a call panni extract, classify, summarise, draft pannum, illa agent build pannum.

### Credentials

Ovvoru app node-ukkum oru **credential** venum: andha app-ku saved access, perumbaalum OAuth-la sign in panni illa API key-a paste panni. n8n credentials-a encrypt panni store pannum, workflows-la thirumba use pannalaam. Workflow-ku thevaiyaana access mattum irukkura dedicated account-a use pannunga, unga personal admin account-a illa.

### Nodes naduvula data-va map panradhu

Node settings-la munnaadi nodes-la irundhu endha data use pannanum-nu choose pannuveenga. Input panel-la irundhu oru field-a izhuthu podalaam, illa double curly braces-la oru **expression** ezhudhalaam, udhaaranathukku `{{ $json.email }}` current item-oda email field-ku. Output panel ovvoru node enna produce pannuchu-nu exact-aa kaattum, adhanaala thappugal easy-aa theriyum.

### Testing

Editor-la irundhu sample data-oda workflow-a odikkunga. Ovvoru node-ayum click panni input, output-a paarunga, mapping problems-a oru node oru node-aa fix pannunga. Trigger-oda test data-va **pin** pannunga, appo ovvoru thadavaiyum pudhu email anuppaama, pudhu row serkkaama, muzhu workflow-a thirumba odikkalaam.

### Publishing

Velai seiyyudhu-na, workflow-a **publish** pannunga. (n8n 2.0-ku munnaadi idhu oru Active toggle.) Appuram production triggers thaanaa odum. **Executions list** ovvoru run-ayum, adhoda data-vodayum errors-odayum kaattum.

```flow
dir: LR
Build -> Test with pinned data -> Fix -> Publish -> Watch executions
Fix -[test again]-> Build
```

## Oru example

Shalini Jaipur-la oru coaching institute-oda admissions-a paakkuraanga. Enquiries Google Form-la varudhu, responses oru sheet-ku pogum. Ippo counsellors dhinamum oru thadavai sheet-a paathu, marunaal kaalaila students-a phone pannuvaanga. Avanga first workflow-a build panraanga:

| # | Node | Enna pannum |
| --- | --- | --- |
| 1 | Google Sheets trigger | Responses sheet-la pudhu row serkkum podhu fire aagum |
| 2 | Edit Fields | Spaces-a trim pannum, phone-a +91-oda format pannum, name-a capitalise pannum |
| 3 | If | Course "JEE" illa "NEET"-aa? |
| 4 | Gmail (rendu branches) | Student peyar-oda, brochure link-oda course-ku-ya welcome email anuppum |
| 5 | Telegram | "New JEE enquiry: Rohan Sharma, +91 98xxxxxx45, prefers evening batch"-nu counsellors group-la post pannum |

**Testing.** Moonu sample rows-a pin panni workflow-a odikkuraanga. Rendu sariyaa pogudhu. Moonaavadhula, oru student "jee"-nu lower case-la type pannadhaala, thappaana branch-la poyi NEET email kidaikkudhu. If node-a lower case-la compare panna maathraanga, moonum pass aagudhu.

Kaali phone number-um try panraanga. Telegram message "phone: undefined"-nu varudhu, counsellors-a kuzhappum. Oru default serkkuraanga: "phone not given, reply by email".

**Publishing.** Workflow-a publish panraanga. Marunaal kaalai executions list-la 14 successful runs, counsellors pudhu students-a marunaal illaama, oru mani neram-kulla phone pannaanga.

| Measure | Munnaadi | Appuram |
| --- | --- | --- |
| Enquiry-la irundhu welcome email varra neram | Marunaal, kaiyaala | Oru nimisham-ku kammi |
| Counsellor call varra neram | Marunaal kaalai | Oru mani neram-kulla |
| Miss aana enquiries | Vaaram-ku sila | Mudhal vaaram onnum illa |

## Podhuvaa panra thappugal

- **Happy path-a mattum test panradhu.** Kaali fields, vithiyaasamaana spelling, extra spaces, duplicates-a try pannunga.
- **Credentials-ku unga personal admin account-a use panradhu.** Limited access-oda dedicated account use pannunga.
- **Maarra values-a code-kulla fix pannidradhu.** Email templates, chat IDs, prices-a edit panna koodiya oru edathula vainga.
- **Publish panna marakkaradhu.** Test mode-la mattum odura workflow yaarukkum onnum pannaadhu.
- **Error alert illaama irukkradhu.** Nambradhukku munnaadi, run fail aanaa ungalukku message anuppura error workflow-a serunga.
- **Item counts-a kandukkaama irukkradhu.** Oru node thideernu zero items output pannunaa adhu oru common silent failure; counts-a check pannunga.

## Practice pannunga

n8n-oda quickstart-a pannunga, apram keezha link panni irukkura adhoda N8N101 Essentials course-a pannunga.

1. **Build pannunga.** Oru trigger, kuraindha-patcham oru data-tidying node, oru branch, rendu app actions-oda, pinned test data-vai vechu oru workflow build pannunga.
2. **Udaichu paarunga.** Moonu bad inputs kudunga: oru missing field, vithiyaasamaana spelling, oru duplicate. Ovvonnayum fix pannunga.
3. **Publish pannunga.** Publish panni, konjam real illa simulated runs-ku apram executions list-a check pannunga.

**Mudinjadhu-nu eppo sollalaam:** Unga workflow-la ovvoru node-oda input, output-a explain panna mudiyum, oru successful automatic run-a kaattalaam.
