## Idhu enna

Ungaloda laptop-la work aagura code oru aarambam thaan, mudivu illa. **Project tooling**-na vera yaaravadhu adha run panna, safe-aa maatha, raathiri 2 mani-ku debug panna vaikkura, ungaloda code-a sutthi irukkura ellaamae. Naalu parts romba mukkiyam:

| Part | Edhu tharum | Adhu illaama |
| --- | --- | --- |
| **Oru isolated environment** | Project-oda packages vera edhoda-vum clash aagaadhu | "En machine-la work aagudhu" |
| **pyproject.toml, sensible layout** | Project ellaa idathulayum ore maadhiri install aagum | Edhu eppadi set up pannanum-nu yaarukkum theriyaadhu |
| **pytest tests** | Edhavadhu odacha maatram ship aagradhukku munnaadi sathama fail aagum | Users bugs-a kandupidippaanga |
| **Logging** | Production-la edhavadhu thappaa pona, enna nadandhudhu-nu paakka mudiyum | Guess panradhu |

Idhula ethuvum glamorous illa. Illaama irundhaa ellaamae gavanikkapadum, usually neenga hand over panna oru vaaram-ku apram client-oda engineer-aala.

Indha lesson-la Coimbatore-la oru textile exporter-ku neenga build panna invoice extractor-a, avanga engineer Karthik edukkaradha follow pannuvom. Mudiyum podhu, ungaloda projects-a oru therinjavar README-a mattum padichi set up panni, test panni, debug panna mudiyum.

## Idhu eppadi work aagudhu

### Environments-um lock files-um

Ovvoru project-kum thani virtual environment. `venv` with `pip` illa vegamaana `uv` maadhiri tools oru environment create panni, neenga pin panna versions-a exact-aa install pannum. **Lock file**, example `uv.lock` illa fully pinned `requirements.txt`, ovvoru package-oda exact version-aiyum, ungaloda packages-a sarndhirukkura packages-aiyum serthu record pannum, adhanaala vera machine exact adhe set-a vaangum.

### Layout

Oru Python project-ku common, safe shape:

```text
invoice-extractor/
  pyproject.toml           # name, version, dependencies, tool settings
  uv.lock                  # exact versions of everything
  README.md                # how to set up, test and run
  src/invoice_extractor/   # your package
      __init__.py
      extract.py
      models.py
  tests/                   # pytest tests
      conftest.py          # shared fixtures
      test_extract.py
      fixtures/sample_invoice.txt
```

`src` folder, unga folder-la irundhu mattum work aagura code-a tests thaniyaave import panradhai thadukkum. `pyproject.toml` `setup.py` maadhiri pazhaya files-a maathi, pytest, linters maadhiri tools-oda settings-a oru idathula vaikkum.

### pytest

Oru test-na peyar `test_`-la aarambikkura function, plain `assert` use pannum. pytest ellaathayum kandupidichi run pannum:

```python
def test_total_matches_line_items(sample_invoice):
    inv = parse_invoice(sample_invoice)
    assert inv.total == sum(i.amount for i in inv.items)
```

**Fixtures** tests peyar sollikkekkura shared setup tharum: oru sample PDF, oru temporary folder, oru fake model client. Adhu `tests/conftest.py`-la irukkum.

### Model-a call panra code-a test panradhu

Unit tests-la unmaiyaana model calls romba mella, selavu, ovvoru thadavayum konjam vera answers tharum, adhanaala tests thaanaave fail aagum. Adhukku badhila:

| | Unit tests | Evaluation suite |
|---|---|---|
| Eppo | Fast, ovvoru commit-layum | Mella, oru schedule-la |
| Enna check pannum | Ungaloda parsing, validation, scoring logic | 50-200 examples-oda golden set-la unmaiyaana model |
| Model | Fake client fixed reply tharum | Unmaiyaana model; quality-a score panni neram pogum podhu track pannum |

Ungaloda logic-a fake client-oda test pannunga; model-oda quality-a thaniyaa measure pannunga.

### Logging

Production-la `print` output kaanaama pogum. `logging` module ovvoru message-kum oru **level**, oru neram, adhu vandha module-a tharum, platform logs-a collect panra idathukku anuppum.

| Level | Edhukku |
| --- | --- |
| DEBUG | Developers-ku detail, production-la off |
| INFO | Normal events: oru request handle aachu, oru file process aachu |
| WARNING | Konjam vinodhamaanadhu aana handle aachu: oru retry, oru bad input skip aachu |
| ERROR | Edhavadhu fail aachu, gavanikkanum |

Ovvoru module-kum oru logger, `log = logging.getLogger(__name__)`, start-up-la oru thadava output-a configure pannunga, therinjavar-ku help panra facts-a log pannunga: entha request, entha document, evvalavu neram, enna fail aachu.

### README

Nalla README, oru therinjavar-ku ungakitta onnum kekkaama clone-la irundhu passing tests varaikkum pogum. Adhula exact commands order-la irukkum: environment set up, environment variables set panradhu (real secret values illaama), tests run panradhu, tool run panradhu. Adha ezhudhi, oru fresh folder-la neengalae test pannunga; perumbaalaana READMEs rendavadhu line-laye odanjudum.

## Oru worked example

Coimbatore-la oru textile exporter-ku invoice extractor build pannirukkeenga. Adutha maadham avanga engineer Karthik, ungal illaama adha run panni maintain pannanum.

**Mudhal naal.** Avar repository-a clone panni README-a follow pannuraanga:

```text
uv sync            # installs the exact locked versions
uv run pytest      # 12 passed
```

Lock file neenga test panna versions-a install pannum. Pannendu-la rendu tests:

```python
import pytest

from invoice_extractor.extract import parse_invoice
from invoice_extractor.models import Invoice

def test_total_matches_line_items(sample_invoice):
    inv = parse_invoice(sample_invoice)
    assert inv.total == sum(i.amount for i in inv.items)

def test_rejects_gstin_with_wrong_length():
    with pytest.raises(ValueError):
        Invoice(gstin="33ABCDE1234", total=100, items=[])
```

`sample_invoice`-na `tests/conftest.py`-la oru sinna text file-a load panra fixture, adhanaala unmaiyaana model call thevai illa.

**Oru maadham kazhichu.** Production-la oru invoice fail aagudhu. Log line ippadi irukku:

```text
2026-11-20 10:14:03 WARNING invoice_extractor.extract invoice=INV-8812 pages=3 field=total model_value="12,40,000.00" error="not a number"
```

Indian digit grouping number parser-a odachudhu-nu Karthik udane paakkuraanga. "12,40,000.00"-ku oru test add panni, parser-a sari panni, ella 13 tests-um pass aagudhu-nu paathu ship pannuraanga.

| Tooling illaama | Tooling-oda |
| --- | --- |
| Oru user-oda "sila neram fail aagudhu" | Invoice, field, value-a sollra oru log line |
| Oru fix-a check panna vazhi illai | Fix-ku munnaadi fail aagi, apram pass aagura oru pudhu test |
| Server-la vera package versions | Ellaa idathulayum ore locked versions |
| Karthik ungalukku WhatsApp-la message panraanga | Karthik thaniyaa 20 nimishathula sari pannuraanga |

## Podhuvaa panra thappugal

- **System Python-la install panradhu.** Unga laptop-la work aagum, vera engayum aagaadhu. Eppavum project environment use pannunga.
- **Pin pannaadha versions.** Oru library breaking change release pannum, oru fresh install fail aagum. Lock file-a commit pannunga.
- **Unmaiyaana model-a call panra tests.** Mella, selavu, thaanaave fail aagum. Unit tests-la client-a fake pannunga.
- **Secrets illa personal data-va log panradhu.** API keys, muzhu documents, customer phone numbers-a log pannaadheenga. Adhukku badhila ids, sizes log pannunga.
- **"run main.py"-nu sollra README.** Set up, test, run panna exact commands-a ezhudhi, neengalae test pannunga.
- **Production-la DEBUG logging-a on-la vachirukkradhu.** Disks-a nirappum, data-va leak panna vaaippu irukku.

## Practice pannunga

pytest-oda Get Started page-a padinga, keezha link irukku, apram Python-oda logging tutorial-oda basic section.

1. **Restructure.** Neenga ezhudhina entha script-aiyum `pyproject.toml`, `src` layout, `tests` folder-oda oru project-aa maathunga.
2. **Test.** Aindhu tests ezhudhunga, adhula onnu fixture use pannanum, onnu error raise aagudha-nu check pannanum.
3. **Log.** Ovvoru `print`-aiyum sensible level-la oru logger call-a maathunga, oru failure-a debug panna help panra oru log line add pannunga.

**Mudinjadhu-nu eppo sollalaam:** Repository-a oru friend-kitta kuduthu, README-la irundhu rendu commands-la tests-a run panna vachi, ellaam pass aagudhu-nu paakka mudiyum.
