## Idhu enna

Oru application-la prompt-um code thaan. **System prompt**-la ellaa requests-kum common-aana standing instructions irukkum: model-oda role, task, rules, output format, examples. **User message**-la indha request-ku mattum specific input irukkum. Nalla prompt design neenga try pannina oru input-la mattum illa, aayirakkanakkaana vera vera inputs-layum results-a thelivaa, consistent-aa, test panna mudiyura maadhiri aakkum.

```flow
System prompt | ovvoru request-kum orey maadhiri, versioned file: role, audience, task, context (price list, timings, policies), rules ("theriyalainaa sollitu hand over pannunga"), output format, length, 2-3 vera vera examples -> Model
User message | ovvoru request-layum maarum: customer-oda message, data-aa eduthukkum -> Model
Model -> Reply -> Unga test set-aala check aagum
```

System prompt maaraama versioned-aa irukkum; user message mattum oru request-la irundhu adutha request-ku maarum.

Indha lesson Chennai-la oru phone-repair chain, oru-line prompt-a nooru kanakkaana real messages-la work aagura prompt-aa maathura vidhathai follow pannum.

## Idhu eppadi work aagudhu

**System prompt-la enna podanum.**

- *Role, audience*: "Chennai-la oru mobile phone repair chain-oda customers-oda questions-ku badhil solreenga."
- *Task*: ovvoru input-kum enna pannanum.
- *Context*: model-ku thevaiyaana facts (policies, product names, tone guidelines).
- *Rules*: enna pannanum, enna pannakkoodaadhu, theriyaadhappo enna pannanum ("Kelvi repairs pathi illaina, repairs-ku mattum help panna mudiyum-nu sollunga").
- *Output format*: exact structure, length, language.
- *Examples*: onnu mudhal moonu worked input-output pairs.

Secrets-a prompts-la podaadheenga; users sila neram model-a avatrai veliya solla vachchiduvaanga.

**Specific-aa irunga, yen-nu explain pannunga.** "Customers phones-la padikkaradhaala answers 80 words-ku kulla irukkanum" "be concise"-a vida nalla work aagum. Models kaaranangala nallaa follow pannum.

**Descriptions-a vida examples better.** Oru nalla example tone, length, format, edge-case handling-a orey neraththula kaattum. Vera vera examples use pannunga, oru tricky case-um sethu, appo model oru example-a romba appadiye copy pannaadhu.

**Neenda prompts-a structure pannunga.** Instructions, context, examples-ku clear sections illa tags use pannunga, appo model ovvonnayum pirichu paakkum. Neenda reference documents-a kelvi-ku munnaadi podunga.

**Data-va instructions-la irundhu piringa.** User kuduththa text-a clear-aa mark pannunga ("Customer-oda message keezha irukkura tags-kku naduvula irukku"), appo adhukkulla irukkura instructions data-vaa eduthukkum.

**Neraya inputs-la test pannunga.** Oru example-la work aagura prompt matha-vatrula perumbaalum fail aagum. Kashtamaana, vichithiramaana inputs-um sethu 20-la irundhu 50 realistic inputs set-a build pannunga, ellaathaiyum odunga, failures-a padinga, onnu maathunga, thirumba odunga. Idhu thaan evals-oda aarambam.

**Prompts-a version pannunga.** Avatrai version control-la irukkura files-la vechchirukkunga, code-la pala idangalla paste pannaadheenga.

**Prompt improvement loop:**

| Round | Maatram | 50 test messages-la pass count |
| --- | --- | --- |
| 0 | "Customer-ku politeaa reply pannunga." | 18 |
| 1 | Role, facts, price list serthaanga | 31 |
| 2 | Rules serthaanga: list-la illaadha prices illa, rival shops illa, language matching | 39 |
| 3 | Format-um 60-word kaaranamum serthaanga | 42 |
| 4 | Rendu examples serthaanga | 44 |
| 5 | Water-damage rule-um example-um serthaanga | 47 |

Ovvoru round-layum onnu mattum maathunaanga, adhanaala edhu help pannichu-nu team-ku theriyum. Oru maatram pass count-a kuraichaa, adha revert pannaanga. Indha discipline thaan prompt velaiya guess panradhaa illaama engineering-aa aakkudhu.

**Clear sections irukkura prompt.** Tags, edhu enna paagam-nu model-ku theliva kaattum, neenga orey thadava oru paagathai mattum maathavum easy-aa irukkum:

```python
SYSTEM = """<role>
You answer WhatsApp questions from customers of Fixit, a phone repair chain in Chennai.
</role>

<facts>
Shops: T. Nagar, Velachery, Anna Nagar. Open 10 am to 8 pm, closed Tuesdays.
{price_list}
</facts>

<rules>
- Quote only prices in the price list. If a repair is not listed, say a technician will call.
- Never mention other shops.
- Reply in the customer's language (English, Tamil or Tanglish).
- Keep replies under 60 words, because customers read on phones.
- Water damage: never promise a fix; ask them to bring the phone in, switched off.
</rules>

<examples>
Customer: screen change for redmi note 12 how much
Reply: A Redmi Note 12 screen replacement is ₹2,400 and takes about an hour. Visit any Fixit shop, 10 am to 8 pm, except Tuesdays.
</examples>"""

def build_messages(customer_text):
    return [{"role": "user", "content": f"<customer_message>\n{customer_text}\n</customer_message>"}]
```

**Prompt-a code maadhiri test pannunga.** Ovvoru test message-aiyum odunga, code-la properties-a check pannunga, pass count-a print pannunga:

```python
import re

PRICES = {"2,400", "1,800", "3,200", "650"}                # every price in the list
TAMIL = re.compile(r"[஀-௿]")

def check(customer_text, reply):
    problems = []
    if len(reply.split()) > 60:
        problems.append("too long")
    for amount in re.findall(r"₹\s?([\d,]+)", reply):
        if amount not in PRICES:
            problems.append(f"unlisted price ₹{amount}")
    if TAMIL.search(customer_text) and not TAMIL.search(reply):
        problems.append("did not reply in Tamil")
    if re.search(r"\b(other shop|competitor)\b", reply, re.I):
        problems.append("mentioned another shop")
    return problems

def run(cases, generate):
    failures = {c: p for c in cases if (p := check(c, generate(c)))}
    print(f"{len(cases) - len(failures)}/{len(cases)} passed")
    return failures
```

Code checks perumbaalaana rule breaks-a free-aa pidikkum. Reply kelvi-ku sariyaa badhil sonnadhaa maadhiri, code-aala paakka mudiyaadha qualities-ku mattum model judge vechchirukkunga.

**Periya tasks-a steps-aa piringa.** Classify panni, price lookup panni, reply ezhudhi, adha translate panra oru prompt debug panna kashtam. Pala chinna prompts (classify, apram reply, apram check) ovvonnum test panna easy, simple steps-ku mella-aana models use pannalaam, edhu fail aachu-nu exact-aa kaattum. Cost: adhigam calls-um konjam adhigam delay-um.

**Thevaippadumbodhu reasoning-ku idam kudunga.** Several rules-oda eligibility check maadhiri work out panna vendiya tasks-ku, badhil solradhukku munnaadi reason panna sonnaa accuracy perumbaalum improve aagum. Reasoning models idha thaanaave pannum. Reasoning-a customer paakkura idathula irundhu veliya vechchirukkunga, reasoning-a illa, final answer-a check pannunga.

**Prompts-a versions-oda files-la vechchirukkunga.** Ovvoru prompt-aiyum version peru-oda oru file-aa store pannunga, start-up-la load pannunga, ovvoru request-oda version-a log pannunga. Appo quality kuraindhaa, adhukku kaaranamaana prompt maatrathai trace pannalaam.

## Oru worked example

Chennai phone-repair chain customer WhatsApp messages-ku replies draft panra assistant venumnu virumbudhu.

Mudhal prompt: "Customer-ku politeaa reply pannunga." 30 real messages-la replies neenda-aa irukku, shop kudukkaadha prices-a promise pannudhu, rival brands-oda warranties pathina kelvigalukkum badhil sollidhu.

Improved system prompt (surukkamaa):

- Role: Chennai-la naalu stores irukkura "FixFast Mobiles"-ku staff review panna replies draft pannum.
- Facts: common repairs-ku price list, store timings, parts-ku 90 naal warranty.
- Rules: list-la illaadha price-a eppavum promise pannaadheenga ("inspection-ku apram confirm pannuvom"-nu sollunga); matha shops pathi pesaadheenga; customer-oda language-la reply pannunga (Tamil illa English); staff idha WhatsApp-la anuppradhaala 60 words-ku kulla.
- Format: greeting, answer, next step.
- Rendu examples: English-la oru screen replacement kelvi, Tamil-la oru battery kelvi.

Adhe 30 messages-um 20 pudhusum thirumba odinaa: 50-la 44 drafts onnum illa konjam edits-oda use pannalaam, munnaadi 30-la 11. Aaru failures perumbaalum water damage pathi; team adhukku oru rule-um example-um serthu thirumba odudhu.

**Meedhi irundha aaru failures kathukkuduthadhu.** Failures-a padikka pathu nimishangal aachu, podhuvaana oru prompting tip-a vida adhu useful-aa irundhadhu. Customers water damage-a pala vidhamaa sonnaanga ("phone bucket-la vizhundhuduchu", "mazhaila nanainjuduchu"), model inspection mudhalla thevaippadura oru fault-ku repair prices sonnadhu. Oru rule ("edhaavadhu liquid damage-na, phone-a konduvara sollunga; price eppavum solladheenga") oru example-um perumbaalaanavatrai sari pannichu.

## Podhuvaa panra thappugal

- **Oru example-la test panradhu.** Vera vera set use pannunga, failures-a padinga.
- **Thelivillaadha instructions.** Enna venum, yen-nu exact-aa sollunga.
- **Theriyaadha case-ku rule illaadhadhu.** Badhil context-la illaadhappo model enna pannanum-nu sollunga.
- **Prompts-la secrets.** Passwords, keys-a avvidam podaadheenga.
- **Orey neraththula neraya maatrangal.** Onnu maathunga, thirumba odunga, compare pannunga.

- **Prompt-a rules-aala overload panradhu.** "Never", "always" lines oru page irundhaa model kuzhambum, adhae thanaakku maaru-um. Rules-a kammiyaa, specific-aa, explain pannina maadhiri vechchirukkunga; test set venaam-nu kaattura rules-a eduthudunga.
- **Oru prompt-a rendu moonu inputs-la test panradhu.** Vichithiramaanavai serthu 20-la irundhu 50 vara set use pannunga.
- **Pala-step task-ku oru periya prompt.** Pirichidunga, appo ovvoru step-aiyum test pannalaam.
- **Prompts-a code-la pala idangalla paste panradhu**, adhanaala versions vera vera aagidum.

## Prompt velai badhil illaadha idangal

- **Model-ku facts illa**: neenda prompts-ku badhila retrieval illa tools serunga.
- **Pala round-um kavanamaa senjum orey format thappu irundhukitte irukku**: structured output illa fine-tuning sari pannalaam.
- **Task-ku exact logic thevai**, tax calculations maadhiri: adha code-la pannunga, model result-a explain pannattum.
- **Gains thadai pattirukku**: moonu rounds-um oru pass thaan serthaa, bottleneck vera edathula irukku.

## Demo-la irundhu production-ku

- **Prompts-a files-la version pannunga**, ovvoru request-layum version-a log pannunga.
- **Ovvoru prompt maatraththukkum test set-a CI-la odunga**, pull request-la pass count-oda.
- **Orey neraththula oru vishayatha mattum maathunga**, ovvoru version enna sari pannichu-nu oru chinna changelog vechchirukkunga.
- **Model maarumbodhu thirumba test pannunga**, yen-na oru model-ku tune pannina prompts vera onnula veraa nadakkalaam.
- **User text-a clear-aa mark panna tags-kulla vechchirukkunga**, adhu rules-a maatha vidaadheenga.
