## Idhu enna

**Total cost of ownership (TCO)**-na oru system-ku oru kaalaththula aagura ellaa selavum, perumbaalum oru illa moonu varushangal, model bill mattum illa. Oru AI system-ku:

- **Model costs**: API-la tokens, illa self-hosting-ku GPUs (vaangina illa vaadagaiku eduththadhu).
- **Infrastructure**: app-oda compute, databases, vector stores, storage, networking, monitoring, gateways.
- **Makkal**: build panradhu, nadathuradhu, on-call, evaluate panradhu, upgrade panradhu. Perumbaalum romba periya item.
- **Data work**: connectors, pipelines, golden sets label panradhu, documents clean-up.
- **Compliance-um security-yum**: audits, penetration tests, reviews.
- **Change**: model upgrades, re-embedding, providers models-a deprecate pannumbodhu prompt rework.

Point, options-a fair-aa compare panradhu, client-ku nermaiyaana budget-a kudukkradhu.

| Total cost of ownership, varushathukku | Adhula enna irukkum |
|---|---|
| Model | API-la tokens, illa self-hosted-aa irundhaa maadham muzhukka odura GPUs |
| Infrastructure | App compute, databases, vector store, monitoring |
| Makkal | Build, operate, on-call, evals, upgrades: **perumbaalum romba periyadhu** |
| Data | Connectors, pipelines, golden sets, clean-up |
| Compliance | Audits, pen tests, reviews |
| Change | Model upgrades, re-embedding, prompt rework |

```flow
dir: LR
title: Options-a adhe usage-la compare pannunga
Model + infra + makkal + data + compliance + change -> Oru claim-ku cost
Oru claim-ku cost -> Oru claim-oda value-oda compare pannunga
```

## Idhu eppadi work aagudhu

**Usage-la irundhu aarambinga.** Users, oru user-ku naal-ku requests, oru request-ku input-um output-um tokens (traces-la irundhu alandhadhu, oohichadhu illa), varushatha valarchi, peak-um average-um.

**API option.** Oru request-ku cost = input tokens x input price + output tokens x output price, caching discounts, batch discounts, model tiering-kaaga adjust pannitu. Maadha requests-aal perukkunga. Ippo irukkura price lists-yum independent comparisons-yum use pannunga; prices adikkadi maarum, perumbaalum kuraiyum.

**Self-hosted option.** Peak load-ku headroom-oda thevaippadura GPUs (load tests-la irundhu), x oru manineraththukku price illa amortised purchase, busy-aa irundhaalum illaadhaalum maadham muzhukka odum. Adhoda, nadathi, monitor panni, upgrade panna engineering neram, open model weak-aa irundhaa quality gap-yum serunga.

**Sensitivity.** Usage estimate-la paadhiyaa illa irandu madangaa irundhaa, output length valarndhaa, illa prices 30% kuraindhaa cost eppadi nagarum-nu kaattunga. Orae oru exact usage level-la mattum artham varra mudivugal asingamaanavai.

**Unit economics.** Result-a client-ku mukkiyamaana unit-ku solrunga: oru resolved ticket-ku, oru process aana claim-ku, oru employee-ku maadhathukku cost. Adha value-oda compare pannunga: save aana manineram, vegamaana processing, kuraivaana thappugal.

**Oru page-la comparison (example figures):**

| Maadhathukku item | Option A: avanga cloud-vazhiyaa API | Option B: self-hosted open model |
| --- | --- | --- |
| Model | Caching-um tiering-um aprom sumaar ₹6.5 lakh | Naalu GPUs-ku sumaar ₹10 lakh |
| Infrastructure | Sumaar ₹1.2 lakh | Sumaar ₹1.5 lakh |
| Makkal | Oru engineer-oda oru sirusaana pagudhi | Sumaar 1.5 engineers, sumaar ₹3 lakh |
| Evals-la quality | Baseline | 2 points kammi |
| Varusha total | Sumaar ₹1 crore | Sumaar ₹1.75 crore |

**Sensitivity, nadaimuraiyila.** Rendu options-aiyum, alandha usage-la paadhi-yilum irandu madangilum, outputs irandu madangu neelamaa irundhaalum, API prices 30% kammiyaa irundhaalum thirumba kanakku pannunga. Crossover point-a ezhudhi vechukkunga, self-hosting cheaper aagura usage. Inga adhu sumaar ippo irukkura volume-oda moonu madangu. Andha oru number, oru vivaadhatha oru review trigger-aa maathum: "maadha requests 3 million-a thaandinaa thirumba paarunga".

**Value pakkam.** Cost mattum oru system-a justify panna mudiyaadhu. Adha pilot-la irundhu varra value-oda jodi pannunga: oru task-ku save aana nimishangal x maadhathukku tasks, thavirkkapatta thappugal, customers-ku vegamaana turnaround. Cost-yum value-yum oru unit-ku pakkam pakkamaa vechunga, appo leaders bill mattum illa, margin-a paakkalaam.

**Thirumba ottalaam-na oru cost model.** Assumptions-a oru idathula vechukkunga, ovvoru price-yum check pannina date-oda:

```python
PRICES = {"checked": "2026-11-08", "usd_to_inr": 84,
          "in_per_m": 3.0, "out_per_m": 15.0, "cache_read_ratio": 0.1,      # USD per million tokens
          "gpu_hour_inr": 250, "engineer_month_inr": 250_000}

def api_month(requests, in_tok, out_tok, cached_share=0.5, small_share=0.0, small_ratio=0.25):
    p = PRICES
    per_req_usd = (in_tok * (1 - cached_share) * p["in_per_m"] + in_tok * cached_share * p["in_per_m"] * p["cache_read_ratio"]
                   + out_tok * p["out_per_m"]) / 1e6
    blended = per_req_usd * (1 - small_share + small_share * small_ratio)       # share sent to a cheaper model
    return requests * blended * p["usd_to_inr"]

def self_host_month(gpus, engineers=1.5, infra_inr=150_000):
    p = PRICES
    return gpus * p["gpu_hour_inr"] * 730 + engineers * p["engineer_month_inr"] + infra_inr

def table(base_requests, in_tok=3000, out_tok=400, gpus=4):
    print(f"prices checked {PRICES['checked']}")
    for label, mult in [("half usage", 0.5), ("measured", 1), ("double usage", 2)]:
        a = api_month(base_requests * mult, in_tok, out_tok, small_share=0.4) + 0.3 * PRICES["engineer_month_inr"]
        s = self_host_month(gpus if mult <= 1 else gpus * 2)
        print(f"{label:<13} API ₹{a/1e5:6.1f} lakh   self-hosted ₹{s/1e5:6.1f} lakh")

table(base_requests=600_000)
```

Traces-la irundhu client-oda unmaiyaana usage-yum ippo irukkura quotes-yum maathunga. Print aagura date, prices eppo unmaiyaa irundhana-nu ellarayum nermaiyaa vechirukkum.

**Crossover-a kandupidinga.** Self-hosted line API line-ku keezha pora varaikkum usage-a yetthunga:

```python
def crossover(in_tok=3000, out_tok=400, gpus_per_million=2):
    for r in range(100_000, 20_000_001, 100_000):
        gpus = max(1, round(r / 1e6 * gpus_per_million))
        if self_host_month(gpus) < api_month(r, in_tok, out_tok, small_share=0.4):
            return r
    return None
```

`gpus_per_million` load test-la irundhu varanum, oohichu illa. Crossover edhirpaakkura usage-ku romba mela irundhaa mudivu easy; kitta irundhaa, usage valara valara thirumba paakka plan pannunga.

**Ovvoru line-yum ennunga.** Tokens-yum GPUs-yum thaandi: embeddings-um re-embedding-um, vector database, tracing-um log storage-um, evaluation runs (judge calls serndhu perusaagum), staging environments, security reviews, system-a nadathi, monitor panni, improve panra makkal. Makkal-a vittudradhu indha comparisons-la romba common thappu.

**Cost-a value-oda jodi pannunga.** Ovvoru velai unit-kum, alandha value-va cost pakkam vechunga: save aana nimishangal x loaded staff cost per minute, thavirkkapatta thappugal, vegamaana turnaround. "Oru ticket-ku ₹4 AI cost, ₹60 staff neram save aachu" maadhiri oru-line ratio thaan decision-makers-ku gyabagam irukkum.

## Oru worked example

Kolkata-la oru insurance company, 2,000 staff-ku oru claims-document assistant-a roll out panna plan pannudhu. Pilot-la alandhadhu: oru user-ku oru velai naal-ku 25 requests, oru request-ku 3,000 input tokens (perumbaalum retrieved passages), 300 output tokens. Idhu maadham sumaar 1.1 million requests.

**Option A, avanga cloud-vazhiyaa API.** Example-kaaga 1,000 input tokens-ku ₹0.25, 1,000 output tokens-ku ₹1.00-la: (3 x 0.25) + (0.3 x 1.00) = oru request-ku ₹1.05, maadham sumaar ₹11.5 lakh. Maaraadha system prompt-la prompt caching-um, simple lookups-a sirusaana model-ku tiering-um sernthu adha sumaar ₹6.5 lakh-ku kondu varudhu. Infrastructure ₹1.2 lakh. Operations-ku oru engineer-oda neramla oru pagudhi.

**Option B, self-hosted open model.** Load tests peak load-ku moonu GPUs-um oru spare-um-nu kaattudhu, example-kaaga oru GPU-ku maadham ₹2.5 lakh-la: ₹10 lakh. Infrastructure ₹1.5 lakh. Serving stack-a nadathura sumaar onnara engineers, maadham sumaar ₹3 lakh. Evals 2 points kammi accuracy-a kaattudhu.

Oru varushathula, A sumaar ₹1 crore, B sumaar ₹1.75 crore. Usage moonu madangu aanaa illa data rules appadi theva-nnaa mattum B jeikkum. Client A-a select pannudhu, volume maadham 3 million requests-a thaandinaa review-oda. Value pakkam: pilot, maadham 40,000 claims-la ovvoru claim-kum 9 nimishangal save aagudhu-nu kaattuchu, sumaar 6,000 staff manineram, selavai vida romba adhigam.

(Inga prices example-kaaga. Model-a build pannra naal-la providers-oda comparisons-oda ippo irukkura prices-a use pannunga.)

| Pilot-la alandhadhu | Value |
| --- | --- |
| Oru claim-ku save aana neram | 9 nimishangal |
| Maadham claims | 40,000 |
| Maadham save aana staff manineram | Sumaar 6,000 |
| Mudivu | Option A, volume maadham 3 million requests-a thaandinaa review |

## Podhuvaa panra thappugal

- **Tokens illa GPUs-a mattum ennuradhu.** Makkal-um change-um selavum perumbaalum adhigam.
- **Token counts-a oohikkradhu.** Unmaiyaana traces-la irundhu alanga; retrieved context input tokens-a perusaakkum.
- **Average-ku size panradhu.** Self-hosted capacity peaks-a cover pannanum; APIs avatra eduthukkum.
- **Price trends-a ignore panradhu.** API prices thodarndhu kuraindhirukku; moonu varusha GPU commitments nallaa vayasaagaama pogalam.
- **Value pakkam illaama irukkradhu.** Miththam aana manineram illa thavirkkapatta thappugal illaama oru cost model edhaiyum justify panna mudiyaadhu.
- **Self-hosted (API-yum) cost-la makkal-a vittudradhu.**
- **Date illaadha prices**, maadhangal kazhichu sappunu pazhasaagiduchu.
- **GPU counts-a oohikkradhu**, load test-la capacity-a alakkaama.

## Vivaramaana cost model thevai illaadha idangal

- **Sirusaana, fixed budget-la oru pilot**: oru spend cap-um vaaraa vaaram bill-a oru paarvaiyum podhum.
- **Unmaiyaana vera vazhi illaama**, ex: data rules on-premises hosting-a force pannaa: choose panna illa, budget-kaaga cost-a model pannunga.
- **Romba sirusaana usage**, cost value-oda oppitta oru rounding error maadhiri irukkum.

## Demo-la irundhu production-ku

- **Cost model-a repository-la vechukkunga**, dated prices-oda, alandha usage-oda.
- **Maadha maadham update pannunga**, traces-la irundhum unmaiyaana bill-la irundhum, vithyaasangala vilakkunga.
- **Ovvoru velai unit-ku cost-a track pannunga**, ovvoru unit-ku value pakkathula.
- **Usage, prices, models maarumbodhu crossover-a thirumba kanakku pannunga.**
- **Ovvoru line-yum serunga**: evals, tracing, storage, staging, makkal.
