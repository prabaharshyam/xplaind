## Idhu enna

Nalla hybrid search kooda query-yum document-um oththu irukkaadhappo fail aagum. Moonu techniques, neenga edhoda search panreenga illa edha thirumba tharreenga-nu maathum:

- **Query rewriting**: oru model user-oda message-a nalla search queries-aa maathum.
- **HyDE** (hypothetical document embeddings): oru model nambura maadhiri oru answer ezhudhum, adhoda neenga search pannuveenga.
- **Parent-child chunks**: precision-kaaga chinna chunks-la search pannuveenga, apram ovvonnum vandha periya section-a model-ku kudupeenga.

Ovvonnukkum cost irukku, usually oru extra model call illa adhigam tokens, adhanaala adhu sari panra problem-a unga golden set kaattina apram mattum onna serkkunga.

```flow
User: "And for senior citizens?" -> Query rewrite with chat history | "FD interest rate for senior citizens"
Query rewrite with chat history -> Optional HyDE for short queries | write a fake answer, embed it
Optional HyDE for short queries -> Search small child chunks | c17, c18, c42
Search small child chunks -> Fetch the parent sections, de-duplicate | section 3.2, section 7.1
Fetch the parent sections, de-duplicate -> Prompt to the model | question + parent sections
```

Indha lesson Delhi-la oru bank-oda internal assistant-a follow pannum, adhu 900 pages circulars-la irundhu staff kelvigalukku badhil solludhu.

## Idhu eppadi work aagudhu

**Query rewriting** pala vidha mosamaana queries-a handle pannum:

- *Follow-ups.* "And for senior citizens?"-nu thaniyaa solla edhuvum artham aagaadhu. Chat history-oda serthu "Fixed deposit interest rate for senior citizens"-aa rewrite pannunga.
- *Compound questions.* "Compare the cancellation rules for Gold and Platinum cards" rendu queries-aagum, ovvoru card-ku onnu, results merge aagum.
- *Jargon gaps.* Users "PF withdrawal"-nu ezhudhuvaanga; documents "provident fund advance"-nu solludhu. Rewrite synonyms serkkalaam, illa moonu phrasings ("multi-query") uruvaakki results-a merge pannalaam.

Oru chinna, vegamaana model idha nallaa pannum. Rewrites-a log pannunga: retrieval fail aana, rewrite thaan kaaranam-aa irukkum.

**HyDE.** Oru kelvi short, kelvi-aa phrase aagiyirukkum; adhukku badhil solra passage neelamaa, statement-aa phrase aagiyirukkum. Avai-oda embeddings dhooram dhooram-aa irukkalaam. HyDE oru model-a oru short, thappaa kooda irukkalaam, answer ezhudha solli, adha embed panni, adhoda search pannum. Poyya answer real passage maadhiri irukkum, adhanaala adhukku pakkathula vandhu nikkum. Queries short-aa, documents formal-aa irukkum podhu romba help pannum. Model-oda guess urudhiyaa topic-ku sambandham illaama irundha kedukkum, ovvoru search-kum munnaadi oru model call-um serkkum.

**Parent-child chunks.** Chinna chunks (100 to 200 tokens) sariyaa match aagum, aana badhil sollradhukku thevaiyaana suthi irukkura context perumbaalum irukkaadhu: rendu paragraph apram irukkura exception, table header. Periya chunks context tharum, aana match mosam. Adhanaala chinna "child" chunks-a index pannunga, ovvonnum adhoda "parent"-oda (section illa page) id-a store pannum. Children-a search pannunga, apram prompt-ku adhoda parents-a eduthu, de-duplicate pannunga. Sometimes sentence-window retrieval-nu solra oru variant, match-oda iru pakkamum konjam sentences-a thirumba tharum.

**Ovvoru technique-oda cost-um benefit-um:**

| Technique | Edha sari pannum | Extra cost | Edhukku route pannanum |
| --- | --- | --- | --- |
| Query rewriting | Follow-ups, compound questions, jargon gaps | Oru chinna model call | Mudhal turn-ku apram varra chat turns; neelamaana illa compound queries |
| Multi-query | Jargon, phrasing gaps | Oru call plus pala searches | Top scores kammi-yaa irukkura queries |
| HyDE | Short, purila queries | Oru model call | Sumaar 8 words-ku kammi irukkura queries |
| Parent-child | Sariyaana match-a suthi context illaadhadhu | Adhigam prompt tokens | Chunks build aana apram ellaa queries-um |

Routing mukkiyam: ellaa technique-aiyum ellaa query-layum odina, ippavae work aagura queries-ku latency-yum cost-um serkkum, gain konjam thaan.

**Code-la rewriting, multi-query, HyDE.** Oru chinna, vegamaana model moonu-aiyum paarthukkum:

```python
import anthropic

client = anthropic.Anthropic()
FAST = "claude-haiku-5-5"                         # check the docs for current names

def ask(prompt, max_tokens=200):
    r = client.messages.create(model=FAST, max_tokens=max_tokens,
                               messages=[{"role": "user", "content": prompt}])
    return "".join(b.text for b in r.content if b.type == "text").strip()

def standalone(question, last_turns):
    history = "\n".join(f"{t['role']}: {t['text']}" for t in last_turns[-4:])
    return ask(f"Rewrite the last question so it makes sense on its own. Reply with the question only.\n\n"
               f"{history}\nuser: {question}")

def variants(question, n=3):
    text = ask(f"Write {n} different ways a bank's policy documents might phrase this question. "
               f"One per line, no numbering.\n\n{question}")
    return [question] + [l for l in text.splitlines() if l.strip()][:n]

def hyde(question):
    return ask(f"Write a short, formal policy paragraph that would answer: {question}", max_tokens=150)

def route(question, history, search):
    q = standalone(question, history) if history else question
    if len(q.split()) < 8:
        return search(hyde(q))                     # short and vague: search with a fake answer
    if " and " in q or " vs " in q or "compare" in q.lower():
        results = [search(v) for v in variants(q)]
        return fuse(results)                       # reciprocal rank fusion, as in the RAG lesson
    return search(q)
```

Original kelvi-ya, ovvoru rewrite-aiyum, edhu route odunadhu-nu log pannunga. Oru answer thappaa pona, rewrite thaan kaaranam-aa irukkum.

**Code-la parent-child.** Children-a `parent_id`-oda store pannunga, children-a search pannunga, parents-a oru thadava mattum thirumba kudunga:

```python
def parent_child(question, search_children, get_parent, k_children=12, k_parents=4):
    seen, parents = set(), []
    for child in search_children(question, k=k_children):
        if child["parent_id"] not in seen:
            seen.add(child["parent_id"])
            parents.append(get_parent(child["parent_id"]))
        if len(parents) == k_parents:
            break
    return parents
```

**Contextual retrieval.** Ingestion-la, ovvoru chunk-aiyum adhoda document-la vaikkura oru, rendu sentences-a ezhudha oru model-a kelunga ("This is from the 2026 FD rates circular, section on senior citizens"), embedding-kum keyword indexing-kum munnaadi adha munnaadi serunga. Anthropic idhoda tests-la failed retrievals sumaar paadhi-a kuraichadhaaga sonnaanga, reranking-oda serthu sumaar moondril rendu pangu. Ovvoru chunk-ku oru call, oru thadava mattum; muzhu document-a cache panna prompt-la vechaa, andha cost romba kuraiyum.

**Ovvoru technique-aiyum adhoda target-la thaniya alakkunga.** Follow-ups, short queries, compound queries-ku recall-a thaniya report pannunga, technique on-layum off-layum. Oru technique clear-aa help panra query types-ku mattum vechukkunga.

## Oru worked example

Delhi bank-oda internal assistant 900 pages circulars-la irundhu staff kelvigalukku badhil solludhu. Golden set moonu failure clusters kaattudhu.

*Follow-ups fail aagudhu.* Home loan prepayment pathi oru kelvikku apram "What about NRIs?" NRI account rules-a tharudhu. Last rendu turns-a use panra oru rewrite step serkkuringa: query "home loan prepayment charges for NRI borrowers" aagudhu. Follow-up questions-la recall at 5, 41%-la irundhu 83%-ku ezhundhudhu.

*Short questions fail aagudhu.* "KYC refresh period?" KYC-a pogaraakkula mattum solra pages-a match pannudhu. HyDE ippadi generate pannudhu: "Customers classified as high risk must update KYC every two years, medium risk every eight years and low risk every ten years." Adhoda embedding, unmaiyaana periodic-update clause pakkathula vandhu nikkudhu. Short queries-la recall at 5, 58%-la irundhu 74%-ku pogudhu. Neelamaana, specific kelvigal-la HyDE edhuvum maathala, adhanaala 8 words-ku kammi irukkura queries-a mattum adhula route panreenga.

*Answers exceptions-a miss pannum.* Sariyaana 150-token chunk kidaikkudhu, aana priority-sector loans-ku irukkura exception adutha paragraph-la irukku, adhanaala answers thappu. Parent-child-ku maaruna (150 tokens children, oru sub-section parents), idhu maadhiri 11 cases-la 9-a sari pannudhu, sumaar 40% adhigam prompt tokens cost-la.

| Failure cluster | Fix | Recall at 5 munnaadi | Aprom |
| --- | --- | --- | --- |
| Follow-up questions | Last rendu turns-oda rewrite | 41% | 83% |
| Short questions | Enmbadhu words-ku kammi queries-ku HyDE | 58% | 74% |
| Miss aana exceptions | Parent-child chunks | 11-la 11 fail | 11-la 2 fail |

## Podhuvaa panra thappugal

- **Ellaathaiyum ore thadavaila serkkuradhu.** Edhu help pannichu-nu theriyaadhu. Onna serunga, alakkunga, vechukkunga illa vittudunga.
- **Conversation illaama rewrite panradhu.** Thaniya rewrite panna follow-up innum artham illaadhadhu thaan.
- **HyDE-oda text-a nambradhu.** Hypothetical answer oru search key mattum thaan. User-kitta kaattaadheenga, final prompt-kullayum vidaadheenga.
- **Romba periya parents.** Muzhu 20-page documents-a thirumba kuduthaa context budget-a oodachu, answer-a pudhaichidum. Parents sections-a irukkanum, files-a illa.
- **Latency-a ignore panradhu.** Retrieval-kku munnaadi rendu extra model calls response time-a rendu madangu aakkalaam. Chinna model use panni alakkunga.
- **Rewrites-a log pannaadhadhu.** Thappaana rewrite, retrieval failure maadhiri theriyum.
- **Ellaa query-kum ellaa technique-aiyum on panradhu.** Query type-padi route panni alakkunga.

## Basic retrieval podhum-nu irukkura idangal

- **Chat history illaadha thani kelvigal**, documents-oda sonda language-la phrase aanavai.
- **Chinna, nallaa structure aana collections**, plain hybrid search ippavae sariyaana passage-a kandupidikkudhu.
- **Tight latency budgets**, search-kku munnaadi oru extra model call romba mella irukkum.

## Demo-la irundhu production-ku

- **Ovvoru request-kum original query, rewrites, route, retrieve aana ids-a log pannunga.**
- **Ovvoru technique-um on-layum off-layum, query type-padi recall alakkunga.**
- **Thirumba kekkura kelvigalukku rewrites-aiyum HyDE outputs-aiyum cache pannunga.**
- **Documents maarum podhu contextual chunk notes-a thirumba odunga.**
- **Extra calls-a latency-layum cost per request-layum budget pannunga.**
