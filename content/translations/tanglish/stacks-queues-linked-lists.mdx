## Idhu enna

Indha moonu structures-um **items eppadi ulla pogudhu, eppadi veliya varudhu** pathi.

**Stack** oru plates kuvyal maadhiri: mela add pannuveenga, melaye irundhu edupeenga. Kadaisiyaa ulla vandhadhu mudhalla veliya varum, idhu **LIFO**. Undo buttons, browser back buttons, programs function calls-a track panra vidham ellaam stacks.

**Queue** oru railway ticket counter line maadhiri: makkal pinnaadi serndhu, munnaadi irundhu pogaanga. Mudhalla ulla vandhadhu mudhalla veliya varum, idhu **FIFO**. Print jobs, customer support tickets, background tasks ellaam queues.

**Linked list** nodes-oda oru chain. Ovvoru node-layum oru value-um adutha node-ku oru pointer-um irukkum. Mathadhai shift pannaama, rendu pointers-a maathi enga venumaanaalum oru node-a add illa remove pannalaam.

| Structure | Eppadi work aagum | Example |
|---|---|---|
| Stack (LIFO) | Mela push, melaye irundhu pop: last in, first out | A, B, C push; pop kudutha C |
| Queue (FIFO) | Pinnaadi enqueue, munnaadi irundhu dequeue: first in, first out | A, B, C enqueue; dequeue kudutha A |
| Linked list | Ovvoru node-layum value-um adutha node-ku pointer-um | 9-ku apram 7 insert: rendu pointers mattum maarum |

## Idhu eppadi work aagudhu

**Stacks**-ku rendu operations thevai: `push` (mela add) and `pop` (melaye irundhu remove). Python-la saadharana list nalla work aagum: `append` push pannum, `pop()` pop pannum, rendumae O(1). Top item-a remove pannaama `peek` pannalaam.

**Queues**-ku `enqueue` (pinnaadi add) and `dequeue` (munnaadi irundhu remove) thevai. Python list mosamaana queue, yen-na `pop(0)` ellaa items-aiyum shift pannum, O(n). `collections.deque` use pannunga, double-ended queue, adhoda `append`-um `popleft`-um rendumae O(1). Threads illa programs naduvula share panra velaikku, queue library illa message queue service use pannuveenga, adha system design track-la paapeenga.

**Linked lists** ovvoru item-aiyum adhoda sondha node object-la vechchu adutha-dhukku point pannum. Neenga already pidichirukkura node-ku apram insert panna, pudhu node-a pazhaya adutha node-ku point panna veinga, pazhaya node-a pudhu node-ku point panna veinga: O(1). Position-padi read panradhu thaan cost. 500-vadhu item-a ethanum-na 500 pointers-a follow pannanum, O(n). Python-la built-in linked list type illa, yen-na lists-um deques-um perumbaalaana thevaiya paathukkum, aanaa idea interview problems-layum matha structures-kulla-yum varum.

| Structure | Add | Remove | Item k read | Edhukku use pannalaam |
|---|---|---|---|---|
| Stack (list) | push O(1) | pop O(1) | top mattum | undo, bracket matching, DFS |
| Queue (deque) | append O(1) | popleft O(1) | front mattum | tasks-a order-la, BFS |
| Linked list | theriyura node-la O(1) | theriyura node-la O(1) | O(n) | adikkadi nadula edit, LRU caches |
| Array (list) | kadaisila O(1) | munnaadi O(n) | O(1) | position-padi read |

**Interviews-la** indha structures matha questions-kulla olinjirukkum. "Most recent", "undo", "nested", "matching pairs" stack-a kaattum. "Vandha order-la", "level by level", "tasks-a fair-aa process pannu" queue-a kaattum. Linked list questions perumbaalum pointer-a kavanamaa kaiyaaludhaanu test pannum: list-a reverse panradhu, slow, fast pointer vechchu middle kandupidikkaradhu, loop detect panradhu. Mudhalla paper-la nodes-um arrows-um varainga; linked list bugs perumbaalum thondra pointers, oru sketch pottirundha pidichirukkum.

## Oru worked example

Ananya Kota-la coaching centres-la use panra maths quiz app-ku oru chinna expression checker build pannraanga. Students `(2+3)*[4-(1+1)]` maadhiri answers type pannuvaanga, app evaluate panna try pannaradhukku munnaadi balance aagaadha brackets irukkura answers-a reject pannanum.

Stack perfect-aa poruthum. Ovvoru opening bracket-um adhukku match aagura closing bracket-aala close aaganum, romba recent-aa thirandhadhu mudhalla close aaganum, idhu LIFO thaan.

```python
PAIRS = {")": "(", "]": "[", "}": "{"}

def balanced(text):
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)                 # push
        elif ch in PAIRS:
            if not stack or stack.pop() != PAIRS[ch]:
                return False                 # nothing to close, or wrong type
    return not stack                         # anything left open?
```

`[(])`-a trace pannunga: `[` push, `(` push, apram `]` `(`-a pop pannum, adhu `[`-oda match aagaadhu, adhanaala `False` return pannum. `{[()()]}`-ku ovvoru pop-um match aagi, stack kaaliyaa mudiyum, adhanaala `True`. Function oru pass thaan edukkum: O(n) time, O(n) space varaikkum.

Adutha, live test-la neraya answers orey neraththula vandhaalum, app submit panna answers-a vandha order-la mark pannanum. Ananya queue use panraanga:

```python
from collections import deque
pending = deque()
pending.append("answer-101")       # enqueue
pending.append("answer-102")
first = pending.popleft()          # "answer-101", O(1)
```

Fairness free-aa kidaikkum: entha student-oda answer-um line-a thaandi pogaadhu.

## Podhuvaa panra thappugal

**list.pop(0)-a queue-aa use panradhu.** Chinna data-la work aagum, neenda neram odumbodhu O(n²) aagum. `deque.popleft()` use pannunga.

**Kaali stack-a pop panradhu.** Kaali list-la `pop()` call pannaa error varum. Bracket checker maadhiri mudhalla `if stack` check pannunga.

**Kadaisi check-a marakkradhu.** `((` maadhiri bracket string-la entha pop-um fail aagaadhu, aanaa adhu balanced illa. Kadaisila stack kaaliyaa-nu epovum check pannunga.

**Palakkathula linked list-a edukkradhu.** Python-la lists-um deques-um kittathatta ellathukkum vegam. Neenga already pidichirukkura nodes-la cheap-aa insert, remove thevai-nu unmaiyaa irundhaa mattum linked list use pannunga.

**Linked list-oda meedhi-a thorakkradhu.** Insert pannumbodhu, pazhaya node-oda pointer-a maathradhukku munnaadi pudhu node-a adutha node-ku point pannunga, illa chain-a vettiduveenga.

**Graph search-la stack-aiyum queue-vaiyum kuzhappikkradhu.** Depth-first search stack (illa recursion) use pannum; breadth-first search queue use pannum. Maathi potta veru traversal varum.
