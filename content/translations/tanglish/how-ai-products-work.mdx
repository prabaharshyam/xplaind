## Idhu enna

Veliyila irundhu paarthaa, oru AI product kelvikku badhil solra chat box maadhiri theriyum. Ulla, adhu sinna parts-oda oru system, adhu thappaa pogum podhu, fix **edhu part** fail aachu-nu poruthu irukkum. Parts-a varaiya theriyura product managers engineers-oda payanulla pechu pesalaam. Theriyaadhavanga ovvoru thadavaiyum "oru nalla model" kekka vendiyadhu thaan.

Language models-la katta perumbaalaana AI products ore parts-a share pannum. Oru request-a avatha vazhiyaa follow pannunga:

```flow
User -> 1 Interface | chat, an in-app button, email, WhatsApp, an API
1 Interface -> 2 Context assembly | system prompt + user input + history
3 Retrieval | search company documents and data -> 2 Context assembly
2 Context assembly -> 6 Guardrails on input | topic limits, personal data, injection checks
6 Guardrails on input -> 4 Model | writes the answer, or asks to use a tool
4 Model -[asks for a tool]-> 5 Tools | look up an order, create a ticket
5 Tools -[result back]-> 4 Model
4 Model -> 6 Guardrails on output | policy rules, format, no promises it can't keep
6 Guardrails on output -> 7 Human checkpoint | review or approve where mistakes are costly
7 Human checkpoint -> Answer to the user -> 8 Evaluation and monitoring | quality, cost, feedback
```

| Part | Enna pannum | Fail aanaa |
| --- | --- | --- |
| **Interface** | User product-a sandhikkura idam | Kuzhappamaana illa maraichuttu irukkura feature |
| **Context assembly** | Instructions, input, history-a serkkum | Model task-a thappaa purinjukkum |
| **Retrieval (RAG)** | Company data-la irundhu poruthamaana facts-a edukkum | Thappaana illa pazhaya answers |
| **Model** | Answer-a uruvaakkum | Kashtamaana tasks-la weak reasoning |
| **Tools** | Model request panra actions | Thappaana action, illa onnume illa |
| **Guardrails** | Input, output-oda checks | Safe illaadha illa policy-ku veliyila replies |
| **Human checkpoints** | Selavaana cases-ku review illa approval | Selavaana thappugal customers-a adayum |
| **Evaluation and monitoring** | Release-ku munnaadi test sets; appuram tracking | Neengala illa, customers problems-a kandupidippaanga |

Indha lesson-la Mumbai-la oru bank-la product manager Ritu-va follow pannuvom, avanga bank-oda assistant oru customer-ku nadakkaadha fee waiver-a promise panna yen-nu trace panraanga. Mudiyum podhu, picture-a vechu, oru answer yen thappu, enna maaranum-nu explain panna mudiyum.

## Idhu eppadi work aagudhu

### Quality engae irundhu varudhu

Thappaana answers perumbaalum naalu idangalla onnula irundhu varum:

1. **Illaadha illa pazhaya information**: retrieval thappaana document-a kandupidichudhu, illa sariyaanadhu illa.
2. **Theliva illaadha instructions**: system prompt indha situation-la enna pannanum-nu sollala.
3. **Task-ku weak-aana model**: nadakkalaam, aana makkal ninaikkura alavukku common illa.
4. **Output-a check pannaama irukkradhu**: user paarkkradhukku munnaadi thappa yaarum pidikkala.

Edhaavadhu thappaa pona, perisaana model kekkradhukku munnaadi edhu part fail aachu-nu kelunga.

### Cost engae irundhu varudhu

Ovvoru request-kum selavu:

- **model tokens**, input (prompt, history, retrieved text), output rendukkum;
- retrieval, tools, infrastructure.

Neelamaana prompts, neelamaana answers selavu adhigam. Perisaana models ovvoru token-kum selavu adhigam. Rendu common savings: prompts-la repeat aagura parts-a **caching** pannuradhu, easy requests-a sinna, selavu kammi models-ku **routing** panradhu.

### Risk engae irundhu varudhu

Confident-aana thappaana answers, check illaama edukkura actions, expose aagura personal data, **prompt injection** (model padikkura documents, emails-kulla maraichu vacha instructions), nyaayam illaadha results. Controls: guardrails, tools-ku permissions, human review, evaluation.

### Prompting, retrieval, illa fine-tuning?

| Approach | Enna maathudhu | Maathuradhukku speed, selavu | Eppo use panradhu |
| --- | --- | --- | --- |
| **Prompting** | Instructions, examples | Vegam, selavu kammi | Behaviour, tone, format |
| **Retrieval (RAG)** | Ovvoru request-kum model paakkura facts | Naduthara | Current illa private information |
| **Fine-tuning** | Training-aala model-oda pazhakkangal | Mella, selavu adhigam | Scale-la oru narrow style illa skill |

Perumbaalaana products prompting, retrieval-la aarambikkum, neraya per fine-tuning-ae thevai padaadhu.

### Agents

Model tool calls-oda oru muzhu sequence-a thaane mudivu pannumbodhu, andha product oru **agent**. Agents flexible, aana predict panna kashtam, adhanaala avatha enna seiyalaam-nu limits, ovvoru step-oda logs, risky actions-ku approvals thevai. Fixed workflows work aagura idathula adha use pannunga, flexibility payan tharura idathula agents.

### Product manager-oda levers

Engineers **eppadi**-nu mudivu pannuvaanga. Neenga **enna, evvalavu nallaa**-nu mudivu pannuveenga:

- user problem, success metric;
- edhu actions-ku approval thevai;
- edhu failures paravaayillai, edhu illa;
- oru request-ku budget;
- evaluation set enna cover pannanum.

## Oru worked example

Ritu Mumbai-la oru bank-oda mobile app-la credit card charges pathi customers-oda kelvikku badhil solra oru feature-ku product manager.

**Complaint.** Assistant oru customer-ku avanga ₹2,500 annual fee waive aagum-nu sonnadhu. Aagala, customer-ku charge pannitaanga.

Ritu-vum engineers-um request-a parts vazhiyaa trace pannuraanga:

| Part | Enna kandupidichaanga | Problem-aa? |
| --- | --- | --- |
| Interface | In-app chat, normal-aa work aagudhu | Illa |
| Context assembly | System prompt bank documents-la irundhu mattum badhil sollunga-nu sonnadhu | Illa |
| Retrieval | Kadandha varushathoda fee-waiver offer-a thandhudhu, adhu expire aagiduchu | **Aama: kaaranam** |
| Model | Kudutha document-la irundhu nermaiyaa badhil sonnadhu | Illa |
| Guardrails | Fees pathi promises-a edhuvum thadukkala | **Aama: illaadha control** |
| Evaluation | Entha test question-um expire aana offers-a pathi illa | **Aama: oru gap** |

**Fixes, part vazhiyaa:**

- **Retrieval:** documents-a adhoda valid-from, valid-until dates vachu filter pannunga, adhanaala expire aana offers varavae varaadhu.
- **Guardrails:** assistant waivers, refunds-a promise pannaama thadukkunga; adhukku badhila, "You may be eligible. Here is how to check,"-nu oru link-oda solludhu.
- **Evaluation:** expire aana, varappora offers-um serthu, 30 fee questions-a test set-la serkkunga.
- **Monitoring:** oru pudhu metric, 10,000 chats-ku thappaana fee information pathi complaints, vaaram review.

Yaarukkum vera model thevai padala. Model-ku enna kudutharanga, yaarum enna check pannala-nu thaan answer thappaa irundhudhu.

## Podhuvaa panra thappugal

- **Ovvoru thappukkum model-a kutram solradhu.** Neraya data, retrieval, illaadha checks-la irundhu varum.
- **Prompt-a secret sauce-nu ninaikkradhu.** Adhu oru part; evaluation-um data-vum adhigam mukkiyam.
- **Oru request-ku cost-a ignore panradhu.** Users virumbura feature scale-la nashtam aagalam.
- **Evaluation set illa.** Adhu illannaa ovvoru change-um oru guess.
- **Default-aa agents.** Fixed workflows work aagura idathula adha use pannunga.
- **Documents-ku owner illa.** Retrieval-oda nalladhu, adhukku pinnaadi irukkura content-oda nalladhu thaan.

## Practice pannunga

Keezha link panni irukkura Chip Huyen-oda "Building a Generative AI Platform"-a padinga, Eugene Yan-oda LLM-based systems katta patterns-a skim pannunga.

1. **Varaiyunga.** Neenga use panra oru AI feature-a pick pannunga, banking chatbot, shopping assistant, email writer maadhiri, adhoda possible parts-a varaiyunga.
2. **Failures-a trace pannunga.** Andha feature-oda moonu possible failures-ku, ovvonnukkum kaaranam-aana part-a, oru fix-a sollunga.
3. **Ungaloda mudivugal.** Adhukku oru product manager edukkavendiya mudivugal-a list pannunga: metric, approval points, paravaayillaadha errors, oru request-ku budget.

**Mudinjadhu-nu eppo sollalaam:** Oru engineer-kitta picture-a vechu, oru answer yen thappu, enna maaranum-nu explain panna mudiyum.
