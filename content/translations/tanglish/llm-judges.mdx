## Idhu enna

**LLM judge**-na oru model-oda output-a grade panna kekkapadura language model: "Indha answer passages-ku faithful-aa irukkaa? Yes illa no, oru reason-oda sollu", illa "Indha reply-a indha rubric vechu 1 la irundhu 5 varaikkum rate pannu". Code checks-aala mudiyaadha idathula, open-ended outputs-a (summaries, explanations, replies) scale-la evaluate panna judges udhavum.

Aana judge-um oru model thaan, adhukkum errors-um biases-um irukku. Adhoda scores-a nambradhukku munnaadi check pannanum.

```flow
Case | oru excerpt-um adhoda summary-yum -> Code checks | word limit 150? citation irukkaa? Exact, free
Case -> Judge | "Support illaadha statements-a list pannu, apram SUPPORTED illa UNSUPPORTED"
Judge -> Calibration | 80 summaries-a rendu lawyers grade pannaanga; judge 74-la othu pogudhu: 92.5%
Calibration -> Indha rubric-ku nambalaam
Judge -> Pairwise tests | A, B-yum B, A-yum kaattunga; consistent verdicts mattum vainga
```

Indha lesson Chennai-la oru legal-tech startup, adhoda judgment summaries-la support illaadha claims irukkaa-nu measure pannradha follow pannum.

## Idhu eppadi work aagudhu

**Narrow, specific rubric ezhudhunga.** Vague scales-a vida ("Indha answer evvalavu nallaa irukku, 1 to 10?") oru neraththula oru clear kelvila ("Answer-la passages support panna claim edhavadhu irukkaa?") judges nallaa seiyuvaanga. Yes illa no, illa sinna labelled scale-a virumbunga, mudhalla oru short reason kelunga.

**Judge-ku thevaiyaanadhai kudunga.** Kelvi, output, reference: faithfulness-ku retrieve panna passages, correctness-ku expected answer, compliance-ku policy.

**Aalgal-oda agreement-a check pannunga.** Oru illa rendu perai ade rubric-la 30 la irundhu 100 outputs-a grade panna vainga. Judge-oda compare pannunga. Agreement kammi-na, disagreements-a padichu rubric-a, examples-a fix pannunga. Judge-oda prompt illa model-a maathinaal, thirumba check pannunga.

**Theriyaadha biases.**

- *Position bias*: rendu answers-a compare panna, judges perumbaalum mudhalla (illa rendavadhu) kaattuna onna virumbum. Positions-a maathi average pannunga.
- *Length bias*: neelamaana, adhiga detail-a irukkura answers nalladhu illaanaalum adhiga scores vaangum.
- *Self-preference*: models thangaloda family-oda outputs-a adhiga rate pannalaam.
- *Leniency*: judges perumbaalum romba generous; clearly bad examples vechu calibrate pannunga.

**Code decide panna mudinjaa code use pannunga.** Exact values, JSON validity, required fields, word limits, citation irukkaa, banned phrases: idhellaam code-la check panradhu nalladhu, adhu free, fast, eppavum consistent.

**Cost.** Judges ovvoru case-kum model calls-a serkkum. Agreement adhigamaa irukkura edathula sinna models use pannunga, judges-a offline-la illa samples-la odunga.

**Biases-um adhoda fixes-um:**

| Bias | Eppadi theriyum | Fix |
| --- | --- | --- |
| Position | Mudhalla kaattuna answer-a adhigam pick pannum | Rendu orders-la odunga; consistent verdicts vainga |
| Length | Neelamaana answers adhiga score | Code-la word limit; length quality illa-nu rubric sollum |
| Self-preference | Thanga family-oda outputs-a adhiga rate pannum | Vera family-oda judge use pannunga, illa aalgalodu check pannunga |
| Leniency | Perumbaalaana outputs pass aagum | Clearly bad examples serunga; verdict-ku munnaadi problems-a kelunga |

**Agreement-a compute panradhu.** Yes-or-no judge-ku, agreement-na judge-um human label-um othu pora cases-oda share. Rate-a mattum illa, disagreements-aiyum paarunga: aalgal fail panra outputs-a judge pass pannina, adhu romba lenient, nijamaana problems thappi pogum. Rendu vagai disagreements-aiyum thani-yaa track pannunga, failures-la adhiga agreement-a nokki pogunga, ennanna adha pidikkathaan eval irukku.

**Judge prompt ezhudhuradhu.** Oru kelvi-a sollunga, reference material kudunga, pass, fail-a oru short example-oda define pannunga, badhil sollradhukku munnaadi evidence-a list panna sollunga. Mudhalla reason kekkura verdicts-a innum consistent-aa aakkum, padikkum podhu disagreements-a purinjukka easy-aa irukkum.

**Judge model-a choose panradhu.** Agreement level set panna mudhalla oru strong model-oda aarambinga, apram ade calibration set-la oru sinna, cheaper model-a try pannunga. Agreement rendu points-kulla irundhaa, routine runs-ku sinnadha use pannunga, spot checks-ku strong-a vainga. Judge-oda model version-a matha dependency maadhiri pin pannunga: oru silent model update scores-a maathalaam, indha maadha numbers-a kadandha maadhathoda compare panna mudiyaama pogum.

**Pipeline-la judges enga varum.** Mudhalla code checks-a odunga, adhula already fail aana outputs-ku judge-a skip pannunga, calls micham aagum. Offline evals-la ovvoru case-kum judge-a odunga, online monitoring-ku live traffic-oda sinna random sample-la odunga. Production-la judge failures-a review queue-ku anuppunga, anga aalgal confirm illa overturn pannuvaanga, confirm aanadha test set-la serunga.

**Code-la oru judge.** Mudhalla evidence-um, kadaisiyaa verdict-um, structured output-aa kelunga, adhanaala verdicts count panna easy, reasons padikka easy:

```python
import json
import anthropic

client = anthropic.Anthropic()
JUDGE_MODEL = "claude-sonnet-5-5"           # pin a dated version where offered
JUDGE_PROMPT = """You check one thing: does the ANSWER contain any claim not supported by the PASSAGES?
Ignore style, length and tone.
PASS example: every number and fact in the answer appears in a passage.
FAIL example: the answer gives a fee the passages never mention.
Reply only with JSON: {"unsupported_claims": [...], "verdict": "pass" or "fail"}"""

def judge(question, passages, answer):
    msg = f"QUESTION:\n{question}\n\nPASSAGES:\n{passages}\n\nANSWER:\n{answer}"
    r = client.messages.create(model=JUDGE_MODEL, max_tokens=400, system=JUDGE_PROMPT,
                               messages=[{"role": "user", "content": msg}])
    text = "".join(b.text for b in r.content if b.type == "text")
    try:
        return json.loads(text)
    except json.JSONDecodeError:
        return {"verdict": "error", "raw": text}       # count these; do not guess
```

Guaranteed shape thevai-na andha lesson-la irundha structured-output features-a use pannunga; mela irukkura fallback kuraindhadhu broken replies-a maraikkaama count pannum.

**Aalgal-oda agreement, code-la.** Ade cases-la judge-um human labels-um compare pannunga, chance-ku correct pannunga:

```python
def agreement(human, judge):
    """Two equal-length lists of 'pass' / 'fail'."""
    n = len(human)
    observed = sum(h == j for h, j in zip(human, judge)) / n
    p_h, p_j = human.count("pass") / n, judge.count("pass") / n
    expected = p_h * p_j + (1 - p_h) * (1 - p_j)
    kappa = (observed - expected) / (1 - expected) if expected < 1 else 1.0
    missed = sum(h == "fail" and j == "pass" for h, j in zip(human, judge))
    return {"agreement": round(observed, 2), "kappa": round(kappa, 2), "failures_missed": missed}
```

Kappa 0.6-ku mela perumbaalum workable, 0.8-ku mela strong. `failures_missed`-la ovvoru case-aiyum padinga: idhu thaan judge thappa vidura problems.

**Judge oru model plus oru prompt.** Edhu maathinaalum, pazhaya-dhoda scores-oda compare panna mudiyaadha pudhu judge. Ovvoru score-kooda judge-oda model version-um prompt version-um store pannunga, edha maathinaalum, pudhu numbers-a nambradhukku munnaadi calibration set-la thirumba odunga.

**Judges-oda vagaigal.** Rubric-oda general model-a thavira, specialised-um irukku: outputs-a score panna train panna reward models, oru check-ku (toxicity, faithfulness) fine-tune panna sinna classifiers, rendu answers-la nalladha pick panra comparison judges. Specialised judges oru narrow velaikku cheaper-aa, innum consistent-aa irukkum; general judges flexible, aarambikka vegam.

**Judges thangalukku thaangale disagree pannum.** Ade judge-a ade case-la rendu thadavai odina, vera verdicts tharalaam. Unga calibration set-la idha measure pannunga; konjam percent-ku mela flip aanaa, rubric-a tighten pannunga, support irundhaa temperature 0 use pannunga, close cases-ku moonu runs-oda majority edunga.

## Oru worked example

Chennai legal-tech startup court judgments-a summarise pannudhu. Summaries-la support illaadha claims irukkaa-nu measure panna virumburaanga.

- Judge prompt: "Idho oru judgment excerpt-um oru summary-yum. Excerpt-la support illaadha summary statement edhavadhu irundhaa list pannu. Apram SUPPORTED illa UNSUPPORTED-nu badhil sollu."
- Rendu lawyers 80 summaries-a grade pannaanga. Judge avangaloda 74-la othu pogudhu (92.5%).
- Thani comparison task-la (rendu summaries-la edhu nalladhu), judge 63% neram edhu mudhalla kaattuchoo adha pick pannuchu. Rendu orders-layum kaattura, consistent verdicts-a mattum count panradhuku maaraanga.
- Judge neelamaana summaries-a adhiga rate pannudhu-nu kandupidichaanga. 150-word limit-ku oru code check-um, length oru quality illa-nu rubric-la oru line-um serthaanga.

Faithfulness judge ippo ovvoru model illa prompt change-kum odudhu, lawyers maadhathuku 20 cases spot-check pannuraanga.

| Kandupidippu | Fix | Result |
| --- | --- | --- |
| Judge 80-la 74-la lawyers-oda othu pochu | Edhuvum thevai illa | Faithfulness-ku nambalaam |
| 63% neram mudhal summary-a pick pannuchu | Rendu orders, consistent verdicts mattum | Fair comparisons |
| Neelamaana summaries-a adhiga rate pannuchu | Code-la 150-word limit; length pathi rubric line | Length-ku ippo reward illa |

## Podhuvaa panra thappugal

- **Aalgal-oda agreement-a check pannaama judge-a nambradhu.**
- **Vague 1-to-10 scales.**
- **Position, length bias-a ignore panradhu.**
- **Code check panna mudiyura vishayathukku judge use panradhu.**
- **Judge-a maathinaalum thirumba check pannaama irukkradhu.**
- **Vera vera judge versions-oda scores-a compare panradhu.** Mudhalla recalibrate pannunga.
- **Parse aagaadha judge replies-a maraikkradhu.** Avangala errors-aa count panni paarunga.
- **Agreement mattum report panradhu**, chance-corrected agreement-a illa missed failures-a illa.

## LLM judge use pannaadha neram

- **Code decide panna mudiyum**: exact values, formats, word counts, required fields, banned phrases.
- **Reference answer irukku, exact-aa match aaganum**, oru number illa category maadhiri.
- **Aalgal poruppu edukkanum-nu high-stakes verdicts**, medical illa legal correctness maadhiri: experts-a use pannunga, judge-a avangaloda review-a prioritise panna mattum.
- **Innum agreement-a check pannala**: pannura varaikkum, judge-oda score oru guess.

## Demo-la irundhu production-ku

- **Judge-oda model, prompt versions-a pin pannunga**, ovvoru score-kooda store pannunga.
- **50 la irundhu 100 human-graded cases-oda calibration set-a vainga**, ovvoru judge change-kum thirumba odunga.
- **Judge error, flip rates-a track pannunga.**
- **Production-la judge failures-a human review-ku anuppunga**, confirm aanadha test set-la serunga.
- **Judge cost-a thani-yaa budget pannunga**, ellathaiyum judge pannaama live traffic-a sample pannunga.
