## Idhu enna

Oru public cloud, computers, storage, networks, ready-made services-a mani neraththukku illa use-kku vaadagaikku tharum. Moonu periya providers, AWS, Microsoft Azure, Google Cloud, vera vera peyar-la, romba orae maadhiri building blocks-a tharaanga. India-la enterprises perumbaalum oru group-wide choice-a follow pannuvaanga; banks-um government-oda sambandham irukkura clients-um Indian regions illa oru specific provider-oda sovereign offering-a kooda kekkalaam.

Ella services-um thevai illa. Oru AI deployment aarum vagai use pannum:

- **Compute**: unga code odura idam.
- **Storage**: files-um documents-um.
- **Databases**: structured data, perumbaalum pgvector-oda PostgreSQL.
- **Networking**: private networks, load balancers, DNS.
- **Identity and access**: yaar enna seiyalaam.
- **Managed AI**: cloud-la irundhu hosted model APIs, data agreements-ku idhu mukkiyam-aa irukkalaam.

```flow
title: Oru Indian region-la, example Mumbai-la, oru virtual network-kulla oru app
Users | company SSO -> Load balancer | HTTPS, public subnet-la
Load balancer -> Serverless containers | app, private subnet-la, least-privilege role-oda
Serverless containers -> Managed PostgreSQL
Serverless containers -> Object storage
Serverless containers -> Managed model API
```

Indha lesson, Hyderabad-la oru pharma company-oda document assistant-a Azure-la design panra neraththula, avangala follow pannum.

## Idhu eppadi work aagudhu

**Regions-um zones-um.** Ovvoru region-kum (India-la provider-a poruthu Mumbai, Hyderabad, Pune, Delhi, vera idangal) pala zones irukku, thani data centres. Resilience-ku instances-a zones-la parappungal. Users-ku latency, data residency rules, adhula edhu models kidaikkum-nu paathu region-a select pannunga.

**Compute choices**, adhigama manage panradhula irundhu kammiya manage panradhu varaikkum: serverless containers (Cloud Run, Azure Container Apps, illa AWS ECS on Fargate, ECS Express Mode serthu; AWS App Runner pudhu customers-ku moodiyaachu) neenga oru image kudutha oru URL kidaikkum; managed Kubernetes (EKS, AKS, GKE) client-oda platform team oru cloud odinaa; GPUs illa muzhu control thevaina virtual machines. Perumbaalaana AI APIs-ku, serverless containers thaan vegamaana, safe-aana start.

**Storage-um databases-um.** Documents-ku object storage (S3, Blob Storage, Cloud Storage). Relational data-kum vectors-kum managed PostgreSQL. Managed services use pannunga: backups, patches, failover ullae irukkum.

**Networking.** Resources private subnets-oda oru virtual network-la irukkum. Databases-ku public address irukkakoodadhu; unga app avangala privately reach pannum. Veliya irundhu varra traffic HTTPS-oda oru load balancer vazhiya varum.

**Identity.** Long-lived access keys-a store panradhukku badhil, ovvoru service-kum thani identity (oru role illa managed identity), adhukku thevaiyaana permissions mattum kudunga. Makkal company-oda single sign-on vazhiya sign in pannuvaanga.

**Managed models.** Ovvoru cloud-um major models-a resell pannum (Amazon Bedrock, Azure OpenAI-oda Microsoft Foundry, Google Vertex AI). Clients idha virumbuvaanga, yenna data avanga ippo irukkura cloud contract, region-kulla irukkum.

**Cost.** Compute, managed databases, veliya pogura data transfer, model tokens thaan perumbaalaana bills. Build panradhukku munnaadi provider-oda pricing calculator use pannunga, mudhal naal-lae oru budget alert set pannunga.

**Orae building blocks, moonu peyar:**

| Building block | AWS | Azure | Google Cloud |
| --- | --- | --- | --- |
| Serverless containers | ECS on Fargate (Express Mode) | Container Apps | Cloud Run |
| Managed Kubernetes | EKS | AKS | GKE |
| Object storage | S3 | Blob Storage | Cloud Storage |
| Managed PostgreSQL | RDS, Aurora | Azure Database for PostgreSQL | Cloud SQL, AlloyDB |
| Service identity | IAM role | Managed identity | Service account |
| Secrets | Secrets Manager | Key Vault | Secret Manager |
| Managed models | Bedrock | Microsoft Foundry (Azure OpenAI) | Vertex AI |

Oru cloud-a sariyaa kathukkunga, apram ippadi oru table vachu matha-vangalukku translate pannunga.

**Oru Indian region-la oru container-a deploy panradhu.** Google Cloud-la, oru command thaniyaa identity-oda, Secret Manager-la irundhu secrets-oda oru private service-a deploy pannum:

```bash
gcloud run deploy claims-api \
  --image asia-south1-docker.pkg.dev/my-project/apps/claims-api:3f9c2e1 \
  --region asia-south1 \
  --service-account claims-api@my-project.iam.gserviceaccount.com \
  --no-allow-unauthenticated \
  --set-secrets MODEL_API_KEY=model-api-key:latest,DATABASE_URL=db-url:latest \
  --min-instances 1 --max-instances 10 --cpu 1 --memory 1Gi
```

`--no-allow-unauthenticated`-na permission irukkura callers mattum (oru load balancer, oru gateway, illa adhu vazhiya sign in panna users) adha reach panna mudiyum. Traffic spike aanaa, `--max-instances` cost-a cap pannum. AWS (ECS on Fargate)-um Azure (Container Apps)-um orae ideas-a vera syntax-la edukkum: oru image, oru region, oru identity, reference vazhiya secrets, scaling limits.

**Mudhal naal-lae oru budget alert.**

```bash
gcloud billing budgets create --billing-account=XXXXXX-XXXXXX-XXXXXX \
  --display-name="claims-pilot" --budget-amount=20000INR \
  --threshold-rule=percent=0.5 --threshold-rule=percent=0.9 --threshold-rule=percent=1.0
```

Ovvoru cloud-kum idhukku equivalent irukku. Alerts-a oru shared channel-ku anuppunga, oruthar inbox-ku illa.

**Unga cloud vazhiya models.** Client-oda cloud vazhiya oru model-a call panna, traffic avanga contract-um identity controls-um kulla irukkum. Anthropic-oda SDK-vula, Bedrock client orae message shape-a use pannum:

```python
from anthropic import AnthropicBedrock

client = AnthropicBedrock(aws_region="ap-south-1")      # uses the service's IAM role, not a key
reply = client.messages.create(
    model="<the model id shown in your Bedrock console>", max_tokens=300,
    messages=[{"role": "user", "content": "Summarise this claim note: ..."}])
```

Data residency promise panradhukku munnaadi, ovvoru Indian region-layum edhu models-um features-um kidaikkum-nu check pannunga; sila vera idangalai vida Indian regions-ku late-aa varum.

**Panam enga pogudhu.** Oru normal AI app-ku, model tokens-um managed databases-um mukkiyam, appuram compute, appuram cloud-la irundhu veliya pogura data transfer. Ovvoru resource-aiyum project-oda environment-oda tag pannunga, bill-a pirikkalaam; mudhal maadhathula vaaram-oru-thadava cost breakdown-a paarunga.

**Default-aa private.** Databases-um vector stores-um public address illaama private networks-la vainga, kidaikkura edathula private endpoints vazhiya model services-a reach pannunga, load balancer illa gateway-a mattum internet-ku expose pannunga.

**Browser-laye try pannunga.** Build panradhukku munnaadi oru maadhathu cloud bill-a estimate pannunga. Inputs-a unga own-aa maathunga.

```python
requests_per_day = 20_000
instance_rupees_per_hour = 6        # one small container instance; check current prices
instances = 2
db_rupees_per_month = 4_000
egress_gb, egress_rupees_per_gb = 50, 8

compute = instance_rupees_per_hour * 24 * 30 * instances
total = compute + db_rupees_per_month + egress_gb * egress_rupees_per_gb
print(f"compute ₹{compute:,}, total ₹{total:,} a month")
print(f"about ₹{total / (requests_per_day * 30):.3f} per request before model costs")
```

## Oru worked example

Azure-la irukkura oru Hyderabad pharma company, avanga regulatory team-ku oru document assistant-a virumbuthu. Requirements: data India-la irukkanum, public database illa, company accounts-oda sign in.

Unga design:

- **Region**: ellaathukkum Central India, company-oda Azure AI agreement vazhiya thevaiyaana model angae kidaikkudhu-nu check pannina apram.
- **Compute**: Azure Container Apps-la unga FastAPI image odum, 1-la irundhu 5 instances varaikkum scale aagum.
- **Storage**: source PDFs-ku Blob Storage; chunks-ku pgvector-oda Azure Database for PostgreSQL, app-oda private network-la irundhu mattum reach panna mudiyum.
- **Identity**: app oru storage container-ku-um database-kum read access irukkura oru managed identity use pannum, stored keys illa. Users Microsoft Entra ID-la sign in pannuvaanga.
- **Cost**: calculator model tokens-ku munnaadi maadham sumaar ₹55,000 estimate pannudhu, tokens-a expected usage-la irundhu thaniyaa estimate panraanga. Budget alert 80%-la set pannirukkaanga.

Client-oda cloud team oru review-layae approve pannum, mukkiyamaa ovvoru choice-um avanga ippo irukkura patterns-ku porundhudhunaala.

| Maadha estimate-oda line | Edhu drive pannudhu | Eppadi kammi pannalaam |
| --- | --- | --- |
| Container Apps | Instances-um odura hours-um | Raathiri oru instance-ku scale pannunga |
| PostgreSQL | Instance size, storage | Sinnadhaa aarambinga; measure panna load-ku scale pannunga |
| Blob Storage | Store panna gigabytes | Pazhaya versions-a archive pannunga |
| Data transfer | Cloud-la irundhu veliya pogura data | Traffic-a region-kulla vainga |
| Model tokens | Requests × tokens | Chinna prompts, caching, easy kelvigala sinna model-ku route panradhu |

**Review yen smooth-aa pochu.** Client-oda cloud team veliya irundhu varra perumbaalaana designs-a, orae moonu points-la reject pannum: public endpoints, stored keys, India-ku veliyila regions. Unga design moonaiyum thavirthudhu, avanga team ippo odikittu irukkura services-a use pannudhu, ovvoru network boundary-yum kaattura oru diagram-oda vandhudhu. Avanga maathina ore vishayam resources-ku oru naming convention.

## Podhuvaa panra thappugal

- **Moonu cloud-a surface-la kathukkiradhu.** Oru cloud-a sariyaa kathukkunga; peyargala vera idathukku translate panna oru naal podhum.
- **Public databases.** Public address irukkura database thaan romba common-aana serious cloud mistake.
- **Code-la long-lived access keys.** Service identities-um short-lived credentials-um use pannunga.
- **Data transfer-um model costs-um ignore panradhu.** Adhu compute-a vida adhigamaagalaam. Estimate pannunga.
- **Latency-ku mattum oru region-a pick panradhu.** Mudhalla residency rules-um model availability-yum check pannunga.

- **Budget alert illa.** Marandhu vitta GPU machine, illa odikittae irukkura loop oru weekend-la lakhs selavu vaikkum. Mudhal naal-lae alerts set pannunga.
- ****Services public-aa reach panna mudiyura maadhiri irukkiradhu**, avanga oru gateway illa load balancer-kku pinnaadi irukkanum.**
- **Maximum instance count illa**, adhanaala traffic spike illa bug bill-a ellai illaama scale pannum.
- **Tag panna resources**, adhanaala edhu project-ku evvalavu-nu yaarukkum theriyaadhu.

## Kammiyaa cloud thevaippadura edathula

- **Oru prototype illa demo**: Vercel, Render, Railway maadhiri platform-um oru hosted database-um vegam.
- **Client ellaathaiyum on-premises-la odikiraanga**: adhukku badhil avanga platform-a kathukkunga.
- **Oru server function-la API key irukkura oru static site**: muzhu virtual network romba adhigam.

## Demo-la irundhu production-ku

- **Regions-a** users-ku, data residency-ku, model availability-ku select panni, yen-nu record pannunga.
- **Service identities-um secret references-um use pannunga**, stored keys illa.
- **Data services-a private-aa vainga**, gateway mattum public.
- **Budgets-um maximum instances-um** mudhal naal-lae set pannunga.
- **Resources-a** project-oda environment-oda tag pannunga, aarambathula vaaram-oru-thadava costs-a review pannunga.
