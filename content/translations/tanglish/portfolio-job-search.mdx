## Idhu enna

**Portfolio**-na, ungalaala indha velaiya seiya mudiyum-ngradhukkaana evidence. AI engineering, FDE roles-ku podhuvaa adhu idhellaam:

- **Oru GitHub profile**, unga moonu mudhal anju sirandha projects-oda aarambikkum, ovvonnukkum thelivaana README irukkum.
- **Case-study write-ups**, onnu illa rendu projects-ku, end-to-end case study maadhiri ezhudhinadhu: problem, numbers, mudivugal, results, enna thappaa pochu.
- **Oru resume**, oru pakkam (anubavam ulla engineers-ku adhigapatcham rendu), kadamaigal illa, results irukkum.
- **Virumbinaa**, chinna demo videos, neenga enna kathukkitteenganu vilakkura sila public posts.

**Job search**-na andha evidence-a sariyaana aalgal munnaadi kondu pora plan.

```flow
title: Oru link, 60 vinaadi: github.com/you
Profile README -> Pin pannadhu: enterprise RAG assistant | "recall at 5: 60 kelvigalla 68%-la irundhu 93%"
Profile README -> Pin pannadhu: approvals irukkura operations agent | "200 test runs-la 0 unapproved actions"
Profile README -> Pin pannadhu: document QA API | "96% field accuracy; oru file-ku 4 s"
Profile README -> Case study: hospital chain capstone | 3 pakkam + 2 nimisha video
```

```flow
dir: LR
title: Search
40 target companies -> 15-la contacts -> Kurippaana notes -> Oru sheet-la track
```

Resume: oru pakkam, kadamaigal illa results, tools context-oda.

Indha lesson, Coimbatore-la irukkura backend developer Nandhini, indha path-a mudichadhula irundhu offers vaangura varai eppadi ponaanganu follow pannum.

## Idhu eppadi work aagudhu

**Job-ku poruntura projects-a thernthedungga.** FDE roles-ku: realistic client problem, kuzhappamaana data, evals, deployment, governance irukkura projects. Indha path-la irukkura aaru stage projects idhukkaagave design pannadhu. Patthu tutorials-a vida, mudichcha moonu nalla projects sirandhadhu.

**Vikkura READMEs.** Ovvoru README-yaiyum problem-a oru vaakkiyathula solli, oru screenshot illa 60 vinaadi video-oda aarambinga. Apram result-a oru number-oda thaanga ("300 real-style documents-la field accuracy 96%; oru file-ku 4 vinaadi"), architecture-a oru chinna diagram-la, eppadi run panradhunnu. Apram vivarangal. Indha repositories-a unga profile-la pin panni, unga case studies-ku link tharra oru profile README serunga.

**Results irukkura resume bullets.** Pattern: action, enna, measure panna mudiyura result. "4,000 pakka insurance policies mela hybrid search, reranking-oda RAG assistant build pannen; 60-kelvi golden set-la retrieval recall at 5-a 68%-la irundhu 93%-ku uyarthinen." AI, cloud, tools-a neelamaana keyword list-aa illaama, context-oda podunga.

**Target companies.** India-la, remote-aavum: enterprise customers irukkura AI labs, AI-first startups, data, AI platform companies, AI teams uruvaakkura periya firms-oda global capability centres, AI practices irukkura IT services, consulting firms. Job posts-a gavanamaa padinga: silathu "forward deployed"-nu solum, mathavai "solutions engineer", "AI engineer, customer-facing", "applied AI engineer"-nu solum.

**Referrals, conversations vaangunga.** Target companies-la irukkura engineers-ku, oru kurippaana note-oda, poruththamaana oru project-oda link-a anuppunga. Neenga use panna open-source tools-ku contribute pannunga. Neenga build pannadhaiyum kathukkittadhaiyum pathina chinna write-ups-a share pannunga.

**Track pannunga.** Applications, contacts, stages, follow-ups-kaana oru elimaiyaana sheet. Niraiya rejections varumnu edhirpaarunga; ovvoru patthu applications-kum edhu badhil vaangudhunnu paarthu materials-a maathunga.

**Balaveenamaana, valuvaana portfolio pagudhigal:**

| Pagudhi | Balaveenam | Valuvaanadhu |
| --- | --- | --- |
| Project | Oru video paarthu oru PDF mela chatbot | Real problem, kuzhappamaana data, golden set, deploy pannadhu |
| README thodakkam | "pip install ..." | Problem, oru visual, oru number-oda result |
| Resume bullet | "Worked on RAG" | "60-kelvi golden set-la recall at 5-a 68%-la irundhu 93%-ku uyarthinen" |
| Outreach note | "Please refer me" | "Unga customers-ku irukkura maadhiri problems-ku X build pannen; link idho" |

**Outreach note ezhudhuradhu.** Naalu vaakkiyathula vechchukonga: neenga yaaru, avanga company-ku poruththamaana oru project, adhoda result, oru kurippaana kelvi illa korikkai, nandri. Udhaaranamaa: "Naan Coimbatore-la irukkura oru backend developer, AI engineering-ku maarikkittu irukken. 300 test files-la 96% field accuracy irukkura oru claims-document assistant build pannen, unga team insurers-ku vikkuradhukku romba kitta. Unga FDE team eppadi velai seiyudhunnu solla ungalukku 15 nimisham irukkumaa? Nandri." Kurippaana notes-ku replies varum; podhuvaana referral korikkaigalukku aridhaa thaan varum.

**Ovvoru patthu applications-kum appuram review panradhu.** Replies, first rounds-a ennunga. Replies kammiyaa irundhaa, resume-oda mela moonula oru pangaiyum, unga READMEs-oda mudhal varigalaiyum maathi ezhudhunga. First rounds mosamaa ponaa, fail aana round-a practice pannunga. Oru neraththula onnai mattum maathunga, appo thaan edhu udhavuchunnu theriyum.

## Oru worked example

Coimbatore-la rendu varusha Java anubavam ulla backend developer Nandhini, indha path-a ezhu maasathula mudikkiraanga.

Avanga portfolio, naalu projects-la ovvonnukkum oru repository-a pin pannudhu, ovvonnukkum mudhal variyilaye oru result irukku. Avai: document QA API, eval report-oda enterprise RAG assistant, approval gates irukkura operations agent, oru karpanai hospital chain-ku-aana capstone. Avanga capstone case study moonu pakkam, rendu nimisha video-oda.

Avanga resume, Java velaiya surukkamaana bullets-aa maathi, numbers-oda oru "Projects" section-a serkkudhu. 40 target companies-a pattiyal pottu, adhula 15-la engineers-a kandupidichchu, ovvoru company-oda customers-kum romba poruththamaana project-a link panni chinna notes anuppuraanga.

Ettu vaaraththula results: 31 applications, 9 replies, 6 first rounds, 3 final loops, 2 offers. Oru offer, hospitals-ku vikkura oru startup-la forward deployed role; capstone case study thaan thanga call-kku kaaranam-nu avanga sonnaanga.

## Podhuvaa panra thappugal

- **Tutorial clones.** Oru video paarthu oru PDF mela kattina chatbot konjamae kaattum. Oru real problem, evals, deployment serunga.
- **Installation-la aarambikkura READMEs.** Problem-aiyum result-aiyum munnaadi vainga.
- **Results-ku badhila kadamaigal.** "Worked on RAG" onnume sollaadhu; numbers sollum.
- **Ore resume-oda ellaa idathukkum apply panradhu.** Ovvoru role-kum mela moonula oru pangai tailor pannunga.
- **"Ready" aagura varai kaathirukkuradhu.** Kadaisi projects-a mudikkumbodhe apply pannunga; interviews edhai improve pannanumnu kathukkodukkum.

## Practice pannunga

GitHub-oda profile READMEs guide-aiyum, Tech Interview Handbook-oda resume guide-aiyum paadinga.

Indha lesson-oda check unga portfolio thaan. Oru GitHub profile README-a publish panni, indha path-la irundhu kurainjadhu moonu projects-a pin pannunga, ovvonnukkum problem, oru visual, oru alandha result-oda aarambikkura README irukkanum. Kurainjadhu naalu result-based bullets irukkura unga resume-a ezhudhunga. 20 target companies-a, ovvonnulayum contact panna oru nabaroda pattiyal podunga.

**Eppo mudinjadhunnu sollalaam:** Oru andhiyarukku oru link anuppi, 60 vinaadikkulla neenga enna build pannineenga, adhu enna saadhichchudhunnu kaatta mudiyum.
