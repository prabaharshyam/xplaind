## Idhu enna

**Portfolio**-na ungalaala andha velaiyai seyya mudiyum-nguradhukkaana evidence. AI engineering, forward deployed engineer (FDE) roles-kku adhula podhuvaa anju pagudhigal irukkum:

- **Oru GitHub profile**, unga best moonula irundhu anju projects-oda aarambikkum, ovvonnukkum thelivaana README irukkum.
- Onnu rendu projects pathina **case-study write-ups**: problem, numbers, decisions, results, edhu thappaa pochu-nnu.
- **Oru resume**, oru page (experienced engineers-kku adhigabatcham rendu), duties illaama results-a list pannum.
- Adhe kadhaiyai solra **oru LinkedIn profile**, yenna niraiya Indian recruiters anga dhaan theduraanga.
- **Viruppappattaa**, chinna demo videos, neenga kathukittadhu pathi sila public posts.

**Job search**-na indha evidence-a sariyaana aalunga munnaadi, sariyaana nerathula, sariyaana sambalathukku kondu pora plan.

```flow
title: Ore link, 60 seconds: github.com/you
Profile README -> Pinned: enterprise RAG assistant | "recall at 5: 68% to 93% on my 60-question golden set"
Profile README -> Pinned: operations agent with approvals | "0 unapproved actions in 200 scripted test runs"
Profile README -> Pinned: document QA API | "96% field accuracy on 300 synthetic files; 4 s per file"
Profile README -> Case study: hospital chain capstone | 3 pages, koodave oru 2-minute video
```

```flow
dir: LR
title: Search eppadi pogum
40 target companies -> 15-la referrals alladhu contacts -> Coding test, interviews -> Fixed pay vachu offers compare -> Notice mudichu join
```

Indha lesson, Coimbatore-la backend developer-aa irukkura Nandhini-a, indha path-a mudikkuradhula irundhu offers-la onnai thernthedukkura varai follow pannudhu.

## Idhu eppadi work aagudhu

### Velaikku yetha projects-a thernthedunga

FDE roles-kku, indha path-la irukkura stage projects maadhiri, realistic client problem, kuzhappamaana data, evals, deployment, governance irukkura projects-a thernthedunga. Pathu tutorials-a vida mudicha moonu projects better, yenna interviewers onnai eduthu arai mani neram adhai pathi kelvi keppaanga.

### Sell panra READMEs

Ovvoru README-yaiyum problem pathi oru vaakkiyam, oru screenshot alladhu 60-second video-la aarambinga. Appuram number-oda result, oru chinna architecture diagram, adhai eppadi run panradhu-nnu kudunga. Indha repositories-a pin pannunga, unga case studies-kku link panra oru profile README serunga.

Oru reviewer test panra maadhiriye neengalum test pannunga. Oru friend-kitta oru project-a clone panni README-a mattum vachu run panna sollunga. 10 nimishathukku mela aanaa, alladhu ungalukku message panna vendi vandhaa, README-a sari pannunga alladhu oru hosted demo serunga.

### Defend panna mudiyura numbers

Unga portfolio-la irukkura ovvoru number-um kelvi kekka oru azhaippu. Interviewers keppaanga: "Idhu edhula alandhadhu? Kaatta mudiyumaa?" Moonu rules-a follow pannunga:

1. **Test set-oda peraiyum size-aiyum sollunga.** "96% field accuracy"-na adhu oru claim. "Naan uruvaakkuna 300 synthetic insurance files-la 96% field accuracy"-na adhu evidence.
2. **Data enga irundhu vandhadhu-nnu nermaiyaa sollunga.** Karpanaiyaana oru hospital chain-kkaana capstone paravaayilla. Adhai "discharge delays-a 30% kuraichudhu"-nu solradhu sariyilla, yenna endha hospital-um adhai use pannala. Neenga enna alandheengalo adhai sollunga: accuracy, latency, oru request-kku cost.
3. **Eval-a run panra maadhiriye vachirunga.** Golden set-aiyum eval script-aiyum repository-laye vainga, kettaa live-aa thirumba run pannalaam.

Neenga explain panna mudiyaadha periya number-a vida, explain panna mudiyura sumaaraana number better.

### Resume, screening software, LinkedIn

**Results-oda bullets.** Pattern: action, neenga enna build panneenga, alandha oru result. Udhaaranamaa: "Built a RAG assistant over 4,000 pages of insurance policies with hybrid search and reranking; raised retrieval recall at 5 from 68% to 93% on a 60-question golden set."

**Mudhal paarvai romba chinnadhu.** 2018-la oru eye-tracking study-la, Ladders-ngura job site, ovvoru resume-vaiyum mudhal thadavai paarkka recruiters sumaar 7.4 seconds selavazhichaanga-nnu kandupidichudhu. Avanga perumbaalum titles, companies, dates-a dhaan paarthaanga. Thelivaana headings ulla simple layouts gavanathai pidichu vachudhu; nerisalaana, multi-column layouts mosamaa pochu. Adhoda sample size sollappadala, aanaa paadam appadiye dhaan: unga results-laye strongest-aanadhai top third-la vainga.

**Applicant tracking systems.** Niraiya employers resumes-a oru applicant tracking system (ATS)-la load panraanga; adhu applications-a store panni, recruiters keyword vachu filter panna vidura software. Two-column templates, images-la irukkura text, icons ellaam kalainju varalaam, adhanaala oru column, standard headings (Experience, Projects, Skills, Education), text-based PDF use pannunga. Job post-la irukkura exact terms-a ("RAG", "LangGraph", "AWS") thirumba solra oru chinna skills line serunga, avai unmaiyaa irukkura varai. Matha idangalla, neelamaana keyword list-kku badhilaa, tools-a unga result bullets-kkulla context-oda vainga.

**LinkedIn.** Unga GitHub profile-la irukkura adhe headline-a use pannunga, udhaaranamaa "Backend engineer building RAG and agent systems for healthcare". Featured section-la oru project-a pin pannunga, unga best rendu results-oda oru chinna About section ezhudhunga. Neenga open to work-nu mark panna LinkedIn vidudhu; venumnaa recruiters-kku mattum theriyura maadhiri vaikkalaam.

### Indian AI jobs enga post aagudhu

| Channel | Edhukku best | Gavanikka vendiyadhu |
| --- | --- | --- |
| Naukri | Volume: IT services, GCCs, periya firms; recruiters adhoda resume database-la theduraanga | Unga profile-aiyum notice period-aiyum update-aa vainga; recruiters rendaiyum vachu filter panraanga |
| LinkedIn | Product companies, GCCs, AI startups; hire panravangalai kandupidikka | Oru post-kku niraiya applications; Apply button-kku mattum illaama contacts-a kandupidikkavum use pannunga |
| Instahyre, foundit | Tech roles (Instahyre); palavidhamaana roles (foundit) | Skills-aiyum expected pay-aiyum gavanamaa fill pannunga; matching adhai vachu dhaan nadakkudhu |
| Wellfound | Startups, early-stage AI startups udpada | Join panradhukku munnaadi funding, runway-a check pannunga |

Titles-a gavanamaa padinga. FDE maadhiri velaiyai "forward deployed engineer", "solutions engineer", "AI engineer, customer-facing" alladhu "applied AI engineer"-nu koopidalaam.

### Referrals, outreach

India-la, oru manushan unga resume-a padikka vaikka referral dhaan perumbaalum fastest vazhi. Niraiya companies employee referral programmes nadathuraanga, adhanaala neenga hire aanaa referrer-kku bonus kidaikkalaam. Adhanaala idhu niyaayamaana request, favour illa. Aanaa referrer ungalukkaaga than perai vaikkuraanga, adhanaala avangalukku sulabamaavum safe-aavum aakkunga:

- **Mudhalla ungalai therinjavangakitta kelunga:** college alumni, pazhaiya colleagues, seniors, open-source projects, meetups-la pazhakkamaanavanga.
- **Ellaathaiyum ore thadavaiyila anuppunga:** job link alladhu ID, unga resume, unga projects-laye romba relevant-aana onnu pathiyum adhoda result pathiyum rendu lines.
- **Theriyaadhavangakitta referral kekkaadheenga, oru conversation kelunga.** Naalu vaakkiyangal: neenga yaaru, relevant-aana oru project-um adhoda result-um, oru kurippaana kelvi, nandri. Udhaaranamaa: "Naan Coimbatore-la oru backend developer, AI engineering-kku maaritu irukken. 300 synthetic test files-la 96% field accuracy irukkura oru claims-document assistant-a build pannen, unga team insurers-kku vikkuradhukku kittathatta adhe maadhiri. Unga FDE team eppadi work pannudhu-nnu solla ungalukku 15 nimisham kidaikkumaa? Nandri." Nalla conversation-kku appuram referrals perumbaalum thaanaa varum.

Context illaadha "Please refer me"-kku reply varradhu aridhu.

### Coding round

Niraiya Indian product companies, GCCs, IT services firms, HackerRank alladhu HackerEarth maadhiri oru platform-la online coding test-oda aarambikkuraanga. Candidates solra reports-la perumbaalum onnula irundhu rendu mani neram, data structures and algorithms (DSA)-la rendu moonu easy-to-medium problems irukkum: arrays, strings, hash maps, two pointers, sorting, trees, graph search, sila samayam basic dynamic programming. Cut-off scores irukku-nnum candidates solraanga, adhanaala indha step-la fail aanaa unga strong portfolio-vai yaarum paarkkaamale pogalaam.

FDE, AI-startup loops practical coding pakkam adhigamaa saayum: kuzhappamaana data-vai clean panradhu, oru API-a call panradhu, validation, tests serkkuradhu ("The FDE interview loop" lesson-a paarunga). Decision rule:

- **Prepare panradhukku munnaadi round one-oda format-a recruiter-kitta kelunga.**
- **DSA test-na,** random-aa 400 illaama, pattern vaariyaa sumaar 60-la irundhu 80 common problems practise pannunga. Neram vachu pannunga, unga approach-a sathamaa sollunga.
- **Practical coding-na,** tests-oda kuzhappamaana CSVs, JSON-la practise pannunga, trade-offs pathi pesunga.
- **Edhuvaa irundhaalum, vidaama pannunga:** search nadakkura varai dhinamum 30 nimisham, oru panic week-a vida better.

### Notice periods, timing

Unga **notice period**-na resign pannadhukku appuram evvalavu naal velai seyyanum-nguradhu. Adhai unga appointment letter-um company policy-yum dhaan mudivu pannudhu, national rule illa. Periya IT services firms podhuvaa 90 naal vaikkuraanga. Niraiya product companies, startups kuraivaana periods vaikkuraanga. Plan panradhukku munnaadi moonu clauses padinga: notice evvalavu naal, **buyout** pannalaamaa (serve pannaadha naatkalukku badhilaa salary katturadhu), training costs-kku edhaavadhu bond alladhu recovery irukkaa.

Neelamaana notice unga mottha search-aiyum maathum:

- **Resign panradhukku munnaadiye interview pannunga,** appo moonu maasam sambalamum options-um illaama irukka maatteenga.
- **Unga notice-a aarambathulaye sollunga,** Naukri-layum recruiters-kittayum. Sila posts 30 naal alladhu adhukkum kuraivaa join panna mudiyuravangalai edhirpaarkkudhu; 90 naal notice-a maraichaa ellaarudaiya neramum veenaagum.
- **Pudhu employer-kitta rendu kelvi kelunga:** wait panna mudiyumaa, buyout-a reimburse pannuvaangalaa? Silar pannuvaanga; unga employer buyout-kku marukkalaam.
- **Neelamaana notice nerathula offers risk-la irukkum-nu edhirpaarunga.** Join panra varai unga pudhu manager kooda touch-la irunga, innoru offer irukku-nnu poi sollaadheenga.

### Salary research

Unga ippodhaiya job-kku illa, neenga apply panra role-kkaana band-a research pannunga. Xplaind-oda Jobs page, Glassdoor, AmbitionBox, Instahyre, job posts-la irundhu typical yearly CTC bands-a, lakh rupees-la, segarikkudhu, **2 November 2026 annaikku check pannadhu**. Ivai nadutharamaana bands, offers illa; indha table-la irundhu vera maadhiri irundhaa Jobs page dhaan sari.

| Role | 0 mudhal 2 varusham | 3 mudhal 5 varusham | 6+ varusham |
| --- | --- | --- | --- |
| AI Engineer | 6 mudhal 12 | 12 mudhal 25 | 25 mudhal 50 |
| Generative AI Engineer | 8 mudhal 15 | 18 mudhal 35 | 35 mudhal 65 |
| Forward Deployed Engineer | 12 mudhal 25 | 25 mudhal 50 | 50 mudhal 90 |

Idhai eppadi use panradhu:

- **Band-a surukkunga.** Big tech, global AI labs, Bengaluru adhigamaa pay panraanga; IT services, chinna cities kuraivaa pay panraanga. Early FDE band aridhaa dhaan oru fresher job.
- **Kurippitta company-a** Glassdoor, AmbitionBox-la check pannunga, neenga sandhikkuravangakitta band ennanu kelunga.
- **"Current and expected CTC"-kku gavanamaa badhil sollunga.** Indian recruiters podhuvaa rendaiyum aarambathulaye keppaanga. Unga current CTC-a nermaiyaa sollunga, yenna adhai payslips kooda check pannalaam. Unga expected figure-a, current pay-kku mela oru fixed percentage vachu illaama, pudhu role-oda band, unga evidence-a vachu mudivu pannunga.

### Offers-a compare panradhu

CTC (cost to company)-na take-home pay illa. Ovvoru offer-aiyum fixed pay, variable pay, joining bonus (oru varushathukkulla vittu ponaa perumbaalum thirumbi kudukkanum), stock alladhu ESOPs (oruvelai panamaave varaama pogalaam), benefits-aa piringa. Mudhal varushathula urudhiyaa kidaikkappora cash-a compare pannunga, appuram velai, learning, team, pudhu notice period. Accept panradhukku munnaadi endha maatrathaiyum ezhuthula vaangunga.

### Remote roles, velinaattu jobs

Foreign companies Indian engineers-a oru employer of record (avanga saarbaa India-la ungalai employ panra oru firm) moolamaa alladhu contractors-aa remote-aa hire panraanga. Competition global, adhanaala unga portfolio-vum written English-um innum adhigamaa mukkiyam. Contractor-aa neenga self-employed: invoices anuppuveenga, unga tax-a neengale handle pannuveenga, adhanaala sign panradhukku munnaadi oru chartered accountant kitta pesunga. Velinaattukku poga work visa venum. Juniors-kku sponsorship aridhu, US work-visa rules 2025-la romba maaruchu, innum maaritte irukku, adhanaala adhai vachu plan panradhukku munnaadi official government source-a check pannunga.

### Track panni review pannunga

Oru simple sheet vachirunga: company, role, channel (cold, referral, recruiter), date, stage, adutha follow-up. Ovvoru pathu applications-kku appuramum, endha stage-la aalunga drop aaguraanga-nnu kandupidichu, oru thadavaikku oru vishayathai mattum maathunga:

| Enga nikkudhu | Vaaippulla kaaranam | Enna maathanum |
| --- | --- | --- |
| Replies illa | Thappaana roles, weak top third, referrals illa, notice maraichadhu alladhu romba neelam | Top third-a tailor pannunga; referrals pakkam ponga; innum porutthamaana roles-a target pannunga |
| Coding test-la fail | Format-a practise pannala | Format-a kelunga; neram vachu, pattern vaariyaa practise pannunga |
| First rounds-la fail | Project deep dive-la thadumaatram | Unga project-oda decisions, numbers-a sathamaa rehearse pannunga |
| Final loops-la fail | Weak design alladhu client role-play | Andha rounds-a oru friend kooda practise pannunga |
| Offers kaivittu pogudhu | Pay mismatch alladhu notice period | Bands-a munnaadiye research pannunga; mudhal call-laye notice pathi pesunga |

"Ready"-nu thonuradhukku munnaadiye apply pannunga: edhai sari pannanum-nu interviews kaattum.

## Oru worked example

Coimbatore-la rendu varusha Java experience irukkura backend developer Nandhini, indha path-a ezhu maasathula mudikkuraanga. Keezha irukkura numbers oru illustration dhaan, benchmark illa. Unga sondha funnel rombave vera maadhiri irukkalaam.

**Portfolio.** Avanga naalu projects-a pin panraanga, ovvonnulayum mudhal lines-laye oru result-um adhoda test set-um: document QA API, eval report-oda enterprise RAG assistant, approval gates-oda operations agent, karpanaiyaana oru hospital chain-kkaana capstone. Capstone case study moonu pages, koodave rendu nimisha video. Adhoda README, hospital karpanaiyaanadhu, data synthetic-nu velippadaiyaa solludhu. Oru friend RAG assistant-a adhoda README-a vachu ettu nimishathula run panraanga.

**Resume, LinkedIn.** Avanga one-column resume-kku maaruraanga, Java velaiyai chinna bullets-aa surukki, numbers-oda oru "Projects" section serkkuraanga. Avanga LinkedIn headline avanga GitHub profile-oda match aagudhu.

**Timing, pay.** Avanga appointment letter 90 naal notice-nu solludhu, buyout company-oda viruppappadi. Idhai avanga Naukri profile-la podraanga. Avanga current CTC ₹7 lakh. Avangalukku venum-ngura role-kku, 0 mudhal 2 varushathukkaana FDE band ₹12 mudhal 25 lakh. AI velaikku pudhusu, Bengaluru-kku veliye irukkaanga, adhanaala band-oda keezh paadhiyila thannai vachu, expected CTC-a ₹15 mudhal 17 lakh-nu vaikkuraanga.

**Pathu vaarathula search.** Avanga 40 target companies-a list panraanga, adhula 15-la alumni alladhu contacts-a kandupidikkuraanga.

| Channel | Applications | Replies | First rounds | Final loops | Offers |
| --- | --- | --- | --- | --- | --- |
| Cold (Naukri, LinkedIn) | 30 | 2 | 1 | 0 | 0 |
| Referral alladhu contact | 15 | 6 | 5 | 3 | 2 |
| Mottham | 45 | 8 | 6 | 3 | 2 |

Avanga sheet rendu vishayangalai kaattudhu. Ettu replies-la aaru referrals moolamaa vandhuchu. Appuram, moonaavadhu vaarathula avanga mudhal DSA online test-la fail aanaanga, adhanaala ovvoru recruiter-kittayum format-a kekka aarambichu, dhinamum 30 nimisham, neram vachu pattern vaariyaa problems practise pannaanga. Adutha rendulayum pass aanaanga.

**Rendu offers.** Hospitals-kku vikkura oru AI startup oru forward deployed role-a offer pannudhu. Avangalai koopittadhukku kaaranam capstone case study dhaan-nu hiring manager solraaru.

| Offer-oda pagudhi | Startup, FDE | GCC, applied AI engineer |
| --- | --- | --- |
| Fixed pay | ₹15 lakh | ₹16 lakh |
| Variable pay | ₹1.5 lakh, targets meet pannaa | Illa |
| Joining bonus | Illa | ₹1 lakh, oru varushathukkulla vittu ponaa thirumbi kudukkanum |
| Stock | Varushathukku ₹1.5 lakh madhippulla ESOPs | Illa |
| Ezhudhiyirukkura CTC | ₹18 lakh | ₹17 lakh |
| Mudhal varushathula avangalukku urudhiyaa kidaikkura cash | ₹15 lakh | ₹17 lakh |

Startup-oda CTC adhigam, aanaa urudhiyaana cash-la GCC ₹2 lakh adhigamaa tharudhu. Irundhaalum Nandhini, thanakku venum-ngura client-facing velaikkaaga startup-aiye thernthedukkuraanga, ₹16 lakh fixed kekkuraanga. Startup othukkudhu, ezhuthula. Avanga handover mudinjadhum 60 naalla avanga company avangalai release pannudhu, startup wait panna othukkudhu.

## Podhuvaa panra thappugal

- **Tutorial clones.** Oru video paarthu build panna, oru PDF mela chatbot konjam dhaan kaattum. Oru real problem, evals, deployment serunga.
- **Installation-la aarambikkura READMEs.** Problem-aiyum result-aiyum mudhalla vainga.
- **Defend panna mudiyaadha numbers.** Test set illaadha result, alladhu karpanaiyaana client-oda "business impact", project deep dive-la udainju pogum.
- **Fancy two-column templates.** Screening software-la kalainju pogalaam. Oru column use pannunga.
- **Cold applications mattum.** Referrals-um conversations-um podhuvaa selavazhikkura ovvoru mani nerathukkum romba adhigamaana replies vaangi tharum.
- **Coding practice-a skip panradhu.** Mudhalla varra online test-la fail aanaa strong portfolio-vaala oru udhaviyum illa.
- **Notice period-a maraikkuradhu.** Adhu kadaisiyila veliya vandhu offer-a keduthudum.
- **CTC-a mattum vachu offers-a compare panradhu.** Variable pay, joining bonuses, stock ellaam urudhiyaana cash illa.

## Practice pannunga

Profile READMEs pathina GitHub-oda guide-aiyum, Tech Interview Handbook-oda resume guide-aiyum padinga.

**Check (idhai submit pannunga).** Oru GitHub profile README-a publish pannunga, indha path-la irundhu kurainjadhu moonu projects-a pin pannunga, oru case-study write-up ezhudhunga. Ovvoru project README-yum problem, oru screenshot alladhu chinna video, adhoda test set-aiyum size-aiyum solra oru result-la aarambikkanum. Kurainjadhu oru project-a adhoda README-a vachu 10 nimishathukkulla oru reviewer run panna mudiyanum. Unga profile-oda link-a submit pannunga.

**Unga search-kku (idhai check panna maattom, aanaa pannunga).**

1. Unga resume-a oru column-la, kurainjadhu naalu result-based bullets-oda thirumba ezhudhunga, unga LinkedIn headline-a unga GitHub profile-oda match pannunga.
2. Unga appointment letter-a padichu, unga notice period, buyout terms-a ezhudhi vainga.
3. Unga target role-kkaana Jobs page band-a paarthu, oru line kaaranathoda unga expected CTC-a ezhudhunga.
4. Ovvonnulayum contact panna oru aaloda 20 target companies-a list pannunga, oru tracking sheet aarambinga.

**Mudinjadhu-nnu eppo sollalaam:** theriyaadha orutharukku ore oru link anuppi, 60 seconds-kkulla neenga enna build panneenga, adhu enna saadhichudhu, andha number edhula alandhadhu-nnu kaatta mudiyumbodhu.
