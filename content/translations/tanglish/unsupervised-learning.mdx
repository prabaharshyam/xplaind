## Idhu enna

**Unsupervised learning** labels illaadha data-la patterns kandupidikkum. Moonu common tasks:

- **Clustering**: oththa records-a group panradhu, example customer segments illa oththa stores.
- **Dimensionality reduction**: neraya features-a, perumbaalaana information-a vechirukkura konjam features-aa compress panradhu; visualisation-ku, speed-ku, illa simple models-ku. **PCA** classic method.
- **Anomaly detection**: matha records-a maadhiri illaadha records-a kandupidikkuradhu, example vinthaiyaana transactions illa kedaana sensors.

Check panna "correct answer" illa, adhanaala useful-aa-nu judge panradhu velaiyoda oru pagudhi.

```text
  basket size (scaled)

   |        o o              x x
   |      o  o o           x  x x      o = weekly family stock-up
   |       o o               x x       x = premium packaged
   |                                   + = daily fresh shoppers
   |   + + +                           * = a possible anomaly
```

## Idhu eppadi work aagudhu

**Features-a ready pannunga.** Unsupervised methods yenna features use panreenga, eppadi scale panreenga-nu adha romba sarndhirukkum. Numeric features-a standardise pannunga; business-ku "oththa"-nu na enna artham-nu nallaa yosinga.

**k-means clustering.** K, clusters ennikkai-a choose pannunga. Algorithm k centres vaikkum, ovvoru record-aiyum nearest centre-ku assign pannum, centres-a adhoda records-oda nadula nagarthum, thirumba thirumba seiyum. Roughly round, oththa size groups-ku nallaa work aagum. K-a elbow method illa silhouette scores-la choose pannunga, aana perumbaalum clusters business-ku artham aagudha-nu paathu.

**Matha clustering methods.** DBSCAN edhu shape clusters-aiyum kandupidikkum, sparse points-a noise-nu label pannum; hierarchical clustering groupings-oda oru tree-a build pannum; Gaussian mixtures soft memberships tharum.

**PCA.** Original features-oda combinations-aana pudhu axes-a kandupidikkum, adhu romba variation-a pidikkum. Mudhal rendu components-a plot panna groups illa outliers theriyum. Udhaaranamaa, 90% variance-a explain panra components-a vechukittaa, 50 features 10-aa kuraiyalaam.

**Anomaly detection.** Isolation Forest maadhiri methods, oru record-a matha-vangala-la irundhu evvalavu easy-aa pirikkalaam-nu score pannum. Scores-a review-a prioritise panna use pannunga, final verdicts-aa illa.

**Results-a judge panradhu.** Ovvoru cluster-aiyum adhoda features-oda averages-um real examples-um vachu describe pannunga; business user-ku purira oru peru kudunga; stability check pannunga (veru sample-oda thirumba run panna clusters similar-aa irukka?); useful-aa-nu test pannunga (segment-a vachu target panna campaign improve aagudha?).

**Method-a choose panradhu:**

| Task | Method | Edhukku set aagum |
| --- | --- | --- |
| Similar size, shape segments | k-means | Customer, store segments |
| Ozhungilla shapes, noise | DBSCAN | Location data, dense areas kandupidikka |
| Groupings-oda oru tree | Hierarchical clustering | Chinna datasets, structure-a explore panna |
| Soft membership | Gaussian mixtures | Rendu segments-ku paadhi paadhi serndha customers |
| Compress, visualise | PCA | Neraya features, vegamaana plots |
| Unusual records kandupidikka | Isolation Forest | Transactions, sensors, data quality |

**Kashtamaana pagudhi artham thaan.** Random data-la kooda algorithms clusters-a tharum. Unmaiyaana velai, ovvonnayum averages-um real examples-um vachu describe panradhu, business team-oda peru vaikkuradhu, test-la useful-nu prove panradhu. Yaaraalayum describe panna illa act panna mudiyaadha cluster segment illa.

**K-a evidence-oda choose pannunga, elbow mattum illa.**

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

X, _ = make_blobs(n_samples=3000, centers=4, n_features=6, cluster_std=1.6, random_state=8)
Xs = StandardScaler().fit_transform(X)

for k in range(2, 8):
    labels = KMeans(n_clusters=k, n_init=10, random_state=8).fit_predict(Xs)
    print(k, "silhouette", round(silhouette_score(Xs, labels, sample_size=2000, random_state=8), 3))
```

**Segments-ku peru vaikkradhukku munnaadi stability check pannunga.**

```python
def stability(Xs, k, runs=5, frac=0.8, seed=0):
    rng = np.random.default_rng(seed)
    ref = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    scores = []
    for r in range(runs):
        idx = rng.choice(len(Xs), int(frac * len(Xs)), replace=False)
        other = KMeans(n_clusters=k, n_init=10, random_state=r + 1).fit(Xs[idx])
        scores.append(adjusted_rand_score(ref.predict(Xs[idx]), other.labels_))
    return round(float(np.mean(scores)), 3)

print("stability at k=4:", stability(Xs, 4), " at k=7:", stability(Xs, 7))
```

Adjusted Rand index 1-ku pakkam irundha, adhae records thirumba serndhae varudhu-nu artham; romba kammi-yaa irundha, segments oru run-oda artefacts-nu artham.

**Clusters-a business terms-la describe pannunga.** Cluster labels-a original, scale pannaadha columns-oda serthu, summarise pannunga:

```python
import pandas as pd

def describe(df, labels):
    d = df.assign(cluster=labels)
    summary = d.groupby("cluster").agg(["mean", "median"]).round(1)
    summary["size"] = d.cluster.value_counts().sort_index()
    return summary
```

Apram "weekend family shoppers" maadhiri peru kudukkradhukku munnaadi, ovvoru cluster-la irundhum pathu real records padinga.

**Review queue-ku anomaly scores.**

```python
from sklearn.ensemble import IsolationForest

iso = IsolationForest(n_estimators=300, contamination="auto", random_state=8).fit(Xs)
scores = -iso.score_samples(Xs)                  # higher = more unusual
queue = np.argsort(-scores)[:20]
print("top anomaly scores:", scores[queue][:5].round(3))
```

Top cases-a, avai-a thaniyaa kaattura features-oda (example, ovvoru value-um median-la irundhu evvalavu standard deviations thalli irukku) oru aal-kitta anuppunga, avanga enna mudivu pannaanga-nu record pannunga. Andha decisions pinnaadi oru supervised model-ku labels aagum.

**Mudhal paarvaikku PCA.** `PCA(n_components=2).fit_transform(Xs)` plot panna coordinates tharum; `explained_variance_ratio_` rendu axes-um evvalavu variation-a pidikkudhu-nu solludhu. Adhu kammi-yaa irundha, picture unmaiyaana structure-a maraikkalaam.

## Oru worked example

400,000 loyalty-card customers irukkura Kochi supermarket chain marketing-kaaga segments venumnu ninaikkudhu.

12 maadhathula oru customer-ku features: maadhathukku visits, rupees-la average basket, fresh produce, packaged foods, household items-la selavu share, weekend visits share, promotion-la vaangina purchases share. Ellaam standardise pannadhu.

k 3-la irundhu 10 varaikkum k-means; silhouette scores 6, 7 chuthi peak aagudhu. Ezhu clusters, marketing team-oda aaru-aa merge panni peru vachaanga:

1. Weekly family stock-up (periya baskets, weekends)
2. Daily fresh shoppers (aadikkadi, chinna, produce adhigam)
3. Deal hunters (promotion share adhigam)
4. Occasional top-up (arithu, chinna baskets)
5. Premium packaged (periya basket, imported brands)
6. Lapsing (sameeba maadhangalla visits vegamaa kuraiyudhu)

Moonu maadha test, ovvoru segment-la paadhi per-ku segment-specific offers anuppudhu. Response overall 3.1%-la irundhu 4.6%-ku ezhundhudhu, "lapsing" segment-oda offers andha customers-la 12%-a thirumba kondu varudhu. Segment label, churn model-la oru useful feature-um aagudhu.

| Alavu | Segments-ku munnaadi | Segment-specific offers-oda |
| --- | --- | --- |
| Offer response rate | 3.1% | 4.6% |
| Thirumba vandha lapsing customers | Alakkala | 12% |
| Adhigam use | Illa | Churn model-la segment label feature-aa serthaanga |

**Marketing-oda clusters-a peru vaikkradhu.** K = 7-oda mudhal output, data team-ku veliya yaarukkum padikka mudiyaadha ezhu column averages. Oru manineram workshop-la, team marketing-kku ovvoru cluster-oda averages-a, adhula irundhu aindhu real, anonymised customers-oda serthu kaattunaanga. Marketing thangaloda sonnalaiyae segments-ku peru vachaanga, mukkiyamaana idangalla mari sonnaanga. Weekend visits-la chinna difference-aala algorithm pirichu vachirundha rendu clusters-a merge pannaanga, yenna rendu groups-aiyum avanga ore maadhiri treat pannuvaanga. Andha pechukku apram thaan aaru clusters final segments aachu. Team pudhu moonu maadha sample-la clustering-a thirumba run pannaanga. Aaru-la aindhu segments similar sizes-la thirumba vandhudhu. Aaravadhu, romba chinnadhu, kammi-yaa vandhudhu, adhanaala team ovvoru quarter-um adha thirumba check pannum.

## Podhuvaa panra thappugal

- **Scale pannaadha features.** Periya values irukkura features distances-a dominate pannum.
- **K-a oru score-la mattum choose panradhu.** Business meaning mukkiyam.
- **Clusters-a unmai-nu nambradhu.** Adhu oru useful paarvai, customers pathi oru fact illa.
- **Stability check pannaadhadhu.** Unstable clusters ovvoru rerun-layum maarum.
- **Anomaly scores-a verdicts-aa edukkuradhu.** Human review-a prioritise panna use pannunga.

- **Act panna mudiyaadha features-la clustering panradhu.** Business-ku targeting-ku use panna mudiyaadha data-vala define aana segments edhaiyum maatha maattaanga.
- **K-a elbow-la mattum choose panradhu**, stability illa business meaning illaama.
- **Averages-la mattum clusters-ku peru vaikkradhu**, real records padikkaama.
- **Anomaly scores-a verdicts-aa edukkuradhu**, review order-aa illaama.

## Unsupervised methods use panna koodaadha idangal

- **Neenga care panra vishayathukku labels irukku**: supervised models adhukku nerae badhil tharum.
- **Segments fixed rules-a follow pannanum**, regulatory customer categories maadhiri.
- **Meaningful groups uruvaaga records illa features romba kammi.**

## Demo-la irundhu production-ku

- **Seeds-a fix pannunga, settings-a record pannunga**, adhanaala segments reproducible-aa irukkum.
- **Pudhu segments-a release panradhukku munnaadi stability check pannunga.**
- **Schedule-la re-cluster pannunga**, pudhu clusters-a pazhaya peyargalodu veendumae map pannunga.
- **Cluster sizes-a neram povadhula track pannunga**; periya maatram-na behaviour illa data maariduchu-nu artham.
- **Anomalies-oda review decisions-a labels-aa thirumba feed pannunga.**
