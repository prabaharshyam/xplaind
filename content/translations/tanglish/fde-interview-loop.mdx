## Idhu enna

Oru forward deployed engineer (FDE) oru client-oda organisation-kkullaye irundhu velai seivaaru, thelivillaadha oru business problem-a makkal unmaiyaa use panra software-aa maathuvaaru. Neenga adhai seiyuradhai sila mani nerathula paarkka thaan interview loop muyarchi pannudhu.

### Indha role-um loop-um enga irundhu vandhuchu

Indha role-a mudhalla aarambichadhu thaanga thaan-nu Palantir solludhu. Indha engineers-a avanga Forward Deployed Software Engineers-nu koopidraanga, sellappaer "Deltas"; core platform-a build panra "Devs"-oda compare panraanga: oru Dev niraiya customers-kku oru capability-a build panraaru, oru Delta oru customer-kku niraiya capabilities-oda serve panraaru. Perumbaalaana Palantir FDE onsites-la oru "decomposition" round irukku-nnu candidate reports-um prep guides-um solludhu: sumaar 60 nimisham, code konjam allathu illave illa, interviewer thelivillaadha problem irukkura oru customer-aa nadippaaru. Silar oru "learning" round pathiyum solraanga: pazhakkamillaadha oru concept, API allathu system-a vegamaa purinjukkittu adhumela build pannanum.

Ippo AI labs-um AI startups-um indha title-a use panraanga. OpenAI, Anthropic rendume mukkiyamaana customers kooda embed aagura FDEs-a hire panraanga. OpenAI loop pathina prep guides, production-level coding, system design, oru customer-facing exercise, neenga build panna onnula ovvoru mudivaiyum defend panra oru project deep-dive irukku-nnu report panraanga. Report panra round ennikkai maarudhu, adhanaala endha exact number-aiyum nambaadheenga.

India-la indha title vegamaa paravudhu. July 2026-la TCS chief executive K Krithivasan, company-oda staff-la 1% mudhal 1.5% perai forward deployed roles-la vaikkanum-nu Reuters kitta sonnaaru; Reuters adhai sumaar 5,900 mudhal 8,900 per-nu kanakku pottuchu; avangalai hire pannuvaangalaa, retrain pannuvaangalaa-nnu avaru sollala. Coforge than FDE team-a sumaar 20-la irundhu 100-aa valarkka plan panradhaa July 2026-la report aachu. 2026-la indha title-oda Bengaluru postings-la Google Cloud-um Nanonets-um irundhuchu. Sila firms idhe velaikku vera titles use panraanga, adhanaala job description-a padinga.

### Rounds-um ovvonnum edhai test pannudhu-nnum

| Round | Edhai test pannum | Strong-naa eppadi irukkum |
|---|---|---|
| Practical coding | Kuzhappamaana data, APIs, validation, tests | Mudhalla data pathi kekkuradhu; mosamaana rows-a report panradhu; edge cases-a test panradhu |
| Problem decomposition | Thelivillaadha oru goal-a plan-aa maathuradhu | Solutions-kku munnaadi kelvigal; oru KPI, oru baseline, gate-oda oru mudhal step |
| Learning (Palantir-la report aanadhu) | Pazhakkamillaadha system-a vegamaa purinjukkiradhu | Nalla kelvigal; system-a udaikkaama extend panradhu |
| AI system design | Client constraints-kkulla oru end-to-end design | Client-oda data, rules, budget, team kooda inainja choices |
| Client role-play | Pressure-la expectations-a manage panradhu | Adipaniyavum illa, marukkavum illa; options tharradhu; oru owner, oru thedhiyoda mudikkiradhu |
| Behavioural, project deep-dive | Ownership, modhal, failure, kathukkiradhu | Alandha result-um oru lesson-um irukkura STAR kadhaigal |
| Take-home allathu work sample | Oru time box-kkulla judgement | Velai seiyura core path, nermaiyaana README, chinna eval, selavazhicha neram sollappattirukku |

Ella company-yum ella round-aiyum nadathaadhu. FDE roles-kke uriyadhu decomposition thaan:

```flow
dir: LR
title: Decomposition round
Thelivillaadha oru problem -> Goal, owner -> Process, data -> KPI + baseline -> Non-AI udpada options -> Proof of concept + gate -> Risks
```

Indian banks-kku vikkira oru AI startup-la FDE loop-kku thayaaragura Arjun-ngra karpanai candidate-a indha lesson follow pannudhu.

## Idhu eppadi work aagudhu

### Loop-kku munnaadi: recruiter kitta naalu kelvigal kelunga

1. Ennenna rounds irukku, ovvonnum evvalavu neram, edhu case allathu role-play?
2. Take-home irukkaa? Sollappadura neram evvalavu, naan adhai present pannanumaa?
3. Application-laiyum coding round-laiyum AI tools pathina rules enna?
4. On-site velaiyum travel-um saadhaaranamaa evvalavu, oru FDE-oda success-a eppadi alakkuraanga?

Policies maaruradhaala, munnaadiyai vida 2026-la moonaavadhu kelvi romba mukkiyam. Anthropic candidates-kku guidance publish pannudhu: unga resume-a job description kooda check panradhu maadhiri sila vishayangalukku Claude-a use pannalaam, aanaa unga answers-a adhai vachu ezhudha koodaadhu. 2025-la Meta, candidates oru AI assistant-a use pannakkoodiya coding interviews-a trial panradhaa report aachu. Rules company-kku company maarum, sila neram ore loop-la round-kku round kooda maarum. Kekkuradhu saadhaaranam; thappaa guess pannaa loop-e mudinjidalaam.

### Practical coding

Niraiya FDE coding rounds unmaiyaana client velai maadhiriye irukkum; aanaa sila loops, candidates report panra Palantir loop udpada, algorithm maadhiri problems-um tharuvaanga; edhai edhirpaarkkanum-nu kelunga. Oru yadhaarthamaana 30 nimisha task: "Oru lender than branch system-la irundhu UPI collections-a CSV-aa export panraanga. Sila rows-la amount illa, dates rendu formats-la irukku, allathu transaction ID repeat aagudhu. Clean records-aiyum, kaaranangaloda rejected rows list-aiyum return pannunga, appuram adhai oru API endpoint pinnaadi vainga."

Mudhal rendu nimishatha kelvigalukku selavazhinga. Duplicate-a reject pannanumaa, illa rendaavadhu copy jeyikkanumaa? Negative amounts refunds-aa errors-aa? Endha date formats varudhu? Appuram core-a ezhudhunga:

```python
from datetime import date, datetime
from decimal import Decimal
from pydantic import BaseModel, Field, ValidationError, field_validator

class Txn(BaseModel):
    txn_id: str = Field(min_length=1)
    amount: Decimal = Field(gt=0)
    paid_on: date

    @field_validator("paid_on", mode="before")
    @classmethod
    def parse_date(cls, v: str) -> date:
        for fmt in ("%Y-%m-%d", "%d/%m/%Y"):
            try:
                return datetime.strptime(str(v).strip(), fmt).date()
            except ValueError:
                pass
        raise ValueError(f"unknown date format: {v!r}")

def clean(rows):
    good, rejected, seen = [], [], set()
    for line, row in enumerate(rows, start=2):  # line 1 is the header
        try:
            txn = Txn(**row)
        except ValidationError as e:
            rejected.append((line, e.errors()[0]["msg"]))
            continue
        if txn.txn_id in seen:
            rejected.append((line, "duplicate txn_id"))
            continue
        seen.add(txn.txn_id)
        good.append(txn)
    return good, rejected
```

Aaru rows irukkura oru sample-a kuduthaa (oru nalla row, amount illaadha onnu, `dd/mm/yyyy` date onnu, repeat aana ID onnu, negative amount onnu, "Nov 5"-ngra date onnu), idhu rendu rows-a vachukkittu naalai reject pannum, ovvonnukkum line number-um kaaranamum serthu. `float`-kku badhilaa `Decimal` venumne use pannadhu: panathula rounding errors varakkoodaadhu. Upload panna file-a accept panra oru FastAPI endpoint-kkulla `clean`-a wrap panna innum sila nimisham thaan aagum ("FastAPI-oda REST APIs" lesson-a paarunga).

| Interviewers edhai check panraanga | Weak | Strong |
|---|---|---|
| Kelvigal | Udane type panna aarambikkiradhu | Edhu mosamaana row, duplicates-a enna panradhu-nnu kekkuradhu |
| Mosamaana data | Mosamaana rows-a amaidhiyaa skip panradhu | Reject aana ovvoru row-aiyum kaaranathoda return panradhu |
| Types | Panathukku floats, dates-kku strings | `Decimal`, unmaiyaana dates, oru validation model |
| Tests | "En sample-la work aagudhu" | Aarambathula sonna edge cases-kku rendu moonu tests |
| Pesuradhu | Pathu nimisham amaidhi | Ovvoru trade-off-aiyum sathamaa solradhu, udhaaranamaa "ippodhaikku duplicates-a reject panren; maathuradhu easy" |

Task-la oru language model irundhaalum idhe pazhakkangal thaan: oru schema define pannunga, reply-a validate pannunga, validation error-oda onnu rendu thadavai retry pannunga, appuram sathamaa fail panni log pannunga. Indha pattern-a "Structured JSON output-a vaangunga" lesson cover pannudhu.

### Problem decomposition

"Oru hospital discharge delays-a kuraikkanum" maadhiri oru prompt kuduthaa, final answer-kku illa, neenga eppadi yosikkireenga-nnu thaan score. Aaru steps-a sathamaa pannunga:

1. **Goal-aiyum adhoda owner-aiyum clarify pannunga.** Yaaru kekkuraanga, avangalukku enna maarum?
2. **Ippodhaiya process, volumes, data pathi kelunga.** Neram unmaiyaa enga pogudhu? Oru naalaikku ethanai discharges? Enna record aagudhu, enga?
3. **Oru KPI, oru baseline-a agree pannunga**, udhaaranamaa "fit for discharge"-la irundhu bed-a vittu pora varaikkumaana median mani neram, innaikku alandhadhu.
4. **Non-AI udpada options-a list pannunga**, oru checklist allathu pharmacy timing-la oru maatram maadhiri, appuram onnai thernthedutthu yen-nu sollunga.
5. **Oru gate-oda proof of concept-a plan pannunga.** Proof of concept-naa unmaiyaana data-la oru chinna, time-boxed test. Gate-naa thodaralaamaa vendaamaa-nnu mudivu panra, munnaadiye agree panna oru number, udhaaranamaa "oru ward-la naalu vaarathula median delay-a 20% kuraikkanum".
6. **Risks-aiyum avattrai eppadi kuraippeenga-nnum sollunga**: patient data rules, staff adoption, thappaana outputs.

Interviewer numbers edhuvum tharalai-nnaa, assumptions-a sathamaa sollunga ("moonu hospitals-la oru naalaikku 200 discharges-nu vachukkuvom"). Rendu failure modes saadhaaranam: mudhal anju nimishathulaye oru model-a propose panradhu, mudive illaama kelvigal kekkuradhu. Paadhi nerathukkulla oru KPI-um oru mudhal option-um board-la irukkanum. Kelvigal pathi "Client discovery" lesson innum aazhamaa pogudhu.

### Learning round

Palantir loop pathina prep guides-um candidate reports-um oru interviewer pathi solludhu: neenga pazhakkamillaadha oru concept, API allathu system-a kathukkittu adhumela build pannumbodhu avaru unga reference-aa iruppaaru. Score unga learning curve thaan: thulliyamaana kelvigal kekkureengalaa, summarise panni unga purithalai check panreengalaa, sonnadhumela build panreengalaa. Practice panna, pazhakkamillaadha oru open-source repository-a 20 nimisham padinga, appuram oru module-a sathamaa vilakki oru chinna feature-a serunga.

### AI system design

Structure-a "Design interview" lesson cover pannudhu. FDE-la irukkura twist: client-oda constraints thaan problem, adhu noise illa: India-kkullaye irukka vendiya data, erkanave irukkura oru vendor stack, fixed budget, neenga ponadhukku appuram maintain pannappora oru chinna team. Ovvoru choice-aiyum idhula onnoda inainga, evals, oru human fallback, oru handover plan-aiyum serunga.

### Client role-play

Oru interviewer sandhegappadura, porumaiyillaadha, allathu requirements-a maathikkitte irukkura oru client-aa nadippaaru. Anju moves use pannunga:

1. Kettadhai ore vaakkiyathula **summarise pannunga**.
2. **Demand-kku pinnaadi irukkura thevaiyai kandupidinga.** Thedhikko request-kko enna kaaranam-nu kelunga.
3. **Risks-a facts-aa sollunga**, bayamaa illa: edhu test aagala, enna thappaa pogalaam, yaaru baadhikkappaduvaanga.
4. **Trade-offs-oda rendu options thaanga**, client thernthedukkattum.
5. Adutha step, oru owner, oru thedhi, ezhuthula confirmation-oda **mudinga**.

| Soozhnilai | Weak response | Strong response |
| --- | --- | --- |
| "Adutha vaaram ella branches-laiyum live pannunga" | "Sari, try panrom" allathu "Mudiyaadhu" | Thedhikku enna kaaranam-nu kelunga; risks-a sollunga; oru board demo allathu partial rollout thaanga |
| "AI oru thappu pannidichu; cancel panrom" | Model-a defend panradhu | Enna nadandhuchu-nnu kelunga, case-a paarunga, safeguards-aiyum oru fix plan-aiyum vilakkunga |
| "Indha feature-aiyum serunga" | Angeye othukkiradhu | "Naan idhai size panni viyaazhakkizhamaikkulla options-oda varren" |
| Unga proposal-kku appuram amaidhi | Pesikkitte irukkuradhu | Neradiyaa oru kelvi: "Idhula edhu unga board timeline-kku porundhum?" |

Pudhu request-a size panradhai "Scope creep-a manage panradhu" lesson innum aazhamaa cover pannudhu.

### Behavioural kelvigalum project deep-dive-um

STAR (situation, task, action, result) use panni aaru mudhal ettu kadhaigalai thayaar pannunga, ovvonnulaiyum alandha oru result-um oru lesson-um. Ivattrai cover pannunga: aarambam mudhal mudivu varai neenga nadathina oru project, oru stakeholder kooda karuthu vertrumai, oru failure, neenga mudiyaadhu-nnu sonna oru neram, thelivillaadha soozhnilaiyila velai seidhadhu, edho onnai vegamaa kathukkittadhu. Neenga pannadhukku "naan"-nu sollunga, team-oda velaikku mattum "naanga".

Idho oru strong kadhai. Situation: "Enga team-oda monthly sales report-kku moonu naal manual spreadsheet velai aachu." Task: "Adhai vegappaduththa sonnaanga." Action: "Steps-a map pannen, data pulls-aiyum checks-aiyum Python-la automate pannen, analysts review panra oru validation step-a serthen." Result: "Adutha moonu monthly cycles-la ovvoru thadavaiyum sumaar naalu mani neram thaan aachu, release-kku appuram kandupidicha errors maasathukku anjula irundhu zero-aa kuranjudhu." Lesson: "Analysts-a innum munnaadiye serthirukkanum; naan miss panna rendu edge cases-a avanga checks pidichudhu." Indha result-la oru before, oru after, oru kaalam, alandha murai ellaam irukku.

Oru project deep-dive-la ovvoru choice-kkum "Yen X illa?"-nu edhirpaarunga: neenga reject panna alternative-aiyum yen-num thayaar pannikkonga.

### Take-home

- **Time box-a madhinga.** Naalu mani neram-nu sonnaa, sumaar naalu mani neram selavazhinga, unmaiyaana number-a README-la ezhudhunga. Irubadhu mani neram polish pannaa, neenga constraints-a kandukka maatteenga-nnu avangalukku theriyum.
- **Breadth serkkuradhukku munnaadi oru path-a end to end velai seiya vainga.**
- **Oru README ezhudhunga**: ore command-la eppadi run panradhu, assumptions, trade-offs, aduthu enna pannuveenga.
- **Evidence kaattunga**: sila tests, allathu labelled examples-la oru chinna eval, failures-a nermaiyaa list panni.
- **Present pannaa**, client-oda problem-aiyum result-aiyum vachu aarambinga, appuram design.
- **Ungalukku sonna AI-tool rules-a follow pannunga**, allow panna tools-a eppadi use panneenga-nnu sollunga.

### Innum client experience illaiyaa

Indha path-la irukkura perumbaalaanavangalukku panam tharra client idhuvarai irundhadhilla. Aanaalum ungakitta kadhaigal irukku. Oru professor, oru internship manager, oru hackathon judge, oru family business allathu oru NGO "client"-aa irukkalaam. Ovvonnukkum avanga enna kettaanga, avangalukku enna thevaippattuchu, oru karuthu vertrumai, oru number-a note pannunga. Innum nalladhu, oru unmaiyaana aalukku edhaavadhu chinnadhaa build pannunga, udhaaranamaa oru kirana kadaikku low-stock alert sheet, notes vachukkonga. Unga capstone case study ("Oru case study, aarambam mudhal mudivu varai" lesson-a paarunga) oru project deep-dive-kku udhavum.

Behavioural round-la avaru mela irukkura sales-report kadhaiyai (moonu naalla irundhu sumaar naalu mani neram) use panraaru, oru college project-la irundhu innonnaiyum: avaru retries-um alerts-um serthadhukku appuram oru maasathula nightly failed data jobs 12%-la irundhu 1%-aa kuranjudhu.

## Podhuvaa panra thappugal

- **Coding-kku mattum thayaaraguradhu.** Decomposition-kkum role-play-kkum adhe maadhiri timed practice venum.
- **Neraa solution-kku kudhikkiradhu.** Mudhalla goal, process, data pathi kelunga, sathamaa.
- **Drive pannaama kelvigal mattum kekkuradhu.** Decomposition round-la paadhi nerathukkulla oru KPI-aiyum oru mudhal option-aiyum board-la vainga.
- **Ellaathukkum sari-nnu solradhu, allathu neradiyaa mudiyaadhu-nnu solradhu.** Oru request-a size panni client-kku unmaiyaana choice thara mudiyumaa-nnu interviewers test panraanga.
- **Results illaadha kadhaigal.** Ovvoru kadhaikkum oru before, oru after, alandha murai, unga pangu, oru lesson venum.
- **Podhuvaana system designs.** Ovvoru choice-aiyum client-oda constraints kooda inainga.
- **Take-home-a overbuild panradhu.** Time box-a romba thaandi ponaa unga judgement theriyaadhu, marainjidum.
- **AI-tool rules-a kandukkaama viduradhu.** Ovvoru round-laiyum edhu allowed-nu kettu adhai follow pannunga.

## Practice pannunga

Tech Interview Handbook-oda behavioural guide-aiyum, FDE role pathina a16z essay-aiyum padinga.

1. Unga sondha velai allathu projects-la irundhu aaru STAR kadhaigal ezhudhunga, ovvonnulaiyum alandha oru result-um oru lesson-um. Ovvonnaiyum rendu nimishathukkulla sathamaa padinga.
2. Mela irukkura CSV-cleaning task-a tests-oda 30 nimishathula pannunga, pannumbodhe sathamaa pesikkittu.
3. Neenga thernthedukkura Indian business problems-la moonu timed decomposition exercises (ovvonnum 30 nimisham) pannunga. Ungalai record panni, unga mudhal proposal-kku munnaadi ethanai nimisham aachu-nnu note pannunga. Anjukku keezha-naa neenga kudhichitteenga.
4. Indha path-oda lessons-la irukkura oru scenario-vai vachu, oru friend-a kashtamaana client-aa nadikka sollunga. Anju role-play moves-aiyum practice panni, oru owner, oru thedhiyoda mudinga.

**Mudinjadhu-nnu eppo sollalaam:** paarthiraadha oru business problem-a 30 nimishathula, sathamaa, kelvigal, oru KPI, gate-oda oru proof of concept-aa udaikka mudiyum, oru role-play client-oda nadakkaadha demand-a adipaniyaamalum marukkaamalum handle panna mudiyum.
