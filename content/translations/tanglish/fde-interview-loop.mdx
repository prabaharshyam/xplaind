## Idhu enna

Forward deployed engineers-a hire panra companies (AI labs, AI startups, data platforms, AI practices build panra consultancies) loops maariyirukkum, aana perumbaalum indha rounds-la sila irukkum:

- **Coding**: puzzle-a vida practical. Messy file-a parse panradhu, oru API call panradhu, oru chinna service ezhudhuradhu, code-a debug panradhu.
- **Problem decomposition**: oru vague business problem ("oru hospital discharge delays-a kuraikka virumbuthu") 45 nimidam, adha questions-aa, oru plan-aa, oru design-aa maatha.
- **System design**: oru AI system mudhal-la irundhu kadaisi varai: data, retrieval, models, evals, deployment, security, cost.
- **Client role-play illa case**: interviewer sandhegamaana, adhigaaram panra, requirements-a maathura oru client-a nadikkiraanga; neenga kekkanum, clarify pannanum, push back pannanum, next steps agree pannanum.
- **Behavioural**: ownership, conflict, ambiguity, failure, learning-a kaattura pazhaya situations.
- **Take-home illa work sample**: oru chinna project illa ezhuthu proposal, sila neram present panna vendum.

| Round | Enna test pannum |
|---|---|
| Coding | Practical: parse, API call, chinna service, structured output, tests |
| Decomposition | Oru vague problem: questions, KPI-um baseline-um, options, gate-oda POC, risks |
| System design | Data, retrieval, models, evals, guardrails, deploy, cost |
| Client role-play | Kelunga, summarise pannunga, ask-ku pinnaadi irukkura need, options, next steps |
| Behavioural | 6-8 STAR stories, ovvondrukkum oru number-um oru lesson-um |
| Take-home | Oru chinna project illa proposal, sila neram present pannanum |

## Idhu eppadi work aagudhu

**Coding.** Python-la realistic tasks practice pannunga: bad rows irukkura CSV-yum JSON-yum padikkaradhu, validation-oda oru FastAPI endpoint ezhudhuradhu, structured output-um retries-um irukkura oru LLM API use panradhu, tests ezhudhuradhu. Velai seiyumbodhae pesunga; speed-a vida clarity-um mukkiyam.

**Problem decomposition.** Discovery mindset-a sathamaa use pannunga:

1. Goal-a clarify pannunga, adha yaar kavanikkiraanga-nu.
2. Ippo irukkura process, volumes, data pathi kelunga.
3. Measurable KPI-um baseline-um propose pannunga.
4. Non-AI options-um serthu list pannunga, reasons-oda onna pick pannunga.
5. Gate-oda oru proof of concept plan pannunga.
6. Risks-um, adha eppadi kuraippeenga-nu-um peru sollunga.

Interviewers structured thinking-um nalla questions-um thaan paarpaanga, perfect answer illa.

**System design.** Muzhu path-a cover pannunga: ingestion, retrieval, prompting, evals, guardrails, permissions, deployment model, observability, cost, failure handling. Trade-offs-a explicit-aa sollunga ("inga hybrid search, yen-na users policy codes type pannuvaanga").

**Client role-play.** Mudhalla kelunga, ketta-a summarise pannunga. Oru demand-ku pinnaadi irukkura thevai pathi kelunga. Appovae promise panna vendaam; options-um trade-offs-um kudunga. "Client" push pannumbodhu amaidhiyaa irunga. Agree panna next steps-oda mudinga.

**Behavioural.** STAR (situation, task, action, result) vechu aaru-la irundhu ettu stories prepare pannunga, numbers-oda, enna kathukkitteenga-nu-oda. Cover pannunga: neenga mudhal-la irundhu kadaisi varai drive panna oru project, oru stakeholder-oda disagree panna oru neram, oru failure, no sonna oru neram, ambiguity-oda velai seiyradhu, edhaiyaavadhu seekkiram kathukkuradhu.

**Ungaloda sondha questions.** FDEs evvalavu neram travel illa on-site-la selavu panraanga, projects eppadi select aagudhu, FDEs product-ku eppadi feedback tharaanga, success eppadi measure aagudhu-nu kelunga.

**Nalla score tharra role-play moves:**

| Situation | Weak response | Strong response |
| --- | --- | --- |
| "Adutha vaaram ella branches-kum live pannunga" | "Sure, try pannuvom" illa "Mudiyaadhu" | Date-ku enna kaaranam-nu kelunga; risks-a peru sollunga; oru board demo illa oru partial rollout offer pannunga |
| "AI oru thappu pannidhu; cancel panrom" | Model-a defend panradhu | Enna nadandhadhu-nu kelunga, andha case-a paarunga, safeguards-um oru fix plan-um explain pannunga |
| "Indha feature-um serthukkunga" | Appovae othukkradhu | "Naan size panni, Thursday-kulla options-oda varen" |
| Ungaloda proposal-ku apram amaidhi | Pesitte irukkradhu | Oru direct question kelunga: "Idhula edhu ungaloda board timeline-ku set aagum?" |

**Numbers-oda oru STAR story.** Situation: "Engal team-oda monthly sales report-ku moonu naal manual spreadsheet work aagum." Task: "Adha vegamaakka sonnaanga." Action: "Steps-a map panni, data pulls-um checks-um Python-la automate panni, analysts review panna oru validation step serthen." Result: "Ippo naalu manineram aagudhu, release-ku apram kandupidicha errors maasam anju-la irundhu moonu maasaththula onnum illai-nu aachu." Lesson: "Analysts-a munnaadiyae involve pannirukkanum; avanga checks naan miss panna rendu edge cases-a pidichaanga."

**Decomposition-a prepare panradhu.** Indian business problems-a select pannunga, 30 nimida timer vainga, edhaavadhu solution-ku munnaadi ungaloda questions-a sathamaa sollunga. Record panni thirumba kelunga: neenga edhaavadhu propose panradhukku munnaadi evvalavu nimidam aachu-nu ennunga. Anju-kku kammiya irundhaa, romba vegamaa jump panneenga.

## Oru worked example

Oru candidate, Arjun, Indian banks-ku sell panra oru AI startup-la FDE loop-ku prepare panraanga.

Coding-ku naalu timed tasks practice panraanga: oru statement parser, oru FastAPI endpoint, Pydantic validation-um retries-um irukkura oru extraction call, oru failing test-a fix panradhu.

Decomposition-ku "oru state transport corporation kammi complaints venum-nu virumbuthu" maadhiri prompts-la practice panraanga, ungaloda questions-a sathamaa sollitu, neram paarthukkittu.

Client role-play-la, interviewer solraanga: "Your pilot is too slow. Our MD wants it live for all branches next week." Arjun concern-a summarise panraanga, deadline-ku edhu trigger-nu kekkuraanga (oru board meeting), adutha vaaram full rollout enna risk-nu explain panraanga (security review mudiyala, rendu branches-la 50%-ku kammi adoption), options offer panraanga: pilot results-oda oru board demo-um moonu-wave rollout plan-um, illa best-aa prepare aana anju branches-ku rollout. Interviewer apram solraanga, idhu avanga loop-la romba strong-aana pagudhi: avanga thorkkavum illa, marukkavum illa.

Avanga behavioural stories ovvondrukkum oru number irukku: "report preparation-a 3 naal-la irundhu 4 manineram-aa kuraichen", "failed jobs 12%-la irundhu 1%-aa kuraichen".

| Preparation | Arjun enna pannaanga |
| --- | --- |
| Coding | Naalu timed tasks: statement parser, FastAPI endpoint, validation-um retries-um irukkura extraction, failing test fix |
| Decomposition | "Oru state transport corporation kammi complaints venum-nu virumbuthu" maadhiri prompts-la timed practice |
| Role-play | Thorkkaama, marukkaama oru board demo illa anju-branch rollout offer pannaanga |
| Behavioural | Numbers irukkura stories, example reports 3 naal-la irundhu 4 manineram-aa kuraindhadhu |

## Podhuvaa panra thappugal

- **Coding-ku mattum prepare panradhu.** Decomposition-um role-play rounds-um aadikkadi FDE offers-a decide pannum.
- **Solution-ku jump panradhu.** Mudhalla questions kelunga, sathamaa.
- **Role-play-la ellathukkum yes sollradhu.** Neenga expectations-a manage panna mudiyuma-nu interviewers test pannuvaanga.
- **Result illaadha stories.** Ovvoru story-kum oru number illa clear outcome-um, oru lesson-um vendum.
- **Generic system designs.** Ovvoru choice-aiyum scenario-oda constraints-oda connect pannunga.

## Practice pannunga

Tech Interview Handbook-oda behavioural guide-aiyum, FDE role pathi a16z essay-aiyum padinga.

1. Ungaloda velai illa projects-la irundhu aaru STAR stories ezhudhunga, ovvondrukkum oru result-um oru lesson-um.
2. Neenga select panra Indian business problems-la moonu timed decomposition exercises pannunga (ovvondrum 30 nimidam), sathamaa pesi, record panni.
3. Oru friend-a, indha path-oda lessons-la irukkura scenarios-la onna vechu, kashtamaana client-aa nadikka sollunga; kekkradhu, clarify panradhu, options tharadhu, mudikkaradhu practice pannunga.

**Mudinjadhu-nu eppo sollalaam:** Neenga paakkaadha oru business problem-a, 30 nimidathula, sathamaa, questions-aa, oru KPI-aa, oru POC plan-aa decompose panna mudiyum.
