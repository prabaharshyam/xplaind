## Idhu enna

RAG system-oda perumbaalaana thappaana answers retrieval-la thaan aarambikkum: sariyaana passage kidaikkavae illa, adhanaala model adha use panna mudiyala. **Retrieval check panradhu**-na, fixed test kelvigal vechu, sariyaana passages varudhaa-nu measure panradhu, final answer nallaa irukkaa-ngradhula irundhu thaniyaa.

```flow
Oru thappaana answer -> Sariyaana passage top k-la irundhucha?
Sariyaana passage top k-la irundhucha? -[illa]-> Retrieval problem | chunking, embeddings, hybrid search, query rewriting, filters
Sariyaana passage top k-la irundhucha? -[irundhuchu]-> Generation problem | prompt, grounding rules, citations, model choice
```

Indha lesson, Kochi-la oru bank-oda staff assistant-a follow pannum; adhu avanga circulars pathi romba thappaana answers kuduthuchu.

## Idhu eppadi work aagudhu

**Test set build pannunga.** 30-la irundhu 100 realistic kelvigal collect pannunga, ovvonnukkum answer irukkura passage illa passages. Mudinja varai real user kelvigal use pannunga, easy, hard, vague, answer illaadha kelvigalum serunga. Maatrangala fair-aa compare panna set-a maathaama vechukkunga.

**Retrieval metrics.**

- **Recall at k**: evvalavu kelvikku kuraindhadhu oru sariyaana passage top k results-la irukku? Recall at 5 oru common headline number. Strict-aa sonnaa, indha "kuraindhadhu onnu" version-a hit rate-nu um solvaanga; oru kelvikku neraya sariyaana passages irundha, sila tools recall at k-a, kandupidicha passages-oda share-aa define pannum.
- **Precision at k** illa **context precision**: retrieve aana k passages-la, evvalavu unmaiyilae relevant? RAGAS-oda context precision, relevant-a mela rank pannuradhaiyum reward pannum. Precision kammi-naa prompts-la noise nirambum.
- **MRR** (mean reciprocal rank): sariyaana passage-a mela vekkradhai reward pannum.

**Answer metrics**, thaniyaa measure pannunga:

- **Faithfulness**: answer-la sollra claims retrieve aana passages-aala support aagudhaa?
- **Answer correctness**: expected answer-oda match aagudhaa?

RAGAS maadhiri tools idhai compute pannum, perumbaalum oru model-a judge-aa use panni; oru sample-a kaiyaala check pannunga.

**Split vechu diagnose pannunga.** Oru answer thappaa irundha:

- sariyaana passage retrieve *aagala* → retrieval-a fix pannunga (chunking, embeddings, hybrid search, query rewriting, filters);
- sariyaana passage retrieve aachu, aana answer thappu → generation-a fix pannunga (prompt, grounding, model).

**Ovvoru maatrathukkum run pannunga.** Chunk size, embedding model, top-k maathuna, sila kelvikku help aagum, sila-kku hurt aagum. Fixed set thaan net effect-a kaattum.

**Metrics-oda oru chinna worked example.** Naalu test kelvigal, ovvonnukkum top 5 results; mudhal sariyaana passage-oda idam kaattapattirukku:

| Kelvi | Mudhal sariyaana passage idam | Top 5-la irukkaa? | Reciprocal rank |
| --- | --- | --- | --- |
| Q1 | 1 | aama | 1.0 |
| Q2 | 3 | aama | 0.33 |
| Q3 | kidaikkala | illa | 0 |
| Q4 | 2 | aama | 0.5 |

Recall at 5 = 4-la 3 = 75%. MRR = (1.0 + 0.33 + 0 + 0.5) ÷ 4, sumaar 0.46.

**Test set-a vegamaa build panradhu.** Support tickets, search logs, chats-la irukkura real kelvigal-la irundhu aarambinga. Ovvonnukkum, documents theriyra oru aal answer irukkura passage-a kandupidichu, adhoda document, section-a record pannuvaanga. 30 kelvigal-a oru afternoon-la mudikkalaam. Documents-la answer illaadha kelvigalum serunga, expected passage "none"-nu, appo system "theriyaadhu"-nu solludhaa-nu check pannalaam. Oru user thappaana answer-a report pannura ovvoru thadavaiyum pudhu kelvi serunga.

**Model-a judge-aa use panradhu.** RAGAS maadhiri tools faithfulness, relevance-a periya alavula score panna oru model-a use pannum. Useful, aana perfect illa. 20 sample-a kaiyaala score panni compare pannunga; judge makkal-oda adikkadi disagree pannaa, adhoda numbers-a nambum munnaadi adhoda instructions-a fix pannunga.

**Code-la metrics.** Ovvoru test case-um adhukku answer irukkura passage ids-a list pannum; retriever ranked ids-a return pannum:

```python
import math

def metrics(cases, retrieve, k=5):
    """cases: list of (question, set_of_relevant_ids). Empty set = unanswerable."""
    recall = precision = mrr = ndcg = 0.0
    answerable = [c for c in cases if c[1]]
    for q, relevant in answerable:
        ranked = retrieve(q)[:k]
        hits = [1 if r in relevant else 0 for r in ranked]
        recall += any(hits)
        precision += sum(hits) / k
        mrr += next((1 / (i + 1) for i, h in enumerate(hits) if h), 0)
        dcg = sum(h / math.log2(i + 2) for i, h in enumerate(hits))
        ideal = sum(1 / math.log2(i + 2) for i in range(min(len(relevant), k)))
        ndcg += dcg / ideal
    n = len(answerable)
    return {"recall@k": recall / n, "precision@k": precision / n, "mrr": mrr / n, "ndcg@k": ndcg / n}
```

Answer illaadha cases-a indha numbers-la venumnae ozhichu vechirukkom; adhai thaniyaa, final answer "theriyaadhu"-nu solludhaa-nu paathu check pannunga.

**Results-a pirichu paarunga.** Oru overall recall problems-a maraikkum. Ovvoru kelvikkum tag podunga (exact code, vague, Hindi, multi-part, recent policy), apram tag-ku recall report pannunga. Ingestion maatrathukku apram "recent policy" kelvigal-la recall kuraindha, pudhu documents index aagala-nu artham.

```python
from collections import defaultdict

def by_tag(cases_with_tags, retrieve, k=5):
    groups = defaultdict(list)
    for q, rel, tag in cases_with_tags:
        groups[tag].append((q, rel))
    return {tag: metrics(cs, retrieve, k)["recall@k"] for tag, cs in groups.items()}
```

**Chinna sets-la noise irukkum.** 30 kelvigal-la, oru kelvi 3 points-ku mela. 3-point maatrathukku kondaadavum vendaam, bayappadavum vendaam; endha kelvigal maarichu, yen-nu paarunga. Set-a neram pogapoga valarunga, mukkiyamaana tags-la especially.

**Model vechu kelvigal draft panradhu.** Vegamaa aarambikka, oru model-ku oru passage kuduthu, adhu answer pannura rendu kelvigal-a, user pesura vaarthaigal-la ezhudha sollunga. Apram oru aal ovvonnayum edit illa reject panni, passage-a expected answer-aa record pannuvaanga. Idhai synthetic-nu mark panni, logs-la irundhu real kelvigal-a serthukkitte irunga: models passage-oda vaarthaigalaiyae reuse panna paakkum, adhanaala retrieval nijathai vida easy-aa theriyum.

**Retrieval-um answers-um serndhu.** Ovvoru case-kum, retrieve aana ids, answer, verdicts-a store pannunga. Appo ovvoru thappaana answer-um oru paarvaila rendu bucket-la onnula vizhum: sariyaana passage illa (retrieval problem) illa irukku (generation problem).

## Oru worked example

Kochi-la oru bank-oda internal assistant, 900 circulars-la irundhu staff kelvigalukku badhil solludhu. Answers adikkadi thappaa irukku-nu staff pugaar sollraanga.

Team 60 kelvigal ezhudhuraanga, ovvonnukkum answer irukkura circular, paragraph-oda. Results:

- recall at 5: 63%;
- answers-oda faithfulness: 0.92;
- correctness: 58%.

Faithfulness adhigam, adhanaala retrieve aana passages sollradhaiyae model perumbaalum solludhu. Recall kammi: sariyaana passages adikkadi varavae illa. Misses-a paathaa, perumbaalaanadhula circular numbers ("as per RBI/2026-27/41"), irukku, appuram revise aana circulars-la pazhaya versions pudhusa vida mela rank aagudhu.

Maatrangal: circular numbers-ku keyword matching-oda hybrid search, apram superseded circulars-a ozhikkura oru filter. Adhe 60 kelvigal-la, recall at 5 87%-ku, correctness 81%-ku uyarndhudhu.

| Measure | Munnaadi | Hybrid search, superseded filter-ku apram |
| --- | --- | --- |
| Recall at 5 | 63% | 87% |
| Faithfulness | 0.92 | 0.93 |
| Correctness | 58% | 81% |

Model oru naalum problem illa; thappaana circulars-la irundhu faithful-aa badhil sollittu irundhuchu.

**Misses-a padikkradhu.** Team numbers-oda niruththala. Top five-la sariyaana passage illaadha 22 kelvigalayum padichaanga, kaaranangala pirichaanga: 9-la embedding search-aala exact-aa match panna mudiyaadha circular numbers, 7-la current circular-a vida superseded circular mela retrieve aachu, 4 vague kelvigal, 2-la test set-layae thappaana expected passage irundhuchu. Ovvoru kaaranamum vera fix-a kaattuchu, test set-oda sondha thappugala fix panradhum velaiyoda oru normal paguthi.

## Podhuvaa panra thappugal

- **Final answers mattum paakkuradhu.** Retrieval-aa generation-aa edhu fail aachu-nu theriyaadhu.
- **Runs-ku idaila test set-a maathuradhu.** Compare panna adha fixed-aa vechukkunga.
- **Answer illaadha kelvigal illaama irukkuradhu.** Refusals-a test panna adhu thevai.
- **Automatic judges-a kannai moodikkitu nambradhu.** Oru sample-a check pannunga.
- **Precision sarigarappo recall-a mattum optimise panradhu.** Rendaiyum track pannunga.
- **Easy kelvigal mattum irukkura test sets.** Real users ketkura maadhiri vague, multi-part, answer illaadha kelvigalum serunga.
- **Re-test pannaama pala vishayam maathuradhu.** Oru setting-a maathunga, set-a marubadiyum run pannunga, numbers-a record pannunga, apram adutha onnu.
- **Synthetic kelvigal mattum**, adhu documents-oda vaarthaigalaiyae use panni retrieval-a thookkiyae kaattum.
- **Oru overall number.** Recall-a kelvi vagai-ku pirichu paarunga.
- **Answer illaadha kelvigala recall-la kalakkuradhu**, rendu numbers-aiyum maraikkum.

## Oru lighter check podhum-naa

- **Chinna prototype**: kaiyaala check panna paththu kelvigal, retrieval podhuvaa work aagudhaa-nu sollidum.
- **Adikkadi maaraadha collection**, launch-la oru careful test-um spot checks-um podhum.
- **Use panra munnaadi makkal source-oda verify pannura answers.**

## Demo-la irundhu production-ku

- **Test set-a repository-la vechukkunga**, kelvi vagai-oda tag panni, ovvoru retrieval maatrathukkum run pannunga.
- **Recall, precision, MRR, nDCG-a record pannunga**, settings, index version-oda.
- **Report aana ovvoru thappaana answer-aiyum** pudhu kelvi-aa serunga.
- **Model-judge scores-a maasam oru thadavai kaiyaala spot-check pannunga.**
- **Entha mukkiyamaana tag-layum recall kuraindhaa alert** vaanga.
