## Idhu enna

Ungaloda mudhal n8n workflow-la oru trigger-um konja nodes-um thaan irundhudhu. Unmaiyaana business automations innum dhooram pogum: aayirakkanakkula records process pannum, strict limits irukkura APIs-a call pannum, neraya systems-la irundhu data-va serkkum, AI steps irukkum, raathiri 3 mani-ku edhavadhu fail aanaalum work aagikittu irukkanum.

Ivatrukkellaam n8n-la building blocks irukku:

| Building block | Edhukku |
| --- | --- |
| **Sub-workflows** | Matra workflows-la irundhu call panna mudiyura reusable workflows, functions maadhiri |
| **Loops, batches** | API limits-a respect panna items-a groups-aa process panradhu |
| **Merge, split** | Rendu sources-oda data-va serkkuradhu, illa lists-a items-aa pirikkuradhu |
| **Code nodes** | Visual nodes cover pannaadha logic-ku sinna JavaScript illa Python snippets |
| **AI nodes** | Model calls, structured output parsers, tools-oda agent nodes |
| **Error workflows** | Adhoda settings-la peyar kudutha workflow fail aagumbodhu run aagi, yaarukkavadhu alert anuppum |

```flow
Schedule: 6 am -> Shopify: orders, page page-aa
Schedule: 6 am -> Gateway: settlements, batch-um wait-um
Shopify: orders, page page-aa -> Merge on order id
Gateway: settlements, batch-um wait-um -> Merge on order id
Merge on order id -> Code: mismatches-a flag pannu -> Sub-workflow: pudhusaa irundhaa row ezhudhu -> AI: ovvoru mismatch-aiyum explain pannu -> Slack: summary
Edhavadhu fail -> Error workflow | execution link-oda finance-ops-ku alert
```

Indha lesson-la Bengaluru-la oru skincare brand daily order reconciliation-a automate panradha follow pannuvom. Mudiyum podhu volume, limits, AI, failure-a handle panra workflows-a build panna mudiyum.

## Idhu eppadi work aagudhu

### Structure

Ovvoru workflow-um oru velaiyila focus-aa irukkattum. "Oru customer-a look up pannu", "oru alert anuppu" maadhiri shared logic-a, matra workflows call panra **sub-workflows**-la podunga. Nodes-ku clear-aa peyar vainga: "HTTP Request 3"-nu illa, "Get open orders from Shopify". Oru colleague, illa moonu maadham kazhichu neenga, canvas-a paathe workflow-a purinjukkanum.

### Volume-um rate limits-um

Neraya APIs vinaadiku illa nimishathukku evvalavu requests anuppalaam-nu limit vaikkum, oru neraththula oru page results mattum thirumba tharum. Idhu use pannunga:

- **pagination**, ellaathayum onnaa edukkaama page page-aa fetch panna;
- **Loop Over Items** oru batch size-oda, items-a groups-aa process panna;
- batches-ku naduvula **Wait** node, limit-ku kezhae irukka.

```flow
dir: LR
3,000 items -> 100-oda oru batch -> API calls -> Wait 1 s
Wait 1 s -[adutha batch]-> 100-oda oru batch
```

### Data-va merge panradhu

**Merge** node rendu branches-la irundhu items-a position vachu illa matching field vachu serkkum, example sheet rows-a CRM contacts-oda email vachu, illa orders-a payments-oda order id vachu match panradhu.

### Code nodes

Unusual formats parse panna, date maths, amounts-a Indian-aa format panna (₹1,25,000) useful. Short-aa, comments-oda vachukkunga. Complex logic-a code node-kulla test panni maintain panradhu kashtam; adhu valarndhaa oru proper service-ku move pannunga.

### AI steps

Clear prompt-oda oru model node-um, **structured output parser**-um use pannunga, adhanaala pinnaadi irukkura nodes-ku free text illa, reliable, peyar vacha fields kidaikkum. **Agent nodes** multi-step tasks-ku tools-a, example vera nodes illa sub-workflows-a call pannum. Matra agent maadhiri nadathunga: thevaiyaana tools mattum kudunga, steps count-a limit pannunga, payments maadhiri risky actions-ku approval vaanggunga.

### Reliability

| Practice | Yen |
| --- | --- |
| Flaky nodes-ku retries | Thaarkaalika API errors rendavadhu thadavaila thaanaave sari aagum |
| Idempotent writes | Record-a create panradhukku munnaadi irukka-nu check pannunga, adhanaala reruns duplicate aagaadhu |
| Oru error workflow | Unga team chat-la workflow peyar, fail aana node, execution link-oda post pannum |
| Item-count checks | Sappunnu onnumae process pannaadha runs-a pidikkum |

### Maintainability

Workflows-a JSON-aa Git-ku export pannunga, illa irundhaa n8n-oda source control features use pannunga. Development, production instances illa projects thaniyaa vachukkunga, credentials-a environment-ku oru maadhiri store pannunga. Production-a thodradhukku munnaadi development-la changes-a test pannunga.

### Self-hosting basics

n8n-a neengalae, example Docker-la, run panninaa data mela control kidaikkum. Appo adhoda database backups, updates, security, scaling ellaam ungaloda poruppu. Adhiga volume-ku **queue mode** executions-a thani worker processes-la run pannum.

## Oru worked example

Bengaluru-la oru D2C skincare brand Shopify store-la naalaikku sumaar 1,500 orders vikkudhu. Ovvoru kaalaiyum finance team orders-a payment gateway settlements-oda, accounting sheet-oda match panna rendu mani neram selavu pannum. Avanga adha automate pannaanga:

| # | Node | Enna pannum |
| --- | --- | --- |
| 1 | Schedule trigger | Kaalai 6 mani-ku run aagum |
| 2 | Shopify | Nethu orders-a 250 250 pages-aa fetch pannum |
| 3 | Loop-la HTTP Request | Payment gateway API-la irundhu settlements-a batches-aa fetch pannum, adhoda limit-a respect panna 1-second wait-oda |
| 4 | Merge | Orders-aiyum settlements-aiyum order id vachu serkkum |
| 5 | Code | Mismatches-a flag pannum: amount maaruchu, settlement missing, refund record aagala; amounts-a Indian style-la format pannum |
| 6 | Sub-workflow "write to accounting sheet" | Serkkradhukku munnaadi andha order-ku row irukka-nu check pannum, adhanaala reruns safe |
| 7 | Structured output-oda AI node | Finance team-ku ovvoru mismatch-ukkum oru line explanation ezhudhum |
| 8 | Slack | Totals-um mismatch sheet-ku link-um post pannum |
| + | Error workflow | Edhavadhu fail aanaa execution link-oda finance-ops channel-ku alert pannum |

**Results:**

| Measure | Munnaadi | Apram |
| --- | --- | --- |
| Finance team-oda kaalai reconciliation | Sumaar 2 mani | Flag aana cases review panna sumaar 15 minutes |
| Oru naal-ku kandupidicha mismatches | Maaruum, sila miss aagum | 20-la irundhu 40, ellaam oru reason-oda list aagum |

**Oru mosamaana kaalai.** Oru naal 6 mani-ku payment gateway-oda API down-aa irundhudhu. Node moonu thadava retry pannudhu, apram error workflow fail aana execution-ku link-oda alert post pannudhu. Team 9 mani-ku workflow-a thirumba run pannaanga. Ovvoru write-um mudhalla irukkura row-a check pannadhaala, rerun duplicates illaama mudinjudhu.

## Podhuvaa panra thappugal

- **Oru periya workflow.** Clear peyar-oda sub-workflows-aa piringa.
- **Rate limits-a ignore panradhu.** Paginate, batch, wait pannunga.
- **Idempotent illaadha writes.** Reruns duplicates create pannum.
- **Periya code nodes-la pudhachu vacha logic.** Code-a sinnadhaa vainga; complex logic-a service-ku move pannunga.
- **Version control illai, test instance illai.** Production changes sappunnu things-a odaikkum.
- **AI output free text-aa.** Pinnaadi steps-ku reliable fields kidaikka structured output parser use pannunga.

## Practice pannunga

n8n-oda N8N102 Integrations course-a mudinga, keezha link irukku, hosting overview-vayum padinga.

1. **Volume.** API illa sheet-la irundhu kammiyaa nooru items-a batches-aa, batches-ku naduvula wait-oda process panra oru workflow build pannunga.
2. **Merge, write, AI.** Rendu data sources-oda merge, irukkura rows-a check panra records ezhudhra sub-workflow, structured output-oda oru AI step add pannunga.
3. **Failure.** Ungalukku alert anuppura oru error workflow add pannunga, oru node-a purposeful-aa odachu, alert-um clean rerun-um confirm pannunga. Manual test runs-ku error workflows run aagaadhu, adhanaala workflow-a adhoda trigger-la run aaga vidunga.

**Mudinjadhu-nu eppo sollalaam:** Ungaloda workflow-a duplicates illaama thodarndhu rendu thadava rerun panna mudiyum, fail aana execution-ku link irukkura error alert-a kaattamudiyum.
