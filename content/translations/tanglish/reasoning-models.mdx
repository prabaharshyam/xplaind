## Idhu enna

AI-la perumbaalaana panam neenga oru model-a paakkuradhukku munnaadiye selavaagudhu: adha train panradhula. **Test-time compute** adhoda marupakkam. Answer panra neraththula adhigam computing selavazhikkradhu, appo answer sariyaa irukka vaaippu adhigam. "Test time"-ngradhu inference-kkaana research vaarththai, adhaavadhu train aana oru model use aagura neram.

Idha seyya moonu podhuvaana vazhigal irukku.

1. **Step by step yosikka sollunga.** Idhu **chain-of-thought** (CoT) prompting: model answer-kku munnaadi thannoda reasoning-a ezhudhum. Idhoda nerungiya sondham **self-critique**: model mudikkiradhukku munnaadi thannoda draft-a thaane check pannum.
2. **Pala answers-a generate panni best-a vechukkonga.** Idhu **best-of-N**. Oru **verifier** (oru test, oru rule check illa oru scoring model) winner-a thernthedukkum; answers exact-aa irundhaa oru majority vote adha seyyum.
3. **Oru reasoning model-a use pannunga.** Indha models answer panradhukku munnaadi neelamaa yosikka train pannappattavai. Avai evvalavu effort selavazhikkanum-nu neenga set pannuveenga. Thinking adikkadi maranjirukkum: neenga answer-a mattum dhaan paappeenga, aana thinking-kkum panam kattuveenga.

Moonume accuracy-kkaaga panaththaiyum kaathirukkura neraththaiyum vittukkudukkudhu. Model sariyaana answer-a *adaiya mudiyum*, aana vazhiyila adikkadi thadumaarumbodhu dhaan koodudhal thinking palan tharum: multi-step maths, code, planning maadhiri. Model-kitta facts illainnaa adhu udhavaadhu.

```flow
title: Oru question-kku evvalavu thinking venum-nu thernthedukkuradhu
Pudhu question -> Plain model-kku kashtamaa? | unga test set-a check pannunga
Plain model-kku kashtamaa? -[illa]-> Plain answer | vegam, malivu
Plain model-kku kashtamaa? -[aamaa]-> Step-by-step prompt | idha mudhalla try pannunga
Step-by-step prompt -> Podhumaa?
Podhumaa? -[aamaa]-> Ship pannunga
Podhumaa? -[illa]-> Answers-a check panna mudiyumaa? | tests, rules, exact values
Answers-a check panna mudiyumaa? -[aamaa]-> N sample panni verify pannunga | best-of-N illa vote
Answers-a check panna mudiyumaa? -[illa]-> Reasoning model | effort setting-a pala levels-la test pannunga
N sample panni verify pannunga -[samples oththuppogala]-> Reasoning model
```

## Idhu eppadi work aagudhu

### Chain of thought

Idhoda ellaaththaiyum vida simple-aana version prompt-la ore oru line serkkuradhu dhaan: "Think step by step, then give only the final answer on the last line." Neenga venumngra steps-a list pannalaam, illa oru worked example kaattalaam. Indha method-kku peru vecha 2022 paper (Wei and others, keezha link irukku) periya models-la maths word problems-la periya gains kaattuchu. Kadaisi line-la varra answer mukkiyam: unga code adha kandupidikkanum.

Mudhal sikkal neelam: reason panna oru answer-la niraiya adhiga tokens irukkum, ovvonnukkum panamum neramum aagum. Rendaavadhu sikkal saththamillaadhadhu: **ezhudhina reasoning dhaan answer-kkaana unmaiyaana kaaranam-nu endha guarantee-um illa.** 2025 Anthropic study-la, models-kku answer-kkaana oru hint ragasiyamaa kudukkappattadhu. Avai hint-a use pannappo, Claude 3.7 Sonnet thannoda reasoning-la adha 25% neram mattum dhaan solluchu, DeepSeek R1 39% neram. Munnaadi vandha work (Turpin and others, 2023) chain-of-thought prompts-layum idhe pattern-a kandupidichudhu. Adhanaala kaattura reasoning-a oru udhaviyaana draft-aa paarunga, proof-aa illa. Steps evvalavu nambumpadi irukku-nnu illa, final answer-a check pannunga.

### Best-of-N-um verifiers-um

Konjam variety-oda (zero-kku mela oru temperature, illa konjam vera vera prompts) pala answers kelunga, apram onna thernthedunga.

- **Majority vote moolamaa**, idha **self-consistency**-nnum solluvaanga. Ore maths question-a anju thadavai kettu, ellaaththaiyum vida adhigamaa varra final number-a edunga. Answers exact-aa irundhaa mattum dhaan idhu work aagum: oru number, oru label, oru choice. Oththupporadhum oru signal: samples oththuppogalainnaa, andha question kashtamaanadhaa irukka vaaippu adhigam.
- **Oru outcome verifier-oda**, idhu final answer-a check pannum. Generate aana code-a tests mela ottunga, generate aana SQL-a otti adhoda result-a erkanave therinja oru result-oda compare pannunga, illa extract panna date unmaiyaana date-aa-nnu check pannunga. 2021-la OpenAI report pannuchu: grade-school maths problems-la, oru trained verifier-oda irundha 6-billion-parameter model, fine-tune panna oru 175-billion-parameter model-a konjamaa vendradhu; indha gain-a model size-la 30 madangu adhigarippukku samam-nu avanga oppittaanga.
- **Oru process verifier-oda**, podhuvaa oru **process reward model** (PRM); idhu kadaisiya mattum illaama ovvoru step-aiyum score pannum. OpenAI-oda 2023 paper "Let's Verify Step by Step", competition maths-la answer-level feedback-a vida step-level feedback nallaa irundhuchu-nnu kandupidichudhu; adhu oru test subset-la 78% solve pannuchu. Indha lesson-oda main resource-aana Hugging Face write-up, search-a guide panna oru PRM-a use pannuchu; podhumaana samples kuduththappo, MATH-500 benchmark-la 1B, 3B models avaththoda 8B, 70B siblings-a vendradha kaattuchu.
- **Oru scoring model-oda**, oru LLM judge maadhiri. Idhu open-ended text-kku work aagum, aana judge evvalavu nalladho avvalavu dhaan.

N answers-a sample panna kittaththatta N madangu cost aagum, adhanaala N podhuvaa chinnadhu: products-la sumaar 3 mudhal 8, research runs-la use panra noottrukkanakkaanadha vida romba kammi.

Majority voting-kku oru chinna helper. Normalising step-a gavaninga: "12.50", "25/2", "12.5" ellaam ore answer dhaan, oru plain text comparison vote-a moonaa pirichudum.

```python
from collections import Counter
from fractions import Fraction

def normalise(text):
    """Turn '12.50', ' 25/2 ' and '12.5' into the same vote. Non-numbers stay as text."""
    t = text.strip().lower().rstrip(".")
    try:
        return Fraction(t)  # exact, so rounding never splits a vote
    except (ValueError, ZeroDivisionError):
        return t

def majority_answer(ask, question, n=3):
    """ask(question) returns the model's final answer as a short string."""
    votes = Counter(normalise(ask(question)) for _ in range(n))
    best, count = votes.most_common(1)[0]
    unanimous = count == n
    # Accept only a unanimous answer. Anything else goes to the stronger model.
    return best, unanimous
```

### Reasoning models

Indha models, adikkadi check pannakkoodiya answers irukkura problems mela reinforcement learning moolamaa, reply panradhukku munnaadi neelamaa yosikka train pannappadudhu. Maths, code, planning-la ivai jolikkum; simple questions-la perumbaalum cost-um delay-um dhaan koottum.

Neenga ivaththa prompt-aala illa, oru **effort setting**-aala steer pannuveenga. Udhaaranamaa, November 2026 nilavarappadi, OpenAI-oda Responses API-la `reasoning.effort` irukku, Anthropic-oda API-la `output_config.effort` irukku; recent Claude models-la adhoda levels `low`-la irundhu `max` varai. Effort-ngradhu oru soft guidance, token count illa: low effort-la easy-aana inputs-kku model thinking-a skip pannalaam. Defaults model-kku model maarum (Anthropic-oda default perumbaalaana Claude models-la `high`, sila pudhu models-la `medium`), adhanaala effort-a explicit-aa set pannunga, rendu moonu levels-a thaniththani options-aa test pannunga. Pazhaya tutorials oru fixed thinking budget (`budget_tokens`) kaattum; Anthropic adha deprecate panniduchu, Claude 4.7-um adhukku apram vandha models-um adha reject pannum.

**Reasoning model mela chain-of-thought prompts-a adukkaadheenga.** Adhu erkanave answer panradhukku munnaadi yosikkudhu. OpenAI thannoda o1 reasoning models-a launch pannappo, adhoda prompting guide simple, direct prompts-a use pannavum, chain-of-thought instructions kudukkaama irukkavum solluchu. Anthropic mudhalla effort level-a maaththa solludhu, adhukku apram dhaan, oru task-kku innum thevaippattaa, "Think carefully before responding" maadhiri oru chinna nudge. Steps-a script pannaadheenga, ella reasoning-aiyum reply-la kekkaadheenga: maranja thinking-kku oru thadavai, adhoda visible copy-kku innoru thadavai panam kattuveenga.

### Neenga edhukku panam katturreenga, user edhukku kaathirukkaaru

- **Thinking output tokens-aa bill aagum**, neenga adha paakkave illainnaalum. Output tokens podhuvaa input tokens-a vida adhigam cost aagum.
- **Oru summary-kkum muzhu thinking-oda cost dhaan.** Anthropic thinking-oda oru chinna summary-a return panna mudiyum, aana summary-oda neelaththukku illa, adhukku pinnaadi irukkura muzhu thinking-kkum bill aagum.
- **Thinking output limit-la kanakkaagum.** Chinna replies-kku alavu vecha oru output limit (Anthropic-la `max_tokens`) thinking nadakkumbodhe theernthudalaam, reply konjam answer-oda illa answer-e illaama ninnudum. Rendukkum idam vidunga, illa effort-a kuraiynga.
- **Unmaiyaana count-a padinga.** Anthropic adha `usage.output_tokens_details.thinking_tokens`-la report pannum; OpenAI thannoda usage data-la `output_tokens_details`-kku keezha reasoning tokens-a report pannum. Ovvoru request-kkum adha log pannunga: unga bill-a vilakkura number adhu dhaan.
- **Thinking nadakkumbodhu visible-aa edhuvum stream aagaadhu.** Thinking maranjirundhaa (Anthropic-oda Claude 5 models-la adhu dhaan default), thinking mudinja apram dhaan mudhal visible vaarththai varum. User paakkura mudhal vaarththai varaikkumaana neraththa alanga, progress-aa oru status line illa oru thinking summary kaattunga.
- **Multi-turn chats-kku adhiga cost.** Conversation-la irukkura thinking aduththa turns-la input-aa bill aagum: sila models-la mundhaiya ovvoru turn-la irundhum, vera siladhula kadaisi turn-la irundhu mattum. Conversation naduvula effort level-a maaththuradhum prompt cache-a udaikkalaam.

### Methods-a pakkaththu pakkaththula vechu paaththaa

| Method | Koodudhal cost | Koodudhal kaathiruppu | Eppo best-aa work aagum | Edhula gavanam venum |
| --- | --- | --- | --- | --- |
| Step-by-step prompt | Output tokens-oda 2 mudhal 5 madangu | Vinaadigal | Non-reasoning model-la multi-step problems | Neelamaana replies; sariyaa thonum aana sariyillaadha reasoning |
| 5-oda majority vote | Sumaar 5 madangu | Parallel-aa ottinaa konjam dhaan | Exact answers: numbers, labels | Free-form text-kku payanilla; ella samples-kkum ore blind spots |
| Verifier-oda best-of-N | Sumaar N madangu, kooda checks | Parallel-aa irundhaa konjam dhaan | Code, SQL, test pannakkoodiya formats | Oru weak verifier mosamaana answers-a edukkum |
| Reasoning model | Adikkadi 3 mudhal 10 madangu | Vinaadigalla irundhu nimishangal varai | Kashtamaana maths, code, planning | Maranja thinking-kku bill; output limit romba chinnadhu |

Indha multipliers options-a compare panradhukkaana thoraayamaana patterns, prices illa. Unga sondha questions-la alandhu paarunga.

## Oru worked example

Kota-la oru coaching company, JEE-style maths problems-kku students-oda answers-a AI check panni thappugala vilakkanum-nu virumbudhu, oru naalaikku sumaar 300 problems. Teachers dhinamum pudhu practice problems ezhudhuraanga, students vera books-la irundhum doubts upload pannraanga, adhanaala perumbaalaana problems **answer key illaama** dhaan varudhu. AI mudhalla sariyaana answer-a kandupidikkanum, apram adha student-oda answer-oda compare pannanum. (Key irukkura idaththula, oru plain comparison andha pagudhiya senjudum, endha model-um thevaiyilla.)

Options-a compare panna, teachers check panna answers irukkura 200 pazhaya problems-oda oru test set-a team build pannudhu. Keezha "sari"-nnaa andha option sariyaana answer-a kandupidichudhu-nnu arththam. Adhukku apram varra explanation step ella option-kkum ore cost dhaan, adhanaala adha vittuttom. Ella numbers-um method-a kaatturadhukkaaga thernthedutha udhaaranangal dhaan; alandha prices illa.

Testing-kku munnaadiye oththukkitta targets: kurainjadhu 88% sari, 100 problems-kku ₹150-kku keezha, perumbaalaana students-kku 10 vinaadikkulla result.

| Option | Sari | 100 problems-kku cost | Vazhakkamaana kaathiruppu |
| --- | --- | --- | --- |
| Mid-size model, plain prompt | 71% | ₹20 | 3 s |
| Adhe model, step-by-step prompt | 81% | ₹55 | 8 s |
| Step-by-step, 5-oda majority | 88% | ₹275 | 9 s (parallel) |
| Reasoning model, low effort | 82% | ₹45 | 8 s |
| Reasoning model, medium effort | 90% | ₹120 | 20 s |
| Reasoning model, high effort | 91% | ₹260 | 45 s |
| Router: 3 plain answers, avai oththuppogalainnaa mattum reasoning model (medium) | 90.5% | ₹96 | 70%-kku 3 s, 30%-kku 23 s |

**Noise-a manasula vechu padinga.** 200 problems-la, 90% pakkaththula margin of error rendu pakkamum sumaar 4 points (Quality, cost, speed trade-offs lesson-a paarunga). Adhanaala quality-la 88%, 90%, 90.5%, 91% ellaam tie dhaan, cost-um kaathiruppum dhaan mudivu pannum.

- Step-by-step prompt oru periya, malivaana vetri: 100-kku ₹35 adhigamaa 10 points. Thaanaa reason pannaadha endha model-layum idha mudhalla try pannunga.
- Low effort target-a miss pannudhu. High effort, medium-a vida rendu madangukkum adhigamaa cost aagudhu, students-a 45 vinaadi kaathirukka vaikkudhu, adhuvum noise-kkulla irukkura oru gain-kkaaga. Oru effort sweep-oda vazhakkamaana shape idhu dhaan: aarambaththula periya gains, apram adhiga vilaikku chinna gains.
- 5-oda majority-yum high effort-um budget-a udaikkudhu. Medium effort quality-yaiyum cost-aiyum thaandudhu, aana ovvoru student-um 20 vinaadi kaathirukkanum, adhanaala wait target-la fail aagudhu. Router mattum dhaan moonaiyum meet pannudhu.

**Router eppadi work aagudhu, adhoda numbers enga irundhu varudhu.** Ovvoru problem-kkum mudhalla moonu vegamaana plain-prompt answers kidaikkum, parallel-aa, ovvonnum 100-kku ₹20: moththam 100-kku ₹60. Moonum oththuponaa, andha answer use aagum. Illainnaa, problem medium effort-la reasoning model-kku pogum.

- Test set-la, 200-la 140 problems-la (70%) moonum oththuppochu. Adhula 136-la oththuppona answer sari, adhaavadhu 97%. 100% illa: oru model-kku oru blind spot irundhaa, ovvoru thadavaiyum adhe sign error maadhiri, moonu samples-um adhe thappaana answer-la oththuppogum. Oththupporadhu evidence, proof illa.
- Meedhi 60 problems (30%) reasoning model-kku pochu, adhu 45-a sariyaa pannuchu, adhaavadhu 75%. Adhoda overall 90%-a vida idhu romba kammi, yenna ivai dhaan kashtamaana problems.
- Accuracy: 136 + 45 = 200-la 181, adhaavadhu 90.5%.
- Cost: samples-kku ₹60, kooda 30% problems × ₹120 = escalations-kku ₹36, adhanaala 100-kku ₹96.
- Kaathiruppu: oththuppora 70%-kku 3 vinaadi, escalate aagura 30%-kku 3 + 20 = 23 vinaadi. Reasoning model mattum use panradha vida, ellaaraiyum vida adhiga neram kaathirukkura students 3 vinaadi adhigamaa kaathirukkaanga, 95th-percentile kaathiruppa slow path dhaan set pannudhu.

Mudhal stage-la yen plain answers? Moonu step-by-step answers-kku 100-kku ₹165 aagum, reasoning model mattum use panradha vida adhigam. Mudhal stage difficulty-kkaana oru malivaana test-aa irundhaa podhum.

**Mudivu.** Avanga router-a thernthedutthaanga: noise-kkulla reasoning model-oda adhe quality, 20% malivu, 10-la 7 students-kku 20 vinaadikku badhilaa 3 vinaadiyila result. Escalate aana problems-kku app oru progress bar-oda "Checking your working carefully…" kaattudhu, yenna yedho nadakkudhu-nnu paakka mudinjaa students oru chinna kaathiruppa yeththukkuvaanga. Raaththiri muzhukka check aagura homework oru batch API vazhiyaa pogudhu; November 2026 nilavarappadi, OpenAI-um Anthropic-um adhukku normal rate-la paadhi vilai vaikkuraanga.

Escalate aana ovvoru problem-aiyum oru pudhu test case-aa log pannraanga, pudhu problems-la 97% figure-a maasaa maasam re-check pannraanga: andha number evvalavu nalladho, router-um avvalavu dhaan nalladhu.

## Podhuvaa panra thappugal

- **Ellaaththukkum reasoning model use panradhu.** Greetings, lookups, formatting-kku adhu thevaiyilla. Edhaiyum serkkaadha thinking-kku panam katturreenga.
- **Malivaana step-a skip panradhu.** Thaanaa reason pannaadha oru model-la, oru step-by-step prompt adikkadi gap-la perumpagudhiya cost-oda oru chinna pangulaye moodidum.
- **Reasoning model-kku step-by-step prompts serkkuradhu.** Adhu erkanave yosikkudhu. Adhukku badhilaa effort level-a set pannunga.
- **Thinking-kku idame illaadha output limit.** Thinking adhula kanakkaagum, adhanaala answers paadhiyila vettuppadum.
- **Free-form text mela vote panradhu.** Rendu nalla paragraphs eppavume ore maadhiri irukkaadhu, adhanaala vote-kku edhuvum kidaikkaadhu. Adhukku badhilaa oru verifier illa judge use pannunga.
- **Oththupporadha unmaiyaa eduththukkradhu.** Ore model-oda samples-kku adhoda blind spots ellaam irukkum. Unanimous answers evvalavu adikkadi sariyaa irukku-nnu alanga.
- **Oru weak verifier-a nambradhu.** Checker-a emaaththuradhu easy-nnaa, best-of-N adha ellaaththaiyum vida nallaa emaaththura answer-a edukkum.
- **Raw reasoning-a nambradhu illa kaatturadhu.** Answer-a unmaiyaa drive pannadha adhu vittudalaam, adhula thappaana thiruppangalum irukkum. Results-a check pannunga, users-kku answer-a oru chinna, check panna explanation-oda kaattunga.

## Adhiga thinking thappaana tool-aa irukkum nerangal

- **Model-kitta facts illa.** Neenda neram yosichaa knowledge seraadhu. Retrieval use pannunga.
- **Task simple illa creative.** Chinna replies, summaries, tone maaththuradhu aridhaa dhaan improve aagum.
- **Oru chinna gain-a vida latency mukkiyam.** Oru voice agent illa autocomplete paththu vinaadi kaathirukka mudiyaadhu.
- **Gain-a alakka mudiyaadhu.** Test set illaama, adhigam selavu pannuveenga, adhu udhavuchaa-nnu theriyaadhu.

## Demo-la irundhu production-ku

- **Difficulty-a poruththu route pannunga.** Easy-aana questions-a fast path-la anuppunga, oru check fail aanaa illa samples oththuppogalainnaa mattum escalate pannunga.
- **Selavukku cap vainga.** Effort-a explicit-aa set pannunga, thinking-kku idam irukkura maadhiri oru output limit set pannunga, ovvoru request-kkum thinking tokens-aiyum cost-aiyum track pannunga.
- **Progress kaattunga**, mukkiyamaa thinking maranjirukkumbodhu.
- **Effort sweep-a marupadi ottunga**, model-aiyo adhoda version-aiyo maaththumbodhu, yenna adhe level vera maadhiri behave pannalaam.

## Practice pannunga

1. Answers therinja paththu maths illa logic questions edunga. Endha chat model-layum, oru plain prompt-a, apram oru step-by-step prompt-a score pannunga.
2. Adhu thappaa panna questions-kku, ovvonnukkum anju answers sample panni majority-a edunga. Vote eththanaiya sari pannuchu? Edhaavadhu unanimous-aa irundhum thappaa irundhuchaa?
3. Oru reasoning model-kku API access irundhaa, adhe paththu questions-a rendu effort levels-la ottunga. Usage data-la irundhu thinking tokens-a log panni, oru question-kku cost-a kanakku pannunga.
4. Ovvoru method-kkum accuracy, cost, kaathiruppa ezhudhunga, oru student app-kku edha ship pannuveenga-nnu mudivu pannunga.
