## Idhu enna

AI-la perumbaalaana panam, neenga oru model-a paakkradhukku munnaadiyae selavaagidudhu: adha train panradhula. **Test-time compute** adhoda innoru pakkam. Answer panra nimishathula adhigam computing selavu panradhu, appo answer sariyaa irukka vaaippu adhigam. "Test time"-nu research-la inference-a solluvaanga, model use aagura neram.

Idha panna moonu podhuvaana vazhigal irukku.

1. **Padi padiyaa yosikka sollunga.** Idhu **chain-of-thought** (CoT) prompting: model answer-kku munnaadi adhoda reasoning-a ezhudhum. Adhukku nerunga sondham **self-critique**, model mudikkaradhukku munnaadi adhoda sondha draft-a check pannum.
2. **Pala answers-a generate panni nalladha vechukkunga.** Idhu **best-of-N**. Jeikkradha **verifier** (oru test, oru rule check, oru scoring model) vechu, illa answers exact-aa irundhaa majority vote vechu select pannuveenga.
3. **Oru reasoning model use pannunga.** Indha models answer panradhukku munnaadi neraya neram yosikka train aagirukku. Perumbaalaana models evvalavu effort selavu pannanum-nu set panna vidum, sila yosikkradha maraichu result-a mattum kaattum.

Moonumae accuracy-kaaga panatthaiyum kaathirukkura neraththaiyum trade pannum. Andha trade worth-aa-nu therinjukkradhu thaan skill.

```flow
title: Oru question-ku evvalavu yosikkanum-nu select panradhu
Pudhu question -> Plain model-kku kashtamaa? | unga test set-a check pannunga
Plain model-kku kashtamaa? -[illa]-> Plain answer | fast, selavu kammi
Plain model-kku kashtamaa? -[aamaa]-> Step-by-step prompt | idha mudhalla try pannunga
Step-by-step prompt -> Podhumaa irukkaa?
Podhumaa irukkaa? -[aamaa]-> Ship pannunga
Podhumaa irukkaa? -[illa]-> Answers-a check panna mudiyumaa? | tests, rules, exact values
Answers-a check panna mudiyumaa? -[aamaa]-> N sample panni verify pannunga | best-of-N illa vote
Answers-a check panna mudiyumaa? -[illa]-> Reasoning model | oru effort budget set pannunga
```

## Idhu eppadi work aagudhu

**Chain of thought.** Simple version oru line serkkum: "Think step by step before you answer," illa "Explain your reasoning, then give the final answer on the last line." Neenga ketkura steps-a list-um pannalaam, illa oru worked example-um kaattalaam. Indha method-a per vechcha 2022 paper, maths word problems-la periya gains-a kaattichu, apram vandha work idhu made-up facts-a kuraikkum-nu kandupidichadhu. Catch length: oru reasoned answer-la neraya tokens irukkum, ellaathukkum panamum neramum selavaagum.

**Best-of-N.** Pala answers-a kelunga, konjam variety-oda (adhiga temperature illa konjam vera prompts), apram onnu select pannunga.

- **Verifier-oda.** Generate panna code-a tests-oda run pannunga, generate panna SQL-a run panni rows varudhaa-nu paarunga, extract panna date unmaiyaana date-aanu check pannunga. Oru nalla maths verifier-oda oru sinna model, verifier illaadha sumaar 30 madangu periya model-oda match aachu-nu OpenAI kandupidichaanga.
- **Majority vote vechu**, self-consistency-nu-um solluvaanga. Adhe maths question-a aindhu thadavai kettu, romba common-aana final number-a edunga. Answers exact-aa irukkum bodhu work aagum: oru number, oru label, oru choice.
- **Oru scoring model vechu.** Oru reward model illa LLM judge ovvoru answer-aiyum rate pannum. Open-ended text-ku work aagum, aana judge evvalavu nalladho avvalavu thaan.

N answers-a sample panna sumaar N madangu selavaagum, adhanaala N perumbaalum sinnadhu: real products-la 3 la irundhu 8. Nooru, aayiram samples-oda research runs gains thodarndhu varudhu-nu kaattudhu, aana entha product-um ovvoru request-kkum adhukku pay panna mudiyaadhu.

**Reasoning models.** Idhu perumbaalum checkable answers irukkura problems-la reinforcement learning-oda train aagi, reply-kku munnaadi oru neelamaana internal chain of thought produce pannum. Idha perumbaalum oru effort illa budget setting-aala control pannuveenga. Maths, code, planning, multi-step analysis-la romba nallaa irukkum. Simple questions-la perumbaalum cost-aiyum delay-yaiyum thaan serkkum.

Majority voting-ku oru sinna helper:

```python
from collections import Counter

def majority_answer(ask, question, n=5):
    """ask(question) returns the model's final answer as a short string."""
    answers = [ask(question).strip().lower() for _ in range(n)]
    best, votes = Counter(answers).most_common(1)[0]
    agreement = votes / n
    # Low agreement is a signal: send it to a stronger model or a person.
    return best, agreement

# answer, agreement = majority_answer(ask, "If 3x + 7 = 25, what is x?")
# if agreement < 0.6: escalate(question)
```

| Method | Extra cost | Extra wait | Eppo nallaa work aagum | Edhai kavanikkanum |
| --- | --- | --- | --- | --- |
| Step-by-step prompt | Output tokens-oda 2 la irundhu 5 madangu | Seconds | Multi-step problems | Users scroll panni thaandi pogavendiya neelamaana answers |
| 5-oda majority vote | Sumaar 5 madangu | Parallel-aa run panna konjam | Exact answers: numbers, labels | Free-form text-ku use illa |
| Verifier-oda best-of-N | Sumaar N madangu + checks | Parallel-aa irundha konjam | Code, SQL, test panna mudiyura formats | Weak verifier mosamaana answers-a select pannum |
| Reasoning model | Perumbaalum 3 la irundhu 10 madangu | Seconds la irundhu minutes | Kashtamaana maths, code, planning | Easy questions-ku yosikkradhukku pay panradhu |

Indha multipliers options-a compare panna rough patterns, prices illa. Unga sondha questions-la measure pannunga.

## Oru worked example

Kota-la oru coaching company students-oda JEE-style maths problems answers-a AI check panni thappugala explain panna virumbudhu, naal-ku sumaar 300 problems. Avanga therinja answers-oda 200 problems-oda oru test set build panni options-a compare pannuraanga.

| Option | Sariyaana checks | 100 problems-ku cost | Typical wait |
| --- | --- | --- | --- |
| Mid-size model, plain prompt | 71% | ₹20 | 3 s |
| Adhe model, step-by-step prompt | 81% | ₹55 | 8 s |
| Step-by-step, 5-la majority | 88% | ₹275 | 9 s (parallel) |
| Reasoning model, medium effort | 90% | ₹120 | 20 s |
| Route: 5-la majority, votes disagree aanaa mattum reasoning model | 91% | ₹140 | Perumbaalaanadhukku 9 s, sila-vatrukku 25 s |

Numbers compare panra vazhiya kaattradhukku illustration-ku. Rendu vishayam thaniyaa theriyudhu. Step-by-step prompt oru periya, selavu kammiyaana win. Routing ella single option-aiyum jeichudhu: aindhula naalu illa aindhu samples agree aanaa, answer almost eppavum sariyaa irukkum, adhanaala disputed problems mattum (aaruvula onnu) reasoning model-kku pogudhu.

Avanga "Checking your working…"-nu oru progress bar-oda kaatturaanga, yenna ethaavadhu nadakkudhu-nu paakkura bodhu students konja neram kaathirukka othukkuvaanga.

## Podhuvaa panra thappugal

- **Ellaathukkum oru reasoning model use panradhu.** Simple lookups, greetings, formatting-ku adhu thevai illa. Edhuvum serkkaadha yosikkradhukku pay pannureenga.
- **Cheap step-a skip panradhu.** Oru step-by-step prompt perumbaalum gap-a selavula oru pagudhi-ku close pannidum.
- **Free-form text-la vote panradhu.** Rendu nalla paragraphs eppavum ore maadhiri irukkaadhu, adhanaala vote edhaiyum kandupidikkaadhu. Adhukku badhila verifier illa judge use pannunga.
- **Weak verifier-a nambradhu.** Checker-a emaatha easy-na, best-of-N adha romba nallaa emaatharadha select pannum.
- **Raw reasoning-a users-ku kaattradhu.** Adhu neelam, kuzhappalaam, thappaana thirumbangalum irukkalaam. Answer-aiyum oru sinna explanation-aiyum kaattunga.
- **Kaathirukkradha marakkradhu.** Yosikkradhu mudiyra varaikkum user-ku onnum theriyaadhu. Model-oda mudhal token illa, "user paakkura mudhal vaarthaikku aagura neram"-a measure pannunga.

## Adhiga yosikkradhu thappaana tool-na eppo

- **Model-kku facts illa.** Neram yosichaalum knowledge serkkaadhu. Retrieval use pannunga.
- **Task simple illa creative.** Short replies, summaries, tone changes perumbaalum improve aagaadhu.
- **Oru sinna gain-a vida latency mukkiyam.** Oru voice agent illa autocomplete pathu second kaathirukka mudiyaadhu.
- **Gain-a measure panna mudiyala.** Test set illaama neenga adhigam pay pannuveenga, adhu help pannunadha-nu therinjukka maattenga.

## Demo-la irundhu production-ku

- **Kashtatthukku route pannunga.** Easy questions-a fast model-kku anuppunga, oru check fail aana illa samples disagree aana mattum escalate pannunga.
- **Budget-a cap pannunga.** Effort illa thinking limits-aiyum oru maximum output length-aiyum set pannunga, ovvoru request-oda cost-aiyum track pannunga.
- **Samples-a parallel-aa run pannunga.** Aindhu answers ore neraththula oru answer-a mathiri neram edukkum.
- **Progress-a kaattunga.** Theriyura oru step illa progress message kaathirukkura neraththai kurachaa feel aaka vaikkum.
- **Disagreements-a log pannunga.** Samples disagree aagura questions thaan unga nalla test cases-um training examples-um.
