## Idhu enna

**Neural network**-na layers-oda stack. Ovvoru layer-um numbers-a ulla eduthu, weights-oda multiply panni, bias serthu, result-a **activation**-nu solra sinna non-linear function-la anuppum (ReLU maadhiri, adhu negatives-a zero aakkum). Oru layer-oda output adutha layer-oda input. Kadaisi layer prediction tharum: oru number, illa ovvoru class-kum probabilities.

Podhumaana layers-um units-um irundhaa, networks romba complex patterns-a represent pannum. **Deep learning**-na neraya layers irukkura networks.

```flow
dir: LR
Inputs | 64 features -[weights]-> Hidden layer 1 | 128 units, ReLU
Hidden layer 1 -[weights]-> Hidden layer 2 | 64 units, ReLU
Hidden layer 2 -[weights]-> Output | 5 units, softmax: leaf spot 0.81
Output -[backpropagation: a gradient for every weight]-> Inputs
```

Indha lesson-la Bengaluru-la leaf photos-a disease-padi classify panra oru agritech startup-a follow pannuvom.

## Idhu eppadi work aagudhu

**Forward pass.** Input features layers vazhiyaa poi prediction tharum.

**Loss.** Prediction evvalavu thappu-nu oru loss function alakkum: numbers-ku mean squared error, classes-ku cross-entropy.

**Backpropagation.** Chain rule use panni, ovvoru weight loss-ku evvalavu kaaranam-nu, output-la irundhu pinnaadi layer layer-aa network compute pannum. Idhu ovvoru weight-kum gradient tharum.

**Gradient descent.** Ovvoru weight-um adhoda gradient-ku ethiraa sinna step nagarum. Adam maadhiri variants ovvoru weight-kum step size-a adapt panni, perumbaalum vegamaa train aagum. Training examples-oda **batches**-la nadakkum; ella data-vayum oru thadavai paakkuradhu oru **epoch**.

**Non-linearity yen mukkiyam.** Activations illaama, stack panna layers oru linear model-a collapse aagidum. Activations networks-a features-a valaichu, serkka vaikkum.

**Overfitting-um regularisation-um.** Neraya weights irukkura networks training data-va memorise pannidum. Training loss-um validation loss-um serndhu paarunga: training loss kuraindhukitte irundhu validation loss ezhumbinaa, network overfit aagudhu. Remedies: adhigam data, data augmentation, dropout (training-la units-a random-aa off panradhu), weight decay, sinna networks, early stopping.

**Practical settings.** Learning rate (romba mukkiyam), batch size, layers-um units-um ennikkai, epochs. Unga problem type-ku therinja nalla defaults-la irundhu aarambinga.

**Eppo use pannalaam.** Images, audio, text, romba periya datasets-la neural networks thaan mudhalidam. Normal tabular business data-la gradient-boosted trees kammi effort-la perumbaalum samam illa jeikkum.

**Weights-a ennuradhu.** Layers-kku idaiyila ovvoru connection-kum oru weight, ovvoru unit-kum oru bias. Leaf network-la, mudhal hidden layer-ku 64 × 128 weights-um 128 biases-um, adhu 8,320 numbers. Rendavadhu-kku 128 × 64 + 64 = 8,256, output layer-ku 64 × 5 + 5 = 325. Mothama 16,901 numbers data-la irundhu kathukkudhu. Modern language models-ku billions irukku, aana ovvoru layer-oda kanakku adhe thaan.

**Loss curves-a padikkradhu:**

| Neenga paakkuradhu | Adhoda artham | Enna try pannalaam |
| --- | --- | --- |
| Loss thaavudhu illa valarudhu | Learning rate romba adhigam | 10 madangu kuraingga |
| Loss romba mella kurayudhu | Learning rate romba kammi, illa inputs scale aagala | Adhigam pannunga; inputs-a standardise pannunga |
| Training kurayudhu, validation ezhumbudhu | Overfitting | Dropout, weight decay, early stopping, adhigam data |
| Rendum high-aa irukku | Underfitting | Periya network, adhigam epochs, nalla features |
| Rendum serndhu kuraindhu level aagudhu | Healthy | Best validation epoch-la nillunga |

**Training loop-a vaarthaiyila.** Ovvoru epoch-kum, data-va shuffle panni batches-aa piringa. Ovvoru batch-kum, forward pass odi, loss compute panni, backpropagation-a odi gradients vaangi, optimiser weights-a update pannum. Ovvoru epoch-kum aprom, weights update pannaama validation loss compute panni, ippo varaikkum best-na model-a save pannunga. PyTorch-la irundhu Keras varaikkum ella deep learning library-yum indha pattern-a thaan follow pannum.

**NumPy-la scratch-la oru network.** Oru sinna network-a kaiyaala build panna, forward pass, loss, backpropagation, gradient descent ellaam purinjidum. Idhu XOR-a kathukkudhu, edhai endha straight line-um pirikka mudiyaadhu:

```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

W1, b1 = rng.normal(0, 1, (2, 8)), np.zeros((1, 8))
W2, b2 = rng.normal(0, 1, (8, 1)), np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))

def forward(X):
    h = np.tanh(X @ W1 + b1)              # hidden layer with a non-linearity
    return h, sigmoid(h @ W2 + b2)        # output probability

lr = 0.5
for step in range(3000):
    h, p = forward(X)
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))    # cross-entropy
    d_out = (p - y) / len(X)                       # gradient at the output (sigmoid + cross-entropy)
    dW2, db2 = h.T @ d_out, d_out.sum(0, keepdims=True)
    d_h = (d_out @ W2.T) * (1 - h ** 2)            # chain rule through tanh
    dW1, db1 = X.T @ d_h, d_h.sum(0, keepdims=True)
    W2 -= lr * dW2; b2 -= lr * db2; W1 -= lr * dW1; b1 -= lr * db1
    if step % 1000 == 0:
        print(f"step {step}: loss {loss:.3f}")

print("predictions:", forward(X)[1].round(2).ravel())     # close to 0, 1, 1, 0
```

Ovvoru framework-um idhey steps-a thaan seiyum, automatic-aa, romba periya networks-la.

**Backward pass-a numerical-aa check pannunga.** Oru weight-a konjam nagarthi loss eppadi nagarudhu-nu paarunga; adhu compute panna gradient-oda match aaganum:

```python
def loss_of(W1_):
    h = np.tanh(X @ W1_ + b1); p = sigmoid(h @ W2 + b2)
    return -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))

h, p = forward(X)
d_h = (((p - y) / len(X)) @ W2.T) * (1 - h ** 2)
analytic = (X.T @ d_h)[0, 0]
eps = 1e-5
W_plus, W_minus = W1.copy(), W1.copy(); W_plus[0, 0] += eps; W_minus[0, 0] -= eps
numeric = (loss_of(W_plus) - loss_of(W_minus)) / (2 * eps)
print(f"analytic {analytic:.6f}  numeric {numeric:.6f}")
```

**Initialisation-um scale-um mukkiyam.** Weights romba periyadhaa aarambichaa, activations saturate aagi gradients maraiyum; romba sinnadhaa irundhaa, signals layer layer-aa maraiyum. Adhanaala frameworks Kaiming, Xavier initialisation maadhiri nalla defaults use pannum. Inputs-a kooda standardise pannunga, appo endha feature-um adhoda units-naala mattum dominate aagaadhu.

**Tabular data-la neural networks, nermaiyaa.** Normal business tables-la, gradient-boosted trees romba kammi tuning-la perumbaalum neural network-a samam illa jeikkum. Romba periya data irundhaa, tables-a text illa images-oda serkkanum-naa, illa high-cardinality categories-ku embeddings kathukkanum-naa network try pannunga, adhe split-la boosting-oda compare pannunga.

## Oru worked example

Bengaluru agritech startup, leaf photos-a healthy illa naalu diseases-la onnunu classify panraanga. Mudhal step-aa, mechanics purinjukka, ovvoru image-layum irundhu eduththa 64-number features (colour, texture statistics) mela oru sinna fully connected network build panraanga:

- 64 features-oda input layer → ReLU-oda 128 units hidden layer → ReLU-oda 64 units hidden layer → softmax-oda 5 units output layer (5 classes-ku probabilities);
- cross-entropy loss, Adam optimiser, learning rate 0.001, 32 batches, 50 epochs varaikkum.

Loss curves-la training loss sirappaa kurayudhu, validation loss epoch 14-la thaazhndhu, apram ezhumbudhu. 0.3 dropout serthu, best validation epoch-la early stop panna, 78% validation accuracy kidaikkudhu. Adhe 64 features-la gradient-boosted trees 80% adaiyudhu.

Avanga kathukkittadhu: kaiyaala senja tabular features-la, network-ku edge illa. Adutha step, raw images-la convolutional network, adhu thanoda features-a thaane kathukkum, perumbaalum romba nallaa pannum. CNN lesson-la adha eppadi-nu irukku.

| Model | Validation accuracy |
| --- | --- |
| Network, regularisation illaama, 50 epochs | 74% |
| Dropout 0.3-oda network, epoch 14-la early stopping | 78% |
| Adhe 64 features-la gradient-boosted trees | 80% |
