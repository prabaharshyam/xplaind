## Idhu enna

Oru **evaluation metric** oru model-oda predictions-a, neenga compare panna mudiyura oru number-aa maathum. Veru veru metrics veru veru behaviour-a parisalikkum, adhanaala thervu use-la edhu mukkiyam-nu irukkura-dhula irundhu varanum.

| | Predicted positive | Predicted negative |
|---|---|---|
| **Unmaiyaave positive** | True positive (pidichadhu) | False negative (miss aachu) |
| **Unmaiyaave negative** | False positive (false alarm) | True negative (sariyaa fine) |

```flow
dir: LR
title: Precision-um recall-um enga irundhu varudhu
Ovvoru unmaiyaana positive -> Pidichadhu: true positives
Ovvoru unmaiyaana positive -> Miss aachu: false negatives
Ezhuppina ovvoru alarm -> Sari: true positives
Ezhuppina ovvoru alarm -> Thappu: false positives
```

**Recall** = TP / (TP + FN): unmaiyaana positives-la, evvalavu pidichinga. **Precision** = TP / (TP + FP): neenga flag panna-dhula, evvalavu sari.

Indha lesson Mumbai-la oru bank-la moonu teams-a follow pannum, ovvonnum veru problem-ku veru metric-a select panradhu.

## Idhu eppadi work aagudhu

**Classification.**

- *Accuracy*: sariyaana share. Balanced classes-ku sari; rare events-ku yemaathum.
- *Precision*: predicted positives-la, evvalavu sari. False alarms selavaana idathula mukkiyam (genuine payments-a block panradhu).
- *Recall*: actual positives-la, evvalavu pidichadhu. Misses selavaana idathula mukkiyam (miss aana fraud, miss aana noi).
- *F1*: oru threshold-la precision-um recall-um oru balance.
- *ROC AUC*: ella thresholds-layum model positives-a negatives-ku mela eppadi rank pannudhu; class balance-a paakkaadhu, adhu rare classes-la mosamaana performance-a maraikkalaam.
- *PR AUC* (average precision): positive class-la focus pannum; rare events-ku nalladhu.
- *Log loss*-um calibration-um: probabilities nambakkoodiyadhaa-nu.

**Regression.**

- *MAE*: average absolute error, original units-la; outliers-naala kammiyaa aadum, explain panna easy.
- *RMSE*: periya errors-a adhigam thandikkum; periya misses romba kettadhu-nu irukkura idathula use pannunga.
- *MAPE*: percentage error; purinjikka easy, aana zero pakkam irukkura values-la udaiyum, sinna actuals-a adhigamaa thandikkum.
- *Quantile illa pinball loss*: neenga ranges-a predict panra podhu (udhaaranathukku, promises-ku delivery time-oda 90th percentile).

**Ranking-um recommendation-um.** Precision at k, recall at k, NDCG: sariyaana items mela pakkathula vandhucha?

**Cost-weighted metrics.** Outcomes-ku panam vainga: false positive-oda selavu, false negative-oda selavu, true positive-oda value. Expected value-va adhigamaakkura model-aiyum threshold-aiyum select pannunga. Business owners-ku idhu perumbaalum romba thelivaana metric.

**Offline metric vs business KPI.** Offline metric oru proxy. Adha improve panradhu A/B tests illa pilots vazhiyaa unmaiyaana KPI-a (losses, revenue, save aana neram) nagarthudhaa-nu check pannunga.

**Segment-a.** Model average-la nalladhaa irundhu sila users-ku mosamaa irukkaradha pidikka, mukkiyamaana groups-a (region, language, customer type) metrics-a report pannunga.

**Metric-a problem-oda poruththuradhu:**

| Problem | Mosamaana error | Primary metric | Serthu report pannunga |
| --- | --- | --- | --- |
| Card fraud (rare) | Miss aana fraud | PR AUC, oru fixed alert budget-la recall | Cost-weighted value |
| Spam filter | Real email spam-la poradhu | Precision | Recall |
| Disease screening | Miss aana noi | Recall | Precision, doctors-ku vellam varaama |
| Delivery time promise | Late delivery | 90th percentile quantile loss | MAE |
| Sales forecast | Periya misses | RMSE | Reporting-ku MAE |
| Recommendations | Sambandham illaadha top items | Precision at k, NDCG | Clicks illa sign-ups-la A/B test |

**Thresholds scores-a decisions-aa maathum.** Perumbaalaana classifiers 0-kum 1-kum idaila oru score tharum. Edhukku mela oru case flag aagum-nu oru threshold select panreenga. Kammiyaana threshold adhigam positives-a pidikkum (adhiga recall), aana adhigam false alarms-a ezhuppum (kammiyaana precision); adhigamaana threshold ethirmaraiyaa irukkum. Podhuvaa sariyaana threshold-nu onnu illa: adhu ovvoru error-kum enna selavaagum, unga team evvalavu cases-a review panna mudiyum-nu poruththu irukkum. Oru common practical vazhi: capacity-a mudhalla fix pannunga, udhaaranathukku "fraud team oru naalaikku 300 alerts review pannalaam", sumaar 300 alerts tharra threshold-a select pannunga, apram andha point-la recall-a report pannunga.

**Calibration.** Oru model 0.8-nu sonnaa, adhu 80% chance-nu artham-aa? Perumbaalum illa. Calibrated model-oda scores unmaiyaana frequencies-oda poruthum: 0.8 sumaar score aana ella cases-layum, sumaar 80% positive. Makkal probability-yae vachchu act panra idathula, udhaaranathukku insurance pricing illa oru doctor-ku risk level kaattura idathula, calibration mukkiyam. Adha reliability plot-oda check pannunga, Platt scaling illa isotonic regression maadhiri vazhigalaala fix pannunga.

**Rare-event problem-la metrics, code-la.** 2% positives irukkura oru synthetic fraud maadhiri dataset, numbers evvalavu veru maadhiri nadandhukkudhu-nu kaattum:

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (accuracy_score, roc_auc_score, average_precision_score,
                             precision_score, recall_score, brier_score_loss)

X, y = make_classification(n_samples=20_000, n_features=12, weights=[0.98], class_sep=0.9, random_state=7)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=7)
p = LogisticRegression(max_iter=1000).fit(X_tr, y_tr).predict_proba(X_te)[:, 1]

print("accuracy, always 'no':", round(accuracy_score(y_te, np.zeros_like(y_te)), 3))
print("ROC AUC:", round(roc_auc_score(y_te, p), 3), " PR AUC:", round(average_precision_score(y_te, p), 3))
print("precision, recall at 0.5:", round(precision_score(y_te, p > 0.5), 3), round(recall_score(y_te, p > 0.5), 3))
print("Brier:", round(brier_score_loss(y_te, p), 4))
```

"Eppovum fraud illa"-nu predict panna sumaar 98% accuracy kidaikkum, ROC AUC nambikkaiyaa theriyum, PR AUC rare class pathi unmaiyai solludhu.

**Selavulaa irundhu threshold-a select pannunga.** Thresholds-a sweep panni, motham selavu romba kammiyaa irukkuradha vachchukkunga:

```python
def best_threshold(y_true, scores, cost_fp=200, cost_fn=15_000):
    best = None
    for t in np.linspace(0.01, 0.99, 99):
        pred = scores >= t
        fp = int(((pred == 1) & (y_true == 0)).sum())
        fn = int(((pred == 0) & (y_true == 1)).sum())
        cost = fp * cost_fp + fn * cost_fn
        if best is None or cost < best[1]:
            best = (round(float(t), 2), cost, fp, fn)
    return {"threshold": best[0], "cost_inr": best[1], "false_alarms": best[2], "missed": best[3]}

print(best_threshold(y_te, p))
```

Miss aana fraud oru false alarm-a vida 75 madangu selavaana-naa, nalla threshold 0.5-ku romba keezha irukkum.

**Vithyaasam unmaiyaanadhaa?** Oru interval kidaikka test set-a bootstrap pannunga:

```python
def bootstrap_ci(y_true, scores, metric=average_precision_score, n=1000, seed=0):
    rng = np.random.default_rng(seed)
    vals = []
    for _ in range(n):
        idx = rng.integers(0, len(y_true), len(y_true))
        if y_true[idx].sum() == 0:
            continue
        vals.append(metric(y_true[idx], scores[idx]))
    return np.percentile(vals, [2.5, 97.5]).round(3)

print("PR AUC 95% interval:", bootstrap_ci(y_te, p))
```

Rendu models-oda intervals neraya overlap aanaa, indha test set-a mattum vachchu onnu nalladhu-nu sollaadheenga.

**Oru range-a predict panradhu.** Delivery promises-ku, 90th percentile-ku train panni, pinball loss-oda score pannunga:

```python
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.metrics import mean_pinball_loss

rng = np.random.default_rng(1)
km = rng.uniform(1, 12, 3000).reshape(-1, 1)
minutes = 10 + 3 * km[:, 0] + rng.gamma(2, 4, 3000)          # skewed delays
q90 = GradientBoostingRegressor(loss="quantile", alpha=0.9).fit(km[:2000], minutes[:2000])
pred = q90.predict(km[2000:])
print("share delivered within the promise:", round(float((minutes[2000:] <= pred).mean()), 2))
print("pinball loss:", round(mean_pinball_loss(minutes[2000:], pred, alpha=0.9), 2))
```

Sumaar 90% deliveries promise panna neraththukkulla vandhirukkanum; andha share-a area vaariyaa real data-la check pannunga.

## Oru worked example

Mumbai bank-la moonu teams:

- **Card payments-la fraud** (0.2% fraud): accuracy artham illaadhadhu. Models-a compare panna PR AUC-yum, apram threshold-a select panna oru cost-weighted alavu-yum use pannuraanga (average loss-la miss aana fraud vs oru alert-ku analyst neram).
- **ATM cash demand forecasting**: cash theerndhu poradhu extra vachchirukkaradha vida romba kettadhu, adhanaala demand-oda 90th percentile-a predict panni, reporting-ku MAE-oda, quantile loss-la evaluate pannuraanga.
- **Mobile app-la product recommendations**: mela irukkura moonu suggestions mattum thaan theriyum, adhanaala precision at 3 use panni, product sign-ups-la oru A/B test-oda confirm pannuraanga.

Ovvoru team-um thanga metric-a customer segment vaariyaa report pannum. Recommendation model metros-la nalla, rural branches-oda customers-ku mosamaa work aagudhu-nu therinjudhu; rural customers-ku oru thani feature set andha gap-oda perumbaalaana pagudhiya sari panradhu.

**Business-ku thervu-a explain panradhu.** Fraud team-oda head-ku PR AUC vendaam; model bank-ku enna pannum-nu theriyanum. Adhanaala team translate pannadhu: "Oru naalaikku 300 alerts-la, ungal analysts handle pannalaam, pudhu model ovvoru 100 fraud cases-la sumaar 78-a pidikkum, 64-la irundhu. Idhu maadhathukku sumaar ₹1.1 crore losses thavirkkapadum, extra analyst neram illaama." Model metric model-a select pannadhu; rupee figure decision-a eduthadhu.

| Team | Model metric | Business translation |
| --- | --- | --- |
| Fraud | PR AUC, oru naalaikku 300 alerts-la recall | Maadhathukku thavirkkappatta losses |
| ATM cash | 90th percentile-la quantile loss | Maadhathukku cash theerndhu pora ATMs |
| Recommendations | Precision at 3 | A/B test-la extra product sign-ups |

## Podhuvaa panra thappugal

- **Imbalanced data-la accuracy.**
- **Rare events-ku ROC AUC mattum.** PR AUC-yum unga operating point-la precision-yum paarunga.
- **Sinna illa zero actuals-oda MAPE.** MAE illa weighted variants use pannunga.
- **KPI-a nagarthaadha oru metric-a optimise panradhu.** Pilots illa A/B tests-oda validate pannunga.
- **Overall numbers mattum.** Segments-a check pannunga.

- **Habit-aala threshold select panradhu.** 0.5 ariyadhaa dhaan nalla threshold. Selavula irundhum review capacity-la irundhum select pannunga.
- **Calibration check pannaama scores-a probabilities-aa edhukkiradhu.**
- **Results paathadhukku apram metric select panradhu.** Experiment-ku munnaadi onnu seruvom-nu mudivu pannunga.
- **Sinna test sets-la interval illaama**, adhanaala noise progress-aa report aagum.
- **Error costs oru pakkam saayum podhu 0.5 default threshold.**

## Oru simple metric podhum-nu irukkura idam

- **Balanced classes-um ottappaana error costs-um**: accuracy sari, explain panna easy.
- **Aarambathula explore panra podhu**, oru nalla metric ideas-a vegamaa compare panna help pannum.
- **Muzhu evaluation-ku munnaadi** oru baseline-oda oru vegamaana sanity check.

## Demo-la irundhu production-ku

- **Training-ku munnaadi metric, threshold, costs-a business owner-oda ezhudhi vainga.**
- **Intervals-aiyum segment-level metrics-aiyum report pannunga**, oru overall number mattum illa.
- **Costs, volumes illa model maarumpodhu threshold-a thirumba check pannunga.**
- **Launch-ku apram offline metric-oda serthu business KPI-a track pannunga.**
- **Yaaraavadhu probabilities-a vachchu act pannaa, calibration-a monitor pannunga.**
