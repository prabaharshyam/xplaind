## Idhu enna

Oru **test** nu solradhu unga code-a neenga thervu panna input-oda run panni, result neenga edhirpaarkkura maadhiri irukkaanu check panra chinna code. Oru **unit test** oru chinna part-a, perumbaalum oru function-a, thaniyaa check pannum. Result thappaa irundhaa, test fail aagi enga-nu solludhu.

Tests indhikku ezhudhura code-ku vida, adhukku apram varura ovvoru change-kum mukkiyam. Aaru maadham kazhichu, neengalo unga teammate-o oru function-a maathuveenga. Tests illaama, edhuvum udaiyala-nu therinjukka app-la click panni paathu nambikkai vaikka vendiyadhu thaan. Tests irundhaa, oru command run panni seconds-la therinjukkalaam.

**pytest** Python-ku standard testing tool. `test_`-nu aarambikkura simple functions ezhudhureenga, simple `assert` statements use panreenga, pytest adha kandupidichu run pannum, edhaavadhu fail aanaa enna values vithyaasamaa irundhuchu-nu kaattum.

## Idhu eppadi work aagudhu

Oru test moonu steps follow pannum, adhai **arrange, act, assert**-nu solluvaanga: inputs-a ready pannunga, code-a oru thadavai call pannunga, result-a check pannunga.

```python
# gst.py
def gst(amount: float, rate: float = 0.18) -> float:
    if amount < 0:
        raise ValueError("amount must not be negative")
    return round(amount * rate, 2)
```

```python
# test_gst.py
import pytest
from gst import gst

def test_default_rate_is_18_percent():
    assert gst(100) == 18.0

def test_rounds_to_two_decimals():
    assert gst(10.555) == 1.9

def test_negative_amount_is_refused():
    with pytest.raises(ValueError):
        gst(-1)
```

Project folder-la `pytest` run pannunga, adhu `3 passed in 0.02s` maadhiri oru result kaattum.

Neenga velai seiyura loop:

```flow
dir: LR
Code ezhudhu illa maathu -> pytest run pannu
pytest run pannu -[oru test fail aagudhu]-> Failure-a padi | edha values vithyaasam
Failure-a padi -> Code ezhudhu illa maathu
pytest run pannu -[ellaam pass]-> Commit
```

Moonu tools perumbaalaana real tests-a cover pannum:

| Tool | Enna pannum | Example use |
| --- | --- | --- |
| `@pytest.mark.parametrize` | Oru test-a palavidha inputs-la run pannum | Ovvoru GST rate: 5%, 12%, 18%, 28% |
| `@pytest.fixture` | Test peyar solli kekkura shared setup | Oru sample invoice, oru temporary folder |
| Fakes, mocks | Mellaana illa external parts-a maathum | Oru nillaana badhil tharra model client |
| `pytest.raises` | Oru error raise aagudhaa-nu check pannum | Negative amounts maruthikkappadum |
| `tmp_path` | Ovvoru test-kum pudhu temporary folder | Files ezhudhura code |

Tests-a copy panradhukku badhila **parametrise** pannunga:

```python
@pytest.mark.parametrize("amount, rate, expected", [
    (100, 0.05, 5.0),
    (100, 0.12, 12.0),
    (100, 0.28, 28.0),
])
def test_rates(amount, rate, expected):
    assert gst(amount, rate) == expected
```

**Fixtures** shared setup-a vachchirukkum:

```python
@pytest.fixture
def invoice():
    return {"items": [("Charger", 999.0), ("Cable", 299.0)], "rate": 0.18}

def test_invoice_total(invoice):
    assert invoice_total(invoice) == 1531.64
```

**Fakes** tests-a vegamaavum, ovvoru thadavaiyum ore maadhiriyum vachchirukkum. Oru function model client-a parameter-aa eduthukkittaa (idhukku **dependency injection**-nu peyar), test oru fake-a pass pannalaam:

```python
class FakeClient:
    def complete(self, prompt):
        return '{"category": "refund"}'

def test_classify_reads_category():
    assert classify("Money not returned", client=FakeClient()) == "refund"
```

**Mudhalla edha test pannanum.** Tests illaadha oru project-la, bug vandhaa romba selavaagura idathula aarambinga: panam kanakku, matha systems padikkura data, neenga maatha pora code. Apram neenga fix panra ovvoru bug-kum oru test serunga. AI projects-la, rendu vagaiya thaniyaa vainga: ungalodaiya sondha parsing, validation, scoring logic-ku vegamaana unit tests, ovvoru commit-lum run aagum, apram real model-oda golden set-la mellaana evaluation runs, oru schedule-la run aagum. Rendayum kalandha, dhinasari tests mellaa, flaky-aa aaidum.

## Oru worked example

Sneha Chennai-la oru logistics company-la invoice-extraction service-a maintain panraanga. Oru customer ₹0.50 rounding vithyaasam irundha oru invoice reject aachu-nu report panraanga. Veru edhaiyum udaikkaama adha fix panna virumburaanga.

**Mudhalla, fail aagura oru test.** Code-a thodaradhukku munnaadi, bug-a reproduce panra oru test ezhudhuraanga: lines ₹1,180.00-ku kootunga, aana print aana total ₹1,180.50 irukkura oru invoice. Business ₹1 varaikkum rounding allow pannum, adhanaala test adha accept pannanum-nu edhirpaarkkum. pytest run pannuraanga: pudhu test fail aagudhu, adhu bug-a pidikkudhu-nu nirubikkudhu.

**Apram fix.** `validate_total`-la, check `lines_total == printed_total`-nu irundhuchu. Adha `abs(lines_total - printed_total) <= 1.0`-nu maathuraanga. Pudhu test pass aagudhu.

**Apram edges.** ₹1 tolerance pudhu kelvigala kilappudhu, adhanaala parametrise panraanga: sariyaa ₹1 vithyaasam accept aagum, ₹1.01 reject aagum, negative vithyaasam positive maadhirithaan. Oru case fail aagudhu: floating-point error-naala avangoda check ₹1.01 vithyaasatha accept pannidhu. Amounts-a `Decimal`-ku maathuraanga, ellaa cases-um pass aagudhu.

**Kadaisiyaa, muzhu suite.** 214 tests-ayum run panraanga. Edhaiyum sambandham illaadha oru test fail aagudhu: adhu oru forged invoice-a reject panna pazhaya exact-match behaviour-a nambi irundhuchu. Team-oda pesi, forgery check oru thani rule use pannanum-nu mudivu pannuraanga, rendayum update panraanga. Tests illaama irundhaa, andha forgery check production-la sappunu velai seiyaama poirukkum.

## Podhuvaa panra thappugal

- **Happy path mattum test panradhu.** Bugs edges-la irukkum: zero, empty lists, negatives, romba periya values, missing fields.
- **Pathu vishayatha check panra oru test.** Fail aanaa edhu-nu theriyaadhu. Oru test-ku oru behaviour, enna-nu solra peyar-oda.
- **Onnukkonnu illa order-a saarndhirukkura tests.** Ovvoru test-um thanakku vendiyadha set panni thaniyaa pass aaganum.
- **Unit tests-la real network illa model calls.** Mellaa irukkum, kaasu selavaagum, tests-a flaky aakkum. Fake pannunga; real service-a thaniyaa, kammiyaa test pannunga.
- **Bug fix pannadhukku apram tests ezhudharadhu.** Mudhalla fail aagura test-a ezhudhunga, appo adhu bug-a unmaiyaave pidikkudhu-nu theriyum.
- **100% coverage-kku thurathuradhu.** Coverage edhu run aachu-nu kaattum, check aachaa-nu illa. Mukkiyamaana behaviour-a test pannunga.
