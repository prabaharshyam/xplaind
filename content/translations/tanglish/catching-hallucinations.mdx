## Idhu enna

**Hallucination**-na facts-aala illa model-ku kodutha source-aala support aagaadha, confident-aana answer, illa adhoda oru pagudhi. 2023-la oru law firm-ku, oru chatbot kattina cases-a court filings-la submit pannadhukku fine pottaanga. Danger model-ku sure illa-nu illa; adhu sure-aa pesudhu-nu thaan.

Correctness-la rendu useful vagai irukku:

- **Local factual consistency**: answer oru kodutha source-oda, example retrieved document, company policy, illa data-vodu othu pogudhaa? Idhu summaries, support assistants, RAG apps-ku mukkiyam.
- **Global factual consistency**: ellaarum othukkura facts-oda othu pogudhaa? Idhu open chat, research, fact-checking-ku mukkiyam.

Local consistency check panradhu romba easy, yenna source kaila irukku. Models-ku retrieval vazhiyaa facts-a kodukkanum-nu solla idhu innoru karanam.

**Yen nadakkudhu.** Rendu explanations romba pesapadudhu:

1. **Self-delusion, illa snowballing.** Model-ku, thanakku kodutha text-um thaan ezhudhina text-um onnu-nu theriyaadhu. Mudhal sentence konjam thappaa irundhaa, aprom varra sentences adha fact-aa eduthukitu build pannum.
2. **Model-ku theriyaadhadha kathukkodukkuradhu.** Training-la, models-ku theriyaadha vishayangal theriyum aalgal ezhudhina answers-a copy pannum. Adhu, andha knowledge illaamalae confident-aana answers kodukka kathukkodukkum.

Practice-la, hallucinations rendu idathula kuvikkum: model rombavum paarkkaadha **niche topics**, appuram **illaadha vishayangala pathi kelvigal** (RBI edhuvum sollaadha podhu "X pathi RBI enna sonnaanga?").

```flow

Answer -> Thani claims-aa pirikkuradhu
Thani claims-aa pirikkuradhu -> Ovvoru claim-aiyum thaniyaa nikka vaikkuradhu | "adhu"-ku badhila subject-a podunga

Evidence thedunga -> Ovvoru claim-aiyum judge pannunga | supported, contradicted, unknown
```

## Idhu eppadi work aagudhu

**Mudhalla thadunga.** Detection thavara thappi vandhadha pidikkum; prevention adhoda alavai kammi pannum.

- Model-ku facts-a kodunga: documents-ku retrieval, live data-ku tools.
- Kodutha sources-la irundhu mattum answer panna sollunga, illaina "theriyaadhu" illa "documents idha cover panala"-nu solla sollunga.
- Ovvoru claim-kum source passage-oda citation kelunga, adhula kuduthirukkura passage irukkaa-nu check pannunga.
- Factual tasks-ku temperature-a kammiyaa vainga, neelamaana tasks-a chinna steps-aa pirichunga, appo errors snowball aagaadhu.

**Unga model engae hallucinate panudhu-nu kandupidinga.** Detectors build panradhukku munnaadi, fail aana answers-a padichu group pannunga. Weak spots-a target panra test cases build pannunga: rare topics, false premise irukkura kelvigal, sources-aala badhil sollamudiyaadha kelvigal. Idhu illaadha test set, real users paarkkaadha oru aaruthalaana number-a kaattum.

**Judge vechu detect pannunga.** Oru judge model-ku source-aiyum answer-aiyum kuduthu, source support pannaadha edhaavadhu answer-la irukkaa-nu kelunga. Strong models idha nallaa pannum, especially short answers-la. Nambarathukku munnaadi, oru sample-la human labels-oda judge-a check pannunga.

**Claim-by-claim detect pannunga.** Neelamaana answers-la unmai, poi statements kalandhu irukkum, adhanaala oru verdict problems-a maraikkum. Google DeepMind-oda SAFE method pattern-a kaattudhu: answer-a thani claims-aa pirichu, ovvonnayum thaniyaa nikkura maadhiri maathi ezhudhi, evidence thedi, appuram ovvoru claim-aiyum judge pannunga. RAG apps-ku, "search" step-nu sollradhu retrieved passages dhaan.

**Entailment model vechu detect pannunga.** Natural language inference (NLI) models oru premise (source), oru hypothesis (claim) eduthukitu **entailment** (supported), **contradiction**, illa **neutral** (theriyaadhu)-nu sollum. Idhukku train panna chinna, open models ovvoru claim-kum vegamaa, cheap-aa odum.

**Marubadiyum sample panni detect pannunga.** SelfCheckGPT, adhe kelvikku pudhu answers-a pala thadavai sample pannum. Adhu original answer-oda claims-oda othu pogalana, andha claims kattunadhaa irukkalaam, yenna model unmaiyaa theriyardhadha thirumba solum, katturadhadha maathi maathi solum. Idhukku source thevai illa, aana selavu pala madangu aagum, adhanaala spot checks-ku illa high-stakes answers-ku use pannunga.

Entailment model vechu oru simple claim checker:

```python
def unsupported_claims(answer, sources, split_claims, entails):
    """split_claims(text) -> list of standalone claims.
    entails(premise, claim) -> 'entailment' | 'contradiction' | 'neutral'."""
    flagged = []
    for claim in split_claims(answer):
        verdicts = [entails(src, claim) for src in sources]
        if "entailment" not in verdicts:
            flagged.append({"claim": claim, "contradicted": "contradiction" in verdicts})
    return flagged
```

## Oru worked example

Bengaluru-la oru fintech, Income Tax Act-oda retrieved sections-um CBDT circulars-um vechu freelancers-oda income tax kelvigalukku badhil solra oru assistant-a nadathudhu. Oru tax lawyer 100 answers-a review panni, 9-la support illaadha claim irukkunnu kandupidikkiraanga. Aaru, rare deductions pathi; moonu, illaadha circulars-a describe panradhu.

Avanga steps:

1. **Targeted test set.** 150 kelvigal: common-aanadhu, rare deductions, appuram false premises irukkura 30 kelvigal ("Section 44ADA-la freelancer GST pathi 2025 circular enna solludhu?").
2. **Prevention.** Prompt ippo passages-la irundhu mattum answer panna, adhu kelvia cover pannalana thelivaa sollavum, ovvoru claim-kum section-a cite pannavum solludhu.
3. **Ovvoru answer-kum detection.** Oru entailment model ovvoru claim-aiyum retrieved passages-oda check pannum. Support illaadha claims-a eduthudum, core answer adhai nambi irundhaa, assistant answer panna mudiyaadhu-nu sollittu oru chartered accountant-a suggest pannum.
4. **Vaaram thorum review.** Oru judge model oru sample-a score pannum, checks flag panna ellaathaiyum lawyer review pannuvaanga.

| 150-question set-la measure | Munnaadi | Aprom |
| --- | --- | --- |
| Edhaavadhu support illaadha claim irukkura answers | 11% | 2% |
| False-premise kelvigala unmai-nu ninaichu badhil sonnadhu | 60% | 7% |
| Refuse panna koodaadha podhu refuse panra answers | 1% | 4% |

Numbers purposeukku mattum. Kadaisi row-la trade-off-a gavanikkunga: strict-aana checks assistant-a konjam adhigamaa refuse panna vaikkum. Team rendu numbers-aiyum track panraanga, yenna ellathaiyum refuse panra assistant-um oru failure thaan.

## Podhuvaa panra thappugal

- **Model-ku nallaa theriyura kelvigala mattum test panradhu.** Rare topics-um false-premise kelvigalum serunga, illaina unga score unga-ala puzhaiyaa solludhu.
- **Neelamaana answer-ku oru verdict.** Claims-a onnu onna check pannunga; onbadhu unmai sentences-kulla oru kattuna number olinjirukkalaam.
- **Citations-a check pannaama nambradhu.** Cite panna passage irukkaa-nu, adhu claim-a support pannudhaa-nu confirm pannunga.
- **Source kaila irukkum podhu general knowledge-oda check panradhu.** RAG app-la retrieved passages-oda judge pannunga.
- **Hallucinations-a mattum ennuradhu.** Refusals-aiyum track pannunga, appo fixes assistant-a use illaama aakkaadhu.
- **Periya model idha sari pannidum-nu ninaikkradhu.** Periya models common facts-la kammiyaa hallucinate pannum, aana niche, false-premise kelvigalla innum kattum.

## Detection mattum podhaadha neramgal

- **High-stakes answers**, legal, medical, financial advice maadhiri, loop-la oru qualified aal thevai.
- **Nambakkoodiya source illa.** Facts enna-nu unga-ala sollamudiyaadhaa, entha checker-aalayum mudiyaadhu.
- **Real-time voice**-la claim checks-ku neram irukkaadhu; adhukku badhila safe, scripted topics-ku mattum limit pannunga.

## Demo-la irundhu production-ku

- **Ovvoru answer-kum cheap checks** (citations, entailment) odunga, selavaana checks-a oru sample-la odunga.
- **Flag panna ovvoru claim-aiyum** source-oda log pannunga, appo reviewers retrieval illa documents-a sari pannalaam.
- **Topic vaaripaa hallucination, refusal rates-a track pannunga,** model illa prompt update-ku aprom thideernu maatram vandhaa alert pannunga.
- **Confirm aana failures-a test set-la serunga,** appo adhu theriyaama thirumba varaadhu.
