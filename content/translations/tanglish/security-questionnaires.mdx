## Idhu enna

**Security questionnaire** (vendor risk assessment) nu oru enterprise, oru supplier-ku data illa systems-ku access kudukkuradhukku munnaadi adha check panra vazhi. Idhu client-oda sondha spreadsheet-aa irukkalaam, Cloud Security Alliance-oda CAIQ, illa SIG questionnaire maadhiri standard-aa irukkalaam, illa oru vendor-risk platform-oda portal-aa irukkalaam. Questions inga cover pannum:

- company-oda security programme, policies, certifications (SOC 2, ISO 27001);
- access control, authentication, staff vetting;
- transit-layum rest-layum encryption, key management;
- network security, vulnerability management, penetration tests;
- logging, monitoring, incident response;
- business continuity, backups, disaster recovery;
- data handling: location, retention, deletion, sub-processors;
- adhoda, adhigamaa, AI-specific questions: client data-la training, model providers, prompt injection, output review, human oversight.

```flow
Questionnaire, 240 questions -> Answer library
Answer library -[170 match aachu]-> Evidence links-oda review pannina answers
Answer library -[40 AI-specific]-> Design docs-la irundhu badhil | data flow map, gateway config, masking rules, guardrail tests, approval step, audit log schema
Answer library -[30 client-specific]-> Legal-oda sernthu draft | RBI outsourcing, localisation
Design docs-la irundhu badhil -> Gaps: 'Partially' + oru dated plan
Legal-oda sernthu draft -> Gaps: 'Partially' + oru dated plan
Gaps: 'Partially' + oru dated plan -[pudhu answers thirumba serkkapadum]-> Answer library
```

Indha lesson, Bengaluru-la oru AI startup-la FDE-aa irukkura Meera-va follow pannum; oru nalla pilot-ku aprom oru periya private bank-oda questionnaire-ku badhil solraanga.

## Idhu eppadi work aagudhu

**Answer library build pannunga.** Perumbaalaana questions clients-ku clients thirumba thirumba varum. Approved answers-oda review pannina oru library vechukkunga, ovvonnukkum oru owner, last-checked date, evidence links (policy documents, SOC 2 report, penetration test summary, architecture diagrams) irukkattum. Pudhu questionnaires-ku adhula irundhu badhil sollunga, review-ku aprom pudhu answers-a thirumba serunga.

**Thulliyamaavum unmaiyaavum badhil sollunga.** Detail illaama "Yes" nu sonna follow-ups varum; adhigam claim panradhu contract breach-aa maaralaam. Nalla answers enna, eppadi, enga-nu solluvaanga: "Ellaa data-vum Central India-la Azure Key Vault-la irukkura keys-oda AES-256-la rest-la encrypt aagudhu; keys varushaththukku oru dhadava rotate aagum."

**Partial-um planned-um.** "Partially" nu oru vilakkam-oda, meedhikku oru date-oda sollradhu okay; false "Yes" okay illa.

**AI section.** Thirumba thirumba ungaluku kekkapadum badhilgala thayaaraa vechukkunga:

- Edhu model providers-um regions-um use aagudhu, entha terms-la (data-la training, retention)?
- Model-ku enna data anuppuraanga, personal data mask aagudhaa?
- Prompt injection-a eppadi handle panraanga, risky actions-ku outputs-a makkal review panraangala?
- Enna guardrails, audit logs, kill switches irukku?
- Model illa prompt changes release-ku munnaadi eppadi test aagudhu?

**Sub-processors.** Client data-va thodra ovvoru third party-yum (cloud, model provider, tracing tool, email service) purpose-oda location-oda list pannunga. Pudhusaa serkkura sub-processors-a adhirkka clients-ku urimai irukkalaam.

**Evidence-um NDAs-um.** Muzhu SOC 2 report maadhiri sensitive evidence-a, non-disclosure agreement-oda, expire aagura secure link-vazhiyaa share pannunga.

**Weak, strong answers:**

| Question | Weak | Strong |
| --- | --- | --- |
| Rest-la encryption? | "Yes" | "AES-256, Azure Key Vault keys, Central India; varushaththukku oru dhadava rotate" |
| Data training-ku use aagudhaa? | "No" | "Provider X-oda contract client data-la training-a vilakkudhu; retention 30 days; clause 7.2 attached" |
| Prompt injection? | "Industry-standard AI security use panrom" | "Least-privilege tools, outbound actions-ku approval, CI-la ottura injection test set; latest results attached" |
| Pen testing? | "Yes" | "Web app-ku varushaanthira external test; adutha maadham book aana test-la AI endpoints serkkapattirukku" |

**Library-a uyirodu vechukkradhu.** Ovvoru answer-kum oru owner (perumbaalum andha control-a nadathuravanga) -um oru review date-um kudunga. Architecture maarum podhu, pudhu model provider illa pudhu tracing tool maadhiri, library-la paadhikkapatta answers-a thedi, adhe vaaramae update pannunga. Ovvoru questionnaire-kum aprom, pudhu questions-um avatrukku review pannina answers-um serunga. Ippadi maintain panna library, rendu vaara thinaralai, konjam naal-la kavanamaa seiyura velaiyaa maathidum.

**Client-oda reviewers-oda velai.** Follow-up calls irukkum-nu edhirpaarunga. System theriyra engineer-a, data flow map-a, evidence-a kooda kondu vaarunga. Ungaluku therinjadha mattum sollunga, check pannanum-nu irukkuradha ezhudhi vechitu, adhe naal anuppunga. "Idhu innum pannala, idhu thaan plan" nu solra vendors-a, ellaathaiyum seiyuromnu solra vendors-a vida reviewers romba nambuvaanga.

**Answer library data-vaa.** Answers-a code maadhiri team review panra oru file-la store pannunga, bookkeeping-a oru script paathukkattum:

```yaml
# security-answers.yaml
- id: enc-at-rest
  question: Is customer data encrypted at rest?
  answer: >
    Yes. Postgres and object storage use AES-256 with keys in Azure Key Vault (Central India), rotated yearly.
  owner: platform-lead
  evidence: [docs/architecture.pdf#storage, key-vault-policy.pdf]
  reviewed: 2026-09-14
  tags: [encryption, storage]
- id: ai-training
  question: Is our data used to train AI models?
  answer: >
    No. Our model provider's enterprise terms exclude training on API data; retention is 30 days for abuse
    monitoring (terms version and clause attached).
  owner: cto
  evidence: [provider-terms-2026-07.pdf]
  reviewed: 2026-07-30
  tags: [ai, vendor]
```

```python
import yaml
from datetime import date, timedelta

def load(path="security-answers.yaml"):
    return yaml.safe_load(open(path))

def stale(answers, max_age_days=180):
    cutoff = date.today() - timedelta(days=max_age_days)
    return [(a["id"], a["owner"]) for a in answers if a["reviewed"] < cutoff or not a.get("evidence")]

def suggest(question, answers, top=3):
    words = set(question.lower().split())
    scored = sorted(answers, key=lambda a: -len(words & set((a["question"] + " " + " ".join(a["tags"])).lower().split())))
    return [a["id"] for a in scored[:top]]
```

`stale`-a maadha maadham ottunga, ovvoru owner-kum avanga list-a anuppunga. Pudhu questionnaire-ku candidate answers-a kandupidikka `suggest` (illa periya libraries-ku embeddings) use pannunga, aana ovvoru answer-um velila poradhukku munnaadi oru aal check pannanum: model illa keyword match, close-aa irukkura aana thappaana answer-a pickup pannalaam.

**AI-vodu draft panradhu, kavanamaa.** Oru model, unga library-yum architecture notes-yum vechu answers-a draft pannum; neelamaana questionnaires-la neram migum. Rules: adhu library-yum attach pannina documents-yum mattum use pannalaam, ovvoru draft-um adhu use panna library ids-a cite pannanum, ovvoru answer-um oru peyar kudutha aal approve pannanum. Ungalitta illaadha oru control-a oru model-a ezhuthi vida vidaadheenga.

**AI section-a current-aa vechukkradhu.** Unga model providers-a, avangaloda terms-a check pannina date-oda, use panra regions-a, enna data anuppuraanga, adhu mask aagudhaa, guardrails-um avatroda test results-um, kill switches, prompt-um model changes-um eppadi test aagudhu, sub-processor list-a list pannunga. Idhula edhu maarunaalum adhe vaaram indha section-a update pannunga.

**Pazhasaagaadha evidence.** Therinja living documents-a (ippo irukkura architecture diagram, latest eval-um penetration test summaries-um) link pannunga, aana pazhaya aagura text-a paste pannaadheenga. Injection tests-oda permission tests-oda CI results-a oru sirusaana PDF-aa export panna vidhamaa vechukkunga, yen-na AI-specific evidence thaan reviewers munnaadi paathirukka vaaippu kammi.

## Oru worked example

Bengaluru-la oru AI startup, oru periya private bank-oda nalla pilot-ku aprom, rendu vaara deadline-oda 240-question spreadsheet-a pervaanga. FDE-aana Meera coordinate pannuraanga.

Answer library-la irundhu aarambikkiraanga, adhu 170 questions-a cover pannudhu. Meedhi irukkuradhula, 40 AI-specific, 30 bank-specific (example, RBI outsourcing guidelines, data localisation).

AI questions-ku system-oda unmaiyaana design documents-a use panraanga: data flow map, gateway configuration (Indian region mattum, model provider data-la train pannaadha-nu contract), masking rules, test results-oda guardrail list, customer-facing messages-ku human approval step, audit log schema. Ovvoru answer-um poruththamaana document section-a cite pannum.

Rendu questions unmaiyaana gaps-a velila kondu varudhu: AI endpoints-ku varushaanthira formal penetration test illa, model misbehaviour-ku mattum documented incident plan illa. Rendukkum "Partially" nu badhil solraanga, adutha maadham book panna external penetration test-um, attach pannina draft incident runbook-um-oda. Bank-oda security team andha plan-a conditions-oda otthukkudhu, contract vazhakkamaana moonu maadhathukku badhila naalu vaarathula munnetrudhu.

| Questionnaire-oda pagudhi | Ennikkai | Eppadi handle pannaanga |
| --- | --- | --- |
| Library-la irundhu badhil | 170 | Checks-oda thirumba use |
| AI-specific | 40 | Citations-oda design documents-la irundhu badhil |
| Bank-specific | 30 | Legal-oda draft |
| Gaps | 2 | Book pannina pen test-um draft runbook-um-oda "Partially" |
| Result | | Moonu maadhathukku badhila naalu vaarathula contract |

## Podhuvaa panra thappugal

- **Adhigam claim panradhu.** False "Yes", pinnaadi legal problem-aa aagalam. "Partially"-nu sollitu vilakkunga.
- **Ovvoru dhadavayum modhalla irundhu aarambikkiradhu.** Owners-um dates-um-oda answer library maintain pannunga.
- **Kuzhappamaana AI answers.** "Industry-standard AI security use panrom" nu sonna artham illa. Providers, regions, terms, controls-a peyar sollunga.
- **Sub-processors-a marakkradhu.** Client data-va paakkura tracing illa email tool-um count aagum.
- **Library-a pazhasaa vidradhu.** Poona varushatha architecture pathi answers thappaana answers.
- **Owner-um review date-um illaadha answers.** Avai pazhasaanaalum yaarukkum theriyaadhu.
- **Oru aal ovvoru answer-yum check pannaama AI-draft pannina answers-a anuppradhu.**
- **Pudhu sub-processors-a marakkradhu**, poona maadham serthaa tracing tool maadhiri.

## Muzhu library overkill-aa irukkura idangal

- **Unga mudhal oru rendu questionnaires**: kavanamaa badhil sollunga, apram andha answers-a library-aa maathunga.
- **Sirusaana clients**, email-la konjam questions kekkuravanga: adhe thulliyathoda neraiya badhil sollunga.
- **Internal projects**, company-oda sondha security review process cover panradhu.

## Demo-la irundhu production-ku

- **Library-a version control-la vechukkunga**, owners, dates, evidence links-oda.
- **Pazhaya answers-a maadha maadham flag pannunga**, ovvoru architecture change-layum.
- **Sub-processor list-a maintain pannunga**, ovvonnukkum purpose-um location-um-oda.
- **AI test results-a export pannunga** (injection, permissions, guardrails), evidence-aa.
- **Ovvoru questionnaire-yum track pannunga**, adhoda date, anuppina answers-oda version, vaakku kuduthha follow-ups-oda.
