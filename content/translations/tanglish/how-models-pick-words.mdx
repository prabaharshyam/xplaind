## Idhu enna

Oru language model muzhu answer-a oru thadavaiyilae ezhudhaadhu. Oru nerathula oru **token** ezhudhum (token-na oru word illa oru word-oda pagudhi). Ovvonna select panna, adhu theriyura ovvoru token-kum oru score tharum, application scores-a chances-aa maathum, onna select pannum. Select panna token text-la serum, answer mudiyura varaikkum adutha token-kum ellaam marubadiyum nadakkum.

Indha select panra step-ku peru **sampling**. Adha maathradhukku model-a maathanum-nu illa. API call-la sila settings, select pannura thunichal evvalavu irukkum-nu mudivu pannum: **temperature**, **top-p**, **top-k**. Neenga panra ovvoru LLM call-layum perumbaalum thotta poradhu indha settings thaan.

Idhu thaan ore prompt rendu vera answers-a tharadhukku reason. Model oru stored reply-a thedala. Ovvoru step-layum sila reasonable adutha tokens irukku, sampling adhula onna select pannum.

```flow
dir: LR
title: Oru reply ezhudhura oru step
Prompt-um ippo varaikkum text-um -> Model ovvoru token-kum score tharum | logits
Model ovvoru token-kum score tharum -> Temperature scores-a reshape pannum
Temperature scores-a reshape pannum -> Chances serndhu 100 percent aagum | softmax
Chances serndhu 100 percent aagum -> Top-k, top-p saathiyam kammi tokens-a veliyeththum
Top-k, top-p saathiyam kammi tokens-a veliyeththum -> Chance-padi random-aa onna select pannu
Chance-padi random-aa onna select pannu -> Adha text-la serkkum
Adha text-la serkkum -> Prompt-um ippo varaikkum text-um
```

Indha lesson-la Bengaluru-la oru fintech team-a follow pannuvom, avanga moonu LLM features serkkuraanga, ovvonnukkum settings select pannanum.

## Idhu eppadi work aagudhu

1. **Model sambavikka koodiya ovvoru adutha token-kum score tharum.** Indha raw scores-ku peru **logits**. Perusa number-na, inga andha token poruthama irukkum-nu model ninaikkudhu-nu artham. Oru vocabulary-la paththu aayirakkanakkaana tokens irukku, adhanaala ovvoru step-layum paththu aayirakkanakkaana scores.
2. **Softmax scores-a chances-aa maathum.** Ovvoru score-um 0-kum 1-kum idaiyila oru number aagum, ella numbers-um serndhu 1 varum. Adhigam score irukkura token-ku adhigam chance, aana ellaa chance-um illa.
3. **Temperature mudhalla scores-a reshape pannum.** Softmax-ku munnaadi, ovvoru logit-um temperature-aala divide aagum. **Kammi** temperature (0.2 solluvom) gaps-a perusaakkum, adhanaala top token kittathatta ellaa chance-yum edukkum. **Adhigam** temperature (1.5 solluvom) gaps-a sirusaakkum, adhanaala aroomaiyaana tokens-ku unmaiyaana chance kidaikkum. Sariyaa 1-la edhuvum maaraadhu. 0-la model eppavum top token-a edukkum, adhuku peru **greedy** decoding.
4. **Top-k, top-p list-a vettum.** **Top-k** top k tokens-a mattum vachukkum, example 40. **Top-p** (nucleus sampling-num solluvaanga) chances serndhu p varra, sirusaana tokens group-a vachukkum, example 0.9. Meedhi irukkuravangala chances marubadiyum serndhu 1 aagura maadhiri scale up aagum.
5. **Oru token random-aa select aagum, adhoda chance-a poruththu.** 60% irukkura token, paththula aaru thadavai select aagum. Apram loop marubadiyum aarambikkum.
6. **Niruththum**, model oru end token ezhudhinaalum, maximum length-a thottaalum, neenga select panna **stop sequence** vandhaalum.

**Ovvoru setting-um enna pannum:**

| Setting | Edha control pannum | Kammi value | Adhigam value |
| --- | --- | --- | --- |
| Temperature | Chances evvalavu flat | Steady, romba safe-aana wording-a repeat pannum | Adhigam varied, adhigam surprising, nonsense varra risk adhigam |
| Top-p | Saathiyamaana mass-la evvalavu vachukkanum | Kammi options, safe | Adhigam options, adhigam variety |
| Top-k | Evvalavu tokens vachukkanum | Kammi options, safe | Adhigam options, adhigam variety |
| Max tokens | Anumadhi aana neelamaana reply | Vilai kammi, vettappadalaam | Neelam, adhigam selavu |
| Stop sequences | Reply-a mudikkura text | Edhuvum thevai illa | Kattuppaadu illaama pogura output-a niruththi selavu migaikkum |

Model romba urudhiya irukkum podhu top-k-um top-p-um vera maadhiri nadandhukkum. Oru token-ku 95% chance irundhaa, top-p 0.9 andha oru token-a mattum vachukkalaam, top-k 40 innum 40 vachukkum. Adhanaala thaan top-p, model evvalavu urudhiya irukku-nu adjust aagum, top-k aagaadhu.

Defaults provider-kum model-kum maarum, sila pudhu models indha settings-la sila-vatra fix pannum illa ignore pannum. Neenga use panra model-ku, provider-oda documentation-a check pannunga.

## Oru worked example

"My favourite Indian city to visit is" prompt-a eduthukkunga, model anju adutha tokens-ku indha scores tharudhu-nu vechukkunga. Maths-a follow panna easy-aa irukka numbers-a naanga kalpitham panniruken.

| Token | Score (logit) |
| --- | --- |
| Mumbai | 3.0 |
| Delhi | 2.5 |
| Chennai | 1.5 |
| Jaipur | 0.5 |
| Pune | -0.5 |

Naalu temperatures-la chances:

| Temperature | Mumbai | Delhi | Chennai | Jaipur | Pune |
| --- | --- | --- | --- | --- | --- |
| 0.2 | 92.4% | 7.6% | 0.1% | 0.0% | 0.0% |
| 0.5 | 70.2% | 25.8% | 3.5% | 0.5% | 0.1% |
| 1.0 | 51.5% | 31.2% | 11.5% | 4.2% | 1.6% |
| 2.0 | 36.9% | 28.7% | 17.4% | 10.6% | 6.4% |

0.2-la model kittathatta ovvoru thadavaiyum "Mumbai"-nu solludhu. 2.0-la, pathinaaru thadavaila oru thadavai Pune-nu solludhu.

Ippo temperature 1.0-la list-a vettunga. Mela irundhu chances-a serthaa: Mumbai 51.5%, apram Delhi 82.7%, apram Chennai 94.2%. **Top-p 0.9**-la, 90%-a ettura sirusaana group andha moonu. **Top-k 3**-la, group-um andha moonu thaan. Adhoda chances 100% aagura maadhiri scale up aagum: Mumbai 54.7%, Delhi 33.1%, Chennai 12.2%. Jaipur-yum Pune-yum ini select aaga mudiyaadhu.

Maths-a konjam Python lines-la check pannalaam:

```python
import numpy as np

tokens = ["Mumbai", "Delhi", "Chennai", "Jaipur", "Pune"]
logits = np.array([3.0, 2.5, 1.5, 0.5, -0.5])

def chances(logits, temperature=1.0):
    scaled = logits / temperature
    e = np.exp(scaled - scaled.max())      # subtract the max for numeric safety
    return e / e.sum()

for t in (0.2, 0.5, 1.0, 2.0):
    print(t, np.round(chances(logits, t) * 100, 1))

def top_p(probs, p=0.9):
    order = np.argsort(-probs)
    keep, total = [], 0.0
    for i in order:
        keep.append(i)
        total += probs[i]
        if total >= p:
            break
    out = np.zeros_like(probs)
    out[keep] = probs[keep]
    return out / out.sum()

print(np.round(top_p(chances(logits)) * 100, 1))   # [54.7 33.1 12.2  0.   0. ]
rng = np.random.default_rng(0)
print(tokens[rng.choice(5, p=top_p(chances(logits)))])
```

## Aam velaigalukku aarambikka points

Idhu aarambikka points, rules illa. Unga sondha examples-la test pannunga.

| Velai | Try panna temperature | Yen |
| --- | --- | --- |
| Extraction, classification, routing | 0 mudhal 0.2 | Oru sariyaana answer, adhanaala steady thaan best |
| Documents-la irundhu answers (RAG) | 0 mudhal 0.3 | Sources-kku kittathatta irukkanum |
| Code ezhudhuradhu illa fix panradhu | 0 mudhal 0.3 | Sinna maatrangal code-a udaikkalaam |

## Indha settings thappaana lever-aa irukkura idangal

- **Hallucinations-a nirutha.** Kammi temperature model-a ovvoru thadavaiyum top choice-a edukka vaikkum, aana top choice thappaa irukkalaam. Model-ku facts kudunga (retrieval), sources kelunga, answer-a check pannunga. Grounding, citations lesson-a paarunga.
- **Valid JSON vaanga.** Kammi temperature clean JSON tharum-nu nambikkai vaikkaadheenga. Structured output use pannunga, adhu model-a unga format-kulla kattuppaduthum. Structured output lesson-a paarunga.
- **Results-a exact-aa repeat aaga vaikka.** Temperature 0-la kooda, servers requests-a eppadi batch panni arithmetic panraanga-ngradhaala runs-ku idaiyila outputs konjam vera aagalaam. Audit trail thevai-na, input, settings, output-a log pannunga.
- **Theliva illaadha prompt-a sari panna.** Instruction theliva illaadhadhaala answers maarudhunaa, prompt-a tight pannuradhu edha setting-a vida adhigam help pannum.

## Playground-la irundhu production varai

- **Settings-a oru idathula vainga.** Temperature, matha settings-a ovvoru task-kum config-la store pannunga, code muzhukka sidharaama illa, ovvoru call-oda log pannunga, appo oru mosamaana answer-a reproduce pannalaam.
- **Oru thadavai-kku mela test pannunga.** Ovvoru test question-aiyum moonu mudhal anju thadavai odunga. Runs-ku idaiyila scores romba maarinaa, oru run enna kaattinaalum, andha feature pothumaana alavu steady illa.
- **Pala answers sample panradhu oru tool, default illa.** Pala answers generate panni, athigama onnu pattadha, illa oru judge virumburadha select pannalaam. Idhu kashtamaana reasoning questions-a pala thadavai improve pannum, aana pala madangu selavu, delay-yum serum. Risk adhigama irukkura idathula use pannunga.
- **Selavu-a cap pannunga.** Max tokens set pannunga, reply-ku theliva mudivu irundhaa stop sequence-um serunga, appo oru aroomaiyaana reply odi odi panam selavaakkaadhu.
- **Randomness irundhaa mattum thaan retry help pannum.** Temperature 0-la, ade call-a marubadiyum odinaa bodhuvaa ade thappaana answer thaan varum.

## Podhuvaa panra thappugal

- **Ellaa idathulayum default temperature use panradhu.** Extraction-kum brainstorming-kum romba vera settings thevai.
- **Temperature-yum top-p-yum serthu maathradhu.** Rendum ore choice-a reshape pannum. Onna maathi, test panni, apram innonnu thottalaamaanu mudivu pannunga.
- **Temperature 0-na correct-nu nambradhu.** Adhu steady-nu artham, steady-aana thappaana answer innum thappu thaan.
- **Factual tasks-ku "adhigam creative" answers-kaaga adhigam temperature vaikkradhu.** Adhigam variety-yum, adhigam thappugalum kidaikkum.
- **Oru run-la irundhu oru setting-a judge panradhu.** Oru adhirshtamaana illa adhirshtam illaadha sample konjam thaan sollum. Pala thadavai odunga.
- **Stop sequence illa max tokens-a marakkaradhu.** Mudiyaadha reply-ku panam selavaagum.
