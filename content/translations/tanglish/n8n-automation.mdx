## Idhu enna

**n8n** ("n-eight-n"-nu solluvaanga) oru workflow automation tool. **Nodes**-a connect panni, visual canvas-la automations build pannuveenga. Ovvoru node-um oru vishayam pannum: pudhu email-a paakkum, spreadsheet padikkum, API call pannum, AI model-a kekkum, message anuppum. Data oru node-la irundhu adutha node-ku pogum.

Idhu Zapier illa Make maadhiri, aana makkal mathikkura rendu vithiyaasam irukku. Neenga adha unga own server-la **self-host** pannalaam, data unga kaila irukkum, volume-la selavum kammi. Adhoda strong **AI nodes**-um irukku, reason panni, tools use panni, oru conversation-a nyaabagam vechukkura AI Agent node-um serthu.

**Workflow automation**-na business use: oru chinna team already use panra apps naduvula software data-va nagarthuradhaala vaaram-ku neraya mani neram thirumbi kidaikkum.

```flow
Trigger: form enquiry | a webhook -> AI Agent | classify and draft a reply
Memory: past chats -> AI Agent
Model, prompt and tools -> AI Agent
AI Agent -> About fees?
About fees? -[yes]-> Sheet: log it -> Gmail: a draft for approval
About fees? -[no]-> Slack: alert the staff
```

## Idhu eppadi work aagudhu

**Triggers thaan ellaathayum start pannum.** Common-aana-vai: schedule (dhinamum 9 a.m.), webhook (vera app oru URL-a call pannum), app triggers (pudhu Gmail message, Google Sheets-la pudhu row), chatbots-ku chat trigger.

**Nodes velai seiyum.** n8n-la nooru kanakkaana integrations irukku: Google Workspace, Slack, Notion, Airtable, HubSpot, databases, edhavadhu API-ku HTTP requests, official Business API vazhiyaa WhatsApp. IF, Switch, Merge, Loop maadhiri **logic nodes** flow-va control pannum.

**Data JSON-aa pogum.** Ovvoru node-um items-a output pannum. Appuram varra nodes `{{ $json.email }}` maadhiri **expressions** vachu adha padikkum. Ovvoru step-layum exact data-va paakkalaam, adhanaala code-la irukkradha vida debug panna romba easy.

**AI nodes.** AI Agent node oru chat model (Claude, GPT, Gemini illa local model), oru system prompt, **memory**, **tools**-a serkkum. Tools vera nodes-aa irukkalaam, "search this sheet", "create a calendar event" maadhiri, adhanaala agent pesa mattum illa, velaiyum seiyum. Text-a classify panna, fields-a structured data-va edukka, summarise panna simple nodes-um irukku.

**Credentials** oru thadavai store aagi thirumba use aagum, adhanaala API keys workflows-kulla eppavum irukkaadhu.

**Odikkradhu.** Vegamaa start panna n8n Cloud use pannunga, illa oru chinna server-la Docker-oda self-host pannunga. Sample data-vodu test panni, appuram workflow-a activate pannunga, appo thaanaa odum.

| Building block | Edhukku | Example |
|---|---|---|
| Schedule trigger | kurippitta neram-la odum | 8 a.m.-ku daily sales summary |
| Webhook | vera app-ku udane react pannum | payment gateway success event |
| HTTP Request | edhavadhu API-a call pannum | exchange rates edukkum |
| IF / Switch | conditions-la branch pannum | enquiries-a type-a vechu route pannum |
| AI Agent | tools-oda reason panni velai seiyum | price sheet-a vechu FAQs-ku badhil solum |
| Information Extractor | text-a fields-aa maathum | invoice-la amount, date padikkum |
| Wait / approval | oru aalukkaaga nikkum | reply anuppradhukku munnaadi approve |
| Error workflow | failures-a pidikkum | run fail aanaa Slack-la alert |

**Nambradhukku munnaadi test pannunga.** n8n workflow-a kaiyaala odikka vidum, trigger-la sample data-va pin pannalaam, adhanaala ovvoru test-layum ore input varum, ovvoru node-oda output-ayum step by step paakkalaam. Real maadhiri kuzhappamaana data-vodu test pannunga: Hinglish-la oru enquiry, oru kaali field, moonu attachments-oda oru email. Perumbaalaana automation bugs yaarum try pannaadha inputs-la irundhu thaan varum.

**Kavanikkavendiya selavugal.** Ovvoru AI step-kum oru call-ku konjam selavu, n8n Cloud plans maasathukku evvalavu workflow runs kidaikkum-nu limit pannum. Client-ku maasa cost-a promise panradhukku munnaadi, providers-oda sites-la current limits-ayum model prices-ayum check pannunga.

## Oru example

Arvind Jaipur-la 600 students-oda oru coaching institute nadathuraanga. Enquiries Google Form-la ethuvum neram varum, front desk marunaal thaan reply pannum, adhukkulla neraya parents oru competitor-a phone pannidraanga.

Avar oru madhiyam-kulla oru workflow build panraanga:

1. Ovvoru pudhu enquiry-layum **Google Forms trigger**.
2. Batch timings, fees, demo-class schedule irukkura prompt-oda **AI Agent**. Adhu enquiry-a fees, timings, demo, other-nu classify panni, parent use panna language-la, Hindi illa English, oru reply-a draft pannum.
3. **IF node:** demo requests nerukku Google Calendar tool-ku pogum, adhu adutha free slot-a book pannum.
4. **Google Sheets** ovvoru enquiry-ayum, adhoda category-yum, draft-ayum log pannum.
5. **Gmail** anuppura mail illa, oru draft-a uruvaakkum. Front-desk manager phone-la irundhu approve pannuvaanga.

Mudhal maasathula median reply time 14 mani neram-la irundhu 25 nimisham-aa kuraiyudhu, demo bookings moonla onnu adhigamaagudhu. Rendu vaaram, kittatha edit illaama drafts-a approve pannina apram, Arvind "timings" category-a thaanaa anuppa vidraar, fees-ku approval-a vechukkuraar, yenna adhula thappu selavaanadhu.

Oru raathri Sheets API konjam neram fail aanappo, avar-oda error workflow Slack alert anuppudhu, run thirumba try aagudhu, adhanaala oru enquiry-um miss aagala.

## Podhuvaa panra thappugal

**Kuzhappamaana process-a automate panradhu.** Mudhalla steps-a ezhudhi simple aakkunga; automation oru mosamaana process-a innum vegamaa fail aaka vaikkum.

**Aarambathulaye AI review illaama anuppa vidradhu.** Drafts-oda, human approval-oda start pannunga. Neenda kaalam nalla output kuduthadha category-ku mattum approval-a edunga.

**Error handling illaama irukkradhu.** APIs fail aagum. Retries, error workflow, alerts serunga, illa-na failures vaarakkanakkaa theriyaama pogum.

**Keys, values-a code-kulla fix pannidradhu.** Keys-ku credentials-ayum, prices maadhiri maarra values-ku settings node illa sheet-ayum use pannunga.

**Oru periya workflow.** Periya automations-a, ottrai oru vittu call panra chinna workflows-aa pirichukkunga. Test panna, fix panna easy.

**Data protection-a kandukkaama irukkradhu.** Prompts-layum logs-layum irukkura customer data personal data. Thevaiyaanadha mattum edunga, ovvoru service-um enga store pannudhu-nu therinjukkunga.
