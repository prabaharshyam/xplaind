## Idhu enna

**Handover**-na oru system-a adha own panna pora aalgalukku plan panni transfer panradhu. Idhula moonu pagudhi irukku:

- Ovvoru audience-kum **Documentation**: users, operators, developers, owners.
- **Knowledge transfer**: training, pairing, neenga innum available-aa irukkumbodhu client-oda team system-a run panra oru period.
- **Formal close**: handover complete-nu agree panna criteria, access remove, venumna oru support arrangement.

AI systems-ku extra handover material thevai, yen-na adhoda behaviour code-ah mattum illa, prompts, models, data, evals-a poruthu irukku.

```flow
dir: LR
title: Naalu vaaraththula handover
Week 1: shadow | avanga neenga operate panradha paathu docs padippaanga -> Week 2: reverse shadow | avanga prompt-a maathi, simulated incident-a handle pannuvaanga; neenga paarpeenga
Week 2: reverse shadow -> Week 3: run alone | avanga KPI report-um cost review-um run pannuvaanga
Week 3: run alone -> Week 4: close | checklist sign-off, unga access remove, secrets rotate, support terms
```

| Reader | Documents |
|---|---|
| Users | Oru guide |
| Operators | Runbooks |
| Developers | How-tos, architecture |
| Owners | KPIs, costs, risks |
| Ellarukkum | Decision records |

Indha lesson, Chennai-la oru lender-oda credit-file assistant handover-a follow pannum.

## Idhu eppadi work aagudhu

**Ovvoru reader-kum ezhudhunga.** Oru useful split (Diátaxis framework-la irundhu): kathukka tutorials, tasks-ku how-to guides, facts-ku reference, reasons-ku explanations.

- *Users*: system-a nallaa use panna oru short guide, edhula nallaa, edhula mosam, outputs-a eppadi check panradhu, feedback eppadi tharadhu.
- *Operators*: routine tasks-ku, therinja incidents-ku **runbooks**, example "model provider errors tharudhu", "answers pazhaya documents-a reference panradhu", "costs spike aagudhu", "connector nindruchu". Ovvoru runbook-layum: symptoms, checks, fix, escalation.
- *Developers*: architecture overview, locally eppadi run panradhu, eppadi deploy panradhu, prompt-a paadhukaappa eppadi maathuradhu, configuration enga irukku.
- *Owners*: system enna seiyudhu, adhoda KPI-um ippo irukkura numbers-um, risks, costs, edutha decisions reasons-oda.

**AI-ku mattum thevaiyaana mukkiyamaanadhu.** Golden sets, evals-a eppadi run panradhu; ippo use aagura prompt-um model versions-um, adha eppadi maathuradhu; data pipeline, re-index eppadi panradhu; guardrails, adhoda test sets; audit log schema; cost dashboard; therinja failure modes examples-oda.

**Decision records.** Mukkiyamaana choices-ku short notes: enna decide pannom, alternatives, yen. Adutha team nalla decisions-a undo panradhayum, mosamaana experiments-a repeat panradhayum idhu thadukkum.

**Shadow, apram reverse shadow.** Mudhalla client-oda engineers neenga system-a operate panni maathuradha paarpaanga. Apram avanga seiyvaanga, neenga paarpeenga: oru deploy, CI vazhiya evals-oda oru prompt change, runbook-la irundhu oru simulated incident. Ovvoru core task-aiyum avangalae seidhu mudikkumbodhu handover complete.

**Clean exit.** Unga access-a remove pannunga, shared secrets-a rotate pannunga, accounts-um billing-um transfer pannunga, support terms-a confirm pannunga.

**Oru runbook page:**

| Section | Example: "answers pazhaya documents-a cite panradhu" |
| --- | --- |
| Symptoms | Users pazhaya rates sollraanga; refusal rate normal; feedback-la dates pathi irukku |
| Checks | Index freshness dashboard; last pipeline run; effective-date filter setting |
| Fix | Paadhikkapatta source-ku indexing job-a thirumba run pannunga; superseded flags-a confirm pannunga |
| Verify | Ippo irukkura rates pathi golden set-la irundhu moonu test questions kelunga |
| Escalate | Source connector rendu thadava fail aanaa, platform team lead-a contact pannunga |

**Handover checklist.** Sign-off-ku munnaadi, ovvoru item-aiyum adha seidha client engineer-oda peroda tick pannunga: oru release deploy pannadhu; onna rollback pannadhu; CI vazhiya evals-oda oru prompt-a maathunadhu; oru source-a re-index pannadhu; runbooks-la irundhu rendu simulated incidents handle pannadhu; monthly KPI-um cost report-um produce pannadhu; oru secret-a rotate pannadhu. Kudutha documents-um remove panna accounts-um serungga. Client-oda team sign panna checklist engagement-oda mudivu-a clear-aa kaattum, enna handover aachu-nu disputes varaama paathukkum.

**Angae illaadhavangalukku ezhudhuradhu.** Reader oru varusham kazhichu join panraanga, unga team-a paathadhae illa-nu assume pannunga. Vishayangal yen appadi irukku-nu explain pannunga, decision records-ku link kudunga, examples real-aa vechukkunga. Project-ku velila irukkura oruthara ovvoru how-to guide-aiyum help illaama follow panna sollunga, avanga ottikkura ovvoru idaththayum fix pannunga.

## Oru worked example

Chennai lender-oda credit-file assistant handover-ku naalu vaaram aagudhu.

Vaaram 1: lender-oda rendu engineers, Karthik-um Divya-vum, daily operations-la ungaloda pair panni, developer docs-a padichu, 23 questions kekkaraanga, adhu doc fixes-aa maarudhu.

Vaaram 2: Divya oru pudhu regional format-ku summary prompt-a maathuraanga. CI-la eval suite-a run panni, golden set-la 1.5-point drop paathu, oru instruction-a fix panni merge panraanga. Karthik "document store-ku connector nindruchu"-nu oru simulated incident-a runbook vechu 25 nimidathula handle panraanga.

Vaaram 3: monthly KPI report-aiyum cost review-aiyum avangalae run panraanga; operations team-oda champion, unga user guide-a vechu pudhu officers-ku oru training session nadathuraanga.

Vaaram 4: handover checklist padi sign-off, unga accounts remove, neenga use panna gateway keys rotate, escalations-ku mattum moonu maadha support agreement.

Aaru maadham kazhichu, Karthik evals pass aana apram gateway-kku pinnaadi irukkura model-a unga-a kooptaama upgrade panraanga. Idhu thaan oru successful handover.

| Vaaram | Transfer aanadhukku evidence |
|---|---|
| 1 | Client engineers-oda 23 questions doc fixes-aa maarinadhu |
| 2 | Divya-oda prompt change CI-la 1.5-point drop-a pidichu fix pannidhu; Karthik oru simulated connector incident-a 25 nimidathula theerthaanga |
| 3 | KPI-um cost reviews-um client team run pannaanga; officer training-a avanga champion nadathunaanga |
| 4 | Checklist sign aachu; accounts remove; gateway keys rotate; moonu maadha escalation support |
| Aaru maadham kazhichu | Evals pass aana apram Karthik model-a upgrade pannaanga, kooptaama |

## Podhuvaa panra thappugal

- **Oru periya document.** Veru veru readers-ku veru veru documents thevai.
- **Runbooks illaama irukkradhu.** Operators mudhal incident-la thaan system-a kathukkuvaanga.
- **Evals-a vittudradhu.** Golden sets-um eval scripts-um illaama, client prompts-a, models-a paadhukaappa maatha mudiyaadhu.
- **Kadaisi vaaraththula handover.** Pilot-laye aarambinga; adhukku neramum practice-um thevai.
- **Access-a marakkradhu.** Unga keys-um accounts-um remove aaganum, secrets rotate aaganum.

## Practice pannunga

3. Oru friend-a unga how-to guide-aiyum oru runbook-aiyum unga help illaama follow panna sollunga; avanga kekkura ovvoru question-aiyum note panni, docs-a fix pannunga.

**Mudinjadhu-nu eppo sollalaam:** Vera oruthar prompt-a maathi, evals run panni, deploy panradha, unga documents mattum vechu paarkka mudiyum.
