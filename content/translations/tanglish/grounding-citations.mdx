## Idhu enna

Oru RAG system passages-a retrieve panni, adhula irundhu badhil solla model-a kekkum. Andha passages-kulla irukka model-a edhuvum force pannaadhu. Training-la kathukkitta vishayangala kalakkalaam, gaps-a nambuvadhu maadhiri detail-la nirappalaam, documents cover pannaadha kelvikkum badhil sollalaam. **Grounding**-na badhil-a sources-oda ottiyiruka vaikkura techniques:

- kodutha passages-a mattum use pannunga-nu solra instructions;
- ovvoru claim-aiyum adhai support panra passage-oda link panra **citations**;
- passages-la badhil illaina, thelivaana **refusal** path;
- badhil adhoda sources-ku **faithful**-aa irukkudhaa-nu, automatic-aa illa manushanaal, oru check.

```flow
Question -> Retrieve passages | [1] Leave Policy v4, 3.2, p.6; [2] Leave Policy v4, 3.4, p.7; [3] Travel Policy v2, 1.1, p.2
Retrieve passages -> Prompt | use only these, cite ids, refuse with a next step
Prompt -> Answer | "Earned leave carries forward up to 45 days [1]. The policies do not cover sick leave carry-forward; ask hr-help."
Answer -> Checks | ids exist? quotes match? every claim supported?
```

Indha lesson-la Bengaluru-la oru IT services firm-oda HR assistant pilot-a follow pannuvom.

## Idhu eppadi work aagudhu

**Sources-a mark pannunga.** Retrieve aana ovvoru passage-aiyum prompt-la oru id-oda, adhoda origin-oda podunga, udhaaranam `[3] Leave Policy v4, section 2.1, page 6`. Ids citations-a possible aakkum, debugging-a easy-aa aakkum.

**Thulliyamaa instruct pannunga.** Model-kitta sollunga: passages-la irundhu mattum badhil sollu; oru passage-a use panra ovvoru sentence-kum aprom id-a cite pannu; passages badhil sollalainaa, adha sollittu yaarukitta kekkalaam-nu suggest pannu. Cite panna oru badhil-ukkum, oru refusal-ukkum oru short example kaattunga. Models rules-a vida examples-a nallaa follow pannum.

**Irukkura idathula built-in citations use pannunga.** Pala model APIs citations-a structured data-vaa tharum: exact quoted span-um, adhu edha document-la irundhu vandhadhu-nu. Idhu text-la bracketed numbers kekkaradhai vida nambikkaiyaanadhu, yenna andha quote source-la irukkunu API guarantee pannum.

**Generation-kku aprom check pannunga.** Cheap-la irundhu thorough varaikkum moonu practical checks:

1. Cite panna ovvoru id-um anuppina passages-la irukkanum. Aindhu passages mattum anuppina bodhu `[7]`-a cite panra badhil-a drop pannunga illa flag pannunga.
2. Quoted spans source text-la unmaiyilaye irukkanum (string match).
3. Oru faithfulness score: rendavadhu model, illa RAGAS maadhiri eval library, badhil-a claims-aa pirichu, ovvonnayum passages-oda check pannum. Idha ungaloda golden set-la offline-laum, live traffic-oda oru sample-layum odunga.

**Refusal-a design pannunga.** "I could not find this in the HR policies. For leave encashment questions, contact hr-help@..." useful. Verum "I don't know" illa. Refusal rate-a track pannunga: romba adhigam-naa retrieval fail aagudhu; kashtamaana golden set-la zero-ku kittathula irundhaa, model guess pannudhu.

**Checks-um avai enna pidikkum-nu:**

| Check | Cost | Edhai pidikkum |
| --- | --- | --- |
| Cite panna ids irukku | Free, code mattum | Kathai kattina citation numbers |
| Quotes source-la irukku | Free, string match | Kandupidicha illa maathina quotes |
| Ovvoru sentence-kum citation irukku | Free, code mattum | Support illaadha sentences |
| Rendavadhu model-oda faithfulness score | Oru extra call | Oru citation unmaiyila support pannaadha claims |
| Oru sample-a manushan review | Staff neram | Sooksumamaana thappugal, tone problems |

**Users-ku sources-a kaattuvadhu.** Citation-a adhu support panra sentence-kku pakkathula podunga, adhu quoted passage-a adhoda section, page-oda thirakkum padi pannunga. Appo users avangalukku mukkiyamaana answers-a check pannuvaanga, nambikkai varum, long holiday-ku munnaadi leave rules maadhiri, mismatches-a report pannuvaanga, adhu thirumba golden set-ku pogum.

**Code-la built-in citations.** Anthropic-oda API anuppina documents-a neradiyaa cite pannum. Ovvoru passage-aiyum citations on pannina oru document-aa anuppunga:

```python
import anthropic

client = anthropic.Anthropic()

def cited_answer(question, passages):
    docs = [{"type": "document",
             "source": {"type": "text", "media_type": "text/plain", "data": p["text"]},
             "title": f"{p['title']}, section {p['section']}, page {p['page']}",
             "citations": {"enabled": True}} for p in passages]
    reply = client.messages.create(
        model="claude-sonnet-5-5", max_tokens=600,          # check the docs for current names
        system="Answer only from the documents. If they do not answer the question, say so "
               "and suggest who to contact.",
        messages=[{"role": "user", "content": docs + [{"type": "text", "text": question}]}])
    parts = []
    for block in reply.content:
        if block.type != "text":
            continue
        cites = [f'{passages[c.document_index]["title"]}: "{c.cited_text}"' for c in (block.citations or [])]
        parts.append({"text": block.text, "sources": cites})
    return parts
```

Badhil-oda ovvoru pagudhi-yum adhu nambina exact text-oda varum, sentence-kku pakkathula kaattalaam. Citations illaadha pagudhigal thaan paakka vendiyavai: onnu general wording, illa support illaadha claim.

**Bracket-style citations-ku checks.** Plain text-la `[n]` markers kekkum bodhu, code-la check pannunga:

```python
import re

def check_citations(answer, n_passages, passages_text):
    problems = []
    sentences = [s for s in re.split(r"(?<=[.!?])\s+", answer.strip()) if s]
    for s in sentences:
        ids = [int(x) for x in re.findall(r"\[(\d+)\]", s)]
        if not ids and len(s.split()) > 5:
            problems.append(f"no citation: {s[:60]}")
        for i in ids:
            if not 1 <= i <= n_passages:
                problems.append(f"cites [{i}] but only {n_passages} passages were sent")
    for quote in re.findall(r'"([^"]{12,})"', answer):
        if not any(quote in p for p in passages_text):
            problems.append(f"quote not in any passage: {quote[:40]}")
    return problems
```

Problems irukkura answers-a stakes-a poruthu, oru thadavai regenerate pannalaam, warning-oda kaattalaam, illa review-ku anuppalaam.

**Grounding unmai illa.** Source pazhasaa illa thappaa irundha, perfect-aa cite panna badhil-um thappaa irukkalaam. Retrieval-la maathappatta documents-a filter pannunga, ovvoru citation-oda document-oda date-a kaattunga, oru thappaana source-a users report panna vidunga.

**Scale-la faithfulness.** Golden set-ku, live traffic-oda oru sample-ku, ovvoru badhil-aiyum claims-aa pirichu, ovvonnayum cite panna passages-oda oru judge model-oda check pannunga. Support illaadha claims-oda pagudhiya neram-vaari, topic-vaari track pannunga.

## Oru worked example

Bengaluru IT services firm-ku adhoda leave, travel, reimbursement policies mela oru HR assistant venum. Pilot-la oru employee kekkaraanga: "Can I carry forward unused sick leave?"

Retrieve aana passages earned leave carry-forward-a (45 days varaikkum) cover pannudhu, aana sick leave pathi onnum sollala. Mudhal version badhil sonnadhu: "Yes, you can carry forward up to 45 days of leave." Sick leave-ku idhu thappu, adhuvum unmaiyaa solli irukku.

Neenga moonu vishayam maathureenga. Prompt ippo ovvoru sentence-kum citation kekkudhu, oru refusal example-um irukku. API-oda citation feature-ku maarureenga, appo ovvoru claim-kum quoted span varum. Citation illaadha claims-oda badhil-a flag panra check-um serkkureenga.

Pudhu badhil: "The policies I have cover carry-forward of earned leave: up to 45 days [Leave Policy v4, 3.2]. They do not say whether sick leave can be carried forward. Please check with HR at hr-help." Employee citation-a click panni clause-a padikkalaam.

80-question golden set-la, faithfulness 0.81-la irundhu 0.96-ku yeruthu, badhil illaadha kelvigalukku refusal sonna pagudhi 30%-la irundhu 85%-ku pogudhu. Badhil kidaikkura kelvigalukku sariyaana badhil konjam thaan maarudhu. Moonu numbers-aiyum client-ku report pannureenga.

## Podhuvaa panra thappugal

- **Passage-a illa, document-a cite panradhu.** "Source: HR Policies.pdf"-a check panna mudiyaadhu. Section, page-a cite pannunga.
- **Golden set-la badhil illaadha kelvigal illa.** Appo guess panradhu measure aagaadhu. Set-la kammiyaa aindhil oru pagudhiya documents-la badhil illaadhadhaa vainga.
- **Model ezhudhina citation numbers-a nambradhu.** Models sila samayam claim-a support pannaadha passage-a cite pannum. Citations-a thaanaagavae check pannunga.
- **Adutha step illaadha refusals.** User-a oru person, team, form-ku point pannunga.
- **Users-kitta sources-a maraikkradhu.** Quoted passage-a kaattuna nambikkai varum, system miss panna thappugala users pidippaanga.
- **Checks illaama citations-a parse panradhu.** Ids irukkudhaa, quotes match aagudhaa-nu verify pannunga.
- **Citation illaadha sentences-a maraikkradhu.** Avai thaan support illaadhadha irukka romba vaaippu.
- **Pazhaya documents-a cite panradhu.** Dates kaattunga, maathappatta versions-a filter pannunga.

## Citations kammi mukkiyam-aana idangal

- **Creative illa drafting tasks,** model documents-la irundhu facts solla illaadha idam.

- **Internal brainstorming,** makkal output-a facts-aa illa, ideas-aa paakkum idam.

Users facts-a vechu act pannum bodhu citations avasiyam: policies, prices, eligibility, health, legal, financial information.
