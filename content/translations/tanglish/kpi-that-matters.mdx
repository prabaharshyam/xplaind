## Idhu enna

**KPI** (key performance indicator)-na project work aachaa-nu sollra number. Oru AI deployment-ku perumbaalum ungalukku thevai:

- Business result-oda connect aana **oru primary KPI**: oru loan file-ku nimidam, first-response time, oru officer oru naalaikku process panra claims, resolve aana ticket-ku cost.
- **Oru baseline**: ungaloda system-ku munnaadi, adhe conditions-la measure panna KPI.
- **Oru target-um oru date-um**: "pilot start-la irundhu ettu vaaraththukkulla, oru file-ku 40-la irundhu 20 nimidam".
- **Guardrail measures**: mosamaagakoodaadhavai, example error rate, customer complaints, compliance exceptions.
- **Adoption**: makkal system-a unmaiyaa use panraangala-nu, yen-na yaarum use pannaadha tool KPI-a nagartha mudiyaadhu.

Accuracy, faithfulness maadhiri model metrics inputs, KPI illa. Yaarukkum neram micham pannaadha 95%-accurate extractor oru failure.

| Scope of work-la sign panna KPI plan | |
|---|---|
| **Primary** | Oru loan file-ku median officer nimidam |
| **Baseline** | 41 nimidam (loan-system timestamps, 4 vaaram, 6,200 files) |
| **Target** | Pilot start-la irundhu 10 vaaraththukkulla 22 nimidam |
| **Guardrails** | Rework adhikapatcham 7%; audit policy exceptions-la uyarvu illa |
| **Adoption** | Officers, avanga files-la kurainjadhu 80%-la draft-a use pannuvaanga |

## Idhu eppadi work aagudhu

**Problem statement-la irundhu aarambinga.** Discovery-la officers oru file-ku 40 nimidam selavu panraanga-nu kandupidichaa, KPI "AI accuracy" illa, oru file-ku time.

**Ungalukku kidaikkura data-la measurable-aa aakkunga.** Surveys-a vida systems already record panra numbers-a prefer pannunga (loan system-la timestamps, ticket close times). Edhuvum record panlana, mudhalla measurement-a set up pannunga: oru sample cases-ku start-um end-um times-oda oru simple log.

**Baseline-a sariyaa measure pannunga.** Adhe team, adhe maadhiri cases, podhumaana volume (konjam nooru cases illa rendu-la irundhu naalu vaaram). Seasonal effects-a paarunga: month-end rush normal illa.

**Guardrails-a yosichu choose pannunga.** Adhigam errors-oda vegamaa process panradhu oru win illa. Client-oda risk owners kavanikkura oru illa rendu quality measures-a pick pannunga.

**Ezhudhthula agree pannunga.** KPI, baseline method, target, guardrails, measurement period-a scope of work-la vainga, business owner sign panni.

**Nyaayamaa compare pannunga.** Pilot-la, system-oda users-a adhe kaalaththula system illaadha similar users-oda illa adhe users-a before-after, theriyura differences-a adjust panni compare pannunga.

**Regular-aa report pannunga.** Vaaram oru oru-line update ("indha vaaram oru file-ku median 26 nimidam, 41-la irundhu kuraindhu; rework 7% baseline-ku 5.8%; 82% officers active") ellaraiyum align-aa vechirukkum.

**Inputs-um outcomes-um:**

| Input (model illa system) | Outcome (business) |
| --- | --- |
| Extraction accuracy | Oru loan file-ku nimidam |
| Retrieval recall | Oru policy question-ku badhil solla aagura time |
| Faithfulness score | Rework illa complaint rate |
| Latency | Oru agent oru manineraththula handle panra calls |
| Uptime | Oru naalaikku process aana claims |

**Nyaayamaana comparisons.** Mudinjaa, pilot users-a, adhe vaarangal-la system-a innum use pannaadha similar users-oda compare pannunga, appo month-end rush maadhiri seasonal maatrangal rendu groups-aiyum paadhikkum. Ellarukkum oru neraththula tool kidaicha, adhe users-a before-after compare pannunga, vera enna maarinadhu-nu note pannunga, example oru pudhu policy illa staffing. Pilot aarambikka munnaadiyae method-a measurement plan-la ezhudhunga, appo yaarum apram oru sadhagamaana comparison-a pick panna mudiyaadhu.

**Vaaram oru line.** KPI-um guardrail-um adoption-um irukkura oru vaakkiyam, ovvoru vaaramum anuppunga: "Indha vaaram oru file-ku median 26 nimidam, 41-la irundhu kuraindhu; rework 7% baseline-ku 5.8%; 82% officers active." Idhu business owner-a informed-aa vechirukkum, final review-a oru formality-aa aakkum, yen-na yaarukkum aachariyam illa.

## Oru worked example

Chennai lender-la discovery-ku apram, neenga propose panradhu:

- **Primary KPI**: oru loan file-ku median officer time, file-a thirakkaradhula irundhu credit note submit panra varai.
- **Baseline**: pilot-ku munnaadi naalu vaaram loan system-oda timestamps-la irundhu measure panna: 41 nimidam median, 6,200 files.
- **Target**: pilot start-la irundhu paththu vaaraththukkulla, 20 pilot officers-ku 22 nimidam median.
- **Guardrails**: credit committee rework rate (baseline 7%) uyaraadhu; audit flag panna policy exceptions-la adhigam illa.
- **Adoption**: pilot officers-la, avanga files-la kurainjadhu 80%-la draft summary-a use panravanga share.

Operations head mudhalla "90% AI accuracy"-a target-aa kekkuraanga. Accuracy quality input-aa track aagum, aana lender-oda business result officer time-um rework-um-nu explain panni, rendu-aiyum agree pannureenga. Paththu vaaram kazhichu, pilot 24 nimidam median, 5.1% rework, 88% adoption kaattudhu. Target time-la konjam thavara vittuchu, aana quality-la meeri pochu; measures munnaadiyae agree aanadhaala, pesaradhu rollout pathi, success-na enna-nu illa.

| Measure | Baseline | Target | Pilot result |
| --- | --- | --- | --- |
| Oru file-ku median nimidam | 41 | 22 | 24 |
| Rework rate | 7% | 7%-ku mele illa | 5.1% |
| Adoption | Porundhaadhu | Files-la 80% | 88% |
| Kadaisila pesaradhu | | | Rollout pathi, success-na enna-nu illa |

## Podhuvaa panra thappugal

- **Model metrics-a KPI-aa vaikkiradhu.** Accuracy oru vazhi; business-la time, cost, errors thaan mudivu.
- **Baseline illaama irukkradhu.** "Officers-ku vegamaa irukku-nu thonudhu" budget review-la nikkaadhu.
- **Romba KPIs.** Paththu numbers, edhu mukkiyam-nu yaarukkum theriyaadhu. Oru primary, konjam guardrails.
- **Launch-ku apram mattum measure panradhu.** System-a behaviour-a maathuradhukku munnaadi baseline edukkanum.
- **Adoption-a ignore panradhu.** 'AI help pannala' result-gal perumbaalum kammi usage-naala thaan.

## Practice pannunga

Success measure panradhu pathi GOV.UK guide-a padinga.

1. Ungaloda discovery exercise-la irundhu use case-ku, oru primary KPI, oru baseline method, date-oda oru target, rendu guardrails, oru adoption measure ezhudhunga.
2. Ovvoru number-um enga irundhu varum, yaar report pannuvaanga-nu thulliyamaa vivaringa.
3. Pilot-oda naalaavadhu vaaraththula neenga anuppura vaaram-oru-line update-a draft pannunga.

**Mudinjadhu-nu eppo sollalaam:** Accuracy yen KPI illa-nu oru client-kitta explain panni, avanga sign panna kudiya oru measurement plan-a kaattamudiyum.
