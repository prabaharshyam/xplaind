## Idhu enna

Oru **KPI** (key performance indicator)-na project velai senjudhaa-nnu solra andha oru number. Oru AI deployment-ku, muzhumaiyaana KPI plan-la aaru pagudhigal irukku:

- Business result kooda inainja **oru primary KPI**: oru loan file-ku minutes, first-response time, oru officer oru naalaikku process panra claims, solve aana oru ticket-ku cost.
- **Oru baseline**: unga system varradhukku munnaadi, adhe muraiyila, adhe maadhiriyaana aalunga, cases-ku alandha KPI.
- **Thedhiyoda oru target**, edhu met, close, missed-nu munnaadiye othukkitta bands.
- **Guardrail measures**: mosamaagakkoodaadha vishayangal, udhaaranamaa error rate, customer complaints alladhu compliance exceptions.
- **Adoption**: aalunga unmaiyileye system-a use panraangalaa, yenna yaarum use pannaadha tool-aala KPI-a nagartha mudiyaadhu.
- **Oru method**: ovvoru number-um enga irundhu varudhu, endha cases count aagum, endha vaarangal count aagum, yaar report panraanga.

Accuracy alladhu faithfulness maadhiri model metrics inputs thaan, KPI illa. Officers nambaadha oru 95%-accurate extractor-na, avanga eppadiyum thirumba type pannuvaanga; yaarukkum oru minute kooda michamaagaadhu.

| Scope of work-la sign aana KPI plan | |
|---|---|
| **Primary** | Oru loan file-kkaana median minutes, file-a open panradhula irundhu credit note-a submit panradhu varaikkum (loan-system timestamps) |
| **Baseline** | Lender muzhukka 41 min (June-la naalu vaaram, 6,200 files); 20 pilot officers-ku mattum 41 min (andha files-la sumaar 690) |
| **Target** | Pilot aarambichu pathu vaarathukkulla 22 min, pilot weeks 7 to 10 vechu judge pannappadum |
| **Bands** | Met: 22 alladhu adhukku keezha. Close: 22-ku mela, 26 varaikkum. Missed: 26-ku mela |
| **Guardrails** | Credit committee rework 7%-ku mela pogakkoodaadhu; audit policy exceptions koodakkoodaadhu; edit illaama accept aana drafts-oda weekly spot check |
| **Adoption** | Kuranjadhu 80% pilot files-la credit note draft-la irundhu submit aaganum |
| **Comparison** | Adhe pathu vaarathula lender-oda matha branches |

### Number-a exact-aa define pannunga

Discovery kandupidicha problem-la irundhu aarambinga. Officers oru file-ku sumaar 40 minutes selavu panraanga-nna, KPI oru file-kkaana time, "AI accuracy" illa. Appuram adha thelivaa nirnayinga, yenna thelivillaadha KPI-na ovvoru pakkamum result-a avangalukku yetha maadhiri padichukkuvaanga:

- **Start, end events.** "File-a open panradhula irundhu credit note-a submit panradhu varaikkum", rendaiyume loan system stamp pannudhu.
- **Endha cases count aagum.** Oru pilot officer handle panna ella file-um, avanga draft-a use pannaalum pannaattiyum. Aalunga oru pudhu tool-a mudhalla easy-aana cases-la thaan try pannuvaanga. Tool use aana files-a mattum count panna, adhu unmaiya vida vegamaa theriyum.
- **Endha statistic.** Median, mean illa. Lunch nerathulayo raathiri muzhukkavo open-aave vitta oru file, hours-aa kaattum. Appadi oru file mean-a niraiya nagarthum, median-a kittathatta nagarthaadhu. Data-ku oru check-aa, rendu mani nerathukku mela aana files-oda share-a thaniyaa report pannunga.
- **Elapsed time-um working time-um onnu illa.** Timestamps kadigaarathai alakkudhu, uzhaippai illa. Baseline-aiyum pilot-aiyum ore maadhiri alakkura varaikkum adhu paravaayilla.

Surveys-a vida, systems erkanave record panra numbers-a (timestamps, ticket close times) therndhedunga. Endha system-um andha number-a record pannalai-nna, mudhalla measurement-a set up pannunga: sila cases-ku start, end times-oda oru simple log, pilot-ku munnaadiye aarambichu.

### Sariyaana aalunga mela baseline-a alanga

Adhe team, adhe maadhiriyaana cases, podhumaana volume (sila nooru cases, kuranjadhu rendula irundhu naalu vaaram varaikkum), oru saadhaarana kaalam use pannunga. Month-end rush, festival season alladhu oru pudhu credit policy, idhellaam adha keduthudum.

Rendu baselines alanga: muzhu organisation-ku onnu, pilot group-ku mattum onnu. Pilot groups perumbaalum avanga aarvamaa irukkuradhaalayo, nallaa run aagaradhaalayo, head office-ku pakkathula irukkuradhaalayo thaan therndhedukkappaduraanga. Pilot officers erkanave 35 minutes eduthirundhaa, avangala lender muzhukkavaana 41 kooda compare panna, tool michappaduthave illaadha aaru minutes-ku adhukku credit poyidum. Chennai lender-la rendu baselines-um 41 minutes-aa vandhuchu, adhanaala pilot comparison niyaayamaanadhu. Irundhaalum pilot branches average-a vida aarvamaa irundhaanga, adhanaala thaan full rollout-ku business case appuramaa innum kavanamaana oru figure-a plan pannuchu (executives kooda pesuradhu pathina lesson-a paarunga).

### Aasaiyila irundhu illa, evidence-la irundhu target-a set pannunga

"Paadhiyaa kurainga"-nguradhu oru aasai. Defend pannakkoodiya oru target velaiyila irundhe varudhu. Discovery-la, team officers koodave ukkaarndhu paarthukkitte sila files-a time pannuchu (case-oda figures): sumaar 16 minutes documents-a padikkuradhulayum applicant-a judge panradhulayum pochu, sumaar 25 figures-a thirumba type panradhulayum credit note ezhudhuradhulayum pochu. Assistant figures-aiyum note-aiyum draft pannudhu, aana officers innum flag aana, critical fields-a check panraanga; adhukku sumaar 6 minutes aagum-nu team estimate pannuchu. Adhanaala target 16 + 6 = 22 minutes.

Ippadi build panna target rendu velai seiyudhu. Adhu enga irundhu vandhuchu-nnu client-aala paarkka mudiyum. Pilot miss aana, endha step-a paarkkanum-nu ungalukku theriyum: inga, checking estimate pannadha vida adhiga neram eduthuchu.

### Met, close, missed-na enna-nnu munnaadiye othukkonga

Weekly medians tharseyalaa nagarum. June baseline vaarangalla, edhuvume maaraama irundhappavum, vaarathukku sumaar 170 files-la, pilot group-oda weekly median onnula irundhu rendu minutes varaikkum nagarndhuchu. Adhanaala 22 target-ku edhiraa 24 result vandhaa, yaarum adha paarkkuradhukku munnaadiye othukkitta oru rule venum.

| Band | Range | Enna nadakkum |
| --- | --- | --- |
| Met | 22 minutes alladhu adhukku keezha | Rollout-a recommend pannunga |
| Close | 22-ku mela, 26 minutes varaikkum | Kavanamaana oru planning figure-odavum, gap-ku oru fix plan-odavum rollout-a recommend pannunga |
| Missed | 26 minutes-ku mela | Oru chinna extension, kurugina scope kooda fix plan, illainna stop |

Pinnaadi vaarangalai vechu judge pannunga. Mudhal vaarangalla results rendu pakkamum distort aagum: officers innum tool-a kathukkittu iruppaanga, silar pudhusaana onnu vandhadhaala excite aagi appuram use panradha vida adhigamaa use pannuvaanga (novelty effect). Lender, mudhal problems sariyaanadhukku appuram, pilot weeks 7 to 10 vechu judge pannuchu.

Oru gap-la evvalavu tharseyal-nu paarkka, median-ku oru likely range-a compute pannunga. Thanithani files-a illa, officers-a resample pannunga, yenna oru officer-oda files ore maadhiri irukkum:

```python
import numpy as np
import pandas as pd

df = pd.read_csv("pilot_files.csv", parse_dates=["opened_at", "submitted_at"])
df["minutes"] = (df["submitted_at"] - df["opened_at"]).dt.total_seconds() / 60

# Weekly median per branch: the numbers behind the weekly line
print(df.pivot_table(index="pilot_week", columns="branch",
                     values="minutes", aggfunc="median").round(1))

# Judge on pilot weeks 7 to 10, using every file, draft used or not
end = df[df["pilot_week"].between(7, 10)]
officers = [g.to_numpy() for _, g in end.groupby("officer_id")["minutes"]]

# Resample officers, not files: one officer's files are alike
rng = np.random.default_rng(7)
n = len(officers)
medians = [np.median(np.concatenate([officers[i] for i in rng.integers(0, n, n)]))
           for _ in range(2000)]
low, high = np.percentile(medians, [2.5, 97.5])
print(f"median {end['minutes'].median():.1f} min, likely range {low:.1f} to {high:.1f}")
```

Target likely range-ku veliye irundhaa, andha gap unmaiyaanadhu, noise illa. Adha neradiyaa sollunga.

### Gaming-ku edhiraa onnaiyum serthu guardrails-a therndhedunga

Adhiga errors-oda vegamaana processing vetri illa. Client-oda risk owners erkanave kavalaippadura onnu alladhu rendu quality measures-a therndhedunga, udhaaranamaa credit committee rework, audit exceptions. Rework oru lagging measure: committee, submit aanadhula irundhu onnu rendu vaaram kazhichu thaan files-a thirumba anuppum, adhanaala andha lag-oda report pannunga, kadaisi vaarathai vechu adha judge pannaadheenga.

Gaming-ku edhiraa oru guardrail serunga. Economist Charles Goodhart per-la irukkura Goodhart's law-a perumbaalum ippadi solluvaanga: "oru measure target aanadhum, adhu nalla measure-aa irukkuradha niruthidum". 22 minutes-a thodanum-ngura pressure-la, oru officer draft-a padikkaamaleye accept pannalaam. Number nallaagum; unmaiyaana result nallaagaadhu. Adhanaala endha edit-um illaama accept aana drafts-oda share-a track pannunga, oru senior officer vaarathukku random-aa 20 files-a spot-check pannattum. Zero-edit share 100%-a nokki yeritte poga, spot checks-la miss aana errors therinjaa, adhu rubber-stamping.

### Niyaayamaa compare pannunga

Pilot nadakkumbodhu vera edhaavadhu eppavume maarum: oru pudhu policy, leave-la irukkura staff, oru seasonal rush. Oru comparison group adha pidikkum. Adhe vaarangalla system illaadha adhe maadhiriyaana aalungalukku KPI-a track pannunga; lender-la, matha branches muzhukka sumaar 41 minutes-laye irundhaanga, adhanaala andha kuraivu lender muzhukkavaana oru maatram illa. Ellaarukkum ore nerathula tool kidaichaa, adhe aalungalai munnaadiyum appuramum compare pannunga, vera ennenna maaruchuvo ellaathaiyum ezhudhi vainga. Pilot aarambikkuradhukku munnaadiye method-a measurement plan-la podunga, appo yaarum appuramaa thanakku saadhagamaana comparison-a therndhedukka mudiyaadhu.

### KPI-a rupees-aa maathunga

Executives fund panradhu rupees-a, minutes-a illa. Lender-oda sondha HR figure-padi oru loaded officer hour-ku sumaar ₹600-nu vechaa, ovvoru file-layum oru minute michamaanaa 6,000 files ÷ 60 = maasathukku 100 officer hours, adhoda madhippu maasathukku sumaar ₹60,000. Padhinanju minutes michamaanaa maasathukku sumaar ₹9 lakh. Andha oru conversion irundhaa, yaar venumnaalum ovvoru weekly result-aiyum panamaa maathikkalaam.

| Input (model alladhu system) | Outcome (business) | Adhu eppadi rupees-aa maarudhu |
| --- | --- | --- |
| Extraction accuracy | Oru loan file-kkaana minutes | Michamaana minutes × files × oru minute-kkaana cost |
| Faithfulness score | Rework rate | Thirumba anuppappadaadha files × thirumba seiya aagura hours × hourly cost |
| Retrieval recall | Oru policy kelvikku badhil solra time | Michamaana minutes × kelvigal × oru minute-kkaana cost |
| Latency | Oru agent oru mani nerathukku handle panra calls | Koodudhal staff illaama handle aagura koodudhal calls |

Running cost therinjadhum, break-even-a kanakku pannunga: value-um cost-um samamaagura, oru file-kkaana miga chinna saving. Lender-la, full-volume cost model late-aa, contract week 10-la thaan vandhuchu (case study lesson-a paarunga). Adhu sumaar 13 minutes break-even kuduthuchu: saving 13 minutes alladhu adhukku mela irukkanum, adhaavadhu oru file-ku 28 minutes alladhu adhukku keezha. Mudhal vaarangallaye cost model-a build pannunga, appo pilot judge aagaradhukku munnaadiye andha floor theriyum.

### Ovvoru vaaramum report pannunga, group vaariyaa pirichu

Ovvoru vaaramum KPI, guardrail, adoption-oda oru line anuppunga. Pilot week 2-la adhu ippadi irundhuchu: "Oru file-ku median 27 minutes (baseline 41, target 22); rework 5.4%, limit 7%; 78% files-la draft use aachu."

Adha branch vaariyaavum piringa. Oru vaaram kazhichu, blended line kaattaadhadha andha split kaattuchu: Anna Nagar-la 92% files-la draft use aachu, aana Tambaram-la 41% thaan, anga median 37 minutes. Anga irundha officers AI errors-ku thanga mela pazhi varum-nu bayandhu ellaathaiyum thirumba type pannaanga. Andha split thaan adha sari panna branch visit-ku vazhi vaguthuchu (change management pathina lesson-a paarunga). Blended number oru problem irukkaa-nnu sollum. Split adhu enga irukku-nnu sollum.

## Oru worked example

Chennai lender-la discovery mudinjadhum, mela irukkura table-la irukkura plan-a neenga propose panreenga. Head of operations mudhalla "90% AI accuracy"-a target-aa kekkuraanga. Golden set-la accuracy-a oru quality input-aa track panna neenga othukkureenga. Appuram, officers nambaadha oru accurate draft edhaiyum michappaduthaadhu-nnu explain panreenga. Lender panam kudukkuradhu officer time-kkum rework-kkum thaan, adhanaala avai thaan KPI-um guardrail-um. Avanga othukkuraanga, plan scope of work-kkulla pogudhu.

Pilot-ku munnaadi, June timestamps-a rendu thadavai edukkureenga: lender muzhukka (41 minutes, 6,200 files), 20 pilot officers-ku mattum (41 minutes, sumaar 690 files). Time panna steps-la irundhu target-a (22 minutes) set panni, bands-a othukkureenga.

Pilot nadakkumbodhu, weekly line pilot week 3-la Tambaram-a flag pannudhu, rendu vaaram kazhichu anga adoption 85%-ku thirumba varudhu. Appuram pilot weeks 7 to 10 verdict-a kudukkudhu:

| Measure | Baseline | Target | Pilot weeks 7 to 10 | Verdict |
| --- | --- | --- | --- | --- |
| Oru file-kkaana median minutes | 41 | 22 | 24 (likely range 23 to 25) | Close |
| Rework rate | 7% | 7%-ku mela illa | 5.1% | Nilaichudhu, innum nallaachu |
| Adoption | Porundhaadhu | 80% files | 88% | Met |
| Matha branches, adhe vaarangal | 41 | Maatram edhirpaarkkala | Sumaar 41 | Veliye endha maatramum illa |

Nermaiyaana summary idhu: "Close, met illa. Oru file-kkaana time 17 minutes kuranjudhu, 41-la irundhu 24. 22 target likely range-ku veliye irukku, adhanaala gap unmaiyaanadhu. Flag aana fields-a check panna, naanga estimate panna 6 minutes-a vida adhiga neram aachu." Bands munnaadiye othukkittadhaala, 24 vetriyaa illaiyaa-nnu yaarum vaadham panradhilla. End-of-pilot meeting rollout pathiyum checking step pathiyum thaan, vetri-nna enna-nnu pathi illa.

## Podhuvaa panra thappugal

- **Model metrics-a KPI-aa vaikkuradhu.** Accuracy oru vazhi; business-la time, cost alladhu errors thaan ilakku.
- **Baseline illaadhadhu, alladhu thappaana group-oda baseline.** "Officers-ku vegamaa irukkura maadhiri thonudhu"-nguradhu oru budget review-la nikkaadhu, lender muzhukkavaana baseline oru aarvamaana pilot group-a irukkuradha vida nallaa kaattalaam.
- **Tool use aana files-a mattum count panradhu.** Aalunga adha mudhalla easy-aana cases-la thaan use pannuvaanga. Ella pilot file-aiyum count pannunga.
- **Mudhal vaarangalai vechu judge panradhu.** Kathukkuradhum novelty effect-um avatrai distort pannum. Othukkitta maadhiri, pinnaadi vaarangalai vechu judge pannunga.
- **Konjathula miss aanadha appuramaa vaadham panradhu.** Pilot aarambikkuradhukku munnaadiye met, close, missed bands-a othukkonga.
- **Nallaa kekkudhu-nnu therndhedutha target.** Time panna steps-la irundhu build pannunga, appo oru miss enga paarkkanum-nu sollum.
- **Gaming-a pidikka mudiyaadha guardrails.** Rework mattum lag aagum; edit illaama accept aana drafts-oda spot checks-aiyum serunga.
- **Blended number mattum.** Ovvoru vaaramum branch alladhu team vaariyaa piringa, illainna ninnupona oru group average-kkulla olinjukkum.
- **Romba adhigamaana KPIs.** Pathu numbers irundhaa edhu mukkiyam-nu yaarukkum theriyaadhu. Oru primary, sila guardrails, oru adoption measure.

## Practice pannunga

Measuring success pathina GOV.UK guide-a padinga.

1. Unga discovery exercise-la irundha use case-ku, oru muzhu KPI plan ezhudhunga: start, end events-oda primary KPI, muzhu organisation-kkum pilot group-kkum oru baseline method, time panna steps-la irundhu build panna target, met, close, missed bands, rendu guardrails, oru adoption measure.
2. Ovvoru number-um enga irundhu varudhu, endha cases count aagum, yaar report panraanga-nnu exact-aa vivaringa.
3. Oru case-ku michamaagura oru minute-a, client thannodadhu-nnu yethukkura oru cost figure-a vechu, maasathukku rupees-aa maathunga.
4. Ovvoru guardrail-kkum, unmaiyaana result illaamaleye aalunga KPI-a nagarthakkoodiya oru vazhiyaiyum, adha neenga eppadi kandupidippeenga-nnum ezhudhunga.
5. Team vaariyaa pirichu, pilot week 4-kkaana weekly line-a draft pannunga.

**Mudinjadhu-nnu eppo sollalaam:** accuracy yen KPI illai-nnu oru client-kitta explain panna mudiyum, avanga sign pannakkoodiya oru measurement plan-a kaatta mudiyum, endha result-a close-nu solveenga-nnu munnaadiye solla mudiyum.
