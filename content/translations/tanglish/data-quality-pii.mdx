## Idhu enna

Ovvoru AI data pipeline-layum irukkura, rendu sambandhappatta velaigal:

- **Data quality**: data-va index panra munnaadi illa model-ku anuppura munnaadi, adhu complete, valid, consistent, current-aa irukkaa-nu check panradhu. Missing fields, duplicate records, mudiyaadha dates, kuzhappamaana text ellaam thappaana answers-aa maarum.
- **Personal data handling**: personal data-va (names, phone numbers, emails, addresses, Aadhaar, PAN, bank account numbers, health details) kandupidichu, adhu pogura ovvoru idathulayum keep panradhaa, mask panradhaa, pseudonymise panradhaa, illa drop panradhaa-nu decide panradhu.

```flow
Raw records -> Quality checks
Quality checks -[fail]-> Quarantine, block illa warn
Quality checks -[pass]-> Personal data-va kandupidinga | patterns + NER + context words
Personal data-va kandupidinga -[index]-> Vechukkunga, permissions-aala restrict panni
Personal data-va kandupidinga -[external model]-> Task-ku thevai illadhadhai mask pannunga
Personal data-va kandupidinga -[logs, traces]-> Default-aa mask pannunga
Personal data-va kandupidinga -[staging, tests]-> Realistic fakes-aala maathunga
```

Indha lesson, Coimbatore-la oru hospital group, follow-up calls-ku discharge-note summariser build panradhai follow pannum.

## Idhu eppadi work aagudhu

**Quality checks tests maadhiri.** Data meet pannanum-nu rules ezhudhi, ovvoru batch-layum run pannunga:

- required fields irukkanum (ovvoru claim-kum policy number-um date-um);
- values valid-aa irukkanum (dates future-la illa, amounts positive, PIN codes aaru digits);
- uniqueness (duplicate invoice numbers illa);
- freshness (pudhusaa irukkura record oru naalukku kammi pazhasu);
- text sanity (parse aana pages-la podhumaana characters, kuzhappamaana symbols run illa).

Great Expectations maadhiri libraries illa simple pytest-style checks work aagum. Ovvoru rule-kum, fail aanaa batch-a block panradhaa, thappaana records-a quarantine panradhaa, illa warn mattum panradhaa-nu decide pannunga.

**Personal data-va kandupidikkradhu.** Idhai serunga:

- structured identifiers-ku *patterns*: Indian mobile numbers, emails, PAN (aindhu letters, naalu digits, oru letter), Aadhaar (12 digits, mudinjaa adhoda checksum-oda), IFSC codes, GSTINs;
- names, places, organisations-ku *named-entity recognition*, Presidio illa spaCy maadhiri tools-la irundhu;
- confidence-a uyartha *context words* ("Aadhaar no.", "DOB").

Entha detector-um perfect illa. Real documents-oda labelled sample-la adhoda recall-a measure pannunga, especially Indian names-um mixed-language text-um.

**Ovvoru flow-kum treatment choose panradhu.**

- *Index-kulla*: adikkadi keep pannalaam (staff-ku customer names thevai), aana permissions-aala restrict pannunga.
- *External model-ku prompts-la*: task-ku thevaiyaanadhai mattum anuppunga; answer-ku thevai illaadha identifiers-a mask pannunga.
- *Logs, traces-la*: default-aa mask pannunga.
- *Test, staging data-la*: realistic fakes-aala maathunga (pseudonymise).

**Reversible masking.** Sila tasks-ku, model call-ku munnaadi "Lakshmi Narayanan, 98400 12345"-a "PERSON_1, PHONE_1"-nu maathi, answer vandhadhukku apram unmaiyaana values-a thirumba podalaam. Model unmaiyaana data-va paakkave paakkaadhu, aana user-ku muzhu reply kidaikkum.

**Indian identifier patterns, vaarthaigalla:**

| Identifier | Pattern | Extra check |
| --- | --- | --- |
| Mobile number | 6-la irundhu 9 varai aarambikkura 10 digits, adikkadi +91-oda | "mob", "ph" maadhiri context words |
| PAN | 5 letters, 4 digits, 1 letter | Naangaavadhu letter holder type-a kaattum |
| Aadhaar | 12 digits, adikkadi naalu naalu-aa pirichu | Verhoeff checksum |
| IFSC | 4 letters, oru zero, 6 letters illa digits | Bank code list |
| GSTIN | 2-digit state code-oda aarambikkura 15 characters | PAN-a ulladakkum |
| PIN code | 6 digits | Valid mudhal digit |

**Masking, practice-la.** Reversible masking oru mapping-a vechirukkum, PERSON_1-la irundhu unmaiyaana name-ku, request neram mattum memory-layae. Prompt "PERSON_1 was discharged on..."-nu solludhu, model "Call PERSON_1 to check..."-nu ezhudhum, nurse paakkura munnaadi code unmaiyaana name-a thirumba podum. External model identity-a eppavumae vaanguradhu illa, mapping eppavumae log aagaadhu.

**Code-la quality checks.** Fail aana rows-a return panra simple functions, appo ovvoru batch-um clean, quarantined-nu pirikkalaam:

```python
import re
from datetime import date

RULES = {
    "policy number present": lambda r: bool(r.get("policy_no")),
    "claim date not in future": lambda r: r["claim_date"] <= date.today(),
    "amount positive": lambda r: r["amount_paise"] > 0,
    "PIN code 6 digits": lambda r: bool(re.fullmatch(r"[1-9]\d{5}", r.get("pin", ""))),
    "text long enough": lambda r: len(r.get("text", "")) > 200,
}

def check_batch(rows, unique_key="claim_id"):
    clean, quarantine, seen = [], [], set()
    for r in rows:
        failed = [name for name, ok in RULES.items() if not _safe(ok, r)]
        if r.get(unique_key) in seen:
            failed.append("duplicate id")
        seen.add(r.get(unique_key))
        (quarantine if failed else clean).append({**r, "_failed": failed} if failed else r)
    print(f"{len(clean)} clean, {len(quarantine)} quarantined")
    return clean, quarantine

def _safe(rule, row):
    try:
        return rule(row)
    except (KeyError, TypeError):
        return False
```

Ovvoru batch-layum rule-ku failures-a ennunga. Oru rule-la thidheernu jump aanaa, adhu perumbaalum data mosamaagala, source format maathiduchu-nu artham.

**Presidio vechu personal data-va detect panradhu.** Microsoft-oda open-source Presidio, patterns, context words, named-entity models-a serkkum. Recent versions-la PAN, Aadhaar maadhiri sila Indian identifiers-ku recognisers irukku; matha-vatrukku ungaloda sondhama serunga:

```python
from presidio_analyzer import AnalyzerEngine, Pattern, PatternRecognizer

analyzer = AnalyzerEngine()
analyzer.registry.add_recognizer(PatternRecognizer(
    supported_entity="IN_IFSC",
    patterns=[Pattern("ifsc", r"\b[A-Z]{4}0[A-Z0-9]{6}\b", 0.6)],
    context=["ifsc", "branch", "bank"]))

text = "Refund to Lakshmi Narayanan, IFSC HDFC0001234, mobile 9840012345."
for r in analyzer.analyze(text=text, language="en"):
    print(r.entity_type, text[r.start:r.end], round(r.score, 2))
```

**Detector-a type-padiyum language-padiyum measure pannunga.** 100 real snippets-a kaiyaala label pannunga (labels-ku masked copies-um paravaayilla), apram:

```python
def detector_recall(labelled, detect):
    """labelled: list of (text, set of (start, end, type)); detect returns the same shape."""
    found = total = 0
    for text, gold in labelled:
        hits = detect(text)
        total += len(gold)
        found += sum(any(abs(s - hs) < 3 and abs(e - he) < 3 for hs, he, _ in hits) for s, e, _ in gold)
    return found / total if total else 1.0
```

Indian names, transliterated text, mixed scripts-la thaan detectors adhigam miss pannum; adhukku recall-a thaniyaa report pannunga.

**Staging-ku fake data.** Production data-va staging-la eppavumae copy pannaadheenga. Adhai generate pannunga:

```python
from faker import Faker
fake = Faker("en_IN")
print(fake.name(), fake.phone_number(), fake.address())
```

Adhe shapes-aiyum edge cases-aiyum (neenda names, missing fields, Hindi text) vechukkunga, appo production kandupidikkura bugs-a staging pidikkum.

## Oru worked example

Coimbatore hospital group, follow-up calls-ku discharge notes-a summarise panra assistant venumnu virumbudhu. Notes-la patient names, phone numbers, addresses, diagnoses, doctors-oda names irukku.

Quality checks, discharge date illaadha notes-a reject pannudhu, therindha double-export bug-aala vandha duplicates-a (3% records) flag pannudhu, OCR text perumbaalum symbols-aa irukkura 40 scanned notes-a quarantine pannudhu.

Personal data-ku, data protection officer idhai oththukkaraanga:

- Summariser-ku clinical content thevai, identity illa. Names, phone numbers, addresses, hospital ids model call-ku munnaadi mask aagi, nurse-ku kaattura summary-la restore aagum.
- Logs, traces masked text-a mattum vechukkum.
- Staging environment, templates-la irundhu generate aana synthetic notes-a use pannum.

200 hand-labelled notes-la detector-a test pannaa, phone numbers-la 97%-um patient names-la 81%-um thaan kandupidikkudhu, lowercase-la ezhudhina neraya Tamil names-a miss pannudhu. Hospital-oda sondha patient-name list-a lookup-aa serthaa 98%-ku uyarudhu. DPO, design document-la measure panna numbers-oda sign off pannuraanga.

| Check | Finding | Action |
| --- | --- | --- |
| Discharge date illai | Sila notes | Reject |
| Duplicate exports | 3% records | Flag panni neekkinaanga |
| Kuzhappamaana OCR text | 40 scanned notes | Re-scan-ku quarantine |
| Phone number detection | 97% kandupidichudhu | Oththukkittaanga |
| Patient name detection | 81%, apram hospital-oda name list-oda 98% | Fix-ku apram oththukkittaanga |

## Podhuvaa panra thappugal

- **Quality-a oru thadavai kannaala paathutu vidradhu.** Data maarum; ovvoru batch-layum checks-a automate pannunga.
- **Measure pannaama detector-a nambradhu.** Indian data-la name detection, vendors-oda English benchmarks-a vida romba weak-aa irukkalaam.
- **Ella flow-kum oru rule.** Index, prompts, logs, test data-ku vera vera treatments thevai.
- **Task-a odaikkura masking.** Answer panna model-ku oru date thevaina, adhai mask pannaa result paazhaagum. Field-ku field decide pannunga.
- **Free text-a marakkuradhu.** Personal data comments, notes, email bodies-la olinjirukkum, peyar vecha columns-la mattum illa.
- **Production data-va staging illa tests-ku copy panradhu.** Adhukku badhila realistic fakes generate pannunga.
- **Oru overall detector score.** Identifier type-padiyum language-padiyum recall-a measure pannunga.
- **Missing field-la crash aagura rules**, failure-a record pannaama.

## Lighter checks podhum-naa

- **Public illa synthetic data mattum**, personal information illaama: quality checks innum mukkiyam, PII detection romba kammi.
- **Oru thadavai analysis**, neengalae run panni kaiyaala check panradhu.
- **Aarambathulayae validate aagi varra data**, therindha system-la irundhu, adhoda sondha contracts-um checks-um irukkura.

## Demo-la irundhu production-ku

- **Ovvoru batch-layum quality checks run pannunga**, failures-a quarantine panni, rule-ku jumps-ku alert pannunga.
- **Detector recall-a** labelled sample-la ovvoru quarter-um, maatrangal-ku apramum measure pannunga.
- **Logs, traces-la default-aa mask pannunga**, ovvoru exception-aiyum document pannunga.
- **Staging, tests-la generate panna data** use pannunga.
- **Pudhu document types illa languages varum podhellaam** masking rules-a review pannunga.
