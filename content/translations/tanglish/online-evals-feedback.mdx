## Idhu enna

**Offline evals** ship pannradhukku munnaadi oru fixed golden set-a test pannum. **Online evals** ship pannina apram, real traffic-la enna nadakkudhu-nu score pannum. Rendum thevai: offline evals therinja regressions-a thadukkum; online evals theriyaadhavatrai kandupidikkum.

Online signals naalu vagai:

- **Automatic checks** ovvoru response-layum: valid format, citations irukkaa, refusal-aa illaiyaa, length, latency, guardrail triggers.
- **Model-graded scores** oru sample-la: sources-ku faithfulness, relevance, tone; human grades-oda check panna oru judge model score pannum.
- **User feedback**: thumbs up illa down, oru reason, answer-a copy pannaangalaa, thirumba kettaangalaa, illa oru aal-kitta escalate pannaangalaa.
- **Human review**: oru expert vaaram oru sample-a padichu, enna thappu-nu label pannuvaanga.

```flow
Live request -[kaathirukkaama]-> User-ku answer
Live request -> Trace store aagum
Trace store aagum -> Ovvoru trace-layum rules | format, citations, refusal, length, latency
Trace store aagum -> 10% sample + ella negative feedback-layum judge | faithfulness, relevance
Trace store aagum -> User feedback | thumbs-um reason-um, maathi kettadha question, escalation
Trace store aagum -> Vaaram oru human review | 50 traces kaaranam-vaaree label
Ovvoru trace-layum rules -> Naal, version, topic, language-vaaree dashboard
10% sample + ella negative feedback-layum judge -> Naal, version, topic, language-vaaree dashboard
User feedback -> Naal, version, topic, language-vaaree dashboard
Vaaram oru human review -> Naal, version, topic, language-vaaree dashboard
Naal, version, topic, language-vaaree dashboard -[thideer maatrathukku alerts]-> Periya kaaranatha fix pannunga -> Offline golden set-la cases serunga
```

Indha lesson Chennai-la oru telecom-oda customer assistant-a follow pannum; launch aana aaru vaaram apram adhoda negative feedback kittathatta rendu madangaachu.

## Idhu eppadi work aagudhu

**Asynchronously score pannunga.** Response user-kitta poyidhu apram, traces-la irundhu checks-aiyum judges-aiyum run pannunga, appo latency serkkaadhu.

**Sensible-aa sample pannunga.** Ella traces-aiyum rules vechu cheap-aa score pannunga; random 5 la irundhu 10% mela, kooda negative feedback irukkura ovvoru trace-layum guardrail trigger aana ovvoru trace-layum judge run pannunga.

**Feedback-a easy-aa, specific-aa aakkunga.** Thumbs down-ku apram moonu quick reasons ("wrong", "incomplete", "not what I asked") verum thumbs down-a vida romba adhigam kudukkum. Implicit signals-um help pannum: oru nimishathukkulla maathi kekkura question, perumbaalum mudhal answer miss aachu-nu artham.

**Oru number-a illa, trends-a paarunga.** Naal-vaareeyum version-vaareeyum dashboards: faithfulness, refusal rate, negative feedback rate, escalations. Thideer maatrangalukku alert pannunga, example document upload-ku apram refusal rate rendu madangaagradhu, illa provider-oda model update-ku apram faithfulness kuraiyaradhu.

**Loop-a mudinga.** Vaaram thorum: romba kammiyaa score aana, negative rating vandha traces-a padinga, kaaranam-vaaree group pannunga (retrieval miss, stale document, prompt gap, out-of-scope question), periya group-a fix pannunga, fix nilaichu irukka representative cases-a offline golden set-la serunga.

**Judge-a check pannunga.** Oru judge model-ukkum adhoda errors irukku. Konja vaaram-ku oru vaatti, oru aal 50 judged samples-a grade panni agreement-a check pannunga. Agreement kuraindhaa, adhoda numbers-a nambradhukku munnaadi judge prompt-a fix pannunga.

**Signals-um adhu enna pidikkum-um:**

| Signal | Cost | Edhu pidikkum |
| --- | --- | --- |
| Ovvoru trace-layum rule checks | Kittathatta free | Udaindha formats, missing citations, slow responses |
| Topic-vaaree refusal rate | Free | Missing documents, over-strict prompts |
| Oru sample-la judge | Model calls | Faithful illaadha illa relevant illaadha answers |
| Thumbs-um reasons-um | Free | Users-ku unmaiyilaye pidikkaadhadhu |
| Oru nimishathukkulla rephrase | Free | Question-a miss panna answers |
| Vaaram oru human review | Staff time | Entha automatic signal-um sollaadha kaaranangal |

**Weekly review-a nadathuradhu.** 50 traces-a edunga: judge score-la romba kammiyaana 20, negative feedback irukkura 20, random-aa 10. Ovvonnukkum oru short list-la irundhu oru kaaranam label ezhudhunga: retrieval miss, stale illa missing document, prompt gap, out of scope, model error, illa fine. Labels-a count pannunga. Periya group thaan adutha vaaram-oda fix. Counts-a vaaram-vaareeya vechukkunga, appo fixes vara vara kaaranangal kurayaradha neengalum client-um paakkalaam.

**Client-kitta solradhu.** Offline score mattum illa, online dashboard-aiyum vaaram-oda cause counts-aiyum share pannunga. Oru problem-a kandupidichu, explain panni, fix aanadhai kaattura team-a, high launch number mattum report panra team-a vida clients romba nambuvaanga.

**Deterministic sampling.** Judge-ku traces-a trace id-a hash panni select pannunga, appo ore trace eppavum sample-kulla illa veliya irukkum, reruns-um dashboards-um onnu pola irukkum:

```python
import hashlib

def in_sample(trace_id, rate=0.08):
    h = int(hashlib.sha256(trace_id.encode()).hexdigest()[:8], 16)
    return h / 0xFFFFFFFF < rate

def should_judge(trace):
    return (in_sample(trace["id"])
            or trace.get("feedback") == "down"
            or trace.get("guardrail_triggered")
            or trace.get("stop_reason") == "max_tokens")
```

**Conversation-la irundhu implicit signals.** Makkal thumbs down-a rarely thaan press pannuvaanga, aana avanga behaviour neraya sollum. Mudinja conversations-mela run panra oru sinna detector:

```python
from difflib import SequenceMatcher

def implicit_signals(turns):
    """turns: list of {"role", "text", "at" (seconds), "stopped_early", "regenerated"}."""
    flags = []
    users = [t for t in turns if t["role"] == "user"]
    for a, b in zip(users, users[1:]):
        similar = SequenceMatcher(None, a["text"].lower(), b["text"].lower()).ratio() > 0.6
        if similar and b["at"] - a["at"] < 90:
            flags.append("rephrased within 90 s")
    if any(t.get("stopped_early") for t in turns):
        flags.append("stopped a reply")
    if any(t.get("regenerated") for t in turns):
        flags.append("regenerated")
    if any(w in t["text"].lower() for t in users for w in ("wrong", "not what i asked", "galat")):
        flags.append("said it was wrong")
    return flags
```

Explicit ratings-oda sernthu, naal-vaareeyum version-vaareeyum flags-a count pannunga. Thumbs down kammi-aa irundhu, rephrasing adhigam irukkura oru version, probably nalladhu illa.

**Feedback-a kavanamaa design pannunga.** Iyalbaana neraththula kelunga (task naduvula illa, answer-ku apram), one tap-aa vaiyyunga, thumbs down-ku apram rendu moonu reasons kudunga. Yaaru feedback tharaanga-nu ninaivula vaiyyunga: sandhosham illaadha users-um romba sandhoshamaana users-um, adhanaala explicit ratings skew aagum. Kaattina rendu options-la mudhal option-ku feedback adhigam, adhu mudhalla irundhadhaala thaan. Versions-a ore feedback design vechu compare pannunga, redesigns-a thaandi illa.

**Dashboard-ku oru query.** Traces Postgres-la vizhundha, version-vaaree oru daily view konjam lines thaan:

```sql
SELECT date(created_at AT TIME ZONE 'Asia/Kolkata') AS day, app_version,
       count(*) AS requests,
       avg(CASE WHEN feedback = 'down' THEN 1.0 ELSE 0 END) AS thumbs_down_rate,
       avg(CASE WHEN judge_verdict = 'fail' THEN 1.0 END) AS judge_fail_rate,
       avg(CASE WHEN refused THEN 1.0 ELSE 0 END) AS refusal_rate
FROM traces
WHERE created_at > now() - interval '30 days'
GROUP BY 1, 2 ORDER BY 1, 2;
```

**Kurugura loops-a jaakkirathai.** Feedback-la irundhu rank pannina illa recommend pannina, neenga perumbaalum already kaattinadha pathi thaan kathukkuveenga. Traffic-oda oru sinna share-a vera options-a explore panna vidunga, maatrangala clicks-a mattum illa, offline evals-aalayum judge pannunga.

## Oru worked example

Chennai telecom-oda customer assistant adhoda offline golden set-la 91% pass pannichu. Launch aana aaru vaaram apram, negative feedback 6%-la irundhu 11%-ku yerichu.

Online data kaattinadhu:

- Faithfulness (10% sample-la judge pannadhu) 0.93-la steady: answers adhoda sources-oda match aachu.
- Refusal rate 8%-la irundhu 17%-ku yerichu.
- Perumbaalaana negative feedback "not what I asked" reason-oda vandhadhu.

Andha traces-la 60 padicha apram kaaranam therinjudhu: oru pudhu prepaid plan launch aachu, customers adha pathi Tamil-layum English-layum kettaanga, plan documents index-la serkkapadala. Assistant sariyaa refuse pannichu, customers-ku pidikkala.

Fixes: marketing team-oda plan launches ippo oru indexing job-a trigger pannum; oru topic-ku refusal rate thideer-nu yeraana alert adikkum; pudhu plans pathi 25 questions golden set-la serndhadhu. Negative feedback oru vaarathula thirumba 6% aachu. Monthly review-la client-kku timeline-a kaattineenga, adhu mudhal 91%-a vida nambikkaikku adhigam help pannichu.

| Vaaram | Negative feedback | Refusal rate | Action |
| --- | --- | --- | --- |
| Launch | 6% | 8% | Onnum illa |
| Vaaram 6 | 11% | 17% | 60 traces padichaanga: pudhu plan documents missing |
| Vaaram 7 | 6% | 8% | Plan launches indexing-a trigger pannum; topic refusal alert; 25 golden cases serkkapattadhu |

## Podhuvaa panra thappugal

- **Online signals illaama ship panradhu.** Kobamaana users-kitta illa client-oda boss-kitta irundhu problems pathi kekkuveenga.
- **Check pannaadha judge-a nambradhu.** Judge scores drift aagum, blind spots irukkum; human grades-oda aduthadutha compare pannunga.
- **Feedback-a collect panni padikkaama irukkradhu.** Weekly review-a schedule pannunga.
- **Averages mattum.** Oru steady average-la oru topic illa language romba mosamaaguradha maraikkalaam. Topic, language, version-vaaree slice pannunga.
- **Tests serkkaama fix panradhu.** Adutha change-ku apram adhe failure thirumba varum.
- **Ovvoru run-layum maarura random sampling.** Trace id-a hash pannunga, appo samples stable-aa irukkum.
- **Explicit ratings-a mattum nambradhu.** Konja perumthaan tharuvaanga, adhum negative-pakkamum positive-pakkamum skew aagum.
- **Clicks illa thumbs-kku mattum optimise panradhu**, adhu product-a already panradhu pakkam kurukkidum.

## Online evals kaathirukkalaam-na eppo

- **Launch-ku munnaadi**: oru nalla test set-la offline evals thaan mudhalla.
- **Romba kammi traffic**: sample pannaama ovvoru conversation-aiyum padinga.
- **Konjam experts irukkura internal tools**, edhaachum thappa irundha avangalae neraa solluvaanga.

## Demo-la irundhu production-ku

- **Traces-la irundhu asynchronously score pannunga**, response path-la edhuvum vendaam.
- **Feedback-aiyum implicit flags-aiyum trace id-oda, version-oda store pannunga.**
- **Thideer maatrangalukku alert pannunga**, version-vaareeyum topic-vaareeyum, oru mosamaana conversation-ku illa.
- **Weekly cause review nadathunga**, counts-a client-oda share pannunga.
- **Judge-a recheck pannunga**, konja vaaram-ku oru vaatti human grades-oda.

## Practice pannunga

Langfuse-oda evaluation overview-aiyum, Eugene Yan-oda evaluation process pathi ezhudhinadhaiyum padinga.

1. Unga app-la moonu reasons-oda oru thumbs up illa down serunga, trace id-oda store aagura maadhiri.
2. Rendu automatic checks (citation irukku, response oru length limit-kku keezha) oru faithfulness judge-um ezhudhunga, response anuppina apram 10% sample-la run aagura maadhiri.
3. 30 judged samples-a neengalae grade panni, judge-oda evvalavu thadavai agree aaringa-nu compute pannunga.
4. Unga sondha conversations-oda oru vaaratha mela implicit_signals-a run panni, flag aanadha thumbs down vandhadhoda compare pannunga.

Innum depth-ku, Chip Huyen-oda *AI Engineering* (O'Reilly, 2025) chapter 10 explicit-um conversational feedback-um, feedback design-aiyum adhoda biases-aiyum cover pannudhu, chapter 3 judges-a cover pannudhu.

**Mudinjadhu-nu eppo sollalaam:** unga online scores-oda oru weekly view-aiyum, adhunaala neenga panna oru change-aiyum kaattalaam.
