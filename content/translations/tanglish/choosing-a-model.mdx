## Idhu enna

Model select panradhu-nu sollradhu, unga application-oda ovvoru pagudhiyaiyum entha language model, entha provider-oda, entha size-la run pannum-nu pick panradhu. Nooru-kanakkula options irukku: API-ku pinnaadi hosted models, neenga sondhamaa run panra open-weight models. Pudhu models ovvoru maasamum varum, ovvonnukkum record scores pathi oru press release.

Scores **benchmarks**-la irundhu varum: school maths, general knowledge, code ezhudhuradhu maadhiri oru skill-a measure panra fix panna public test sets. Oru **leaderboard** models-a, oru select panna benchmarks-oda scores-a serthu, illa rendu anonymous answers-la ethu nallaa irukkunnu makkal vote panni, rank pannum.

Benchmarks useful dhaan, aana adhu unga kelvi-ku vera kelvi-ku badhil solludhu. Adhu "indha tests-la entha model nallaa?"-nu kekkum. Neenga theriyanumnu virumburadhu "enna task-la, naan thaanga mudiyura price-layum speed-layum, en rules-oda, entha model podhumaana alavu nallaa?" Nambakkoodiya vazhikku naalu steps.

```flow
title: Naalu steps-la model select panradhu
Ellaa candidate models -> Hard requirements-la filter pannunga | licence, data location, languages, price
Hard requirements-la filter pannunga -> Public benchmarks-oda shortlist pannunga | 3 mudhal 5 models
Public benchmarks-oda shortlist pannunga -> Unga sondha data-la test pannunga | unga inputs, unga rubric
Unga sondha data-la test pannunga -> Quality, cost, speed meet aagudhaa?
Quality, cost, speed meet aagudhaa? -[illa]-> Design-a maathunga | chinna task, nalla prompt, retrieval
Design-a maathunga -> Unga sondha data-la test pannunga
Quality, cost, speed meet aagudhaa? -[aamaa]-> Launch panni monitor pannunga | models maarum podhu thirumba check pannunga
```

## Idhu eppadi work aagudhu

**Step 1: hard requirements-la filter pannunga.** Sila vishayangala prompting-aala sari panna mudiyaadhu. Mudhalla adha ezhudhunga, onnu fail aana ovvoru model-aiyum eduthudunga.

- **Licence, terms.** Commercial-aa use pannalaamaa? Adhoda outputs-a vechukkalaamaa? Sila open-weight licences periya companies-ku limits vaikkum.
- **Data location, privacy.** Indian cloud region-la illa unga sondha servers-la run aagumaa? India-oda data protection law-la, banks-ku RBI rules-la, idhu pala options-a thalli vidum.
- **Languages.** Unga users ezhudhura languages-a handle pannumaa, kalandha Hinglish-um serthu?
- **Context length, speed, price.** Unga romba neelamaana document-a padikkumaa? Podhumaana vegathula badhil solluma? Oru request-ku cost unga budget-ku set aagumaa?

**Step 2: public benchmarks-oda shortlist pannunga.** Test panna worth-aana 3 mudhal 5 candidates-a pick panna benchmarks-um leaderboards-um use pannunga, winner-a select panna illa. Indha limits-a manasula vechu padinga:

- **Leaderboards thangaloda tests-a select panrangaa.** Oru leaderboard aayirakkanakkula irundhu konjam benchmarks-a mattum cover pannum, adha select panradhu yaaru jeyikkiraanga-nu mudivu pannum. Perumbaalaanadhu English-ku, general knowledge-ku adhigam weight kodukkum.
- **Chinna details scores-a maathum.** Hugging Face oru thadavai, ore model, ore benchmark-la prompt eppadi ezhudhi score panninaanga-nu poruthu romba vera scores vaangunadha kandupidichaanga. Ore maadhiri measure panna scores-a mattum compare pannunga.
- **Saturation.** Top models ellaam 100%-kku pakkathula score pannum podhu, oru benchmark avangala pirikkaadhu. Leaderboards saturated benchmarks-a oru, rendu varushathukku oru thadavai maathum.
- **Contamination.** Benchmark questions public, adhanaala adhu web text-kulla, appuram training data-kulla leak aagudhu. Questions-a paartha model memory-la nallaa score pannum. Labs idha rendu common vazhigalla check pannuvaanga: test-kum training data-kum pothuvaa irukkura neelamaana word sequences-a thedradhu (n-gram overlap), model test questions-a sandhegamaa easy-aa predict panudhaa-nu paarkkuradhu (low perplexity). Pazhaya, popular benchmarks-la scores-a jaakkirathaiyaa paarunga.
- **Vote-based rankings** perumbaalum short chats-la makkal edhu virumbuvaangaannu kaattum, adhu fluent-aa, confident-aa, nalla formatted answers-a irukkum. Adhu unga task-oda othu pogaadhu.

**Step 3: unga sondha data-la test pannunga.** Mudivu pannura step idhu. 100 mudhal 300 real inputs-oda oru test set build pannunga, personal data anonymise panni, ovvoru language-aiyum ovvoru request vagaiyaiyum cover panni. Entha outputs-aiyum paarkka munnaadi oru scoring rubric ezhudhunga. Shortlist panna ovvoru model-aiyum ore prompt-oda odunga, quality, cost, speed-a serthu record pannunga. Test sets, LLM judges pathi lessons score panradhu eppadi-nu cover pannum.

Oru chinna harness compare panradha fair-aa vechirukkum:

```python
import json, time

def run(model_name, call_model, cases, score):
    """call_model(prompt) returns (text, cost_in_rupees). score(case, text) returns 0 to 1."""
    total, cost, slow = 0.0, 0.0, []
    for case in cases:
        start = time.time()
        text, rupees = call_model(case["input"])
        slow.append(time.time() - start)
        total += score(case, text)
        cost += rupees
    slow.sort()
    return {
        "model": model_name,
        "quality": round(total / len(cases), 3),
        "cost_per_1000": round(cost / len(cases) * 1000, 1),
        "p95_seconds": round(slow[int(len(slow) * 0.95) - 1], 2),
    }

cases = [json.loads(line) for line in open("helpdesk_test.jsonl")]
```

**Step 4: launch panni monitor pannunga.** Ovvoru vaaramum real conversations-a sample panni score pannunga. Provider model-a update pannum podhu, prices maarum podhu, illa oru cheap-aana model vara podhu, unga test set-a thirumba odunga. Maaruradhu safe-aa irukkarthukku karanam unga test set thaan.

**Build illa buy.** Hosted APIs aarambikka vegam, ungalukkaaga scale aagum, perumbaalum romba strong models. Open-weight models, adhigam volume-la data-vilayum cost-layum ungalukku control kodukkum, aana servers-a neenga odanum. Neraya teams API-la aarambichu, test set adhu podhum-nu prove pannina aprom, adhigam volume, simple steps-a chinna open model-ku maathuvaanga.

## Oru worked example

Chennai-la oru lending company-ku, Tamil-layum English-layum loan kelvigalukku oru helpdesk assistant venum. Data India-laye irukkanum, budget oru conversation-ku sumaar ₹0.37.

Avanga ettu candidates-oda aarambikkiraanga. Filter moonu-a eduthududhu: onnu Indian region-la odaadhu, onnoda licence avangaloda use-a thadukkudhu, onnu budget-a vida romba adhigam. Public leaderboards, instructions-a follow panna weak-aana innoru model-a thalla help pannudhu. Naalu meedhi irukku.

240 real kelvigal (120 Tamil, 120 English), names-um loan numbers-um eduthuttu, oru test set build panraanga, oru rubric-oda: policy-la irundhu sariyaana facts, theliva next step, polite tone, sariyaana language.

| Model | Leaderboard rank | Sondha test: Tamil | Sondha test: English | Oru conversation-ku cost | p95 reply time |
| --- | --- | --- | --- | --- | --- |
| A, periya hosted | 1 | 81% | 93% | ₹0.62 | 3.1 s |
| B, medium hosted | 6 | 84% | 90% | ₹0.21 | 1.4 s |
| C, open-weight, self-hosted | 11 | 74% | 88% | ₹0.09 | 1.9 s |
| D, chinna hosted | 15 | 62% | 85% | ₹0.05 | 0.8 s |

Numbers compare panradhu eppadi-nu kaatturadhukku mattum. Leaderboard leader A, English-la best, aana budget-a vida adhigam, Tamil-la B-a vida konjam mosam. B rendu languages-layum bar-a A-oda price-la moonu-la oru pangu-la meet pannudhu, adhanaala B-a select panraanga. C-a, pinnaadi Tamil replies-la fine-tune panna fallback-aa vechukkaraanga, pudhu model announce aagum podhu ellaam 240 kelvigalayum thirumba odi paarkkiraanga.

## Podhuvaa panra thappugal

- **Headline score vechu select panradhu.** Leaderboard win-nu sollradhu andha tests-la nallaa-nu artham, unga task-la nallaa-nu illa.
- **English-la mattum test panradhu.** Indian languages-layum kalandha-language text-layum quality perumbaalum kammi aagum. Unga users ezhudhura ovvoru language-layum test pannunga.
- **Vera vidhamaa measure panna scores-a compare panradhu.** Vera prompts, scoring rules scores-a romba maathum.
- **Launch varaikkum cost-aiyum speed-aiyum ignore panradhu.** 2 points nallaa irundhu, aana 3 madangu price-ulla model thappaana choice-aa irukkalaam.
- **Thirumba check pannaadhu.** Prices kuraiyum, models improve aagum. Aaru maasam munnaadi panna choice ippo overpriced-aa irukkalaam.
- **Pazhaya benchmarks-a nambradhu.** Popular, pazhaya test sets training data-la irukka vaaippu adhigam, adhanaala high scores memory-aa irukkalaam.

## Benchmarks help panra neramgal

- **Oru shortlist-a vegamaa build panradhu.** Coding, neelamaana documents maadhiri ungalukku thevaiyaana skill-la theliva weak-aana models-a eduthudum.
- **Field-a track panradhu.** Pudhusaa, kashtamaana benchmark, models evvalavu vegamaa improve aagudhunnu kaattum.
- **Oru claim-a check panradhu.** Oru vendor avanga model maths-la best-nu sonnaa, test panna neram selavu panna munnaadi oru public benchmark mudhal check kodukkum.

3. Unga feature-ku, nalla answer-la enna irukkanum-nu serthu, pathu real test inputs ezhudhunga. Rendu models-a adhula odi, rendaiyum score pannunga.
