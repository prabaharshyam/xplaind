## Idhu enna

Oru model pudhu data-la eppadi perform pannum-nu theriya, adhu eppovum kathukkaadha data-la, unmaiyaana use maadhiri conditions-la test pannanum.

- **Train, validation, test**: oru pagudhila train pannunga, oru validation pagudhila choices-a tune pannunga, kadaisi varaikkum thodaama vaitha oru test pagudhila final performance-a oru thadava report pannunga.
- **Cross-validation**: pala different splits-la (folds) training-um validation-um repeat panni average pannunga, data kammiyaa irukkum podhu oru stable estimate kidaikkum.
- **Data leakage**: validation illa test data-la irundhu, illa future-la irundhu information, entha vazhiyilaa irundhaalum training-ku poradhu, adhanaala results use-la irukkaradhai vida nallaa theriyum.

| Split vagai | Eppadi work aagum | Eppo use pannanum |
|---|---|---|
| Random k-fold | Fold 1 part 1-la validate panni meedhi-la train pannum, fold 2 part 2-la, apdiyae; 5 scores-a average pannunga | Rows independent-aa irundha |
| Time-based | Jan-Jun train, Jul validate; Jan-Jul train, Aug validate; Jan-Aug train, Sep validate | Rows time-pada order-la irundha: future-la ennaikkum train pannaadheenga |
| Grouped | Patient A-oda 4 admissions-um fold 2-la, Patient B-oda 2-um fold 5-la | Orae aal illa vishayam pala rows-la varum podhu |

```flow
dir: LR
title: Time-based splits future-la ennaikkum train aagaadhu
Train: Jan-Jun -> Validate: Jul
Train: Jan-Jul -> Validate: Aug
Train: Jan-Aug -> Validate: Sep
```

## Idhu eppadi work aagudhu

**k-fold cross-validation.** Data-va k folds-aa (perumbaalum 5) pirinjunga. k minus 1-la train pannunga, meedhi irukkura onnula validate pannunga; k thadava repeat pannunga. Classification-ku, stratified folds class proportions-a orae maadhiri vachirukkum.

**Time-based splits.** Data-ku time order irukkum podhu (transactions, demand, churn), random splits future-a training-kulla leak pannum. Munnaadi periods-la train panni, pinnaadi periods-la validate pannunga; time-series cross-validation indha window-a munnaadi nagarthum.

**Grouped splits.** Orae customer, patient, store pala rows-la irundha, adhoda ella rows-aiyum orae fold-la vainga. Illana model individuals-a memorise panni, pudhusaa irukkuravangalla, irukkaradhai vida nallaa theriyum.

**Leakage-oda common sources.**

- *Ella data-la preprocessing*: split panradhukku munnaadi compute panna scaling, imputing, target encoding validation rows-oda information-a use pannum. Preprocessing-a training fold-la mattum fit pannunga; scikit-learn **pipelines** cross-validation-kulla idha thaanaagavae pannum.
- *Future features*: prediction neraththukku apram irukkura information vachu compute panna features.
- *Target proxies*: outcome-oda vilaivugal-aana columns (churn predict panradhula "closed reason" field).
- *Duplicates*: orae record train-layum test-layum varudhu.
- *Test set-la tune panradhu*: test score vachu models-a select pannaa, adhu validation set-aa maaridum; final results optimistic aagum.

**Leakage-oda signs.** Aachariyamaa high-aa irukkura validation scores; oru feature-ku romba adhigamaana importance; unmaiyilaye pudhu period-la score panna periya drop.

**Final check.** Launch-ku munnaadi, model paakkaadha romba recent period-la score pannunga, ideal-aa production-la odura adhe maadhiri.

**Edhu split edhu problem-ku porundhum:**

| Data | Use panna vendiya split | Yen |
| --- | --- | --- |
| Independent rows, time order illa | Stratified k-fold | Stable estimate, class balance irukkum |
| Transactions, demand, churn | Time-based, munnaadi nagara | Model eppovum future-a predict pannum |
| Oru customer illa patient-ku pala rows | Grouped k-fold | Model paakka pora pudhu customers thaan |
| Time order-um groups-um rendum | Time-based, groups boundary-a thaandaama | Rendu risks-aiyum serkkum |

**Ovvoru split-kum pinnaadi irukkura rule:** validation data, model unmaiyaana use-la sandhikkura data maadhiri irukkanum, training prediction neraththula kidaikkura information-a mattum use pannanum. Unga split production-a eppadi mirror pannudhu-nu explain panna mudinjaa, neenga nallaa select pannirukkeenga.

**Oru score-a nambradhukku munnaadi leakage checklist.** Ovvoru feature-kum "prediction panra neraththula indha value enakku theriyumaa?"-nu kelunga. Ovvoru preprocessing step-aiyum oru pipeline-kulla fit pannunga. Splits-kku naduvula exact duplicates-a remove pannunga. Feature importance-a paathu, romba nallaa theriyura edhaiyum kelvi kelunga. Kadaisiyaa, romba recent thodaadha period-la score pannunga.

**Feature engineering-naala varra leakage.** Neraya leaks event logs-la irundhu build panna features vazhiya varum: "support calls count", "last status", "last payment-la irundhu days". Ovvonnum prediction neraththukku munnaadi irukkura events-la irundhu mattum compute aaganum. Oru nalla palakkam: ovvoru row-kum oru "prediction time" column-a fix panni, features build panra podhu ovvoru source table-aiyum adhukku munnaadi irukkura events-ku filter pannunga.

**Leakage nadakkaradha neengalae paarunga.** Pure noise-la signal illa, adhanaala nermaiyaana score 0.5 around irukkanum. Mudhalla ella data-la features-a select pannaa, noise-a predictive-aa theriya vaikkum:

```python
import numpy as np
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline

rng = np.random.default_rng(0)
X = rng.normal(size=(200, 5000))                  # 5,000 random features
y = rng.integers(0, 2, 200)                       # random labels
cv = StratifiedKFold(5, shuffle=True, random_state=0)

X_leaky = SelectKBest(f_classif, k=20).fit_transform(X, y)          # chose features using every label
print("leaky:", cross_val_score(LogisticRegression(max_iter=1000), X_leaky, y, cv=cv).mean().round(2))

honest = make_pipeline(SelectKBest(f_classif, k=20), LogisticRegression(max_iter=1000))
print("honest:", cross_val_score(honest, X, y, cv=cv).mean().round(2))
```

Leaky version random data-la 0.5-a vida romba mela score pannum; ovvoru training fold-kulla features-a select panra pipeline version chance-ku vizhundhidum. Adhe scaling, imputing, target encoding-kum poruntum.

**Code-la grouped, time splits.**

```python
from sklearn.model_selection import GroupKFold, TimeSeriesSplit

def grouped_score(model, X, y, customer_ids):
    return cross_val_score(model, X, y, cv=GroupKFold(n_splits=5), groups=customer_ids).mean()

def time_score(model, X_sorted, y_sorted, gap=0):
    """Rows must be sorted by time. gap leaves rows out between train and test."""
    return cross_val_score(model, X_sorted, y_sorted, cv=TimeSeriesSplit(n_splits=5, gap=gap)).mean()
```

Labels vara neram aagum podhu `gap` mukkiyam: churn 30 naal kazhichu judge aanaa, 30-naal gap vidunga, adhanaala training labels test period-oda overlap aagaadhu.

**Unga-lae emaathikkaama tune panradhu.** Cross-validation score vachu settings select panni, adhe score-a report pannaa optimistic. Nested cross-validation ullae tune panni, veliya score pannum:

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.datasets import make_classification

Xc, yc = make_classification(n_samples=2000, n_features=20, random_state=1)
inner = GridSearchCV(HistGradientBoostingClassifier(random_state=1),
                     {"max_depth": [3, 6], "learning_rate": [0.05, 0.1]}, cv=3, scoring="roc_auc")
outer = cross_val_score(inner, Xc, yc, cv=5, scoring="roc_auc")
print("nested ROC AUC:", outer.mean().round(3), "±", outer.std().round(3))
```

Data neraya irundha, oru simple vazhi, kadaisila oru thadava score panra thani test period.

**Leaks-a pidikkura oru test.** Ovvoru feature-kum, oru one-feature model-a train pannunga; kittathatta perfect accuracy irukkura edhaavadhu oru feature-a gavanamaa paarunga. Indha check-a unga training pipeline-la serthu, top five-a print pannunga.

## Oru worked example

Chennai-la oru hospital network discharge records-la irundhu 30-naal readmission-a predict panraanga.

Mudhal notebook random 5-fold cross-validation-oda AUC 0.91 report pannudhu. Sandhegangal:

1. Neraya patients-ku pala admissions irukku. Random folds-la, orae patient training-layum validation-layum vandhaar. **Patient vachu grouped folds**: AUC 0.83.
2. Missing lab values-a, split panradhukku munnaadi muzhu dataset-la compute panna mean vachu nirappinaanga. Imputation-a oru pipeline-kulla kondu ponaa: AUC 0.82.
3. "Follow-up appointment cancelled"-nu oru feature, sila neram readmission-ku apram record aachu. Adha remove pannaa: AUC 0.78.
4. 2023-la irundhu 2025 admissions-la train panni, 2026-oda mudhal paadhiyila test pannaa: AUC 0.77.

Nermaiyaana number, 0.77, adhuvae clinical team-oda plan-ku adippadai. Aaru maadha pilot-la, live AUC 0.76.

| Fix | Fix-ku apram AUC |
| --- | --- |
| Random 5-fold (aarambam) | 0.91 |
| Patient vachu grouped folds | 0.83 |
| Pipeline-kulla imputation | 0.82 |
| Readmission-ku apram varra feature remove | 0.78 |
| 2023-2025-la train, 2026 aarambathula test | 0.77 |
| Aaru maadha pilot-la live | 0.76 |

0.91-la irundhu 0.77-kku vizhundhadhu model mosamaanadhaala illa. Measurement nermaiyaanadhu, adhanaala thaan pilot-la edhuvum aachariyam illa.

## Podhuvaa panra thappugal

- **Time-ordered data-la random splits.**
- **Orae entity train-layum test-layum.** Customer, patient, store vachu group pannunga.
- **Split panradhukku munnaadi preprocessing.** Pipelines use pannunga.
- **Test set-a marubadi marubadi check panradhu.** Final report-ku vachukkunga.
- **Sandhegaththukkidamaana nalla scores-a ignore panradhu.** Kondaaduradhukku munnaadi investigate pannunga.

- **Cross-validation-la tune panni, adhae cross-validation score-a final-aa report panradhu.** Pala tuning rounds-ku apram, cross-validation score-um optimistic thaan. Oru thani final test set vainga.
- **Leakage rare-nu nenaikkiradhu.** Launch-ku apram models fail aagradhukku romba common-aana kaaranangalla idhu onnu. Ovvoru thadavaiyum, mukkiyamaa logs illa event tables-la irundhu build panna features-ku, idha check pannunga.
- **Cross-validate panradhukku munnaadi ella data-layum features-a select panradhu illa tune panradhu.**
- **Labels late-aa vara, training-kum test periods-kum naduvula gap illa.**
- **Best tune panna score-a, thodaadha estimate maadhiri report panradhu.**

## Simple splits podhumaanadhu eppo

- **Neraya independent rows**, time order illa, repeated entities illa: oru random hold-out set podhum.
- **Aarambathula vegamaana comparisons**, oru validation split direction kudukkum.
- **Pretrained models-a appadiyae use panra podhu**, cross-validation illa, oru clean test set mattum thevai.

## Demo-la irundhu production-ku

- **Ovvoru preprocessing step-aiyum oru pipeline-la vainga**, training folds-la mattum fit aagum.
- **Split-a production-oda match pannunga**: time, groups, illa rendum, late labels-ku gaps-oda.
- **Oru final test period vainga**, ovvoru model version-kum oru thadava score pannunga.
- **Single-feature leak checks-a** training pipeline-la odunga.
- **Offline scores-a production-oda mudhal vaarangaloda compare pannunga**; periya drop leakage-a kaattum.
