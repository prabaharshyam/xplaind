## Idhu enna

**Change management**-na makkal pazhaya velai murai-la irundhu pudhusukku maara help panra velai. AI systems-ku idhu cover pannum:

- Maatram yen nadakkudhu, ovvoru aal-ukkum adhu enna artham-nu explain panradhu;
- Design-layum testing-layum users-a serkkradhu;
- Avangaloda sondha real cases-a use panra training;
- Pazhakkam uruvaagura mudhal vaarangalla support;
- Adoption-a measure panni, makkal-a edhu thadukkudhu-nu action edukkradhu.

ADKAR-nra oru common model, ovvoru aal-ukkum yen-nu **awareness**, pangeduka **desire**, eppadi-nu **knowledge**, nadaimuraila seiya **ability**, nilaikka **reinforcement** thevai-nu solludhu. Adoption nindraa, idhula edhu missing-nu kandupidinga.

| ADKAR | Ovvoru aal-ukkum enna thevai | Neenga enna panreenga |
|---|---|---|
| **A**wareness | Maatram yen? | Leaders reason-aiyum enna maarudhu-nu explain panraanga |
| **D**esire | Naan virumbanuma? | Jobs, blame, extra work pathi nermaiyaana badhilgal |
| **K**nowledge | Idhu eppadi work aagudhu? | Avangaloda sondha cases-la 45 nimisha training |
| **A**bility | Daily panna mudiyuma? | Champions, support channel, mudhal annoyances-a sari pannunga |
| **R**einforcement | Idhu nilaikkumaa? | Results share panni, processes-um targets-um update pannunga |

Indha lesson Chennai-la oru lender-a follow pannum, avangaloda oru branch credit-summary assistant-a vegamaa adopt pannichu, innoru branch pannala.

## Idhu eppadi work aagudhu

**Worries-a peru sollunga.** Typical-aanavai: "Idhu ennai replace pannumaa?", "AI thappaa irundhaa enakku blame varumaa?", "Idhoda output-a check panradhu extra velaiyaa?", "En velai monitor pannapadudhaa?" Leaders irukkum podhu nermaiyaa badhil sollunga. Roles maaruna, eppadi-nu sollunga.

**Accountability-a clear pannunga.** AI-oda help-oda eduththa decision thappaa irundhaa yaar poruppu? Perumbaalum adhai review panni approve panna aal thaan, munnaadi maadhiri. Idhai ezhuthula podunga, review step avangalukku sariyaa check panna thevaiyaanadhai tharudhaa-nu paarunga.

**Champions-a serkkunga.** Ovvoru team-la irundhum mariyaadhai irukkura users-a select pannunga, early versions-a test panni design-a shape panna. Avangaloda feedback system-a nalladhaakkum, avangaloda support, edhu announcement-aiyum vida nallaa peers-a ottum.

**Real velaila train pannunga.** Avangaloda sondha queue-la irundhu cases-a use panra short sessions (45 nimisham): eppadi use panradhu, edhula nallaa irukku, enga fail aagudhu, eppadi check panradhu, eppadi feedback tharadhu. System thappaa irukkura examples-um serkkunga.

**Mudhal vaarangalla support pannunga.** Kelvigalukku theriyura oru channel, ovvoru team-layum oru champion, mudhal annoyances-a vegamaa sari panradhu. Ignore pannaa, mudhal frustrations nilaiyaana opinions-aa aagidum.

**Measure panni act pannunga.** Per person, per team usage, feedback, use pannaadhadhuku reasons-a track pannunga. Kammiyaa use panravanga kitta pesunga; avangaloda reasons perumbaalum sari pannalaam (oru slow step, oru missing field, adhai onnum sollaadha manager).

**Reinforce pannunga.** Results-a (neram migaththam, kammi rework) share pannunga, teams-a credit pannunga, processes-um targets-um update pannunga, pudhu murai thaan normal murai-aa aagum.

**Worries-um nermaiyaana badhilgalum:**

| Worry | Help pannura badhil |
| --- | --- |
| "Idhu ennai replace pannumaa?" | Roles-la edhaavadhu maarina enna, enna maaraadhu-nu thelivaa sollunga; leaders badhil sollanum, project team mattum illa |
| "Thappaa irundhaa enakku blame varumaa?" | Ezhuthula accountability: officers flag aana, mukkiya fields-oda review-a own pannuvaanga, tool sources-a pakkathula kaattum |
| "Idhu extra velaiyaa?" | Similar team-la irukkura colleagues-oda, file-ku munnaadi, pinnaadi measure panna neram-a kaattunga |
| "Naan monitor pannapadureena?" | Enna measure pannapadudhu, yen, yaar paarkkuraanga-nu sollunga; adoption-a team-vaaripaa measure pannunga, individuals-a rank panna illa |

**Adoption dashboard.** Ovvoru team-kkum, ovvoru vaarathukkum kaattunga: tool-oda seiyappatta eligible velaiyoda share, oru item-ku median neram, rework rate, mukkiyamaana feedback reasons. Edutha actions-ku oru short note column serunga. Oru team oppukkitta level-kku keezha, 50% maadhiri, poyiduchuna, andha vaaramae yaaravadhu andha team-a paakka pogalaam. Dashboard, enga help thevai-nu kandupidikka, teams-a blame panna illa.

**Nilaikkura training.** Team-oda sondha queue-la irundhu cases, system thappaa irukkura oru case-um serthu, demo paarkkaama session-laye makkal try pannattum. Kelvigal enga kekkalaam, avangaloda champion yaaru-nu sollitu mudinga. Miss pannavangalukku session-a thirumba nadathunga, yen-na training skip pannavanga thaan perumbaalum pinnaadi tool velai seiyala-nu solluvaanga.

## Oru worked example

Chennai lender-la, pilot-la moonu vaarathukku apram, Anna Nagar branch-la adoption 92%, Tambaram-la 41%.

Neenga Tambaram-ku poi officers kitta pesureenga. Moonu reasons varudhu:

- Branch manager, edhaavadhu figure error-um "AI irundhaalum illaadhaalum avangaloda poruppu"-nu sonnaar, neraya perum ellaathaiyum thirumba type panradhu safe-nu mudivu pannaanga.
- Rendu officers training-a miss pannaanga.
- Draft summary-la English headings, avangaloda regional credit head virumbura format-a vida veraa.

Actions: head of operations, officers flag aana, mukkiya fields-a review panna accountable-nu, side-by-side view thaan check panna approved vazhi-nu oru note anuppuraanga; branch manager officers fields-a eppadi verify panraanga-nu kaattura session-la serraar. Oru repeat training nadakkudhu. Summary template-ku oru regional variant serkkappadudhu. Rendu vaarathula Tambaram 85% adaiyudhu, adhoda median file time 37-la irundhu 25 nimishathukku kuraiyudhu.

| Branch measure | Visit-ku munnaadi | Rendu vaaram aprom |
| --- | --- | --- |
| Tambaram-la adoption | 41% | 85% |
| Tambaram-la median file time | 37 nimisham | 25 nimisham |
| Sari panna kaaranangal | Blame message, miss aana training, template mismatch | Clarify panna note, repeat training, regional template |

## Podhuvaa panra thappugal

- **Email-la launch panradhu.** Oru announcement adoption illa.
- **Job kelvi-a thavirkkradhu.** Amaidhi, rumours-a valarkkum. Enna maarudhu-nu nermaiyaa sollunga.
- **Generic demos-la train panradhu.** Makkal-oda sondha cases-a use pannunga, failures-um serthu.
- **Clear-aa illaadha accountability.** Blame bayandhaa, tool-a nambavum use pannavum maattaanga.
- **Low adopters-a paakkaama irukkradhu.** Reasons local-aa irukkum, perumbaalum sari pannalaam.

## Practice pannunga

Prosci-oda ADKAR model vilakkatha padinga.

1. Unga use case-ku, moonu groups-oda (front-line staff, avangaloda managers, risk illa compliance) worries-a list pannunga, ovvonnayum eppadi address pannuveenga.
2. Real cases-a use panra 45 nimisha training session plan pannunga, system thappaa irukkura oru case-um serthu.
3. Oru adoption dashboard design pannunga: ovvoru team-kkum enna measure pannuveenga, oru team 50%-kku keezha pona enna pannuveenga.

**Mudinjadhu-nu eppo sollalaam:** Nindra oru team-ku, edhu ADKAR element missing-nu, indha vaaram adha sari panna enna pannuveenga-nu explain panna mudiyum.
