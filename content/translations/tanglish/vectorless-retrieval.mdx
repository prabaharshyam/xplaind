## Idhu enna

Standard RAG documents-a chunks-aa vettum, embed pannum, similarity vechu retrieve pannum. Idhu neraya chinna documents-ku nallaa work aagum. 300-page annual report, oru insurance regulation, oru master services agreement maadhiri oru neenda, structured document-ku adhu kammiyaa work aagum, adhula:

- badhil oru passage enga irukku-nu thaan sarndhu irukku ("standalone-la illa, consolidated statements-oda notes-la");
- text "as defined in section 2.4"-nu solludhu, aana definition romba doorathula irukku;
- pala passages onnu pola theriyum (ovvoru varushathoda revenue table), adhanaala similarity avatrai pirikka mudiyaadhu.

**Vectorless retrieval** document-oda structure-a vachirukkum. Table of contents-la irundhu oru tree build pannuveenga (chapters, sections, sub-sections, ovvondrukkum oru chinna summary), oru model thaanaave yosichu keezhe pogum: top level-a padikkum, sariyaana section-a choose pannum, adha thirakkum, thirumba choose pannum, kadaisila sariyaana pages-a padikkum. PageIndex maadhiri open-source projects indha idea-va package pannuthu.

```flow
title: Annual report FY2026, 320 pages: the model opens only the branches it needs
Annual report -> Corporate overview | strategy, products
Annual report -> Directors' report | performance, risks
Annual report -> Standalone statements | parent company only
Annual report -[opened: analysts mean consolidated]-> Consolidated statements
Consolidated statements -> Balance sheet, P&L, cash flow
Consolidated statements -[opened]-> Notes
Notes -[opened]-> Note 38 Contingent liabilities | p.241, refers to Note 41
Note 38 Contingent liabilities -[opened]-> Note 41 Disputed tax matters | p.247
Note 41 Disputed tax matters -> Answer cites Note 38 and Note 41
```

Indha lesson-la Mumbai-la oru equity research team, oru company-oda annual report pathi thulliyamaana kelvigal kekkaradha follow pannuvom.

## Idhu eppadi work aagudhu

**Tree-a oru thadava build pannunga.** Document-oda headings-a oru hierarchy-aa parse pannunga. Ovvoru node-kum title, page range, konjam lines summary store pannunga, adha indexing-la oru model ezhudhalaam. Scan panna illa mosamaa format aana documents-a mudhalla clean pannanum; indha method adhu kandupidikkura structure-a vida nallaa irukkaadhu.

**Ovvoru kelvikkum navigate pannunga.** Model-ku kelviyum top-level nodes-um kudunga (titles, summaries mattum, adhu selavu kammi). Edha thirakkanum, yen-nu kelunga. Avatrai expand pannunga, leaf sections varaikkum thirumba pannunga, apram adhoda muzhu text-a prompt-la vechu, sections-aiyum pages-aiyum cite panni badhil sollunga.

**References-a follow pannunga.** Oru section "see note 14"-nu sonnaa, model andha node-a kekkalaam. Vectors-aala idhu mudiyaadhu.

**Selavu.** Ovvoru kelvikkum sequence-la pala model calls, adhanaala oru vector lookup-a vida methuvaa, selavaana-dhu. Konjam neenda, high-value documents-ku, precision mukkiyamaana kelvigal-ku set aagum, example oru analyst oru company-oda filings pathi kekkaradhu. 50,000 support articles-la search panna set aagaadhu; adhula hybrid search jeikkum.

Neraya production systems rendaiyum serkkum: edha documents mukkiyam-nu pick panna vector illa keyword search, ovvoru neenda document-kullayum tree navigation.

**Vector RAG vs tree navigation:**

| Factor | Vector RAG | Tree navigation |
| --- | --- | --- |
| Nalla documents | Neraya chinnavai | Konjam neenda, structured-aanavai |
| Cross-references | Thavara vidum | Follow pannum |
| Onnu pola theriyura passages | Aksar kuzhambum | Tree-la position-pada pirikkapadum |
| Oru kelvikku calls | Oru search, oru answer | Sequence-la pala |
| Latency | Perumbaalum vegam: oru lookup | Methuvaa: ovvoru call-kum valarum |
| Setup | Chunk and embed | Headings-a parse pannunga, node summaries ezhudhunga |

**Tree-a check panradhu.** Indha method-a nambu munnaadi, ovvoru document-kum tree-a print panni, nijamaana table of contents-oda compare pannunga. Headings kandupidikkaama flat-aa irukkura trees-a, overlap aagura page ranges irukkura sections-a, vague-aana summaries-a paarunga. Konjam mukkiyamaana documents-ku tree-a kaiyaala sari seiyaradhu perumbaalum worth, yenna adhe documents-a pala thadava query pannuvaanga.

**Node summaries ezhudhuradhu.** Nalla summaries oru section edha vachirukku-nu solum, edha vaadhidum-nu illa: "Contingent liabilities by type, both years, with references to tax notes" model choose panna help pannum; "Discusses the company's risks" pannaadhu. Users kekkura mukkiya terms-a serungal, example taxes, schemes, contract parties-oda per.

**PDF-oda bookmarks-la irundhu tree-a build pannunga.** Neraya neenda PDFs-la PyMuPDF padikka mudiyura table of contents irukkum:

```python
import fitz

def build_tree(pdf_path):
    doc = fitz.open(pdf_path)
    toc = doc.get_toc()                         # [[level, title, page], ...]
    nodes = []
    for i, (level, title, page) in enumerate(toc):
        end = next((p - 1 for l, _, p in toc[i + 1:] if l <= level), doc.page_count)
        nodes.append({"id": f"n{i}", "level": level, "title": title.strip(),
                      "pages": (page, max(page, end)), "summary": None})
    return doc, nodes

def text_of(doc, node):
    a, b = node["pages"]
    return "\n".join(doc[p - 1].get_text() for p in range(a, b + 1))
```

`get_toc()` kaaliyaa irundhaa, font size-vachu headings-a kandupidikkalaam, illa mukkiyamaana documents-ku mudhal rendu levels-a kaiyaala ezhudhalaam. Ovvoru node-oda `summary`-a oru model indexing neraththula oru thadava nirappum.

**Navigation loop.** Titles-aiyum summaries-aiyum kaattunga, model nodes-a pick pannattum, avatrai thirandhu, oru cap-la nirutthunga:

```python
import json

def children(nodes, parent):
    if parent is None:
        return [n for n in nodes if n["level"] == 1]
    i = nodes.index(parent)
    out = []
    for n in nodes[i + 1:]:
        if n["level"] <= parent["level"]:
            break
        if n["level"] == parent["level"] + 1:
            out.append(n)
    return out

def navigate(question, doc, nodes, choose, answer, max_open=6):
    """choose(question, options) -> {"open": [ids], "done": bool}, as structured output."""
    frontier, gathered, opened = children(nodes, None), [], 0
    while frontier and opened < max_open:
        menu = [{"id": n["id"], "title": n["title"], "pages": n["pages"], "summary": n["summary"]} for n in frontier]
        pick = choose(question, json.dumps(menu, ensure_ascii=False))
        chosen = [n for n in frontier if n["id"] in pick["open"]][: max_open - opened]
        if not chosen:
            break
        next_frontier = []
        for n in chosen:
            opened += 1
            kids = children(nodes, n)
            if kids:
                next_frontier += kids
            else:
                gathered.append((n["title"], n["pages"], text_of(doc, n)))
        if pick.get("done"):
            break
        frontier = next_frontier
    if not gathered:
        return "I could not find a section that answers this.", []
    return answer(question, gathered), [(t, p) for t, p, _ in gathered]
```

Kaattina ovvoru menu-vaiyum, edukkapatta ovvoru choice-aiyum log pannunga. Oru badhil thappaa irundhaa, model enga thappaa thirumbunadhu-nu log neraa kaattum.

**References-a follow panradhu.** Serththa text-la "see Note 14" irundhaa, adhu child illaadhaalum, porundhura node-a adutha menu-la serunga. Serththa text-mela "Note \d+", "Section \d+(\.\d+)*", "Schedule [IVX]+"-kku oru simple regex perumbaalaana annual reports-aiyum circulars-aiyum cover pannum.

**Search-oda mix pannunga.** Neenda documents-oda oru library-kku, document titles-lum node summaries-lum keyword illa vector search use panni document-aiyum oru starting node-aiyum pick pannunga, apram adhukkulla navigate pannunga.

## Oru worked example

Mumbai-la oru equity research team kekkudhu: "FY2026 mudivula disputed GST demands-kaana contingent liability evvalavu, adhu valarndhirukka?"

Annual report 320 pages. Saadhaa vector search GST-aiyum contingent liabilities-aiyum kuripidura aindhu chunks-a return pannum, standalone statements-la irundhu, consolidated statements-la irundhu, directors' report-la irundhu, mundhaiya varusha comparison column-la irundhu. Model standalone-aiyum consolidated figures-aiyum kalandhu oru thappaana badhil tharum.

Tree navigation-oda:

1. Model top level-a paakkudhu: Corporate overview, Directors' report, Standalone financial statements, Consolidated financial statements. Analysts sollaama irundhaa consolidated-nu thaan artham, adhanaala adha thirakkudhu.
2. Ulla: Balance sheet, Profit and loss, Cash flow, Notes. Adhu Notes-a thirakkudhu, apram "Note 38: Contingent liabilities and commitments".
3. Andha note-la rendu varushamum irukkura oru table irukku, disputed tax details-ku Note 41-a refer pannudhu. Model Note 41-aiyum thirakkudhu.

Badhil Note 38 (page 241), Note 41 (page 247)-a cite pannudhu, rendu varushaththaiyum adhe table-la irundhu tharudhu. Adhukku aindhu model calls-um sumaar onbadhu seconds-um aachu, vector RAG-ku rendu seconds-kum kammi. Page-oda check panna mudiyura sariyaana badhilukku team kaathirukka sandhoshappaduvaanga.

| Approach | Sari | Calls | Neram |
| --- | --- | --- | --- |
| Vector RAG | Illa: standalone-aiyum consolidated figures-aiyum kalandhudhu | 2 | 2 s-kku kammi |
| Tree navigation | Aam, rendu varushamum, page citations-oda | 5 | Sumaar 9 s |

## Podhuvaa panra thappugal

- **Ellathukkum use panradhu.** Neraya chinna documents-ku, tree search methuvaa, selavaana-dhu, gain illa.
- **Odanjupona table of contents-a nambradhu.** Scan panna illa sariyaa tag aagaadha PDFs flat illa thappaana tree-a tharum. Nambu munnaadi tree-a check pannunga.
- **Model-a alaiya vidradhu.** Oru kelvikku adhu thirakka koodiya nodes-ku cap podunga, illaina cost-um latency-yum limit illaama valarum.
- **Evaluation-a vittudradhu.** Adhe golden set-la unga hybrid RAG-oda compare pannunga; oru method smart-aa kekkudhu-nu adopt pannaadheenga.
- **Page numbers-a izhakkradhu.** Page, section citations thaan mukkiya payan; ovvoru step-layum vachukkunga.
- **Node openings-ku cap illaama irukkradhu**, adhanaala kashtamaana kelvigal alanju cost-a yethum.
- **Nijamaana table of contents-oda print panni check pannaadha tree-a nambradhu.**

## Vectors-a eppo use pannanum

- **Neraya chinna documents**, FAQs illa support articles maadhiri: hybrid search vegam, selavu kammi.
- **Unmaiyaana structure illaadha documents**, chat logs illa emails maadhiri.
- **Tight latency budgets**, pala sequential calls romba methuvaa irukkum idathula.

## Demo-la irundhu production-ku

- **Ingestion-ku aprom ovvoru document-oda tree-a check pannunga**, mukkiyamaanavatrai kaiyaala sari pannunga.
- **Ovvoru kelvikkum openings-aiyum neram-aiyum cap pannunga**, oru clear "not found" badhil-oda.
- **Ovvoru kelvikkum menus-aiyum choices-aiyum log pannunga.**
- **Oru document version-la thirumba kekkura kelvigalukku badhilgala cache pannunga.**
- **Oru document-oda pudhu version vandha, trees-aiyum summaries-aiyum thirumba build pannunga.**

## Practice pannunga

PageIndex introduction-a padinga, tree eppadi build aagudhu-nu adhoda docs-a skim pannunga.

1. Oru neenda public document-a edunga, example oru listed company-oda annual report illa oru regulator-oda master circular. Page ranges-oda headings-oda oru tree-a build pannunga, venumna mudhal rendu levels-a kaiyaala.
2. Sariyaana section thevaippadura paththu kelvigal ezhudhunga, rendu cross-reference thevaippadura kelvigal-um serthu.

4. Unga document-ku tree-a print pannunga, print panna table of contents-oda compare pannunga, mudhal moonu difference-a sari pannunga.

**Mudinjadhu-nu eppo sollalaam:** Unga test-la entha vagai kelvikkum documentkkum tree navigation jeichudhu-nu, adhukku enna selavu aachu-nu sollamudiyum.
