## Idhu enna

**Debugging**-na oru program neenga ethirpaarkkaradha vida vera edhaiyo yen pannudhu-nu kandupidichu, kaaranatha fix panradhu. Bug program-a crash pannalaam, thappaana number kudukkalaam, illa unga laptop-la odi server-la fail aagalaam.

Beginners perumbaalum guess panni debug pannuvaanga: oru line-a maathu, thirumba odu, innoru line-a maathu. Chinna bugs-ku adhu work aagum; unmaiyaana bugs-ku maadha kanakkaa neram veenaagum. Anubavam ulla engineers oru method use pannuvaanga. Easy bugs-ku adhu vegam illa, aana adhu eppavum mudiyum, edhaiyaachum eppadi track pannuveenga-nu interviewers kekkum podhu adhu thaan kekka virumbuvaanga.

## Idhu eppadi work aagudhu

```flow
title: Debugging loop
Reproduce pannunga | eppavum fail aagura romba chinna input -> Error-a padinga | traceback keezha irundhu mela
Error-a padinga -> Oru guess pannunga | idhu nadakka enna unmaiyaa irukkanum?
Oru guess pannunga -> Narrow down pannunga | print, breakpoint, search-a paadhiyaakkunga
Narrow down pannunga -[guess thappu]-> Oru guess pannunga
Narrow down pannunga -[kaaranam kidaichuchu]-> Symptom-a illa, kaaranatha fix pannunga
Symptom-a illa, kaaranatha fix pannunga -> Fix illaama fail aagura oru test serunga
```

**Reproduce.** Bug-a eppavum trigger panra romba chinna input-a kandupidinga. "Sila neram fail aagum" "CSV-la amount kaaliyaa irundha fail aagum"-nu maarum. Nambikkaiyaana reproduction paadhi velai.

**Error-a padinga.** Python traceback keezha irundhu mela padikkum:

```text
Traceback (most recent call last):
  File "report.py", line 31, in <module>
    print(monthly_total(rows))
  File "report.py", line 12, in monthly_total
    total = total + row["amount"]
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Kadaisi line thaan error: oru number-ayum oru string-ayum serka paathingale. Adhukku mela irukkura line adhu enga nadandhuchu-nu. Adhukku mela irukkura lines program eppadi anga vandhuchu-nu kaattum.

**Narrow down pannunga.** Indha error nadakka enna unmaiyaa irukkanum-nu kelunga, apram adha check pannunga. Moonu tools, vegamaanadhula irundhu aazhamaanadhu varaikkum:

| Tool | Eppadi | Edhukku nalladhu |
| --- | --- | --- |
| `print(repr(x))` | Mukkiyamaana idathula values-a print pannunga | Vegamaana checks; `repr` quotes-ayum types-ayum kaattum |
| `breakpoint()` | Niruthi, debugger-la paarunga | Thappaa pora neratha-la ella variables-ayum paakka |
| Editor debugger | Click panni breakpoints vainga, step pannunga, values-a watch pannunga | Neenda investigations |
| Logging | Context-oda `logging.debug(...)` | Server-la mattum therira bugs |
| `git bisect` | Commits-la binary search | "Pona vaaram work aachu" |

**Debugger.** Oru line-la `breakpoint()` podunga, program-a odunga. Adhu anga nikkum; `p row` type panni oru variable-a print pannalaam, `n` adutha line-a odum, `s` function-kulla pogum, `c` continue pannum. Guess panradhukku badhila, mukkiyamaana neratha-la unmaiyaana state-a paakkalaam.

**Search-a paadhiyaakkunga.** 200-line pipeline thappaana total kuduthaa, naduvula value-a check pannunga. Anga sariyaa irukkaa? Bug rendaavadhu paadhila. Thappaa? Mudhal paadhila. Konjam checks-la line kidaichidum. `git bisect` adhey commits-la pannum: oru nalla commit-um oru mosamaana commit-um mark pannunga, adhai udaichcha maatrathukku Git ungalai kondu pogum.

**Kaaranatha fix pannunga.** Fail aagura line-a `try/except`-la sutthinaa symptom-a maraikkum; bad data appadiyae irukkum. Thappaana value enga irundhu varudho anga fix pannunga.

**Prove pannunga.** Unga fix illaama fail aagi, fix-oda pass aagura oru test ezhudhunga.

**AI apps-la bugs.** Oru LLM feature thappaa answer kuduthaa, adhey method thaan, traceback-ku badhila oru trace-oda. Andha request-oda trace-a thirandhu, ovvoru step-ayum order-la check pannunga: kelvi sariyaa rewrite aachaa, retrieval sariyaana passage-a kandupidichucha, prompt-la adhu irundhucha, model adha use pannucha? Mudhal thappaa therira step-la thaan thondanum.

## Oru worked example

Pune-la oru pharmacies chain-ku Imran-oda monthly sales report oru store-ku ₹0 kaattudhu, dashboard ₹4.2 lakh kaattudhu.

**Reproduce.** Adhey export file-oda, October-ku report-a avan laptop-la odraan. Adhey result: Kothrud store-ku ₹0. Reproduce aagudhu.

**Padinga.** Error edhuvume illa, adhuvae oru clue: code odudhu, aana data-va skip pannudhu illa zero aakkudhu.

**Guess, narrow down.** Total zero aaga enna unmaiyaa irukkanum? Store-ku rows match aagala, illa ella amounts-um zero. Loop-kulla `breakpoint()` vachchu, mudhal sila rows-oda `row["store"]`-a print panraan: `'Kothrud '`, kadaisila oru space. Avan filter `'Kothrud'`-oda compare pannudhu. Rows edhuvum match aagala.

**Kaaranatha fix pannunga.** Filter-la space-a serkkalaam, aana unmaiyaana problem export-oda ozhungillaadha data. File padikkura idathulaye store peyargal-oda whitespace-a strip panraan, appo pinnaadi ovvoru step-kum clean values kidaikkum.

**Prove pannunga.** Kadaisila space irukkura store peyar-oda oru test serthu, adhu count aagudha-nu check panraan. Master list-la irukkura oru store-ku rows illaadha podhu warn panra oru check-um serkkuraan; appo adhutha thadavai idhu maadhiri mismatch ₹0-nu amaidhiyaa kaattaama, sathamaa therium.

## Podhuvaa panra thappugal

- **Bug-a reproduce panna mudiyaadhappo code-a maathradhu.** Unga fix velai senjuchu-nu theriyaadhu.
- **Traceback-a mela irundhu padikkiradhu.** Error-um fail aana line-um keezha irukku.
- **Symptom-a fix panradhu.** Error-a vizhungura `try/except` adutha bug-a kandupidikka innum kashtamaakkum.
- **Onnukku mela maatrathai oru thadavaiyilaye panradhu.** Work aaga aarambichaa, edhu mukkiyam-nu theriyaadhu.
- **Debug prints-ayum breakpoints-ayum vittuttu poradhu.** Commit panradhukku munnaadi `breakpoint(`-a, stray prints-a search pannunga.
- **Test serkkaama vidradhu.** Yaaraavadhu andha code-a thodum podhu bug thirumba varalaam.

## Practice pannunga

1. Oru chinna script-la oru bug-a vainga (string amount, range-la off-by-one), `breakpoint()`-oda kandupidinga.
2. Unga pazhaiya errors-la irundhu moonu tracebacks-a padichu, kadaisi line-la irundhu enna thappu-nu sollunga.
3. Oru practice repository-la, paththu commits-la onnula edhaiyaachum udaichu, `git bisect`-la kandupidinga.
4. Interview-la solra maadhiri, unga debugging method-a oru nimishathula sathamaa explain pannunga.
