## Idhu enna

Ovvoru AI product-um orae maadhiri thaan aarambikkum: unga app oru model-ku oru kelvi-a anuppi answer-a kaattum. Idhu oru muzhumaiyaana, work aagura architecture. Perumbaalaana unmaiyaana products idhula irundhu parts-a serthu valarum, order mukkiyam.

Neraya teams valarum oru podhuvaana order:

1. **Context-a better pannunga.** Model-ku sariyaana information-a kudunga: documents-la irundhu retrieval, data lookups, tools.
2. **Guardrails podunga.** Model-ku ulla pogradhaiyum veliya varradhaiyum check pannunga.
3. **Router-um gateway-um serunga.** Ovvoru request-yum sariyaana idathuku anuppunga, ellaa model calls-yum oru idathula manage pannunga.
4. **Caches serunga.** Adhe velaiku rendu dhadava selavu pannaadheenga.
5. **Agent patterns serunga.** Loops, pala steps, ulagathula edhaavadhu maatha actions.

Idhu ellaathoda sernthu, mudhal naal-la irundhu: **monitoring**, appo ovvoru part-um enna pannudhu-nu paakkalaam.

Idhu oru kattayamaana recipe illa. Unmaiyaana oru problem kekkum podhu mattum oru layer-a serkkanum-nu thaan point, appo system, product anumadhikkara alavukku simple-aa irukkum.

```flow
title: Valarndha oru AI app-vazhiyaa oru request
User question -> Input guardrails | personal data mask, injection block
Input guardrails -> Router | intent: FAQ, account, scope-ku velila
Router -[FAQ]-> Cache | exact illa semantic
Cache -[miss]-> Retrieve context | documents, data, tools
Router -[account]-> Retrieve context
Router -[scope-ku velila]-> Stock reply
Retrieve context -> Gateway | keys, limits, retries, fallback
Gateway -> Model
Model -> Output guardrails | format, facts, safety
Output guardrails -[fail]-> Retry illa oru aal-kitta kudukkum
Output guardrails -[pass]-> Answer, trace-a log pannu
```

## Idhu eppadi work aagudhu

**Step 1: context-a mempadutthunga.** Oru model-ku adhoda training data-vum prompt-la neenga vekkradhum mattum thaan theriyum. Perumbaalaana aarambha quality problems missing illa pazhasaana facts, adhanaala mudhal addition perumbaalum retrieval (documents, oru database, oru search index) illa tools (oru order lookup, oru calculator). RAG-um tool-calling-um lessons idhai aazhamaa cover pannum.

**Step 2: guardrails.** Rendu vagai.

- **Input guardrails**, private data velila services-ku leak aagaama thadukkum, example model call-ku munnaadi Aadhaar numbers, phone numbers, names-a mask panradhu, kedutha illa inject pannina instructions-a pidikkum.
- **Output guardrails**, user paakkradhukku munnaadi answer-a check pannum: valid format, support illaadha claims illa, personal data illa, unga policy-ku edhiraa edhuvum illa. Oru check fail aanaa, retry pannalaam, vera model-ku fall back pannalaam, oru safe message tharalaam, illa oru aal-kitta kudukkalaam.

Guardrails latency-a serkkum, kuripaa stream aagura answers-la, adhula text-a kaattradhukku munnaadiyaa, kaattum podhaa check pannanum-nu mudivu pannanum. Vegamaana checks-a inline-aa vechukkunga, mella-aanavai-a oru sample-la.

**Step 3: router-um gateway-um.**

- Oru **router**, oru request enga pogum-nu mudivu pannum, perumbaalum oru sirusaana, vegamaana intent classifier-vechu. Easy questions-a oru cheap model-ku, kashtamaanavai-a oru strong model-ku anuppalaam, billing disputes-a oru aal-ku anuppalaam, scope-ku velila irukkura questions-ku model-a call pannaamalae oru polite stock reply tharalaam, illa oru message kuzhappamaa irundhaa clarification kekkalaam ("Freeze my account, or the weather?").
- Oru **gateway**, ellaa model calls-um pogura oru idam. API keys-a vechirukkum, appo avai services-la sidharaama irukkaadhu; yaaru entha model use pannalaam-nu control pannum, spend limits-a amulpadutthum, ovvoru call-yum log pannum, oru provider down-aa irundhaa retry pannum illa vera provider-ku fall back aagum.

**Step 4: caches.**

- **Exact cache:** adhe normalise pannina question, template version, model onnu-na, adhe store pannina answer varum. Safe-um simple-um.
- **Semantic cache:** oru pudhu question, oru pazhaya question-oda **artham** onnu-na, oru answer-a thirumba use panradhu, embeddings-vum oru similarity threshold-vum vechu match pannuvaanga. Questions thirumba thirumba varra podhu neraya save pannum, aana oru loose match thappaana answer tharum ("refund for order 1" -um "refund for order 2" -um close). Hit rate adhigamaa irukkum podhum, adhoda thappugala alandhirukkum podhum mattum serunga.

Thirumba use panna safe-aana exact cache key-la, answer-a maathura ellaathaiyum serkkanum:

```python
import hashlib, re

def cache_key(question, template_version, model, day):
    """Same key only when the answer would be the same: same words, prompt, model and day."""
    normalised = re.sub(r"\s+", " ", question.strip().lower())
    raw = f"{normalised}|{template_version}|{model}|{day}"
    return hashlib.sha256(raw.encode()).hexdigest()

# cache_key("What are Dr Mehta's timings?", "v7", "fast-model", "2026-11-08")
```

- **Prompt caching**-um **KV cache**-um model provider illa server-la nadakkum; avai work aaga, unga prompt-oda maaraadha pagudhi-a mudhalla vechukkunga.

**Step 5: agent patterns.** Ippo varaikkum ovvoru request-um oru pakkamaa pogum. Agent patterns loops (mudhal answer muzhumaiyillana thirumba retrieve pannu), pala steps, email anuppradhu illa oru appointment book panradhu maadhiri **write actions**-a serkkum. Avai system-a romba capable-aa aakkum, romba risky-aavum aakkum. Kadaisiyaa serunga, data-va maathura edhukkum approvals-oda, tools enna seiyalaam-nu limits-oda, steps-kum spend-kum budgets-oda.

**Mudhal naal-la irundhu monitoring.** Ovvoru request-yum oru trace-aa log pannunga: input, retrieved context, model, prompt version, output, guardrail results, latency, cost, personal data mask aagi. Oru dashboard-la konjam signals-a track pannunga: error-um refusal rates-um, guardrail triggers, ovvoru request-ku cost, latency, user feedback. System valarum podhu, edhu layer fail aachu-nu kandupidikka traces thaan vazhi.

| Layer | Eppo serkkanum | Saadhaarana tools | Adhu konduvara pudhu risk |
| --- | --- | --- | --- |
| Context | Answers facts-a miss pannum illa kandupidikkum | Vector search, SQL, APIs | Thappaana illa pazhasaana documents |
| Guardrails | Unmaiyaana users-um unmaiyaana data-vum varum | PII masking, validators, judge checks | Latency, thappaana blocks |
| Router | Requests difficulty illa type-la maarum | Sirusaana classifier, rules | Thappaa route aana requests |
| Gateway | Oru model, service illa team-a vida adhigam | LiteLLM, cloud gateways | Oru single point of failure |
| Cache | Neraya thirumba thirumba varra questions | Redis, vector index | Pazhasaana illa thappaana thirumba use |
| Agents-um actions-um | Tasks-ku pala steps illa maatrangal thevai | Agent SDKs, LangGraph | Control illaadha loops, harmful actions |

## Oru worked example

Pune-la 40 clinics irukkura oru chain, oru WhatsApp assistant nadathudhu. Adhu timings-yum fees-yum list panra oru neelamaana prompt-oda oru model call-aa aarambichudhu. Aaru maadham aprom, naalu problems: sollra fees sila neram pazhasaa irukkum, patients messages-la Aadhaar-yum phone numbers-yum share pannuraanga, adhe paththu questions traffic-la 40%, patients appointments book panna kettute irukkaanga.

Order-la valarkkuraanga:

1. **Context.** Timings, fees, doctor schedules ippo question vara neraththula clinic system-la irundhu varudhu. Pazhaya fees maraiyudhu.
2. **Guardrails.** Entha model call-ku munnaadiyum Aadhaar-yum phone numbers-yum mask aagudhu. Oru output check, diagnosis maadhiri padikkura edhaiyum block pannum, fees clinic system-oda match aagudhaa-nu confirm pannum.
3. **Router.** Oru sirusaana classifier, top FAQs-a fixed answers-ku, lab-report questions-a oru secure link-ku, urgent edhaiyum oru phone number-ku anuppudhu, model call illaama.
4. **Exact cache**, meedhi thirumba thirumba varra questions-ku, normalise pannina question-oda date-oda key pannina, yen-na schedules thinam maarum.
5. **Booking oru tool-aa**, kadaisiyaa: assistant oru slot-a propose pannum, patient oru button-la confirm pannuvaanga, ovvoru booking-yum log aagum.

| Measure | Munnaadi | Aprom |
| --- | --- | --- |
| 1,000 messages-ku model calls | 1,000 | 520 |
| Thappaana fee illa timing answers (vaaraanthira sample) | 6% | 1%-ku kammi |
| Aadhaar numbers-oda model-ku anuppina messages | Dhinam sila | Onnum illa |
| Chat-la mudinja bookings | 0 | Booking requests-la 22% |

Numbers example-kaaga thaan. Avanga semantic cache-a serkkala: oru test, adhu "Dr Mehta's timings"-a "Dr Mehra's timings"-oda match pannadhai kaattuchu.

## Podhuvaa panra thappugal

- **Muzhu platform-a mudhalla build panradhu.** Paththu users-ku munnaadi aindhu layers-na, debug panna aindhu idam, kathukkitta edhuvum illa.
- **Context work aagradhukku munnaadi agents-a serkkradhu.** Thappaana facts-la seiyra agent innum adhigam, innum vegamaa nashtam kudukkum.
- **Log mattum panra guardrails.** Block pannaadha, retry pannaadha, escalate pannaadha oru check edhaiyum paadhugaakkaadhu.
- **Details irukkura questions-la semantic cache.** Order numbers, names, dates, orae maadhiri theriyura questions-a vera artham-aakkidum.
- **Traces illaama irukkradhu.** Oru request-ku oru trace illaama, retrieval-aa, router-aa, model-aa fail aachu-nu solla mudiyaadhu.
- **Keys-um limits-um services-la sidharaama irukkradhu.** Oru gateway, simple-aa irundhaalum, spend-yum access-yum oru idathula vechirukkum.

## Simple-aa vechukka vendiya idangal

- **Konjam peroda internal tools-ku** router, gateway, cache eppavum thevaippadaama pogalam.
- **Kammi volume** caching-um routing-um savings-a gavanikka mudiyaadha alavukku sirusaakkum.
- **Read-only answers-ku** agent loops-um write actions-um thevai illa.

## Demo-la irundhu production-ku

- **Ovvoru layer-um yen irukkunu ezhudhi vechukkunga**, adhu theertha problem-um, alandha effect-um-oda.
- **Layers-a thaniyaa test pannunga**: retrieval recall, router accuracy, guardrail false-block rate, cache error rate.
- **Ellaathaiyum serthu version pannunga**: prompts, router model, guardrail rules, cache keys; appo oru release-a oru ottaiyaa rollback pannalaam.
- **Safe-aa fail aagunga**: oru layer down-aa irundhaa, request oru error page-ku illa, oru simple-aana path-ku fall back aaganum.
