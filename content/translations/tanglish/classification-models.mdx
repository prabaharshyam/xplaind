## Idhu enna

**Classification** oru category-a predict pannum: fraud illa genuine, poiduvaanga illa irundhuduvaanga, aindhu complaint types-la edhu. Perumbaalaana classifiers oru **probability** illa score-a output pannum; oru **threshold** adha decision-aa maathum ("probability 0.3-ku mela irundha fraud-nu flag pannunga").

Common models: **logistic regression** (probabilities output panra oru linear model, explain panna easy), decision trees, random forests, gradient boosting, neural networks.

```flow
Features | amount, merchant, time, device -> Classifier -> 0.0-la irundhu 1.0 varaikkum Score
0.0-la irundhu 1.0 varaikkum Score -[0.3-ku keezha, review threshold]-> Allow
0.0-la irundhu 1.0 varaikkum Score -[0.3-kum 0.9-kum naduvula]-> Oru analyst review pannuvaar
0.0-la irundhu 1.0 varaikkum Score -[0.9-ku mela, block threshold]-> Block, oru vegamaana appeal-oda
```

Indha lesson, Pune-la oru payments company fraud rules-a oru classifier-a maathum podhu, avangala follow pannum.

## Idhu eppadi work aagudhu

**Logistic regression.** Linear regression maadhiri thaan, aana weighted sum oru function vazhiya pogum, adhu adha 0-kum 1-kum naduvula oru probability-aa squeeze pannum. Coefficients, entha features ovvoru class pakkam thalludhu-nu kaattum.

**Confusion matrix.** Select panna threshold-ku, true positives (fraud flag aachu), false positives (genuine flag aachu), false negatives (fraud miss aachu), true negatives-a count pannunga. Ovvoru metric-um indha naalu numbers-la irundhu varum.

**Precision-um recall-um.** Precision: flag aana cases-la, evvalavu unmaiyilaye positive. Recall: unmaiyaana ella positives-la, evvalavu flag aachu. Threshold-a kammi pannaa recall ericham, precision kuraiyum; adhigam pannaa opposite aagum.

**Threshold-a select panradhu.** Errors-ku rupee values podunga. Oru miss aana fraud-ku sarasariyaa ₹15,000 selavaagi, oru false alarm-a investigate panna analyst neram ₹200 selavaana, neraya fraud pidikka neraya false alarms-a othukkanum. Capacity-yum paarunga: analysts naalaiku 500 cases review panna mudinjaa, threshold sumaar 500 flag pannura maadhiri set aagalaam.

**Imbalanced classes.** Positives rare-aa irundha (0.5% fraud), accuracy use illa: "ennaikkum fraud illa"-nu predict pannaa 99.5% score aagum. Precision, recall, precision-recall curve, ROC AUC use pannunga. Techniques: rare class-la varra errors-a adhigamaa count panna class weights, sampling methods, training-ku podhumaana positive examples.

**Calibration.** Model 0.3-nu sonnaa, andha score-la fraud sumaar 30% neram nadakkudhaa? Nalla calibrate panna probabilities, thresholds-aiyum business rules-aiyum nambikkaiyaakkum.

**Multi-class.** Rendu-kku mela categories irundha, edhu edhoda kuzhappudhu-nu paaka confusion matrix paarunga.

**Common classifiers compare:**

| Model | Strengths | Weaknesses | Mudhal choice-aa nalladhu eppo |
| --- | --- | --- | --- |
| Logistic regression | Vegam, explain panna easy, kittatha calibrated probabilities | Complex interactions-a miss pannum | Credit maadhiri decisions-a explain pannanum-na |
| Decision tree | Varaiya, explain panna easy | Overfit aagum, stable illa | Kathukkodukka, simple rules-ku |
| Random forest | Robust, kammiyaa tuning | Periya, mella | Tables-la oru strong baseline |
| Gradient boosting | Perumbaalum tables-la romba accurate | Tuning thevai, explain panna kashtam | Tabular data-la fraud, churn, risk |
| Neural network | Text, images, romba periya data | Neraya data thevai, explain panna kashtam | Unstructured inputs |

**Oru sariyaana workflow.** Oru simple baseline-oda aarambinga, example ippo irukkura rules illa logistic regression, apothaan "better"-na enna-nu theriyum. Data-va time vachu split pannunga. Class weights-oda oru strong model train pannunga. Accuracy illa, precision, recall, PR AUC-la compare pannunga. Costs-um capacity-yum vachu oru threshold select pannunga. Calibration check pannunga. Apram result-a rupees-layum, naalaiku evvalavu alerts maadhiri operational terms-layum report pannunga.

**Oru model-oda mistakes-a padikkradhu.** Threshold select pannina apram, 50 false positives-um 50 false negatives-um kaiyaala padinga. Patterns vegamaa theriyum: genuine festival-season spikes fraud-nu flag aagiradhu, illa training data paakkaadha pudhu fraud pattern. Ovvoru pattern-um oru fix suggest pannum: "Diwali-ku innum evvalavu naal" maadhiri oru feature, innum recent training data, illa oru specific case-ku oru rule. Metrics model evvalavu thappaa irukku-nu solludhu; cases padikkradhu yen-nu solludhu.

**Oru baseline-um oru strong model-um, sariyaa compare panradhu.** 1% fraud irukkura synthetic transactions, time vachu split pannittu (mudhal 80% training-ku):

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.metrics import average_precision_score, confusion_matrix

X, y = make_classification(n_samples=30_000, n_features=15, n_informative=8,
                           weights=[0.99], class_sep=1.0, random_state=3)
cut = int(0.8 * len(y))                                   # pretend rows are in time order
X_tr, X_te, y_tr, y_te = X[:cut], X[cut:], y[:cut], y[cut:]

logit = make_pipeline(StandardScaler(), LogisticRegression(class_weight="balanced", max_iter=2000))
gbm = HistGradientBoostingClassifier(class_weight="balanced", max_iter=300, learning_rate=0.05, random_state=3)
for name, model in [("logistic", logit), ("boosting", gbm)]:
    model.fit(X_tr, y_tr)
    print(name, "PR AUC", round(average_precision_score(y_te, model.predict_proba(X_te)[:, 1]), 3))
```

`class_weight="balanced"` training-la, ovvoru fraud case-um pala genuine cases-oda sama-aa count aaga vaikkum, adhanaala model simple-aa "ennaikkum fraud illa"-nu kathukkaadhu.

**Calibrate pannunga, apram threshold-a rupees-la select pannunga.** Class weights probabilities-a distort pannum; calibration adha fix pannum:

```python
from sklearn.calibration import CalibratedClassifierCV

cal = CalibratedClassifierCV(HistGradientBoostingClassifier(max_iter=300, learning_rate=0.05, random_state=3),
                             method="isotonic", cv=3).fit(X_tr, y_tr)
p = cal.predict_proba(X_te)[:, 1]

COST_FN, COST_FP = 15_000, 200            # missed fraud, analyst review
t = COST_FP / (COST_FP + COST_FN)         # flag when expected loss from missing exceeds review cost
tn, fp, fn, tp = confusion_matrix(y_te, p >= t).ravel()
print(f"threshold {t:.3f}: caught {tp}, missed {fn}, false alarms {fp}")
print(f"cost of errors ₹{fn * COST_FN + fp * COST_FP:,}")
```

Calibrate panna probabilities-oda, nalla threshold costs-la irundhu neradiyaa varum: oru case-oda fraud chance × ₹15,000, ₹200-a vida adhigam-naa flag pannunga.

**Capacity limits rule-a maathum.** Analysts naalaiku 300 cases thaan review panna mudinjaa, score vachu sort panni top 300-a edunga; threshold-la illa, andha budget-la recall-a measure pannunga.

**Thani decisions-a explain pannunga.** Oru logistic model-ku, ovvoru feature-oda contribution, adhoda coefficient × adhoda (scaled) value. Boosted trees-ku, permutation importance entha features muzhumaiyaa mukkiyam-nu kaattum, SHAP maadhiri tools thani predictions-a explain pannum. Credit-um insurance decisions-um perumbaalum customers-kum regulators-kum idhu maadhiri explanations vendum.

## Oru worked example

Pune-la oru payments company-ku maadham 2 million UPI merchant transactions irukku, adhula sumaar 0.3% pinnaadi fraud-nu confirm aagum.

1. Baseline: avanga rules maadham 6,000 alerts-oda 40% fraud-a pidikkum.
2. Class weights-oda oru gradient-boosted classifier, aaru maadha data-la train panni, adutha maadham-la test pannanga.
3. Maadham 6,000 alerts tharura threshold-la (analysts-oda capacity), adhu 68% fraud-a pidikkum.
4. Maadha fraud sumaar 6,000 cases (2 million-la 0.3%). 68% pidikkradhu-na, 6,000 alerts-la sumaar 4,080 unmaiyaana fraud: precision sumaar 68%, rules-ku 40%.
5. Business view: maadham sumaar 1,680 adhigama fraud pidikkum; sarasari ₹9,000 loss-la, adhe analyst team-oda maadham sumaar ₹1.5 crore save aagum.

Avanga rendavadhu, adhigamaana threshold set panraanga, score romba high-aa irundhu precision 98%-ku mela irukkum podhu mattum transactions-a automatic-aa block pannum, merchants-ku oru vegamaana appeal vazhiyoda.

**Risk committee-ku explain panradhu.** Committee gradient boosting pathi kekkala. Moonu kelvi kettaanga: analysts overload aaguvaangala, genuine merchants hurt aaguvaangala, evvalavu save aagum? Team ippadi badhil sonnanga: ippo irukkura adhe alerts count, analysts neram kammiyaa waste aaga 40%-ku badhil sumaar 68% precision, precision 98%-ku mela irukkura score-ku mela mattum automatic block, appeals naalu mani neraththula badhil, rules miss panna maadham sumaar ₹1.5 crore fraud pidikkum. Merchant category-yum city-yum vachu model-oda performance-yum kaattinaanga, yenna sarasariyaa nalla, aana sinna kirana merchants-ku mosamaa irukkura model, oru fairness-um business-um problem-aa irundhirukkum. Adhu, history kammiyaa irukkura pudhu merchants-ku konjam weak-aa irundhadhu, adhanaala pudhu merchants-a avanga mudhal maadhathukku automatic blocking-ku badhil review-ku anuppinaanga.

## Podhuvaa panra thappugal

- **Imbalanced data-la accuracy-a report panradhu.** Precision, recall, PR curves use pannunga.
- **Default 0.5 threshold use panradhu.** Costs-um capacity-yum vachu select pannunga.
- **Time-based data-la random rows-la test panradhu.** Unmaiyaana use maadhiri, pinnaadi period-la test pannunga.
- **Calibration-a ignore panradhu.** Decisions-ku use panra scores, solradhai sollanum.
- **Ella actions-kum oru threshold.** Review-kum automatic blocking-kum veru veru precision vendum.

- **Baseline illa.** Ippo irukkura rules illa simple model-oda compare pannaama, pudhu model worth-nu kaattha mudiyaadhu.
- **Time-ordered data-la random splits**, future-a leak pannum.
- **Class-weighted probabilities-a calibrate pannaama unmaiyaana probabilities-aa use panradhu.**
- **Review capacity-a ignore panradhu**: moonu perukku naalaiku 5,000 cases flag panra threshold oru solution illa.

## Oru model-a vida simple rule jeikkum edathula

- **Romba kammiyaana positive examples**, kathukka podhumaana alla: expert rules-oda aarambichu labels-a collect pannunga.
- **Oru clear rule ippavae work aagudhu**, example thirudu pona cards-a block panradhu.
- **Decisions-a oru vaakkiyathula explain pannanum**, oru sinna scorecard adha meet pannum.

## Demo-la irundhu production-ku

- **Time vachu split pannunga**, ippo recent period-la test pannunga.
- **Costs-la irundhu thresholds set panradhukku munnaadi calibrate pannunga.**
- **Thresholds-a costs illa capacity-la irundhu set pannunga**, business-oda othukkittu, apram marubadiyum paarunga.
- **Labels vara vara precision-um recall-um monitor pannunga**, segment-wise.
