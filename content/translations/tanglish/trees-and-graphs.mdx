## Idhu enna

**Graph** **edges**-aala serndha **nodes**-oda oru set. Tracks-aala serndha metro stations, friendships-aala serndha makkal, links-aala serndha web pages ellaam graphs. Edges-ku direction (one-way street), weight (distance illa price) irukkalaam.

**Tree** oru special graph: connected, cycles illa, adhanaala entha rendu nodes-kum naduvula exactly orey path. Perumbaalum mela **root**-um keezha **children**-um irukkum. Unga laptop-la folders, oru company-oda org chart, oru web page-oda HTML ellaam trees. **Binary tree**-la ovvoru node-kum adhigamaa rendu children; **binary search tree**-la chinna values left-layum perusu right-layum irukkum.

```flow
title: Oru tree: cycles illa, entha rendu nodes-kum naduvula orey path
CEO -> CTO
CEO -> CFO
CTO -> Dev1
CTO -> Dev2
CFO -> Fin1
```

```flow
dir: LR
title: Oru graph: cycles-um neraya paths-um irukkalaam, adhanaala "visited" track pannunga
Rajiv Chowk -> Kashmere Gate -> Civil Lines -> Vishwavidyalaya
Rajiv Chowk -> Mandi House -> ITO -> Central Secretariat
Rajiv Chowk -> Central Secretariat
```

Avatrai explore panna rendu vazhigal thirumba thirumba varum: **breadth-first search** (BFS), **depth-first search** (DFS).

## Idhu eppadi work aagudhu

Code-la graph perumbaalum **adjacency list**: ovvoru node-la irundhu adhoda neighbours-ku oru dict.

```python
metro = {
    "Rajiv Chowk": ["Kashmere Gate", "Mandi House", "Central Secretariat"],
    "Kashmere Gate": ["Rajiv Chowk", "Civil Lines"],
    "Mandi House": ["Rajiv Chowk", "ITO"],
    "Central Secretariat": ["Rajiv Chowk", "ITO"],
    "ITO": ["Mandi House", "Central Secretariat"],
    "Civil Lines": ["Kashmere Gate", "Vishwavidyalaya"],
    "Vishwavidyalaya": ["Civil Lines"],
}
```

**BFS** rings-aa explore pannum. Oru node-la aarambichu, adhoda ellaa neighbours-aiyum, apram avanga neighbours-aiyum paakkum, appadiyae; **queue** use pannum, adhanaala nodes kandupidichha order-la handle aagum. Orey thadavaiku oru edge veliya pogaradhaala, BFS oru node-a mudhal thadava ethuradhu kammiyaana edges vazhiya thaan. Adhanaala "kammiyaana stops", "degrees of separation"-ku idhu thaan sariyaana tool.

**DFS** oru path-la mudinjavarai aazhama pogum, apram pinnaadi vandhu adutha branch-a try pannum. **Stack** use pannum, perumbaalum recursion vazhiya call stack. Reach panna mudiyura ellaathaiyum explore panna, cycles detect panna, trees-a oru kuripitta order-la nadakka DFS iyalbaa irukkum.

Graphs-la rendukkum **visited** set thevai, illaina cycles avatrai endru mudiyaama suthha vaikkum. Rendukkum O(V + E) time, V nodes count, E edges count.

| Kelvi | Use pannunga | Yen |
|---|---|---|
| Rendu nodes-kum naduvula kammiyaana hops, unweighted | BFS | edges distance padi explore pannum |
| Oru node-la irundhu reach panna mudiyura ellaam | DFS illa BFS | rendumae ellaathaiyum visit pannum; DFS ezhudha chinnadhu |
| Cycle detect panradhu, dependencies irukkura tasks-a order panradhu | DFS | adhoda back-tracking cycles-a kaattum; topological order kudukkum |
| Network-la connected groups | Visit aagaadha ovvoru node-la irundhum DFS illa BFS | ovvoru run-um oru group-a mark pannum |
| Weighted edges-oda cheapest path | Dijkstra's algorithm | BFS weights-a ignore pannum |
| Sorted tree-la oru value kandupidikka | binary search tree walk | ovvoru step-layum search paadhiyaagum |

## Oru worked example

Kabir Delhi-la commuters-ku oru route helper build pannraanga. User rendu stations pick pannuvaanga, app kammiyaana stops irukkura route-a kaattum. Pakkathula irukkura stations-ku naduvula ovvoru hop-um orey maadhiri count aagum, adhanaala BFS poruthum.

```python
from collections import deque

def fewest_stops(graph, start, goal):
    queue = deque([[start]])          # each item is a path so far
    visited = {start}
    while queue:
        path = queue.popleft()
        station = path[-1]
        if station == goal:
            return path
        for nxt in graph[station]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(path + [nxt])
    return None
```

"Mandi House"-la irundhu "Civil Lines"-ku, BFS mudhalla Rajiv Chowk-um ITO-vum (oru stop dhoorathula) kandupidikkum, apram Kashmere Gate-um Central Secretariat-um (rendu dhoorathula), apram Civil Lines (moonu dhoorathula). Adhu `Mandi House → Rajiv Chowk → Kashmere Gate → Civil Lines` return pannum, kammiyaana route illa, yen-na BFS ellaa rendu-stop routes-aiyum mudhalla check pannidichu.

Maintenance-la oru station moodiyirukkumbodhu app warn pannanum. Kabir moodiya station-a graph-la irundhu eduthu, oru periya interchange-la irundhu DFS odi innum reach panna mudiyura ellaa stations-aiyum list pannuraanga:

```python
def reachable(graph, start, seen=None):
    seen = seen if seen is not None else set()
    seen.add(start)
    for nxt in graph[start]:
        if nxt not in seen:
            reachable(graph, nxt, seen)
    return seen
```

Result-la illaadha station reach panna mudiyaadhu, adhukku warning banner varum.

Pinnaadi team fares-a serkkumbodhu, kammiyaana stops irukkura routes epovum cheapest-aa irukkaadhu. Idhu weighted graph, Kabir Dijkstra's algorithm-ku maaraanga, total cost padi order panna priority queue irukkura BFS.

## Podhuvaa panra thappugal

**Visited set illaama irukkradhu.** Cycles irukkura graph-la BFS-um DFS-um endrum suthum. Nodes-a queue-la serkkumbodhae visited-nu mark pannunga, edukkumbodhu illa; illaina adhey node-a neraya thadava serppeenga.

**Shortest paths-ku DFS use panradhu.** DFS oru path-a kandupidikkum, shortest-a illa. Kammiyaana edges-ku BFS use pannunga.

**Weighted graphs-la BFS use panradhu.** BFS edges-a count pannum, cost-a illa. Edges-ku vera vera weights irundhaa Dijkstra's algorithm use pannunga.

**Deep recursion limits.** Neenda chain-la recursive DFS Python-oda sumaar 1,000 recursion limit-a thaandalaam. Romba aazhamaana graphs-ku explicit stack use pannunga.

**Ellaa trees-um balanced-nu ninaikkradhu.** Munnaadiye sorted data-la irundhu build panna binary search tree neenda chain aagidum, searches O(n)-ku vizhum. Real systems self-balancing trees use pannum.

**Edge direction-a marakkradhu.** Instagram-la oru follow one-way. Directed edges-a poguradhu direction-la mattum store pannunga.
