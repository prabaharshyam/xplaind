## Idhu enna

"Smart software"-a solla makkal moonu words-a ore artham-la use panraanga: **artificial intelligence**, **machine learning**, **large language model**. Idhu moonum onnu kidaiyaadhu. Indha difference theriyudha-nu thaan interviewer, client, unga manager first check pannuvaanga.

Onnukulla onnaa irukkura moonu circles-a yosichu paarunga:

```flow
title: Ovvoru circle-um mundhaiya circle-kulla irukku
Artificial intelligence (AI) | manushanga thaan seiyanum-nu nenacha velaigala seira software -> Machine learning (ML) | examples-la irundhu rules-a kathukum
Machine learning (ML) -> Large language models (LLMs) | text-la kathukum, text ezhudhum
```

- **Artificial intelligence (AI)** thaan periya goal: manusha judgement thevai-nu naama nenacha velaigala seira software. Mugatha identify panradhu, Tamil-la irundhu English-ku translate panradhu, oru paatta recommend panradhu, kelvikku badhil solradhu, idhu ellaamae AI velaigal thaan.
- **Machine learning (ML)** thaan innaiku AI build panra main vazhi. Ovvoru rule-ayum oru aal ezhudradhukku badhila, program-ku neraya examples-a kaattuvom; adhu thaane pattern-a kathukum.
- **Large language model (LLM)** oru vagaiyaana machine learning model. Romba adhigamaana text-la train panni, adutha-dhu enna varum-nu predict panna vachirukkaanga. ChatGPT, Claude, Gemini ellaam LLM mela build panna products.

Appo ella LLM-um machine learning, ella machine learning-um AI. Aana thalaikeezhaa solla mudiyaadhu. Unga UPI app-la vara fraud alert machine learning thaan, aana language model kidaiyaadhu. 1990-gal-la vandha oru chess program kaiyaala ezhudhuna search rules-a follow pannuchu; adhu AI thaan, aana adhula machine learning illa.

Indha lesson-la Pune-la 200 per vela seira oru company-la HR paakura Asha-voda oru normal work day-a follow panna porom. Lesson mudiyum podhu, avanga paakura ovvoru "AI" vishayathayum sariyaana circle-la poda mudiyum, language model eppadi ezhudhudhu-nu explain panna mudiyum, adhu yen sila neram thappaa solludhu-nu solla mudiyum.

## Idhu eppadi work aagudhu

### Rules vs learning

Machine learning-ku munnaadi, software oru aal ezhudhuna rules-a thaan follow pannuchu. Asha-voda company expense system-la ippadi oru rule irukku:

```text
IF amount > 5,000 rupees AND receipt missing
THEN send to manager for approval
```

Rules clear-aa, predictable-aa irukkum. Aana ovvoru case-ayum yaaraavadhu yosichu ezhudhanum. Fraud, mugangal, language idhukku ellaam cases romba adhigam; yaaraalum ellaathayum ezhudhi vaikka mudiyaadhu.

Machine learning indha vela-ya thalaikeezhaa maathudhu. Badhil already therinja examples-a serkurom, program adhula irukkura pattern-a kandupidikkudhu:

```flow
dir: LR
Badhiloda examples | payment 1: genuine, payment 2: fraud ... innum 1 crore -> Training | pattern-a kathukudhu
Training -> Oru model | pudhu payment ulla, "fraud: 0.93" veliya
```

Kadaisiya kidaikiradhu oru **model**: input-a output-aa maathura, kathukitta numbers nenanja oru file. Oru bank-oda fraud model unga exact payment-a paathadhae illa, aana adhae maadhiri latchakkanakkaana payments-a paathirukku; adhanaala nalla guess pannum. Aana adhoda examples evvalavu nalladho, avvalavu thaan adhuvum. Oru kurippitta vagai fraud examples-layae illa-na, model adha miss pannidum.

| | Rule-based software | Machine learning |
| --- | --- | --- |
| Logic-a yaar decide panraanga | Oru aal ezhudhuraanga | Examples-la irundhu kathukudhu |
| Edhula strong | Tax slabs maadhiri clear, maaradha rules | Mugam, fraud, language maadhiri theliva illaadha patterns |
| Thappaa pona | Rule thappu; rule-a fix pannunga | Examples kammi illa bias; data-va fix pannunga |
| Oru decision-a explain panradhu | Easy: rule-a kaattalaam | Kashtam: pattern neraya numbers-la paravi irukku |

### Language model eppadi ezhudhudhu

Large language model-na text-ku apply panna machine learning. Training-la adhu romba adhigamaana ezhuthukkala padikkudhu: books, websites, code, forum posts. Adhoda ore vela, adutha varra chinna text thundu-va guess panradhu; adhukku peru **token**. Oru token perumbaalum oru muzhu chinna word ("the"), sila neram periya word-oda oru part ("under" + "stand" + "ing").

Training mudinjadhum, neenga question kettaa model oru time-la oru token-aa answer-a ezhudhum:

```text
Prompt: "The capital of Karnataka is"

Step 1: likely next tokens ->  " Bengaluru" 0.86 | " Bangalore" 0.12 | " Mysuru" 0.01
Step 2: picks " Bengaluru", adds it, and asks again ->  "." 0.71 | "," 0.20 ...
Step 3: keeps going until the answer is complete
```

Generation-na ivvalavu thaan: predict pannu, onna edu, serthuko, marupadiyum pannu. Podhumaana data-vum periya model-um irundha, indha simple skill-ae summaries, translations, emails, code, step-by-step explanations ellaam uruvaakudhu. Yenna manushanga ezhudhunadhula indha patterns ellaamae irukku.

### Idhu enna pannaadhu

Dhinamum nyaabagam vachukka vendiya moonu limits:

1. **Idhu facts-a thedi paakaadhu.** Product adha web search-odayo unga documents-odayo connect panni irundha thavira, training-la kathukitta patterns-la irundhu thaan answer sollum. Adhukulla unmaiyaana facts-oda database edhuvum illa.
2. **Idhukku oru knowledge cut-off irukku.** Training data serthadhukku apram nadandhadhu idhukku theriyaadhu, product pudhu info kuduthaa thavira.
3. **Idhu thannai thaane check pannikaadhu.** Edhu likely-o adha ezhudhum, edhu verified-o adha illa. Adhanaala smooth-aa, confident-aa irukkura, aana thappaana text-a kooda ezhudhum. Idhukku peru **hallucination**.

### Model vs product

Innoru difference-la neraya per kuzhambuvaanga. **Model**-na train panna numbers-oda file. **Product**-na adha sutthi irukkura app: chat window, search tool, memory feature, safety filters. Oru chat assistant "web-la search pannudhu"-na, adhu product oru search tool-a koopittu, results-a model-ku kudukkudhu. Makkal "ChatGPT vs Claude"-nu compare pannum podhu, vera vera models mela build panna products-a thaan compare panraanga.

## Oru naal, oru example

Idho Asha-voda Monday. Ovvoru AI-yayum adhoda circle-la pottirukkom.

**Kaalai 8:40, spam filter (machine learning, LLM illa).** Avanga inbox "Veetla irundhae vaaram ₹50,000 sambaadhinga!"-ngura fake job offer-a spam-ku anuppudhu. Makkal spam / not spam-nu mark panna latchakkanakkaana emails-la irundhu filter kathukichu. Adhu oru label kudukkudhu, text illa.

**Kaalai 9:05, face unlock (machine learning, LLM illa).** Pudhu kannaadi pottirundhaalum phone avangala identify pannudhu. Images-la train panna oru model endha features mukkiyam-nu kathukichu.

**Kaalai 10:15, payroll formula (AI illa).** Oru spreadsheet overtime-a koottudhu. Oru aal exact formula-va ezhudhinaanga; edhuvum kathukkapadala.

**Kaalai 11:00, chat assistant (LLM).** Asha kekkuraanga: "Enga pudhu hybrid work policy-ku friendly-aa oru announcement draft pannu: vaaram moonu naal office, December 1-la irundhu."

Draft nallaa irukku. Anbaa, clear-aa, nalla structure-oda irukku. Aana adhula indha line-um irukku: "Shops and Establishments Act-padi, endha policy maatrathukkum employees-ku 30 naal notice kudukkanum."

Kekka official-aa irukku. Asha company lawyer kitta check panraanga. Maharashtra-ku indha claim sariyilla, inga endha law-vayum quote panna thevaiyilla-nu lawyer solraanga. Asha andha line-a delete panraanga.

| Vela | AI illaama time | AI-oda time |
| --- | --- | --- |
| First draft ezhudhradhu | sumaar 45 nimisham | 2 nimisham |
| Facts, tone check panradhu | 5 nimisham | 10 nimisham |
| Mothham | sumaar 50 nimisham | sumaar 12 nimisham |

Assistant avangalukku arai mani nerathukku mela michapaduthuchu, aana avanga check pannadhaala mattum thaan. Vegamaa draft, gavanamaa check: professionals language models-a ippadi thaan use panraanga.

**Madhiyam 3:30, fraud alert (machine learning, LLM illa).** Pudhu account-ku pora ₹49,000 payment-a bank app niruthi OTP kekkudhu. Fraud model andha payment-a vithiyaasamaanadhu-nu score pannuchu. Adhu genuine payment thaan; adhanaala idhu false positive, hallucination illa. Model text-a karpanai pannala; thappaa oru yes/no solliduchu, avvalavu thaan.

## Podhuvaa panra thappugal

- **AI, ML, LLM-a ore word-aa use panradhu.** Idhu onnukulla onnu. Oru vendor "enga AI"-nu sonna, endha vagai-nu kelunga. Rules engine, fraud model, chat assistant moonukkum data, testing, budget ellaamae romba vera.
- **Language model thedi paakudhu-nu nenaikiradhu.** Product search pannudhu-nno unga documents use pannudhu-nno sollala-na, adhu patterns-la irundhu generate pannudhu. "Adhu sonnuchu"-ngradhu oru source kidaiyaadhu.
- **Confidence-a nambradhu.** Smooth-aana tone accuracy pathi edhuvum sollaadhu. Numbers, laws, names, dates, recent vishayangal idhula romba gavanamaa irunga.
- **Ella thappayum hallucination-nu solradhu.** Hallucination-na generative model karpanaiyaa uruvaakura content. Fraud model genuine payment-a block panna adhu false positive; spam filter spam-a miss panna adhu false negative.
- **Model manushan maadhiri purinjukkudhu-nu nenaikiradhu.** Oru kashtamaana idea-va super-aa explain pannittu, konjam vithiyaasamaa ketta oru simple question-ku fail aagalaam. Nambradhukku munnaadi unga real vela-la test pannunga.
- **Model-ayum product-ayum kuzhappikiradhu.** Ore model rendu apps-la romba vera maadhiri behave pannalaam; adha sutthi irukkura tools, instructions, safety settings thaan kaaranam.

## Practice pannunga

Keezha link panni irukkura large language models intro-va paarunga; maths illaama training, generation-a clear-aa explain pannudhu. Apram indha moonu tasks-a pannunga.

1. **Unga week-a pirichu paarunga.** Pona week neenga use panna 5 AI features-a list pannunga: maps, spam filter, payment app, voice typing, oru recommendation, oru chat assistant. Ovvonnum endha circle, adhu enna output kudukkudhu (label, score, route, text)-nu ezhudhunga.
2. **Oru hallucination-a pudinga.** Oru chat assistant kitta unga ooru illa unga field pathi numbers irukkura moonu facts kelunga: population, start aana varusham, oru statistic. Ovvonnayum oru official source-la check pannunga. Edhu thappu, adhu evvalavu confident-aa sonnuchu-nu note pannunga.
3. **Sathamaa explain pannunga.** Token, predict, hallucination indha words-a use panni, language model eppadi answer ezhudhudhu-nu oru friend-ku rendu nimishathula explain pannunga. Record panni thirumba kelunga.

**Mudinjadhu-nu eppo sollalaam:** AI, machine learning, language model moonukkum irukkura difference-a simple-aa explain panna mudiyum, ovvonnukkum daily life-la oru example solla mudiyum, language model yen confident-aa thappaa sollum-nu solla mudiyum.
