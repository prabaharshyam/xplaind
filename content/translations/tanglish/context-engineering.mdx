## Idhu enna

Prompt engineering-nu sollradhu oru nalla instruction ezhudhuradhu pathi. **Context engineering**-nu sollradhu, oru call-la model paakkura ellaathaiyum pathi: system prompt, tool definitions, examples, retrieved documents, memory, ippo varaikkum conversation, munnaadi tool calls-oda results. Oru one-shot kelvi-ku idhu chinnadhu. Aimbadhu steps odura oru agent-ku idhu kuvindhu pogum, appuram kelvi: ippo window-la enna irukkanum, enna irukka koodaadhu?

Context oru budget. Romba neelamaana windows irukkura models kooda, window relevant illaadha vishayangalaala nirambum podhu mosamaa seiyum: details-a miss pannum, goal-a marakkum, ovvoru step-kum adhigam selavaagum.

| Step 37-la context | Munnaadi | Aprom |
|---|---|---|
| System prompt | Rules, 6k tokens | Principles, 1.5k tokens |
| Tools | 12 definitions | 4 definitions |
| Data | Muzhu purchase register-um supplier filings-um | Notes: pages 1-2 resolved, INV-7781-um INV-7790-um open; 20 mismatches-oda ippo irukkura page |
| Tool results | 36 pazhaya ones, window nirambura varaikkum | 2 pudhu ones |
| Result | Suppliers-a kuzhappinadhu, limit-a ettudhu | Oru run-la 3,000 mismatches |

```flow
dir: LR
title: Ovvoru step-layum context-a chinnadhaa vechukkuradhu
Pazhaya tool results -[notes-la summarise pannunga]-> Notes
Notes -> Adutha model call
Ippo irukkura page + 2 pudhu results -> Adutha model call
```

Indha lesson, Chennai-la oru consultancy-la oru GST reconciliation agent-a follow pannum.

## Idhu eppadi work aagudhu

**Sariyaana altitude-la system prompt.** Romba vague-aa ("be helpful") irundhaa guidance illa; romba rigid-aa (pakkam pakkamaa if-then rules) irundhaa neenga edhirpaarkkaadha cases-la udayum. Theliva principles, mukkiya steps, sila examples, headings-ku kezha organise panni, adha target pannunga.

**Lean tools.** Ovvoru tool definition-um ovvoru call-layum tokens selavu pannum, ovvoru overlapping tool-um accuracy-a kuraikkum. Ippo irukkura task-ku thevaiyaana tools mattum kodunga.

**Just-in-time retrieval.** Ovvoru document-aiyum mudhalle load panradhukku badhila, agent-ku things-a look up panna vazhigal (search, open file, read record) kodunga, avanga thevaippadum podhu thevaiyaanadha izhukkattum. File paths, record ids maadhiri lightweight references-a context-la vechu, content-a thevaippadum podhu fetch pannunga.

**Pazhaya tool results-a clear pannunga.** Moonu steps munnaadi use panna 5,000-token search result dead weight. Results use aanadhum, avai drop illa shrink pannunga, enna kidaichadhu-nu oru line note vechirunga.

**Compaction.** Context adhoda limit-ku pakkathula varum podhu, history-a oru short state-aa summarise pannunga: goal, eduthaa decisions, open questions, key facts. Andha summary-oda pudhusaa aarambinga.

**Structured notes.** Neelamaana tasks-ku, agent-a context-ku veliya oru notes file illa to-do list vechukka sollunga, adha thirumba padikka sollunga, appo compaction-ukku aprom progress-um nikkum.

**Sub-agents.** Oru sub-task-a, thanoda sondha clean context-oda oru sub-agent-kitta kudunga, adhoda summary mattum thirumba vaangunga.

**Tokens enga pogudhu:**

| Pagudhi | Podhu problem | Fix |
| --- | --- | --- |
| System prompt | Rare cases-ku pakkam pakkamaa rules | Principles, steps, onnu illa rendu examples |
| Tool definitions | Neraya overlapping tools | Indha task-ku thevaiyaana tools mattum |
| Retrieved documents | Ellaam mudhalle load panradhu | Id vechu thevaippadum podhu fetch pannunga |
| Tool results | Ennaikkum vechirukkuradhu | Use aanadhum clear pannunga, oru line note vechukkunga |
| History | Ovvoru turn-layum valarum | Oru state summary-aa compact pannunga |

**Oru nalla compaction summary ezhudhuradhu.** Oru summary adhukku munnaadi irukkura ellaathaiyum maathum, adhanaala agent thodara thevaiyaanadha adhu eduthukitu pogaanum: original task-um constraints-um muzhusaa, eduthaa decisions-um yen-um, ippo varaikkum results totals-aa, open items adhoda ids-oda, appuram adutha step. Ovvoru step-um eppadi nadandhadhu-nu narration-a vittudunga. Compaction-a, adhoda-um adhu illaamalum oru task-a odi, final results othu pogudhaa-nu paarthu test pannunga; compacted run oru constraint-a marandhaa, summary prompt-la oru section illa.

**Effect-a measure panradhu.** Sila tasks-ku, ovvoru maatrathukku munnaadiyum aprom-um, ovvoru step-layum pagudhi vaaripaa token counts-a log pannunga. Moonu numbers-a gavanikkunga: oru task-ku tokens, oru task-ku cost, task success. Tokens-a kuraichu success-a kuraikkura oru maatram, model-ku thevaiyaana edhaiyo eduthuduchu-nu artham.

**Code-la pazhaya tool results-a clear pannunga.** Latest sila results-a muzhusaa vechukkunga, pazhaya ones-a oru line note-aa maathunga:

```python
def clear_old_results(messages, keep_last=3, max_chars=400):
    """Anthropic-style messages: tool results are blocks of type 'tool_result' in user turns."""
    seen = 0
    for msg in reversed(messages):
        if msg["role"] != "user" or not isinstance(msg["content"], list):
            continue
        for block in msg["content"]:
            if block.get("type") != "tool_result":
                continue
            seen += 1
            text = str(block.get("content", ""))
            if seen > keep_last and len(text) > max_chars:
                block["content"] = f"[cleared: {len(text)} chars; first line: {text.splitlines()[0][:120]}]"
    return messages
```

Call nadandhadhum, sumaar adhu enna return pannichunu model-ku innum theriyum, aana adhoda 5,000 tokens theriyaadhu. Details thirumba thevai-naa, tool-a thirumba call pannalaam.

**Fixed sections irukkura oru compaction prompt.** Oru free-form "idha summarise pannu" constraints-a izhakkum. Agent thodara thevaiyaana pagudhigala kelunga:

```python
COMPACT_PROMPT = """Summarise this work so another assistant can continue it with no other context.
Use exactly these headings:
TASK: the original request and every constraint, word for word where possible
DECISIONS: what was decided and why, one line each
RESULTS SO FAR: totals and key facts, with ids
OPEN ITEMS: what remains, with ids
NEXT STEP: the single next action
Leave out how each step was done."""
```

Context oru threshold-a thaandum podhu adha odunga, system prompt-um summary-yum serndha oru pudhu conversation-a aarambinga, rendu token counts-aiyum log pannunga.

**Context-ku veliya notes.** Neelamaana tasks-ku, agent-ku rendu chinna tools-a kodunga, ovvoru milestone-kum aprom adhoda notes-a update panna sollunga:

```python
from pathlib import Path

NOTES = Path("runs/notes-{run_id}.md")

def read_notes(run_id):
    p = Path(str(NOTES).format(run_id=run_id))
    return p.read_text() if p.exists() else "(no notes yet)"

def write_notes(run_id, text):
    p = Path(str(NOTES).format(run_id=run_id))
    p.parent.mkdir(exist_ok=True)
    p.write_text(text[:4000])                    # keep notes short
    return "saved"
```

Compaction illa restart-ukku aprom, agent mudhalla adhoda notes-a padichu thodarum.

**Adhigam context-na mosamaana answers-aa irukkalaam.** Neelamaana inputs pathi studies, simple lookups-ku kooda context valarum podhu accuracy kuraiyum-nu, neelamaana inputs-oda nadula irukkura facts kammi nambakkaiyaa use aagum-nu kandupidikkudhu. Context engineering-nu sollradhu, window-a nirappurathu illa, model task-a nallaa seiya vidura, romba chinna tokens set-a kodukkuradhu.

**Order mukkiyam.** Stable content-a (system prompt, tool definitions) mudhalla vainga, appo adha cache panna mudiyum, working material-a nadulla, ippo irukkura kelvi-yum latest results-um kadaisiyila, models romba gavanikkura idathula.

## Oru worked example

Chennai GST consultancy-ku oru agent, oru client-oda purchase register-a supplier filings-oda reconcile pannudhu: aayirakkanakkula invoices, vilakkanum mismatches, oru final report.

Mudhal version muzhu register-aiyum, muzhu filing data-vaiyum, pannirandu tools-aiyum context-la load pannichu. Naarpadhu invoices-ku aprom window limit-a ettudhu, adhukku munnaadiyae oru maadhiri peyar irukkura suppliers-a kuzhappi.

Redesign:

- System prompt, reconciliation rules-aiyum report format-aiyum oru worked mismatch-oda vilakkudhu.
- Naalu tools mattum: `list_mismatches(page)`, `get_invoice(id)`, `get_supplier_filing(gstin, period)`, `write_note(text)`.
- Agent oru thadavaikku 20 mismatches-oda oru page-a work pannum. Ovvoru page-kum aprom, oru note ezhudhum ("Page 3: 14 timing differences-aa resolved, 4 supplier not filed, 2-ku client input thevai: INV-7781, INV-7790"), pazhaya tool results clear aagum.
- Ovvoru 100 mismatches-kum, history totals-um open items-um serntha oru summary-aa compact aagum.

Agent ippo oru run-la 3,000 mismatches-a handle pannudhu. Oru invoice-ku cost 70% kuraiyudhu, supplier matching-la error rate kuraiyudhu, yenna model kaila irukkura case-oda records-a mattum paarkkudhu.

| Measure | Mudhal version | Redesign |
| --- | --- | --- |
| Oru run-la handle panna mismatches | Sumaar 40, appuram window nirambichu | 3,000 |
| Oru invoice-ku cost | Baseline | 70% kammi |
| Supplier matching errors | Oru maadhiri peyar-a adikkadi kuzhappudhu | Arudhaa |

## Podhuvaa panra thappugal

- **Edhaiyum irukkattum-nu ellaathaiyum load panradhu.** Adhigam context nalla context illa. Thevaippadum podhu retrieve pannunga.
- **Ovvoru tool result-aiyum ennaikkum vechirukkuradhu.** Results use aanadhum clear illa summarise pannunga.
- **Goal-a compact panni azhikkuradhu.** Oru summary task-aiyum constraints-aiyum open items-aiyum vechirukkanum, sameeba nadandhadhu mattum illa.
- **Aindhu-tool task-ku irubadhu tools.** Ovvonnum tokens selavu pannum, thappaana choices-a azhaikkum.
- **Unmaiyaana context-a ennaikkum paarkkaama irukkuradhu.** Fail aagura steps-la model vaangadhadha log panni padinga; karanam perumbaalum theriyum.
- **Constraints-a vidura free-form compaction summaries.** Fixed headings use pannunga.
- **Note illaama results-a clear panradhu,** adhanaala model adhe call-a thirumba pannum.
- **Calls-ukku naduvula tool order-a maathuradhu,** adhu prompt caching-a udaikkum.

## Context engineering kaathirukkalaam-nu irukkura neramgal

- **Window-kulla, sila steps-la mudiyura short tasks.**
- **Oru fixed prompt-um oru input-um irukkura single calls.**
- **Kammi volume,** extra tokens-ku selavu kammi, quality ippovae nallaa irukkum podhu.

Neelamaana agent runs, neelamaana chats, periya documents, context valarum podhu cost illa accuracy kuraiyura entha onnukkum idhu romba mukkiyam.

## Demo-la irundhu production-ku

- Ovvoru step-layum **pagudhi vaaripaa tokens-a log pannunga**: system, tools, history, results.
- Clearing-kum compaction-kum **thresholds set pannunga**, ovvonnum eppo fire aagudhu-nu log pannunga.
- Adhey tasks-la adhoda-um illaamalum results-a compare panni **compaction-a test pannunga**.
- Ovvoru run-kum **notes-a** storage-la, trace-oda link panni vainga.
- Caching-ku **context-a order pannunga**, maatrangal aprom cache hit rates-a check pannunga.
