## Idhu enna

**Multimodal RAG** plain text illaadha content-la irundhu retrieve panni answer pannum: slides, charts, tables, scanned pages, diagrams, photos. Rendu mukkiya approaches irukku:

- **Text-aa maathi, apram normal RAG use panradhu.** Scans-a OCR pannunga, images-aiyum charts-aiyum vision-language model-oda describe pannunga, tables-a text-aa extract pannunga, ellaathayum text-aa index pannunga. Simple, ippo irukkura pipelines-oda compatible.
- **Images-a neraa retrieve panradhu.** Ovvoru page-aiyum multimodal embedding model use panni image-aa index pannunga (ColPali maadhiri approaches OCR illaama page images-a embed pannum), romba relevant-aana page images-a retrieve panni, answer panna **vision-language model**-kku anuppunga.

Neraya systems rendaiyum serkkum.

```flow
title: Text-aa maathradhu: selavu kammi, normal RAG
Scan -[OCR]-> Text index
Chart -[VLM describe pannum]-> Text index
Table -[extract]-> Text index
Text index -> Oru normal RAG answer
```

```flow
title: Images-a retrieve panradhu
Page -[render]-> Image -[multimodal embedding]-> Image index
Question -[embed]-> Top 3 page images
Image index -> Top 3 page images
Top 3 page images -> Vision-language model images-la irundhu answer pannum
```

Hybrid forms-ku OCR text-um, photos, diagrams, slides-ku image retrieval-um use pannum, ovvoru answer-oda page thumbnail-aiyum kaattum, appo adha check pannalaam.

Indha lesson Vadodara-la oru chemicals manufacturer-a follow pannum; avanga engineers scans, photos, diagrams niraindha 15 varusha maintenance reports-a query pannuraanga.

## Idhu eppadi work aagudhu

**Text-aa maathra route.**

- Charts, diagrams: vision-language model-kitta axis labels, values, trends-oda oru detailed description kelunga, page reference-oda store pannunga.
- Images-la irukkura tables: structured text-aa extract pannunga.
- Photos: use case-ku edhu mukkiyamo adha vechu caption pannunga ("rust on the flange joint, upper left").

Pros: queries selavu kammi, entha text model-oda-um work aagum, filter panna, cite panna easy. Cons: descriptions-la details poidum, edhu mukkiyam-nu munnaadiyae decide pannanum.

**Image-retrieval route.**

- Ovvoru page-aiyum slide-aiyum image-aa render pannunga.
- Oru multimodal retrieval model-oda embed pannunga.
- Query time-la, question-a embed panni, top pages-a retrieve panni, images-a question-oda vision-language model-kku pass pannunga.

Pros: layout, charts, visual details-a vechukkum; OCR errors illa. Cons: indexes periyadhu, image inputs adhiga tokens-um neramum edukkum, kammiyaana tools thaan idha support pannum.

**Evaluation.** Visual content thevaippadura questions-oda ("revenue chart-la Q3 value enna?", "photo-la entha valve open-aa irukku?") oru golden set build panni routes-a compare pannunga.

**Practical cautions.** Vision models charts-la sinna text-aiyum numbers-aiyum thappaa padikkalaam; page-a cite panna sollunga, numbers mukkiyamaana idangalla, underlying data irundha adhoda check pannunga. Images-a podhumaana resolution-la vechukkunga.

**Content type-vaaree select panradhu:**

| Content | Nalla route | Yen |
| --- | --- | --- |
| Text niraindha scans, forms | OCR to text | Exact wording, selavu kammi, searchable |
| Tables | Structured text-aa extract | Precise answers-ku rows-um headers-um irukkum |
| Charts | Image route, illa careful description | Values-um trends-um picture-la irukku |
| Diagrams, drawings | Image route | Labels, positions, connections mukkiyam |
| Photos | Image route | Caption-la detail-a predict panna kashtam |
| Slides | Image route | Layout-ku artham irukku |

**Help aagura descriptions ezhudhuradhu.** Visuals-ku text route use panna, podhuvaana caption illa, users enna kepaanga-nu adhai vision model-kitta kelunga. Oru chart-ku: title, axes, units, ovvoru labelled value, mukkiya trend. Oru piping diagram-ku: equipment tags, valve states, connections. Ovvoru description-oda page number-aiyum store pannunga. Sila pages-la golden set-oda test panna oru focused description prompt, image route-oda irukkura gap-a perumbaalum kuraikkum, query cost-la oru pagudhi-kku.

**Evidence-a kaattradhu.** Visual content-la, citation-a page illa slide-oda thumbnail-aa kaattina innum useful. Engineers-um analysts-um image-a oru paarvai paathu answer-a confirm pannalaam, adhu model sinna numbers-a appappo thappaa padikkradhaiyum pidikkum.

**Code-la pages-a render panni visuals-a describe panradhu.** PyMuPDF PDF pages-a images-aa maathum; vision model focused prompt-oda adha describe pannum:

```python
import base64
import fitz                                      # PyMuPDF
import anthropic

client = anthropic.Anthropic()
CHART_PROMPT = ("Describe this page for search. For each chart: title, axes and units, every labelled value, "
                "and the main trend. For tables: headers and every row. Quote numbers exactly as shown.")

def page_images(pdf_path, dpi=150):
    doc = fitz.open(pdf_path)
    for i, page in enumerate(doc, start=1):
        yield i, page.get_pixmap(dpi=dpi).tobytes("png")

def describe(png_bytes):
    r = client.messages.create(
        model="claude-sonnet-5-5", max_tokens=800,           # check the docs for current names
        messages=[{"role": "user", "content": [
            {"type": "image", "source": {"type": "base64", "media_type": "image/png",
                                         "data": base64.b64encode(png_bytes).decode()}},
            {"type": "text", "text": CHART_PROMPT}]}])
    return "".join(b.text for b in r.content if b.type == "text")

# Text route: store describe(png) with the page number, and index it like any other chunk.
```

Answer time-la, adhe image block format, image route-ku top retrieved page images-a question-oda anuppa vidum.

**Text queries-oda images-a retrieve panradhu.** Oru multimodal embedding model images-aiyum text-aiyum ore space-la vaikkum:

```python
from PIL import Image
from sentence_transformers import SentenceTransformer

clip = SentenceTransformer("clip-ViT-B-32")
img_vecs = clip.encode([Image.open(p) for p in photo_paths], normalize_embeddings=True)
q = clip.encode(["rust on a flange joint"], normalize_embeddings=True)[0]
best = (img_vecs @ q).argsort()[::-1][:5]
```

Idhu maadhiri general models photos-ku work aagum. Text-um charts-um niraindha document pages-ku, page retrieval-ku train panna models (ColPali family oru nalla theriyaadha example) romba nallaa pannum; rendaiyum unga golden set-la test pannunga.

**Image tokens-ku selavu.** Vision model-kku anuppura page image neraya tokens-aa bill aagum, adhoda size-ku approx proportion-la. Top rendu moonu pages anuppunga, pathu illa; mudinja podhu relevant region-ku crop pannunga; sinna numbers innum padikkura maadhiri oru resolution-a select pannunga. Ovvoru route-kkum ovvoru question-ku cost-a measure pannunga.

**Images-la irundhu padicha numbers-a check pannunga.** Vision models sila samayam charts-layum scans-layum sinna digits-a thappaa padikkum. Underlying data irundha (chart-ku pinnaadi irukkura spreadsheet), adhukku link panni compare pannunga; illana answer-oda page thumbnail-a kaattunga, users check pannikkalaam.

**Browser-la try pannunga.** Image inputs size-ku tokens selavaagum. Vera vera sizes-la page images anuppina cost evvalavu aagum-nu estimate pannunga.

```python
def image_tokens(width, height):
    return (width * height) / 750                 # a common rule of thumb; check your provider's docs

for w, h in [(1600, 2000), (1000, 1250), (800, 1000)]:
    t = image_tokens(w, h)
    print(f"{w}x{h}: about {t:,.0f} tokens per page, {3 * t:,.0f} for three pages")
```

## Oru worked example

Vadodara chemicals manufacturer thanga plant engineers 15 varusha maintenance reports-a query panna vekkanum: scanned forms, equipment photos, piping diagrams, root-cause reviews-oda slide decks.

Rendu routes-aiyum 60 questions-la test pannuveenga:

- *Text-aa maathradhu*: forms-ku OCR, photos-kum diagrams-kum model ezhudhina descriptions. 58% correct. Failures: engineers kekkura detail-a descriptions miss pannichu, example entha valve tag circle pannirukku-nu.
- *Image retrieval*: page images multimodal retriever-oda embed aachu; top moonu pages vision-language model-kku pochu. 79% correct. Failures: scans-la irukkura sinna handwritten notes.

Neenga oru hybrid ship pannuveenga: scanned forms OCR-la pogum (adhoda text fields thaan engineers search pannuvaanga), photos, diagrams, slides images-aa retrieve aagum. Answers page thumbnail-a kaattum, engineers check pannalaam. Query cost text-only route-a vida sumaar naalu madangu, avangalukku romba mukkiyamaana questions-la accuracy yerinadhukkaaga client adha accept pannuraanga.

| 60 questions-la route | Correct | Mukkiya failures | Query cost |
| --- | --- | --- | --- |
| Text-aa maathradhu | 58% | Circle panna valve tags maadhiri details miss | 1 |
| Image retrieval | 79% | Sinna handwritten notes | Sumaar 4 |
| Content type-vaaree hybrid | Ship aachu | Forms-ku OCR, photos-kum diagrams-kum images | Rendukkum naduvula |

## Podhuvaa panra thappugal

- **Visual content-a ignore panradhu.** Text-only pipelines charts-aiyum photos-aiyum sappunu skip pannidum.
- **Chart readings-a adhigama nambradhu.** Vision models sinna numbers-a thappaa padikkum; pages-a cite pannunga, mukkiya values-a check pannunga.
- **Low-resolution images.** Details maraiyum; kekkura questions-ku podhumaana resolution vachukkunga.
- **Golden set-la visual questions illa.** Appo multimodal work help pannunadha-nu therinjukka mudiyaadhu.
- **Ellaathukkum image route.** Text niraindha documents text-aa irundha selavu kammi, perumbaalum nallaa-yum irukkum.
- **Charts-kum diagrams-kum generic captions.** Users-ku thevaippadura values-aiyum labels-aiyum kelunga.
- **Ovvoru question-kum neraya full-resolution pages anuppradhu**, adhu slow-um selavum adhigam.
- **Document pages-ku photo model use panradhu.** Oru page-retrieval model-aiyum test pannunga.

## Text-only RAG podhum-na eppo

- **Visuals text sollradhaiyae thirumba sollum bodhu**, charts sonna numbers-a illustrate panra neraya reports-la maadhiri.
- **Tables-a PDF parser clean-aa** text-aa extract panna mudiyum bodhu.
- **Konjam questions-ku mattum visuals thevai-nu irundha**, sila mukkiya pages-a kaiyaala describe pannradhu selavu kammi.

## Demo-la irundhu production-ku

- **Ovvoru description-oda, retrieved image-oda page numbers-aiyum thumbnails-aiyum** vechukkunga.
- **Route-vaaree query cost-a track pannunga**, image tokens-a serthu.
- **Description prompt nallaa aanaa pages-a thirumba describe pannunga**, descriptions-a version pannunga.
- **Oru visual golden set vechukkunga**, models maarum bodhu thirumba run pannunga.
- **Users thappaa padicha numbers-a flag panna vidunga**, adha test set-la serunga.
