## Idhu enna

Ippo varaikkum neenga ezhudhina programs-la data code-kkulla thaan irundhuchu. Real programs files-la irundhu data-va read pannum, results-a thirumba ezhudhum. Real data romba messy: file illa, row format thappu, number irukka vendiya idathula "NA". Idhukku rendu skills:

- **File input and output:** text, CSV files-a safe-aa open, read, write panradhu.
- **Error handling:** **exceptions**-a catch pannradhu, so oru bad input vandhaalum motha program-um crash aagaadhu, problems-a clear-aa report pannalaam.

```flow
dir: LR
Input: payments.csv | 412 rows, adhula 3 bad -> Ovvoru row-kum | try: convert pannu, total-la serkku
Ovvoru row-kum -[sariyaa velai seidhaa]-> Summary | collect aana total
Ovvoru row-kum -[except: bad row-a note pannu, thodarndhu po]-> problems.csv | check panna 3 rows
```

Indha lesson Sana-va follow pannum. Mysuru-la oru music school-la fees paakuraanga. Modhal bad row-lae crash aana script-a, velaiya mudichu check panna vendiyadha list panra script-aa maathuraanga. Lesson mudiyum podhu, messy CSV-a safe-aa process panna mudiyum.

## Idhu eppadi work aagudhu

### `with` vechu files open panradhu

```python
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

Block mudinjadhum `with` file-a thaane close pannidum, ullukkulla error vandhaalum. Eppavum `encoding="utf-8"` set pannunga, especially Indian language text-kum ₹ maadhiri symbols-kum. Illa-na, unga laptop-la work aagura file, colleague-oda computer-la fail aagalaam.

### File modes

| Mode | Artham | Danger |
| --- | --- | --- |
| `"r"` | Read (default) | File illa-na fail aagum |
| `"w"` | Write, file-la irukkura ellathaiyum **replace** pannum | Irukkura report-a `"w"`-la open panna azhinjidum |
| `"a"` | Kadaisila serkkum | Logs-ku safe |
| `"x"` | Pudhu file create pannum, already irundha fail aagum | Overwrite aagaama irukka useful |

### Line by line read panradhu

```python
with open("big_log.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())     # strip removes the newline at the end
```

Idhu romba periya files-a kooda handle pannum, ellathaiyum ore time-la memory-la load pannaadhu.

### CSV files

CSV file-na text-a save panna oru table: oru line-ku oru row, fields-ku naduvula commas. Neengalae commas vechu split pannaama `csv` module use pannunga, yenna fields-kulla quotes-oda commas irukkalaam, address maadhiri:

```text
name,address,amount
Asha,"12, MG Road, Mysuru",1500
```

```python
import csv
with open("orders.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["customer"], row["amount"])
```

`csv.DictReader` ovvoru row-vum header-a key-aa vechu dictionary-aa tharum. `csv.DictWriter` dictionaries-la irundhu rows ezhudhum. Gavanam: ella values-um **text**-aa thaan varum: "1500", 1500 illa. Maths panradhukku munnaadi convert pannunga.

### Exceptions

Edhaavadhu fail aana, Python **exception raise** pannum: oru type-um message-um irukkura error object. Common-aanavai:

| Exception | Selaa kaaranam |
| --- | --- |
| `FileNotFoundError` | File name illa folder thappu |
| `ValueError` | `int("twenty")` illa `float("NA")`: text number illa |
| `KeyError` | Dictionary-la illa CSV row-la andha key, column illa |
| `ZeroDivisionError` | Zero-vaala divide panradhu, empty list-oda average maadhiri |
| `TypeError` | Text-oda number-a serkkradhu |

Neenga expect panra specific exceptions-a catch panni, enna pannanum-nu decide pannunga:

```python
try:
    age = int("twenty")
except ValueError:
    age = -1          # mark as invalid instead of crashing
print(age)            # -1
```

Specific exceptions-a catch pannunga, ellathaiyum illa. Bare `except:` real bugs-a kooda maraichidum, misspelt variable maadhiri. Kandippa run aaganum-nu clean-up-ku `finally` use pannunga, unga sondha errors-a clear message-oda signal panna `raise` use pannunga:

```python
if amount < 0:
    raise ValueError(f"Negative amount on line {line_no}")
```

### Bad rows: collect pannunga, crash aagaadheenga

Neraya rows process pannum podhu, ovvoru row-oda errors-aiyum thaniyaa handle pannunga, line numbers-oda failures-a collect pannunga, kadaisila report pannunga. 400-la oru bad row, mathha 399-a niruthakkoodaadhu.

## Oru example

Sana Mysuru-la oru music school-la fees paakuraanga. Ovvoru maasamum bank `payments.csv` anuppum. Avangalukku collect aana total-um, kaiyaala check panna vendiya rows list-um vennum. Avanga first script modhal "NA"-lae crash aachu, bad row-a scroll panni thedanum. Avanga pudhu script:

```python
import csv

total = 0
problems = []
try:
    with open("payments.csv", newline="", encoding="utf-8") as f:
        for line_no, row in enumerate(csv.DictReader(f), start=2):
            try:
                amount = float(row["amount"].replace(",", ""))
                total += amount
            except (ValueError, KeyError) as e:
                problems.append((line_no, row.get("student", "?"), str(e)))
except FileNotFoundError:
    print("payments.csv not found. Download it from the bank portal first.")
    raise SystemExit(1)

with open("problems.csv", "w", newline="", encoding="utf-8") as out:
    writer = csv.writer(out)
    writer.writerow(["line", "student", "error"])
    writer.writerows(problems)

print(f"Collected Rs {total:,.2f}; {len(problems)} rows need checking")
```

`enumerate(..., start=2)` rows-a 2-la irundhu number pannum, yenna file-oda line 1 header. So Sana file-a open panna paakkura line numbers-oda match aagum.

| Run | Rows | Converted | Problems | Result |
| --- | --- | --- | --- | --- |
| Pazhaya script | 412 | Row 37-la nindruchu | Crash aachu | Total illa, row-a kaiyaala kandupidikkanum |
| Pudhu script | 412 | 409 | 3 ("NA" rendu thadavai, onnu blank) | Total-um problems.csv-um |

Indha maasam moonu rows-a anju nimishathula fix pannuraanga, arai mani neram waste aagala.

## Podhuvaa panra thappugal

- **`with` marandhudradhu.** Files open-aavae irukkalaam, illa data lose aagalaam.
- **`"a"` vendiya idathula `"w"` use panradhu.** Pazhaya content-um sertthu pogum, thirumba varaadhu.
- **CSV lines-a commas vechu split panradhu.** `csv` module use pannunga; quoted commas split-a udaichidum.
- **CSV values text-nu marandhudradhu.** Maths-ku munnaadi `int()` illa `float()` vechu convert pannunga.
- **Bare `except` vechu ellathaiyum catch panradhu.** Neenga expect panra specific exceptions-a catch pannunga.
- **Modhal bad row-la nirutradhu.** Failures-a collect panni thodarndhu po.
