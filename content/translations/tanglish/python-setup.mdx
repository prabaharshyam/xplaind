## Idhu enna

Programs ezhudhuradhukku munnaadi, adhai ezhudha oru idamum, run panna oru vazhiyum venum. First-year student-la irundhu oru periya company-la irukkura AI engineer varai, ovvoru Python programmer-um idhae moonu tools-a vachu thaan velai seiyuraanga:

| Tool | Adhu enna | Udhaaranam |
| --- | --- | --- |
| **Python** | Unga code-a padichu run panra program (**interpreter**) | Python 3, python.org-la irundhu |
| **Oru code editor** | Neenga code ezhudhura idam; adhu unga code-kku colour kudukkum, chinna thappugalai kandupidikkum, type panna udhavum | Visual Studio Code (VS Code), free |
| **Oru terminal** | Commands type panra oru text window; unga file-a run panra command-um idhula thaan | VS Code-kkulla irukkura terminal |

Moonum **othuppona** thaan setup mudinjadhu: terminal-aala Python-a kandupidikka mudiyanum, editor adhae Python-a use pannanum, terminal unga file irukkura folder-la thirandhirukkanum. Beginners-kku varra kittathatta ella problem-um, idhula edho onnu othuppogaadhadhaala thaan.

Othupponadhum, ovvoru programmer-um dhinamum suthura loop-a aarambikkireenga:

```flow
dir: LR
Oru file ezhudhunga -> Save pannunga
Save pannunga -> Terminal-la run pannunga
Terminal-la run pannunga -> Output-aiyo error-aiyo padinga
Output-aiyo error-aiyo padinga -> Fix pannunga
Fix pannunga -[marubadi]-> Oru file ezhudhunga
```

Indha lesson, Madurai-la irukkura commerce graduate Karthik-a follow pannudhu; avar than Windows laptop-la Python set up panraaru, beginners-kku adhigamaa varra problems-a sandhikkiraaru. Idhoda check oru chinna project: unga sondha mudhal file, terminal-la run panni, online-la share panradhu.

## Idhu eppadi work aagudhu

### Oru version-a thernthedunga

Ellaathaiyum vida pudhusaana Python 3-a install pannunga. Python 3.15.0, 9 October 2026-la vandhuchu; bugfix releases 3.15.1, 3.15.2 October-laye vandhuchu, innum sumaar rendu maasathukku oru thadavai varum, adhanaala neenga paakkura kadaisi number innum adhigamaa irukkalaam. Python 3.14-um paravaayilla. Moonu rules:

- **Python 3 thaan, Python 2 eppavumae vendaam.** Oru tutorial brackets illaama `print "hello"`-nu ezhudhunaa, adhu Python 2-kkaanadhu; pudhusaa onnai thedunga.
- **Oru Python podhum.** "Safe-aa irukkattum"-nu pala Pythons install panradhu thaan, editor-um terminal-um othuppogaama poga ellaathaiyum vida seekkiramaana vazhi.
- **Periya libraries pinthangalaam.** Sila periya data, AI libraries oru pudhu version-a support panna vaarakkanakkaa edukkum. Edhaavadhu onnu install aaga maattengudhu-nnaa, andha project-kku 3.14 use pannunga.

### Python install pannunga

| Computer | Eppadi |
| --- | --- |
| Windows 10 allathu 11 | python.org/downloads-la irundho Microsoft Store-la irundho **Python install manager**-a install pannunga. Adhu ungalukku `python`, `py` commands-a kudukkum. Edhuvum install aagaadha nilaiyila mudhal thadavai Python-a run panna, adhu latest release-a download pannum; `py install 3.15`-num type pannalaam. |
| Mac | python.org-la irundhu macOS installer-a download panni run pannunga. `python3` command-a use pannunga. |
| Linux | Python 3 podhuvaa erkanavae irukkum. `python3` use pannunga; niraiya systems-la verum `python` command irukkavae irukkaadhu. |

Install manager thaan ippo Windows-la Python install panradhukkaana official vazhi. Pazhaya full installer (orae oru `.exe`) Python 3.15-kku innum irukku, aanaa Python 3.16-la irundhu python.org adhai kudukkuradhai niruthidum. Adhai use panna, adhoda mudhal screen-la **"Add python.exe to PATH"**-a tick pannunga. **PATH**-na, neenga oru command type pannumbodhu Windows thedura folders-oda list. Python-oda folder andha list-la illanna, Python install aagiyirundhaalum `python`-nu type panna fail aagum.

### Install-a check pannunga

Oru **pudhu** terminal thirandhu idhai type pannunga:

```text
python --version
```

Mac, Linux-la `python3 --version` type pannunga. `Python 3.15.0` maadhiri 3-la aarambikkira oru version theriyanum. Windows-la, install manager-kku therinja ella Python-aiyum `py list` kaattum.

Yen pudhu terminal? Oru terminal PATH-a orae oru thadavai, adhu thirakkumbodhu thaan padikkum. Install nadakkumbodhu thirandhirundha terminal-kitta innum pazhaya list thaan irukkum, adhaala Python-a kandupidikka mudiyaadhu. VS Code terminal, PATH-a VS Code-la irundhae copy pannudhu, adhanaala terminal tab-a mattum illa, VS Code-aiyae muzhusaa close panni thirumba thiranga.

### Windows-aala Python-a kandupidikka mudiyaadhappo

Windows learners adhigamaa sandhikkira moonu messages ivai thaan:

| Ungalukku theriyuradhu | Adhoda artham | Fix |
| --- | --- | --- |
| `The term 'python' is not recognized...` (PowerShell) allathu `'python' is not recognized as an internal or external command` (Command Prompt) | Python install aagala, illanna adhoda folder PATH-la illa | Install manager-a install pannunga, illanna PATH box-a tick panni pazhaya installer-a thirumba run pannunga. Apram pudhu terminal thiranga. |
| `Python was not found; run without arguments to install from the Microsoft Store...`, illanna Store app thirakkudhu | Python install aagala. Windows-la **app execution alias**-nu oru shortcut koodavae varudhu, adhu `python`-a Store-kku anuppudhu. | Python-a ozhungaa install pannunga. Pazhaya installer-a use panniyirundhaa, Start menu-la "Manage app execution aliases"-a thedi, python.exe, python3.exe-kkaana rendu App Installer entries-aiyum off pannunga. |
| Neenga edhirpaarkkaadha oru version | Onnukku mela Python install aagiyirukku, PATH-la mudhalla irukkuradhu thaan jeyikkum | `py list`, `where.exe python` ellaathaiyum kaattum. Koodudhalaa irukkuradhai uninstall pannunga. |

```flow

Install pannunga allathu alias-a off pannunga -> VS Code-a close panni thirumba thiranga

```

### Mac-la: sariyaana python3-a thaan run panreengalaa-nnu urudhi pannunga

macOS-kku `/usr/bin/python3`-la adhoda sondha `python3` irukku. Adhu Apple-oda developer tools-a serndhadhu, podhuvaa pazhaiyadhu; adhai call panna Command Line Tools-a install panna solli kekkalaam. python.org installer adhoda sondha `python3`-a mudhalla vara vaikkum. Check panna, oru pudhu terminal thirandhu `which python3` type pannunga. `/Library/Frameworks/Python.framework` allathu `/usr/local/bin`-kku keezha irukkura path-naa adhu python.org-odadhu; `/usr/bin/python3`-naa Apple-odadhu.

### Oru editor install panni, adhai Python-kku point pannunga

VS Code-aiyum adhoda **Python extension**-aiyum (Microsoft-odadhu) install pannunga. Unga velaikku `python-practice` maadhiri oru folder uruvaakki, File, Open Folder vachu adhai thiranga. Ovvoru project-aiyum adhoda sondha folder-la vachaa, apram niraiya kuzhappathai thavirkkalaam.

Apram endha Python-a use pannanum-nu VS Code-kku sollunga. Ctrl+Shift+P (Mac-la Cmd+Shift+P) azhuthi, **Python: Select Interpreter**-nu type panni, neenga ippo install panna Python-a pick pannunga. Thernthedutha version keezha status bar-la theriyum. VS Code vera oru Python-a pick panniyirundhaa, visithiramaana results varum: file terminal-la run aagum, aanaa editor unga imports-kku keezha sivappu kodu podum, illanna Run button neenga venumnu install pannaadha oru version-a use pannum. Interpreter-a maathunaa erkanavae thirandhirukkura terminals maaraadhu, adhanaala apram oru pudhu terminal thiranga.

Kadaisiyaa, **File, Auto Save**-a on pannunga. Oru file-oda tab-la dot irundhaa, adhula save pannaadha changes irukku-nnu artham. Python disk-la irukkura file-a thaan run pannum, unga screen-la irukkuradhai illa, adhanaala save pannaadha fix onnumae pannaadhu.

### Unga mudhal file-a ezhudhunga

Andha folder-la `hello.py`-nu oru file uruvaakkunga:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

Line 1, Python-oda built-in `datetime` module-la irundhu `date`-a kondu varudhu. Line 3, `name`-ngra variable-la text-a store pannudhu. Lines 4, 5 print pannudhu, `date.today()` unga computer-kitta innaikku date-a kekkudhu.

`.py` ending, idhu Python code-nu Python-kkum unga editor-kkum solludhu. Windows default-aa file endings-a maraikkum, adhanaala `hello.py`-nu neenga ninaikkira file unmaiyila `hello.py.txt`-aa irukkalaam. File Explorer-la View menu-vai thirandhu, file name extensions-a on pannunga, appo unmai theriyum.

### Terminal-la run pannunga

View, Terminal vachu VS Code-kkulla terminal-a thiranga. Terminal eppavumae oru folder-"kkulla" thaan velai seiyum, adhu endha folder-nu prompt podhuvaa kaattum, udhaaranam `PS C:\Users\karthik\python-practice>`. Adhu unga file irukkura folder thaanaa-nnu urudhi pannunga:

| Command | Windows | Mac, Linux |
| --- | --- | --- |
| Naan enga irukken? | PowerShell-la `pwd` (VS Code default), Command Prompt-la `cd` | `pwd` |
| Inga irukkura files-a list pannu | `dir` | `ls` |
| Oru folder-kkulla po | `cd python-practice` | `cd python-practice` |
| Oru folder mela po | `cd ..` | `cd ..` |
| Oru file-a run pannu | `python hello.py` | `python3 hello.py` |

`python hello.py` type panni Enter azhuthunga. Output keezha theriyum. Tip: Tab file names-a complete pannum, Up arrow kadaisi command-a thirumba kudukkum.

VS Code-oda Run button (mela valadhu pakkam irukkura mukkonam) adhae command-a ungalukkaaga type pannum. Irundhaalum type panra command-a kathukkonga: servers, options, remote machines ellaathukkum adhu thevai.

### `>>>` prompt vera oru idam

File name illaama verum `python` (allathu `python3`) type panna, neenga **interactive shell**-kkulla poveenga, adhu `>>>` prompt-a kaattum. Adhu oru nerathula Python-oda oru line-a thaan run pannum; `2 + 3` allathu `len("Madurai")` maadhiri chinna experiments-kku adhu vasadhi. Aanaa adhukku Python mattum thaan puriyum, terminal commands puriyaadhu. Anga `python hello.py` type panna idhu varum:

```text
>>> python hello.py
  File "<python-input-0>", line 1
    python hello.py
           ^^^^^
SyntaxError: invalid syntax
```

`exit()` type panni Enter azhuthi terminal-kku thirumbunga, apram anga irundhu unga file-a run pannunga.

### Error messages-a padinga

Edhaavadhu thappaa irundhaa, Python oru error message print pannum, pala neram sivappula. **Kadaisi variyai mudhalla** padinga: adhu error-oda peyarai sollum. Apram adhukku mela irukkura file name, line number-a paarunga; Python suttikkaattura pagudhikku keezha `^` marks potta unga code-oda copy-aiyum paarunga.

Line 5-la kadaisi bracket-a delete panreenga-nnu vachukkonga. Python edhaiyum run panradhukku munnaadi muzhu file-aiyum check pannum, adhanaala output edhuvumae varaadhu, line 4-odadhu kooda varaadhu:

```text
  File "C:\Users\priya\python-practice\hello.py", line 5
    print("Today is", date.today()
         ^
SyntaxError: '(' was never closed
```

Thirandhu moodaama vitta bracket-kku keezha thaan `^` irukku. Matha thappugal program run aagumbodhu thaan theriyum. Line 5-la `date.todya()`-nu type panna, Python nikkumbodhu line 4 erkanavae print aagiyirukkum. Indha muzhu report-kku **traceback**-nu peru:

```text
Hello, my name is Priya
Traceback (most recent call last):
  File "C:\Users\priya\python-practice\hello.py", line 5, in <module>
    print("Today is", date.todya())
                      ^^^^^^^^^^
AttributeError: type object 'datetime.date' has no attribute 'todya'. Did you mean '.today' instead of '.todya'?
```

Adhu Python 3.15-oda wording; pazhaya versions hint-a konjam vera maadhiri sollum. Python pala neram fix-aiyae suggest pannum, adhanaala line-oda kadaisi varai padinga. Oru gotcha: line number-na Python problem-a **kavanicha** idam, adhu eppavum thappu irukkura idamaa thaan irukkum-nu illa. Udhaaranamaa, oru `if` line-kku apram indent missing aanaa, adhu adhukku keezha irukkura line-la report aagum, adhanaala oru line melayum paarunga.

| Error | Podhuvaana kaaranam |
| --- | --- |
| `SyntaxError` | Oru bracket, quote allathu colon missing, illanna `>>>`-la type panna oru terminal command |
| `IndentationError` | Indent pannakkoodaadha oru line indent aagiyirukku, illanna tabs-um spaces-um kalandhirukku |
| `NameError` | Oru variable-oda spelling thappu, illanna uruvaakkuradhukku munnaadiyae oru variable-a use panradhu |
| `AttributeError` | Dot-kku apram varra function allathu method peyaroda spelling thappu |
| `ModuleNotFoundError` | Neenga run panra Python-la install aagaadha oru package |
| `can't open file` | Terminal thappaana folder-la irukku, illanna file name thappu |

### Packages install panradhu: ippovae oru pazhakkam

Seekkiramae neenga `requests` allathu `pandas` maadhiri packages install pannuveenga. Unga files-a run panra adhae Python vazhiyaa avattrai install pannunga:

```text
python -m pip install requests
```

Mac-la `python3 -m pip` use pannunga. Verum `pip install` vera oru Python-odadhaa irukkalaam; adhanaala thaan learners "ippo thaan install panna" oru package-kku `ModuleNotFoundError` paakkuraanga. Samibathiya Ubuntu, Debian versions-la system Python-kkulla install panna `error: externally-managed-environment`-nu ninnudum. Adhai force panni thaandaadheenga; fix oru virtual environment thaan, adhu "Packages-um virtual environments-um" lesson-la (B3) varudhu. Apram "Project tooling" lesson (B3) uv-a kaattum; adhu environments-a uruvaakkum, ungalukkaaga Python-aiyae kooda install panna mudiyum. Unga `hello.py`-kku endha package-um thevaiyilla.

### Python-a run panna matha vazhigal

**Google Colab**, **Kaggle** maadhiri online notebooks, edhuvum install pannaama browser-laye Python-a run pannum. Unga computer lock panniyirundhaa, pazhasaa irundhaa, allathu palar share panradhaa irundhaa avai udhavum. Rendu echarikkaigal: anga neenga uruvaakkura files session mudiyumbodhu kaanaama pogalaam, adhanaala unga velaiya download pannikkonga; adhoda, ovvoru unmaiyaana project-kkum thevaiyaana terminal, folder skills-a notebook maraichidum. Aarambikka avattrai use pannunga, local setup-kku badhilaa illa.

## Oru worked example

Madurai-la irukkura commerce graduate Karthik, oru naal saayangaalam than Windows 11 laptop-la Python set up panraaru.

**Step 1: Store surprise.** Edhaiyum install panradhukku munnaadi, PowerShell-a thirandhu `python` type panraaru. Microsoft Store thirakkudhu. Indha lesson-la paatha Windows shortcut idhu-nnu avarukku puriyudhu; Store-a close panni, adhukku badhilaa Python-a ozhungaa install panraaru.

**Step 2: install.** python.org/downloads-la irundhu Python install manager-a install panni, oru pudhu PowerShell window-vai thirandhu `py install 3.15` type panraaru. Adhu latest Python 3.15-a download panni install pannudhu.

**Step 3: pudhu terminal-la check.** VS Code-aiyum adhoda Python extension-aiyum install panraaru. VS Code terminal-la `python --version`, `Python 3.15.2`-nu print pannudhu. Oru `python-practice` folder uruvaakki, File, Open Folder vachu adhai thirandhu, Python: Select Interpreter vachu 3.15-a pick panraaru.

**Step 4: mudhal error.** `C:\Users\karthik\python-practice`-la than sondha peyaroda `hello.py` ezhudhuraaru. Adhai run panna, Step 2-la thirandha thani PowerShell window-la `python hello.py` type panraaru; andha window avaroda home folder-la thirandhirundhuchu, adhanaala fail aagudhu. Message-oda kadaisi ippadi irukku:

```text
can't open file 'C:\\Users\\karthik\\hello.py': [Errno 2] No such file or directory
```

Double backslashes, Python oru Windows path-a print panra vidham thaan. Python enga thedichu-nnu path solludhu: `python-practice` illa, avaroda home folder. Avar `cd python-practice` type panni, apram `hello.py` anga irukkaa-nnu urudhi panna `dir` type panni, command-a thirumba run panraaru:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: save pannaadha change.** Than peyarai Tamil script-la print panra oru line serthu file-a run panraaru. Output maarala. ## Podhuvaa panra thappugal

- **Mudhal error-laye reinstall panradhu.** Perumbaalaana errors folder, PATH, allathu save pannaadha file pathinadhu thaan; udainja install pathinadhu illa. Kadaisi variyai mudhalla padinga.
- **Pazhaya terminal-la test panradhu.** Python install pannina apramo PATH-a maathuna apramo, VS Code-a muzhusaa close panni oru pudhu terminal thiranga.
- **Store shortcut-a Python-nu ninaikkiradhu, allathu pazhaya installer-la PATH tick-a vittudradhu.** Install manager-a use pannunga.
- **Thappaana folder-la irundhu run panradhu.** Run panradhukku munnaadi `pwd`, `dir` allathu `ls` vachu check pannunga.
- **Save pannaadha file-a run panradhu.** Tab-la dot irukkaa-nnu paarunga, illanna Auto Save-a on pannunga.
- **`>>>` prompt-la terminal commands type panradhu.** Mudhalla `exit()` type pannunga.
- **File-a `hello.py.txt`-aa save panradhu.** File Explorer-la file name extensions-a on pannunga.
- **Pala Pythons irukkuradhu, VS Code vera onnai use panradhu.** Orae oru Python vachukkonga, Python: Select Interpreter vachu adhai thernthedunga.
- **Verum `pip install` use panradhu.** `python -m pip install` use pannunga, appo thaan package unga code-a run panra Python-kkulla pogum.
