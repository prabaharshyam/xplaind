## Idhu enna

Programs ezhudha, ezhudha oru idamum, run panna oru vazhiyum thevai. Oru student-la irundhu periya company-la irukkura AI engineer varaikkum, ovvoru Python programmer-um ore moonu vishayatha vechchu thaan velai seiraanga:

| Tool | Idhu enna | Example |
| --- | --- | --- |
| **Python** | Unga code-a padichu run panra program | Python 3, python.org-la irundhu |
| **Code editor** | Code ezhudha idam; mistakes-a highlight pannum, type panna help pannum | Visual Studio Code (VS Code), free |
| **Terminal** | Commands type panra text window, unga file-a run panra command ulpada | VS Code-kkulla irukkura terminal |

Moonum work aanadhum, ovvoru programmer-um vaazhra loop aarambikkum:

```flow
dir: LR
File ezhudhu -> Run pannu -> Output illa error-a padi -> Fix pannu
Fix pannu -[thirumba]-> File ezhudhu
```

Indha lesson Karthik-a follow pannum. Madurai-la commerce graduate-aa irukkura avar Windows laptop-la Python set up panni, beginners-ku varra rendu common problems-a sandhikkuraar. Indha lesson-oda check oru chinna project: unga first file-a terminal-la run panni, online-la share pannunga.

## Idhu eppadi work aagudhu

### Python install panradhu

| Computer | Eppadi |
| --- | --- |
| Windows | python.org-la irundhu illa Microsoft Store-la irundhu **Python install manager** install pannunga. Idhu `python`, `py` commands-a set up pannum. Pazhaya full installer use pannaa, adhoda first screen-la **"Add python.exe to PATH"** tick pannunga. |
| Mac | python.org-la irundhu installer download panni run pannunga. |
| Linux | Python 3 perumbaalum already install aagi irukkum. |

Pazhaya full installer-la PATH tick mukkiyam: neenga `python` type pannum podhu terminal Python-a kandupidikka adhu help pannum. Illa-na terminal Python-a recognise pannala-nu solludhu.

Install check panna, terminal open panni type pannunga:

```text
python --version
```

Mac, Linux-la `python3 --version` type pannunga. 3-la aarambikkura version theriyanum, `Python 3.15.2` maadhiri.

### Editor install panradhu

VS Code-um adhoda **Python extension**-um install pannunga. Apram `python-practice` maadhiri unga velaikku oru folder create panni, File, Open Folder vechu open pannunga. Ovvoru project-aiyum thani folder-la vechchaa, apram neraya kuzhappam thavirkalaam.

### First file ezhudhunga

Andha folder-la `hello.py`-nu oru file create pannunga:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

`.py` mudivu, idhu Python code-nu Python-kum unga editor-kum solludhu.

### Terminal-la irundhu run panradhu

VS Code-kkulla View, Terminal vechu terminal open pannunga. Terminal eppavum oru folder-"la" thaan velai seiyum. Adhu unga file irukkura folder-nu confirm pannikonga:

| Command | Windows | Mac and Linux |
| --- | --- | --- |
| Naan engey irukken? | PowerShell-la `pwd` (VS Code default), Command Prompt-la `cd` | `pwd` |
| Inga irukkura files list | `dir` | `ls` |
| Oru folder-kkulla po | `cd python-practice` | `cd python-practice` |
| Oru folder mela po | `cd ..` | `cd ..` |
| File run pannu | `python hello.py` | `python3 hello.py` |

`python hello.py` type panni Enter amukkunga. Output keezha varum.

### Error messages-a padikkradhu

Edhaavadhu thappaa irundha, Python oru **traceback** print pannum. **Kadaisi line-a modhalla** padinga: adhu error-oda peyar-a solludhu. Adhukku mela irukkura line number, Python problem-a engey kavanichadhu-nu kaattum.

```text
  File "hello.py", line 4
    print("Today is", date.today()
                                  ^
SyntaxError: '(' was never closed
```

Beginners-ku varra perumbaalaana errors idhula onnu:

| Error | Selaa kaaranam |
| --- | --- |
| `SyntaxError` | Bracket, quote, colon illama pogradhu |
| `IndentationError` | Thappaana illa kalandha indentation |
| `NameError` | Spelling thappaana variable, illa create panradhukku munnaadi use panna variable |
| `can't open file` | Terminal thappaana folder-la irukku, illa file name thappu |

### Python-a vera vazhiyila run panradhu

**Google Colab**, **Kaggle** maadhiri online notebooks edhuvum install pannaama browser-la Python-a run pannum. Unga computer locked-down-aa, illa pazhaiyadhaa irundha, data velaikkum idhu useful. Aana terminal-la irundhu files run panna kathukkonga: real projects, servers, AI applications ellaam appadi thaan velai seiyum.

## Oru example

Madurai-la commerce graduate Karthik, oru maalai avar Windows laptop-la Python set up panraar.

**Step 1: install.** python.org-la irundhu full installer download panni, "Add python.exe to PATH" tick panni install pannuraar. (Python install manager-um work aagum, adhukku tick thevaiyilla.)

**Step 2: check.** Pudhu terminal-la `python --version` `Python 3.15.2`-nu print pannudhu. PATH tick marandhirundha, inga thaan "python is not recognized"-nu paathirupaar.

**Step 3: editor, file.** VS Code-um Python extension-um install panni, `python-practice` folder create panni, mela irukkura code-a avar sondha peyar-oda `hello.py`-la ezhudhuraar.

**Step 4: first error.** `python hello.py` type pannaa idhu varudhu:

```text
python: can't open file 'C:\Users\karthik\hello.py': [Errno 2] No such file or directory
```

Terminal avar home folder-la irundhuchu, `python-practice`-la illa. `cd python-practice` type panni, thirumba command run pannuraar. Ippo work aagudhu:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: oru maatram.** Avar peyar-a Tamil script-layum print panna oru line serkkuraar, thirumba run pannaa sariyaa print aagudhu, yenna VS Code files-a UTF-8-la save pannum.

| Problem | Avar paartha message | Fix |
| --- | --- | --- |
| Terminal thappaana folder-la | `can't open file ... No such file or directory` | `cd python-practice` |
| (Thavirththadhu) PATH set aagala | `python is not recognized` | PATH box tick panni thirumba install pannunga |

Kadaisila GitHub account create panni, `hello.py`-a pudhu repository-la vaikkiraar, share panna oru link kidaikkum. Andha link thaan indha lesson-oda check.

## Podhuvaa panra thappugal

- **Pazhaya Windows installer-la "Add to PATH" marandhudradhu.** Appo terminal Python-a kandupidikka mudiyala-nu solludhu. Box tick panni thirumba install panni, pudhu terminal open pannunga.
- **Thappaana folder-la irundhu run panradhu.** Run panradhukku munnaadi `pwd` (illa Command Prompt-la `cd`) vechu engey irukkeenga-nu check pannunga.
- **File-a .txt mudivoda save panradhu.** Adhu `.py`-la mudiyanum. Windows-la "show file extensions" on pannaa theriyum.
- **Sivappu text-a paathu bayappadradhu.** Error-oda kadaisi line-um line number-um padinga.
- **Tabs-um spaces-um kalakkradhu.** Editor-ae indent pannattum.
- **Neraya Python versions-a ore time-la install panradhu.** Aarambikka oru recent Python 3 podhum.

## Practice pannunga

Unga operating system-kku Python for Everybody installation lesson-a follow pannunga, keezha link irukku.

1. **Ezhudhunga:** unga peyar-um innaiku date-um print panra `hello.py`.

4. **Share pannunga:** file-oda link, GitHub repository illa gist maadhiri.

**Mudinjadhu-nu eppo sollalaam:** pudhu `.py` file create panni, terminal-la run panni, message-a padichu simple error-a fix panna mudiyum.
