## Idhu enna

Machine learning-na periya numbers tables-la maths, Python-la andha maths **NumPy**-la run aagum, fast numerical arrays-ku library. pandas, scikit-learn, PyTorch ellaam adhoda ideas mela build aagirukku, adhanaala inga kathukkura habits model velaikku appadiyae varum. **Matplotlib** standard plotting library; Seaborn, Plotly maadhiri matrava similar ideas use pannum.

Mukkiya skills:

| Skill | Artham | Example |
| --- | --- | --- |
| **Arrays, shapes** | Arrays create panni, adhoda dimensions theriyanum | `X.shape` `(50000, 3)` |
| **Vectorisation** | Muzhu arrays-la oru neraththula maths | `prices * 1.18` |
| **Broadcasting** | Vera aana compatible shapes-oda arrays-a serkkuradhu | `X - X.mean(axis=0)` |
| **Masks, indexing** | Condition illa position vachu data select panradhu | `y[y > 30]`, `X[:, 0]` |
| **Plotting** | Distributions, relationships, trends-a paakkradhu | histogram, scatter, line, box plot |

```text
  X: shape (5, 3)                          means: shape (3,)
   distance  items  hour                   [ 4.2,  3.0, 15.4 ]
  [  2.1      1     13 ]                          |
  [  6.8      4     19 ]     X - means            | broadcast to every row
  [  3.0      2     11 ]   ------------>          v
  [  5.5      5     20 ]                   result: shape (5, 3), each column centred
  [  3.6      3     14 ]
```

Indha lesson-la Bengaluru-la oru quick-commerce company-a follow pannuvom; rendu simple plots oru logging bug-aiyum delivery times-la maraindhu irundha oru factor-aiyum kaattum. Mudiyum podhu moonu plots vachu oru pudhu dataset-a explore panni, kandupidicha oru data problem-a sollalaam.

## Idhu eppadi work aagudhu

### Arrays-um shapes-um

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.shape)          # (2, 2)
```

12 features-oda 10,000 customers dataset-oda shape `(10000, 12)`. Oru single row-oda shape `(12,)`. Numerical code-la perumbaalaana bugs shape mismatches, adhanaala `.shape`-a adikkadi print pannunga.

### Vectorisation

```python
prices = np.array([120, 450, 999])
with_gst = prices * 1.18            # every element at once
print(np.mean(prices), np.std(prices), np.percentile(prices, 90))
```

Vectorised code loop-a vida sinnadhu, periya arrays-la perumbaalum pathu madangu fast, yenna velai kezhae irukkura optimised code-la nadakkudhu.

**Axis** argument direction-a mudivu pannum:

| Call | Result |
| --- | --- |
| `X.mean()` | Oru number: ellaathoda mean |
| `X.mean(axis=0)` | Ovvoru column-ukkum oru value: ovvoru feature-oda mean |
| `X.mean(axis=1)` | Ovvoru row-kum oru value: ovvoru record-oda mean |

### Broadcasting

Shapes compatible-aa irundhaa NumPy sinna array-a periyadhoda match aaga stretch pannum. `(10000, 12)` array-la irundhu `(12,)` array-oda column means-a kazhicha, ovvoru column-aiyum oru line-la centre pannidum:

```python
Z = (X - X.mean(axis=0)) / X.std(axis=0)    # each column: mean 0, std 1
```

### Indexing-um slicing-um

Arrays position vachu index aagum, 0-la irundhu aarambikkum, ovvoru dimension-kum oru index:

```python
X[0]          # the first row: all features of the first record
X[:, 0]       # the first column: one feature for every record
X[10:20, 1:]  # rows 10 to 19, and every column from the second onwards
X[-1]         # the last row
```

Colon-na "indha dimension-la ellaam". `X[:, 0]`-a "every row, column zero"-nu sathama padichaa help aagum. Slices views, copies illa: oru slice-a maathinaa original array-um maarum, adhanaala thaniyaa oru piece thevaina `.copy()` use pannunga.

### Boolean masks

```python
incomes = np.array([18000, 52000, 75000, 31000])
print(incomes[incomes > 50000])                     # [52000 75000]
print(incomes[(incomes > 20000) & (incomes < 60000)])
```

"And"-ku `&`, "or"-ku `|` use pannunga, ovvoru condition-um brackets-kulla.

### Reproducible random numbers

`rng = np.random.default_rng(42)` neenga appadiyae thirumba pannalaam-nu oru random generator tharum, data-va sample panna, illa training, test sets-aa pirikka.

### Machine learning-la mukkiyamaana plots

| Plot | Enna kaattum | Podhuvaana finding |
| --- | --- | --- |
| **Histogram** | Oru feature-oda distribution | Skew, outliers, zeros maadhiri mudiyaadha values |
| **Scatter plot** | Rendu features-oda, illa oru feature-kum target-kum relationship | Oru curve, oru cluster, oru value-la break |
| **Line chart** | Neram pogum podhu values | Seasonality, sappunnu drop, epoch-ku training loss |
| **Box plot** | Groups-la distributions | Oru city-oda deliveries matravangala vida romba mella |

Axes-aiyum units-aiyum eppavum label pannunga, order values maadhiri romba skewed data-ku **log scale** use pannunga.

## Oru worked example

Bengaluru-la oru quick-commerce company delivery time-a predict panna virumbudhu. 50,000 deliveries-a arrays-la load pannureenga: distance km-la, items count, hour of day, edutha actual minutes.

```python
import numpy as np
import matplotlib.pyplot as plt

# X (distance, items, hour) and y (minutes) were loaded earlier
print(X.shape, y.shape)                  # (50000, 3) (50000,)
print(np.percentile(y, [50, 90, 99]))    # median 14, p90 24, p99 61 minutes

plt.hist(y, bins=60)
plt.xlabel("Delivery time (minutes)"); plt.ylabel("Orders")
plt.show()

plt.scatter(X[:, 0], y, s=2, alpha=0.3)
plt.xlabel("Distance (km)"); plt.ylabel("Minutes")
plt.show()
```

**Histogram enna kaattudhu.** Mella deliveries-oda nee-nda tail, expect panna madhiriye, apram exact-aa 0 minutes-la oru vinodhamaana spike: 412 deliveries edhuvum neram edukkaama record aagirukku. Idhu oru logging bug, miracle illa.

**Scatter plot enna kaattudhu.** Times dhooram-oda sumaar 6 km varai ozhungaa yerudhu, apram thaavudhu. Andha orders-a check pannaa, kuraivaana riders irukkura vera oru dark store-la irundhu vandhadhu-nu theriyudhu.

| Plot | Finding | Model-la enna maathradhu |
| --- | --- | --- |
| Minutes-oda histogram | 0 minutes-la 412 deliveries | Andha rows-a drop illa fix pannunga; bug-a report pannunga |
| Distance vs minutes scatter | 6 km-ku mela thaavudhu | Oru "store" feature add pannunga |
| Percentiles | p99 61 minutes | Average mattum illa, p90, p99-la errors-a report pannunga |

Edhavadhu model train aagradhukku munnaadi, aindhu nimishathula, rendu plots-a vida clear-aa, entha oru metric-um idha kaattirukkaadhu.

## Podhuvaa panra thappugal

- **Arrays mela Python loops.** Vectorise pannunga; short-aavum romba fast-aavum.
- **Shapes-a ignore panradhu.** Print pannunga, broadcasting neenga nenaikkiradhai pannudha-nu check pannunga.
- **Plot pannaama modelling.** Plots bugs, outliers, leakage-a modhalaiyae kaattum.
- **Label illaadha charts.** Axes-um units-um plots-a matravangalukku padikka vaikkum.
- **Skewed data-la linear scales.** Values orders of magnitude paravi irundhaa log scales use pannunga.
- **axis=0, axis=1-a kuzhappikkuradhu.** Result-oda shape-a paathu direction-a confirm pannunga.
