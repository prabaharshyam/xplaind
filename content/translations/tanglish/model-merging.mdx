## Idhu enna

Fine-tuning oru model-a maathum. **Model merging** rendu illa adhukku mela models-a, avatroda weights-a kalandhu, oru model-aa serkkum. Adhu perumbaalum models **orae base model**-la irundhu fine-tune panna pothu nallaa work aagum, adhanaala avatroda weights porundhum.

Yen idhellaam?

- **Oru model-la neraya skills.** Oru model-a complaints-ku, innoru model-a replies-ku fine-tune pannaa, oru merge rendaiyum pannum.
- **Tasks-a onnukkapuram onnaa train panradhaala forgetting illa.** Task A-ku train panni, apram task B-ku train pannaa, adhu perumbaalum A-a marakkum. Ovvonnaiyum thaniyaa train panni merge pannaa adhu varaadhu.
- **GPUs thevai illa.** Simple merges weights-oda arithmetic, oru saadhaarana computer-la odum.
- **Chinna deployments.** Neraya-vatrukku badhila oru model, phones, laptops, memory kammiyaa irukkura vera devices-la, illa data device-a vittu veliya pogakkoodaadha idathula udhavum.

Merging, **ensemble**-la irundhu vera. Ensemble neraya models-a odi adhoda answers-a serkkum, adhu oru request-ku neraya calls selavu aakkum. Merge weights-a oru thadavai serkkum; apram neenga normal cost-la oru model-a serve pannuveenga.

Merging innum ilamaiyaana, paadhi experimental vishayam. Open model leaderboards-la neraya top entries merges thaan, aana results maarum, adhanaala ovvoru merge-aiyum test panna vendiya pudhu model-aa paarunga.

```flow
title: Fine-tune panna models-a merge panradhu
Base model -> Task A-ku fine-tune | adapter illa full
Base model -> Task B-ku fine-tune
Task A-ku fine-tune -> Task vector A | A - base
Task B-ku fine-tune -> Task vector B | B - base
Task vector A -> Combine | average, SLERP, TIES, DARE
Task vector B -> Combine
Combine -> Merge aana model
Merge aana model -> Ovvoru task, general skills, safety-a test pannunga
```

## Idhu eppadi work aagudhu

**Task vectors.** Fine-tune panna model-oda weights-la irundhu base model-oda weights-a kazhichaa, ungalukku oru **task vector** kidaikkum: fine-tuning panna maatram. LoRA-la, adapter-ae mukkiyamaa task vector thaan. Task vectors-a base-oda serthaa skills serum, onnai kazhichaa oru behaviour-a kuraikkalaam, researchers idhai vendaadha abilities-a, biases-a balaheenam aakka use pannirukkaanga.

**Linear combination.** Romba simple merge, weights-oda illa task vectors-oda oru weighted average. Adhu aachariyamaa nallaa work aagum, especially orae base-la irundhu vandha models-ku. "Model soups" orae model-oda neraya fine-tune panna versions-a average panni, kooduthal running cost illaama accuracy-a yerthuchu. Weights oru model-a innoru model-a vida adhigama count aaga vaikkum.

**SLERP.** Spherical linear interpolation rendu models-a oru neraana kodu illaama valaindha paadhaila blend pannum, adhu oru saadhaarana average-a vida ovvoru model-oda gunatha nallaa kaapaatthalaam. 0-la irundhu 1 varaikkum oru interpolation factor edhu model adhigam-nu decide pannum. Oru thadavaiku rendu models-a merge pannum; moonavadhai thirumba thirumba seiya merge pannalaam.

**TIES-um DARE-um.** Fine-tuning kiratta ella weights-aiyum maathum, aana perumbaalaana maatrangal romba chinnadhu, konjam thaan serkkum. Vera vera tasks-oda andha chinna maatrangal merge aagumbodhu mothikkalaam. Rendu methods-um mudhalla ovvoru task vector-aiyum **prune** pannum, mukkiyamaana maatrangala mattum vechukkum:

- **TIES** romba periya maatrangala vechukkum, apram merge-ku munnaadi, tasks oru weight-a edhirthisaila thallumbodhu varra conflicts-a sari pannum.
- **DARE** perumbaalaana maatrangala random-aa vittuttu, migirathai adhoda motha effect-a kaappaatha rescale pannum.

Rendum perumbaalum plain averaging-a vida theliva nalla merges-a tharum, neraya models-a merge pannum podhu adhoda advantage adhigam aagum.

**Layer stacking.** Weights-a kalakkaama, vera vera models-oda layers-la irundhu oru model-a build pannunga, sila neram "frankenmerge"-nu solluvaanga. Chinna models-la irundhu periya model-a seiyalaam (oru team 7B model-oda rendu copies-la irundhu 10.7B model-a build pannaanga), irukkura oru model-la irundhu mixture-of-experts model-a aarambikkura oru vazhi. Idhukku nallaa work aaga perumbaalum innum training thevai.

**Concatenation** adapters-a pakkam pakkamaa serkkum. Ella parameters-aiyum vechukkum, adhanaala memory-a save pannaadhu, worth aagadhu.

PEFT-oda rendu LoRA adapters-a merge panradhu ippadi irukkum:

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("base-model-id")
model = PeftModel.from_pretrained(base, "adapters/complaints", adapter_name="complaints")
model.load_adapter("adapters/replies", adapter_name="replies")

# Combine into a new adapter; TIES keeps the strongest changes (density) and resolves conflicts.
model.add_weighted_adapter(
    adapters=["complaints", "replies"], weights=[1.0, 1.0],
    adapter_name="merged", combination_type="ties", density=0.3,
)
model.set_adapter("merged")
```

Muzhu models-ku, open-source tool mergekit oru chinna configuration file-la irundhu merges-a odum.

| Method | Eppadi combine pannum | Strengths | Enna paakkanum |
| --- | --- | --- | --- |
| Weighted average | Weights illa task vectors-a average pannum | Simple, perumbaalum nalladhu | Tasks mothalaam |
| SLERP | Rendu models-a oru valaivil blend pannum | Rendin smooth blend | Oru thadavaiku rendu models |
| TIES | Periya maatrangala vechukkum, sign conflicts-a sari pannum | Neraya tasks-ku nalladhu | Density setting-a tune pannanum |
| DARE | Perumbaalaana maatrangala random-aa vittu, rescale pannum | Robust, apply panna simple | Randomness; oru thadavai-kku mela test pannunga |
| Layer stacking | Layers-a serkkum, size valarkkalaam | Upscale illa MoE build pannalaam | Perumbaalum innum training thevai |

**Unga browser-la try pannunga.** Rendu task vectors-a average pannunga, apram periya maatrangala mattum vechukkura TIES-style merge-a try pannunga.

```python
import numpy as np

rng = np.random.default_rng(7)
base = rng.normal(size=10)
task_a = np.where(rng.random(10) < 0.3, rng.normal(0, 1, 10), rng.normal(0, 0.05, 10))
task_b = np.where(rng.random(10) < 0.3, rng.normal(0, 1, 10), rng.normal(0, 0.05, 10))

average = base + (task_a + task_b) / 2
def trim(v, keep=0.3):
    cut = np.quantile(np.abs(v), 1 - keep)
    return np.where(np.abs(v) >= cut, v, 0)
ties = base + trim(task_a) + trim(task_b)
print("average change:", (average - base).round(2))
print("TIES change:   ", (ties - base).round(2))
```

## Oru worked example

Mumbai-la oru bank-ku orae open 8B base model-la moonu LoRA adapters irukku: complaint classification, English-layum Hindi-layum reply drafting, KYC field extraction. Internet illaadha branch laptops-la oru model-a vekka virumburaanga.

Moonu merges-a try panni, ovvoru task-oda sonda test set-layum test pannuraanga:

| Model | Complaint accuracy | Reply quality (reviewer score, 5-la) | KYC extraction accuracy |
| --- | --- | --- | --- |
| Thaniyaana adapters (target) | 93% | 4.3 | 96% |
| Moonu-um serntha weighted average | 89% | 4.0 | 84% |
| TIES, density 0.3 | 92% | 4.2 | 88% |
| Complaints-um replies-um TIES; KYC thaniyaa | 92% | 4.2 | 96% |

Numbers udhaaranathukkaaga. Romba thulliyamaana task-aana extraction, ovvoru muzhu merge-layum adhigam paadhikkapattudhu. Team complaints-kum replies-kum merge aana model-a ship pannudhu, KYC adapter-a thaniyaa vechukkittu, oru document scan aagumbodhu mattum load pannudhu. Rendum laptops-la porundhum. Avanga safety, refusal checks-aiyum thirumba odudhu, yen-na merging, adapters-la edhuvum train aagaadha behaviour-a balaheenam aakkalaam.

## Podhuvaa panra thappugal

- **Vera vera bases-la irundhu models-a merge panradhu**, risks-a purinjukkaama. Results perumbaalum mosamaa irukkum.
- **Oru task-a mattum test panradhu.** Oru merge amaidhiyaa innoru task-ayum general abilities-aiyum paadhikkalaam.
- **Safety checks-a thaandradhu.** Merge-ku apram refusal, safety behaviour balaheenam aagalaam.
- **Leaderboard merges-a kannai moodikkittu nambradhu.** Sila benchmarks-ku tune aagirukkum; ungaloda sonda data-la test pannunga.
- **Memory-a save panna concatenation use panradhu.** Adhu panaadhu.
- **Licence-a marandhuduradhu.** Oru merge adhula irukkura ovvoru model-oda licence terms-aiyum inherit pannum.

## Eppo merge pannakoodaadhu

- **High precision thevaippadura tasks**, thaniyaana adapters-aa vechukkalaam.
- **Ovvoru task-kum podhumaana data-oda oru nalla multi-task fine-tune-a ungalaala panna mudiyum.**
- **Neraya adapters-a serve panradhu already sila-vu**, neraya servers adhai efficient-aa support pannum.
- **Models vera vera base models-la irundhu varudhu.**

## Demo-la irundhu production-ku

- **Merges-a models maadhiri version pannunga**: inputs, method, weights, settings oru config file-la.
- **Thaniyaana adapters-a** fallback-kum oppidavum vechukkunga.
- **Ovvoru release-kum munnaadi ovvoru task-aiyum, serthu general, safety checks-aiyum test pannunga.**
- **Edhaavadhu input model maarina thirumba merge panni**, thirumba test pannunga.
