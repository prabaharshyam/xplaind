## Idhu enna

Useful-aana Python-la perumbaalum Python-a irundhu varaadhu. Matravanga ezhudhina **packages**-la irundhu varum: web APIs-ku `requests`, tables-ku `pandas`, arrays-ku `numpy`, AI model providers-oda official SDKs. Adha Python-oda package installer-aana **pip** vachu install pannuveenga.

Idhula oru problem varum. Project A-ku pandas version 2.1 venum; project B-ku 2.3. Rendum ore idathula install aanaa, onnu odanjudum. Idhukku solution **virtual environment**: oru project-ku install aana packages-oda private folder.

```flow
title: Environments illaama
System Python | project B-kaaga pandas 2.3-ku upgrade aachu -> Project A odaiyudhu
```

```flow
title: Environments-oda: ovvoru project-kum thaniyaa, edhuvum clash aagaadhu
project-a/.venv | pandas 2.1, requests 2.32 -> Project A work aagudhu
project-b/.venv | pandas 2.3, anthropic SDK -> Project B work aagudhu
```

**requirements.txt** file oru project-ku thevaiyaana packages-aiyum versions-aiyum list pannum, adhanaala yaarum, entha machine-layum, adhe environment-a thirumba create pannalaam.

Indha lesson-la Pune-la oru student Nikhil-a follow pannuvom; avanga classmate-oda project-a run panni, thanga projects ore onnai onnu odaikkaama paathukuraanga. Mudiyum podhu entha project-kum, adhoda requirements file-la irundhu, rendu nimishathukkulla oru fresh environment set up panna mudiyum.

## Idhu eppadi work aagudhu

### Environment-a create panni activate pannunga

Unga project folder-kulla:

```bash
python -m venv .venv
```

Apram adha activate pannunga:

| System | Command |
| --- | --- |
| Windows (Command Prompt illa PowerShell) | `.venv\Scripts\activate` |
| Mac illa Linux | `source .venv/bin/activate` |

Ungaloda terminal prompt ippo `(.venv)`-oda aarambikkum. Neenga install panra ellaam indha project-ku mattum pogum. Veliya vara `deactivate` type pannunga.

### Packages install pannunga

```bash
pip install requests pandas
pip list                       # what is installed in this environment
pip show pandas                # details and version of one package
```

### Install pannadhai record pannunga

```bash
pip freeze > requirements.txt
```

`pip freeze` ovvoru package-aiyum adhoda **exact** version-oda print pannum, example `pandas==2.3.1`, adhanaala matravangalum adhe install pannuvaanga. Requirements file ippadi irukkum:

```text
# shortened: pip freeze also lists every sub-dependency
certifi==2025.8.3
numpy==2.3.2
pandas==2.3.1
requests==2.32.5
```

### Vera machine-la thirumba create panradhu

Oru project-a clone panni, oru fresh environment create panni activate panni, apram:

```bash
pip install -r requirements.txt
```

### Version specifiers

Oru requirements file exact-aa pin pannalaam illa oru range allow pannalaam:

| Line | Artham |
| --- | --- |
| `pandas==2.3.1` | Exact-aa indha version: romba reproducible |
| `pandas>=2.2` | Indha version illa pudhusu: pudhu major version vandhaa odayalaam |
| `pandas>=2.2,<3` | 2.2-la irundhu entha 2.x-um: libraries-ku common compromise |
| `pandas` | Innaikku pudhusa edhu irukko adhu: matravanga run panra projects-la thavirunga |

Neenga deploy panna pora oru application-ku, exact versions-a pin pannunga, adhanaala server neenga test panna adhaiyae vaangum. Matravanga install panra oru library-ku, sensible ranges allow pannunga, adhanaala avanga matra packages-oda clash aagaadhu. Upgrade panrappo, vendunnae upgrade pannunga: version-a maathi, tests-a run panni, apram pudhu file-a commit pannunga.

### AI velaikku packages

AI projects konjam habits-a add pannum. Anthropic, OpenAI-oda official Python packages maadhiri model provider SDKs vegamaa maarum, adhanaala adha pin panni, upgrade panradhukku munnaadi release notes-a padinga. Indha SDKs ungaloda API key-a `ANTHROPIC_API_KEY` maadhiri environment variable-la irundhu padikkum; adha shell-la illa `.gitignore`-la list aana `.env` file-la vainga, code-la vaikkaadheenga. PyTorch maadhiri periya packages nooru megabytes irukkalaam, unga computer-oda graphics card-a sarndhirukkum, adhanaala plain `pip install`-ku badhila, adhoda install instructions-a follow pannunga.

### Git-la irundhu veliya vainga

`.venv/`-a `.gitignore`-la serthu, `requirements.txt`-a commit pannunga. Environments nooru megabytes periyadhu, oru machine-oda operating system-ku katti irukkum.

### Unga editor-oda interpreter-a select pannunga

VS Code-la `.venv` Python interpreter-a select pannunga (Command Palette, "Python: Select Interpreter"). Illaina editor ungaloda terminal-la irundhu vera Python use panni, packages missing-nu sollum.

### Pudhu tools

| Tool | Enna add pannum |
| --- | --- |
| `pip`, `venv` | Built in; aarambikka podhum |
| `uv` | Romba vegamaana installs, environment creation, lock file-oda |
| Poetry | Lock file-oda dependency management, packaging |

**Lock files** neenga peyar sonna packages-a mattum illa, ovvoru sub-dependency-yaiyum pin pannum. Ideas maaraadhu: oru project-ku oru environment, versions oru file-la record.

## Oru worked example

Pune-la oru student Nikhil, weather API-a call panni Indian cities-oda temperatures-a plot panra oru classmate-oda project-a clone pannuraanga. Avanga adha run pannuraanga:

```text
$ python main.py
ModuleNotFoundError: No module named 'requests'
```

Project-ku avangakitta illaadha packages thevai. Oru environment create panni, project-oda file-la irundhu install pannuraanga:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Work aagudhu, Chennai, Delhi, Shimla temperatures-oda chart varudhu.

Apram `matplotlib` thevai padra oru feature add pannuraanga. Adha install panni, `pip freeze > requirements.txt` run panni, update aana file-a commit pannuraanga. Avanga classmate pull panni, `pip install -r requirements.txt` run panni, exact adhe version-a vaanguraanga.

| Munnaadi | Apram |
| --- | --- |
| Ellaam system Python-la install aachu | Oru project-ku oru `.venv` |
| Oru assignment-kaaga pandas upgrade pannaa matrodhu odanjudhu | Projects ore onnai onnu affect panna mudiyaadhu |
| "En machine-la work aagudhu" | `requirements.txt` adhe setup-a entha idathulayum thirumba create pannum |
| `.venv` commit pannunappo 400 MB repositories | `.gitignore`-la `.venv/`; sinna text file mattum share aagum |

Oru maadham munnaadi, Nikhil ellaathayum system Python-la install pannirundhaanga, oru assignment-kaaga pandas upgrade pannaa matrodhu odanjudhu. Thaniya environments andha problem-a mudichchudhu.

## Podhuvaa panra thappugal

- **System Python-la install panradhu.** Appo projects ore onnai onnu disturb pannum.
- **Environment-a activate panna marandhudradhu.** Packages thappaana idathukku pogum, illa "missing"-aa theriyum. Prompt-la `(.venv)` irukka-nu paarunga.
- **`.venv`-a Git-la commit panradhu.** `requirements.txt`-a commit pannunga.
- **Version pins illai.** Pinnaadi varra oru release unga code-a odaikkalaam; `pip freeze` exact versions-a record pannum.
- **Editor vera interpreter use panradhu.** Editor-la project-oda `.venv`-a select pannunga.
- **`pip`-um `python`-um vera vera idathula irundhu run panradhu.** Rendum match aaga `python -m pip install ...` use pannunga.

## Practice pannunga

Python Packaging User Guide-oda pip, virtual environments page-a padinga, keezha link irukku.

1. **Create.** Thani virtual environment-oda oru project folder-a create panni, `requests` install pannunga.
2. **Rebuild.** `requirements.txt`-a save panni, environment-a delete panni, thirumba create panni, file-la irundhu thirumba install pannunga.
3. **Share.** `.venv/`-a `.gitignore`-la serthu, adhu illaama project-a GitHub-ku push pannunga.

**Mudinjadhu-nu eppo sollalaam:** Entha project-kum, adhoda requirements file-la irundhu, rendu nimishathukkulla oru fresh environment set up panna mudiyum.
