## Idhu enna

Oru **chat assistant** oru website-la chat window-la illa oru messaging app-la customers-oda kelvigalukku badhil solludhu. Nalla build panna adhu:

- podhuvaana knowledge-a vida, business-oda sondha information-la irundhu (FAQs, price lists, policies, timings) badhil solum;
- business systems-oda connections vazhiyaa common tasks-a (order status, appointment booking) handle pannum;
- adhaala mudiyaadhappo illa customer ketta, **oru aal-kitta hand-over pannum**;
- privacy-yum messaging platform-oda rules-aiyum madhikkum.

WhatsApp-la, businesses **WhatsApp Business Platform** (API)-a, perumbaalum oru provider vazhiyaa use pannuvaanga. Adhukku rules irukku: customers opt in pannanum, 24-hour customer-service window-ku veliya business aarambikkura messages-ku mundhaiye approve aana templates thevai, messages WhatsApp-oda pricing model padi charge aagum.

```flow
WhatsApp-la customer -> Provider webhook -> Assistant
Assistant -> Retrieval | FAQ sheet, price list
Assistant -> Tools | order status, booking, confirmation-oda
Assistant -> Oru aal-kitta hand-over | summary-oda
Retrieval -> Customer-oda language-la reply
Tools -> Customer-oda language-la reply
```

Indha lesson Madurai-la oru multi-specialty clinic-a follow pannum; adhoda reception-la WhatsApp messages vellam maadhiri varudhu.

## Idhu eppadi work aagudhu

**Knowledge.** Business-oda FAQs, price list, policies, timings-a serunga. Business update panna mudiyura oru document illa sheet-la vainga. Badhilgal indha sources-la irundhu varanum-nu retrieval use pannunga, assistant-ku theriyaadhappo theriyaadhunu solla sollunga.

**Actions.** Order status illa booking-ku, tools-a connect pannunga: oru order-a number-um phone-um vachchu paarkka, slots check panna, oru booking create panna. Act pannradhukku munnaadi, details-a customer-kitta thirumba confirm pannunga.

**Hand-over.** Edhu neram-layum "oru aal-kitta pesanum" option kudunga. Complaints, payment disputes, medical illa legal kelvigal, kovamaana customers, illa rendu thadavai failed badhil-ku apram thaanaave hand-over pannunga. Andha aal marubadi kekka vendaam-nu conversation-um oru summary-yum anuppunga, eppo badhil varum-nu customer-ku sollunga.

**WhatsApp rules.**

- Business-la irundhu messages vaanga customers opt in pannirukkanum.
- Customer-oda kadaisi message-ku 24 mani neraththukkulla, business sudhandhiramaa reply pannalaam. Adhukku apram, approve aana template messages mattum thaan oru conversation-a aarambikkalaam.
- Edha vikkalaam illa promote pannalaam-nu WhatsApp-oda commerce, business policies-a follow pannunga.

**Language-um tone-um.** Mudiyura idathula customer-oda language-la badhil sollunga; Hindi, Tamil, Hinglish, unga customers use panra matha languages-a test pannunga. Messages-a surukkamaa vainga; chat email illa.

**Privacy.** Task-ku thevaiyaanadhai mattum collect pannunga; muzhu card numbers-a illa passwords-a kekkaadheenga; DPDP consent, retention rules-a follow pannunga; logs-la personal data-va mask pannunga.

**Measure.** Oru aal illaama theerndha conversations-oda share, hand-over rate-um reasons-um, customer ratings, thappaana badhil reports.

**Assistant edhellaam handle pannum, edha eppovum pannaadhu:**

| Request vagai | Assistant-oda velai | Example |
| --- | --- | --- |
| Information | Business-oda sources-la irundhu badhil sollum | Timings, fees, doctor schedules |
| Simple actions | Oru tool use pannum, act pannradhukku munnaadi confirm pannum | Appointment book panradhu, order status paakkuradhu |
| Sensitive illa complex | Summary-oda hand-over pannum | Complaints, refunds, disputes |
| Professional advice | Eppovum illa; hand-over | Medical, legal, financial kelvigal |
| Emergencies | Fixed safe message-um hand-over-um | "Engal emergency number-ku call pannunga..." |

**Message costs.** WhatsApp businesses-ku adhoda pricing model padi charge pannum; adhu message vagai-yaiyum naatai-yaiyum poruthu irukkum. Ippo irukkura pricing page-a paarunga, client-oda running-cost estimate-la neenga paartha date-oda serunga.

**Code-la oru WhatsApp Cloud API webhook.** Meta unga URL-a oru thadavai verify panna call pannum, apram ovvoru incoming message-a post pannum. Oru minimal FastAPI version; API version-kum fields-kum Meta-oda ippo irukkura docs-a paarunga:

```python
import hashlib, hmac, os
import httpx
from fastapi import FastAPI, Request, Response, BackgroundTasks, HTTPException

app = FastAPI()
VERIFY_TOKEN = os.environ["WA_VERIFY_TOKEN"]
APP_SECRET = os.environ["WA_APP_SECRET"].encode()
TOKEN, PHONE_ID = os.environ["WA_TOKEN"], os.environ["WA_PHONE_NUMBER_ID"]
SEEN = set()                                     # use Redis or a table in production

@app.get("/whatsapp")
def verify(request: Request):
    q = request.query_params
    if q.get("hub.mode") == "subscribe" and q.get("hub.verify_token") == VERIFY_TOKEN:
        return Response(q.get("hub.challenge"))
    raise HTTPException(status_code=403)

@app.post("/whatsapp")
async def receive(request: Request, tasks: BackgroundTasks):
    raw = await request.body()
    sig = request.headers.get("X-Hub-Signature-256", "")
    expected = "sha256=" + hmac.new(APP_SECRET, raw, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(sig, expected):
        raise HTTPException(status_code=401)
    for entry in (await request.json()).get("entry", []):
        for change in entry.get("changes", []):
            for msg in change["value"].get("messages", []):
                if msg["id"] in SEEN:
                    continue                     # a repeat delivery
                SEEN.add(msg["id"])
                if msg.get("type") == "text":
                    tasks.add_task(handle, msg["from"], msg["text"]["body"])
    return {"ok": True}                          # reply fast; work happens in the background

async def handle(wa_id, text):
    answer = assistant_reply(wa_id, text)        # retrieval, tools and hand-over rules
    async with httpx.AsyncClient() as http:
        await http.post(f"https://graph.facebook.com/v21.0/{PHONE_ID}/messages",
                        headers={"Authorization": f"Bearer {TOKEN}"},
                        json={"messaging_product": "whatsapp", "to": wa_id,
                              "type": "text", "text": {"body": answer[:4000]}})
```

Webhook-ku konja seconds-kulla badhil sollunga, model call-a background-la pannunga, illannaa WhatsApp retry pannalaam, duplicates-a paapeenga.

**Hand-over rules prompt-la mattum illa, code-lum.** Model-a call panradhukku munnaadi, message-layum ippo varaikkum irundha conversation-layum irundhu mudivu pannunga:

```python
HANDOVER_WORDS = {"complaint", "refund", "lawyer", "consumer court", "chargeback"}

def needs_person(text, state):
    t = text.lower()
    return (any(w in t for w in HANDOVER_WORDS)
            or state["failed_answers"] >= 2
            or state.get("asked_for_person"))
```

Adhu true-nu thirumbinaa, andha chat-ku bot-a niruthunga, conversation-ayum summary-yaiyum staff inbox-la post pannunga, eppo badhil varum-nu customer-ku sollunga.

**Code-la 24-hour window.** Ovvoru customer-oda kadaisi message-oda neraththa store pannunga. Anuppuradhukku munnaadi, adhu 24 mani neraththukkulla-nu check pannunga; illannaa free text-ku badhila approve aana template anuppunga, illa anuppavae vendaam.

**Grounded-aa irukkiradhu.** Retrieval-oda business-oda sondha sheet illa documents-la irundhu badhil sollunga, logs-la source-a serunga, ethuvum sambandhamaa kidaikkalaannaa maruthidunga: "Enkitta andha information illa; team badhil sollunga-nu kettirukken." WhatsApp-la anuppina thappaana oru price illa timing screenshot edukkappattu share aagum.

## Podhuvaa panra thappugal

- **Podhu knowledge-la irundhu badhil sollradhu.** Badhilgala business-oda sondha information-la grounded-aa vainga.
- **Oru aal-kitta pogura easy vazhi illaadhadhu.** Vedhanaipadra customers poiduvaanga, public-la complain pannuvaanga.
- **Platform rules-a udaikkiradhu.** Kekkaama anuppura messages-um approve aagaadha templates-um numbers-a block pannum.
- **Medical, legal, financial advice kudukkiradhu.** Hand-over pannunga.
- **Pazhaya information.** Source-a update panradhai yaaroda dhinasari velaila serunga.

- **Neelamaana, email maadhiri replies.** Chat users phones-la padikkuvaanga; badhilgala konja varigala vainga, "innum details venuma?"-nu kelunga.
- **Knowledge sheet-ku owner illaadhadhu.** Timings, prices, leave naatkala update panravar yaar, eppo-nu peyar solli vainga.
- **Webhook-la signature check-a thavirkkiradhu.**
- **Webhook-ku reply pannradhukku munnaadi mellaana velai seiyaradhu**, adhu retries-kum duplicate badhilgalukkum kaaranam.
- **24-hour window-ku veliya free-text messages.** Adhu fail aagum illa policy-a udaikkum; approve aana templates use pannunga.

## Chat assistant worth illaadha podhu

- **Dhinam romba kammiyaana messages**: saved quick replies-oda oru aal selavu kammi, anbaanadhum kooda.
- **Perumbaalaana kelvigalukku judgement thevai**, custom quotes illa complaints maadhiri.
- **Business thanoda information-a update-aa vachchukka mudiyaadhu**: bot pazhaya prices-um timings-aiyum thirumba solum.
- **Customers perumbaalum call pannuvaanga**, message pannaadhu: voice assistant illa nalla IVR poruthamaa irukkum.

## Demo-la irundhu production-ku

- **Signatures-a verify panni, deduplicate pannunga** ovvoru incoming message-aiyum.
- **Knowledge sheet-a business-ae vachchukkattum**, ovvoru entry-yilum oru date-oda, vaaram oru check-oda.
- **Ovvoru conversation-aiyum log pannunga**, sources, call panna tools, hand-overs, ratings-oda, masked-aa.
- **Hand-over reasons-a vaaram oru thadavai paarunga**, romba common badhil-a sheet-la serunga.
- **Messaging costs-a budget pannunga**, ippo irukkura WhatsApp pricing-la irundhu, neenga paartha date-oda.
