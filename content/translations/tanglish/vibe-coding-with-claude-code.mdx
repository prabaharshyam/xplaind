## Idhu enna

**Vibe coding**-na, perumbaalaana code-a neengalae type pannaama, enna vennum-nu AI coding agent-kitta describe panni, adhoda velaiya steer panni check panni software build panradhu. Indha term 2025-la romba pochu, ippo neraya founders, product managers, analysts, students avanga first tools-a ippadi thaan build panraanga.

**Claude Code** Anthropic-oda coding agent. Code-a mattum suggest panra chatbot maadhiri illa, idhu unga project-lae velai seiyum: files-a padikkum, ezhudhum, edit pannum, tests, builds maadhiri commands-a run pannum, errors-a paarkkum, thirumba try pannum. Idha terminal-la, VS Code illa JetBrains-kulla, Claude desktop app-la, illa claude.ai-la browser-la use pannalaam.

Skill-na prompts type panradhu illa. Oru nalla engineering lead pudhu team member-oda use panra adhae skill thaan: goal-a clear-aa explain pannunga, velaiya steps-aa piringa, vandhadha review pannunga, enna maathanum-nu sollunga.

```flow
title: Chinna steps-la thirumba thirumba pannunga; ovvoru working step-kum apram commit pannunga
Neenga: oru idea, oru spec -> Claude Code plan pannum
Claude Code plan pannum -[neenga approve pannuveenga]-> Claude Code files-a edit pannum
Claude Code files-a edit pannum -> Claude Code tests-um app-um run pannum
Claude Code tests-um app-um run pannum -> Changes-oda summary, errors, output
Changes-oda summary, errors, output -> Neenga diff-a review panni, try panni, feedback kudupeenga
Neenga diff-a review panni, try panni, feedback kudupeenga -> Neenga: oru idea, oru spec
```

## Idhu eppadi work aagudhu

**1. Set up.** Official docs-la irundhu Claude Code install pannunga, oru empty folder-la terminal open panni `claude` run pannunga. Idhukku Claude subscription illa API account thevai. Folder-a oru git repository aakkunga, appo ovvoru change-um paarkkalaam, undo pannalaam.

**2. Chinna spec ezhudhunga.** Code-ku munnaadi, arai page ezhudhunga: app enna pannum, yaar use pannuvaanga, mukkiyamaana moonu-la irundhu anju features, phone-la eppadi irukkanum, edhellaam scope-la illa. Adha Claude-a padikka sollitu, ungaluku kelvigal kekka sollunga. Indha oru palakkam, perumbaalaana mosamaana results-a neekidum.

**3. CLAUDE.md vechu memory kudunga.** Claude ovvoru session aarambikkum podhum `CLAUDE.md`-a padikkum. Adhula stack, app-a eppadi run, test panradhu, unga rules-a podunga, "mobile first", "no paid APIs", "never commit secrets" maadhiri. `/init` vechu Claude-a first version ezhudha sollalaam.

**4. Plan, apram build, chinna steps-la.** Modhalla plan kelunga (Claude Code-la plan mode irukku, adhu padichu propose mattum pannum). Approve illa correct pannunga. Apram oru time-la oru feature build pannunga: layout, apram data, apram calculations, apram saving, apram deployment.

**5. Ovvoru change-aiyum review pannunga.** Summary-a padinga, diff-a skim pannunga. App-a neengalae run pannunga. Edhaavadhu vithyaasamaa therinjaa "yen ippadi pannina?"-nu kelunga. Oru step work aanaa commit pannunga.

**6. Adhuvae test panni fix pannattum.** Mukkiyamaana logic-ku tests ezhudhi, run panna sollunga. Edhaavadhu udanjaa error-a paste pannunga illa exact steps-a describe pannunga; evidence irundha bug-a trace panradhula adhu romba nalla.

| Stage | Neenga enna solveenga | Enna check pannanum |
|---|---|---|
| Spec | "Read SPEC.md and ask me anything unclear" | Adhoda kelvigal, adhu purinjukkitta-nu kaattum |
| Plan | "Plan the first feature; don't write code yet" | Edhellaam files touch aagum, approach, extra edhuvum illa |
| Build | "Implement step 1 of the plan" | Run aagudhu; diff chinnadhaa, padikkaraa maadhiri irukku |
| Test | "Add tests for the split calculation and run them" | Tests edge cases-a cover pannudhu, happy path mattum illa |
| Fix | "On 360 px wide the table overflows. Fix it" | Fix-um, vera edhuvum maaralanga-nu check pannunga |
| Ship | "Set up deployment to Vercel and explain the steps" | Code-la secrets illa; environment variables use aagudhu |

## Oru example

Nisha Pune-la moonu friends-oda oru flat share panraanga, WhatsApp chat-la bills-a split panni sali aagiduchu. Avanga oru product designer, developer illa.

Avanga `SPEC.md` ezhudhuraanga: "A one-page web app. Add a bill with who paid and who shares it. Show who owes whom, settling with the fewest payments. Works on a phone. Saves in the browser; no login. Rupees." Pudhu folder-la `claude` run panni, spec-a padichu kelvigal kekka solluraanga. Bills-a samamaa illaama split pannalaamaa, payments-ku UPI link vennumaa-nu Claude kekkudhu. Samamaa illaadha split apram, UPI links venum-nu solluraanga.

Plan kekkuraanga, kidaikkudhu: oru Next.js app, oru form, bills-oda list, oru settlement function, local storage, settlement maths-ku tests. Step onnu mattum approve panraanga: page-um form-um. Run aagudhu. Commit pannuraanga.

Moonaavadhu step settlement maths. Tests-a modhalla ezhudha solluraanga, avangalukku answer therinja oru case-oda: moonu friends, onnu groceries-ku ₹3,000 kuduthaanga. Oru test fail aagudhu, yenna rounding-naala ₹1 kanakku thappudhu. Claude kaaranatha explain panni, remainder-a paid pannavangalukku kuduthu fix pannudhu. Idha kannaala avanga kandupidichirukkave maattaanga.

Maalai Vercel-ku deployment set up panna Claude-a solluraanga. Adutha kaalai avanga flatmates app-a use panraanga. Mothha neram: sumaar aindhu maninerathu, perumbaalaanadhu enna vennum-nu decide panradhula pochu.

## Podhuvaa panra thappugal

**Motha app-aiyum oru message-la kekkradhu.** Periya, test pannaadha kuzhappam kidaikkum. Oru time-la oru feature kelunga.

**Spec-a skip panradhu.** Illa-na Claude guess pannum, adhu mela build pannina apram thaan thappaana guess-nu theriyum.

**Purinjukkaadha changes-a accept panradhu.** Explanation kelunga. Code-um, adhoda bugs-um, security-yum ungaludhu.

**Git illama irukkradhu.** Commits illa-na enna maariduchu-nu paarkkavum, thirumba pogavum mudiyaadhu. Ovvoru working step-ku apramum commit pannunga.

**API keys-a code-la podradhu.** Secrets-a environment variables-layum git ignore panra `.env` file-layum vachchukonga. Push pannradhukku munnaadi secrets irukkaa-nu check panna Claude-a sollunga.

**Mudiyaadha "fix it" loops.** Ore bug moonu muyarchila pogala-na, nirutthunga. Exact steps-a, edhirpaartha, nadandha result-a describe panni, edhaiyum maatraadha munnaadi kaaranatha explain panna Claude-a sollunga.
