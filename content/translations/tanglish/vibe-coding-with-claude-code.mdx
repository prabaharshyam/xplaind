## Idhu enna

**Vibe coding**-naa code-a neengaley type panradhukku badhilaa, ungalukku enna venum-nu oru AI agent-kitta vivarichu software build panradhu. Nalla therinja AI researcher Andrej Karpathy, February 2025-la oru post-la indha vaarthaiya uruvaakkinaaru. Vibes-kku vittukoduthu, AI ezhudhuradha accept panni, code-a kittathatta paarkkaamaley irukkura oru style-a avaru vivarichaaru. Indha phrase evvalavu vegamaa paravuchu-nnaa, Collins Dictionary "vibe coding"-a 2025-oda Word of the Year-aa aakkiduchu.

Andha original, review pannaadha style-kkum oru idam irukku. Oru weekend prototype-kku, unga sondha laptop-la oru one-off script-kku, allathu thookkippodap pora oru demo-kku adhu paravaayilla. Aanaa mathavangaloda data, panam, passwords allathu private notes vachirukkura edhukkum adhu risky, yennaa code enna pannudhu-nnu yaarumey check pannala. **Indha lesson review panra version-a katthukudukkudhu**: perumbaalaana code-a Claude ezhudhum; goal-a set panradhu, ovvoru step-aiyum check panradhu, edhu ship aaganum-nu mudivu panradhu neenga. Oru interviewer "vibe coding"-nu sonnaa, avanga endha arthathula solraanga-nnu kettu therinjukkonga.

**Claude Code** Anthropic-oda coding agent. Oru **agent**-naa text replies mattum illaama, oru loop-la actions edukkura AI. Oru chatbot neenga copy panradhukku code-a suggest pannum. Claude Code unga project-kkulleye act pannum: files-a padikkum, ezhudhum, edit pannum, tests, builds maadhiri commands run pannum, errors-a padichu marubadi try pannum. Idha terminal-la, VS Code allathu oru JetBrains IDE-la, Claude desktop app-la, allathu claude.ai/code-la browser-laye use pannalaam.

Inga skill-naa buddhisaalithanamaana vaarthaigal illa. Oru nalla team lead, vegamaa velai seiyura oru pudhu colleague kooda use panra adhe skill dhaan: goal-a explain panradhu, velaiya chinna steps-aa pirikkiradhu, thirumba varradha review panradhu, enna maathanum-nu sariyaa solradhu.

```flow
title: Ovvoru feature-kkum oru loop; velai seiyura ovvoru step-kku appuramum commit
Neenga: oru spec, oru feature -> Claude plan mode-la plan pannum
Claude plan mode-la plan pannum -[neenga approve allathu trim panreenga]-> Claude files-a edit pannum
Claude files-a edit pannum -> Claude tests-aiyum app-aiyum run pannum
Claude tests-aiyum app-aiyum run pannum -> Neenga diff-a padichu app-a try panreenga
Neenga diff-a padichu app-a try panreenga -[work aagudhu]-> Commit, adutha feature
Neenga diff-a padichu app-a try panreenga -[thappaa irukku]-> Precise feedback allathu rewind
Precise feedback allathu rewind -> Claude plan mode-la plan pannum
```

## Idhu eppadi work aagudhu

### 1. Set up pannunga, cost-a therinjukkonga

Official overview page-la irukkura command-a vachu Claude Code-a install pannunga, appuram oru pudhu folder-la terminal-a thirandhu `claude` run pannunga. Mudhal thadavai login panna sollum. Adhe folder-la `git init`-um run pannunga, appo ovvoru change-aiyum paarkkavum undo pannavum mudiyum. Neenga terminal-a use pannadhey illa-nnaa, docs-la oru chinna terminal guide irukku.

Ungalukku oru paid Claude plan allathu Claude Console-la oru API account venum. Claude Code Free plan-la kidaiyaadhu. Anthropic-oda pricing page-la 28 November 2026 annaikku check pannappo irundha prices:

| Plan | US dollars-la vilai (28 Nov 2026 annaikku check pannadhu) | Usage |
|---|---|---|
| Free | $0 | Chat mattum; Claude Code illa |
| Pro | Maasathukku $20, allathu varushathukku bill pannaa maasathukku $17 (munnaadiye $200) | Free-a vida adhigam, oru 5-hour limit-um oru weekly limit-um irukku |
| Max | Maasathukku $100 | Pro usage-oda 5x |
| Ultra | Maasathukku $200 | Oru vaarathukku Pro usage-oda 10x, verified accounts-kku 5-hour limit illa |

Indhiyaala plans rupees-la bill aagum, rupee amount maaralaam, adhanaala vaangura annaikke claude.ai/upgrade-a check pannunga. Claude Code unga plan-oda limits-a chat kooda share pannikkum. Anthropic-oda pricing page Pro-va "for everyday work"-num Max-a "for all-day work"-num solludhu. Oru build naduvula 5-hour limit-a thottaa, reset-kku wait pannanum allathu paid usage credits-a on pannanum. Neenga evvalavu use panniyirukkeenga-nnu paarkka oru session-la `/usage` type pannunga. Adhigamaa pay panradhukku munnaadi, Pro ungalukku podhumaa-nnu paarkka keezha irukkura maadhiri oru chinna app nalla test.

### 2. Oru chinna spec ezhudhunga

Endha code-kkum munnaadi `SPEC.md`-la arai page ezhudhunga: app enna pannum, yaaru use pannuvaanga, mukkiyamaana moonu mudhal anju features, phone-la eppadi theriyanum, edhu scope-kku veliyila. Ellaathaiyum vida out-of-scope list dhaan mukkiyam, yennaa neenga kekkaadha vishayangala Claude serkkaama adhu thadukkum. Ungalukku enna venum-nu urudhiyaa theriyala-nnaa, ungala interview panna Claude-kitta sollunga: "Ask me questions one at a time until you could write SPEC.md, then write it."

### 3. CLAUDE.md-aala adhukku oru memory kodunga

Ovvoru session-um oru fresh context-oda aarambikkum. Ovvoru session aarambathulayum Claude `CLAUDE.md`-a padikkum, adhanaala code-la irundhu adhuvaa kandupidikka mudiyaadhadha adhula podunga: app-a eppadi run, test panradhu, unga rules, udhaaranamaa "mobile first, 360 px wide", "no paid APIs" allathu "never put keys in client code". First draft-kku `/init` run pannunga, appuram lines-a delete pannunga. Ovvoru file-aiyum 200 lines-kku keezha vaikka Anthropic-oda docs suggest pannudhu, yennaa ovvoru line-um ovvoru task-layum Claude-oda attention-la konjatha eduthukkum. Orey vishayathukkaaga Claude-a rendu thadavai correct pannaa, oru line serunga.

### 4. Neenga use pannappora controls

| Neenga panna ninaikkiradhu | Idha pannunga |
|---|---|
| Edits illaama oru plan vaanga | `/plan`-um task-um type pannunga, allathu mode-la plan-nu kaatura varaikkum Shift+Tab azhuthunga |
| Ovvoru command-aiyum neengaley approve panna | Auto mode-la irundhu manual (default) mode-kku poga Shift+Tab azhuthunga |
| Enna maaruchu-nnu paarkka | `/diff` type pannunga, allathu `git diff` run pannunga |
| Claude-oda kadaisi edits-a undo panna | Kaaliyaana prompt-la Esc-a rendu thadavai azhuthunga, allathu `/rewind` type pannunga |
| Sambandhamillaadha oru pudhu task-a aarambikka | `/clear` type pannunga (`/resume`-aala thirumba varalaam) |
| Neelamaana session-a surukka | Edha vachukkanum-nu solli `/compact` type pannunga, udhaaranamaa `/compact keep the test commands` |
| Oru step naduvula Claude-a nirutha | Esc azhuthunga |

**Permission modes** ungakitta kekkaama Claude enna pannalaam-nu mudivu pannum. Pudhu terminal, VS Code sessions **auto mode**-la aarambikkum: routine steps-kku nikkaama Claude velai seiyum, oru thani safety model ovvoru action-aiyum check panni risky aanadha block pannum, udhaaranamaa oru production deploy, oru force push, allathu theriyaadha oru server-kku data anuppuradhu. Auto mode prompts-a kuraikkum, aanaa safety-kku guarantee kidaiyaadhu-nnu Anthropic velippadaiyaa solludhu. Unga mudhal project-la manual mode-a yosichu paarunga; adhula ovvoru command-kkum munnaadi Claude kekkum, adhanaala adhu enna run pannudhu-nnu neenga katthukkuveenga. Unga sondha laptop-la bypass mode-a use pannavey pannaadheenga; docs adha isolated containers-kku mattum dhaan vaikkudhu.

**Checkpoints backup illa.** Claude adhoda file tools-aala panna edits-a `/rewind` undo pannum, aanaa oru shell command panna ella change-aiyum illa. Unga unmaiyaana history Git dhaan: velai seiyura ovvoru step-kku appuramum commit pannunga.

### 5. Plan pannunga, appuram chinna steps-la build pannunga

Mudhalla oru plan kelunga, adha padinga, thevaiyillaadhadha vettunga. Appuram oru nerathula oru feature build pannunga: layout, appuram data, appuram calculations, appuram saving, appuram deployment. Chinna step-naa chinna diff, chinna diff-a dhaan neenga unmaiyileye padikka mudiyum. Claude adhoda velaiya adhuve check panna oru vazhi kodunga: tests, allathu "run the app and check it at 360 px wide". Built-in `/verify` command, app-a build panni run panni result-a paarkka Claude-kitta sollum.

### 6. Diff-la red flags irukkaa-nnu padinga

Nalla review panna ovvoru line-um puriyanum-nu avasiyam illa. Idhaiyellaam skim panni paarunga, edhaavadhu onnu kannula pattaa "yen?"-nu kelunga:

- **Neenga sollaadha files.** Oru layout fix settlement maths-a thodavey koodaadhu.
- **Delete pannina allathu weak aakkina tests.** Pressure-la irukkura oru agent sila neram, fail aagura oru test edha expect pannudhu-ngaradhaiye maathi adha "fix" panniddum.
- **Neenga othukkaadha pudhu packages.** Ovvonnum inime neenga depend panra code.
- **Browser-la run aagura endha file-layum oru secret key.**
- **Alavukku meerina size.** Oru one-line bug-kku 300-line diff vandhaa adhukku explanation venum.

### 7. Link-a share panradhukku munnaadi security-a check pannunga

AI-built apps baadhikkappadura oru podhuvaana vazhi buddhisaalithanamaana hacking illa. Thirandhey vitta oru key allathu database dhaan. Vera yaarukkaavadhu link kidaikkaradhukku munnaadi:

- **Client code-la secret keys illa.** Next.js-la, `NEXT_PUBLIC_`-la aarambikkura per irukkura endha variable-um, ovvoru visitor-kkum anuppura JavaScript-kkulla copy aagidum. Publish panna safe-aana values-kku mattum andha prefix-a use pannunga.
- **`.env` `.gitignore`-la irukku**, unga git history-la endha key-um illa.
- **Ovvoru Supabase table-layum row-level security.** Supabase-oda browser key public-aa irukkathaan uruvaakkappattadhu; ovvoru user-um endha rows-a padikkalaam allathu maathalaam-nu row-level security dhaan mudivu pannum. Secret (service role) key andha rules-a skip panniddum, adhanaala adhu server-laye irukkanum.
- **Input-a server-la check pannunga**, form-la mattum illa.
- Appuram Claude-kitta neradiyaa kelunga: "Review this project for exposed secrets, tables without row-level security and unchecked input. List each problem with the file."

## Oru worked example

Idhu oru udhaaranathukkaana kadhai; nerangalum udhaaranathukku dhaan, measure pannadhu illa. Nisha Pune-la moonu friends kooda oru flat-a share panraanga, WhatsApp chat-la bills-a pirikkiradhu avangalukku aluthupochu. Avanga oru product designer, developer illa.

**Spec.** Avanga `SPEC.md` ezhudhuraanga: "Oru one-page web app. Oru bill serkkalaam: amount, yaar pay pannaanga, yaar share panraanga (pay pannavanga eppavumey share panraanga). Yaar yaarukku tharanum-nu, mudinja alavu kuraivaana payments-la kaattanum. Phone-la velai seiyanum. Browser-la save aagum; login illa. Rupees, whole numbers. Scope-kku veliyila: accounts, samamillaadha splits, payment links." Avanga `claude` run panni, `/init` type panni, spec-a padichu kelvigal kekka Claude-kitta solraanga. Oru bill-a sila flatmates mattum share panna mudiyumaa-nnu Claude kekkudhu. Mudiyum-nu solraanga: oruthar oorla illaadhappo groceries moonu perukkulla piriyum.

**Plan-um, avangaloda push-back-um.** Plan mode-la Claude oru Next.js app-a propose pannudhu: oru server, oru form, oru bill list, oru settlement function, local storage, tests. Nisha kekkuraanga: "There is no login and no database. Is there a simpler stack?" Claude rendu options kodukkudhu: plain HTML-um JavaScript-um, allathu tests-kku Vitest-oda oru chinna Vite app. Avanga Vite-a therndhedukkuraanga, yennaa adhu Vercel host pannakkoodiya plain static files-aa build aagum, Vitest maths-a test panradha easy aakkum. Step one-a mattum approve panraanga: page-um form-um. Adhu avanga phone-la run aagudhu. Commit panraanga.

**Tests pidicha bug.** Step three-kku, adhaavadhu settlement maths-kku, mudhalla tests kekkuraanga. Oru test, avangaley kaiyaala check pannakkoodiya oru case-a use pannudhu: Nisha, Aarti, Meera share panra groceries-kku Nisha ₹1,000 pay panraanga. ₹1,000-a moonaala vaguthaa ₹333.33, adhanaala oruthar oru rupee adhigamaa kodukkanum. Claude oru rule-based test-um ezhudhudhu: shares-a koottinaa eppavumey bill amount varanum. Andha test fail aagudhu. Mudhal version ellaarukkum ₹333 koduthuchu, koottinaa ₹999, adhanaala oru rupee kaanaama pogudhu. Claude kaaranatha explain panni, micham irukkura rupee-a pay pannavangalukku koduthu fix pannudhu:

```js
export function splitBill(amount, payer, people) {
  const share = Math.floor(amount / people.length); // 1000 / 3 -> 333
  const shares = Object.fromEntries(people.map((p) => [p, share]));
  shares[payer] += amount - share * people.length; // payer is a sharer: 333 + 1 = 334
  return shares;
}
// splitBill(1000, "Nisha", ["Nisha", "Aarti", "Meera"])
// -> { Nisha: 334, Aarti: 333, Meera: 333 }; Aarti and Meera each owe Nisha 333
```

Oru rupee kaanaama ponadha avanga kannaala paarthu kandupidichirukkavey maattaanga. Rule-based test adha pidichudhu, pinnaadi edhaavadhu oru change adhe thappa thirumba kondu vandhaa adhaiyum pidikkum.

**Oru red flag.** 360 px screen-la table-a fix pannumbodhu, Claude-oda diff settlement file-aiyum edit pannudhu. Nisha yen-nu kekkuraanga. Adhu sambandhamey illaadha oru rename. Avanga Esc-a rendu thadavai azhuthi, rewind panni, "change only the CSS"-nu serthu marubadi kekkuraanga.

**Shipping.** Deploy panradhukku munnaadi, step 7-la irukkura security review-a kekkuraanga. Keys-um illa, server-um illa, adhanaala `.gitignore`-la `.env` illa-ngaradhu mattum dhaan finding; Claude adha serkkudhu. Saayangaalam Vercel-la deploy panraanga. Marunaal kaalaiyila flatmates app-a use panraanga. Sumaar anju mani neram aachu, adhula perumbagudhi avangalukku enna venum-nu mudivu panradhulaye pochu.

## Podhuvaa panra thappugal

**Orey message-la muzhu app-aiyum kekkuradhu.** Review panna mudiyaadha, test pannaadha oru periya kuzhappam dhaan kidaikkum. Oru nerathula oru feature kelunga.

**Spec-a skip panradhu.** Spec illa-nnaa Claude guess pannum, andha thappaana guess mela adhu build pannina piragu dhaan neenga adha gavanippeenga. Edhu scope-kku veliyila-nnum ezhudhunga.

**Thevaikku mela build panra plan-a accept panradhu.** Agents adikkadi ungalukku thevaiyaanadha vida periya stack-a propose pannum. Approve panradhukku munnaadi "is there a simpler way?"-nu kelunga.

**Puriyaadha changes-a accept panradhu.** Explanation kelunga. Code, adhoda bugs, adhoda security ellaathukkum owner neenga dhaan.

**Auto mode-aiyo checkpoints-aiyo safety net-aa namburadhu.** Auto mode oru model-oda judgement, guarantee illa; checkpoints sila changes-a miss pannum. Velai seiyura ovvoru step-kku appuramum commit pannunga.

**Browser paarkkakkoodiya idathula keys-a poduradhu.** Client code-layo oru `NEXT_PUBLIC_` variable-layo irukkura secret public dhaan. Secrets-a server-side environment variables-layum, git ignore panra oru `.env` file-layum vainga.

**Database-a thirandhey viduradhu.** Row-level security illaadha oru Supabase table-a, unga app-oda public key irukkura yaar venaalum padikkalaam, perumbaalum maathavum mudiyum; andha key ovvoru visitor-kittayum irukku.

**Mudivillaadha "fix it" loops.** Rendu correction-kku appuramum adhe bug irundhaa, niruthunga. `/clear` run pannunga, appuram exact steps, edhirpaartha result, unmaiyaana result, neenga katthukittadhu ellaam vachu orey oru pudhu prompt ezhudhunga, endha change-kkum munnaadi kaaranatha kelunga.

## Practice pannunga

Indha guided task-a sumaar 45 nimishathula pannunga. Ungalukku oru paid plan allathu oru API account venum.

1. Oru pudhu folder uruvaakki, `git init` run pannunga, appuram `claude`.
2. Worked example-la varra Nisha-voda bill splitter-kku, unga sondha vaarthaigal-la, oru out-of-scope list-oda `SPEC.md` ezhudhunga.
3. `/init` run pannunga, `CLAUDE.md`-a thirandhu run, test commands-aiyum unga sondha rule onnaiyum serunga. Chinnadhaa vainga.
