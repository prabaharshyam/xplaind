## Idhu enna

Model-ku thevaiyaana information-a kudukka rendu vazhi irukku:

- **Long context**: muzhu document-a, illa sila documents-a prompt-la potu kelvi kekkuradhu.
- **Retrieval (RAG)**: romba relevant-aana konjam passages-a search panni, adha mattum prompt-la podradhu.

Ippo irukkura models romba neelamaana inputs-a edhukkum, adhanaala long context pannalaam-nu pala neram irukkum. Adhu sariyaa-nu, accuracy, cost, latency, scale-a poruththu irukku.

| | Long context | RAG |
|---|---|---|
| Model-ku enna kidaikkum | Muzhu contract (40,000 tokens), instructions, kadaisila kelvi | 3 chunks-um kelvi-yum (3,000 tokens) |
| Palam | Ellaathaiyum paakkum, cross-reference panna mudiyum | Sutthamaa, vegam, millions of documents varaikkum scale aagum |
| Balaveenam | Cache pannaama selavu adhigam, mella | Retrieval miss panradhai miss pannum |

```flow
dir: LR
title: Naduvula irukkura vazhi
Kelvi -> Sariyaana 2 documents-a kandupidi -> Muzhusaa model-ku anuppu
```

Indha lesson-la Chennai-la oru law firm contract-review assistant build panraanga, rendu romba vera vera use-kku.

## Idhu eppadi work aagudhu

**Neelamaana inputs-la accuracy.** Models ella positions-aiyum samamaa use panradhu illa. Neelamaana context-la nadula irukkura information-a, aarambathula illa kadaisila irukkradha vida kammiyaa use pannum-nu ("lost in the middle"), input valara valara simple tasks-la kooda performance kuraiyalaam-nu studies kandupidichaanga. Pudhu models improve aagiruku, aana unga documents-layum, question types-layum neengalae test pannanum.

**Cost.** Ovvoru call-layum ovvoru input token-kum kaasu. Oru kelvikku 200,000-token document anuppuna, 3,000 tokens retrieved passages anuppuradha vida romba adhigam aagum. **Prompt caching** idha maathum: adhe long document-a neraya kelvikku reuse panna, appuram varra calls-la cached input romba sutthamaa, vegamaa irukkum.

**Latency.** Input neelamaana first token varra neram adhigam aagum. Cache pannaama irundhaa, neelamaana prompts interactive use-a mella aakkum.

**Scale.** Context window-ku oru limit irukku; oru company-oda documents-ku illa. Corpus window-a vida periyadhu aanaa, edhavadhu retrieve pannanum, kuraindha pakshama endha documents-a anuppanum-nu select panna.

**Thumb rules.**

- Oru illa sila documents, oru session-la adhu pathi neraya kelvigal, muzhu document thevaippadura kelvigal (summaries, sections-a compare panradhu): long context, mudinjaa cached.
- Periya illa valarum collections, short factual kelvigal, neraya users: RAG.
- Naduvula: document level-la retrieve pannunga (sariyaana rendu contracts-a kandupidinga), apram andha muzhu documents-a context-la podunga.

**Hybrid palakkangal.** Long context irundhaalum, instructions-um kelvi-yum kadaisila podunga, sections illa pages-ku citations kelunga, documents-a oru consistent, labelled format-la vainga.

**Options-a compare panradhu:**

| Factor | Long context | RAG |
| --- | --- | --- |
| Corpus size | Context window varaikkum | Unlimited |
| Muzhu document thevaippadura kelvigal | Strong | Weak, chunking-a poruththu |
| Short factual lookups | Okay, aana selavu adhigam | Strong |
| Oru kelvikku cost | Cache illaama adhigam, caching-oda kammi | Kammi |
| Latency | Adhigam, caching-oda kammi | Kammi |
| Maarura documents | Ovvoru thadavaiyum thirumba anuppanum | Maarina items-a re-index pannanum |
| Engineering effort | Kammi | Adhigam: chunking, indexing, retrieval tuning |

**Oru worked cost comparison.** Input-ku oru million tokens-ku fixed price-nu vechukkalaam. 12 kelvikkum ovvonnukkum 40,000-token contract anuppuna, sumaar 480,000 input tokens. Caching-oda, appuram varra calls cached contract-a normal price-oda oru pagudhi-ku padikkum, adhanaala total sumaar naalil oru pangu aagalaam. RAG oru kelvikku sumaar 3,000 tokens anuppum, total 36,000, adhu innum sutthamaa, aana cross-reference kelvigala kammiyaa score pannudhu. Sariyaana choice, andha task-ku accuracy-a indha costs-oda tharasula vechu paarkkum, cost mattum paakkaadhu.

**Unga documents-la test pannunga.** Published studies echarikkai tharum, badhil tharaadhu. Badhil document-oda aarambathula, nadula, kadaisila irukkura kelvigalaiyum, rendu thooram-aana sections thevaippadura kelvigalaiyum ezhudhunga. Rendu vazhilayum run panni, failures-a padinga.

**Code-la oru position test.** Oru real document-oda vera vera depth-la oru fact-a vechu, answers sariyaa irukkaanu paarunga:

```python
import anthropic

client = anthropic.Anthropic()
FACT = "The penalty for late GST filing under clause 14.3 is ₹750 per day."
QUESTION = "What is the penalty per day for late GST filing under clause 14.3?"

def plant(doc, depth):
    cut = int(len(doc) * depth)
    return doc[:cut] + "\n\n" + FACT + "\n\n" + doc[cut:]

def position_test(doc, depths=(0.05, 0.5, 0.95), runs=3):
    for d in depths:
        correct = 0
        for _ in range(runs):
            r = client.messages.create(
                model="claude-sonnet-5-5", max_tokens=100,       # check the docs for current names
                messages=[{"role": "user", "content": plant(doc, d) + "\n\n" + QUESTION}])
            text = "".join(b.text for b in r.content if b.type == "text")
            correct += "750" in text
        print(f"fact at {d:.0%} depth: {correct}/{runs} correct")
```

Unga real documents-layum lengths-layum idha run pannunga. Apram rendu thooram-aana sections thevaippadura kelvigala test pannunga, adhula thaan long context pala neram RAG-a jeikkum.

**Neenga adjust panna koodiya cost comparison.** Ippo irukkura prices-a podunga, check panna date-oda:

```python
def cost_inr(input_tokens, output_tokens, price_in, price_out, cached_tokens=0, cache_read_ratio=0.1,
             usd_to_inr=84):
    """Prices in USD per million tokens. cache_read_ratio: cached input price as a share of normal."""
    uncached = input_tokens - cached_tokens
    usd = (uncached * price_in + cached_tokens * price_in * cache_read_ratio + output_tokens * price_out) / 1e6
    return usd * usd_to_inr

questions, doc, out = 12, 40_000, 300
long_ctx = sum(cost_inr(doc + 100, out, 3, 15, cached_tokens=doc if i else 0) for i in range(questions))
rag = questions * cost_inr(3_000, out, 3, 15)
print(f"long context with caching ₹{long_ctx:.1f}, RAG ₹{rag:.1f}")
```

Mudhal call muzhu document-kum kaasu kudukkum (cache ezhudha konjam extra-um), appuram varra calls cache lifetime-kulla vandha, sutthamaa padikkum. Numbers-a unga document sizes-ku, traffic-ku maathikkonga.

**Naduvula irukkura vazhi code-la.** Chunks illa, muzhu documents-a retrieve pannunga, apram padikkura velaya long context-a seiya vidunga:

```python
def doc_level_answer(question, search_docs, load_doc, max_docs=2):
    docs = search_docs(question, k=max_docs)          # search over document summaries or titles
    context = "\n\n".join(f"<document title='{d['title']}'>\n{load_doc(d['id'])}\n</document>" for d in docs)
    return context + f"\n\nAnswer using the documents above, citing titles and sections.\nQuestion: {question}"
```

Kelvigalukku muzhu document thevai, aana neraya nooru documents irukku-nu irukkura contracts, policies, reports-ku idhu set aagum.

**Moonu vishayatha alandhu mudivu pannunga.** Unga question types-la accuracy, unga traffic-la oru answer-ku cost, first token varra neram. Ovvoru option-kum numbers-a oru sinna table-la ezhudhi, palakkathula illa, client-oda serndhu choose pannunga.

## Oru worked example

Chennai-la oru law firm contract review-ku assistant vennum-nu kekkuraanga. Rendu use cases:

*Oru contract-a review panradhu.* Oru lawyer 60 page agreement-a (sumaar 40,000 tokens) upload panni, oru dozen kelvi kekkuraanga: termination rights, indemnity caps, clauses-kku idaiyila conflicts. Neraya answers-ku muzhu document thevai. Neenga contract-a cache panni long context use pannuveenga. Mudhal kelvikku 9 seconds; appuram varradhu 2 mudhal 3 seconds, cache-naala romba kammi selavu. 30 kelvi test-la, long context 90% score pannudhu, chunk-based RAG 73%, adhu clauses-kku idaiyila cross-references-a miss pannudhu.

*Firm-oda precedent library-la search panradhu.* 25,000 past contracts, endha context window-yum vida romba periyadhu. Lawyers kekkuraanga "IT services contracts-la, kadaisi 12 maadhathula kudutha fees varaikkum cap panna indemnity clauses-a kandupidi." Neenga metadata filters-oda hybrid retrieval use panni nalla 20 clauses-a kandupidichu, apram oru model citations-oda summarise pannum.

Firm-ku rendumae kidaikkum, ovvonnum adhukku set aagura idathula.

| Use case | Approach | Accuracy | Notes |
| --- | --- | --- | --- |
| Oru 60 page contract-a review panradhu | Long context, cached | 90% | Chunk-based RAG 73% score pannudhu |
| 25,000 precedents-la search panradhu | Filters-oda hybrid retrieval | Recall-vaala alakkalaam | Endha window-yum vida romba periyadhu |

## Podhuvaa panra thappugal

- **Long context eppovum adhigam accurate-nu nenaikkradhu.** Test pannunga; length-yum position-yum poruththu accuracy kuraiyalaam.
- **Oru kelvikku cost-a ignore panradhu.** Ovvoru kelvikkum neelamaana, cache illaatha prompts scale-la selavaagum.
- **Caching-a marakkradhu.** Adhe document-a thirumba thirumba use pannum podhu, adhu economics-a maathidum.
- **Kelvi-a mudhalla vaikkradhu.** Instructions-um kelvi-yum neelamaana material-ku aprom vainga.
- **"RAG saagiduchu" nu nenaikkradhu.** Periya collections-ku innum retrieval thevai.
- **Adhe document neraya kelvikku use aagum podhu, caching illaama costs-a compare panradhu.**
- **Periya window-na model adha muzhusaa nallaa use pannum-nu nenaikkradhu.** Positions-um cross-references-um test pannunga.

## Mudivu theliva irukkum podhu

- **Oru short document**: adha appadiyae prompt-la podunga.
- **Millions of documents**: edhavadhu oru vagai retrieval thevai, kuraindha pakshama documents-a select panna.
- **Structured data-la irundhu answers**, records illa tables maadhiri: database query illa tool use pannunga, indha rendu-la edhuvum illa.

## Demo-la irundhu production-ku

- Neenga select panna approach-ku unga golden set-la **accuracy, cost, latency-a record pannunga**, model maarum podhu thirumba check pannunga.
- Minutes-kulla reuse aagura neelamaana documents-ku **prompt caching use pannunga**.
- **Ovvoru request-layum input tokens-a log pannunga**, edhir paaraadha valarchi-na alert vechukkonga.
- Models maathumbodhu illa document lengths valarumbodhu **position test-a thirumba run pannunga**.
- **Naduvula irukkura vazhi-a nenaivula vainga**: collections valarum podhu document-level retrieval pala neram jeikkum.
