## Idhu enna

Research-na oru kelviya, neenga defend pannakkoodiya oru mudivaa maathuradhu. Oru AI assistant medhuvaana pagudhigalai vegamaa seiyum: sources kandupidikkiradhu, neelamaana documents padikkiradhu, summarise panradhu, compare panradhu, calculate panradhu. Aanaa moonu vishayangalukku innum neenga thaan poruppu: **kelvi, sources, mudivu.**

Indha lesson research workflow pathinadhu: oru kelviya eppadi frame panradhu, endha assistant mode use panradhu, adhoda evidence-a eppadi kaatta vaikkiradhu, kandupidichadha eppadi ezhudhuradhu. Endha oru thani badhilaiyum check panradhukkaana general routine-a (stakes, check pannakkoodiya claims, nambagamaana sources) "AI answer-a check panradhu" lesson cover pannudhu. Inga adha vachu, neelamaana research velaigalukku build panrom.

Mudhal mudivu **endha mode use panradhu**-ngradhu, yenna ovvoru mode-um adhukke uriya vazhila fail aagum:

```flow
title: Kelvikku porundhura mode-a thernthedunga
Unga research kelvi -[oru parandha mudhal map]-> Plain chat
Unga research kelvi -[ippodhaiya facts, rules]-> Links-oda web search
Unga research kelvi -[pala sources-oda parandha survey]-> Deep research report
Unga research kelvi -[unga sondha files-la irundhu badhilgal]-> Document notebook
Unga research kelvi -[oru sheet-la irukkura numbers]-> Spreadsheet analysis
```

| Mode | Edhukku nalladhu | Vazhakkamaa varra failure | Unga check |
| --- | --- | --- | --- |
| Plain chat (memory mattum) | Key terms, oru overview, aduthu enna search panradhu | Pazhaya allathu karpanai facts, thirandhu paarkka source illa | Ovvoru fact-aiyum oru finding-aa illa, oru lead-aa eduthukkunga |
| Links-oda web search | Ippodhaiya rules, figures, news | Claim-a support pannaadha oru nija link; official page-kku badhilaa oru blog | Page-la andha exact sentence-a kandupidinga |
| Deep research report | Oru landscape: pala sources, options, arguments | Balaveenamaa support panra niraiya citations irukkura neelamaana reports | Unga mudivu nikkira claims-a mattum trace pannunga |
| Document notebook allathu upload | Unga reports, policies, papers pathina kelvigal | Gaps-a memory-la irundhu nirappuradhu; scanned PDFs-la tables-a thappaa padikkiradhu | Document-aala badhil solla mudiyaadha oru kelviya kelunga |
| Spreadsheet analysis | Totals, trends, charts | Thappaana column, vidupatta rows, mosamaana data | Row count-a check pannunga, oru sample-a thirumba compute pannunga |

Madurai-la oru garments kadai nadathura Meena, oru tax mudiva aarambathula irundhu kadaisi varai research panna oru assistant-a eppadi use panraanga-nnu follow pannuvom.

## Idhu eppadi work aagudhu

### Kekkuradhukku munnaadi kelviya frame pannunga

Oru kelviyoda wording thaan badhila vadivamaikkudhu. Assistants-kku podhuvaa kekkuravanga kooda othuppora tendency irukku, researchers indha pazhakkatha **sycophancy**-nnu solraanga. Adhanaala oru leading kelvikku oru pakka badhil varalaam.

- **Leading:** "Chinna kadaigalukku GST composition scheme yen better?"
- **Neutral:** "Tamil Nadu-la oru garments kadaikku, GST composition scheme-oda advantages, disadvantages enna, yaarukkellaam adha use panna anumadhi illa?"

Oru nalla research kelvi **idatha** (state, country-kku etha maadhiri rules maarum), **nerathai** ("indha varusha nilavarappadi"), **scope-a** (yaarukku, endha size business), neenga edhirpaarkkura **output-a** (oru table, pros, cons list, oru expert-kitta kekka vendiya kelvigal) sollum.

Bias-a innum kuraikka rendu prompts:

- "Idhukku edhiraa irukkuradhulaye valuvaana case enna?"
- "Endha evidence irundhaa unga badhil maarum?"

### Explore pannunga, date-a gavaninga

Parandha alavula aarambinga: "Indha topic-a simple-aa explain pannu, key terms-a list pannu, endha official sources idha cover pannudhu-nnu sollu." Andha overview-a oru **map-aa eduthukkunga, nija nilamaa illa**. Enga paarkkanum-nu adhu sollum, edhu unmai-nnu illa.

Ovvoru model-um oru **knowledge cutoff** varaikkum irukkura data-la train aagiyirukku, adhukku appuram enna maaruchu-nnu adhukku theriyaadhu. Research-la ellaathaiyum vida adhigamaa nadakkura thappu, sila varushangalukku munnaadi unmaiyaa irundha oru rule, rate, limit allathu price-a ippodhaiyadhaa solradhu. Adhanaala oru rule-a follow pannunga: **maarakkoodiya edhukkum, source-oda date-a kandupidichu official site-la confirm pannunga.** Badhil memory-la irundhu mattum vandhirundhaa, adhu pazhasaa irukkalaam-nu eduthukkunga.

### Web badhilgal adhoda evidence-a kaatta vainga

Assistant web-la search pannumbodhu links kaattum. Adha thirakkiradhu aarambam thaan, mudivu illa. Mukkiyamaana test **support**: badhil claim panradha andha page unmaiyileye solludhaa? Oru nijamaana, official page-a, adhu sollave sollaadha oru claim-kku cite pannalaam.

Indha velaiyoda oru pagudhiya assistant-aiye seiya vainga:

- "Ovvoru claim-kkum, adha support panra source-la irukkura exact sentence-a quote pannu, page-oda date-aiyum kudu."
- "Indha sources-la edhu original, edhu vera oruthharoda figure-a report pannudhu?"

Appuram **upstream** ponga. Oru blog NPCI figure-a quote pannaa, NPCI-a thiranga. Oru news story oru government circular-a cite pannaa, andha circular-a thiranga. Secondary sources onna onnu copy pannum, adhanaala ore number-a thirumba solra anju pages-um ore source thaan.

Idhu aridhaana problem illa. Tow Center for Digital Journalism March 2025-la panna oru test-la, chinna news excerpts-oda source-a kandupidikka ettu AI search tools-kitta kettaanga, avai 60%-kkum adhigamaana queries-kku thappaana badhilgal koduthuchu.

### Deep research modes

Pala assistants ippo oru **deep research** mode kudukkudhu (OpenAI February 2025-la ChatGPT-la onna launch pannuchu, matha assistants-kkum avangalukkunnu onnu irukku). Oru quick search-kku badhilaa, oru agent pala nimishangalukku niraiya pages-a search panni padichu, appuram dozen kanakkaana citations-oda oru neelamaana report ezhudhum. Adhuvum thappaana facts-a sollalaam, thappaana mudivugalukku varalaam-nu launch-laye OpenAI-ye echarichudhu.

Deep research-a oru **parandha mudhal survey**-kku use pannunga: "Enna options irukku, ovvonnaiyum pathi sources enna solludhu, enga avai othupogala?" Adha kadaisi vaarthaiyaa eduthukkaadheenga. Idhula irukkura gotcha: **adhiga citations-na adhigamaa check pannanum-nu artham, adhigamaa nambalaam-nu illa.** Oru 20-page report muzhumaiyaa irukkura maadhiri theriyum, aanaa adhu pazhaya, pudhu sources-a kalakkalaam, copy panna pages-a othupporadhaa ennalaam, source lesaa mattum support panra oru sentence-kku citation podalaam.

Oru practical rule: report-a padikkiradhukku munnaadi, **unga mudivu depend panra moonula irundhu anju claims-a** ezhudhi vainga. Andha claims-kku, ovvonnukkum source, date, support panra quote-oda oru table-a assistant-kitta kelunga. Adha original sources-oda check pannunga, report-la meedhi irukkuradha background-aa eduthukkunga.

### Unga sondha documents-la badhilgalai ground pannunga

**Grounding**-na model-a memory-la irundhu illaama, neenga kudukkura material-la irundhu badhil solla vaikkiradhu. Oru chat-la file-a upload pannalaam, allathu idhukkunne build panna oru notebook tool use pannalaam, udhaaranamaa Google-oda Gemini Notebook (July 2026 varaikkum idhukku NotebookLM-nnu per). Neenga serkkura sources-la irundhu thaan adhoda chat badhil sollum, source-la quote panna passage-a paarkka click pannakkoodiya citations-aiyum kudukkum-nu Google solludhu.

Niraiya tools idha **retrieval-augmented generation (RAG)** moolamaa pannudhu: unga kelvikku porundhura passages-a unga documents-la search panni, andha passages-la irundhu badhila ezhudhudhu. Search thappaana passage-a eduthaa, unga file-a cite pannaalum badhil thappaa thaan irukkum.

Oru valuvaana grounding prompt:

> Attach panna documents-la irundhu mattum badhil sollu. Ovvoru point-kkum, sentence-a quote panni page number-a kudu. Documents-la indha kelvikku badhil illainnaa, "Not in the documents"-nnu reply pannu.

Appuram oru **canary test** pannunga: documents-la badhil illai-nnu ungalukku therinja oru kelviya kelunga. Appadiyum assistant badhil sonnaa, gaps-a memory-la irundhu nirappudhu-nnu artham, adhoda matha badhilgalai neenga innum kandippaa check pannanum. Scanned PDFs-la tables-la irundhu edutha numbers-aiyum check pannunga, avai thappaa padikkappadalaam.

### Academic sources

Students-um analysts-um adikkadi research papers keppaanga. Models nijam maadhiri theriyura citations-a karpanai pannalaam, idhu oru vagai **hallucination**: oru nija journal per, nambakkoodiya authors, illave illaadha oru title. Scientific Reports-la publish aana oru 2023 study-la, GPT-3.5 uruvaakkuna citations-la 55%-um, GPT-4 uruvaakkunadhula 18%-um fabricate pannappattadhu. Endha tool use pannaalum, nambi irukkiradhukku munnaadi ovvoru paper-aiyum check pannunga:

1. Exact title-a Google Scholar-layo publisher site-layo search pannunga. Kandupidikka mudiyalainnaa, cite pannaadheenga.
2. Abstract-a padinga. Claim solradha thaan andha paper study pannuchaa-nnu (adhe makkal, adhe outcome) check pannunga.
3. Neenga padicha paper-a cite pannunga, adha pathi assistant kudutha summary-a illa.

### Spreadsheets

Niraiya assistants, pinnaadi code ezhudhi run panni thaan oru spreadsheet-a analyse pannum. Maths podhuvaa sariyaa irukkum; fail aaguradhu **data-layum column choice-layum** thaan:

| Problem | Enna thappaagudhu | Eppadi pidikkiradhu |
| --- | --- | --- |
| Thappaana column | "amount"-kku badhilaa "invoice number"-a total pannudhu | Endha column use pannuchu-nnu kelunga |
| Merged cells allathu extra header rows | Rows-a skip pannudhu allathu rendu thadavai ennudhu | Adhoda row count-a ungalodadhoda compare pannunga |
| Text-aa store aana numbers | Oru CSV-la lakh commas-oda type panna 1,00,000 maadhiri values text-aa padikkappadudhu allathu vidupadudhu | Ovvoru total-layum ethana rows use aachu-nnu kelunga |
| Positive numbers-aa store aana returns | Refunds sales-la koottappadudhu | Oru maasatha kaiyaala thirumba calculate pannunga |
| Blank allathu "NA" cells | Averages-la irundhu rows sathamillaama vidupadudhu | Missing values-a eppadi handle pannuchu-nnu kelunga |

Eppavum kelunga: "Calculation-aiyum code-aiyum kaattu, ethana rows use pannen-nu sollu." Appuram onnu rendu numbers-a neengale thirumba calculate pannunga.

### Kandupidichadha ezhudhunga

Paste panna AI badhil illaama, oru chinna **research note**-oda mudinga. Ovvoru claim-kkum, evidence evvalavu valuvaanadhu-nnu mark pannunga:

- **Verified:** oru original allathu official source-la neenga padicheenga, date-aiyum note panneenga.
- **Likely:** oru nambagamaana secondary source solludhu, aanaa original-a neenga paarkkala.
- **Unverified:** assistant mattum thaan solludhu. Adha nambi irukkaadheenga.

Unga manager, teacher allathu accountant-kitta share panradhu indha note thaan. Ungalukku enna theriyum, adhu eppadi theriyum, edhu innum open-nu adhu kaattum.

## Oru worked example

Meena-kku Madurai-la oru garments kadai irukku. **GST composition scheme**-la seralaamaa-nnu avanga therinjukkanum; indha scheme chinna businesses turnover mela oru fixed rate-la tax kattavum, filing-a simple-aa pannavum vidudhu. Keezha irukkura avanga kadaiyoda numbers indha example-kkaaga uruvaakkinadhu; GST rules nijamaanadhu, November 2026-la check pannadhu.

**Step 1: frame panni explore panradhu.** Avangaloda mudhal draft "Composition scheme en kadaikku yen nalladhu?". Adha neutral-aa thirumba ezhudhuraanga:

> Naan Tamil Nadu-la oru garments kadai nadathuren. 2026 nilavarappadi, GST composition scheme-oda advantages, disadvantages enna, turnover limit enna, yaarellaam adha use panna mudiyaadhu? Ovvoru rule-kkum date-aiyum source-aiyum kudu.

Web search on-la irukka, **₹1 crore varaikkum** turnover irukkura kadaigal seralaam-nu assistant badhil solli, rendu pages-a cite pannudhu: oru official government page, oru tax blog.

**Step 2: support-aiyum date-aiyum check panradhu.** "₹1 crore limit-a solra sentence-a page-oda date-oda quote pannu"-nnu kekkuraanga. Andha quote 2018-la ezhudhina blog-la irundhu varudhu. Official page vera maadhiri solludhu. Tamil Nadu udpada perumbaalaana states-la goods suppliers-kku limit **₹1.5 crore**, adhu 1 April 2019 mudhal ₹1 crore-la irundhu uyarthappattadhu-nnu official GST, government sites-la confirm panraanga. (Sila special category states-la limit ₹75 lakh.) Assistant oru secondary source-la irundhu pazhaya figure-a use panniyirundhuchu.

**Step 3: avanga data-la ground panradhu.** Pona varusha sales sheet-a upload panraanga:

> Indha sheet-a mattum use panni, monthly sales-aiyum yearly total-aiyum kudu. Calculation-a kaattu, ethana rows use pannen-nu sollu.

Assistant yearly total **₹1,41,10,000**-nnu report pannudhu. Deepavali-naala avangalukku varushathulaye romba busy-aana maasamaana October-a check panraanga. Assistant ₹19,02,000 kaattudhu. Avanga sondha koottal ₹17,78,000 varudhu: ₹18,40,000 sales-la irundhu ₹62,000 returns kazhichaa. Returns positive numbers-aa store aagiyirundhadhaala, kazhikkappadaama **koottappattuchu**. Andha thappu effect-a rendu madangaakkudhu: gap 2 × ₹62,000 = ₹1,24,000.

Returns column-a sari panni thirumba run panraanga. Varusham muzhukka sales ₹1,38,00,000, returns ₹3,10,000, adhanaala avanga net sales ₹1,41,10,000 illa, **₹1,34,90,000**.

Ippo Step 2 thappoda vilai theriyudhu. Pazhaya ₹1 crore limit-a vachu paarthirundhaa, thannaala sera mudiyaadhu-nnu thappaa mudivu panniyiruppaanga. Net sales thaan kanakkula varra turnover-naa (idhu avanga accountant-kitta kekka vendiya kelvi), avanga ₹1.5 crore limit-kku ₹15,10,000 keezha irukkaanga, adutha varusham sumaar 11% growth vandhaa limit-a thaandiduvaanga.

**Step 4: edhiraana case-a kekkuradhu.** "En kadai maadhiri oru kadai serakkoodaadhu-nnu solradhukku irukkuradhulaye valuvaana kaaranangal enna?"-nnu kekkuraanga. Rendu points thaniyaa theriyudhu. Composition taxpayers avanga purchases mela input tax credit claim panna mudiyaadhu, goods-a inter-state supply pannavum mudiyaadhu. Kerala-la irukkura customers-kku orders anuppa aarambikka Meena plan panniyirundhaanga. Rendu rules-aiyum oru official source-la confirm panraanga.

**Step 5: note ezhudhuradhu.**

| Claim | Evidence | Status |
| --- | --- | --- |
| Tamil Nadu-la goods-kku limit ₹1.5 crore | Official GST pages, 1 April 2019 mudhal amalil | Verified (November 2026-la check pannadhu) |
| Avanga net sales ₹1,34,90,000 | Avanga sondha sheet, sari panni thirumba compute pannadhu | Verified |
| Input tax credit illa; goods-a inter-state supply panna mudiyaadhu | Official source | Verified |
| Net sales thaan kanakkula varra turnover-aa, adhanaala avangalukku evvalavu headroom | Innum kidaikkala | Open: accountant-kitta kekkanum |

Note-aiyum naalu kelvigalaiyum eduthukkittu accountant-kitta poraanga; varushathoda naduvula limit-a thaandinaa enna aagum, Kerala plan indha choice-a eppadi maathum-ngradhum adhula adakkam. Assistant avangalukku manikkanakkaana padippa michappaduthuchu; final call eduthadhu accountant.

## Podhuvaa panra thappugal

- **Leading kelvi kekkuradhu.** "X yen better?"-kku X-kku aadharavaana case thaan varum. Rendu pakkathaiyum, edhiraana case-aiyum kelunga.
- **Ippodhaiya rules-kku memory-only badhilgalai use panradhu.** Limits, rates, prices maarum. Date-aiyum official page-aiyum kandupidinga.
- **Secondary source-laye ninnudradhu.** Oru figure-a thirumba solra blog allathu news story original illa. Upstream ponga.
- **Neelamaa irukku-nnu oru report-a nambradhu.** Dozen kanakkaana citations-na check panna adhigam irukku-nnu artham. Unga mudivu nikkira andha sila claims-a trace pannunga.
- **Canary test-a skip panradhu.** Document-aala badhil solla mudiyaadha oru kelviya neenga kekkave illainnaa, adhu grounded-aa-nnu ungalukku theriyaadhu.
- **Thirandhe paarkkaadha papers-a cite panradhu.** Ovvoru title-aiyum Google Scholar-la kandupidichu abstract-a padinga.
- **Row count illaama oru spreadsheet total-a ethukkiradhu.** Neenga kekkalainnaa, vidupatta allathu rendu thadavai ennappatta rows kannukku theriyaadhu.
- **AI badhila unga finding-aa paste panradhu.** Edhu verified, edhu innum open-nu solra oru chinna note ezhudhunga.
- **Approve aagaadha oru tool-la private documents-a upload panradhu.** Endha tools endha data-va paarkkalaam-ngra unga organisation-oda rules-a follow pannunga.

## Practice pannunga

Keezha link panniyirukkura OpenAI Academy-oda research sessions-a paarunga, Civic Online Reasoning-la irundhu oru lateral reading lesson-a try pannunga.

1. **Frame pannittu, appuram search pannunga.** Work allathu padippukku ungalukku thevaiyaana oru rule allathu figure-a edunga. Kelvikku oru leading version-um oru neutral version-um ezhudhi, rendaiyum run panni, badhilgal eppadi verupadudhu-nnu note pannunga. Neutral kelvikku, ovvoru claim-kkum support panra quote-aiyum date-aiyum kettu, original source varaikkum upstream ponga.
2. **Ground panni test pannunga.** Oru public report-a upload panni, page references, quotes-oda anju kelvigal kelunga. Report-aala badhil solla mudiyaadha oru canary kelviya serunga. Ovvoru reference-aiyum check panni, canary-a assistant eppadi handle pannuchu-nnu record pannunga.
3. **Oru sheet-a check pannunga.** Oru assistant-oda udhaviyoda oru chinna spreadsheet-a analyse pannunga. Adhoda row count-a ungalodadhoda compare panni, rendu numbers-a kaiyaala thirumba calculate pannunga.

**Mudinjadhu-nnu eppo sollalaam:** thappaa, pazhasaa allathu support illaadhadhaa neenga pidicha kuranjadhu oru claim-um, adha theerthu vacha original source-um irukkura oru chinna research note-a kaatta mudiyumbodhu.
