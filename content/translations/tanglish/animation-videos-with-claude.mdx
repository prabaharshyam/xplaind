## Idhu enna

Claude **animated explainer videos** pannum: slide aagi varra titles, step by step-aa build aagura diagrams, valara charts, path-la nagarura icons. Idha ovvoru element-aiyum varaiyum, animate panna **code ezhudhi** pannum, camera footage generate panni illa. Adhanaala idhu **motion graphics**-ku romba nalladhu: oru idea, oru process, sila numbers-a explain panna.

2026 kadaisila idha moonu vazhiyila pannalaam:

- **Claude Motion** (beta, October 2026-la launch): explainer-a describe pannunga illa oru report, data-va paste pannunga, Claude neenga edit panni export panna mudiyura oru short animation-a build pannum. Unga Claude plan-la idhu irukkaa-nu check pannunga.
- **Claude artifacts:** oru normal chat-la Claude-kitta animated HTML, CSS illa SVG scene kelunga. Adhu udanae play aagurathu theriyum, screen-record pannalaam.
- **Claude Code with Remotion:** Claude oru Remotion project ezhudhum, ovvoru frame-um code-aa irukkura React components, oru sariyaana MP4-a render pannum. Neenda videos, series, data-driven videos-ku best.

```flow
Idea -> Script | scenes, timings, on-screen text -> Claude animation code-a ezhudhum | Claude-la Motion, HTML illa SVG artifact, illa Claude Code + Remotion
Claude animation code-a ezhudhum -> Preview
Preview -[inga slow-aa, anga periya text]-> Revise
Revise -> Preview
Revise -> MP4 export -> Voice-over, captions, music serkkunga -> Publish
```

## Idhu eppadi work aagudhu

**1. Prompt-la illa, script-la irundhu aarambinga.** Ovvoru scene-aiyum adhoda length, enna theriyum, enna nagarum, screen-la illa narration-la irukkura words-oda ezhudhunga. Oru idea-ku muppadhu-la irundhu thonnooru second podhum. Quality-ku idhu thaan mukkiyamaana oru kaaranam.

**2. Visual style-a oru thadavai set pannunga.** Rendu moonu brand colours, oru font, background, motion style-a peyar kudunga, "smooth ease-in-out, no bouncing" maadhiri. Claude ellaa scenes-layum adha follow pannum.

**3. First draft-a generate pannunga.** Script-aiyum style-aiyum Claude Motion-la illa chat-la paste pannunga, illa Claude Code-a ovvoru scene-kum oru component-oda oru Remotion project create panna sollunga. Phone-la padikka mudiyura alavukku text periyadhaa vaikka sollunga.

**4. Pesi refine pannunga.** Video code-aa irukkradhaala, thulliyamaana maatrangal easy: "scene 3-a rendu second neenda aakku", "arrow idadhu pakkam irundhu varanum", "38%-a 41%-aa maathu". Andha element mattum maarum.

**5. Export.** Claude Motion-um Remotion-um MP4 export pannum. Artifact-na screen-record pannunga, illa Claude-a Remotion project-aa maatha sollunga.

**6. Sound-um captions-um serkkunga.** Narration record pannunga illa text-to-speech voice use pannunga, mute-la paarkkuravangalukku captions serkkunga, help pannum-na oru melliya music track-um.

| Approach | Edhukku best | Effort | Output |
|---|---|---|---|
| Claude Motion | prompt, report, data-la irundhu vega explainers | romba kammi | edit panna mudiyura animation, MP4 export (plan-a poruthadhu) |
| Claude artifact | oru animated scene illa diagram | kammi | screen-record panna mudiyura HTML |
| Claude Code + Remotion | neenda videos, series, data-driven batches | naduthara | render aana MP4, reuse panna mudiyura templates |
| Video model (Veo, adutha guide-la paarunga) | realistic footage | naduthara | generate aana clips |

**Data-la irundhu videos pannradhu.** Remotion video oru program-aa irukkradhaala, adhu data-va input-aa edukkum. Oru sales team spreadsheet-la irundhu ovvoru region-kum oru personalised video render pannalaam, illa oru teacher scripts list-la irundhu ovvoru chapter-kum oru video render pannalaam. Data-va padichu ovvoru version-aiyum render panra loop-a Claude Code ezhudhum, adhukku nigaraa edhuvum kaiyaala panra animation workflow-la illa.

## Oru example

Sneha Nagpur-la oru college-la computer science kathu tharaanga. Avanga students-ku RAG chatbot eppadi work aagum-nu purinjukka kashtam, adhanaala class WhatsApp group-ku 60-second animation vennum.

Avanga oru script ezhudhuraanga:

1. (6 s) Oru student chat box-la "What is the exam syllabus?"-nu type panraanga.
2. (12 s) Question numbers-oda oru varisaiyaa, "embedding"-aa maari, documents-oda oru stack-ku pogudhu.
3. (12 s) Match aagura moonu paragraphs ezhunthu, stack-la irundhu veliya varudhu.
4. (15 s) Question-um andha moonu paragraphs-um "LLM"-nu label panna oru box-kulla pogudhu.
5. (10 s) Oru answer varudhu, keezha source document-oda peyar-oda.
6. (5 s) Title card: "RAG = search first, then answer".

Avanga Claude Code-a Remotion-la build panna sollraanga, purple, white-la flat style, ovvoru scene-kum keezha captions, 48 px-ku chinna text illama. First render kittathatta sariyaa irukku. Rendu maatrangal kekkuraanga: scene 2-a slow pannunga, adhu padikka mudiyaadha alavukku vegamaa poyduchu, scene 3-la document peyargala kaattunga. Ovvoru maatrathukkum Claude-ku oru nimishathukku kammi thaan aagudhu.

Avanga thangaludaiya narration-a phone-la record panraanga, Claude Code scene lengths-a audio-oda sync pannudhu, avanga MP4-a export panraanga. Adutha semester script-a maathi ovvoru topic-kum oru video pannikka adhae project-a reuse panraanga, yenna scenes components.

## Podhuvaa panra thappugal

**Script illaama prompt panradhu.** "Make an explainer about X" generic result tharum. Scenes, timings, words-a modhalla ezhudhunga.

**Screen-la romba text.** Makkal padichukittu kekka mudiyaadhu. Ovvoru scene-kum screen-la konja words mattum vachchu, narration-a details-a edukka vidunga.

**Saadha-aaga motion.** Suthradhu, thullradhu, zoom aagradhu, idea-vai vittu distract pannum. Purinjukka help panradha mattum animate pannunga.

**Phone-ku romba chinna text.** Perumbaalaana viewers phone-la thaan paarppaanga. Preview-a phone size-la check pannunga.

**Realistic scenes-ku use panradhu.** Claude-oda animation code-la varaiyapadum. Camera-la people, places, products-ku, adutha guide-la varra Veo maadhiri video model use pannunga.

**Urimai illaadha music-um images-um.** Royalty-free tracks-um, unga sondha illa licensed images-um use pannunga, especially public illa commercial edhaavadhu-na.
