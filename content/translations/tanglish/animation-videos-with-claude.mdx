## Idhu enna

Claude **animated explainer videos** seyyum: slide aagi ulla varra titles, step by step build aagura diagrams, valarra charts, oru path-la nagarra icons. Ovvoru element-aiyum varanju animate panra **code-a ezhudhi** dhaan idha seyyudhu. Adhu edhaiyum film panradhilla, camera footage-a generate panradhum illa. Adhanaala idhu **motion graphics**-kku romba porutham, adhaavadhu oru idea, oru process alladhu sila numbers-a vilakkura animated text, shapes, charts.

Video-ve code-ngradhaala, adhu oru recording maadhiri illa, oru document maadhiri nadandhukkum: oru vaarthai, number alladhu timing-a maathi marupadi render pannunga. Data-va kuduthu nooru versions kooda vaangalaam.

## Idhu eppadi work aagudhu

### 1. Prompt-la illa, script-la aarambinga

Ovvoru scene-aiyum oru variyila ezhudhunga: adhoda neelam seconds-la, enna theriyudhu, enna nagarudhu, screen-laiyo narration-laiyo varra vaarthaigal. Oru idea-kku muppadhula irundhu thonnooru seconds thaaraalamaa podhum. Oru vari prompt kudutthaa, indha ovvoru choice-aiyum Claude guess pannanum, andha guesses generic-aa dhaan irukkum.

Prompt panradhukku munnaadi rendu checks. Timer vachu narration-a sathamaa padinga: 12-second scene-a solla 17 seconds aanaa, script-a ippove fix pannunga. Appuram ovvoru scene-kkum ore oru velai kudunga; adha vivarikka rendu thadavai "and" thevaippattaa, adha pirichidunga.

### 2. Visual style-a oru thadavai set pannunga

Rendu moonu colours (brand colours irundhaa hex codes-oda), oru font, background, motion style, udhaaranamaa "smooth ease-in-out, 0.4 s moves, no bouncing"-a sollunga. Idha ellaam oru style file-laiyo oru constants block-laiyo vaikka Claude-kitta sollunga. Appuram ovvoru scene-um adhula irundhu dhaan padikkum, adhanaala pinnaadi brand colour-a maatha ore oru edit podhum.

### 3. Oru route-a therndhedunga

| Unga nilaimai | Route | Ungalukku vendiya plan | Ungalukku kidaikkiradhu |
|---|---|---|---|
| Oru scene, alladhu oru idea nallaa animate aagudhaannu test panradhu | Claude artifact | endha Claude plan-um | Chat-la play aagura HTML; adha screen-record pannunga |
| Narration-oda oru muzhu video, personal plan-la | Claude Code + Remotion | Claude Code irukkura oru paid plan | Render aana MP4, marupadi use pannakkoodiya project |
| Oru sheet alladhu oru list-la irundhu niraiya versions | Claude Code + Remotion | Claude Code irukkura oru paid plan | Oru template-la irundhu ovvoru row-kkum oru MP4 |
| Motion irukkura oru company-la, oru report-la irundhu oru quick explainer | Claude Motion | Team alladhu Enterprise | Edit pannakkoodiya animation, MP4 download |
| Realistic manushanga, idangal alladhu products | Veo maadhiri oru video model | Veo, Flow guide-a paarunga | Generate aana clips |

Oru simple rule: adha oru thadavaikku mela thodap poreengannaa, alladhu adhu oru voice-over-oda match aaganumnaa, Remotion use pannunga. Oru idea animation-aa work aagudhaannu mattum paakkanumnaa, oru artifact use pannunga.

### 4. Claude Code enna ezhudhudhu, adha eppadi padikkiradhu

"Ovvoru scene-kkum oru component-oda oru pudhu Remotion project create pannu"-nu Claude Code-kitta kekkalaam, adhu onna set up pannum (official starter `npx create-video@latest`). React-a neengale ezhudha vendiyadhilla, aanaa adha padikka therinjirukkanum, yennaa appadi dhaan oru thappaana number-a kandupidippeenga, alladhu oru thulliyamaana change-a keppeenga. Naalu ideas idhula perumbaalaanadha cover pannum:

- **Frames, fps.** Oru video-na frames-nu sollappadura still pictures-oda oru varisai. Oru second-kku 30 frames (fps)-la, oru 5-second scene-na 150 frames.
- **Ippodhaiya frame.** `useCurrentFrame()` ippo varaiyappadura frame-oda number-a kudukkum. Oru scene-kkulla adhu andha scene-oda start-la irundhu ennum, adhanaala ovvoru scene-um adhoda animation-a 0-la aarambikkalaam.
- **Interpolate.** `interpolate()` oru frame range-a oru value range-kku map pannum: "frame 0-kkum frame 15-kkum naduvula, invisible-la irundhu fully visible-kku po".
- **Composition.** Oru `Composition` video-voda width, height, fps, frames-la neelam (`durationInFrames`) ellaathaiyum set pannum.

Keezha irukkura worked example-la varra Sneha-voda title card idhu, thaniyaa oru 5-second scene:

```tsx
import { AbsoluteFill, Composition, interpolate, useCurrentFrame, useVideoConfig } from "remotion";

// Scene 6, the title card: the text fades in and rises over half a second.
export const TitleCard = ({ text }: { text: string }) => {
  const frame = useCurrentFrame(); // 0, 1, 2 ... counted from the start of this scene
  const { fps } = useVideoConfig(); // 30 in this project
  const opacity = interpolate(frame, [0, 0.5 * fps], [0, 1], { extrapolateRight: "clamp" });
  const y = interpolate(frame, [0, 0.5 * fps], [40, 0], { extrapolateRight: "clamp" });
  return (
    <AbsoluteFill style={{ backgroundColor: "#ffffff", justifyContent: "center", alignItems: "center", padding: 80 }}>
      <h1 style={{ fontSize: 96, color: "#5b2a86", textAlign: "center", opacity, transform: `translateY(${y}px)` }}>
        {text}
      </h1>
    </AbsoluteFill>
  );
};

// The video's settings: size, frame rate and length in frames.
export const RemotionRoot = () => (
  <Composition
    id="TitleCard"
    component={TitleCard}
    width={1080}
    height={1920}
    fps={30}
    durationInFrames={150} // 5 seconds x 30 fps
    defaultProps={{ text: "RAG = search first, then answer" }}
  />
);
```

Idha vari variyaa padinga. Arai second-na `0.5 * fps`, adhaavadhu 15 frames, adhanaala `opacity` frames 0-la irundhu 15 varai 0-la irundhu 1-kku pogum. Rendaavadhu `interpolate` text-a adhoda idathukku 40 pixels keezha irundhu mela nagarthum. `extrapolateRight: "clamp"`-na "frame 15-kku appuram, final value-laye iru"; adhu illannaa text screen-a vittu mela erikkitte pogum, idhu Remotion code-la oru common bug. `Composition` video 1080 wide, 1920 tall (oru phone screen), 30 fps, 150 frames neelamnu solludhu.

Timing raw frame numbers-aa illaama, seconds times `fps`-aa ezhudhiyirukku paarunga. Adha appadiye vachukka Claude-kitta sollunga. Appo pinnaadi frame rate-a maathinaa ovvoru animation-um udaiyaadhu.

### 5. Timestamps vachu narration-oda sync pannunga

Claude-aala unga audio-va kekka mudiyaadhu, adhanaala "voice-over-oda match pannu"-ngradhu adhu thaanaa seyya mudiyaadha onnu. Adhukku badhilaa numbers kudunga:

1. Mudhalla narration-a record panni ore file-aa save pannunga.
2. Ovvoru sentence-um endha second-la aarambikkudhunnu edunga. Timestamps kudukkura oru transcription tool idha seyyum, udhaaranamaa Whisper; Remotion-la idhukku helper packages irukku. Aaru scenes-kku, file-a play panni times-a neengale ezhudhikkalaam.
3. Andha list-a Claude Code-kitta kuduthu, seconds-a frames-aa maathi adhula irundhu ovvoru scene-oda neelatthaiyum set panna sollunga.

```tsx
// Second at which each narration sentence starts, from the transcript, then the end.
const cues = [0, 6.2, 18.5, 30.9, 46.0, 55.4, 60.0];
const fps = 30;
const starts = cues.map((s) => Math.round(s * fps)); // [0, 186, 555, 927, 1380, 1662, 1800]
const lengths = starts.slice(1).map((f, i) => f - starts[i]); // [186, 369, 372, 453, 282, 138]
```

Appuram ovvoru scene-um oru `Series.Sequence`-kkulla pogum, adhoda `durationInFrames` adhoda neelathukku set aagum, narration adhu ellaathukkum keezha play aagum. Muzhu video oru rendaavadhu `Composition`, id `RagVideo`, `durationInFrames={1800}`-oda. Oru expert detail: **start times**-a frames-kku round pannunga, appuram subtract pannunga. Ovvoru scene-oda neelatthaiyum thanithaniyaa round panninaa, chinna rounding errors koodikkitte poi, kadaisi scenes voice-a vittu drift aagidum.

### 6. Pesiye refine pannunga

Video-ve code-ngradhaala, thulliyamaana changes malivu: "scene 3-la arrows idadhu pakkathula irundhu varattum", "38%-a 41%-aa maathu". Andha element mattum dhaan maarum. Rendu pazhakkangal udhavum:

- **Stills kelunga.** Claude Code-aalaiyum video-va paakka mudiyaadhu. Full render-kku munnaadi, `npx remotion still`-oda key moments-oda still frames-a render panni adha paakka sollunga, alladhu neengale check pannunga.
- **Remotion Studio-la preview pannunga** (`npx remotion studio`). Adhu unga browser-la video-va play pannum, frame by frame scrub pannavum vidum.

### 7. Sound, captions serunga

Narration dhaan vilakkura velaiya seyyum; on-screen text key words mattum dhaan irukkanum. Mute-la paakkuravangalukkaaga captions serunga. Oru nalla rule of thumb: ovvoru caption-um moonu vaarthaikku kurainjadhu oru second screen-la irukkanum, eppovum sumaar onnara second-a vida kuraiyakkoodaadhu. Udhavumnaa mattum voice-kku keezha oru amaidhiyaana music track vainga, kadaisiyila adha fade out pannunga.

### 8. Render, export

Remotion unga computer-la CLI-oda render pannum, udhaaranamaa `npx remotion render RagVideo out/rag.mp4`. Adhukku Node.js install aagiyirukkanum, adhu ovvoru frame-aiyum Remotion ungalukkaaga set up panra oru headless browser-la (window illaadha browser) varaiyum. Evvalavu neram aagumngradhu unga computer-aiyum, ovvoru frame-um evvalavu varaiyudhungradhaiyum poruthadhu, adhanaala nooru videos-oda batch-a plan panradhukku munnaadi unga mudhal render-kku evvalavu neram aagudhunnu paarunga.

| Enga play aagum | Size (width x height) | Frame rate | Kurainjapatcha text size |
|---|---|---|---|
| WhatsApp, Reels, Shorts (phone first) | 1080 x 1920 (9:16) | 30 fps | sumaar 48 px |
| Classroom projector, YouTube, slides | 1920 x 1080 (16:9) | 30 fps | sumaar 36 px |
| Rendu vidhathulaiyum work aaganumngra oru feed post | 1080 x 1080 (1:1) | 30 fps | sumaar 44 px |

Ivai sensible defaults, platform rules illa. Motion graphics-kku 30 fps thaaraalamaa podhum; 60 fps render velaiya irattippaakkum, text-kku adhu nallaa theriyuradhu aridhu. Messaging apps adikkadi videos-a marupadi compress pannum, adhu chinna text-a blur aakkum, adhanaala unga phone-kke oru test anuppunga. Length, size limits app-kku app verupadum, maaravum seyyum, adhanaala neenga post panra idathula ippodhaiya limit-a check pannunga.

### Data-la irundhu videos

Oru Remotion video oru program, adhanaala adhu data-va props-aa edutthukkalaam; props-na oru component-kku varra inputs. Oru sales team oru spreadsheet-la irundhu ovvoru region-kkum oru personalised video render pannalaam; oru teacher scripts list-la irundhu ovvoru chapter-kkum oru video render pannalaam. Ovvoru row-aiyum padichu oru file-a render panra loop-a Claude Code ezhudhalaam. 40 versions render panradhukku munnaadi, ellaathaiyum vida kashtamaana rendu rows-a (ellaathaiyum vida neelamaana per, ellaathaiyum vida periya number) render panni, edhuvum overflow aagalainnu check pannunga.

## Oru worked example

Sneha Nagpur-la oru college-la computer science teach panraanga. ## Podhuvaa panra thappugal

**Audio sync-a guess panradhu.** "En voice-over-oda match pannu"-nu Claude-kitta kettaa work aagaadhu, yennaa adhaala file-a kekka mudiyaadhu. Sentence start times-a kuduthu, adha frames-aa maatha vidunga.

**Clamp panna marakkuradhu.** `extrapolateRight: "clamp"` illaadha oru `interpolate` adhoda range mudinjadhukku appuramum nagarndhukitte irukkum, adhanaala text screen-a vittu drift aagum, alladhu zero-va thaandi fade aagum.

**Screen-la romba adhiga text.** Ore nerathula oru paragraph-a padikkavum kekkavum makkalaala mudiyaadhu. Ovvoru scene-laiyum on-screen text-a sila key words-aa vachukkonga, detail-a narration paathukkattum.
