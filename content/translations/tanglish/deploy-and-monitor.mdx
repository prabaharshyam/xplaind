## Idhu enna

LLM app-a deploy panradhu-na, adhai real users nambikkaiyaa adaiyura idathula online-la vekkuradhu. Monitoring-na, anga poitta apram adhu eppadi nadandhukkudhu-nu paakkuradhu. LLM apps-ku monitoring naalu vagai signal-a cover pannum:

- **Errors**: fail aana requests, provider errors, timeouts.
- **Latency**: users evvalavu neram kaathirukkaanga, especially time to first token.
- **Cost**: oru request-ku, oru user-ku, oru naalaikku tokens-um panamum.
- **Quality**: answers innum nallaa irukka-nu, user feedback, automatic checks, sampled review-la irundhu.

```flow
Users -[HTTPS]-> Managed service-la oru container, Indian region | key secret settings-la irundhu, oru /health endpoint
Managed service-la oru container, Indian region -> Model API
Managed service-la oru container, Indian region -> Ovvoru request-um log aagum | id, user, latency, tokens, cost, model, prompt version, rating
Ovvoru request-um log aagum -> Daily dashboard | requests, error rate, p95 latency, oru naalaikku cost, thumbs-up rate
Daily dashboard -> Alerts | errors 2%-a thaandina, cost oru naalaikku ₹150-a thaandina, app down
Daily dashboard -[weekly]-> 20 real conversations padinga -> Fix -> Test env + evals -> Chinna release -> Ellaa users
```

## Idhu eppadi work aagudhu

**Simple-aa deploy pannunga.** Mudhal app-ku, oru managed platform podhum: oru serverless service-la container (Cloud Run, Azure Container Apps, Amazon ECS Express Mode maadhiri), illa Vercel, Render, Railway maadhiri platform-la oru web app. API key-a platform-oda secret settings-la vainga, environment variables set pannunga, oru health-check endpoint serunga, HTTPS-a enable pannunga (perumbaalum automatic).

**Ovvoru request-aiyum log pannunga**: request id, user (illa pseudonymous id), latency, tokens, cost, model, prompt version, errors-oda. Oru tracing tool illa structured logs use pannunga.

**Dashboards.** Oru naalaikku requests, error rate, p95 latency, oru naalaikku cost, feedback rate-oda oru chinna dashboard. Mudhalla daily paarunga.

**Alerts.** Error rate oru threshold-a thaandina; cost oru daily budget-a thaandina; latency spikes; app down aanaa. Yaaraavadhu paakkura idathuku anuppunga.

**Quality signals.**

- *User feedback*: thumbs up illa down, optional reason-oda.
- *Automatic checks*: format valid-aa, refusals, citations irukka, guardrail triggers.
- *Sampled review*: vaaram 20 real conversations padinga.
- *Online evals*: live answers-oda oru sample-a oru judge score pannum.

Edhuvum error illaamaiyae quality kurayalaam: oru provider model-a update pannalaam, documents maaralaam, users pudhu vagai kelvigal kekka aarambikkalaam.

**Latency-ku rendu pagudhi.** Stream aagura reply-ku, users **time to first token** (TTFT)-a, apram **time per output token** (TPOT)-a feel pannuvaanga. Total neram sumaar TTFT + TPOT x output tokens: 1.2-second TTFT-um, 300 tokens-ku oru token-ku 30 ms-um irundhaa, total sumaar 10 seconds, aana user 1.2-la padikka aarambichuduvaanga. Makkal sumaara oru token-ku 100 mudhal 150 ms-la padippaanga, adhanaala adhai vida vegamaa stream aanaa kavanikka maattaanga, aana slow-aana mudhal token eppavum therium. **Percentiles** (p50, p95) sollunga, average mattum eppavum venaam: 100 ms-la onbadhu replies-um 3,000 ms-la oru reply-um average 390 ms, adhu yaaraiyum describe pannaadhu.

**Metrics, logs, traces.** Metrics 3:05-la edho thappaa pochu-nu sollura totals. Logs 3:05-la enna nadandhudhu-nu sollura thani thani events. **Trace** oru request-oda ovvoru step-aiyum (retrieval, prompt, model call, tool calls, final answer) ovvonnoda neram, cost-oda serkkum, adhanaala edhu step fail aachu-nu paakkalaam. Langfuse, LangSmith, Arize Phoenix, illa simple OpenTelemetry maadhiri tools adhai collect pannum.

**Makkal nadandhukkura vidhathula irundhu signals.** Users thumbs down-a rare-aa thaan amukkuvaanga, aana avanga nadandhukkura vidham pesum: reply-a paadhi-la niruthuradhu, regenerate amukkuradhu, ore kelvi-a maathi kekkuradhu, rendu turns-la mudiya vendiya task-ku neenda conversations. Idhai explicit ratings-oda serthu track pannunga.

**Moonu vagai drift.** Unga code maaraamalaiyae quality maaralaam:

- **Ungaloda sonda maatrangal**: oru prompt edit, oru pudhu document set, vera chunk size.
- **Ungaloda users maaruvaanga**: pudhu vagai kelvigal, oru pudhu mozhi, exam results announce aana apram neenda inputs.
- **Model maarum**: adhae peyarla oru provider model-a update illa retire pannalaam. Kidaikkura idathula dated model versions-a pin pannunga, maaradhukku munnaadi evals-a thirumba odunga.

**Ungaloda monitoring evvalavu nalladhu?** Software operations-la irundhu moonu numbers: oru problem-a **kandupidikka aagura neram**, adha **sari panna aagura neram**, **change failure rate**, adhavadhu fix illa rollback thevaipadura releases-oda share. Change failure rate adhigam-na, release-ku munnaadi ungaloda evals innum neraya pidikkanum.

**Oru chinna logging wrapper.** Oru tool vaangaradhukku munnaadi, konjam lines perumbaalaana value-va tharum. Idhu oru reply-a stream panni, TTFT-aiyum total neraththaiyum measure panni, ovvoru request-kum oru JSON line ezhudhum:

```python
import json, time, uuid
import anthropic

client = anthropic.Anthropic()
PRICES = {"input": 3 / 1e6, "output": 15 / 1e6}       # USD per token; check current prices
USD_TO_INR = 84
VERSION = "rag-v14"                                    # prompt and code version

def answer(user_id, question, system, messages):
    start, first, rid = time.monotonic(), None, str(uuid.uuid4())
    record = {"id": rid, "user": user_id, "version": VERSION, "model": "claude-sonnet-5-5"}
    try:
        with client.messages.stream(model=record["model"], max_tokens=600,
                                    system=system, messages=messages) as stream:
            parts = []
            for text in stream.text_stream:
                first = first or time.monotonic()
                parts.append(text)
            final = stream.get_final_message()
        u = final.usage
        record |= {"ok": True, "stop": final.stop_reason,
                   "in": u.input_tokens, "out": u.output_tokens,
                   "cost_inr": round((u.input_tokens * PRICES["input"] + u.output_tokens * PRICES["output"]) * USD_TO_INR, 3)}
        return "".join(parts), rid
    except anthropic.APIError as err:
        record |= {"ok": False, "error": type(err).__name__}
        raise
    finally:
        now = time.monotonic()
        record |= {"ttft_ms": round(((first or now) - start) * 1000), "total_ms": round((now - start) * 1000)}
        with open("requests.jsonl", "a") as f:
            f.write(json.dumps(record) + "\n")
```

Kelvi-yum answer text-um venumnae vittuttom; keezha irukkura privacy note-a paarunga. Oru daily job andha file-a padichu thresholds-a check pannum:

```python
import json, statistics

def daily_report(path="requests.jsonl", cost_limit_inr=150, error_limit=0.02):
    rows = [json.loads(line) for line in open(path)]
    ok = [r for r in rows if r["ok"]]
    p95 = statistics.quantiles([r["total_ms"] for r in ok], n=20)[-1]
    errors = 1 - len(ok) / len(rows)
    cost = sum(r["cost_inr"] for r in ok)
    alerts = [msg for bad, msg in [
        (errors > error_limit, f"error rate {errors:.1%}"),
        (cost > cost_limit_inr, f"cost ₹{cost:.0f}"),
        (any(r["stop"] == "max_tokens" for r in ok), "some replies were cut off"),
    ] if bad]
    return {"requests": len(rows), "p95_ms": round(p95), "errors": f"{errors:.1%}",
            "cost_inr": round(cost), "alerts": alerts}
```

**Logs-la privacy.** Muzhu prompts-um replies-um debugging-a romba easy aakkum, aana adhu personal data. India-oda Digital Personal Data Protection Act-padi, neenga enna vechirukkeenga, yen-nu unga privacy notice-la sollunga, thevaippadura varaikkum mattum vainga, phone numbers, email addresses, ID numbers-a mask pannunga, logs-a yaar padikkalaam-nu limit pannunga. Neraya teams ovvoru request-kum metadata-vum, oru chinna, consent-oda, masked sample-ku muzhu text-um log pannuvaanga.

**Paadhugaappaa release pannunga.** Maatrangala mudhalla oru test environment-ku deploy pannunga, ungaloda evals-a odunga, apram release pannunga, ellaarukkum munnaadi oru chinna share users-ku release pannuradhu nalladhu. Munnaadi version-a rollback panna ready-aa vainga.

**Signals-um adhu enna solludhu-nu:**

| Signal | Example threshold | Breach aanaa enna artham |
| --- | --- | --- |
| Error rate | 10 nimidam 2%-kku mela | Provider outage, bug, thappaana deploy |
| p95 latency | 8 seconds-kku mela | Slow retrieval, neenda outputs, provider slowness |
| Cost per day | ₹150-kku mela | Oru heavy user, oru script, oru loop |
| Thumbs-down rate | Oru vaarathula irandu madangu | Documents illa, prompt maatram, pudhu kelvigal |
| Refusal rate | Oru topic-ku romba yerudhu | Documents index aagala |

**Irubadhu nimidathula oru vaara review.** Dashboard-a thirandhu kadaisi vaaraththoda oppidunga. Kadaisi paththu thumbs-down conversations-aiyum paththu random-aanavatraiyum padinga. Ovvoru conversation-kum edhavadhu thappu irundhaa oru line ezhudhunga. Romba common-aana kaaranatha edukkunga, adhai sari pannunga. Indha chinna palakkam, yaarum satham-aa pugaar solradhukku vaarakkanakku munnaadiyae perumbaalaana quality problems-a pidichudum.

**Rollback panradhu.** Munnaadi container image-a tag panni ready-aa vainga. Rollback platform-la oru command illa oru click-aa irukkanum, launch-ku munnaadi oru thadavai test pannittu. Ovvoru log line-layum version-a record pannunga, adhanaala rollback-ku apram pazhaya version thaan traffic-a serve pannudhu-nu confirm pannalaam.

**Region select panradhu.** Unga users-ku romba pakkathula irukkura, edhaavadhu data rules allow panra hosting region-a select pannunga, Indian users-oda personal data-kku Indian region maadhiri. Model provider illa adhoda cloud partner-um pakkathula endpoint tharaanga-nu check pannunga, yen-na ovvoru model call-um kandangala thaandi poga vendi irundhaa, vegamaana app server-um romba udhavaadhu. Region choice-a unga README-la ezhudhunga, reviewers adhu vendumae pannadhu-nu paakkalaam.

## Podhuvaa panra thappugal

- **Cost-aiyum tokens-aiyum log pannaama irukkradhu.**
- **Errors-a mattum paakkradhu.** Errors illaamalum quality kurayum.
- **Alerts illaama irukkradhu.** Problems-a users thaan kandupidippaanga.
- **Code illa image-la secrets.** Platform-oda secrets-a use pannunga.
- **Rollback illaama big-bang releases.**
- **Percentiles-a vida averages.** Oru slow request average-la maraindhidum; p95 adhai kaattum.
- **Version illaadha logs.** Ovvoru line-layum model, prompt version illanaa, edhu release maatrathukku kaaranam-nu sollamudiyaadhu.
- **Ellaathaiyum eppavum log panradhu.** Logs-la irukkura personal data-kku masking, retention limit, restricted access thevai.

## Simple-aa irundhaale podhumaana idangal

- **Oru personal tool illa oru-naal demo**: token usage-aiyum errors-aiyum console-la print pannunga.
- **Konjam users-oda chinna internal pilot**: oru log file, melae irukkura daily report, vaaram oru thadavai conversations padikkradhu.
- **Oru hosted no-code assistant**, angae platform-oda sonda usage page cost-aiyum errors-aiyum cover pannum.

Real users app-a nambi irundhaa, illa pipeline-la pala steps irundhaa, tracing tools, online evals, staged releases-a serunga.

## Demo-la irundhu production-ku

- **Edhu failures-a mudhalla pidikkanum-nu mudivu pannunga**, apram avatrukku metrics select pannunga: thappaana format, miss aana answers, slow replies, kattuppaadu illaadha cost.
- **Ovvoru metric-aiyum break down pannunga** version, model, feature, naal vaariyaa, oru maatrathai adhoda kaaranathoda trace panna.
- **Model versions-a pin pannunga**, maaradhukku munnaadi evals-a thirumba odunga.
- **Oru-page runbook ezhudhunga**: yaarukku alerts pogum, eppadi rollback pannanum, backup model-ku eppadi maaranum.
- **Kandupidikkradha thirumba evals-ku kudunga**: ovvoru real failure-um oru test case aagum.
