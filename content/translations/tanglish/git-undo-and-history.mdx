## Idhu enna

Git unga velaiya moonu idathula vechirukkum, ovvonnukkum adhoda sondha undo irukku:

- **Working folder**: neenga ippo edit panra files.
- **Staging area**: adutha commit-ku pogattum-nu `git add` vechu mark panninadhu.
- **History**: commits-ae, mudhalla unga laptop-la mattum, push pannina appuram shared server-la.

Sariyaana undo, thappu engae irukku-nu, ellaathukkum mela vera yaarukkaavadhu adhu already irukkaa-nu poruthu irukkum. Perumbaalaana ellaathaiyum mudivu panra rule: **Yaarukkum illaadha history-a rewrite pannalaam; matravanga already pull panna history-a rewrite pannakoodadhu.**

## Idhu eppadi work aagudhu

```flow
title: Thappu engae irukku?
Mistake -> Where is it?
Where is it? -[edited, not staged]-> git restore file | edit-a thooki podunga
Where is it? -[staged, not committed]-> git restore --staged file | edit-a vechukittu unstage pannunga
Where is it? -[committed, not pushed]-> git reset or git commit --amend | unga sondha history-a rewrite pannunga
Where is it? -[pushed to a shared branch]-> git revert commit | adha undo panra oru commit-a serkkunga
git reset or git commit --amend -[went wrong]-> git reflog | pazhaya commit-a kandupidichu thirumba ponga
```

**Restore** files-la work aagum. `git restore app.py` unstaged edits-a thooki pottu, last commit panna version-a thirumba kondu varum. `git restore --staged app.py` oru file-a staging area-la irundhu edukkum, aana unga edits-a vechukkum.

**Reset** unga branch label-a oru munnaadi commit-ku nagarthum. Neenga thaandura commits-oda changes-ku enna aagum-nu mode-a poruthu irukkum:

| Command | Branch pinnaadi nagarudhaa | Andha commits-oda changes | Eppo use panradhu |
| --- | --- | --- | --- |
| `git reset --soft HEAD~1` | Aama | Vechukkum, staged-aa | Last commit-a vera maadhiri thirumba pannanum-na |
| `git reset HEAD~1` (mixed) | Aama | Vechukkum, unstaged | Edhai commit pannanum-nu pirikkanum, illa thirumba thervu pannanum-na |
| `git reset --hard HEAD~1` | Aama | Unga files-la irundhu delete aagum | Velai poganum-nu ninaicha (urudhiyaa irunga) |
| `git revert <id>` | Illa | Oru pudhu commit adhai undo pannum | Commit already shared aagirundhaa |

`HEAD~1`-na "naan irukkura idathukku oru commit munnaadi". `HEAD~3`-na moonu.

**Amend**-na last commit-ku oru sinna reset: oru fix-a stage panni `git commit --amend` odunga, last commit-a sari panna onnaala replace pannum. Push pannuradhukku munnaadi message-la oru typo, illa marandha file-ku idhu super.

**Revert** orupodhum edhaiyum rewrite pannaadhu. `git revert a1b2c3d` andha commit enna maathuchu-nu paathu, adha thirumba maathura oru pudhu commit-a uruvaakkum. History valarum; ellaroda copy-um innum match aagum. Main-la, neenga ketkura undo idhu thaan.

**Stash** velaiya commit pannaama pakkathula vechidum. `git stash` unga mudiyaadha edits-a save panni oru clean folder tharum, example vera oru branch-la urgent bug-a fix panna; `git stash pop` edits-a thirumba kondu varum. Commit pannaadha changes-a thooki podura entha command-kum munnaadi idhu safe move, yen-na edits stash aanaa, adutha step thappaa poyum meetkalaam.

**Reflog** unga safety net. Unga branch tip nagarum ovvoru thadavaiyum, commit, reset, rebase, checkout-aala, Git adha reflog-la sumaar 90 naal note pannum. `git reflog` andha positions-a list pannum, adhula entha onnukkum thirumba thaavalaam.

## Oru worked example

Rahul Hyderabad-la oru e-commerce company-ku recommendation API-la velai seiyraanga. Velli kizhamai maalai.

**Mudhal thappu: oru debug print.** `ranker.py`-la `print(user)` sidhari irukku, avanga stage pannala. `git restore ranker.py` adha udanadiyaa clean pannidum.

**Rendavadhu thappu: commit-la oru secret.** Avanga last commit, innum push aagala, adhula API key irukkura `.env` serndhirukku. Avanga odurathu:

```bash
git reset --soft HEAD~1
git restore --staged .env
echo ".env" >> .gitignore
git add .gitignore ranker.py
git commit -m "Add category boost to ranker"
```

Commit secret illaama thirumba kattappadudhu. Adhu orupodhum push aagaadhadhanaala, rewrite panradhu safe. Appovum key-a rotate pannuraanga, yen-na history-la disk-la irukkura secret leak aagirukkalaam-nu ninaikkuradhu jaakkirathai.

**Moonavadhu thappu: main-la oru bad change.** Thinkal-kizhamai, oru teammate-oda merge aana commit pudhu users-ku ranker empty lists tharudhu. Adhu oru naal main-la irukku, ellarum pull pannitaanga. Main-a reset pannaa ella copies-um udayum. Adhukku badhila:

```bash
git switch main
git pull
git revert 7f3e9c1
git push
```

"Revert 'Boost recent items'"-nu oru pudhu commit normal pull request, pipeline vazhiyaa pogum. Bug poidudhu, history thappaama irukku, team appuram original change-a sariyaa fix pannum.

**Naalaavadhu thappu: ilandha madhiyam.** Branch-a clean pannum podhu, Rahul `git reset --hard HEAD~3` odi, andha moonu commits-la onnu avarukku thevaippatta test-nu purinjukkaraanga. `git reflog` odi, `e41d2aa HEAD@{1}: commit: Add tests for cold-start users`-nu paathu, `git cherry-pick e41d2aa` vechu thirumba kondu varaanga. Edhaavadhu oru thadavai commit panniruntha, unmaiyila onnum poradhu illa.

## Podhuvaa panra thappugal

- **Shared branch-a reset panradhu.** Main-la `git reset` plus force push ellaroda history-aiyum rewrite pannum. Shared-aa irukkura edhukkum `git revert` use pannunga.
- **Revert secret-a neekkum-nu ninaikkradhu.** Revert secret-a history-la vittudum. Key-a rotate pannunga; history-la irundhu neekkuradhukku special tools-um coordinated rewrite-um thevai.
- **Check pannaama --hard use panradhu.** Mudhalla `git status`, `git stash`. `--hard` delete panna uncommitted edits reflog-la irukkaadhu.
- **Push panna commit-a amend panradhu.** Adhu commit-a oru pudhu onnaala replace pannum, adhanaala pazhaya onna pull panna teammates diverge aagiduvaanga.
- **Reflog irukkunu marakkradhu.** "En velai poiduchu" panic-la perumbaalum `git reflog`-la mudiyum.

## Practice pannunga

1. Oru practice repository-la, moonu commits pannunga. Ovvoru reset mode-aiyum varisaiyaa use panni, ovvonnukku appuram `git status` paarunga.
2. Oru commit-a revert panni, pudhu commit-oda diff-a `git show` vechu padinga.
3. `git reset --hard HEAD~2` odi, apram ilandha commits-a `git reflog` vechu meetkunga.
4. Unga future-self-ku oru-line rule ezhudhunga: share pannaadha velaiku entha undo, share panna velaiku entha undo.
