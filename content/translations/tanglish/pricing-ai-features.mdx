## Idhu enna

**Oru AI feature-a price panradhu**-na customers adhukku eppadi pay pannanum-nu mudivu panradhu, revenue adhoda cost-a cover panni nalla margin vidudhaa-nnu check panradhu. Rendu vishayangal idhai saadhaarana software-la irundhu vithiyaasamaakkudhu:

- **Ovvoru use-kkum variable cost.** Oru saadhaarana software feature-a innoru customer click pannaa koodudhalaa kittathatta endha selavum illa. Oru AI feature ovvoru request-kkum model tokens-kku kaasu kattudhu. Heavy users light users-a vida romba adhigamaa selavu vaikkuraanga.
- **Urudhiyillaadha value.** AI thangalukku evvalavu madhippu-nnu customers innum kathukkittu irukkaanga, adhanaala copy panradhukku settled-aana "normal" price edhuvum illa.

## Idhu eppadi work aagudhu

### Step 1: oru request-oda cost-a build pannunga

Cost-a estimate panna beta thevaiyilla. Naalu numbers podhum: ulla pora tokens, veliya varra tokens, oru token-kkaana price, exchange rate. Appuram model bill kaattaadhadhai serkkanum.

```flow
title: Cost per request-a build panradhu
Input tokens × input price -> Dollars-la model cost
Theriyura output-um thinking tokens-um × output price -> Dollars-la model cost
Dollars-la model cost -[× exchange rate]-> Rupees-la model cost
Rupees-la model cost -[× retry factor]-> Retries sertha cost
Retries sertha cost -[+ storage, logs, hosting]-> Cost per request
```

| Model | Input | Output | Edhukku nalladhu |
| --- | --- | --- | --- |
| Claude Haiku 5.5 | $0.10 | $0.50 | Thelivaana, simple, high-volume tasks |
| Claude Sonnet 5.5 | $2 | $10 | Photos, handwriting maadhiri kashtamaana inputs |

Matha providers-um idhe structure-a (thanithani input, output prices) vera numbers-oda use panraanga. Avangaloda ippodhaiya price page-a padichu, neenga use panra ovvoru number pakkathulayum check date-a ezhudhunga.

- Input: 1,500 tokens (instructions-um invoice image-um) × oru million-kku $2 = $0.003.
- Output: 200 theriyura tokens (ledger entries) plus 400 thinking tokens = 600 × oru million-kku $10 = $0.006.
- Model cost: $0.009. Oru dollar-kku ₹94-nu assume pannaa, adhu ₹0.85.
- Retries: 10-la 1 invoice format check-la fail aagi thirumba run aagudhu-nnu vachukkuvom, adhanaala 1.1-aala perukkunga: ₹0.93.
- Storage, logs, ovvoru invoice-kkum pirichcha hosting maadhiri matha per-use costs: ₹0.07-nu vachukkuvom.
- **Oru invoice-kku cost: sumaar ₹1.00.**

### Step 2: maranjirukkura thinking tokens-a gavaninga

Ippo irukkura perumbaalaana models badhil solradhukku munnaadi "think" pannudhu. Andha thinking tokens-a user-um unga app-um paarkkave illai-nnaalum, avai output-aa, muzhu output price-la bill aagudhu. Response oru summary-a mattum kaattinaalum muzhu thinking-kkum neenga pay panreenga-nnu Anthropic-oda documentation solludhu.

Oru PM-a beta bill aacharyappaduthuradhukku idhu thaan migap podhuvaana kaaranam. Varun-oda mudhal beta vaarathula, model adhoda default effort level-la run aachu; Anthropic-oda API-la Sonnet 5.5-kku adhu `high`. 200 theriyura tokens-a tharradhukku oru invoice-kku sumaar 1,600 tokens think pannuchu. Output line 1,800 × oru million-kku $10 = $0.018 aachu, oru invoice-kku muzhu cost sumaar **₹2.24**-kku eruchu, estimate-a vida rettippukkum adhigam. Extraction-kku kuraivaana effort level-a set panni, appuram oru test set invoices-la accuracy-a check pannadhum, thinking sumaar 400 tokens-kkum cost ₹1.00-kkum thirumba vandhuchu.

Idhula irundhu rendu rules varudhu. Thinking tokens-a thaniyaa log pannunga (Anthropic ovvoru response-oda usage data-layum avatrai report pannudhu, OpenAI reasoning tokens-a idhe maadhiri oru field-la report pannudhu). Appuram maximum output length-a theriyura reply size-kku cap pannave pannaadheenga: thinking-um andha limit-kkulla count aagum, adhanaala tight cap badhilai paadhiyila vettidum, retry innum adhigamaa cost aagum.

### Step 3: GST, gateway fees, rupee-a kanakkula edunga

Moonu India-specific vishayangal sathamillaama margin-a nagarthudhu.

- **GST.** India-la software subscriptions-kku 18% GST irukku. "₹999 + GST"-nu advertise pannaa, customer ₹1,178.82 pay panraanga, neenga ₹999 vachukkureenga. "₹999 GST udpada"-nu advertise pannaa, neenga 999 ÷ 1.18 = ₹846.61 mattum thaan vachukkuveenga, neenga ninaichirukkakkoodiyadhai vida sumaar 15% kuraivu. Eppavume GST illaadha price-la margin-a kanakku pannunga, pricing page-la edhai solreenga-nnu thelivaa sollunga. GST-kku register aana business buyers podhuvaa GST-a thirumba claim pannalaam; consumers panna mudiyaadhu, adhanaala consumer apps-kku buyer-kku mukkiyamaanadhu inclusive price thaan.
- **Payment gateway fees.** Razorpay-oda standard domestic rate ovvoru payment-layum 2%, plus andha fee mela GST (28 November 2026 annaikku check pannadhu). ₹1,178.82 payment-la 2% sumaar ₹24, plus adhu mela sumaar ₹4 GST. Register aana oru business podhuvaa fee mela irukkura GST-a thirumba claim pannalaam.
- **Exchange rate.** Perumbaalaana model APIs US dollars-la bill pannudhu. November 2025 naduvula rupee oru dollar-kku sumaar ₹88.7; November 2026 naduvula, May 2026-la sumaar ₹96-a thotta piragu, sumaar ₹93.5-la irundhu ₹94. Andha nagarvu mattume oru varushathula adhe dollar bill-a rupees-la sumaar 6% adhiga vilaiyaakkiduchu: maasam $10,000 bill sumaar ₹8.9 lakh-la irundhu ₹9.4 lakh aachu. Oru buffer vachu price pannunga, rupee nagarumbodhu thirumba kanakku pannunga. GST-kku register aana oru Indian company oru foreign API-a vaangumbodhu, podhuvaa reverse charge-la GST-a adhuve katti thirumba claim pannum; details-a unga accountant kitta check pannunga.

### Step 4: oru pricing model-a thernthedunga

| Model | Udhaaranam (date illai-nnaa illustrative) | Edhukku nalladhu | Gavanikka vendiyadhu |
| --- | --- | --- | --- |
| Bundled | Ovvoru plan-layum AI included | Adoption | Maranja cost; fair-use limits venum |
| Tiered | Pro-la maasam 200, Business-la 2,500 | Thelivu, upgrades | Included alavugalai mudivu panradhu |
| Add-on | AI-kku oru user-kku maasam ₹299 | Thelivaana value signal | Kuraivaana adoption |
| Usage-based | Oru invoice-kku ₹1.50 | Price cost-a follow pannum | Customers-kku budget panradhu kashtam |
| Outcome-based | Intercom Fin: oru resolution-kku $0.99 (28 November 2026 annaikku check pannadhu) | Price value-a follow pannum | Success-kku rendu perum othukkitta definition venum |

Perumbaalaana products ivatrai kalakkudhu: included usage irukkura oru tier, adhukku mela paid packs. Indha hybrid perumbaalaana customers-kku bill-a predictable-aa vachukkudhu, adhe neram ellaaraiyum vida heavy-aana users-kitta charge-um pannudhu.

Outcome-based pricing kavarchiyaa irukku, aanaa niraiya edhirpaarkkudhu. Fin-oda kadaisi badhilukku appuram customer merkondu endha help-um kekkaadha oru conversation-a thaan Intercom billable Fin resolution-nu define pannudhu. Adhu enna pannudhu-nnu gavaninga: fail aagura ovvoru attempt-oda cost-aiyum vendor thaan sumakkudhu, adhanaala unga success rate adhigamaavum nilaiyaavum irundhaa mattum thaan idhu work aagum. Idhai thernthedukkuradhukku munnaadi, neengalum customer-um logs-la irundhu count pannakkoodiya oru "outcome"-oda sariyaana definition-a ezhudhunga.

### Step 5: customers nambura credits-a design pannunga

Packs allathu credits vithaa, munnaadiye moonu vishayangalai mudivu pannunga.

- **Expiry.** Endha warning-um illaama maasa kadaisiyila expire aagura credits emaathu velai maadhiri thonum, kobamaana support tickets-a undaakkum. 12 maasam valid aagura packs-a prefer pannunga, allathu use pannaadha included usage-a oru maasathukku roll over pannunga.
- **Visibility.** App-la oru usage meter-a kaattunga, included use-oda 80%-layum 100%-layum email-layum product-layum warn pannunga.
- **Breakage.** Breakage-na kaasu kattiyum use pannave pannaadha credits-la irundhu varra revenue. Unga margin-a adhu mela build pannaadheenga. Use pannaadha credits-kku pay panrom-nu gavanikkura customers vittu poyiduvaanga.

### Step 6: margin-a kaappaathunga

- **Per-account rate limits.** Oru account-kku daily cap (udhaaranamaa, oru saadhaarana heavy naaloda 3 madangu) irundhaa, oru script allathu abuse pannappatta free trial ore raathiriyila oru maasa budget-a erichidaama thadukkum.
- **Model tiering.** Thelivaana, simple requests-a chinna model-kkum, kashtamaanadhai mattum periya model-kkum anuppunga.
- **Caching.** Ovvoru request-layum oru cached prompt prefix-kku (fixed instructions) muzhu price katturadhukku badhilaa, adhai reuse pannunga.
- Avasaram illaadha velaikku **chinna outputs-um batch processing-um**.
- **Top 5% users-a gavaninga.** Keezha irukkura Varun-oda mix-la, 5% customers 55% cost-a undaakkuraanga.

### Step 7: cost-a vachu illa, value-a vachu price pannunga

Cost floor-a mudivu pannudhu. Value ceiling-a mudivu pannudhu: michamaana mani nerangal, thavirtha thappugal, koodudhalaa varra revenue. Oru price-a fix panradhukku munnaadi, Varun-oda team pathu customers-kitta invoice entry-kku evvalavu neram aagudhu, yaar seiyuraanga-nnu kettuchu. Chinna kadaigal vaarathukku onnu rendu mani neram, owner-e seiyuraaru-nnu sonnaanga. Accountants ovvoru maasamum staff-oda muzhu naatkal pogudhu-nnu sonnaanga. Cost-la irukkura vithiyaasam illa, value-la irukkura andha vithiyaasam thaan accountants-kku thani Business plan-a niyaayappaduthuchu. Surveys-oda mattum illaama, real offers-oda (oru pricing page, oru sales quote) prices-a test pannunga: makkal survey-la onnu solluvaanga, pay panradhu vera onnukku.

Costs-um usage-um rendume maarum. Token prices podhuvaa kuranjukittu vandhirukku, aanaa nalla features innum adhigamaana, neelamaana requests-a kondu varum, rupee-um nagarum. Beta-la irundhu illaama, real usage-la irundhu ovvoru quarter-um unit economics-a thirumba kanakku pannunga.

**Unga browser-laye try pannunga.** Idhu tokens-la irundhu oru invoice-kku cost-aiyum, ovvoru customer type-kkum micham irukkura margin-aiyum kanakku pannudhu. Numbers-a ungalodadhaa maathip paarunga.

```python
# Illustrative token counts; prices are Anthropic list prices, USD per million tokens, checked 28 November 2026
INR_PER_USD = 94          # assumption; check today's rate
RETRY = 1.1               # 1 in 10 requests runs twice
OTHER_INR = 0.07          # storage, logs, hosting per request

def cost_per_invoice(tokens_in, visible_out, thinking, price_in, price_out):
    usd = tokens_in * price_in / 1e6 + (visible_out + thinking) * price_out / 1e6
    return usd * INR_PER_USD * RETRY + OTHER_INR

print(f"Sonnet 5.5, high effort: ₹{cost_per_invoice(1500, 200, 1600, 2, 10):.2f}")
print(f"Sonnet 5.5, low effort:  ₹{cost_per_invoice(1500, 200, 400, 2, 10):.2f}")
print(f"Haiku 5.5:               ₹{cost_per_invoice(1500, 200, 400, 0.10, 0.50):.2f}")

cost = 0.45               # blended cost after tiering, from the worked example
for name, invoices, pays in [("Light", 30, 999), ("Typical", 150, 999), ("Heavy", 2000, 2499)]:
    ai_cost = invoices * cost
    print(f"{name}: pays ₹{pays} before GST, AI cost ₹{ai_cost:.2f}, left ₹{pays - ai_cost:.2f}")
```

## Podhuvaa panra thappugal

- **Flat price-la unlimited AI.** Ellaaraiyum vida heavy-aana 5% users paadhikkum mela cost-a undaakki, avangalukku aagura cost-a vida kuraivaa pay pannalaam.
- **Theriyura reply length-a vachu price panradhu.** Thinking tokens output-aa bill aagudhu. Prices set panradhukku munnaadi avatrai alanga, ovvoru task-kkum effort level-a set pannunga.
- **GST-inclusive price-la margin-a kanakku panradhu.** Adhula 18% eppavume ungalodadhu illa, gateway innum sumaar 2% eduthukkum.
- **Exchange rate-a kandukkaama viduradhu.** Usage-la endha maatramum illaamale, rupee balaveenamaagumbodhu dollar-la bill aagura model vilai erum.
- **Beta usage-a vachu price panradhu.** Beta users aarvamaanavanga, ennikkaiyila kuraivu. Launch-kku appuram usage, request length, user mix ellaam maarum.
- **Per-account rate limit illaadhadhu.** Oru script allathu abuse pannappatta free trial ore raathiriyila oru maasa budget-a erichidalaam.
- **Yaarukkum theriyaama expire aagura credits.** Customers emaandha maadhiri unarndhu vittu povaanga. Oru meter kaattunga, munnaadiye warn pannunga, rollover-a allow pannunga.
- **Cost-a mattum vachu price panradhu.** Customers value-kku thaan pay panraanga; adhula konjathai capture pannunga.
- **Competitor-oda price-a copy panradhu.** Avanga costs, customers, value ellaam ungalodadhula irundhu vera.

## Practice pannunga

a16z-oda generative AI economics pathina essay-a padinga, oru independent comparison site-la ippodhaiya model prices-a check pannunga. Neenga use panra ovvoru price pakkathulayum check date-a ezhudhunga.

1. Ungalukku therinja oru AI feature-kku, tokens-la irundhu cost per request-a build pannunga: input, theriyura output, thinking, price, exchange rate, retries, matha costs. Appuram light, typical, heavy users-kku maasam ethanai requests-nu estimate pannunga.
2. Rendu pricing options-a design pannunga (udhaaranamaa, included usage-oda tiered onnu, usage-based onnu). GST illaadha prices-la, ovvoru user type-kkum AI cost poga enna micham-nu kanakku pannunga.
3. Rupee 7% balaveenamaa irukkura maadhiriyum, thinking tokens rettippaana maadhiriyum numbers-a thirumba run pannunga. Edhaavadhu segment negative-aa maarudhaa?
4. Willingness to pay-a test panna anju customers-kitta neenga kekkura kelvigalai ezhudhunga.

**Mudinjadhu-nnu eppo sollalaam:** neenga thernthedutha pricing-la light, typical, heavy users-kku margins-a kaatta mudiyum, cost per request-la ovvoru rupee-um enga irundhu varudhu-nnu vilakka mudiyum, ellaaraiyum vida heavy-aana users-kitta irundhu eppadi paadhukaakkureenga-nnu solla mudiyum.
