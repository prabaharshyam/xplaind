## Idhu enna

**Oru AI feature-ku pricing panradhu**-na, customers adhukku eppadi panam kudukkuvaanga-nu mudivu pannradhu, revenue adhoda costs-a nalla margin-oda cover pannudhaa-nu check pannradhu. Saadharana software-la irundhu idha vera maadhiri aakkura rendu unmaigal:

- **Oru use-ku maaruthal cost**: ovvoru request-um model tokens-kum infrastructure-kum panam selavaakkum. Heavy users light users-a vida romba adhigam selavaakkuvaanga.
- **Urudhiyaa theriyaadha value**: AI avangalukku evvalavu worth-nu customers innum kathukkitte irukkaanga.

| User | Maadham requests | Oru request-ku cost | Maadha cost |
|---|---|---|---|
| Light | 30 | ₹0.80 | ₹24 |
| Typical | 150 | ₹0.80 | ₹120 |
| Heavy | 2,000 | ₹0.80 | **₹1,600**: ₹999 subscription-a vida adhigam |

Oru user-ku maadha cost = requests x oru request-oda cost.

## Idhu eppadi work aagudhu

**Unga unit economics-a theriyaadhu vainga.** Unmaiyaana usage-la irundhu, light, typical, heavy users-ku oru request-oda cost-yum, oru user-ku maadham requests-um measure pannunga. Oru user-ku cost = requests × oru request-oda cost. Adha user kudukkuradhoda compare pannunga. Model costs kaalam pogap poga kurainjirukku, aana features nalla aagum podhu usage bodhuvaa adhigam vegamaa yerum.

**Pricing models.**

- **Bundled**: ippo irukkura plan-la serndhirukkum. Simple, adoption-a thoondum, aana costs margin-kulla maraiyum; fair-use limits thevai.
- **Tiered**: ucha plans-la AI illa adhigam AI irukkum ("Pro-la maadhathukku 100 AI summaries, Business-la unlimited"). Common-um, purinjukka easy-um.
- **Add-on**: AI feature-ku oru user-ku thani fee. Value-a theliva kaattum; adoption kammi.
- **Usage-based**: oru document-ku, oru nimishathukku, oru conversation-ku, oru credit-ku panam. Vilai-a cost-oda serkkum; customers budget panna kashtam.
- **Outcome-based**: oru resolved ticket-ku, oru qualified lead-ku panam. Value-oda serum; theliva measurement-um pagirndha risk-um thevai.

Neraya products avatrai kalandhu use pannum: included usage irukkura oru tier-um, adhukku mela charge-um.

**Margins-a kaappaathunga.** Fair-use limits, model tiering (simple requests-ku vilai kammi models), caching, sinna outputs, urgent illaadha velaiku batch processing. Top 5% users-a gavanichukkunga; avanga perumbaalum perumbaalaana cost-a ottivaranga.

**Value-vai vachu vilai podunga, cost-a vachu illa.** Cost kezha limit-a set pannum. Value mela limit-a set pannum: meettha neram, sambaadhicha revenue. Customers-kitta value pathi pesunga; surveys mattum illa, unmaiyaana offers-oda vilai-a test pannunga.

**Indian market kurippugal.** Consumer, sinna-business segments-la vilai sensitivity adhigam; rupee pricing, UPI payments, sinna pack sizes ("50 credits-ku ₹199") help pannum. Enterprise clients usage bands-oda predict panna koodiya annual pricing-a virumbuvaanga.

**Pricing models pakkathula pakkam:**

| Model | Example | Edhukku nalladhu | Gavanikka vendiyadhu |
| --- | --- | --- | --- |
| Bundled | Ovvoru plan-layum AI irukku | Adoption | Maraindha cost; fair-use limits thevai |
| Tiered | Pro-la maadhathukku 100, Business-la 2,000 | Theliva, upgrades | Sariyaana included amounts select panradhu |
| Add-on | Oru user-ku maadhathukku ₹299 AI-ku | Theliva value signal | Kammi adoption |
| Usage-based | Oru invoice-ku ₹0.60 | Vilai cost-a follow pannum | Customers budget panna kashtam |
| Outcome-based | Oru resolved ticket-ku | Vilai value-a follow pannum | Orumicha measurement thevai |

**Model cost maaradhu.** Per-token vilai kuraiya poghum, aana nalla features-na bodhuvaa adhigam, neelamaana requests. Unit economics-a ovvoru quarter-um unmaiyaana usage-la irundhu marubadiyum compute pannunga, beta-la irundhu illa.

**Value pathi customers-kitta pesuradhu.** Vilai-a fix panradhukku munnaadi, Varun-oda team paththu customers-kitta invoice entry evvalavu neram edukkudhu, yaar pannuvaanga-nu kettaanga. Sinna kadaigal, owner vaaraththukku oru rendu manikkoor-nu sonnaanga; accountants, avanga staff-ku maadhathukku muzhu naatkal-nu sonnaanga. Indha value vithyaasam, cost vithyaasam illa, accountants-ku thani Business plan-a justify pannudhu, yen-na feature avangalukku romba adhigam meettham seiyudhu, adhanaala sandhoshama adhigam kudupaanga.

**Browser-la try pannunga.** Vera vera vilai-la oru AI feature-oda margin-a kandupidinga. Numbers-a unga sondha numbers-aa maathunga.

```python
cost_per_use_inr = 0.60          # model, hosting and support per use; measure your own
uses_per_user_month = 120
for price in (49, 99, 149):
    cost = cost_per_use_inr * uses_per_user_month
    margin = (price - cost) / price
    print(f"₹{price}/month: cost ₹{cost:.0f}, margin {margin:.0%}")
```

## Podhuvaa panra thappugal

- **Flat price-la unlimited AI.** Heavy users unga-a nashtam aakkalaam.
- **Oru request-oda cost-a ignore panradhu.** Vilai set panradhukku munnaadi adha measure pannunga.
- **Cost-a vachu mattum vilai podradhu.** Customers value-kku panam kudukkuvaanga; adhula konjam pidichukkunga.
- **Complex credit systems.** Customers enna vaanguraanga-nu purinjukkanum.
- **Marubadiyum paakkaama irukkradhu.** Costs-um usage-um maarum; pricing-a avvappo review pannunga.

- **Competitor-oda vilai-a copy panradhu.** Avanga costs, customers, value ungalodadhu-la irundhu vera.
