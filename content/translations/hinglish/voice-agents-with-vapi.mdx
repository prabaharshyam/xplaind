## Ye kya hai

**Voice agent** ek AI hai jisse aap phone line par ya web page mein baat karte ho, aur woh wapas bolta hai. Andar se ye ek second mein kai baar teen systems ko chain karta hai:

1. **Speech-to-text** (transcriber) caller ki audio ko words mein badalta hai.
2. **Language model** tay karta hai ki kya bolna hai aur tool use karna hai ya nahi.
3. **Text-to-speech** (voice) reply ko natural audio mein badalta hai.

Ye loop khud banana matlab audio streams, interruptions, silence, phone networks aur latency sab sambhaalna. **Vapi** ek developer platform hai jo ye plumbing karta hai. Aap ek **assistant** configure karte ho, transcriber, model aur voice chunte ho, uske instructions likhte ho, use tools dete ho, aur ek phone number ya web-call button jodte ho. Conversation Vapi real time mein chalata hai.

```flow
dir: LR
title: Phone line, streaming audio, turn-taking, interruptions aur call logs Vapi sambhaalta hai
Caller speaks -> Transcriber -[text]-> LLM + prompt -[reply]-> Voice -> Caller hears
LLM + prompt -[tool call]-> Your server or n8n webhook | slots check, book, order look up
Your server or n8n webhook -[result]-> LLM + prompt
```

## Ye kaam kaise karta hai

**Assistant.** Vapi dashboard mein aap ek assistant banate ho aur ye set karte ho:

- **Model aur system prompt:** agent kaun hai, kya kar sakta hai, use kin facts ki zaroorat hai (timings, prices) aur pakke rules (medical advice kabhi nahi dena, book karne se pehle hamesha confirm karna).
- **First message:** call connect hone par wo kya bolta hai. Usmein ye shaamil karo ki wo ek AI assistant hai.
- **Transcriber:** speech-to-text provider aur language. Indian English, Hindi aur doosri languages ki quality providers ke beech alag hoti hai, isliye real speakers ke saath test karo.
- **Voice:** text-to-speech provider aur voice. Aisi voice chuno jo aapke callers ko natural lage, aur local names ka pronunciation test karo.

**Tools.** Tools baat ko action mein badalte hain. Aap ek function describe karte ho, jaise `book_slot(date, time, name, phone)`, aur Vapi ko call karne ke liye ek server URL dete ho. Model tay karta hai ki ise kab call karna hai; aapka server, ya webhook ke peeche ka n8n workflow, kaam karta hai aur ek result wapas deta hai jo agent bolta hai.

**Phone numbers.** Aap Vapi se number le sakte ho ya Twilio jaise telephony provider se laa sakte ho. Inbound calls aapke assistant tak jaati hain; reminders ya follow-ups ke liye API se outbound calls bhi shuru kar sakte ho. Client ko local number ka vaada karne se pehle check karo ki India ke liye kaunse countries aur number types supported hain.

**Conversation behaviour.** Settings control karti hain ki agent kab maane ki caller ne bolna khatam kiya (**endpointing**), caller beech mein bole toh kya ho, background noise handling, maximum call length, aur human ko transfer kab karna hai.

**Call ke baad.** Vapi transcripts, recordings (agar enabled ho) aur ek end-of-call report rakhta hai jo aapke server ko bheji ja sakti hai: ek summary, aapne jo structured data maanga, aur success criteria. Isi se aap quality review karte ho aur CRM ko feed karte ho.

| Concern | Achha kaisa dikhta hai | Wahan kaise pahunchein |
|---|---|---|
| Response delay | kareeb 1 second se kam | tez model, chhota prompt, tez tools |
| Samajhna | names aur numbers sahi | us language ke liye achha transcriber; wapas confirm karo |
| Task par tikna | out-of-scope requests mana karta hai | prompt mein saaf rules; edge cases test karo |
| Actions | bookings valid hain | sirf prompt mein nahi, tool mein validate karo |
| Hand-off | zaroorat par human | transfer ya message lene ka raasta |
| Bharosa | caller ko pata hai ye AI hai | first message mein batao; recording rules follow karo |

**Web calls bhi.** Wahi assistant Vapi ke web SDK se website ya app mein chal sakta hai, isliye "Talk to us" button bina phone line ke browser mein voice conversation shuru kar deta hai. Numbers kharidne se pehle prototype karne ka ye sasta tareeka hai.

**Code mein ek tool server.** Jab assistant tool call karta hai, Vapi aapke server URL par POST request bhejta hai, aur aapka server aise results ke saath jawab deta hai jo agent bolta hai. Ek chhota FastAPI handler; exact payload fields ke liye Vapi ke maujooda docs dekho:

```python
import os
from fastapi import FastAPI, Request, HTTPException

app = FastAPI()
SECRET = os.environ["VAPI_SERVER_SECRET"]          # the secret you set on the assistant

@app.post("/vapi/tools")
async def tools(request: Request):
    if request.headers.get("x-vapi-secret") != SECRET:
        raise HTTPException(status_code=401)
    body = await request.json()
    results = []
    for call in body["message"].get("toolCallList", []):
        name, args = call["function"]["name"], call["function"]["arguments"]
        if name == "book_slot":
            result = book_slot(**args)             # your validation and booking code
        else:
            result = "Sorry, I can't do that on this call."
        results.append({"toolCallId": call["id"], "result": result})
    return {"results": results}

def book_slot(date, time, name, phone):
    if not (phone.isdigit() and len(phone) == 10):
        return "The phone number should be 10 digits. Please ask the caller to repeat it."
    slot = calendar.find(date, time)
    if not slot:
        return f"{time} on {date} is taken. The nearest free times are {calendar.nearest(date, time)}."
    calendar.book(slot, name, phone)
    return f"Booked {name} for {time} on {date}. Read the date and time back to the caller."
```

Results bolne ke liye likhe jaate hain: chhote, aur agli baat ke saath. Validation aapke code mein rehti hai, sirf prompt mein nahi.

**Ek latency budget.** Ek second se upar ke gaps callers ko dikhte hain. Parts jodo aur har ek ko kam karo:

| Part | Typical range | Kaise kam karein |
| --- | --- | --- |
| Ye tay karna ki caller ruk gaya | 0.2 se 0.8 s | Endpointing tune karo; tez jawabon ke liye chhota |
| Speech to text | 0.1 se 0.4 s | India ke paas ka streaming transcriber |
| Model ka first token | 0.3 se 1.5 s | Chhota, tez model; chhota prompt |
| Tool call | 0.1 se 2 s | Tez tools; dheeron se pehle "let me check" bolo |
| Text to speech, first audio | 0.1 se 0.5 s | Streaming voice; chhota pehla vaakya |

Dashboard ke best case se nahi, real call logs se naapo, aur sirf average nahi, sabse dheeri calls bhi dekho.

**Live jaane se pehle calls test karna.** 20 scripted calls likho jo normal bookings, interruptions, galat numbers, background noise, vaakya ke beech mein Hindi ya Tamil, aur out-of-scope requests cover karein. Unhe alag-alag speakers ke saath phone par chalao, aur har ek ko score do: booking sahi, facts sahi, koi gadhe hue jawab nahi, jab chahiye tab hand over hua.

**India mein calling ke rules.** Call record karna aur transcripts store karna personal data process karna hai: first message aur apne privacy notice mein batao, aur recordings utne hi samay tak rakho jitna zaroori ho. Promotion ya reminders ke outbound calls TRAI ke commercial communication rules ke dayre mein aate hain, jinmein registration, number series aur consent shaamil hain. Koi bhi outbound campaign se pehle maujooda rules check karo.

## Ek worked example

Visakhapatnam ke Dr Rao ke dental clinic ki hafte mein lagbhag 40 calls chhoot jaati hain, zyadatar shaam 7 baje ke baad ki appointment requests. Faizan, ek automation freelancer, ek voice receptionist banata hai.

Woh ek chhota system prompt likhta hai: clinic ka naam, hours, fixed consultation fees ke saath teen services, treatment par kabhi baat na karne ka rule, aur book karne se pehle date, time aur phone number confirm karne ka rule. First message: "Hello, this is the AI assistant for Rao Dental. I can book or change appointments. How can I help?"

Woh n8n webhooks ki taraf point karte hue do tools banata hai. `check_slots` clinic ki Google Sheet se free slots padhta hai; `book_slot` booking likhta hai aur patient ko SMS confirmation bhejta hai. n8n workflow clinic hours ke bahar ke times reject karta hai, isliye confused model raat ke 3 baje book nahi kar sakta.

Testing mein teen problems milti hain. Average response time 1.8 seconds hai, isliye woh tez model par switch karta hai aur prompt chhota karta hai, jisse yeh lagbhag 0.9 seconds ho jaata hai. Transcriber "Gajuwaka" galat sunta hai, isliye woh use keyword ke roop mein jodta hai aur agent se locations wapas bulwata hai. Ek tester daant dard ki dawai ke baare mein poochta hai; agent jawab dena shuru kar deta hai, isliye woh rule pakka karta hai aur clinic ke on-call number par transfer jodta hai.

Launch ke baad, end-of-call reports ek sheet mein jaati hain jo receptionist har subah check karti hai. Chhoote hue after-hours bookings lagbhag khatam ho jaate hain.

## Aam galtiyaan

**Lambe prompts.** Har extra paragraph delay aur confusion jodta hai. Prompt ko focused rakho aur reference data tools mein daalo.

**Model par rules enforce karne ka bharosa karna.** Apne tools mein bhi validate karo: business hours, prices, permissions.

**Sirf apni awaaz se test karna.** Alag accents, background noise, interruptions, aur aise logon ke saath test karo jo vaakya ke beech mein man badal dete hain.

**AI hone ka disclosure na karna.** Callers ko pata hona chahiye ki woh AI se baat kar rahe hain, aur recording ke liye privacy rules ke tahat consent chahiye. Dono saaf bolo.

**Nikalne ka raasta nahi.** Hamesha human, callback ya message ka option do. Bot ke saath phans jaana customer khone ka sabse tez tareeka hai.

**Per-minute cost ko ignore karna.** Transcriber, model, voice aur telephony har ek per minute ya per token charge karta hai. Quote dene se pehle monthly minutes ka andaza lagao aur maujooda prices check karo.

- **Webhook secret check na karna.** URL dhoondhne wala koi bhi aapke tools call kar sakta hai.
- **Lambe, likhe hue style ke tool results.** Zor se padhne par ye dheere aur akde lagte hain.
- **Sirf apni awaaz se test karna.** Accents, noise aur languages accuracy badal dete hain.

## Jab voice agent galat choice hai

- **Callers ko bahut saare options compare karne hain**, jaise lambi price lists: WhatsApp message ya web page aasaan hai.
- **Bahut sensitive baatcheet**, jaise medical results ya debt collection, jahan insaan ko bolna chahiye.
- **Aapke callers ki languages ke liye kharaab transcription**, jo tests mein confirm ho.
- **Simple IVR menu pehle se kaam karta hai**, aur callers usse khush hain.

## Demo se production tak

- **Har call log karo** transcript, tool calls, har part ki latency aur outcome ke saath.
- **Hafte mein das calls review karo**, paanch fail hui aur paanch random.
- **Lambe gaps, high transfer rates aur fail hue tool calls par alert lagao.**
- **Har call par human ka raasta rakho:** transfer ya message lena.
- **Prompt, voice, transcriber ya model badalne ke baad har baar 20 scripted calls dobara test karo.**
