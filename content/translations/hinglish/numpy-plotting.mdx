## Ye kya hai

Machine learning numbers ki badi tables par maths hai, aur Python mein woh maths **NumPy** par chalta hai, fast numerical arrays ki library. pandas, scikit-learn aur PyTorch sab uske ideas par bane hain, isliye yahan seekhi habits seedhe model ke kaam mein aati hain. **Matplotlib** standard plotting library hai; Seaborn aur Plotly jaisi doosri libraries similar ideas use karti hain.

Core skills:

| Skill | Matlab | Example |
| --- | --- | --- |
| **Arrays aur shapes** | Arrays banana aur unki dimensions jaanna | `X.shape` `(50000, 3)` hai |
| **Vectorisation** | Poore arrays par ek saath maths | `prices * 1.18` |
| **Broadcasting** | Alag par compatible shapes ke arrays ko jodna | `X - X.mean(axis=0)` |
| **Masks aur indexing** | Condition ya position se data chunna | `y[y > 30]`, `X[:, 0]` |
| **Plotting** | Distributions, relationships aur trends dekhna | histogram, scatter, line, box plot |

```text
  X: shape (5, 3)                          means: shape (3,)
   distance  items  hour                   [ 4.2,  3.0, 15.4 ]
  [  2.1      1     13 ]                          |
  [  6.8      4     19 ]     X - means            | broadcast to every row
  [  3.0      2     11 ]   ------------>          v
  [  5.5      5     20 ]                   result: shape (5, 3), each column centred
  [  3.6      3     14 ]
```

Is lesson mein hum Bengaluru ki ek quick-commerce company ko follow karenge, jahan do simple plots ek logging bug aur delivery times ka ek chhupa hua factor dikhate hain. End tak aap teen plots se naya dataset explore kar paoge aur ek data problem bata paoge jo aapne pakadi.

## Ye kaam kaise karta hai

### Arrays aur shapes

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.shape)          # (2, 2)
```

12 features waale 10,000 customers ke dataset ki shape `(10000, 12)` hai. Ek single row ki shape `(12,)` hai. Numerical code ke zyadatar bugs shape mismatches hote hain, isliye `.shape` baar-baar print karo.

### Vectorisation

```python
prices = np.array([120, 450, 999])
with_gst = prices * 1.18            # every element at once
print(np.mean(prices), np.std(prices), np.percentile(prices, 90))
```

Vectorised code loop se chhota hota hai aur bade arrays par aksar dasiyon guna tez, kyunki kaam neeche optimised code mein hota hai.

**Axis** argument direction tay karta hai:

| Call | Result |
| --- | --- |
| `X.mean()` | Ek number: sab kuch ka mean |
| `X.mean(axis=0)` | Har column ke liye ek value: har feature ka mean |
| `X.mean(axis=1)` | Har row ke liye ek value: har record ka mean |

### Broadcasting

Shapes compatible hon toh NumPy chhote array ko bade ke saath match karne ke liye stretch karta hai. `(10000, 12)` array se `(12,)` array ke column means ghatane se har column ek line mein centre ho jaata hai:

```python
Z = (X - X.mean(axis=0)) / X.std(axis=0)    # each column: mean 0, std 1
```

### Indexing aur slicing

Arrays position se index hote hain, 0 se shuru, har dimension ke liye ek index:

```python
X[0]          # the first row: all features of the first record
X[:, 0]       # the first column: one feature for every record
X[10:20, 1:]  # rows 10 to 19, and every column from the second onwards
X[-1]         # the last row
```

Colon ka matlab "is dimension ka sab kuch". `X[:, 0]` ko zor se "every row, column zero" padhne se madad milti hai. Slices views hote hain, copies nahi: slice badalne se original array bhi badalta hai, isliye alag piece chahiye toh `.copy()` use karo.

### Boolean masks

```python
incomes = np.array([18000, 52000, 75000, 31000])
print(incomes[incomes > 50000])                     # [52000 75000]
print(incomes[(incomes > 20000) & (incomes < 60000)])
```

"And" ke liye `&` aur "or" ke liye `|` use karo, har condition ke aas-paas brackets ke saath.

### Reproducible random numbers

`rng = np.random.default_rng(42)` ek random generator deta hai jise aap bilkul dohra sakte ho, data sample karne ya use training aur test sets mein baantne ke liye.

### Machine learning mein zaroori plots

| Plot | Kya dikhata hai | Aam finding |
| --- | --- | --- |
| **Histogram** | Ek feature ka distribution | Skew, outliers, zero jaisi impossible values |
| **Scatter plot** | Do features, ya ek feature aur target ka relationship | Ek curve, ek cluster, kisi value par break |
| **Line chart** | Time ke saath values | Seasonality, achanak girawat, epoch ke hisaab se training loss |
| **Box plot** | Groups mein distributions | Ek city ki deliveries baaki se bahut dheemi |

Axes aur units hamesha label karo, aur order values jaise bahut skewed data ke liye **log scale** use karo.

## Ek example se samjho

Bengaluru ki ek quick-commerce company delivery time predict karna chahti hai. Aap 50,000 deliveries ko arrays mein load karte ho: distance km mein, items ki ginti, hour of day, aur lage hue actual minutes.

```python
import numpy as np
import matplotlib.pyplot as plt

# X (distance, items, hour) and y (minutes) were loaded earlier
print(X.shape, y.shape)                  # (50000, 3) (50000,)
print(np.percentile(y, [50, 90, 99]))    # median 14, p90 24, p99 61 minutes

plt.hist(y, bins=60)
plt.xlabel("Delivery time (minutes)"); plt.ylabel("Orders")
plt.show()

plt.scatter(X[:, 0], y, s=2, alpha=0.3)
plt.xlabel("Distance (km)"); plt.ylabel("Minutes")
plt.show()
```

**Histogram kya dikhata hai.** Dheemi deliveries ki lambi tail, jaisa expect tha, aur theek 0 minute par ek ajeeb spike: 412 deliveries jo bina time liye record hui hain. Ye logging bug hai, chamatkaar nahi.

**Scatter plot kya dikhata hai.** Time distance ke saath lagbhag 6 km tak steadily badhta hai, phir kood jaata hai. Un orders ko check karne par pata chalta hai ki woh ek alag dark store se aaye the jahan riders kam the.

| Plot | Finding | Model mein badlaav |
| --- | --- | --- |
| Minutes ka histogram | 0 minute par 412 deliveries | Un rows ko hatao ya theek karo; bug report karo |
| Distance vs minutes scatter | 6 km ke aage kood | Ek "store" feature jodo |
| Percentiles | p99 61 minute hai | Sirf average nahi, p90 aur p99 par errors report karo |

Koi ek metric ye cheezein do plots jitni saaf nahi dikhata, paanch minute mein, koi model train hone se pehle.

## Aam galtiyaan

- **Arrays par Python loops.** Vectorise karo; ye chhota aur bahut tez hai.
- **Shapes ko ignore karna.** Print karo, aur check karo ki broadcasting wahi kar rahi hai jo aap soch rahe ho.
- **Plot kiye bina modelling.** Plots bugs, outliers aur leakage jaldi dikhate hain.
- **Bina label ke charts.** Axes aur units plots ko doosron ke liye padhne layak banate hain.
- **Skewed data par linear scales.** Jahan values orders of magnitude mein phaili hon wahan log scales use karo.
- **axis=0 aur axis=1 mein ghalat-malat.** Direction confirm karne ke liye result ki shape dekho.
