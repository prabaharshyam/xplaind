## Ye kya hai

**PyTorch** neural networks banane aur train karne ke liye ek open-source Python library hai. Iske building blocks:

- **Tensors**: NumPy arrays jaise multi-dimensional arrays, jo CPU ya GPU par reh sakte hain aur gradients track karte hain.
- **Autograd**: tensors par hone wale operations record karta hai aur gradients automatically compute karta hai.
- **nn.Module**: models ki base class; layers aur models modules hain.
- **Dataset** aur **DataLoader**: data load karte hain aur shuffle kiye hue batches mein dete hain.
- **Optimisers**: gradients se weights update karte hain (SGD, Adam).

```flow
CSV of images and labels -> Dataset | __getitem__(i) gives (tensor 3x224x224, label 4)
Dataset -> DataLoader | batches of 64, shuffled, .to(device)
DataLoader -> nn.Module | forward(x) gives scores for 6 classes
nn.Module -> loss_fn -> loss.backward() -> opt.step()
opt.step() -[next batch]-> DataLoader
opt.step() -[each epoch]-> Validate | model.eval() + no_grad(), save the best checkpoint
```

Is lesson mein hum Pune ki ek textile manufacturer mein ek engineer ko follow karenge jo apne pehle PyTorch project ke roop mein fabric-defect classifier bana raha hai.

## Ye kaam kaise karta hai

**Tensors aur devices.** Data se tensors banao, `.shape` aur `.dtype` check karo, aur model aur data dono ko ek hi device par le jao (GPU ke liye `"cuda"`, warna `"cpu"`). Device mismatch beginners ki top galti hai.

**Data.** `Dataset` index se ek example aur uska label deta hai; `DataLoader` unhe batch aur shuffle karta hai. Training aur prediction dono waqt wahi preprocessing lagao.

**Model.** `nn.Module` ko subclass karo, layers `__init__` mein define karo, aur forward computation `forward` mein.

**Training loop.** PyTorch ka dil:

```python
model.to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(epochs):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()              # clear old gradients
        loss = loss_fn(model(x), y)  # forward pass and loss
        loss.backward()              # backpropagation
        opt.step()                   # update weights

    model.eval()                     # switch off dropout etc.
    with torch.no_grad():            # no gradients needed for evaluation
        val_loss = evaluate(model, val_loader)
    save_if_best(model, val_loss)
```

**Evaluation mode.** `model.eval()` dropout aur batch normalisation jaisi layers ko inference behaviour mein badalta hai; `torch.no_grad()` memory aur time bachata hai. `eval()` bhoolne par validation numbers galat aate hain; `no_grad()` bhoolne par memory waste hoti hai.

**Saving.** Model ka `state_dict` (uske weights) save karo, saath mein use dobara banane ke liye zaroori settings aur preprocessing. Sirf aakhri nahi, validation score ke hisaab se best checkpoint save karo.

**Reproducibility.** Random seeds set karo, settings aur library versions log karo.

**Higher-level tools.** PyTorch Lightning ya fastai jaisi libraries loop ko logging, checkpoints aur multi-GPU support ke saath wrap karti hain. Pehle plain loop seekho taaki wrappers ko debug kar sako.

**Ek minimal model aur dataset:**

```python
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader

class DefectData(Dataset):
    def __init__(self, rows, label_map, transform):
        self.rows, self.label_map, self.transform = rows, label_map, transform
    def __len__(self):
        return len(self.rows)
    def __getitem__(self, i):
        path, label = self.rows[i]
        return self.transform(load_image(path)), self.label_map[label]

class SmallNet(nn.Module):
    def __init__(self, classes=6):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(32, classes)
    def forward(self, x):
        return self.head(self.body(x).flatten(1))
```

`label_map` ek baar banta hai aur training aur validation dono datasets ko diya jaata hai, jo bilkul wahi fix hai jo worked example ko chahiye tha.

**Chalte-chalte shapes check karo.** Bahut saari PyTorch errors shape errors hoti hain. Training se pehle ek batch model se guzaaro aur har layer ke baad shape print karo. 224 pixels ke 64 colour images ke batch ka shape `[64, 3, 224, 224]` hota hai, aur model ka output `[64, 6]` hona chahiye. Jab error mein "mat1 and mat2 shapes cannot be multiplied" aaye, toh kisi layer ko jitne inputs mile, usne alag number expect kiya tha.

**GPU use karna.** `torch.cuda.is_available()` check karo aur script ke upar ek baar `device = "cuda" if torch.cuda.is_available() else "cpu"` set karo, phir har jagah `device` use karo. Google Colab ya Kaggle notebooks par free GPUs is path ke projects ke liye kaafi hain. GPU har layer ke bade matrix multiplications ko aksar das gunaa ya usse zyada tez kar deta hai, par dheemay data loading ke liye kuch nahi karta. Agar loop chalte waqt GPU khaali baitha ho, toh DataLoader par `num_workers` badhao taaki images parallel mein padhi aur resize ho.

**Loop se aadat tak.** Loop ek baar haath se likho aur template ki tarah rakho: upar seeds aur device, datasets aur loaders, model, optimiser aur loss, phir validation aur checkpoint saving ke saath epoch loop. Zyadatar naye projects mein sirf dataset aur model badalte hain.

**Ek poori, chalne laayak training script.** Synthetic tabular data, taaki ye kahin bhi CPU par chale; apna `Dataset` daal do:

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader, random_split

torch.manual_seed(0)
device = "cuda" if torch.cuda.is_available() else "cpu"

N, D, C = 6000, 20, 3
X = torch.randn(N, D)
true_w = torch.randn(D, C)
y = (X @ true_w + 0.5 * torch.randn(N, C)).argmax(1)

mean, std = X.mean(0), X.std(0)                      # save these with the model
ds = TensorDataset((X - mean) / std, y)
train_ds, val_ds = random_split(ds, [5000, 1000], generator=torch.Generator().manual_seed(0))
train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
val_dl = DataLoader(val_ds, batch_size=512)

model = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C)).to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
loss_fn = nn.CrossEntropyLoss()

def evaluate():
    model.eval(); correct = total = 0; loss_sum = 0.0
    with torch.no_grad():
        for xb, yb in val_dl:
            xb, yb = xb.to(device), yb.to(device)
            out = model(xb)
            loss_sum += loss_fn(out, yb).item() * len(yb)
            correct += (out.argmax(1) == yb).sum().item(); total += len(yb)
    return loss_sum / total, correct / total

best, patience, bad = float("inf"), 5, 0
for epoch in range(100):
    model.train()
    for xb, yb in train_dl:
        xb, yb = xb.to(device), yb.to(device)
        opt.zero_grad()
        loss_fn(model(xb), yb).backward()
        opt.step()
    val_loss, val_acc = evaluate()
    if val_loss < best - 1e-4:
        best, bad = val_loss, 0
        torch.save({"state_dict": model.state_dict(), "mean": mean, "std": std,
                    "epoch": epoch, "val_acc": val_acc, "torch": str(torch.__version__)}, "best.pt")
    else:
        bad += 1
        if bad >= patience:
            break
print(f"stopped at epoch {epoch}, best val loss {best:.3f}")
```

**Alag script mein load karke predict karo.** Wahi architecture rebuild karo, weights load karo, save kiya hua preprocessing lagao aur eval mode mein jao:

```python
ckpt = torch.load("best.pt", map_location="cpu", weights_only=True)   # never unpickle untrusted files
model2 = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C))
model2.load_state_dict(ckpt["state_dict"]); model2.eval()
new_rows = torch.randn(5, D)
with torch.no_grad():
    probs = model2((new_rows - ckpt["mean"]) / ckpt["std"]).softmax(1)
print(probs.round(decimals=2), "from epoch", ckpt["epoch"], "val acc", round(ckpt["val_acc"], 3))
```

Prediction ke waqt save kiye hue mean aur standard deviation bhool jaana sabse common chupchaap wale bugs mein se ek hai.

**GPUs par tez.** Mixed precision (forward pass ke aas-paas `torch.autocast(device_type="cuda", dtype=torch.bfloat16)`) modern GPUs par kam memory leti hai aur tez chalti hai, aur `torch.compile(model)` training ko aur tez kar sakta hai. Plain loop chal jaaye tab inhe jodo, aur check karo ki validation scores na badlein.

**Data loading aksar bottleneck hoti hai.** Agar GPU use kam hai, toh `DataLoader` mein `num_workers` badhao, data ko tez local disk par rakho, aur GPU par train karte waqt `pin_memory=True` set karo.

## Aam galtiyaan

- **Model aur data alag devices par.**
- **`zero_grad()` bhool jaana.** Batches ke beech gradients accumulate hote hain.
- **Validation ke waqt `model.eval()` aur `torch.no_grad()` bhool jaana.**
- **Training aur prediction mein alag preprocessing.**
- **Sirf aakhri epoch save karna.** Validation ke hisaab se best checkpoint rakho.
- **Shapes kabhi print na karna.** Ek batch model se guzaarke shapes print karne se error messages padhne ka ek ghanta bach jaata hai.
- **Weights ke saath preprocessing statistics save na karna.**
- **Validation ke hisaab se best ki jagah aakhri epoch rakhna.**
- **Correctness se pehle speed optimise karna**: pehle plain loop sahi karo.

## Jab PyTorch likhne ki zaroorat nahi

- **Tabular problems** jinhe scikit-learn ya gradient-boosting libraries achhe se sambhaal leti hain.
- **Standard models fine-tune karna**, jahan Hugging Face ka Trainer ya aise tools aapke liye loop wrap kar dete hain.
- **API ke zariye hosted models use karna**, bina kisi training ke.

## Demo se production tak

- **Poore checkpoints save karo**: weights, settings, preprocessing, label map, versions.
- Training aur serving mein **library versions pin karo**.
- Settings, metrics aur data version ke saath **har run log karo**.
- CI ke hisse ke roop mein ek fresh process mein **loading test karo**.
- Output original se match karne ki jaanch ke baad hi serving ke liye (TorchScript ya ONNX mein) **export karo**.
