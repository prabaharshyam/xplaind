## Ye kya hai

Ye teen structures is baare mein hain ki **items andar kaise jaate hain aur bahar kaise aate hain**.

**Stack** plates ke dher jaisa hai: upar se add karte ho aur upar se hi uthate ho. Jo item sabse baad mein gaya, woh sabse pehle nikalta hai, ise **LIFO** kehte hain. Undo buttons, browser back buttons aur programs function calls ko jis tarah track karte hain, ye sab stacks hain.

**Queue** railway ticket counter ki line jaisi hai: log peeche jud-te hain aur aage se jaate hain. Jo item sabse pehle gaya, woh sabse pehle nikalta hai, ise **FIFO** kehte hain. Print jobs, customer support tickets aur background tasks queues hain.

**Linked list** nodes ki chain hai. Har node mein ek value aur agle node ka pointer hota hai. Baaki sab ko shift kiye bina, do pointers badalkar kahin bhi node add ya remove kar sakte ho.

| Structure | Kaise kaam karta hai | Example |
|---|---|---|
| Stack (LIFO) | Upar push, upar se pop: last in, first out | A, B, C push karo; pop se C milta hai |
| Queue (FIFO) | Peeche enqueue, aage se dequeue: first in, first out | A, B, C enqueue karo; dequeue se A milta hai |
| Linked list | Har node mein value aur agle ka pointer | 9 ke baad 7 insert: sirf do pointers badalte hain |

```flow

title: Linked list mein 9 ke baad 7 insert karna
head -> 5 -> 9 -> 7 | naya node -> 2 -> end
```

## Ye kaam kaise karta hai

**Stacks** ko do operations chahiye: `push` (upar add karo) aur `pop` (upar se hatao). Python mein normal list achhi chalti hai: `append` push karta hai aur `pop()` pop karta hai, dono O(1). Top item ko hataye bina `peek` bhi kar sakte ho.

**Queues** ko `enqueue` (peeche add karo) aur `dequeue` (aage se hatao) chahiye. Python list buri queue hai, kyunki `pop(0)` har item ko shift karta hai, O(n). `collections.deque` use karo, double-ended queue, jiska `append` aur `popleft` dono O(1) hain. Threads ya programs ke beech share hone waale kaam ke liye queue library ya message queue service use hoti hai, jo aap system design track mein dekhoge.

**Linked lists** har item ko apne node object mein rakhti hain jo agle ki taraf point karta hai. Jis node ko aap pakde hue ho, uske baad insert karne ke liye naye node ko purane next node par point karao aur purane node ko naye par: O(1). Cost position se read karne mein hai. Item 500 tak pahunchne ke liye 500 pointers follow karne padte hain, O(n). Python mein built-in linked list type nahi hai kyunki lists aur deques zyadatar zaroorat poori kar dete hain, par idea interview problems mein aur doosre structures ke andar aata hai.

| Structure | Add | Remove | Item k read karna | Kis liye use karo |
|---|---|---|---|---|
| Stack (list) | push O(1) | pop O(1) | sirf top | undo, bracket matching, DFS |
| Queue (deque) | append O(1) | popleft O(1) | sirf front | tasks order mein, BFS |
| Linked list | jaane-pehchaane node par O(1) | jaane-pehchaane node par O(1) | O(n) | beech mein aksar edits, LRU caches |
| Array (list) | end mein O(1) | front se O(n) | O(1) | position se read karna |

**Interviews mein** ye structures doosre questions ke andar chhipe hote hain. "Most recent", "undo", "nested" ya "matching pairs" stack ki taraf ishara karte hain. "Aane ke order mein", "level by level" ya "tasks ko fairly process karo" queue ki taraf. Linked list questions aam taur par pointer sambhaalne ki parakh karte hain: list reverse karna, slow aur fast pointer se uska middle dhoondhna, ya loop detect karna. Pehle kaagaz par nodes aur arrows banao; zyadatar linked list bugs kho gaye pointers hote hain jo ek jhatpat sketch pakad leta.

## Ek example se samjho

Ananya Kota ke coaching centres mein use hone waale maths quiz app ke liye ek chhota expression checker bana rahi hai. Students `(2+3)*[4-(1+1)]` jaise answers type karte hain, aur app ko evaluate karne se pehle unbalanced brackets wale answers reject kar dene chahiye.

Stack ekdum fit hota hai. Har opening bracket ko uske matching closing bracket se band hona chahiye, aur sabse recent khula hua pehle band hona chahiye, jo bilkul LIFO hai.

```python
PAIRS = {")": "(", "]": "[", "}": "{"}

def balanced(text):
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)                 # push
        elif ch in PAIRS:
            if not stack or stack.pop() != PAIRS[ch]:
                return False                 # nothing to close, or wrong type
    return not stack                         # anything left open?
```

`[(])` ko trace karo: `[` push, `(` push, phir `]` `(` ko pop karta hai, jo `[` se match nahi karta, isliye `False` return hota hai. `{[()()]}` ke liye har pop match karta hai aur stack khaali ho jaata hai, isliye `True`. Function ek hi pass leta hai: O(n) time aur O(n) tak space.

Phir, live test ke dauran jab saikdon answers ek saath aate hain, tab bhi app ko submitted answers ko aane ke order mein mark karna hai. Ananya queue use karti hai:

```python
from collections import deque
pending = deque()
pending.append("answer-101")       # enqueue
pending.append("answer-102")
first = pending.popleft()          # "answer-101", O(1)
```

Fairness free mein mil jaati hai: kisi student ka answer line todkar aage nahi jaata.

## Aam galtiyaan

**list.pop(0) ko queue ki tarah use karna.** Chhote data par chalta hai aur lambe run mein O(n²) ban jaata hai. `deque.popleft()` use karo.

**Khaali stack ko pop karna.** Khaali list par `pop()` call karne se error aata hai. Pehle `if stack` check karo, jaise bracket checker karta hai.

**Aakhri check bhool jaana.** `((` jaisi bracket string mein koi pop fail nahi hota, par woh balanced nahi hai. Hamesha end mein check karo ki stack khaali hai.

**Aadat se linked list utha lena.** Python mein lists aur deques lagbhag har cheez ke liye fast hain. Linked list tab use karo jab aapko un nodes par sasta insert aur remove sach mein chahiye jo aap pakde hue ho.

**Linked list ka baaki hissa kho dena.** Insert karte waqt purane node ka pointer badalne se pehle naye node ko agle node par point karao, warna chain kat jaati hai.

**Graph search mein stack aur queue ko mila dena.** Depth-first search stack (ya recursion) use karti hai; breadth-first search queue. Badal do toh alag traversal milta hai.
