## Ye kya hai

Log aksar maths ki wajah se machine learning ko taalte hain. Aapko mathematician banne ki zaroorat nahi. Aapko teen areas ki **intuition** chahiye, aur formula milne par use follow kar paane ki kshamta:

| Area | Core idea | ML mein kahan aata hai |
| --- | --- | --- |
| **Linear algebra** | Data ko **vectors** (numbers ki list) aur **matrices** (numbers ki table) ki tarah dekhna, aur un par operations | Customer features ka vector hota hai; dataset ek matrix; model ke weights matrices |
| **Calculus** | Inputs ko thoda hilane par koi quantity kaise badalti hai | Models **gradient** ko follow karke seekhte hain, yaani woh direction jisme error sabse tezi se girta hai |
| **Probability** | Uncertainty ko describe karna | Models probabilities output karte hain; data ke distributions hote hain; evaluation poochta hai ki results kitne hold karenge |

```flow
dir: LR
Linear algebra | data aur weights vectors, matrices ki tarah: model kya compute karta hai -> Calculus | weights hilne par error kaise badalta hai (gradients): kaise seekhta hai
Calculus -> Probability | kitna sure hain? Outputs, base rates, Bayes: output ko kaise padhein aur kitna bharosa karein
```

Is lesson mein hum Hyderabad ki ek fintech ko follow karenge jo ek simple loan-default model train karti hai aur mushkil se seekhti hai ki scale aur base rates kyun matter karte hain. End tak aap gradient descent ko sketch ke saath samjha paoge aur bata paoge ki rare events mein zyadatar false alarms kyun aate hain.

## Ye kaam kaise karta hai

### Vectors aur similarity

**Vector** kisi ek cheez ko describe karne waale numbers ki list hai. Similar direction mein point karne waale do vectors similar cheezon ko describe karte hain. **Dot product** matching entries ko multiply karke jodta hai:

```text
  a = (3, 1, 2)      b = (2, 0, 4)
  a . b = 3*2 + 1*0 + 2*4 = 6 + 0 + 8 = 14
```

Bada dot product matlab similar direction. **Cosine similarity** vectors ki length se divide karti hai, isliye sirf direction count hoti hai, size nahi. Recommendation systems aur embedding search "similar" isi se naapte hain.

### Matrices transformations ki tarah

Vector ko matrix se multiply karne par woh transform hota hai: rotate, stretch ya features ka mix. Neural network ki ek layer ek matrix multiplication hoti hai, jiske baad ek simple non-linear function aata hai.

**Shapes match honi chahiye.** 100 rows aur 20 columns waali matrix ko 20 weights ke vector se multiply karo, toh 100 predictions milti hain:

```text
   data X            weights w        predictions
  (100 x 20)    x     (20 x 1)    =    (100 x 1)
       ^^                ^^
       these must be equal
```

Code mein zyadatar matrix bugs shape mismatches hote hain. Shapes print karo.

### Derivatives aur gradients

**Derivative** batata hai ki ek input thoda badalne par output kitna badalta hai. Kai inputs hon toh **gradient** un saare derivatives ko ek vector mein jodta hai jo uphill point karta hai.

**Gradient descent** model ko **loss** (error ka naap) par baar-baar chhote kadam downhill lekar train karta hai, jab tak improvement band na ho jaaye:

```text
   loss
    |  *
    |    *                        too-large steps bounce around:
    |      *                          *       *
    |        *  *                    *   *   *   *
    |            * * * * --           (never settles)
    +--------------------------> steps
          small, steady steps
```

**Learning rate** kadam ka size hai. Bahut bada ho toh training idhar-udhar kood jaati hai ya explode ho jaati hai; bahut chhota ho toh rengti hai. Loss curve dekho aur adjust karo.

### Chain rule aur backpropagation

Neural networks kai functions ko stack karte hain. **Chain rule** beech ki saari layers ke through ye nikaalta hai ki final error shuruaati weights par kaise depend karta hai. **Backpropagation** chain rule ko efficiently lagana hai, jiski wajah se bade networks train karna possible hota hai.

### Probability

- **Probability distribution** batata hai ki har value kitni likely hai.
- **Expected value** long-run average hai.
- **Conditional probability**, jaise "income ₹25,000 se kam hone par default ki probability", classification ka dil hai.
- **Bayes' rule** evidence ke saath beliefs update karta hai, aur samjhata hai ki accurate tests ke baawajood rare events mein itne false alarms kyun aate hain.

### Scaling

Agar ek feature 400 tak jaata hai aur doosra 1 se neeche rehta hai, toh gradient descent zigzag karta hai aur training dheemi ya unstable ho jaati hai. Features ko **standardise** karne se, taaki har ek ki range similar ho, kai models tez aur behtar train hote hain.

| Feature | Raw range | Standardise karne ke baad |
| --- | --- | --- |
| Income mein EMI ka hissa | 0.05 to 0.9 | about -2 to +2 |
| Pichhle saal ki missed payments | 0 to 12 | about -2 to +2 |
| Current job mein mahine | 1 to 400 | about -2 to +2 |

## Ek example se samjho

Hyderabad ki ek fintech ek simple model se monthly EMI default risk predict karti hai:

```text
score = w1 x (EMI / income) + w2 x (missed payments last year)
      + w3 x (months at current job) + b
```

**Vectors aur weights.** Har applicant teen features ka ek vector hai. Weights w1, w2, w3 aur b milkar model banate hain.

**Training.** Woh random weights se shuru karta hai, 50,000 purane loans ke liye predict karta hai, loss naapta hai (predictions asal nateeje se kitni door hain), gradient nikaalta hai (har weight ke saath loss kaise badalta hai), aur har weight ko downhill ki taraf khiskata hai. Kuch sau steps ke baad loss girna band ho jaata hai.

**Pehli problem: scale.** Shuru mein training unstable thi: loss idhar-udhar kood raha tha. "Months at job" 400 tak jaata tha, jabki EMI ratio 1 se neeche tha, isliye ek weight ko chhote kadam chahiye the aur doosre ko bade. Teeno features ko standardise karne se theek ho gaya.

**Doosra sabak: base rates.** Maan lo 2% applicants default karte hain, model 90% defaulters ko pakadta hai, aur 10% achhe applicants ko galat flag karta hai. 1,000 applicants mein:

| | Default karenge | Default nahi karenge | Total |
| --- | --- | --- | --- |
| Count | 20 | 980 | 1,000 |
| Model ne flag kiye | 18 (20 ka 90%) | 98 (980 ka 10%) | 116 |
| Flag nahi hue | 2 | 882 | 884 |

Flag hue 116 applicants mein se sirf 18, lagbhag chhe mein se ek, sach mein default karenge. Zyadatar flags false alarms hain, bas isliye ki achhe applicants bahut zyada hain. Isi liye bank score ko **review prioritise karne** ke liye use karta hai, automatic reject karne ke liye nahi.

## Aam galtiyaan

- **Pehle saara maths master karne ki koshish.** Intuition seekho, phir zaroorat ke hisaab se gehrayi badhao.
- **Shapes ko ignore karna.** Zyadatar matrix bugs shape mismatches hote hain; shapes print karo.
- **Learning rate ka andaaza lagana.** Loss curve dekho aur adjust karo.
- **Unscaled features.** Gradient-based models ke liye standardise karo.
- **Base rates ko ignore karna.** Rare events aur imperfect models ka matlab bahut saare false alarms.
- **Probability ko certainty padhna.** 0.8 score ka matlab likely hai, pakka nahi.
