## Ye kya hai

Ab tak jo programs aapne likhe, unka data code ke andar hi tha. Asli programs files se data padhte hain aur result wapas files mein likhte hain. Aur asli data gandha hota hai: file gayab, row ka format kharab, number ki jagah "NA". Do skills isse sambhaalti hain:

- **File input aur output:** text aur CSV files ko safely kholna, padhna aur likhna.
- **Error handling:** **exceptions** pakadna, taaki ek kharab input poore program ko crash na kare, aur problems saaf-saaf report ho.

```flow
dir: LR
Input: payments.csv | 412 rows, jinmein 3 kharab -> Har row ke liye | try: convert karo, total mein jodo
Har row ke liye -[chal gaya]-> Summary | total collected
Har row ke liye -[except: kharab row note karo, aage badho]-> problems.csv | check karne ke liye 3 rows
```

Is lesson mein hum Sana ke saath chalenge, jo Mysuru ke ek music school mein fees sambhaalti hain. Unki script pehli kharab row par crash ho jaati thi. Woh use aisi script banati hain jo kaam poora kare aur check karne waali rows ki list de. Lesson ke end tak aap ek gandhi CSV ko safely process kar paoge.

## Ye kaam kaise karta hai

### `with` se files kholna

```python
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

`with` block khatam hote hi file apne aap band kar deta hai, andar error aaye tab bhi. Hamesha `encoding="utf-8"` lagao, khaaskar Indian bhasha ke text aur ₹ jaise symbols ke liye. Iske bina jo file aapke laptop par chalti hai, woh colleague ke laptop par fail ho sakti hai.

### File modes

| Mode | Matlab | Khatra |
| --- | --- | --- |
| `"r"` | Read (default) | File na ho toh fail hota hai |
| `"w"` | Write, file mein jo kuch pehle se hai use **replace** karke | Purani report ko `"w"` se khologe toh woh mit jaayegi |
| `"a"` | End mein jodna | Logs ke liye safe |
| `"x"` | Nayi file banao, pehle se ho toh fail | Overwrite se bachne ke liye kaam ka |

### Line by line padhna

```python
with open("big_log.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())     # strip removes the newline at the end
```

Isse bahut bade files bhi chal jaate hain, kyunki sab kuch ek saath memory mein load nahi hota.

### CSV files

CSV file ek table hoti hai jo text ki tarah save hoti hai: har line ek row, aur fields ke beech comma. Khud comma se split karne ki jagah `csv` module use karo, kyunki fields ke andar quotes mein comma ho sakta hai, jaise address mein:

```text
name,address,amount
Asha,"12, MG Road, Mysuru",1500
```

```python
import csv
with open("orders.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["customer"], row["amount"])
```

`csv.DictReader` har row ko dictionary bana deta hai, jiski keys header se aati hain. `csv.DictWriter` dictionaries se rows likhta hai. Dhyaan rahe, har value **text** ki tarah aati hai: "1500", 1500 nahi. Maths karne se pehle convert karo.

### Exceptions

Kuch fail hone par Python **exception raise karta hai**: ek error object, jismein type aur message hota hai. Aam wale:

| Exception | Aam wajah |
| --- | --- |
| `FileNotFoundError` | File ka naam ya folder galat hai |
| `ValueError` | `int("twenty")` ya `float("NA")`: text number nahi hai |
| `KeyError` | Dictionary ya CSV row mein aisi key ya column nahi hai |
| `ZeroDivisionError` | Zero se divide karna, jaise khaali list ka average |
| `TypeError` | Text ko number se jodna |

Jo specific exceptions aap expect karte ho unhe pakdo aur tay karo ki kya karna hai:

```python
try:
    age = int("twenty")
except ValueError:
    age = -1          # mark as invalid instead of crashing
print(age)            # -1
```

Specific exceptions pakdo, sab kuch nahi. Bare `except:` asli bugs bhi chhupa deta hai, jaise variable name ki spelling galti. `finally` us clean-up ke liye hai jo hamesha chalna chahiye, aur `raise` se aap saaf message ke saath apni error utha sakte ho:

```python
if amount < 0:
    raise ValueError(f"Negative amount on line {line_no}")
```

### Kharab rows: jama karo, crash mat karo

Bahut saari rows process karte waqt har row ki error alag se handle karo, failures ko line numbers ke saath jama karo, aur end mein report do. 400 mein se ek kharab row se baaki 399 nahi rukni chahiye.

## Ek example se samjho

Sana Mysuru ke ek music school mein fees sambhaalti hain. Har mahine bank `payments.csv` bhejta hai. Unhe total collected chahiye aur haath se check karne waali rows ki list. Unki pehli script pehle "NA" par hi crash ho gayi aur kharab row scroll karke dhoondhni padi. Unki nayi script:

```python
import csv

total = 0
problems = []
try:
    with open("payments.csv", newline="", encoding="utf-8") as f:
        for line_no, row in enumerate(csv.DictReader(f), start=2):
            try:
                amount = float(row["amount"].replace(",", ""))
                total += amount
            except (ValueError, KeyError) as e:
                problems.append((line_no, row.get("student", "?"), str(e)))
except FileNotFoundError:
    print("payments.csv not found. Download it from the bank portal first.")
    raise SystemExit(1)

with open("problems.csv", "w", newline="", encoding="utf-8") as out:
    writer = csv.writer(out)
    writer.writerow(["line", "student", "error"])
    writer.writerows(problems)

print(f"Collected Rs {total:,.2f}; {len(problems)} rows need checking")
```

`enumerate(..., start=2)` rows ko 2 se number karta hai, kyunki file ki line 1 header hai. Isse line numbers wahi aate hain jo Sana ko file kholne par dikhte hain.

| Run | Rows | Convert hui | Problems | Result |
| --- | --- | --- | --- | --- |
| Purani script | 412 | Row 37 par ruk gayi | Crash | Total nahi, kharab row haath se dhoondhi |
| Nayi script | 412 | 409 | 3 ("NA" do baar, ek khaali) | Total aur problems.csv |

Is mahine woh teen rows paanch minute mein theek kar leti hain, aadha ghanta barbaad hone ki jagah.

## Aam galtiyaan

- **`with` bhool jaana.** Files khuli reh sakti hain ya data kho sakta hai.
- **`"a"` chahiye tha aur `"w"` use kiya.** Purana content hamesha ke liye gaya.
- **CSV lines ko comma se split karna.** `csv` module use karo; quotes ke andar ke commas aapka split tod denge.
- **Bhool jaana ki CSV values text hoti hain.** Maths se pehle `int()` ya `float()` se convert karo.
- **Bare `except` se sab kuch pakadna.** Jo specific exceptions expect karte ho wahi pakdo.
- **Pehli kharab row par ruk jaana.** Failures jama karo aur aage badho.
