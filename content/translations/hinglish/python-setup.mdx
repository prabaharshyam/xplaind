## Ye kya hai

Programs likhne se pehle aapko unhe likhne ki ek jagah aur chalaane ka ek tareeka chahiye. First-year student se lekar kisi badi company ke AI engineer tak, har Python programmer inhi teen tools ke saath kaam karta hai:

| Tool | Ye kya hai | Udaharan |
| --- | --- | --- |
| **Python** | Wo program jo aapka code padhta aur chalaata hai (**interpreter**) | Python 3, python.org se |
| **Ek code editor** | Jahaan aap code likhte ho; ye aapke code ko rang deta hai, chhoti galtiyaan pakadta hai aur type karne mein madad karta hai | Visual Studio Code (VS Code), free |
| **Ek terminal** | Ek text window jahaan aap commands type karte ho, unmein wo command bhi jo aapki file chalaata hai | VS Code ke andar waala terminal |

Setup tab poora hota hai jab teenon **ek raay par** hon: terminal Python ko dhoondh paaye, editor wahi Python istemaal kare, aur terminal usi folder mein khula ho jismein aapki file hai. Beginners ki lagbhag har problem inhi mein se kisi ek ke mel na khaane se hoti hai.

Jab ye mel kha jaayein, toh aap wo loop shuru karte ho jismein har programmer roz rehta hai:

```flow
dir: LR
File likho -> Save karo
Save karo -> Terminal mein chalao
Terminal mein chalao -> Output ya error padho
Output ya error padho -> Theek karo
Theek karo -[phir se]-> File likho
```

Ye lesson Madurai ke commerce graduate Karthik ke saath chalta hai, jo apne Windows laptop par Python set up karta hai aur un problems se takraata hai jo beginners ko sabse zyada aati hain. Iska check ek chhota project hai: aapki apni pehli file, terminal se chalaayi gayi aur online share ki gayi.

## Ye kaam kaise karta hai

### Version chuno

Sabse naya Python 3 install karo. Python 3.15.0, 9 October 2026 ko aaya, bugfix releases 3.15.1 aur 3.15.2 October mein hi aa gaye, aur lagbhag har do mahine mein aur aate hain, toh aapko jo aakhri number dikhe wo isse zyada ho sakta hai. Python 3.14 bhi theek hai. Teen niyam:

- **Python 3, Python 2 kabhi nahi.** Agar koi tutorial bracket ke bina `print "hello"` likhta hai, toh wo Python 2 ke liye hai; koi naya tutorial dhoondho.
- **Ek Python kaafi hai.** "Safe rehne ke liye" kai Python install karna, editor aur terminal mein matbhed paida karne ka sabse tez tareeka hai.
- **Bhaari libraries peeche reh sakti hain.** Kuch badi data aur AI libraries ko naya version support karne mein hafte lag jaate hain. Agar koi install hone se mana kare, toh us project ke liye 3.14 istemaal karo.

### Python install karo

| Computer | Kaise |
| --- | --- |
| Windows 10 ya 11 | python.org/downloads se ya Microsoft Store se **Python install manager** install karo. Isse aapko `python` aur `py` commands milte hain. Jab kuch bhi install na ho aur aap pehli baar Python chalao, toh ye latest release download kar leta hai; aap `py install 3.15` bhi type kar sakte ho. |
| Mac | python.org se macOS installer download karo aur use chalao. `python3` command istemaal karo. |
| Linux | Python 3 aam taur par pehle se hota hai. `python3` istemaal karo; kai systems par sirf `python` command hota hi nahi. |

Install manager ab Windows par Python install karne ka official tareeka hai. Puraana full installer (ek akeli `.exe`) Python 3.15 ke liye abhi bhi hai, par Python 3.16 se python.org ise dena band kar dega. Agar aap ise istemaal karo, toh iski pehli screen par **"Add python.exe to PATH"** par tick karo. **PATH** un folders ki list hai jinmein Windows tab dhoondhta hai jab aap koi command type karte ho. Agar Python ka folder us list mein nahi hai, toh Python install hone ke baavjood `python` type karna fail ho jaata hai.

### Install check karo

Ek **naya** terminal kholo aur type karo:

```text
python --version
```

Mac aur Linux par `python3 --version` type karo. Aapko 3 se shuru hone waala version dikhna chahiye, jaise `Python 3.15.0`. Windows par `py list` har wo Python dikhaata hai jiske baare mein install manager jaanta hai.

Naya terminal kyun? Terminal PATH ko ek hi baar padhta hai, jab wo khulta hai. Jo terminal install ke dauraan khula tha, uske paas abhi bhi puraani list hai aur wo Python ko nahi dhoondh paata. VS Code ka terminal PATH ko khud VS Code se copy karta hai, isliye sirf terminal tab nahi, VS Code ko poori tarah band karke phir se kholo.

### Jab Windows ko Python nahi milta

Windows learners ko sabse zyada ye teen messages milte hain:

| Aapko dikhta hai | Iska matlab | Fix |
| --- | --- | --- |
| `The term 'python' is not recognized...` (PowerShell) ya `'python' is not recognized as an internal or external command` (Command Prompt) | Python install nahi hai, ya uska folder PATH par nahi hai | Install manager install karo, ya puraana installer PATH box par tick lagaakar phir se chalao. Phir naya terminal kholo. |
| `Python was not found; run without arguments to install from the Microsoft Store...`, ya Store app khul jaata hai | Python install nahi hai. Windows mein **app execution alias** naam ka ek shortcut aata hai jo `python` ko Store par bhej deta hai. | Python theek se install karo. Agar puraana installer istemaal kiya tha, toh Start menu mein "Manage app execution aliases" dhoondho aur python.exe aur python3.exe waali dono App Installer entries band karo. |
| Aisa version jiski aapko ummeed nahi thi | Ek se zyada Python install hain, aur PATH par jo pehle aata hai wahi jeetta hai | `py list` aur `where.exe python` sab dikha dete hain. Faaltu waale uninstall karo. |

```flow
title: Terminal ko Python nahi mil raha
python --version type karo -[Python 3 dikhaata hai]-> Code likhne ke liye taiyaar
python --version type karo -[not recognized]-> Install karo ya PATH theek karo
python --version type karo -[Microsoft Store khulta hai]-> Install karo ya alias band karo
Install karo ya PATH theek karo -> VS Code band karke phir kholo
Install karo ya alias band karo -> VS Code band karke phir kholo
VS Code band karke phir kholo -> python --version type karo
```

### Mac par: pakka karo ki sahi python3 chal raha hai

macOS ka apna `python3` hota hai, `/usr/bin/python3` par. Ye Apple ke developer tools ka hissa hai aur aam taur par puraana hota hai; ise chalaane par ye Command Line Tools install karne ko keh sakta hai. python.org ka installer apne `python3` ko sabse pehle rakhta hai. Check karne ke liye naya terminal kholo aur `which python3` type karo. `/Library/Frameworks/Python.framework` ya `/usr/local/bin` ke andar ka path python.org waala hai; `/usr/bin/python3` Apple waala hai.

### Editor install karo aur use Python par point karo

VS Code aur uska **Python extension** (Microsoft waala) install karo. Apne kaam ke liye `python-practice` jaisa ek folder banao aur use File, Open Folder se kholo. Har project ko uske apne folder mein rakhne se baad mein bahut saari uljhan bachti hai.

Phir VS Code ko batao ki kaun-sa Python istemaal karna hai. Ctrl+Shift+P (Mac par Cmd+Shift+P) dabao, **Python: Select Interpreter** type karo aur wo Python chuno jo aapne abhi install kiya. Chuna hua version neeche status bar mein dikhta hai. Agar VS Code ne koi doosra Python chun liya, toh ajeeb nateeje aate hain: file terminal mein chal jaati hai, par editor aapke imports ke neeche laal line laga deta hai, ya Run button aisa version istemaal karta hai jo aapne jaan-boojhkar install nahi kiya. Interpreter badalne se pehle se khule terminals nahi badalte, isliye uske baad naya terminal kholo.

Aakhir mein, **File, Auto Save** chaalu karo. File ke tab par dot ka matlab hai ki usmein changes save nahi hue. Python disk par padi file chalaata hai, aapki screen par jo hai wo nahi, isliye bina save kiya fix kuch nahi karta.

### Apni pehli file likho

Us folder mein `hello.py` naam ki ek file banao:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

Line 1 Python ke built-in `datetime` module se `date` laati hai. Line 3 `name` naam ke variable mein text rakhti hai. Lines 4 aur 5 print karti hain, aur `date.today()` aapke computer se aaj ki date poochta hai.

`.py` ending Python aur aapke editor ko batati hai ki ye Python code hai. Windows default roop se file endings chhupa deta hai, toh jis file ko aap `hello.py` samajh rahe ho wo asal mein `hello.py.txt` ho sakti hai. File Explorer mein View menu kholo aur file name extensions chaalu karo, taaki sach dikh sake.

### Ise terminal se chalao

VS Code ke andar View, Terminal se terminal kholo. Terminal hamesha kisi ek folder "mein" kaam karta hai, aur prompt aam taur par dikhaata hai ki kaun-se, jaise `PS C:\Users\karthik\python-practice>`. Pakka karo ki ye wahi folder hai jismein aapki file hai:

| Command | Windows | Mac aur Linux |
| --- | --- | --- |
| Main kahaan hoon? | PowerShell mein `pwd` (VS Code ka default), Command Prompt mein `cd` | `pwd` |
| Yahaan ki files ki list | `dir` | `ls` |
| Kisi folder mein jaao | `cd python-practice` | `cd python-practice` |
| Ek folder upar jaao | `cd ..` | `cd ..` |
| File chalao | `python hello.py` | `python3 hello.py` |

`python hello.py` type karo aur Enter dabao. Output neeche dikhta hai. Tip: Tab file names poore kar deta hai, aur Up arrow pichhla command dohra deta hai.

VS Code ka Run button (upar daayin taraf waala triangle) aapke liye yahi command type kar deta hai. Phir bhi typed command seekho: servers, options aur remote machines, sabmein iski zaroorat padti hai.

### `>>>` prompt ek alag jagah hai

Agar aap bina file name ke sirf `python` (ya `python3`) type karo, toh aap **interactive shell** mein pahunch jaate ho, jo `>>>` prompt dikhaata hai. Ye ek baar mein Python ki ek line chalaata hai, jo `2 + 3` ya `len("Madurai")` jaise chhote experiments ke liye kaam ka hai. Par ye sirf Python samajhta hai, terminal commands nahi. Wahaan `python hello.py` type karne par ye aata hai:

```text
>>> python hello.py
  File "<python-input-0>", line 1
    python hello.py
           ^^^^^
SyntaxError: invalid syntax
```

`exit()` type karo aur Enter dabaakar terminal par waapas jaao, phir wahaan se apni file chalao.

### Error messages padho

Jab kuch gadbad hoti hai, Python ek error message print karta hai, aksar laal rang mein. **Aakhri line pehle** padho: wo error ka naam batati hai. Phir uske upar file name aur line number dekho, aur aapke code ki wo copy jismein Python jis hisse ki taraf ishaara kar raha hai uske neeche `^` ke nishaan hain.

Maan lo aap line 5 ka aakhri bracket mita dete ho. Python kuch bhi chalaane se pehle poori file check karta hai, toh koi output nahi aata, line 4 ka bhi nahi:

```text
  File "C:\Users\priya\python-practice\hello.py", line 5
    print("Today is", date.today()
         ^
SyntaxError: '(' was never closed
```

`^` us bracket ke neeche hai jo khola gaya aur kabhi band nahi hua. Baaki galtiyaan program chalte waqt hi saamne aati hain. Agar aap line 5 par `date.todya()` type karo, toh Python ke rukne tak line 4 print ho chuki hoti hai. Poori report ko **traceback** kehte hain:

```text
Hello, my name is Priya
Traceback (most recent call last):
  File "C:\Users\priya\python-practice\hello.py", line 5, in <module>
    print("Today is", date.todya())
                      ^^^^^^^^^^
AttributeError: type object 'datetime.date' has no attribute 'todya'. Did you mean '.today' instead of '.todya'?
```

Ye Python 3.15 ke shabd hain; puraane versions hint ko thoda alag dhang se likhte hain. Python aksar fix khud sujha deta hai, isliye line ke aakhir tak padho. Ek gotcha: line number wo jagah hai jahaan Python ne problem ko **notice** kiya, jo hamesha galti waali jagah nahi hoti. Maslan, kisi `if` line ke baad indent chhoot jaaye, toh wo uske neeche waali line par report hota hai, isliye ek line upar bhi dekho.

| Error | Aam wajah |
| --- | --- |
| `SyntaxError` | Koi bracket, quote ya colon chhoot gaya, ya `>>>` par terminal command type kar diya |
| `IndentationError` | Koi line indent ho gayi jabki nahi honi chahiye thi, ya tabs aur spaces mila diye |
| `NameError` | Kisi variable ki spelling galat, ya variable banaane se pehle hi istemaal kar liya |
| `AttributeError` | Dot ke baad kisi function ya method ke naam ki spelling galat |
| `ModuleNotFoundError` | Aisa package jo us Python mein install nahi hai jise aap chala rahe ho |
| `can't open file` | Terminal galat folder mein hai, ya file ka naam galat hai |

### Packages install karna: abhi se ek aadat

Jald hi aap `requests` ya `pandas` jaise packages install karoge. Unhe usi Python se install karo jo aapki files chalaata hai:

```text
python -m pip install requests
```

Mac par `python3 -m pip` istemaal karo. Sirf `pip install` kisi doosre Python ka ho sakta hai, yahi wajah hai ki learners ko us package ke liye `ModuleNotFoundError` dikhta hai jo unhone "abhi toh install kiya tha". Ubuntu aur Debian ke haal ke versions par system Python mein install karne par `error: externally-managed-environment` aakar ruk jaata hai. Ise zabardasti paar mat karo; iska fix virtual environment hai, jo "Packages aur virtual environments" lesson (B3) mein hai. Baad mein "Project tooling" lesson (B3) uv dikhaata hai, jo environments banaata hai aur aapke liye Python bhi install kar sakta hai. Aapki `hello.py` ko kisi package ki zaroorat nahi hai.

### Python chalaane ke doosre tareeke

**Google Colab** aur **Kaggle** jaise online notebooks bina kuch install kiye browser mein Python chalaate hain. Ye tab kaam aate hain jab aapka computer locked ho, puraana ho ya kai logon mein shared ho. Do saavdhaaniyaan: wahaan banaayi files session khatam hone par gaayab ho sakti hain, isliye apna kaam download kar lo; aur notebook wo terminal aur folder skills chhupa deta hai jinki har asli project ko zaroorat hoti hai. Shuruaat ke liye inhe istemaal karo, local setup ki jagah nahi.

## Ek worked example

Madurai ke commerce graduate Karthik ek shaam apne Windows 11 laptop par Python set up karte hain.

**Step 1: Store waala surprise.** Kuch bhi install karne se pehle wo PowerShell kholte hain aur `python` type karte hain. Microsoft Store khul jaata hai. Wo is lesson waala Windows shortcut pehchaan lete hain, Store band karte hain aur uski jagah Python theek se install karte hain.

**Step 2: install.** python.org/downloads se wo Python install manager install karte hain, nayi PowerShell window kholte hain aur `py install 3.15` type karte hain. Ye latest Python 3.15 download karke install kar deta hai.

**Step 3: naye terminal mein check.** Wo VS Code aur uska Python extension install karte hain. VS Code ke terminal mein `python --version` se `Python 3.15.2` print hota hai. Wo ek `python-practice` folder banaate hain, use File, Open Folder se kholte hain, aur Python: Select Interpreter se 3.15 chunte hain.

**Step 4: pehli error.** Wo `C:\Users\karthik\python-practice` mein apne naam ke saath `hello.py` likhte hain. Use chalaane ke liye wo Step 2 waali alag PowerShell window mein `python hello.py` type karte hain, jo unke home folder mein khuli thi, aur ye fail ho jaata hai. Message ka aakhri hissa ye hai:

```text
can't open file 'C:\\Users\\karthik\\hello.py': [Errno 2] No such file or directory
```

Dohre backslashes bas Python ka Windows path print karne ka tareeka hai. Path batata hai ki Python ne kahaan dhoondha: unke home folder mein, `python-practice` mein nahi. Wo `cd python-practice` type karte hain, phir `dir` se pakka karte hain ki `hello.py` wahaan hai, aur command phir se chalaate hain:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: bina save ka change.** Wo ek line jodte hain jo unka naam Tamil script mein print karti hai, aur file chalaate hain. Output waisa hi rehta hai. Phir unki nazar `hello.py` ke tab par dot par padti hai: unhone save hi nahi kiya tha. Wo Ctrl+S dabaate hain, phir se chalaate hain, aur Tamil waali line aa jaati hai, kyunki VS Code files ko UTF-8 mein save karta hai, jismein koi bhi script aa sakti hai. Wo Auto Save chaalu kar dete hain.

**Step 6: todo aur theek karo.** Jaan-boojhkar wo line 5 ka aakhri bracket mitaate hain aur file chalaate hain. Koi output nahi aata; aakhri line kehti hai `SyntaxError: '(' was never closed` aur `^` `print` ke baad waale bracket ki taraf ishaara karta hai. Wo bracket waapas lagaate hain aur ye chal jaati hai.

**Step 7: share.** Wo ek GitHub account banaate hain aur `hello.py` ko ek naye gist mein paste karte hain, jisse unhe share karne ke liye ek link milta hai. Wahi link is lesson ka check hai.

Ek hi shaam mein unka saamna Store shortcut, galat folder aur bina save ki file se hua, aur unhone har ek ko reinstall karne ki jagah message padhkar theek kiya.

## Aam galtiyaan

- **Pehli error par hi reinstall karna.** Zyaadatar errors folder, PATH ya bina save ki file ki hoti hain, toote hue install ki nahi. Aakhri line pehle padho.
- **Puraane terminal mein test karna.** Python install karne ya PATH badalne ke baad, VS Code poori tarah band karo aur naya terminal kholo.
- **Store shortcut ko Python samajh lena, ya puraane installer mein PATH waala tick chhod dena.** Install manager istemaal karo.
- **Galat folder se chalaana.** Chalaane se pehle `pwd` aur `dir` ya `ls` se check karo.
- **Bina save ki file chalaana.** Tab par dot ka dhyaan rakho, ya Auto Save chaalu karo.
- **`>>>` prompt par terminal commands type karna.** Pehle `exit()` type karo.
- **File ko `hello.py.txt` ke roop mein save karna.** File Explorer mein file name extensions chaalu karo.
- **Kai Python, aur VS Code kisi doosre ko istemaal kar raha hai.** Ek hi Python rakho aur use Python: Select Interpreter se chuno.
- **Sirf `pip install` istemaal karna.** `python -m pip install` istemaal karo, taaki package usi Python mein jaaye jo aapka code chalaata hai.

Neeche link kiya gaya Python for Everybody ka installation lesson apne operating system ke liye follow karo. Interpreter istemaal karne par Python ka apna tutorial page iske baad padhne ke liye achha hai.

Is lesson ka check ek chhota project hai:

1. **Install aur check karo.** Python install karo, naya terminal kholo, aur pakka karo ki `python --version` (ya `python3 --version`) 3 se shuru hota hai. Windows par `py list` bhi chalao.
2. **Likho** `hello.py` jo aapka naam aur aaj ki date print kare, ek `python-practice` folder mein jo VS Code mein khula ho aur jismein sahi interpreter chuna ho.
3. Ise terminal se command type karke **chalao**, sirf Run button se nahi.
4. Ise teen tareekon se **todo aur theek karo**: ek bracket mitao, line 4 par `name` ki spelling galat karo, aur ek baar galat folder se chalao. Har message padho aur theek karne se pehle wajah bolo.
5. **Shell mein jaakar dekho.** Sirf `python` type karo, `2 + 3` aazmao, phir `exit()` se baahar aao.
6. File ka link **share karo**, jaise ek GitHub gist ya repository.

**Aapka kaam poora hai jab aap** ek nayi `.py` file bana sako, use sahi folder mein khule terminal se chala sako, aur message ki aakhri line padhkar ek simple error theek kar sako.
