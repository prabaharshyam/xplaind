## Ye kya hai

Programs likhne se pehle aapko unhe likhne ki ek jagah chahiye aur unhe chalane ka ek tareeka. Har Python programmer, chahe student ho ya kisi badi company ka AI engineer, in teen cheezon ke saath kaam karta hai:

| Tool | Kya hai | Example |
| --- | --- | --- |
| **Python** | Woh program jo aapka code padhta aur chalata hai | Python 3, python.org se |
| **Code editor** | Jahan aap code likhte ho; yeh galtiyan highlight karta hai aur type karne mein madad karta hai | Visual Studio Code (VS Code), free |
| **Terminal** | Ek text window jahan aap commands type karte ho, jinmein woh command bhi hai jo aapki file chalata hai | VS Code ke andar ka terminal |

Teeno chalne lagein, toh woh loop shuru hota hai jismein har programmer rehta hai:

```flow
dir: LR
File likho -> Chalao -> Output ya error padho -> Theek karo
Theek karo -[phir se]-> File likho
```

Is lesson mein hum Karthik ke saath chalenge, jo Madurai ka commerce graduate hai. Woh apne Windows laptop par Python set up karta hai aur beginners ki do sabse aam problems se takraata hai. Is lesson ka check ek chhota project hai: aapki apni pehli file, terminal se chalayi hui aur online share ki hui.

## Ye kaam kaise karta hai

### Python install karo

| Computer | Kaise |
| --- | --- |
| Windows | python.org ya Microsoft Store se **Python install manager** install karo. Yeh `python` aur `py` commands set up kar deta hai. Purana full installer use karo toh uski pehli screen par **"Add python.exe to PATH"** tick karo. |
| Mac | python.org se installer download karo aur chalao. |
| Linux | Python 3 aksar pehle se install hota hai. |

Purane full installer mein PATH ka tick zaroori hai: yeh terminal ko `python` type karne par Python dhoondhne deta hai. Iske bina terminal kehta hai Python is not recognised.

Install check karne ke liye terminal kholo aur type karo:

```text
python --version
```

Mac aur Linux par `python3 --version` type karo. Aapko 3 se shuru hone waala version dikhna chahiye, jaise `Python 3.15.2`.

### Editor install karo

VS Code aur uska **Python extension** install karo. Phir apne kaam ke liye ek folder banao, jaise `python-practice`, aur use File, Open Folder se kholo. Har project ko apne folder mein rakhne se baad mein bahut confusion bachta hai.

### Apni pehli file likho

Us folder mein `hello.py` naam ki file banao:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

`.py` ka ending Python aur aapke editor ko batata hai ki yeh Python code hai.

### Terminal se chalao

VS Code ke andar View, Terminal se terminal kholo. Terminal hamesha kisi ek folder "mein" kaam karta hai. Dekho ki woh wahi folder ho jismein aapki file hai:

| Command | Windows | Mac aur Linux |
| --- | --- | --- |
| Main kahan hoon? | PowerShell (VS Code ka default) mein `pwd`, Command Prompt mein `cd` | `pwd` |
| Yahan ki files dekho | `dir` | `ls` |
| Folder ke andar jao | `cd python-practice` | `cd python-practice` |
| Ek folder upar jao | `cd ..` | `cd ..` |
| File chalao | `python hello.py` | `python3 hello.py` |

`python hello.py` type karo aur Enter dabao. Output neeche dikhega.

### Error messages padhna

Kuch galat ho toh Python ek **traceback** print karta hai. **Aakhri line pehle padho**: woh error ka naam batati hai. Uske upar ki line number batata hai ki Python ko problem kahan dikhi.

```text
  File "hello.py", line 4
    print("Today is", date.today()
                                  ^
SyntaxError: '(' was never closed
```

Beginners ki zyadatar errors inmein se ek hoti hain:

| Error | Aam wajah |
| --- | --- |
| `SyntaxError` | Bracket, quote ya colon chhoot gaya |
| `IndentationError` | Galat ya mix indentation |
| `NameError` | Variable ki spelling galat, ya banne se pehle use kiya |
| `can't open file` | Terminal galat folder mein hai, ya file ka naam galat hai |

### Python chalane ke aur tareeke

**Google Colab** aur **Kaggle** jaise online notebooks bina kuch install kiye browser mein Python chalate hain. Agar aapka computer locked down ya purana hai, aur data ke kaam ke liye, yeh kaam aate hain. Phir bhi terminal se files chalana seekho: asli projects, servers aur AI applications isi tarah chalte hain.

## Ek example se samjho

Karthik, Madurai ka commerce graduate, ek shaam apne Windows laptop par Python set up karta hai.

**Step 1: install.** Woh python.org se full installer download karta hai, "Add python.exe to PATH" tick karta hai aur install karta hai. (Python install manager bhi chalta, aur usmein tick nahi chahiye.)

**Step 2: check.** Naye terminal mein `python --version` `Python 3.15.2` print karta hai. PATH ka tick bhool jaata, toh yahin use "python is not recognized" dikhta.

**Step 3: editor aur file.** Woh VS Code aur Python extension install karta hai, `python-practice` folder banata hai, aur upar wale code se `hello.py` likhta hai, apne naam ke saath.

**Step 4: pehli error.** Woh `python hello.py` type karta hai aur dekhta hai:

```text
python: can't open file 'C:\Users\karthik\hello.py': [Errno 2] No such file or directory
```

Terminal uske home folder mein tha, `python-practice` mein nahi. Woh `cd python-practice` type karta hai, phir command dobara chalata hai. Ab chal jaata hai:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: ek badlaav.** Woh ek line jodta hai jo uska naam Tamil script mein bhi print kare, dobara chalata hai, aur woh sahi print hota hai kyunki VS Code files ko UTF-8 mein save karta hai.

| Problem | Jo message dikha | Fix |
| --- | --- | --- |
| Terminal galat folder mein | `can't open file ... No such file or directory` | `cd python-practice` |
| (Bach gayi) PATH set nahi | `python is not recognized` | PATH box tick karke dobara install karo |

Aakhir mein woh GitHub account banata hai aur `hello.py` ko nayi repository mein daalta hai, taaki uske paas share karne ke liye link ho. Wahi link is lesson ka check hai.

## Aam galtiyaan

- **Purane Windows installer mein "Add to PATH" bhool jaana.** Tab terminal kehta hai Python not found. Box tick karke dobara install karo aur naya terminal kholo.
- **Galat folder se chalana.** Chalane se pehle `pwd` (ya Command Prompt mein `cd`) se check karo ki aap kahan ho.
- **File ko .txt ending ke saath save karna.** Use `.py` par khatam hona chahiye. Windows par "show file extensions" on karo taaki dikhe.
- **Laal text dekh kar ghabrana.** Error ki aakhri line aur line number padho.
- **Tabs aur spaces mix karna.** Indent editor ko karne do.
- **Kai Python versions ek saath install karna.** Shuru karne ke liye ek recent Python 3 kaafi hai.
