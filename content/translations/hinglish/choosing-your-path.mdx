## Ye kya hai

Logon ke AI seekhna chhodne ki sabse common wajah ye nahi ki woh bahut mushkil hai. Wajah ye hai ki woh bina saaf raaste ke shuru karte hain: yahan ek YouTube video, wahan ek course, har hafte naya tool, aur progress ka koi ehsaas nahi. Path chunna ye theek karta hai.

Xplaind ke nau paths hain. Har ek shared lessons ke beech ek ordered raasta hai, har stage ke end mein ek project ke saath. Jo lessons aap khatam karte ho woh **har** us path par count hote hain jo unhe use karta hai, isliye baad mein switch karne se aapka kaam barbaad nahi hota.

| Path | Kiske liye | Coding |
| --- | --- | --- |
| **AI Engineer** | Jo log broad AI engineering role chahte hain: data, ML, LLM apps aur production | Haan |
| **Generative AI & LLM Engineer** | Language models par applications banane waale, RAG ki gehraai ke saath, Python basics se system design tak | Haan |
| **Forward Deployed Engineer (FDE)** | Engineers jo clients ke saath aur unke liye AI systems banate hain | Haan |
| **AI Product Manager** | Jo log decide karte hain ki kaunsa AI banana hai, use measure karte hain aur zimmedaari se ship karte hain | Nahi |
| **Agentic AI Engineer** | Engineers jo AI agents ko safely design aur chalate hain | Haan |
| **AI Automation Specialist** | Jo log n8n jaise tools aur AI steps se business workflows automate karna chahte hain | Halki |
| **AI Governance & Compliance Specialist** | Risk, compliance, legal aur policy ke log jo AI ko safe, fair aur lawful rakhte hain | Nahi |
| **Machine Learning Engineer** | Classical aur deep learning models train karne waale | Haan, plus maths |
| **MLOps Engineer** | Engineers jo ML aur LLM systems ko bade scale par bharosemand tareeke se chalate hain | Haan |

Is lesson mein hum Imran ke saath chalenge, jo Hyderabad mein accountant hain, jab woh kaam par AI use karne ke kuch mahine baad apna path chunte hain. Lesson ke end tak aap ek path chun chuke hoge, apne weekly hours plan kar chuke hoge aur pehla milestone set kar chuke hoge.

## Ye kaam kaise karta hai

Achhe se chunne ke liye teen checks chahiye, is kram mein: **background, goal, time.**

```flow
dir: LR
1. Background | mujhe pehle se kya aata hai? Coding, maths, koi domain? -> 2. Goal | kya is role ke asli job posts mujhe excite karte hain?
2. Goal -> 3. Time | hafte mein kitne ghante main mahino tak nibha sakta hoon?
3. Time -> Aapka path
```

### Check 1: apne background se shuru karo

| Kya aap code kar sakte ho, ya Python seekhoge? | Agar aap... | Shuru karo |
|---|---|---|
| Nahi | AI se workflows banana chahte ho | AI Automation Specialist |
| Nahi | Ye decide karna chahte ho ki kaunsa AI banana hai | AI Product Manager |
| Nahi | Risk, legal ya compliance mein kaam karte ho | AI Governance & Compliance |
| Haan | Strong maths ya data background hai | Machine Learning Engineer |
| Haan | DevOps ya cloud se aate ho | MLOps Engineer |
| Haan | Clients ke saath kaam karna pasand hai | Forward Deployed Engineer |
| Haan | Agents mein gehraai chahte ho | Agentic AI Engineer |
| Haan | LLMs aur RAG mein gehraai chahte ho | Generative AI & LLM Engineer |
| Haan | Abhi pakka nahi pata | AI Engineer (sabse broad) |

### Check 2: goal ko asli jobs se test karo

Job site kholo aur us role ke das asli job descriptions padho jahan path le jaata hai. Agar roz ka kaam excite kare, toh achha. Agar boring lage, toh mahine lagane se pehle doosra path dekho. Ye das minute ka check kai logon ko sabse hyped path se bacha leta hai jo unke liye suit nahi karta.

### Check 3: time ke baare mein honest raho

Koi deadline nahi hai. Har path aapki apni raftaar par chalta hai, isliye woh ghante chuno jo aap lambe time tak nibha sako, woh nahi jo ek achhe hafte mein kar paate ho:

| Weekly hours | Kaisa lagta hai |
| --- | --- |
| 3 ghante | Hafte mein ek lesson, achhe se |
| 5 ghante | Har hafte ek lesson aur uski practice |
| 8 ghante | Do lessons aur ek chhota project step |
| 12 ghante | Ek stage mein steady progress, projects ke liye time ke saath |

Paanch steady ghante, do hafte ke bees ghanton ke baad kuch nahi se behtar hain. Engineering paths par, jo aap pehle se jaante ho use skip karne ke liye level test lo.

### Plan banao

Plan ke teen hisse hote hain:

1. **Fixed study slots** apne hafte mein, jaise Tuesday aur Thursday shaam aur Sunday subah. Unhe meetings ki tarah calendar mein daalo.
2. **Chaar hafte ke andar pehla milestone**, jaise stage 1 khatam karna ya uska project banana.
3. **Accountability**: aapke saath seekhta ek dost, study group, ya har hafte apni progress share karna.

### Pehle stage ke baad dobara dekho

Stage 1 ke baad poochho: kya mujhe ye pasand aa raha hai, aur kya ye mujhe role ki taraf le ja raha hai? Agar nahi, toh switch karo. Aapke khatam kiye lessons saath aate hain, isliye bahut kam nuksaan hota hai.

## Ek example se samjho

Imran, 34, Hyderabad ki ek distribution company mein accountant hain. Woh kuch mahine se kaam par AI assistant use kar rahe hain. Unhe bank reconciliations tez karne mein ise use karna achha laga aur woh aur karna chahte hain, par programmer banne mein unhe koi interest nahi.

**Background.** Coding nahi, strong finance aur process knowledge, Excel formulas mein comfortable.

**Goal.** Woh das job posts padhte hain. "AI automation specialist" aur "finance automation analyst" titles waale roles mein n8n, Power Automate, APIs aur process mapping ka zikr hai, aur "invoice processing automate karo" aur "manual reconciliation kam karo" jaise kaam bataye gaye hain. Ye bilkul wahi hai jo unhe pasand aaya tha.

**Time.** Unke do chhote bachche hain. Realistic roop se: do weekday shaamein aur ek weekend ki subah, lagbhag hafte mein 5 se 6 ghante. Is raftaar par AI Automation Specialist path mein lagbhag teen mahine lagte hain.

Unka plan:

| Hissa | Imran ka plan |
| --- | --- |
| Path | AI Automation Specialist |
| Study slots | Tuesday aur Thursday raat 8 se 9:30, Saturday subah 9 se 11 |
| Pehla milestone | Chaar hafte mein: unka pehla n8n workflow jo invoice emails padhta hai aur unhe sheet mein log karta hai |
| Accountability | Har Sunday ek colleague ko chhota update bhejte hain jo khud bhi seekh raha hai |
| Final project | Ek asli reconciliation process jo unke manager ne tab offer kiya jab Imran ne unhe plan ke baare mein bataya |

Manager ko batana sabse achhi chaal nikli: unka final project ab asli kaam hai, jo unke portfolio ko practice exercise se kahin zyada strong banayega.

## Aam galtiyaan

- **Sabse hyped path chunna.** Woh chuno jo aapke background aur us kaam se match karta ho jo aapko pasand aaye.
- **Unrealistic hours plan karna.** Woh ghante chuno jo aap mahino tak nibha sako, woh nahi jo aap chahte ho ki aapke paas hon.
- **Har hafte path badalna.** Dobara sochne se pehle ek stage ke liye commit karo.
- **Projects skip karna.** Employers projects dekhna chahte hain, aur asli confidence wahin se aata hai.
- **Bina accountability ke akele seekhna.** Ek insaan ke saath weekly check-in se aap zyada chalte rahoge.
- **Perfect plan ka intezaar karna.** Ek achha plan jo isi hafte shuru ho, perfect plan se behtar hai jo agle mahine shuru ho.

## Practice karo

Bade picture ke liye Watch & learn panel ka video lesson dekho, phir Xplaind ke Roadmaps page par wapas aao.

Is lesson ka check aapka plan hai. Xplaind par ek path chuno aur "Make this my path" dabao. Phir ek page ka plan likho, jisme ho:

1. **Ye path kyun**, do sentences mein, aapke background aur aapne jo job posts padhe unke aadhar par.
2. **Aapke weekly study slots**, jo pehle se calendar mein hon.
3. **Aapka pehla milestone aur uski date**, lagbhag chaar hafte door.
4. **Kiske saath progress share karoge**, aur kab.

Pehla lesson isi hafte shuru karo.

**Aapka kaam poora jab:** aapka chuna hua path Xplaind par "your path" ke roop mein dikhe aur aapka pehla study slot calendar mein ho.
