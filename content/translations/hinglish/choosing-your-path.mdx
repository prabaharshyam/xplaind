## Ye kya hai

AI seekhna shuru karne waale bahut se log beech mein atak jaate hain kyunki unke paas koi saaf raasta nahi hota: yahaan ek video, wahaan ek course, har hafte ek naya tool, aur teen mahine baad bhi koi skill poori nahi. Path chunna ise theek karta hai.

Xplaind par **path** ek job role tak ka kram waala raasta hai, jo shared lessons se bana hai. Har path stages mein bata hai. Kai stages ke saath ek guided project aata hai, aur har path mein kam se kam ek guided project hai jo aap kisi employer ko dikha sakte ho. Aap jo lessons poore karte ho wo **har** us path par gine jaate hain jo unhe use karta hai, isliye baad mein badalne se aapki mehnat bekaar nahi jaati.

Xplaind par das paths hain. Length waala column steady padhaai ke liye Xplaind ka mota andaaza hai. Ye sirf seekhne ka time hai: iske upar kuch mahinon ki job search bhi plan karo.

| Path | Kiske liye hai | Coding | Moti length | Level test |
| --- | --- | --- | --- | --- |
| **AI Engineer** | Students aur developers jo AI engineering ka chauda role chahte hain | Haan, pehle din se | 9 mahine | Haan |
| **Generative AI & LLM Engineer** | Naye log aur engineers jo language models par apps banana chahte hain, RAG gehraai se | Haan, level B2 se | 9 mahine | Haan |
| **Agentic AI Engineer** | Developers jo pehle se Python se language model API call kar sakte hain | Haan | 4 mahine | Haan |
| **Forward Deployed Engineer (FDE)** | Engineers jinke paas ek saal ya usse zyada Python ka anubhav hai aur jinhe client ka kaam pasand hai | Haan | 6 mahine | Haan |
| **Machine Learning Engineer** | Graduates aur engineers jo Python aur school maths mein comfortable hain | Haan, saath mein maths | 9 mahine | Nahi |
| **MLOps Engineer** | Backend, DevOps, data aur cloud engineers | Haan | 6 mahine | Haan |
| **AI Security Engineer** | Students, developers aur IT ya security staff; security ki zero jaankaari se shuru hota hai | Thodi (halka Python) | 6 mahine | Nahi |
| **AI Automation Specialist** | Operations, support, sales aur marketing ke log, freelancers, chhote business owners | Thodi (APIs, JSON, chhote scripts) | 3 mahine | Nahi |
| **AI Product Manager** | Product managers, business analysts, founders aur consultants | Nahi | 3 mahine | Nahi |
| **AI Governance & Compliance Specialist** | Risk, compliance, legal, audit, privacy aur policy ke log | Nahi | 3 mahine | Nahi |

Chunne se pehle do baatein jaan lo:

- **Ho sakta hai aapko path ki zaroorat hi na ho.** Agar aap apni maujooda job AI se tezi se karna chahte ho, aur naya role nahi chahte, toh iski jagah Library ke B1 using-AI lessons se shuru karo: prompting, writing aur summarising, research, aur AI ke jawaab check karna.
- **Poore roadmap ke liye account chahiye.** Sign in kiye bina aapko har path ka sirf pehla stage dikhta hai. Account hone par roadmaps aur lessons free hain, aur account aapka path aur progress bhi save karta hai. Accounts 18 saal aur usse upar ke logon ke liye hain; agar aap 18 se kam ke ho, toh quick answer aur har lesson ka pehla hissa Library mein khule rehte hain.

Ye lesson Hyderabad ke accountant Imran ke saath chalta hai, jab wo apna path chunte hain. Aakhir tak aap apna path chun chuke hoge, apne ghante plan kar chuke hoge aur pehla milestone tay kar chuke hoge.

## Ye kaam kaise karta hai

Achhe se chunne ke liye ek sawaal aur phir teen checks chahiye, isi kram mein: **naya role ya nahi, phir background, goal aur time.**

```flow
dir: LR
title: Path kaise chunein
Start | kya mujhe naya role chahiye? -[nahi]-> Using-AI lessons | maujooda job mein tezi se kaam

1. Background -> 2. Goal | kya das asli job posts mujh par fit hoti hain?
2. Goal -> 3. Time | ghante jo main mahinon tak nibha sakoon
3. Time -> Aapka path
```

### Check 1: apne background se shuru karo

Sabse zyada buzz waale role se nahi, jo aapke paas pehle se hai wahaan se shuru karo. Har path ek starting point maankar chalta hai, isliye apna usse milaao:

| Aapka starting point | Yahaan se shuru karo | Path kya maankar chalta hai |
| --- | --- | --- |
| Aap tay karna chahte ho ki kaun-sa AI banana hai, aur code nahi karna chahte | AI Product Manager | Code nahi; engineers ke saath achhe se kaam karne laayak seekhte ho |
| Aap risk, legal, audit, compliance ya privacy mein kaam karte ho | AI Governance & Compliance | Code nahi; aapki domain ki samajh hi aapka faayda hai |
| Aap business processes chalaate ho aur halka code seekhoge | AI Automation Specialist | Aap APIs aur JSON padhoge aur chhote scripts likhoge |
| Aap IT support, networking ya security mein kaam karte ho, ya security mein dilchaspi hai | AI Security Engineer | Halka Python; security ki basics zero se sikhaai jaati hain |
| Aap code mein naye ho lekin language-model apps ke liye Python seekhne ko taiyaar ho | Generative AI & LLM Engineer | AI basics se shuru; level B2 se Python |
| Aap code karte ho, ya abhi Python seekhoge, aur sabse chauda role chahte ho | AI Engineer | Pehle stage se Python |
| Aap pehle se Python se language model API call karte ho | Agentic AI Engineer | Tool calling se shuru hota hai, isliye chhota hai |
| Aapke paas ek saal ya usse zyada Python hai aur client meetings pasand hain | Forward Deployed Engineer | Stage 1 se production-level Python |
| Aap Python jaante ho aur aapko maths, statistics aur data pasand hai | Machine Learning Engineer | Python aur school maths |
| Aap backend, DevOps, data ya cloud engineer ho | MLOps Engineer | Linux, containers aur cloud aapko jaldi aa jaayenge |

Label nahi, assumption check karo. Jis fresher ne kabhi koi API call nahi kiya, wo Agentic AI Engineer chune toh pehle hi hafte mein deewar se takraayega; GenAI path iski jagah dheere-dheere agents tak le jaata hai.

### Teen engineering paths jo ek jaise dikhte hain

AI Engineer, Generative AI & LLM Engineer aur Agentic AI Engineer aapas mein sabse zyada overlap karte hain. Ye kai lessons share karte hain, lekin alag-alag jagah se shuru hote hain aur alag-alag cheezon par zor dete hain:

| | AI Engineer | Generative AI & LLM Engineer | Agentic AI Engineer |
| --- | --- | --- | --- |
| Pehla stage | Python aur data ki neenv | AI basics, bina code (B2 se Python) | Model APIs, structured output, tool calling |
| Kya cover karta hai | Classical ML, deep learning aur transformers, phir LLM apps, testing, production, system design | Naye learner se system designer tak nau levels: prompts, gehraai se RAG, agents, evals, production | Agent design, frameworks, MCP, reliability, production |
| Length | 9 mahine | 9 mahine | 4 mahine |
| Ise chuno agar | Aap chauda role chahte ho; India ki kai AI engineer posts ML basics bhi maangti hain | Aap pakke ho ki language-model apps hi chahiye, ya zero code se shuru kar rahe ho | Aap pehle se language models ke saath banaate ho aur agents mein gehraai chahte ho |

**Decision rule:** agar aap code karte ho aur tay nahi kar pa rahe, toh AI Engineer lo, jo sabse chauda hai. Zero code se ho, toh GenAI path lo, jo sabse aaraam se shuru hota hai. Agentic AI Engineer doosre kadam ke taur par lo, jab aap API call kar sako. FDE bhi milti-julti engineering hai, saath mein client ka kaam, un logon ke liye jinke paas ek saal ya usse zyada Python hai.

### Check 2: goal ko asli jobs se parkho

Mahinon commit karne se pehle, ek shaam das asli job posts par lagao. Apne shehar mein us role ke liye Naukri ya LinkedIn par search karo aur chaar columns note karo:

| Title | Shehar ya remote | Kitne saal maange | Top teen skills ya duties |
| --- | --- | --- | --- |
| AI Automation Engineer | Hyderabad | 1 se 3 | n8n, APIs, process mapping |

Title nahi, duties padho: "India mein AI careers" lesson dikhata hai ki "AI engineer" naam ki post asal mein ML ka kaam kaise ho sakti hai. Phir teen rules lagao:

- **Kya duties aapko excite karti hain?** Agar das mein se zyaadatar posts aise kaam batati hain jo aapko har hafte achha lagega, toh goal rakho. Agar nahi, toh abhi doosra path dekho, chauthe mahine mein nahi.
- **Kya zyaadatar posts teen ya usse zyada saal maangti hain?** Toh ek bridge plan karo: paas ka koi junior role, ya pehle apni maujooda company ke andar koi AI project. Jaise, zyaadatar FDE aur AI product manager posts pehle ka engineering ya product anubhav maangti hain.
- **Kya aapke shehar mein lagbhag koi post nahi hai?** Remote posts, sabse paas ka hub aur global capability centres (GCCs) ke careers pages dekho, jo aksar seedhe hire karte hain.

### Freshers aur working professionals

- **Freshers** un paths par sabse achha karte hain jinmein asli entry-level hiring aur projects ka portfolio ho: AI Engineer, GenAI, ML Engineer aur AI Automation. Jobs page 0 se 2 saal ke liye typical pay dikhata hai (2 November 2026 ko check kiya), jaise AI Engineer ke liye saal ka 6 se 12 lakh CTC aur AI Automation Specialist ke liye 4 se 8 lakh. FDE aur AI Product Manager ke oonche early bands freshers ko shaayad hi kabhi milte hain.
- **Working professionals** sabse tezi se us path par switch karte hain jo unki pehle ki jaankaari dobara use karta hai: DevOps se MLOps, compliance se governance, Java developer se FDE. Sabse tez raasta aksar apni hi company ke andar ek AI pilot hota hai.

### Check 3: time ke baare mein imaandaar raho

Koi deadline nahi hai. Har path aapki apni raftaar par chalta hai, isliye hafte ke utne ghante chuno jitne aap mahinon tak nibha sako, na ki jitne zyada se zyada kisi achhe hafte mein kar paao:

| Hafte ke ghante | Kaisa lagta hai |
| --- | --- |
| 3 ghante | Hafte mein ek chhota lesson, theek se |
| 5 ghante | Har hafte ek lesson aur uski practice |
| 8 ghante | Do lessons aur project ka ek chhota step |
| 12 ghante | Ek stage mein steady progress, projects ke liye time ke saath |

Ghanton ko date mein badalne ke liye ek chhota hisaab lagao: har lesson page par uske ghante dikhte hain, toh ek stage ke ghante jodo, apne hafte ke ghanton se bhaag do aur practice ke liye kareeb ek tihaai jod do. Level test waale paanch paths (AI Engineer, GenAI, Agentic AI, FDE aur MLOps) par roadmap mein **Find my level** dabao: test wo skip kar deta hai jo aapko pehle se aata hai, aur result dikhata hai ki aapke ghanton par baaki mein kareeb kitne hafte lagenge. Baaki paanch paths stage 1 se shuru hote hain. Do hafte bees ghante aur phir kuch nahi, isse paanch steady ghante behtar hain.

### Plan banao

Plan ke teen hisse hain:

1. **Hafte mein tay study slots**, jaise Tuesday aur Thursday ki shaam aur Sunday ki subah. Inhe meetings ki tarah calendar mein daalo, aur jo busy hafte aapko pehle se pata hain, jaise exams ya month-end close, unhe note karo.
2. **Chaar hafton ke andar ek pehla milestone** jo aap kisi ko dikha sako: ek poora stage, ek pehla workflow, ek chhota chalta hua app. Check karo ki uske lesson ghante aapke slots ke chaar hafton mein, thodi gunjaaish ke saath, fit ho jaayein.
3. **Accountability**: ek naam waala vyakti, aapke update ka ek tay din, aur khud update, jaise ek line ki kya poora kiya aur aage kya hai.

### Pehle stage ke baad dobara aanko

Stage 1 ke baad poocho: kya mujhe ye kaam achha lag raha hai, aur kya ye mujhe job posts waale role ki taraf le ja raha hai? Agar nahi, toh badlo. Aapke poore kiye lessons saath aate hain: jaise "AI, machine learning aur language model: teeno asal mein kya hain" das mein se chhah paths par hai. Ek lesson mushkil tha ya ek hafta kharaab gaya, isliye mat badlo. Aisa har path par hota hai.

## Ek example se samjho

Imran, 34, Hyderabad ki ek distribution company mein accountant hain. Wo kuch mahinon se kaam par ek AI assistant use kar rahe hain. Bank reconciliations jaldi karne ke liye use use karna unhe achha laga aur wo aur karna chahte hain, lekin full-time programmer banne ki unki koi ichchha nahi hai.

**Naya role ya nahi?** Wo aisa role chahte hain jismein automation hi unka mukhya kaam ho, isliye sirf using-AI lessons kaafi nahi hain.

**Background.** Coding nahi, finance aur process ki mazboot samajh, Excel formulas mein comfortable. Do paths mumkin dikhte hain: AI Automation Specialist (thoda code) aur AI Governance & Compliance (koi code nahi), kyunki wo financial controls jaante hain.

**Goal.** Wo Hyderabad ki das job posts padhte hain, dono ke liye paanch-paanch. Unke notes (ek udaharan, koi survey nahi) dikhaate hain ki governance posts zyaadatar risk ya compliance ka wo anubhav maangti hain jo unke paas nahi hai, aur policy writing ka kaam batati hain jo unhe neeras lagta hai. Automation posts, jinke title "AI automation engineer" ya "finance automation analyst" hain, n8n, Power Automate, APIs aur process mapping ka zikr karti hain. Unki duties mein "automate invoice processing" aur "reduce manual reconciliation" likha hai, jo theek wahi hai jo unhe achha laga tha. Zyaadatar 0 se 3 saal maangti hain. Wo maan lete hain ki unhe APIs aur JSON padhne aur chhote scripts likhne honge.

**Time.** Unke do chhote bachche hain. Asal mein: hafte ki do shaamein aur weekend ki ek subah, hafte mein kareeb 5 se 6 ghante. Path ka mota andaaza teen mahine hai; unki raftaar par, projects ginne ke baad, ye thoda lamba chal sakta hai.

**Milestone check karna.** Automation path ke stage 1 mein saat lessons hain, kul kareeb 10 ghante. Stage 2 ka pehla lesson, "Aapka pehla n8n workflow", kareeb 3 ghante aur hai. Yaani 13 ghante ke lessons. Hafte ke 5.5 ghante par chaar hafte 22 ghante dete hain, jisse practice aur rework ke liye 9 ghante bachte hain. Milestone fit hota hai.

Unka plan:

| Hissa | Imran ka plan |
| --- | --- |
| Path | AI Automation Specialist |
| Study slots | Tuesday aur Thursday raat 8 se 9:30, Saturday subah 9 se 11:30 (5.5 ghante) |
| Pehla milestone | Chaar hafton mein: stage 1 poora, saath mein unka pehla n8n workflow jo invoice emails ko sheet mein log karta hai |
| Accountability | Har Sunday ek colleague ko chhota update, jo khud bhi seekh raha hai |
| Final project | Path ka capstone, ek invoice-to-ledger automation, unki team ke asli invoice process par bana |

**Kya gadbad hui.** Hafta 3 mein month-end close ne unki do shaamein le leen, aur unki milestone ki date chhoot gayi. Unhone plan nahi chhoda. Date ek hafta aage badha di, apne colleague ko bataya, aur har month-end waale hafte ko light hafta mark kar diya.

**Jo kadam kaam aaya.** Unhone apne manager ko plan ke baare mein bataya. Manager ne capstone ke liye team ka invoice process offer kiya, ek shart par: Imran ise vendor bank details hataayi hui copies par banaayein aur test karein, aur live ledger ko chhoone se pehle approval lein. Unka final project ab naape ja sakne waale result ke saath asli kaam hai, jo unke portfolio ko kisi practice exercise se kahin zyada mazboot banayega.

## Aam galtiyaan

- **Sabse zyada hype waala ya sabse zyada pay waala path chunna.** Wo chuno jo aapke background aur us kaam se mel khaaye jo aapko har hafte achha lage.
- **Path kya maankar chalta hai, ise nazarandaaz karna.** Agentic AI Engineer ummeed karta hai ki aap Python se API call kar sako, aur FDE ek saal ka Python maangta hai. Agar abhi ye nahi kar sakte toh ek kadam pehle se shuru karo.
- **Jab sirf kaam par AI use karna ho, tab career path lena.** Using-AI lessons aapko mahinon mein nahi, kuch ghanton mein wahaan pahuncha dete hain.
- **Aise ghante plan karna jo nibh nahi paayenge.** Wo ghante chuno jo mahinon tak nibha sako, na ki wo jo kaash aapke paas hote.
- **Bina jode milestone tay karna.** Pehle lesson ghante jodo, warna milestone khiskega aur aapko lagega ki aap peeche ho.
- **Har hafte path badalna.** Dobara sochne se pehle ek stage ke liye commit karo.
- **Projects skip karna.** Employers projects hi dekhna chahte hain, aur asli confidence bhi wahin se aata hai.
- **Akele seekhna.** Ek vyakti ko har hafte tay update dene se chupchaap bhatak jaana bahut mushkil ho jaata hai.
- **Perfect plan ka intezaar karna.** Isi hafte shuru kiya achha plan, agle mahine shuru kiye perfect plan se behtar hai.
