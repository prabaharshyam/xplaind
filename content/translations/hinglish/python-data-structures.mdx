## Ye kya hai

Programs shayad hi ek baar mein ek value ke saath kaam karte hain. Ek din mein bahut saare orders hote hain, ek class mein bahut saare students, ek dukaan mein bahut saare products. Python ke do mehnati collections bahut saari values rakhte hain:

- **Lists** ordered sequences hain, jinhe position se pahunchte hain. "Ek hi tarah ki bahut saari cheezein, order mein" ke liye achhi: din ke orders, marks ki list.
- **Dictionaries** key aur value ka lookup hain. "Is key ki value jaldi dhoondho" ke liye achhi: roll number se marks, field name se customer ki details.

Do aur aksar aate hain:

- **Tuples** fixed, na badalne waali sequences hain, jaise latitude aur longitude ki jodi.
- **Sets** unique items ke unordered collections hain, duplicates hatane ke liye kaam ke.

| Type | Example | Value kaise milti hai |
|---|---|---|
| list | `["Pune", "Kochi", "Jaipur"]` | Position se: `[0]`, `[1]`, `[2]` |
| dict | `{"K101": 78, "K102": 64}` | Key se: `["K101"]` |
| tuple | `(18.52, 73.86)` | Ek fixed jodi jo badal nahi sakti |
| set | `{"a@x.in", "b@y.in"}` | Unique values, koi order nahi |

Inhe ek-doosre ke andar rakhne (nesting) se zyadatar asli data model ho jaata hai. Dictionaries ki list ek table hai; har dictionary ek row. Ye bilkul wahi shape hai jo APIs aur AI models ka bheja hua **JSON** hota hai, isliye nested lists aur dictionaries se comfortable hona AI ki core skill hai.

Is lesson mein hum Kota ke ek coaching centre ke office ke saath chalenge, jo test results ki list ko parents ke liye turant jawabon mein badalta hai. Lesson ke end tak aap kisi kaam ke liye sahi structure chun paoge aur nested data aasaani se padh paoge.

## Ye kaam kaise karta hai

### Lists

```python
nums = [3, 1, 2]
nums.append(5)            # [3, 1, 2, 5]
print(len(nums))          # 4
print(nums[0], nums[-1])  # 3 5   (first and last)
print(sorted(nums))       # [1, 2, 3, 5]
print(nums[1:3])          # [1, 2]  (a slice: from position 1 up to, not including, 3)
```

`for n in nums:` se loop karo. Nayi lists **list comprehension** se banao, ek compact loop jo list banata hai:

```python
doubled_big = [n * 2 for n in nums if n > 1]    # [6, 4, 10]
```

### Dictionaries

```python
marks = {"asha": 80, "ravi": 72}
marks["meena"] = 91              # add a new key
print(marks["asha"])             # 80
print(marks.get("john", 0))      # 0: a default instead of an error
for name, score in marks.items():
    print(name, score)
```

Square brackets se missing key dhoondhne par `KeyError` aata hai; `get` uski jagah default deta hai. Key se lookup lakhon entries mein bhi tez hota hai, kyunki dictionary khojne ki jagah seedhe key par kood jaati hai.

### Sahi wala chunna

| Aapko chahiye | Use karo | Example |
| --- | --- | --- |
| Order, ya cheezein position se pahunchna | List | Customers ki queue |
| Pehchaan (id) se cheezein dhoondhna | Dictionary | Product code se price |
| Unique items, tez "kya ye yahan hai?" | Set | Unique email addresses |
| Values ka ek chhota fixed group | Tuple | Dukaan ke coordinates |
| Records ki table | Dictionaries ki list | Aaj ki sales |
| Category ke hisaab se grouped values | Lists ki dictionary | Shehar ke hisaab se students |

### List mein dhoondhna slow kyun hai

```flow
dir: LR
title: 10,000 records mein roll "K9000" dhoondho
List mein -> [0], [1], [2] ... ek-ek karke check karo -> 10,000 tak checks
Roll se bani dictionary mein -> Seedhe "K9000" par jao -> Lagbhag 1 step
```

Agar aap ek hi tarah ki id kai baar dhoondhte ho, toh ek baar dictionary banao aur use dobara use karo.

### Nesting

```python
cities = {
    "Pune":   [{"name": "Asha", "marks": 80}],
    "Nagpur": [{"name": "Ravi", "marks": 72}, {"name": "Meena", "marks": 91}],
}
print(cities["Nagpur"][1]["name"])     # Meena
```

Nested access ko left se right padho: "Nagpur" ki list, uska doosra item, us item ka "name".

### JSON se Python aur wapas

Jab koi API ya AI model JSON wapas deta hai, Python ka `json` module use lists aur dictionaries mein badal deta hai, aur wapas bhi:

```python
import json
text = '{"city": "Pune", "pins": ["411001", "411002"]}'
data = json.loads(text)          # now a dictionary
print(data["pins"][0])           # 411001
print(json.dumps(data, indent=2))  # back to neatly formatted JSON text
```

JSON objects dictionaries ban jaate hain, JSON arrays lists ban jaate hain, `true` aur `false` `True` aur `False` ban jaate hain, aur `null` `None` ban jaata hai.

### Copy karna

`b = a` list ko copy **nahi** karta. Dono naam ek hi list ki taraf point karte hain, isliye ek ko badalne se doosre ko bhi badla dikhta hai:

```python
a = [1, 2]
b = a
b.append(3)
print(a)          # [1, 2, 3]  surprise!
c = a.copy()      # a real copy
```

## Ek example se samjho

Kota ka ek coaching centre test results ko records ki list ki tarah rakhta hai, har student ke liye ek:

```python
results = [
    {"roll": "K101", "name": "Asha",  "physics": 78, "chem": 85},
    {"roll": "K102", "name": "Ravi",  "physics": 64, "chem": 70},
    {"roll": "K103", "name": "Meena", "physics": 91, "chem": 88},
]

# 1. Look up by roll number quickly: build a dictionary once
by_roll = {r["roll"]: r for r in results}
print(by_roll["K102"]["name"])            # Ravi

# 2. Average per subject with a list comprehension
physics = [r["physics"] for r in results]
print(round(sum(physics) / len(physics), 1))   # 77.7

# 3. Group students by grade band
bands = {}
for r in results:
    total = r["physics"] + r["chem"]
    band = "A" if total >= 160 else "B"
    bands.setdefault(band, []).append(r["name"])
print(bands)                               # {'A': ['Asha', 'Meena'], 'B': ['Ravi']}
```

| Office ka sawaal | Jawab dene waala structure | Code |
| --- | --- | --- |
| "Roll K102 ka kaisa raha?" | Roll se bani dictionary | `by_roll["K102"]` |
| "Physics ka average kya hai?" | Physics marks ki list | `sum(physics) / len(physics)` |
| "Band A mein kaun hai?" | Lists ki dictionary | `bands["A"]` |

`setdefault(band, [])` us band ki list return karta hai, aur pehli baar ek khaali list bana deta hai. Isse har baar `if` likhne ki zaroorat nahi padti.

Ab office parents ke "roll K102 ka kaisa raha?" jaise calls ka jawab turant deta hai, 600 students ki sheet mein scroll karne ki jagah.

## Aam galtiyaan

- **Kisi id ke liye list mein baar-baar dhoondhna.** Us id se bani dictionary ek baar banao.
- **Missing keys par `KeyError`.** Jab key na bhi ho sakti hai, toh default ke saath `get` use karo.
- **Index out of range.** Lists 0 se shuru hoti hain; aakhri item `[-1]` hai.
- **Anjaane mein shared lists.** `b = a` copy nahi hai; `a.copy()` use karo.
- **List par loop karte waqt use badalna.** Uski jagah nayi list banao, jaise comprehension se.
- **Sets se order ki ummeed.** Order matter kare toh result sort karo: `sorted(set(items))`.
