## Ye kya hai

**n8n** ("n-eight-n" bola jaata hai) ek workflow automation tool hai jisme visual editor hota hai. Aap canvas par **nodes** rakhte ho aur unhe arrows se jodte ho. Ek **trigger** node workflow ko shuru karta hai, aur uske baad ka har node ek kaam karta hai: sheet padhna, app call karna, data badalna, kisi condition par branch karna ya AI model ko call karna.

Data node se node tak **items** ki list ki tarah behta hai. Har item ek chhota JSON record hota hai, jaise spreadsheet ki ek row:

```flow
Trigger: nayi sheet row | name "Rohan", phone "98xx", course "JEE" -> Edit Fields: data saaf karo | phone ban jaata hai "+9198xx"
Edit Fields: data saaf karo -> If: course JEE hai?
If: course JEE hai? -[haan]-> Gmail: JEE welcome
If: course JEE hai? -[nahi]-> Gmail: NEET welcome
Gmail: JEE welcome -> Telegram: counsellors ko batao
Gmail: NEET welcome -> Telegram: counsellors ko batao
```

Aap n8n ka hosted cloud version use kar sakte ho ya khud chala sakte ho, jaise Docker se, jo kaafi companies pasand karti hain taaki unka data apne servers par rahe.

Is lesson mein hum Shalini ke saath chalenge, jo Jaipur ke ek coaching institute mein admissions sambhaalti hain, aur apna pehla workflow banati hain. Lesson ke end tak aap apna ek workflow banaoge, test karoge aur publish karoge.

## Ye kaam kaise karta hai

### Triggers

Har workflow ek trigger se shuru hota hai. Ek workflow mein ek se zyada ho sakte hain, par har run sirf ek se shuru hota hai. Common wale:

| Trigger | Kab chalta hai | Example use |
| --- | --- | --- |
| Schedule | Ek tay time aata hai | Roz subah 9 baje daily report bhejna |
| Webhook | Koi doosra app ek URL call karta hai | Payment app nayi payment report karta hai |
| Email (IMAP ya Gmail) | Nayi email aati hai | accounts@ par bheje invoices process karna |
| Form ya Sheets | Nayi submission ya row aati hai | Nayi admission enquiry |
| Manual | Aap "Execute workflow" par click karte ho | Banate aur test karte waqt |

### Nodes

Nodes teen families ke hote hain:

- **App nodes:** Gmail, Google Sheets, Slack, Telegram, WhatsApp Business, HubSpot aur sainkdon aur.
- **Core nodes:** kisi bhi API ke liye HTTP Request, chhote scripts ke liye Code, data badalne ke liye Edit Fields (jise Set bhi kehte hain), branch karne ke liye If aur Switch, jodne ke liye Merge, batches mein process karne ke liye Loop.
- **AI nodes:** language model ko call karke extract, classify, summarise ya draft karte hain, ya agent banate hain.

### Credentials

Har app node ko ek **credential** chahiye: us app tak saved access, aksar OAuth se sign in karke ya API key paste karke. n8n credentials ko encrypted store karta hai aur unhe kai workflows mein dobara use karne deta hai. Apna personal admin account nahi, ek dedicated account use karo jiske paas sirf workflow ke liye zaroori access ho.

### Nodes ke beech data mapping

Node ki settings mein aap chunte ho ki pehle ke nodes ka kaunsa data use karna hai. Aap input panel se field drag kar sakte ho, ya double curly braces mein **expression** likh sakte ho, jaise current item ke email field ke liye `{{ $json.email }}`. Output panel bilkul dikhata hai ki har node ne kya banaya, isliye galtiyan aasaani se dikh jaati hain.

### Testing

Editor se sample data ke saath workflow chalao. Har node par click karke uska input aur output dekho, aur mapping ki problems ek-ek node karke theek karo. Trigger ke test data ko **pin** karo taaki aap har baar nayi email bheje ya nayi row jode bina poora workflow dobara chala sako.

### Publishing

Jab chal jaaye, workflow ko **publish** karo. (n8n 2.0 se pehle ye ek Active toggle hota tha.) Phir production triggers apne aap chalte hain. **Executions list** har run ko uske data aur kisi bhi error ke saath dikhaati hai.

```flow
dir: LR
Banao -> Pinned data se test karo -> Theek karo -> Publish karo -> Executions dekho
Theek karo -[dobara test karo]-> Banao
```

## Ek example se samjho

Shalini Jaipur ke ek coaching institute ke admissions sambhaalti hain. Enquiries ek Google Form se aati hain jiske responses ek sheet mein jaate hain. Abhi counsellors din mein ek baar sheet dekhte hain aur agli subah students ko call karte hain. Woh apna pehla workflow banati hain:

| # | Node | Kya karta hai |
| --- | --- | --- |
| 1 | Google Sheets trigger | Responses sheet mein nayi row judne par chalta hai |
| 2 | Edit Fields | Spaces hataata hai, phone ko +91 ke saath format karta hai, naam capitalise karta hai |
| 3 | If | Kya course "JEE" ya "NEET" hai? |
| 4 | Gmail (do branches) | Student ke naam ke saath, brochure link waali course-specific welcome email bhejta hai |
| 5 | Telegram | Counsellors ke group mein "New JEE enquiry: Rohan Sharma, +91 98xxxxxx45, prefers evening batch" post karta hai |

**Testing.** Woh teen sample rows pin karti hain aur workflow chalaati hain. Do sahi nikalti hain. Teesri, jisme student ne lower case mein "jee" likha, galat branch mein jaati hai aur use NEET waali email mil jaati hai. Woh If node ko lower case mein compare karne ke liye badal deti hain, aur teeno pass ho jaati hain.

Woh ek khaali phone number bhi try karti hain. Telegram message mein "phone: undefined" aata hai, jo counsellors ko confuse karega. Woh ek default jodti hain: "phone not given, reply by email".

**Publishing.** Woh workflow publish karti hain. Agli subah executions list mein 14 successful runs dikhte hain, aur counsellors ne agli subah ki jagah ek ghante ke andar naye students ko call kar diya.

| Measure | Pehle | Baad mein |
| --- | --- | --- |
| Enquiry se welcome email tak ka time | Agla din, haath se | Ek minute se kam |
| Counsellor ke call tak ka time | Agli subah | Ek ghante ke andar |
| Chhooti hui enquiries | Hafte mein kuch | Pehle hafte mein koi nahi |

## Aam galtiyaan

- **Sirf happy path test karna.** Khaali fields, ajeeb spellings, extra spaces aur duplicates try karo.
- **Credentials ke liye apna personal admin account use karna.** Limited access waala dedicated account use karo.
- **Badalne waali values ko hard-code karna.** Email templates, chat IDs aur prices ek aisi jagah rakho jahan aap edit kar sako.
- **Publish karna bhool jaana.** Jo workflow sirf test mode mein chalta hai, woh kisi ke kaam nahi aata.
- **Error alert nahi.** Us par bharosa karne se pehle ek error workflow jodo jo run fail hone par aapko message kare.
- **Item counts ignore karna.** Jo node achanak zero items output kare, woh chupchaap fail hone ka common tareeka hai; counts check karo.

## Practice karo

n8n ka quickstart karo, phir uska N8N101 Essentials course (link neeche hai).

1. **Banao.** Pinned test data ke saath ek trigger, kam se kam ek data-saaf karne waala node, ek branch aur do app actions waala workflow banao.
2. **Tod do.** Use teen bure inputs do: ek missing field, ek ajeeb spelling aur ek duplicate. Har ek ko theek karo.
3. **Publish karo.** Use publish karo aur kuch asli ya simulated runs ke baad executions list dekho.

**Aapka kaam poora jab:** aap apne workflow ke har node ka input aur output samjha sako aur ek successful automatic run dikha sako.
