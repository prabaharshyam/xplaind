## Ye kya hai

**Unsupervised learning** aise data mein patterns dhoondhta hai jismein labels nahi hote. Teen common tasks:

- **Clustering**: milte-julte records ko group karna, jaise customer segments ya milte-julte stores.
- **Dimensionality reduction**: bahut saare features ko kuch features mein compress karna jo zyadatar information rakhte hain, visualisation, speed ya simple models ke liye. **PCA** classic method hai.
- **Anomaly detection**: aise records dhoondhna jo baaki sab se alag dikhte hain, jaise unusual transactions ya kharaab sensors.

Check karne ke liye koi "sahi jawab" nahi hota, isliye useful hai ya nahi ye judge karna kaam ka hissa hai.

```text
  basket size (scaled)
   ^
   |        o o              x x
   |      o  o o           x  x x      o = weekly family stock-up
   |       o o               x x       x = premium packaged
   |                                   + = daily fresh shoppers
   |   + + +                           * = a possible anomaly
   |  + + + +            *
   |   + +
   +----------------------------------> visits per month (scaled)
```

Ye lesson Kochi ki ek supermarket chain ko follow karta hai jo marketing ke liye 400,000 loyalty-card customers ko segment karti hai.

## Ye kaam kaise karta hai

**Features taiyaar karo.** Unsupervised methods is par bahut depend karte hain ki aap kaunse features use karte ho aur unhe kaise scale karte ho. Numeric features ko standardise karo; business ke liye "milta-julta" ka kya matlab hona chahiye, ye dhyaan se socho.

**k-means clustering.** k chuno, yaani clusters ki ginti. Algorithm k centres rakhta hai, har record ko sabse paas ke centre se jodta hai, centres ko unke records ke beech mein khisakata hai, aur dohrata hai. Ye lagbhag gol, ek jaise size ke groups par sabse achha kaam karta hai. k ko elbow method ya silhouette scores se chuno, par zyadatar is se ki clusters business ke liye samajh aate hain ya nahi.

**Doosre clustering methods.** DBSCAN kisi bhi shape ke clusters dhoondhta hai aur sparse points ko noise label karta hai; hierarchical clustering groupings ka ek tree banata hai; Gaussian mixtures soft memberships deti hain.

**PCA.** Naye axes (original features ke combinations) dhoondhta hai jo sabse zyada variation pakadte hain. Pehle do components plot karne se aksar groups ya outliers dikh jaate hain. Jo components, maan lo, 90% variance explain karein, unhe rakhne se 50 features 10 ho sakte hain.

**Anomaly detection.** Isolation Forest jaise methods score karte hain ki ek record ko baaki se alag karna kitna aasaan hai. Scores ko review prioritise karne ke liye use karo, final verdict ki tarah nahi.

**Results judge karna.** Har cluster ko uske features ke averages aur real examples se describe karo; use aisa naam do jo business user samjhe; stability check karo (alag sample ke saath dobara chalane par clusters milte-julte rehte hain?); aur usefulness test karo (segment ke hisaab se target karne se campaign behtar hota hai?).

**Method chunna:**

| Task | Method | Kis kaam ke liye achha |
| --- | --- | --- |
| Ek jaise size aur shape ke segments | k-means | Customer aur store segments |
| Irregular shapes, noise | DBSCAN | Location data, dense areas dhoondhna |
| Groupings ka tree | Hierarchical clustering | Chhote datasets, structure explore karna |
| Soft membership | Gaussian mixtures | Aise customers jo do segments mein aadhe-aadhe aate hain |
| Compress aur visualise | PCA | Bahut saare features, quick plots |
| Unusual records dhoondhna | Isolation Forest | Transactions, sensors, data quality |

**Mushkil hissa matlab nikaalna hai.** Algorithms random data mein bhi clusters de dete hain. Asli kaam hai har ek ko averages aur real examples se describe karna, business team ke saath naam dena, aur test se saabit karna ki wo useful hai. Jis cluster ko koi describe na kar sake ya jispar koi action na le sake, woh segment nahi hai.

**k ko evidence se chuno, sirf elbow se nahi.**

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

X, _ = make_blobs(n_samples=3000, centers=4, n_features=6, cluster_std=1.6, random_state=8)
Xs = StandardScaler().fit_transform(X)

for k in range(2, 8):
    labels = KMeans(n_clusters=k, n_init=10, random_state=8).fit_predict(Xs)
    print(k, "silhouette", round(silhouette_score(Xs, labels, sample_size=2000, random_state=8), 3))
```

**Segments ko naam dene se pehle stability check karo.**

```python
def stability(Xs, k, runs=5, frac=0.8, seed=0):
    rng = np.random.default_rng(seed)
    ref = KMeans(n_clusters=k, n_init=10, random_state=0).fit(Xs)
    scores = []
    for r in range(runs):
        idx = rng.choice(len(Xs), int(frac * len(Xs)), replace=False)
        other = KMeans(n_clusters=k, n_init=10, random_state=r + 1).fit(Xs[idx])
        scores.append(adjusted_rand_score(ref.predict(Xs[idx]), other.labels_))
    return round(float(np.mean(scores)), 3)

print("stability at k=4:", stability(Xs, 4), " at k=7:", stability(Xs, 7))
```

Adjusted Rand index 1 ke paas ho toh matlab wahi records baar-baar saath aa rahe hain; bahut kam values ka matlab segments sirf ek run ki upaj hain.

**Clusters ko business terms mein describe karo.** Cluster labels ko original, unscaled columns ke saath jodo aur summarise karo:

```python
import pandas as pd

def describe(df, labels):
    d = df.assign(cluster=labels)
    summary = d.groupby("cluster").agg(["mean", "median"]).round(1)
    summary["size"] = d.cluster.value_counts().sort_index()
    return summary
```

Phir "weekend family shoppers" jaisa naam dene se pehle har cluster ke das real records padho.

**Review queue ke liye anomaly scores.**

```python
from sklearn.ensemble import IsolationForest

iso = IsolationForest(n_estimators=300, contamination="auto", random_state=8).fit(Xs)
scores = -iso.score_samples(Xs)                  # higher = more unusual
queue = np.argsort(-scores)[:20]
print("top anomaly scores:", scores[queue][:5].round(3))
```

Top cases ek insaan ko bhejo, un features ke saath jinki wajah se woh alag dikhte hain (jaise har value median se kitne standard deviations door hai), aur record karo ki unhone kya decide kiya. Ye decisions baad mein supervised model ke labels ban jaate hain.

**Pehli nazar ke liye PCA.** `PCA(n_components=2).fit_transform(Xs)` plot karne ke coordinates deta hai; `explained_variance_ratio_` batata hai ki do axes kitna variation pakadte hain. Agar woh chhota hai, toh picture asli structure chhupa sakti hai.

## Ek worked example

Kochi ki ek supermarket chain ke 400,000 loyalty-card customers hain aur use marketing ke liye segments chahiye.

12 mahine mein har customer ke features: mahine mein visits, rupees mein average basket, fresh produce, packaged foods aur household items par kharche ka share, weekend visits ka share aur promotion par kharide gaye purchases ka share. Sab standardised.

k 3 se 10 tak k-means; silhouette scores 6 aur 7 ke aas-paas peak karte hain. Saat clusters, marketing team ke saath chhe mein merge kiye aur naam diye:

1. Weekly family stock-up (bade baskets, weekends)
2. Daily fresh shoppers (aksar, chhote, produce zyada)
3. Deal hunters (promotion share zyada)
4. Occasional top-up (kabhi-kabhi, chhote baskets)
5. Premium packaged (bada basket, imported brands)
6. Lapsing (haal ke mahinon mein visits tezi se gir rahe hain)

Teen mahine ka test har segment ke aadhe logon ko segment-specific offers bhejta hai. Response overall 3.1% se badhkar 4.6% ho jaata hai, aur "lapsing" segment ke offers un customers mein se 12% ko wapas laate hain. Segment label churn model mein ek useful feature bhi ban jaata hai.

| Measure | Segments se pehle | Segment-specific offers ke saath |
| --- | --- | --- |
| Offer response rate | 3.1% | 4.6% |
| Wapas laaye gaye lapsing customers | Naapa nahi gaya | 12% |
| Extra use | Koi nahi | Churn model mein segment label feature ke roop mein joda gaya |

**Marketing ke saath clusters ka naam rakhna.** k = 7 ka pehla output saat columns ke averages the jinhe data team ke bahar koi nahi padh sakta tha. Ek ghante ke workshop mein team ne marketing ko har cluster ke averages ke saath us cluster ke paanch real, anonymised customers dikhaye. Marketing ne segments ke naam apne shabdon mein rakhe aur jahan zaroori tha wahan pushback kiya. Unhone do clusters merge kar diye jinhe algorithm ne weekend visits ke ek chhote se farak par alag kar diya tha, kyunki woh dono groups ke saath ek jaisa vyavhaar karenge. Is baatcheet ke baad hi chhe clusters final segments bane. Team ne naye teen mahine ke sample par clustering dobara bhi chalayi. Chhe mein se paanch segments milte-julte sizes mein wapas aa gaye. Chhatha, sabse chhota, aur chhota wapas aaya, isliye team use har quarter dobara check karti hai.

## Aam galtiyaan

- **Unscaled features.** Bade values wale features distances par haavi ho jaate hain.
- **k ko sirf ek score se chunna.** Business meaning matter karta hai.
- **Clusters ko sach maan lena.** Ye ek useful nazariya hai, customers ke baare mein koi tathya nahi.
- **Stability check na karna.** Unstable clusters har rerun par badal jaate hain.
- **Anomaly scores ko verdict maan lena.** Unhe human review prioritise karne ke liye use karo.

- **Aise features par clustering jinpar action nahi liya ja sakta.** Jo segments aise data se bane hon jise business targeting ke liye use nahi kar sakta, woh shaayad hi kuch badlte hain.
- **k ko sirf elbow se chunna**, stability ya business meaning ke bina.
- **Sirf averages dekhkar clusters ka naam rakhna**, real records padhe bina.
- **Anomaly scores ko verdict maan lena**, review order ki jagah.

## Jab unsupervised methods use na karein

- **Jis cheez ki aapko parwaah hai uske labels aapke paas hain**: supervised models seedha jawab dete hain.
- **Segments ko fixed rules follow karne hain**, jaise regulatory customer categories.
- **Meaningful groups banane ke liye records ya features bahut kam hain.**

## Demo se production tak

- **Seeds fix karo aur settings record karo**, taaki segments reproducible hon.
- **Naye segments release karne se pehle stability check karo.**
- **Schedule par re-cluster karo** aur naye clusters ko purane naamon se soch-samajhkar map karo.
- **Cluster sizes ko samay ke saath track karo**; bade badlaav ka matlab behaviour ya data badla hai.
- **Anomalies par review decisions ko labels ke roop mein wapas feed karo.**
