## Ye kya hai

**Sorting** items ko order mein rakhti hai. Data sorted ho jaaye toh kai sawaal aasaan ho jaate hain: duplicates ek-doosre ke bagal mein hote hain, sabse chhota aur sabse bada ends par hote hain, aur kuch bhi jaldi dhoondh sakte ho.

**Binary search** sorted data mein beech wala item check karke us aadhe hisse ko hata deta hai jismein item ho hi nahi sakta. Har step mein jo bacha hai woh aadha ho jaata hai, isliye lagbhag log₂ n steps lagte hain: 10 lakh items ke liye 20.

**Two pointers** ek array mein do positions ko chalate hain, aksar dono ends se ya ek doosre ke peeche, taaki pair aur range problems nested loops ke bajaay ek pass mein solve ho jaayein. **Sliding window** best contiguous stretch dhoondhne ka two-pointer pattern hai.

```flow
dir: LR
title: [3 8 15 21 27 33 42 50 61 77] mein 42 ke liye binary search
Beech ka 27 hai -[27, 42 se chhota hai: right half search karo]-> [33 42 50 61 77] ka beech 42 hai -> 2 steps mein mil gaya
```

```flow
title: Two pointers: sorted [5 12 18 25 30 38 45] mein sum 50 wala pair
L 5 par, R 45 par -> Sum = 50?
Sum = 50? -[bahut chhota]-> L ko right le jao
Sum = 50? -[bahut bada]-> R ko left le jao
Sum = 50? -[haan: 5 + 45]-> Mil gaya
L ko right le jao -> Sum = 50?
R ko left le jao -> Sum = 50?
```

## Ye kaam kaise karta hai

**Sorting algorithms** speed aur behaviour mein alag hote hain:

| Algorithm | Average time | Extra space | Notes |
|---|---|---|---|
| Bubble / insertion sort | O(n²) | O(1) | simple; insertion sort lagbhag sorted data par fast hai |
| Merge sort | O(n log n) | O(n) | aadhe-aadhe karta hai, sorted halves ko merge karta hai; stable |
| Quicksort | O(n log n), worst O(n²) | O(log n) | pivot chunta hai aur partition karta hai; practice mein fast |
| Heap sort | O(n log n) | O(1) | heap use karta hai; stable nahi |
| Timsort (Python ka `sorted`) | O(n log n) | O(n) | merge sort plus insertion sort; real data par bahut fast |

Practice mein aap built-in sort hi call karoge. Phir bhi ye pata hona chahiye ki comparison sorting average mein O(n log n) se behtar nahi ho sakti, aur interview mein merge sort ya quicksort samjhana aana chahiye.

**Binary search** `lo` se `hi` tak ek range rakhta hai. Woh beech wala check karta hai; target bada ho toh `lo` ko beech ke aage le jaata hai; chhota ho toh `hi` ko beech se pehle le aata hai. Target mil jaaye ya range khaali ho jaaye, tab ruk jaata hai. Yahi idea kisi bhi **monotonic** yes/no sawaal par chalta hai, jaise "kya day d tak cumulative sales target tak pahunch gayi?", jise **binary search on the answer** kehte hain.

**Two pointers** sorted order ka faayda uthate hain. Target sum wala pair dhoondhne ke liye dono ends se shuru karo: sum bahut chhota ho toh sum badhane ke liye left pointer ko right le jao; bahut bada ho toh right pointer ko left le jao. Har move ek saath kai pairs ko rule out kar deti hai, isliye ye O(n) hai.

**Sliding window** mein left aur right edge hoti hain. Window badhane ke liye right edge aage badhao; jab woh koi rule tod de, jaise budget se upar chali jaaye, toh left edge badhakar window chhoti karo. Chalte-chalte best window track karte raho.

**Interviews mein** clues sunte raho. "Sorted array", "first ya last position dhoondho" ya "minimum value jo kaam kare" binary search ki taraf ishara karte hain. Sorted data mein "pair", "triplet" ya "sum wala subarray" two pointers ki taraf. "Sabse lamba ya sabse chhota contiguous stretch" sliding window ki taraf. Code likhne se pehle pattern zor se bolo; isse interviewer ko pata chalta hai ki aap kaise sochte ho.

## Ek example se samjho

Sneha Hyderabad mein ek online coaching platform ke liye analytics sambhaalti hai. Uske paas ek saal ka daily ads spend hai aur monthly budget ka sawaal hai: lagaataar kitne days ka sabse lamba run hai jismein total ad spend ₹1 lakh ke andar raha?

Har start aur end day try karna O(n²) hai. Sliding window ye ek pass mein kar deti hai:

```python
def longest_within(spend, budget):
    best = total = left = 0
    for right, amount in enumerate(spend):
        total += amount                   # grow the window
        while total > budget:             # shrink until within budget
            total -= spend[left]
            left += 1
        best = max(best, right - left + 1)
    return best
```

Har din window mein ek baar aata hai aur zyada se zyada ek baar nikalta hai, isliye ye O(n) hai.

Phir finance poochta hai: kis din cumulative sign-ups pehli baar 50,000 tak pahunche? Cumulative totals sirf upar jaate hain, isliye "day d tak pahunch gaye?" ka jawab false, false, ..., phir har agle din ke liye true hota hai. Ye monotonic hai, toh woh answer par binary search karti hai:

```python
from itertools import accumulate

def first_day_reaching(daily, target):
    totals = list(accumulate(daily))
    lo, hi = 0, len(totals) - 1
    answer = -1
    while lo <= hi:
        mid = (lo + hi) // 2
        if totals[mid] >= target:
            answer, hi = mid, mid - 1     # works; look for an earlier day
        else:
            lo = mid + 1
    return answer
```

Ek saal ke data ke liye ye lagbhag 9 checks hain, 365 tak ke bajaay. 10 saal ke hourly data par lagbhag 90,000 ke bajaay lagbhag 17 checks. Python ka `bisect` module yahi ek call mein kar deta hai: `bisect.bisect_left(totals, target)`.

## Aam galtiyaan

**Unsorted data par binary search.** Ye chupchaap galat answers deta hai. Pehle sort karo, ya yes/no sawaal monotonic hona chahiye.

**Off-by-one bounds.** Inclusive aur exclusive `hi` ko mila dena, ya `mid + 1` ki jagah `lo = mid` likhna infinite loops karta hai. Ek convention chuno aur length 0, 1 aur 2 ki lists se test karo.

**Asli kaam ke liye apna sort likhna.** Built-in sorts achhe se tested aur fast hote hain. Apna sort sirf seekhne ke liye likho, ya interview mein jab pooche.

**Loop ke andar re-sort karna.** Sort ek baar loop ke bahar karo. Andar sort karne se O(n log n) kaam n baar hota hai.

**Unsorted data par pair sums ke liye two pointers.** Ye method order par depend karta hai. Sort kiye bina hash map use karo.

**Window sikodne ke liye while ki jagah if.** Ek step rule mein wapas aane ke liye kaafi nahi ho sakta. Jab tak rule toota hai, sikodte raho.
