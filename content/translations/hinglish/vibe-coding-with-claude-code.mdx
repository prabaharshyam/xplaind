## Ye kya hai

**Vibe coding** matlab AI coding agent ko describe karke software banana, phir uske kaam ko steer aur check karna, zyadatar code khud type karne ki jagah. Yeh term 2025 mein chala aur ab kai founders, product managers, analysts aur students apne pehle tools aise hi banate hain.

**Claude Code** Anthropic ka coding agent hai. Sirf code suggest karne waale chatbot se alag, yeh aapke project mein kaam karta hai: files padhta hai, unhe likhta aur edit karta hai, tests aur builds jaise commands chalata hai, errors dekhta hai aur dobara try karta hai. Aap ise terminal mein, VS Code ya JetBrains ke andar, Claude desktop app mein, ya claude.ai par browser mein use kar sakte ho.

Skill prompts type karna nahi hai. Yeh wahi skill hai jo achha engineering lead naye team member ke saath use karta hai: goal saaf batao, kaam ko steps mein todo, jo wapas aaye use review karo, aur batao ki kya badalna hai.

```flow
title: Chhote steps mein repeat karo; har chalte step ke baad commit karo
Aap: idea aur spec -> Claude Code plan banata hai
Claude Code plan banata hai -[aap approve karte ho]-> Claude Code files edit karta hai
Claude Code files edit karta hai -> Claude Code tests aur app chalata hai
Claude Code tests aur app chalata hai -> Changes, errors, output ka summary
Changes, errors, output ka summary -> Aap diff review karte ho, try karte ho, feedback dete ho
Aap diff review karte ho, try karte ho, feedback dete ho -> Aap: idea aur spec
```

## Ye kaam kaise karta hai

**1. Set up.** Official docs se Claude Code install karo, khaali folder mein terminal kholo aur `claude` chalao. Ke liye Claude subscription ya API account chahiye. Folder ko git repository banao taaki har change dikhe aur undo ho sake.

**2. Chhota spec likho.** Code se pehle aadha page likho: app kya karta hai, kaun use karta hai, kaunse teen se paanch features matter karte hain, phone par kaisa dikhna chahiye, aur kya scope se bahar hai. Claude se kaho ki use padhe aur aapse sawaal pooche. Yeh ek aadat zyadatar kharab results hata deti hai.

**3. CLAUDE.md se use memory do.** Claude har session ke shuru mein `CLAUDE.md` padhta hai. Usmein stack, app chalane aur test karne ka tareeka, aur aapke rules daalo, jaise "mobile first", "no paid APIs" ya "never commit secrets". Pehla version Claude se `/init` se likhwa sakte ho.

**4. Plan, phir build, chhote steps mein.** Pehle plan maango (Claude Code mein plan mode hota hai jo sirf padhta aur propose karta hai). Use approve ya correct karo. Phir ek-ek feature banao: layout, phir data, phir calculations, phir saving, phir deployment.

**5. Har change review karo.** Summary padho aur diff par nazar daalo. App khud chalao. Kuch ajeeb lage toh poochho "yeh tareeka kyun chuna?" Step chal jaaye toh commit karo.

**6. Use test aur fix karne do.** Claude se zaroori logic ke tests likhne aur chalane ko kaho. Kuch tootne par error paste karo ya exact steps batao; saboot mile toh yeh bug ka raasta pakadne mein bahut achha hai.

| Stage | Aap kya kehte ho | Kya check karna hai |
|---|---|---|
| Spec | "Read SPEC.md and ask me anything unclear" | uske sawaal dikhate hain ki use samajh aaya |
| Plan | "Plan the first feature; don't write code yet" | kaunsi files, approach, kuch extra nahi |
| Build | "Implement step 1 of the plan" | chalta hai; diff chhota aur padhne laayak hai |
| Test | "Add tests for the split calculation and run them" | tests sirf aasaan case nahi, edge cases bhi cover karte hain |
| Fix | "On 360 px wide the table overflows. Fix it" | fix, aur ki aur kuch nahi hila |
| Ship | "Set up deployment to Vercel and explain the steps" | code mein secrets nahi; environment variables use hue |

## Ek example se samjho

Nisha Pune mein teen doston ke saath flat share karti hai aur WhatsApp chat mein bills baantne se thak gayi hai. Woh product designer hai, developer nahi.

Woh `SPEC.md` likhti hai: "A one-page web app. Add a bill with who paid and who shares it. Show who owes whom, settling with the fewest payments. Works on a phone. Saves in the browser; no login. Rupees." Woh naye folder mein `claude` chalati hai aur use spec padhne aur sawaal poochne ko kehti hai. Claude poochta hai ki kya bills unequal bhi baante ja sakte hain aur kya payments ke liye UPI link chahiye. Woh kehti hai unequal splits baad mein, UPI links haan.

Woh plan maangti hai aur milta hai: ek Next.js app, ek form, bills ki list, ek settlement function, local storage, aur settlement maths ke tests. Woh sirf step ek approve karti hai: page aur form. Chal jaata hai. Woh commit karti hai.

Step teen settlement maths hai. Woh Claude se pehle tests likhwati hai, ek aise case ke saath jiska jawab use pata hai: teen dost, ek ne grocery ke ₹3,000 diye. Ek test fail hota hai kyunki rounding se ₹1 hisaab se bahar reh jaata hai. Claude wajah batata hai aur bacha hua paisa payer ko dekar theek karta hai. Yeh woh aankhon se kabhi nahi pakad paati.

Shaam ko woh Claude se Vercel par deployment set up karwati hai. Agli subah uske flatmates app use karte hain. Total time: lagbhag paanch ghante, zyadatar yeh tay karne mein ki use chahiye kya.

## Aam galtiyaan

**Poora app ek hi message mein maangna.** Aapko bada, bina test ka ulajha hua code milta hai. Ek baar mein ek feature maango.

**Spec skip karna.** Iske bina Claude andaaza lagata hai, aur galat andaaze ka pata tab chalta hai jab woh uske upar build kar chuka hota hai.

**Jo changes samajh nahi aaye unhe accept karna.** Explanation maango. Code, uske bugs aur uski security aapki zimmedari hai.

**Git nahi.** Commits ke bina aap dekh nahi sakte ki kya badla ya wapas nahi ja sakte. Har chalte step ke baad commit karo.

**API keys ko code mein daalna.** Secrets ko environment variables aur git ke ignore kiye `.env` file mein rakho. Push se pehle Claude se secrets check karne ko kaho.

**Kabhi na khatam hone waale "fix it" loops.** Wahi bug teen koshishon ke baad bhi rahe toh ruk jao. Exact steps, expected aur actual result batao, aur kuch badalne se pehle Claude se wajah samjhane ko kaho.
