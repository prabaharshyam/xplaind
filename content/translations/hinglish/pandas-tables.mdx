## Ye kya hai

Business ka zyadatar data tables mein rehta hai: sales exports, customer lists, attendance sheets, survey results. **pandas** tables ke saath kaam karne ki Python library hai. Uska mukhya object, **DataFrame**, rows aur naam waale columns rakhta hai, spreadsheet ki tarah jise aap code se control karte ho.

**DataFrame: df.** Columns ke naam hote hain; rows ka index hota hai.

| index | date | store | item | amount |
|---|---|---|---|---|
| 0 | 2026-10-01 | RS Puram | Glucometer | 1250.0 |
| 1 | 2026-10-01 | Gandhipuram | Paracetamol | 40.0 |
| 2 | 2026-10-02 | RS Puram | Insulin pen | 2100.0 |

Kuch lines mein aap CSV ya Excel file load kar sakte ho, clean kar sakte ho, rows filter kar sakte ho, group aur summarise kar sakte ho, tables jod sakte ho aur result save kar sakte ho. Spreadsheet ke ulat, steps likhe hote hain, isliye agle mahine ki report ek command hai, poora din click karna nahi.

AI kaam ke liye, pandas se hi aap training data taiyaar karte ho, model outputs inspect karte ho aur evaluation reports banate ho.

Is lesson mein hum Lakshmi ko follow karenge, jo Coimbatore mein paanch pharmacies manage karti hain, aur har mahine ki 40,000-row export ko seconds mein jawab mein badalti hain. End tak aap ek messy CSV load karoge, use clean karoge aur grouped summary banaoge jo dobara chala sako.

## Ye kaam kaise karta hai

### Load karo aur dekho

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()           # first five rows
df.info()           # columns, types, missing values
df.describe()       # quick statistics for number columns
```

Calculate karne se pehle hamesha dekho. `info()` batata hai ki jis column ko aap numbers samajh rahe the use text ki tarah padha gaya hai ya nahi.

### Columns select karo aur rows filter karo

```python
df["city"]                                        # one column
df[["city", "sales"]]                             # several columns
df[df["age"] > 30]                                # rows where age is above 30
df[(df["city"] == "Pune") & (df["sales"] > 5000)] # two conditions
```

"And" ke liye `&` aur "or" ke liye `|` use karo, har condition ke aas-paas brackets ke saath. Plain `and` aur `or` yahan kaam nahi karte.

### Missing values

Khaali ya na padhi ja sakne waali cells **NaN** ("not a number") ki tarah dikhti hain. Unhe `df.isna().sum()` se dhoondho. Phir soch-samajhkar tay karo: `fillna` se bharo, `dropna` se rows hatao, ya kisi ko check karne ke liye flag karo.

### Types theek karo

| Problem | Fix |
| --- | --- |
| "1,250" jaise amounts text ki tarah padhe gaye | `pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")` |
| 05/11/2026 jaisi dates | `pd.to_datetime(df["date"], dayfirst=True)` |
| Item codes ke shuru ke zeros ud jaate hain | `pd.read_csv(..., dtype={"item_code": str})` |

`errors="coerce"` na padhi ja sakne waali har cheez ko crash karne ki jagah NaN bana deta hai, taaki aap bad rows gin aur report kar sako.

### Naye columns

```python
df["gst"] = df["sales"] * 0.18
df["month"] = pd.to_datetime(df["date"], dayfirst=True).dt.month
```

### Group karo aur summarise karo

```python
df.groupby("city")["sales"].sum()                                # total per city
df.groupby(["city", "month"])["sales"].agg(["sum", "mean", "count"])
```

```flow
Saari rows -[city se baanto]-> Pune rows
Saari rows -[city se baanto]-> Nagpur rows
Saari rows -[city se baanto]-> Nashik rows
Pune rows -[sum()]-> Pune: 4.2 lakh
Nagpur rows -[sum()]-> Nagpur: 3.1 lakh
Nashik rows -[sum()]-> Nashik: 2.7 lakh
```

### Sort karo aur save karo

```python
df.sort_values("sales", ascending=False).head(10)
df.to_csv("clean_sales.csv", index=False)
```

### Pivot tables se reshape karo

Spreadsheet use karne waale pivot tables pasand karte hain, aur pandas mein bhi hain:

```python
df.pivot_table(index="store", columns="month", values="amount", aggfunc="sum")
```

Isse har store ki ek row aur har mahine ka ek column milta hai, har cell mein totals ke saath. Manager ko trend dikhane ka ye aksar sabse saaf tareeka hai. Row aur column totals ke liye `margins=True` jodo.

### Dates ke saath kaam karo

Ek baar column asli date ban jaaye, toh pandas uske saath bahut kuch kar sakta hai:

```python
df["date"] = pd.to_datetime(df["date"], dayfirst=True)
df["weekday"] = df["date"].dt.day_name()             # Monday, Tuesday...
weekly = df.set_index("date").resample("W")["amount"].sum()
```

`resample("W")` sales ko hafte-hafte jodta hai; calendar months ke liye `"MS"` use karo. Isi se pata chalta hai ki Sunday ki sales hamesha kam hoti hain, ya Diwali se pehle ka hafta saal ka peak hota hai.

### Tables jodo

```python
pd.merge(orders, customers, on="customer_id", how="left")
```

| `how=` | Kya rakhta hai |
| --- | --- |
| `"inner"` | Sirf woh rows jo dono tables mein match karti hain |
| `"left"` | Left table ki har row, jahan match nahi wahan blanks ke saath |
| `"outer"` | Dono tables ki har row |

Inner joins chupchaap rows hata sakte hain. Merge se pehle aur baad mein row counts check karo.

## Ek example se samjho

Lakshmi Coimbatore mein paanch pharmacies ki chain manage karti hain. Har mahine unhe lagbhag 40,000 rows ka sales export milta hai aur pehle woh use spreadsheet mein summarise karne mein ek din lagati thi.

```python
df = pd.read_csv("sales_oct.csv")
df["amount"] = pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")
print(df["amount"].isna().sum(), "rows with unreadable amounts")

by_store = df.groupby("store")["amount"].sum().sort_values(ascending=False)
print(by_store)

top_items = (df[df["category"] == "Diabetes care"]
             .groupby("item")["amount"].sum()
             .sort_values(ascending=False).head(5))
print(top_items)
```

**Woh kya seekhti hain:**

| Sawaal | Jawab |
| --- | --- |
| Na padhe ja sakne waale amounts ki rows | 37, sab ek till ki galti se "NA"; us store ko report kiya |
| Sabse zyada bikne waala store | RS Puram |
| RS Puram mein diabetes-care sales doosron ke mukable | Lagbhag 40% zyada |
| Top diabetes-care item | Glucometer strips |

40% ka ye farak unhe diabetes-care products ka stock stores ke beech move karne par le jaata hai, taaki baaki branches mein stock khatam hona band ho aur RS Puram mein overstock band ho. Jo analysis unhe ek din leta tha woh ab har mahine seconds mein chalta hai, aur kyunki steps code mein hain, November ki report wahi script hai, bas nayi file name ke saath.

### Apna kaam check karo

Kisi ko numbers bhejne se pehle unhe check karo. Grand total ko source system ke total se compare karo. Har filter aur merge se pehle aur baad mein rows gino, aur kisi bhi badlaav ko samjhao. Paanch sabse bade aur paanch sabse chhote values mein galtiyaan dekho, jaise rupees ki jagah paise mein likha hua price. Aur ek number haath se dobara nikaalo. In checks mein kuch minute lagte hain aur galat report owner tak pahunchne ki sharminda hone se bachate hain.

## Aam galtiyaan

- **Types check na karna.** Commas ki wajah se text ki tarah padhe gaye numbers ka sum nahi hota. Convert karo.
- **Missing values ko ignore karna.** Tay karo ki fill, drop ya flag karna hai, aur batao ki kaunsa.
- **Date ka galat order.** Indian dates day first hoti hain; `dayfirst=True` ya explicit format use karo.
- **Filters mein `&` ki jagah `and` use karna.** Brackets ke saath `&` aur `|` use karo.
- **Inner joins jo chupchaap rows hata dete hain.** Merge se pehle aur baad mein row counts check karo.
- **Original file edit karna.** Clean kiya hua data nayi file mein save karo aur raw export ko chhuo mat.
