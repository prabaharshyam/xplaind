## Ye kya hai

**Portfolio** is baat ka evidence hai ki aap ye kaam kar sakte ho. AI engineering aur FDE roles ke liye ye aam taur par ye hota hai:

- **Ek GitHub profile** jo aapke teen se paanch best projects se shuru ho, har ek ka clear README ho.
- **Case-study write-ups**, ek ya do projects ke, end-to-end case study ki tarah likhe hue: problem, numbers, decisions, results, aur kya galat gaya.
- **Ek resume** ek page ka (experienced engineers ke liye zyada se zyada do), jisme duties nahi, results hon.
- **Chaho to**, chhote demo videos aur kuch public posts jo batayein ki aapne kya seekha.

**Job search** woh plan hai jo us evidence ko sahi logon ke saamne rakhta hai.

```flow
title: Ek link, 60 second: github.com/you
Profile README -> Pinned: enterprise RAG assistant | "recall at 5: 60 sawaalon par 68% se 93%"
Profile README -> Pinned: approvals waala operations agent | "200 test runs mein 0 unapproved actions"
Profile README -> Pinned: document QA API | "96% field accuracy; ek file par 4 s"
Profile README -> Case study: hospital chain capstone | 3 pages + 2 minute ka video
```

```flow
dir: LR
title: Search
40 target companies -> 15 mein contacts -> Specific notes -> Sheet mein track
```

Resume: ek page, duties ki jagah results, tools context ke saath.

Is lesson mein hum Nandhini ke saath chalenge, jo Coimbatore ki backend developer hain, is path ko khatam karne se lekar offers milne tak.

## Ye kaam kaise karta hai

**Job se match karne waale projects chuno.** FDE roles ke liye: aise projects jinmein realistic client problem, messy data, evals, deployment aur governance ho. Is path ke chhe stage projects isi ke liye bane hain. Dus tutorials se teen strong, poore kiye hue projects behtar hain.

**README jo bechte hain.** Har README ek line mein problem se shuru karo aur ek screenshot ya 60 second ka video lagao. Phir number ke saath result do ("300 real-style documents par field accuracy 96%; ek file par 4 seconds"), ek chhote diagram mein architecture, aur ise run kaise karein. Uske baad details. In repositories ko profile par pin karo aur ek profile README jodo jo aapke case studies se link kare.

**Results waale resume bullets.** Pattern: action, kya, measurable result. "4,000 pages ki insurance policies par hybrid search aur reranking ke saath RAG assistant banaya; 60-sawaal ke golden set par retrieval recall at 5 ko 68% se 93% tak badhaya." AI, cloud aur tools ko lambi keyword list ki tarah nahi, context mein likho.

**Target companies.** India mein aur remotely: enterprise customers waali AI labs aur AI-first startups, data aur AI platform companies, bade firms ke global capability centres jo AI teams bana rahe hain, aur AI practices waali IT services aur consulting firms. Job posts dhyaan se padho: kuch "forward deployed" likhte hain, baaki "solutions engineer", "AI engineer, customer-facing" ya "applied AI engineer".

**Referrals aur conversations paao.** Target companies ke engineers ko specific note aur ek relevant project ke link ke saath message karo. Jin open-source tools ko use kiya unme contribute karo. Aapne kya banaya aur seekha, uske chhote write-ups share karo.

**Track karo.** Applications, contacts, stages aur follow-ups ki ek simple sheet. Bahut rejections ke liye taiyaar raho; har dus applications ke baad dekho ki kya response la raha hai aur materials badlo.

**Weak aur strong portfolio pieces:**

| Piece | Weak | Strong |
| --- | --- | --- |
| Project | Video dekh kar PDF par banaya chatbot | Real problem, messy data, golden set, deployed |
| README opening | "pip install ..." | Problem, visual, number ke saath result |
| Resume bullet | "Worked on RAG" | "60-sawaal ke golden set par recall at 5 ko 68% se 93% tak badhaya" |
| Outreach note | "Please refer me" | "Maine aapke customers jaisi problems ke liye X banaya; link ye raha" |

**Outreach note likhna.** Chaar sentences mein rakho: aap kaun ho, unki company se relevant ek project aur uska result, ek specific sawaal ya ask, aur thanks. Jaise: "Main Coimbatore ka backend developer hoon aur AI engineering mein move kar raha hoon. Maine ek claims-document assistant banaya jisme 300 test files par 96% field accuracy hai, jo aapki team insurers ko jo bechti hai uske kaafi kareeb hai. Kya aapke paas 15 minute honge ye batane ke liye ki aapki FDE team kaise kaam karti hai? Thank you." Specific notes ko reply milte hain; generic referral requests ko kam hi milte hain.

**Har dus applications ke baad review.** Replies aur first rounds gino. Replies kam hain to resume ka upar ka ek-tihaai hissa aur READMEs ki pehli lines dobara likho. First rounds kharab ja rahe hain to jo round fail hua use practice karo. Ek baar mein ek hi cheez badlo, taaki pata chale kya kaam aaya.

## Ek worked example

Nandhini, Coimbatore ki backend developer jinke paas do saal ka Java experience hai, ye path saat mahine mein khatam karti hain.

Unke portfolio mein chaar projects ke liye ek-ek repository pinned hai, har ek ki pehli line mein ek result hai. Ye hain document QA API, eval report ke saath enterprise RAG assistant, approval gates waala operations agent, aur ek fictional hospital chain ka capstone. Unka capstone case study teen pages ka hai aur do minute ka video bhi hai.

Unke resume mein Java ka kaam chhote bullets mein aa gaya aur numbers ke saath ek "Projects" section jud gaya. Woh 40 target companies ki list banati hain, unmein se 15 mein engineers dhoondhti hain, aur har company ke customers se sabse relevant project ke link ke saath chhote notes bhejti hain.

Aath hafton ke results: 31 applications, 9 replies, 6 first rounds, 3 final loops aur 2 offers. Ek offer ek startup mein forward deployed role ka tha jo hospitals ko bechta hai, aur unhone kaha ki capstone case study ki wajah se unhone call kiya.

## Common galtiyan

- **Tutorial clones.** Video dekh kar PDF par banaya chatbot kam hi dikhata hai. Real problem, evals aur deployment jodo.
- **README jo installation se shuru hote hain.** Problem aur result se shuru karo.
- **Results ki jagah duties.** "Worked on RAG" kuch nahi batata; numbers batate hain.
- **Ek hi resume se sab jagah apply karna.** Har role ke liye upar ka ek-tihaai hissa tailor karo.
- **"Ready" hone tak ruke rehna.** Aakhri projects poore karte hue hi apply karo; interviews sikhaate hain ki kya improve karna hai.
