## Ye kya hai

**Portfolio** is baat ka saboot hai ki aap ye kaam kar sakte ho. AI engineering aur forward deployed engineer (FDE) roles ke liye iske aam taur par paanch hisse hote hain:

- **Ek GitHub profile** jo aapke teen se paanch sabse achhe projects se shuru ho, har ek ki saaf README ke saath.
- Ek ya do projects ki **case-study write-ups**: problem, numbers, decisions, results aur kya galat hua.
- **Ek resume**, ek page ka (experienced engineers ke liye zyada se zyada do), jo duties nahi, results bataaye.
- **Ek LinkedIn profile** jo wahi kahaani kahe, kyunki kai Indian recruiters wahin search karte hain.
- **Chaaho toh**, chhote demo videos aur aapne jo seekha us par kuch public posts.

**Job search** wo plan hai jo is saboot ko sahi logon ke saamne, sahi samay par, sahi pay par pahunchaata hai.

```flow
title: Ek link, 60 seconds: github.com/you
Profile README -> Pinned: enterprise RAG assistant | "recall at 5: 68% to 93% on my 60-question golden set"
Profile README -> Pinned: operations agent with approvals | "0 unapproved actions in 200 scripted test runs"
Profile README -> Pinned: document QA API | "96% field accuracy on 300 synthetic files; 4 s per file"
Profile README -> Case study: hospital chain capstone | 3 pages aur ek 2-minute video
```

```flow
dir: LR
title: Search kaise chalti hai
40 target companies -> 15 par referrals ya contacts -> Coding test aur interviews -> Fixed pay par offers ki tulna -> Notice poora, phir join
```

Ye lesson Coimbatore ki backend developer Nandhini ko follow karta hai, is path ko poora karne se lekar offers mein se ek chunne tak.

## Ye kaam kaise karta hai

### Job se mel khaate projects chuno

FDE roles ke liye aise projects chuno jinmein realistic client problem, messy data, evals, deployment aur governance ho, jaise is path ke stage projects mein hain. Das tutorials se teen poore kiye projects behtar hain, kyunki interviewers ek project uthaate hain aur aadhe ghante tak us par sawaal poochhte hain.

### READMEs jo bikein

Har README ko problem par ek sentence aur ek screenshot ya 60-second video se shuru karo. Phir number ke saath result, ek chhota architecture diagram aur use run kaise karein, ye do. In repositories ko pin karo aur ek profile README jodo jo aapki case studies se link kare.

Ise waise test karo jaise reviewer karega. Kisi friend se kaho ki ek project clone kare aur sirf README ke sahaare use run kare. Agar 10 minutes se zyada lagein, ya aapko message karna pade, toh README theek karo ya ek hosted demo jodo.

### Numbers jinka bachaav kar sako

Aapke portfolio ka har number sawaal poochhe jaane ka nyota hai. Interviewers poochhte hain: "Ye kis par maapa gaya? Dikha sakte ho?" Teen rules follow karo:

1. **Test set ka naam aur size batao.** "96% field accuracy" ek daava hai. "Meri banaayi 300 synthetic insurance files par 96% field accuracy" saboot hai.
2. **Data kahaan se aaya, ye imaandaari se batao.** Ek kaalpanik hospital chain ke liye capstone theek hai. Use "discharge delays 30% kam kiye" kehna theek nahi, kyunki kisi hospital ne use use nahi kiya. Wo batao jo aapne maapa: accuracy, latency, har request ki cost.
3. **Eval ko chalne laayak rakho.** Golden set aur eval script repository mein hi rakho, taaki poochhe jaane par aap use live dobaara chala sako.

Ek maamooli number jise aap samjha sako, us bade number se behtar hai jise aap nahi samjha sakte.

### Resume, screening software aur LinkedIn

**Results waale bullets.** Pattern hai action, aapne kya banaaya, aur ek maapa hua result. Jaise: "Built a RAG assistant over 4,000 pages of insurance policies with hybrid search and reranking; raised retrieval recall at 5 from 68% to 93% on a 60-question golden set."

**Pehli nazar chhoti hoti hai.** 2018 ki ek eye-tracking study mein job site Ladders ne paaya ki recruiters har resume par pehli nazar mein lagbhag 7.4 seconds lagaate the. Wo zyaadatar titles, companies aur dates dekhte the. Saaf headings waale simple layouts ne dhyaan baandhe rakha; bhare-bhare, multi-column layouts ka haal bura raha. Iska sample size nahi bataaya gaya, par sabak wahi hai: apna sabse strong result top third mein rakho.

**Applicant tracking systems.** Kai employers resumes ko ek applicant tracking system (ATS) mein daalte hain, ye software applications store karta hai aur recruiters ko keyword se filter karne deta hai. Two-column templates, images mein likha text aur icons bigadkar aa sakte hain, isliye ek column, standard headings (Experience, Projects, Skills, Education) aur text-based PDF use karo. Ek chhoti skills line jodo jo job post ke exact terms ("RAG", "LangGraph", "AWS") dohraaye, basharte wo sach hon. Baaki jagah, tools ki lambi keyword list ki jagah unhe apne result bullets ke andar context ke saath rakho.

**LinkedIn.** Wahi headline use karo jo aapki GitHub profile par hai, jaise "Backend engineer building RAG and agent systems for healthcare". Featured section mein ek project pin karo aur apne do sabse achhe results ke saath ek chhota About section likho. LinkedIn aapko khud ko open to work mark karne deta hai, chaaho toh sirf recruiters ko dikhe.

### India mein AI jobs kahaan post hoti hain

| Channel | Kiske liye best | Kis baat ka dhyaan rakhein |
| --- | --- | --- |
| Naukri | Volume: IT services, GCCs, badi firms; recruiters iske resume database mein search karte hain | Apni profile aur notice period updated rakho; recruiters dono par filter karte hain |
| LinkedIn | Product companies, GCCs, AI startups; hire karne waale logon ko dhoondhna | Har post par bahut applications; ise sirf Apply button ke liye nahi, contacts dhoondhne ke liye use karo |
| Instahyre, foundit | Tech roles (Instahyre); har tarah ke roles (foundit) | Skills aur expected pay dhyaan se bharo; matching unhi par depend karti hai |
| Wellfound | Startups, early-stage AI startups bhi | Join karne se pehle funding aur runway check karo |
| Company careers pages | GCCs aur badi firms | Har company jo titles use karti hai, unse search karo |

Titles dhyaan se padho. FDE jaise kaam ko "forward deployed engineer", "solutions engineer", "AI engineer, customer-facing" ya "applied AI engineer" kaha ja sakta hai.

### Referrals aur outreach

India mein kisi insaan se aapka resume padhwaane ka sabse tez raasta aksar referral hota hai. Kai companies employee referral programmes chalaati hain, toh aapke hire hone par referrer ko bonus mil sakta hai. Isliye ye ek jaayaz request hai, ehsaan nahi. Par referrer aap par apna naam lagaata hai, toh uske liye ise aasaan aur safe banao:

- **Pehle unse poochho jo aapko jaante hain:** college alumni, puraane colleagues, seniors, open-source projects aur meetups se mile log.
- **Sab kuch ek saath bhejo:** job link ya ID, apna resume, aur apne sabse relevant project aur uske result par do lines.
- **Anjaan logon se referral nahi, baatcheet maango.** Chaar sentences use karo: aap kaun ho, ek relevant project aur uska result, ek specific sawaal, aur dhanyavaad. Jaise: "Main Coimbatore mein backend developer hoon aur AI engineering mein aa rahi hoon. Maine ek claims-document assistant banaaya hai jiski 300 synthetic test files par field accuracy 96% hai, jo aapki team insurers ko bechti hai uske kaafi kareeb. Kya aap 15 minutes nikaalkar bata sakte hain ki aapki FDE team kaise kaam karti hai? Dhanyavaad." Achhi baatcheet ke baad aksar referral mil jaata hai.

Bina context ke "Please refer me" ka jawaab kam hi aata hai.

### Coding round

Kai Indian product companies, GCCs aur IT services firms HackerRank ya HackerEarth jaise kisi platform par online coding test se shuruaat karti hain. Candidates ki reports mein aksar ek se do ghante aur data structures and algorithms (DSA) ke do ya teen easy-to-medium problems bataaye jaate hain: arrays, strings, hash maps, two pointers, sorting, trees aur graph search, kabhi-kabhi basic dynamic programming. Candidates cut-off scores ki bhi baat karte hain, isliye agar aap ye step fail kar gaye toh ho sakta hai aapka strong portfolio koi dekhe hi nahi.

FDE aur AI-startup loops practical coding ki taraf zyada jhukte hain: messy data saaf karna, kisi API ko call karna, validation aur tests jodna (lesson "The FDE interview loop" dekho). Decision rule:

- **Prepare karne se pehle recruiter se round one ka format poochho.**
- **Agar DSA test hai,** toh random tareeke se 400 nahi, pattern ke hisaab se lagbhag 60 se 80 common problems practise karo. Time lagaakar karo, aur apna approach bolkar batao.
- **Agar practical coding hai,** toh tests ke saath messy CSVs aur JSON par practise karo, aur trade-offs par baat karo.
- **Dono haalaat mein, practice jaari rakho:** search ke dauraan roz 30 minutes, ek panic week se behtar hai.

### Notice periods aur timing

Aapka **notice period** wo samay hai jitna resign karne ke baad aapko kaam karte rehna hota hai. Ise aapka appointment letter aur company policy tay karte hain, koi national rule nahi. Badi IT services firms aam taur par 90 din rakhti hain. Kai product companies aur startups chhote periods rakhte hain. Plan karne se pehle teen clauses padho: notice kitna lamba hai, kya aap **buyout** kar sakte ho (jo din serve nahi karoge unki jagah salary dena), aur training costs ka koi bond ya recovery.

Lamba notice aapki poori search ko badal deta hai:

- **Resign karne se pehle interview karo,** taaki aap teen mahine bina pay ya options ke na raho.
- **Apna notice shuru mein hi batao,** Naukri par bhi aur recruiters ko bhi. Kuch posts aise log chahti hain jo 30 din ya usse kam mein join kar sakein; 90 din ka notice chhupaane se sabka samay barbaad hota hai.
- **Naye employer se do sawaal poochho:** kya wo wait kar sakte hain, aur kya wo buyout reimburse karenge? Kuch karte hain; aapka employer buyout se mana kar sakta hai.
- **Lambe notice ke dauraan offers ko risk mein maankar chalo.** Join karne tak apne naye manager se sampark mein raho, aur doosre offer ke baare mein jhooth mat bolo.

### Salary research

Us role ka band research karo jiske liye aap apply kar rahe ho, apni current job ka nahi. Xplaind ka Jobs page Glassdoor, AmbitionBox, Instahyre aur job posts se typical yearly CTC bands, lakh rupees mein, ikattha karta hai, **2 November 2026 ko check kiye gaye**. Ye beech ke bands hain, offers nahi, aur agar Jobs page is table se alag ho toh Jobs page hi sahi maana jaayega.

| Role | 0 se 2 saal | 3 se 5 saal | 6+ saal |
| --- | --- | --- | --- |
| AI Engineer | 6 se 12 | 12 se 25 | 25 se 50 |
| Generative AI Engineer | 8 se 15 | 18 se 35 | 35 se 65 |
| Forward Deployed Engineer | 12 se 25 | 25 se 50 | 50 se 90 |

Ise kaise use karein:

- **Band ko chhota karo.** Big tech, global AI labs aur Bengaluru zyada pay karte hain; IT services aur chhote shehar kam. Shuruaati FDE band shaayad hi kabhi fresher job hota hai.
- **Us specific company ko** Glassdoor aur AmbitionBox par check karo, aur jin logon se milo unse poochho ki band kya hai.
- **"Current and expected CTC" ka jawaab dhyaan se do.** Indian recruiters aam taur par dono jaldi poochhte hain. Apna current CTC imaandaari se batao, kyunki use payslips se check kiya ja sakta hai. Apna expected figure naye role ke band aur apne saboot par rakho, current pay par kisi fixed percentage ke hisaab se nahi.

### Offers ki tulna

CTC (cost to company) take-home pay nahi hai. Har offer ko fixed pay, variable pay, joining bonus (aksar ek saal ke andar chhodne par lautaana padta hai), stock ya ESOPs (jinse shaayad kabhi paisa na mile) aur benefits mein todo. Pehle saal mein jo cash pakka milega uski tulna karo, phir kaam, learning, team aur naye notice period ki. Accept karne se pehle koi bhi badlaav likhit mein lo.

### Remote roles aur videsh mein jobs

Foreign companies Indian engineers ko remote tareeke se ek employer of record (ek firm jo unki taraf se aapko India mein employ karti hai) ke zariye ya contractors ke roop mein hire karti hain. Competition global hai, isliye aapka portfolio aur likhi hui English aur bhi zyada maayne rakhte hain. Contractor ke taur par aap self-employed ho: aap invoices bhejte ho aur apna tax khud sambhaalte ho, isliye sign karne se pehle kisi chartered accountant se baat karo. Videsh jaane ke liye work visa chahiye. Juniors ke liye sponsorship kam hi milti hai, aur US work-visa rules 2025 mein bahut badle aur ab bhi badal rahe hain, isliye unke hisaab se plan karne se pehle official government source check karo.

### Track karo aur review karo

Ek simple sheet rakho: company, role, channel (cold, referral, recruiter), date, stage aur agla follow-up. Har das applications ke baad dekho ki log kis stage par baahar ho rahe hain, aur ek baar mein ek hi cheez badlo:

| Kahaan rukta hai | Sambhaavit wajah | Kya badlein |
| --- | --- | --- |
| Koi reply nahi | Galat roles, kamzor top third, referrals nahi, notice chhupaaya ya bahut lamba | Top third tailor karo; referrals ki taraf jaao; behtar mel khaate roles target karo |
| Coding test mein fail | Format ki practice nahi | Format poochho; pattern ke hisaab se, time lagaakar practise karo |
| First rounds mein fail | Project deep dive kamzor | Apne project ke decisions aur numbers bolkar rehearse karo |
| Final loops mein fail | Kamzor design ya client role-play | Wo rounds kisi friend ke saath practise karo |
| Offers haath se nikal jaate hain | Pay mismatch ya notice period | Bands pehle research karo; pehli call mein hi notice ki baat karo |

"Ready" mehsoos karne se pehle hi apply karo: interviews dikhaate hain ki kya theek karna hai.

## Ek example se samjho

Coimbatore ki backend developer Nandhini, jinke paas do saal ka Java experience hai, ye path saat mahine mein poora karti hain. Neeche ke numbers ek illustration hain, benchmark nahi. Aapka apna funnel kaafi alag dikh sakta hai.

**Portfolio.** Wo chaar projects pin karti hain, har ek ki pehli lines mein result aur uska test set: document QA API, apni eval report ke saath enterprise RAG assistant, approval gates waala operations agent, aur ek kaalpanik hospital chain ke liye capstone. Capstone case study teen pages ki hai, saath mein do minute ka video. Uski README saaf kehti hai ki hospital kaalpanik hai aur data synthetic. Ek friend RAG assistant ko uski README se aath minutes mein run kar leta hai.

**Resume aur LinkedIn.** Wo one-column resume par aa jaati hain, Java waale kaam ko chhote bullets mein sametti hain aur numbers ke saath ek "Projects" section jodti hain. Unki LinkedIn headline unki GitHub profile se mel khaati hai.

**Timing aur pay.** Unka appointment letter kehta hai 90 din ka notice, buyout company ki marzi par. Wo ye apni Naukri profile par daalti hain. Unka current CTC ₹7 lakh hai. Jo role wo chahti hain, uske liye 0 se 2 saal ka FDE band ₹12 se 25 lakh hai. AI kaam mein nayi aur Bengaluru se baahar hone ki wajah se wo khud ko band ke nichle aadhe hisse mein rakhti hain, toh apna expected CTC ₹15 se 17 lakh rakhti hain.

**Das hafton ki search.** Wo 40 target companies ki list banaati hain aur unmein se 15 mein alumni ya contacts dhoondhti hain.

| Channel | Applications | Replies | First rounds | Final loops | Offers |
| --- | --- | --- | --- | --- | --- |
| Cold (Naukri, LinkedIn) | 30 | 2 | 1 | 0 | 0 |
| Referral ya contact | 15 | 6 | 5 | 3 | 2 |
| Kul | 45 | 8 | 6 | 3 | 2 |

Unki sheet do baatein dikhaati hai. Aath mein se chhah replies referrals se aaye. Aur teesre hafte mein wo apna pehla DSA online test fail ho gayin, toh unhone har recruiter se format poochhna shuru kiya aur roz 30 minutes, time lagaakar pattern ke hisaab se problems practise kiye. Agle dono mein wo pass huin.

**Do offers.** Hospitals ko bechne waala ek AI startup ek forward deployed role offer karta hai. Hiring manager kehte hain ki unhone capstone case study ki wajah se hi call kiya.

| Offer ka hissa | Startup, FDE | GCC, applied AI engineer |
| --- | --- | --- |
| Fixed pay | ₹15 lakh | ₹16 lakh |
| Variable pay | ₹1.5 lakh, agar targets poore hon | Koi nahi |
| Joining bonus | Koi nahi | ₹1 lakh, ek saal ke andar chhodne par lautaana hoga |
| Stock | ₹1.5 lakh saalaana ke ESOPs | Koi nahi |
| Likha hua CTC | ₹18 lakh | ₹17 lakh |
| Pehle saal mein pakka milne waala cash | ₹15 lakh | ₹17 lakh |

Startup ka CTC zyada hai, par pakke cash mein GCC ₹2 lakh zyada deta hai. Phir bhi Nandhini startup chunti hain, us client-facing kaam ke liye jo wo karna chahti hain, aur ₹16 lakh fixed maangti hain. Wo maan jaate hain, likhit mein. Unki handover poori hone par unki company unhe 60 din baad release kar deti hai, aur startup wait karne ko taiyaar ho jaata hai.

## Aam galtiyaan

- **Tutorial clones.** Video dekhkar banaaya PDF par chatbot bahut kam dikhaata hai. Ek real problem, evals aur deployment jodo.
- **Installation se shuru hone waali READMEs.** Problem aur result se shuruaat karo.
- **Numbers jinka bachaav na kar sako.** Bina test set ka result, ya kisi kaalpanik client ka "business impact", project deep dive mein tikta nahi.
- **Fancy two-column templates.** Screening software mein ye bigad sakte hain. Ek column use karo.
- **Sirf cold applications.** Referrals aur baatcheet se aam taur par lagaaye gaye har ghante par kahin zyada replies milte hain.
- **Coding practice chhod dena.** Agar aap pehle aane waala online test fail kar gaye toh strong portfolio kaam nahi aata.
- **Apna notice period chhupaana.** Ye baad mein saamne aata hai aur offer khatam kar deta hai.
- **Sirf CTC par offers ki tulna.** Variable pay, joining bonuses aur stock pakka cash nahi hain.

## Practice karo

Profile READMEs par GitHub ki guide aur Tech Interview Handbook ki resume guide padho.

**Check (ise submit karo).** Ek GitHub profile README publish karo, is path ke kam se kam teen projects pin karo aur ek case-study write-up likho. Har project README problem, ek screenshot ya chhote video, aur aise result se shuru ho jo apna test set aur uska size bataaye. Ek reviewer ko kam se kam ek project uski README se 10 minutes se kam mein run kar paana chahiye. Apni profile ka link submit karo.

**Apni search ke liye (check nahi hoga, par karo).**

1. Apna resume ek column mein, kam se kam chaar result-based bullets ke saath dobaara likho, aur apni LinkedIn headline ko apni GitHub profile se milaao.
2. Apna appointment letter padho aur apna notice period aur buyout terms likh lo.
3. Apne target role ke liye Jobs page ka band dekho aur ek line ki wajah ke saath apna expected CTC likho.
4. 20 target companies ki list banao, har ek mein contact karne ke liye ek insaan ke saath, aur ek tracking sheet shuru karo.

**Aapka kaam poora hai jab aap** kisi anjaan insaan ko ek link bhej sako jo 60 seconds mein dikha de ki aapne kya banaaya, usse kya haasil hua aur wo number kis par maapa gaya.
