## Ye kya hai

Jaise-jaise programs bade hote hain, aap wahi chaar-paanch lines baar-baar copy karne lagte ho: teen jagah GST nikaalna, do scripts mein phone numbers saaf karna. Copy karne se bugs aate hain, kyunki ek copy theek karo toh baaki bhool jaate ho. **Function** isi ka ilaaj hai.

Function ek naam waala code block hai jo **ek hi kaam** karta hai. Aap use input dete ho, jinhe **parameters** kehte hain, woh apna kaam karta hai, aur ek result **return** karta hai.

```flow
dir: LR
Inputs | price = 1000, rate = 0.18 -> Function: gst_amount(price, rate=0.18) | return price * rate
Function: gst_amount(price, rate=0.18) -> Output: 180.0
```

Functions se aap ye kar sakte ho:

- code ko copy karne ki jagah **reuse** karna;
- bade problem ko chhote tukdon mein **todna**, jinhe ek-ek karke test kar sako;
- steps ko **naam** dena, taaki program instructions ki tarah padhe: `clean_phone_number`, `monthly_emi`, `send_reminder`.

Is lesson mein hum Imran ke saath chalenge, jo ek form se aaye customers ke phone numbers saaf karta hai, aur ek gandhi script ko chhote reusable functions mein badalta hai. Lesson ke end tak aap aise functions likh paoge jo result return karein aur programs mein dobara use ho sakein.

## Ye kaam kaise karta hai

### Define karna aur call karna

```python
def gst_amount(price, rate=0.18):
    return price * rate

print(gst_amount(1000))         # 180.0, uses the default rate
print(gst_amount(1000, 0.05))   # 50.0
```

- `def` se definition shuru hoti hai.
- `price` aur `rate` **parameters** hain.
- `rate=0.18` ek **default** hai, jo tab use hota hai jab caller value na de.
- `return` result wapas deta hai.

Call karne ke liye brackets chahiye: `gst_amount(1000)`. `gst_amount` bina brackets ke likhne se function ka reference milta hai, woh chalta nahi.

### Return vs print

Beginners ko sabse zyada yahi confuse karta hai:

| | `return` | `print` |
| --- | --- | --- |
| Kya karta hai | Caller ko value wapas deta hai | Screen par text dikhata hai |
| Kya caller value use kar sakta hai? | Haan: `total = price + gst_amount(price)` | Nahi: function `None` return karta hai |
| Kab use karein | Jo functions kuch compute karte hain | Sirf us code mein jo results dikhata hai |

Jo function kuch compute karta hai, use return karna chahiye, aur print karna us code par chhod do jo use call karta hai. Phir wahi function report, web app ya test, sab mein chalega.

### Position se aur naam se arguments

```python
gst_amount(1000, 0.05)               # by position
gst_amount(price=1000, rate=0.05)    # by name: clearer with several parameters
```

### Scope

Function ke andar bane variables sirf usi ke andar rehte hain:

```python
def tax(amount):
    total = amount * 1.18
    return total

result = tax(100)     # 118.0
print(total)          # NameError: total only existed inside tax
```

Function ko jo chahiye woh pass karo aur jo banaye woh return karo, bahar ke variables par depend mat karo. Jo functions sirf apne inputs use karte hain, unhe test aur reuse karna aasaan hota hai.

### Har function ek kaam

Achha function ek hi cheez karta hai, aur uska naam batata hai ki kya. Describe karne ke liye "aur" lagana pade, jaise "number saaf karta hai aur SMS bhejta hai", toh use do functions mein todo.

```flow
dir: LR
Ek bada function: process_customers() | reads, cleans, checks and writes: hard to test or reuse -[todo isse]-> Chhote functions | digits_only(), normalise_mobile(), is_valid_email(), read_customers(), write_report(): each testable alone
```

### Docstrings aur type hints

Ek line ka description aur type hints padhne waalon aur tools, jaise aapke editor, ki madad karte hain:

```python
def monthly_emi(principal: float, annual_rate: float, months: int) -> float:
    """Equated monthly instalment for a loan."""
    r = annual_rate / 12
    return principal * r * (1 + r) ** months / ((1 + r) ** months - 1)

print(round(monthly_emi(500000, 0.09, 60)))   # about 10379 rupees a month
```

### Ek jaal: mutable defaults

```python
def add_order(order, orders=[]):      # bug: the same list every call
    orders.append(order)
    return orders
```

Default list ek hi baar banti hai aur calls ke beech share hoti hai, isliye orders jama hote jaate hain. `None` use karo aur andar nayi list banao:

```python
def add_order(order, orders=None):
    if orders is None:
        orders = []
    orders.append(order)
    return orders
```

## Ek example se samjho

Imran Hyderabad ki ek chhoti marketing agency mein kaam karta hai. Ek client ke form se 3,000 customers ke phone numbers aaye, har tareeke se likhe hue: "98450 12345", "+91-9845012345", "09845012345", "9845012345 ". SMS tool ko woh `+91` ke baad das digits ke format mein chahiye.

Uski pehli script ek lamba code block thi, jo do aur scripts mein thoda badal kar copy ki gayi thi. Woh use chhote functions mein likhta hai, har ek ka ek kaam:

```python
def digits_only(text: str) -> str:
    """Keep only the digits in text."""
    return "".join(ch for ch in text if ch.isdigit())

def normalise_mobile(raw: str) -> str | None:
    """Return +91 and ten digits, or None if it is not a valid mobile number."""
    d = digits_only(raw)
    if d.startswith("91") and len(d) == 12:
        d = d[2:]
    if d.startswith("0") and len(d) == 11:
        d = d[1:]
    return "+91" + d if len(d) == 10 else None

for raw in ["98450 12345", "+91-9845012345", "09845012345", "12345"]:
    print(raw, "->", normalise_mobile(raw))
```

| Input | digits_only ke baad | Rules ke baad | Result |
| --- | --- | --- | --- |
| `98450 12345` | 9845012345 | 10 digits | +919845012345 |
| `+91-9845012345` | 919845012345 | shuru ka 91 hataya | +919845012345 |
| `09845012345` | 09845012345 | shuru ka 0 hataya | +919845012345 |
| `12345` | 12345 | bahut chhota | None |

Teen numbers `+919845012345` ban jaate hain; aakhri `None` return karta hai, toh woh invalid numbers ki list client ko de sakta hai. Logic functions mein hai, isliye agle hafte woh `normalise_mobile` ko do aur scripts mein copy karne ki jagah import kar leta hai, aur jab client landline numbers bhi accept karne ko kehta hai, woh ek jagah ek function badalta hai.

## Aam galtiyaan

- **Return ki jagah print karna.** Caller ko `None` milta hai.
- **Function call karna bhool jaana.** `gst_amount` bina brackets ke kuch nahi karta.
- **Bahut kaam karne waale functions.** Tab tak todo jab tak har ek ka ek hi kaam na ho.
- **Bahar ke variables par depend karna.** Inputs parameters mein do aur results return karo.
- **Mutable defaults** jaise `def add(item, items=[])`. `None` use karo aur andar nayi list banao.
- **Dhundhle naam.** `process()` aur `do_stuff()` padhne waale ko kuch nahi batate.
