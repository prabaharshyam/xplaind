## Ye kya hai

"Smart software" ke liye log teen words aise use karte hain jaise sab ek hi hon: **artificial intelligence**, **machine learning** aur **large language model**. Ye teeno ek nahi hain. Interviewer, client ya aapka manager sabse pehle yahi check karenge ki aapko farak pata hai ya nahi.

Teen gole socho, ek ke andar ek:

```flow
title: Har gola pichhle gole ke andar hai
Artificial intelligence (AI) | woh software jo aise kaam kare jo humein lagta tha insaan hi kar sakte hain -> Machine learning (ML) | examples se rules seekhta hai
Machine learning (ML) -> Large language models (LLMs) | text se seekhte hain, text likhte hain
```

- **Artificial intelligence (AI)** bada goal hai: aisa software jo woh kaam kare jinke liye humein lagta tha ki insaan ki samajh chahiye. Chehra pehchaanna, Tamil se English mein translate karna, gaana recommend karna aur sawaal ka jawab dena, ye sab AI ke kaam hain.
- **Machine learning (ML)** aaj AI banane ka sabse bada tareeka hai. Har rule insaan se likhwane ki jagah, program ko bahut saare examples dikhate hain aur woh pattern khud seekh leta hai.
- **Large language model (LLM)** ek tarah ka machine learning model hai, jise bahut zyada text par train kiya gaya hai taaki woh predict kare ki aage kya aayega. ChatGPT, Claude aur Gemini, LLM par bane products hain.

Yaani har LLM machine learning hai, aur har machine learning AI hai. Ulta sach nahi hai. Aapke UPI app ka fraud alert machine learning hai, par language model nahi. Aur 1990 ke dashak ka ek chess program, jo haath se likhe search rules follow karta tha, AI tha par usmein machine learning nahi tha.

Is lesson mein hum Asha ke saath chalenge, jo Pune ki 200 logon waali company mein HR sambhaalti hain, unke ek normal kaam ke din mein. Lesson ke end tak aap unke saamne aane waali har "AI" cheez ko sahi gole mein rakh paoge, bata paoge ki language model kaise likhta hai, aur ye bhi ki woh kabhi-kabhi galat kyun ho jaata hai.

## Ye kaam kaise karta hai

### Rules vs learning

Machine learning se pehle software woh rules follow karta tha jo insaan likhta tha. Asha ki company ke expense system mein aisa ek rule hai:

```text
IF amount > 5,000 rupees AND receipt missing
THEN send to manager for approval
```

Rules saaf aur predictable hote hain, par har case kisi ko sochna padta hai. Fraud, chehre aur language mein itne cases hain ki koi sab likh hi nahi sakta.

Machine learning ye kaam ulta kar deta hai. Aap aise examples ikattha karte ho jinka jawab pehle se pata hai, aur program unmein pattern dhoondh leta hai:

```flow
dir: LR
Jawab waale examples | payment 1: asli, payment 2: fraud ... 1 crore aur -> Training | pattern seekhna
Training -> Ek model | naya payment andar, "fraud: 0.93" baahar
```

Nateeja hota hai ek **model**: seekhe hue numbers ki ek file, jo input ko output mein badalti hai. Bank ke fraud model ne aapka exact payment kabhi nahi dekha, par uske jaise laakhon dekhe hain, isliye woh achha andaaza laga leta hai. Par woh utna hi achha hai jitne uske examples. Agar examples mein kisi tarah ka fraud tha hi nahi, toh model use miss kar dega.

| | Rule-based software | Machine learning |
| --- | --- | --- |
| Logic kaun tay karta hai | Insaan likhta hai | Examples se seekha jaata hai |
| Kismein achha | Tax slabs jaise saaf, stable rules | Chehre, fraud, language jaise dhundhle patterns |
| Galat hone par | Rule galat tha; rule theek karo | Examples kam the ya biased the; data theek karo |
| Faisla samjhaana | Aasaan: rule dikha do | Mushkil: pattern bahut saare numbers mein phaila hai |

### Language model kaise likhta hai

Large language model, text par lagaya gaya machine learning hai. Training mein woh behisaab likha hua padhta hai: books, websites, code, forum posts. Uska ek hi kaam hai, text ka agla chhota tukda guess karna, jise **token** kehte hain. Token aksar ek poora chhota word hota hai ("the"), kabhi lambe word ka hissa ("under" + "stand" + "ing").

Training ke baad, jab aap sawaal poochhte ho, model ek-ek token karke jawab likhta hai:

```text
Prompt: "The capital of Karnataka is"

Step 1: likely next tokens ->  " Bengaluru" 0.86 | " Bangalore" 0.12 | " Mysuru" 0.01
Step 2: picks " Bengaluru", adds it, and asks again ->  "." 0.71 | "," 0.20 ...
Step 3: keeps going until the answer is complete
```

Generation bas itna hi hai: predict karo, ek chuno, jodo, phir se karo. Kaafi data aur bada model ho, toh yahi simple skill summaries, translations, emails, code aur step-by-step explanations bana deti hai, kyunki insaanon ke likhe text mein ye saare patterns maujood hain.

### Ye kya nahi karta

Teen limits jo roz yaad rakhni hain:

1. **Ye facts dhoondhta nahi.** Jab tak product ise web search ya aapke documents se na jode, ye training mein seekhe patterns se jawab deta hai. Iske andar sachche facts ka koi database nahi hai.
2. **Iski ek knowledge cut-off hoti hai.** Training data ikattha hone ke baad jo hua, woh ise nahi pata, jab tak product nayi jaankari na de.
3. **Ye khud ko check nahi kar sakta.** Ye woh likhta hai jo likely hai, woh nahi jo verified hai. Isliye ye fluent, confident par galat text bhi likh sakta hai. Ise **hallucination** kehte hain.

### Model vs product

Ek aur farak par log atakte hain. **Model** train kiye gaye numbers ki file hai. **Product** uske chaaron or ka app hai: chat window, search tool, memory feature, safety filters. Jab chat assistant "web search karta hai", toh asal mein product ek search tool bulaakar results model ko deta hai. Jab log "ChatGPT vs Claude" compare karte hain, toh woh alag-alag models par bane products compare kar rahe hote hain.

## Ek example se samjho

Ye raha Asha ka Monday, har AI apne gole mein.

**Subah 8:40, spam filter (machine learning, LLM nahi).** Unka inbox "Ghar baithe hafte ke ₹50,000 kamao!" waala fake job offer spam mein daal deta hai. Filter ne un laakhon emails se seekha jinhe logon ne spam ya not spam mark kiya. Woh ek label deta hai, text nahi.

**Subah 9:05, face unlock (machine learning, LLM nahi).** Naye chashme ke bawajood phone unhe pehchaan leta hai. Images par train hue model ne seekha ki kaunse features maayne rakhte hain.

**Subah 10:15, payroll formula (AI nahi).** Ek spreadsheet overtime jodti hai. Exact formula insaan ne likha; kuch seekha nahi gaya.

**Subah 11:00, chat assistant (ek LLM).** Asha poochhti hain: "Hamari nayi hybrid work policy ka friendly announcement draft karo: hafte mein teen din office, 1 December se."

Draft achha hai. Garmjoshi bhara, saaf aur achhe structure waala. Par usmein ye line bhi hai: "Shops and Establishments Act ke tehat, policy mein kisi bhi badlaav ke liye employees ko 30 din ka notice dena zaroori hai."

Sunne mein official lagta hai. Asha company ke lawyer se check karti hain, jo batate hain ki Maharashtra ke liye ye baat sahi nahi hai aur yahan kisi law ka zikr karne ki zaroorat hi nahi. Asha woh line hata deti hain.

| Kaam | AI ke bina time | AI ke saath time |
| --- | --- | --- |
| Pehla draft likhna | lagbhag 45 minute | 2 minute |
| Facts aur tone check karna | 5 minute | 10 minute |
| Total | lagbhag 50 minute | lagbhag 12 minute |

Assistant ne aadhe ghante se zyada bachaaya, par sirf isliye kyunki unhone check kiya. Tez draft aur dhyaan se check: professionals language models ko aise hi use karte hain.

**Dopahar 3:30, fraud alert (machine learning, LLM nahi).** Unka bank app ek naye account ko ja raha ₹49,000 ka payment rokkar OTP maangta hai. Fraud model ne payment ko ajeeb score kiya. Payment asli tha, toh ye false positive tha, hallucination nahi: model ne text nahi gadha, bas yes/no ka galat faisla kiya.

## Aam galtiyaan

- **AI, ML aur LLM ko ek hi word ki tarah use karna.** Ye ek ke andar ek hain. Vendor kahe "hamara AI", toh poochho kaunsa. Rules engine, fraud model aur chat assistant ko bilkul alag data, testing aur budget chahiye.
- **Ye sochna ki language model cheezein dhoondhta hai.** Jab tak product na bataye ki woh search karta hai ya aapke documents use karta hai, woh patterns se generate kar raha hai. "Usne bola tha" koi source nahi hai.
- **Confidence par bharosa karna.** Fluent tone accuracy ke baare mein kuch nahi batata. Numbers, laws, naam, dates aur haal ki kisi bhi cheez mein sabse zyada saavdhaan raho.
- **Har galti ko hallucination kehna.** Hallucination, generative model ka gadha hua content hai. Fraud model ka asli payment rokna false positive hai; spam filter ka spam miss karna false negative hai.
- **Ye maan lena ki model insaan ki tarah samajhta hai.** Woh koi mushkil idea badhiya samjha sakta hai aur phir thode alag dhang se poochhe gaye aasaan sawaal par fail ho sakta hai. Bharosa karne se pehle apne asli kaam par test karo.
- **Model aur product ko mix karna.** Ek hi model do apps mein bahut alag behave kar sakta hai, uske aas-paas ke tools, instructions aur safety settings ki wajah se.

## Practice karo

Neeche link kiya large language models ka intro dekho; ye bina maths ke training aur generation saaf samjhaata hai. Phir ye teen kaam karo.

1. **Apna hafta chhaanto.** Pichhle hafte use kiye 5 AI features likho: maps, spam filter, payment app, voice typing, koi recommendation, chat assistant. Har ek ke liye likho ki woh kis gole mein hai aur kya output deta hai (label, score, route, text).
2. **Ek hallucination pakdo.** Kisi chat assistant se apne shehar ya field ke baare mein numbers waale teen facts poochho, jaise aabaadi, sthaapna ka saal aur koi statistic. Har ek ko kisi official source se check karo. Note karo kaunse galat the aur kitne confidence se bole gaye the.
3. **Zor se samjhaao.** Token, predict aur hallucination words use karke do minute mein kisi dost ko samjhaao ki language model jawab kaise likhta hai. Khud ko record karke suno.

**Aapka kaam poora jab:** aap AI, machine learning aur language model ka farak aasaan shabdon mein samjha sako, har ek ki roz ki ek misaal de sako, aur bata sako ki language model poore confidence se galat kyun ho sakta hai.
