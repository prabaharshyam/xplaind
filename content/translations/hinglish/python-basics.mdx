## Ye kya hai

Python AI ke kaam ki main language hai: data cleaning, automation scripts, AI APIs call karna aur applications banana, sab isse hota hai. Kaam ka banne ke liye poora Python seekhna zaroori nahi. Paanch building blocks se zyadatar chhote programs likhe ja sakte hain:

| Building block | Kya karta hai | Example |
| --- | --- | --- |
| **Variables** | Ek naam ke neeche value store karte hain | `price = 250` |
| **Conditions** | Tay karte hain ki kya karna hai | `if price > 200:` |
| **Loops** | Steps dohraate hain | `for item in cart:` |
| **Functions** | Aise steps ka package jo dobara use ho sakein | `def total(cart):` |
| **Lists aur dictionaries** | Bahut saari values rakhte hain | prices ki list, kisi student ki details ki dictionary |

```flow
dir: LR
Data andar | orders, prices, marks -> Aapka program | variables values rakhte hain, loops har order se guzarte hain, conditions price chunti hain, functions jod-ghata karte hain
Aapka program -> Result baahar | bills, totals, reports
```

Is lesson mein hum Divya ke saath chalenge, jo Bengaluru mein tiffin service chalaati hain, aur apne customers ke bills nikaalne ke liye apna pehla kaam ka program likhti hain. Lesson ke end tak aap apna 20 lines ka program likh paoge aur samjha paoge.

## Ye kaam kaise karta hai

### Values aur types

Python mein kuch basic tarah ki values hoti hain:

| Type | Examples | Notes |
| --- | --- | --- |
| Poore numbers (`int`) | `250`, `-3` | Counts aur bina paise ke rupees ke liye |
| Decimal numbers (`float`) | `18.5`, `0.18` | Rates, averages ke liye |
| Text (`str`) | `"Chennai"`, `'Asha'` | Hamesha quotes mein |
| Sach ya jhooth (`bool`) | `True`, `False` | Comparisons ke results |

Python value dekhkar type khud samajh leta hai. Types ke beech convert karne ke liye `int("42")`, `float("3.5")` aur `str(42)` use karo.

### Variables

Variable ek value ka label hai. Dobara assign karne se woh badal jaata hai ki woh kiski taraf point karta hai:

```python
monthly_rent = 15000
monthly_rent = monthly_rent + 500    # now 15500
```

`x` ki jagah `monthly_rent` jaise saaf naam use karo. Agle mahine aap khud ko thank you bologe.

### Conditions

```python
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Pass")
```

Indentation, chaar spaces, dikhati hai ki kaunsi lines har branch ki hain. Python ise gambhirta se leta hai: galat indentation error hai ya, aur bura, program ka kaam badal deti hai.

Comparisons `==` (barabar), `!=` (barabar nahi), `>`, `>=`, `<` aur `<=` se hote hain. Ek akela `=` assign karta hai; compare nahi karta.

### Loops

`for` loop har item ke liye ek baar chalta hai:

```python
for city in ["Pune", "Kochi", "Jaipur"]:
    print("Delivering to", city)

for i in range(3):
    print(i)        # prints 0, then 1, then 2
```

`range(3)` 0, 1 aur 2 deta hai: ye 0 se shuru hota hai aur 3 se **pehle** ruk jaata hai. `while` loop tab tak dohraata hai jab tak condition sach rahe, jo tab kaam aata hai jab pehle se pata na ho ki kitni baar dohraana hai.

### Functions

Function inputs leta hai, kuch kaam karta hai aur ek result `return` karta hai:

```python
def gst(amount, rate=0.18):
    return amount * rate

print(gst(1000))         # 180.0
print(gst(1000, 0.05))   # 50.0
```

`rate=0.18` ek default hai: jab aap rate nahi dete tab use hota hai. Jab bhi khud ko wahi kuch lines copy karte paao, function likh do.

### Lists

Ordered collections:

```python
cities = ["Pune", "Kochi"]
cities.append("Jaipur")     # add to the end
print(cities[0])            # Pune: counting starts at 0
print(len(cities))          # 3
```

### Dictionaries

Position ki jagah key se values dhoondho:

```python
profile = {"name": "Asha", "age": 24}
profile["city"] = "Pune"     # add or change a key
print(profile["name"])       # Asha
```

**Dictionaries ki list** wahi shakal hai jismein Python mein zyadatar asli data dikhta hai: har dictionary ek record hai, jaise spreadsheet ki ek row.

### Error messages padhna

Jab kuch galat hota hai, Python ek **traceback** print karta hai. Use neeche se upar padho: aakhri line error ka naam batati hai, aur uske upar ki line batati hai ki kahan hua.

```text
Traceback (most recent call last):
  File "bill.py", line 12, in <module>
    total = total + amount
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Ye kehta hai: line 12 par aapne ek number aur ek text ko jodne ki koshish ki. Fix ye hai ki jahan value padhi gayi thi wahan text ko `int()` se convert kar do. Errors normal hain; unhe shaanti se padhna aadhi programming hai.

## Ek example se samjho

Divya Bengaluru mein ek chhoti tiffin service chalaati hain aur pehle orders apne dimaag mein rakhti thi. Veg meal ₹90 ka hai aur non-veg ₹120 ka. Woh apna pehla kaam ka program likhti hain:

```python
orders = [
    {"customer": "Ravi", "meals": 2, "veg": True},
    {"customer": "Sana", "meals": 1, "veg": False},
    {"customer": "Arun", "meals": 3, "veg": True},
]
PRICE_VEG = 90
PRICE_NONVEG = 120

def bill(order):
    price = PRICE_VEG if order["veg"] else PRICE_NONVEG
    return order["meals"] * price

total = 0
for order in orders:
    amount = bill(order)
    total = total + amount
    print(order["customer"], "owes Rs", amount)

print("Today's total: Rs", total)
```

Step by step ye hota hai:

| Loop pass | Customer | Veg? | Price | Meals | Bill | Running total |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Ravi | haan | 90 | 2 | 180 | 180 |
| 2 | Sana | nahi | 120 | 1 | 120 | 300 |
| 3 | Arun | haan | 90 | 3 | 270 | 570 |

Program har customer ka bill aur din ka total ₹570 print karta hai. Jab prices badalte hain, woh upar ki do lines edit kar deti hain. Prices capital letters mein hain, yaad dilaane ke liye ki ye settings hain, aisi values nahi jo program badalta hai.

Aage woh orders ko program mein type karne ki jagah CSV file se padhne ki plan bana rahi hain, jo files waala lesson sikhaata hai.

## Aam galtiyaan

- **Galat indentation.** `if`, `for` aur `def` ke andar ki lines ko ek jaisa indent karna hai, aam taur par chaar spaces.
- **`range` ke saath ek-ka-farak.** `range(3)` matlab 0, 1, 2, na ki 1, 2, 3.
- **Text aur numbers ko milana.** `"5" + 3` fail hota hai; pehle `int()` ya `str()` se convert karo.
- **Condition mein `=` use karna.** Comparison `==` se hota hai.
- **Function mein `return` ki jagah `print`.** Print value dikhaata hai; return use karne ke liye wapas deta hai.
- **Samajh na aane waale naam.** `a`, `b` aur `temp` se programs padhna mushkil ho jaata hai; cheezon ka naam wahi rakho jo woh rakhti hain.
