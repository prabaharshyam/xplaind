## Ye kya hai

**Convolutional neural network (CNN)** images ko chhote learned filters se process karta hai jo tasveer par slide karte hain. Shuruaati layers edges aur textures seekhti hain; baad ki layers unhe milakar shapes aur objects banati hain. Kyunki image mein har jagah wahi filter use hota hai, CNNs achhe se efficiently seekhte hain aur patterns jahan bhi dikhein unhe pehchaan lete hain.

**Transfer learning** aise CNN (ya vision transformer) se shuru hota hai jo pehle se lakhon general images par train ho chuka hai, aur use aapke task ke liye adapt karta hai. Isme scratch se train karne se bahut kam data aur time lagta hai aur results aam taur par behtar aate hain.

```flow
dir: LR
Image, 224x224 -> Conv: edges | kai chhote maps, 3x3 filters -> Conv: textures | pooling maps ko chhota karti hai
Conv: textures -> Conv: parts | bade regions -> Classifier | "slub defect" 0.91
```

```flow
dir: LR
title: Transfer learning
Pre-trained layers, frozen -> Ek nayi final layer, train hoti hai -[chaho toh]-> Chhote learning rate ke saath last blocks unfreeze karo
```

Ye lesson Pune ki ek textile factory ke fabric-defect project ko follow karta hai.

## Ye kaam kaise karta hai

**Convolution aur pooling.** Ek filter (jaise 3 × 3 pixels) apne neeche ke pixels ko multiply aur sum karta hai, aur ek map banata hai ki uska pattern kahan dikhta hai. Ek layer mein kai filters kai patterns detect karte hain. Pooling ya strided convolutions maps ko chhota karte hain, isliye gehri layers bade regions dekhti hain.

**Classic architectures.** ResNet, EfficientNet aur doosre achhe se tested hain aur pre-trained milte hain. Vision transformers ek naya alternative hain; dono practice mein use hote hain.

**Transfer learning ke steps.**

1. Ek pre-trained model load karo.
2. Uski final layer ko apne classes se match karti layer se badlo.
3. Pehle nayi layer ko train karo jab pehli layers frozen hon; phir chaho toh kuch ya saari layers unfreeze karke chhote learning rate se train karo (fine-tuning).

**Data augmentation.** Random flips, crops, rotations, brightness aur colour changes training images ke alag-alag versions banate hain aur overfitting kam karte hain. Aise augmentations choose karo jo asliyat se milte hon: leaf photos ko rotate karo, par text documents ko flip mat karo.

**Image data quality.** Asli images mein roshni, angle, background aur camera badalte hain. Aisi training images collect karo jo production images jaisi dikhein (shop mein phone se li gayi photos studio photos jaisi nahi hoti). Labels check karo; galat label wali images aapki soch se zyada nuksaan karti hain.

**Evaluation.** Generalisation test karne ke liye alag dinon, devices ya locations ki images alag rakho. Confusion matrix aur galat classify hui images dekho; woh aksar label errors aur missing conditions (raat, baarish, blur) dikha deti hain.

**Classification ke aage.** Object detection (cheezein kahan hain), segmentation (kaunse pixels kiske hain) aur OCR milte-julte architectures use karte hain, jo aksar pre-trained models se fine-tune hote hain.

**Scratch vs transfer learning:**

| Approach | Data chahiye | Time | Chhote datasets par typical result |
| --- | --- | --- | --- |
| Scratch se train | Das hazaar images ya zyada | Lamba | Kamzor |
| Transfer learning, frozen backbone | Sau se kuch hazaar | Chhota | Achha |
| Last blocks ko fine-tune karna | Kuch hazaar | Medium | Aksar best |

**Ek filter kya compute karta hai.** 3 × 3 filter mein nau learned weights hote hain. Har position par woh unhe neeche ke nau pixels se multiply karta hai aur results ko jodkar ek number banata hai. Image par slide karne se ek aisa map milta hai jo wahan bright hota hai jahan filter ka pattern dikhta hai, jaise vertical edge. 64 filters wali layer 64 aise maps banati hai, aur agli layer unhe milakar aur complex patterns banati hai.

**Confusion matrix padhna.** Sirf accuracy chhupa deti hai ki kaunse classes aapas mein confuse ho rahe hain. Confusion matrix har true class ke liye dikhata hai ki model ne har class ko kitni baar predict kiya. Fabric project mein isne dikhaya ki "slub" aur "thick place" defects aksar aapas mein badal jaate the, jabki "hole" lagbhag kabhi miss nahi hua. Isse team ko pata chala ki kahan aur examples collect karne hain aur kahan inspector ki doosri nazar sabse zyada matter karti hai. Confidence ke hisaab se sort ki hui bees galat classify hui images ko aankh se dekhna aksar kisi bhi ek number se zyada sikhata hai.

**torchvision se transfer learning.** Ek pretrained network load karo, final layer badlo, aur do phases mein train karo:

```python
import torch
from torch import nn
from torchvision import models, transforms

weights = models.ResNet18_Weights.DEFAULT
model = models.resnet18(weights=weights)              # downloads pretrained weights once
for p in model.parameters():
    p.requires_grad = False                           # phase 1: freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 6)         # six defect classes

train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.7, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.3, contrast=0.3),      # shop lighting varies
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
eval_tf = weights.transforms()                        # the exact resize and normalisation used in pretraining

opt = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)
# ... train a few epochs on the head only ...

# Phase 2: unfreeze the last block and fine-tune gently
for p in model.layer4.parameters():
    p.requires_grad = True
opt = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-4},
    {"params": model.fc.parameters(), "lr": 1e-3},
], weight_decay=1e-4)
```

Aise augmentations choose karo jo asliyat se milte hon: flips leaves aur fabric ke liye theek hain, par labels par text ya left-versus-right defects ke liye galat.

**Training se pehle shapes aur counts check karo.**

```python
x = torch.randn(4, 3, 224, 224)
```

**Class ke hisaab se results aur sabse buri galtiyan.**

```python
from sklearn.metrics import classification_report, confusion_matrix

def evaluate(model, loader, class_names):
    model.eval(); ys, ps, losses = [], [], []
    with torch.no_grad():
        for xb, yb in loader:
            out = model(xb)
            ys += yb.tolist(); ps += out.argmax(1).tolist()
            losses += nn.functional.cross_entropy(out, yb, reduction="none").tolist()
    print(classification_report(ys, ps, target_names=class_names, digits=3))
    print(confusion_matrix(ys, ps))
    return sorted(range(len(losses)), key=lambda i: -losses[i])[:30]   # indices of the most confident mistakes
```

Pehle sabse zyada loss wali 30 images dekho: ye aksar galat label hoti hain, blurry hoti hain ya kisi anokhe camera ki hoti hain, aur inhe theek karna tuning se zyada madad karta hai.

**Sirf random nahi, source ke hisaab se split karo.** Agar photos kai shops ya phones se aati hain, toh har shop ki images ek hi split mein rakho. Warna model defect ki jagah kisi shop ka background aur roshni seekh sakta hai.

**Dekho model kya dekh raha hai.** Grad-CAM image ke un regions ko highlight karta hai jinse prediction bana. Agar highlight watermark ya table ke kinare par hai, toh model ne koi shortcut seekh liya hai.

## Ek example se samjho

Pune fabric-defect project ko aage badhate hain: do factory lines se, chhe defect types mein 4,800 labelled images.

- Scratch se train hua chhota CNN: 71% validation accuracy.
- Pre-trained ResNet-50, nayi final layer, frozen backbone, 5 epochs: 86%.
- Aakhri do blocks ko das guna chhote learning rate se unfreeze karna, aur augmentations (flips, chhote rotations, brightness changes): 93%.

Validation mein training se alag hafte ki images use hui. Confusion matrix ne dikhaya ki zyadatar errors "slub" aur "thick place" defects ke beech the; 60 galat classify hui images review karne par 14 galat label mili. Labels theek karke retrain karne par 94.5%.

Deployment se pehle team ne doosri factory line ki 300 images par test kiya, jahan roshni alag thi: 88%. Unhone us line ki 400 images training mein jodi aur wahan bhi 93% mila, aur ek confidence threshold set kiya jiske neeche ki images human inspector ke paas jaati hain.

| Step | Validation accuracy |
| --- | --- |
| Scratch se chhota CNN | 71% |
| Pre-trained ResNet-50, frozen, nayi final layer | 86% |
| Aakhri do blocks fine-tune, augmentation ke saath | 93% |
| 14 galat label wali images theek karne ke baad | 94.5% |
| Doosri factory line, uski images jodne se pehle | 88% |
| Doosri line, uski 400 images jodne ke baad | 93% |

Labels aur doosri line ki roshni utne hi matter karte the jitna architecture.

## Aam galtiyaan

- **Kam data ke saath scratch se train karna.** Transfer learning use karo.
- **Unrealistic augmentations.** Wahi augment karo jis tareeke se asli images badalti hain, jaise roshni, angle aur blur, woh nahi jo kabhi hota hi nahi.
- **Training images ke near-duplicates par validate karna.** Din, device ya location ke hisaab se split karo.
- **Galat classify hui images ko ignore karna.** Woh label errors aur missing conditions dikhati hain.
- **Production mein confidence threshold na hona.** Uncertain images ko guess karwane ki jagah inspector ko bhejo.
- **Serving mein pretrained model se alag preprocessing.**
- **Aise augmentations jo label badal dein**, jaise left-right defects ko flip karna.
- **Shops ya devices ke across random splits**, jo scores ko phula dete hain.

## Jab CNN jawab nahi hai

- **Vision-language model task ko pehle se prompt se kar leta hai**, jaise receipt padhna ya damage describe karna, aapke volume aur cost par.
- **Bahut kam labelled images** aur aur milne ka koi raasta nahi: few-shot vision model ya rules se shuru karo.
- **Signal metadata mein hai**, jaise sensor readings ya time stamps, pixels mein nahi.

## Demo se production tak

- **Training aur serving mein wahi preprocessing** use karo, model ke saath save karke.
- **Class aur source (shop, device, din) ke hisaab se evaluate karo.**
- **Zyada loss wali images review karo** aur tuning se pehle labels theek karo.
- **Production mein image quality monitor karo:** blur, brightness, resolution.
- **Low-confidence predictions ke liye human check** rakho.
