## Ye kya hai

**n8n** ("n-eight-n" bola jaata hai) ek workflow automation tool hai. Aap visual canvas par **nodes** jodkar automations banate ho. Har node ek kaam karta hai: nayi email par nazar rakhna, spreadsheet padhna, API call karna, AI model se poochhna, message bhejna. Data ek node se agle node tak behta hai.

Ye Zapier ya Make jaisa hai, do farak ke saath jinhe log value karte hain. Aap ise apne server par **self-host** kar sakte ho, jisse data aapke haath mein rehta hai aur volume par kharcha kam aata hai, aur isme strong **AI nodes** hain, jinmein ek AI Agent node bhi hai jo reason kar sakta hai, tools use kar sakta hai aur baatcheet yaad rakh sakta hai.

**Workflow automation** business use hai: ek chhoti team apne pehle se use hone waale apps ke beech software se data move karwaakar har hafte ghante wapas paati hai.

```flow
Trigger: form enquiry | ek webhook -> AI Agent | classify karo aur reply ka draft banao
Memory: purani chats -> AI Agent
Model, prompt aur tools -> AI Agent
AI Agent -> Fees ke baare mein hai?
Fees ke baare mein hai? -[haan]-> Sheet: log karo -> Gmail: approval ke liye draft
Fees ke baare mein hai? -[nahi]-> Slack: staff ko alert karo
```

## Ye kaam kaise karta hai

**Triggers sab kuch shuru karte hain.** Common wale hain schedule (roz subah 9 baje), webhook (koi doosra app ek URL call karta hai), app triggers (nayi Gmail message, Google Sheets mein nayi row) aur chatbots ke liye chat trigger.

**Nodes kaam karte hain.** n8n mein sainkdon integrations hain: Google Workspace, Slack, Notion, Airtable, HubSpot, databases, kisi bhi API ko HTTP requests, aur official Business API se WhatsApp. IF, Switch, Merge aur Loop jaise **logic nodes** flow ko control karte hain.

**Data JSON ki tarah chalta hai.** Har node items output karta hai. Baad ke nodes unhe `{{ $json.email }}` jaise **expressions** se padhte hain. Aap har step par exact data dekh sakte ho, jisse debugging code ke mukable bahut aasaan ho jaati hai.

**AI nodes.** AI Agent node ek chat model (Claude, GPT, Gemini ya local model), ek system prompt, **memory** aur **tools** ko milaata hai. Tools doosre nodes ho sakte hain, jaise "is sheet mein search karo" ya "calendar event banao", taaki agent sirf baat na kare, kaam bhi kar sake. Text ko classify karne, fields ko structured data mein nikaalne aur summarise karne ke liye aur simple nodes bhi hain.

**Credentials** ek baar store hote hain aur dobara use hote hain, isliye API keys kabhi workflows ke andar nahi baithti.

**Chalana.** Jaldi shuru karne ke liye n8n Cloud use karo, ya chhote server par Docker se self-host karo. Sample data se test karo, phir workflow ko activate karo taaki woh apne aap chale.

| Building block | Kis kaam ke liye | Example |
|---|---|---|
| Schedule trigger | tay times par chalna | subah 8 baje daily sales summary |
| Webhook | doosre app par turant react karna | payment gateway ka success event |
| HTTP Request | kisi bhi API ko call karna | exchange rates laana |
| IF / Switch | conditions par branch karna | enquiries ko type ke hisaab se route karna |
| AI Agent | tools ke saath reason aur act karna | price sheet se FAQs ka jawab dena |
| Information Extractor | text ko fields mein badalna | invoice se amount aur date padhna |
| Wait / approval | insaan ke liye ruk jaana | reply bhejne se pehle approve karna |
| Error workflow | failures pakadna | run fail hone par Slack par alert |

**Bharosa karne se pehle testing.** n8n aapko workflow haath se chalaane deta hai, trigger par sample data pin karne deta hai taaki har test mein wahi input ho, aur har node ke output ko step by step dekhne deta hai. Asli jaisa messy data test karo: Hinglish mein ek enquiry, ek khaali field, teen attachments waali email. Zyadatar automation bugs un inputs se aate hain jo kisi ne try hi nahi kiye.

**Kharche par nazar.** Har AI step har call par thoda kharcha karta hai, aur n8n Cloud plans mahine mein kitne workflow runs milenge ye limit karte hain. Client ko monthly cost ka vaada karne se pehle providers ki sites par current limits aur model prices dekho.

## Ek example se samjho

Arvind Jaipur mein 600 students ka ek coaching institute chalaate hain. Enquiries Google Form se kisi bhi time aati hain, aur front desk agle din reply karta hai, tab tak kaafi parents kisi competitor ko call kar chuke hote hain.

Woh ek dopahar mein ek workflow banate hain:

1. **Google Forms trigger** har nayi enquiry par.
2. **AI Agent**, jiske prompt mein batch timings, fees aur demo-class schedule hain. Woh enquiry ko fees, timings, demo ya other mein classify karta hai, aur parent ne jis bhasha mein likha, Hindi ya English, usmein reply ka draft banata hai.
3. **IF node:** demo requests seedhe ek Google Calendar tool par jaati hain jo agla khaali slot book kar deta hai.
4. **Google Sheets** har enquiry, uski category aur draft log karta hai.
5. **Gmail** draft banata hai, bheji hui mail nahi. Front-desk manager use apne phone se approve karti hain.

Pehle mahine mein, median reply time 14 ghante se girkar 25 minute ho jaata hai, aur demo bookings ek tihaai badh jaati hain. Do hafte tak lagbhag bina edit ke drafts approve karne ke baad, Arvind "timings" category ko apne aap bhejne dete hain aur fees ke liye approval rakhte hain, jahan galtiyan mehngi hoti hain.

Jab ek raat Sheets API kuch der ke liye fail hota hai, unka error workflow Slack alert bhejta hai aur run dobara try hota hai, isliye koi enquiry nahi khoti.

## Aam galtiyaan

**Messy process ko automate karna.** Pehle steps likho aur unhe simple karo; automation kharaab process ko aur tezi se fail karwaata hai.

**Shuru mein AI ko bina review ke bhejne dena.** Drafts aur human approval se shuru karo. Approval sirf un categories ke liye hatao jinka output lambe time se achha raha ho.

**Error handling nahi.** APIs fail hote hain. Retries, ek error workflow aur alerts jodo, nahi toh failures hafton tak pata nahi chalte.

**Keys aur values ko hard-code karna.** Keys ke liye credentials aur prices jaisi badalne waali values ke liye ek settings node ya sheet use karo.

**Ek bada sa workflow.** Bade automations ko chhote workflows mein todo jo ek-doosre ko call karein. Unhe test karna aur theek karna aasaan hota hai.

**Data protection ignore karna.** Prompts aur logs mein customer data personal data hai. Sirf utna lo jitna chahiye aur jaano ki har service use kahan store karti hai.
