## ये क्या है

Claude **animated explainer videos** बना सकता है: titles जो सरकते हुए आते हैं, diagrams जो step by step बनते हैं, charts जो बढ़ते हैं, icons जो रास्ते पर चलते हैं। ये हर element को बनाने और चलाने वाला **code लिखकर** ऐसा करता है, camera footage generate करके नहीं। इसीलिए ये **motion graphics** के लिए एकदम सही है: कोई idea, process या numbers समझाना।

2026 के आख़िर में इसके तीन तरीके हैं:

- **Claude Motion** (beta, अक्टूबर 2026 में launch): explainer describe करो या कोई report या data paste करो, और Claude एक छोटी animation बनाता है जिसे आप edit और export कर सकते हो। देखो कि आपके Claude plan में ये शामिल है या नहीं।
- **Claude artifacts:** सामान्य chat में Claude से animated HTML, CSS या SVG scene माँगो। वो तुरंत चलता दिखता है और आप उसे screen-record कर सकते हो।
- **Remotion वाला Claude Code:** Claude एक Remotion project लिखता है, यानी React components जहाँ हर frame code है, और एक proper MP4 render करता है। लंबे videos, series और data से चलने वाले videos के लिए सबसे अच्छा।

```flow
Idea -> Script | scenes, timings, on-screen text -> Claude animation code लिखता है | Claude में Motion, HTML या SVG artifact, या Claude Code + Remotion
Claude animation code लिखता है -> Preview
Preview -[यहाँ धीमा, वहाँ बड़ा text]-> Revise
Revise -> Preview
Revise -> MP4 export करो -> Voice-over, captions, music जोड़ो -> Publish
```

## ये काम कैसे करता है

**1. Prompt से नहीं, script से शुरू करो।** हर scene लिखो: उसकी लंबाई, क्या दिखता है, क्या चलता है, और screen पर या narration में कौन-से शब्द हैं। एक idea के लिए तीस से नब्बे seconds काफ़ी हैं। Quality का सबसे बड़ा कारण यही है।

**2. Visual style एक बार तय करो।** दो-तीन brand colours, एक font, background और motion का अंदाज़ बताओ, जैसे "smooth ease-in-out, कोई उछल-कूद नहीं"। Claude इसे सभी scenes में निभाएगा।

**3. पहला draft बनवाओ।** Script और style को Claude Motion या chat में paste करो, या Claude Code से कहो कि हर scene के लिए एक component वाला Remotion project बनाए। कहो कि text इतना बड़ा रखे कि phone पर पढ़ा जा सके।

**4. बात करके सुधारो।** Video code है, इसलिए सटीक बदलाव आसान हैं: "scene 3 को दो seconds लंबा करो", "तीर बाईं ओर से आना चाहिए", "38% को 41% करो"। बस वही element बदलता है।

**5. Export।** Claude Motion और Remotion MP4 export करते हैं। Artifact के लिए screen-record करो, या Claude से उसे Remotion project में बदलने को कहो।

**6. Sound और captions जोड़ो।** Narration record करो या text-to-speech voice लो, mute पर देखने वालों के लिए captions जोड़ो, और ज़रूरत हो तो हल्का music track।

| तरीका | किसके लिए सबसे अच्छा | मेहनत | Output |
|---|---|---|---|
| Claude Motion | prompt, report या data से जल्दी explainers | सबसे कम | edit हो सकने वाली animation, MP4 export (plan पर निर्भर) |
| Claude artifact | एक animated scene या diagram | कम | HTML जिसे आप screen-record कर सको |
| Claude Code + Remotion | लंबे videos, series, data से चलने वाले batches | मध्यम | render किया MP4, दोबारा use होने वाले templates |
| Video model (Veo, अगली guide देखो) | असली-सी footage | मध्यम | generate की गई clips |

**Data से videos बनाना।** Remotion video एक program है, इसलिए वो data को input ले सकता है। एक sales team spreadsheet से हर region के लिए एक personalised video render कर सकती है, या एक teacher scripts की list से हर chapter के लिए एक video। Claude Code वो loop लिख सकता है जो data पढ़े और हर version render करे, जिसकी बराबरी हाथ से बनी animation का कोई workflow नहीं कर सकता।

## एक example से समझो

Sneha नागपुर के एक college में computer science पढ़ाती हैं। उनके students को RAG chatbot का काम समझने में दिक्कत होती है, इसलिए वो class के WhatsApp group के लिए 60 seconds की animation बनाना चाहती हैं।

वो script लिखती हैं:

1. (6 s) एक student chat box में "What is the exam syllabus?" टाइप करता है।
2. (12 s) सवाल numbers की एक कतार में बदल जाता है, एक "embedding", और documents के ढेर की ओर जाता है।
3. (12 s) तीन मेल खाते paragraphs जगमगाते हैं और ढेर से बाहर सरकते हैं।
4. (15 s) सवाल और तीनों paragraphs "LLM" लिखे box में बहते हैं।
5. (10 s) एक जवाब आता है, और नीचे source document का नाम।
6. (5 s) Title card: "RAG = search first, then answer"।

वो Claude Code से Remotion में इसे बनाने को कहती हैं, flat style में purple और white के साथ, हर scene के नीचे captions, और text 48 px से छोटा नहीं। पहला render पास का है। वो दो बदलाव माँगती हैं: scene 2 धीमा करो, जो पढ़ने से पहले ही निकल गया, और scene 3 में document names दिखाओ। हर बदलाव में Claude को एक मिनट से कम लगता है।

वो अपनी narration phone पर record करती हैं, Claude Code scene lengths को audio से sync करता है, और वो MP4 export करती हैं। अगले semester वो उसी project से हर topic का video बनाती हैं, बस script बदलकर, क्योंकि scenes components हैं।

## आम गलतियाँ

**Script के बिना prompt करना।** "X पर एक explainer बनाओ" से generic नतीजा मिलता है। पहले scenes, timings और शब्द लिखो।

**Screen पर बहुत ज़्यादा text।** लोग एक साथ पढ़ और सुन नहीं सकते। हर scene में screen पर कुछ ही शब्द रखो और details narration पर छोड़ो।

**बस दिखाने के लिए motion।** घूमना, उछलना और zoom करना idea से ध्यान हटाते हैं। सिर्फ़ वही animate करो जो समझने में मदद करे।

**Phones के लिए बहुत छोटा text।** ज़्यादातर लोग phone पर देखते हैं। Preview को phone के size पर check करो।

**असली-से scenes के लिए इसे use करना।** Claude की animation code से बनी drawing है। Camera पर लोगों, जगहों और products के लिए Veo जैसा video model use करो, जो अगली guide में है।

**ऐसे music और images जिनका आपको हक़ नहीं।** Royalty-free tracks और अपनी या licensed images use करो, खासकर public या commercial चीज़ों के लिए।
