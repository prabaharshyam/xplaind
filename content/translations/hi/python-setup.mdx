## ये क्या है

Programs लिखने से पहले आपको उन्हें लिखने की जगह और चलाने का तरीका चाहिए। Student से लेकर बड़ी company के AI engineer तक, हर Python programmer इन्हीं तीन चीज़ों के साथ काम करता है:

| Tool | ये क्या है | Example |
| --- | --- | --- |
| **Python** | वो program जो आपका code पढ़ता और चलाता है | Python 3, python.org से |
| **Code editor** | जहाँ आप code लिखते हो; ये गलतियाँ highlight करता है और typing में मदद करता है | Visual Studio Code (VS Code), free |
| **Terminal** | एक text window जहाँ आप commands टाइप करते हो, जिनमें file चलाने वाला command भी है | VS Code के अंदर का terminal |

जब तीनों काम करने लगते हैं, तो वो loop शुरू होता है जिसमें हर programmer जीता है:

```flow
dir: LR
File लिखो -> चलाओ -> Output या error पढ़ो -> ठीक करो
ठीक करो -[फिर से]-> File लिखो
```

इस lesson में हम Karthik के साथ चलेंगे, जो मदुरै के एक commerce graduate हैं। वो अपने Windows laptop पर Python set up करते हैं और beginners की दो सबसे आम दिक्कतों से टकराते हैं। इसका check एक छोटा project है: आपकी अपनी पहली file, terminal से चलाई हुई और online share की हुई।

## ये काम कैसे करता है

### Python install करो

| Computer | कैसे |
| --- | --- |
| Windows | python.org या Microsoft Store से **Python install manager** install करो। ये `python` और `py` commands set up कर देता है। अगर पुराना full installer use करो, तो उसकी पहली screen पर **"Add python.exe to PATH"** पर tick लगाओ। |
| Mac | python.org से installer download करके चलाओ। |
| Linux | Python 3 आमतौर पर पहले से installed होता है। |

पुराने full installer में PATH का tick ज़रूरी है: इससे `python` टाइप करने पर terminal को Python मिल जाता है। इसके बिना terminal कहता है कि Python पहचाना नहीं गया।

Install check करने के लिए terminal खोलो और टाइप करो:

```text
python --version
```

Mac और Linux पर `python3 --version` टाइप करो। आपको 3 से शुरू होने वाला version दिखना चाहिए, जैसे `Python 3.15.2`।

### Editor install करो

VS Code और उसका **Python extension** install करो। फिर अपने काम के लिए एक folder बनाओ, जैसे `python-practice`, और उसे File, Open Folder से खोलो। हर project को अपने folder में रखने से आगे बहुत उलझन बचती है।

### अपनी पहली file लिखो

उस folder में `hello.py` नाम की file बनाओ:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

`.py` वाला ending Python और आपके editor को बताता है कि ये Python code है।

### Terminal से चलाओ

VS Code के अंदर View, Terminal से terminal खोलो। Terminal हमेशा किसी एक folder "में" काम करता है। पक्का करो कि वो वही folder है जिसमें आपकी file है:

| Command | Windows | Mac और Linux |
| --- | --- | --- |
| मैं कहाँ हूँ? | PowerShell में `pwd` (VS Code का default), Command Prompt में `cd` | `pwd` |
| यहाँ की files की list | `dir` | `ls` |
| किसी folder में जाओ | `cd python-practice` | `cd python-practice` |
| एक folder ऊपर जाओ | `cd ..` | `cd ..` |
| File चलाओ | `python hello.py` | `python3 hello.py` |

`python hello.py` टाइप करो और Enter दबाओ। Output नीचे दिखेगा।

### Error messages पढ़ना

कुछ गलत हो तो Python एक **traceback** print करता है। **पहले आखिरी line** पढ़ो: वो error का नाम बताती है। उसके ऊपर का line number दिखाता है कि Python को समस्या कहाँ दिखी।

```text
  File "hello.py", line 4
    print("Today is", date.today()
                                  ^
SyntaxError: '(' was never closed
```

Beginners के ज़्यादातर errors इनमें से कोई एक होते हैं:

| Error | आम वजह |
| --- | --- |
| `SyntaxError` | Bracket, quote या colon छूट गया |
| `IndentationError` | Indentation गलत या मिली-जुली |
| `NameError` | Variable की spelling गलत, या बनने से पहले use हुआ |
| `can't open file` | Terminal गलत folder में है, या file का नाम गलत है |

### Python चलाने के दूसरे तरीके

**Google Colab** और **Kaggle** जैसे online notebooks बिना कुछ install किए browser में Python चलाते हैं। अगर आपका computer locked-down या पुराना है तो ये काम आते हैं, और data के काम में भी। फिर भी terminal से files चलाना सीखो: असली projects, servers और AI applications ऐसे ही चलते हैं।

## एक example से समझो

Karthik, मदुरै के एक commerce graduate, एक शाम अपने Windows laptop पर Python set up करते हैं।

**Step 1: install।** वो python.org से full installer download करते हैं, "Add python.exe to PATH" पर tick लगाते हैं और install करते हैं। (Python install manager भी चलता, और उसमें tick की ज़रूरत नहीं।)

**Step 2: check।** नए terminal में `python --version` से `Python 3.15.2` print होता है। अगर वो PATH का tick भूल जाते, तो यहीं "python is not recognized" दिखता।

**Step 3: editor और file।** वो VS Code और Python extension install करते हैं, `python-practice` folder बनाते हैं, और ऊपर वाले code से `hello.py` लिखते हैं, अपना नाम डालकर।

**Step 4: पहला error।** वो `python hello.py` टाइप करते हैं और ये दिखता है:

```text
python: can't open file 'C:\Users\karthik\hello.py': [Errno 2] No such file or directory
```

Terminal उनके home folder में था, `python-practice` में नहीं। वो `cd python-practice` टाइप करते हैं, फिर command दोबारा चलाते हैं। अब चल जाता है:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: एक बदलाव।** वो अपना नाम तमिल लिपि में भी print करने वाली एक line जोड़ते हैं, फिर चलाते हैं, और वो सही print होता है क्योंकि VS Code files को UTF-8 में सेव करता है।

| समस्या | जो message दिखा | Fix |
| --- | --- | --- |
| Terminal गलत folder में | `can't open file ... No such file or directory` | `cd python-practice` |
| (बच गए) PATH set नहीं था | `python is not recognized` | PATH वाले box पर tick लगाकर दोबारा install करो |

आखिर में वो GitHub account बनाते हैं और `hello.py` को एक नई repository में डालते हैं, ताकि share करने के लिए link हो। यही link इस lesson का check है।

## आम गलतियाँ

- **पुराने Windows installer में "Add to PATH" भूल जाना।** तब terminal कहता है कि Python नहीं मिला। Tick लगाकर दोबारा install करो और नया terminal खोलो।
- **गलत folder से चलाना।** चलाने से पहले `pwd` से (या Command Prompt में `cd` से) देखो कि आप कहाँ हो।
- **File को .txt ending के साथ सेव करना।** उसे `.py` पर खत्म होना चाहिए। Windows पर "show file extensions" चालू करो ताकि दिखे।
- **लाल text देखकर घबराना।** Error की आखिरी line और line number पढ़ो।
- **Tabs और spaces मिलाना।** Indentation editor को करने दो।
- **एक साथ कई Python versions install करना।** शुरू करने के लिए एक नया Python 3 काफ़ी है।
