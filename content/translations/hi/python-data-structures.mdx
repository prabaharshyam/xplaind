## ये क्या है

Programs शायद ही एक बार में एक value के साथ काम करते हैं। एक दिन में कई orders होते हैं, class में कई students, दुकान में कई products। Python के दो मुख्य collections कई values रखते हैं:

- **Lists** क्रम वाले sequences हैं, जिन्हें position से पाया जाता है। "एक ही तरह की कई चीज़ें, क्रम में" के लिए अच्छे हैं: दिन के orders, marks की list।
- **Dictionaries** key और value वाले lookups हैं। "इस key की value जल्दी ढूँढो" के लिए अच्छे हैं: roll number से marks, field के नाम से customer की details।

दो और अक्सर आते हैं:

- **Tuples** तय, न बदलने वाले sequences हैं, जैसे latitude और longitude का जोड़ा।
- **Sets** unique items के बिना क्रम वाले collections हैं, duplicates हटाने के लिए काम के।

| Type | Example | Value कैसे मिलती है |
|---|---|---|
| list | `["Pune", "Kochi", "Jaipur"]` | Position से: `[0]`, `[1]`, `[2]` |
| dict | `{"K101": 78, "K102": 64}` | Key से: `["K101"]` |
| tuple | `(18.52, 73.86)` | एक तय जोड़ा जो बदल नहीं सकता |
| set | `{"a@x.in", "b@y.in"}` | Unique values, कोई क्रम नहीं |

इन्हें एक-दूसरे के अंदर रखकर ज़्यादातर असली data की शक्ल बनती है। Dictionaries की list एक table है; हर dictionary एक row। यही उस **JSON** की shape है जो APIs और AI models भेजते हैं, इसलिए nested lists और dictionaries में आसानी होना AI की बुनियादी skill है।

इस lesson में हम कोटा के एक coaching centre के office के साथ चलेंगे, जो test results की list को parents के लिए तुरंत जवाबों में बदलता है। Lesson के अंत तक आप किसी काम के लिए सही structure चुन पाओगे और nested data आसानी से पढ़ पाओगे।

## ये काम कैसे करता है

### Lists

```python
nums = [3, 1, 2]
nums.append(5)            # [3, 1, 2, 5]
print(len(nums))          # 4
print(nums[0], nums[-1])  # 3 5   (first and last)
print(sorted(nums))       # [1, 2, 3, 5]
print(nums[1:3])          # [1, 2]  (a slice: from position 1 up to, not including, 3)
```

`for n in nums:` से loop चलाओ। नई lists **list comprehension** से बनाओ, जो list बनाने वाला छोटा loop है:

```python
doubled_big = [n * 2 for n in nums if n > 1]    # [6, 4, 10]
```

### Dictionaries

```python
marks = {"asha": 80, "ravi": 72}
marks["meena"] = 91              # add a new key
print(marks["asha"])             # 80
print(marks.get("john", 0))      # 0: a default instead of an error
for name, score in marks.items():
    print(name, score)
```

Square brackets से गायब key ढूँढने पर `KeyError` आता है; `get` इसकी जगह default लौटाता है। Key से lookup लाखों entries में भी तेज़ रहता है, क्योंकि dictionary ढूँढने की जगह सीधे key पर पहुँच जाती है।

### सही वाला चुनना

| आपको क्या चाहिए | क्या use करें | Example |
| --- | --- | --- |
| क्रम, या चीज़ें position से पाना | List | Customers की queue |
| किसी identifier से चीज़ें ढूँढना | Dictionary | Product code से price |
| Unique items, तेज़ "क्या ये यहाँ है?" | Set | Unique email addresses |
| Values का छोटा तय group | Tuple | किसी shop के coordinates |
| Records की table | Dictionaries की list | आज की sales |
| Category के हिसाब से groups की values | Lists की dictionary | शहर के हिसाब से students |

### List में ढूँढना धीमा क्यों है

```flow
dir: LR
title: 10,000 records में roll "K9000" ढूँढो
List में -> [0], [1], [2] ... एक-एक करके देखो -> 10,000 तक checks
Roll से बनी dictionary में -> सीधे "K9000" पर कूदो -> करीब 1 step
```

अगर आप एक ही तरह का identifier बार-बार ढूँढते हो, तो dictionary एक बार बनाओ और दोबारा use करो।

### Nesting

```python
cities = {
    "Pune":   [{"name": "Asha", "marks": 80}],
    "Nagpur": [{"name": "Ravi", "marks": 72}, {"name": "Meena", "marks": 91}],
}
print(cities["Nagpur"][1]["name"])     # Meena
```

Nested access को बाएँ से दाएँ पढ़ो: "Nagpur" की list, उसका दूसरा item, उस item का "name"।

### JSON से Python और वापस

जब कोई API या AI model JSON लौटाता है, Python का `json` module उसे lists और dictionaries में बदलता है, और वापस भी:

```python
import json
text = '{"city": "Pune", "pins": ["411001", "411002"]}'
data = json.loads(text)          # now a dictionary
print(data["pins"][0])           # 411001
print(json.dumps(data, indent=2))  # back to neatly formatted JSON text
```

JSON objects dictionaries बन जाते हैं, JSON arrays lists बन जाते हैं, `true` और `false` `True` और `False` बन जाते हैं, और `null` `None` बन जाता है।

### Copy करना

`b = a` list की copy **नहीं** बनाता। दोनों नाम एक ही list की तरफ़ इशारा करते हैं, इसलिए एक को बदलने पर दूसरे को भी बदला दिखता है:

```python
a = [1, 2]
b = a
b.append(3)
print(a)          # [1, 2, 3]  surprise!
c = a.copy()      # a real copy
```

## एक example से समझो

कोटा का एक coaching centre test results को records की list की तरह रखता है, हर student का एक:

```python
results = [
    {"roll": "K101", "name": "Asha",  "physics": 78, "chem": 85},
    {"roll": "K102", "name": "Ravi",  "physics": 64, "chem": 70},
    {"roll": "K103", "name": "Meena", "physics": 91, "chem": 88},
]

# 1. Look up by roll number quickly: build a dictionary once
by_roll = {r["roll"]: r for r in results}
print(by_roll["K102"]["name"])            # Ravi

# 2. Average per subject with a list comprehension
physics = [r["physics"] for r in results]
print(round(sum(physics) / len(physics), 1))   # 77.7

# 3. Group students by grade band
bands = {}
for r in results:
    total = r["physics"] + r["chem"]
    band = "A" if total >= 160 else "B"
    bands.setdefault(band, []).append(r["name"])
print(bands)                               # {'A': ['Asha', 'Meena'], 'B': ['Ravi']}
```

| Office का सवाल | कौन-सा structure जवाब देता है | Code |
| --- | --- | --- |
| "Roll K102 का result कैसा रहा?" | Roll से बनी dictionary | `by_roll["K102"]` |
| "Physics का average क्या है?" | Physics marks की list | `sum(physics) / len(physics)` |
| "Band A में कौन है?" | Lists की dictionary | `bands["A"]` |

`setdefault(band, [])` उस band की list लौटाता है, और पहली बार खाली list बना देता है। इससे हर बार `if` लिखने से बचते हैं।

Office अब parents के "roll K102 का result कैसा रहा?" जैसे calls का जवाब तुरंत दे देता है, 600 students की sheet में scroll करने की जगह।

## आम गलतियाँ

- **किसी id के लिए list में बार-बार ढूँढना।** Id की key वाली dictionary एक बार बनाओ।
- **गायब keys पर `KeyError`।** जब key न होने की संभावना हो तो default के साथ `get` use करो।
- **Index out of range।** Lists 0 से शुरू होती हैं; आख़िरी item `[-1]` है।
- **गलती से shared lists।** `b = a` copy नहीं है; `a.copy()` use करो।
- **Loop चलाते हुए list बदलना।** इसकी जगह नई list बनाओ, जैसे comprehension से।
- **Sets से क्रम की उम्मीद करना।** क्रम ज़रूरी हो तो नतीजे को sort करो: `sorted(set(items))`।
