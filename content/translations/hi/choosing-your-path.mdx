## ये क्या है

AI सीखना शुरू करने वाले बहुत से लोग बीच में अटक जाते हैं क्योंकि उनके पास कोई साफ़ रास्ता नहीं होता: यहाँ एक video, वहाँ एक course, हर हफ़्ते एक नया tool, और तीन महीने बाद भी कोई skill पूरी नहीं। Path चुनना इसे ठीक करता है।

Xplaind पर **path** एक job role तक का क्रम वाला रास्ता है, जो shared lessons से बना है। हर path stages में बँटा है। कई stages के साथ एक guided project आता है, और हर path में कम से कम एक guided project है जो आप किसी employer को दिखा सकते हो। आप जो lessons पूरे करते हो वे **हर** उस path पर गिने जाते हैं जो उन्हें use करता है, इसलिए बाद में बदलने से आपकी मेहनत बेकार नहीं जाती।

Xplaind पर दस paths हैं। Length वाला column steady पढ़ाई के लिए Xplaind का मोटा अंदाज़ा है। यह सिर्फ़ सीखने का समय है: इसके ऊपर कुछ महीनों की job search भी plan करो।

| Path | किसके लिए है | Coding | मोटी length | Level test |
| --- | --- | --- | --- | --- |
| **AI Engineer** | Students और developers जो AI engineering का चौड़ा role चाहते हैं | हाँ, पहले दिन से | 9 महीने | हाँ |
| **Generative AI & LLM Engineer** | नए लोग और engineers जो language models पर apps बनाना चाहते हैं, RAG गहराई से | हाँ, level B2 से | 9 महीने | हाँ |
| **Agentic AI Engineer** | Developers जो पहले से Python से language model API call कर सकते हैं | हाँ | 4 महीने | हाँ |
| **Forward Deployed Engineer (FDE)** | Engineers जिनके पास एक साल या उससे ज़्यादा Python का अनुभव है और जिन्हें client का काम पसंद है | हाँ | 6 महीने | हाँ |
| **Machine Learning Engineer** | Graduates और engineers जो Python और school maths में comfortable हैं | हाँ, साथ में maths | 9 महीने | नहीं |
| **MLOps Engineer** | Backend, DevOps, data और cloud engineers | हाँ | 6 महीने | हाँ |
| **AI Security Engineer** | Students, developers और IT या security staff; security की ज़ीरो जानकारी से शुरू होता है | थोड़ी (हल्का Python) | 6 महीने | नहीं |
| **AI Automation Specialist** | Operations, support, sales और marketing के लोग, freelancers, छोटे business owners | थोड़ी (APIs, JSON, छोटे scripts) | 3 महीने | नहीं |
| **AI Product Manager** | Product managers, business analysts, founders और consultants | नहीं | 3 महीने | नहीं |
| **AI Governance & Compliance Specialist** | Risk, compliance, legal, audit, privacy और policy के लोग | नहीं | 3 महीने | नहीं |

चुनने से पहले दो बातें जान लो:

- **हो सकता है आपको path की ज़रूरत ही न हो।** अगर आप अपनी मौजूदा job AI से तेज़ी से करना चाहते हो, और नया role नहीं चाहते, तो इसकी जगह Library के B1 using-AI lessons से शुरू करो: prompting, writing और summarising, research, और AI के जवाब check करना।
- **पूरे roadmap के लिए account चाहिए।** Sign in किए बिना आपको हर path का सिर्फ़ पहला stage दिखता है। Account होने पर roadmaps और lessons free हैं, और account आपका path और progress भी save करता है। Accounts 18 साल और उससे ऊपर के लोगों के लिए हैं; अगर आप 18 से कम के हो, तो quick answer और हर lesson का पहला हिस्सा Library में खुले रहते हैं।

यह lesson हैदराबाद के accountant इमरान के साथ चलता है, जब वह अपना path चुनते हैं। आखिर तक आप अपना path चुन चुके होगे, अपने घंटे plan कर चुके होगे और पहला milestone तय कर चुके होगे।

## ये काम कैसे करता है

अच्छे से चुनने के लिए एक सवाल और फिर तीन checks चाहिए, इसी क्रम में: **नया role या नहीं, फिर background, goal और समय।**

```flow
dir: LR
title: Path कैसे चुनें
Start | क्या मुझे नया role चाहिए? -[नहीं]-> Using-AI lessons | मौजूदा job में तेज़ी से काम
Start -[हाँ]-> 1. Background | code, maths, कोई domain?
1. Background -> 2. Goal | क्या दस असली job posts मुझ पर fit होती हैं?
2. Goal -> 3. समय | घंटे जो मैं महीनों तक निभा सकूँ
3. समय -> आपका path
```

### Check 1: अपने background से शुरू करो

सबसे ज़्यादा buzz वाले role से नहीं, जो आपके पास पहले से है वहाँ से शुरू करो। हर path एक starting point मानकर चलता है, इसलिए अपना उससे मिलाओ:

| आपका starting point | यहाँ से शुरू करो | Path क्या मानकर चलता है |
| --- | --- | --- |
| आप तय करना चाहते हो कि कौन-सा AI बनाना है, और code नहीं करना चाहते | AI Product Manager | Code नहीं; engineers के साथ अच्छे से काम करने लायक सीखते हो |
| आप risk, legal, audit, compliance या privacy में काम करते हो | AI Governance & Compliance | Code नहीं; आपकी domain की समझ ही आपका फ़ायदा है |
| आप business processes चलाते हो और हल्का code सीखोगे | AI Automation Specialist | आप APIs और JSON पढ़ोगे और छोटे scripts लिखोगे |
| आप IT support, networking या security में काम करते हो, या security में दिलचस्पी है | AI Security Engineer | हल्का Python; security की basics ज़ीरो से सिखाई जाती हैं |
| आप code में नए हो लेकिन language-model apps के लिए Python सीखने को तैयार हो | Generative AI & LLM Engineer | AI basics से शुरू; level B2 से Python |
| आप code करते हो, या अभी Python सीखोगे, और सबसे चौड़ा role चाहते हो | AI Engineer | पहले stage से Python |
| आप पहले से Python से language model API call करते हो | Agentic AI Engineer | Tool calling से शुरू होता है, इसलिए छोटा है |
| आपके पास एक साल या उससे ज़्यादा Python है और client meetings पसंद हैं | Forward Deployed Engineer | Stage 1 से production-level Python |
| आप Python जानते हो और आपको maths, statistics और data पसंद है | Machine Learning Engineer | Python और school maths |
| आप backend, DevOps, data या cloud engineer हो | MLOps Engineer | Linux, containers और cloud आपको जल्दी आ जाएँगे |

Label नहीं, assumption check करो। जिस fresher ने कभी कोई API call नहीं किया, वह Agentic AI Engineer चुने तो पहले ही हफ़्ते में दीवार से टकराएगा; GenAI path इसकी जगह धीरे-धीरे agents तक ले जाता है।

### तीन engineering paths जो एक जैसे दिखते हैं

AI Engineer, Generative AI & LLM Engineer और Agentic AI Engineer आपस में सबसे ज़्यादा overlap करते हैं। ये कई lessons share करते हैं, लेकिन अलग-अलग जगह से शुरू होते हैं और अलग-अलग चीज़ों पर ज़ोर देते हैं:

| | AI Engineer | Generative AI & LLM Engineer | Agentic AI Engineer |
| --- | --- | --- | --- |
| पहला stage | Python और data की नींव | AI basics, बिना code (B2 से Python) | Model APIs, structured output, tool calling |
| क्या cover करता है | Classical ML, deep learning और transformers, फिर LLM apps, testing, production, system design | नए learner से system designer तक नौ levels: prompts, गहराई से RAG, agents, evals, production | Agent design, frameworks, MCP, reliability, production |
| Length | 9 महीने | 9 महीने | 4 महीने |
| इसे चुनो अगर | आप चौड़ा role चाहते हो; भारत की कई AI engineer posts ML basics भी माँगती हैं | आप पक्के हो कि language-model apps ही चाहिए, या ज़ीरो code से शुरू कर रहे हो | आप पहले से language models के साथ बनाते हो और agents में गहराई चाहते हो |

**Decision rule:** अगर आप code करते हो और तय नहीं कर पा रहे, तो AI Engineer लो, जो सबसे चौड़ा है। ज़ीरो code से हो, तो GenAI path लो, जो सबसे आराम से शुरू होता है। Agentic AI Engineer दूसरे कदम के तौर पर लो, जब आप API call कर सको। FDE भी मिलती-जुलती engineering है, साथ में client का काम, उन लोगों के लिए जिनके पास एक साल या उससे ज़्यादा Python है।

| AI Automation Engineer | Hyderabad | 1 से 3 | n8n, APIs, process mapping |

Title नहीं, duties पढ़ो: "भारत में AI careers" lesson दिखाता है कि "AI engineer" नाम की post असल में ML का काम कैसे हो सकती है। फिर तीन rules लगाओ:

- **क्या duties आपको excite करती हैं?** अगर दस में से ज़्यादातर posts ऐसे काम बताती हैं जो आपको हर हफ़्ते अच्छा लगेगा, तो goal रखो। अगर नहीं, तो अभी दूसरा path देखो, चौथे महीने में नहीं।
- **क्या ज़्यादातर posts तीन या उससे ज़्यादा साल माँगती हैं?** तो एक bridge plan करो: पास का कोई junior role, या पहले अपनी मौजूदा company के अंदर कोई AI project। जैसे, ज़्यादातर FDE और AI product manager posts पहले का engineering या product अनुभव माँगती हैं।
- **क्या आपके शहर में लगभग कोई post नहीं है?** Remote posts, सबसे पास का hub और global capability centres (GCCs) के careers pages देखो, जो अक्सर सीधे hire करते हैं।

### Freshers और working professionals

- **Freshers** उन paths पर सबसे अच्छा करते हैं जिनमें असली entry-level hiring और projects का portfolio हो: AI Engineer, GenAI, ML Engineer और AI Automation। Jobs page 0 से 2 साल के लिए typical pay दिखाता है (2 November 2026 को check किया), जैसे AI Engineer के लिए साल का 6 से 12 lakh CTC और AI Automation Specialist के लिए 4 से 8 lakh। FDE और AI Product Manager के ऊँचे early bands freshers को शायद ही कभी मिलते हैं।
- **Working professionals** सबसे तेज़ी से उस path पर switch करते हैं जो उनकी पहले की जानकारी दोबारा use करता है: DevOps से MLOps, compliance से governance, Java developer से FDE। सबसे तेज़ रास्ता अक्सर अपनी ही company के अंदर एक AI pilot होता है।

### Check 3: समय के बारे में ईमानदार रहो

कोई deadline नहीं है। हर path आपकी अपनी रफ़्तार पर चलता है, इसलिए हफ़्ते के उतने घंटे चुनो जितने आप महीनों तक निभा सको, न कि जितने ज़्यादा से ज़्यादा किसी अच्छे हफ़्ते में कर पाओ:

| हफ़्ते के घंटे | कैसा लगता है |
| --- | --- |
| 3 घंटे | हफ़्ते में एक छोटा lesson, ठीक से |
| 5 घंटे | हर हफ़्ते एक lesson और उसकी practice |
| 8 घंटे | दो lessons और project का एक छोटा step |
| 12 घंटे | एक stage में steady progress, projects के लिए समय के साथ |

घंटों को date में बदलने के लिए एक छोटा हिसाब लगाओ: हर lesson page पर उसके घंटे दिखते हैं, तो एक stage के घंटे जोड़ो, अपने हफ़्ते के घंटों से भाग दो और practice के लिए करीब एक तिहाई जोड़ दो। Level test वाले पाँच paths (AI Engineer, GenAI, Agentic AI, FDE और MLOps) पर roadmap में **Find my level** दबाओ: test वह skip कर देता है जो आपको पहले से आता है, और result दिखाता है कि आपके घंटों पर बाकी में करीब कितने हफ़्ते लगेंगे। बाकी पाँच paths stage 1 से शुरू होते हैं। दो हफ़्ते बीस घंटे और फिर कुछ नहीं, इससे पाँच steady घंटे बेहतर हैं।

### Plan बनाओ

Plan के तीन हिस्से हैं:

1. **हफ़्ते में तय study slots**, जैसे Tuesday और Thursday की शाम और Sunday की सुबह। इन्हें meetings की तरह calendar में डालो, और जो busy हफ़्ते आपको पहले से पता हैं, जैसे exams या month-end close, उन्हें note करो।
2. **चार हफ़्तों के अंदर एक पहला milestone** जो आप किसी को दिखा सको: एक पूरा stage, एक पहला workflow, एक छोटा चलता हुआ app। Check करो कि उसके lesson घंटे आपके slots के चार हफ़्तों में, थोड़ी गुंजाइश के साथ, fit हो जाएँ।
3. **Accountability**: एक नाम वाला व्यक्ति, आपके update का एक तय दिन, और खुद update, जैसे एक line कि क्या पूरा किया और आगे क्या है।

### पहले stage के बाद दोबारा आँको

Stage 1 के बाद पूछो: क्या मुझे यह काम अच्छा लग रहा है, और क्या यह मुझे job posts वाले role की तरफ़ ले जा रहा है? अगर नहीं, तो बदलो। आपके पूरे किए lessons साथ आते हैं: जैसे "AI, machine learning और language model: तीनों असल में क्या हैं" दस में से छह paths पर है। एक lesson मुश्किल था या एक हफ़्ता खराब गया, इसलिए मत बदलो। ऐसा हर path पर होता है।

## एक example से समझो

इमरान, 34, हैदराबाद की एक distribution company में accountant हैं। वह कुछ महीनों से काम पर एक AI assistant use कर रहे हैं। Bank reconciliations जल्दी करने के लिए उसे use करना उन्हें अच्छा लगा और वह और करना चाहते हैं, लेकिन full-time programmer बनने की उनकी कोई इच्छा नहीं है।

**नया role या नहीं?** वह ऐसा role चाहते हैं जिसमें automation ही उनका मुख्य काम हो, इसलिए सिर्फ़ using-AI lessons काफ़ी नहीं हैं।

**Background.** Coding नहीं, finance और process की मज़बूत समझ, Excel formulas में comfortable। दो paths मुमकिन दिखते हैं: AI Automation Specialist (थोड़ा code) और AI Governance & Compliance (कोई code नहीं), क्योंकि वह financial controls जानते हैं।

**Goal.** वह हैदराबाद की दस job posts पढ़ते हैं, दोनों के लिए पाँच-पाँच। उनके notes (एक उदाहरण, कोई survey नहीं) दिखाते हैं कि governance posts ज़्यादातर risk या compliance का वह अनुभव माँगती हैं जो उनके पास नहीं है, और policy writing का काम बताती हैं जो उन्हें नीरस लगता है। Automation posts, जिनके title "AI automation engineer" या "finance automation analyst" हैं, n8n, Power Automate, APIs और process mapping का ज़िक्र करती हैं। उनकी duties में "automate invoice processing" और "reduce manual reconciliation" लिखा है, जो ठीक वही है जो उन्हें अच्छा लगा था। ज़्यादातर 0 से 3 साल माँगती हैं। वह मान लेते हैं कि उन्हें APIs और JSON पढ़ने और छोटे scripts लिखने होंगे।

**समय.** उनके दो छोटे बच्चे हैं। असल में: हफ़्ते की दो शामें और weekend की एक सुबह, हफ़्ते में करीब 5 से 6 घंटे। Path का मोटा अंदाज़ा तीन महीने है; उनकी रफ़्तार पर, projects गिनने के बाद, यह थोड़ा लंबा चल सकता है।

**Milestone check करना.** Automation path के stage 1 में सात lessons हैं, कुल करीब 10 घंटे। Stage 2 का पहला lesson, "आपका पहला n8n workflow", करीब 3 घंटे और है। यानी 13 घंटे के lessons। हफ़्ते के 5.5 घंटे पर चार हफ़्ते 22 घंटे देते हैं, जिससे practice और rework के लिए 9 घंटे बचते हैं। Milestone fit होता है।

उनका plan:

| हिस्सा | इमरान का plan |
| --- | --- |
| Path | AI Automation Specialist |
| Study slots | Tuesday और Thursday रात 8 से 9:30, Saturday सुबह 9 से 11:30 (5.5 घंटे) |
| पहला milestone | चार हफ़्तों में: stage 1 पूरा, साथ में उनका पहला n8n workflow जो invoice emails को sheet में log करता है |
| Accountability | हर Sunday एक colleague को छोटा update, जो खुद भी सीख रहा है |
| Final project | Path का capstone, एक invoice-to-ledger automation, उनकी team के असली invoice process पर बना |

**क्या गड़बड़ हुई.** हफ़्ता 3 में month-end close ने उनकी दो शामें ले लीं, और उनकी milestone की date छूट गई। उन्होंने plan नहीं छोड़ा। Date एक हफ़्ता आगे बढ़ा दी, अपने colleague को बताया, और हर month-end वाले हफ़्ते को light हफ़्ता mark कर दिया।

**जो कदम काम आया.** उन्होंने अपने manager को plan के बारे में बताया। Manager ने capstone के लिए team का invoice process offer किया, एक शर्त पर: इमरान इसे vendor bank details हटाई हुई copies पर बनाएँ और test करें, और live ledger को छूने से पहले approval लें। उनका final project अब नापे जा सकने वाले result के साथ असली काम है, जो उनके portfolio को किसी practice exercise से कहीं ज़्यादा मज़बूत बनाएगा।

## आम गलतियाँ

- **सबसे ज़्यादा hype वाला या सबसे ज़्यादा pay वाला path चुनना।** वह चुनो जो आपके background और उस काम से मेल खाए जो आपको हर हफ़्ते अच्छा लगे।
- **Path क्या मानकर चलता है, इसे नज़रअंदाज़ करना।** Agentic AI Engineer उम्मीद करता है कि आप Python से API call कर सको, और FDE एक साल का Python माँगता है। अगर अभी यह नहीं कर सकते तो एक कदम पहले से शुरू करो।
- **जब सिर्फ़ काम पर AI use करना हो, तब career path लेना।** Using-AI lessons आपको महीनों में नहीं, कुछ घंटों में वहाँ पहुँचा देते हैं।
- **ऐसे घंटे plan करना जो निभ नहीं पाएँगे।** वे घंटे चुनो जो महीनों तक निभा सको, न कि वे जो काश आपके पास होते।
- **बिना जोड़े milestone तय करना।** पहले lesson घंटे जोड़ो, वरना milestone खिसकेगा और आपको लगेगा कि आप पीछे हो।
- **हर हफ़्ते path बदलना।** दोबारा सोचने से पहले एक stage के लिए commit करो।
- **Projects skip करना।** Employers projects ही देखना चाहते हैं, और असली confidence भी वहीं से आता है।
- **अकेले सीखना।** एक व्यक्ति को हर हफ़्ते तय update देने से चुपचाप भटक जाना बहुत मुश्किल हो जाता है।
- **Perfect plan का इंतज़ार करना।** इसी हफ़्ते शुरू किया अच्छा plan, अगले महीने शुरू किए perfect plan से बेहतर है।
