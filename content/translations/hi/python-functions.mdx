## ये क्या है

जैसे-जैसे programs बड़े होते हैं, आप वही कुछ lines बार-बार copy करने लगते हो: GST की गिनती तीन जगह, phone numbers की सफ़ाई दो scripts में। Copy करने से bugs आते हैं, क्योंकि एक copy ठीक करते हो तो बाकी भूल जाते हो। **Function** इसका हल है।

Function नाम वाला code block है जो **एक काम** करता है। आप उसे inputs देते हो, जिन्हें **parameters** कहते हैं, वो अपना काम करता है, और result **return** करता है।

```flow
dir: LR
Inputs | price = 1000, rate = 0.18 -> Function: gst_amount(price, rate=0.18) | return price * rate
Function: gst_amount(price, rate=0.18) -> Output: 180.0
```

Functions से आप ये कर सकते हो:

- code को copy करने की जगह **दोबारा use** करना;
- बड़ी समस्या को छोटे टुकड़ों में **तोड़ना** जिन्हें एक-एक करके test किया जा सके;
- steps को **नाम देना**, ताकि program निर्देशों की तरह पढ़े: `clean_phone_number`, `monthly_emi`, `send_reminder`।

इस lesson में हम Imran के साथ चलेंगे, जो एक form से customers के phone numbers साफ़ करते हैं। वो एक गड़बड़ script को छोटे, दोबारा use होने वाले functions में बदलेंगे। Lesson के अंत तक आप ऐसे functions लिखना सीख जाओगे जो result लौटाएँ और कई programs में काम आएँ।

## ये काम कैसे करता है

### Define करना और call करना

```python
def gst_amount(price, rate=0.18):
    return price * rate

print(gst_amount(1000))         # 180.0, uses the default rate
print(gst_amount(1000, 0.05))   # 50.0
```

- `def` से definition शुरू होती है।
- `price` और `rate` **parameters** हैं।
- `rate=0.18` एक **default** है, जो तब use होता है जब बुलाने वाला value न दे।
- `return` result वापस देता है।

Call करने के लिए brackets चाहिए: `gst_amount(1000)`। Brackets के बिना `gst_amount` लिखने से function खुद का reference मिलता है, वो चलता नहीं।

### Return बनाम print

Beginners सबसे ज़्यादा यहीं उलझते हैं:

| | `return` | `print` |
| --- | --- | --- |
| क्या करता है | बुलाने वाले को value वापस देता है | Screen पर text दिखाता है |
| क्या caller value use कर सकता है? | हाँ: `total = price + gst_amount(price)` | नहीं: function `None` लौटाता है |
| कब use करें | जो functions कुछ compute करते हैं | सिर्फ़ उस code में जो results दिखाता है |

जो function कुछ compute करे, उसे वो return करना चाहिए, और print करना उस code पर छोड़ दो जो उसे बुलाता है। तब वही function report में, web app में और test में, हर जगह चलेगा।

### Position से और नाम से arguments

```python
gst_amount(1000, 0.05)               # by position
gst_amount(price=1000, rate=0.05)    # by name: clearer with several parameters
```

### Scope

Function के अंदर बने variables सिर्फ़ उसी के अंदर रहते हैं:

```python
def tax(amount):
    total = amount * 1.18
    return total

result = tax(100)     # 118.0
print(total)          # NameError: total only existed inside tax
```

Function को जो चाहिए वो अंदर भेजो और जो बने वो return करो, बाहर के variables पर निर्भर मत रहो। जो functions सिर्फ़ अपने inputs use करते हैं, उन्हें test करना और दोबारा use करना आसान होता है।

### हर एक का एक ही काम

अच्छा function एक ही चीज़ करता है, और उसका नाम बताता है कि क्या। अगर उसे बताने में "और" लगाना पड़े, जैसे "number साफ़ करता है और SMS भेजता है", तो उसे दो में बाँट दो।

```flow
dir: LR
एक बड़ा function: process_customers() | पढ़ता, साफ़ करता, check करता और लिखता है: test या reuse करना मुश्किल -[इसे बाँटो]-> छोटे functions | digits_only(), normalise_mobile(), is_valid_email(), read_customers(), write_report(): हर एक अकेले test हो सकता है
```

### Docstrings और type hints

एक line का description और type hints पढ़ने वालों और आपके editor जैसे tools की मदद करते हैं:

```python
def monthly_emi(principal: float, annual_rate: float, months: int) -> float:
    """Equated monthly instalment for a loan."""
    r = annual_rate / 12
    return principal * r * (1 + r) ** months / ((1 + r) ** months - 1)

print(round(monthly_emi(500000, 0.09, 60)))   # about 10379 rupees a month
```

### एक जाल: mutable defaults

```python
def add_order(order, orders=[]):      # bug: the same list every call
    orders.append(order)
    return orders
```

Default list एक बार बनती है और calls के बीच share होती है, इसलिए orders जमा होते जाते हैं। `None` use करो और अंदर नई list बनाओ:

```python
def add_order(order, orders=None):
    if orders is None:
        orders = []
    orders.append(order)
    return orders
```

## एक example से समझो

Imran हैदराबाद की एक छोटी marketing agency में काम करते हैं। एक client के form में 3,000 customers के phone numbers आए, हर संभव तरीके से लिखे हुए: "98450 12345", "+91-9845012345", "09845012345", "9845012345 "। SMS tool को ये `+91` और उसके बाद दस digits के रूप में चाहिए।

उनकी पहली script code का एक लंबा block थी, जिसे थोड़ा बदलकर दो और scripts में copy किया गया था। वो उसे छोटे functions में दोबारा लिखते हैं, हर एक का एक काम:

```python
def digits_only(text: str) -> str:
    """Keep only the digits in text."""
    return "".join(ch for ch in text if ch.isdigit())

def normalise_mobile(raw: str) -> str | None:
    """Return +91 and ten digits, or None if it is not a valid mobile number."""
    d = digits_only(raw)
    if d.startswith("91") and len(d) == 12:
        d = d[2:]
    if d.startswith("0") and len(d) == 11:
        d = d[1:]
    return "+91" + d if len(d) == 10 else None

for raw in ["98450 12345", "+91-9845012345", "09845012345", "12345"]:
    print(raw, "->", normalise_mobile(raw))
```

| Input | digits_only के बाद | Rules के बाद | Result |
| --- | --- | --- | --- |
| `98450 12345` | 9845012345 | 10 digits | +919845012345 |
| `+91-9845012345` | 919845012345 | शुरू का 91 हटाया | +919845012345 |
| `09845012345` | 09845012345 | शुरू का 0 हटाया | +919845012345 |
| `12345` | 12345 | बहुत छोटा | None |

तीन numbers `+919845012345` बन जाते हैं; आखिरी `None` लौटाता है, ताकि वो client को गलत numbers की list दे सकें। Logic functions में है, इसलिए अगले हफ़्ते वो `normalise_mobile` को बाकी दो scripts में copy करने की जगह import कर लेते हैं। और जब client कहता है कि landline numbers भी चलने चाहिए, तो वो एक जगह एक function बदल देते हैं।

## आम गलतियाँ

- **Return करने की जगह print करना।** Caller को `None` मिलता है।
- **Function को call करना भूल जाना।** Brackets के बिना `gst_amount` कुछ नहीं करता।
- **बहुत ज़्यादा काम करने वाले functions।** तब तक बाँटो जब तक हर एक का एक ही काम न हो।
- **बाहर के variables पर निर्भर रहना।** Inputs को parameters बनाओ और results return करो।
- **Mutable defaults,** जैसे `def add(item, items=[])`। `None` use करो और अंदर नई list बनाओ।
- **अस्पष्ट नाम।** `process()` और `do_stuff()` पढ़ने वाले को कुछ नहीं बताते।
