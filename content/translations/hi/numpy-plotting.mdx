## ये क्या है

Machine learning, numbers की बड़ी tables पर maths है, और Python में वो maths **NumPy** पर चलता है, जो तेज़ numerical arrays की library है। pandas, scikit-learn और PyTorch सब इसके ideas पर बने हैं, इसलिए यहाँ सीखी आदतें सीधे model के काम में काम आती हैं। **Matplotlib** standard plotting library है; Seaborn और Plotly जैसी दूसरी libraries भी मिलते-जुलते ideas use करती हैं।

मुख्य skills:

| Skill | इसका मतलब | Example |
| --- | --- | --- |
| **Arrays और shapes** | Arrays बनाना और उनके dimensions जानना | `X.shape` है `(50000, 3)` |
| **Vectorisation** | पूरे arrays पर एक साथ maths करना | `prices * 1.18` |
| **Broadcasting** | अलग पर compatible shapes के arrays को जोड़ना | `X - X.mean(axis=0)` |
| **Masks और indexing** | Condition या position से data चुनना | `y[y > 30]`, `X[:, 0]` |
| **Plotting** | Distributions, रिश्ते और trends देखना | histogram, scatter, line, box plot |

```text
  X: shape (5, 3)                          means: shape (3,)
   distance  items  hour                   [ 4.2,  3.0, 15.4 ]
  [  2.1      1     13 ]                          |
  [  6.8      4     19 ]     X - means            | broadcast to every row
  [  3.0      2     11 ]   ------------>          v
  [  5.5      5     20 ]                   result: shape (5, 3), each column centred
  [  3.6      3     14 ]
```

इस lesson में हम Bengaluru की एक quick-commerce company के साथ चलेंगे, जहाँ दो simple plots एक logging bug और delivery times का एक छिपा factor पकड़ लेते हैं। अंत तक आप तीन plots से एक नया dataset explore कर पाओगे और अपने मिले हुए data problem का नाम बता पाओगे।

## ये काम कैसे करता है

### Arrays और shapes

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.shape)          # (2, 2)
```

12 features वाले 10,000 customers के dataset की shape `(10000, 12)` है। एक अकेली row की shape `(12,)` है। Numerical code के ज़्यादातर bugs shape mismatch के होते हैं, इसलिए `.shape` अक्सर print करो।

### Vectorisation

```python
prices = np.array([120, 450, 999])
with_gst = prices * 1.18            # every element at once
print(np.mean(prices), np.std(prices), np.percentile(prices, 90))
```

Vectorised code loop से छोटा होता है और बड़े arrays पर अक्सर दसियों गुना तेज़, क्योंकि असली काम नीचे optimised code में होता है।

**axis** argument दिशा तय करता है:

| Call | Result |
| --- | --- |
| `X.mean()` | एक number: सबका mean |
| `X.mean(axis=0)` | हर column के लिए एक value: हर feature का mean |
| `X.mean(axis=1)` | हर row के लिए एक value: हर record का mean |

### Broadcasting

जब shapes compatible हों, NumPy छोटे array को खींचकर बड़े के बराबर कर देता है। `(10000, 12)` array में से `(12,)` array वाले column means घटाने से हर column एक ही line में centre हो जाता है:

```python
Z = (X - X.mean(axis=0)) / X.std(axis=0)    # each column: mean 0, std 1
```

### Indexing और slicing

Arrays को position से index किया जाता है, 0 से शुरू करके, हर dimension के लिए एक index:

```python
X[0]          # the first row: all features of the first record
X[:, 0]       # the first column: one feature for every record
X[10:20, 1:]  # rows 10 to 19, and every column from the second onwards
X[-1]         # the last row
```

Colon का मतलब है "इस dimension में सब कुछ"। `X[:, 0]` को ज़ोर से "हर row, column zero" पढ़ना मदद करता है। Slices views होते हैं, copies नहीं: slice बदलने से original array बदल जाता है, इसलिए जब अलग टुकड़ा चाहिए तो `.copy()` use करो।

### Boolean masks

```python
incomes = np.array([18000, 52000, 75000, 31000])
print(incomes[incomes > 50000])                     # [52000 75000]
print(incomes[(incomes > 20000) & (incomes < 60000)])
```

"और" के लिए `&` और "या" के लिए `|` use करो, हर condition के चारों ओर brackets के साथ।

### Reproducible random numbers

`rng = np.random.default_rng(42)` एक random generator देता है जिसे आप बिल्कुल वैसा ही दोहरा सकते हो, data sample करने या उसे training और test sets में बाँटने के लिए।

### Machine learning में काम के plots

| Plot | क्या दिखाता है | आम तौर पर क्या मिलता है |
| --- | --- | --- |
| **Histogram** | एक feature का distribution | Skew, outliers, zero जैसी नामुमकिन values |
| **Scatter plot** | दो features का, या एक feature और target का रिश्ता | कोई curve, कोई cluster, किसी value पर टूट |
| **Line chart** | समय के साथ values | Seasonality, अचानक गिरावट, epoch के हिसाब से training loss |
| **Box plot** | Groups में distributions | किसी एक शहर की deliveries बाकियों से बहुत धीमी |

हमेशा axes और units label करो, और बहुत skewed data, जैसे order values, के लिए **log scale** use करो।

## एक example से समझो

Bengaluru की एक quick-commerce company delivery time predict करना चाहती है। आप 50,000 deliveries को arrays में load करते हो: distance km में, items की गिनती, दिन का घंटा, और असल में लगे मिनट।

```python
import numpy as np
import matplotlib.pyplot as plt

# X (distance, items, hour) and y (minutes) were loaded earlier
print(X.shape, y.shape)                  # (50000, 3) (50000,)
print(np.percentile(y, [50, 90, 99]))    # median 14, p90 24, p99 61 minutes

plt.hist(y, bins=60)
plt.xlabel("Delivery time (minutes)"); plt.ylabel("Orders")
plt.show()

plt.scatter(X[:, 0], y, s=2, alpha=0.3)
plt.xlabel("Distance (km)"); plt.ylabel("Minutes")
plt.show()
```

**Histogram क्या दिखाता है।** धीमी deliveries की लंबी पूँछ, जैसा सोचा था, और ठीक 0 मिनट पर एक अजीब spike: 412 deliveries जिनमें कोई समय नहीं लगा दर्ज है। ये logging bug है, कोई चमत्कार नहीं।

**Scatter plot क्या दिखाता है।** Distance के साथ समय लगभग 6 km तक धीरे-धीरे बढ़ता है, फिर अचानक छलाँग मारता है। उन orders को देखने पर पता चलता है कि वो एक दूसरे dark store से आए थे जहाँ riders कम थे।

| Plot | क्या मिला | Model में बदलाव |
| --- | --- | --- |
| Minutes का histogram | 0 मिनट पर 412 deliveries | उन rows को हटाओ या ठीक करो; bug report करो |
| Distance बनाम minutes का scatter | 6 km के बाद छलाँग | एक "store" feature जोड़ो |
| Percentiles | p99 है 61 मिनट | सिर्फ़ average नहीं, p90 और p99 पर errors report करो |

कोई एक metric इन्हें इतना साफ़ नहीं दिखाता जितना दो plots ने दिखाया, पाँच मिनट में, कोई model train करने से पहले।

## आम गलतियाँ

- **Arrays पर Python loops चलाना।** Vectorise करो; ये छोटा और बहुत तेज़ है।
- **Shapes को ignore करना।** उन्हें print करो, और check करो कि broadcasting वही कर रहा है जो आप सोच रहे हो।
- **Plot करने से पहले modelling करना।** Plots से bugs, outliers और leakage जल्दी दिख जाते हैं।
- **बिना label के charts।** Axes और units से plots दूसरों को भी पढ़ने लायक लगते हैं।
- **Skewed data पर linear scale।** जहाँ values कई गुना के दायरे में फैली हों, वहाँ log scale use करो।
- **axis=0 और axis=1 में गड़बड़ करना।** Result की shape देखकर दिशा confirm करो।
