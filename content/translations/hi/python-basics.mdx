## ये क्या है

Python AI के काम की मुख्य भाषा है: data cleaning, automation scripts, AI APIs को call करना और applications बनाना, सब इसी में होते हैं। काम का होने के लिए पूरी Python सीखना ज़रूरी नहीं। पाँच building blocks से आप ज़्यादातर छोटे programs लिख सकते हो:

| Building block | क्या करता है | Example |
| --- | --- | --- |
| **Variables** | किसी नाम के नीचे value रखते हैं | `price = 250` |
| **Conditions** | तय करते हैं क्या करना है | `if price > 200:` |
| **Loops** | steps दोहराते हैं | `for item in cart:` |
| **Functions** | दोबारा use होने लायक steps का package | `def total(cart):` |
| **Lists और dictionaries** | कई values रखते हैं | prices की list, किसी student की details की dictionary |

```flow
dir: LR
Data अंदर | orders, prices, marks -> आपका program | variables values रखते हैं, loops हर order पर जाते हैं, conditions price चुनती हैं, functions जोड़-घटाव करते हैं
आपका program -> Result बाहर | bills, totals, reports
```

## ये काम कैसे करता है

### Values और types

Python में कुछ बुनियादी तरह की values होती हैं:

| Type | Examples | Notes |
| --- | --- | --- |
| पूरी संख्याएँ (`int`) | `250`, `-3` | गिनती और बिना पैसों वाले rupees के लिए |
| दशमलव संख्याएँ (`float`) | `18.5`, `0.18` | Rates, averages के लिए |
| Text (`str`) | `"Chennai"`, `'Asha'` | हमेशा quotes में |
| सही या गलत (`bool`) | `True`, `False` | तुलना के नतीजे |

Python value देखकर type खुद समझ लेता है। Types बदलने के लिए `int("42")`, `float("3.5")` और `str(42)` use करो।

### Variables

Variable किसी value का label है। दोबारा assign करने पर वो बदल जाता है कि label किस पर लगा है:

```python
monthly_rent = 15000
monthly_rent = monthly_rent + 500    # now 15500
```

`x` की जगह `monthly_rent` जैसे साफ़ नाम रखो। अगले महीने आप खुद को धन्यवाद दोगे।

### Conditions

```python
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Pass")
```

Indentation, चार spaces, बताता है कि कौन-सी lines किस branch की हैं। Python इसे गंभीरता से लेता है: गलत indentation error देता है या, उससे भी बुरा, program का मतलब बदल देता है।

तुलना के लिए `==` (बराबर), `!=` (बराबर नहीं), `>`, `>=`, `<` और `<=` हैं। अकेला `=` assign करता है; तुलना नहीं करता।

### Loops

`for` loop हर item के लिए एक बार चलता है:

```python
for city in ["Pune", "Kochi", "Jaipur"]:
    print("Delivering to", city)

for i in range(3):
    print(i)        # prints 0, then 1, then 2
```

`range(3)` 0, 1 और 2 देता है: ये 0 से शुरू होता है और 3 से **पहले** रुकता है। `while` loop तब तक दोहराता है जब तक condition सही रहे, जो तब काम आता है जब पहले से पता न हो कि कितनी बार दोहराना है।

### Functions

Function inputs लेता है, कुछ काम करता है और नतीजा `return` करता है:

```python
def gst(amount, rate=0.18):
    return amount * rate

print(gst(1000))         # 180.0
print(gst(1000, 0.05))   # 50.0
```

`rate=0.18` एक default है: जब आप rate नहीं देते तब ये use होता है। जब भी लगे कि आप वही कुछ lines copy कर रहे हो, function लिख लो।

### Lists

क्रम वाले collections:

```python
cities = ["Pune", "Kochi"]
cities.append("Jaipur")     # add to the end
print(cities[0])            # Pune: counting starts at 0
print(len(cities))          # 3
```

### Dictionaries

Position की जगह key से values ढूँढो:

```python
profile = {"name": "Asha", "age": 24}
profile["city"] = "Pune"     # add or change a key
print(profile["name"])       # Asha
```

**Dictionaries की list** ही वो तरीका है जिसमें Python में ज़्यादातर असली data दिखता है: हर dictionary एक record है, spreadsheet की एक row जैसी।

### Error messages पढ़ना

जब कुछ गलत होता है, Python एक **traceback** print करता है। इसे नीचे से ऊपर पढ़ो: आख़िरी line error का नाम बताती है, और उसके ऊपर वाली line बताती है कि कहाँ हुआ।

```text
Traceback (most recent call last):
  File "bill.py", line 12, in <module>
    total = total + amount
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

इसका मतलब है: line 12 पर आपने एक number और एक text को जोड़ने की कोशिश की। हल ये है कि जहाँ value पढ़ी गई थी वहीं text को `int()` से convert कर लो। Errors आम बात हैं; उन्हें शांति से पढ़ना आधी programming है।

## एक example से समझो

Divya बेंगलुरु में छोटी tiffin service चलाती हैं और पहले orders अपने दिमाग़ में रखती थीं। Veg meal ₹90 का है और non-veg ₹120 का। वो अपना पहला काम का program लिखती हैं:

```python
orders = [
    {"customer": "Ravi", "meals": 2, "veg": True},
    {"customer": "Sana", "meals": 1, "veg": False},
    {"customer": "Arun", "meals": 3, "veg": True},
]
PRICE_VEG = 90
PRICE_NONVEG = 120

def bill(order):
    price = PRICE_VEG if order["veg"] else PRICE_NONVEG
    return order["meals"] * price

total = 0
for order in orders:
    amount = bill(order)
    total = total + amount
    print(order["customer"], "owes Rs", amount)

print("Today's total: Rs", total)
```

Step by step ये होता है:

| Loop की बारी | Customer | Veg? | Price | Meals | Bill | अब तक का total |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Ravi | हाँ | 90 | 2 | 180 | 180 |
| 2 | Sana | नहीं | 120 | 1 | 120 | 300 |
| 3 | Arun | हाँ | 90 | 3 | 270 | 570 |

Program हर customer का bill और दिन का total ₹570 print करता है। जब prices बदलते हैं, वो ऊपर की दो lines edit कर देती हैं। Prices बड़े अक्षरों में हैं, ये याद दिलाने के लिए कि ये settings हैं, ऐसी values नहीं जिन्हें program बदलता है।

आगे वो orders को program में type करने की जगह CSV file से पढ़ना चाहती हैं, जो files वाला lesson सिखाता है।

## आम गलतियाँ

- **गलत indentation।** `if`, `for` और `def` के अंदर की lines एक जैसी indent होनी चाहिए, आमतौर पर चार spaces।
- **`range` के साथ off-by-one।** `range(3)` का मतलब 0, 1, 2 है, 1, 2, 3 नहीं।
- **Text और numbers मिलाना।** `"5" + 3` fail होता है; पहले `int()` या `str()` से convert करो।
- **Condition में `=` use करना।** तुलना `==` से होती है।
- **Function में `return` की जगह `print`।** Print value दिखाता है; return उसे use करने के लिए वापस देता है।
- **अस्पष्ट नाम।** `a`, `b` और `temp` से programs पढ़ना मुश्किल हो जाता है; चीज़ों का नाम उनमें रखी चीज़ के हिसाब से रखो।
