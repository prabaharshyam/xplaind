## இது என்ன

உங்க programs பெருசாக பெருசாக, அதே சில lines-ஐ copy பண்ண ஆரம்பிப்பீங்க: மூணு இடத்துல GST கணக்கு போடுறது, ரெண்டு scripts-ல phone numbers-ஐ clean பண்றது. Copy பண்ணா bugs வரும், ஏன்னா ஒரு copy-ஐ fix பண்ணிட்டு மத்ததை மறந்துடுவீங்க. இதை **function** தீர்க்குது.

Function-னா **ஒரே ஒரு வேலை** செய்யுற, பெயர் இருக்குற code block. நீங்க அதுக்கு **parameters**-ங்குற inputs கொடுப்பீங்க, அது வேலையை செய்யும், result-ஐ **return** பண்ணும்.

```flow
dir: LR
Inputs | price = 1000, rate = 0.18 -> Function: gst_amount(price, rate=0.18) | return price * rate
Function: gst_amount(price, rate=0.18) -> Output: 180.0
```

Functions இதை பண்ண உதவும்:

- Copy பண்றதுக்கு பதிலா code-ஐ **மறுபடி use** பண்ணலாம்;
- பெரிய problem-ஐ ஒண்ணொண்ணா test பண்ணக்கூடிய சின்ன துண்டுகளா **பிரிக்கலாம்**;
- Steps-க்கு **பெயர் வைக்கலாம்**, அப்போ program instructions மாதிரி படிக்கலாம்: `clean_phone_number`, `monthly_emi`, `send_reminder`.

இந்த lesson-ல ஒரு form-ல இருந்து customers-ஓட phone numbers-ஐ clean பண்ற Imran-ஐ follow பண்றோம். Messy script-ஐ சின்ன, மறுபடி use பண்ணக்கூடிய functions-ஆ அவர் மாத்துறார். Lesson முடியும்போது, results return பண்ணி, programs முழுக்க மறுபடி use பண்ணக்கூடிய functions எழுத முடியும்.

## இது எப்படி work ஆகுது

### Define பண்றது, call பண்றது

```python
def gst_amount(price, rate=0.18):
    return price * rate

print(gst_amount(1000))         # 180.0, uses the default rate
print(gst_amount(1000, 0.05))   # 50.0
```

- `def` definition-ஐ ஆரம்பிக்குது.
- `price`, `rate` ரெண்டும் **parameters**.
- `rate=0.18` ஒரு **default**; call பண்றவங்க கொடுக்கலைன்னா இதை use பண்ணும்.
- `return` result-ஐ திருப்பி கொடுக்குது.

Call பண்ண brackets வேணும்: `gst_amount(1000)`. Brackets இல்லாம `gst_amount` எழுதினா function-ஐயே குறிக்குது, அதை run பண்ணாது.

### Return vs print

Beginners-க்கு இதுதான் அதிகமா குழப்பம்:

| | `return` | `print` |
| --- | --- | --- |
| என்ன பண்ணும் | Call பண்றவங்களுக்கு ஒரு value-வை திருப்பி கொடுக்கும் | Screen-ல text காட்டும் |
| Call பண்றவங்க value-வை use பண்ண முடியுமா? | முடியும்: `total = price + gst_amount(price)` | முடியாது: function `None` return பண்ணும் |
| எப்போ use பண்றது | ஏதாவது compute பண்ற functions-ல | Results காட்டுற code-ல மட்டும் |

ஏதாவது compute பண்ற functions அதை return பண்ணணும், print பண்றதை அதை call பண்ற code-க்கு விடணும். அப்போ அதே function report-லயும், web app-லயும், test-லயும் work ஆகும்.

### Position வச்சும் பெயர் வச்சும் arguments

```python
gst_amount(1000, 0.05)               # by position
gst_amount(price=1000, rate=0.05)    # by name: clearer with several parameters
```

### Scope

Function-க்குள்ள உருவாக்குற variables அதுக்குள்ள மட்டும் தான் இருக்கும்:

```python
def tax(amount):
    total = amount * 1.18
    return total

result = tax(100)     # 118.0
print(total)          # NameError: total only existed inside tax
```

Function-க்கு தேவையானதை உள்ள pass பண்ணுங்க, அது உருவாக்குனதை return பண்ணுங்க; வெளியில இருக்குற variables-ஐ நம்பாதீங்க. தன் inputs-ஐ மட்டும் use பண்ற functions test பண்ணவும் மறுபடி use பண்ணவும் easy.

### ஒவ்வொண்ணுக்கும் ஒரே வேலை

நல்ல function ஒரே ஒரு விஷயத்தை செய்யும், அதோட பெயரே அது என்னன்னு சொல்லும். "number-ஐ clean பண்ணி SMS-ஐ அனுப்புது"ன்னு விவரிக்க "and" தேவைப்பட்டா, அதை ரெண்டா பிரிங்க.

```flow
dir: LR
ஒரு பெரிய function: process_customers() | படிக்கும், clean பண்ணும், check பண்ணும், எழுதும்: test பண்ணவும் மறுபடி use பண்ணவும் கஷ்டம் -[பிரிங்க]-> சின்ன functions | digits_only(), normalise_mobile(), is_valid_email(), read_customers(), write_report(): ஒவ்வொண்ணையும் தனியா test பண்ணலாம்
```

### Docstrings, type hints

ஒரு வரி விளக்கமும் type hints-உம் படிக்கிறவங்களுக்கும், உங்க editor மாதிரி tools-க்கும் உதவும்:

```python
def monthly_emi(principal: float, annual_rate: float, months: int) -> float:
    """Equated monthly instalment for a loan."""
    r = annual_rate / 12
    return principal * r * (1 + r) ** months / ((1 + r) ** months - 1)

print(round(monthly_emi(500000, 0.09, 60)))   # about 10379 rupees a month
```

### ஒரு trap: mutable defaults

```python
def add_order(order, orders=[]):      # bug: the same list every call
    orders.append(order)
    return orders
```

Default list ஒரே தடவை உருவாக்கப்பட்டு calls-க்கு நடுவுல share ஆகும், அதனால orders சேர்ந்துக்கிட்டே போகும். `None` use பண்ணி, உள்ளயே புது list உருவாக்குங்க:

```python
def add_order(order, orders=None):
    if orders is None:
        orders = []
    orders.append(order)
    return orders
```

## ஒரு worked example

Imran Hyderabad-ல ஒரு சின்ன marketing agency-ல வேலை செய்யுறார். ஒரு client-ஓட form 3,000 customers-ஓட phone numbers-ஐ சேகரிச்சிருக்கு, எல்லாம் வித்தியாசமா எழுதியிருக்காங்க: "98450 12345", "+91-9845012345", "09845012345", "9845012345 ". SMS tool-க்கு அவை `+91` அப்புறம் பத்து digits-ஆ வேணும்.

அவரோட முதல் script ஒரு நீளமான code block, இன்னும் ரெண்டு scripts-ல கொஞ்சம் மாத்தி copy பண்ணியிருந்தார். இப்போ அதை சின்ன functions-ஆ திருப்பி எழுதுறார், ஒவ்வொண்ணுக்கும் ஒரே வேலை:

```python
def digits_only(text: str) -> str:
    """Keep only the digits in text."""
    return "".join(ch for ch in text if ch.isdigit())

def normalise_mobile(raw: str) -> str | None:
    """Return +91 and ten digits, or None if it is not a valid mobile number."""
    d = digits_only(raw)
    if d.startswith("91") and len(d) == 12:
        d = d[2:]
    if d.startswith("0") and len(d) == 11:
        d = d[1:]
    return "+91" + d if len(d) == 10 else None

for raw in ["98450 12345", "+91-9845012345", "09845012345", "12345"]:
    print(raw, "->", normalise_mobile(raw))
```

| Input | digits_only-க்கு அப்புறம் | Rules-க்கு அப்புறம் | Result |
| --- | --- | --- | --- |
| `98450 12345` | 9845012345 | 10 digits | +919845012345 |
| `+91-9845012345` | 919845012345 | ஆரம்பத்துல இருக்குற 91-ஐ எடுத்தாச்சு | +919845012345 |
| `09845012345` | 09845012345 | ஆரம்பத்துல இருக்குற 0-வை எடுத்தாச்சு | +919845012345 |
| `12345` | 12345 | ரொம்ப சின்னது | None |

மூணு numbers `+919845012345` ஆகுது; கடைசியது `None` return பண்ணுது, அதனால invalid ones-ஐ client-க்கு list போட்டு கொடுக்கலாம். Logic functions-க்குள்ள இருக்கிறதால, அடுத்த வாரம் அவர் `normalise_mobile`-ஐ copy பண்ணாம, மத்த ரெண்டு scripts-ல import பண்ணிக்கிறார். Client landline numbers-ஐயும் accept பண்ணச் சொன்னப்போ, ஒரே இடத்துல ஒரே function-ஐ மாத்துனா போதும்.

## பொதுவா பண்ற தப்புகள்

- **Return பண்றதுக்கு பதிலா print பண்றது.** Call பண்றவங்களுக்கு `None` தான் கிடைக்கும்.
- **Function-ஐ call பண்ண மறக்குறது.** Brackets இல்லாத `gst_amount` ஒண்ணும் பண்ணாது.
- **அதிகமா வேலை செய்யுற functions.** ஒவ்வொண்ணுக்கும் ஒரே வேலைன்னு ஆகுற வரைக்கும் பிரிங்க.
- **வெளியில இருக்குற variables-ஐ நம்புறது.** Inputs-ஐ parameters-ஆ pass பண்ணி, results-ஐ return பண்ணுங்க.
- **Mutable defaults**, `def add(item, items=[])` மாதிரி. `None` use பண்ணி, உள்ளயே புது list உருவாக்குங்க.
- **தெளிவில்லாத பெயர்கள்.** `process()`, `do_stuff()` படிக்கிறவங்களுக்கு எதுவும் சொல்லாது.
