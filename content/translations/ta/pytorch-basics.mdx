## இது என்ன

**PyTorch** neural networks build பண்ணி train பண்ண ஒரு open-source Python library. இதோட building blocks:

- **Tensors**: NumPy arrays மாதிரி multi-dimensional arrays. CPU-லயோ GPU-லயோ இருக்கலாம், gradients-ஐ track பண்ணும்.
- **Autograd**: tensors மேல நடக்குற operations-ஐ record பண்ணி, gradients-ஐ தானா compute பண்ணும்.
- **nn.Module**: models-ஓட base class. Layers-உம் models-உம் modules தான்.
- **Dataset**, **DataLoader**: data-வை load பண்ணி, shuffle ஆன batches-ஆ கொடுக்கும்.
- **Optimisers**: gradients-ஐ வச்சு weights-ஐ update பண்ணும் (SGD, Adam).

```flow
images, labels இருக்குற CSV -> Dataset | __getitem__(i) (tensor 3x224x224, label 4) கொடுக்கும்
Dataset -> DataLoader | 64-ஓட batches, shuffle ஆனது, .to(device)
DataLoader -> nn.Module | forward(x) 6 classes-க்கு scores கொடுக்கும்
nn.Module -> loss_fn -> loss.backward() -> opt.step()
opt.step() -[அடுத்த batch]-> DataLoader
opt.step() -[ஒவ்வொரு epoch-லயும்]-> Validate | model.eval() + no_grad(), best checkpoint-ஐ save பண்ணும்
```

இந்த lesson-ல Pune-ல ஒரு textile manufacturer-ல வேலை செய்யுற engineer-ஐ follow பண்ணுவோம். அவர் தன்னோட first PyTorch project-ஆ fabric-defect classifier build பண்றார்.

## இது எப்படி work ஆகுது

**Tensors, devices.** Data-ல இருந்து tensors உருவாக்கலாம், `.shape`, `.dtype` check பண்ணலாம். Model-ஐயும் data-வையும் ஒரே device-க்கு நகர்த்தணும் (GPU-க்கு `"cuda"`, இல்லைன்னா `"cpu"`). Devices மாறி இருக்கறது beginners பண்ற top தப்புல ஒண்ணு.

**Data.** `Dataset` index கொடுத்தா ஒரு example-ஐயும் அதோட label-ஐயும் தரும். `DataLoader` அதை batch பண்ணி shuffle பண்ணும். Training-லயும் prediction-லயும் அதே preprocessing-ஐ apply பண்ணுங்க.

**Model.** `nn.Module`-ஐ subclass பண்ணி, `__init__`-ல layers-ஐயும், `forward`-ல forward computation-ஐயும் define பண்ணுங்க.

**Training loop.** PyTorch-ஓட heart இதுதான்:

```python
model.to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(epochs):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        opt.zero_grad()              # clear old gradients
        loss = loss_fn(model(x), y)  # forward pass and loss
        loss.backward()              # backpropagation
        opt.step()                   # update weights

    model.eval()                     # switch off dropout etc.
    with torch.no_grad():            # no gradients needed for evaluation
        val_loss = evaluate(model, val_loader)
    save_if_best(model, val_loss)
```

**Evaluation mode.** `model.eval()` dropout, batch normalisation மாதிரி layers-ஐ inference behaviour-க்கு மாத்தும். `torch.no_grad()` memory-யும் நேரத்தையும் மிச்சப்படுத்தும். `eval()` மறந்தா validation numbers தப்பா வரும். `no_grad()` மறந்தா memory வீணாகும்.

**Saving.** Model-ஓட `state_dict`-ஐ (அதோட weights) save பண்ணுங்க, கூடவே அதை rebuild பண்ண தேவையான settings, preprocessing-ஐயும். கடைசி epoch-ஐ மட்டும் இல்லாம, validation score-ல best-ஆ வந்த checkpoint-ஐ save பண்ணுங்க.

**Reproducibility.** Random seeds set பண்ணுங்க, settings-ஐயும் library versions-ஐயும் log பண்ணுங்க.

**Higher-level tools.** PyTorch Lightning, fastai மாதிரி libraries loop-ஐ சுத்தி logging, checkpoints, multi-GPU support-ஐ wrap பண்ணும். முதல்ல plain loop-ஐ கத்துக்கோங்க, அப்போ தான் wrappers-ஐ debug பண்ண முடியும்.

**ஒரு minimal model, dataset:**

```python
import torch
from torch import nn
from torch.utils.data import Dataset, DataLoader

class DefectData(Dataset):
    def __init__(self, rows, label_map, transform):
        self.rows, self.label_map, self.transform = rows, label_map, transform
    def __len__(self):
        return len(self.rows)
    def __getitem__(self, i):
        path, label = self.rows[i]
        return self.transform(load_image(path)), self.label_map[label]

class SmallNet(nn.Module):
    def __init__(self, classes=6):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(32, classes)
    def forward(self, x):
        return self.head(self.body(x).flatten(1))
```

`label_map` ஒரு தடவை build பண்ணி training, validation ரெண்டு datasets-க்கும் pass பண்ணுவோம். Worked example-ல தேவைப்பட்ட fix இதுதான்.

**போகும்போதே shapes-ஐ check பண்றது.** நிறைய PyTorch errors shape errors தான். Training-க்கு முன்னாடி ஒரு batch-ஐ model வழியா அனுப்பி, ஒவ்வொரு layer-க்கு அப்புறமும் shape-ஐ print பண்ணுங்க. 224 pixels-ஓட 64 colour images கொண்ட batch-ஓட shape `[64, 3, 224, 224]`, model-ஓட output `[64, 6]`-ஆ இருக்கணும். "mat1 and mat2 shapes cannot be multiplied"ன்னு error வந்தா, ஒரு layer எதிர்பார்த்த inputs எண்ணிக்கையும் அதுக்கு வந்ததும் வேற வேறன்னு அர்த்தம்.

**GPU use பண்றது.** `torch.cuda.is_available()` check பண்ணி, script-ஓட மேல ஒரு தடவை `device = "cuda" if torch.cuda.is_available() else "cpu"` set பண்ணுங்க. அப்புறம் எல்லா இடத்துலயும் `device`-ஐ use பண்ணுங்க. இந்த path-ல இருக்குற projects-க்கு Google Colab அல்லது Kaggle notebooks-ல கிடைக்குற free GPUs போதும். ஒவ்வொரு layer-லயும் இருக்குற பெரிய matrix multiplications-ஐ GPU பத்து மடங்கு அல்லது அதுக்கு மேல வேகப்படுத்தும். ஆனா data loading மெதுவா இருந்தா அதுக்கு எதுவும் பண்ணாது. Loop ஓடும்போது GPU சும்மா இருந்தா, DataLoader-ல `num_workers`-ஐ அதிகப்படுத்துங்க. அப்போ images parallel-ஆ read ஆகி resize ஆகும்.

**Loop-ல இருந்து பழக்கத்துக்கு.** Loop-ஐ ஒரு தடவை கையால எழுதி, template-ஆ வச்சுக்கோங்க: மேல seeds, device, அப்புறம் datasets, loaders, model, optimiser, loss, கடைசியா validation, checkpoint saving இருக்குற epoch loop. பெரும்பாலான புது projects-ல dataset-உம் model-உம் மட்டும் தான் மாறும்.

**முழுசா run ஆகுற ஒரு training script.** எங்கயும் CPU-ல ஓடுற மாதிரி synthetic tabular data. உங்க சொந்த `Dataset`-ஐ போட்டு மாத்திக்கோங்க:

```python
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader, random_split

torch.manual_seed(0)
device = "cuda" if torch.cuda.is_available() else "cpu"

N, D, C = 6000, 20, 3
X = torch.randn(N, D)
true_w = torch.randn(D, C)
y = (X @ true_w + 0.5 * torch.randn(N, C)).argmax(1)

mean, std = X.mean(0), X.std(0)                      # save these with the model
ds = TensorDataset((X - mean) / std, y)
train_ds, val_ds = random_split(ds, [5000, 1000], generator=torch.Generator().manual_seed(0))
train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
val_dl = DataLoader(val_ds, batch_size=512)

model = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C)).to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
loss_fn = nn.CrossEntropyLoss()

def evaluate():
    model.eval(); correct = total = 0; loss_sum = 0.0
    with torch.no_grad():
        for xb, yb in val_dl:
            xb, yb = xb.to(device), yb.to(device)
            out = model(xb)
            loss_sum += loss_fn(out, yb).item() * len(yb)
            correct += (out.argmax(1) == yb).sum().item(); total += len(yb)
    return loss_sum / total, correct / total

best, patience, bad = float("inf"), 5, 0
for epoch in range(100):
    model.train()
    for xb, yb in train_dl:
        xb, yb = xb.to(device), yb.to(device)
        opt.zero_grad()
        loss_fn(model(xb), yb).backward()
        opt.step()
    val_loss, val_acc = evaluate()
    if val_loss < best - 1e-4:
        best, bad = val_loss, 0
        torch.save({"state_dict": model.state_dict(), "mean": mean, "std": std,
                    "epoch": epoch, "val_acc": val_acc, "torch": str(torch.__version__)}, "best.pt")
    else:
        bad += 1
        if bad >= patience:
            break
print(f"stopped at epoch {epoch}, best val loss {best:.3f}")
```

**Load பண்ணி predict பண்றது, தனி script-ல.** அதே architecture-ஐ rebuild பண்ணி, weights-ஐ load பண்ணி, save பண்ண preprocessing-ஐ apply பண்ணி, eval mode-க்கு மாத்துங்க:

```python
ckpt = torch.load("best.pt", map_location="cpu", weights_only=True)   # never unpickle untrusted files
model2 = nn.Sequential(nn.Linear(D, 64), nn.ReLU(), nn.Dropout(0.2), nn.Linear(64, C))
model2.load_state_dict(ckpt["state_dict"]); model2.eval()
new_rows = torch.randn(5, D)
with torch.no_grad():
    probs = model2((new_rows - ckpt["mean"]) / ckpt["std"]).softmax(1)
print(probs.round(decimals=2), "from epoch", ckpt["epoch"], "val acc", round(ckpt["val_acc"], 3))
```

Prediction நேரத்துல save பண்ண mean, standard deviation-ஐ மறந்துடுறது, சத்தமே இல்லாம வர்ற bugs-ல ரொம்ப பொதுவான ஒண்ணு.

**GPUs-ல வேகமா.** Mixed precision (forward pass-ஐ சுத்தி `torch.autocast(device_type="cuda", dtype=torch.bfloat16)`) modern GPUs-ல memory குறைவா எடுத்து வேகமா ஓடும். `torch.compile(model)` training-ஐ இன்னும் வேகப்படுத்தலாம். Plain loop work ஆனதுக்கு அப்புறம் இதை சேர்த்து, validation scores மாறலைன்னு check பண்ணுங்க.

**Data loading தான் பெரும்பாலும் bottleneck.** GPU use குறைவா இருந்தா, `DataLoader`-ல `num_workers`-ஐ அதிகப்படுத்துங்க, data-வை fast local disk-ல வச்சுக்கோங்க, GPU-ல train பண்ணும்போது `pin_memory=True` set பண்ணுங்க.

## ஒரு நாள், ஒரு example

Pune-ல ஒரு textile manufacturer fabric defect images-ஐ ஆறு வகையா classify பண்ண விரும்புறாங்க. First PyTorch project-ஆ, ஒரு engineer pipeline-ஐ முதல்ல இருந்து கடைசி வரை build பண்றார்:

- CSV-ல இருந்து images, labels-ஐ படிக்குற ஒரு `Dataset`. 224 × 224-க்கு resize பண்ணி, normalise பண்ணும்;
- batch size 64-ஓட ஒரு `DataLoader`. Training-க்கு மட்டும் shuffle;
- ஒரு சின்ன model (அடுத்த lesson-ல pre-trained CNN-ஐ போடுவார்);
- மேல இருக்குற training loop. AdamW, 20 epochs, validation accuracy-ல best checkpoint-ஐ save பண்ணும்;
- checkpoint-ஐ load பண்ணி, அதே preprocessing-ஐ apply பண்ணி, class-ஐயும் probability-யையும் திருப்பி தர்ற ஒரு prediction script.

First run: validation accuracy 17%-ல மாட்டிக்கிச்சு. ஆறு classes-க்கு இது கிட்டத்தட்ட chance level. Bug என்னன்னா, labels strings-ஆ படிக்கப்பட்டு, training, validation datasets-ல வேற வேற மாதிரி map ஆச்சு. Mapping-ஐ ஒரே shared இடத்துல fix பண்ணதுக்கு அப்புறம், சின்ன model-லயே accuracy 71%-க்கு உயர்ந்துச்சு. அப்புறம் தான் transfer learning-க்கு போகணும்.

## பொதுவா பண்ற தப்புகள்

- **Model-உம் data-வும் வேற வேற devices-ல இருக்கறது.**
- **`zero_grad()` மறந்துடுறது.** Batches முழுக்க gradients சேர்ந்துக்கிட்டே போகும்.
- **Validation-ல `model.eval()`, `torch.no_grad()` மறந்துடுறது.**
- **Training-லயும் prediction-லயும் வேற வேற preprocessing.**
- **கடைசி epoch-ஐ மட்டும் save பண்றது.** Validation-ல best-ஆ வந்த checkpoint-ஐ வச்சுக்கோங்க.
- **Shapes-ஐ print பண்ணவே பண்ணாம இருக்கறது.** ஒரு batch-ஐ model வழியா அனுப்பி shapes-ஐ print பண்ணா, error messages-ஐ படிச்சு ஒரு மணி நேரம் வீணாக்காம இருக்கலாம்.
- **Preprocessing statistics-ஐ weights-ஓட save பண்ணாம இருக்கறது.**
- **Validation-ல best-ஆ வந்ததுக்கு பதிலா கடைசி epoch-ஐ வச்சுக்கறது.**
- **Correctness-க்கு முன்னாடியே speed-ஐ optimise பண்றது**: முதல்ல plain loop-ஐ சரியா பண்ணுங்க.
