## இது என்ன

Programs எழுதுறதுக்கு முன்னாடி, அதை எழுத ஒரு இடமும், run பண்ண ஒரு வழியும் வேணும். First-year student-ல இருந்து ஒரு பெரிய company-ல இருக்குற AI engineer வரை, ஒவ்வொரு Python programmer-உம் இதே மூணு tools-ஐ வச்சு தான் வேலை செய்யுறாங்க:

| Tool | அது என்ன | உதாரணம் |
| --- | --- | --- |
| **Python** | உங்க code-ஐ படிச்சு run பண்ற program (**interpreter**) | Python 3, python.org-ல இருந்து |
| **ஒரு code editor** | நீங்க code எழுதுற இடம்; அது உங்க code-க்கு colour குடுக்கும், சின்ன தப்புகளை கண்டுபிடிக்கும், type பண்ண உதவும் | Visual Studio Code (VS Code), free |
| **ஒரு terminal** | Commands type பண்ற ஒரு text window; உங்க file-ஐ run பண்ற command-உம் இதுல தான் | VS Code-க்குள்ள இருக்குற terminal |

மூணும் **ஒத்துப்போனா** தான் setup முடிஞ்சது: terminal-ஆல Python-ஐ கண்டுபிடிக்க முடியணும், editor அதே Python-ஐ use பண்ணணும், terminal உங்க file இருக்குற folder-ல திறந்திருக்கணும். Beginners-க்கு வர்ற கிட்டத்தட்ட எல்லா problem-உம், இதுல ஏதோ ஒண்ணு ஒத்துப்போகாததால தான்.

ஒத்துப்போனதும், ஒவ்வொரு programmer-உம் தினமும் சுத்துற loop-ஐ ஆரம்பிக்கிறீங்க:

```flow
dir: LR
ஒரு file எழுதுங்க -> Save பண்ணுங்க
Save பண்ணுங்க -> Terminal-ல run பண்ணுங்க
Terminal-ல run பண்ணுங்க -> Output-ஐயோ error-ஐயோ படிங்க
Output-ஐயோ error-ஐயோ படிங்க -> Fix பண்ணுங்க
Fix பண்ணுங்க -[மறுபடி]-> ஒரு file எழுதுங்க
```

இந்த lesson, Madurai-ல இருக்குற commerce graduate Karthik-ஐ follow பண்ணுது; அவர் தன் Windows laptop-ல Python set up பண்றாரு, beginners-க்கு அதிகமா வர்ற problems-ஐ சந்திக்கிறாரு. இதோட check ஒரு சின்ன project: உங்க சொந்த முதல் file, terminal-ல run பண்ணி, online-ல share பண்றது.

## இது எப்படி work ஆகுது

### ஒரு version-ஐ தேர்ந்தெடுங்க

எல்லாத்தையும் விட புதுசான Python 3-ஐ install பண்ணுங்க. Python 3.15.0, 9 October 2026-ல வந்துச்சு; bugfix releases 3.15.1, 3.15.2 October-லயே வந்துச்சு, இன்னும் சுமார் ரெண்டு மாசத்துக்கு ஒரு தடவை வரும், அதனால நீங்க பாக்குற கடைசி number இன்னும் அதிகமா இருக்கலாம். Python 3.14-உம் பரவாயில்ல. மூணு rules:

- **Python 3 தான், Python 2 எப்பவுமே வேண்டாம்.** ஒரு tutorial brackets இல்லாம `print "hello"`-னு எழுதுனா, அது Python 2-க்கானது; புதுசா ஒண்ணை தேடுங்க.
- **ஒரு Python போதும்.** "Safe-ஆ இருக்கட்டும்"-னு பல Pythons install பண்றது தான், editor-உம் terminal-உம் ஒத்துப்போகாம போக எல்லாத்தையும் விட சீக்கிரமான வழி.
- **பெரிய libraries பின்தங்கலாம்.** சில பெரிய data, AI libraries ஒரு புது version-ஐ support பண்ண வாரக்கணக்கா எடுக்கும். ஏதாவது ஒண்ணு install ஆக மாட்டேங்குதுன்னா, அந்த project-க்கு 3.14 use பண்ணுங்க.

### Python install பண்ணுங்க

| Computer | எப்படி |
| --- | --- |
| Windows 10 அல்லது 11 | python.org/downloads-ல இருந்தோ Microsoft Store-ல இருந்தோ **Python install manager**-ஐ install பண்ணுங்க. அது உங்களுக்கு `python`, `py` commands-ஐ குடுக்கும். எதுவும் install ஆகாத நிலையில முதல் தடவை Python-ஐ run பண்ணா, அது latest release-ஐ download பண்ணும்; `py install 3.15`-னும் type பண்ணலாம். |
| Mac | python.org-ல இருந்து macOS installer-ஐ download பண்ணி run பண்ணுங்க. `python3` command-ஐ use பண்ணுங்க. |
| Linux | Python 3 பொதுவா ஏற்கனவே இருக்கும். `python3` use பண்ணுங்க; நிறைய systems-ல வெறும் `python` command இருக்கவே இருக்காது. |

Install manager தான் இப்போ Windows-ல Python install பண்றதுக்கான official வழி. பழைய full installer (ஒரே ஒரு `.exe`) Python 3.15-க்கு இன்னும் இருக்கு, ஆனா Python 3.16-ல இருந்து python.org அதை குடுக்குறதை நிறுத்திடும். அதை use பண்ணா, அதோட முதல் screen-ல **"Add python.exe to PATH"**-ஐ tick பண்ணுங்க. **PATH**-னா, நீங்க ஒரு command type பண்ணும்போது Windows தேடுற folders-ஓட list. Python-ஓட folder அந்த list-ல இல்லன்னா, Python install ஆகியிருந்தாலும் `python`-னு type பண்ணா fail ஆகும்.

### Install-ஐ check பண்ணுங்க

ஒரு **புது** terminal திறந்து இதை type பண்ணுங்க:

```text
python --version
```

Mac, Linux-ல `python3 --version` type பண்ணுங்க. `Python 3.15.0` மாதிரி 3-ல ஆரம்பிக்கிற ஒரு version தெரியணும். Windows-ல, install manager-க்கு தெரிஞ்ச எல்லா Python-ஐயும் `py list` காட்டும்.

ஏன் புது terminal? ஒரு terminal PATH-ஐ ஒரே ஒரு தடவை, அது திறக்கும்போது தான் படிக்கும். Install நடக்கும்போது திறந்திருந்த terminal-கிட்ட இன்னும் பழைய list தான் இருக்கும், அதால Python-ஐ கண்டுபிடிக்க முடியாது. VS Code terminal, PATH-ஐ VS Code-ல இருந்தே copy பண்ணுது, அதனால terminal tab-ஐ மட்டும் இல்ல, VS Code-ஐயே முழுசா close பண்ணி திரும்ப திறங்க.

### Windows-ஆல Python-ஐ கண்டுபிடிக்க முடியாதப்போ

Windows learners அதிகமா சந்திக்கிற மூணு messages இவை தான்:

| உங்களுக்கு தெரியுறது | அதோட அர்த்தம் | Fix |
| --- | --- | --- |
| `The term 'python' is not recognized...` (PowerShell) அல்லது `'python' is not recognized as an internal or external command` (Command Prompt) | Python install ஆகல, இல்லன்னா அதோட folder PATH-ல இல்ல | Install manager-ஐ install பண்ணுங்க, இல்லன்னா PATH box-ஐ tick பண்ணி பழைய installer-ஐ திரும்ப run பண்ணுங்க. அப்புறம் புது terminal திறங்க. |
| `Python was not found; run without arguments to install from the Microsoft Store...`, இல்லன்னா Store app திறக்குது | Python install ஆகல. Windows-ல **app execution alias**-னு ஒரு shortcut கூடவே வருது, அது `python`-ஐ Store-க்கு அனுப்புது. | Python-ஐ ஒழுங்கா install பண்ணுங்க. பழைய installer-ஐ use பண்ணியிருந்தா, Start menu-ல "Manage app execution aliases"-ஐ தேடி, python.exe, python3.exe-க்கான ரெண்டு App Installer entries-ஐயும் off பண்ணுங்க. |
| நீங்க எதிர்பார்க்காத ஒரு version | ஒண்ணுக்கு மேல Python install ஆகியிருக்கு, PATH-ல முதல்ல இருக்குறது தான் ஜெயிக்கும் | `py list`, `where.exe python` எல்லாத்தையும் காட்டும். கூடுதலா இருக்குறதை uninstall பண்ணுங்க. |

```flow
title: Terminal-ஆல Python-ஐ கண்டுபிடிக்க முடியல
python --version type பண்ணுங்க -[Python 3 காட்டுது]-> Code எழுத ready
python --version type பண்ணுங்க -[not recognized]-> Install பண்ணுங்க அல்லது PATH-ஐ fix பண்ணுங்க
python --version type பண்ணுங்க -[Microsoft Store திறக்குது]-> Install பண்ணுங்க அல்லது alias-ஐ off பண்ணுங்க
Install பண்ணுங்க அல்லது PATH-ஐ fix பண்ணுங்க -> VS Code-ஐ close பண்ணி திரும்ப திறங்க
Install பண்ணுங்க அல்லது alias-ஐ off பண்ணுங்க -> VS Code-ஐ close பண்ணி திரும்ப திறங்க
VS Code-ஐ close பண்ணி திரும்ப திறங்க -> python --version type பண்ணுங்க
```

### Mac-ல: சரியான python3-ஐ தான் run பண்றீங்களான்னு உறுதி பண்ணுங்க

macOS-க்கு `/usr/bin/python3`-ல அதோட சொந்த `python3` இருக்கு. அது Apple-ஓட developer tools-ஐ சேர்ந்தது, பொதுவா பழையது; அதை call பண்ணா Command Line Tools-ஐ install பண்ண சொல்லி கேக்கலாம். python.org installer அதோட சொந்த `python3`-ஐ முதல்ல வர வைக்கும். Check பண்ண, ஒரு புது terminal திறந்து `which python3` type பண்ணுங்க. `/Library/Frameworks/Python.framework` அல்லது `/usr/local/bin`-க்கு கீழ இருக்குற path-னா அது python.org-ஓடது; `/usr/bin/python3`-னா Apple-ஓடது.

### ஒரு editor install பண்ணி, அதை Python-க்கு point பண்ணுங்க

VS Code-ஐயும் அதோட **Python extension**-ஐயும் (Microsoft-ஓடது) install பண்ணுங்க. உங்க வேலைக்கு `python-practice` மாதிரி ஒரு folder உருவாக்கி, File, Open Folder வச்சு அதை திறங்க. ஒவ்வொரு project-ஐயும் அதோட சொந்த folder-ல வச்சா, அப்புறம் நிறைய குழப்பத்தை தவிர்க்கலாம்.

அப்புறம் எந்த Python-ஐ use பண்ணணும்னு VS Code-க்கு சொல்லுங்க. Ctrl+Shift+P (Mac-ல Cmd+Shift+P) அழுத்தி, **Python: Select Interpreter**-னு type பண்ணி, நீங்க இப்போ install பண்ண Python-ஐ pick பண்ணுங்க. தேர்ந்தெடுத்த version கீழ status bar-ல தெரியும். VS Code வேற ஒரு Python-ஐ pick பண்ணியிருந்தா, விசித்திரமான results வரும்: file terminal-ல run ஆகும், ஆனா editor உங்க imports-க்கு கீழ சிவப்பு கோடு போடும், இல்லன்னா Run button நீங்க வேணும்னு install பண்ணாத ஒரு version-ஐ use பண்ணும். Interpreter-ஐ மாத்துனா ஏற்கனவே திறந்திருக்குற terminals மாறாது, அதனால அப்புறம் ஒரு புது terminal திறங்க.

கடைசியா, **File, Auto Save**-ஐ on பண்ணுங்க. ஒரு file-ஓட tab-ல dot இருந்தா, அதுல save பண்ணாத changes இருக்குன்னு அர்த்தம். Python disk-ல இருக்குற file-ஐ தான் run பண்ணும், உங்க screen-ல இருக்குறதை இல்ல, அதனால save பண்ணாத fix ஒண்ணுமே பண்ணாது.

### உங்க முதல் file-ஐ எழுதுங்க

அந்த folder-ல `hello.py`-னு ஒரு file உருவாக்குங்க:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

Line 1, Python-ஓட built-in `datetime` module-ல இருந்து `date`-ஐ கொண்டு வருது. Line 3, `name`-ங்குற variable-ல text-ஐ store பண்ணுது. Lines 4, 5 print பண்ணுது, `date.today()` உங்க computer-கிட்ட இன்னைக்கு date-ஐ கேக்குது.

`.py` ending, இது Python code-னு Python-க்கும் உங்க editor-க்கும் சொல்லுது. Windows default-ஆ file endings-ஐ மறைக்கும், அதனால `hello.py`-னு நீங்க நினைக்கிற file உண்மையில `hello.py.txt`-ஆ இருக்கலாம். File Explorer-ல View menu-வை திறந்து, file name extensions-ஐ on பண்ணுங்க, அப்போ உண்மை தெரியும்.

### Terminal-ல run பண்ணுங்க

View, Terminal வச்சு VS Code-க்குள்ள terminal-ஐ திறங்க. Terminal எப்பவுமே ஒரு folder-"க்குள்ள" தான் வேலை செய்யும், அது எந்த folder-னு prompt பொதுவா காட்டும், உதாரணம் `PS C:\Users\karthik\python-practice>`. அது உங்க file இருக்குற folder தானான்னு உறுதி பண்ணுங்க:

| Command | Windows | Mac, Linux |
| --- | --- | --- |
| நான் எங்க இருக்கேன்? | PowerShell-ல `pwd` (VS Code default), Command Prompt-ல `cd` | `pwd` |
| இங்க இருக்குற files-ஐ list பண்ணு | `dir` | `ls` |
| ஒரு folder-க்குள்ள போ | `cd python-practice` | `cd python-practice` |
| ஒரு folder மேல போ | `cd ..` | `cd ..` |
| ஒரு file-ஐ run பண்ணு | `python hello.py` | `python3 hello.py` |

`python hello.py` type பண்ணி Enter அழுத்துங்க. Output கீழ தெரியும். Tip: Tab file names-ஐ complete பண்ணும், Up arrow கடைசி command-ஐ திரும்ப குடுக்கும்.

VS Code-ஓட Run button (மேல வலது பக்கம் இருக்குற முக்கோணம்) அதே command-ஐ உங்களுக்காக type பண்ணும். இருந்தாலும் type பண்ற command-ஐ கத்துக்கோங்க: servers, options, remote machines எல்லாத்துக்கும் அது தேவை.

### `>>>` prompt வேற ஒரு இடம்

File name இல்லாம வெறும் `python` (அல்லது `python3`) type பண்ணா, நீங்க **interactive shell**-க்குள்ள போவீங்க, அது `>>>` prompt-ஐ காட்டும். அது ஒரு நேரத்துல Python-ஓட ஒரு line-ஐ தான் run பண்ணும்; `2 + 3` அல்லது `len("Madurai")` மாதிரி சின்ன experiments-க்கு அது வசதி. ஆனா அதுக்கு Python மட்டும் தான் புரியும், terminal commands புரியாது. அங்க `python hello.py` type பண்ணா இது வரும்:

```text
>>> python hello.py
  File "<python-input-0>", line 1
    python hello.py
           ^^^^^
SyntaxError: invalid syntax
```

`exit()` type பண்ணி Enter அழுத்தி terminal-க்கு திரும்புங்க, அப்புறம் அங்க இருந்து உங்க file-ஐ run பண்ணுங்க.

### Error messages-ஐ படிங்க

ஏதாவது தப்பா இருந்தா, Python ஒரு error message print பண்ணும், பல நேரம் சிவப்புல. **கடைசி வரியை முதல்ல** படிங்க: அது error-ஓட பெயரை சொல்லும். அப்புறம் அதுக்கு மேல இருக்குற file name, line number-ஐ பாருங்க; Python சுட்டிக்காட்டுற பகுதிக்கு கீழ `^` marks போட்ட உங்க code-ஓட copy-ஐயும் பாருங்க.

Line 5-ல கடைசி bracket-ஐ delete பண்றீங்கன்னு வச்சுக்கோங்க. Python எதையும் run பண்றதுக்கு முன்னாடி முழு file-ஐயும் check பண்ணும், அதனால output எதுவுமே வராது, line 4-ஓடது கூட வராது:

```text
  File "C:\Users\priya\python-practice\hello.py", line 5
    print("Today is", date.today()
         ^
SyntaxError: '(' was never closed
```

திறந்து மூடாம விட்ட bracket-க்கு கீழ தான் `^` இருக்கு. மத்த தப்புகள் program run ஆகும்போது தான் தெரியும். Line 5-ல `date.todya()`-னு type பண்ணா, Python நிக்கும்போது line 4 ஏற்கனவே print ஆகியிருக்கும். இந்த முழு report-க்கு **traceback**-னு பேரு:

```text
Hello, my name is Priya
Traceback (most recent call last):
  File "C:\Users\priya\python-practice\hello.py", line 5, in <module>
    print("Today is", date.todya())
                      ^^^^^^^^^^
AttributeError: type object 'datetime.date' has no attribute 'todya'. Did you mean '.today' instead of '.todya'?
```

அது Python 3.15-ஓட wording; பழைய versions hint-ஐ கொஞ்சம் வேற மாதிரி சொல்லும். Python பல நேரம் fix-ஐயே suggest பண்ணும், அதனால line-ஓட கடைசி வரை படிங்க. ஒரு gotcha: line number-னா Python problem-ஐ **கவனிச்ச** இடம், அது எப்பவும் தப்பு இருக்குற இடமா தான் இருக்கும்னு இல்ல. உதாரணமா, ஒரு `if` line-க்கு அப்புறம் indent missing ஆனா, அது அதுக்கு கீழ இருக்குற line-ல report ஆகும், அதனால ஒரு line மேலயும் பாருங்க.

| Error | பொதுவான காரணம் |
| --- | --- |
| `SyntaxError` | ஒரு bracket, quote அல்லது colon missing, இல்லன்னா `>>>`-ல type பண்ண ஒரு terminal command |
| `IndentationError` | Indent பண்ணக்கூடாத ஒரு line indent ஆகியிருக்கு, இல்லன்னா tabs-உம் spaces-உம் கலந்திருக்கு |
| `NameError` | ஒரு variable-ஓட spelling தப்பு, இல்லன்னா உருவாக்குறதுக்கு முன்னாடியே ஒரு variable-ஐ use பண்றது |
| `AttributeError` | Dot-க்கு அப்புறம் வர்ற function அல்லது method பெயரோட spelling தப்பு |
| `ModuleNotFoundError` | நீங்க run பண்ற Python-ல install ஆகாத ஒரு package |
| `can't open file` | Terminal தப்பான folder-ல இருக்கு, இல்லன்னா file name தப்பு |

### Packages install பண்றது: இப்போவே ஒரு பழக்கம்

சீக்கிரமே நீங்க `requests` அல்லது `pandas` மாதிரி packages install பண்ணுவீங்க. உங்க files-ஐ run பண்ற அதே Python வழியா அவற்றை install பண்ணுங்க:

```text
python -m pip install requests
```

Mac-ல `python3 -m pip` use பண்ணுங்க. வெறும் `pip install` வேற ஒரு Python-ஓடதா இருக்கலாம்; அதனால தான் learners "இப்போ தான் install பண்ண" ஒரு package-க்கு `ModuleNotFoundError` பாக்குறாங்க. சமீபத்திய Ubuntu, Debian versions-ல system Python-க்குள்ள install பண்ணா `error: externally-managed-environment`-னு நின்னுடும். அதை force பண்ணி தாண்டாதீங்க; fix ஒரு virtual environment தான், அது "Packages-உம் virtual environments-உம்" lesson-ல (B3) வருது. அப்புறம் "Project tooling" lesson (B3) uv-ஐ காட்டும்; அது environments-ஐ உருவாக்கும், உங்களுக்காக Python-ஐயே கூட install பண்ண முடியும். உங்க `hello.py`-க்கு எந்த package-உம் தேவையில்ல.

### Python-ஐ run பண்ண மத்த வழிகள்

**Google Colab**, **Kaggle** மாதிரி online notebooks, எதுவும் install பண்ணாம browser-லயே Python-ஐ run பண்ணும். உங்க computer lock பண்ணியிருந்தா, பழசா இருந்தா, அல்லது பலர் share பண்றதா இருந்தா அவை உதவும். ரெண்டு எச்சரிக்கைகள்: அங்க நீங்க உருவாக்குற files session முடியும்போது காணாம போகலாம், அதனால உங்க வேலையை download பண்ணிக்கோங்க; அதோட, ஒவ்வொரு உண்மையான project-க்கும் தேவையான terminal, folder skills-ஐ notebook மறைச்சுடும். ஆரம்பிக்க அவற்றை use பண்ணுங்க, local setup-க்கு பதிலா இல்ல.

## ஒரு worked example

Madurai-ல இருக்குற commerce graduate Karthik, ஒரு நாள் சாயங்காலம் தன் Windows 11 laptop-ல Python set up பண்றாரு.

**Step 1: Store surprise.** எதையும் install பண்றதுக்கு முன்னாடி, PowerShell-ஐ திறந்து `python` type பண்றாரு. Microsoft Store திறக்குது. இந்த lesson-ல பாத்த Windows shortcut இதுன்னு அவருக்கு புரியுது; Store-ஐ close பண்ணி, அதுக்கு பதிலா Python-ஐ ஒழுங்கா install பண்றாரு.

**Step 2: install.** python.org/downloads-ல இருந்து Python install manager-ஐ install பண்ணி, ஒரு புது PowerShell window-வை திறந்து `py install 3.15` type பண்றாரு. அது latest Python 3.15-ஐ download பண்ணி install பண்ணுது.

**Step 3: புது terminal-ல check.** VS Code-ஐயும் அதோட Python extension-ஐயும் install பண்றாரு. VS Code terminal-ல `python --version`, `Python 3.15.2`-னு print பண்ணுது. ஒரு `python-practice` folder உருவாக்கி, File, Open Folder வச்சு அதை திறந்து, Python: Select Interpreter வச்சு 3.15-ஐ pick பண்றாரு.

**Step 4: முதல் error.** `C:\Users\karthik\python-practice`-ல தன் சொந்த பெயரோட `hello.py` எழுதுறாரு. அதை run பண்ண, Step 2-ல திறந்த தனி PowerShell window-ல `python hello.py` type பண்றாரு; அந்த window அவரோட home folder-ல திறந்திருந்துச்சு, அதனால fail ஆகுது. Message-ஓட கடைசி இப்படி இருக்கு:

```text
can't open file 'C:\\Users\\karthik\\hello.py': [Errno 2] No such file or directory
```

Double backslashes, Python ஒரு Windows path-ஐ print பண்ற விதம் தான். Python எங்க தேடுச்சுன்னு path சொல்லுது: `python-practice` இல்ல, அவரோட home folder. அவர் `cd python-practice` type பண்ணி, அப்புறம் `hello.py` அங்க இருக்கான்னு உறுதி பண்ண `dir` type பண்ணி, command-ஐ திரும்ப run பண்றாரு:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: save பண்ணாத change.** தன் பெயரை Tamil script-ல print பண்ற ஒரு line சேர்த்து file-ஐ run பண்றாரு. Output மாறல. அப்புறம் `hello.py` tab-ல dot இருக்குறதை கவனிக்கிறாரு: அவர் save பண்ணவே இல்ல. Ctrl+S அழுத்தி, திரும்ப run பண்றாரு, Tamil line வருது; ஏன்னா VS Code files-ஐ UTF-8-ஆ save பண்ணும், அதுல எந்த script-ஐயும் வைக்கலாம். அவர் Auto Save-ஐ on பண்றாரு.

**Step 6: உடைச்சு சரி பண்றது.** வேணும்னே line 5-ல கடைசி bracket-ஐ delete பண்ணி file-ஐ run பண்றாரு. Output எதுவும் வரல; கடைசி வரி `SyntaxError: '(' was never closed`-னு சொல்லுது, `^` `print`-க்கு அப்புறம் இருக்குற bracket-ஐ காட்டுது. Bracket-ஐ திரும்ப போட்டதும் அது run ஆகுது.

**Step 7: share.** ஒரு GitHub account உருவாக்கி, `hello.py`-ஐ ஒரு புது gist-ல paste பண்றாரு; அது share பண்ண ஒரு link குடுக்குது. அந்த link தான் இந்த lesson-ஓட check.

ஒரே சாயங்காலத்துல அவர் Store shortcut, தப்பான folder, save பண்ணாத file மூணையும் சந்திச்சாரு; ஒவ்வொண்ணையும் reinstall பண்ணாம, message-ஐ படிச்சே சரி பண்ணாரு.

## பொதுவா பண்ற தப்புகள்

- **முதல் error-லயே reinstall பண்றது.** பெரும்பாலான errors folder, PATH, அல்லது save பண்ணாத file பத்தினது தான்; உடைஞ்ச install பத்தினது இல்ல. கடைசி வரியை முதல்ல படிங்க.
- **பழைய terminal-ல test பண்றது.** Python install பண்ணின அப்புறமோ PATH-ஐ மாத்துன அப்புறமோ, VS Code-ஐ முழுசா close பண்ணி ஒரு புது terminal திறங்க.
- **Store shortcut-ஐ Python-னு நினைக்கிறது, அல்லது பழைய installer-ல PATH tick-ஐ விட்டுடுறது.** Install manager-ஐ use பண்ணுங்க.
- **தப்பான folder-ல இருந்து run பண்றது.** Run பண்றதுக்கு முன்னாடி `pwd`, `dir` அல்லது `ls` வச்சு check பண்ணுங்க.
- **Save பண்ணாத file-ஐ run பண்றது.** Tab-ல dot இருக்கான்னு பாருங்க, இல்லன்னா Auto Save-ஐ on பண்ணுங்க.
- **`>>>` prompt-ல terminal commands type பண்றது.** முதல்ல `exit()` type பண்ணுங்க.
- **File-ஐ `hello.py.txt`-ஆ save பண்றது.** File Explorer-ல file name extensions-ஐ on பண்ணுங்க.
- **பல Pythons இருக்குறது, VS Code வேற ஒண்ணை use பண்றது.** ஒரே ஒரு Python வச்சுக்கோங்க, Python: Select Interpreter வச்சு அதை தேர்ந்தெடுங்க.
- **வெறும் `pip install` use பண்றது.** `python -m pip install` use பண்ணுங்க, அப்போ தான் package உங்க code-ஐ run பண்ற Python-க்குள்ள போகும்.

## Practice பண்ணுங்க

கீழ link பண்ணியிருக்குற, உங்க operating system-க்கான Python for Everybody installation lesson-ஐ follow பண்ணுங்க. Interpreter-ஐ use பண்றது பத்தின Python-ஓட சொந்த tutorial page, அடுத்ததா படிக்க நல்லது.

இந்த lesson-ஓட check ஒரு சின்ன project:

1. **Install பண்ணி check பண்ணுங்க.** Python install பண்ணி, ஒரு புது terminal திறந்து, `python --version` (அல்லது `python3 --version`) 3-ல ஆரம்பிக்குதான்னு உறுதி பண்ணுங்க. Windows-ல `py list`-உம் run பண்ணுங்க.
2. உங்க பெயரையும் இன்னைக்கு date-ஐயும் print பண்ற `hello.py`-ஐ, சரியான interpreter தேர்ந்தெடுத்து VS Code-ல திறந்திருக்குற ஒரு `python-practice` folder-ல **எழுதுங்க**.
3. அதை terminal-ல command-ஐ type பண்ணி **run பண்ணுங்க**, Run button-ஐ மட்டும் வச்சு இல்ல.
4. அதை மூணு வழியில **உடைச்சு சரி பண்ணுங்க**: ஒரு bracket-ஐ delete பண்ணுங்க, line 4-ல `name`-ஓட spelling-ஐ தப்பா எழுதுங்க, ஒரு தடவை தப்பான folder-ல இருந்து run பண்ணுங்க. ஒவ்வொரு message-ஐயும் படிச்சு, fix பண்றதுக்கு முன்னாடி காரணத்தை சொல்லுங்க.
5. **Shell-ஐ visit பண்ணுங்க.** வெறும் `python` type பண்ணி, `2 + 3` try பண்ணி, அப்புறம் `exit()` வச்சு வெளிய வாங்க.
6. File-க்கான ஒரு link-ஐ **share பண்ணுங்க**, உதாரணம் ஒரு GitHub gist அல்லது repository.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** ஒரு புது `.py` file-ஐ உருவாக்கி, சரியான folder-ல இருக்குற terminal-ல அதை run பண்ணி, message-ஓட கடைசி வரியை படிச்சு ஒரு simple error-ஐ fix பண்ண முடியும்போது.
