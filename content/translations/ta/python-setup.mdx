## இது என்ன

Programs எழுதுறதுக்கு முன்னாடி, அதை எழுத ஒரு இடமும், run பண்ண ஒரு வழியும் வேணும். ஒரு student-ல இருந்து பெரிய company-ல இருக்குற AI engineer வரை, எல்லா Python programmers-உம் இதே மூணு விஷயங்களோட தான் வேலை செய்றாங்க:

| Tool | அது என்ன | Example |
| --- | --- | --- |
| **Python** | உங்க code-ஐ படிச்சு run பண்ற program | python.org-ல இருந்து Python 3 |
| **A code editor** | Code எழுதுற இடம்; தப்புகளை highlight பண்ணும், type பண்ண உதவும் | Visual Studio Code (VS Code), free |
| **A terminal** | Commands type பண்ற text window, உங்க file-ஐ run பண்ற command உட்பட | VS Code-க்குள்ள இருக்குற terminal |

இந்த மூணும் work ஆனதும், ஒவ்வொரு programmer-உம் வாழுற அந்த loop ஆரம்பிக்கும்:

```flow
dir: LR
File எழுது -> Run பண்ணு -> Output அல்லது error-ஐ படி -> Fix பண்ணு
Fix பண்ணு -[மறுபடி]-> File எழுது
```

இந்த lesson-ல Madurai-ல ஒரு commerce graduate Karthik-ஐ follow பண்றோம். அவர் தன் Windows laptop-ல Python set up பண்ணி, beginners-க்கு வர்ற ரெண்டு பொதுவான problems-ல மாட்டிக்கிறார். இதோட check ஒரு சின்ன project: உங்க சொந்த முதல் file-ஐ terminal-ல run பண்ணி, online-ல share பண்றது.

## இது எப்படி work ஆகுது

### Python install பண்ணுங்க

| Computer | எப்படி |
| --- | --- |
| Windows | python.org அல்லது Microsoft Store-ல இருந்து **Python install manager**-ஐ install பண்ணுங்க. அது `python`, `py` commands-ஐ set up பண்ணும். பழைய full installer use பண்ணா, அதோட முதல் screen-ல **"Add python.exe to PATH"**-ஐ tick பண்ணுங்க. |
| Mac | python.org-ல இருந்து installer-ஐ download பண்ணி run பண்ணுங்க. |
| Linux | Python 3 பெரும்பாலும் ஏற்கனவே install ஆகியிருக்கும். |

பழைய full installer-ல PATH tick முக்கியம்: நீங்க `python`-னு type பண்ணும்போது terminal Python-ஐ கண்டுபிடிக்க அது உதவும். அது இல்லன்னா, Python-ஐ recognise பண்ணலைன்னு terminal சொல்லும்.

Terminal திறந்து இதை type பண்ணி install-ஐ check பண்ணுங்க:

```text
python --version
```

Mac, Linux-ல `python3 --version` type பண்ணுங்க. `Python 3.15.2` மாதிரி 3-ல ஆரம்பிக்குற version தெரியணும்.

### Editor install பண்ணுங்க

VS Code-ஐயும் அதோட **Python extension**-ஐயும் install பண்ணுங்க. அப்புறம் `python-practice` மாதிரி உங்க வேலைக்கு ஒரு folder உருவாக்கி, File, Open Folder-ல திறங்க. ஒவ்வொரு project-ஐயும் அதுக்குன்னு தனி folder-ல வச்சா, அப்புறம் நிறைய குழப்பம் வராது.

### உங்க முதல் file-ஐ எழுதுங்க

அந்த folder-ல `hello.py`-ன்னு ஒரு file உருவாக்குங்க:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

`.py` ending தான் இது Python code-ன்னு Python-க்கும் editor-க்கும் சொல்லுது.

### Terminal-ல run பண்ணுங்க

VS Code-க்குள்ள View, Terminal வழியா terminal-ஐ திறங்க. Terminal எப்பவும் ஒரு folder-ல தான் "வேலை செய்யும்". அது உங்க file இருக்குற folder தானான்னு உறுதி பண்ணுங்க:

| Command | Windows | Mac, Linux |
| --- | --- | --- |
| நான் எங்க இருக்கேன்? | PowerShell-ல `pwd` (VS Code default), Command Prompt-ல `cd` | `pwd` |
| இங்க இருக்குற files-ஐ list பண்ணு | `dir` | `ls` |
| ஒரு folder-க்குள்ள போ | `cd python-practice` | `cd python-practice` |
| ஒரு folder மேல போ | `cd ..` | `cd ..` |
| ஒரு file-ஐ run பண்ணு | `python hello.py` | `python3 hello.py` |

`python hello.py` type பண்ணி Enter அழுத்துங்க. Output கீழ தெரியும்.

### Error messages-ஐ படிக்கிறது

ஏதாவது தப்பா இருந்தா, Python ஒரு **traceback**-ஐ print பண்ணும். **கடைசி வரியை முதல்ல** படிங்க: அது error-ஓட பெயரை சொல்லும். அதுக்கு மேல இருக்குற line number, Python எங்க problem-ஐ கவனிச்சதுன்னு காட்டும்.

```text
  File "hello.py", line 4
    print("Today is", date.today()
                                  ^
SyntaxError: '(' was never closed
```

Beginners-க்கு வர்ற பெரும்பாலான errors இவற்றுல ஒண்ணு:

| Error | பொதுவான காரணம் |
| --- | --- |
| `SyntaxError` | Bracket, quote அல்லது colon விட்டுப்போச்சு |
| `IndentationError` | Indentation தப்பு அல்லது கலந்திருக்கு |
| `NameError` | Variable பெயர் தப்பா எழுதியிருக்கு, அல்லது உருவாக்குறதுக்கு முன்னாடியே use பண்ணியிருக்கு |
| `can't open file` | Terminal தப்பான folder-ல இருக்கு, அல்லது file பெயர் தப்பு |

### Python-ஐ run பண்ண மத்த வழிகள்

**Google Colab**, **Kaggle** மாதிரி online notebooks எதுவும் install பண்ணாம, browser-லயே Python-ஐ run பண்ணும். உங்க computer lock பண்ணியிருந்தா அல்லது பழசா இருந்தா, data வேலைக்கும் இவை useful. இருந்தாலும், terminal-ல files-ஐ run பண்ண கத்துக்கோங்க: real projects, servers, AI applications எல்லாம் அப்படித்தான் ஓடுது.

## ஒரு worked example

Madurai-ல ஒரு commerce graduate Karthik, ஒரு நாள் சாயங்காலம் தன் Windows laptop-ல Python set up பண்றார்.

**Step 1: install.** python.org-ல இருந்து full installer-ஐ download பண்றார், "Add python.exe to PATH"-ஐ tick பண்ணி install பண்றார். (Python install manager-உம் work ஆகும், அதுக்கு tick தேவையில்ல.)

**Step 2: check.** புது terminal-ல `python --version` `Python 3.15.2`-ஐ print பண்ணுது. PATH tick-ஐ மறந்திருந்தா, இங்க தான் "python is not recognized"-ன்னு பார்த்திருப்பார்.

**Step 3: editor, file.** VS Code, Python extension install பண்றார், `python-practice` folder உருவாக்கி, மேல இருக்குற code-ஐ தன் சொந்த பெயரோட `hello.py`-ல எழுதுறார்.

**Step 4: முதல் error.** `python hello.py` type பண்ணா இது தெரியுது:

```text
python: can't open file 'C:\Users\karthik\hello.py': [Errno 2] No such file or directory
```

Terminal `python-practice`-ல இல்ல, அவரோட home folder-ல இருந்துச்சு. `cd python-practice` type பண்ணிட்டு, command-ஐ மறுபடி run பண்றார். இப்போ work ஆகுது:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: ஒரு மாற்றம்.** தன் பெயரை Tamil script-லயும் print பண்ற ஒரு வரியை சேர்த்து, மறுபடி run பண்றார். VS Code files-ஐ UTF-8-ல save பண்றதால, அது சரியா print ஆகுது.

| Problem | அவர் பார்த்த message | Fix |
| --- | --- | --- |
| Terminal தப்பான folder-ல | `can't open file ... No such file or directory` | `cd python-practice` |
| (தவிர்த்தது) PATH set ஆகல | `python is not recognized` | PATH box-ஐ tick பண்ணி reinstall பண்ணுங்க |

கடைசியா, GitHub account உருவாக்கி, `hello.py`-ஐ ஒரு புது repository-ல போடுறார், அப்போ share பண்ண ஒரு link இருக்கும். அந்த link தான் இந்த lesson-ஓட check.

## பொதுவா பண்ற தப்புகள்

- **பழைய Windows installer-ல "Add to PATH" மறந்துடுறது.** அப்போ Python கிடைக்கலைன்னு terminal சொல்லும். Box-ஐ tick பண்ணி reinstall பண்ணி, புது terminal திறங்க.
- **தப்பான folder-ல இருந்து run பண்றது.** Run பண்றதுக்கு முன்னாடி `pwd` (Command Prompt-ல `cd`) வச்சு எங்க இருக்கீங்கன்னு check பண்ணுங்க.
- **File-ஐ .txt ending-ஓட save பண்றது.** அது `.py`-ல முடியணும். Windows-ல "show file extensions"-ஐ on பண்ணா பார்க்கலாம்.
- **Red text பார்த்து பதறுறது.** Error-ஓட கடைசி வரியையும் line number-ஐயும் படிங்க.
- **Tabs, spaces-ஐ கலக்குறது.** Indent பண்றதை editor-கிட்ட விடுங்க.
- **ஒரே நேரத்துல நிறைய Python versions install பண்றது.** ஆரம்பிக்க சமீபத்திய ஒரு Python 3 போதும்.

## Practice பண்ணுங்க

கீழே link பண்ணியிருக்குற, உங்க operating system-க்கான Python for Everybody installation lesson-ஐ follow பண்ணுங்க.

இந்த lesson-ஓட check ஒரு சின்ன project:

1. **எழுதுங்க:** உங்க பெயரையும் இன்னைக்கு date-ஐயும் print பண்ற `hello.py`.
2. **Run பண்ணுங்க:** editor-ஓட run button வச்சு மட்டும் இல்ல, terminal-ல run பண்ணுங்க.
