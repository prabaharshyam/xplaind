## இது என்ன

"Smart software"-ஐ சொல்ல மக்கள் மூணு வார்த்தைகளை ஒரே அர்த்தத்துல use பண்றாங்க: **artificial intelligence**, **machine learning**, **large language model**. இது மூணும் ஒண்ணு கிடையாது. இந்த வித்தியாசம் தெரியுதான்னு தான் interviewer, client, உங்க manager முதல்ல check பண்ணுவாங்க.

ஒண்ணுக்குள்ள ஒண்ணா இருக்குற மூணு வட்டங்களை யோசிச்சு பாருங்க:

```flow
title: ஒவ்வொரு வட்டமும் முந்தைய வட்டத்துக்குள்ள இருக்கு
Artificial intelligence (AI) | மனுஷங்க தான் செய்யணும்னு நினைச்ச வேலைகளை செய்யுற software -> Machine learning (ML) | examples-ல இருந்து rules-ஐ கத்துக்கும்
Machine learning (ML) -> Large language models (LLMs) | text-ல கத்துக்கும், text எழுதும்
```

- **Artificial intelligence (AI)** தான் பெரிய goal: மனுஷ judgement தேவைன்னு நாம நினைச்ச வேலைகளை செய்யுற software. முகத்தை அடையாளம் காணுறது, Tamil-ல இருந்து English-க்கு translate பண்றது, ஒரு பாட்டை recommend பண்றது, கேள்விக்கு பதில் சொல்றது, இது எல்லாமே AI வேலைகள் தான்.
- **Machine learning (ML)** தான் இன்னைக்கு AI build பண்ற முக்கியமான வழி. ஒவ்வொரு rule-ஐயும் ஒரு ஆள் எழுதுறதுக்கு பதிலா, program-க்கு நிறைய examples-ஐ காட்டுவோம்; அது தானே pattern-ஐ கத்துக்கும்.
- **Large language model (LLM)** ஒரு வகையான machine learning model. ரொம்ப அதிகமான text-ல train பண்ணி, அடுத்து என்ன வரும்னு predict பண்ண வச்சிருக்காங்க. ChatGPT, Claude, Gemini எல்லாம் LLM மேல build பண்ண products.

அப்போ எல்லா LLM-உம் machine learning, எல்லா machine learning-உம் AI. ஆனா தலைகீழா சொல்ல முடியாது. உங்க UPI app-ல வர்ற fraud alert machine learning தான், ஆனா language model கிடையாது. 1990-கள்ல வந்த ஒரு chess program கையால எழுதுன search rules-ஐ follow பண்ணுச்சு; அது AI தான், ஆனா அதுல machine learning இல்லை.

இந்த lesson-ல Pune-ல 200 பேர் வேலை செய்யுற ஒரு company-ல HR பார்க்குற Asha-வோட ஒரு சாதாரண வேலை நாளை follow பண்ணப் போறோம். Lesson முடியும் போது, அவங்க பார்க்குற ஒவ்வொரு "AI" விஷயத்தையும் சரியான வட்டத்துல போட முடியும், language model எப்படி எழுதுதுன்னு explain பண்ண முடியும், அது ஏன் சில நேரம் தப்பா சொல்லுதுன்னு சொல்ல முடியும்.

## இது எப்படி work ஆகுது

### Rules vs learning

Machine learning-க்கு முன்னாடி, software ஒரு ஆள் எழுதுன rules-ஐ தான் follow பண்ணுச்சு. Asha-வோட company expense system-ல இப்படி ஒரு rule இருக்கு:

```text
IF amount > 5,000 rupees AND receipt missing
THEN send to manager for approval
```

Rules clear-ஆ, predictable-ஆ இருக்கும். ஆனா ஒவ்வொரு case-ஐயும் யாராவது யோசிச்சு எழுதணும். Fraud, முகங்கள், மொழி இதுக்கெல்லாம் cases ரொம்ப அதிகம்; யாராலும் எல்லாத்தையும் எழுதி வைக்க முடியாது.

Machine learning இந்த வேலையை தலைகீழா மாத்துது. பதில் ஏற்கனவே தெரிஞ்ச examples-ஐ சேர்க்குறோம், program அதுல இருக்குற pattern-ஐ கண்டுபிடிக்குது:

```flow
dir: LR
பதிலோட examples | payment 1: genuine, payment 2: fraud ... இன்னும் 1 crore -> Training | pattern-ஐ கத்துக்குது
Training -> ஒரு model | புது payment உள்ள, "fraud: 0.93" வெளியே
```

கடைசியில கிடைக்கிறது ஒரு **model**: input-ஐ output-ஆ மாத்துற, கத்துக்கிட்ட numbers நிறைஞ்ச ஒரு file. ஒரு bank-ஓட fraud model உங்க exact payment-ஐ பார்த்ததே இல்லை, ஆனா அதே மாதிரி லட்சக்கணக்கான payments-ஐ பார்த்திருக்கு; அதனால நல்லா guess பண்ணும். ஆனா அதோட examples எவ்வளவு நல்லதோ, அவ்வளவு தான் அதுவும். ஒரு குறிப்பிட்ட வகை fraud examples-லயே இல்லைன்னா, model அதை miss பண்ணிடும்.

| | Rule-based software | Machine learning |
| --- | --- | --- |
| Logic-ஐ யார் முடிவு பண்றாங்க | ஒரு ஆள் எழுதுறாங்க | Examples-ல இருந்து கத்துக்குது |
| எதுல strong | Tax slabs மாதிரி clear, மாறாத rules | முகம், fraud, மொழி மாதிரி தெளிவில்லாத patterns |
| தப்பா போனா | Rule தப்பு; rule-ஐ fix பண்ணுங்க | Examples குறைவு அல்லது bias; data-வை fix பண்ணுங்க |
| ஒரு முடிவை explain பண்றது | ஈஸி: rule-ஐ காட்டலாம் | கஷ்டம்: pattern நிறைய numbers-ல பரவி இருக்கு |

### Language model எப்படி எழுதுது

Large language model-னா text-க்கு apply பண்ண machine learning. Training-ல அது ரொம்ப அதிகமான எழுத்துக்களை படிக்குது: books, websites, code, forum posts. அதோட ஒரே வேலை, அடுத்து வர்ற சின்ன text துண்டை guess பண்றது; அதுக்கு பேரு **token**. ஒரு token பெரும்பாலும் ஒரு முழு சின்ன வார்த்தை ("the"), சில நேரம் பெரிய வார்த்தையோட ஒரு பகுதி ("under" + "stand" + "ing").

Training முடிஞ்சதும், நீங்க கேள்வி கேட்டா model ஒரு நேரத்துல ஒரு token-ஆ பதிலை எழுதும்:

```text
Prompt: "The capital of Karnataka is"

Step 1: likely next tokens ->  " Bengaluru" 0.86 | " Bangalore" 0.12 | " Mysuru" 0.01
Step 2: picks " Bengaluru", adds it, and asks again ->  "." 0.71 | "," 0.20 ...
Step 3: keeps going until the answer is complete
```

Generation-னா இவ்வளவு தான்: predict பண்ணு, ஒண்ணை எடு, சேர்த்துக்கோ, மறுபடியும் பண்ணு. போதுமான data-வும் பெரிய model-உம் இருந்தா, இந்த simple skill-ஏ summaries, translations, emails, code, step-by-step explanations எல்லாம் உருவாக்குது. ஏன்னா மனுஷங்க எழுதுனதுல இந்த patterns எல்லாமே இருக்கு.

### இது என்ன பண்ணாது

தினமும் ஞாபகம் வச்சுக்க வேண்டிய மூணு limits:

1. **இது facts-ஐ தேடி பார்க்காது.** Product அதை web search-ஓடயோ உங்க documents-ஓடயோ connect பண்ணியிருந்தா தவிர, training-ல கத்துக்கிட்ட patterns-ல இருந்து தான் பதில் சொல்லும். அதுக்குள்ள உண்மையான facts-ஓட database எதுவும் இல்லை.
2. **இதுக்கு ஒரு knowledge cut-off இருக்கு.** Training data சேர்த்ததுக்கு அப்புறம் நடந்தது இதுக்கு தெரியாது, product புது தகவல் கொடுத்தா தவிர.
3. **இது தன்னைத் தானே check பண்ணிக்காது.** எது likely-ஓ அதை எழுதும், எது verified-ஓ அதை இல்லை. அதனால smooth-ஆ, confident-ஆ இருக்குற, ஆனா தப்பான text-ஐ கூட எழுதும். இதுக்கு பேரு **hallucination**.

### Model vs product

இன்னொரு வித்தியாசத்துல நிறைய பேர் குழம்புவாங்க. **Model**-னா train பண்ண numbers-ஓட file. **Product**-னா அதை சுத்தி இருக்குற app: chat window, search tool, memory feature, safety filters. ஒரு chat assistant "web-ல search பண்ணுது"ன்னா, அது product ஒரு search tool-ஐ கூப்பிட்டு, results-ஐ model-க்கு கொடுக்குது. மக்கள் "ChatGPT vs Claude"ன்னு compare பண்ணும்போது, வேற வேற models மேல build பண்ண products-ஐ தான் compare பண்றாங்க.

## ஒரு நாள், ஒரு example

இதோ Asha-வோட Monday. ஒவ்வொரு AI-யையும் அதோட வட்டத்துல போட்டிருக்கோம்.

**காலை 8:40, spam filter (machine learning, LLM இல்லை).** அவங்க inbox "வீட்ல இருந்தே வாரம் ₹50,000 சம்பாதிங்க!"ங்குற fake job offer-ஐ spam-க்கு அனுப்புது. மக்கள் spam / not spam-ன்னு mark பண்ண லட்சக்கணக்கான emails-ல இருந்து filter கத்துக்கிச்சு. அது ஒரு label கொடுக்குது, text இல்லை.

**காலை 9:05, face unlock (machine learning, LLM இல்லை).** புது கண்ணாடி போட்டிருந்தாலும் phone அவங்களை அடையாளம் காணுது. Images-ல train பண்ண ஒரு model எந்த features முக்கியம்னு கத்துக்கிச்சு.

**காலை 10:15, payroll formula (AI இல்லை).** ஒரு spreadsheet overtime-ஐ கூட்டுது. ஒரு ஆள் exact formula-வை எழுதினாங்க; எதுவும் கத்துக்கப்படல.

**காலை 11:00, chat assistant (LLM).** Asha கேக்குறாங்க: "எங்க புது hybrid work policy-க்கு friendly-ஆ ஒரு announcement draft பண்ணு: வாரம் மூணு நாள் office, December 1-ல இருந்து."

Draft நல்லா இருக்கு. அன்பா, clear-ஆ, நல்ல structure-ஓட இருக்கு. ஆனா அதுல இந்த வரியும் இருக்கு: "Shops and Establishments Act-படி, எந்த policy மாற்றத்துக்கும் employees-க்கு 30 நாள் notice கொடுக்கணும்."

கேக்க official-ஆ இருக்கு. Asha company lawyer கிட்ட check பண்றாங்க. Maharashtra-க்கு இந்த claim சரியில்லை, இங்க எந்த law-வையும் quote பண்ண தேவையில்லைன்னு lawyer சொல்றாங்க. Asha அந்த வரியை delete பண்றாங்க.

| வேலை | AI இல்லாம நேரம் | AI-ஓட நேரம் |
| --- | --- | --- |
| முதல் draft எழுதுறது | சுமார் 45 நிமிஷம் | 2 நிமிஷம் |
| Facts, tone check பண்றது | 5 நிமிஷம் | 10 நிமிஷம் |
| மொத்தம் | சுமார் 50 நிமிஷம் | சுமார் 12 நிமிஷம் |

Assistant அவங்களுக்கு அரை மணி நேரத்துக்கு மேல மிச்சப்படுத்துச்சு, ஆனா அவங்க check பண்ணதால மட்டும் தான். வேகமா draft, கவனமா check: professionals language models-ஐ இப்படித்தான் use பண்றாங்க.

**மதியம் 3:30, fraud alert (machine learning, LLM இல்லை).** புது account-க்கு போற ₹49,000 payment-ஐ bank app நிறுத்தி OTP கேக்குது. Fraud model அந்த payment-ஐ வித்தியாசமானதுன்னு score பண்ணுச்சு. அது genuine payment தான்; அதனால இது false positive, hallucination இல்லை. Model text-ஐ கற்பனை பண்ணல; தப்பா ஒரு yes/no சொல்லிடுச்சு, அவ்வளவு தான்.

## பொதுவா பண்ற தப்புகள்

- **AI, ML, LLM-ஐ ஒரே வார்த்தையா use பண்றது.** இது ஒண்ணுக்குள்ள ஒண்ணு. ஒரு vendor "எங்க AI"ன்னு சொன்னா, எந்த வகைன்னு கேளுங்க. Rules engine, fraud model, chat assistant மூணுக்கும் data, testing, budget எல்லாமே ரொம்ப வேற.
- **Language model தேடி பார்க்குதுன்னு நினைக்கிறது.** Product search பண்ணுதுன்னோ உங்க documents use பண்ணுதுன்னோ சொல்லலைன்னா, அது patterns-ல இருந்து generate பண்ணுது. "அது சொல்லுச்சு"ங்குறது ஒரு source கிடையாது.
- **Confidence-ஐ நம்புறது.** Smooth-ஆன tone accuracy பத்தி எதுவும் சொல்லாது. Numbers, laws, பெயர்கள், dates, சமீபத்திய விஷயங்கள் இதுல ரொம்ப கவனமா இருங்க.
- **எல்லா தப்பையும் hallucination-ன்னு சொல்றது.** Hallucination-னா generative model கற்பனையா உருவாக்குற content. Fraud model genuine payment-ஐ block பண்ணா அது false positive; spam filter spam-ஐ miss பண்ணா அது false negative.
- **Model மனுஷன் மாதிரி புரிஞ்சுக்குதுன்னு நினைக்கிறது.** ஒரு கஷ்டமான idea-வை super-ஆ explain பண்ணிட்டு, கொஞ்சம் வித்தியாசமா கேட்ட ஒரு simple கேள்விக்கு fail ஆகலாம். நம்புறதுக்கு முன்னாடி உங்க real வேலையில test பண்ணுங்க.
- **Model-ஐயும் product-ஐயும் குழப்பிக்கிறது.** ஒரே model ரெண்டு apps-ல ரொம்ப வேற மாதிரி behave பண்ணலாம்; அதை சுத்தி இருக்குற tools, instructions, safety settings தான் காரணம்.

## Practice பண்ணுங்க

கீழே link பண்ணியிருக்குற large language models intro-வை பாருங்க; maths இல்லாம training, generation-ஐ clear-ஆ explain பண்ணுது. அப்புறம் இந்த மூணு tasks-ஐ பண்ணுங்க.

1. **உங்க வாரத்தை பிரிச்சு பாருங்க.** கடந்த வாரம் நீங்க use பண்ண 5 AI features-ஐ list பண்ணுங்க: maps, spam filter, payment app, voice typing, ஒரு recommendation, ஒரு chat assistant. ஒவ்வொண்ணும் எந்த வட்டம், அது என்ன output கொடுக்குது (label, score, route, text)ன்னு எழுதுங்க.
2. **ஒரு hallucination-ஐ பிடிங்க.** ஒரு chat assistant கிட்ட உங்க ஊர் அல்லது உங்க field பத்தி numbers இருக்குற மூணு facts கேளுங்க: population, தொடங்கின வருஷம், ஒரு statistic. ஒவ்வொண்ணையும் ஒரு official source-ல check பண்ணுங்க. எது தப்பு, அது எவ்வளவு confident-ஆ சொல்லுச்சுன்னு note பண்ணுங்க.
3. **சத்தமா explain பண்ணுங்க.** Token, predict, hallucination இந்த வார்த்தைகளை use பண்ணி, language model எப்படி பதில் எழுதுதுன்னு ஒரு friend-க்கு ரெண்டு நிமிஷத்துல explain பண்ணுங்க. Record பண்ணி திரும்ப கேளுங்க.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** AI, machine learning, language model மூணுக்கும் இருக்குற வித்தியாசத்தை simple-ஆ explain பண்ண முடியும், ஒவ்வொண்ணுக்கும் தினசரி வாழ்க்கையில ஒரு example சொல்ல முடியும், language model ஏன் confident-ஆ தப்பா சொல்லும்னு சொல்ல முடியும்.
