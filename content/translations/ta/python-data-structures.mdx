## இது என்ன

Programs அபூர்வமா தான் ஒரு நேரத்துல ஒரு value-வோட வேலை செய்யும். ஒரு நாளுக்கு நிறைய orders, ஒரு class-க்கு நிறைய students, ஒரு கடைக்கு நிறைய products. Python-ஓட ரெண்டு workhorse collections நிறைய values-ஐ வச்சிருக்கும்:

- **Lists** ordered sequences; position வச்சு எடுக்கலாம். "ஒரே வகையான நிறைய விஷயங்கள், order-ல" க்கு நல்லது: ஒரு நாளோட orders, marks list.
- **Dictionaries** key, value lookups. "இந்த key-க்கான value-ஐ சீக்கிரம் கண்டுபிடி" க்கு நல்லது: roll number வச்சு marks, field name வச்சு ஒரு customer-ஓட details.

இன்னும் ரெண்டு அடிக்கடி வரும்:

- **Tuples** மாத்த முடியாத fixed sequences; latitude, longitude pair மாதிரி.
- **Sets** unique items-ஓட order இல்லாத collections; duplicates-ஐ நீக்க கைகொடுக்கும்.

| Type | உதாரணம் | Value-ஐ எப்படி எடுக்குறது |
|---|---|---|
| list | `["Pune", "Kochi", "Jaipur"]` | Position வச்சு: `[0]`, `[1]`, `[2]` |
| dict | `{"K101": 78, "K102": 64}` | Key வச்சு: `["K101"]` |
| tuple | `(18.52, 73.86)` | மாத்த முடியாத ஒரு fixed pair |
| set | `{"a@x.in", "b@y.in"}` | Unique values, order இல்லை |

இவற்றை ஒண்ணுக்குள்ள ஒண்ணா வச்சா, பெரும்பாலான real data-வை model பண்ணலாம். Dictionaries-ஓட ஒரு list ஒரு table; ஒவ்வொரு dictionary-யும் ஒரு row. APIs, AI models திருப்பி அனுப்புற **JSON**-ஓட shape-உம் இதே தான்; அதனால nested lists, dictionaries-ஓட comfortable-ஆ இருக்கிறது ஒரு core AI skill.

இந்த lesson Kota-ல ஒரு coaching centre-ஓட office, test results list-ஐ parents-க்கு உடனடி பதில்களா மாத்துறதை follow பண்ணும். முடிக்கும் போது, ஒரு வேலைக்கு சரியான structure-ஐ தேர்ந்தெடுக்கவும், nested data-வை ஈஸியா படிக்கவும் முடியும்.

## இது எப்படி work ஆகுது

### Lists

```python
nums = [3, 1, 2]
nums.append(5)            # [3, 1, 2, 5]
print(len(nums))          # 4
print(nums[0], nums[-1])  # 3 5   (first and last)
print(sorted(nums))       # [1, 2, 3, 5]
print(nums[1:3])          # [1, 2]  (a slice: from position 1 up to, not including, 3)
```

`for n in nums:` வச்சு loop பண்ணுங்க. **List comprehension** வச்சு புது lists-ஐ build பண்ணுங்க; அது ஒரு list-ஐ உருவாக்குற சுருக்கமான loop:

```python
doubled_big = [n * 2 for n in nums if n > 1]    # [6, 4, 10]
```

### Dictionaries

```python
marks = {"asha": 80, "ravi": 72}
marks["meena"] = 91              # add a new key
print(marks["asha"])             # 80
print(marks.get("john", 0))      # 0: a default instead of an error
for name, score in marks.items():
    print(name, score)
```

Square brackets வச்சு இல்லாத key-ஐ தேடுனா `KeyError` வரும்; `get` அதுக்கு பதிலா ஒரு default தரும். Millions entries இருந்தாலும், key வச்சு தேடுறது வேகம்; ஏன்னா dictionary தேடாம, நேரா அந்த key-க்கு தாவுது.

### சரியானதை தேர்ந்தெடுக்குறது

| உங்களுக்கு வேண்டியது | Use பண்ணுங்க | உதாரணம் |
| --- | --- | --- |
| Order, அல்லது position வச்சு எடுக்குறது | List | Customers-ஓட ஒரு queue |
| ஒரு identifier வச்சு தேடுறது | Dictionary | Product code வச்சு price |
| Unique items, "இது இங்க இருக்கா?"ன்னு வேகமா check பண்றது | Set | Unique email addresses |
| Values-ஓட ஒரு சின்ன fixed group | Tuple | ஒரு கடையோட coordinates |
| Records-ஓட ஒரு table | Dictionaries-ஓட list | இன்னைக்கு sales |
| ஒரு category வச்சு group பண்ண values | Lists-ஓட dictionary | City வச்சு students |

### List-ல தேடுறது ஏன் மெதுவு

```flow
dir: LR
title: 10,000 records-ல roll "K9000"-ஐ கண்டுபிடிங்க
List-ல -> [0], [1], [2] ... ஒண்ணு ஒண்ணா check பண்ணு -> 10,000 checks வரைக்கும்
Roll-ஐ key-ஆ வச்ச dictionary-ல -> நேரா "K9000"-க்கு தாவு -> கிட்டத்தட்ட 1 step
```

ஒரே வகை identifier-ஐ நிறைய தடவை தேடுறீங்கன்னா, ஒரு தடவை ஒரு dictionary-ஐ build பண்ணி, திரும்ப use பண்ணுங்க.

### Nesting

```python
cities = {
    "Pune":   [{"name": "Asha", "marks": 80}],
    "Nagpur": [{"name": "Ravi", "marks": 72}, {"name": "Meena", "marks": 91}],
}
print(cities["Nagpur"][1]["name"])     # Meena
```

Nested access-ஐ இடமிருந்து வலமா படிங்க: "Nagpur" list, அதோட ரெண்டாவது item, அந்த item-ஓட "name".

### JSON-ல இருந்து Python-க்கு, திரும்பவும்

ஒரு API அல்லது AI model JSON-ஐ திருப்பி தரும்போது, Python-ஓட `json` module அதை lists, dictionaries-ஆ மாத்தும், திரும்பவும் மாத்தும்:

```python
import json
text = '{"city": "Pune", "pins": ["411001", "411002"]}'
data = json.loads(text)          # now a dictionary
print(data["pins"][0])           # 411001
print(json.dumps(data, indent=2))  # back to neatly formatted JSON text
```

JSON objects dictionaries ஆகும், JSON arrays lists ஆகும், `true`, `false` `True`, `False` ஆகும், `null` `None` ஆகும்.

### Copy பண்றது

`b = a` ஒரு list-ஐ copy **பண்ணாது**. ரெண்டு பேரும் ஒரே list-ஐ சுட்டும்; அதனால ஒண்ணை மாத்துனா, மற்றது பார்க்குறதும் மாறும்:

```python
a = [1, 2]
b = a
b.append(3)
print(a)          # [1, 2, 3]  surprise!
c = a.copy()      # a real copy
```

## ஒரு நாள், ஒரு example

Kota-ல ஒரு coaching centre test results-ஐ, ஒரு student-க்கு ஒண்ணுன்னு records-ஓட ஒரு list-ஆ வச்சிருக்கு:

```python
results = [
    {"roll": "K101", "name": "Asha",  "physics": 78, "chem": 85},
    {"roll": "K102", "name": "Ravi",  "physics": 64, "chem": 70},
    {"roll": "K103", "name": "Meena", "physics": 91, "chem": 88},
]

# 1. Look up by roll number quickly: build a dictionary once
by_roll = {r["roll"]: r for r in results}
print(by_roll["K102"]["name"])            # Ravi

# 2. Average per subject with a list comprehension
physics = [r["physics"] for r in results]
print(round(sum(physics) / len(physics), 1))   # 77.7

# 3. Group students by grade band
bands = {}
for r in results:
    total = r["physics"] + r["chem"]
    band = "A" if total >= 160 else "B"
    bands.setdefault(band, []).append(r["name"])
print(bands)                               # {'A': ['Asha', 'Meena'], 'B': ['Ravi']}
```

| Office-ல இருந்து வர்ற கேள்வி | பதில் சொல்ற structure | Code |
| --- | --- | --- |
| "Roll K102 எப்படி பண்ணாங்க?" | Roll-ஐ key-ஆ வச்ச dictionary | `by_roll["K102"]` |
| "Physics average என்ன?" | Physics marks-ஓட list | `sum(physics) / len(physics)` |
| "Band A-ல யாரெல்லாம் இருக்காங்க?" | Lists-ஓட dictionary | `bands["A"]` |

`setdefault(band, [])` அந்த band-க்கான list-ஐ திருப்பி தரும்; முதல் தடவை ஒரு empty list-ஐ உருவாக்கும். ஒவ்வொரு தடவையும் ஒரு `if` எழுதுறதை இது மிச்சப்படுத்தும்.

600 students இருக்குற ஒரு sheet-ல scroll பண்றதுக்கு பதிலா, "roll K102 எப்படி பண்ணாங்க?" மாதிரி parents-ஓட calls-க்கு office இப்போ உடனே பதில் சொல்லுது.

## பொதுவா பண்ற தப்புகள்

- **ஒரு id-க்காக list-ஐ திரும்ப திரும்ப தேடுறது.** ஒரு தடவை அந்த id-ஐ key-ஆ வச்ச ஒரு dictionary-ஐ build பண்ணுங்க.
- **இல்லாத keys-ல `KeyError`.** ஒரு key இல்லாம இருக்கலாம்ன்னா, default-ஓட `get`-ஐ use பண்ணுங்க.
- **Index out of range.** Lists 0-ல ஆரம்பிக்கும்; கடைசி item `[-1]`.
- **தெரியாம shared lists.** `b = a` ஒரு copy இல்லை; `a.copy()` use பண்ணுங்க.
- **Loop பண்ணிக்கிட்டே ஒரு list-ஐ மாத்துறது.** அதுக்கு பதிலா, உதாரணமா ஒரு comprehension வச்சு, ஒரு புது list-ஐ build பண்ணுங்க.
- **Sets order-ஐ வச்சிருக்கும்ன்னு எதிர்பார்க்குறது.** Order முக்கியம்ன்னா, result-ஐ sort பண்ணுங்க: `sorted(set(items))`.
