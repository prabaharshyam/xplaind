## இது என்ன

இந்த மூணு structures-உம் **items எப்படி உள்ள போகுது, வெளிய வருது**ங்குறதை பத்தினது.

**Stack** தட்டுகளை அடுக்கி வச்ச மாதிரி: மேல போடுவீங்க, மேல இருந்து எடுப்பீங்க. கடைசியா உள்ள போன item தான் முதல்ல வெளிய வரும், இதுக்கு **LIFO**ன்னு பேரு. Undo buttons, browser back buttons, programs function calls-ஐ track பண்ற விதம் எல்லாம் stacks தான்.

**Queue** railway ticket counter-ல நிக்குற line மாதிரி: ஆட்கள் பின்னாடி சேருவாங்க, முன்னாடி இருந்து போவாங்க. முதல்ல உள்ள போன item தான் முதல்ல வெளிய வரும், இதுக்கு **FIFO**ன்னு பேரு. Print jobs, customer support tickets, background tasks எல்லாம் queues.

**Linked list** nodes-ஓட ஒரு சங்கிலி. ஒவ்வொரு node-லயும் ஒரு value-உம் அடுத்த node-க்கு ஒரு pointer-உம் இருக்கும். மீதியை shift பண்ணாம, ரெண்டு pointers-ஐ மாத்தி எங்க வேணும்னாலும் ஒரு node-ஐ சேர்க்கலாம், நீக்கலாம்.

| Structure | எப்படி work ஆகுது | Example |
|---|---|---|
| Stack (LIFO) | மேல push, மேல இருந்து pop: last in, first out | A, B, C push; pop பண்ணா C கிடைக்கும் |
| Queue (FIFO) | பின்னாடி enqueue, முன்னாடி இருந்து dequeue: first in, first out | A, B, C enqueue; dequeue பண்ணா A கிடைக்கும் |
| Linked list | ஒவ்வொரு node-லயும் ஒரு value, அடுத்ததுக்கு ஒரு pointer | 9-க்கு அப்புறம் 7-ஐ insert: ரெண்டு pointers மட்டும் மாறும் |

```flow

head -> 5 -> 9 -> 7 | புது node -> 2 -> end
```

## இது எப்படி work ஆகுது

**Stacks**-க்கு ரெண்டு operations வேணும்: `push` (மேல சேர்க்க), `pop` (மேல இருந்து நீக்க). Python-ல சாதாரண list நல்லா work ஆகும்: `append` push பண்ணும், `pop()` pop பண்ணும், ரெண்டும் O(1). மேல இருக்குற item-ஐ நீக்காம `peek` பண்ணவும் செய்யலாம்.

**Queues**-க்கு `enqueue` (பின்னாடி சேர்க்க), `dequeue` (முன்னாடி இருந்து நீக்க) வேணும். Python list ஒரு மோசமான queue, ஏன்னா `pop(0)` ஒவ்வொரு item-ஐயும் shift பண்ணும், O(n). `collections.deque` use பண்ணுங்க, அது ஒரு double-ended queue; அதோட `append`, `popleft` ரெண்டும் O(1). Threads அல்லது programs இடையே share ஆகுற வேலைக்கு, ஒரு queue library அல்லது message queue service use பண்ணுவீங்க; அதை system design track-ல பார்ப்பீங்க.

**Linked lists** ஒவ்வொரு item-ஐயும், அடுத்ததை point பண்ற, தன்னோட node object-ல சேமிக்கும். உங்ககிட்ட ஏற்கனவே இருக்குற ஒரு node-க்கு அப்புறம் insert பண்ண, புது node-ஐ பழைய next node-க்கு point பண்ணி, பழைய node-ஐ புது node-க்கு point பண்ணுவீங்க: O(1). விலை என்னன்னா position வச்சு படிக்கிறது. Item 500-ஐ அடைய 500 pointers-ஐ follow பண்ணணும், O(n). Python-ல built-in linked list type இல்ல, ஏன்னா lists-உம் deques-உம் பெரும்பாலான தேவைகளை பூர்த்தி பண்ணும்; ஆனா இந்த idea interview problems-லயும் மத்த structures-க்குள்ளயும் வரும்.

| Structure | Add | Remove | Item k-ஐ படிக்க | எதுக்கு use பண்றது |
|---|---|---|---|---|
| Stack (list) | push O(1) | pop O(1) | மேல இருக்குறது மட்டும் | undo, bracket matching, DFS |
| Queue (deque) | append O(1) | popleft O(1) | முன்னாடி இருக்குறது மட்டும் | order-ல tasks, BFS |
| Linked list | தெரிஞ்ச node-ல O(1) | தெரிஞ்ச node-ல O(1) | O(n) | அடிக்கடி நடுவுல edits, LRU caches |
| Array (list) | கடைசில O(1) | முன்னாடி O(n) | O(1) | position வச்சு படிக்க |

**Interviews-ல** இந்த structures மத்த கேள்விகளுக்குள்ள ஒளிஞ்சிருக்கும். "Most recent", "undo", "nested", "matching pairs" இதெல்லாம் stack-ஐ காட்டும். "வந்த order-ல", "level by level", "tasks-ஐ நியாயமா process பண்ணு" இதெல்லாம் queue-வை காட்டும். Linked list கேள்விகள் பெரும்பாலும் pointer-ல கவனத்தை test பண்ணும்: ஒரு list-ஐ reverse பண்றது, slow, fast pointer வச்சு அதோட நடுவை கண்டுபிடிக்கிறது, அல்லது loop-ஐ கண்டுபிடிக்கிறது. முதல்ல paper-ல nodes-ஐயும் arrows-ஐயும் வரைங்க; பெரும்பாலான linked list bugs, ஒரு சின்ன sketch பிடிச்சிருக்கக்கூடிய, தொலைஞ்சு போன pointers தான்.

## ஒரு worked example

Ananya, Kota-ல coaching centres-ல use ஆகுற ஒரு maths quiz app-க்கு ஒரு சின்ன expression checker build பண்றாங்க. Students `(2+3)*[4-(1+1)]` மாதிரி answers type பண்றாங்க, app அவற்றை evaluate பண்றதுக்கு முன்னாடியே, brackets balanced இல்லாத answers-ஐ reject பண்ணணும்.

Stack சரியா பொருந்தும். ஒவ்வொரு opening bracket-ஐயும் அதுக்கு match ஆகுற closing bracket close பண்ணணும், கடைசியா திறந்தது தான் முதல்ல close ஆகணும், இது exactly LIFO.

```python
PAIRS = {")": "(", "]": "[", "}": "{"}

def balanced(text):
    stack = []
    for ch in text:
        if ch in "([{":
            stack.append(ch)                 # push
        elif ch in PAIRS:
            if not stack or stack.pop() != PAIRS[ch]:
                return False                 # nothing to close, or wrong type
    return not stack                         # anything left open?
```

`[(])`-ஐ trace பண்ணா: `[`-ஐ push, `(`-ஐ push, அப்புறம் `]` வந்து `(`-ஐ pop பண்ணுது, அது `[`-க்கு match ஆகல, அதனால `False` திருப்பும். `{[()()]}`-க்கு ஒவ்வொரு pop-உம் match ஆகி, stack கடைசில காலியா இருக்கு, அதனால `True`. Function ஒரு pass தான் எடுக்கும்: O(n) time, அதிகபட்சம் O(n) space.

அடுத்து, ஒரு live test-ல நூற்றுக்கணக்கான answers ஒரே நேரத்துல வந்தாலும், submit ஆன answers-ஐ வந்த order-லயே app mark பண்ணணும். Ananya ஒரு queue use பண்றாங்க:

```python
from collections import deque
pending = deque()
pending.append("answer-101")       # enqueue
pending.append("answer-102")
first = pending.popleft()          # "answer-101", O(1)
```

Fairness தானா வந்துடும்: எந்த student-ஓட answer-உம் line-ஐ தாண்டி முன்னாடி போகாது.

## பொதுவான தவறுகள்

**list.pop(0)-ஐ queue-வா use பண்றது.** சின்ன data-ல work ஆகும், நீண்ட ஓட்டத்துல O(n²) ஆயிடும். `deque.popleft()` use பண்ணுங்க.

**காலியான stack-ஐ pop பண்றது.** காலியான list-ல `pop()` call பண்ணா error வரும். Bracket checker பண்ற மாதிரி, முதல்ல `if stack` check பண்ணுங்க.

**கடைசி check-ஐ மறந்துடுறது.** `((` மாதிரி bracket string எந்த pop-லயும் fail ஆகாது, ஆனா அது balanced இல்ல. கடைசில stack காலியா இருக்கான்னு எப்பவும் check பண்ணுங்க.

**பழக்கத்துல linked list-ஐ எடுக்குறது.** Python-ல lists-உம் deques-உம் கிட்டத்தட்ட எல்லாத்துக்கும் வேகம். ஏற்கனவே உங்ககிட்ட இருக்குற nodes-ல மலிவான inserts, removals உண்மையிலேயே தேவைப்பட்டா மட்டும் linked list use பண்ணுங்க.

**Linked list-ஓட மீதியை தொலைச்சுடுறது.** Insert பண்ணும்போது, பழைய node-ஓட pointer-ஐ மாத்துறதுக்கு முன்னாடி புது node-ஐ next node-க்கு point பண்ணுங்க, இல்லன்னா சங்கிலி அறுந்துடும்.

**Graph search-ல stack-ஐயும் queue-வையும் குழப்பிக்கிறது.** Depth-first search stack (அல்லது recursion) use பண்ணும்; breadth-first search queue use பண்ணும். மாத்தினா வேற traversal கிடைக்கும்.
