## இது என்ன

**Neural network**-னா layers-ஓட ஒரு அடுக்கு. ஒவ்வொரு layer-உம் numbers-ஐ உள்ள வாங்கி, weights-ஆல பெருக்கி, ஒரு bias சேர்த்து, முடிவை **activation**-ன்னு சொல்ற ஒரு எளிமையான non-linear function வழியா அனுப்பும் (ReLU மாதிரி, அது negatives-ஐ பூஜ்யமா மாத்தும்). ஒரு layer-ஓட output அடுத்த layer-ஓட input. கடைசி layer prediction-ஐ தரும்: ஒரு number, அல்லது ஒவ்வொரு class-க்கும் probabilities.

போதுமான layers, units இருந்தா, networks ரொம்ப சிக்கலான patterns-ஐ represent பண்ணும். **Deep learning**-னா நிறைய layers உள்ள networks.

```flow
dir: LR
Inputs | 64 features -[weights]-> Hidden layer 1 | 128 units, ReLU
Hidden layer 1 -[weights]-> Hidden layer 2 | 64 units, ReLU
Hidden layer 2 -[weights]-> Output | 5 units, softmax: leaf spot 0.81
Output -[backpropagation: a gradient for every weight]-> Inputs
```

இந்த lesson-ல Bengaluru-ல ஒரு agritech startup, இலை photos-ஐ நோய் வாரியா classify பண்றதை follow பண்ணுவோம்.

## இது எப்படி work ஆகுது

**Forward pass.** Input features layers வழியா ஓடி ஒரு prediction உருவாகும்.

**Loss.** ஒரு loss function prediction எவ்வளவு தப்புன்னு அளக்கும்: numbers-க்கு mean squared error, classes-க்கு cross-entropy.

**Backpropagation.** Chain rule வச்சு, output-ல இருந்து பின்னோக்கி layer by layer, ஒவ்வொரு weight-உம் loss-க்கு எவ்வளவு காரணம்னு network compute பண்ணும். இதுல ஒவ்வொரு weight-க்கும் gradient கிடைக்கும்.

**Gradient descent.** ஒவ்வொரு weight-உம் அதோட gradient-க்கு எதிரா ஒரு சின்ன step நகரும். Adam மாதிரி variants ஒவ்வொரு weight-க்கும் step size-ஐ adapt பண்ணும், பொதுவா வேகமா train ஆகும். Training examples-ஓட **batches்**-ல நடக்கும்; எல்லா data வழியா ஒரு தடவை போறது ஒரு **epoch**.

**Non-linearity ஏன் முக்கியம்.** Activations இல்லாம, அடுக்கி வச்ச layers ஒரே linear model-ஆ சுருங்கிடும். Activations networks-ஐ வளைக்கவும் features-ஐ சேர்க்கவும் விடுது.

**Overfitting, regularisation.** நிறைய weights உள்ள networks training data-வை மனப்பாடம் பண்ணிடலாம். Training loss-ஐயும் validation loss-ஐயும் சேர்த்து பாருங்க: training loss தொடர்ந்து குறைஞ்சு validation loss ஏறுச்சுன்னா, network overfit ஆகுது. தீர்வுகள்: அதிக data, data augmentation, dropout (training-ல units-ஐ randomly off பண்றது), weight decay, சின்ன networks, early stopping.

**Practical settings.** Learning rate (மிக முக்கியம்), batch size, layers, units எண்ணிக்கை, epochs. உங்க problem வகைக்கு தெரிஞ்ச நல்ல defaults-ல இருந்து ஆரம்பிங்க.

**எப்போ use பண்றது.** Images, audio, text, ரொம்ப பெரிய datasets-ல neural networks ஆதிக்கம் செலுத்தும். சாதாரண tabular business data-க்கு, gradient-boosted trees பொதுவா குறைவான முயற்சில சமமா அல்லது நல்லா இருக்கும்.

**Weights-ஐ எண்ணுறது.** Layers-க்கு நடுவுல உள்ள ஒவ்வொரு connection-க்கும் ஒரு weight, ஒவ்வொரு unit-க்கும் ஒரு bias. இலை network-ல, முதல் hidden layer-க்கு 64 × 128 weights + 128 biases, அதாவது 8,320 numbers. ரெண்டாவதுக்கு 128 × 64 + 64 = 8,256, output layer-க்கு 64 × 5 + 5 = 325. மொத்தம் 16,901 numbers data-ல இருந்து கத்துக்கப்படுது. நவீன language models-ல பில்லியன் கணக்குல இருக்கும், ஆனா ஒவ்வொரு layer-லயும் கணக்கு அதே தான்.

**Loss curves-ஐ படிக்கிறது:**

| நீங்க பார்க்குறது | அர்த்தம் | என்ன try பண்றது |
| --- | --- | --- |
| Loss எகிறுது அல்லது வளருது | Learning rate ரொம்ப அதிகம் | 10 மடங்கு குறைங்க |
| Loss ரொம்ப மெதுவா குறையுது | Learning rate ரொம்ப குறைவு, அல்லது inputs scale பண்ணல | ஏத்துங்க; inputs-ஐ standardise பண்ணுங்க |
| Training குறையுது, validation ஏறுது | Overfitting | Dropout, weight decay, early stopping, அதிக data |
| ரெண்டும் உயரமாவே இருக்கு | Underfitting | பெரிய network, அதிக epochs, நல்ல features |
| ரெண்டும் சேர்ந்து குறைஞ்சு level ஆகுது | ஆரோக்கியமானது | Best validation epoch-ல நிறுத்துங்க |

**Training loop-ஐ வார்த்தைகள்ல.** ஒவ்வொரு epoch-க்கும் data-வை shuffle பண்ணி batches-ஆ பிரிங்க. ஒவ்வொரு batch-க்கும், forward pass ஓட்டுங்க, loss compute பண்ணுங்க, gradients பெற backpropagation ஓட்டுங்க, optimiser weights-ஐ update பண்ணட்டும். ஒவ்வொரு epoch-க்கு அப்புறமும், weights-ஐ update பண்ணாம validation loss compute பண்ணி, இதுவரை best-ஆ இருந்தா model-ஐ save பண்ணுங்க. PyTorch-ல இருந்து Keras வரை ஒவ்வொரு deep learning library-யும் இந்த pattern-ஐ தான் follow பண்ணும்.

**NumPy-ல scratch-ல இருந்து ஒரு network.** ஒரு குட்டி network-ஐ கையால build பண்ணா forward pass, loss, backpropagation, gradient descent எல்லாம் நேரா புரியும். இது XOR-ஐ கத்துக்குது, எந்த நேர் கோடும் அதை பிரிக்க முடியாது:

```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

W1, b1 = rng.normal(0, 1, (2, 8)), np.zeros((1, 8))
W2, b2 = rng.normal(0, 1, (8, 1)), np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))

def forward(X):
    h = np.tanh(X @ W1 + b1)              # hidden layer with a non-linearity
    return h, sigmoid(h @ W2 + b2)        # output probability

lr = 0.5
for step in range(3000):
    h, p = forward(X)
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))    # cross-entropy
    d_out = (p - y) / len(X)                       # gradient at the output (sigmoid + cross-entropy)
    dW2, db2 = h.T @ d_out, d_out.sum(0, keepdims=True)
    d_h = (d_out @ W2.T) * (1 - h ** 2)            # chain rule through tanh
    dW1, db1 = X.T @ d_h, d_h.sum(0, keepdims=True)
    W2 -= lr * dW2; b2 -= lr * db2; W1 -= lr * dW1; b1 -= lr * db1
    if step % 1000 == 0:
        print(f"step {step}: loss {loss:.3f}")

print("predictions:", forward(X)[1].round(2).ravel())     # close to 0, 1, 1, 0
```

ஒவ்வொரு framework-உம் இதே steps-ஐ தான் பண்ணும், தானியங்கியா, ரொம்ப பெரிய networks-ல.

**Backward pass-ஐ numerical-ஆ check பண்ணுங்க.** ஒரு weight-ஐ கொஞ்சம் தள்ளி loss எப்படி நகருதுன்னு பாருங்க; அது compute பண்ண gradient-ஓட பொருந்தணும்:

```python
def loss_of(W1_):
    h = np.tanh(X @ W1_ + b1); p = sigmoid(h @ W2 + b2)
    return -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))

h, p = forward(X)
d_h = (((p - y) / len(X)) @ W2.T) * (1 - h ** 2)
analytic = (X.T @ d_h)[0, 0]
eps = 1e-5
W_plus, W_minus = W1.copy(), W1.copy(); W_plus[0, 0] += eps; W_minus[0, 0] -= eps
numeric = (loss_of(W_plus) - loss_of(W_minus)) / (2 * eps)
print(f"analytic {analytic:.6f}  numeric {numeric:.6f}")
```

**Initialisation, scale ரெண்டும் முக்கியம்.** ரொம்ப பெரிசா ஆரம்பிக்கிற weights activations-ஐ saturate ஆக்கி gradients மறைஞ்சு போக வைக்கும்; ரொம்ப சிறுசா இருந்தா signals layer by layer மங்கிடும். அதனால தான் frameworks கவனமான defaults use பண்ணுது (Kaiming அல்லது Xavier initialisation மாதிரி). Inputs-ஐயும் standardise பண்ணுங்க, அப்போ ஒரு feature தன் units-ஆலயே ஆதிக்கம் செலுத்தாது.

**Tabular data-ல neural networks, நேர்மையா.** சாதாரண business tables-ல gradient-boosted trees பொதுவா ரொம்ப குறைவான tuning-ல neural network-ஐ விட சமமா அல்லது நல்லா இருக்கும். ரொம்ப பெரிய data இருக்கும்போது, tables-ஐ text அல்லது images-ஓட சேர்க்கணும்னா, அல்லது அதிக வேறுபாடுகள் உள்ள categories-க்கு embeddings கத்துக்கணும்னா network try பண்ணுங்க. அதே split-ல boosting-ஓட compare பண்ணுங்க.

## ஒரு example

Bengaluru-ல ஒரு agritech startup, இலை photos-ஐ healthy அல்லது நாலு நோய்கள்ல ஒண்ணுன்னு classify பண்றாங்க. முதல் step-ஆ, mechanics-ஐ கத்துக்க, ஒவ்வொரு image-ல இருந்தும் எடுத்த 64-number features-ல (colour, texture statistics) ஒரு சின்ன fully connected network build பண்றாங்க:

- 64 features உள்ள input layer → ReLU-ஓட 128 units உள்ள hidden layer → ReLU-ஓட 64 units உள்ள hidden layer → softmax-ஓட 5 units உள்ள output layer (5 classes-க்கான probabilities);
- cross-entropy loss, Adam optimiser, learning rate 0.001, 32-ஓட batches, அதிகபட்சம் 50 epochs.

Loss curves-ல training loss சீரா குறையுது, ஆனா validation loss epoch 14-ல கீழ போய் அதுக்கப்புறம் ஏறுது. 0.3 dropout சேர்த்து, best validation epoch-ல early stop பண்ணா 78% validation accuracy கிடைக்குது. அதே 64 features-ல gradient-boosted trees 80% எட்டுது.

அவங்க எடுத்த பாடம்: கையால செய்த tabular features-ல network-க்கு எந்த ஆதாயமும் இல்லை. அடுத்த step, raw images-ல ஒரு convolutional network, அது தன் சொந்த features-ஐ கத்துக்கும், பொதுவா ரொம்ப நல்லா செய்யும். அது எப்படின்னு CNN lesson சொல்லும்.

| Model | Validation accuracy |
| --- | --- |
| Network, regularisation இல்லாம, 50 epochs | 74% |
| Dropout 0.3, epoch 14-ல early stopping உள்ள network | 78% |
| அதே 64 features-ல gradient-boosted trees | 80% |
| Raw images-ல convolutional network (அவங்க அடுத்த step) | ரொம்ப அதிகமா இருக்கும்னு எதிர்பார்ப்பு |

## பொதுவா பண்ற தப்புகள்

- **Learning rate ரொம்ப அதிகம் அல்லது குறைவு.** Loss curve-ஐ கவனிங்க; tune பண்ண வேண்டியதுல முதல் விஷயம் இது.
- **Training loss-ஐ மட்டும் பார்க்கிறது.** Overfitting validation loss-ல தான் தெரியும்.
- **Scale பண்ணாத inputs.** Features-ஐ normalise பண்ணுங்க; இல்லைன்னா training unstable ஆகும்.
- **சின்ன tabular datasets-க்கு default-ஆ neural networks.** முதல்ல boosted trees try பண்ணுங்க.
- **Compare பண்றப்போ random seeds-ஐ fix பண்ணாம இருக்கிறது.** Runs-க்கு நடுவுல results மாறும்; நியாயமா compare பண்ணுங்க.
- **Scale பண்ணாத inputs**, training-ஐ slow ஆக்கும் அல்லது unstable ஆக்கும்.
- **Baseline-ஐ skip பண்றது**: tables-ல network தேர்ந்தெடுக்கிறதுக்கு முன்னாடி gradient boosting-ஓட compare பண்ணுங்க.
- **கையால எழுதின backward pass-ஐ gradient check இல்லாம நம்பறது.**

## Neural network use பண்ணக்கூடாத நேரங்கள்

- **சின்ன tabular datasets**: boosted trees அல்லது logistic regression பொதுவா நல்லது, எளிமையானதும்.
- **எளிமையான explanations தேவைப்படுற முடிவுகள்**, reason codes உள்ள credit approvals மாதிரி.
- **GPU budget இல்லாம, latency இறுக்கமா இருக்கும்போது** பெரிய network, அங்க சின்ன model போதும்.

## Demo-ல இருந்து production-க்கு

- **Training-ல save பண்ண statistics வச்சு inputs-ஐ standardise பண்ணுங்க**, serving-லயும் அதே apply பண்ணுங்க.
- **ஒவ்வொரு run-க்கும் training, validation loss-ஐ track பண்ணுங்க**, best checkpoint-ஐ வச்சுக்கோங்க.
- **Ship பண்றதுக்கு முன்னாடி அதே split-ல ஒரு strong baseline-ஓட compare பண்ணுங்க.**
- **Seeds-ஐ fix பண்ணி settings-ஐ record பண்ணுங்க**, runs-ஐ திரும்ப பண்ண முடியும்.
- **Input drift-ஐ monitor பண்ணுங்க**, ஏன்னா தெரியாத inputs-ல networks அமைதியா fail ஆகும்.

## Practice பண்ணுங்க

3Blue1Brown-ஓட neural networks series-ஐ பாருங்க, Google-ஓட ML Crash Course-ல neural networks modules-ஐ செய்யுங்க; Dive into Deep Learning-ஐ reference-ஆ use பண்ணுங்க.

1. உங்களுக்கு தெரிஞ்ச ஒரு problem-க்கு ஒரு சின்ன network-ஐ வரைஞ்சு, அதோட weights-ஐ எண்ணுங்க.
2. நீங்க தேர்ந்தெடுத்த library-ல ஒரு public dataset-ல ஒரு சின்ன network-ஐ train பண்ணுங்க; epoch வாரியா training, validation loss-ஐ plot பண்ணுங்க.
3. Dropout, early stopping சேர்த்து, அதே features-ல ஒரு gradient-boosted model-ஓட validation results-ஐ compare பண்ணுங்க.
4. NumPy network-ல இருந்து hidden layer-ஐ எடுத்துடுங்க (inputs-ஐ நேரடியா output-ஓட connect பண்ணுங்க), இனி XOR-ஐ கத்துக்க முடியாதுன்னு காட்டுங்க.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** forward pass, loss, backpropagation, gradient descent-ஐ உங்க சொந்த வார்த்தைகள்ல explain பண்ண முடியும், ஒரு ஜோடி loss curves-ஐ படிச்சு overfitting-ஐ diagnose பண்ண முடியும்.
