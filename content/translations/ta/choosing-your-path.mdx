## இது என்ன

AI கத்துக்க தொடங்குற நிறைய பேர் பாதியிலேயே நின்னுடுறாங்க, ஏன்னா அவங்களுக்கு தெளிவான route இல்ல: இங்க ஒரு video, அங்க ஒரு course, வாரா வாரம் ஒரு புது tool, மூணு மாசம் கழிச்சும் ஒரு skill-உம் முழுசா முடியல. ஒரு path-ஐ தேர்ந்தெடுக்குறது இதை சரி பண்ணும்.

Xplaind-ல ஒரு **path**-னா shared lessons-ல கட்டப்பட்ட, ஒரு job role-க்கான வரிசையான route. ஒவ்வொரு path-உம் stages-ஆ பிரிக்கப்பட்டிருக்கு. நிறைய stages-ல ஒரு guided project இருக்கு; ஒவ்வொரு path-லயும் ஒரு employer-கிட்ட காட்டக்கூடிய குறைஞ்சது ஒரு guided project இருக்கு. நீங்க முடிக்கிற lessons அதை use பண்ற **எல்லா** paths-லயும் கணக்குல வரும்; அதனால அப்புறமா மாத்தினாலும் உங்க உழைப்பு வீணாகாது.

இந்த lesson, Hyderabad-ல accountant-ஆ இருக்குற Imran தன் path-ஐ தேர்ந்தெடுக்குறதை follow பண்ணுது. கடைசியில நீங்களும் உங்க path-ஐ தேர்ந்தெடுத்து, உங்க மணி நேரங்களை plan பண்ணி, ஒரு முதல் milestone-ஐ வச்சிருப்பீங்க.

## இது எப்படி work ஆகுது

நல்லா தேர்ந்தெடுக்க ஒரு கேள்வியும் அப்புறம் மூணு checks-உம் வேணும், இந்த order-ல: **புது role-ஆ இல்லையா, அப்புறம் background, goal, நேரம்.**

```flow
dir: LR
title: ஒரு path-ஐ எப்படி தேர்ந்தெடுக்குறது
Start | எனக்கு புது role வேணுமா? -[இல்ல]-> Using-AI lessons | இப்போதைய வேலையில வேகமா செய்ய
Start -[ஆமா]-> 1. Background | code, maths, ஒரு domain?
1. Background -> 2. Goal | பத்து real job posts எனக்கு பொருந்துதா?
2. Goal -> 3. நேரம் | மாசக்கணக்கா தொடர முடிஞ்ச மணி நேரங்கள்
3. நேரம் -> உங்க path
```

### Check 1: உங்க background-ல இருந்து தொடங்குங்க

எல்லாத்தையும் விட அதிக buzz இருக்குற role-ல இருந்து இல்ல, உங்ககிட்ட ஏற்கனவே இருக்குறதுல இருந்து தொடங்குங்க. ஒவ்வொரு path-உம் ஒரு starting point-ஐ எதிர்பார்க்குது, அதனால உங்களோடதை அதோட match பண்ணுங்க:

| உங்க starting point | இதுல தொடங்குங்க | Path நீங்க என்ன தெரிஞ்சு வச்சிருக்கணும்னு எதிர்பார்க்குது |
| --- | --- | --- |
| எந்த AI-ஐ build பண்ணணும்னு decide பண்ண விரும்புறீங்க, code பண்ண விரும்பல | AI Product Manager | Code இல்ல; engineers கூட நல்லா வேலை செய்ய தேவையான அளவு கத்துக்குவீங்க |
| Risk, legal, audit, compliance அல்லது privacy-ல வேலை செய்யுறீங்க | AI Governance & Compliance | Code இல்ல; உங்க domain அறிவு தான் உங்க பலம் |
| Business processes-ஐ நடத்துறீங்க, கொஞ்சம் code கத்துக்குவீங்க | AI Automation Specialist | APIs, JSON-ஐ படிச்சு சின்ன scripts எழுதுவீங்க |
| IT support, networking அல்லது security-ல வேலை செய்யுறீங்க, இல்லன்னா security-ல ஆர்வம் இருக்கு | AI Security Engineer | Light Python; security basics zero-ல இருந்து கத்துக்கொடுக்கப்படும் |
| Code-க்கு புதுசு, ஆனா language-model apps-க்காக Python கத்துக்க தயார் | Generative AI & LLM Engineer | AI basics-ல தொடங்குது; level B2-ல இருந்து Python |
| Code பண்றீங்க, இல்லன்னா இப்போ Python கத்துக்குவீங்க, மிகப் பரந்த role வேணும் | AI Engineer | முதல் stage-ல இருந்தே Python |
| Python-ல இருந்து ஏற்கனவே ஒரு language model API-ஐ call பண்றீங்க | Agentic AI Engineer | Tool calling-ல தொடங்குது, அதனால சின்னது |
| ஒரு வருஷமோ அதுக்கு மேலயோ Python அனுபவம் இருக்கு, client meetings பிடிக்கும் | Forward Deployed Engineer | Stage 1-ல இருந்தே production-level Python |
| Python தெரியும், maths, statistics, data பிடிக்கும் | Machine Learning Engineer | Python, school maths |
| நீங்க ஒரு backend, DevOps, data அல்லது cloud engineer | MLOps Engineer | Linux, containers, cloud உங்களுக்கு சீக்கிரம் பிடிபடும் |

Label-ஐ இல்ல, path என்ன எதிர்பார்க்குதுங்கற assumption-ஐ check பண்ணுங்க. ஒரு API-ஐ கூட call பண்ணாத ஒரு fresher Agentic AI Engineer-ஐ தேர்ந்தெடுத்தா, முதல் வாரத்துலயே சுவத்துல மோதுவாங்க; GenAI path அதுக்கு பதிலா படிப்படியா agents வரைக்கும் கொண்டு போகுது.

### பார்க்க ஒரே மாதிரி இருக்குற மூணு engineering paths

AI Engineer, Generative AI & LLM Engineer, Agentic AI Engineer தான் ஒண்ணோட ஒண்ணு எல்லாத்தையும் விட அதிகமா overlap ஆகுது. நிறைய lessons-ஐ share பண்ணுது, ஆனா வெவ்வேற இடத்துல தொடங்கி, வெவ்வேற விஷயங்களுக்கு முக்கியத்துவம் குடுக்குது:

| | AI Engineer | Generative AI & LLM Engineer | Agentic AI Engineer |
| --- | --- | --- | --- |
| முதல் stage | Python, data foundations | AI basics, code இல்ல (B2-ல இருந்து Python) | Model APIs, structured output, tool calling |
| என்ன cover பண்ணுது | Classical ML, deep learning, transformers, அப்புறம் LLM apps, testing, production, system design | புதியவர்ல இருந்து system designer வரை ஒன்பது levels: prompts, ஆழமான RAG, agents, evals, production | Agent design, frameworks, MCP, reliability, production |
| Length | 9 மாசம் | 9 மாசம் | 4 மாசம் |
| எப்போ இதை தேர்ந்தெடுக்கணும் | பரந்த role வேணும்; இந்தியால நிறைய AI engineer posts ML basics-ஐயும் கேக்குது | Language-model apps தான் வேணும்னு உறுதியா இருக்கீங்க, இல்லன்னா zero code-ல இருந்து தொடங்குறீங்க | ஏற்கனவே language models வச்சு build பண்றீங்க, agents-ல ஆழம் வேணும் |

**Decision rule:** நீங்க code பண்றீங்க, ஆனா முடிவு பண்ண முடியலன்னா, எல்லாத்தையும் விட பரந்ததான AI Engineer-ஐ எடுங்க. Zero code-ல இருந்துன்னா, எல்லாத்தையும் விட மென்மையா தொடங்குற GenAI path-ஐ எடுங்க. ஒரு API-ஐ call பண்ணத் தெரிஞ்சதுக்கு அப்புறம், ரெண்டாவது step-ஆ Agentic AI Engineer-ஐ எடுங்க. FDE-யும் இதே மாதிரி engineering தான், கூட client வேலை; ஒரு வருஷமோ அதுக்கு மேலயோ Python அனுபவம் இருக்குறவங்களுக்கு.

### Check 2: Goal-ஐ real jobs கூட test பண்ணுங்க

மாசக்கணக்கா commit பண்றதுக்கு முன்னாடி, ஒரு மாலை நேரத்தை பத்து real job posts-க்கு செலவு பண்ணுங்க. உங்க city-ல அந்த role-க்கு Naukri அல்லது LinkedIn-ல search பண்ணி, நாலு columns-ஐ note பண்ணுங்க:

| Title | City அல்லது remote | கேக்குற வருஷங்கள் | Top மூணு skills அல்லது duties |
| --- | --- | --- | --- |
| AI Automation Engineer | Hyderabad | 1 முதல் 3 | n8n, APIs, process mapping |

Title-ஐ இல்ல, duties-ஐ படிங்க: "AI engineer"-னு பேர் வச்ச ஒரு post உண்மையில ML வேலையா இருக்கலாம்னு "இந்தியால AI careers" lesson காட்டுது. அப்புறம் மூணு rules-ஐ apply பண்ணுங்க:

- **Duties உங்களை உற்சாகப்படுத்துதா?** பத்து posts-ல பெரும்பாலானது ஒவ்வொரு வாரமும் நீங்க ரசிக்கக்கூடிய வேலையை விவரிச்சா, goal-ஐ வச்சுக்கோங்க. இல்லன்னா, இப்போவே வேற path-ஐ பாருங்க, நாலாவது மாசத்துல இல்ல.
- **பெரும்பாலான posts மூணு அல்லது அதுக்கு மேல வருஷம் கேக்குதா?** அப்போ ஒரு bridge plan பண்ணுங்க: பக்கத்துல இருக்குற ஒரு junior role, இல்லன்னா முதல்ல உங்க இப்போதைய company-க்குள்ளேயே ஒரு AI project. உதாரணமா, பெரும்பாலான FDE, AI product manager posts முன்னாடியே engineering அல்லது product அனுபவம் கேக்குது.
- **உங்க city-ல கிட்டத்தட்ட posts-ஏ இல்லையா?** Remote posts, மிகப் பக்கத்துல இருக்குற hub, global capability centres (GCCs)-ஓட careers pages-ஐ பாருங்க; அவங்க பல நேரம் நேரடியா hire பண்றாங்க.

### Freshers-உம் வேலை செய்யுறவங்களும்

- **Freshers**-க்கு real entry-level hiring-உம் projects portfolio-வும் இருக்குற paths-ல தான் எல்லாத்தையும் விட நல்லா போகும்: AI Engineer, GenAI, ML Engineer, AI Automation. 0 முதல் 2 வருஷத்துக்கான typical pay-ஐ Jobs page காட்டுது (2 November 2026 அன்னைக்கு check பண்ணது); உதாரணமா AI Engineer-க்கு வருஷத்துக்கு 6 முதல் 12 lakh CTC, AI Automation Specialist-க்கு 4 முதல் 8 lakh. FDE, AI Product Manager-ஓட அதைவிட அதிகமான early bands freshers-க்கு அரிதா தான் கிடைக்கும்.
- **வேலை செய்யுறவங்க** தங்களுக்கு ஏற்கனவே தெரிஞ்சதை reuse பண்ற path-ல தான் எல்லாத்தையும் விட வேகமா switch பண்றாங்க: DevOps-ல இருந்து MLOps, compliance-ல இருந்து governance, ஒரு Java developer FDE-க்கு. மிக வேகமான route பல நேரம் உங்க சொந்த company-க்குள்ள ஒரு AI pilot தான்.

### Check 3: நேரத்தை பத்தி நேர்மையா இருங்க

Deadline எதுவும் இல்ல. எல்லா path-உம் உங்க சொந்த வேகத்துல போகும்; அதனால ஒரு நல்ல வாரத்துல உங்களால முடிஞ்ச அதிகபட்ச மணி நேரத்தை இல்ல, மாசக்கணக்கா தொடர முடிஞ்ச வாராந்திர மணி நேரத்தை தேர்ந்தெடுங்க:

| வாராந்திர மணி நேரங்கள் | எப்படி இருக்கும் |
| --- | --- |
| 3 மணி நேரம் | வாரத்துக்கு ஒரு சின்ன lesson, ஒழுங்கா |
| 5 மணி நேரம் | வாரா வாரம் ஒரு lesson, அதோட practice |
| 8 மணி நேரம் | ரெண்டு lessons, ஒரு சின்ன project step |
| 12 மணி நேரம் | ஒரு stage வழியா சீரான முன்னேற்றம், projects-க்கும் நேரம் |

மணி நேரத்தை ஒரு date-ஆ மாத்த, ஒரு சின்ன கணக்கு போடுங்க: ஒவ்வொரு lesson page-லயும் அதோட hours இருக்கு, அதனால ஒரு stage-ஓட hours-ஐ கூட்டி, உங்க வாராந்திர hours-ஆல வகுத்து, practice-க்கு சுமார் மூணுல ஒரு பங்கு சேர்த்துக்கோங்க. Level test இருக்குற அஞ்சு paths-ல (AI Engineer, GenAI, Agentic AI, FDE, MLOps), roadmap-ல **Find my level**-ஐ அழுத்துங்க: ஏற்கனவே தெரிஞ்சதை test skip பண்ணும், மிச்சத்துக்கு உங்க hours-ல சுமார் எத்தனை வாரம் ஆகும்னு result காட்டும். மத்த அஞ்சு paths stage 1-ல தொடங்கும். ரெண்டு வாரம் இருபது மணி நேரம் படிச்சுட்டு அப்புறம் எதுவுமே இல்லாததை விட, சீரான அஞ்சு மணி நேரம் நல்லது.

### ஒரு plan போடுங்க

ஒரு plan-ல மூணு பாகங்கள்:

1. **உங்க வாரத்துல நிலையான study slots**, உதாரணமா Tuesday, Thursday மாலை, Sunday காலை. Meetings மாதிரி calendar-ல போடுங்க; exams, month-end close மாதிரி ஏற்கனவே தெரிஞ்ச busy வாரங்களையும் note பண்ணுங்க.
2. **நாலு வாரத்துக்குள்ள ஒரு முதல் milestone**, யார்கிட்டயாவது காட்டக்கூடியது: முடிச்ச ஒரு stage, ஒரு முதல் workflow, வேலை செய்யுற ஒரு சின்ன app. அதோட lesson hours உங்க slots-ஓட நாலு வாரத்துக்குள்ள, கொஞ்சம் இடம் மிச்சம் இருக்குற மாதிரி அடங்குதான்னு check பண்ணுங்க.
3. **Accountability**: பேர் சொல்லக்கூடிய ஒரு ஆள், உங்க update-க்கு ஒரு நிலையான நாள், அந்த update-உம்; உதாரணமா என்ன முடிச்சீங்க, அடுத்து என்னன்னு ஒரு வரி.

### முதல் stage-க்கு அப்புறம் மறுபரிசீலனை பண்ணுங்க

Stage 1-க்கு அப்புறம் கேளுங்க: இந்த வேலையை நான் ரசிக்கிறேனா, job posts-ல இருக்குற role பக்கம் இது என்னை நகர்த்துதா? இல்லன்னா, மாத்துங்க. முடிச்ச lessons carry over ஆகும்: உதாரணமா, "AI, machine learning, language model: மூணும் என்னன்னு simple-ஆ" பத்து paths-ல ஆறுல இருக்கு. ஒரு lesson கஷ்டமா இருந்துச்சுன்னோ, ஒரு வாரம் மோசமா போச்சுன்னோ மாத்தாதீங்க. அது எல்லா path-லயும் சாதாரணம் தான்.

## ஒரு worked example

Imran, 34, Hyderabad-ல ஒரு distribution company-ல accountant. சில மாசமா வேலையில ஒரு AI assistant-ஐ use பண்றார். Bank reconciliations-ஐ வேகப்படுத்த அதை use பண்றது அவருக்கு பிடிச்சிருந்தது, இன்னும் அதிகம் பண்ண விரும்புறார்; ஆனா full-time programmer ஆகுறதுல அவருக்கு ஆர்வம் இல்ல.

**புது role-ஆ இல்லையா?** Automation தான் தன் முக்கிய வேலையா இருக்குற ஒரு role அவருக்கு வேணும்; அதனால using-AI lessons மட்டும் போதாது.

**Background.** Coding இல்ல, finance, process அறிவு வலுவா இருக்கு, Excel formulas-ல comfortable. ரெண்டு paths possible-ஆ தெரியுது: AI Automation Specialist (கொஞ்சம் code), AI Governance & Compliance (code இல்ல), ஏன்னா அவருக்கு financial controls தெரியும்.

**Goal.** Hyderabad-ல பத்து job posts-ஐ படிக்கிறார், ஒவ்வொண்ணுக்கும் அஞ்சு. அவரோட notes (இது ஒரு illustration தான், survey இல்ல) காட்டுறது: governance posts பெரும்பாலும் அவர்கிட்ட இல்லாத risk அல்லது compliance அனுபவத்தை கேக்குது, அவருக்கு bore அடிக்கிற policy writing-ஐ விவரிக்குது. "AI automation engineer" அல்லது "finance automation analyst"-னு title இருக்குற automation posts n8n, Power Automate, APIs, process mapping-ஐ குறிப்பிடுது. அவற்றோட duties "automate invoice processing", "reduce manual reconciliation"-னு இருக்கு; அவருக்கு பிடிச்சது சரியா இது தான். பெரும்பாலானது 0 முதல் 3 வருஷம் கேக்குது. APIs, JSON-ஐ படிக்கவும் சின்ன scripts எழுதவும் வேண்டியிருக்கும்னு அவர் ஏத்துக்கிறார்.

**நேரம்.** அவருக்கு ரெண்டு சின்ன குழந்தைகள். நடைமுறையா: ரெண்டு weekday மாலைகள், ஒரு weekend காலை, வாரத்துக்கு சுமார் 5 முதல் 6 மணி நேரம். Path-ஓட தோராயமான guide மூணு மாசம்; projects-ஐயும் கணக்குல எடுத்தா, அவரோட வேகத்துல கொஞ்சம் அதிகமா ஆகலாம்.

**Milestone-ஐ check பண்றது.** Automation path-ஓட stage 1-ல ஏழு lessons இருக்கு, மொத்தம் சுமார் 10 மணி நேரம். Stage 2-ஓட முதல் lesson, "உங்க முதல் n8n workflow", இன்னும் சுமார் 3 மணி நேரம். ஆக 13 மணி நேரம் lessons. வாரத்துக்கு 5.5 மணி நேரத்துல நாலு வாரம்னா 22 மணி நேரம்; practice-க்கும் rework-க்கும் 9 மணி நேரம் மிச்சம். Milestone அடங்குது.

அவரோட plan:

| பாகம் | Imran-ஓட plan |
| --- | --- |
| Path | AI Automation Specialist |
| Study slots | Tuesday, Thursday இரவு 8 முதல் 9:30 வரை, Saturday காலை 9 முதல் 11:30 வரை (5.5 மணி நேரம்) |
| முதல் milestone | நாலு வாரத்துல: stage 1 முடிஞ்சிருக்கும், கூட invoice emails-ஐ ஒரு sheet-ல log பண்ற அவரோட முதல் n8n workflow |
| Accountability | கூட கத்துக்குற ஒரு colleague-க்கு ஒவ்வொரு Sunday-உம் ஒரு சின்ன update |
| Final project | Path-ஓட capstone, ஒரு invoice-to-ledger automation, அவரோட team-ஓட real invoice process மேல build பண்ணது |

**என்ன தப்பா போச்சு.** வாரம் 3-ல month-end close அவரோட ரெண்டு மாலைகளை எடுத்துக்கிச்சு, அவர் milestone date-ஐ miss பண்ணிட்டார். Plan-ஐ விடல. Date-ஐ ஒரு வாரம் தள்ளி வச்சு, colleague-கிட்ட சொல்லி, ஒவ்வொரு month-end வாரத்தையும் light வாரமா mark பண்ணார்.

**பலன் குடுத்த move.** தன் plan பத்தி manager-கிட்ட சொன்னார். Manager team-ஓட invoice process-ஐ capstone-க்கு குடுக்க முன்வந்தார், ஒரு condition-ஓட: vendor bank details நீக்கப்பட்ட copies மேல தான் Imran அதை build பண்ணி test பண்ணணும், live ledger-ஐ தொடுறதுக்கு முன்னாடி approval வாங்கணும். அவரோட final project இப்போ measure பண்ணக்கூடிய result இருக்குற real வேலை; அது ஒரு practice exercise-ஐ விட அவரோட portfolio-வை ரொம்ப வலுவாக்கும்.

## பொதுவா பண்ற தப்புகள்

- **எல்லாத்தையும் விட அதிக hype ஆன, இல்லன்னா எல்லாத்தையும் விட அதிக சம்பளம் தர்ற path-ஐ தேர்ந்தெடுக்கிறது.** உங்க background-க்கும், ஒவ்வொரு வாரமும் நீங்க ரசிக்கக்கூடிய வேலைக்கும் பொருந்துறதை தேர்ந்தெடுங்க.
- **ஒரு path என்ன எதிர்பார்க்குதுன்னு கவனிக்காம விடுறது.** Agentic AI Engineer, நீங்க Python-ல இருந்து ஒரு API-ஐ call பண்ணுவீங்கன்னு எதிர்பார்க்குது; FDE ஒரு வருஷ Python அனுபவத்தை எதிர்பார்க்குது. அதை இன்னும் உங்களால பண்ண முடியலன்னா, ஒரு step முன்னாடி தொடங்குங்க.
- **வேலையில AI use பண்ண மட்டும் விரும்பும்போது ஒரு career path எடுக்கிறது.** Using-AI lessons உங்களை மாசக்கணக்குல இல்ல, சில மணி நேரத்துல அங்க கொண்டு சேர்க்கும்.
- **நடைமுறைக்கு ஒத்துவராத மணி நேரங்களை plan பண்றது.** இருக்கணும்னு ஆசைப்படுற மணி நேரங்களை இல்ல, மாசக்கணக்கா தொடர முடிஞ்ச மணி நேரங்களை தேர்ந்தெடுங்க.
- **கூட்டிப் பார்க்காத ஒரு milestone-ஐ வைக்கிறது.** முதல்ல lesson hours-ஐ கூட்டுங்க; இல்லன்னா milestone தள்ளிப் போகும், நீங்க பின்தங்கிட்டதா உணருவீங்க.
- **வாரா வாரம் path-ஐ மாத்துறது.** மறுபரிசீலனை பண்றதுக்கு முன்னாடி ஒரு stage-க்கு commit பண்ணுங்க.
- **Projects-ஐ skip பண்றது.** Employers பார்க்க விரும்புறது projects தான், உண்மையான நம்பிக்கையும் அங்க இருந்து தான் வரும்.
- **தனியா கத்துக்கிறது.** ஒரு ஆளுக்கு வாரா வாரம் ஒரு நிலையான update குடுத்தா, சத்தமில்லாம விலகிப் போறது ரொம்ப கஷ்டமாகும்.
- **Perfect plan-க்காக காத்திருக்கிறது.** இந்த வாரம் தொடங்குற ஒரு நல்ல plan, அடுத்த மாசம் தொடங்குற perfect plan-ஐ விட நல்லது.

## Practice பண்ணுங்க

பரந்த பார்வைக்கு Watch & learn panel-ல இருக்குற video lesson-ஐ பாருங்க; அப்புறம் Xplaind-ஓட Roadmaps page-க்கு போங்க.

இந்த lesson-ஓட check தான் உங்க plan. ஒரு path-ஐ தேர்ந்தெடுத்து, sign in பண்ணி **Make this my path**-ஐ அழுத்துங்க. அப்புறம் இதோட ஒரு page plan எழுதுங்க:

1. **ஏன் இந்த path**, உங்க background, பத்து job posts பத்தின notes அடிப்படையில.
2. **உங்க வாராந்திர study slots**, உங்க calendar-ல.
3. **உங்க முதல் milestone, அதோட date**, சுமார் நாலு வாரம் தள்ளி.
4. **யாருக்கு update குடுப்பீங்க**, எந்த நாள்ல.

Share பண்றதுக்கு முன்னாடி, அதை test பண்ணுங்க:

| Test | எப்போ pass ஆகும் |
| --- | --- |
| Path-க்கு நியாயம் இருக்கா? | உங்க background-ஐயும் பத்து job posts என்ன கேட்டுச்சுன்னும் அது குறிப்பிடுது |
| Hours real-ஆ? | Slots கூட்டினா உங்க வாராந்திர hours வருது, அவை உங்க calendar-ல இருக்கு |
| Milestone-ஐ check பண்ண முடியுமா? | நீங்க காட்டக்கூடிய ஒரு விஷயம், நாலு வாரத்துக்குள்ள ஒரு date இருக்கு, அதோட lesson hours அடங்குது |
| யாராவது கவனிக்கிறாங்களா? | பேர் சொல்லக்கூடிய ஒரு ஆள், நிலையான ஒரு update நாள் |

முதல் lesson-ஐ இந்த வாரமே தொடங்குங்க. இப்போதைய வேலையில மட்டும் AI வேணுமா? மூணு using-AI lessons-ஐயும், அவற்றை try பண்ண ஒரு real வேலை task-ஐயும் தேர்ந்தெடுங்க.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** நீங்க தேர்ந்தெடுத்த roadmap "This is your path"-னு காட்டுது, உங்க முதல் study slot உங்க calendar-ல இருக்கு.
