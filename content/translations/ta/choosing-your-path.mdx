## இது என்ன

AI கத்துக்கிறதை மக்கள் விட்டுடுறதுக்கு பொதுவான காரணம் அது ரொம்ப கஷ்டம்னு இல்ல. தெளிவான route இல்லாம தொடங்குறது தான்: இங்க ஒரு YouTube video, அங்க ஒரு course, வாரா வாரம் ஒரு புது tool, முன்னேற்றம் தெரியாது. ஒரு path-ஐ தேர்ந்தெடுக்குறது இதை சரி பண்ணும்.

Xplaind-ல ஒன்பது paths இருக்கு. ஒவ்வொண்ணும் shared lessons வழியா ஒரு வரிசையான route, ஒவ்வொரு stage முடிவுலயும் ஒரு project. நீங்க முடிக்கிற lessons அதை use பண்ற **எல்லா** paths-லயும் கணக்குல வரும்; அதனால அப்புறமா மாத்தினாலும் உங்க உழைப்பு வீணாகாது.

| **Generative AI & LLM Engineer** | Python basics-ல இருந்து system design வரை, RAG-ஐ ஆழமா, language models மேல applications build பண்றவங்க | ஆமா |

இந்த lesson-ல Hyderabad-ல ஒரு accountant-ஆ இருக்குற Imran-ஐ follow பண்ணுவோம். வேலையில சில மாசம் AI-ஐ use பண்ணதுக்கு அப்புறம் அவர் தன் path-ஐ தேர்ந்தெடுக்குறார். Lesson முடியும்போது, நீங்க ஒரு path-ஐ தேர்ந்தெடுத்து, வாராந்திர மணி நேரங்களை plan பண்ணி, முதல் milestone-ஐ வச்சிருப்பீங்க.

## இது எப்படி work ஆகுது

நல்லா தேர்ந்தெடுக்க மூணு checks, இந்த வரிசையில: **background, goal, நேரம்.**

```flow
dir: LR
1. Background | நான் ஏற்கனவே என்ன தெரிஞ்சிருக்கேன்? Coding, maths, ஒரு domain? -> 2. Goal | இந்த role-ஓட real job posts என்னை உற்சாகப்படுத்துதா?
2. Goal -> 3. நேரம் | மாசக்கணக்கா வாரத்துக்கு எத்தனை மணி நேரம் தொடர முடியும்?
3. நேரம் -> உங்க path
```

### Check 1: உங்க background-ல இருந்து தொடங்குங்க

| Code எழுத முடியுமா, அல்லது Python கத்துக்க தயாரா? | நீங்க... | இதுல தொடங்குங்க |
|---|---|---|
| இல்ல | AI வச்சு workflows build பண்ண விரும்புறீங்க | AI Automation Specialist |
| இல்ல | எந்த AI-ஐ build பண்ணணும்னு decide பண்ண விரும்புறீங்க | AI Product Manager |
| இல்ல | Risk, legal அல்லது compliance-ல வேலை செய்யுறீங்க | AI Governance & Compliance |
| ஆமா | Maths அல்லது data background வலுவா இருக்கு | Machine Learning Engineer |
| ஆமா | DevOps அல்லது cloud-ல இருந்து வர்றீங்க | MLOps Engineer |

| ஆமா | Agents-ல ஆழம் வேணும் | Agentic AI Engineer |

### Check 2: Goal-ஐ real jobs கூட test பண்ணுங்க

ஒரு job site-ஐ திறந்து, அந்த path போற role-ஓட பத்து real job descriptions-ஐ படிங்க. தினசரி வேலை உங்களை உற்சாகப்படுத்தினா, நல்லது. சலிப்பா தெரிஞ்சா, மாசக்கணக்கா முதலீடு பண்றதுக்கு முன்னாடி வேற path-ஐ பாருங்க. இந்த பத்து நிமிஷ check, பலரை, தங்களுக்கு பொருந்தாத மிகவும் hype ஆன path-ல இருந்து காப்பாத்துது.

### Check 3: நேரத்தை பத்தி நேர்மையா இருங்க

Deadline இல்ல. ஒவ்வொரு path-உம் உங்க வேகத்துல வேலை செய்யும்; அதனால ஒரு நல்ல வாரத்துல உங்களால முடியுற அதிகபட்சத்தை இல்ல, நீண்ட காலம் தொடர முடிஞ்ச வாராந்திர மணி நேரங்களை தேர்ந்தெடுங்க:

| வாராந்திர மணி நேரங்கள் | எப்படி இருக்கும் |
| --- | --- |
| 3 மணி நேரம் | வாரத்துக்கு ஒரு lesson, ஒழுங்கா |
| 5 மணி நேரம் | வாரா வாரம் ஒரு lesson, அதோட practice |
| 8 மணி நேரம் | ரெண்டு lessons, ஒரு சின்ன project step |
| 12 மணி நேரம் | ஒரு stage வழியா சீரான முன்னேற்றம், projects-க்கும் நேரம் |

ரெண்டு வாரம் இருபது மணி நேரம் படிச்சுட்டு அப்புறம் எதுவுமே இல்லாததை விட, சீரான ஐந்து மணி நேரம் நல்லது. Engineering paths-ல, ஏற்கனவே தெரிஞ்சதை skip பண்ண level test-ஐ எடுங்க.

### ஒரு plan போடுங்க

ஒரு plan-ல மூணு பாகங்கள்:

1. **உங்க வாரத்துல நிலையான study slots**, உதாரணமா செவ்வாய், வியாழன் மாலை, ஞாயிறு காலை. Meetings மாதிரி calendar-ல போடுங்க.
2. **நாலு வாரத்துக்குள்ள ஒரு முதல் milestone**, stage 1-ஐ முடிக்கிறது அல்லது அதோட project-ஐ build பண்றது மாதிரி.
3. **Accountability**: உங்க கூட கத்துக்குற ஒரு நண்பர், ஒரு study group, அல்லது வாரா வாரம் உங்க progress-ஐ share பண்றது.

### முதல் stage-க்கு அப்புறம் மறுபரிசீலனை பண்ணுங்க

Stage 1-க்கு அப்புறம் கேளுங்க: இதை நான் ரசிக்கிறேனா, இது என்னை role பக்கம் நகர்த்துதா? இல்லன்னா, மாத்துங்க. முடிச்ச lessons carry over ஆகும், அதனால நீங்க இழக்குறது ரொம்ப கம்மி.

## ஒரு worked example

## பொதுவா பண்ற தப்புகள்

- **மிகவும் hype ஆன path-ஐ தேர்ந்தெடுக்கிறது.** உங்க background-க்கும், நீங்க ரசிக்கக்கூடிய வேலைக்கும் பொருந்துறதை தேர்ந்தெடுங்க.
- **நடைமுறைக்கு ஒத்துவராத மணி நேரங்களை plan பண்றது.** இருக்கணும்னு ஆசைப்படுற மணி நேரங்களை இல்ல, மாசக்கணக்கா தொடர முடிஞ்ச மணி நேரங்களை தேர்ந்தெடுங்க.
- **வாரா வாரம் path-ஐ மாத்துறது.** மறுபரிசீலனை பண்றதுக்கு முன்னாடி ஒரு stage-க்கு commit பண்ணுங்க.
- **Projects-ஐ skip பண்றது.** Employers பார்க்க விரும்புறது projects தான், உண்மையான நம்பிக்கையும் அங்க இருந்து தான் வரும்.
- **Accountability இல்லாம தனியா கத்துக்கிறது.** ஒரு ஆளோட வாராந்திர check-in, நீங்க தொடர்ந்து போற வாய்ப்பை ரொம்ப அதிகப்படுத்தும்.
- **சரியான plan-க்காக காத்திருக்கிறது.** இந்த வாரம் தொடங்குற ஒரு நல்ல plan, அடுத்த மாசம் தொடங்குற perfect plan-ஐ விட நல்லது.
