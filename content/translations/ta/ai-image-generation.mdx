## இது என்ன

AI image tools வார்த்தைகள்ல இருந்து படங்களை உருவாக்குது. பெரும்பாலானவை **diffusion models**: random noise-ல இருந்து ஆரம்பிச்சு, உங்க prompt சொல்ற திசையில, ஒரு image தெரியுற வரைக்கும் படிப்படியா noise-ஐ நீக்குது. நிறைய tools **reference images**-ஐயும் எடுத்துக்கும். அதனால ஒரு photo-வை edit பண்ணலாம், இல்லன்னா நிறைய படங்கள்ல ஒரே ஆளை அல்லது product-ஐ அப்படியே வச்சுக்கலாம்.

ரெண்டு tools பெரும்பாலான தேவைகளை பூர்த்தி பண்ணும்:

- **Gemini-ஓட image model**: செல்லப் பேரு **Nano Banana**. Gemini app-லயும் Google-ஓட AI Studio-லயும் இருக்கு. **சாதாரண வார்த்தைகள்ல editing** ("night-ஆ மாத்து", "shirt colour-ஐ மாத்து") பண்றதுலயும், edits முழுக்க முகங்களையும் பொருட்களையும் consistent-ஆ வச்சுக்கிறதுலயும் ரொம்ப நல்லது.
- **Midjourney**: வலுவான look-ஓட அழகான, artistic images-க்கு பேர் போனது; அதோட website வழியா use பண்றோம். Aspect ratio, result எவ்வளவு stylised-ஆ இருக்கணும், variations இதுக்கெல்லாம் settings இருக்கு.

```flow
Prompt | subject, details, setting, camera, light, style, aspect ratio -[வார்த்தைகள்ல இருந்து புது image]-> Generate பண்ணு
Generate பண்ணு -> 4-ல சிறந்ததை தேர்ந்தெடு -> Upscale பண்ணு
Prompt -[உங்க photo + ஒரு instruction]-> Edit பண்ணு | "bags-ஐ remove பண்ணு, warm light, ஆளை அப்படியே வை"
4-ல சிறந்ததை தேர்ந்தெடு -[reference-ஆ திரும்ப use பண்ணு]-> Consistent-ஆன images set
```

## இது எப்படி work ஆகுது

**Photographer அல்லது illustrator மாதிரி prompt எழுதுங்க.** தெளிவில்லாத prompts generic images-ஐ கொடுக்கும். ஒரு professional முடிவு பண்றதை எல்லாம் பேர் சொல்லுங்க:

| பகுதி | எந்த கேள்விக்கு பதில் | உதாரணம் |
|---|---|---|
| Subject | யார் அல்லது என்ன, சரியா | appam தட்டை பிடிச்சிருக்குற, சிரிக்கிற ஒரு Malayali பாட்டி |
| Details | உடைகள், materials, colours | gold border இருக்குற வெள்ளை mundu, வாழை இலை plate |
| Setting | எங்க, எப்போ | copper பானைகள் இருக்குற, வெயில் படுற ஒரு Kerala kitchen |
| Composition | framing, angle | medium shot, eye level, subject வலது third-ல |
| Lighting | தரம், திசை | window-ல இருந்து வர்ற மென்மையான காலை வெளிச்சம் |
| Style அல்லது medium | photo, illustration, 3D, watercolour | editorial food photography |
| Format | எங்க use ஆகும் | Instagram-க்கு 4:5, YouTube-க்கு 16:9 |

**திரும்ப generate பண்றதுக்கு பதிலா edit பண்ணுங்க.** Gemini-ல ஒரு photo-வை upload பண்ணி, ஒரு தடவைக்கு ஒரு மாற்றத்தை சொல்லுங்க. எது அப்படியே இருக்கணும்ன்னும் சொல்லுங்க ("முகத்தையும் pose-ஐயும் அப்படியே வை"). நிறைய சின்ன edits, ஒரு பெரிய edit-ஐ விட நல்லா வேலை செய்யும்.

**தெரிஞ்சுக்க வேண்டிய Midjourney settings.** `--ar 16:9` aspect ratio-ஐ set பண்ணும். Stylize setting, Midjourney தன் சொந்த artistic look-ஐ எவ்வளவு சேர்க்கணும்ன்னு கட்டுப்படுத்தும். Variations, remix இதெல்லாம் கிட்டத்தட்ட பிடிச்ச result-ஐ கொஞ்சம் நகர்த்த உதவும்; image, style references-ம் கொடுக்கலாம். Version பேர்களும் options-உம் மாறிக்கிட்டே இருக்கும், அதனால தற்போதைய documentation-ஐ பாருங்க.

**Consistency.** ஒரு character, product அல்லது mascot-க்கு, ஒரு வலுவான reference image-ஐ உருவாக்குங்க. அப்புறம் ஒவ்வொரு புது image-லயும் அதை reference-ஆ use பண்ணி, அதே எழுத்து description-ஐயே வைங்க.

**Image-ல இருந்து video-க்கு.** நல்ல still images AI video-க்கும் ஆரம்ப புள்ளி. Veo, Flow guide-ல ஒரு image-ஐ shot-ஓட முதல் frame-ஆ, அல்லது character, product reference-ஆ use பண்ணுவீங்க. அதனால நல்ல image-க்கு செலவழிக்கிற நேரம் ரெண்டு தடவை பலன் தரும்.

**Images-குள்ள text.** புது models சின்ன text-ஐ முன்பை விட நல்லா எழுதுது, ஆனா நீளமான text இன்னும் தப்பாகும். Posts, thumbnails-ஓட headlines-ஐ Canva அல்லது Figma-ல சேர்க்குறது பெரும்பாலும் வேகம்.

**Resolution, upscaling.** Generators ஒரு fixed size-ல images தரும். Print, banners, பெரிய screens-க்கு, tool-ஓட upscale option-ஐயோ தனி upscaler-ஐயோ use பண்ணுங்க. Publish பண்றதுக்கு முன்னாடி கைகள், text, logos மாதிரி நுணுக்கமான விஷயங்களை full size-ல check பண்ணுங்க; phone-ல தெரியாத சின்ன தப்புகள் print-ல தெரியும்.

**Rights, labels.** Commercial use-க்கு ஒவ்வொரு tool-ஓட terms-ஐயும் check பண்ணுங்க; paid plans பொதுவா அனுமதிக்கும். நிறைய platforms இப்போ AI-generated அல்லது ரொம்ப edit பண்ண images-ஐ label பண்ணச் சொல்லுது; Google தன் models-ல வர்ற images-ல கண்ணுக்கு தெரியாத SynthID watermark-ஐ சேர்க்குது. AI use பத்தி வெளிப்படையா இருக்குறது customers-கிட்ட நம்பிக்கையை வளர்க்கும்.

## ஒரு நாள், ஒரு example

Lakshmi Kochi-ல ஒரு home bakery நடத்துறாங்க. புது Instagram page-க்கு images வேணும், ஆனா வாரா வாரம் ஒரு photographer-ஐ afford பண்ண முடியாது.

அவங்க தன்னோட best-selling plum cake-ஐ kitchen table-ல phone-ல photo எடுக்குறாங்க. Gemini-ல ஒரு தடவைக்கு ஒண்ணா மூணு edits பண்றாங்க: "background-ஐ rustic wooden table-ஆவும் ஒரு coffee cup-ஆவும் மாத்து", "அதிகாலை மாதிரி warmer, softer light", "plate-ல ஒரு rosemary sprig சேர், cake-ஐ அப்படியே வை". Cake உண்மையிலயே அவங்களோடது தான்; customers-கிட்ட நேர்மையா இருக்க இது முக்கியம்.

Festive banner-க்கு Midjourney use பண்றாங்க: "Christmas window display of a small Kerala bakery at dusk, fairy lights, star lanterns, plum cakes on the shelf, warm glow, cinematic, --ar 16:9". நாலு results-ல ஒண்ணை தேர்ந்தெடுத்து upscale பண்றாங்க.

Gemini-ல ஒரு mascot-ஐ, அதாவது சந்தோஷமா இருக்குற ஒரு cartoon baker-ஐ, design பண்ணி, அந்த image-ஐ இன்னும் மூணு posts-க்கு reference-ஆ use பண்றாங்க; அதனால ஒவ்வொரு தடவையும் அவர் ஒரே மாதிரி தெரியுறார். Headlines-ஐ Canva-ல சேர்க்குறாங்க.

Page முதல் நாளே professional-ஆ தெரியுது. அவங்க rule: real products எப்பவும் edit பண்ண photos, ஒருபோதும் generate பண்ணதில்லை; அதனால customers தாங்க பார்க்குறதையே வாங்குறாங்க.

## பொதுவா பண்ற தப்புகள்

**ஒரே வார்த்தை prompts.** "A cake" ஒரு stock-photo cake-ஐ கொடுக்கும். உங்க மனசுல தெரியுற shot-ஐ describe பண்ணுங்க.

**ஒரே edit-ல நிறைய மாத்துறது.** Gemini ஒண்ணு அல்லது ரெண்டு தெளிவான மாற்றங்களை, ஒரே நேரத்துல அஞ்சு மாற்றங்களை விட ரொம்ப நல்லா follow பண்ணும்.

**Real products-ஓட generated "photos".** Customers தாங்க பார்க்குறதை எதிர்பார்ப்பாங்க. அதுக்கு பதிலா உங்க products-ஓட real photos-ஐ edit பண்ணுங்க.

**Real ஆட்கள், brands-ஐ use பண்றது.** Celebrities, ஒப்புதல் இல்லாத real customers, மத்த companies-ஓட logos இவற்றோட images-ஐ உருவாக்காதீங்க.

**உயிரோட இருக்குற artist-ஓட style-ஐ பணத்துக்காக copy பண்றது.** Artist பேரை சொல்றதுக்கு பதிலா, உங்களுக்கு பிடிச்ச குணங்களை describe பண்ணுங்க.

**Aspect ratio-ஐ கவனிக்காம விடுறது.** Square-ஆ உருவாக்குன image YouTube thumbnail-ஆ மோசமா crop ஆகும். Generate பண்றதுக்கு முன்னாடி format-ஐ set பண்ணுங்க.

**முதல் result-ஐயே ஏத்துக்கிறது.** சில options-ஐ generate பண்ணி, compare பண்ணி, சிறந்ததை சின்ன, குறிப்பிட்ட மாற்றங்களோட refine பண்ணுங்க.
