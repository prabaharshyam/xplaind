## இது என்ன

Maths-னால machine learning-ஐ தள்ளிப்போடுறவங்க நிறைய பேர். நீங்க mathematician ஆகணும்னு இல்லை. மூணு பகுதிகளுக்கு **intuition** வேணும்; ஒரு formula-வை பார்க்கும்போது அதை follow பண்ற திறனும் வேணும்:

| பகுதி | முக்கிய idea | ML-ல எங்க வருது |
| --- | --- | --- |
| **Linear algebra** | Data-வை **vectors** (numbers-ஓட lists), **matrices** (numbers-ஓட tables) ஆ பார்க்குறது, அவற்றுக்கான operations | ஒரு customer features-ஓட vector; ஒரு dataset matrix; ஒரு model-ஓட weights matrices |
| **Calculus** | Inputs-ஐ லேசா நகர்த்தும்போது ஒரு அளவு எப்படி மாறுதுங்குறது | Models **gradient**-ஐ follow பண்ணி கத்துக்கும்; error வேகமா குறையுற திசை அது |
| **Probability** | Uncertainty-ஐ விவரிக்கிறது | Models probabilities-ஐ output பண்ணும்; data-க்கு distributions இருக்கு; results தாக்குப்பிடிக்க எவ்வளவு வாய்ப்புன்னு evaluation கேக்கும் |

```flow
dir: LR
Linear algebra | data, weights vectors, matrices-ஆ: model என்ன compute பண்ணுது -> Calculus | weights நகரும்போது error எப்படி மாறுது (gradients): அது எப்படி கத்துக்குது
Calculus -> Probability | நாம எவ்வளவு உறுதி? Outputs, base rates, Bayes: அதன் output-ஐ எப்படி படிச்சு நம்புறது
```

இந்த lesson Hyderabad-ல ஒரு fintech-ஐ follow பண்ணும்; அவங்க ஒரு எளிய loan-default model-ஐ train பண்ணி, scale, base rates ஏன் முக்கியம்னு கஷ்டப்பட்டு கத்துக்குறாங்க. Lesson முடியும்போது, gradient descent-ஐ ஒரு sketch வச்சு explain பண்ணவும், அபூர்வமான events ஏன் பெரும்பாலும் false alarms-ஐ தருதுன்னு சொல்லவும் முடியும்.

## இது எப்படி work ஆகுது

### Vectors, similarity

**Vector**-னா ஒரு விஷயத்தை விவரிக்கிற numbers-ஓட list. ஒரே மாதிரி திசையில சுட்டுற ரெண்டு vectors ஒரே மாதிரி விஷயங்களை விவரிக்கும். **Dot product** பொருந்துற entries-ஐ பெருக்கி கூட்டும்:

```text
  a = (3, 1, 2)      b = (2, 0, 4)
  a . b = 3*2 + 1*0 + 2*4 = 6 + 0 + 8 = 14
```

பெரிய dot product-னா ஒரே மாதிரி திசை. **Cosine similarity** vectors-ஓட நீளத்தால வகுக்கும்; அதனால திசை மட்டும் தான் கணக்கு, அளவு இல்லை. Recommendation systems-உம் embedding search-உம் "ஒத்தது"ன்னு இப்படித்தான் அளக்குது.

### Matrices, transformations-ஆ

ஒரு vector-ஐ ஒரு matrix-ஆல பெருக்குனா அது transform ஆகும்: சுத்தும், இழுக்கும் அல்லது features-ஐ கலக்கும். ஒரு neural network-ஓட ஒரு layer-னா ஒரு matrix multiplication, அதுக்கு அப்புறம் ஒரு எளிய non-linear function.

**Shapes பொருந்தணும்.** 100 rows, 20 columns இருக்குற ஒரு matrix-ஐ 20 weights உள்ள ஒரு vector-ஆல பெருக்குனா 100 predictions கிடைக்கும்:

```text
   data X            weights w        predictions
  (100 x 20)    x     (20 x 1)    =    (100 x 1)
       ^^                ^^
       these must be equal
```

Code-ல பெரும்பாலான matrix bugs shape mismatches தான். Shapes-ஐ print பண்ணுங்க.

### Derivatives, gradients

**Derivative** ஒரு input லேசா மாறும்போது output எவ்வளவு மாறுதுன்னு சொல்லும். பல inputs இருக்கும்போது, **gradient** அந்த எல்லா derivatives-ஐயும் மேல் நோக்கி சுட்டுற ஒரு vector-ஆ சேர்க்கும்.

**Gradient descent** ஒரு model-ஐ train பண்றது இப்படித்தான்: **loss**-ல, அதாவது error-ஓட அளவுல, கீழ் நோக்கி சின்ன சின்ன அடிகள், மேம்படுறது நிக்குற வரை திரும்ப திரும்ப:

```text
   loss
    |  *
    |    *                        too-large steps bounce around:
    |      *                          *       *
    |        *  *                    *   *   *   *
    |            * * * * --           (never settles)
    +--------------------------> steps
          small, steady steps
```

**Learning rate** அடியோட அளவு. ரொம்ப பெருசுன்னா training துள்ளி குதிக்கும் அல்லது வெடிக்கும்; ரொம்ப சின்னதுன்னா ஊர்ந்து போகும். Loss curve-ஐ பார்த்து சரி பண்ணுங்க.

### Chain rule, backpropagation

Neural networks நிறைய functions-ஐ அடுக்கி வச்சிருக்கும். **Chain rule** நடுவுல இருக்குற எல்லா layers வழியா, ஆரம்ப weights-ஐ பொறுத்து final error எப்படி இருக்குதுன்னு கணக்கிடும். **Backpropagation**-னா chain rule-ஐ திறமையா apply பண்றது; பெரிய networks-ஐ train பண்றதை சாத்தியமாக்குறது அதுதான்.

### Probability

- **Probability distribution** ஒவ்வொரு மதிப்புக்கும் எவ்வளவு வாய்ப்புன்னு சொல்லும்.
- **Expected value**-னா நீண்ட கால சராசரி.
- "₹25,000-க்கு கீழ income இருந்தா default-க்கான probability" மாதிரி **Conditional probability** தான் classification-ஓட இதயம்.
- **Bayes' rule** evidence-ஓட நம்பிக்கைகளை update பண்ணும்; துல்லியமான tests இருந்தாலும் அபூர்வமான events ஏன் நிறைய false alarms தருதுன்னும் அது விளக்கும்.

### Scaling

ஒரு feature 400 வரை போகுது, இன்னொண்ணு 1-க்கு கீழயே இருக்குன்னா, gradient descent zigzag பண்ணி மெதுவா அல்லது நிலையில்லாம train ஆகும். Features-ஐ **standardise** பண்ணா, ஒவ்வொண்ணுக்கும் ஒரே மாதிரி range இருக்கும்; நிறைய models வேகமாவும் நல்லாவும் train ஆகும்.

| Feature | Raw range | Standardise பண்ணதுக்கு அப்புறம் |
| --- | --- | --- |
| Income-ல EMI-ஓட பங்கு | 0.05 முதல் 0.9 | கிட்டத்தட்ட -2 முதல் +2 |
| போன வருஷம் தவறவிட்ட payments | 0 முதல் 12 | கிட்டத்தட்ட -2 முதல் +2 |
| இப்போ இருக்குற வேலையில மாதங்கள் | 1 முதல் 400 | கிட்டத்தட்ட -2 முதல் +2 |

## ஒரு example

Hyderabad-ல ஒரு fintech ஒரு எளிய model வச்சு மாத EMI default risk-ஐ predict பண்றாங்க:

```text
score = w1 x (EMI / income) + w2 x (missed payments last year)
      + w3 x (months at current job) + b
```

**Vectors, weights.** ஒவ்வொரு applicant-உம் மூணு features-ஓட ஒரு vector. Weights w1, w2, w3, b சேர்ந்தது தான் model.

**Training.** Random weights-ஓட ஆரம்பிச்சு, 50,000 பழைய loans-க்கு predict பண்ணி, loss-ஐ (predictions உண்மையில நடந்ததுல இருந்து எவ்வளவு தூரம்) அளந்து, gradient-ஐ (ஒவ்வொரு weight-க்கும் loss எப்படி மாறுது) கணக்கிட்டு, ஒவ்வொரு weight-ஐயும் கீழ் நோக்கி நகர்த்தும். சில நூறு steps-க்கு அப்புறம் loss குறையுறது நிக்குது.

**முதல் பிரச்சனை: scale.** முதல்ல training நிலையில்லாம இருந்துச்சு: loss துள்ளி குதிச்சது. "Months at job" 400 வரை போச்சு, EMI ratio 1-க்கு கீழ இருந்துச்சு; அதனால ஒரு weight-க்கு ரொம்ப சின்ன அடிகளும் இன்னொண்ணுக்கு பெரிய அடிகளும் தேவைப்பட்டுச்சு. மூணு features-ஐயும் standardise பண்ணதும் சரியாச்சு.

**ரெண்டாவது பாடம்: base rates.** 2% applicants default ஆகுறாங்க, model 90% defaulters-ஐ பிடிக்குது, நல்ல applicants-ல 10%-ஐ தப்பா flag பண்ணுதுன்னு வச்சுக்கோங்க. 1,000 applicants-ல:

| | Default ஆவாங்க | Default ஆக மாட்டாங்க | மொத்தம் |
| --- | --- | --- | --- |
| எண்ணிக்கை | 20 | 980 | 1,000 |
| Model flag பண்ணது | 18 (20-ல 90%) | 98 (980-ல 10%) | 116 |
| Flag பண்ணாதது | 2 | 882 | 884 |

Flag ஆன 116 applicants-ல 18 பேர் தான், சுமார் ஆறுல ஒருத்தர், உண்மையில default ஆவாங்க. நல்ல applicants அதிகமா இருக்குறதால, பெரும்பாலான flags false alarms. அதனாலதான் bank score-ஐ **review-க்கு priority தர** use பண்ணுது, தானா reject பண்ண இல்லை.
