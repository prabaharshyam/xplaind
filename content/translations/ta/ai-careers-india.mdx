## இது என்ன

"AI job"-னா ஒரே job இல்ல. Companies பல roles families-க்கு ஆள் எடுக்குறாங்க, titles-உம் company-க்கு company மாறும். ஒரு firm-ல "GenAI developer" செய்யுறதை இன்னொண்ணுல "AI engineer" செய்வாங்க. அதனால AI career-ஓட முதல் rule: **title-ஐ மட்டும் இல்லாம, job description-ஐ படிங்க.**

இதோ முக்கிய roles-ஓட map, எவ்வளவு code வேணும்ங்குறதை வச்சு குழுவா பிரிச்சது:

```flow
dir: LR
title: Role-க்கு எவ்வளவு code வேணும்
Code இல்ல அல்லது கொஞ்சம் | உங்க field-ல AI (HR, law, sales), AI governance, compliance -> கொஞ்சம் code | AI product manager, automation specialist
கொஞ்சம் code -> நிறைய code | AI அல்லது GenAI engineer, forward deployed engineer, agent, RAG specialist, MLOps, ML engineer, data scientist
```

### AI-ஓட build பண்றது (coding roles)

- **AI engineer அல்லது GenAI engineer** language models மேல applications build பண்றாங்க: prompts, documents மேல retrieval (RAG), agents, evaluation, deployment. வேகமா வளர்ற AI titles-ல இதுவும் ஒண்ணு.
- **Forward deployed engineer** customers கூட நேரடியா வேலை செய்யுற AI engineer. தீர்க்குறதுக்கு தகுதியான problem-ஐ கண்டுபிடிச்சு, system-ஐ தினசரி use-ல கொண்டு வராங்க.
- **Agent, RAG specialists** actions எடுக்குற agents build பண்றதுலயோ, company documents மேல search பண்றதுலயோ ஆழமா போவாங்க.
- **MLOps, LLMOps அல்லது AI platform engineer** ML, AI systems-ஐ பெரிய scale-ல நம்பகமா ஓட வைக்குறாங்க: serving, monitoring, cost, security.
- **ML engineer, data scientist** prediction, ranking, fraud, forecasting-க்கு machine learning models-ஐ train பண்ணி deploy பண்றாங்க.

### AI-ஐ shape பண்ணி use பண்றது (கொஞ்சம் அல்லது coding வேணாம்)

- **AI product manager** எந்த AI features build பண்ணணும், அது வேலை செய்யுதான்னு எப்படி measure பண்றதுன்னு decide பண்றாங்க.
- **AI automation specialist** low-code tools, AI steps வச்சு business workflows-ஐ automate பண்றாங்க.
- **AI governance, compliance specialist** AI safe-ஆ, fair-ஆ, சட்டப்படி இருக்கான்னு check பண்றாங்க: risk assessments, policy, audits, incident handling. இந்தியாவோட DPDP Act மாதிரி laws-ஓட, EU customers-க்கு EU AI Act-ஓட கீழ.
- **உங்க இப்போதைய field, கூட AI skills.** AI தெரிஞ்ச marketers, analysts, HR staff, teachers, lawyers, doctors-க்கு மதிப்பு கூடிட்டே வருது; job title-ஐ மாத்தாமலேயே.

இந்த lesson-ல Chennai-ல மூணு பேரை follow பண்ணுவோம்: ஒரு student, ஒரு developer, ஒரு hospital manager. ஒவ்வொருத்தரும் தனக்கு பொருந்தின role-ஐ எப்படி தேர்ந்தெடுக்குறாங்கன்னு பார்க்கலாம்.

## இது எப்படி work ஆகுது

### Jobs எங்க இருக்கு

இந்தியால AI hiring ஐந்து வகை employers-ல இருந்து வருது:

| Employer வகை | என்ன build பண்றாங்க | என்ன எதிர்பார்க்குறாங்க |
| --- | --- | --- |
| IT services firms | Global clients-க்கு AI solutions | Deliver பண்ணக்கூடிய engineers, client skills; சில நேரம் certifications உதவும் |
| Product companies, startups | அவங்க சொந்த products-ல AI features | Strong builders, வேகம், deploy பண்ணின projects |
| Global capability centres (GCCs) | ஒரு multinational-ஓட சொந்த business-க்கு AI | Engineering quality, domain knowledge, security awareness |
| Consulting firms | Strategy, implementation | Communication, problem framing, delivery |
| வெளிநாட்டு companies, remote | Product வேலை | சிறந்த portfolio, எழுத்து communication; ரொம்ப போட்டி அதிகம் |

GCCs-னா multinational banks, retailers, manufacturers-ஓட in-house technology offices; Bengaluru, Hyderabad, Pune, Chennai, NCR-ல குவிஞ்சிருக்கு. AI roles-க்கு இவை பெரிய source ஆகிட்டாங்க.

### Employers என்ன எதிர்பார்க்குறாங்க

- **Engineering roles:** Python, APIs, Git, குறைஞ்சது ஒரு cloud; prompting, RAG, agents, evals மாதிரி language-model skills; notebook-ஐ இல்லாம, deploy பண்ணி measure பண்ணின system-ஐ காட்டுற projects.
- **Product, automation roles:** AI என்ன செய்யும், என்ன செய்யாதுன்னு தெரிஞ்சுக்குறது, problems-ஐ நல்லா தேர்ந்தெடுக்குறது, metrics define பண்றது, processes map பண்றது, clear-ஆ communicate பண்றது, tools-ஐ hands-on use பண்றது.
- **எல்லாருக்கும்:** Evidence. Real projects-ஓட portfolio, அல்லது வேலையில நீங்க deliver பண்ணின ஒரு கதை, certificates list-ஐ விட பலம்.

### Pay, seniority

Pay company, city, experience-ஐ பொறுத்து ரொம்ப மாறும். AI roles பொதுவா அதே மாதிரி non-AI roles-ஐ விட அதிகமா pay பண்ணும், ஆனா articles-ல வர்ற salary figures தோராயமான signals தான், பெரும்பாலும் சின்ன samples-ல இருந்து. Online-ல படிச்ச ஒரு number-க்காக மட்டும் role-ஐ தேர்ந்தெடுக்காதீங்க.

### உள்ள நுழைய வழிகள்

## ஒரு worked example

Chennai-ல மூணு பேர் AI careers பத்தி யோசிக்கிறாங்க.

**Sneha**, Python-ல comfortable-ஆன final-year B.Tech student, AI engineer ஆகணும்னு நினைக்கிறாங்க. இருபது job descriptions படிக்கிறாங்க, அதே skills திரும்ப திரும்ப வருது: Python, RAG, evaluation, deployment. AI Engineer path-ஐ follow பண்ணி, ஒவ்வொண்ணுக்கும் ஒரு சின்ன evaluation report-ஓட மூணு deployed projects build பண்ணி, startups, GCCs-க்கு apply பண்றாங்க. அவங்க marks இல்ல, portfolio தான் interviews வாங்கி தருது.

**Rahul**-க்கு ஒரு IT services firm-ல Java backend developer-ஆ ஐந்து வருஷம் experience. பெரும்பாலான engineers-ஐ விட அவருக்கு clients கூட பேசுறது பிடிக்கும். **Kavitha** ஒரு hospital chain-ல operations manager, code எழுதினதே இல்ல. Healthcare operations-ல AI adoption-ஐ lead பண்ணணும்னு ஆசை. ## பொதுவா பண்ற தப்புகள்

- **Title அல்லது hype பார்த்து தேர்ந்தெடுக்கிறது.** Commit பண்றதுக்கு முன்னாடி real job descriptions-ஐ படிச்சு, அந்த role-ல இருக்கவங்க கிட்ட பேசுங்க.
- **Projects-க்கு பதிலா certificates சேர்க்கிறது.** Certificates நீங்க படிச்சீங்கன்னு காட்டும். Build அல்லது deliver பண்ண முடியும்னு proof தான் employers-க்கு வேணும்.
- **உங்ககிட்ட ஏற்கனவே இருக்குற strengths-ஐ கவனிக்காம விடுறது.** Domain knowledge கூட AI skills அரிதான, மதிப்புள்ள கலவை.
- **எல்லாத்தையும் கத்துக்க முயற்சி பண்றது.** ஒரு path-ஐ தேர்ந்தெடுத்து ஆழமா போங்க; அப்புறம் விரிவாக்கலாம்.
- **ராத்திரியோட ராத்திரி results எதிர்பார்க்கிறது.** AI-க்கு பெரும்பாலான career switches, வேலையோட சேர்த்து மாசக்கணக்கான சீரான உழைப்பை எடுக்கும்.
- **பெரிய பெயர்களுக்கு மட்டும் apply பண்றது.** GCCs, mid-size product firms, IT services-ஓட AI practices பெரும்பாலும் அதிக ஆளுங்களை எடுக்குறாங்க.

## Practice பண்ணுங்க

Skills பத்தின பரந்த பார்வைக்கு Watch & learn panel-ல இருக்குற video lessons-ஐ பாருங்க.

1. **பத்து job descriptions படிங்க.** ஏதாவது job site-ல இந்தியால பத்து AI job postings கண்டுபிடிங்க. ஒவ்வொண்ணுக்கும் title, அதிகம் வர்ற மூணு skills, coding வேணுமான்னு note பண்ணுங்க.
2. **உங்களை match பண்ணுங்க.** உங்க background-க்கு நல்லா பொருந்துற ரெண்டு roles-ஐ தேர்ந்தெடுங்க. ஒவ்வொண்ணுக்கும் உங்ககிட்ட என்ன இருக்கு, என்ன இல்லைன்னு list பண்ணுங்க.
3. **ஒருத்தர் கிட்ட பேசுங்க.** அந்த roles-ல ஒண்ணுல வேலை செய்யுற ஒருத்தருக்கு message பண்ணுங்க (senior, alumnus, LinkedIn contact மாதிரி), ஒரு சாதாரண வாரம் எப்படி இருக்கும்னு கேளுங்க.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** உங்களுக்கு நல்லா பொருந்துற AI role-ஐ பேரு சொல்லி, hype இல்லாம evidence அடிப்படையில மூணு காரணங்கள் சொல்ல முடியும்.
