## இது என்ன

Claude **animated explainer videos** செய்யும்: உள்ள வந்து சறுக்குற titles, step by step-ஆ உருவாகுற diagrams, வளருற charts, ஒரு path-ல நகருற icons. இதை ஒவ்வொரு element-ஐயும் வரைஞ்சு animate பண்ற **code-ஐ எழுதி** செய்யுது, camera footage-ஐ generate பண்ணி இல்ல. அதனால **motion graphics**-க்கு இது ரொம்ப பொருத்தம்: ஒரு idea, ஒரு process அல்லது சில numbers-ஐ explain பண்றதுக்கு.

2026 இறுதியில இதை செய்ய மூணு வழிகள் இருக்கு:

- **Claude Motion** (beta, October 2026-ல launch): explainer-ஐ விவரிங்க அல்லது ஒரு report, data-வை paste பண்ணுங்க, Claude edit பண்ணி export பண்ணக்கூடிய ஒரு சின்ன animation-ஐ build பண்ணும். உங்க Claude plan-ல இது இருக்கான்னு check பண்ணுங்க.
- **Claude artifacts:** ஒரு சாதாரண chat-ல Claude-கிட்ட animated HTML, CSS அல்லது SVG scene கேளுங்க. அது உடனே play ஆகுறதை பார்க்கலாம், screen-record பண்ணிக்கலாம்.
- **Remotion-ஓட Claude Code:** Claude ஒரு Remotion project எழுதும், அதாவது ஒவ்வொரு frame-உம் code-ஆ இருக்குற React components, அப்புறம் ஒரு proper MP4-ஐ render பண்ணும். நீளமான videos, series, data-driven videos-க்கு சிறந்தது.

```flow
Idea -> Script | scenes, timings, on-screen text -> Claude animation code எழுதும் | Claude-ல Motion, ஒரு HTML அல்லது SVG artifact, அல்லது Claude Code + Remotion
Claude animation code எழுதும் -> Preview
Preview -[இங்க மெதுவா, அங்க பெரிய text]-> Revise
Revise -> Preview
Revise -> Export MP4 -> Voice-over, captions, music சேர் -> Publish
```

## இது எப்படி work ஆகுது

**1. Prompt-ல இல்ல, script-ல ஆரம்பிங்க.** ஒவ்வொரு scene-ஐயும் அதோட நீளம், என்ன தெரியுது, என்ன நகருது, screen-ல அல்லது narration-ல என்ன வார்த்தைகள்னு எழுதுங்க. ஒரு idea-வுக்கு முப்பது முதல் தொண்ணூறு நொடி போதும். Quality-ய தீர்மானிக்கிற ஒரே பெரிய விஷயம் இதுதான்.

**2. Visual style-ஐ ஒரு தடவை set பண்ணுங்க.** ரெண்டு, மூணு brand colours, ஒரு font, background, motion style பெயர் சொல்லுங்க, உதாரணம்: "smooth ease-in-out, no bouncing". எல்லா scenes-லயும் Claude அதை follow பண்ணும்.

**3. முதல் draft-ஐ generate பண்ணுங்க.** Script-ஐயும் style-ஐயும் Claude Motion-ல அல்லது ஒரு chat-ல paste பண்ணுங்க, அல்லது ஒரு scene-க்கு ஒரு component-ஓட ஒரு Remotion project-ஐ உருவாக்க Claude Code-கிட்ட சொல்லுங்க. Phone-ல படிக்க போதுமான அளவு text பெருசா இருக்கணும்னு சொல்லுங்க.

**4. பேசியே refine பண்ணுங்க.** Video-வே code ஆனதால, துல்லியமான changes easy: "scene 3-ஐ ரெண்டு நொடி நீளமாக்கு", "arrow இடது பக்கத்துல இருந்து வரணும்", "38%-ஐ 41%-ஆ மாத்து". அந்த element மட்டும் தான் மாறும்.

**5. Export.** Claude Motion-உம் Remotion-உம் MP4-ஆ export பண்ணும். Artifact-ன்னா, screen-record பண்ணுங்க, அல்லது அதை ஒரு Remotion project-ஆ convert பண்ண Claude-கிட்ட சொல்லுங்க.

**6. Sound, captions சேருங்க.** Narration-ஐ record பண்ணுங்க அல்லது text-to-speech voice use பண்ணுங்க, mute-ல பார்க்குறவங்களுக்கு captions சேருங்க, தேவைப்பட்டா ஒரு மெல்லிய music track-உம்.

| Approach | எதுக்கு சிறந்தது | முயற்சி | Output |
|---|---|---|---|
| Claude Motion | Prompt, report அல்லது data-ல இருந்து விரைவான explainers | குறைஞ்சது | Edit பண்ணக்கூடிய animation, MP4 export (plan-ஐ பொறுத்து) |
| Claude artifact | ஒரே ஒரு animated scene அல்லது diagram | குறைவு | Screen-record பண்ணக்கூடிய HTML |
| Claude Code + Remotion | நீளமான videos, series, data-driven batches | நடுத்தரம் | Render ஆன MP4, மறுபடி use பண்ணக்கூடிய templates |
| Video model (Veo, அடுத்த guide-ல பாருங்க) | Realistic footage | நடுத்தரம் | Generate ஆன clips |

**Data-ல இருந்து videos செய்யுறது.** ஒரு Remotion video ஒரு program ஆனதால், அது data-வை input-ஆ எடுக்கலாம். ஒரு sales team ஒரு spreadsheet-ல இருந்து ஒவ்வொரு region-க்கும் ஒரு personalised video-வை render பண்ணலாம், அல்லது ஒரு teacher scripts list-ல இருந்து ஒவ்வொரு chapter-க்கும் ஒரு video-வை render பண்ணலாம். Data-வை படிச்சு ஒவ்வொரு version-ஐயும் render பண்ற loop-ஐ Claude Code எழுதும்; கையால செய்யுற எந்த animation workflow-உம் இதை சமமா பண்ண முடியாது.

## ஒரு worked example

Sneha Nagpur-ல ஒரு college-ல computer science கத்துக்கொடுக்குறாங்க. RAG chatbot எப்படி work ஆகுதுன்னு அவங்க students-க்கு புரிய கஷ்டமா இருக்கு, அதனால class WhatsApp group-க்கு 60 நொடி animation ஒண்ணு வேணும்னு நினைக்கிறாங்க.

அவங்க ஒரு script எழுதுறாங்க:

1. (6 s) ஒரு student chat box-ல "What is the exam syllabus?"ன்னு type பண்றாங்க.
2. (12 s) Question ஒரு வரிசை numbers-ஆ மாறுது, அதான் "embedding", அது documents stack-க்கு நகருது.
3. (12 s) பொருந்துற மூணு paragraphs ஒளிர்ந்து stack-ல இருந்து வெளிய சறுக்குது.
4. (15 s) Question-உம் மூணு paragraphs-உம் "LLM"-னு label இருக்குற ஒரு box-க்குள்ள flow ஆகுது.
5. (10 s) ஒரு answer தெரியுது, கீழ source document-ஓட பெயரோட.
6. (5 s) Title card: "RAG = search first, then answer".

Purple, white-ல flat style, ஒவ்வொரு scene-க்கும் கீழ captions, text 48 px-க்கு குறையாம இருக்கணும்னு சொல்லி, Remotion-ல இதை build பண்ண Claude Code-கிட்ட கேக்குறாங்க. முதல் render நெருக்கமா இருக்கு. ரெண்டு changes கேக்குறாங்க: படிக்க முடியாத அளவு வேகமா போன scene 2-ஐ மெதுவாக்குறது, scene 3-ல document பெயர்களை காட்டுறது. ஒவ்வொரு change-க்கும் Claude-க்கு ஒரு நிமிஷத்துக்கு குறைவு தான் ஆகுது.

தன் phone-ல சொந்த narration-ஐ record பண்றாங்க, Claude Code scene நீளங்களை audio-வோட sync பண்ணுது, அவங்க MP4-ஐ export பண்றாங்க. அடுத்த semester, scenes components ஆனதால, script-ஐ மாத்தி ஒவ்வொரு topic-க்கும் ஒரு video செய்ய அதே project-ஐ மறுபடி use பண்றாங்க.

## பொதுவா பண்ற தப்புகள்

**Script இல்லாம prompt பண்றது.** "Make an explainer about X" ஒரு generic result தான் கொடுக்கும். முதல்ல scenes, timings, வார்த்தைகளை எழுதுங்க.

**Screen-ல அதிக text.** மக்களால படிக்கவும் கேக்கவும் ஒரே நேரத்துல முடியாது. ஒவ்வொரு scene-லயும் on-screen text-ஐ சில வார்த்தைகளா வச்சு, விவரத்தை narration சொல்லட்டும்.

**காரணமில்லாத motion.** சுத்துறது, துள்ளுறது, zoom பண்றது idea-வுல இருந்து கவனத்தை திசை திருப்பும். புரிஞ்சுக்க உதவுறதை மட்டும் animate பண்ணுங்க.

**Phones-க்கு சின்ன text.** பெரும்பாலானவங்க phone-ல பார்ப்பாங்க. Phone size-ல preview-ஐ check பண்ணுங்க.

**Realistic scenes-க்கு use பண்றது.** Claude-ஓட animation code-ல இருந்து வரையப்படுது. Camera-ல மனுஷங்க, இடங்கள், products-க்கு, அடுத்த guide-ல வர்ற Veo மாதிரி ஒரு video model-ஐ use பண்ணுங்க.

**Use பண்ற உரிமை இல்லாத music, images.** Royalty-free tracks-ஐயும், உங்களோட சொந்த அல்லது licensed images-ஐயும் use பண்ணுங்க, முக்கியமா public அல்லது commercial விஷயங்களுக்கு.

## Practice பண்ணுங்க

1. Watch & learn panel-ல இருக்குற Claude motion graphics tutorial-ஐயும், Remotion-ஓட Claude Code build-ஐயும் பாருங்க, கூடவே Claude Motion-க்கான Anthropic-ஓட சின்ன introduction-ஐயும்.
2. மேல இருக்குற "Brief-ஐ எழுதுங்க" exercise-ஐ பண்ணுங்க.
3. Scenes எப்படி frames ஆகுதுன்னு பார்க்க, கீழே link பண்ணியிருக்குற Remotion docs-ஐ skim பண்ணுங்க.
4. Project check-ஐ பண்ணுங்க: நீங்க முடிச்ச ஒரு lesson-ஓட 45 முதல் 60 நொடி explainer, narration அல்லது captions-ஓட.
