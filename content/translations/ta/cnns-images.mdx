## இது என்ன

**Convolutional neural network (CNN)**, படத்து மேல நகர்ற, கத்துக்கிட்ட சின்ன filters வச்சு images-ஐ process பண்ணும். ஆரம்ப layers edges, textures-ஐ கத்துக்கும்; பிந்தைய layers அவற்றை shapes, objects-ஆ சேர்க்கும். Image முழுக்க ஒரே filter-ஐ use பண்றதால, CNNs efficient-ஆ கத்துக்கும், ஒரு pattern எங்க வந்தாலும் அடையாளம் காணும்.

**Transfer learning**-ல, லட்சக்கணக்கான general images-ல ஏற்கனவே train ஆன ஒரு CNN (அல்லது vision transformer)-ல இருந்து ஆரம்பிச்சு, உங்க task-க்கு adapt பண்ணுவீங்க. Scratch-ல இருந்து train பண்றதை விட இதுக்கு data-வும் நேரமும் ரொம்ப குறைவு, results-உம் பொதுவா நல்லா இருக்கும்.

```flow
dir: LR
Image, 224x224 -> Conv: edges | நிறைய சின்ன maps, 3x3 filters -> Conv: textures | pooling maps-ஐ சுருக்குது
Conv: textures -> Conv: parts | பெரிய பகுதிகள் -> Classifier | "slub defect" 0.91
```

```flow
dir: LR
title: Transfer learning
Pre-trained layers, frozen -> புது final layer, train ஆகுது -[வேணும்னா]-> கடைசி blocks-ஐ சின்ன learning rate-ல unfreeze பண்ணுங்க
```

## இது எப்படி work ஆகுது

**Convolution, pooling.** ஒரு filter (உதாரணத்துக்கு 3 × 3 pixels) அதுக்கு கீழ இருக்குற pixels-ஐ multiply பண்ணி கூட்டி, அதோட pattern எங்க வருதுன்னு காட்டுற ஒரு map உருவாக்கும். ஒரு layer-ல பல filters இருந்தா பல patterns-ஐ கண்டுபிடிக்கும். Pooling அல்லது strided convolutions maps-ஐ சுருக்கும், அதனால ஆழமான layers பெரிய பகுதிகளை பார்க்கும்.

**Classic architectures.** ResNet, EfficientNet மாதிரியானவை நல்லா test ஆனவை, pre-trained-ஆவே கிடைக்கும். Vision transformers ஒரு புது alternative; ரெண்டுமே practice-ல use ஆகுது.

**Transfer learning steps.**

1. ஒரு pre-trained model-ஐ load பண்ணுங்க.
2. அதோட final layer-ஐ உங்க classes-க்கு பொருந்துற layer-ஆ மாத்துங்க.
3. முந்தைய layers-ஐ freeze பண்ணி, முதல்ல புது layer-ஐ train பண்ணுங்க. அப்புறம் வேணும்னா சில layers-ஐ அல்லது எல்லாத்தையும் unfreeze பண்ணி, சின்ன learning rate-ல train பண்ணுங்க (fine-tuning).

**Data augmentation.** Random flips, crops, rotations, brightness, colour மாற்றங்கள் training images-ஓட பலவிதமான versions-ஐ உருவாக்கி, overfitting-ஐ குறைக்கும். நிஜத்தோட பொருந்துற augmentations-ஐ தேர்ந்தெடுங்க: இலை photos-ஐ rotate பண்ணலாம், ஆனா text documents-ஐ flip பண்ணக்கூடாது.

**Image data quality.** Real images, வெளிச்சம், கோணம், background, camera-ல வேறுபடும். Production images மாதிரி இருக்குற training images-ஐ collect பண்ணுங்க (ஒரு கடையில phone-ல எடுத்த photos, studio photos மாதிரி இருக்காது). Labels-ஐ check பண்ணுங்க; தப்பா label ஆன images நீங்க நினைக்கிறதை விட அதிகம் பாதிக்கும்.

**Evaluation.** Generalisation test பண்ண, வேற நாட்கள், devices, locations-ல எடுத்த images-ஐ hold out பண்ணுங்க. Confusion matrix-ஐயும், தப்பா classify ஆன images-ஐயும் பாருங்க; அவை பெரும்பாலும் label errors-ஐயோ, விடுபட்ட conditions-ஐயோ (இரவு, மழை, blur) காட்டும்.

**Classification-ஐ தாண்டி.** Object detection (பொருட்கள் எங்க இருக்கு), segmentation (எந்த pixels எதுக்கு சொந்தம்), OCR இவையும் தொடர்புடைய architectures-ஐ use பண்ணும், இவையும் பெரும்பாலும் pre-trained models-ல இருந்து fine-tune பண்ணப்படும்.

**Scratch vs transfer learning:**

| Approach | Data needed | Time | சின்ன datasets-ல பொதுவான result |
| --- | --- | --- | --- |
| Scratch-ல இருந்து train | பத்தாயிரக்கணக்கான images அல்லது அதுக்கு மேல | நீளம் | பலவீனம் |
| Transfer learning, frozen backbone | நூறுகள்ல இருந்து சில ஆயிரங்கள் | குறைவு | நல்லது |
| கடைசி blocks-ஐ fine-tune பண்றது | சில ஆயிரங்கள் | நடுத்தரம் | பெரும்பாலும் சிறந்தது |

**ஒரு filter என்ன compute பண்ணுது.** 3 × 3 filter-ல கத்துக்கிட்ட ஒன்பது weights இருக்கும். ஒவ்வொரு இடத்துலயும், அவற்றை கீழ இருக்குற ஒன்பது pixels-ஓட multiply பண்ணி, results-ஐ கூட்டி ஒரு number ஆக்கும். Image முழுக்க அதை நகர்த்தினா, filter-ஓட pattern (உதாரணத்துக்கு ஒரு vertical edge) எங்கெல்லாம் வருதோ அங்க பிரகாசமா இருக்குற ஒரு map கிடைக்கும். 64 filters இருக்குற ஒரு layer 64 maps-ஐ உருவாக்கும், அடுத்த layer அவற்றை சேர்த்து இன்னும் சிக்கலான patterns-ஆ மாத்தும்.

**Confusion matrix-ஐ படிக்கிறது.** Accuracy மட்டும் எந்த classes குழம்புதுன்னு மறைச்சிடும். Confusion matrix, ஒவ்வொரு true class-க்கும், model ஒவ்வொரு class-ஆ எத்தனை தடவை predict பண்ணுச்சுன்னு காட்டும். Fabric project-ல, "slub", "thick place" defects அடிக்கடி மாறி predict ஆனதுன்னு அது காட்டுச்சு; "hole" கிட்டத்தட்ட ஒரு தடவை கூட miss ஆகல. எங்க இன்னும் examples collect பண்ணணும், எங்க ஒரு inspector-ஓட ரெண்டாவது பார்வை ரொம்ப முக்கியம்னு team-க்கு இது சொல்லுச்சு. தப்பா classify ஆன இருபது images-ஐ confidence வாரியா அடுக்கி கண்ணால பாக்குறது, எந்த ஒரு number-ஐ விடவும் பொதுவா அதிகம் கத்துக்கொடுக்கும்.

**torchvision-ல transfer learning.** ஒரு pretrained network-ஐ load பண்ணுங்க, final layer-ஐ மாத்துங்க, ரெண்டு phases-ல train பண்ணுங்க:

```python
import torch
from torch import nn
from torchvision import models, transforms

weights = models.ResNet18_Weights.DEFAULT
model = models.resnet18(weights=weights)              # downloads pretrained weights once
for p in model.parameters():
    p.requires_grad = False                           # phase 1: freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 6)         # six defect classes

train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.7, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.3, contrast=0.3),      # shop lighting varies
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
eval_tf = weights.transforms()                        # the exact resize and normalisation used in pretraining

opt = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)
# ... train a few epochs on the head only ...

# Phase 2: unfreeze the last block and fine-tune gently
for p in model.layer4.parameters():
    p.requires_grad = True
opt = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-4},
    {"params": model.fc.parameters(), "lr": 1e-3},
], weight_decay=1e-4)
```

நிஜத்தோட பொருந்துற augmentations-ஐ தேர்ந்தெடுங்க: இலைகளுக்கும் fabric-க்கும் flips சரி, ஆனா labels-ல இருக்குற text-க்கும், இடது-வலது defects-க்கும் தப்பு.

```python
            out = model(xb)
            ys += yb.tolist(); ps += out.argmax(1).tolist()
            losses += nn.functional.cross_entropy(out, yb, reduction="none").tolist()
    print(classification_report(ys, ps, target_names=class_names, digits=3))
    print(confusion_matrix(ys, ps))
    return sorted(range(len(losses)), key=lambda i: -losses[i])[:30]   # indices of the most confident mistakes
```

முதல்ல loss அதிகமான 30 images-ஐ பாருங்க: அவை பெரும்பாலும் தப்பா label ஆனவை, blur ஆனவை அல்லது ஒரு வித்தியாசமான camera-ல எடுத்தவை. Tuning-ஐ விட இவற்றை சரி பண்றது அதிகம் உதவும்.

**Random-ஆ மட்டும் இல்லாம, source வாரியா split பண்ணுங்க.** Photos பல கடைகள் அல்லது phones-ல இருந்து வந்தா, ஒவ்வொரு கடையோட images-ஐயும் ஒரே split-ல வைங்க. இல்லன்னா model, defect-ஐ கத்துக்காம, ஒரு கடையோட background-ஐயும் வெளிச்சத்தையும் கத்துக்கலாம்.

**Model எதை பாக்குதுன்னு பார்க்கிறது.** Grad-CAM, ஒரு prediction-ஐ தூண்டுன image regions-ஐ highlight பண்ணும். Highlight ஒரு watermark மேலயோ மேஜை ஓரத்துலயோ இருந்தா, model ஒரு shortcut-ஐ கத்துக்கிட்டிருக்குன்னு அர்த்தம்.

## ஒரு worked example

Pune fabric-defect project-ஐ தொடர்ந்து: ரெண்டு factory lines-ல இருந்து ஆறு defect types-ல 4,800 labelled images.

- Scratch-ல train பண்ண ஒரு சின்ன CNN: 71% validation accuracy.
- Pre-trained ResNet-50, புது final layer, frozen backbone, 5 epochs: 86%.
- கடைசி ரெண்டு blocks-ஐ பத்து மடங்கு சின்ன learning rate-ல unfreeze பண்ணி, augmentations-ஓட (flips, சின்ன rotations, brightness மாற்றங்கள்): 93%.

Validation-க்கு, training-ஐ விட வேற வாரத்தோட images-ஐ use பண்ணாங்க. Confusion matrix, பெரும்பாலான errors "slub", "thick place" defects-க்கு நடுவுல இருக்குன்னு காட்டுச்சு. தப்பா classify ஆன 60 images-ஐ review பண்ணப்போ, அதுல 14 தப்பா label ஆனவை. Labels-ஐ சரி பண்ணி retrain பண்ணப்புறம்: 94.5%.

Deploy பண்றதுக்கு முன்னாடி, team ரெண்டாவது factory line-ல, வேற வெளிச்சத்துல எடுத்த 300 images-ல test பண்ணுச்சு: 88%. அந்த line-ல இருந்து 400 images-ஐ training-ல சேர்த்தாங்க, அங்கயும் 93% வந்துச்சு. அப்புறம் ஒரு confidence threshold வச்சாங்க; அதுக்கு கீழ இருக்குற images ஒரு human inspector-க்கு போகும்.

| Step | Validation accuracy |
| --- | --- |
| Scratch-ல ஒரு சின்ன CNN | 71% |
| Pre-trained ResNet-50, frozen, புது final layer | 86% |
| கடைசி ரெண்டு blocks fine-tune + augmentation | 93% |
| 14 தப்பா label ஆன images-ஐ சரி பண்ணப்புறம் | 94.5% |
| ரெண்டாவது factory line, அதோட images சேர்க்கிறதுக்கு முன்னாடி | 88% |
| ரெண்டாவது line, அதோட 400 images சேர்த்தப்புறம் | 93% |

Architecture மாதிரியே labels-உம், ரெண்டாவது line-ஓட வெளிச்சமும் முக்கியமா இருந்துச்சு.

## பொதுவா பண்ற தப்புகள்

- **கொஞ்சம் data வச்சு scratch-ல இருந்து train பண்றது.** Transfer learning use பண்ணுங்க.
- **நிஜமில்லாத augmentations.** Real images எப்படி வேறுபடுமோ அப்படி augment பண்ணுங்க (வெளிச்சம், கோணம், blur), ஒரு நாளும் நடக்காத விதத்துல இல்லை.
- **Training images-ஓட near-duplicates-ல validate பண்றது.** நாள், device, location வாரியா split பண்ணுங்க.
- **தப்பா classify ஆன images-ஐ கண்டுக்காம விடுறது.** அவை label errors-ஐயும், விடுபட்ட conditions-ஐயும் காட்டும்.
- **Production-ல confidence threshold இல்லாம இருக்கிறது.** நிச்சயமில்லாத images-ஐ guess பண்ண வைக்காம, ஒரு inspector-க்கு அனுப்புங்க.
- **Serving-ல pretrained model-ஓட preprocessing-ஐ விட வேற preprocessing use பண்றது.**
- **Label-ஐ மாத்துற augmentations**, இடது-வலது defects-ஐ flip பண்றது மாதிரி.
- **கடைகள் அல்லது devices முழுக்க random splits**, scores-ஐ ஊதிக் காட்டும்.

## CNN பதில் இல்லாத இடங்கள்

- **ஒரு vision-language model அந்த task-ஐ ஏற்கனவே ஒரு prompt-ல பண்ணுது**, ரசீது படிக்கிறது, சேதத்தை விவரிக்கிறது மாதிரி, உங்க volume-லயும் cost-லயும்.
- **Labelled images ரொம்ப குறைவு**, இன்னும் பெற வழியும் இல்லை: few-shot vision model அல்லது rules-ல ஆரம்பிங்க.
- **Signal pixels-ல இல்லை, metadata-ல இருக்கு**, sensor readings அல்லது time stamps மாதிரி.

## Demo-ல இருந்து production-க்கு

- **Training-லயும் serving-லயும் ஒரே preprocessing use பண்ணுங்க**, model-ஓட சேர்த்து save பண்ணி.
- **Class வாரியாவும், source வாரியாவும் (கடை, device, நாள்) evaluate பண்ணுங்க.**
- **Tune பண்றதுக்கு முன்னாடி, அதிக loss இருக்குற images-ஐ review பண்ணி labels-ஐ சரி பண்ணுங்க.**
- **Production-ல image quality-ஐ monitor பண்ணுங்க**: blur, brightness, resolution.
- **Confidence குறைவான predictions-க்கு human check வச்சிருங்க.**
