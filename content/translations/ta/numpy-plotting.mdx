## இது என்ன

Machine learning-னா பெரிய numbers tables மேல பண்ற maths, Python-ல அந்த maths **NumPy** மேல ஓடுது; இது fast numerical arrays-க்கான library. pandas, scikit-learn, PyTorch எல்லாமே இதோட ideas மேல build ஆகியிருக்கு, அதனால இங்க கத்துக்குற பழக்கங்கள் நேரடியா model வேலைக்கு போகும். **Matplotlib** தான் standard plotting library; Seaborn, Plotly மாதிரி மத்தது கிட்டத்தட்ட இதே ideas-ஐ தான் use பண்ணும்.

முக்கிய skills:

| Skill | அர்த்தம் | உதாரணம் |
| --- | --- | --- |
| **Arrays and shapes** | Arrays உருவாக்கி, அதோட dimensions தெரிஞ்சுக்கிறது | `X.shape` என்பது `(50000, 3)` |
| **Vectorisation** | முழு arrays மேலயும் ஒரே நேரத்துல maths பண்றது | `prices * 1.18` |
| **Broadcasting** | வேற வேற ஆனா பொருந்துற shapes உள்ள arrays-ஐ சேர்க்கிறது | `X - X.mean(axis=0)` |
| **Masks and indexing** | Condition அல்லது position வச்சு data-வை select பண்றது | `y[y > 30]`, `X[:, 0]` |
| **Plotting** | Distributions, relationships, trends-ஐ பார்க்கிறது | histogram, scatter, line, box plot |

## இது எப்படி work ஆகுது

### Arrays and shapes

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.shape)          # (2, 2)
```

12 features இருக்குற 10,000 customers dataset-க்கு shape `(10000, 12)`. ஒரு single row-வோட shape `(12,)`. Numerical code-ல பெரும்பாலான bugs shape mismatches தான், அதனால `.shape`-ஐ அடிக்கடி print பண்ணுங்க.

### Vectorisation

```python
prices = np.array([120, 450, 999])
with_gst = prices * 1.18            # every element at once
print(np.mean(prices), np.std(prices), np.percentile(prices, 90))
```

Vectorised code loop-ஐ விட சுருக்கமா இருக்கும், பெரிய arrays-ல பல மடங்கு வேகமாவும் இருக்கும்; ஏன்னா வேலை உள்ளுக்குள்ள optimised code-ல நடக்குது.

**axis** argument திசையை முடிவு பண்ணும்:

| Call | Result |
| --- | --- |
| `X.mean()` | ஒரே ஒரு number: எல்லாத்தோட mean |
| `X.mean(axis=0)` | ஒவ்வொரு column-க்கும் ஒரு value: ஒவ்வொரு feature-ஓட mean |
| `X.mean(axis=1)` | ஒவ்வொரு row-க்கும் ஒரு value: ஒவ்வொரு record-ஓட mean |

### Broadcasting

Shapes பொருந்துற மாதிரி இருந்தா, NumPy ஒரு சின்ன array-ஐ பெரிய array-க்கு ஏத்த மாதிரி நீட்டிக்கும். `(10000, 12)` array-ல இருந்து `(12,)` array-ஆ இருக்குற column means-ஐ கழிச்சா, ஒரே வரியில ஒவ்வொரு column-ஐயும் centre பண்ணலாம்:

```python
Z = (X - X.mean(axis=0)) / X.std(axis=0)    # each column: mean 0, std 1
```

### Indexing and slicing

Arrays-ஐ position வச்சு, 0-ல இருந்து ஆரம்பிச்சு, ஒவ்வொரு dimension-க்கும் ஒரு index-ஓட access பண்றோம்:

```python
X[0]          # the first row: all features of the first record
X[:, 0]       # the first column: one feature for every record
X[10:20, 1:]  # rows 10 to 19, and every column from the second onwards
X[-1]         # the last row
```

Colon-க்கு "இந்த dimension-ல இருக்குற எல்லாமே"ன்னு அர்த்தம். `X[:, 0]`-ஐ "எல்லா rows, column zero"ன்னு சத்தமா படிச்சா உதவும். Slices copies இல்லை, views: ஒரு slice-ஐ மாத்துனா அசல் array-உம் மாறும்; அதனால தனியா ஒரு துண்டு வேணும்னா `.copy()` use பண்ணுங்க.

### Boolean masks

```python
incomes = np.array([18000, 52000, 75000, 31000])
print(incomes[incomes > 50000])                     # [52000 75000]
print(incomes[(incomes > 20000) & (incomes < 60000)])
```

"and"-க்கு `&`, "or"-க்கு `|` use பண்ணுங்க, ஒவ்வொரு condition-ஐயும் brackets-ல போடுங்க.

### Reproducible random numbers

`rng = np.random.default_rng(42)` துல்லியமா மறுபடி உருவாக்கக்கூடிய ஒரு random generator-ஐ கொடுக்கும்; data-வை sample பண்ணவோ training, test sets-ஆ பிரிக்கவோ இது பயன்படும்.

### Machine learning-ல முக்கியமான plots

| Plot | என்ன காட்டும் | பொதுவா கிடைக்கிற finding |
| --- | --- | --- |
| **Histogram** | ஒரு feature-ஓட distribution | Skew, outliers, zeros மாதிரி சாத்தியமில்லாத values |
| **Scatter plot** | ரெண்டு features-க்கு இடையில, அல்லது ஒரு feature-க்கும் target-க்கும் இடையில இருக்குற தொடர்பு | ஒரு curve, ஒரு cluster, ஏதோ ஒரு value-ல ஒரு break |
| **Line chart** | காலத்தோட மாறுற values | Seasonality, திடீர் வீழ்ச்சி, epoch வாரியா training loss |
| **Box plot** | Groups முழுவதும் distributions | ஒரு city-ஓட deliveries மத்ததை விட ரொம்ப மெதுவா இருக்கு |

Axes-ஐயும் units-ஐயும் எப்பவும் label பண்ணுங்க, order values மாதிரி ரொம்ப skewed data-வுக்கு **log scale** use பண்ணுங்க.

## ஒரு உதாரணம்

Bengaluru-ல ஒரு quick-commerce company, delivery time-ஐ predict பண்ண நினைக்குது. 50,000 deliveries-ஐ arrays-ஆ load பண்றீங்க: km-ல distance, items எண்ணிக்கை, நாளோட மணி நேரம், உண்மையில எடுத்த நிமிஷங்கள்.

```python
import numpy as np
import matplotlib.pyplot as plt

# X (distance, items, hour) and y (minutes) were loaded earlier
print(X.shape, y.shape)                  # (50000, 3) (50000,)
print(np.percentile(y, [50, 90, 99]))    # median 14, p90 24, p99 61 minutes

plt.hist(y, bins=60)
plt.xlabel("Delivery time (minutes)"); plt.ylabel("Orders")
plt.show()

plt.scatter(X[:, 0], y, s=2, alpha=0.3)
plt.xlabel("Distance (km)"); plt.ylabel("Minutes")
plt.show()
```

**Histogram என்ன காட்டுது.** எதிர்பார்த்த மாதிரி மெதுவான deliveries-ஓட நீண்ட tail, அப்புறம் சரியா 0 நிமிஷத்துல ஒரு விசித்திரமான spike: 412 deliveries எந்த நேரமும் எடுக்கலைன்னு பதிவாகியிருக்கு. இது அதிசயம் இல்லை, ஒரு logging bug.

**Scatter plot என்ன காட்டுது.** Distance கூடக்கூட, சுமார் 6 km வரை times சீரா ஏறுது, அப்புறம் திடீர்னு தாவுது. அந்த orders-ஐ check பண்ணா, அவை குறைவான riders இருக்குற வேற ஒரு dark store-ல இருந்து வந்தவைன்னு தெரியுது.

| Plot | Finding | Model-ல என்ன மாத்தணும் |
| --- | --- | --- |
| நிமிஷங்களோட Histogram | 0 நிமிஷத்துல 412 deliveries | அந்த rows-ஐ நீக்கு அல்லது சரி பண்ணு; bug-ஐ report பண்ணு |
| Distance vs நிமிஷங்கள் scatter | 6 km-க்கு மேல ஒரு தாவல் | ஒரு "store" feature-ஐ சேர் |
| Percentiles | p99 61 நிமிஷம் | Average மட்டும் இல்லாம, p90, p99-ல errors-ஐ report பண்ணு |

எந்த ஒரு metric-உம், எந்த model-ஐயும் train பண்றதுக்கு முன்னாடியே, ஐந்து நிமிஷத்துல, ரெண்டு plots மாதிரி இதை தெளிவா காட்டியிருக்காது.

## பொதுவா பண்ற தப்புகள்

- **Arrays மேல Python loops.** Vectorise பண்ணுங்க; சுருக்கமாவும் ரொம்ப வேகமாவும் இருக்கும்.
- **Shapes-ஐ கண்டுக்காம விடுறது.** அவற்றை print பண்ணி, broadcasting நீங்க எதிர்பார்த்த மாதிரி நடக்குதான்னு check பண்ணுங்க.
- **Plot பண்றதுக்கு முன்னாடியே modelling.** Plots bugs, outliers, leakage-ஐ ஆரம்பத்துலயே காட்டும்.
- **Label இல்லாத charts.** Axes-உம் units-உம் மத்தவங்களுக்கு plots-ஐ படிக்கிற மாதிரி ஆக்கும்.
- **Skewed data-வுக்கு linear scales.** Values பல magnitude அளவுகள்ல பரவியிருக்குற இடத்துல log scales use பண்ணுங்க.
- **axis=0-வையும் axis=1-ஐயும் குழப்பிக்கிறது.** திசையை confirm பண்ண result-ஓட shape-ஐ check பண்ணுங்க.
