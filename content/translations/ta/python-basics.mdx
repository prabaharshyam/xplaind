## இது என்ன

Python தான் AI வேலையோட முக்கியமான language: data cleaning, automation scripts, AI APIs-ஐ call பண்றது, applications build பண்றது எல்லாத்துலயும் அதை use பண்றாங்க. பயன்படுற அளவுக்கு இருக்க, Python முழுசையும் கத்துக்க தேவையில்லை. அஞ்சு building blocks இருந்தா பெரும்பாலான சின்ன programs-ஐ எழுதலாம்:

| Building block | என்ன பண்ணும் | உதாரணம் |
| --- | --- | --- |
| **Variables** | ஒரு பேருல ஒரு value-ஐ store பண்ணும் | `price = 250` |
| **Conditions** | என்ன பண்றதுன்னு தேர்ந்தெடுக்கும் | `if price > 200:` |
| **Loops** | Steps-ஐ திரும்ப திரும்ப செய்யும் | `for item in cart:` |
| **Functions** | மறுபடி use பண்ணக்கூடிய steps-ஐ package பண்ணும் | `def total(cart):` |
| **Lists, dictionaries** | நிறைய values-ஐ வச்சிருக்கும் | prices-ஓட ஒரு list, ஒரு student-ஓட details-ஓட ஒரு dictionary |

```flow
dir: LR
உள்ள போற data | orders, prices, marks -> உங்க program | variables values-ஐ வச்சிருக்கும், loops ஒவ்வொரு order-ஐயும் பாக்கும், conditions ஒரு price-ஐ தேர்ந்தெடுக்கும், functions கணக்கு போடும்
உங்க program -> வெளிய வர்ற result | bills, totals, reports
```

இந்த lesson Bengaluru-ல ஒரு tiffin service நடத்துற Divya, தன் customers-ஓட bills-ஐ கணக்கு போட தன்னோட முதல் பயனுள்ள program-ஐ எழுதுறதை follow பண்ணும். முடிக்கும் போது, உங்க சொந்த 20-line program-ஐ எழுதி explain பண்ண முடியும்.

## இது எப்படி work ஆகுது

### Values, types

Python-ல சில அடிப்படை வகை values இருக்கு:

| Type | உதாரணங்கள் | குறிப்புகள் |
| --- | --- | --- |
| முழு எண்கள் (`int`) | `250`, `-3` | Counts, paise இல்லாத rupees-க்கு |
| தசம எண்கள் (`float`) | `18.5`, `0.18` | Rates, averages-க்கு |
| Text (`str`) | `"Chennai"`, `'Asha'` | எப்பவும் quotes-குள்ள |
| True அல்லது false (`bool`) | `True`, `False` | Comparisons-ஓட results |

Value-ல இருந்து type-ஐ Python தானா கண்டுபிடிக்கும். Types-க்கு நடுவுல `int("42")`, `float("3.5")`, `str(42)` வச்சு convert பண்ணலாம்.

### Variables

Variable ஒரு value-க்கான label. திரும்ப assign பண்ணா, அது எதை சுட்டுதுன்னு மாறும்:

```python
monthly_rent = 15000
monthly_rent = monthly_rent + 500    # now 15500
```

`x` மாதிரி இல்லாம, `monthly_rent` மாதிரி தெளிவான பேர்களை use பண்ணுங்க. அடுத்த மாசம் நீங்களே நன்றி சொல்லுவீங்க.

### Conditions

```python
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Pass")
```

Indentation, நாலு spaces, எந்த lines ஒவ்வொரு branch-க்கு சொந்தம்ன்னு காட்டும். Python இதை serious-ஆ எடுத்துக்கும்: தப்பான indentation ஒரு error ஆகும், இல்லன்னா, அதைவிட மோசமா, program செய்யுறதையே மாத்தும்.

Comparisons `==` (equal), `!=` (not equal), `>`, `>=`, `<`, `<=` use பண்ணும். ஒரு `=` assign பண்ணும்; compare பண்ணாது.

### Loops

ஒரு `for` loop ஒவ்வொரு item-க்கும் ஒரு தடவை ஓடும்:

```python
for city in ["Pune", "Kochi", "Jaipur"]:
    print("Delivering to", city)

for i in range(3):
    print(i)        # prints 0, then 1, then 2
```

`range(3)` 0, 1, 2 தரும்: 0-ல ஆரம்பிச்சு 3-க்கு **முன்னாடி** நிக்கும். ஒரு `while` loop ஒரு condition true-ஆ இருக்குற வரைக்கும் திரும்ப திரும்ப ஓடும்; எத்தனை தடவை repeat பண்ணணும்ன்னு முன்னாடியே தெரியாதப்போ இது உதவும்.

### Functions

ஒரு function inputs-ஐ எடுத்து, கொஞ்சம் வேலை பண்ணி, ஒரு result-ஐ `return` பண்ணும்:

```python
def gst(amount, rate=0.18):
    return amount * rate

print(gst(1000))         # 180.0
print(gst(1000, 0.05))   # 50.0
```

`rate=0.18` ஒரு default: நீங்க rate-ஐ pass பண்ணாதப்போ அது use ஆகும். அதே சில lines-ஐ copy பண்றதை பார்த்தா, ஒரு function எழுதுங்க.

### Lists

Ordered collections:

```python
cities = ["Pune", "Kochi"]
cities.append("Jaipur")     # add to the end
print(cities[0])            # Pune: counting starts at 0
print(len(cities))          # 3
```

### Dictionaries

Position-க்கு பதிலா ஒரு key வச்சு values-ஐ தேடுங்க:

```python
profile = {"name": "Asha", "age": 24}
profile["city"] = "Pune"     # add or change a key
print(profile["name"])       # Asha
```

Python-ல பெரும்பாலான real data **dictionaries-ஓட ஒரு list**-ஆ தான் இருக்கும்: ஒவ்வொரு dictionary-யும் ஒரு spreadsheet-ஓட ஒரு row மாதிரி ஒரு record.

### Error messages-ஐ படிக்கிறது

ஏதாவது தப்பா போனா, Python ஒரு **traceback**-ஐ print பண்ணும். கீழ இருந்து மேல படிங்க: கடைசி line error-ஓட பேரை சொல்லும், அதுக்கு மேல இருக்குற line அது எங்க நடந்ததுன்னு காட்டும்.

```text
Traceback (most recent call last):
  File "bill.py", line 12, in <module>
    total = total + amount
TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

இது சொல்றது: line 12-ல நீங்க ஒரு number-ஓட ஒரு text-ஐ கூட்ட try பண்ணீங்க. Value படிச்ச இடத்துல text-ஐ `int()` வச்சு convert பண்றது தான் fix. Errors சாதாரணம்; அமைதியா அவற்றை படிக்கிறது programming-ல பாதி.

## ஒரு நாள், ஒரு example

Divya Bengaluru-ல ஒரு சின்ன tiffin service நடத்துறாங்க; orders-ஐ இதுவரை தன் தலையிலயே வச்சிருந்தாங்க. Veg meal ₹90, non-veg ₹120. அவங்க தன்னோட முதல் பயனுள்ள program-ஐ எழுதுறாங்க:

```python
orders = [
    {"customer": "Ravi", "meals": 2, "veg": True},
    {"customer": "Sana", "meals": 1, "veg": False},
    {"customer": "Arun", "meals": 3, "veg": True},
]
PRICE_VEG = 90
PRICE_NONVEG = 120

def bill(order):
    price = PRICE_VEG if order["veg"] else PRICE_NONVEG
    return order["meals"] * price

total = 0
for order in orders:
    amount = bill(order)
    total = total + amount
    print(order["customer"], "owes Rs", amount)

print("Today's total: Rs", total)
```

படிப்படியா என்ன நடக்குதுன்னு பாருங்க:

| Loop pass | Customer | Veg? | Price | Meals | Bill | Running total |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Ravi | ஆமா | 90 | 2 | 180 | 180 |
| 2 | Sana | இல்லை | 120 | 1 | 120 | 300 |
| 3 | Arun | ஆமா | 90 | 3 | 270 | 570 |

Program ஒவ்வொரு customer-ஓட bill-ஐயும், அன்னைக்கு மொத்தம் ₹570-ஐயும் print பண்ணும். Prices மாறுனா, மேல இருக்குற ரெண்டு lines-ஐ edit பண்ணா போதும். Prices capital letters-ல இருக்கு; இவை settings, program மாத்துற values இல்லன்னு நினைவூட்டுறதுக்கு.

அடுத்து, orders-ஐ program-குள்ள type பண்றதுக்கு பதிலா ஒரு CSV file-ல இருந்து படிக்கணும்ன்னு அவங்க plan பண்றாங்க; அதை files பத்தின lesson cover பண்ணும்.

## பொதுவா பண்ற தப்புகள்

- **தப்பான indentation.** `if`, `for`, `def`-குள்ள இருக்குற lines consistent-ஆ indent ஆகியிருக்கணும், பொதுவா நாலு spaces.
- **`range`-ல off-by-one.** `range(3)` 0, 1, 2; 1, 2, 3 இல்லை.
- **Text, numbers-ஐ கலக்குறது.** `"5" + 3` fail ஆகும்; முதல்ல `int()` அல்லது `str()` வச்சு convert பண்ணுங்க.
- **Condition-ல `=` use பண்றது.** Compare பண்றது `==`.
- **Function-ல `return`-க்கு பதிலா `print`.** Print ஒரு value-ஐ காட்டும்; return அதை use பண்றதுக்கு திருப்பி கொடுக்கும்.
- **தெளிவில்லாத பேர்கள்.** `a`, `b`, `temp` programs-ஐ படிக்க கஷ்டமாக்கும்; ஒவ்வொண்ணும் எதை வச்சிருக்குதோ அதுக்கு ஏத்த பேர் வைங்க.
