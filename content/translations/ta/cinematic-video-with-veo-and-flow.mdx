## இது என்ன

**Veo** என்பது Google DeepMind-ஓட **text-to-video** models குடும்பம். ஒரு shot-ஐ விவரிச்சாலோ images கொடுத்தாலோ, அது ஒரு சின்ன realistic clip-ஐ generate பண்ணும். Veo 3, Veo 3.1 மாதிரி recent versions **synchronised sound**-ஐயும் generate பண்ணும்: ambience, effects, பேசுற வரிகள் கூட. இதனால AI video ரொம்பவே நிஜம் மாதிரி தெரியுது.

**Flow** என்பது Veo-வை சுத்தி கட்டின Google-ஓட AI filmmaking tool. ஒரு நேரத்துல ஒரு clip-ஆ இல்லாம, ஒரு director மாதிரி வேலை செய்றீங்க: shots-ஐ generate பண்றீங்க, characters-ஐயும் objects-ஐயும் மறுபடி use பண்ணக்கூடிய references-ஆ வச்சிருக்கீங்க, shots-ஐ நீட்டுறீங்க, scenes-ஆ அடுக்குறீங்க. Flow-வை Google-ஓட AI plans வழியா அணுகலாம்; plans-ம் credits-ம் அடிக்கடி மாறும், அதனால Google-ஓட site-ல இப்போதைய details-ஐ பாருங்க.

Image generators மாதிரியே, Veo-வும் **diffusion models** அடிப்படையிலானது: noise-ல இருந்து ஆரம்பிச்சு, உங்க prompt வழிகாட்ட, நேரத்துல ஒண்ணோடு ஒண்ணு பொருந்துற frames-ஆ refine பண்ணும்.

```flow
Idea -> Shot list | 4-8 shots: subject, action, camera, light, sound -> Flow + Veo
Flow + Veo -[text to video]-> வார்த்தைகள்ல மட்டும் இருந்து ஒரு clip
Flow + Veo -[frames to video]-> முதல், கடைசி image-ல இருந்து ஒரு clip
Flow + Veo -[ingredients]-> Character, product, style images-ல இருந்து ஒரு clip
வார்த்தைகள்ல மட்டும் இருந்து ஒரு clip -> Review
முதல், கடைசி image-ல இருந்து ஒரு clip -> Review
Character, product, style images-ல இருந்து ஒரு clip -> Review
Review -> பலவீனமான shots-ஐ regenerate பண்ணு -> Extend அல்லது trim பண்ணு -> Edit | வரிசை, music, titles -> Export
```

## இது எப்படி work ஆகுது

**Videos-ஆ இல்ல, shots-ஆ யோசிங்க.** ஒவ்வொரு generation-உம் சில seconds தான். 30 seconds ad என்பது editor-ல இணைச்ச அஞ்சு ஆறு shots. ஒரு நிஜ director மாதிரி முதல்ல ஒரு **shot list** எழுதுங்க.

**ஒரு cinematographer பேசுற மாதிரி prompts எழுதுங்க.** ஒரு வலுவான prompt-ல இவை இருக்கும்:

| Element | என்ன சொல்லணும் | Example |
|---|---|---|
| Subject | யார் அல்லது என்ன, குறிப்பான details-ஓட | an elderly weaver with silver hair, cream kurta |
| Action | ஒரு shot-க்கு ஒரு தெளிவான action | slides the shuttle across the loom |
| Setting | இடம், நேரம், வானிலை | a dim workshop in Varanasi, morning light through a window |
| Camera | shot size, angle, movement, lens | close-up, slow dolly in, 50 mm, shallow depth of field |
| Lighting, look | mood, colour grade | warm, soft window light, gentle film grain |
| Sound (audio உள்ள Veo) | ambience, effects, dialogue | the clack of the loom, distant temple bells |

**Flow-ல generate பண்ண மூணு முக்கிய வழிகளை use பண்ணுங்க.**

- **Text to video:** prompt மட்டும். Establishing shots-க்கும் ideas-க்கும் நல்லது.
- **Frames to video:** நீங்க உருவாக்கின அல்லது photo எடுத்த ஒரு image-ல இருந்து ஆரம்பிக்கணும், விருப்பப்பட்டா இன்னொண்ணுல முடிக்கலாம். அதனால composition-ஐ நீங்களே control பண்ணலாம். Product shots-க்கும் continuity-க்கும் ரொம்ப ஏத்தது.
- **Ingredients to video:** உங்க character, product, ஒரு style frame மாதிரி பல reference images கொடுங்க, Veo அவற்றை consistent-ஆ வச்சிருக்குற clip-ஐ கட்டும்.

**Consistency-ஐ பாதுகாங்க.** முதல்ல ஒவ்வொரு character அல்லது product-க்கும் ஒரு வலுவான reference image உருவாக்குங்க (ஒரு image model-ஆல, அடுத்த guide-ஐ பாருங்க). ஒவ்வொரு shot-லயும் அதை மறுபடி use பண்ணுங்க, ஒவ்வொரு prompt-லயும் அதே சின்ன description-ஐ repeat பண்ணுங்க.

**Iterate பண்ணுங்க.** ஒவ்வொரு shot-க்கும் ரெண்டு முதல் நாலு versions generate பண்ணி, சிறந்ததை வச்சுக்கோங்க. பிரச்சனைகளை, எல்லாத்தையும் மறுபடி எழுதாம, குறிப்பான மாற்றங்களால சரி பண்ணுங்க ("hands stay on the loom", "no text on screen").

**Edit பண்ணுங்க.** Clips-ஐ download பண்ணி, CapCut, DaVinci Resolve, Premiere மாதிரி ஏதாவது editor-ல, அல்லது Flow-ஓட சொந்த scene tools-ல வெட்டுங்க. Music, voice-over, ஒரு title card சேருங்க.

**Credits-க்கு budget போடுங்க.** ஒவ்வொரு generation-உம் உங்க plan-ல இருந்து credits எடுக்கும், உயர் quality modes அதிகமா எடுக்கும். முதல்ல shots-ஐ காகிதத்துல plan பண்ணுங்க, வேகமான அல்லது மலிவான modes இருந்தா அவற்றுல ideas-ஐ test பண்ணுங்க, இறுதி takes-க்கு சிறந்த settings-ஐ சேமிங்க.

## ஒரு worked example

Rohan ஒரு சின்ன Banarasi handloom label-ஓட marketing-ஐ பார்க்கிறாரு. அவங்க budget-ல film crew-க்கு இடமில்ல, ஆனா Diwali-க்கு முன்னாடி Instagram-க்கு 30 seconds ad வேணும்.

அவர் ஆறு shots எழுதுறாரு: workshop lane-ஓட விடியல் exterior; loom-ல weaver-ஓட கைகளோட close-up; தங்கமும் சிவப்புமான பட்டு நூல்கள்; Bengaluru-ல ஒரு இளம்பெண் saree-ஐ unbox பண்றது; கண்ணாடி முன்னாடி அவங்க அதை உடுத்துறது; brand name-ஓட ஒரு title card.

அவர் நிஜ saree-ஐ பகல் வெளிச்சத்துல தட்டையா photo எடுத்து, shots 3 முதல் 5 வரை **ingredient**-ஆ use பண்றாரு, அதனால pattern உண்மையா இருக்கும். ஒரு image model-ஆல இளம்பெண்ணுக்கு ஒரு reference image செஞ்சு, shots 4, 5-ல மறுபடி use பண்றாரு. அவரோட prompts camera moves-ஐயும் sound-ஐயும் குறிப்பிடுது: "clack of the loom", "soft temple bells", "cardboard rustle".

முதல் pass-ல ரெண்டு பிரச்சனை: ஒரு shot-ல weaver-க்கு ஆறு விரல்கள், shot 5-ல saree border-ஓட நிறம் மாறுது. கை shot-ஐ "close-up of two hands, natural anatomy"-ஓட regenerate பண்றாரு, shot 5-ஐ **frames to video**-க்கு மாத்தி, சரியான border-ஓட ஒரு still-ல இருந்து ஆரம்பிக்கிறாரு. சிறந்த takes-ஐ CapCut-ல edit பண்ணி, licence உள்ள ஒரு sitar track-ஐயும் title card-ஐயும் சேர்த்து, post-ஐ AI-வால செஞ்சதுன்னு label பண்றாரு.

ஒரு shoot-க்கு பதிலா, இந்த ad-க்கு ஒரு நாள் வேலையும் சில நூறு credits-உம் தான் செலவு. அப்புறம் brand அதே references-ஐ இன்னும் மூணு festival posts-க்கு use பண்ணுது.

## பொதுவான தப்புகள்

**முழு video-க்கும் ஒரே தெளிவில்லாத prompt.** Shots-ஐ plan பண்ணுங்க. ஒவ்வொரு prompt-உம் ஒரு action உள்ள ஒரு shot-ஐ விவரிக்கணும்.

**Shots-க்கு நடுவுல descriptions-ஐ மாத்துறது.** "a woman in a red saree"-யும் "a lady in maroon"-ஐயும் model வேற வேற ஆட்களா எடுத்துக்கும். அதே exact wording-ஐயும் reference images-ஐயும் மறுபடி use பண்ணுங்க.

**ஒரு shot-ல ரொம்ப அதிகம்.** பல actions, நிறைய ஆட்கள், சிக்கலான கை அசைவுகள் artefacts உருவாக்கும். ஒவ்வொரு shot-ஐயும் simple-ஆ வைங்க.

**Sound-ஐ புறக்கணிக்கிறது.** Veo-ஓட audio, realism-ல ஒரு பகுதி. அதை விவரிங்க, இல்லன்னா அதை off பண்ணி உங்க சொந்தத்தை சேருங்க.

**அனுமதி இல்லாம நிஜ மனுஷங்களையோ brands-ஐயோ use பண்றது.** Public figures-ஐயோ மற்ற companies-ஓட logos-ஐயோ generate பண்ணாதீங்க, ஒருத்தரை அடிப்படையா வச்சு character உருவாக்கினா அவங்க consent வாங்குங்க.
