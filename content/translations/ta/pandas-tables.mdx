## இது என்ன

Business-ல பெரும்பாலான data tables-ல தான் இருக்கும்: sales exports, customer lists, attendance sheets, survey results. **pandas** என்பது tables-ஓட வேலை செய்ய உதவுற Python library. அதோட முக்கிய object-ஆன **DataFrame**, rows-ஐயும் பேர் இருக்குற columns-ஐயும் வச்சிருக்கும்; code வச்சு நீங்க control பண்ற spreadsheet மாதிரி.

**DataFrame: df.** Columns-க்கு பேர்கள் இருக்கு; rows-க்கு ஒரு index இருக்கு.

| index | date | store | item | amount |
|---|---|---|---|---|
| 0 | 2026-10-01 | RS Puram | Glucometer | 1250.0 |
| 1 | 2026-10-01 | Gandhipuram | Paracetamol | 40.0 |
| 2 | 2026-10-02 | RS Puram | Insulin pen | 2100.0 |

சில வரிகள்ல, ஒரு CSV அல்லது Excel file-ஐ load பண்ணி, clean பண்ணி, rows-ஐ filter பண்ணி, group பண்ணி summarise பண்ணி, tables-ஐ join பண்ணி, result-ஐ save பண்ணலாம். Spreadsheet மாதிரி இல்லாம, steps எழுதி வைக்கப்படுது; அதனால அடுத்த மாசத்து report ஒரு நாள் முழுக்க click பண்றது இல்லாம, ஒரே ஒரு command தான்.

AI வேலைக்கு, training data-வை தயார் பண்ணவும், model outputs-ஐ பார்க்கவும், evaluation reports build பண்ணவும் pandas தான் வழி.

இந்த lesson-ல Coimbatore-ல ஐந்து pharmacies-ஐ நடத்துற Lakshmi, மாசாமாசம் வர்ற 40,000-row export-ஐ வினாடிகள்ல answers-ஆ மாத்துறதை follow பண்றோம். Lesson முடியும் போது, ஒரு குழப்பமான CSV-ஐ load பண்ணி, clean பண்ணி, மறுபடி run பண்ணக்கூடிய ஒரு grouped summary-ஐ உருவாக்க முடியும்.

## இது எப்படி work ஆகுது

### Load பண்ணி பாருங்க

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()           # first five rows
df.info()           # columns, types, missing values
df.describe()       # quick statistics for number columns
```

Calculate பண்றதுக்கு முன்னாடி எப்பவும் பாருங்க. நீங்க numbers-ஆ எதிர்பார்த்த ஒரு column text-ஆ படிக்கப்பட்டிருக்கான்னு `info()` சொல்லும்.

### Columns-ஐ select பண்றது, rows-ஐ filter பண்றது

```python
df["city"]                                        # one column
df[["city", "sales"]]                             # several columns
df[df["age"] > 30]                                # rows where age is above 30
df[(df["city"] == "Pune") & (df["sales"] > 5000)] # two conditions
```

"and"-க்கு `&`, "or"-க்கு `|` use பண்ணுங்க, ஒவ்வொரு condition-ஐயும் brackets-ல போடுங்க. சாதாரண `and`, `or` இங்க work ஆகாது.

### Missing values

காலியான அல்லது படிக்க முடியாத cells **NaN** ("not a number")-ஆ தெரியும். `df.isna().sum()` வச்சு அவற்றை கண்டுபிடிங்க. அப்புறம் வேணும்னே முடிவு பண்ணுங்க: `fillna`-ஆல நிரப்புங்க, `dropna`-ஆல அந்த rows-ஐ நீக்குங்க, இல்லன்னா யாராவது check பண்றதுக்கு flag பண்ணுங்க.

### Types-ஐ சரி பண்றது

| பிரச்சனை | Fix |
| --- | --- |
| "1,250" மாதிரி amounts text-ஆ படிக்கப்பட்டது | `pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")` |
| 05/11/2026 மாதிரி dates | `pd.to_datetime(df["date"], dayfirst=True)` |
| Item codes-ஓட ஆரம்ப zeros போயிடுது | `pd.read_csv(..., dtype={"item_code": str})` |

`errors="coerce"`, படிக்க முடியாத எல்லாத்தையும் crash ஆகாம NaN-ஆ மாத்தும்; அதனால மோசமான rows-ஐ எண்ணி report பண்ணலாம்.

### புது columns

```python
df["gst"] = df["sales"] * 0.18
df["month"] = pd.to_datetime(df["date"], dayfirst=True).dt.month
```

### Group பண்ணி summarise பண்றது

```python
df.groupby("city")["sales"].sum()                                # total per city
df.groupby(["city", "month"])["sales"].agg(["sum", "mean", "count"])
```

```flow
எல்லா rows -[city வாரியா split]-> Pune rows
எல்லா rows -[city வாரியா split]-> Nagpur rows
எல்லா rows -[city வாரியா split]-> Nashik rows
Pune rows -[sum()]-> Pune: 4.2 lakh
Nagpur rows -[sum()]-> Nagpur: 3.1 lakh
Nashik rows -[sum()]-> Nashik: 2.7 lakh
```

### Sort பண்ணி save பண்றது

```python
df.sort_values("sales", ascending=False).head(10)
df.to_csv("clean_sales.csv", index=False)
```

### Pivot tables வச்சு reshape பண்றது

Spreadsheet பயன்படுத்துறவங்களுக்கு pivot tables ரொம்ப பிடிக்கும்; pandas-லயும் அது இருக்கு:

```python
df.pivot_table(index="store", columns="month", values="amount", aggfunc="sum")
```

இது ஒவ்வொரு store-க்கும் ஒரு row, ஒவ்வொரு மாசத்துக்கும் ஒரு column கொடுத்து, ஒவ்வொரு cell-லயும் totals-ஐ வைக்கும். ஒரு manager-க்கு trend-ஐ காட்ட இது பெரும்பாலும் தெளிவான வழி. Row, column totals-க்கு `margins=True` சேருங்க.

### Dates-ஓட வேலை செய்யுங்க

ஒரு column உண்மையான date ஆனதும், pandas அதை வச்சு நிறைய செய்யலாம்:

```python
df["date"] = pd.to_datetime(df["date"], dayfirst=True)
df["weekday"] = df["date"].dt.day_name()             # Monday, Tuesday...
weekly = df.set_index("date").resample("W")["amount"].sum()
```

`resample("W")` வாரம் வாரமா sales-ஐ கூட்டும்; calendar months-க்கு `"MS"` use பண்ணுங்க. ஞாயிற்றுக்கிழமை sales எப்பவும் குறைவு, அல்லது தீபாவளிக்கு முந்தின வாரம் தான் வருஷத்தோட உச்சம்னு இப்படித் தான் கண்டுபிடிக்கிறோம்.

### Tables-ஐ join பண்றது

```python
pd.merge(orders, customers, on="customer_id", how="left")
```

| `how=` | எதை வச்சிருக்கும் |
| --- | --- |
| `"inner"` | ரெண்டு tables-லயும் பொருந்துற rows மட்டும் |
| `"left"` | Left table-ஓட ஒவ்வொரு row-வும், match இல்லாத இடத்துல blanks-ஓட |
| `"outer"` | ரெண்டு tables-ஓட ஒவ்வொரு row-வும் |

Inner joins சத்தமில்லாம rows-ஐ drop பண்ணிடலாம். Merge பண்றதுக்கு முன்னாடியும் பின்னாடியும் row counts-ஐ check பண்ணுங்க.

## ஒரு உதாரணம்

Lakshmi, Coimbatore-ல ஐந்து pharmacies-ஓட ஒரு chain-ஐ நடத்துறாங்க. ஒவ்வொரு மாசமும் சுமார் 40,000 rows இருக்குற ஒரு sales export அவங்களுக்கு வரும்; அதை ஒரு spreadsheet-ல summarise பண்ண ஒரு நாள் செலவழிப்பாங்க.

```python
df = pd.read_csv("sales_oct.csv")
df["amount"] = pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")
print(df["amount"].isna().sum(), "rows with unreadable amounts")

by_store = df.groupby("store")["amount"].sum().sort_values(ascending=False)
print(by_store)

top_items = (df[df["category"] == "Diabetes care"]
             .groupby("item")["amount"].sum()
             .sort_values(ascending=False).head(5))
print(top_items)
```

இந்த 40% இடைவெளியால, diabetes-care products-ஓட stock-ஐ stores-க்கு நடுவுல நகர்த்துறாங்க; அதனால மத்த branches-ல stock தீர்ந்து போறது நிக்குது, RS Puram-ல overstock ஆகுறதும் நிக்குது. அவங்களுக்கு ஒரு நாள் எடுத்த analysis இப்போ ஒவ்வொரு மாசமும் வினாடிகள்ல ஓடுது; steps code-ல இருக்கிறதால, November report அதே script தான், file பேர் மட்டும் வேற.

### உங்க வேலையை check பண்ணுங்க

யாருக்காவது numbers அனுப்புறதுக்கு முன்னாடி, அவற்றை check பண்ணுங்க. மொத்த total-ஐ source system-ல இருக்குற total-ஓட ஒப்பிடுங்க. ஒவ்வொரு filter, merge-க்கு முன்னாடியும் பின்னாடியும் rows-ஐ எண்ணி, மாற்றம் இருந்தா அதை விளக்குங்க. ஐந்து பெரிய, ஐந்து சின்ன values-ஐ பாருங்க; ரூபாய்க்கு பதிலா பைசாவுல ஒரு விலை உள்ளிடப்பட்டிருக்குற மாதிரி தப்புகள் இருக்கலாம். ஒரு number-ஐ கையால மறுபடி கணக்கிடுங்க. இந்த checks சில நிமிஷங்கள் தான் ஆகும்; ஆனா ஒரு தப்பான report owner-கிட்ட போற அவமானத்துல இருந்து உங்களை காப்பாத்தும்.

## பொதுவா பண்ற தப்புகள்

- **Types-ஐ check பண்ணாம இருக்குறது.** Commas இருக்கிறதால text-ஆ படிக்கப்பட்ட numbers-ஐ sum பண்ண முடியாது. அவற்றை convert பண்ணுங்க.
- **Missing values-ஐ கண்டுக்காம விடுறது.** நிரப்புறதா, நீக்குறதா, flag பண்றதான்னு முடிவு பண்ணி, எதுன்னு சொல்லுங்க.
- **தப்பான date order.** இந்திய dates day first; `dayfirst=True` அல்லது ஒரு explicit format use பண்ணுங்க.
- **Filters-ல `&`-க்கு பதிலா `and` use பண்றது.** Brackets-ஓட `&`, `|` use பண்ணுங்க.
- **சத்தமில்லாம rows-ஐ drop பண்ற inner joins.** Merge பண்றதுக்கு முன்னாடியும் பின்னாடியும் row counts-ஐ check பண்ணுங்க.
- **அசல் file-ஐ edit பண்றது.** Clean பண்ண data-வை புது file-ல save பண்ணி, raw export-ஐ அப்படியே விடுங்க.
