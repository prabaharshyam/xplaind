## இது என்ன

இது வரைக்கும் நீங்க எழுதுன programs-ல data code-க்குள்ளயே இருந்துச்சு. Real programs files-ல இருந்து data படிச்சு, results-ஐ திரும்ப எழுதும். Real data messy-ஆ இருக்கும்: file இல்லாம போகலாம், ஒரு row தப்பான format-ல இருக்கலாம், number இருக்க வேண்டிய இடத்துல "NA" இருக்கலாம். இதுக்கு ரெண்டு skills வேணும்:

- **File input, output:** text, CSV files-ஐ safe-ஆ திறந்து, படிச்சு, எழுதுறது.
- **Error handling:** **exceptions**-ஐ catch பண்ணி, ஒரு bad input வந்ததுக்காக முழு program-உம் crash ஆகாம பார்த்துக்கிறது, problems-ஐ clear-ஆ report பண்றது.

```flow
dir: LR
Input: payments.csv | 412 rows, அதுல 3 bad -> ஒவ்வொரு row-க்கும் | try: convert பண்ணி, total-ல சேர்
ஒவ்வொரு row-க்கும் -[work ஆனா]-> Summary | collect ஆன total
ஒவ்வொரு row-க்கும் -[except: bad row-வை note பண்ணி, தொடர்ந்து போ]-> problems.csv | check பண்ண 3 rows
```

இந்த lesson-ல Mysuru-ல ஒரு music school-ல fees பார்க்குற Sana-வை follow பண்றோம். முதல் bad row-லயே crash ஆன script-ஐ, வேலையை முடிச்சு, எதை check பண்ணணும்னு list போடுற script-ஆ அவங்க மாத்துறாங்க. Lesson முடியும்போது, messy CSV-ஐ safe-ஆ process பண்ண முடியும்.

## இது எப்படி work ஆகுது

### `with` வச்சு files-ஐ திறக்கிறது

```python
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
```

Block முடிஞ்சதும் `with` file-ஐ தானா close பண்ணும், உள்ள error வந்தாலும். எப்பவும் `encoding="utf-8"` set பண்ணுங்க, முக்கியமா இந்திய மொழி text, ₹ மாதிரி symbols இருந்தா. இல்லன்னா உங்க laptop-ல ஓடுற file, உங்க colleague-ஓட laptop-ல fail ஆகலாம்.

### File modes

| Mode | அர்த்தம் | ஆபத்து |
| --- | --- | --- |
| `"r"` | படிக்க (default) | File இல்லன்னா fail ஆகும் |
| `"w"` | எழுத, file-ல ஏற்கனவே இருக்குற எல்லாத்தையும் **replace** பண்ணும் | இருக்குற report-ஐ `"w"`-ல திறந்தா அழிஞ்சுடும் |
| `"a"` | கடைசியில சேர்க்க | Logs-க்கு safe |
| `"x"` | புது file உருவாக்கும், ஏற்கனவே இருந்தா fail ஆகும் | Overwrite ஆகாம தடுக்க useful |

### Line by line படிக்கிறது

```python
with open("big_log.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())     # strip removes the newline at the end
```

இதுல எல்லாத்தையும் ஒரே நேரத்துல memory-ல load பண்ணாம, ரொம்ப பெரிய files-ஐயும் handle பண்ணலாம்.

### CSV files

CSV file-னா text-ஆ save பண்ண ஒரு table: ஒரு line-க்கு ஒரு row, fields-க்கு நடுவுல commas. Commas வச்சு நீங்களே split பண்ணாம `csv` module-ஐ use பண்ணுங்க, ஏன்னா address மாதிரி fields-ல quotes-க்குள்ளயே commas இருக்கலாம்:

```text
name,address,amount
Asha,"12, MG Road, Mysuru",1500
```

```python
import csv
with open("orders.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["customer"], row["amount"])
```

`csv.DictReader` ஒவ்வொரு row-வையும், header-ஐ key-ஆ வச்ச dictionary-ஆ கொடுக்கும். `csv.DictWriter` dictionaries-ல இருந்து rows எழுதும். ஒண்ணை கவனிங்க: ஒவ்வொரு value-உம் **text**-ஆ தான் வரும்: "1500", 1500 இல்லை. Maths பண்றதுக்கு முன்னாடி convert பண்ணுங்க.

### Exceptions

ஏதாவது fail ஆனா, Python **exception-ஐ raise பண்ணும்**: ஒரு type-உம் message-உம் இருக்குற error object. பொதுவா வர்றது:

| Exception | பொதுவான காரணம் |
| --- | --- |
| `FileNotFoundError` | File பெயர் அல்லது folder தப்பு |
| `ValueError` | `int("twenty")` அல்லது `float("NA")`: text number இல்லை |
| `KeyError` | Dictionary அல்லது CSV row-ல அந்த key, column இல்லை |
| `ZeroDivisionError` | Zero-ஆல வகுக்கிறது, உதாரணம்: காலி list-ஓட average |
| `TypeError` | Number-ஓட text-ஐ கூட்டுறது |

நீங்க எதிர்பார்க்குற specific exceptions-ஐ catch பண்ணி, என்ன பண்ணணும்னு முடிவு பண்ணுங்க:

```python
try:
    age = int("twenty")
except ValueError:
    age = -1          # mark as invalid instead of crashing
print(age)            # -1
```

எல்லாத்தையும் இல்லாம, specific exceptions-ஐ மட்டும் catch பண்ணுங்க. Bare `except:` variable பெயர் தப்பா எழுதுற மாதிரி real bugs-ஐயும் மறைச்சுடும். எப்பவும் ஓடணும்னு நினைக்குற clean-up-க்கு `finally` use பண்ணுங்க, சொந்த errors-ஐ clear message-ஓட signal பண்ண `raise` use பண்ணுங்க:

```python
if amount < 0:
    raise ValueError(f"Negative amount on line {line_no}")
```

### Bad rows: collect பண்ணுங்க, crash ஆகாதீங்க

நிறைய rows-ஐ process பண்ணும்போது, ஒவ்வொரு row-வோட errors-ஐயும் தனியா handle பண்ணுங்க, failures-ஐ line numbers-ஓட collect பண்ணுங்க, கடைசியில report பண்ணுங்க. 400-ல ஒரு bad row மத்த 399-ஐ நிறுத்தக்கூடாது.

## ஒரு worked example

Sana Mysuru-ல ஒரு music school-ல fees பார்க்குறாங்க. ஒவ்வொரு மாசமும் bank `payments.csv` அனுப்பும். அவங்களுக்கு collect ஆன total-உம், கையால check பண்ண வேண்டிய rows list-உம் வேணும். முதல் script முதல் "NA"-லயே crash ஆச்சு; bad row-வை scroll பண்ணி தேடிக்கிட்டு இருந்தாங்க. புது script இதோ:

```python
import csv

total = 0
problems = []
try:
    with open("payments.csv", newline="", encoding="utf-8") as f:
        for line_no, row in enumerate(csv.DictReader(f), start=2):
            try:
                amount = float(row["amount"].replace(",", ""))
                total += amount
            except (ValueError, KeyError) as e:
                problems.append((line_no, row.get("student", "?"), str(e)))
except FileNotFoundError:
    print("payments.csv not found. Download it from the bank portal first.")
    raise SystemExit(1)

with open("problems.csv", "w", newline="", encoding="utf-8") as out:
    writer = csv.writer(out)
    writer.writerow(["line", "student", "error"])
    writer.writerows(problems)

print(f"Collected Rs {total:,.2f}; {len(problems)} rows need checking")
```

`enumerate(..., start=2)` rows-ஐ 2-ல இருந்து number பண்ணும், ஏன்னா file-ல line 1 header. அதனால Sana file-ஐ திறக்கும்போது பார்க்குற line numbers-ஓட இது ஒத்துப்போகும்.

| Run | Rows | Convert ஆனது | Problems | Result |
| --- | --- | --- | --- | --- |
| பழைய script | 412 | Row 37-ல நின்னுடுச்சு | Crash | Total இல்ல, row-வை கையால தேடணும் |
| புது script | 412 | 409 | 3 ("NA" ரெண்டு, ஒண்ணு காலி) | Total-உம் problems.csv-உம் |

இந்த மாசம் அவங்க அரை மணி நேரம் இழக்காம, அஞ்சு நிமிஷத்துல மூணு rows-ஐ சரி பண்றாங்க.

## பொதுவா பண்ற தப்புகள்

- **`with` மறந்துடுறது.** Files திறந்தே இருக்கலாம், data போகலாம்.
- **`"a"` வேணும்னு நினைச்சு `"w"` use பண்றது.** பழைய content நிரந்தரமா போயிடும்.
- **CSV lines-ஐ commas வச்சு split பண்றது.** `csv` module use பண்ணுங்க; quotes-க்குள்ள இருக்குற commas உங்க split-ஐ உடைச்சுடும்.
- **CSV values text-ஆ வரும்னு மறந்துடுறது.** Maths பண்றதுக்கு முன்னாடி `int()` அல்லது `float()`-ல convert பண்ணுங்க.
- **Bare `except`-ல எல்லாத்தையும் catch பண்றது.** நீங்க எதிர்பார்க்குற specific exceptions-ஐ மட்டும் catch பண்ணுங்க.
- **முதல் bad row-லயே நின்னுடுறது.** Failures-ஐ collect பண்ணிட்டு தொடர்ந்து ஓடுங்க.

2. **Bad rows.** மூணு bad rows சேருங்க: amount இல்லாதது, number-க்கு பதிலா text, ஒரு column இல்லாதது. Program crash ஆகாம அதை report பண்ற மாதிரி பண்ணுங்க.
3. **File இல்லாதது.** Input file இல்லன்னா, traceback-க்கு பதிலா clear message காட்டுற மாதிரி handle பண்ணுங்க.

**முடிஞ்சதுன்னு எப்போ சொல்லலாம்:** Messy CSV-ஐ safe-ஆ process பண்ண முடியும், `with`-உம் specific `except` clauses-உம் ஏன் முக்கியம்னு explain பண்ண முடியும்.
