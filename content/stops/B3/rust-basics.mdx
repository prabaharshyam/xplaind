## What it is

This lesson covers the everyday building blocks of Rust: variables, types, functions, decisions and loops. If you know Python or JavaScript, most of it will feel familiar. Three things will not: variables cannot change unless you say so, every value has a fixed type, and the compiler checks a great deal before your program ever runs.

You will use **Cargo** throughout. Make a project with `cargo new budget`, open `src/main.rs`, and run it with `cargo run`.

```text
 cargo new budget
 budget/
 ├── Cargo.toml      <- name, version, dependencies (crates)
 └── src/
     └── main.rs     <- fn main() { ... } runs first

 cargo run  =  compile (catches mistakes)  ->  run the program
```

## How it works

**Variables.** `let` creates a variable. It is immutable by default:

```rust
let city = "Pune";          // cannot change
let mut orders = 0;         // mut means it can change
orders += 1;
```

Immutability is a safety habit: values that never change cannot be changed by surprise. **Shadowing** lets you reuse a name with `let` again, often to change its type:

```rust
let qty = "3";                    // text from the user
let qty: u32 = qty.parse().unwrap(); // now a number
```

**Types.** Rust knows every value's type at compile time. Usually it works it out for you; sometimes you write it.

| Kind | Types | Example |
|---|---|---|
| Whole numbers | i8, i16, i32, i64, i128, u8 to u128, isize, usize | `let age: u8 = 23;` |
| Decimals | f32, f64 | `let gst = 0.18;` |
| True or false | bool | `let paid = true;` |
| One character | char | `let grade = 'A';` |
| Text | String (owned), &str (borrowed) | `let name = String::from("Riya");` |
| Fixed group | tuple, array | `let point = (3, 4); let marks = [72, 88, 91];` |
| Growable list | `Vec<T>` | `let mut cart = vec![499, 1299];` |

Unsigned types (`u`) cannot be negative. `usize` is the type for indexes and lengths.

**Functions** declare their parameter and return types. The last expression, without a semicolon, is the return value:

```rust
fn with_gst(price: f64) -> f64 {
    price * 1.18
}
```

**if is an expression,** so it can produce a value:

```rust
let label = if total > 5000.0 { "big order" } else { "small order" };
```

**Loops.** `for` loops over anything iterable: a range like `1..=12` or a vector. `while` runs while a condition holds; `loop` runs until `break`, and can return a value from `break`.

```rust
for month in 1..=12 {
    println!("Month {month}");
}
```

**Printing.** `println!("{}", x)` prints a value; `{:?}` prints a debug view of things like vectors; `{x}` puts a variable straight into the text. The `!` means `println!` is a macro, code that writes code.

## A worked example

Kiran, a final-year student in Coimbatore, tracks his monthly spending. He writes his first useful Rust program:

```rust
fn main() {
    let budget: u32 = 12_000;
    let expenses = vec![3500, 4200, 1800, 2600];

    let mut total: u32 = 0;
    let mut largest: u32 = 0;
    for amount in &expenses {
        total += amount;
        if *amount > largest {
            largest = *amount;
        }
    }

    let average = total as f64 / expenses.len() as f64;
    println!("Total: Rs {total}");
    println!("Average: Rs {average:.0}");
    println!("Largest: Rs {largest}");

    if total > budget {
        println!("Over budget by Rs {}", total - budget);
    } else {
        println!("Within budget, Rs {} left", budget - total);
    }
}
```

A few details are worth noticing. `12_000` uses underscores for readability. `for amount in &expenses` borrows the vector, so it is still usable afterwards. `*amount` reads the value behind the borrow. `as f64` converts integers so the average keeps its decimals. `{average:.0}` prints with no decimal places.

His first attempt forgot `mut` on `total`. The compiler stopped him with "cannot assign twice to immutable variable" and suggested the fix. That message is typical: Rust's errors explain the problem and usually show the change to make.

Later he swaps the loop for iterator methods, which do the same work in one line each:

```rust
let total: u32 = expenses.iter().sum();
let largest = expenses.iter().max().unwrap();
```

**Constants and comments.** A `const` is fixed forever and must have a type, written in capitals: `const GST_RATE: f64 = 0.18;`. Comments start with `//`. Comments that start with `///` become documentation that `cargo doc` turns into a web page, which is how every crate on docs.rs gets its reference pages.

**Formatting and lint.** Run `cargo fmt` to format your code the standard way and `cargo clippy` for friendly advice on more idiomatic Rust. Most teams run both before every commit, so it is a good habit from day one.

## Common mistakes

**Forgetting `mut`.** If you plan to change a value, declare it with `let mut`. The compiler will tell you, but it is quicker to think about it up front.

**A stray semicolon at the end of a function.** `n * 2;` returns nothing. The compiler error about "mismatched types, expected i32, found ()" usually means this.

**Mixing integer and float maths.** `total / count` with integers drops the decimals. Convert with `as f64` first.

**Indexing past the end.** `marks[10]` on a 3-item array panics at run time. Use `marks.get(10)`, which returns an `Option` you can check.

**Ignoring the error text.** Rust's messages are long because they are helpful. Read them to the end; the "help:" line usually holds the answer.

**Comparing different number types.** `let a: u32 = 5; let b: i64 = 5; a == b` does not compile. Rust never converts numbers silently, because silent conversions cause real bugs. Convert one side with `as` or `.into()`.
