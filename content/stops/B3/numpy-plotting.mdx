## What it is

Machine learning is maths on large tables of numbers, and in Python that maths runs on **NumPy**, the library for fast numerical arrays. pandas, scikit-learn and PyTorch all build on its ideas, so the habits you learn here carry straight into model work. **Matplotlib** is the standard plotting library; others such as Seaborn and Plotly use similar ideas.

The core skills:

| Skill | What it means | Example |
| --- | --- | --- |
| **Arrays and shapes** | Create arrays and know their dimensions | `X.shape` is `(50000, 3)` |
| **Vectorisation** | Do maths on whole arrays at once | `prices * 1.18` |
| **Broadcasting** | Combine arrays of different but compatible shapes | `X - X.mean(axis=0)` |
| **Masks and indexing** | Select data by condition or position | `y[y > 30]`, `X[:, 0]` |
| **Plotting** | See distributions, relationships and trends | histogram, scatter, line, box plot |

```text
  X: shape (5, 3)                          means: shape (3,)
   distance  items  hour                   [ 4.2,  3.0, 15.4 ]
  [  2.1      1     13 ]                          |
  [  6.8      4     19 ]     X - means            | broadcast to every row
  [  3.0      2     11 ]   ------------>          v
  [  5.5      5     20 ]                   result: shape (5, 3), each column centred
  [  3.6      3     14 ]
```

This lesson follows a quick-commerce company in Bengaluru as two simple plots reveal a logging bug and a hidden factor in delivery times. By the end you will explore a new dataset with three plots and name a data problem you found.

## How it works

### Arrays and shapes

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
print(a.shape)          # (2, 2)
```

A dataset of 10,000 customers with 12 features has shape `(10000, 12)`. A single row is shape `(12,)`. Most bugs in numerical code are shape mismatches, so print `.shape` often.

### Vectorisation

```python
prices = np.array([120, 450, 999])
with_gst = prices * 1.18            # every element at once
print(np.mean(prices), np.std(prices), np.percentile(prices, 90))
```

Vectorised code is shorter than a loop and often tens of times faster on large arrays, because the work happens in optimised code underneath.

The **axis** argument decides the direction:

| Call | Result |
| --- | --- |
| `X.mean()` | One number: the mean of everything |
| `X.mean(axis=0)` | One value per column: the mean of each feature |
| `X.mean(axis=1)` | One value per row: the mean of each record |

### Broadcasting

NumPy stretches a smaller array to match a bigger one when shapes are compatible. Subtracting the column means from a `(10000, 12)` array with a `(12,)` array centres every column in one line:

```python
Z = (X - X.mean(axis=0)) / X.std(axis=0)    # each column: mean 0, std 1
```

### Indexing and slicing

Arrays are indexed by position, starting at 0, with one index per dimension:

```python
X[0]          # the first row: all features of the first record
X[:, 0]       # the first column: one feature for every record
X[10:20, 1:]  # rows 10 to 19, and every column from the second onwards
X[-1]         # the last row
```

The colon means "everything along this dimension". Reading `X[:, 0]` aloud as "every row, column zero" helps. Slices are views, not copies: changing a slice changes the original array, so use `.copy()` when you need an independent piece.

### Boolean masks

```python
incomes = np.array([18000, 52000, 75000, 31000])
print(incomes[incomes > 50000])                     # [52000 75000]
print(incomes[(incomes > 20000) & (incomes < 60000)])
```

Use `&` for "and" and `|` for "or", with brackets around each condition.

### Reproducible random numbers

`rng = np.random.default_rng(42)` gives a random generator you can repeat exactly, for sampling data or splitting it into training and test sets.

### Plots that matter in machine learning

| Plot | Shows | Typical finding |
| --- | --- | --- |
| **Histogram** | The distribution of one feature | Skew, outliers, impossible values like zeros |
| **Scatter plot** | The relationship between two features, or a feature and the target | A curve, a cluster, a break at some value |
| **Line chart** | Values over time | Seasonality, a sudden drop, training loss by epoch |
| **Box plot** | Distributions across groups | One city's deliveries much slower than others |

Always label axes and units, and use a **log scale** for very skewed data such as order values.

## A worked example

A quick-commerce company in Bengaluru wants to predict delivery time. You load 50,000 deliveries into arrays: distance in km, number of items, hour of day, and the actual minutes taken.

```python
import numpy as np
import matplotlib.pyplot as plt

# X (distance, items, hour) and y (minutes) were loaded earlier
print(X.shape, y.shape)                  # (50000, 3) (50000,)
print(np.percentile(y, [50, 90, 99]))    # median 14, p90 24, p99 61 minutes

plt.hist(y, bins=60)
plt.xlabel("Delivery time (minutes)"); plt.ylabel("Orders")
plt.show()

plt.scatter(X[:, 0], y, s=2, alpha=0.3)
plt.xlabel("Distance (km)"); plt.ylabel("Minutes")
plt.show()
```

**What the histogram shows.** A long tail of slow deliveries, as expected, and a strange spike at exactly 0 minutes: 412 deliveries recorded as taking no time. That is a logging bug, not a miracle.

**What the scatter plot shows.** Times rise steadily with distance up to about 6 km, then jump. Checking those orders, you find they came from a different dark store with fewer riders.

| Plot | Finding | Change to the model |
| --- | --- | --- |
| Histogram of minutes | 412 deliveries at 0 minutes | Drop or fix those rows; report the bug |
| Scatter of distance vs minutes | Jump beyond 6 km | Add a "store" feature |
| Percentiles | p99 is 61 minutes | Report errors at p90 and p99, not just the average |

No single metric would have shown these as clearly as two plots, in five minutes, before any model was trained.

## Common mistakes

- **Python loops over arrays.** Vectorise; it is shorter and much faster.
- **Ignoring shapes.** Print them, and check broadcasting does what you expect.
- **Modelling before plotting.** Plots reveal bugs, outliers and leakage early.
- **Unlabelled charts.** Axes and units make plots readable to others.
- **Linear scales on skewed data.** Use log scales where values span orders of magnitude.
- **Mixing up axis=0 and axis=1.** Check the result's shape to confirm the direction.
