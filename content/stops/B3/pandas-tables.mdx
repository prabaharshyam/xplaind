## What it is

Most data in business lives in tables: sales exports, customer lists, attendance sheets, survey results. **pandas** is the Python library for working with tables. Its main object, the **DataFrame**, holds rows and named columns, like a spreadsheet you control with code.

```text
            DataFrame: df
   index | date       | store       | item         | amount
  -------+------------+-------------+--------------+--------
     0   | 2026-10-01 | RS Puram    | Glucometer   | 1250.0
     1   | 2026-10-01 | Gandhipuram | Paracetamol  |   40.0
     2   | 2026-10-02 | RS Puram    | Insulin pen  | 2100.0
          ^ columns have names; rows have an index
```

With a few lines you can load a CSV or Excel file, clean it, filter rows, group and summarise, join tables and save the result. Unlike a spreadsheet, the steps are written down, so next month's report is one command, not a day of clicking.

For AI work, pandas is how you prepare training data, inspect model outputs and build evaluation reports.

This lesson follows Lakshmi, who manages five pharmacies in Coimbatore, as she turns a monthly 40,000-row export into answers in seconds. By the end you will load a messy CSV, clean it and produce a grouped summary you can rerun.

## How it works

### Load and look

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()           # first five rows
df.info()           # columns, types, missing values
df.describe()       # quick statistics for number columns
```

Always look before you calculate. `info()` tells you if a column you expected to be numbers was read as text.

### Select columns and filter rows

```python
df["city"]                                        # one column
df[["city", "sales"]]                             # several columns
df[df["age"] > 30]                                # rows where age is above 30
df[(df["city"] == "Pune") & (df["sales"] > 5000)] # two conditions
```

Use `&` for "and" and `|` for "or", with brackets around each condition. Plain `and` and `or` do not work here.

### Missing values

Empty or unreadable cells appear as **NaN** ("not a number"). Find them with `df.isna().sum()`. Then decide deliberately: fill them with `fillna`, drop the rows with `dropna`, or flag them for someone to check.

### Fix types

| Problem | Fix |
| --- | --- |
| Amounts like "1,250" read as text | `pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")` |
| Dates like 05/11/2026 | `pd.to_datetime(df["date"], dayfirst=True)` |
| PIN codes losing leading zeros | `pd.read_csv(..., dtype={"pin": str})` |

`errors="coerce"` turns anything unreadable into NaN instead of crashing, so you can count and report bad rows.

### New columns

```python
df["gst"] = df["sales"] * 0.18
df["month"] = pd.to_datetime(df["date"], dayfirst=True).dt.month
```

### Group and summarise

```python
df.groupby("city")["sales"].sum()                                # total per city
df.groupby(["city", "month"])["sales"].agg(["sum", "mean", "count"])
```

```text
   all rows  --> split by city -->  Pune: [..]  Nagpur: [..]  Nashik: [..]
                                       |            |              |
                                     sum()        sum()          sum()
                                       v            v              v
                                   Pune 4.2L   Nagpur 3.1L   Nashik 2.7L
```

### Sort and save

```python
df.sort_values("sales", ascending=False).head(10)
df.to_csv("clean_sales.csv", index=False)
```

### Reshape with pivot tables

Spreadsheet users love pivot tables, and pandas has them too:

```python
df.pivot_table(index="store", columns="month", values="amount", aggfunc="sum")
```

This gives one row per store and one column per month, with totals in each cell. It is often the clearest way to show a trend to a manager. Add `margins=True` for row and column totals.

### Work with dates

Once a column is a real date, pandas can do a lot with it:

```python
df["date"] = pd.to_datetime(df["date"], dayfirst=True)
df["weekday"] = df["date"].dt.day_name()             # Monday, Tuesday...
weekly = df.set_index("date").resample("W")["amount"].sum()
```

`resample("W")` adds up sales week by week; use `"MS"` for calendar months. This is how you spot that Sunday sales are always low, or that the week before Diwali is the year's peak.

### Join tables

```python
pd.merge(orders, customers, on="customer_id", how="left")
```

| `how=` | Keeps |
| --- | --- |
| `"inner"` | Only rows that match in both tables |
| `"left"` | Every row of the left table, with blanks where there is no match |
| `"outer"` | Every row of both tables |

Inner joins can drop rows silently. Check row counts before and after merging.

## A worked example

Lakshmi manages a chain of five pharmacies in Coimbatore. Each month she receives a sales export of about 40,000 rows and used to spend a day summarising it in a spreadsheet.

```python
df = pd.read_csv("sales_oct.csv")
df["amount"] = pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")
print(df["amount"].isna().sum(), "rows with unreadable amounts")

by_store = df.groupby("store")["amount"].sum().sort_values(ascending=False)
print(by_store)

top_items = (df[df["category"] == "Diabetes care"]
             .groupby("item")["amount"].sum()
             .sort_values(ascending=False).head(5))
print(top_items)
```

**What she learns:**

| Question | Answer |
| --- | --- |
| Rows with unreadable amounts | 37, all "NA" from one till's error; reported to that store |
| Highest-selling store | RS Puram |
| Diabetes-care sales at RS Puram compared with the others | About 40% higher |
| Top diabetes-care item | Glucometer strips |

The 40% gap leads her to move stock of diabetes-care products between stores, so the other branches stop running out while RS Puram stops overstocking. The analysis that took her a day now runs in seconds each month, and because the steps are in code, November's report is the same script with a new file name.

### Check your work

Before you send numbers to anyone, check them. Compare the grand total with the total in the source system. Count rows before and after every filter and merge, and explain any change. Look at the five largest and five smallest values for mistakes, such as a price entered in paise instead of rupees. And recompute one number by hand. These checks take a few minutes and save you from the embarrassment of a wrong report reaching the owner.

## Common mistakes

- **Not checking types.** Numbers read as text, because of commas, cannot be summed. Convert them.
- **Ignoring missing values.** Decide whether to fill, drop or flag them, and say which.
- **Wrong date order.** Indian dates are day first; use `dayfirst=True` or an explicit format.
- **Using `and` instead of `&` in filters.** Use `&` and `|` with brackets.
- **Inner joins that drop rows silently.** Check row counts before and after merging.
- **Editing the original file.** Save cleaned data to a new file and keep the raw export untouched.
