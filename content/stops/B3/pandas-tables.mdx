## What it is

**pandas** is the Python library for working with tables. Its main object, the **DataFrame**, holds rows and named columns, like a spreadsheet you can control with code. With a few lines you can load a CSV or Excel file, clean it, filter rows, group and summarise, join tables and save the result.

For AI work, pandas is how you prepare data, inspect model outputs and build evaluation reports.

## How it works

**Load and look.**

```python
import pandas as pd

df = pd.read_csv("sales.csv")
df.head()           # first five rows
df.info()           # columns, types, missing values
df.describe()       # quick statistics for number columns
```

**Select columns and filter rows.**

```python
df["city"]                         # one column
df[["city", "sales"]]              # several columns
df[df["age"] > 30]                 # rows where age is above 30
df[(df["city"] == "Pune") & (df["sales"] > 5000)]
```

Use `&` and `|` with brackets around each condition.

**Missing values.** Empty cells appear as `NaN` (not a number). Find them with `df.isna().sum()`; fill with `fillna` or drop rows with `dropna`, deciding deliberately which makes sense.

**New columns.**

```python
df["gst"] = df["sales"] * 0.18
df["month"] = pd.to_datetime(df["date"], dayfirst=True).dt.month
```

**Group and summarise.**

```python
df.groupby("city")["sales"].sum()              # total sales per city
df.groupby(["city", "month"])["sales"].agg(["sum", "mean", "count"])
```

**Sort and save.**

```python
df.sort_values("sales", ascending=False).head(10)
df.to_csv("clean_sales.csv", index=False)
```

**Join tables.** `pd.merge(orders, customers, on="customer_id", how="left")` adds customer details to orders, keeping orders without a match.

## A worked example

Lakshmi manages a chain of five pharmacies in Coimbatore and receives a monthly sales export of 40,000 rows.

```python
df = pd.read_csv("sales_oct.csv")
df["amount"] = pd.to_numeric(df["amount"].str.replace(",", ""), errors="coerce")
print(df["amount"].isna().sum(), "rows with unreadable amounts")

by_store = df.groupby("store")["amount"].sum().sort_values(ascending=False)
print(by_store)

top_items = (df[df["category"] == "Diabetes care"]
             .groupby("item")["amount"].sum()
             .sort_values(ascending=False).head(5))
print(top_items)
```

She finds 37 rows where the amount column contained "NA" from a till error, reports them to the store, and learns that the RS Puram store sold 40% more diabetes-care products than the others, which leads her to adjust stock across stores. The analysis that took her a day in a spreadsheet now runs in seconds each month.

## Common mistakes

- **Not checking types.** Numbers read as text (because of commas) cannot be summed. Convert them.
- **Ignoring missing values.** Decide whether to fill, drop or flag them.
- **Wrong date order.** Indian dates are day first; use `dayfirst=True` or an explicit format.
- **Using `and` instead of `&` in filters.** Use `&` and `|` with brackets.
- **Inner joins that drop rows silently.** Check row counts before and after merging.
