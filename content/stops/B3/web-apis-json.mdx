Read the quickstart and run the examples. Pay attention to the sections on JSON, status codes and timeouts.

**Do this**

Pick a free public API that needs no key and write a script that calls it, stops with a clear message if the status is not 200, and prints two values from the JSON.

**You are done when you can** explain what a status code of 200, 404 and 429 mean.
