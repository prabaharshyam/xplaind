## What it is

To write Python you need three things on your computer:

- **Python itself**: the program that reads and runs your code.
- **A code editor**: where you write code, such as Visual Studio Code (free), which highlights mistakes and helps with typing.
- **A terminal**: a text window where you type commands, including the command that runs your file.

Once these work, the loop of every programmer begins: write a file, run it, read the output, fix, run again.

## How it works

**Install Python.** On Windows, download the installer from python.org and tick "Add python.exe to PATH" on the first screen; that tick lets the terminal find Python. On a Mac, use the python.org installer. Most Linux systems already have Python 3. Check by opening a terminal and typing `python --version` (or `python3 --version` on Mac and Linux). You should see a version starting with 3.

**Install an editor.** Install VS Code and its Python extension. Open a folder for your work (for example `python-practice`) with File, Open Folder.

**Write your first file.** Create `hello.py`:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

**Run it from the terminal.** Open the terminal inside VS Code (View, Terminal). Make sure you are in the folder with your file; `cd` changes folder and `ls` (Mac, Linux) or `dir` (Windows) lists files. Then type `python hello.py` and press Enter. The output appears below.

**Read error messages.** If something is wrong, Python prints a traceback. Read the last line first: it names the error (`NameError`, `SyntaxError`) and the line number points to where Python noticed it. Most beginner errors are typos, a missing bracket or quote, or wrong indentation.

**Other ways to run Python.** Online notebooks such as Google Colab and Kaggle let you run Python in a browser without installing anything; useful if your computer is locked down or old. Still learn to run files from a terminal; real projects work that way.

## A worked example

Karthik, a commerce graduate in Madurai, sets up Python on his Windows laptop.

1. He downloads Python from python.org, ticks "Add python.exe to PATH", and installs.
2. In a new terminal, `python --version` prints `Python 3.13.1`.
3. He installs VS Code and the Python extension, creates a `python-practice` folder and `hello.py` with the code above, using his own name.
4. He runs `python hello.py` and sees an error: `python: can't open file 'hello.py': No such file or directory`. The terminal was in his home folder. He runs `cd python-practice`, then the command again. It works.
5. He changes the code to print his name in Tamil script as well, runs it again, and it prints correctly.

He pushes the file to a new GitHub repository to share it, which the next lessons cover in more detail.

## Common mistakes

- **Forgetting "Add to PATH" on Windows.** The terminal then says Python is not found. Reinstall with the box ticked.
- **Running from the wrong folder.** Check where you are with `pwd` or `cd` before running.
- **Saving the file with a .txt ending.** It must end in `.py`.
- **Panicking at red text.** Read the last line of the error and the line number.
- **Mixing tabs and spaces.** Let the editor indent for you.
