Install Python 3 from python.org and a free editor such as VS Code. On Windows, tick "Add Python to PATH" in the installer.

**Do this**

1. Make a folder called `learning-python`.
2. In it, create `hello.py` with one line: `print("Hello from <your name>")`.
3. Open a terminal in that folder and run `python hello.py` (on some Macs, `python3 hello.py`).

If you see an error, copy the exact message into a search engine. Almost every setup error has been solved before.
