## What it is

Before you can write programs, you need a place to write them and a way to run them. Every Python programmer, from a student to an AI engineer at a large company, works with the same three things:

| Tool | What it is | Example |
| --- | --- | --- |
| **Python** | The program that reads and runs your code | Python 3, from python.org |
| **A code editor** | Where you write code; it highlights mistakes and helps you type | Visual Studio Code (VS Code), free |
| **A terminal** | A text window where you type commands, including the one that runs your file | The terminal inside VS Code |

Once all three work, the loop every programmer lives in begins:

```text
    +----------+      +----------+      +---------------+      +--------+
    |  Write   | ---> |   Run    | ---> |  Read output  | ---> |  Fix   |
    |  a file  |      |  it      |      |  or the error |      |        |
    +----------+      +----------+      +---------------+      +--------+
         ^                                                          |
         +----------------------------------------------------------+
```

This lesson follows Karthik, a commerce graduate in Madurai, as he sets up Python on his Windows laptop and hits the two most common beginner problems. Its check is a small project: your own first file, run from the terminal and shared online.

## How it works

### Install Python

| Computer | How |
| --- | --- |
| Windows | Install the **Python install manager** from python.org or the Microsoft Store. It sets up the `python` and `py` commands. If you use the older full installer instead, tick **"Add python.exe to PATH"** on its first screen. |
| Mac | Download the installer from python.org and run it. |
| Linux | Python 3 is usually already installed. |

With the older full installer, the PATH tick matters: it lets the terminal find Python when you type `python`. Without it, the terminal says Python is not recognised.

Check the install by opening a terminal and typing:

```text
python --version
```

On Mac and Linux, type `python3 --version`. You should see a version starting with 3, such as `Python 3.15.2`.

### Install an editor

Install VS Code and its **Python extension**. Then make a folder for your work, such as `python-practice`, and open it with File, Open Folder. Keeping each project in its own folder avoids a lot of confusion later.

### Write your first file

Create a file called `hello.py` in that folder:

```python
from datetime import date

name = "Priya"
print("Hello, my name is", name)
print("Today is", date.today())
```

The `.py` ending tells Python and your editor that this is Python code.

### Run it from the terminal

Open the terminal inside VS Code with View, Terminal. The terminal always works "in" one folder. Make sure it is the folder with your file:

| Command | Windows | Mac and Linux |
| --- | --- | --- |
| Where am I? | `pwd` in PowerShell (the VS Code default), `cd` in Command Prompt | `pwd` |
| List files here | `dir` | `ls` |
| Go into a folder | `cd python-practice` | `cd python-practice` |
| Go up one folder | `cd ..` | `cd ..` |
| Run a file | `python hello.py` | `python3 hello.py` |

Type `python hello.py` and press Enter. The output appears below.

### Read error messages

If something is wrong, Python prints a **traceback**. Read the **last line first**: it names the error. The line number above it shows where Python noticed the problem.

```text
  File "hello.py", line 4
    print("Today is", date.today()
                                  ^
SyntaxError: '(' was never closed
```

Most beginner errors are one of these:

| Error | Usual cause |
| --- | --- |
| `SyntaxError` | A missing bracket, quote or colon |
| `IndentationError` | Wrong or mixed indentation |
| `NameError` | A misspelt variable or a variable used before it was created |
| `can't open file` | The terminal is in the wrong folder, or the file name is wrong |

### Other ways to run Python

Online notebooks such as **Google Colab** and **Kaggle** run Python in a browser without installing anything. They are useful if your computer is locked down or old, and for data work. Still, learn to run files from a terminal: real projects, servers and AI applications work that way.

## A worked example

Karthik, a commerce graduate in Madurai, sets up Python on his Windows laptop one evening.

**Step 1: install.** He downloads the full installer from python.org, ticks "Add python.exe to PATH" and installs. (The Python install manager would also work and needs no tick.)

**Step 2: check.** In a new terminal, `python --version` prints `Python 3.15.2`. If he had forgotten the PATH tick, this is where he would have seen "python is not recognized".

**Step 3: editor and file.** He installs VS Code and the Python extension, creates a `python-practice` folder, and writes `hello.py` with the code above, using his own name.

**Step 4: the first error.** He types `python hello.py` and sees:

```text
python: can't open file 'C:\Users\karthik\hello.py': [Errno 2] No such file or directory
```

The terminal was in his home folder, not in `python-practice`. He types `cd python-practice`, then runs the command again. It works:

```text
Hello, my name is Karthik
Today is 2026-11-03
```

**Step 5: a change.** He adds a line to print his name in Tamil script as well, runs it again, and it prints correctly because VS Code saves files in UTF-8.

| Problem | Message he saw | Fix |
| --- | --- | --- |
| Terminal in the wrong folder | `can't open file ... No such file or directory` | `cd python-practice` |
| (Avoided) PATH not set | `python is not recognized` | Reinstall with the PATH box ticked |

Finally, he creates a GitHub account and puts `hello.py` in a new repository, so he has a link to share. That link is this lesson's check.

## Common mistakes

- **Forgetting "Add to PATH" with the older Windows installer.** The terminal then says Python is not found. Reinstall with the box ticked and open a new terminal.
- **Running from the wrong folder.** Check where you are with `pwd` (or `cd` in Command Prompt) before running.
- **Saving the file with a .txt ending.** It must end in `.py`. Turn on "show file extensions" on Windows to see it.
- **Panicking at red text.** Read the last line of the error and the line number.
- **Mixing tabs and spaces.** Let the editor indent for you.
- **Installing many Python versions at once.** One recent Python 3 is enough to start.
