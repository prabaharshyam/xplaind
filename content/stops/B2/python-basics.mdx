## What it is

Five building blocks let you write useful short programs in Python:

- **Variables** store values under a name: `price = 250`.
- **Conditions** choose what to do: `if price > 200:`.
- **Loops** repeat steps: `for item in cart:`.
- **Functions** package steps you can reuse: `def total(cart):`.
- **Lists and dictionaries** hold many values: a list of prices, a dictionary of a student's details.

Together they cover most of what scripts for data cleaning, automation and calling AI APIs need.

## How it works

**Values and types.** Numbers (`250`, `18.5`), text in quotes (`"Chennai"`), and `True` or `False`. Python works out the type from the value. Convert between them with `int("42")`, `float("3.5")`, `str(42)`.

**Variables.** A variable is a label for a value; assigning again changes what it points to. Use clear names: `monthly_rent`, not `x`.

**Conditions.**

```python
marks = 72
if marks >= 75:
    print("Distinction")
elif marks >= 60:
    print("First class")
else:
    print("Pass")
```

Indentation (four spaces) shows which lines belong to the `if`. Python takes it seriously.

**Loops.** A `for` loop runs once per item:

```python
for i in range(3):
    print(i)        # prints 0, 1, 2 on separate lines
```

`range(3)` gives 0, 1 and 2: it starts at 0 and stops before 3. A `while` loop repeats while a condition is true.

**Functions.** A function takes inputs and `return`s a result:

```python
def double(x):
    return x * 2

print(double(4))    # 8
```

**Lists.** Ordered collections: `cities = ["Pune", "Kochi"]`; add with `cities.append("Jaipur")`; the first item is `cities[0]`.

**Dictionaries.** Look up values by key:

```python
profile = {"name": "Asha", "age": 24}
profile["city"] = "Pune"        # add or change a key
print(profile["name"])          # Asha
```

## A worked example

Divya runs a small tiffin service in Bengaluru and keeps orders in her head. She writes her first useful program:

```python
orders = [
    {"customer": "Ravi", "meals": 2, "veg": True},
    {"customer": "Sana", "meals": 1, "veg": False},
    {"customer": "Arun", "meals": 3, "veg": True},
]
PRICE_VEG = 90
PRICE_NONVEG = 120

def bill(order):
    price = PRICE_VEG if order["veg"] else PRICE_NONVEG
    return order["meals"] * price

total = 0
for order in orders:
    amount = bill(order)
    total = total + amount
    print(order["customer"], "owes Rs", amount)

print("Today's total: Rs", total)
```

It prints each customer's bill and the day's total of ₹570. When prices change she edits two lines. Next she plans to read orders from a CSV file instead of typing them in, which the later lessons cover.

## Common mistakes

- **Wrong indentation.** Lines inside `if`, `for` and `def` must be indented consistently.
- **Off-by-one with `range`.** `range(3)` is 0, 1, 2.
- **Mixing text and numbers.** `"5" + 3` fails; convert first.
- **Using `=` in a condition.** Comparison is `==`.
- **`print` instead of `return` in a function.** Printing shows a value; returning hands it back for use.
