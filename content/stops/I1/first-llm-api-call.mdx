Follow the quickstart in Python. Keep your API key in an environment variable, never in your code or on GitHub.

**Do this**

Write a script that reads a question from the command line, sends it to the model with a short system prompt, prints the answer and prints how many input and output tokens it used.

Most providers' APIs look alike, so what you learn here carries over.
