Read the contextual retrieval article for what good looks like, then build the simplest version that works.

**Steps**

1. Load 20 or more documents and chunk them.
2. Embed the chunks and build an index.
3. For a question, retrieve the top chunks and pass them to the model with an instruction to answer only from them and cite the source.
4. Make it say "I don't know" when the chunks do not contain the answer.
