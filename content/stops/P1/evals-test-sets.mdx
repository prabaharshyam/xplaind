Read the evals article closely; it is the core of this level. Then read the evals section of the patterns article.

**Steps**

1. Collect 30 real or realistic inputs for one of your apps.
2. Write what a good answer must contain for each.
3. Write a script that runs the app on all 30 and scores each answer, with simple code checks first.
4. Change the prompt and show the score before and after.
