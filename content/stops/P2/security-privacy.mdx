Read the OWASP items on sensitive information disclosure, system prompt leakage and unbounded consumption.

**Check one of your apps**

- Are API keys only in environment settings, never in code or the browser?
- Do you send the model only the personal data the task needs?
- Can one user see another user's data?
- Is there a limit on how much one user can spend?
